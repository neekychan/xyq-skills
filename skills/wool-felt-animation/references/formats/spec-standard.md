# 视频规格标准
## 固定规格
- 画面比例：9:16 竖屏（短视频平台标准比例）
- 基准风格：内置羊毛毡定格动画风格，无需用户上传参考视频
- 分辨率：分镜视频默认720p，最终合成分辨率匹配分镜视频
- 帧率：默认24fps，符合动画流畅度标准

## 规格文档（Final_Video_Spec.md）必填字段
| 字段 | 说明 |
|---|---|
| 视频标题 | 根据文案内容提炼的简洁标题 |
| 画面比例 | 固定9:16竖屏 |
| 预计总时长 | 根据文案长度按5-6字/秒语速估算，可根据用户需求调整 |
| 主题情绪 | 核心情绪基调（温暖治愈/轻松欢快/怀旧感伤/幽默搞笑等） |
| 风格基准 | 羊毛毡定格动画，真实比例世界，非微缩/玩偶风格 |
| 旁白配置 | 是否需要旁白、旁白语言、配音风格 |
| BGM配置 | 是否需要BGM、音乐风格偏好 |
