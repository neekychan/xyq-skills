# 角色设计规范

## 核心流程
1. **2D原画生成**：大师级游戏角色概念设计图，明确角色职业、性别、核心视觉特征、服饰配色、武器装备，A-pose站立，完整展示全身造型，背景纯白。
2. **四视图生成**：基于原画生成标准角色四视图，分辨率2K，白底背景，严格遵循以下布局：
   - 左侧区域（占画面1/3宽度）：面部特写图，清晰展示面部细节、皮肤质感、妆容、发型、五官特征
   - 右侧区域（占画面2/3宽度）：横向依次排列
     - 全身正面图：A-pose站立，正面朝向镜头，完整展示正面服饰、装备、形体比例
     - 全身背面图：A-pose站立，背面朝向镜头，完整展示背面服饰、装备、发型背面
     - 全身侧面图：A-pose站立，侧面朝向镜头，完整展示侧面轮廓、装备厚度
3. **3D转换**：将四视图输入3D转换模型，生成真实感3D人物形象卡，保留所有材质细节和造型特征。

## 一致性硬规则
- 所有视图必须严格保持角色造型、配色、材质、装备位置与原画100%一致
- 服饰纹理、金属配饰、武器造型在所有视图中无偏差
- 形体比例统一，无透视变形导致的比例失调
- 3D转换后保留皮肤次表面散射、金属反射、布料纹理等真实材质特性

## 材质参数记录标准
3D形象卡生成后，必须提取并记录以下材质参数，供后续视频生成使用：
- 皮肤：粗糙度、次表面散射强度、肤色色值
- 金属：金属度、反射强度、高光颜色
- 布料：粗糙度、纹理密度、褶皱特征
- 毛发：高光方向、发丝粗细、颜色渐变
