# GPT Image 2 图片资产提示词规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

图片资产阶段负责生成"可被视频稳定引用"的图片资产。

## 图片资产类型

### 主角资产图

用于锁定角色长相、比例、材质和气质。

要求：
- 单角色，不要多人
- 不要三视图挤在一张图里
- 不要复杂动作
- 表情自然，五官清晰，造型完整
- 背景干净但不要死白——用柔和渐变背景或简单场景地面

### 场景资产图

用于锁定故事发生地点。

要求：
- 场景干净，主体空间明确
- 留出角色活动区
- 不要堆太多杂物
- 光线和色彩统一，有童话生活感

### 道具资产图

用于锁定关键互动对象。

要求：
- 单一或少量道具
- 形状简单，材质清楚
- 适合角色手持、靠近、观察、触碰
- 不要太小太复杂

### 首帧图

用于图生视频开头。

要求：
- 角色、场景、道具都在正确位置
- 动作处于"准备发生"的状态
- 构图稳定，情绪清楚
- 不要动作已经完成

### 尾帧图

用于锁定结尾氛围。

要求：
- 情绪已经完成，动作处于稳定停留
- 画面温暖，适合做封面和结尾循环
- 不要新增复杂动作

## 提示词公式

**通用公式**：主体 + 造型比例 + 表情情绪 + 场景 + 小故事事件 + 材质 + 光线 + 色彩 + 构图 + 风格 + 负面约束

风格参数必填（见 `references/formats/visual-style-params.md`）：
- 头身比（1:1.5-1:2）
- 眼睛大小（占脸部25%-35%）
- 四肢形态（短圆粗，无骨节）
- 边缘倒角（beveled edges）
- 材质粗糙度（按类型选择）
- 光线方向（侧前方45°柔和漫射光）
- 景深程度（浅景深f/1.8-2.8）

## 品牌风格禁止

严禁出现：Pixar/皮克斯/Disney/迪士尼/DreamWorks/梦工厂/Blender/Cycles及任何动画工作室名、电影名、IP角色名。用"原创软萌3D治愈动画风格"替代。

## 落 prompt 前自检

- 7项风格参数是否全部出现在提示词中？
- 角色一致性属性是否逐项写明（主色/服装/眼睛/耳朵尾巴/体型）？
- 是否有品牌名混入？
- 各类图的要求是否满足（如主角图不要三视图、首帧图动作未完成）？
