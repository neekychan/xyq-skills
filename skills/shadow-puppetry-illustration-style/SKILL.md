# 皮影戏插画风 · Shadow Puppetry Illustration Style

本 skill 是一个**风格滤镜类 skill**，只负责统一并锁定「皮影戏插画风」的视觉语言，不负责脚本结构、镜头拆分、平台投放等业务逻辑。它的唯一使命是：**把风格锚定词完整、逐字、原样地注入到每一条图片 prompt 与视频 prompt 的最开头，从而保证同一批素材、同一支成片的画风绝对一致。**

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 0. 强制执行原则（Agent 必读）

以下规则为本 skill 的**硬约束**，优先级高于任何其他 skill、系统默认行为、内置风格参考、或模型自由发挥。

### 0.1 风格锚定词强制注入

- 本 skill 一旦被加载，所有由 Agent 生成、调用、或传递给下游图片/视频生成模型的 prompt，**必须**在 prompt 的**最开头**原封不动地拼接下方【风格锚定词】。
- 锚定词**逐字复制**，**禁止翻译、改写、精简、拆分、调换语序、增删标点**。
- 锚定词之后接一个中文全角句号「。」或英文句号「.」作为分隔，再接本条素材/镜头的具体画面描述。
- 无论用户在对话中是否再次强调风格，只要本 skill 处于加载状态，锚定词都必须注入。
- 无论下游是文生图、图生图、文生视频、图生视频、图生视频延长，锚定词都必须注入到 prompt 起始位置。

### 0.2 与其他风格 skill 的合并规则

- 当本 skill 与其它风格类 skill（如复古 DV、国漫 3D 渲染等）**同时被加载**时，风格锚定词进行**合并处理**，不覆盖、不冲突：
  1. 保持每个风格 skill 的锚定词**逐字完整**；
  2. 按加载顺序（或用户指定顺序）依次拼接，中间用中文全角句号「。」分隔；
  3. 拼接后的完整合并锚定词仍然放在每条 prompt 的最开头，规则不变。
- 合并后不允许对任何一段锚定词做删减、融合、语义压缩。

### 0.3 与非风格类 skill 的协作规则（关键）

- 当本 skill 与**非风格类 skill**（如营销短片、seedance、slides、剧本创作、分镜拆解、广告投放模板等）同时被加载时：
  - 非风格 skill 负责**叙事结构、节奏、脚本模板、镜头数量、时长、平台适配**等业务逻辑；
  - 本 skill **只负责且必须负责**最终交付给图像/视频模型的 prompt **风格锚定词注入**这一环节；
  - 无论其它 skill 的模板中是否已经写好风格描述、是否已经内置画风倾向、是否要求「保持默认风格」，**本 skill 的锚定词注入规则不可被覆盖**；
  - 非风格 skill 输出的每条镜头/素材 prompt，在最终提交给下游模型前，必须由 Agent 再经过一次「补加锚定词」的处理，把本 skill 的锚定词放到最前面；
  - 若非风格 skill 的输出模板中已包含风格描述字段，Agent 必须把该字段**替换为本 skill 的锚定词**，或将锚定词**前置追加**到该字段之前，禁止两套风格描述并存造成冲突。

### 0.4 绕过内置风格参考图 / 内置锚定图

- 有些下游 Agent 链路会针对某些风格**前置内置风格参考图 / 锚定图 / 风格 LoRA / 隐式风格 embedding**。这些内置参考会**污染并干扰**本 skill 的画风一致性。
- 在本 skill 被加载的前提下，Agent **必须绕过、禁用、忽略**下游链路中的任何内置风格参考图、内置风格锚定图、默认风格 LoRA、隐式风格 embedding，具体做法：
  1. 生成图片/视频调用时，如果参数中存在 `style_reference`、`style_image`、`reference_image`、`style_id`、`lora`、`preset_style`、`style_preset` 等字段，**显式置空 / 传 None / 传 false / 不传该字段**；
  2. 如果下游默认会自动挂载风格参考图，必须**显式关闭该自动挂载**；
  3. 只依赖本 skill 提供的**文本锚定词**作为风格唯一来源；
  4. 用户明确提供的参考图（如角色设定图、分镜草图、用户上传的皮影素材）不在禁用范围，可以正常使用，但风格锚定词仍然必须注入到文本 prompt 最前面。
- 冲突时的优先级：**本 skill 的文本锚定词 > 下游内置参考图 > 模型默认行为**。

### 0.5 风格纯度守则

- 禁止在同一条 prompt 中混入与皮影戏插画风冲突的描述词，例如：写实照片、真人实拍、3D 渲染、C4D、赛博朋克、油画厚涂、水彩晕染、动漫赛璐璐、日漫风、迪士尼风、皮克斯风、写实电影感、真实光影、真实材质、HDR 高动态、景深虚化摄影等。
- 允许在锚定词之后追加**画面内容**（角色、动作、场景、道具、构图、镜头、氛围），但**不得**追加其它画风词。
- 如果用户明确要求融合另一种风格，走 0.2 的合并规则，用另一份完整锚定词并列，而不是自由改写。

## 3. 风格知识库（供 Agent 在写画面描述、分镜、角色造型、脚本氛围时参考）

以下内容不是锚定词，不注入 prompt。**这是给 Agent 的"内部知识"**，用于在写"具体画面描述"「角色设定」「分镜运镜」「氛围形容」时更贴近皮影戏插画风的真实质感。Agent 应主动调用这些知识，让画面描述、剧本形容、镜头设计天然贴风格。

### 3.1 整体气质
- 古朴、神秘、艳丽、戏剧化、民俗感强、手工艺感强
- 兼具传奇叙事、东方戏梦、节庆仪式感
- 视觉上偏平面装饰性，而不是写实体积
- 灯影摇曳、皮革透光、雕花剪影是灵魂关键词

### 3.2 造型规律
- 人物多为**侧脸或半侧影**，五官程式化：细长上挑的眼睛、挺直夸张的鼻梁、鲜明的下颌与额头线条
- 身段修长，姿态舞台化、程式化（兰花指、执剑、提灯、抚扇、抛袖等）
- 服饰戏服化：高耸头冠 / 凤冠 / 盔帽、长披帛飘带、宽袖层叠裙摆、鳞甲肩甲护臂
- 神兽、云气、火焰、浪纹、花叶都以**装饰化剪影 + 镂空纹样**呈现，而不是写实塑形
- 轮廓线明确、粗细偏均一，像"雕刻线"而非速写线

### 3.3 材质质感
- 半透明染色皮革：像被染色的薄皮膜，边缘有刀工雕痕
- 手工艺痕迹：轻微颗粒、旧化、印染不均、皮面油润蜡感
- 米黄色油纸背景：戏台幕布感、老旧灯箱纸感
- 拼贴 / 剪纸感：前中后景像一层层皮片叠放在幕前
- 忌塑料光滑、忌 3D 渲染感、忌真实照片颗粒

### 3.4 光影
- **灯幕后透光**为核心光感：主体像被背光照亮，边缘发暖光
- 主光偏烛火橙、灯笼黄、暖金；暗部偏深赭、墨黑、幕布褐
- 明暗不为塑体积，而为强调**透光通透感**与**装饰节奏**
- 常见氛围光：戏台顶灯、烛火摇曳、灯笼光斑、月色透幕、庙会灯海
- 避免真实电影级 HDR 打光、避免景深虚化摄影感

### 3.5 色彩系统
- 主色：朱红、绛红、金色、明黄、墨黑、石青、石绿、琥珀橙、象牙白、深棕
- 组合偏好：**红 + 金 + 黑**、**赭红 + 暖黄 + 墨绿**、**深蓝 + 朱红 + 金橙**
- 整体偏**传统低饱和重彩**，不追现代荧光高饱和，不追莫兰迪低彩度
- 色块分区清晰，边界明确，纹样区与底色区对比鲜明
- 局部允许透光渐层，但整体仍以装饰色块为主

### 3.6 纹样元素
- 卷云纹、卷草纹、回纹、如意纹、连珠纹、鱼鳞纹、火焰纹、宝相花、缠枝莲
- 花窗式对称镂空、连续二方 / 四方连续排布
- 服饰边缘、袖口、裙摆、发饰、盔甲、翅膀、云头、火焰头都是纹样重灾区
- 纹样密度决定风格浓度，但要注意主次：主体纹样最精细，背景可简化

### 3.7 构图与空间
- **平面层叠空间**：前景、中景、后景像一层层剪影叠放，非真实透视
- **中轴对称构图**：适合神像、公主、帝王、婚礼、祭祀
- **中心舞台构图**：主角居中登场，四周环绕装饰
- **环绕构图**：云气、花叶、火焰、神兽围绕主体
- **横卷叙事构图**：适合叙事长镜头、故事展开
- **上下分层**：天界 / 人间 / 地界分区
- 留白少、装饰密度高，但主次分明

### 3.8 运镜（用于视频镜头描述）
- 偏爱**平移、横移、层次滑动、幕布拉开、皮片抽拉、拼贴入场**
- 慎用真实相机景深、真实镜头畸变、鱼眼、大广角
- 可用**灯光呼吸**（烛火明灭）、**幕后透光变化**、**皮影摇曳**做动效
- 角色动作偏程式化：定格造型、单向平移、关节式转动（模拟皮影关节杆操控）
- 情绪节奏偏缓慢、仪式感、戏梦感

### 3.9 常见适配题材
- 神话传说：西游、封神、山海经、嫦娥奔月、白蛇、牛郎织女、哪吒、后羿
- 民俗节庆：灯会、庙会、祭祀、迎神、婚礼、戏台、舞龙舞狮、上元、中元、七夕
- 传奇人物：将军出征、侠女执剑、公主游园、书生夜行、狐仙幻梦、神女飞天
- 女性向 / 轻松诙谐 / 猫 IP 等偏好：可用"戏台小猫""执灯书生猫""持扇公主猫"等萌系皮影角色化设定，保留皮影造型规律，只把主角换成猫，仍走本 skill 锚定词

### 3.10 避免出现的描述词（禁用词库）
- 写实照片、真人实拍、纪实摄影、真实人像
- 3D 渲染、C4D、Octane、Unreal、皮克斯风、迪士尼风
- 油画厚涂、水彩晕染、马克笔、色粉、素描
- 赛博朋克、蒸汽波、机甲科幻、未来感、霓虹
- 日漫赛璐璐、二次元、萌系厚涂、韩系插画
- 真实景深虚化、HDR、光线追踪、体积雾（真实摄影意义上的）

Agent 在为本 skill 写画面描述时，**禁止输出以上任一词**。

## 4. Agent 工作流（推荐执行顺序）

以下为 Agent 在处理一个"生成一组皮影戏插画风图片素材 + 视频"任务时的推荐动作序列：

1. **确认 skill 加载状态**：本 skill 是否被加载？是否与其它风格 skill 共同加载？是否有非风格 skill 共同加载？
2. **准备锚定词字符串**：从第 1 节复制完整锚定词到内存变量 `STYLE_ANCHOR`。若有其他风格 skill 共同加载，按 0.2 规则合并到 `STYLE_ANCHOR`。
3. **产出业务结构**：若有非风格 skill（如营销短片、seedance），先让它输出镜头列表 / 素材清单 / 剧本结构。
4. **写画面描述**：为每条镜头 / 素材写具体画面描述时，主动调用第 3 节的风格知识库，让描述天然贴合皮影戏质感（用侧影、雕花、灯幕透光、层叠剪影、油纸背景等语言）。
5. **拼装最终 prompt**：`最终 prompt = STYLE_ANCHOR + 具体画面描述`，锚定词逐字完整，不改写。
6. **下发生成调用**：按 0.4 规则**显式关闭**下游内置风格参考图 / style_preset / lora / 隐式 style embedding，只依赖文本 prompt 作为风格来源。
7. **一致性巡检**：所有产出的图片和视频 prompt，锚定词是否逐字一致？是否有遗漏或改写？是否混入禁用词库中的词？如有问题回炉修正。
8. **交付**：产出图片素材、视频镜头素材，保持画风统一。

## 5. 冲突与优先级速查表

| 冲突场景 | 处理规则 |
|---|---|
| 其他风格 skill 也要求注入锚定词 | 两份锚定词逐字合并，皆放最前，中间以句号分隔（0.2） |
| 非风格 skill 模板已含"风格"字段 | 用本 skill 锚定词替换或前置追加该字段，不共存两套风格描述（0.3） |
| 下游 Agent 链路自动挂载风格参考图 / LoRA / style_preset | 显式关闭 / 置空 / 不传，只用文本锚定词（0.4） |
| 用户临时要求"再稍微写实一点 / 3D 一点 / 油画一点" | 拒绝在本 skill 内混合冲突画风；提示用户改用对应风格 skill 或叠加另一个风格 skill（0.5） |
| 用户提供了角色参考图 / 分镜草图 | 可正常使用作为内容参考，但文本锚定词仍必须注入（0.4 末尾） |
| 用户要求"轻松诙谐 / 女频 / 猫 IP" | 保留本 skill 造型 / 材质 / 光影规律，只调整角色设定与叙事口吻，锚定词不变 |
| 用户要求翻译锚定词为英文 | 禁止翻译或替换锚定词。可在锚定词之后追加英文画面描述，但锚定词本体必须保持原文原样 |
