# 角色身份板与视频片段生成策略

> 本文件定义角色参考图生成、视频片段生成、参考图绑定、环境音生成与质量把控的全部规则。生成素材前必读。

## 角色身份板生成

每名主要角色生成两张参考图：
1. **全身参考图：** 人物在低信息量的真实场景中（如街边、走廊、空地），全身可见，背景简洁但为真实环境，非摄影棚。
2. **正面近景：** 面部+上半身，平视机位，背景为虚化或简单的真实场景色块。

**禁止在身份板中出现：** 文字标签、黑色剪影、设计板排版、表情宫格、多人物拼贴、纯白摄影棚背景。

若用户提供参考图，以参考图为视觉输入，强化面部特征一致性。

身份板生成后，绑定至对应角色 key_element；后续该角色所有镜头视频生成时，将此参考图作为视觉参考输入。

## 视频片段生成

- 每段视频时长4–15秒（按分镜设计）。
- 时长≤15秒的成片用一次视频生成即可拿到完整片段。
- 成片总时长超过15秒时，拆成多个≤15秒片段分别生成，再做后处理拼接。
- 若存在参考图，以该镜头涉及的 key_element 参考图作为视觉参考输入。
- 跨镜连续性极强时（人物动作/场景直接衔接），可额外加入上一镜头视频作为参考视频，其余情况默认不加视频参考。

## 参考图绑定规则

若存在需要跨镜头复用的人物或场景 key_element，在生成对应镜头视频前，先生成 element 参考图并绑定至对应 key_element。

生成每个 shot 视频时，以该镜头涉及的 key_element 参考图作为视觉参考输入；跨镜连续性极强时（人物动作/场景直接衔接），可额外加入上一镜头视频作为参考视频，其余情况默认不加视频参考。

用户已上传的图像/视频素材优先绑定到对应分镜槽位，不重复生成。

## 环境音生成

- 环境音轨通过视频生成 prompt 内嵌方式驱动（在 prompt 中明确描述环境音元素）。
- 如需独立环境音素材（如远处方言广播碎片），可生成非对口型人声音效。
- 如用户未提供背景音乐且未明确要求，**不生成任何配乐**。
- 若用户明确要求背景音乐，风格描述为：极简、低沉、空旷、中国民谣或工业环境底纹，时长匹配视频。

## 质量与风格把控

若生成视频出现明显磨皮/高饱和/精致布景等与贾樟柯风格相悖的特征，自动重试一次并在 prompt 中强化纠偏指令；二次失败后告知用户并询问是否接受或跳过。

## 落 prompt 前自检

- [ ] 主要角色是否已生成身份板（全身+正面近景各一张）
- [ ] 身份板是否避免纯白摄影棚背景、文字标签等禁止元素
- [ ] 视频提示词是否包含强制前缀和固定negatives
- [ ] 参考图是否正确绑定至对应key_element
- [ ] 成片≤15秒是否一次生成；>15秒是否已拆成≤15秒片段
- [ ] 环境音是否通过prompt内嵌驱动
- [ ] 是否默认不生成配乐（除非用户明确要求）
- [ ] 风格偏差时是否自动重试并强化纠偏指令
