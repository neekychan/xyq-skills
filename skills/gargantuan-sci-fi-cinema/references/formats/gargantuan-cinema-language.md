## 1. 巨物叙事结构

采用 Pacific Rim / MonsterVerse 经典结构：

**埋伏（暗示存在）→ 揭示（局部出现）→ 确认（全貌暴露）→ 冲突（对抗/战斗）→ 终极压迫（第三方介入或终极一击）→ 余波（灾难后果）**

每一个镜头必须推动三者之一：巨物尺度认知、人类恐惧感、环境破坏程度。禁止重复信息。禁止空镜没有叙事作用。

## 2. 巨物布景设计规范

### 2.1 尺度即恐惧（核心原则）

巨物电影中，真正的恐惧来源不是怪物长什么样，而是"它有多大"。每一个场景都必须回答：人类在这里有多渺小？用参照物、低角度、广角变形三种手段叠加。

示例：
- 机甲足部 vs 维修工人（工人如蚂蚁）
- 怪兽头部 vs 渔船（渔船如树叶）
- 巨手拍海 vs 海面（海坑深50米）

尺度对比必须成为叙事的一部分。

### 2.2 环境先于巨物

巨物不能凭空出现。所有室外镜头优先建立：天空、海面、远景城市轮廓，随后再出现巨物局部，最后巨物全貌进入。

节奏：Environment → Partial Reveal → Full Body → Scale Impact

### 2.3 工业/生物真实性

**机甲：** 外观状态根据剧情阶段动态决定——出厂/部署阶段保持干净工业质感（崭新金属面、无明显战损、少量制造油渍）；首次战斗后出现轻微刮痕和战损；持续战斗或重伤后出现重度战损、锈蚀、油污。重工业感、铜缆外露、液压关节始终保留。禁止塑料感、CGI光滑感、无材质细节。

**怪兽：** 生物恐怖感、粗糙皮肤纹理、荧光脉络、尖刺骨刺、巨口獠牙、血液颜色。禁止光滑皮肤、无纹理细节、卡通化。

### 2.4 天气规则

天气属于叙事，不只是装饰：
- 大雾 = 隐藏恐惧
- 暴雨 = 灾难降临
- 闪电 = 巨物出场号角
- 海浪 = 重量感证明

同一场景天气禁止随机变化，必须有叙事理由。

### 2.5 光线规则

光源必须合理：机甲眼窗光、怪兽荧光、工厂焊接光、暴雨天光、闪电瞬间硬光、月光。禁止无光源的"画面自己发光"。体积光（光柱/光束）是增强巨物感的关键手段。

## 3. G系列运镜系统

所有镜头统一采用G系列（Gargantuan）：

| 代号 | 名称 | 描述 |
|---|---|---|
| G-00 | Static Low-Angle | 固定极低角度仰拍，巨物占据画面，人类极少或极小。最常使用。 |
| G-01 | Slow Dolly Back | 缓慢后拉，逐步揭露巨物完整尺度，从局部→全身。 |
| G-02 | Slow Dolly Forward | 缓慢推进，从远景→巨物细节（眼窗/皮肤纹理）。 |
| G-03 | Worship Rise | 从地面向上摇起，先见足部→小腿→躯干→头部，完整建立巨物尺度。 |
| G-04 | Scale Reveal | 参照物先入画，巨物后入画，用参照物比例建立尺度。 |
| G-05 | Surface Tension | 聚焦水面/地面受力，巨物踩入→凹陷→浪墙/裂痕。 |
| G-06 | Fog Reveal | 雾中逐步显露，轮廓→局部→全貌，恐惧感逐步升级。 |
| G-07 | Impact Hold | 冲击瞬间固定机位，不切镜，张力来自画面内动作而非剪辑。 |
| G-08 | Dual Charge | 对称构图，机甲和怪兽从两侧同时向中心冲锋。 |
| G-09 | Hand from Sky | 第三方巨手/巨物从画面上方砸下，极低角度仰拍。 |
| G-10 | Submerged POV | 水下视角，巨物从上方海水轮廓中显露。 |

### 镜头运动限制

**允许：** Static Low-Angle, Slow Dolly Back, Slow Dolly Forward, Slow Pan, Tracking (with wobble), Crane Rise, Reveal Shot, Impact Shake

**禁止：** FPV, Handheld Shaky Cam (除非灾难混乱场景), Fast Zoom, Crash Zoom, Hyperlapse, Whip Pan, Drone Racing, Selfie Angle

镜头必须具有真实摄影机重量感。镜头运动尽可能克制有力。大量采用：固定机位低角度、缓慢后拉、长时间停留、真实物理震颤。禁止快速推拉、频繁切镜、MV式剪辑、夸张镜头语言。

### 镜头转场

默认采用 Cut（硬切）。

**允许：** Fade In/Fade Out（章节之间）、Cross Dissolve（时间流逝）、Fade To Black（结局）、Match Cut（巨物动作匹配、光线匹配）

**禁止：** 现代MG动画、炫酷转场、闪光转场、像素化转场

## 4. 经典镜头组合

采用 Pacific Rim / MonsterVerse 经典组合：

- **组合一：** 海面大远景→雾中轮廓→局部显露→完整全貌→低角度仰拍特写
- **组合二：** 工厂维修（人类尺度）→镜头后拉→机甲全貌（巨物尺度），单镜头完成尺度跳跃
- **组合三：** 渔船颠簸→雾中轮廓→怪兽俯视，人类视角恐惧升级
- **组合四：** 机甲海中行走特写（腿部）→镜头上摇→头部全貌→眼窗亮起
- **组合五：** 对称构图→双向冲锋→碰撞→冲击波→慢动作碎裂
- **组合六：** 人类仰视→巨物低头俯视→眼神交汇→咆哮/发光
- **组合七：** 天空乌云→巨手砸下→海面凹陷→冲击波扩散→水下视角

## 5. 巨物镜头节奏

| 镜头类型 | 推荐时长 |
|---|---|
| 揭示镜头（雾中/远处） | 8–15秒 |
| 尺度对比镜头（含参照物） | 6–12秒 |
| 海中行走/受力表现 | 8–15秒 |
| 工厂维修（人类尺度） | 6–10秒 |
| 冲锋/战斗镜头 | 5–10秒 |
| 冲击/拍击瞬间 | 3–8秒（可慢动作延长） |
| 终极压迫（俯视/对视） | 10–20秒 |
| 结尾余波 | 15秒左右 |

始终保持：慢节奏建立尺度，快节奏释放冲击。

## 6. 跨镜连续性

所有镜头保持一致：巨物配色、发光元素颜色、皮肤/装甲纹理、天气状态、太阳/闪电方向、海面波浪方向、浪墙形态、参照物位置、巨物站位、光线方向、镜头轴线。若跨章节，仍保持连续，除非剧情明确发生时间变化、天气变化、地点变化。
