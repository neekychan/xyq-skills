# 科普/教程 Prompt 编写指南

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意层的钩子/类比/悬念链规则见 `creative/knowledge-explainer.md`。

## 段时长

科普/教程段时长取值遵循 `storyboard/dialogue-rules.md` 段时长锚点，在第三步分段规划时已执行，此处不重复定义。写 Prompt 时段内动作必须与旁白并行完成，不为动作追加时长。

## Prompt 写法红线

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 只写氛围与运镜，知识点不落画面 | 画面沦为壁纸 | 每段写出承载知识点的具体视觉事件（载体动作→变化→后果） |
| Prompt 中要求画面出现数字、文字、图表、屏幕文本 | 视频模型渲染文字不稳定，错字/乱码=硬伤 | 数据/对比改实物呈现（可数实体堆叠、体积/高度/速度反差）；确需文字信息交给旁白说 |
| "禁止生成任何文本"一刀切 | 示意关系无法呈现 | 禁文字与数字即可；无文字图形元素（箭头、发光连线、对比色块）按需写入 |
| 类比载体只被旁白提及不入画 | 音画脱节 | 旁白讲到的载体和动作必须同步写进画面描述 |
| 段尾写"画面渐归宁静"式收尾 | 段尾空转 | 段尾画面即该段知识点的结果状态，或下一段的悬念画面 |
| 单个画面阶段超过 8 秒无新视觉事件 | 观众流失 | 每 5-8 秒画面必须有一次可见变化（新动作/新元素入画/状态改变），长段拆多个阶段逐一写明；变化必须承载当前知识点，禁止无信息的特效堆砌 |

## Prompt 模板（科普示例）

```
参考@图片1的场景氛围作为面包店，参考@图片2的整体画风。旁白音色参考@音频1（沉稳温和的男声，语速平缓，略带讲解感）。
阶段1 (0-5s)：中景，暖黄顶灯下学徒面包师往面团里连续倒入三种来路不明的粉末，粉尘在灯光中扬起，面团随之膨胀变形，表面鼓起不规则气泡。旁白：{它学过的资料真假混杂，全都揉进了面团。}
阶段2 (5-10s)：特写，面包出炉，表皮金黄在顶灯下泛油亮反光，学徒自信地切开——内部空洞塌陷，切面暗哑无光。旁白：{所以答案看着漂亮，里面可能是空的。}
日系简洁插画风格，细线条勾勒，大面积留白，柔和淡彩。
五官清晰不变形，4K超高清，画面稳定无模糊，保持无字幕，不要生成水印，禁止生成BGM，保留自然环境音效。
时长：10秒，比例：16:9
```

要点：每个阶段 = 载体的一个"动作→后果"事件，旁白与画面事件同步；教程类把"载体事件"换成"操作动作→即时结果"。
