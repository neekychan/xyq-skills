# 大友克洋风格（Akira 式近未来赛博工业风）滤镜

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的大友克洋 / AKIRA 式画风质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。它同时携带一份**风格知识库**（下文「风格质感知识库」章节），供 Agent 生成分镜、角色、场景与故事脚本的**具体描述**时形容参考，让内容在措辞层面也贴近该风格的特点。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一部作品 / 同一套美术里出来的」（画风、光感、色调、材质、机械与城市质感不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一部大友克洋 / AKIRA 式作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **大友克洋风格，经典的大友克洋（Akira）二次元动漫风格，旧日系动画感，电影级光影和分镜叙事，色调中低饱和，强调体积光与空间深度，写实日漫、硬派科幻、工业细节密集、近未来都市、赛博朋克但偏现实、混凝土与金属质感、城市压迫感、霓虹冷光、烟尘与废墟、末世前夜氛围。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述，也不要在具体描述里重复堆写「体积光/低饱和/工业细节」等风格词——风格已由锚定词负责。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格类」skill（营销短片 / 分镜脚本 / 广告等）冲突时的优先级规则（务必遵守）

当本技能与**非风格类**技能（例如营销短片、短剧、广告脚本、分镜生成、口播/带货等）在同一任务里同时被加载时：

- **职责切分，互不覆盖：** 非风格类 skill 负责**内容与结构**（叙事、卖点、分镜节奏、时长、平台形态、CTA 等）；本技能负责**画风质感**（每条图片/视频 prompt 的锚定词注入与一致性）。两者叠加执行，而非二选一。
- **本技能的画风约束不可被降级：** 即使加载了营销/短片类 skill 并由它主导内容流程，**最终交付给生成模型的每一条图片 prompt 与视频 prompt，仍必须由本技能在头部逐字注入锚定词**。任何来自其它 skill 的 prompt 模板、示例或「省略风格词」的建议，都不能取消或改写本技能的锚定词注入。
- **落 prompt 是唯一裁决点：** 无论内容由谁组织，**在真正调用图片/视频生成工具之前**，都要按本技能「输出契约」把锚定词补到每条 prompt 最前面并做静默自检；这一步优先级最高。
- **风格知识优先本技能：** 涉及画面质感、光影、材质、机械与城市、色调等描述时，以本技能「风格质感知识库」为准；其它 skill 若给出与本风格相悖的美术描述，服从本技能。

## 禁止内置风格锚定图 / 内置风格参考干扰（硬规则，最高优先级）

部分 Agent 链路会针对某些风格**前置内置一张风格参考图 / 风格锚定图 / 默认风格 embedding**。这些内置参考会与本专业风格 skill 冲突、污染资产画风。因此：

- **一旦本技能生效，全程禁用任何内置/默认/系统预置的风格锚定图、风格参考图、风格预设或隐式风格注入。** 本次任务的风格来源**有且只有**上文锚定词与本技能知识库，不接受任何链路层自带的风格图/风格提示混入。
- **不将内置风格图作为参考帧 / 风格图 / 底图传入**任何 `sandbox_generate_image`、`sandbox_generate_video`、`render_video`、`sandbox_process_video` 调用；若生成接口存在「默认风格」「风格模板」「内置参考图」等可选项，一律置空 / 关闭 / 不选。
- **唯一允许的参考图**是本技能流程中由用户提供、或本技能自己先生成出来、且已带锚定词的图片素材（用于图生视频的首帧/一致性参考）；除此之外不引入任何外部风格参考。
- 若链路强制注入了无法关闭的内置风格图，**以本技能锚定词为准**：在 prompt 中显式、逐字前置锚定词以覆盖其影响，并在静默自检中确认成片画风归位到大友克洋风格；如仍被污染则重写 prompt / 重生，不得带着被污染的画风交付。

## 风格质感知识库（供写分镜 / 角色 / 场景 / 脚本的「具体描述」时参考）

> 用途：这一节**不是**要塞进锚定词，而是给 Agent 在写锚定词**之后的具体画面描述**、以及写故事脚本 / 分镜 / 角色设定时，提供贴合大友克洋风格的形容词与画面元素，让内容层也更「像」。挑选与本条画面相关的词即可，不要一次全堆上。

### 1. 整体气质
- 关键词：沉重、真实、压迫、冷峻、复杂、社会密度高、末世前夜。
- 秩序与失控并存：严密的道路/管线/钢架/建筑层级，却总处在爆炸、坍塌、暴走、骚乱、系统故障的边缘。
- 宏大中的人类渺小：个体被巨型城市 / 军事设施 / 实验装置吞没。
- 冷静不浪漫化：硬质、粗砺、克制；情绪偏压抑、焦灼、骚动、失衡。

### 2. 造型语言
- 线条干净、准确、硬朗，工业制图 / 建筑草图 / 机械剖面式的清晰与控制力。
- 结构优先于装饰：管道像真能输送、机械像能拆卸维修、建筑外立面/楼梯/通风口/线缆构成可信世界；细节看起来「有功能」。

### 3. 角色造型
- 头身比接近真人，五官自然，强调颧骨/下颌/鼻梁/眼窝；表情收敛，非萌系、非极端美型、非长期夸张颜艺。
- 青年角色常带街头感：倔强、浮躁、叛逆、疲惫、不良少年气质、时代边缘人粗粝感。
- 服装实用：夹克、工装、制服改造、机车服、军事/功能性穿搭，有生活痕迹，而非华丽时装。
- 人与环境同等重要，人物嵌入空间，场景本身在「讲话」，具电影感与现实压力。

### 4. 城市与环境
- 城市是「活着的系统」：高密度建筑群、立交/天桥/隧道/地下设施、广告/霓虹/警示牌/标语、管网/空调外机/维修口/围栏/电缆、工地/废墟/裂缝/污渍/破损墙体。
- 既未来又脏、既发达又衰败：繁荣与腐坏共存。
- 废墟感与施工感重：裸露钢筋、混凝土断面、尘土碎石、半拆卸机械、斑驳墙皮、工业照明、旧设施与新技术混搭。
- 宏观尺度强：超长街道透视、高耸封闭的建筑峡谷、巨大地下实验空间、空旷压抑的工业厂房、高架桥与隧道。

### 5. 机械与科技
- 关键不是「炫」而是「真」：分件明确、功能区分清晰，接缝/铆钉/管线/散热/外壳结构合理，有体积与重量、不悬浮不轻飘。
- 表面带老化痕迹：磨损、划痕、油污、灰尘、焊接痕、漆面剥落——像被使用过的文明遗物/现实工具，而非崭新展示模型。
- 科技 vs 失控：常出现冷硬几何机械 与 失控膨胀的有机形体对撞，制造「科技理性 vs 原始失控」张力（能量暴走、肉体异变、实验越界）。

### 6. 色彩
- 总体中低饱和、灰调：水泥灰、铁锈色、深蓝、冷绿、暗红、钢铁银灰、土黄。
- 霓虹作为局部刺激：大面积灰暗背景中点缀红/蓝/橙/黄的警示灯或广告屏，亮色带危险感而非甜美；底色克制、局部高能。
- 日夜色温差明显：白天灰白/土黄/热尘；傍晚橙红/棕紫/末世夕照；夜晚深蓝黑底 + 霓虹冷暖混光；室内实验空间冷白/青绿/警示红，环境有明确主导色。

### 7. 光影质感
- 电影式照明，强调体积光与空间深度：烟雾、灰尘、逆光颗粒、隧道尽头透光、室内冷光切面、爆炸后的火光反射。
- 硬光与脏空气并存：硬质工业灯、警报灯闪烁、霓虹反射在湿地面与金属外壳上、光穿过烟尘形成脏而厚的光束。
- 高反差但不梦幻：有明确暗部、局部刺眼高光、中间调保留大量细节，让材质/空间/气氛成立。

### 8. 材质
- 关键词：混凝土、旧金属、拉丝钢板、生锈铁件、机油、玻璃反光、旧塑料、沥青路面、潮湿墙面、灰尘颗粒、电缆橡胶、油漆脱落表面、烟尘/蒸汽/火花。
- 表现逻辑：体现使用痕迹、老化程度、环境污染、功能属性、重量与硬度——一面墙不是纯灰，而有修补痕、裂纹、雨渍、旧标识残留、局部反光差异。

### 9. 构图与镜头
- 常见构图：广角透视（城市规模/压迫）、低机位仰拍（建筑/机械/权力感）、长纵深街道（速度与不安）、局部特写（机械零件/手部操作/眼神/仪表盘）、大全景与极近景切换（节奏冲击）。
- 运动镜头感强：机车高速冲刺、爆炸冲击波扩散、人群奔逃、车辆穿梭高架、灯光掠过脸部、碎片飞散、烟尘席卷前景——前后景同时在运动。
- 留白偏紧张：暴风雨前的空场、战斗前停顿、宏大设施中的孤独、城市夜晚的冷清与危险。

### 10. 叙事氛围（供写故事脚本参考）
- 社会性强：国家机器、军事权力、科研伦理、都市治理失控、群体骚乱、青年失序、末世危机。
- 青春是危险能量：少年象征不稳定、怒气、无处安放的力量、被忽视的边缘状态、与体制对冲的生命力。
- 科技是放大器：放大人性缺陷、社会失衡、权力滥用、身体异变、城市崩坏；即便先进也少有乌托邦明亮感。

### 常见误区（模仿易偏，写描述时规避）
- 只做酷炫不做真实（太光滑太新、机械无功能逻辑、城市像游戏宣传图）→ 要有使用痕迹、施工感、破损感、现实密度。
- 只做霓虹不做灰度基础（满屏荧光紫蓝粉、太潮流海报化）→ 大面积克制底色，局部霓虹作危险刺激。
- 人物过于偶像化（脸太精致、服装太时装秀）→ 更生活化、街头化、功能化、真实骨相。
- 背景只是贴图、缺空间叙事 → 让建筑/道路/管线/设施本身讲故事。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否与非风格类 skill（营销短片/短剧/广告等）联用；视频画幅 / 时长偏好；是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，就用本技能「风格质感知识库」补齐一版贴合大友克洋风格的分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。同时确认已按上文禁用任何内置风格锚定图/风格预设。
2. **（如联用非风格类 skill）明确分工。** 让内容/结构类 skill 负责叙事与分镜，本技能负责在最终每条 prompt 头部注入锚定词；写具体画面/脚本时参考「风格质感知识库」。
3. **生成图片素材（逐张）。** 对每一张需要的图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`（具体描述可挑用知识库词汇），然后生成图片。所有图片共用同一份锚定词，且不传入任何内置风格参考图。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该图片（本技能生成、已带锚定词的图）作为视频的画面参考，视频 prompt 仍在头部注入锚定词；不引入内置风格图。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
7. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。
