# 果雾软块风格

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片编辑 prompt 与视频 prompt 的最开头，让用户**先上传的一批已确定图片素材**（角色 / 场景分镜）被统一风格化转绘后，再整体送去做视频生成，使图片素材与视频成片拥有完全一致的果雾软块质感。

这是一个**风格滤镜 + 图片转绘**技能：它不决定画什么（画什么由用户上传的图片决定），只决定「所有东西都长成同一种画风」。

## 核心原则(因果链)

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 用户上传图片被转绘成统一画风的素材 → 视频画风与风格化后的图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试:** 把本次生成的任意两张风格化图片、任意一段视频并排观看，若能明显看出它们「不是同一套渲染管线 / 同一部动画里出来的」(色块边界、颗粒噪点、几何剪影、配色不统一),则本技能执行失败。反之,若陌生人会认为它们出自同一部果雾软块风格的作品,则成立。

## 风格锚定词(本技能的核心资产)

以下为固定风格锚定词,**逐字使用,不得改写、删减、翻译或重排**:

> **果雾软块风格,无线稿,软毛色块边界,像素/颗粒,果粉雾粒噪点,高度几何化,圆钝几何剪影,高饱和/鲜艳,果色明暗强撞**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 用法强约束(本技能与纯风格滤镜的关键区别,务必遵守)

1. **必须图片先行:** 用户**必须先上传一批自己已确定的图片资产**(角色形象或场景分镜)。本技能不负责从零想象画面,而是负责把用户已确定的图片**转绘风格化**,再整体送给视频生成。若用户尚未上传图片,先明确要求其上传,不要凭空生成图片素材。
2. **图片风格化 = 纯风格锚定词转绘:** 对用户上传的每一张图片做风格化处理时,**图片编辑提示词直接且仅使用上面的风格锚定词**,不要再额外添加任何画面 / 内容 / 构图 / 光影 / 镜头描述。完全直接基于用户原图转绘——只换画风,不改画面内容。
   - 即:图片编辑 prompt = 风格锚定词原文(**仅此而已**)。
   - 这条规则**只适用于图片转绘环节**;视频环节的 prompt 仍需在锚定词后补充镜头 / 动作 / 剧情等具体描述(见工作流 Step 4)。
3. **先风格化,再送视频:** 视频生成使用的画面参考,应当是**已经过本技能风格化后的图片素材**,而不是用户上传的原图。顺序恒为:上传原图 → 逐张风格化转绘 → 用风格化后的素材 + 剧情脚本做视频。

## 注入规则(硬规则,最高优先级)

1. **位置固定:** 锚定词永远放在每条 prompt 的**最开头**。图片转绘 prompt 即锚定词本身;视频 prompt 中锚定词后紧跟一个逗号,再接本段镜头的具体描述。顺序恒为「锚定词 → (视频才有的)具体画面」,不得颠倒。
2. **逐字一致:** 每条图片编辑 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖:** 本次任务里需要处理的**所有**图片素材与需要生成的**所有**视频片段,无一例外都要在头部注入锚定词;包括中途返工重生的素材。
4. **不污染具体描述(仅视频环节):** 视频 prompt 里锚定词只负责画风;镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后,不要因为有了锚定词就省略画面描述。(图片转绘环节相反——只用锚定词,不写画面。)
5. **语言:** 锚定词与具体画面描述统一用中文书写。如确需英文版本,仅可作为补充,且锚定词部分不翻译、保持中文原文。

## 与其它风格 skill 搭配时的合并规则(务必遵守)

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时:

- **合并而非替换:** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词,整体放在 prompt 最开头,后接具体画面(视频)或直接作为图片转绘 prompt(图片)。本技能的锚定词按用户 / 加载顺序排入,不单独另起。
- **规则不变:** 合并后仍遵守上面全部注入规则与用法强约束——图片先行、图片转绘仅用合并锚定词、位置固定在最开头、逐字一致、全覆盖、不污染视频具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重:** 若多个风格锚定词出现完全重复的短语,可去重一次,但本技能锚定词的实质内容不得删减。
- **冲突时:** 若两套风格存在直接矛盾的表述,保留双方原文并列即可(不臆改),由生成模型融合;不要为了「调和」而改写任一方锚定词。

## 与非风格类 skill(如营销短片 / 剧情短片等)冲突时的结合规则(务必遵守)

当本技能与**非风格类** skill(例如「营销短片」skill、剧情脚本 skill、分镜 skill 等)被同时调用时,可能出现职责冲突——非风格 skill 往往也会自带自己的一套图片 / 视频 prompt 生成逻辑或画风倾向。此时:

- **本技能的风格与图片转绘规则拥有最高优先级。** 即使加载了其它非风格 skill,凡是涉及「最终送去生成图片素材 / 视频的 prompt」,都必须遵守本技能的:①图片先行;②图片转绘 prompt 仅用风格锚定词;③所有图片 / 视频 prompt 头部逐字注入锚定词。
- **分工结合而非互相覆盖:** 非风格 skill 负责它擅长的部分——叙事结构、卖点提炼、投放脚本、时长节奏、剧情设计等;本技能负责画风统一与图片风格化转绘。二者结果**叠加**:用非风格 skill 产出的剧情 / 结构 / 文案,填充到本技能(或内置 SP)的视频 prompt 的「具体描述」位置,而 prompt 头部仍由本技能注入锚定词。
- **具体落地方式:** 先让非风格 skill 产出叙事 / 结构层的内容 → 本技能把这些内容作为视频 prompt 的具体画面描述 → 在其最前面统一注入(或合并注入)风格锚定词 → 图片素材一律先经本技能纯锚定词转绘。任何非风格 skill 都不得删改、绕过或前置于本技能的锚定词注入与图片转绘环节。
- **一句话:** 非风格 skill 决定「讲什么、怎么讲」,本技能决定「长什么样、怎么风格化」;冲突一律以本技能的画风与转绘规则为准。

## 输入

- **必需:** 用户**已上传的一批已确定图片资产**(角色形象或场景分镜),以及用户的意图描述(想做成什么样的动画 / 短片 / 视频)。
- **可选:** 是否与其它风格 skill 叠加;是否与营销短片等非风格 skill 搭配;视频画幅 / 时长偏好。
- **图片缺失必须先追问:** 若用户没有上传图片,先要求上传,不要凭空生成图片素材(这是本技能与普通滤镜技能的关键差异)。其余信息缺失时,按内置 SP 的默认补全策略处理,不反复追问已明确项。

## 工作流(Steps)

1. **确认锚定词形态。** 若仅本技能生效,锚定词 = 上文原文。若与其它风格 skill 搭配,先按「合并规则」拼出合并锚定词,后续全程复用这一版。若同时有非风格 skill,按上文「结合规则」明确分工。
2. **接收并确认图片素材。** 确认用户已上传一批已确定的图片资产;若未上传,要求先上传。记录每张图片对应的角色 / 场景语义(用于后续脚本里的角色锁定)。
3. **图片风格化转绘(逐张)。** 对用户上传的**每一张**图片,以**风格锚定词原文作为唯一的图片编辑提示词**(不额外添加任何内容),直接基于原图做风格化转绘。所有图片共用同一份锚定词。生成后展示给用户。
   - 图片编辑 prompt = `<锚定词逐字原文>`(仅此,不写画面)。
4. **图片质检与返工。** 对照质量测试检查画风一致性;若某张明显跑偏,仅重跑该图的风格化转绘(锚定词不动、仍不加内容),直到整批风格化图片观感统一。
5. **撰写动画脚本 / 分镜。** 调用本技能内置的 **`references/seedance-story-sp.md`**(Seedance 高密度剧情短片提示词生成器 system prompt),输入 = 风格化后的图像资产 + 用户意图描述,产出详细动画脚本与时间戳分镜,作为视频生成的参考。若还搭配了非风格 skill(如营销短片),按「结合规则」把其叙事 / 结构产物填入脚本的具体描述位置。
6. **生成视频(逐段)。** 对每一段视频,组装 prompt = `<锚定词逐字原文> + "," + 该段镜头 / 动作 / 画面 / 剧情描述(来自 Step 5 的脚本)`,并以**风格化后的图片素材**作为画面参考,再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**,无需分段拼接;分镜 beat(如 0-3s / 3-7s)只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时,才把它拆成多个 ≤15s 片段分别生成,每段头部同样注入同一份锚定词,再做后处理拼接。
7. **视频质检与返工。** 检查视频画风是否与风格化后的图片素材一致;跑偏则改具体描述后重生(锚定词不动)。
8. **交付并展示。** 把最终的风格化图片与视频产物展示给用户;需要保存时按用户要求处理文件。

## 输出契约

- **图片转绘 prompt:**
  ```
  <锚定词逐字原文>
  ```
  (仅锚定词,不含任何画面 / 内容描述。)

- **视频 prompt:**
  ```
  <锚定词逐字原文>,<本段具体镜头 / 动作 / 剧情描述(可含时间戳分镜)>
  ```

- 同一批任务内,`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜(时间轴)时,分镜写在具体描述内,锚定词仍只出现一次且在最前。

**示例(示意):**

- 图片转绘:`果雾软块风格,无线稿,软毛色块边界,像素/颗粒,果粉雾粒噪点,高度几何化,圆钝几何剪影,高饱和/鲜艳,果色明暗强撞`
- 视频:`果雾软块风格,无线稿,软毛色块边界,像素/颗粒,果粉雾粒噪点,高度几何化,圆钝几何剪影,高饱和/鲜艳,果色明暗强撞,0-3s 角色(对应风格化后@图1)快速转身,镜头 Fast Push In 推至特写;3-7s 环绕跟拍展示动作升级;7-12s 远景直切特写呈现高潮撞击。`

## 内置资源

- `references/seedance-story-sp.md` — Seedance 高密度剧情短片提示词生成器 system prompt。在 Step 5 撰写动画脚本 / 分镜时加载并遵循;其输入为风格化后的图像资产 + 用户意图,输出为详细中文视频提示词与分镜。

## 静默自检(交付前内部跑一遍,不展示给用户)

- [ ] 用户是否**先上传了已确定的图片素材**?(未上传应先追问,不凭空生成)
- [ ] 每张图片的风格化转绘是否**仅用锚定词原文、未额外添加任何画面内容**?
- [ ] 送去视频生成的画面参考是否用的是**风格化后的图片**,而非用户原图?
- [ ] 本次每一条图片 / 视频 prompt 的**最开头**都逐字出现了锚定词(或合并锚定词)?
- [ ] 同一批任务内锚定词是否字节级一致、无任何一条被改写 / 漏注入?
- [ ] 视频 prompt 锚定词之后是否都保留了具体画面描述,没有被风格词挤掉?
- [ ] 若叠加了其它风格 skill,是否按合并规则拼接、规则未变、未删减本技能锚定词?
- [ ] 若搭配了营销短片等非风格 skill,是否按结合规则做到「非风格 skill 管叙事 / 结构、本技能管画风与转绘」,且本技能规则优先?
- [ ] 图片之间、图片与视频之间画风是否通过了「同一部作品」的一致性测试?
- [ ] 超过 15s 的成片是否才做了分段;≤15s 的是否一次生成?

发现弱项就在交付前重写对应 prompt 并重生,不要把本清单暴露给用户。
