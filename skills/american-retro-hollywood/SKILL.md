# 美式复古好莱坞风格

这是一个**画风锚定技能**。它的唯一使命：让本次任务里所有需要生成的**图片素材资产**与**视频**，都稳定落在同一套「美式复古好莱坞」质感上。做法不是靠反复描述，而是把一段**固定不变的风格锚定词**，放在**每一条**图片 prompt 与视频 prompt 的**最开头**，再接该镜头/该素材的具体画面描述。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 0. 风格锚定词（本技能的脊柱，逐字复用）

下面这段是**风格锚定词**。凡是本次任务中要生成的**任何一张图片**或**任何一段视频**，其 prompt 都**必须以这段词原样开头**，一字不改、不翻译、不精简、不调换顺序，然后紧接一个换行或分隔，再写该镜头的具体画面描述。

> **美式复古好莱坞风格，参考电影为《Demons》，整体风格包含复古，色调以低调、去饱和为主，光影上使用柔光。20世纪70年代胶片美学、35mm颗粒、轻微欠曝、低照度摄影、柔焦镜头、低锐度低反差、暗角、微弱光晕、温暖钨丝灯色温、橄榄绿与棕红色调、综合色偏移、压低高光、浓郁暗部、肤色柔润偏粉、自然主义布光、侧前方柔光、静态机位、古典中心构图、中近景肖像、适度景深、舞台化场面调度、油画般层次、幽暗浪漫、含蓄诡谲、梦境感、怀旧而压抑。**

**锚定词使用铁律（不可违反）：**
1. **位置**：锚定词永远在 prompt 的**最前面**，具体画面描述在其后。顺序不可颠倒。
2. **完整**：整段逐字复制，不得删词、换词、缩写或"意译"。它是风格一致性的唯一来源。
3. **覆盖全部资产**：每一张分镜图、每一张角色/场景/道具素材图、每一段视频，无一例外都要带上它。中途新增的补充素材同样要带。
4. **图生视频也要带**：即便是基于已生成图片再生成视频，视频 prompt 仍以锚定词开头，保证动态镜头不偏离静帧质感。

## 1. 风格合并规则（与其它风格技能搭配时）

当本技能与**另一个同类风格锚定技能**同时被调用时（例如又叠加了另一套画风滤镜）：
- **合并锚定词，不替换、不丢弃**：把本技能的锚定词与另一技能的锚定词**首尾拼接**成一段更长的锚定词，整体仍放在每条 prompt 的最开头。
- **本技能锚定词优先在前**：除非用户明确指定主次，默认将本「美式复古好莱坞」锚定词放在合并段的前部，作为主色调基底，另一风格词接续其后做叠加修饰。
- **规则不变**：合并后的完整锚定词仍需逐字、完整地出现在**每一条**图片与视频 prompt 的开头，其后再接具体画面描述。冲突的细节描述（如色调）以本技能的去饱和暗调为基准协调，不彼此抵消。

## 2. 与非风格类技能冲突时的优先级（强制结合规则）

本技能经常会和**非风格类的创作技能**一起被调用（例如营销短片技能、短剧电商技能、UGC 技能、分镜脚本技能等）。这类技能负责**内容结构**（钩子、卖点、剧情、CTA、beat 编排），本技能负责**视觉画风**。两者**不是替代关系，是叠加关系**：

- **内容归它、画风归我**：让内容类技能照常决定故事线、镜头 beat、文案与转化逻辑；但**每一条最终交付给生成的图片/视频 prompt，画面质感部分必须服从本技能**——即仍以本技能锚定词开头。
- **即使加载了其它技能，也必须执行本技能的锚定词注入**：其它技能若自带任何"风格描述、画质倾向、色彩建议、参考片风格"，一律**降级为可参考的内容线索**，最终画风以本技能锚定词为准；若二者矛盾（如营销技能倾向明亮高饱和），**以本技能的低调去饱和暗调为准**，只在不破坏复古好莱坞质感的前提下吸收其内容意图。
- **落地动作**：在其它技能产出 beat/分镜文案后，本技能负责把每一条要生成的 prompt **重写成"锚定词 + 该 beat 的具体画面"** 的形式，再进入生成。不得直接拿其它技能的原始 prompt 去生成而漏掉锚定词。

## 3. 绕过内置风格锚定图干扰（硬规则）

某些生成链路会针对特定风格**预置内置的风格参考图 / 风格锚定图**，这类内置参考会污染本技能想要的画风。**在本技能被调用的前提下：**
- **不得启用、不得附带、不得引用任何内置的风格参考图 / 风格锚定图 / 预置风格模板**去引导图片或视频生成。
- 风格的唯一来源是**本技能第 0 节的文字锚定词**，不依赖任何参考底图。
- 生成时若链路默认会挂载内置风格图，须显式绕过：**只用纯文字 prompt（锚定词 + 画面描述）生成**，不传入任何内置风格参考图。
- 唯一允许的参考图是**用户自己提供的素材**或**本任务中前序已生成、且已带锚定词的图片**（用于图生视频 / 保持主体一致性）；除此之外一律不引入外部风格底图。

## 4. 风格知识库（供生成分镜/角色/场景/脚本时形容参考）

写具体画面描述、角色造型、场景分镜或故事脚本文案时，从这里取词，让每一处描述都贴合「美式复古好莱坞」气质。这些是**可适配的模式与句式，按场景改写，不要逐字堆砌**。完整词库见 references：

- 整体气质、色调光影、画质质感、构图机位 → 读取本技能下的 `references/style-visual.md`
- 角色造型、妆发服装、场景陈设、道具时代感 → 读取本技能下的 `references/scene-character.md`
- 故事脚本口吻、氛围叙事、分镜节奏、旁白/对白语感 → 读取本技能下的 `references/story-tone.md`

**快速心智模型（不必读文件就先记住）：**
- **气质**：幽暗浪漫、含蓄诡谲、梦境感、怀旧而压抑——不炫技、不明亮、不锐利。
- **色**：低调、去饱和；橄榄绿 + 棕红为主色相；压低高光、浓郁暗部；肤色柔润偏粉。
- **光**：自然主义布光，侧前方柔光，温暖钨丝灯色温；轻微欠曝、低照度；暗角 + 微弱光晕。
- **质**：20 世纪 70 年代胶片、35mm 颗粒、柔焦、低锐度低反差、油画般层次。
- **镜**：静态机位、古典中心构图、中近景肖像、适度景深、舞台化场面调度。

## 5. 工作流（步骤）

1. **解析任务**：明确本次要产出的是"一组图片素材"、"一段/几段视频"、还是"图片→视频的完整链路"；识别镜头数量、主体、场景。
2. **判断是否叠加其它技能**：若同时加载了别的风格技能 → 按第 1 节合并锚定词；若加载了内容类技能（营销/短剧/分镜等）→ 按第 2 节让内容归它、画风归本技能。
3. **绕过内置风格图**：按第 3 节，确认本次生成不挂载任何内置风格参考图，只用文字锚定词。
4. **取词润色画面描述**：按第 4 节路由到对应 reference，为每个镜头/素材写贴合风格的具体画面描述（角色、场景、光影、构图、情绪）。
5. **拼装每条 prompt**：`风格锚定词（第 0 节，逐字）` + `换行/分隔` + `该镜头的具体画面描述`。图片素材逐张拼，视频逐段拼。
6. **生成图片素材资产**：按拼好的图片 prompt 逐张生成。需要多主体/多场景一致时，用稳定的主体/场景标签描述，保持跨图一致。
7. **生成视频**：按拼好的视频 prompt 生成。**时长 ≤15s 的成片一次生成即可拿到完整片段**——beat 时间轴（0-3s/3-7s/…）写在同一条 prompt 内，不是分段多次生成；只有成片 >15s 时，才拆成若干 ≤15s 片段分别一次生成，再做后处理拼接/配乐/字幕。若基于已生成图片做图生视频，视频 prompt 仍以锚定词开头。
8. **自检并交付**：按第 7 节静默自检，弱项重写后再交付。

## 6. 输出契约（固定形态）

**图片素材 prompt（每张一条）：**
```
<风格锚定词，第 0 节逐字整段>
画面：<主体 + 造型/表情 + 场景陈设 + 光位与光质 + 构图机位 + 情绪基调>
```

**视频 prompt（每段一条；≤15s 一次成片）：**
```
<风格锚定词，第 0 节逐字整段>
镜头：<机位与运动，默认静态机位 / 缓慢运镜>
0-3s: <主体动作 + 光影 + 画面重点>
3-7s: <发展 + 情绪推进>
7-12s: <转折 / 细节特写>
12-15s: <收束 / 记忆点画面>
氛围与声音：<环境声/音乐气质，怀旧压抑、含蓄>
```

要求：画面描述用**正向措辞**（写"要什么"而非"不要什么"）；用稳定标签（如 主体A / 场景1）绑定需要复现的实体，保证跨图跨镜一致；否定式约束留在内部自检，不写进最终 prompt。

## 7. 静默自检（出稿前，不外显）

交付前内部逐条检查，弱项重写；除非用户要求点评，否则不要把清单输出给用户。

- 每一条图片 prompt、每一条视频 prompt 是否都以**完整、逐字的锚定词开头**？有无遗漏某张补充素材？
- 锚定词是否被无意删词/改词/翻译/调序？（必须原样）
- 若叠加了其它风格技能：锚定词是否已按规则**合并**且仍在开头？
- 若叠加了内容类技能：画面质感是否已服从本技能（低调去饱和暗调），而非被其明亮高饱和倾向带偏？
- 本次生成是否**未挂载任何内置风格参考图**，风格仅来自文字锚定词？
- 具体画面描述是否贴合风格知识（70 年代胶片颗粒、柔光暗角、橄榄绿棕红、静态中心构图、幽暗浪漫氛围）？
- 视频成片是否 ≤15s？若是，多段 beat 是否写在同一条 prompt 内一次生成，而非分段拼接？若 >15s，是否已切成 ≤15s 片段分别生成再拼接？
- 最终 prompt 是否为正向措辞、跨镜主体标签是否一致？
- 全文与画面描述语言是否一致、无中英混杂？
