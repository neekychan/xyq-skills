# Seedance 2.5 Brand Film Prompt Writing

Use this provisional reference for 30-second Seedance 2.5 brand films, TVCs, campaign hero films, and cinematic product films. It is the authoritative prompt contract for this local 2.5 skill.

## Default Contract

- Follow the user's explicit model, duration, ratio, platform, language, and style instructions first.
- If duration is not specified, use `30秒`.
- Default brand-film ratio remains `16:9`; use `9:16` for vertical, mobile-first, short-video, TikTok/Reels/Shorts, Douyin/Kuaishou/Xiaohongshu, or phone-native requests.
- Use 5-6 timed beats by default.
- Keep one primary brand idea, one visual world rule, and one brand/product proof mechanism.
- Use the extra 30 seconds for a stronger proof chain and reaction/resolution, not for adding unrelated claims.

## Prompt Opening

Chinese final prompts should start with:

```text
时长：30秒，比例：16:9。任务：生成Seedance 2.5品牌TVC/品牌大片。
```

For vertical:

```text
时长：30秒，比例：9:16。任务：生成Seedance 2.5竖屏品牌TVC/品牌大片。
```

## Required Final Prompt Sections

Use this compact order:

```text
时长：30秒，比例：16:9。任务：生成Seedance 2.5品牌TVC。

标题：
风格与视觉参考：
场景：
主体：
各个分镜的具体内容：
```

`风格与视觉参考` must include:

- one primary style reference or coherent style family
- 4-8 style keywords created from the brief
- full-film lighting rule
- camera/lens behavior
- edit rhythm
- sound motif

## 30-Second Beat Rhythm

Use this rhythm unless the user's structure is stronger:

```text
0-3秒：directed hook / brand world entrance
3-8秒：category tension or audience pressure
8-14秒：protagonist, subject, or brand world expands
14-21秒：product or brand mechanism becomes visible proof
21-27秒：emotional, social, or visual resolution
27-30秒：brand mnemonic lockup
```

Every beat must use:

```text
拍法：
画面内容：
品牌/产品露出：（only when visible）
声音：
```

## 2.5 Upgrade Judgment

Seedance 2.5 should be used to create a fuller filmable chain:

- hook frame
- pressure frame
- brand world frame
- product/brand proof frame
- reaction or resolution frame
- lockup frame

Do not simply stretch a 30-second prompt. Add continuity, action completion, reaction, atmosphere, and brand mnemonic.

## Final Self-Check

- Prompt starts with `时长：30秒`.
- It has 5-6 beats unless the user asks otherwise.
- The product or brand asset changes the story, light, social relation, material behavior, or camera point of view before the final lockup.
- The final 3 seconds include a readable brand/product lockup, brand line or slogan when available, and a concise sonic cue.
- The visible prompt uses positive production wording.
