# 二次元/卡通风格游戏美术规范

## 核心视觉特征
- 材质：赛璐璐渲染，平涂为主，阴影边界清晰，少渐变，材质卡通化
- 光影：风格化光影，阴影形状明确，明暗对比适中，有明显的轮廓线
- 色彩：高饱和度，明亮活泼，配色明快清新，二次元典型配色方案
- 建模：卡通比例（Q版或正常二次元比例），角色头身比符合二次元审美，轮廓线清晰

## 场景规范
- 卡通场景：造型夸张可爱，色彩明亮，纹理手绘感强，有明显的美术风格
- 二次元场景：动漫感场景，光影柔和，空气感强，远景有简化和空气透视
- UI风格：圆润可爱，色彩鲜艳，按钮有Q弹的反馈效果，图标卡通化

## 角色规范
- 二次元角色：五官精致，眼睛大而有神，发型夸张有特色，服饰设计感强，布料褶皱简化
- Q版角色：2-4头身，头大身小，动作夸张可爱，表情丰富
- 材质表现：皮肤光滑白皙，头发有明显的高光块，服饰色彩平涂，阴影为硬边色块

## 战斗特效规范
- 卡通技能：特效夸张可爱，形状圆润，色彩鲜艳，有卡通速度线、夸张表情符号等元素
- 二次元技能：华丽的光效，樱花、光粒、羽毛等唯美元素，技能演出动画感强
- 镜头效果：战斗时有漫画式的速度线、冲击框、夸张的变形效果，反馈感强烈
