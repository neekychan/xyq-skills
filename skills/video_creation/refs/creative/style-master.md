# 视觉基调速查总表(风格+文化+情绪三合一)

本文件合并三套速查:艺术风格(§一)、文化美学(§二)、情绪→视觉参数(§三)。三者可叠加使用——风格定画法,文化定元素,情绪定光影运镜音频。多镜头项目的"风格关键词逐字复制锁定"一致性规则在 §一 统一展开,§二§三涉及处指向 §一,不重复。

---

## 一、艺术风格

> 本节(风格)适用:用户 prompt 中含风格词（水墨/赛博朋克/3D/像素/写实/动漫/美漫/皮影/粘土/盲盒 等）时查此节。

### 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| "动漫风格的视频" | 模型可能生成日漫/国漫/美漫任意一种 | 明确子风格："2D日漫赛璐璐风格"或"3D国漫CG风格" |
| 不同镜头使用不同风格关键词 | 风格漂移，拼接后视觉割裂 | 所有镜头逐字复制相同的风格关键词 |
| "水墨+赛博朋克" | 风格冲突，模型生成混乱结果 | 选择一个主风格，可用色彩/元素微调 |
| 风格关键词做同义替换 | 模型理解不一致导致漂移 | "3D国漫CG风格"不能换成"3D中式动画" |

### 强制规则

1. **确定风格后锁定**：每个镜头的 prompt 末尾必须重复完整的风格关键词
2. **禁止跨镜头混搭风格**：一个项目只能使用一种画风
3. **风格关键词逐字复制**：不可用同义词或近义词替换
4. **动漫/2D/3D 必须显式声明**：不写风格关键词时模型默认偏向写实，非写实风格必须明确

### 预置锚定图

速查表「预置锚定图」列标注了已有经过验证的风格概览图，存放于 `creative/anchors/`。第 0 轮风格锚定时：

1. 在速查表中找到匹配的风格行
2. 该行「预置锚定图」列有路径 → 用 `sandbox_bash` 从 `/workspace/.skills/video_creation/refs/creative/{路径}` cp 到 `assets/{project}/style_anchor.png`，跳过生成，直接进入第 1 轮
3. 该行值为 `—` 或风格不在速查表中 → 走 `assets/ref-image-design.md` §〇.1 生成流程

### 风格选择决策树

1. 用户**提及具体风格名称** → 直接使用速查表对应行的 Prompt 关键词
2. 用户**提及制片厂/年代/导演名** → 先查速查表有无对应行（宫崎骏/吉卜力→手绘吉卜力风，新海诚→光绘动漫，皮克斯→3D皮克斯风）；有则用速查表关键词，无则直接写进 Prompt(如"邵氏武侠风格")
3. 用户**提及的风格不在速查表中** → 基于描述自行构建关键词(参考最接近的行做扩展)
4. **未指定但有参考图** → 识别参考图风格,匹配最接近的行
5. **未指定无参考图** → 按题材默认:现代都市→写实;武侠/历史→3D国漫CG或青绿山水;儿童→3D皮克斯风;校园→日系2D;科普→日系简洁插画;品牌→写实

### 风格锁定规则（多镜头项目必读）

> 本节是"风格关键词逐字复制锁定"一致性规则的统一展开处。§二 文化美学、§三 情绪参数中涉及"逐字重复风格词/锁定"处均指向本节,不再展开。

1. **首次确定风格后**，将完整的风格关键词记录到 `creative_design.md` 的整体风格字段
2. **风格关键词是全片共用约束**：多段视频写入 storyboard.md 的 `通用尾注`（只写一次，生成时拼到每段末尾），单段视频直接附在该段 prompt 末尾——两种方式下每段实际生效的风格词都必须逐字相同，禁止跨段改写。机制见 `storyboard/prompt-craft.md`「质量约束」
3. **每张参考图的生成 prompt** 也必须包含相同的风格关键词
4. **禁止在中途切换风格**——如果用户要求换风格，需要重新生成所有参考素材

## 二、文化美学

> 本节(文化)适用:用户 prompt 中含文化词（中式/日式/北欧/法式/韩式/古风/未来感/复古/东南亚/中东 等）时查此节。

### 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| "中式风格" | 过于宽泛——古典/现代/民国完全不同 | 明确子风格："宋代文人美学"或"赛博中国风" |
| "日式+中式" | 文化元素混搭导致不伦不类 | 选择一个文化主调，另一个仅取色彩或构图元素 |
| 用西方建筑配中式人物 | 场景与角色文化割裂 | 场景和角色的文化背景保持一致 |

### 强制规则

1. **文化词必须细化到子风格**：不接受"中式""日式"这种一级词，必须指定二级子风格
2. **场景、角色、道具的文化背景必须统一**
3. **文化元素需明确具象**：不写"中式元素"，写"青花瓷花纹、红木家具、宣纸"
4. **风格关键词逐字复制锁定**：见 §一「风格锁定规则」,文化子风格关键词一经确定同样需跨镜头逐字复制,不重复展开。

| 东南亚热带 | 翡翠绿、金、朱红 | 寺庙佛塔、热带雨林 | 东南亚热带风情，金色佛塔，茂密植被 |
| 印度 | 藏红、金、宝石色 | 泰姬陵、集市、恒河 | 印度风情，鲜艳色彩，精美纹饰 |

### 文化选择决策树

```
用户提到文化词
  │
  ├─ 已指定子风格（如"侘寂"） → 直接使用对应行
  │
  └─ 仅一级词（如"日式"） → 需澄清：
       │
       └─ 根据题材推断：
            ├─ 安静/禅意/茶道 → 侘寂
            ├─ 校园/青春/热血 → 日漫现代
            ├─ 历史/传统 → 浮世绘
            └─ 恐怖/灵异 → 日式恐怖
```

### 失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| 文化词不细化 | "中式"可能出现古典/现代任意一种 | 必须指定二级子风格 |
| 文化元素混搭 | 日式庭院配中式汉服 | 场景、角色、道具文化背景统一 |
| 仅用文化词不给视觉元素 | 模型不知道放什么具体物件 | 至少指定 2-3 个标志性视觉元素 |
| 忽略配色体系 | 中式宫廷用了北欧冷灰色 | 按速查表使用对应配色 |

## 三、情绪→视觉参数

> 本节(情绪)适用:用户 prompt 中含情绪词（治愈/沉郁/神秘/温馨/紧张/欢快/浪漫/热血/高级/孤独/怀旧/恐怖 等）时查此节。

### 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| "做一个治愈的视频" | 情绪词无具象化，模型自由发挥，结果不可控 | 查速查表，将"治愈"展开为配色+光影+运镜+BGM 四维参数 |
| "治愈感，暖色调" | 仅指定一个维度，光影/运镜/BGM 仍然随机 | 至少覆盖 4 个维度：配色+光影+运镜+音频 |
| 每个镜头使用不同情绪 | 视觉混乱，观众无法建立情感连接 | 全片最多 3 种情绪，按弧线排列 |

### 强制规则

1. **四维映射**：每个情绪词必须映射到至少 4 个维度——配色、光影、运镜节奏、音频氛围
2. **情绪弧线**：一个视频中的情绪变化最多包含 3 种情绪，且必须有过渡（不可硬切）
3. **一致性**：同一情绪段内的所有镜头必须使用相同的情绪参数集
4. **风格关键词逐字复制锁定**：见 §一「风格锁定规则」,情绪参数叠加在锁定的风格关键词之上,风格词本身的逐字复制规则不重复展开。

### 情绪过渡规则

情绪转换不可硬切，必须有过渡处理：

| 转换类型 | 过渡方式 | 过渡时长 |
|---------|---------|---------|
| 相近情绪（治愈→浪漫） | 配色渐变，运镜节奏微调 | 1-2 秒 |
| 中等跨度（欢快→沉郁） | 插入一个中性情绪镜头作为桥接 | 2-3 秒 |
| 对立情绪（治愈→恐怖） | 强烈不建议；如必须，用"反转"手法（如突然静音+画面骤变） | 按叙事需要 |

**对立情绪组合警告**：
- 治愈 + 恐怖 → 认知冲突极强，仅用于刻意反转
- 欢快 + 沉郁 → 需要明确的叙事转折支撑
- 高级 + 欢快 → 调性矛盾（奢华需要克制，欢快需要奔放）

### 失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| 仅用情绪词不展开 | 模型随机发挥，每次结果差异大 | 查速查表展开为四维参数 |
| 配色和 BGM 情绪矛盾 | 认知失调（暖色画面配阴森 BGM） | 用速查表同一行的参数保证一致 |
| 每个镜头情绪不同 | 观众无法建立情感投入 | 全片限 3 种，按弧线编排 |
| 情绪转换无过渡 | 硬切导致割裂感 | 插入过渡镜头或使用渐变 |
| 忽略音频维度 | 画面情绪到位但听感不匹配 | 音频是情绪的重要载体，必须同步指定 |
