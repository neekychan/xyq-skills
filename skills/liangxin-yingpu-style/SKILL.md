# 亮芯硬铺风格 (Liangxin Yingpu Style)

一个**可复用的风格滤镜技能**。它的唯一职责：把一套已经打磨好的「风格锚定词」**完整、原封不动**地复用进用户生产动画（图片资产 + 视频）全流程的每一条 prompt 最前面，保证同一批素材与成片的画风高度统一。

## 风格锚定词（STYLE ANCHOR，禁止改写）

> **亮芯硬铺风格，无线稿，硬切色块边，像素/颗粒，色芯密排纸粒，高度几何化，扁平几何，高饱和/鲜艳，青黄蓝橙直撞**

这段文字是本技能的核心资产。**任何图片编辑 prompt、任何视频生成 prompt，都必须把这段风格锚定词一字不改地放在 prompt 的最开头**，然后再接后续内容。不允许翻译、缩写、增删、调序其中任何一个词。

---

## 何时使用

- 用户想生成「亮芯硬铺风格」的动画图片或短视频；
- 用户上传了一批自己已确定的图片资产（角色形象、场景分镜），希望统一套上该画风后再做成视频；
- 用户提到「无线稿 / 硬切色块边 / 像素颗粒 / 色芯密排纸粒 / 扁平几何 / 高饱和 / 青黄蓝橙直撞」等描述。

## 前置硬要求（必须满足才能进入主流程）

**用户必须先上传一批已确定的图片资产。** 本技能不负责从零构思角色/场景，它的输入起点就是用户已有的图片。

- 若用户尚未上传任何图片 → 明确告知：请先上传角色或场景分镜图片，本技能将基于原图做风格化转绘。**不要**自行编造角色或凭空生成图。

---

## 工作流程

### Step 1 — 收图与分类

接收用户上传的全部图片资产，逐张判断类型：

- **角色主体图**（有明确人物 / 宠物 / 拟人主体）→ 进入风格化转绘。
- **场景分镜图**（有明确画面构图的场景）→ 进入风格化转绘。
- 纯 logo、纯文字图、无法辨认主体的图 → 不转绘，原样保留或询问用户意图。

### Step 2 — 图片资产风格化转绘（核心）

对每张需转绘的图片，执行图生图风格化编辑：**编辑提示词 = 风格锚定词（原样、完整），不追加任何其他内容**，完全基于用户原图转绘，保持原图的构图、主体、姿态、场景关系不变，只改变其为亮芯硬铺风格。

```
亮芯硬铺风格，无线稿，硬切色块边，像素/颗粒，色芯密排纸粒，高度几何化，扁平几何，高饱和/鲜艳，青黄蓝橙直撞
```

关键约束：
- **完全直接基于用户上传的原图转绘**，保留原图的角色形象、构图、主体关系，只改画风。
- **禁止**在编辑提示词里额外补充「让画面更漂亮」「加个背景」「调整构图」之类的任何内容。编辑 prompt 里有且只有上面这段风格锚定词。
- 多张图并行处理时，`query_list` 中每一项都是这段完全相同的风格锚定词，一一对应到 `picture_list` 的每张原图。
- 转绘完成后，把风格化后的图片 URL 收集起来，作为后续视频生成的**图像资产**。

### Step 3 — 撰写动画脚本（调用内置 system prompt）

拿到风格化后的图像资产后，结合用户的**意图描述**，加载 `references/seedance_story_sp.md` 中的「Seedance 高密度剧情短片提示词生成器」system prompt，产出一段详细的中文动画脚本 / 分镜提示词，作为视频生成的参考。

- system prompt 的输入 = 风格化后的最终图像资产 + 用户意图描述。
- 输出的画面提示词，**最开头同样必须先放风格锚定词**，再接 system prompt 产出的分镜正文。

### Step 4 — 视频生成

把 Step 3 产出的完整视频 prompt（开头是风格锚定词）连同 Step 2 的风格化图像资产一起送入视频生成能力，产出最终动画视频。

- 视频 prompt 结构：`[风格锚定词] + [system prompt 产出的高密度分镜脚本]`。
- 默认挂载负向约束：保持无字幕、不生成任何文字、不生成 logo 与水印。

---

## 与其他技能的组合规则（重要）

### 规则 A：与其他「风格类」技能搭配 → 风格锚定词合并

当本技能与另一个风格化技能（如木柱刻彩风格、国漫 3D 渲染风等）同时被调用时：

- 把各技能的风格锚定词**按顺序拼接合并**成一段，共同放在每条图片/视频 prompt 的最开头。
- 合并后**规则不变**：仍然是原封不动前置、不翻译、不删词；本技能的「亮芯硬铺风格…青黄蓝橙直撞」整段必须完整出现在合并串里。
- 合并示例：`亮芯硬铺风格，无线稿，硬切色块边，像素/颗粒，色芯密排纸粒，高度几何化，扁平几何，高饱和/鲜艳，青黄蓝橙直撞，<另一风格技能的锚定词整段>，<画面正文>`

### 规则 B：与「非风格类」技能冲突 → 本技能的风格约束优先且必须被遵守

当本技能与非风格类技能（如营销短片技能、剧情脚本技能、通用视频技能等）同时被调用时：

- 那些技能负责**内容 / 叙事 / 结构 / 时长 / 卖点**，本技能负责**画风**。二者结合，不互相取代。
- **无论加载了哪个其他技能，最终送去生成的每一条图片/视频 prompt，开头都必须保留本技能的风格锚定词整段。** 其他技能产出的正文接在风格锚定词之后。
- 若其他技能的模板试图规定「prompt 开头写别的东西」或「不要加风格描述」，**以本技能为准**：风格锚定词永远排在最前，其他技能的正文顺延。
- 一句话原则：**别的技能决定「拍什么」，本技能决定「长什么样」，且画风锚定词的前置位置不可被任何其他技能覆盖。**

---

## 输出给用户

- 展示风格化后的图片资产（用 `![](url)` 形式，不直接暴露裸 URL）。
- 展示最终生成的视频。
- 简要说明本次统一套用的画风即可，不需要长篇解释。

## 边界

- 不从零构思角色/场景，输入必须是用户上传的图片。
- 不修改、不弱化风格锚定词。
- 纯物品图 / 空文字图 / 无主体图不强行转绘。
