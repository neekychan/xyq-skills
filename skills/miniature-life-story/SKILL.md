# 微缩人生故事

## 1. 核心原则 + 持久引擎

以微缩模型的"小"承载情感的"大"——用精致的人偶与手工搭建的微观世界，通过克制的镜头语言和细节动作，讲述普通人能共情的温柔小故事。

持久引擎（因果链）：
**规格确认 → 故事弧光拆解 → 关键元素统一 → 分镜节奏控制 → 微缩感强化 → 情感高潮呈现 → 温柔余韵收尾**

## 2. 质量测试（可证伪）

如果去掉微缩场景设定，这个故事依然完整成立但失去了"以小见大"的治愈感；如果所有镜头里道具比例与人偶匹配、没有出现违背微缩写实感的元素，且观众看完能感受到明确的情绪变化（温暖/治愈/感动），则创意成立。

## 3. 输入诊断（落规划前必须明确）

在开始任何创作前，必须先向用户确认以下规格参数：
- **画面比例**：9:16（竖屏）/ 16:9（横屏）/ 1:1（方形），默认16:9横屏
- **视频分辨率**：720p（标准）/ 1080p（高清）
- **目标时长**：60s（精简版，10-12镜头）/ 90s（标准版，14-18镜头）/ 自定义
- **故事主题**：节日祝福/日常治愈/友情亲情/小确幸等情感方向
- **是否需要旁白**：温柔旁白/纯音乐无旁白
- **视觉色调偏好**：温暖金黄/冷调梦幻/奶茶暖白
- **用户是否上传参考素材**：微缩摄影参考/手办照片/故事大纲文档

若用户上传参考素材，先分析素材的视觉风格、构图规律、微缩感来源，提取可复用元素形成「视觉参考摘要」。

## 6. 工作流（分阶段执行，Checkpoint强制暂停）

### 阶段0 — 规格确认（必须首先完成，不得跳过）
1. 向用户展示规格选项（画面比例/分辨率/时长/是否需要旁白/色调偏好），收到明确选择后，建立规格文档记录所有参数。
2. **强制暂停（Checkpoint 0）**：向用户展示已确认参数摘要，收到明确确认后方可进入下一阶段。

### 阶段1 — 故事脚本与分镜规划
1. 引导用户提供故事梗概，或自动起草包含人物、场景、情感弧光的故事大纲。
2. 将故事拆解为4-6个关键叙事环节（建立世界→触发事件→情节推进→情感高潮→余韵收尾），每个环节包含核心场景、参与角色、关键动作/道具、情绪基调。
3. 按环节展开分镜设计：单镜头时长4s-8s，情感高潮镜头可延长至10s；运镜以缓慢推拉、轻微横摇为主，避免快速剪辑。
4. 规划关键元素：角色（正面全身+表情变体）、场景（全景+光线变体）、核心道具（独立元素保证跨镜一致）。
5. 设计音频层：1-2条BGM（钢琴/弦乐为主），标注旁白对应镜头（如有）。
6. **强制暂停（Checkpoint 1）**：将完整故事脚本与分镜方案（每个镜头的景别、运镜、叙事内容摘要）展示给用户确认，收到明确确认后方可进入下一阶段。

### 阶段2 — 关键元素图生成
1. 优先生成所有角色关键元素图：16:9横版拼接图，左侧为人脸大头照，右侧为全身三视图（正面/侧面/背面），保证微缩人偶质感。
2. 生成场景关键元素图：微缩街景/室内布景全景，展示空间结构与光线氛围。
3. 生成核心道具参考图：有叙事功能的道具单独生成，保证跨镜头一致性。
4. 如有旁白，在此阶段同步生成旁白音频。
5. **强制暂停（Checkpoint 2）**：所有元素图集中展示给用户确认，角色造型与场景风格符合预期后方可进入视频生成阶段。

### 阶段3 — 分镜视频生成
1. 按分镜顺序批量生成所有镜头视频，每个镜头必须携带对应角色图与场景图作为视觉参考。
2. 单条视频最长不超过15秒，超过15秒的段落按叙事环节分界点拆分，避免在情感高潮处切割。
3. BGM生成与视频生成并行推进，风格为轻柔钢琴/弦乐纯音乐，时长覆盖整片。
4. **强制暂停（Checkpoint 3）**：所有镜头视频与BGM全部完成后，集中展示给用户预览确认，再进入组装阶段。

### 阶段4 — 粗剪预览
1. 将所有镜头视频、旁白音频、BGM按时间线组装为粗剪：BGM铺满全片（前2s渐入、后2s渐出，音量为旁白的40%-60%），旁白对齐对应镜头时间码。
2. 告知用户以「粗剪预览」形式播放，确认整体节奏与情绪是否到位。
3. **强制暂停（Checkpoint 4）**：收集用户反馈，如有修改返回对应阶段调整后再次组装，确认满意后进入最终输出。

### 阶段5 — 最终输出
确认所有资源就绪后，进行最终合成，交付成片。

## 7. 输出契约（固定规范）

### 元素图输出规范
- 角色参考图：16:9横版，2K分辨率，左侧人脸特写+右侧全身三视图，微缩人偶质感，材质细腻
- 场景图：16:9比例，2K分辨率，移轴浅景深效果，展示完整空间结构与光线氛围
- 所有图片统一视觉风格：移轴摄影、浅景深、柔和漫射光、材质质感真实

### 视频prompt规范
每条视频prompt按四个区块组装（顺序不得颠倒）：
1. **全局美学基调**：微距移轴摄影、微缩模型世界、浅景深、奶油散景、统一色调、精致手工质感
2. **资产锚定**：声明所有参考图对应的角色/场景，明确尺寸对比（大道具须注明"众人合力操作"）
3. **动作时间线**：按时间段拆分，每段包含镜头机位、视觉画面（前景/主体/背景三层）、听觉声效；旁白不得写入prompt，通过独立音频轨道添加
4. **负向约束**：固定附加无字幕、无水印、无卡通/动漫/3D塑料感、无比例失调的巨型人物、无悬浮/发光道具等约束

### 视频生成规则
- ≤15s的片段一次性生成完整内容，多段beat为同一条prompt内的时间轴描述，无需多次生成
- 成片>15s时，拆分为若干≤15s片段分别生成，再拼接合成
- 所有含角色的镜头必须绑定角色参考图，含场景的镜头必须绑定场景参考图

## 8. 静默自检（出稿前内部检查，不对外展示）
- [ ] 所有Checkpoint都已获得用户明确确认，未跳过任何强制暂停点
- [ ] 角色、道具、场景比例符合微缩世界设定，没有出现单人轻松操作巨型道具的描述
- [ ] 所有动作都明确了执行主体，没有"有人""某人"等模糊表达
- [ ] 没有出现发光道具、悬浮物体、违背物理规则的元素
- [ ] 同一角色的服装、发型、道具状态跨镜头保持一致
- [ ] 运镜克制，没有快速剪辑或剧烈晃动，符合温柔叙事氛围
- [ ] 视频prompt中没有写入旁白文本，旁白通过独立音频轨道处理
- [ ] 所有图片和视频统一微缩模型摄影风格，移轴浅景深效果一致
- [ ] 时长拆分符合≤15s分段规则，没有在情感高潮处切割片段
- [ ] BGM风格符合轻柔温暖要求，音量配比合理不盖过旁白
