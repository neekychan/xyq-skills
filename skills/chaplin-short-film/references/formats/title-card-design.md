# 字幕卡设计规范

## 功能分类
1. **叙事卡**：交代时间、地点、背景信息，例如"1925年，纽约，冬天"
2. **对白卡**：传递人物关键台词，例如"我可以买一朵花吗？"
3. **情感卡**：点出情感主题，例如"他把所有的钱都留给了她"
4. **章节卡**：划分故事段落，例如"第一幕 流浪的日子"
5. **结尾卡**：片尾字幕，例如"THE END"或"完"

## 视觉风格
- 经典默片风格：纯黑背景（90%场景使用）或纯白背景（特殊情感场景使用）
- 文字：白色文字配黑背景，黑色文字配白背景，居中对齐
- 字体：复古衬线字体，中文使用老宋体风格，英文使用类似Times Bold的粗衬线字体
- 边框：四周有1-2mm的细白边（黑底卡）或细黑边（白底卡）
- 质感：35mm胶片颗粒，轻微的划痕、灰尘痕迹，模拟老电影放映的磨损感
- 禁止：彩色文字、装饰图案、现代字体、花哨设计

## 文字规范
- 中文：每张卡文字不超过2行，每行不超过12个字
- 英文：每张卡文字不超过2行，每行不超过8个单词
- 字体大小适中，上下左右留出足够边距（边距约占画面10%）
- 文字简洁有力，符合默片台词风格，不用长句
- 关键台词可单独成卡，突出情感力量

## 插入时机规范
| 影片时长 | 字幕卡数量 | 间隔时间 |
|----------|------------|----------|
| 1分钟 | 2~3张 | 每20~30秒一张 |
| 2分钟 | 4~6张 | 每20~30秒一张 |
| 3分钟 | 6~9张 | 每20~30秒一张 |
| 5分钟 | 10~15张 | 每20~40秒一张 |

插入位置优先级：
1. 影片开头必须有片名卡
2. 章节转换处
3. 关键对白出现时
4. 时间/地点跳跃时
5. 情感高潮点
6. 影片结尾必须有结束卡

## 衔接规则
1. 字幕卡插入在视频轨道上，与前后视频镜头直切衔接，无转场
2. 字幕卡显示时长：
   - 短文本（1行）：2秒
   - 长文本（2行）：3秒
   - 片名卡/结尾卡：3~4秒
3. 字幕卡前后的镜头需要有情绪铺垫：例如人物说完话后切字幕卡，再切回人物反应镜头
4. 避免连续插入多张字幕卡，中间至少间隔一个视频镜头
