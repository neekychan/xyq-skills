# 视觉特效(VFX)工艺规范

## 特效分层原则
所有战斗特效必须分为以下五层，层次分明，不遮挡核心UI和角色动作：
1. **底层特效**：地面痕迹、冲击波、法阵，位于角色脚下
2. **中层特效**：技能主体特效、刀光、弹道，位于角色周围
3. **上层特效**：爆炸、闪光、粒子飞溅，位于角色上方
4. **屏幕特效**：镜头光晕、色差、屏幕震动、边缘光效，全屏效果
5. **UI特效**：伤害数字、技能CD、Buff图标，固定在UI层

## 不同风格特效规范
### 写实风格特效
- 元素特效符合物理规律：火焰向上燃烧有热浪扭曲，水流有折射和飞溅，雷电有随机分叉
- 粒子大小真实，数量适中，无过度夸张的效果
- 爆炸有冲击波、烟雾、碎片飞溅，物理运动轨迹正确
- 光影正确，特效照亮周围环境，产生真实的投影

### 奇幻/国风特效
- 魔法特效有符文、法阵、光带等元素，色彩鲜艳
- 国风特效采用水墨、祥云、剑气、花瓣等东方元素，线条流畅
- 大招特效有明显的蓄力→爆发→消散三段式动画
- 光效柔和，有辉光和 Bloom 效果，氛围感强

### 赛博朋克/科幻特效
- 能量特效有科技感：光束边缘锐利，有 glitch 故障效果，数字粒子
- 全息投影有扫描线、透明度变化、故障闪烁
- 爆炸有电子脉冲效果，冲击波为圆形能量扩散
- 屏幕特效有扫描线、色差偏移、HUD故障等科技感效果

### 二次元/卡通特效
- 特效形状夸张，边缘清晰，有明显的轮廓线
- 速度线、冲击框、夸张变形等漫画表现手法
- 色彩饱和度高，对比强烈，Q弹的弹性动画
- 打击特效有夸张的星形、爆炸形卡通图案

## 打击感强化规范
所有攻击命中必须包含以下反馈元素，增强打击感：
1. **命中帧停顿**：命中瞬间0.1秒全局时间静止（hit stop）
2. **镜头震动**：命中时镜头根据技能威力产生不同幅度的震动
3. **敌人硬直**：被击中敌人产生明显的受击硬直动作
4. **粒子飞溅**：命中位置产生对应元素的粒子飞溅（火花、碎屑、冰屑等）
5. **伤害数字**：伤害数字向上弹出，根据伤害大小调整字体大小和颜色
6. **屏幕效果**：重击时产生屏幕色差、边缘暗角等效果

## 性能与稳定性规范
- 特效粒子数量控制在合理范围，避免过度遮挡角色动作
- 特效动画流畅，无跳帧无卡顿
- 所有特效不覆盖UI禁止形变区，不导致UI元素变形
- 特效颜色与场景色调协调，不产生突兀的色彩跳变
