# 通用视频与图片创作

来源：[主手册](https://bytedance.larkoffice.com/wiki/PxZgwJwxti0dutk6WIdcwRA6nTd)。

## Agent 模式

- 入口：网页输入框左侧【Agent 模式】。
- 输入自然语言需求，可结合脚本、图片、视频和文案素材进行创作；支持图片、短片、长视频，以及多轮对话探索、打磨创意和修改产物。
- 可使用「一键优化提示词」完善模糊指令；Agent 会按需要确认创作需求。
- 提示词组织方式：我是谁/面向谁 + 想做什么 + 核心信息 + 画面/风格 + 时长/比例 + 必须避免的点。还可描述运镜、节奏、背景音乐、环境声、口播和字幕要求。
- 示例中的 15 秒、1 分钟为创作案例，不代表全部支持范围或最长时长。

## 沉浸式短片

1. 首页模式选择【沉浸式短片】。
2. 输入指令并添加素材。手册描述支持文生视频、图生视频、视频链接参考及图片与视频混合参考。
3. 按需求选择模型、时长和比例，然后点击发送生成。

提示词可按“主体 + 画面运动 + 音效互动 + 台词 + 音色 + 运镜/环境 + 风格 + 限定信息”组织。声音效果需要写进描述。

该章节记录接入 Seedance 2.0，不应与短剧或营销章节的模型信息混用；当前可选模型请用户自行查看最新产品文档。

## 图片创作与修改

1. 首页模式选择【生成图片】；也可在 Agent 模式中提出生图需求。
2. 描述图片内容、样式与限制，按偏好选择模型后生成。
3. 通过连续对话修改结果；局部修改时说明要改的部位、内容和需要保留的主体特征。

手册记录 Seedream 5.0 Lite 和 Seedream 4.0 美感版，并介绍联网实时搜索、精准编辑、逻辑推理等能力。不能推断所有模型都具有同样能力；当前模型列表请用户自行查看最新产品文档。

## 画布

创作 Agent 可开启画布模式，一边对话，一边在画布上调整效果。入口、资产引用、节点编辑、分组、快捷键、分享与深色模式见[创作 Agent 画布](canvas.md)；视频拉片与复刻见[画布拉片与复刻](video-breakdown.md)，多轨编辑见[多轨编辑](multitrack.md)。这些入口适用于通用创作画布，不用短剧画布说明替代。

## 一镜到底

- 入口：首页【一镜到底】。
- 按顺序上传图片，手册记录支持 2～10 张。
- 点击素材之间的箭头，设置转场时长并描述转场方式，例如推进或拉远；也可只设置时长，让小云雀自动处理画面。
- 设置完成后点击生成。功能用于补足图片之间的转场画面，形成连贯长镜头。
- 主手册没有给出完整转场时长范围、总视频时长上限或图片格式限制。

## 爆款复刻

- 入口：首页/常用功能【爆款复刻】，或【沉浸式短片】输入框底部【参考】。
- 输入参考视频链接或从本地上传视频，可描述希望借鉴的文案结构、剧情框架、配乐画风、运镜及需要替换的主体。
- 手册记录支持抖音、头条、西瓜链接。其他平台可将视频保存到本地后上传，不要声称任意平台链接均能直接解析。
- 输入完成后点击生成。案例展示的是参考创作效果，不能保证完全复现或保证成为爆款。

先拆解镜头、再基于已有拆解继续复刻的画布流程，见[画布拉片与复刻](video-breakdown.md)。该流程的链接输入已确认支持抖音分享链接，不将上面爆款复刻入口的链接支持范围直接套用到画布拉片。
