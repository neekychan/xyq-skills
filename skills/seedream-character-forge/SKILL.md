# Seedream Character Forge

将用户提供的角色概念，发展为一套可直接用于美术生成、设定推进和视频创作的完整角色内容包。

你要帮助用户从一个模糊念头出发，生成：
1. 原创角色设定
2. Seedream 角色概念图提示词
3. Seedream 角色板提示词
4. SSS / 终极技能设计
5. 15 秒技能演示视频提示词

这个 skill 的价值，不只是“补全设定”，而是把角色统一成一个**视觉上成立、叙事上成立、技能上成立、出图上可执行**的方案。

## 适用场景

优先用于以下请求：

- “帮我设计一个原创角色”
- “给我做个 Boss / 英雄设定”
- “我有个角色想法，帮我展开”
- “顺便给我出图提示词”
- “帮我做角色板 / 设定板”
- “帮我设计终极技能 / 大招”
- “给我一个 15 秒技能演示视频提示词”
- “帮我做一个适合 AI 短片 / 游戏宣发的角色”

如果用户同时提到角色、设定、立绘、角色板、技能、视频提示词中的任意两项及以上，也应触发本 skill。

## 输入理解

优先从用户输入中提取这些信息：

- 角色原型：如机械修女、深海王女、废土枪手、月神祭司
- 外观气质：如冷峻、神圣、癫狂、贵族感、破败感、妖异感
- 武器 / 道具：如巨型圣枪、双刀、浮游炮、法环、古剑
- 能力元素：如雷电、冰霜、血焰、梦境、时间、重力
- 世界观：如黑金神权、赛博都市、深海帝国、末日废墟、东方奇幻
- 输出用途：如立绘、角色板、PV、短视频、游戏宣发
- 视频比例：如 16:9、9:16、1:1
- 风格方向：如电影感、二次元、暗黑奇幻、超现实、写实、宣传海报感

若用户缺少关键信息，不要停在反复追问。应先做合理补全，并明确说明你补了哪些核心设定。

## 工作流程

### 第一步：统一角色主轴
先不要急着写提示词。先判断这个角色最核心的统一主轴是什么：

- 她 / 他是谁
- 最强记忆点是什么
- 武器和能力怎样互相支撑
- 世界观如何反向强化角色气质
- 这个角色为什么会让人一眼记住

如果用户给了很多元素但互相冲突，优先收束成一个清晰方向，而不是把所有元素都塞进去。

### 第二步：建立视觉记忆点
角色至少要有 2 到 4 个明确视觉锚点，例如：

- 独特轮廓
- 标志性武器
- 特殊服装结构
- 强烈色彩体系
- 稀有材质或纹样
- 明确的能力外显方式

不要生成“华丽但没有记忆点”的角色。

### 第三步：把设定转成 Seedream 可执行提示词
Seedream 提示词默认使用**中文自然语言长提示词**，强调完整、连贯、导演式描述。优先采用如下顺序：

1. 主体身份与核心设定
2. 外观与服装
3. 武器与道具
4. 姿态 / 动作
5. 场景与氛围
6. 光影与色彩
7. 构图 / 镜头 / 景别
8. 风格与完成度
9. 负面约束

避免写成 Midjourney 风格的碎片词堆砌。除非用户明确要求，否则不要输出大量无解释英文标签。

### 第四步：技能设计必须服务角色
SSS / 终极技能不是独立模块，它必须反映角色身份、武器逻辑、能力元素和世界观权力感。技能设计至少要回答：

- 为什么是这个技能名
- 为什么只有这个角色能用
- 技能释放过程是否有表演性
- 视觉奇观是否足够强
- 是否适合做短视频高潮

### 第五步：视频提示词强调镜头节奏
15 秒演示视频提示词要体现完整节奏，而不是只描述一个静态画面。至少包含：

- 开场建立
- 动作启动
- 技能展开
- 高潮爆发
- 收尾定格

并补充：
- 镜头运动
- 速度变化
- 特效层次
- 环境反馈
- 音效 / 同期声建议
- 比例与画幅

除非用户只要其中一部分，否则按以下结构输出：

# 角色总案

## 1. 原创角色设定
包含：

- 角色身份
- 核心概念一句话
- 外观记忆点
- 服装设计
- 武器 / 道具设计
- 能力元素
- 世界观气质
- 性格张力 / 压迫感 / 情绪调性
- 适合的视觉风格方向

## 2. Seedream 角色概念图提示词
输出一段**可直接投喂 Seedream** 的中文完整提示词。

要求：
- 适合生成单张高辨识度角色概念图
- 角色主体明确
- 服装、武器、能力、氛围清晰
- 有明确构图和镜头感
- 有质量要求
- 有负面约束

## 3. Seedream 角色板提示词
输出一段**可直接投喂 Seedream** 的中文完整提示词。

要求：
- 偏设定板 / 白底角色板 / 浅背景展示
- 强调角色多视图倾向
- 包含角色肖像特写
- 包含武器细节
- 包含服装结构与材质细节
- 清晰、干净、适合展示设计信息
- 有负面约束

## 4. SSS / 终极技能设计
包含：
- 技能名称
- 技能定位
- 释放逻辑
- 分阶段过程描述
- 视觉奇观
- 打击感 / 压迫感 / 伤害表现
- 与角色设定的统一性说明

## 5. 15 秒技能演示视频提示词
输出一段完整视频提示词，包含：
- 开场画面
- 动作演出
- 镜头推进
- 特效变化
- 高潮爆发
- 收尾定格
- 节奏
- 音效 / 同期声建议
- 画幅比例

## 输出要求

### 原创角色设定
写得像概念策划案，不要只是堆形容词。尽量让每一条设定都能落到具体视觉结果上。

### Seedream 概念图提示词
必须是能直接使用的成品提示词，不要只给提纲。默认使用中文，完整自然，强调画面逻辑与主体清晰度。

### Seedream 角色板提示词
优先帮助用户拿到“更适合做设定展示”的图，而不是单纯炫技海报。重点是清楚、完整、可读。

### SSS / 终极技能设计
要有强烈游戏宣发感和视觉传播力，同时保持与角色设定一致。

### 视频提示词
写成导演式镜头描述，保证用户拿去继续做视频生成、分镜拆解或创意开发时依然成立。

## Seedream 提示词写法规则

### 概念图提示词默认要素
通常包含这些元素：

- 角色身份与定位
- 年龄感 / 性别气质（如合适）
- 发型 / 面部特征 / 神态
- 服装轮廓与材质
- 武器 / 道具
- 姿态或动作
- 元素能量表现
- 环境背景
- 光影与主色调
- 构图与镜头
- 完成度 / 质感
- 负面约束

### 角色板提示词默认要素
通常包含这些元素：

- 白底或浅灰背景
- 正面 / 侧面 / 背面或多视图角色展示倾向
- 半身或头像特写
- 武器拆解细节
- 服装结构分层
- 清晰线条与材质表现
- 减少环境干扰
- 强调展示设计信息

### 默认负面约束
如果用户没有特别说明，默认在 Seedream 提示词中加入适度负面约束，例如：

无文字，无字幕，无 logo，无水印，无 UI，无多余人物，避免肢体畸形，避免手部错误，避免面部崩坏，避免武器结构错误，避免低清晰度，避免背景过度杂乱

不要把负面约束写得过长导致主体信息被稀释。核心目标是减少污染项，而不是做极端参数堆积。

## 风格补全参考

### 神权 / 宗教 / 审判系
强调：
- 庄严
- 仪式感
- 神圣压迫
- 黑金 / 白金 / 冷银配色
- 垂直构图
- 权杖、圣枪、法环、圣纹等象征物

### 赛博 / 机械系
强调：
- 结构层次
- 发光部件
- 金属、玻璃、纤维、机甲接口
- 冷暖霓虹反差
- 工业感与未来感并存

### 幻想 / 法术系
强调：
- 符文
- 悬浮物
- 能量流
- 多层服装
- 神秘器物
- 超自然空间氛围

### 反派 / Boss 系
强调：
- 压场感
- 统治感
- 武器比例夸张
- 终局技能气质
- 高危险性和视觉压迫

### 英雄 / 主角系
强调：
- 信念感
- 招牌姿态
- 成长型气质
- 清晰的正面轮廓
- 易传播的视觉符号

## 信息不足时的处理

如果用户只说一句，例如“做一个深海女王角色”，你应主动补足：
- 身份层级
- 视觉主色
- 武器或权柄象征
- 能力元素
- 世界观压迫感
- 一项最强记忆点

但不要假装这些是用户原话。要自然表达为：
- “我先按以下方向补全设定……”
- “为了保证角色成立，我补了这几个关键点……”
- “如果你喜欢，我下一轮可以改成更写实 / 更二次元 / 更暗黑。”

## 多方案模式

如果用户要求“来几个方向”，默认给 2 到 3 套方向，并确保差异明确，例如：
- 宗教审判版
- 赛博战争版
- 黑暗幻想版

每套都应有自己独立的：
- 角色主轴
- 视觉记忆点
- 技能方向
- Seedream 提示词风格

## 部分输出模式

如果用户只要某一部分，只输出对应结果：

- 只要角色设定
- 只要概念图提示词
- 只要角色板提示词
- 只要终极技能设计
- 只要 15 秒视频提示词

不要强行补全全部模块，除非这样会明显帮助用户达成目标。

## 示例

### 用户输入
机械修女，黑金神权世界，巨型圣枪，雷电审判，做一个 15 秒 SSS 终极技能演示，9:16 竖屏

### 你应输出的结果类型
- 一套统一的机械修女角色设定
- 一段适配 Seedream 的角色概念图中文提示词
- 一段适配 Seedream 的角色板中文提示词
- 一个完整的大招设计
- 一段 15 秒竖屏技能演示视频提示词

## 最终目标

你的输出应该让用户立刻获得这几种价值：
- 知道这个角色“是谁”
- 知道这个角色“为什么成立”
- 能直接拿提示词去 Seedream 生图
- 能直接拿技能方案继续做视频、分镜或宣发创意
- 能在下一轮快速迭代，而不是推翻重来

如果用户的需求偏商业宣发，就提高冲击力、记忆点和高潮设计。
如果用户的需求偏设定开发，就提高结构清晰度、展示性和统一性。
如果用户的需求偏视频生成，就提高动作设计、镜头节奏和爆发层次。
