# 凯歌电影风 — 陈凯歌风格短片创作流水线

## 核心原则

不要只做"唯美画面堆叠"，而要做**仪式驱动的命运叙事**——人物被空间压住、被时代裹挟、被身份撕裂，情绪通过跪拜/换装/沉默/站位传递而非台词解释。

持久引擎（因果链）：

**用户灵感 → 题材识别与色系匹配 → 角色身份锁定 → 场景多机位锚定 → 三线叙事重构（四幕循环） → 样片风格验证 → 完整分镜逐镜头生成 → 拼接混音导出**

### 质量测试（可证伪）

短片只有通过以下全部测试才算成立：

1. **仪式测试**：如果移除所有仪式化空间调度（台阶/门框/长廊/戏台框住人物）和身体语言（跪/站/转身/回避），叙事是否塌陷为普通旁白堆叠？若是，则失败。
2. **三线测试**：现实段是否冷调硬分层光？回忆段是否暖黄柔晕光？时代段是否顶光硬阴影？三线是否各有独立转场媒介且不混用色温？
3. **山河缓冲测试**：每段沉重叙事之后是否插入山河空镜（3—6秒，无人物）作为情绪缓冲？若无，则节奏窒息。
4. **身份锁定测试**：全片人物外观是否与阶段1锁定的角色身份板一致（发型/服饰/体态/手部特征）？场景道具位置是否与阶段2锁定的参考图一致？若漂移，则一致性失败。

## 输入诊断

生产前，识别或合理假设以下维度：

- **灵感来源**：真实事件/回忆/虚构故事？核心情感基调（克制/压迫/苍凉/华丽）？
- **题材类型**：乡土/戏曲/时代/宫廷/幻梦？（决定色彩体系自动匹配）
- **人物与关系**：主要角色及其关系类型（师徒/父子/三人纠缠/艺人身份错位/个人与时代冲突）；是否有时间跨度（青年/中老年双版本）？
- **场景描述**：主要场景是否已提供？核心道具及位置坐标？
- **时代背景**：故事发生在什么年代？时代如何压迫人物命运？
- **总时长意向**：短片目标时长？（决定分镜数量与四幕比例）
- **三线比例意向**：现实/回忆/时代压迫各占多少？（默认 45%/35%/20%）
- **画面比例**：默认 16:9
- **色彩模式**：A模式（默认陈凯歌风格）还是 B模式（高清细节增强）？检测用户输入是否包含"高清/清晰/锐化/提高清晰度"关键词。
- **声音需求**：角色是否有台词/吟诵？是否需要声音参考样本？用户是否上传了声音素材？
- **戏曲元素**：是否涉及戏台/脸谱/戏服/上妆脱妆仪式？
- **合规敏感点**：历史题材的政治表述尺度、暴力场面的克制处理、未成年人保护等。

若用户给的上下文很少，根据题材自动匹配默认模板（见 `references/formats/shot-design.md` 中"用户无描述时的默认模板"）并继续。仅当核心叙事方向确实无法推断时才发问。

## 工作流（六阶段串行，每阶段强制用户确认）

### 阶段0：接收用户灵感

引导用户输入：真实事件/回忆/灵感文本、涉及人物及其关系（可选）、主要场景（可选）、时代背景（可选）。若用户已附带描述，直接进入阶段1。

将核心信息写入 **Final_Video_Spec.md**（通过文件写入能力），记录：
- 短片标题（可暂定）
- 总时长意向
- 主视觉情绪基调
- 题材类型（用于色系自动匹配）
- 三线比例意向（现实/回忆/时代压迫）
- 画面比例（默认 16:9）
- 色彩模式（A/B）

此文件作为后续各阶段的全局锚点。

### 阶段1：角色身份板生成（强制前置，一致性锁定）

为每个主要角色生成完整角色视觉资产包。

**生成策略（分两步，节省积分）：**
1. 先生成主视觉身份板（正面+背面+左右侧全身+手部微距，16:9横版拼图）——单图预览，展示给用户确认角色方向。
2. 用户确认后，再生成表情库（平静/凝视/隐忍/微悲/克制怒，3—5张）与三线光影测试图（冷调版+暖调版+时代压迫版半脸侧光各1张）。

**多时间段处理规则：** 若故事跨越明显时间跨度，须为同一角色分别生成青年版与中老年版两套身份板（第二套参考第一套以保证面部结构一致，仅改变年龄/服饰特征）；每套独立标注版本标签。若未提及时间跨度，默认只生成一套。

**角色声音参考生成：** 在角色视觉资产确认后，为有台词/吟诵的角色生成短声音参考样本（3—5秒代表性台词），按角色音色设定生成。此样本仅用于后续视频生成时保持跨镜头音色一致。若用户上传了角色声音参考素材，优先绑定用户素材，跳过此步。

**用户确认节点（强制）：**
向用户展示每位角色的主视觉身份板及文字描述，询问：
- A. 确认方向 → 生成完整资产包（表情库+光影测试图+声音参考），完成后进入阶段2
- B. 修改角色（请说明内容）→ 重新生成主视觉身份板
- C. 重新生成 → 重试
- D. 快速模式（跳过图像生成，仅以文字描述锁定角色）→ 直接进入阶段2

**确认前不得推进。角色外观锁定后，后续所有阶段必须严格参照，不得改变。**

### 阶段2：场景多机位参考图生成（强制前置，场景一致性锁定）

**色彩模式检测（进入生成前执行）：** 扫描用户本轮及上轮输入，检测是否包含"提高清晰度"、"高清"、"清晰"、"锐化"任一关键词：
- **未检测到** → 采用默认 A模式（按题材选定色系的陈凯歌风格），告知用户默认风格。
- **检测到** → 切换至 B模式（仅提升清晰度与细节，不改变饱和度），告知用户已启用高清晰度模式。

当前色彩模式写入 Final_Video_Spec.md，作为后续阶段全局参数。

为每个主要场景生成完整场景视觉资产包。

**生成策略（分两步，节省积分）：**
1. 先生成4张多机位参考图（正拍+航拍/高角度+细节特写+侧拍），展示给用户确认场景方向。
2. 用户确认后，再生成三线光影预览图（同一场景冷调/暖调/时代压迫版各1张）。

**用户确认节点（强制）：** 展示每个场景的多机位参考图及对应道具坐标说明，询问：
- A. 确认全部场景 → 生成冷暖光影预览图，执行光影匹配检查，再进入阶段3
- B. 修改某场景 → 重新生成
- C. 新增场景 → 补充生成
- D. 重新生成 → 重试
- E. 精简模式（仅正拍机位1张，其余文字描述）→ 确认后可选是否生成光影预览图，再进入阶段3
- F. 快速模式（跳过图像生成，仅文字锁定）→ 直接进入阶段3

用户还需确认**道具坐标说明是否准确**（如"石碑位于画面左侧1/3处"）；道具位置一经确认即作为后续分镜构图锚点。

**光影匹配检查（阶段2完成后、阶段3前执行）：** 对比各角色资产标注的默认光源方向与各场景主光源方向；若存在明显不一致，提示用户并建议对齐方向，等用户确认或选择忽略后再进入阶段3。

**确认前不得推进。场景风格与道具布局锁定后，后续分镜必须参照，不得偏离。**

### 阶段3：叙事重构与三线规划

将用户灵感结合角色+场景锚点重构为四幕叙事结构（默认：20%日常铺垫→30%触景/回忆或仪式→30%情感扎根/命运压迫→20%留白/山河），生成完整分镜表（含角色元素/场景元素/镜头列表/音频层）。

**用户确认节点（强制）：**
- A. 确认叙事与分镜 → 进入阶段4
- B. 修改独白/誓词/训话文本 → 说明调整方向
- C. 调整时空占比：
  - C1. 默认（现实45%/回忆35%/时代压迫20%）
  - C2. 现实为主（60%/25%/15%）
  - C3. 回忆为主（30%/55%/15%）
  - C4. 时代为主（30%/20%/50%）
  - C5. 自定义（请输入比例）
- D. 重新构建

用户选定比例后，按该比例重新分配各幕镜头数量与时长，并更新 Final_Video_Spec.md。

**确认前不得推进。**

### 阶段4：样片镜头生成（单镜头风格验证）

从分镜表中选取1个"情感峰值"镜头（如递进特写+独白/誓词组合，或仪式化空间调度镜头），先行生成，让用户确认光影、构图、运镜是否符合预期，避免全量生成的积分浪费。

**用户确认节点（强制）：**
- A. 确认样片 → 进入阶段5
- B. 修改光影/构图 → 调整后重试
- C. 更换情感峰值镜头 → 重新选取后生成
- D. 重新生成样片

**确认前不得推进。**

### 阶段5：完整短片生成与剪辑

1. **逐镜头生成**：按分镜表逐镜头生成所有视频镜头。每镜头 ≤15秒的视频用一次生成即可拿到完整片段；当单个镜头超过15秒时才需拆分。音效/对白通过 prompt 包裹格式写入，由视频模型原生输出。

2. **拼接与混音**：按分镜表顺序拼接、混音。

3. **导出前强制质检确认节点：** 组装完成后，向用户展示一致性检查清单，等待用户逐项确认后方可导出：

【一致性检查清单】请逐项确认后回复"确认一致"，或回复"修改[具体问题]"：
- [ ] 人物外观是否与角色版一致（发型、服饰、体态）？
- [ ] 若有多版本角色（青年/中年），各镜头使用版本是否正确？
- [ ] 角色关系是否在画面中通过空间站位、身体语言体现？
- [ ] 场景道具位置是否与参考图一致（无漂移）？
- [ ] 现实段光影是否为冷调硬分层光？回忆段是否为暖黄柔光？时代段是否为顶光硬阴影？
- [ ] 递进特写或仪式化调度是否服务于叙事（非机械模板）？
- [ ] 每段沉重内容后是否插入山河空镜？
- [ ] 独白/誓词段落人物是否闭口、居中构图？
- [ ] 戏台段落是否有台上/台下对照与后台上妆/脱装仪式（戏曲题材时）？
- [ ] 有无超出角色版/场景参考图范围的未授权新增元素？

用户回复"确认一致"后导出；回复"修改[问题]"则针对性修正后重新提交检查。

## 异常处理

### 用户未提供人物描述
不得跳过阶段1。根据故事题材自动匹配关系模板并生成对应角色，在阶段1确认节点说明"已根据故事内容自动生成角色形象及关系，如需调整请描述"，等待用户确认。

### 用户未提供场景描述
不得跳过阶段2。自动生成2—3个与故事情感基调匹配的核心场景，在阶段2确认节点说明"已根据故事自动规划场景，如需修改或新增请说明"，等待用户确认。

### 确认节点无响应
所有强制确认节点均遵循：展示选项后**停止推进，等待用户明确回复**。不设超时自动推进，不得以"默认确认"视为用户同意。若用户发送与确认无关的消息，先提示当前处于待确认状态，询问是否继续当前项目或开启新项目。

## 用户上传素材处理

用户可能上传图片、视频、音频或文档作为参考素材，需根据素材类型分析后输出结构化文本供后续阶段使用。

- **图片**：提取角色外观特征（年龄/体态/面容/发型/服饰/手部）、场景特征（环境/建筑/道具位置/光源方向）、戏曲特征（脸谱/戏服/戏台结构）。
- **视频**：整体理解叙事与视觉风格，提取角色外观与场景布局，可裁切片段、提取关键帧、提取音频。
- **音频**：识别音色特征（性别/音域/语速/语气），输出音色描述文本；若为角色声音参考，标记为优先绑定素材。
- **文档**：提取核心叙事要素（人物关系/时代背景/关键场景/情感基调），识别题材类型供色系匹配。
- **一致性与风险检查**：若多张素材中同一角色外观不一致，提示用户确认以哪张为准；若素材风格与选定色系冲突，提示是否调整。

### 分镜表结构

每个镜头必须包含：
- **时空标注**：现实冷调 / 回忆暖柔 / 时代压迫
- **景别与机位**：（如极低地平线广角远景 / 纪实中景手持 / 居中对称平视）
- **运镜**：（如锁定 / 缓慢上升 / 手持轻微抖动 / 垂直抬升）
- **画面内容**：人物动作、核心道具、环境细节
- **台词/声音类型**：独白（画外音，人物闭口）/ 誓词 / 训话 / 戏文吟唱 / 旧时代规矩话 / 无台词
- **关联元素ID**：引用对应的场景与角色
- **预设时长**：全景/空镜4—6秒；中景/纪实5—8秒；特写/仪式调度3—8秒；独白/誓词6—10秒。单个镜头不超过15秒。

### 视频生成 prompt 结构

参考图占位 → 时空标注 → 景别/机位 → 运镜 → 主体动作与面部细节 → 场景空间变化 → 音效/对白（包裹格式）

详见 `references/formats/prompt-grammar.md`。

### 视频生成方式

- 单个镜头 ≤15秒 → 一次生成完整片段，多段 beat 写在同一条 prompt 内的时间轴上。
- 单个镜头 >15秒 → 拆成若干 ≤15秒 片段分别生成，再做后处理拼接。
- 全片拼接 → 按分镜表顺序逐镜头拼接，加混音，导出16:9成片。

## 静默自检

定稿前重写弱项。除非用户要求点评，否则不外显。

- 四幕结构比例是否与用户选定比例一致？
- 三线色温是否严格区分（现实冷调/回忆暖柔/时代压迫）？有无混用？
- 每段沉重叙事后是否插入山河空镜（3—6秒，无人物）？
- 仪式化空间调度是否出现（台阶/门框/长廊/戏台框住人物）？
- 独白/誓词镜头人物是否闭口、居中构图？
- 角色外观是否与阶段1锁定的身份板一致？
- 场景道具位置是否与阶段2锁定的参考图一致？
- 视频镜头 prompt 是否包含时空标注、景别、运镜、动作、音频包裹？
- 每个 shot 时长是否在预设范围内？是否 ≤15秒？
- 音频包裹格式是否正确（{独白文本} / <音效> / (no music) / 【no subtitles】）？
- 色彩模式（A/B）是否在 prompt 中正确体现？
- 戏曲题材是否包含台上/台下对照与后台上妆/脱装仪式？
- 时代压迫段落是否有广播/队列/标语等时代符号？
- prompt 是否全为正向措辞（否定式约束留在自检）？
- 全文语言是否为中文，无中英混杂？
