# 电影化叙事与情绪蒙太奇 MV Prompt Engineering Skill

## 目标与边界

生成 **≤30 秒、单支直接成片** 的电影化叙事或情绪蒙太奇 MV。用歌词语义和歌曲结构驱动一个可被画面证明的核心命题、人物关系和因果变化，不追求长片式支线。

- 默认无需对口型。人物通过选择、动作、关系、视线、距离和道具变化推进叙事，不需要看镜头唱歌。
- 禁止把叙事退化成对口型 performance、随机“电影感”空镜、无关系人物拼贴或歌词逐字插图。
- 首轮只展示音频理解摘要、推荐方案、时间轴和问卷。
- 确认后在后台生成并提交主提示词、控制点、负向词和关键帧引用；仅用户明确索要时展示完整 PE。
- 音频只驱动语义、结构、情绪和叙事节奏。

## 触发边界

使用本 Skill：核心验收是剧情、人物关系、情绪变化、道具状态、因果连续或叙事蒙太奇。

改用对应 Live／Performance／Dance／Solo Skill：核心诉求是看镜头演唱、准确口型、舞台现场感、个人压场、唱跳表演或编舞。叙事片可以出现走路、奔跑、拥抱、争执等剧情动作，但这些动作必须推进信息，不以展示唱功、台风或舞蹈为目标。

## 输入与默认

必需：
- `audio_path`，或明确指定的音频片段。

可选：
- 歌词、对白、故事梗概、人物／场景／道具图。
- 参考视频文件或链接及目标时间段。
- 风格、时代、地点、人物关系、结局、画幅、色彩、现实／超现实程度。
- 人物模型、性别、年龄、族裔、写实或风格化方向。

默认：
- 画幅 `16:9`；超过 30 秒时推荐最能形成“起因—变化—结果”的片段。
- 默认 1–2 位核心人物、1 个关键道具、2–3 个空间；可按命题调整。
- 人物模型、性别、年龄、族裔、外貌和写实／风格化均不预设固定类型；按故事、音频和用户选择设计。只有用户提供人物参考或明确指定时才锁定相应特征。
- 未给故事时，从歌词与音频提炼一个 30 秒内可视化证明的命题；无可靠歌词时不臆造逐句语义。

## 音频来源与准入

- 用户已上传或明确提供可用音频时，直接使用。
- 用户只给歌曲／BGM 名，或明确要求找音乐且没有可用的 `audio_path`／`video_path` 时，调用 `pippit_omni_search`；`SearchType` 必须为 `mv_music`，`Query` 只做最小清洗，不擅自添加歌手、版本、语种、年代或曲风。
- 返回候选音频让用户确认；选定素材统一绑定为 `canonical_audio`。
- 来源记录为 `uploaded_audio` 或 `copyright_music_asset`；版权库素材记录 `asset_id`、版本和选定片段。
- 无已确认的可用音频时，不进入生成。

### extract_lyrics 调用

- 在 `canonical_audio` 已确认并取得可访问的 `audio_path` 后，音频含人声或当前任务需要歌词信息时，调用 `extract_lyrics`，传入该 `audio_path`，获取歌词文本及对应时间戳。
- 将返回结果作为原有音频理解流程的输入，用于识别歌词关键词、歌词句段、hook、高潮及现有的画面或口型时间映射。
- 纯器乐或无歌词音频跳过该调用；工具未返回歌词时，继续按照原有音频结构分析流程执行，不阻断后续生成。

### BGM 处理规则

- 若用户上传原始音频／BGM，且没有要求换歌、静音或另配配乐，生成后先将生成视频自带原音轨静音，再把该用户音频片段作为唯一主 BGM。
- 只允许基础对齐、裁切、淡入淡出、响度微调和必要 clean up。
- 不允许换成别的歌、改旋律、改节奏或改造成另一版。
- 用户明确要求换歌、静音成片、只参考节奏或另配 BGM 时，可不执行上述规则。

## 叙事硬约束

1. 先写一句核心命题：谁处于何种关系／处境，因什么发生何种变化，最终留下什么情绪或认知。
2. 建立固定角色 roster（`C1–Cn`）：人物模型、年龄段、性别表达、族裔／地域特征（仅在需要或被指定时）、外观、服装、动机、关系、初始状态和终局状态。
3. 建立关键道具状态链，例如“完整信件 → 被打开 → 被雨浸湿 → 留在空椅上”；每次变化都要有原因和结果。
4. 每段必须承担信息目标：交代、触发、升级、揭示、对照或收束；删除只提供气氛却不推进命题的镜头。
5. 动作因果连续：明确动作起点、过程、结果及下一镜承接，不用无来源闪回替代原因。
6. 保持时空连续：人物位置、视线、轴线、服装、伤痕／湿度、道具、时间、天气和光线方向前后一致。
7. 蒙太奇可跳时空，但要由动作、构图、颜色、道具、地点、歌词意象或声音结构建立可读连接；现实、回忆、幻觉使用稳定区分规则。

## 音频／歌词到信息目标映射

| 音频／歌词证据 | 信息目标 | 叙事画面映射 |
|---|---|---|
| 前奏、留白、首句 | 交代关系与缺口 | 人物相对位置、缺席痕迹、道具初态 |
| 事实／关系歌词 | 建立处境 | 行为、环境证据和关系距离，不让角色机械唱词 |
| 情绪／意象歌词 | 建立母题 | 同一物件、动作或构图反复出现并改变含义 |
| build、和声变化 | 触发行动或记忆 | 人物决定、动作开始、现实与回忆匹配剪辑 |
| 重拍、歌词转折 | 揭示因果 | 展示选择及后果、道具状态改变、关系反转 |
| 高潮、长音 | 关系／认知峰值 | 冲突、失去、重逢、告别或空间尺度升级 |
| 尾奏、余韵 | 证明终局 | 道具终态、人物去留、关系余波 |

歌词存在时先拆为事实、关系、情绪和意象四类，再决定直叙或隐喻；默认不把歌词转换为口型。

## 工作流程

### 1. 音频与歌词理解

提取总时长、段落、能量、转折、高潮、尾韵和歌词关键词。输出核心情绪曲线、语义事实、可视化母题、最少必要人物和可完成叙事范围。

### 2. 推荐方案

至少包含：
- 一句话核心命题和结尾情绪。
- 角色 roster、人物关系、欲望／阻力、外观与初终状态；人物类型按本轮设计，不使用固定默认模型。
- 关键道具及完整状态链。
- 主空间、对照空间、时间、天气、色彩、材质和时空区分规则。
- 风格方向：港风、古风、华语流行、情歌、治愈、都市、校园、公路、时代感或自定义；风格服务命题，不只是滤镜。
- 叙事机制：线性、回忆插入、平行蒙太奇、主观幻觉、循环或自定义。
- 镜头、调度和转场连接规则。
- 高潮的具体揭示、选择或关系变化，不能只写“情绪爆发”。

### 3. 时间轴

围绕“关系与缺口建立 → 触发／记忆展开 → 因果或情绪峰值 → 余波收束”组织，不平均切片。每段写明：音频／歌词证据、信息目标、角色、动作起因与结果、道具前后状态、时空、景别、调度、转场和结束状态。

### 4. 问卷确认

紧跟方案，默认采用推荐项：
1. 风格：港风／古风／华语流行／情歌／治愈／都市／校园／公路／时代感／自定义。
2. 人物与关系：采用推荐／调整人物模型、性别、年龄、族裔、写实或风格化／调整关系与结局。
3. 核心命题、道具状态、时空、叙事机制、镜头与转场：采用推荐／调整。
4. 参考视频：没有／上传视频／提供链接；记录目标时间段，默认高精度复刻。
5. 生成方式：直接生成视频／先生成关键帧预览／我要调整。

若已提供参考视频，不重复询问“是否有”，先分析并询问复刻范围与硬锚；只有参考明确展示或用户指定的人物特征才锁定。

### 5. 参考视频真实分析

必须取得可分析的实际视频文件；链接不可访问或只有页面文本时要求上传，不得假装看过。使用 `analyze_media` skill 提取：核心命题、人物模型与关系、造型、表演方式、道具状态、空间时间、动作因果、色彩材质、景别、调度、蒙太奇连接、剪辑密度和结尾。

拆成：
- 硬锚：明确的人物特征与关系、关键道具、核心空间、因果机制、色彩系统、镜头与蒙太奇语法。
- 可重排变量：事件时点、镜头长度、空间顺序和蒙太奇密度，按新音频重新映射。

分析后重写推荐方案、时间轴和后台 PE，旧确认失效并重新确认。不得用通用电影模板代替真实拆解。

### 6. 关键帧模式

生成 3–5 张：
1. 关系与缺口建立。
2. 触发事件或关键道具变化。
3. 高潮前选择／揭示。
4. 情绪或因果峰值。
5. 人物与道具终局状态。

每张写明时间点、人物身份与关系、动作前后、道具状态、时空、构图、光线、色彩、现实／回忆规则和信息目标。关键帧必须形成状态链，不是互不相干的海报。确认后通过 `ImageList` 绑定，并由主提示词、控制点和负向词共同引用。

### 7. 确认后执行

用户选择直接生成时只回复：`方案确认，开始生成 {duration}s 电影化叙事 MV。`

随后后台提交完整 PE。只有用户明确索要时，才把实际主提示词、控制点和负向词置于同一个代码块。

## 控制点模板

```text
控制点：
1. 全片只服务一个核心命题，支线不得抢占短时长。
2. 默认无对口型；人物不看镜头机械唱词，不退化为 performance。
3. 固定角色 roster、关系、人物模型、外观、服装、动机与初终状态。
4. 人物性别、年龄、族裔、写实或风格化仅按本轮方案或参考锁定，不套固定默认。
5. 关键道具按状态链变化，不可无因出现、消失、复原或复制。
6. 每段有信息目标和因果承接；动作写清起点、过程、结果与下一镜承接。
7. 轴线、视线、位置、服装状态、时间、天气和光线连续。
8. 时空跳跃有动作、构图、颜色、道具、地点、意象或声音连接；现实、回忆和幻觉规则可辨。
9. 高潮必须发生揭示、选择、失去、重逢、告别或认知变化中的至少一项。
10. 参考硬锚和确认关键帧共同约束最终视频。
11. 若用户上传原始音频／BGM且未要求换歌、静音或另配配乐，生成后静音生成视频自带原音轨，并将该用户音频片段作为唯一主 BGM；只允许基础对齐、裁切、淡入淡出、响度微调和必要 clean up，不得换歌、改旋律、改节奏或改造成另一版。用户明确要求换歌、静音成片、只参考节奏或另配 BGM 时可不执行。
```

## 负向词模板

```text
负向词：默认对口型，看镜头唱歌，为歌词机械张嘴，live舞台，打歌performance，solo压场，团舞编排，没有核心命题，随机电影感镜头，歌词逐字插图，人物关系不明，默认固定性别年龄族裔，角色换脸，人物模型漂移，服装漂移，道具无因出现，道具状态倒退，因果断裂，动作无结果，视线错位，空间轴线混乱，时间天气跳变，回忆现实无法区分，蒙太奇无连接，空镜过多，只有氛围没有事件，高潮只有慢动作，结尾突然截断，新增无关人物，廉价滤镜，关键帧失配。
```

## 生成后验收

逐秒段检查：
- 能否用一句话复述核心命题，且成片提供视觉证据。
- 人物模型、身份、关系、动作和情绪变化是否连续且符合确认项。
- 道具是否按状态链变化，每次变化都有原因和结果。
- 每段是否完成交代、触发、升级、揭示、对照或收束。
- 动作因果、轴线、视线、时空、天气、服装和光线是否连续。
- 蒙太奇是否有可读连接；高潮与终局是否兑现。
- 是否避免无要求的对口型和看镜头演唱；参考硬锚与关键帧是否映射。

若角色重生、道具跳态、因果断裂、时空失控、高潮不产生变化或叙事退化成对口型 performance，判失败并重新生成。

```text
三、时间轴设计

```

## 质量门禁

- 总时长 ≤30 秒；单支成片；已按 BGM 处理规则执行用户音频，或命中用户明确要求的例外。
- 首轮仅音频摘要、推荐方案、时间轴和问卷，不提前展示 PE。
- 问卷含指定风格选项、人物可调维度、参考视频和三种生成方式。
- 默认无对口型，未退化为 Live／Performance／Dance／Solo。
- 已建立歌词／音频 → 信息目标 → 人物／动作／道具／时空映射。
- 核心命题、人物关系、道具状态、动作因果与时空连续可执行。
- 人物类型没有固定默认；只有用户指定或参考明确时锁定。
- 参考视频已真实取得并分析，且改写方案、时间轴和 PE。
- 关键帧形成叙事状态链并进入最终 PE。
- 后台 PE 含主提示词、控制点、负向词和关键帧引用。
- 成片已按命题、关系、道具、因果、连续、终局、参考硬锚与口型边界验收。
