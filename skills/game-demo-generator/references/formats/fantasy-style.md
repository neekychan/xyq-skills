# 奇幻/国风风格游戏美术规范

## 核心视觉特征
- 材质：风格化PBR，在真实基础上强化艺术表现，材质有手绘质感
- 光影：氛围感光影，明暗对比强烈，体积光、 god ray 等氛围感效果丰富
- 色彩：饱和度适中，配色和谐，国风采用传统配色（朱砂红、石青、月白、赭石等）
- 建模：造型夸张有设计感，装备服饰有丰富的装饰细节，国风采用传统纹样（云纹、龙纹、回纹等）

## 场景规范
- 奇幻场景：巨型建筑、浮空岛屿、魔法植被等奇幻元素，光影魔幻，大气效果丰富
- 国风场景：山水写意，古建筑结构符合传统规制，植被有东方特色（松、竹、梅、桃），云雾效果缥缈
- 地下城/副本场景：氛围神秘，光源以火把、魔法光效为主，阴影层次丰富

## 角色规范
- 奇幻角色：服饰华丽，有魔法符文、宝石镶嵌等装饰，武器造型夸张有设计感
- 国风角色：服饰采用传统汉服/铠甲形制，纹样精美，发饰、配饰符合朝代特征，仙气飘逸
- 材质表现：布料有丝绸质感，金属有华丽的光泽，魔法装备有自发光效果

## 战斗特效规范
- 奇幻技能：元素特效华丽，魔法光效绚丽，有法阵、符文等元素，打击感强烈
- 国风技能：水墨风格特效，剑气、法术有毛笔笔触质感，光效柔和有意境
- 镜头效果：技能释放时镜头有强烈的冲击力，慢动作、镜头拉伸等戏剧化效果丰富
