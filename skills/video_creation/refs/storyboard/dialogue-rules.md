# 台词/旁白语音规则

本文件覆盖所有含语音的视频段——台词（角色开口说话）和旁白（画外音）。无语音场景（纯画面展示、纯动作、纯运镜）不加载本文件。

**人声来源铁律**：台词/旁白人声一律由 `sandbox_generate_video` 按 Prompt 中的 `{台词}` 直接产出（自带口型同步配音）。**禁止**用 `sandbox_generate_audio` 生成台词/旁白再拼接进视频——`sandbox_generate_audio` 的 `tts` 仅用于素材阶段的音色锚定。

## 核心判定规则

台词/旁白时长由第一步 `count_chars.py` 工具输出的**耗时区间**决定。**禁止用字数÷语速手工计算，一律以工具输出为准。**

- **装不下 → 拦截**：耗时区间下限 > 段时长 → 台词塞不下，延长段时长或拆段；台词文案在分镜层不可修改，禁止精简、压缩、删减
- **段尾空白过长 → 拦截**：台词/旁白为段的主要内容（说话驱动画面，而非动作/运镜/场景变换驱动画面）时，段时长 > 耗时区间**中值** + 1s + 不与说话并行的独立动作时间 → 段尾会静止，需缩短段时长。耗时中值 = (下限 + 上限) / 2
- **段时长推荐值**：台词/旁白为段主要内容时，段时长 = 耗时下限 + 0.5s。段时长远大于语音实际耗时会导致台词说完后画面静止无事可做
- **所有可听见文字都计时**：角色台词、路人台词、群众喊声、电话声、内心独白、画外音、旁白都必须传给 `count_chars.py`。禁止因为说话人是路人、画外、心声或短句就漏算

| 参数 | 基准值 | 说明 |
|------|-------|------|
| 停顿预留 | **0.5-1 秒** | 每句台词后，多人对话加换气间隔 |
| 尾部无声段上限 | **≤ 1 秒** | 台词/旁白为段主要内容时，段末留白上限 |
| 段时长锚点 | **耗时下限 + 0.5s** | 段主要内容为说话时，段时长的推荐设定值 |

### 台词节奏：必须让每句话说完

**台词不能赶。** 把大量台词塞进短视频会导致语速异常、台词截断或胡言乱语。
- **对白轮次分档上限**（多角色说话人切换是口型/语速高翻车区）：段时长 ≤8s 最多 1-2 句短对白（≤10 字/句）；8s＜段时长 ≤15s 最多 3-4 句；＞15s 段按画面阶段分配、每阶段 ≤2 句。本档是耗时区间之内的次级约束：耗时装不下一律按「装不下 → 拦截」处理，本档不放宽；耗时装得下但超档时，优先合并短句、减少说话人切换，仍超档才拆段。**用户原文台词只受耗时判定约束，不受本档约束**——用户脚本对白密度超档时靠拆段/延长段时长承载，禁止以本档为由删改用户台词
- **口播/数字人场景**：台词耗时区间上限应 ≥ 段时长 × 0.95（几乎填满段时长），尾部仅留 0.5-1s 收嘴。禁止出现 ≥3 秒的无台词静默段（语气停顿 0.5-1s 除外）。
- 多句对白必须按时间顺序嵌入画面阶段，写清谁先开口、谁停顿、谁反应；禁止把多句台词集中堆在 Prompt 结尾

### 口型驱动：角色说话必须写嘴部动作

**角色说台词时，必须在 Prompt 中显式描写嘴部动作**，否则模型会生成"有声音但嘴不动"的旁白式画面。

- 台词固定句式：`[角色]嘴唇随每个字清晰地一开一合，说：{台词}。说完嘴唇合拢`
- 长台词（>15字）可简化：`[角色]面朝镜头，嘴巴张开说话，嘴唇随字张合，说：{台词}`
- 同画面中**不说话的角色**要写 `嘴唇紧闭不说话`，以区分谁在说
- 画外/电话另一端的声音**不需要**口型描写（说话人不在画面），模型自动生成听筒/画外音
- **大特写留给静默**：面部大特写（充满画面/瞳孔级）只承载静默微表情（睫毛颤动/喉结滚动/眼眶泛红），说台词期间景别上限为近景；需大特写抒情，推近放在该句说完、嘴唇合拢之后。听者反应大特写不受此限（写 `嘴唇紧闭不说话`）

**有音色锚定音频时**（角色/旁白有 voice mp3 锚定文件）：
- 音色绑定写在 Prompt 第一层角色定义处：`参考@图片N的形象作为{角色名}，台词音色参考@音频N（{音色具体描述}）`——AudioList 传入该角色的 voice mp3，用 `@音频N` 锚定音色，括号内附音色具体描述
- 画面阶段中台词句式不再重复音色引用：`[角色]嘴唇随每个字清晰地一开一合，说：{台词}。说完嘴唇合拢`
- 旁白音色绑定同理：第一层写 `旁白音色参考@音频N（{音色具体描述}）`，画面阶段中只写 `旁白：{旁白内容}`

| ❌ 旁白式（嘴不动） | ✅ 口型同步 |
|------------------|-----------|
| `她说：{都是真的}` | `她下巴微动，嘴唇清晰地一开一合，说：{都是真的}，说完嘴唇缓缓合上` |

### 对白段镜头调度：台词时间必须有画面变化

对白段的高频翻车形态是"谁说话拍谁，一镜到底"——台词覆盖的时间同样是画面时间。**对白段每 4-5 秒至少发生一次镜头调度**（切镜，或运镜的启动/收束）。豁免：用户明确要求舒缓/长镜头，或该段命中「情绪→镜头语言配方」的长镜头行（温情/孤独/结局）。

调度模式按下表选用，插入点落在句间停顿或语义转折处：

| 模式 | 时机 | 写法要点 |
|------|------|---------|
| 正反打 | 对白轮次交替 | 台词卡点硬切至对方；说话方近景面朝镜头带口型 |
| 听者反应插入 | 一方长台词进行中 | 硬切至听者近景/特写：`嘴唇紧闭不说话` + 具体微表情或手部动作（指节攥紧/喉结滚动/眼神躲闪）；说话方台词继续，该句转画外声（不写口型） |
| 道具/细节特写插入 | 台词提及关键物件，或句末停顿 | 硬切至道具特写（材质 + 光作用于表面），1-2s 后切回说话方 |
| 环境反馈切入 | 情绪转折点 | 切至环境的可见变化（窗外雨骤、灯光闪烁、门缝光影移动），绑定声画触发 |
| 视线引导（三拍） | 角色目光离开对话对象、投向道具/画外时 | 先写目光落点方向 → 硬切至落点物特写（POV） → 切回该角色反应；落点物必须是场景中已建立的物件 |
| 构图重心偏移 | 强弱/情绪关系变化 | 不切镜：同机位缓移让一方在画面中占比渐增，用景别+身体截取描述，禁止分数 |

- 插入镜头属于主体焦点的实质变化，不算"为丰富而切镜"；但每次插入必须能回答"观众此刻为什么需要看这个"——答不出 = 凑数切镜，删
- 切走再切回后，说话方的位置、朝向、姿态与切走前一致；切回句重新声明口型句式
- 插入特写仍受"大特写留给静默"约束：听者反应可用大特写，说话方带口型时景别上限为近景

### 情绪标注：声音质感 + 身体化，不用泛化词

台词的情绪标注是给配音读的语气指令，要让模型听懂"用什么语气"，不能用泛化词。

| ❌ 泛化标注 | ✅ 精准标注（声音质感+身体化） |
|-----------|--------------------------|
| （愤怒） | （咬牙切齿的低吼，压抑着爆发前的颤抖） |
| （害怕） | （带哭腔的祈求，声线因恐惧不自觉上扬） |
| （冷漠） | （冷声警告，每个字如金属刮擦） |
| （崩溃） | （嘶吼到破音，喉咙发出干涩的嘶哑） |

- 禁止心理描写（"她内心煎熬地说"）——情绪标注不是写小说
- 禁止多情绪叠加（"愤怒+悲伤+不甘"）——选最主导的一个；情绪要变化则拆成两段

### 检查清单（有台词或旁白时必查）

构造完含台词/旁白的 Prompt 后、调用工具前，逐项检查：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | **口型驱动**（有台词时） | 说话角色写了嘴部张合动作，不说话角色写了"嘴唇紧闭" |
| 2 | **台词节奏**（有台词时） | 引用第一步工具输出的耗时区间确认台词在段时长内说得完；台词为段的主要内容时，段时长 ≤ 耗时中值 + 1s |
| 3 | **旁白密度**（有旁白时） | 引用第一步工具输出确认旁白在段时长内说得完；旁白为段的主要内容时，段时长 ≤ 耗时中值 + 1s |
| 4 | **情绪标注**（有台词时） | 用声音质感+身体化描述，非"愤怒""悲伤"等泛化词 |
| 5 | **声音来源** | 台词、内心独白、画外音、旁白区分正确；内心独白和旁白时出镜角色不误张嘴 |
| 6 | **全文计时** | 所有可听见文字都已纳入 `count_chars.py` 工具输入，没有漏掉路人、画外、心声或旁白 |
| 7 | **对白顺序** | 多句对白按时间顺序嵌入阶段，谁说话、谁停顿、谁反应都清楚 |
| 8 | **镜头调度**（对白段） | 每 4-5s 有一次切镜或运镜启停（豁免场景除外）；插入镜头写明切回后说话方状态承接 |

> 通用必查项与推荐项见 `storyboard/prompt-craft.md`「Prompt 构造检查清单」，本表为台词场景的追加项。
