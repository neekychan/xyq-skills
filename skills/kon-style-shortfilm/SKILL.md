# 今敏风格短片

## 核心原则

不要只做"好看的动画片段"，要做**心理时空叙事**——现实与梦境通过匹配剪辑无缝焊接，隐喻道具在四幕弧线中发生物理演变，观众的窥视感与角色的身份危机同步升级。

持久引擎（因果链）：

**用户创意碎片 → 今敏式四幕心理弧线孵化（起·危机觉醒 / 承·现实裂隙 / 转·梦境狂欢 / 合·虚实咬合） → 象征道具双向演变设计 → 故事板分镜（场景绑定 + 匹配剪辑 + 音响导演） → 核心元素资产注册（角色全身三视图 + 场景四宫格 + 音色绑定） → 分镜视频逐一生成（多模态强绑定防跑偏） → 音频层生成与多轨幻听拼贴 → 最终组装成片**

### 质量测试（可证伪）

短片只有通过这条测试才算成立：

**如果抽掉"现实→梦境"的匹配剪辑转场与象征道具的物理演变，主角的心理崩溃就只是一段普通动画，而非今敏式的虚实嵌套叙事。** 即：匹配剪辑是时空焊接的结构性手段，道具演变是心理外化的结构性证据，二者缺一不可。

## 输入诊断

生产前，识别或合理假设以下维度：

- **创意来源**：用户提供的是完整剧本大纲、零散画面灵感、情绪概念，还是几句创意碎片？碎片越多，编剧赋能越重。
- **目标市场 / 语种**：对白与旁白用什么语言？默认中文。
- **画幅与分辨率**：全局锁定 16:9、720p（视频超分辨率阶段可升至 1080p/60fps）。
- **美学基调**：今敏风格写实手绘赛璐珞动画（武藏野美大 90s 基底），高度写实的人体比例与面部线条。
- **主角设定**：身份焦虑来源（都市压抑 / 社交冷漠 / 身份分裂）、性别与年龄段、视觉一致性锚点（红围巾 / 金边眼镜 / 泪痣等 1-2 个不变化的特征）。
- **隐喻道具**：为主角策划 1-2 个极具心理指向的象征道具（穿衣镜 / 复古闹钟 / 融化蜡烛 / 木偶 / 带裂纹的手机屏幕等），并预设其现实稳态与梦境异变态。
- **时空定性**：哪些场景属于"压迫感现实"（低饱和、冷色调、荧光灯白），哪些属于"超现实梦境"（高饱和、猩红金黄迷幻、空间扭曲）？
- **参考素材**：用户是否提供角色图、场景图、参考视频或音色样本？需校验是否符合全身三视图 / 无人物四宫格规范。
- **台词与音色**：发言角色是否需要 TTS 预生成参考人声？男女主角的声学描述词是什么？
- **镜头数量与总时长**：预计多少个分镜？总成片时长是否超过 15s（超过则需拆成多个 ≤15s 片段分别生成再拼接）？
- **合规敏感点**：心理惊悚题材是否涉及过度暴力 / 自残暗示 / 精神疾病污名化？需保守处理。

## 工作流（步骤）

### 第 1 步：确立全局规格参数

创建或更新 `Final_Video_Spec.md`，锁定：
- 画幅：16:9
- 分辨率：720p（超分辨率阶段可升至 1080p）
- 美学：今敏风格写实手绘赛璐珞动画
- 全局输出语言与风格基调

此文件作为后续所有工具的共有基础。

### 第 2 步：孵化剧本并设计故事板

**2a. 编剧赋能（若用户仅提供碎片）：**
将用户零散灵感扩写为符合今敏式四幕心理时空弧线的故事主线大纲（详见 `references/storyboard-design.md` 的"剧本孵化与心理叙事"章节）：
- **起（危机觉醒）**：极写实现代都市日常，展现角色身份焦虑；隐喻道具保持物理稳态。
- **承（现实裂隙）**：现实与梦境开始交叉，道具发生轻微异变态；通过无缝匹配剪辑滑入下一层。
- **转（狂欢与崩溃）**：潜意识全面爆发，色彩转向高饱和猩红金黄，道具极度物理坍塌。
- **合（重塑或困陷）**：虚实边界重新咬合，达成悲剧性困陷或戏剧性解脱。

明确界定角色的内心危机与象征性潜意识道具，向用户呈递。

**2b. 导演级视听转化：**
获得大纲共识后，将故事具象化为高质感故事板（核心元素、分镜镜头、音频层）。关键规范：
- **场景绑定强制核对**：每一个镜头必须显式绑定场景元素 ID（如 `[Element_Scene_X]`），禁止留空或模糊背景。同场景连续镜头必须关联至完全相同的场景元素 ID。
- **匹配剪辑转场设计**：在镜头描述中明确写出过渡手法（形体关联 / 运动关联 / 镜面反射媒介过渡）。
- **声音导演规划**：对白"非虚构化"（口语化、破碎、生理语气词、省略号），多轨幻听交错逻辑。

> **分步确认暂停点 1（剧本大纲与分镜故事板）**：在最终确定故事板前，必须暂停执行，先向用户呈递扩写后的故事大纲、四幕结构、象征道具规划，再展示详细的分镜镜头（含运动、匹配剪辑转场设计、声音导演规划），获得用户明确同意后方可推进。

### 第 3 步：核心元素建立与逻辑资产管理

**3a. 用户素材继承与检验：**
若用户提供了人物人设图、场景图或音色样本，对素材进行画风、写实度、格式合规性评估（详见 `references/asset-analysis.md``）。

- **角色图合规要求**：必须是标准的**全身三视图**（正面、侧面、背面同时包含且均为全身图像，绝不能是半身或单角度）。若符合且画风对齐今敏写实美学 → 直接注册稳定 asset_id 并绑定。
- **场景图合规要求**：满足无人物、多角度且包含标准四格分配（全景定场 / 陈设特写 / 纵深透视 / 气氛光效）。若符合 → 直接注册并绑定。
- **风格 / 格式不契合重绘机制**：若角色图不满足全身三视图格式或画风冲突，或场景图不满足四宫格规范 → 通过 ImageToImage 强引用用户原图重绘为合规格式（详见 `references/media-generation.md`）。重绘成功后注册为全新稳定 asset_id 并绑定。

**3b. 系统自制参考（若用户未提供素材）：**
- 角色全身三视图（TextToImage，aspect_ratio 锁定 16:9）
- 多角度无人物四宫格场景参考图（TextToImage，aspect_ratio 锁定 4:3）

**3c. 角色音色确立与绑定：**
发言角色注册唯一的 key_element_audio 绑定。若用户未提供，以 TTS 预先生成 5s-10s 高拟真参考人声（详见 `references/media-generation.md` 的音色章节）。

**3d. 资产完整性自检：**
逐一自检故事板中所有核心角色、场景、音色等资产，确保每一个元素（以 stable asset_id 标定）均已成功绑定，无一遗漏。

> **分步确认暂停点 2（元素资产）**：向用户展示所有最终绑定的角色原画、场景参考图及音色样音，明确汇报所有元素的完整绑定状态与 asset_id 对应关系，获得确认后方可进行单镜头视频生成。

### 第 4 步：单镜头视频资产逐一生成与前置核对

逐一镜头调用视频生成（Seedance 2.0，MultiModalToVideo 路径），分辨率 720p，时长 4s-15s。

**视频生成前置核对规则（核心）——每次启动前必须对照分镜脚本全量核对：**
- **人物参考**：是否已绑定角色元素参考（如 `<<<image_1>>>`），提示词内是否写明视觉一致性锚点细节。
- **场景参考**：是否已正确绑定场景元素参考（如 `<<<image_2>>>`），背景与冷暖色温是否对齐当前时空定性。**必须强校验该镜头的场景元素 ID 是否与前后相邻镜头一致；同场景必须强制复用完全相同的场景参考图。若两镜属于同一具体子场景（如都在走廊内 / 书桌前），必须锁定四宫格中的同一网格，严禁跳格导致背景跳画。**
- **台词对白**：若有台词，是否已用 `{}` 包裹且文本对齐故事板脚本，是否已关联角色 key_element_audio。
- **声效 / 节拍包裹**：特殊声效是否已用 `<>` 包裹，背景节拍是否已用 `()` 包裹。

详细核对规范与提示词撰写规则见 `references/prompt-formulas.md`。

> **分步确认暂停点 3（镜头生成前与后）**：启动生成前，先将提示词、多模态引用关系（含场景原画资产的一致性绑定检验情况以及相邻镜头的场景网格锁定核对）及上述核对情况向用户展示，确认无误后开始生成。生成完毕后展示镜头视频，由用户核实运动与匹配剪辑质量。

### 第 5 步：音频生成与最终组装

逐一生成故事板中规划的其余音频层（TTS 配音、背景音乐、环境声效），进行最终画轨、音轨剪辑与组装。

音频生成规范（详见 `references/media-generation.md`）：
- 多阶段生理语气渐变拆分生成
- 多轨幻听资产独立生成
- BGM 三套场景自适应模板（心理悬疑 / 狂欢游行 / 时空史诗）
- 生成后置参数微调

> **分步确认暂停点 4（最终总装）**：组装完成后，向用户呈递最终短片并建议进行成果导出。

## 输出契约

### 全局规格文件

`Final_Video_Spec.md` 固定字段：
```
画幅: 16:9
分辨率: 720p（超分辨率可升至 1080p/60fps）
美学: 今敏风格写实手绘赛璐珞动画
全局语言: <语言>
风格基调: <一句话>
```

### 故事板分镜镜头（Shot）固定字段

```
镜头编号: Shot_XX
场景元素 ID: [Element_Scene_X]（强制绑定，不可留空）
时空定性: 现实日常 / 现实裂隙 / 梦境狂欢 / 虚实咬合
时长: 4s-15s（契合叙事节奏动态规划）
画面描述: <相机运动 + 构图 + 角色动作 + 道具状态>
匹配剪辑转场: <与下一镜的焊接锚点，或"无">
对白: {<台词文本，含生理语气词标记>}
音频层: <BGM / 环境声 / 幻听轨规划>
角色参考: <<<image_1>>>（绑定 asset_id）
场景参考: <<<image_2>>>（绑定 asset_id，标注四宫格锁定网格）
音色绑定: key_element_audio（asset_id）
```

### 视频生成方式

单条视频生成时长 4s-15s。日常压抑段落设计较长镜头（8-15s），心理崩溃段落设计最短镜头（4s），但在故事板中标记后期裁剪建议（如"截取前 1-2s 进行高速拼接"）。当成片总时长超过 15s 时，拆成多个 ≤15s 片段分别生成，再进行后处理拼接。

## 静默自检

交付前内部跑清单并重写弱项。除非用户要求点评，否则不外显。

- 四幕心理时空弧线是否每一幕都成立？起（写实日常）→ 承（现实裂隙）→ 转（梦境狂欢）→ 合（虚实咬合）是否递进？
- 象征道具是否在每个阶段都有明确的物理演变（稳态 → 轻度异变态 → 极度物理坍塌 → 虚实融合或循环锁死）？
- 每一个镜头是否都显式绑定了场景元素 ID？同场景连续镜头是否复用同一场景参考图？同一子场景是否锁定四宫格同一网格？
- 匹配剪辑转场是否在镜头描述中明确写出？是否避免了"淡入淡出"等平庸手段？
- 角色三视图是否为全身（正面 / 侧面 / 背面）？场景图是否为无人物四宫格且四格分配标准？
- 视觉一致性锚点是否在所有相关镜头描述中咬合？
- 对白是否"非虚构化"（口语化、破碎、生理语气词、省略号）？多阶段情绪渐变是否拆分为独立段落？
- 多轨幻听是否独立分配至至少 3 条音轨且有 0.5s-1.5s 延迟差？
- 单镜头时长是否在 4s-15s 范围内？成片总时长 >15s 时是否已拆分为多个 ≤15s 片段？
- 四个分步确认暂停点是否全部执行？每个暂停点是否获得用户明确同意后才推进？
- 冷暖色温是否在现实日常（低对比、局部冷暖微光）与梦境崩溃（高能饱和、猩红金黄撕裂）之间建立了强烈反差？
- 合规敏感点（暴力 / 自残暗示 / 精神疾病污名化）是否保守处理？
- 全文语言是否为中文，无中英文混杂？
