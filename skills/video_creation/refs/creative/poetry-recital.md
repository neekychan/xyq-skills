# 古诗词视频创作指南（朗诵 / 第一人称引诗 / 故事演绎 / 讲解赏析）

适用：用户要为某首古诗词/古文名篇制作视频（如"做一个李白将进酒的视频"）。

## 范式路由（先读）

| 用户信号 | 范式 | 阅读路径 |
|---------|------|---------|
| 朗诵/吟诵/朗读这首诗 | §A 朗诵 | 通用层 + §A |
| 让诗人讲述写诗的故事 / 第一人称 / 以XX的视角自述 | §B 第一人称引诗 | 通用层 + §B |
| 演绎/演一个/拍成短剧/这首诗背后的故事 | §C 故事演绎 | 通用层 + §C |
| 赏析/讲解/解读这首诗 | §D 讲解赏析 | 通用层 + §D（借 narrative-suite 单条） |

**未指明方式**（"做一个将进酒的视频"）——**必须给出范式建议并询问用户，禁止替用户决定**：按该诗特质给出 2-4 个范式选项（每项一句话说明创意亮点），并标注推荐项及推荐理由。若本请求同时触发意图澄清问卷（比例/风格未提），将范式选项合并进**同一次**问卷；若不触发问卷，则单独就范式提问一次，等用户选择后再继续规划。范式可组合（如 §B 自述引诗后接整联吟诵），按落点取主范式，只借辅范式单条规则。

**协同 ref 加载时序**：先读完本文件、完成范式路由，再按所落范式补读协同 ref——**§C 借 `creative/narrative-arc.md` 弧线**（落 §C 必读；§A/B/D 一律不借 narrative-arc）；§D 借 `creative/narrative-suite.md` 单条。禁止在范式确定前预读协同 ref。

## 通用层（所有范式共享）

### 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 诗句改写/白话化/增删后引用 | 破坏原文，文化硬伤 | 凡出现诗句必须原文逐字；叙事与诗句界限分明 |
| 诗人嘴里冒现代词（"压力""焦虑""加油"） | 穿越出戏 | 自创文本半文半白，符合诗人性情与时代 |
| 诗句字面直译成画面（"白发三千丈"真画三千丈） | 画面荒诞 | 意象转译三步法（见通用层） |
| 每句配一帧静态"配图" | PPT 幻灯片，无电影感 | 每镜必有自然动势（水流/云移/风吹/光变）+ 运镜 |
| 自创文本也拉慢到吟诵速率求氛围 | 拖沓，流失快节奏受众 | 按语速表分速（诗句 2 字/秒、自创 3 字/秒）；吟咏感靠吟诵语速与音步停连，不加句后静默 |
| §B/C 虚构重大史实（人物/朝代/地点/本事张冠李戴） | 史实硬伤 | 基于通行本事创作；诗人际遇标签（漫游/贬谪/流放/隐居/官任）与创作地须与该诗创作时期一致；细节不确定则模糊处理；史实自检覆盖 plan 全文（含核心梗/概要） |

### 通用强制规则

1. **引文神圣**：凡出现诗句（旁白/台词/吟诵）必须原文逐字，禁止改写、增删、译成白话。生成前先核对全文无错字。自创文本（自述/台词/讲解词）中禁止把诗句白话转述后混入——要么引原文，要么不引；**未引的诗句也一样：其句意只能由画面意象呈现（意象转译），禁止用旁白/台词白话复述来"补偿"**（如未引"人有悲欢离合"却让旁白说"聚散悲欢自古难全"即违规）；**已引的诗句同理：禁止在引诗前后用自述/旁白把句意先白话铺垫一遍**（如先说"我欲渡黄河，河面冰封万里"再引"欲渡黄河冰塞川"即重复表达，引诗沦为复读）——同一句意只出现一次，表达权归诗句原文。自创文本中出现诗句原文或其截取变体，一律按引诗处理：逐字、标【引诗】，禁止删字改标点后冒充自述
2. **完整度策略分范式**：§A 整首优先（见 §A 规则）；§B/C/D 默认只引**核心联**（按 千古名句 > 开篇起兴句 > 收束句 取 1-3 联，篇幅允许时兼顾 1-2 联可群像化的写景/生活句——渔舟、宴饮、行旅、民俗，为画面群像提供取材；必须完整韵律单元、禁止断在半联），在方案中**列出所引与未引诗句**；用户明确要求整首时才全文呈现
3. **分速估时**（诗词体裁专用语速）：诗句（吟诵腔）**2 字/秒**——计量时对诗句原文调用 `count_chars.py --mode slow`；自创文本（自述/讲解/台词）**3 字/秒**，用默认口径计量。字数=纯汉字数，标点不计。撰写前按主文本类型反推字数预算，按预算写，禁止写满再砍。禁止把自创文本也拉慢到吟诵速率
4. **引诗时刻双峰合一**（§A 的名句段 / §B/C/D 的引诗处通用）：引出诗句的瞬间是情绪峰值——语气从叙述/讲解切换为吟诵腔 + 画面切至该句最强意象（最大景别反差/最强光影），两者同拍出现。禁止把诗句平淡地念过去。**引诗前后不加静默**：峰值靠语气与画面制造，句后紧接下一句/下一段（仅 TTS 自然换气）。引诗段不受"信息密度/相邻合并"类校验裁剪——禁止以"诗句无新信息"为由削减诗句
5. **时代一致**：朝代服饰建筑器物一致（查 creative/narrative-suite §C 时代-画风映射）
6. **出镜与声线**：任一段含人物开口（吟诵/自述/台词），该人物必须有三视图参考图。同一声音身份（旁白/诗人）的音色描述跨段逐字一致
7. **吟诵停连**：诗句吟诵按音步停顿——五言 2/3、七言 4/3 或 2/2/3，词依词牌句读；情绪枢纽处停顿加重（如"与尔同销 / 万古愁"在"万古愁"前顿一拍）。停连指令写进 prompt 的语气标注（如"吟诵语气，按 4/3 音步停连，'万古愁'前顿一拍"），**禁止为标停顿改动诗句文字或标点**（引文神圣）；音步停顿已含在 2 字/秒吟诵语速内不另计时，句后不存在任何另计静默
8. **交付卫生**：creative_design.md 只写正式剧本内容（用户可读文体），验算算式等工作性文字一律不入文件
9. **人景结合**：每段画面都含点景人物或出镜人物（「出场形象」字段逐段核验）。点景人物是流动群像：**身份优先从句意取**（渔舟句配渔人、宴饮句配宾客）；**句意无人物的写景句，从该诗时代生活图景取群像身份**（渔樵耕读、游人商旅、乐伎童叟、浣衣孩童等，逐段不同）——群像与句意松耦合，气氛与时代不违和即可，**群像即众生烟火，是画面代入感的主要来源，禁止因"句中无人"回退到诗人或空镜**。**§A/§D 中诗人本人只在"属于他的时刻"入画**——开篇起兴/钩子、出镜吟诵、直抒胸臆的言志句、收束余韵；其余镜头一律用群像并逐镜轮换身份，避免任何单一身份连排成为新的常驻。自检：诗人入画的每个镜头都要能答出"他此刻为何在场"（起兴/吟诵/言志/收束之一），答不出就换成群像身份；§B/§C 的叙事主角不受此限。点景人物以远中景/背影/侧影入画，正脸只出现在出镜开口段；点景人物不开口，不需要三视图与 character-lock，跨段只锁两项——时代服饰（一句话写入整体风格并进通用尾注，如"唐人衣冠"）与整体画风。**不存在留白镜头与空镜段**——所有镜头都有吟诵覆盖，「出场形象：无人物」即违规，按本条补群像

### 定篇与诗风定调

**联网检索定篇**：规划前主动联网搜索该诗词，补齐三类信息——①**权威原文全文**（核对错字与异文；有异文时取通行本，并全片逐字一致）②**创作背景与本事**（年代/地点/诗人际遇，供 §B/C 史实自检与 §D 背景钩子取材）③**情感底色与名句公论**（供诗风定调、核心联选取与意象转译）。检索 1-2 次、取信权威来源即可，与自身记忆冲突时以检索结果为准；无法联网时按记忆执行，不确定的细节一律模糊处理。**检索时机**：若本请求触发意图澄清问卷或范式提问，先提问、等用户回答后再检索——禁止检索与问卷同轮并行（提问点须停止一切规划动作，且用户的回答可能改变检索方向）。

核对诗词全文（错字是文化硬伤）→ 统计字数（逐行计数并以句式自检：七言句 7 字、五言句 5 字、词牌句长查原文——对不上必有错；标点不是字）→ 按规则 3 估时 → 按范式决策完整度（§A 走整首优先与超限协议，§B/C/D 选核心联）。

**画风选择**：用户已指定风格 → 直接采用。未指定 → **禁止惯性默认水墨**：从该诗风候选列取 2-3 个画风选项（每项一句话说明视觉效果差异），随范式建议/意图问卷一并询问用户；若无其他提问可搭载，则单独就画风提问一次。推荐项按该诗意象特质给出理由，不得固定推荐同一画风。用户明确让 agent 决定时才自主选择，并在方案中说明选择理由。

风格关键词、配色、色温、环境音：查 `creative/style-master.md`（§一 对应画风行、§二 中式子风格、§三 对应情绪行），确定后逐字锁定。

**全片光气氛锁定**：定调时选定单一主时段与光型（如黄昏金光侧逆光 / 月夜冷调），写入 creative_design.md 整体风格并全片沿用——场景参考图与各段画面的时段、色温一律继承主时段，禁止"中性偏冷为主、黄昏段转暖"式双色温并存。诗句意象确需异时段（如"画栋朝飞南浦云，珠帘暮卷西山雨"的朝暮对写）时，以主时段为基调，异时段只用于该句画面并在方案中注明。

### 意象转译（审美核心，creative 阶段定方向，分镜阶段落细节）

**长卷思维**：整片是徐徐展开的长卷。相邻段落需视觉钩连（同色调延续 / 同方向运动 / 图形匹配，如上段收尾的水面月影 → 下段开场的杯中酒光）。

creative 阶段只做意象组规划：**① 提炼核心意象（物象+情感底色）→ ② 判断虚实方向 → ③ 写入粗段落的画面方向**。禁止在 `creative_design.md` 中逐句铺满镜头细节、运镜和景别；逐句音画对应、视觉钩连、运镜由分镜规划阶段完成。

| 诗句类型 | 转译策略 | 分镜阶段画面手法参考 |
|---------|---------|---------|
| 景语（明月/黄河/空山） | 实写意象 + 群像点景 | 意象为画面主体，景中置群像点景人物做符合气氛的事（行舟/浣衣/牧归/执灯/抚琴）+ 自然动势；身份按通用规则 9 取（句意优先，无则时代生活群像），逐镜轮换，纯空镜镜头仅作点缀且必须有吟诵覆盖 |
| 夸张比喻（"奔流到海不复回"） | 取气势不取字面 | 极端视角（航拍/仰拍）+ 体积光 + 升格慢镜 |
| 情语（"万古愁""断人肠"） | 剪影写情 | 人物剪影/背影 + 长镜头缓速，吟诵连续不加静默 |
| 叙事句（"呼儿将出换美酒"） | 动作写意 | 局部特写（斟酒/挥袖/抚琴），不露正脸 |

|------|---------|---------|

| 酒 | 斟酒入杯、酒面涟漪映烛光、举杯泼洒 | 豪情、愁绪 |
| 江河 | 航拍奔流、浪涌击石 | 时间流逝、壮阔 |
| 风/柳/衣袂 | 柳枝拂水、衣袂翻飞 | 离别、飘逸 |
| 雪/霜/白发 | 落雪无声、霜染鬓边 | 岁月、孤寂 |
| 落花 | 花瓣飘落水面随波 | 无常、伤逝 |
| 孤舟/鸿雁 | 大远景中的小主体缓慢移动 | 漂泊、渺小 |

### creative_design.md 剧本正文通用格式（§A/B/C/D 一致）

每段必须是粗粒度诗词剧本段落：**声音文本范围**（诗句标【引诗】，锚点句加标【锚点】，自述/讲解/台词标其类型）+ **声音形态**（画外旁白/出镜开口）+ **出场形象**（该段画面中的人物，含不开口的点景人物：身份 + 在做什么，每段至少一条人物条目、按通用规则 9 取群像，禁止写"无人物"或"空镜留白"）+ **核心意象组** + **叙事/讲解功能** + **情绪推进**。禁止把单句诗、单句讲解、单个意象、单次运镜拆成独立段落；视觉钩连、景别、运镜和逐句画面由分镜规划阶段完成。**出场形象记录画面人物、声音形态记录发声方式，两者是独立维度**——声音为画外不代表画面无人；通用规则 9 的人景配比以各段「出场形象」计数核验。

## §A 朗诵范式（默认）

> 诗句原文是全部声音文本，画面为诗意服务。

**§A 特有规则**：
1. **整首优先**：默认完整呈现整首。用户未指定时长 → 按整首估算并告知预计总时长；指定时长 ≥ 整首所需 → 按整首规划，并按规则 2b 校验估时富余——整首估时远低于指定时长时不得靠画面铺时补差
2. **超限提问协议**：仅当用户指定时长 < 整首所需时，**必须停止规划并提问**：A. 整首呈现（附建议总时长）；B. 精选片段装入指定时长（附推荐片段：千古名句 > 开篇起兴 > 收束句，完整韵律单元）。等用户选择后再继续
2b. **不足补联协议（超限协议的镜像，精华片段与整首同受约束）**：用户指定时长（含"N秒左右"）而当前所选内容估时（规则 3 分速；精华选联与整首同一口径，**估时只算声音耗时，静默与画面时长一律不计入**）低于目标的 85% 时——精华片段先**补联再定稿**：按 千古名句 > 开篇起兴 > 收束句 > 可群像化写景/生活句 > 行文顺序 逐联补入并复估，直至估时落入目标的 85%-100%（禁止超出）；**已是整首（或补至整首）仍低于目标 85% → 必须停止规划并提问**：A. 按整首实际估时交付（附实际时长）；B. 由用户决定增补篇目或接受现时长。**红线：禁止用留白、静默、慢镜、空镜段、氛围画面铺时、重复吟诵把总时长拉向目标**——诗词链路不存在任何静默/留白名目（锚点句后留白、引诗后静默、情语留白、"画面呼吸空间"、余韵段都不存在），"诗句 N 秒 + 留白/画面凑到目标"的算式即注水，出现即回本协议重新处理。**估时账本（必产物）**：creative_design.md 必须含「估时账本」小节——只有两列：「诗句字数 | 吟诵秒数（=字数÷2）」，**不存在第三列**（出现"场估时""画面时长"等任何附加列即口径错误）；全篇估时 Z = 各场吟诵秒数之和，与目标 N 秒并排写出占比 Z/N；各场「预估时长」= 该场吟诵秒数，两者不一致即口径错误，回本协议重估。账本末行写**判定**，只有三种合法写法：占比 ≥85% 写「达标」；<85% 写「已补联：{联句清单}，补后占比 X%」；整首仍不足写「已触发提问」。**禁止用「画面过渡」「情绪铺陈」「内容密度合理」等任何说法解释缺口**——"吟诵 X 秒 + 画面 Y 秒 ≈ 目标"正是 2b 红线点名的注水算式，出现在账本上下文即违规，回 2b 重新处理；**禁止在占比不足的账本上继续往下规划**。创意确认门原样展示账本
3. **creative 粗段规划**：短诗/绝句在 creative 阶段按诗意单元合并为 2-3 个粗段，不按每句或每联硬拆；古风/乐府按情绪大段或叙事功能粗分。分镜阶段再按吟诵节奏、联句和画面承载力拆镜头
4. **锚点对齐（音画对应制）**：creative 阶段从所引诗句中选 2-4 处锚点句（千古名句 > 具象标志性景语 > 情语收束，短片取下限），在 creative_design.md 对应粗段标【锚点】。分镜阶段只有锚点句要求音画精确对应（画面即该句最强意象）并按通用规则 4 双峰合一处理；非锚点句画面走点景人物游历线与情绪弧线，与该句气氛/时段/情绪不违和即合格，允许与句意无字面关联，禁止为抽象句、过渡句硬造直译画面。creative_design.md 仍只写粗段意象组与情绪方向，禁止逐句写成镜头表
5. **开篇即入诗**：不播报题目与作者，直接进入首句吟诵；开篇画面必须是钩子镜头——人物动势或最强意象事件（如执卷凭栏、挥毫落笔、舟行破雾），禁止静止空镜起手

**朗诵者形态规划**（画外旁白 / 诗人出镜吟诵，逐段自由混合，按意境与创意自主选择，用户明确指定时从用户）。**朗诵默认画外为主、出镜吟诵点缀 1-3 段**（整首与精华片段同样适用；选呼告句/情绪峰值句），出镜段诗句以一联为宜——出镜吟诵实耗 ≈ 字数÷1.4，15s 段仅容约 21 字，出镜段过多会令段数与总时长翻倍：

| 诗句信号 | 倾向形态 | 理由 |
|---------|---------|------|
| 写景句、宏大意象 | 画外旁白 + 人景结合画面（意象为主体、点景人物为画眼） | 让天地说话，人声退为画外，人物供代入 |
| 呼告句/对话感（"岑夫子，丹丘生"）、第一人称抒怀 | 诗人出镜吟诵 | 诗句本身在"说话"，出镜更有感染力 |
| 情语收束（"万古愁"） | 皆可：剪影+画外低诵，或出镜低吟 | 看全片弧线的收束方式 |

- 出镜吟诵段台词格式：`{诗人名}（{音色}，吟诵语气，{声音质感+身体化情绪}），{神态/动作}，嘴唇随吟诵清晰开合，吟诵：{诗句原文}`；神态动作随诗意变化（举杯/抚须/凭栏/望月），禁止呆立念稿
- 画外朗诵段旁白格式：`旁白（{音色}，吟诵语气，{情绪}）：{诗句原文}`
- 形态选择只看意境与创意；禁止以"减少 ref 加载/降低生成复杂度"为由回避出镜
- 全片情绪弧线：起兴 → 铺陈 → 高潮（千古名句段按通用规则 4 双峰合一）→ 收束（收束句吟诵与渐拉远景并行，不加余韵段）

## §B 第一人称引诗

> 诗人以"我"的口吻讲述创作背景故事，在情绪顶点引出诗句。故事是引信，诗句是爆点。

1. **文本构成**：白话自述（agent 创作）约占 60-75%，诗句引用占 25-40%。自述语言半文半白、符合该诗人性情与口吻（李白狂放、杜甫沉郁、李清照清婉），禁止现代词汇与网络语。**自述与诗句分工**：自述只写**诗外信息**——创作本事、具体事件、人物与心理动因（诗里没有的内容）；句意与意象的表达权归诗句原文与画面（通用规则 1）。检验法：删去某段自述后，仅靠画面与诗句若不缺任何信息，则该自述是诗句白话版，必须重写为事件细节或删除
2. **叙事弧线**：处境自白（我是谁、那年何事）→ 事件与情绪积聚（具体细节，非泛泛感慨）→ **引诗时刻**（按通用规则 4 双峰合一：自述推至顶点，诗句以吟诵腔紧接涌出）→ 收束（一句收束自白，与画面并行）
3. **史实底线**：自述基于该诗通行的创作本事（如《将进酒》=赐金放还后与岑勋、元丹丘置酒），重大史实不得虚构；细节无考则模糊处理（"那一年，我离开了长安"）
4. **声音形态**：默认诗人出镜自述为主（独白即台词，走 dialogue-rules）、穿插意象空镜闪回（自述声画外延续）；也可全程画外自述+画面叙事。出镜自述与画外自述音色逐字一致
5. **完整度**：默认只引核心联（通用规则 2）；引诗后可用画外吟诵补足下联保持韵律完整
6. **时长建议**：未指定时默认 45-60s（自述需要铺垫空间），在方案中告知；用户指定时长第一公民。出镜自述为主时总文本字数 ≈ 目标秒数 × 2（通用规则 3：自创 3 字/秒 × 0.7；引诗部分按 2 字/秒另计），按此反推自述篇幅，避免排段后超 70% 返工

## §C 故事演绎

> 以剧情短片演绎诗背后的本事或意境故事，诗句作点题。

1. 剧本写法遵循 `creative/narrative-arc.md` 的 creative_design.md 格式（场次/动作/台词）与故事弧线（规划阶段 ref 可放宽到 4 个）；本节只管诗词特有项
2. **引诗规模（知情默认，禁止静默缩减）**：默认点题式（按通用规则 2 引核心联 1-3 处），但方案/定稿必须明确列出**所引与未引**的诗句，并附可调提示（如"如需诗句贯穿全剧或整首呈现，总时长约需 X 秒"，X 按 诗句字数÷2 加剧情时间估算）。若本请求已触发范式/画风提问，将"点题式（诗句作爆点）/ 贯穿式（每个情节高点引一联，诗为主线）"作为选项一并询问；用户明确要求整首 → 整首入剧，时长按预算加长并告知
3. **引诗位置三选一**：开篇引子（诗句起兴再入故事）/ 剧情高潮（剧中人在情绪顶点吟出）/ 片尾点题（剧终旁白吟诵+意象画面）——引诗处按通用规则 4 双峰合一；贯穿式则每处引诗均按双峰合一处理
4. 剧中角色台词为 agent 创作（守红线：半文半白、无穿越词、史实底线）；诗句引用逐字。**出镜底线**：全片至少保留 1-2 处角色出镜开口（短句台词或单联吟诵，段长按 Duration 硬等式反推取足），禁止以"通过验算"为目的把全部开口降级为画外旁白——验算超时的正解是缩短文本或加长段，不是消灭出镜
5. 多角色时按根文件素材规范走三视图与 character-lock

## §D 讲解赏析

> 第三人称讲解这首诗的背景、意象与名句。

1. 讲解结构：背景钩子（一句话抓住这首诗最反差/动人的事实）→ 创作语境 → 名句/意象组精读 → 主旨升华。短诗讲解在 creative 阶段一般合并为 3-4 个粗段，禁止按每句诗或每句讲解拆段；逐联/逐句讲解和画面承接由分镜阶段细化。借 `creative/narrative-suite.md` §A"情绪弧线/钩子"单条
2. **引用与讲解双声区分**：讲解词用平实讲述语气；引诗句切换吟诵腔（同一旁白音色，语气标注不同），引诗处按通用规则 4 处理
3. 画面：讲解段配该句意象画面（按通用意象转译），禁止"主播念稿配 PPT"式呈现；诗人可作为画面人物出现，但讲解声音是第三人称旁白

## 失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| §A 时长装不下整首又不提问 | 擅自删句篡改作品 | 触发超限提问协议（§A 规则 2） |
| 选联估时不足却用留白/过渡/慢镜凑到目标时长 | 全片空转拖沓，实际内容量远低于用户预期 | 触发不足补联协议（§A 规则 2b）：先补联，整首仍不足则提问 |
| 段内大段无吟诵画面 | 朗诵节奏漏气，段段拖沓 | 朗诵段 Duration 硬等式 = 吟诵耗时 + ≤1s（poetry-prompt「朗诵段 Duration 口径」），画面与吟诵并行，不存在无吟诵画面段落 |
| §B/C/D 整首硬塞进叙事 | 节奏失衡，故事和诗都被压垮 | 默认只引核心联（通用规则 2） |
| 引诗处平淡念过 | 名句无记忆点 | 引诗时刻双峰合一（通用规则 4） |
| 诗句匀速平诵无停连 | 机械念稿，无吟咏感 | 按音步停连（通用规则 7），语气标注写明断句 |
| 验算写"需调整"却不改稿 / 用"与画面重叠""动作间隙"抵扣语音时长 | 假验算，生成时语音必然超时或被截断 | 声音串行求和；不符即改稿，以修改后文本复验闭环 |
| §B 自述空泛（"我很苦闷"） | 故事无张力，引诗无力 | 自述写具体事件细节，情绪由事而生 |
| §B/C/D 自述/旁白白话复述诗句句意（先说"河面冰封万里"再引"冰塞川"） | 重复表达，引诗时刻沦为复读，自述冗余 | 自述只写诗外本事与细节，句意由原文承担（通用规则 1） |
| §B/C 自创文本现代腔 | 穿越出戏 | 半文半白，符合诗人性情与时代 |
| 自创文本拉慢到吟诵速率 | 拖沓 | 按语速表分速，不加静默 |
| 锚点句音画错位（名句吟到时画面在别处） | 名句无记忆点，音画割裂 | 锚点句精确对应 + 双峰合一（§A 规则 4）；非锚点句不受此限 |
| 每句硬配一个对应画面（逐句直译式排片） | 画面硬凹、节奏被句子边界锁死、景物重复 | 锚点对齐（§A 规则 4）：仅锚点句精确对应，其余走人物游历线 |
| 全程空镜无人 / 全程大头念稿 | 无代入感 / 画面单调 | 按通用规则 9 人景配比执行 |
| 段间意象互不关联 | 幻灯片感 | 长卷思维：相邻段视觉钩连 |
