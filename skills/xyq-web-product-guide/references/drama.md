# 短剧与漫剧 Agent

来源：[主手册](https://bytedance.larkoffice.com/wiki/PxZgwJwxti0dutk6WIdcwRA6nTd)。

## 从剧本到成片

1. 首页选择【短剧Agent】。上传 txt / docx 剧本、直接粘贴文本，或选择 AI 生成剧本并描述故事设定、主角特征、剧情脉络和结局。手册记录剧本最长支持 10 万字。
2. 检查生成的剧本概要，可在内容区增删改写后确认。填写项目名称、画面风格、画面比例；画风按选题推荐，也支持自定义输入。确认后等待剧本整理完成。
3. 生成全局角色。Agent 提取角色、不同时空的妆造特征并映射至相应集号；已有角色图可手动上传。需要新增角色时点击“新建角色”。
4. 生成全局场景。若不满意，在资料库修改场景描述并重新生成。
5. 自动拆分分镜，整理分镜脚本、角色妆造及场景。底部分镜栏可增删镜头，故事板中可手动编辑脚本，并用 `@` 引用资产库角色和场景。点击底部生成分镜视频，支持批量生成多集、多分镜。
6. 视频生成完成后，在右上角点击合成，再导出视频；手册展示“导出全集”。

## 常见使用问题

- 角色不一致：在具体分镜的故事板中 `@角色形象` 引用角色。
- 角色形象或音色不满意：在资料库中修改。手册描述可以一键同步更新该角色出场剧集的画面/声音；未说明触发细节、耗时或费用，不补充承诺。
- 镜头衔接不自然：使用故事板截取上一镜头尾帧，作为下一镜头的首帧参考。
- 想指定道具、光影或人物站位：上传参考素材作为垫图参考。
- 想做旁白解说剧：可将传统短剧剧本交给 Agent 转换为旁白解说体；主手册未写独立按钮的具体位置。
- 剧本格式：手册范例包含“第一集 1-1”、场景及时间、人物、以“△”描述的动作与环境、角色台词及 OS。该范例是参考格式，不应声称所有内容必须严格使用该格式。

## 新能力简介与进一步查询

主手册介绍短剧 Agent 2.0 和 Seedance 2.5，并链接以下能力。重制转绘的详细操作见[短剧重制转绘](drama-redraw.md)。其余下列专项能力的详细操作未收录，无法回答时使用未命中提示；可从[专项手册索引](manual-index.md)附上对应链接供用户自行查看，Agent 不访问链接。

- 剧本助手：对话共创、从零生成、小说改编、系列剧连载、解说剧改写、出海本土化。
- 重制转绘：上传原片后更换画风并适配目标地区；单个视频 5–300 秒、最多 20 个，单项目总时长 100 分钟。支持白模参考、普通复刻、资产本土化和原片对比，完整流程见[短剧重制转绘](drama-redraw.md)。主手册另提及 7000+ 角色库及出海剧本本土化，不能据此推断所有角色均可在重制转绘中直接使用。
- 故事场景无限画布：集中整理与生成角色、场景、参考素材。
- 3D 导演台：在 3D 空间摆放角色/道具、调整站位姿势和机位，截图送回画布作为构图参考。
- 智能预演：统一规划整组分镜，把关键帧插入对应片段。

## 单集多轨编辑

故事板支持以单集为项目进行多轨编辑，画布以多轨道节点为项目。片段编排、音频分离、未生成占位符及导入/分割联动见[画布与故事板多轨编辑](multitrack.md)。
