# TVC广告全流程规划技能

## 核心原则
本技能是大牌商业TVC广告的标准化生产SOP，遵循**素材前置→分析先行→阶段确认→不跳步推进**的核心因果链：
`必要素材校验 → 视觉基因解构 → 品牌调性/理念分析 → 叙事方向确认 → 故事脚本确认 → 表格分镜确认 → 规范文档输出 → 故事板注册 → 资产生成确认 → 提示词构建 → 片段生成 → 时间线合成`

**可证伪质量测试**：全片每3秒必须有视觉反馈点，每7秒必须有情绪/视觉高潮，每个15s片段必须同时覆盖「代言人气质+品牌世界观+产品欲望+品牌记忆」四重商业目标，无黑场/白场/叠化等破坏性转场。

## 前置硬性条件（启动前必须校验）
1. **必须存在用户上传图片**，且至少包含：
   - 代言人图像（必需）
   - 场景调性参考图（必需）
2. 可选上传素材：产品图、品牌视觉参考图、品牌色彩参考图、材质参考图、空间参考图、既有广告参考图。
3. **缺少代言人图像或场景调性参考图时，立即终止流程**，提示用户补充必要素材后再继续。
4. 素材不全时，禁止生成反推文档、品牌分析、剧情方向、剧本、分镜表、故事板、资产图、视频Prompt或视频素材。

## 输入诊断
启动流程前必须确认/收集以下维度信息：
| 维度 | 说明 | 默认值 |
|------|------|--------|
| 必要素材 | 代言人图+场景调性图是否齐全 | - |
| 可选素材 | 产品图/品牌视觉/材质/空间/参考广告是否上传 | - |
| 总时长 | 广告片总时长 | 按用户需求，每15s为一个分段单元 |
| 视频比例 | 画幅比例 | 未指定时优先9:16竖屏；全球Campaign/大屏/官网优先16:9；电商/社媒KV可1:1/4:5 |
| 发布平台 | 投放渠道 | 抖音/小红书/视频号/TikTok/Reels/发布会/官网 |
| 品牌类型 | 高奢/时尚/运动/汽车/3C/混合 | 基于视觉反推自动判定 |
| 品牌信息 | 是否有品牌名、是否允许出现Logo | 默认不出现未授权Logo |
| 音频设置 | 是否需要旁白/对话、是否保留原声、是否加字幕 | 默认无旁白无对话无字幕，保留视频原声 |
| 特殊镜头 | 是否需要汽车动态/运动动作/3C交互/高奢静物镜头 | 基于素材类型自动判定 |
| 禁用元素 | 是否有明确禁止出现的视觉元素 | 无 |

## 强制参考加载契约
1. 执行视觉反推前，必须读取 `references/visual-reverse-engineering.md`，严格按照JSON Schema输出。
2. 设计表格分镜前，必须读取 `references/storyboard-table.md`，严格按照表格字段和节奏要求设计。
3. 生成资产前，必须读取 `references/asset-generation.md`，严格遵守资产注册范围，禁止生成分镜关键帧。

5. 合成视频前，必须读取 `references/timeline-integration.md`，严格遵守衔接规则和质检标准。

## 工作流（严格按顺序执行，禁止跳步）
### 阶段1：视觉基因解构（Visual DNA Analysis）
- 对所有上传素材执行高精度视觉反推，输出严格JSON格式的【美学反推规范文档】与【剧情故事叙事动态潜力文档】。
- 输出必须覆盖：媒介类型、视觉范式、代言人外形结构、人物姿态、服装妆发、品牌调性、场景空间、产品结构、材质、色彩、光影、构图、空间坐标、动态潜力、情绪潜力、广告传播潜力、3s视觉重点、7s高潮点、转场方式。
- 本阶段只分析，不生成剧情/剧本/分镜/资产/视频。

### 阶段2：品牌调性分析、品牌理念分析与参数询问
- 基于阶段1的JSON反推文档，完成品牌调性分析：覆盖品牌类型、高奢/时尚/运动/汽车/3C质感来源、全球广告语气、目标人群情绪、视觉禁忌、可用镜头语法、可用音乐节奏。
- 完成品牌理念分析：覆盖品牌精神、主张关键词、代言人与品牌关系、产品与人物/场景关系、核心传播情绪、全球Campaign扩展性、适合的叙事母题。
- 询问用户所有规划参数（见输入诊断表），**必须暂停，等待用户确认品牌方向与参数**。

### 阶段3：TVC叙事创意方向
- 用户确认后，提出3个差异化的一句话TVC叙事创意方向。
- 每个方向必须包含：方向标题、类型倾向、故事一句话、品牌理念切入、代言人情绪动作、产品角色、场景调性、核心视觉符号、品牌记忆暗示、3s视觉重点、7s高潮点。
- 方向需覆盖不同宣发语气（高奢情绪/时尚大片/运动性能/汽车品牌/3C发布/短剧情/CG/实拍质感等）。
- **必须暂停，等待用户选择、混合或修改方向**。

### 阶段4：前期故事脚本规划
- 基于确认的方向、参数，输出前期故事脚本。
- 脚本必须包含：标题、类型、总时长、比例、视觉风格、品牌主张、核心叙事、代言人/产品/场景行动线、情绪节奏、商业记忆点、旁白/对话草案、音乐氛围、每15s叙事单元概要、片段首尾衔接策略。
- 脚本仅用于确认叙事方案，不是分镜表，不得注册为故事板。
- **必须暂停，等待用户确认故事脚本**。

### 阶段5：全局表格分镜成表
- 用户确认脚本后，按每15s一个独立表格分镜表设计正式分镜。
- 每张表严格15s，包含5-12个镜头，约1000字，信息密度高。
- 必须设计每3s一个视觉重点、每7s一个视觉/情绪高潮的15s动作流。
- 表格字段必须包含：镜头序号、时间段、景别与视角、运镜方式、画面内容与表演、品牌/产品/代言人关系、光影与材质、SFX、音乐与情绪曲线、转场逻辑、首尾衔接策略、商业表达功能。
- 必须考虑分段生成的连续性：片段开头承接上一段的镜头/音乐/动作/情绪，结尾为下一段预留衔接接口。
- **必须先输出完整表格分镜，暂停等待用户确认，任何修改都需重新输出并再次确认**。
- 用户未确认分镜前，严禁编写规范文档、注册故事板、生成资产、构建Prompt、生成视频。

### 阶段6：编写Final_Video_Spec.md
- 仅在分镜确认后执行，编写最终规范文档，包含：标题、类型、比例、总时长、每段时长、品牌调性、品牌理念、视觉风格、语言、模型偏好、分辨率、资产策略、音频策略、片段衔接策略。
- 默认配置：类型为高奢时尚运动汽车3C大牌调性情绪TVC全球广告宣传片；视频模型为Seedance 2.0；分辨率720p；图片模型为GPT Image 2。

### 阶段7：分镜注册（Storyboard Registration）
- 仅在规范文档完成后执行，将每个15s表格分镜完整注册为一个Storyboard Shot。
- 每个Shot必须完整继承对应表格分镜的所有内容，不得删减、压缩、改写、换序或改变格式。
- 仅允许技术性编辑：拆分镜头到≤15s、添加镜头语言字段、补充Shot ID与资产引用字段。
- 不得虚构情节、改写台词、新增未确认内容。

### 阶段8：资产清单分析、注册与生成
- 故事板注册完成后，进行全局资产清单分析，**不以分镜头为单元注册资产，不生成分镜资产图/关键帧图**。
- 仅允许注册以下资产：
  1. 代言人资产：使用用户上传图为参考，生成干净背景全身像三视图（正/侧/背）
  2. 产品资产：若有产品图，生成干净背景产品三视图（正/侧/背或适合产品结构的三角度）
  3. 场景资产：每个不同场景生成一张场景资产图，同一场景跨分镜重复出现只生成一次
  4. 跨分镜重复资产：仅当道具/新造型/视觉元素跨多个分镜重复出现且上传素材未覆盖时才生成
- 所有图片生成必须使用GPT Image 2模型，参考视觉反推文档的美学规范。
- **资产生成完成后必须强制暂停，等待用户调整/重抽/替换/确认，未确认前严禁进入视频生成阶段**。

### 阶段9：提示词构建（Prompt Engineering）
- 仅在所有资产确认后执行，严格按照万能公式生成视频Prompt，每个15s Shot对应一个Prompt。
- 必须完整融入表内所有镜头逻辑，保留镜头顺序、3s重点、7s高潮、动作链、转场、首尾衔接、声音标记、负向约束。
- 所有Prompt使用中文书写，必要英文术语保留。

### 阶段10：视频片段生成
- 使用MultiModalToVideo能力，模型Seedance 2.0，分辨率720p，每个15s Shot生成一个15s视频片段。
- 每个片段必须参考对应Shot已确认的所有资产图和用户上传原始参考图。
- 严格执行3s重点与7s高潮逻辑，保证画面动效连续，首尾保留与相邻片段的衔接元素。

### 阶段11：时间线合成
- 按Shot顺序将所有片段推送至时间线，打开视频轨音量，不额外生成独立BGM/旁白/音效（除非用户明确要求）。
- 检查动作、光影、色彩、材质、角色、产品、音乐、音效、转场的连续性，禁止黑场/白场/渐隐/渐显/叠化。

## 输出契约
### 阶段1输出
严格JSON格式视觉反推文档，符合`references/visual-reverse-engineering.md`中的Schema要求，字数不少于1000字。

### 阶段2输出
品牌调性分析+品牌理念分析+参数确认问卷，等待用户输入。

### 阶段3输出
3个结构化TVC叙事方向，每个方向包含要求的11个字段。

### 阶段4输出
结构化前期故事脚本，包含所有要求的字段。

### 阶段5输出
Markdown表格格式分镜表，每15s一张表，包含要求的12个字段，每张表后附节奏校验说明。

### 阶段6输出
`Final_Video_Spec.md`文档，包含所有规范字段。

### 阶段7输出
结构化Storyboard Shot列表，每个Shot包含要求的所有字段。

### 阶段8输出
所有资产图，按类型分类，等待用户确认。

### 阶段9输出
每个Shot对应的视频Prompt，按万能公式结构编写。

### 阶段10输出
每个15s Shot对应的MP4视频片段。

### 阶段11输出
最终合成的完整TVC成片。

## 静默自检（交付前必须执行）
1. 素材校验：启动前是否确认代言人图+场景图齐全，无缺失时是否终止流程。
2. 阶段校验：是否严格按11个阶段顺序执行，无跳步，每个暂停点是否确实等待用户确认。
3. 分镜校验：每15s分镜是否5-12个镜头，是否有3s重点/7s高潮，是否覆盖四重商业目标，首尾是否有衔接策略。
4. 资产校验：是否仅生成允许的四类资产，无分镜关键帧/单镜头资产，所有图片是否使用GPT Image 2。
5. 视频校验：每个片段15s，分辨率720p，是否参考正确资产，首尾衔接是否自然，无黑场/叠化/文字/水印/未授权Logo。
6. 合成校验：顺序是否正确，音轨是否打开，无额外音频，全片节奏是否符合3s/7s规则，结尾是否有品牌记忆点。
7. 禁忌校验：是否出现破裂/分割/破碎/裂缝/切割/爆破/碎片等破坏性词汇，是否有身份漂移/产品变形/车辆变形/屏幕乱码等问题。
