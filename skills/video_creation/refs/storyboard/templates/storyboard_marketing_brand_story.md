# 分镜图模板：营销转化 · 品牌故事分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以叙事方式讲述品牌起源、理念、价值观与代表人物故事的分镜图，强调情感共鸣与品牌调性，用故事承载品牌核心信息，可兼具广告片功能。
- **典型场景**：
  - 品牌形象片、周年纪念片、品牌价值观故事短片；
  - 电商/社交平台上的品牌自述故事视频；
  - 大促 campaign 中的品牌主片、企业文化宣传片。

## 2. 判定关键词与适用边界
- 典型触发词：`品牌故事`、`品牌理念`、`品牌起源`、`价值观`、`创始人故事`、`企业文化`、`品牌调性`、`情感共鸣`。
- 适用判定：
  - 用户希望“讲一个关于品牌/创始人/用户的故事”，核心目标是建立品牌记忆和情感链接，而不是逐条讲产品参数；
  - 有明确品牌名称与 Slogan，希望通过故事呈现品牌调性（温暖、专业、真实、年轻等）。
- 不适用场景：
  - 主要目标是带货转化、详细说明产品卖点 → 优先归为“产品讲解分镜图”或“痛点-解决方案分镜”；
  - 没有品牌信息，只是普通剧情短片 → 归为“剧情分镜表”；
  - 只想列出品牌历程时间线、无具体故事画面 → 更适合信息图或 PPT，而非分镜图。

## 3. 分镜结构建议
- **推荐宫格数**：9–12 格，适合完整讲述一个简短品牌故事；重要 campaign 主片可用 16 宫格。
- **结构骨架**（品牌叙事三幕式）：
  1. 起点：品牌起源/洞察（2–3 格）——呈现时代背景、创始人或代表用户的困境/发现；
  2. 发展：品牌行动/解决方案（4–6 格）——展示品牌如何回应这一洞察（产品、服务、行为），强调价值观在行动中的体现；
  3. 收束：价值观升华与未来愿景（2–3 格）——用意象或群像画面收束故事，突出 Logo + Slogan + 核心主张。
- **画幅建议**：
  - 用户已指定画幅时照用；未指定时品牌故事片默认 16:9 横版，适配大屏和各类平台。
- **规划方式**：
  - 先用一句话写出品牌故事核心：“因为 {世界的某个问题/人群的某种需要}，{品牌名称} 决定做 {行动}，让 {结果/愿景} 成为可能”，再把这句话拆进三幕结构；
  - 为每格明确“情感状态”（迷茫/发现/行动/改变/希望等），用光线与构图体现品牌调性（温暖、克制、高级、亲切等）。

## 4. 生图 Prompt（PE）模板

```text
你是一名品牌故事片导演兼分镜师，请为下述 {品牌名称} 设计一张 {宫格数} 宫格的“品牌故事分镜图”（用途类型 = 品牌故事分镜），整体画幅为 {画幅比例说明，如“16:9 横版品牌故事片”或“9:16 竖屏品牌故事短视频”}。

【品牌信息】
- 品牌名称：{品牌名称}
- 品牌品类与所属行业：{如咖啡品牌/家居品牌/科技公司/公益机构等}
- 品牌 Slogan 或核心主张：{一句话主张，如“让生活回到本质”}
- 品牌调性关键词：{如“温暖/极简/克制/年轻/真实/专业/科技感”等，3–5 个}

【故事设定】
- 故事视角：{创始人视角/用户视角/品牌拟人视角/旁白视角等}
- 时间与地点：{故事发生的时间段与主要城市/场景}
- 核心人物：{主角的身份与状态，如“刚毕业的年轻设计师”“陪伴家庭成长的品牌”等}
- 初始困境/洞察：{引发品牌行动的真实问题或观察}

【品牌行动与价值观】
- 品牌采取的行动：{具体做了什么，如“坚持使用友好材质”“为小城带来好咖啡”“用技术解决普通人的难题”等}
- 代表性场景：{2–4 个体现行动的场景，如工厂、门店、用户家中等}
- 想传达的价值观：{如“为普通人服务”“慢下来”“相信每个人的故事”等}
- 未来愿景画面：{理想中的世界或生活画面简要描述}

【分镜排布】
- 宫格数量：{宫格数，如 9/12/16 格}，按阅读顺序编号 B1–B{N}。
- 推荐结构：起点（起源与洞察） → 发展（品牌行动与改变） → 收束（价值观升华与愿景），末格固定包含 Logo + Slogan。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 B1 到 B{N} 的分镜要点（每格的场景、人物与品牌信息），供用户确认；确认后再按以下格式，为每格写出详细中文分镜说明：
1. B1：
   - 场景与人物：{起始时代/地点与主角状态}
   - 情绪与洞察：{主角面对的困境或观察到的问题}
   - 旁白/文字：{一句引出品牌故事的旁白或字幕}
2. B2：
   - 场景与人物：{品牌行动的第一步或决定时刻}
   - 行动与情绪：{品牌或主角做出选择的画面}
   - 旁白/文字：{与价值观相关的短句}
……
直到 B{N}，确保故事起承转合完整，最后 1–2 格同时呈现 Logo、Slogan 与价值观意象（如城市夜景、群像微笑等），形成情绪收束。

【画幅与风格约束】
- 画面比例：{16:9 / 9:16}，默认主版本采用 16:9 横版以适配品牌故事片与大屏播放。
- 画风：{电影感写实/高级棚拍/插画故事片/3D 叙事等}，整体光影和调色符合品牌调性（一致的色温与对比度）。
- 主角外观、服装与品牌空间（店铺/工厂/服务场景）在全片保持一致，禁止中途更换风格或空间设定，避免割裂感。
```

## 5. 一致性与避坑
- 品牌故事首要任务是讲清“为什么存在”与“相信什么”，不要在中段塞过多具体促销信息，避免从故事片变成硬广告。
- Logo、品牌名与 Slogan 的呈现位置要统一规划：通常在片头弱露、片尾强化；避免每格都出现 Logo 导致审美疲劳。
- 主要人物的外观与空间设定跨格必须一致，尤其是创始人或代表用户形象，避免不同镜头看起来像不同人。
- 品牌色（主色调）在全片保持一致，仅在不同段落做强度变化（稍暖、稍冷），不要出现完全不同的调色方案。
- 若故事涉及真实单位或公共符号（政企、公益组织），需在 plan 中引用 creative/civic-promo.md 的约束，不让模型直接生成敏感符号，而是通过意象或留白交由后期叠加。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”“剧情分镜表”“影视导演镜头表”等营销相关执行模板：
  - 在概念与分镜阶段，可先按“剧情分镜表”的三幕式结构写出品牌故事文字分镜，再根据需要选择是否添加镜头参数（若为高规格广告，按“影视导演镜头表”补充景别/机位/运镜）；
  - 将最终分镜图归类为营销用途中的“品牌故事/品牌主片”，在视频 Prompt 中使用产品讲解视频模板的输入字段（分镜图 + 参考图 + 目标画幅 + 模型）但重点填充“品牌故事与价值观”而非具体卖点列表。
- 视频生成时推荐：
  - 将 B1–B{N} 中的关键格（起点洞察、品牌行动的高光瞬间、收束价值观意象）作为参考帧传入，锁定主角造型与品牌空间光影；
  - 使用 seedance_2.0_fast 做整体探索，定稿阶段视项目规格选择 seedance2.0_fast_vision 或 seedance2.0_direct，以提升画面质感和统一调色。
- 镜头节奏建议：前 20% 时长建立背景与洞察，中间 50–60% 展开品牌行动，最后 20–30% 用相对舒缓的镜头与音乐收束价值观与愿景，避免高潮后戛然而止。
- 若品牌故事片同时肩负电商转化任务，可在 plan 中叠加 creative/marketing-ad.md 的结构类型（如“情感叙事型广告”），并在结尾 1–2 镜追加可落地的 CTA（如品牌官网、主力产品画面），但不要破坏整体叙事与调性。
