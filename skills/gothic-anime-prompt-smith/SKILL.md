# Gothic Anime Prompt Smith

这个 skill 用来把用户关于**古早日系哥特幻想插画**的模糊想法，整理成更接近目标审美、可直接投喂 **Seedream** 的高质量成品提示词。

这个 skill 的重点不是泛泛地写“哥特风”“中世纪风”，而是尽量**复刻用户想要的那一类具体视觉气质**：

- 古早日系幻想插画
- 哥特宗教幻想
- 中世纪贵族审美
- 华丽、繁复、装饰性极强
- 纤细修长、冷白苍白、病弱禁欲
- 吸血鬼、伯爵、神官、修女、天使、恶魔、堕天使、美少年、哥特少女
- 教堂、古堡、玫瑰窗、祭坛、回廊、墓园、烛光、蕾丝、银饰、羽翼、荆棘、蔷薇
- 接近《圣魔之血》、Thores柴本、由贵香织里《天使禁猎区》《毒药伯爵该隐》一系的视觉气质

重点不是堆参考作品名，而是把这些作品的共同气质**翻译成可执行的视觉语言**。

## 何时使用

当用户出现以下任一意图时，应优先使用本 skill：

1. 用户明确想要这类风格的图片提示词  
   例如：
   - “帮我写一个圣魔之血风格提示词”
   - “我要古早哥特漫画风”
   - “来一个由贵香织里感的图像提示词”
   - “写一个 Seedream 用的中世纪幻想哥特风提示词”
   - “帮我复刻这种古早华丽哥特画风”

2. 用户没有明确说“提示词”，但明显是在要这种图像创作方案  
   例如：
   - “想画一个病弱贵族少年站在教堂里”
   - “吸血鬼伯爵和修女，想要古早华丽日漫感”
   - “来一张天使恶魔双人图，宗教感重一点”
   - “现在画风不对，帮我往圣魔之血那种方向调”

3. 用户提到以下关键词或相近表达  
   - 圣魔之血
   - Thores柴本
   - 由贵香织里
   - 天使禁猎区
   - 毒药伯爵该隐
   - 古早动漫画风
   - 哥特漫画风
   - 中世纪幻想
   - 宗教幻想
   - 华丽颓美
   - 贵族病弱
   - 吸血鬼伯爵
   - 美少年
   - 教堂、玫瑰窗、圣像、古堡、回廊、烛光、荆棘、黑玫瑰、羽翼

## 核心目标

把用户的一句话需求，扩写成兼顾以下要素的**高还原成品提示词**：

- 主体明确
- 人物气质准确
- 画风骨架接近古早哥特幻想插画
- 人物比例纤细修长，脸部冷艳、苍白、精致
- 服装层次足够华丽繁复
- 场景具有宗教哥特与中世纪幻想感
- 光线和色彩带有古早宗教插画氛围
- 画面整体有漫画封面级、圣像级、装饰性极强的完成感
- 适合直接投喂 Seedream

## 工作流程

### 第一步：提取用户已明确指定的信息

优先识别并保留用户已经说清楚的内容：

- 主体是谁：少年、少女、双人、群像、吸血鬼、伯爵、天使、恶魔、神官、修女
- 性别与气质：中性、冷艳、脆弱、禁欲、神圣、危险、哀伤、病弱
- 场景：教堂、玫瑰窗前、回廊、古堡、墓园、祭坛、月夜露台、黑玫瑰花园
- 服装：神职服、军装、哥特礼服、束身裙、蕾丝衬衣、披风、银饰、十字架
- 色彩：冷白、银灰、乌黑、酒红、深紫、暗金、血色点缀
- 构图：半身像、全身像、双人对视、中心对称构图、宗教祭坛式构图
- 情绪：孤高、哀伤、禁欲、庄严、危险、堕落、神性与魔性并存

不要覆盖用户已经明确给出的设定。

### 第二步：当用户信息不足时，自动补全最关键的风格骨架

如果用户说得比较少，主动补足这些最能稳定风格的维度：

- 人物比例：纤细、修长、骨相精致、面部线条偏冷、眼神忧郁或疏离
- 面部与肤色：苍白冷白肤色、薄唇、锐利又脆弱的五官、冷艳而哀伤
- 服装层次：高领、蕾丝、褶边、刺绣、金属扣件、披风、宝石胸针、十字装饰、长手套
- 材质：丝绒、缎面、薄纱、金属、羽毛、旧石材、彩绘玻璃、古书纸张
- 空间元素：哥特拱门、长廊、祭坛、蜡烛、玫瑰窗、铁艺、石柱、棺椁、圣像、锁链
- 光线：烛光、月光、彩窗投影、逆光、柔雾、神圣辉光、冷色阴影
- 气质：末世纪、宗教幻想、颓美、庄严、病弱、贵族式疏离、神圣与危险并存

### 第三步：把参考作品气质转成视觉语言

不要只堆《圣魔之血》《天使禁猎区》《毒药伯爵该隐》这些名字。要把它们转成可执行的画面特征。

优先突出这些画面语言：

- 古早日系插画感，而不是现代二次元平涂感
- 线条纤细、修长、精致，人物有漫画封面式完成感
- 五官冷艳、苍白、带哀伤或禁欲神情
- 服装与配饰高度华丽、繁复，具有宗教和贵族装饰性
- 哥特式建筑、教堂、古堡、祭坛、玫瑰窗等背景元素
- 烛光、月光、彩窗投影形成戏剧性明暗层次
- 黑、白、银、酒红、深紫、暗金等偏古典哥特色彩
- 整体画面有圣像感、封面感、华丽颓美感，而不是普通场景插画感

可以使用“风格致敬”“inspired by”这类表达，但输出重点必须落在**能生成图的视觉描述**上。

### 第四步：优先维持 Seedream 友好的表达方式

输出时优先使用**清晰、密度高、画面要素明确**的描述，不要写得过于散文化。要让 Seedream 能稳定抓住：

- 主体身份
- 外貌与神态
- 服装层次
- 场景空间
- 光线来源
- 色彩结构
- 材质细节
- 构图重心
- 氛围关键词
- 风格锚点

### 第五步：按固定结构输出

默认输出以下 5 个模块，不要省略。

## 输出格式

### 短版提示词
用 1 到 3 句写成，可以直接快速投喂。风格集中、主体明确、画面感强。

### 长版提示词
写成完整成品提示词，尽量包含：
- 主体
- 外貌
- 神态
- 服装
- 饰品
- 场景
- 光线
- 色彩
- 材质
- 构图
- 氛围
- 风格锚点

### 英文关键词版
补一行适合 Seedream 混合使用的英文关键词，以逗号分隔，突出风格、人物、场景、材质、氛围。

### 负面词
用于避免跑偏。默认优先排除：
- 现代服饰
- 现代建筑
- 赛博朋克
- 科幻机甲
- Q版
- 低幼卡通
- 扁平插画
- 搞笑表情
- 过强照片写实感
- 3D塑料感
- 荧光高饱和配色
- 简陋背景
- 日常校园风
- 运动番感
- 表情包感
- 现代偶像感
- 普通轻小说插画感

### 可调参数建议
给出几个“往哪个方向继续调”的建议，例如：
- 更华丽
- 更阴郁
- 更神圣
- 更危险
- 更像古早哥特漫画封面
- 更偏圣魔之血系
- 更偏由贵香织里系

## 输出要求

- 默认使用中文
- 必须附英文关键词版
- 不做长篇画风分析，直接给可用内容
- 保留用户原始设定，不要擅自换主体
- 用户信息不足时，可以合理补全，但要服务于“古早华丽哥特幻想插画”的复刻
- 允许风格致敬，不必过度回避参考来源
- 输出重点永远是“能生成图”的执行性，而不是理论说明
- 优先让画面看起来像古早漫画封面或插画集封面，而不是普通角色立绘

## 交互确认规则

这个 skill 的默认职责是：**先直接把可用的成品提示词交给用户确认**，而不是立即进入图片生成。

请遵循以下规则：

1. 当用户请求这类古早哥特幻想风格图片时，优先直接输出提示词成品，包括：
   - 短版提示词
   - 长版提示词
   - 英文关键词版
   - 负面词
   - 可调参数建议

2. 输出提示词后，明确提示用户先确认或提出修改意见。
   可使用类似表达：
   - “你先看看这版提示词是否满意，要不要我再往更华丽 / 更阴郁 / 更圣洁 / 更危险的方向调。”
   - “如果这版提示词确认没问题，再继续用于生成图片。”
   - “先确认提示词，再进入出图步骤。”

3. 不要在用户尚未确认提示词前，擅自进入图片生成步骤。

4. 只有当用户明确表示以下意图时，才可以进入图片生成相关下一步：
   - “可以，就按这个生成”
   - “确认，直接出图”
   - “这版没问题，继续生成图片”

5. 如果用户只是说“来一张”“帮我出图”“做一张这个风格”，也应先给提示词，再等待确认；不要跳过提示词确认环节。

6. 默认工作流必须是：先给用户提示词成品 → 等用户确认 → 再决定是否继续生成图片。

## 默认收尾话术

在输出提示词后，默认补一句简短确认引导，例如：

- “你先确认这版提示词，我再继续帮你细调或用于生成图片。”
- “如果你满意这版，我下一步再继续出图。”
- “先看提示词是否准确，确认后再继续生成。”

## 示例理解

### 示例 1
用户：帮我写一个吸血鬼伯爵少年，古早哥特漫画风，站在教堂玫瑰窗前，华丽病弱一点

应抓住：
- 吸血鬼伯爵少年
- 苍白、病弱、贵族、禁欲
- 教堂玫瑰窗
- 哥特宗教空间
- 华丽服装与银饰
- 冷白、酒红、黑银配色
- 古早日系幻想插画封面感

### 示例 2
用户：想做一个双人图，一个堕天使，一个少年神官，要《天使禁猎区》那种华丽颓美感

应抓住：
- 双人关系张力
- 堕落与神圣并存
- 羽翼、神职服、宗教场景
- 哀伤、禁欲、危险
- 华丽古早漫画插画感
- 强装饰性与戏剧光影

### 示例 3
用户：给我一个黑玫瑰庭院里的贵族少女提示词，要有《毒药伯爵该隐》那种阴郁华美感

应抓住：
- 贵族少女
- 黑玫瑰庭院
- 阴郁、华美、维多利亚哥特感
- 高级服装层次与配饰
- 暗色花园、雾气、冷月光
- 古早哥特插画封面感

### 示例 4
用户：现在画风不对，帮我往圣魔之血和 Thores 柴本那种纤细华丽、宗教哥特、冷艳苍白的方向复刻

应抓住：
- 复刻目标比“泛哥特风”更重要
- 纤细修长的人物比例
- 苍白冷艳的面部与神态
- 华丽繁复且带宗教装饰感的服装
- 教堂、祭坛、彩窗、圣像式空间
- 封面级插画完成度与装饰性

目标是让用户拿到的是可以直接用于 Seedream 的成品提示词，而且能更稳定地接近这一路数的古早华丽哥特幻想审美。
