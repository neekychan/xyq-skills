# 分镜图模板：知识讲解 · 文案逐句可视化

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：把一段知识讲解文案或口播稿，按句子/段落拆分为一格一画面的**逐句可视化分镜**，每格只负责讲清楚一个知识点或一句话。
- **典型场景**：
  - 心理情感文案、健康养生、科普短文，“为这段话配一组画面”。
  - 课程内容浓缩版，将课堂/文章中的关键句逐句变成画面。
  - 文案驱动的视频脚本，已有完整文本，希望自动拆成可视化节奏。

## 2. 判定关键词与适用边界
- 典型触发词：`逐句可视化`、`按每句话出一格`、`这段文案配画面`、`口播稿分镜`、`每句话一张图`。
- 适用判定：
  - 用户已经提供**连续的讲解文案/口播稿/文章段落**，并强调“按句子或段落拆分画面”。
  - 核心目标是让观众**看懂文案内容**，而不是看复杂剧情或动作。
- 不适用场景：
  - 完全没有现成文案，只给主题让 AI 自己写文案 → 优先用通用“教学/科普分镜”模板。
  - 产品卖点为主、知识只做背景 → 优先走“产品讲解型”模板。

## 3. 分镜结构建议
- **推荐宫格数**：与有效句子/段落数接近，常见为 6/9/12 格。
- **拆分原则**：
  1. 一格只承载一句关键话或一个知识点，禁止一格塞多句长文。
  2. 开头 1–2 格用于提出问题/场景，引出主题；中段多格依次解释；末尾 1–2 格用于总结/行动建议。
  3. 长句可按逻辑断点拆成两格：“问题提出”一格，“解释/解决方案”一格。
- 每格结构：**标题 + 核心句 + 示意画面**，其中核心句可脱水成 10–20 字短句。

## 4. 生图 Prompt（PE）模板

```text
你是一名知识可视化导演，请将下列讲解文案按“每句话/每个自然段一格”的方式拆解成 {宫格数} 宫格分镜图（文案逐句可视化），整体画幅为 {画幅比例说明，如“9:16 竖屏课程短视频”}。

【输入文案】
{粘贴的完整讲解文案/口播稿}

【总体设定】
- 主题：{如“如何科学护肤/高铁安全科普/儿童财商启蒙”等}
- 目标受众：{如“小学生/职场新人/备考学生/中老年”等}
- 画风与色调：{如“扁平信息图/2D 教学插画/3D 教具场景”等 + 主色调说明}

【拆分与布局要求】
- 先将文案拆解为 N 个“核心语句”，每句不超过 20 字；
- 选取其中 {宫格数} 句作为可视化分镜，每格对应一句话；
- 若句子过长，可按逻辑断点拆成两格，分别可视化“问题”和“解释”。

【分镜输出格式】
1. 列出“文字分镜列表”（推荐先输出给用户确认）：
   - L1：{第一句核心文案}
   - L2：{第二句核心文案}
   - …
   - L{N}：{第 N 句核心文案}

2. 在用户确认后，为 L1–L{N} 逐格写出分镜说明：
   - 标题：{4–10 字标题，概括本格知识点}
   - 核心文案：{该格对应的短句，保持用户原文含义}
   - 画面内容：{用一个比喻/场景/示意图可视化这句话，如“把毛孔比作滤网”等}
   - 信息层次：{说明画面中“文字区/图示区/人物区”的占比，确保易读}

【画幅参数】
- 宫格数量：{宫格数，如 9/12}，按顺序编号 L1–L{N}；
- 画幅比例：{9:16 / 16:9 / 1:1}，默认 9:16 面向竖屏短视频；
- 完成度：{草稿/精修/成品级渲染}，教学/科普类默认精修级。
```

## 5. 一致性与避坑
- 保证**每格只有一个知识点或一句核心话**，不要把多句长文挤在一格里。
- 画面设计必须与文字含义对应，避免“文字讲 A，画面画 B”的错配。
- 全部宫格的视觉风格、配色与版式保持统一，避免像拼贴多套模板。
- 为文字预留足够空间：字号≥画面宽度的 1%–1.3%，行数控制在 1–3 行内。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“科普演示分镜图”一节：
  - 先用本模板将文案拆分并可视化为多宫格分镜图；
  - 视频阶段以分镜图为主参考，重要知识点镜头附加 PPT/板书/示意图参考；
  - 镜头切换节奏严格跟随句子顺序，避免跳过或重排文字信息。
- 适合需要**文案内容强保真**的场景（品牌宣言、政策解读、专业科普等），确保视频每一格都能在静止状态下被观众读懂。
