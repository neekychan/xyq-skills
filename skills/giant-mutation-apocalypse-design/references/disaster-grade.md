# 写实灾难调色与毒荧光变异标记（Disaster Grade）

在用户想要「真实感都市废墟、冷调压迫、烟尘火光、毒荧光变异点睛」的电影灾难片质感时读取（这套底片提炼自参考片的都市巨物变异视觉语言）。它不是普通降饱和、加绿滤镜或全局压暗；它同时控制明度、色相、大气透视、尺度质感与变异荧光的点睛配比。它只补充调色，不改变 `apocalypse-visual-grammar.md` 中的巨物造型与画面视觉方法。

## 视觉判断

这套「真实灾难感」来自四件事同时成立：世界是**写实电影质感的真实现代都市**（不是塑料 CGI）；主调是**冷调压迫的蓝灰/青黑废墟色**，但保留真实肤色与材质活气；**烟尘与火光**拉开大气层次、给冷调一点有动机的暖；**变异荧光**只在暗处点睛（默认毒性青绿），像一条贯穿人与巨物的预警线。因此它看起来真实、压迫、有体量，而不会糊成滤镜或塌成塑料游戏 CG。

| 常见误区 | 为什么不像 | 替代方法 |
| --- | --- | --- |
| 全局降饱和 + 绿滤镜 | 会脏、平、像廉价丧尸片 | 只压环境纯度，保留真实肤色、火光暖调与点睛的变异荧光；绿只作变异荧光，不作全局偏色。 |
| 全局压暗成黑 | 会闷、脏、丢体量 | 把黑抬成冷石墨/蓝灰，用烟尘与大气透视拉层次，暗部仍见废墟结构。 |
| 塑料感 CGI 巨物 | 像游戏预渲染，没有真实材质 | 给巨物写实的湿甲壳/软体/结晶材质与真实次表面，落进真实光照与烟尘。 |
| 巨物悬浮无尺度 | 像贴图模型 | 前景永远放真实的人/车/楼作参照，低角度 + 大气透视把体量压出来。 |

## Look Lock：六项同时锁定

1. **黑位**：大面积暗部是冷石墨、蓝灰、湿沥青；仍可看见废墟结构、烟尘形状与楼体轮廓，不塌死黑。
2. **中间调/环境**：偏冷的蓝灰、青灰、废墟混凝土色；低饱和但不灰死，保留真实材质纹理。
3. **肤色**：幸存者肤色保留真实血色与灰粉底，被灰尘血污与疲惫覆盖，像真实灾难中的活人，不做美颜。
4. **烟尘/大气层**：近景清晰；中景有火场烟尘与灰雾拉开层次；远景更淡但不消失。烟尘是有体量的灾难大气，不是梦幻虚化。
5. **火光/暖点**：火场、爆燃、探照灯给出克制的暖橙/暖冷点缀，只作局部动机光与深度，不反向污染冷调主色。
6. **变异荧光**：默认毒性青绿（或蓝紫/赤红/惨白），只在暗处的变异组织、甲缝、感染者眼/血管上作细小点/线状发光，像一条贯穿人与巨物的预警线；绝不大面积泛滥成霓虹。

## 色光分支

| 状态 | 画面控制 | Prompt 短语 |
| --- | --- | --- |
| 灾难现场/外景 | 冷调蓝灰环境、烟尘灰雾、火光暖点、探照灯冷白 | `冷调蓝灰的末日环境光，弥漫有层次的火场烟尘，克制的火光暖点，写实电影质感` |
| 变异前/日常 | 真实暖调日常，自然日光或暖木色实用光，与灾难冷调形成落差 | `真实温暖的日常光，自然通透日光，暖木色实用光，写实生活质感，无棚拍` |
| 变异/感染显现 | 冷暗底不变，暗处点亮变异荧光作预警 | `暗处点睛的毒性青绿生物荧光，脉动的变异标记，无霓虹泛滥` |

## 固定 Prompt 模块

将这段原样加在每条 prompt 的光色块中：

```text
冷调蓝灰与低饱和青黑的末日调色，
抬起但保留结构的冷石墨阴影，
有层次的火场烟尘与灰雾大气透视，
克制的火光暖点与探照灯冷白作动机光，
真实血色的、被灰尘覆盖的活人肤色，
暗处点睛的毒性青绿变异生物荧光，
写实电影质感，真实材质与次表面，主体清晰而中远景被烟尘轻微吞没，
真实尺度参照下的体量压迫
```

并附加：

```text
--排除 全局绿滤镜偏色，脏灰塌黑，塑料感 CGI，橡胶怪兽，卡通渲染，霓虹赛博朋克，干净科幻界面，梦幻虚化，美颜肤色，悬浮无尺度的巨物模型，粗糙胶片颗粒
```

## 校色顺序

先生成三张不含剧情的校色卡：

1. **末日空场景**：被摧毁的街区/废墟、烟尘、火光和一处画内光；检查黑位、大气层次与冷暖配比。
2. **尺度对照**：巨物局部（一条腿/一只钳）+ 前景真实的人/车作参照；检查体量压迫与写实材质是否成立。
3. **变异标记特写**：一处变异组织或感染者的眼/皮肤 + 点睛的变异荧光；检查荧光是否点睛而非泛滥、材质是否真实而非塑料。

仅当三张都通过，才将同一 Look Lock 复制到巨物、角色和场景。之后每次只改变镜头、动作、尺度或变异呈现层级之一，不同时改色温与材质。

## 跑偏纠正

| 若结果… | 先这样改 |
| --- | --- |
| 太绿、太脏、像廉价丧尸片 | 删除全局绿偏色；把绿收回到只做变异荧光点睛；加入 `冷调蓝灰`、`真实血色肤色`、`克制火光暖点`。 |
| 太暗、闷、丢体量 | 把黑抬成 `冷石墨/蓝灰`，加入 `烟尘大气透视` 与 `前景真实尺度参照`，让暗部仍见废墟结构。 |
| 巨物像塑料模型/游戏 CG | 加入 `写实的湿甲壳/软体/结晶材质`、`真实次表面`、`落进真实光照与烟尘`；移除塑料高光。 |
| 巨物悬浮、没有大小感 | 强制前景放 `真实的人/车/楼作尺度参照` + `低角度仰拍` + `大气透视`。 |
| 太像赛博/通用 AI 恐怖 | 移除 `霓虹`、`紫青光污`、`干净科幻`；回到真实都市地点、写实材质、烟尘火光与点睛变异荧光。 |

## 通过标准

缩略图里先读到的是**真实、压迫、正在崩塌的都市与有真实体量的巨物**，而不是绿黑滤镜、塑料怪兽或霓虹；放大后仍看得见混凝土裂纹、烟尘层次、火光反射、湿甲壳与点睛的变异荧光细节，巨物落在真实尺度与真实光照里。目标是"写实灾难压迫，冷调但不脏、荧光点睛而不泛滥"。
