# 图片资产与逐镜视频提示词模板

先读 [风格知识库](style-guide.md)，分镜和空间信息分别来自 [镜表](storyboard-design.md) 与 [空间连续性](spatial-consistency.md)。本文件的每个 `text` 代码块都是完整视觉 prompt 模板，已写入固定前缀；填写方括号后交付，删除不适用条目。不能把模板名称、镜号或 Markdown 围栏一起塞入工具的 prompt 字符串开头。

## 通用写作与提交规则

- 固定中文前缀永不翻译。正文默认中文，也可按用户或工具要求用英文，负向限制置尾或独立字段。
- 用可渲染的颜色、材质、轮廓、构图、位置、光源、动作、表情替代单独的“有氛围/好看”。情绪词可辅助语气，不能代替可见表演。
- 使用三维角色造型语言描述面部、肤质、衣料，避免用真人摄影或过度解剖质感拉向纯写实。保留人物年龄、骨相和身份差异，不把老人变成少年。
- 害怕写“目光骤停、唇微张、指尖收紧”，愤怒写“眉心收紧、目光压向对方、手掌攥紧”。不要用“面色惨白、面如死灰、青面獠牙”作为情绪比喻；若剧情确实包含化妖等外貌变化，建立显式状态变体。
- 世界设定和机位推导写在镜表；prompt 描述从当前机位实际能看见什么。画外关键物仅在必要限制中简记不可见，不详细描绘来诱发乱入。
- 每张参考图标记实际来源、素材 ID 和用途。本文“绑定图像 A”等为写作标记，提交时映射为真实工具附件/引用语法，不能把自造的 `<<<image_1>>>` 当作所有工具通用 API。
- 参数字段中的比例、尺寸、时长与正文一致。工具不支持某参数时记录实际值，不通过在文本里声称“2K/24fps”冒充实际规格。

## 1. 角色母版设定图

目标 2K 级、默认 16:9，生成两张图，一张角色面部特写试光镜头图（非白底图）；一张角色全身立绘面部特写+全身三视图。首版文生图；有用户身份图时绑定 `identity`，按本风格生成合格母版。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作同一位 [时代/世界观、题材] 角色的统一设定板。
[人物] [姓名/角色ID]，[年龄感、身份、性别与体态]。[脸型、眉眼流线、鼻唇轮廓、发际线和识别点]；[已锁定肤色，无其他设定时采用暖白底色]，细腻玉肌与柔和次表面散射，五官具有东方动画角色的清晰轮廓，保留年龄和身份特征。
[发型与服饰] [发型、发色、符合角色的头饰或头部装备，无则省略]；[符合本项目时代的内搭、外层、下装、鞋、腰带、配饰的具体形制]；[2—3 色主调]；[棉布/针织/丝绸/皮革/金属/复合材料等适用材质]；[与身份相符的纹样、工艺与新旧状态]。三视图的衣层、配饰数量和位置一致。
[表情与体态] [常态眉眼、唇角和目光]，[全身中性站姿与手部姿态]。面部特写和全身图保持同一张脸、同一年龄、同一体型与同一造型。
[排列] 左侧约 1/3 为清晰面部特写，右侧约 2/3 为正面、侧面、背面三张全身站姿，头饰到鞋完整可见，彼此不遮挡。
[展示光] 干净白底，柔和均匀照明，精细发束与丝绸反光清晰，轻雾化和柔光仅柔化高光，不遮脸、不淹没纹样，保留三维体积。
[限制] 单一角色的多视图，不增添其他角色；服饰与器物符合已锁定的时代/世界观，无随机文字、标签、logo、水印；不改变已锁定的脸型、肤色与发色。
```

角色图的表情保持利于识别，战损、落泪、易容等另建状态，不让单张母版同时承载互相冲突的状态。

## 2. 场景图

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作同一处 [时代/世界观、题材] 场景的四向空间设定板。
[场景] [场景ID、名称、室内/室外、规模与结构]。[明确门、窗、台阶、固定家具/设备和地标在世界空间的相互位置]。
[材质与工艺] [石材/木材/混凝土/玻璃/金属/织物等适用材料、纹理、光泽和新旧状态]；[适合此场景用途与世界观的工艺、接缝、装饰和结构细节]；[统一主色与辅色]。
[人群] [非群像场景：空场，无人物；群像场景：只保留对应规模、符合时代与职业的服饰、固定分布和活动状态的背景群众，三维风格统一、不抢主景。二选一后删除另一项。]
[展示光] 柔和均匀的高亮低对比照明，暗部保留细节，轻雾透明不遮挡地标，柔光高光不过曝；避免强方向投影和刺眼光束。此图用于结构识别，剧情具体光位另按场景光影元数据进入视频。
[限制] 建筑与器物符合已锁定的时代/世界观，无随机文字、格内标签、logo、水印；不把固定家具拆成孤立道具特写，不生成四套不同的房间。
```

展示板外部可加方向说明，不依赖生图模型生成正确文字。

## 3. 关键道具图

适用于手持/交互物件，固定家具仍归场景。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作 [时代/世界观] 关键道具 [道具ID、名称] 的清晰资产图。
[形制] [长度、宽度、厚度或与手掌的比例]，[完整轮廓、结构、柄部/系绳/扣件位置]。
[材质] [玉石/金属/木材/纸张/玻璃/塑料/复合材料等实际材质]，[颜色、透光或反光特性、纹样、磨损与工艺]。
[状态] [完整/断裂/展开/封合/沾水等本次唯一状态]。若正反两面有关键差别，以一致比例并列展示；不能把不同状态混为同一件母版。
[构图与光线] 干净白底，主体完整无遮挡，柔和均匀展示光，保留精细三维结构与柔和高光，轻雾化不遮挡轮廓和关键识别点。
[限制] 只展示指定道具，无人物、无场景；物品形制符合已锁定的世界观；无随机文字、logo、水印。剧情必须识读的印文、信件或屏幕文字留待后期准确制作。
```

## 4. 同一角色换装或局部编辑

绑定已验收母版为 `identity`，服饰参考另标 `costume`，不添加风格图。正文明确保留范围、改变范围和本次造型状态。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。依据绑定的角色母版 [素材ID]，制作同一角色 [角色ID] 的 [新造型ID/局部编辑目标]。
[保留] 同一脸型、五官比例、年龄感、皮肤底色、体态、身高比例和标志性身份特征；[本次必须保留的服饰或配饰细节]。
[仅修改] [具体衣层、发型、妆容、配饰或指定区域]，替换为 [符合本项目世界观的具体形制、材质、颜色、纹样与状态]；不要修改本次范围外的部分。
[参考职责] 母版用于身份和造型连续性，[可选服饰参考ID] 仅用于衣物结构；渲染风格以开头固定文本为准。
[构图] [沿用母版面部特写+三视图，或按本次编辑明确指定的构图]。白底柔和均匀展示光，三维细节清晰，轻雾与柔光不遮挡识别点。
[限制] 不换人、不变年龄、不混入其他风格；符合已锁定的时代/世界观，无随机文字、logo、水印。
```

## 5. 用户已有素材转为本风格

先看原图，列出要保留的身份/结构及渲染差异。只要求换渲染时，保留原有服装、手机、汽车、建筑等内容，不顺便更换时代。只有用户明确要求改世界观时，才列出需要替换的内容并在授权范围内执行。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。将用户提供的 [素材ID] 转为本国漫3D渲染风短剧的 [角色/场景/道具] 资产。
[保留内容] [逐项写出人物脸型五官、年龄肤色、发型轮廓、衣物结构，或场景门窗布局、物件结构尺寸等适用特征]。
[转化] 采用精细三维建模、温润材质、动画化轮廓、柔和高亮低对比光影；保持本次目标的实际身份与结构。原图仅用于内容与身份参考，不沿用原图的摄影、绘画或其他渲染风格。
[本次内容变更] [只填写用户明确允许改变的服饰、器物或世界观内容；仅换渲染则删除此段]。
[输出布局] [角色设定板/同一场景四视图/道具白底图/指定单画面]，保持对应模板的构图与可读细节。
[限制] 不改变保留清单中的身份与空间信息；不主动引入其他风格图；无随机文字、logo、水印，无未获准加入的元素。
```

## 6. 单镜首帧、尾帧或冻结关键帧

这一步把设定图转成**单一电影画面**，用于只接受单首帧的视频工具或需要精确控制的镜头。冻结瞬间只写当前姿态，不把整段动作写成一张连续漫画。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作镜头 [shot_id/cut_id] 的单一 [首帧/尾帧/关键时刻] 画面，画幅 [实际比例]。
[摄影机] [景别、机位所在侧、拍摄方向、构图与前后景关系]。
[主体] 角色 [角色ID+造型ID] 使用绑定身份图 [素材ID]，此刻 [明确站姿、头部角度、视线目标、双手和持物状态、可见表情]；[其他画中角色及其各自身份引用和姿态]。
[空间] 场景 [场景ID+状态ID]；[逐字继承固定世界光影基准]。从此机位可见 [地标、屏幕位置、角色背后实际背景]；[离场角色原位的画中状态]。
[参考职责] [身份图] 只锁角色与服饰，[场景方向图] 只锁布局，[合格前序帧（如有）] 只锁连续性；构图以本镜摄影机和所选冻结状态为准。
[限制] 一张完整单画面，无多宫格、无三视图、无漫画分栏；内容符合已锁定的时代/世界观，无字幕、随机文字、logo、水印，不出现时间序列的重复人物。
```

## 7. 单个生成片段的视频

写 prompt 前先有镜表、资产计划和逐机位空间描述。只交付提示词或制作方案时，可引用已明确标为待生成的资产 ID，并说明绑定与验收尚待执行；无需为了写作先生成媒体。真正调用视频工具前，必须完成本范围核心资产验收、实际绑定和参考帧筛选（用户明确跳过出图的例外按主文件）。优先使用有效角色图+场景方向图+所需道具；只能单首帧时绑定已生成的单镜关键帧。不要把参考板当首帧。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。[本片段必要的兼容色彩或材质补充，无则删除]
[摄影机] 镜头 [shot_id]，画幅 [实际比例]。内切镜 C01：[景别+机位+运镜+切换原因]；C02：[景别+机位+运镜]；[按实际镜数增减]。每个内切镜的方向、画面主体与机位关系清楚，动作与运镜节奏 [慢/迅速/停留等]。
[主体] 使用已绑定的 [角色ID+造型ID→身份图] 与 [道具ID→道具图]。C01：[谁先做什么，起势→执行→收势，具体表情变化、视线目标、手持物和身体状态]。C02：[延续前一状态或有因果的新行动]。[关键台词或主要动作完成后的表情/姿态余势]。若为 OS 时段，角色嘴唇保持不动，表情按 [具体变化路径] 推进；若为开口对白，只有对应说话者按台词开口。
[空间] 场景 [scene_id+状态ID]，[逐字继承固定世界光影基准]。C01 可见：[逐项背景地标、屏幕位置、人物层级与已离场位置状态]。C02 可见：[按新机位重新推导的背景和左右关系]。[必要的画外排除项]。参考 [场景图/方向图ID] 只锁定布局；[合格参考帧ID（如有）] 只锁定 [明确列出地标和角色状态]，不复制其景别、构图或运镜。画面与摄影机以本片段设计为准，世界布局保持一致。
[音频] 对白：[角色ID]：「[台词原文]」，[语气、停顿和声音身份ID]。内心 OS：[角色ID]：「[OS原文]」，使用同一声音身份，角色不动嘴。音效：[具体声源与动作落点]。无对应项则删除。若本次为独立配音方案，明确本片段生成无对白音轨，后期加入指定声音；不要同时要求原生对白和无声。
[禁止] 无背景音乐、无字幕、无文字叠加、无logo、无水印；不加入已锁定世界观排除的元素，不发生镜表之外的身份、服饰或道具状态漂移；镜表明确的换装、开合、翻面、递交、损坏等变化按动作与起止状态执行。不复制参考板的多宫格，不引入未在场人物。
[时长] [实际支持且不超过15秒的总时长]。按已核算的台词/动作节拍完成，不截断台词与收势。
```

四个核心内容段为摄影机→主体→空间→音频，固定前缀位于这四段之前，禁止与时长在后。没有 OS/对白时删除空项，不把所有示例条件同时提交。正文中的声音 ID 和片段内切镜能力按 [执行适配](execution.md) 映射，不能假定所有模型能原生执行。

时间规划在镜表中必须明确；模型支持时间段描述时可写 C01 0—4 秒等，但不能声称它会精确执行。对时间不敏感的工具以动作顺序和速度词为主，生成后按实测时长剪辑。一个片段内部的多段 beat 不等于多次调用。

## 8. 视频重生成、局部编辑或延长

通常复用上一次完整视频 prompt 并只修改必要字段；如果工具的编辑/延长接口要求独立指令，则使用下面完整模板。两条路径都必须前缀置首。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。对已有片段 [视频素材ID] 执行 [重生成/指定局部编辑/延长]，对应镜号 [shot_id] 与新版本 [version]。
[保留] [原片段中有效的角色身份、造型、道具、背景地标、世界光源、台词和运镜]。
[本次修改] [具体问题与目标变化，或从原尾帧继续的完整动作链]，其他已锁定内容保持一致。
[摄影机] [修改后完整景别、机位、运镜及各内切镜顺序]。
[主体] [修改后动作起势→执行→收势、表情/目光、持物和起止状态]。
[空间] [场景ID+状态ID与固定光影基准]；[当前机位可见背景]；[参考帧/关键帧ID仅用于已验收的连续性状态]。
[音频] [保留或修改后的精确对白/OS/音效，明确原生或独立音轨方案]。
[禁止] 无背景音乐、无烧录字幕、无随机文字、logo、水印或超出已锁定世界观的元素，不改变修改范围外的已确认内容。
[时长] [实际支持的片段或延长时长]；[与前后片段的接点和收势要求]。
```

未验收或风格失败的旧视频不能作为合格视频参考；默认从已验收资产重生成该镜，保留仍有效的文字设计。已验收源视频可按工具能力局部编辑或延长。延长后最终片段若超过 15 秒，按项目镜表重新登记分段/编辑范围，遵守工具实际限制。

## 自检

检查每条最终字符串从固定句开始；现代/科幻等题材未套入“禁现代”、古装、古建或古典台词的默认限制；所有可复制模板已填写，无“同上”和未绑定占位符；输入参考图的职责与来源明确；正文没有另一套冲突风格；设定板、单画面和视频的构图用途没有混用；原稿台词完整、OS 不动嘴、时间可容纳；空间逐机位正确；失败重试保留版本；实际工具参数与文本一致。
