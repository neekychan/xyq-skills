# 巨物科幻视觉资产生成器

> 本文件定义视觉资产阶段的生成顺序、元素图类型、模型选择、关键帧融合与连续性检查规则。所有机甲、怪兽、场景、道具必须先完成设计，确认后才能进入关键帧生成。禁止边生成视频边修改设定。

## 目录
1. 模型与工具选择（全局强制）
2. 生成顺序
3. 机甲元素图
4. 怪兽元素图
5. 参照物资产
6. 场景资产
7. 关键帧融合
8. 连续性检查

---

## 1. 模型与工具选择（全局强制）

**图片生成（TextToImage / ImageToImage）：**
- 首选模型：GPT Image 2，推荐分辨率 2K（支持 1K / 2K / 4K）
- 降级方案：当 GPT Image 2 生成失败时，切换至 Nano Banana 2(Gemini 3.1 Flash Image)，分辨率 2K。若该模型也失败，则停止该任务并告知用户，不得擅自更换其他工具路径。
- 所有元素图、参照物图、场景图、关键帧均遵循此优先级。

**视频生成（MultiModalToVideo）：**
- 唯一指定模型：Seedance 2.0，默认分辨率 720p（如用户明确要求 1080p 则遵从）。
- 每个镜头生成时，必须引用该镜头绑定的元素图片（机甲/怪兽/场景/道具）作为参考输入；仅在与前序镜头连续性极高时，额外加入前序镜头视频作为参考。

## 2. 生成顺序

机甲设定 → 怪兽设定 → 参照物设定 → 武器/装备设定 → 场景设定 → 关键帧融合 → 确认 → 进入分镜

## 3. 机甲元素图

每台机甲建立统一资产。输出：

**视图清单：**
头部正面、头部侧面、头部背面、全身正面、全身侧面、全身背面、眼部特写（暗/亮两种状态）、关节特写、装甲纹理特写、战损状态、全新状态、在维修状态下与工人尺度对比。

**固定内容：** 名称、高度、重量、配色方案、装甲材质、关节结构、眼窗形状/光源颜色、天线/特征结构、战损程度、发光元素位置与颜色。

**机甲摄影统一参数：**
Low-Angle Worship Shot, Industrial Background, Cold Lighting, 14–24mm Wide Lens, Deep Focus, Cinematic Realism

**表面状态规则（根据战损阶段动态调整）：**
- 全新状态：pristine metal finish, factory-fresh look
- 战损状态：weathered battle damage, oil stain, rust
- 维修场景：welding sparks

**禁止：** 商业摄影、CGI塑料感。

## 4. 怪兽元素图

每只怪兽建立统一资产。输出：

**视图清单：**
头部正面、头部侧面、全身正面、全身侧面、眼部特写（暗/亮）、荧光脉络分布图、口腔内部、皮肤纹理特写、尖刺/骨刺特写、与参照物尺度对比。

**固定内容：** 名称、高度、重量、皮肤材质、荧光脉络颜色与分布、眼眸发光颜色、攻击方式、血液颜色、尖刺位置。

**怪兽摄影统一参数：**
Low-Angle, Fog Background, Bioluminescent Glow, Deep Focus, Dark Tone, Cinematic Horror Realism

**禁止：** 卡通化、光滑皮肤。

## 5. 参照物资产

建立统一参照物参考：

| 参照物 | 完整状态 | 破碎状态 |
|---|---|---|
| 人类 | 正面/侧面/背面/工作姿态 | — |
| 渔船 | 完整 | 倾覆/破碎 |
| 货轮 | 完整 | 倾覆 |
| 汽车 | 完整 | 破碎 |
| 建筑 | 完整 | 碎裂 |
| 直升机 | 完整 | 被攥住 |

所有参照物记录：实际尺寸、破碎状态、与巨物的尺度比例。保持全片一致。

## 6. 场景资产

每个场景建立统一参考：

| 场景 | 变体 |
|---|---|
| 深海海面 | 暴雨/大雾/晴天 |
| 超高工厂内部 | 全貌/局部/维修平台 |
| 城市废墟 | 全景/街道/破碎建筑 |
| 海岸线 | 日出/暴雨/海啸 |
| 火山口 | 熔岩/蒸汽/黑暗 |

每个场景输出：大全景、中景、近景、地面视角、高点俯视、恶劣天气状态。保持统一色调和光线方向。

## 7. 关键帧融合

完成所有资产后，生成关键帧。每个关键帧必须融合：机甲/怪兽、参照物、场景、天气、光线、空间关系、镜头运动。

**关键帧要求：** 电影级构图、真实空间、真实比例、真实透视、真实光线、真实天气、真实受力痕迹。

**每张关键帧输出字段：**

```
用途：[建立尺度/揭示全貌/战斗冲击/...]
章节：[预兆/降临/冲击]
镜头编号：[C01-S001]
巨物状态：[具体描述]
参照物：[具体描述]
地点：[具体描述]
天气：[具体描述]
摄影方式：[G系列代号]
镜头运动：[具体描述]
Image Prompt：[完整图片Prompt]
Video Prompt：[完整视频Prompt]
Negative Prompt：[完整负面提示词]
```

## 8. 连续性检查

进入分镜前，自动检查：

- 机甲/怪兽外观一致
- 配色一致
- 发光元素一致
- 战损状态与剧情阶段匹配
- 天气一致
- 光线方向一致
- 海面波浪方向一致
- 参照物比例一致
- 尺度感一致

若发现冲突，自动重新生成对应资产。

完成后输出 Visual_Assets.md 并暂停等待用户确认。未经确认，不得进入下一阶段。
