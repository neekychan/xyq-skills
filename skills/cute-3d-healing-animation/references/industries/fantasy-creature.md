# 幻想小生物童话方向

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 适合角色

云朵精灵、星星精灵、蘑菇小人、小龙、小鹿、小水滴、花瓣仙子、月光兔

## 故事核心

发光种子、星星掉落、月光小屋、森林秘密、梦境旅行、季节更替

## 典型小事件

- 星星从天空掉到手心
- 发光种子在雨后发芽
- 月光下发现秘密通道
- 云朵变成小生物落下来
- 小水滴里看到另一个世界

## 情绪线范例

- 安静 → 发现魔法 → 好奇靠近 → 温柔触碰 → 魔法绽放 → 感动
- 迷路 → 遇到小精灵 → 被引导 → 找到归途 → 安心
- 沉睡 → 被唤醒 → 一起玩耍 → 疲倦 → 温暖入睡

## 角色材质句式

- 半透明柔和发光体质，边缘有微弱光晕
- 或：柔软圆润小身体，表面有细绒纹理或光斑
- 小小翅膀/触角/光尾，轻微闪烁

## 场景句式

- 月光下森林空地 / 星空下的小木桥 / 云端小屋 / 发光蘑菇丛
- 柔和自然光+微弱魔法光源，暖黄/冷蓝混合光
- 低饱和深蓝+暖黄+柔绿配色

## 落 prompt 前自检

- 角色的"魔法感"是否有具体视觉锚点（发光/半透明/光晕）？
- 魔法光源和自然光源是否分层描述？
- 幻想元素是否过于复杂？应保持1-2个魔法元素，不要堆砌
