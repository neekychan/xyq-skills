# 表格分镜规范（阶段5执行标准）
## 基本要求
1. 每15s输出一个独立的Markdown表格分镜表，总时长严格为15s。
2. 每张表包含5-12个镜头，描述量约1000字，信息密度高，具备导演执行性。
3. 必须基于视觉基因、品牌调性、品牌理念、选定的TVC叙事方向设计。
4. 必须设计每3s一个视觉反馈点、每7s一个视觉或情绪高潮的15s动作流。
5. 必须考虑分段生成的连续性：片段开头承接上一段的镜头内容、运镜、音乐、音效、情绪；结尾为下一段预留运镜方向、动作余势、转场音、节拍或视觉接口。
6. 必要时可在相邻15s表的首尾重复一小段动作、音乐动机、转场音、运镜方向或视觉符号，保证分段生成后的连续性。

## 表格字段规范
必须包含以下12个字段，不得删减：
| 字段名 | 内容要求 |
|--------|----------|
| 镜头序号 | 按顺序编号，如1、2、3... |
| 时间段 | 精确到0.5s，如0-2.5s、2.5-5s，所有镜头时间段总和必须为15s |
| 景别与视角 | 明确景别（大特写/特写/近景/中景/全景/远景/大远景）+ 视角（平视/俯视/仰视/侧视/三分之四视角/过肩视角等）+ 焦距范围（如85mm大光圈/24mm广角/200mm长焦） |
| 运镜方式 | 明确运镜类型（固定/推/拉/摇/移/跟/升降/环绕/甩镜/手持稳定器等）+ 运镜速度（慢/中/快/极速）+ 运镜轨迹 |
| 画面内容与表演 | 写清具体动作、表情、视线、物体位移、画面变化，必须是物理可实现的内容，不得出现抽象描述 |
| 品牌/产品/代言人关系 | 明确该镜头中三者的位置关系、互动方式、各自的呈现重点 |
| 光影与材质 | 明确光源方向、光质、明暗对比、重点材质的呈现方式（如金属边缘高光、皮革纹理、缎面反光等） |
| SFX | 具体物理音效，使用<...>标注，如<皮革摩擦声>、<低频电机嗡鸣>、<轮胎擦过地面声>，无音效则填"无" |
| 音乐与情绪曲线 | 使用(...)标注音乐情绪，如(冷调弦乐铺底)、(低频脉冲渐强)、(鼓点进入)，同时描述该镜头的情绪强度（1-10分） |
| 转场逻辑 | 明确与下一个镜头的转场方式，必须是无缝转场：动势匹配/物理遮挡/几何重合/光影延续/声音桥/节拍延续，说明转场的物理依据，最后一个镜头说明与下一分段的转场衔接 |
| 首尾衔接策略 | 第一个镜头说明如何承接上一个分段的结尾（如"承接上一段结尾的手部动作余势，从手指特写开始"）；最后一个镜头说明如何为下一个分段预留衔接接口；中间镜头填"无" |
| 商业表达功能 | 明确该镜头承担的四重目标中的哪些：代言人气质/品牌世界观/产品欲望/品牌记忆，以及具体实现方式 |

## 节奏设计规则
1. **0-3s**：必须建立视觉钩子，第一个视觉反馈点放在2-3s位置，快速抓住注意力。
2. **3-6s**：展示代言人气质、产品材质或核心结构，情绪逐步推进。
3. **6-8s**：第一个视觉或情绪高潮点，使用推镜/环绕/动作爆发/产品功能显现等方式强化记忆。
4. **8-12s**：空间展开、动作升级、产品价值或品牌理念进一步呈现，情绪持续走高。
5. **12-15s**：品牌Hero Moment/产品Hero Moment/全球Campaign记忆点，或为下一段落预留强烈的衔接钩子。

## 镜头设计禁忌
1. 严禁黑场、白场、渐显、渐隐、叠化、无意义空镜作为转场或镜头内容。
2. 长镜头（超过5s）严禁置于片段首尾，必须位于中段承担情绪承接。
3. 所有镜头必须构成连续、物理可成立的动作链，不得出现跳轴、动作不连贯、空间关系混乱。
4. 严禁使用破坏性词汇描述画面：破裂、分割、破碎、裂缝、切割、爆破、碎片，如需表达变化使用滑开、展开、抬起、翻转、漂浮、聚拢、旋转、靠近、遮挡、显露、折射、漫反射、高光滑移、焦点迁移等词汇。
5. 未授权品牌Logo、随机文字、水印、产品标签严禁出现在画面描述中。
6. "高级感""电影感""梦幻"等空洞形容词不得单独使用，必须落到具体物理细节。

## 节奏校验（每张表后必须附加）
每张分镜表输出完成后，必须补充以下校验内容：
1. **3s反馈点校验**：列出0-3s、3-6s、6-9s、9-12s、12-15s每个时间节点的视觉反馈点，确认每3s至少有一个。
2. **7s高潮点校验**：确认6-8s位置的高潮点设计是否到位，是否有足够的视觉冲击力。
3. **四重目标校验**：确认该15s片段是否完整覆盖代言人气质、品牌世界观、产品欲望、品牌记忆四个商业目标，分别说明实现方式。
4. **首尾衔接校验**：确认开头承接上一段的逻辑是否成立，结尾预留的下一段衔接接口是否清晰可行。

## 暂停与修改规则
1. 输出完整表格分镜与校验内容后，必须暂停，等待用户确认。
2. 用户提出任何修改意见，必须重新输出完整的表格分镜（不是局部修改），并再次附上节奏校验，重新等待用户确认。
3. 用户未明确确认分镜表前，严禁进入下一阶段（编写Final_Video_Spec.md、注册故事板、生成资产、构建Prompt、生成视频、合成时间线）。
