# 巨怪 / 怪物设计(开大攻击态,一图定形)

本文件规定怪物如何被设计成**开大态定形、轮廓清晰、扎进真实环境且跨镜一致**的资产。造色/材质/光线见 `visual-grammar.md`,真实场景与母版派生见 `environment-continuity.md`,能量因果见 `vfx-and-talisman.md`。所有图统一 16:9。

## 一、硬性交付:每只怪一张开大攻击态图

**每只巨怪/怪物只交付一张开大攻击态设计图,不出正常态三视图。若要追加细节图或变体,必须在图片清单中单独计数并确认:**

- **开大攻击状态设计图**:怪物进入攻击/异化/爆发形态,标明**开大机制**;必须**清晰呈现完整轮廓与长相**,同时处在已定义的真实 `SCENE_ID` 中。它是无人物、无剧情表演的怪物定形与入景基准;用环境量尺、安静背景、空间层次和有限特效保证可辨,不要改成纯色棚拍或无环境虚空。

判断合格:遮住标题,能一眼读出「这是哪只怪、它在开大」——完整轮廓、材质、色彩、标志性锚点齐全,能量特效只是叠加在可辨的身体上,而非盖住身体。

> **动态归下游**:本环节不生成开大视频。开大的动态表现(巨化、卷吸、爆发的运动)由 video creation 依据本图与特效锁定词生成;巨怪出场时回到本环节读取此图。

## 二、核心方向:扎根环境的巨物(四类造物,巨大为纲)

**本片巨物不是「放之四海皆可」的通用幻想怪,而是「从这个世界的环境、材料与传说里长出来的巨大存在」。** 判断一只怪是否合格,只看两条铁律——它们对下面**四类造物**一视同仁:

1. **足够巨大且可量化**:先写环境量尺表,至少选择两种有稳定现实尺寸的锚点(如 2 米门洞、6 米柱距、标准车辆、1.1 米栏杆、砖块模数),再用透视遮挡、结构占比和地面受力证明怪物体量。不得把人物当尺度道具。
2. **环境自洽且背景同源**:一眼能读出它从**这个具体 `SCENE_ID`** 的材料、施工结构与灵异规则里孕育、盘踞或被封印于此。若该地点已有干净底板,怪物图必须从底板编辑/参考派生;材料相似但空间骨架不同也判失败。

在这两条之上,巨怪可以是下面**四类造物之一(每只怪主选 1 类,可少量混入第 2 类)**——不再局限于「机械/废料聚合」:

| 造物家族 | 是什么 | 巨大化 / 异化逻辑 | 想象方向(原创,勿套IP专有怪) |
|---|---|---|---|
| **A 现实材料造物** | 由现实残骸聚合、异化的造物 | 磁吸缠绕 / 根系贯穿 / 能量骨架牵引 / 锈蚀熔接 | 岩层巨兽、机械集合体、废车堆叠巨兽、行走废墟、锈铁沉船巨物 |
| **B 古兽 / 动物向** | 被环境巨大化、异化的远古生物或动物 | 石化 / 尸化 / 矿物化 / 甲壳增生 / 多头多目 | 盘踞墓道的巨蟒、深渊古龟蛇、海底鲛蜃、镇墓兽苏醒、无名远古巨兽 |
| **C 灵魂 / 魂灵向** | 由怨念、魂气、香火、尸气凝聚成形的巨影 | 群魂聚合 / 附着器物成相 / 半透质凝实 | 陵寝怨魂法相、群俑魂聚合体、香火尸气凝成的半透巨影 |
| **D 未知造物** | 人类没见过、无法归类的异构生命 | 由环境规则本身孕育,内在规则自洽 | 深海机关孕育的异构体、秘境孳生的非常识形态,材质与痕迹仍扎根此地 |

无论哪一类,**成体系的构成逻辑不能少**:A 类要有聚合逻辑、B 类要有异化逻辑(为何巨大、为何异变)、C 类要有凝聚逻辑(魂气如何成形显质)、D 类要有一套自洽的内在规则——不是乱堆、乱变、乱发光。

**环境母题(先定巨怪从哪长出来,再定它是哪类造物):** 参考盗墓探秘、玄学志怪一类的空间设定,巨怪由环境决定气质。下表只学「环境孕育巨物」的因果与视觉,**不复用任何 IP 的专有怪物、名称与设定,必须原创命名与造型**:

| 环境母题 | 场景来源 | 易长出的巨怪方向 |
|---|---|---|
| **地下墓穴 / 古老陵寝** | 墓道、棺椁、陪葬俑、尸洞、壁画、镇墓兽 | 尸化古兽、俑群聚合体、镇墓兽异化、陵寝怨魂法相 |
| **藏宝图山洞 / 秘境洞窟** | 钟乳、暗河、藏骸、矿脉、洞中机关 | 岩层巨兽、洞蟒、盘踞秘境的远古生物、矿物化异兽 |
| **海底机关 / 沉船遗迹** | 沉船、青铜机关、珊瑚、深渊、锚链 | 鲛蜃、锈铁沉船巨物、机关兽、深海未知造物 |
| **上古 / 青铜遗迹** | 祭坛、青铜器、碑石、夯土城墙、破庙木构 | 青铜神兽苏醒、碑石巨像、祭器聚合体 |
| **现代废墟 / 垃圾场** | 废车、机械、混凝土、电缆、集装箱 | 废料聚合巨兽、机械集合体、行走废墟(保留原方向) |

> **时代不限**:主角与世界可为现代、近代或古代;材料与母题随之切换(古代→碑石、青铜、夯土、破庙、墓俑;现代→机械、废车、混凝土)。只要「足够巨大 + 环境自洽 + 构成逻辑成体系」三条成立即可,造物家族与环境母题可自由组合。

## 三、怪物设计公式(锚点成体系,不贴一个部位)

在核心方向之上,沿用「形态来源 + 成体系锚点 + 材质二联 + 环境痕迹 + 接地物理」:

- **形态来源**:先定环境母题,再选一类造物家族(A 现实材料 / B 古兽动物 / C 魂灵 / D 未知造物),调动其**完整语汇**(多材料/多结构/多意象协同),不是只贴一个偷懒部位。可叠加少量民俗/生物意象增加诡异感(如废墟巨物缝隙里渗出香灰水渍、尸化古兽甲壳间嵌着陪葬铜器、魂灵法相里浮出破碎符纸),但主体气质要统一。
- **材质二联**:按造物家族选 2 种主材料,但不要把两者糊成同一种表面。分别写明尺度、粗糙度、反光、局部湿度、断裂方式和积尘;至少约一半身体保留可读的大块面,微裂纹只用于结构转折与能量传导。
- **环境痕迹**:怪物会在场景里留下什么可重复的痕迹(碾压焦痕、金属刮擦、水渍油污、尸斑霉痕、掉落碎块、魂气残雾、火星),供场景卡复用。
- **环境量尺与接地物理**:先记录至少两种固定尺寸的建筑/器物锚点及其与怪物的比例,再写清重心、承重肢体、接触点、地面变形、泥水或碎屑受力、接触阴影和材质反向沾染。怪物图不放角色、路人或人形剪影。

**警惕「太常规」**:问题不在有锚点(明确锚点正是要的),而在(1)只用一个偷懒部位、(2)像道具贴上去、(3)没被材质与色彩统一进一具身体、(4)看不出环境来源或不够巨大。合格要:环境来源可辨 + 巨大尺度 + 完整语汇 + 统一材质 + 有据的开大逻辑。

## 四、开大机制(从静息概念到开大态的展开)

开大不是「换一只更凶的怪」,而是怪物**某套系统被激活**。为每只怪选定 1–2 条开大机制,写清「触发 → 变化 → 代价/破绽」。下表「静息态」只作**设计推导的概念基准**(帮你想清楚它平时收敛成什么样、开大时如何展开),**不需要单独出图**——最终只交付右列的开大态设计图:

| 开大机制 | 静息态(仅概念,不出图) | 开大态(交付的设计图) |
|---|---|---|
| **尺度骤变** | 蜷缩、拟态、藏于窄处、蛰伏于废墟中 | 巨化撑破空间 / 缩小钻缝,尺度对比是主要冲击 |
| **聚合/吸附增生** | 由有限现实材料构成 | 卷吸周围石块、废车、钢构不断增大体量,越战越大 |
| **口腔/裂口展开** | 常态闭合、外形收敛 | 口/裂缝内翻出更精巧的触手、齿列、机械内腔、缆线 |
| **体内异化露出** | 体表完整、看似整体 | 脊背/胸腔/体侧裂开,露出发光内构、能量核、熔岩腔 |
| **武装/结构展开** | 锚点内敛 | 甲板/钢骨/岩片外张成甲、刃、翼、臂,附能量异色 |
| **分体/群化** | 单体 | 崩解为群、分身、蔓延体,占满画面 |
| **附能点亮** | 材质哑光 | 缝隙渗出能量色(见 `vfx-and-talisman.md` 的固定色),纹路/裂缝点亮 |

**开大态设计图既要展开到位,又要保住可辨**:轮廓与长相清晰,并能被镜头拍到破绽或代价(核暴露、动作变慢、需要充能、有弱点部位),供后续打斗与抓诡设计使用。

## 六、出图规格

- **开大攻击态设计图**:攻击/异化形态,**完整轮廓与长相清晰可见**,置于对应真实 `SCENE_ID` 中,16:9;文件名 `creature_<名>_rage.png`。画面只承担“怪物定形 + 环境量尺 + 接地物理”,不放角色、路人或人形剪影;禁止剧情对峙构图、纯背景、游戏展示台和独立重造环境。不出正常态三视图。
- 若图片清单批准了 `scene_master`,先生成母版,再用编辑/参考方式派生怪物图并锁死 `PAIR_ID / CAMERA_SLOT`;若未批准空镜,只生成怪物主图并将其背景登记为场景母版。
- 共享 `visual-grammar.md` 的锁定词;跨资产一次只改一个已声明变量。空间骨架、主光、天气、既有损坏或材质漂移即退回重做,重做前再次执行图片清单确认门。

> 巨物/超尺度怪物只用环境量尺证明尺度:至少两种固定尺寸锚点 + 真实透视遮挡 + 地面受力。人物不属于怪物设计资产,不得作为前景、剪影、比例尺或叙事对手进入开大图。
