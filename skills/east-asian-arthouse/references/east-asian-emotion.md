## 核心原则

拍"生活在那里的人每天看到的亚洲"，而非"旅游宣传片里的亚洲"。用本地人日常视角，不使用西方视角的东方猎奇感。

东亚叙事的情感表达特征是"内收"而非"外放"——情感通过细微行为、环境共振、物件隐喻体现，而非通过人物直接语言或肢体表演体现。

---

## 东亚情感表达规范

| 情感 | 禁止（外放/西方表达） | 推荐（内收/东亚表达） |
|---|---|---|
| 悲伤 | 掩面哭泣、嚎啕 | 低头沉默、轻轻深呼吸、转身面向窗户 |
| 爱意 | 拥抱接吻、语言告白 | 默默多盛一碗饭、帮忙系好围巾 |
| 愤怒 | 摔东西、大喊 | 筷子放下稍重、沉默离席、关门声比平时响 |
| 思念 | 打电话倾诉、奔跑相见 | 翻看旧照片、走过曾经一起走的路 |
| 释怀 | 笑着拥抱、和解对话 | 长时间看向远方后轻轻呼气、打开很久没开的窗 |

## 东亚日常环境参考元素

以下元素写入 shot 描述和 element scene：

**空间：**
窄小公寓走廊、阳台晾晒的衣物、传统市场的窄巷、便利店深夜白色灯光、老旧居民楼楼梯间、屋顶天台、雨天骑楼下

**物件：**
电饭煲的蒸汽、墙上旧日历、塑料袋里的水果、手写便签条、用旧的拖鞋、阳台盆栽、晾衣杆上滴水的衣服

**时间/天气：**
梅雨季节、黄昏五六点光线、清晨五点天刚亮、台风前闷热、秋天第一次穿长袖、冬天呼出的白气

## 叙事连接策略

### 空镜转场

在两个人物段落之间插入 1—2 个环境空镜，承载：时间流逝 / 情绪沉淀 / 地理交代。

推荐内容：天空云层变化、无人街道、窗外光线推移、水面波纹。

---

## 符号/物件叙事

| 叙事需要 | 符号替代方式 |
|---|---|
| 表达"时间过去了" | 同一个杯子：热气 → 无热气 → 杯子被收走 |
| 表达"关系破裂" | 两把椅子：并排 → 一把空了 → 椅子被移走 |
| 表达"等待" | 窗台植物：发芽 → 生长 → 枯萎 |
| 表达"决定离开" | 行李箱：角落里 → 被拉出 → 出现在门口 |

## 背景音乐与环境音作为叙事线

在 audio layer 中设计情绪音效阶段：

| 情绪阶段 | Audio Layer 方向 |
|---|---|
| 平静日常 | 环境音为主：鸟鸣、远处车声、钟摆、水龙头 |
| 情绪积累 | 加入单一乐器线：钢琴单音、大提琴长音 |
| 情绪高点 | 声画分离——画面给空镜/物件，音乐承载全部情绪重量 |
| 情绪释放 | 回归环境音，但比开头更"空"——风声、远处人声消失 |

## 参考素材分析原则

**若用户上传参考影像（剧照、电影截帧、摄影作品）：**
重点提取：主光源方向与质感、色彩倾向（色温/饱和度/高光阴影关系）、景深与焦段感受、人物与环境的空间关系、画面情绪密度。

**若用户上传已有视频素材：**
判断其运镜方式（是否符合推荐运镜范围）、情绪阶段定位（铺垫/积累/高点/释放），并提取可用于 key element 绑定的角色外貌、场景特征信息。

**若用户上传文字剧本或大纲：**
识别其中的"情绪节点"而非"事件节点"，将每个情绪节点映射为分镜设计的情绪单元。

> 所有分析结果须与"东亚情感内收表达"原则对齐：情感通过细微行为、环境共振、物件隐喻体现，而非通过人物直接语言或肢体表演体现。
