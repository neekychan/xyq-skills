# 关键元素设定图生成规范
## 一、通用风格要求
所有设定图默认采用高质量二维手绘动画风格，强调柔和轮廓线、自然笔触、水彩质感，严禁三维塑料感、照片写实感、廉价卡通贴图感。

## 二、角色设定图规范
1. **排版布局**：纯白背景，四张子图水平横向排列，从左到右依次为：半身特写、正面全身、侧面全身、背面全身。
2. **半身特写**：面部占画幅上部三分之二，眼神清澈自然，准确呈现发型、脸型、眼睛、表情，体现角色性格特征。
3. **正面全身**：头顶至足部完整入画，还原服装正面剪裁、材质、颜色、标志道具。
4. **侧面全身**：保留服装侧面轮廓、背包、帽子、发带、披风等层次，体现体型特征。
5. **背面全身**：服装背面细节完整，便于视频生成保持多角度一致性。
6. **背景要求**：必须纯白，无文字、无水印、无额外人物、无复杂场景。

## 三、场景设定图规范
1. **内容要求**：具备真实空间透视、手绘水彩背景质感、自然植物层次、生活细节、建筑功能性结构。
2. **层次结构**：必须包含明确的前景层、中景行动区、远景背景三层结构。
3. **环境信息**：明确光源方向、天气状态、时间（清晨/正午/黄昏/夜晚）、季节特征。
4. **细节要求**：包含符合世界观的生活痕迹、自然元素（植物/水流/云层）、建筑功能细节，避免空泛的概念图。

## 四、机械/飞行器设定图规范（若剧情包含）
1. **结构要求**：必须包含完整可运动的机械结构：齿轮、连杆、螺旋桨、锅炉、蒸汽管、驾驶杆、翼面、活塞等部件，位置逻辑自洽。
2. **材质表现**：体现金属磨损、油污、木质结构、布料蒙皮等材质差异，避免统一塑料高光。
3. **运动逻辑**：明确标注可运动部件的运动方式（旋转/往复/摆动等），确保后续视频生成时机械运动符合物理规律。
4. **严禁空壳机械**：禁止生成只有外壳、没有内部运动逻辑的装饰性机械。

## 五、动物/精灵设定图规范（若剧情包含）
1. **多视角呈现**：包含正面、侧面、背面视角，明确体型比例、毛发/鳞片/羽毛质感。
2. **情绪表达器官**：明确标注用于表达情绪的部位（耳朵/尾巴/触须/翅膀/发光部位等）及运动方式。
3. **运动方式说明**：明确其运动模式（飞行/跳跃/蠕动/爬行/漂浮/奔跑/滚动），符合生物力学逻辑。
4. **与主角关系**：体现其性格特征（温顺/警觉/调皮/神秘等），避免无性格的 generic 生物设计。
