# 镜头调度与摄影导演系统（参考模块）

只处理"这一镜怎么拍才有电影感"——景别、机位与角度、镜头运动、构图、光影、剪辑衔接六个维度，以及不可协商的**视觉硬把控**。不要在这里改故事、改世界观：故事由用户或上游全能创作 agent 给定，世界画风由视觉系统固定。**本模块接手时，故事的分场与镜位候选已由总控阶段 0 从用户给定的 `story_input` 切分好、且视觉资产已批准；本模块的职责是把每一个镜头意图，升级成"拍得像好莱坞大片"的镜头。**

核心信条:**导演思维的起点不是"用什么镜头",而是"拍什么 + 为了说什么"。** 每一镜先答两个判断题——①这一镜要拍什么(内容,来自剧本,本模块不发明)、②拍它是为了说什么(意图,让观众感到/明白什么)——**然后才推导第三题:怎么拍(景别/机位角度/运动/构图/光影/剪辑 + 画框内调度)**。手法永远由"拍什么+为了说什么"推导而来,绝不能先挑好看的运镜再往上套内容。在此之上:**看得懂是及格线,摄影系统负责把及格线以上的部分做成质感。** 镜头调度永不为炫技牺牲可读性——它是在动作/信息已经清楚之后,用视觉语言把情绪、权力关系与节奏放大。本模块**与题材无关、与有无台词无关、与故事好坏无关**:镜头语言是通用语法,视觉系统决定"这个宇宙长什么样",本模块决定"摄影机怎么讲"。越是没有台词的片子,镜头调度承担的信息量越大(走位、视线、运动、构图替代对白)。

**若非用户意图，不可直接照搬原片元素，如机器人的台词、牛仔设定、牛仔帽、鸵鸟、丧尸、塑料模特等原片出现的明确元素**

> 本模块的配方经《ZOMBIE SCAVENGER》整片逐镜拉片提炼再通用化。文中"出处 SHOTxx"指该手法在该片的可查用例，仅为溯源与教学，不是要复刻那一集的角色或剧情，也不要透传任何关于该片的信息。。

## 0. 模块职责与接口

> **在 NEST 泛视频创作流程中的对接：** 本模块产出的 `cinematography_plan`/`rhythm_plan`/`continuity_plan` 全部服务于 NEST **第三步分镜规划**——由 `generate_shot_video_prompt_plan` 在构造 `storyboard.md` 每段 Prompt 时，把景别/机位/运动/构图/光影/剪辑与炫技叠加写进各 `shot_NN` 的镜头语言；`rhythm_plan` 决定分段与每段时长，`continuity_plan` 保证跨镜衔接与尾帧 `ImageList`。**镜头调度门接在 NEST 成片放行阶段。单段流程时这些镜头要求直接写进那唯一一条 Prompt。** NEST 文件名/工具名为内部概念，禁止向用户暴露。

**输入：** 总控阶段 0 从用户给定 `story_input` 切分出的**分场与镜位候选**（每镜的叙事目的与动作，来自用户/上游 agent，本模块不生成）、`world_contract`（视觉系统的色彩/材质/光照锁）、以及可选的**情绪节拍**（用户若给定则驱动光比与节奏；未给定则按动作强度中性处理）。

**输出：** 每镜一份 `cinematography_plan`（§8），把该镜那个单薄的"拍什么"升级为完整的"怎么拍"方案；`rhythm_plan`（§5 镜长时长曲线）与 `continuity_plan`（§3.6/§7 视觉与空间连续性账本）；外加一道 **镜头调度门 / 好莱坞质感门**（§7），接入总控阶段 5。

**边界：** 不决定"拍什么"（故事由用户/上游 agent 定）、不决定"这个世界长什么样"（视觉系统定作者风格锁、色彩职责、材质、动机光年代感）。本模块只决定"摄影机以什么景别、从什么角度、怎么运动、怎么构图、怎么打光、怎么接"来渲染已给定的这一拍。**光影的色温/材质/年代感遵从视觉系统的世界锁；本模块只在其允许范围内决定光质、方向、光比与动机。** 在本模块具体分析的叙事诉求（由AI自主分析）之外的叙事设计正常由**NEST 泛视频创作**（内部代号 `video_creation`）负责，符合本模块涵盖的内容叙事诉求的镜头叠加本模块的镜头指引。

## 1. 视觉硬把控（不可协商的电影感地基）——核心一

这八条是"看起来像电影"与"看起来像 PPT/游戏 CG/AI 废片"的分水岭，**与题材无关，每镜都要过**。它们是门，不是加分项；任一条崩了，画面再好看也掉档。

### 1.1 画幅适配
本模块不指定画幅。遵从用户或 video creation 的实际输出设置，并按该比例安排构图、走位与留白：横幅可多用横向动势、水平线与空间纵深；竖幅或方幅可多用中心构图、纵向引导线与前后层次。不要在 Prompt 中写入比例 token，也不要以任何特定比例作为质检门槛。

### 1.2 镜头景深纪律（焦段即心理）
- **主体分离**：任何该被看的主体，必须靠景深、光比或色彩从背景里"拔"出来，不能糊在环境里。
- **焦段的心理学**：广角（贴近+畸变）= 空间感/疏离/张力/主体渺小；标准 = 中性纪实；长焦（压缩空间）= 亲密/凝视/背景虚化/宿命压迫。选焦段是在选"观众与主体的心理距离"，不是随手。
- **浅景深 vs 大景深**：浅景深（选择性对焦）用于情绪镜、把注意力焊死在一点；大景深用于建立镜、把环境与主体的关系全交代清楚。

### 1.3 光比与影调作为情绪（核心把控）
- **光比 = 戏剧强度，但先服从真实来源。** 低光比（柔和均匀）= 安全/日常/喜剧；高光比（明暗强反差）= 危机/暴力/悬疑/戏剧化。情绪不能成为凭空加光的理由：先定主光、阴影和补光，再决定光比。
- **色温来自光源和反射，不是统一的滤镜。** 暖 = 日照、钨丝灯、钠灯、火焰或锈蚀受光；冷 = 天空、海雾、窗外天光、阴影反射。室内暖 vs 窗外冷的同框对照必须有窗、灯具和空间遮挡作证，不能把主体强行打成橙色、背景统一染蓝。
- **真实曝光优先于“全细节”。** 保护脸、面屏、关键道具和叙事区域；允许小面积镜面高光接近白，允许最深阴影失去少量纹理。禁止把“高光不过曝、暗部留细节”理解为全图均匀可读——这会直接产生 HDR/游戏 CG 的平化影调。
- **光比必须看得出。** 主体受光面、阴影面、背景亮度和材质高光要有层次；若阴影面与受光面等亮、每个表面都有同强高光，判为无来源环境填光，直接打回物理光照卡。
- **色彩与光照分层。** 视觉系统的 `color_lock` 在每镜逐字继承，是常量；本模块只改变同一色彩在受光、半影与阴影中的亮度和反射强弱。不得因情绪、时段、天气或光比重写色相、饱和度、色彩职责或整体调色。

### 1.4 动机光（每束光有来源）
画面里每一处高光、每一道轮廓光，都要能追溯到一个“光是从哪来的”：日照、店招、仪表盘、火焰、舷窗、聚光。无动机的漂浮打光 = 廉价感。情感高潮的内景可以选择画内可见的钨丝灯、钠灯或餐厅灯作唯一主光，但仍逐字继承 `color_lock`，不另加情绪调色。

但只写“动机=日光”不够。每个叙事镜头必须先填写一张**实拍光照卡**，它是镜头、Prompt 与成片质检共同使用的硬约束：

| 必填项 | 写到可验证的粒度 |
|---|---|
| 时间与天气 | 上午/正午/日落前/蓝调/夜晚；晴、薄云、海雾、雨后等。 |
| 主光 | 具体光源、相对镜头与主体的位置、入射角、色温、硬/软、是否在画内可见。一个镜头只能有一个主光。 |
| 阴影 | 主体、建筑和道具的投影/遮挡应向哪个方向、边缘有多硬；若看不见投影，也要写明为何被遮挡。 |
| 补光 | 只允许天空、地面、墙面、海面或可见实用光造成的反射；说明来源与弱于主光的关系。禁止无来源正面补光。 |
| 曝光锚点 | 哪个脸、面屏、道具或区域优先正确曝光；允许哪一部分自然接近白或沉入暗部。 |
| 材质与光学 | 粗糙金属/玻璃/混凝土如何响应这束光；耀斑、体积光、雾化是否满足光源进入光轴与空气介质条件。 |
| 连续性 | 与上一镜相比，太阳方位、窗光、实用灯、天气和曝光是否延续；若变化，写出剧情内原因。 |

没有完整实拍光照卡，不得进入镜头配方、Prompt 或生成。它不是为了堆技术名词，而是用真实世界的因果消除 CG 式全局补光。

### 1.5 质感纪律（反 CG/反游戏感）
胶片颗粒只能克制使用；盐蚀、灰尘、划痕和氧化只出现在真正受风化的局部材料。色彩完全继承视觉系统的 `color_lock`；曝光则服从现场光源和中间调，不把“通透”当作整体提亮指令。世界中不出现赛博朋克霓虹、无菌洁净科幻、现代城市或实时游戏式材质逻辑。

颗粒、脏旧和镜头品牌都不是“真实感滤镜”：它们不能修复错误的太阳方向、被抬平的阴影、无来源的边缘高光或均匀覆盖的磨损贴图。材质真实度由同一物件在受光、半影和阴影里的粗糙度、反射和色偏变化证明；光学效果只能在已经成立的物理受光上加分。

### 1.6 构图秩序（水平线与视线纪律）
- 地平线不无故乱斜（除非用荷兰角表达失衡，且是有意为之）。
- 三分法 / 中心对称二选一并贯彻，不做"随手居中偏一点"的模糊构图。
- 人物留**头部空间**与**视线空间**（朝哪看，哪边留白），越轴前先锁 180 度线。
- 外景至少给一条纵深线索：地平线、道路消失点、圆顶、塔、棕榈列。

### 1.7 运动的动机与稳定度
**每一次摄影机运动都要有理由**——揭示、跟随、加压、抽离、连接空间或情绪升级。无理由的乱晃/乱推 = 业余。运动的**质地**本身是语言：稳态推轨/斯坦尼康 = 优雅/掌控/宿命；手持晃动 = 纪实/紧张/呼吸；固定 = 凝视/仪式/审视。运动的**加速度 = 情绪强度**。

### 1.8 一镜一情绪一意图
一个视频镜头只承担一个情绪、一个主动作、一个摄影意图（一镜一意图原则）。把三个转折、五次景别切换、复杂打斗塞进同一条生成 Prompt，必然崩。复杂段落拆成多镜，靠剪辑（§3.6）串。

### 1.9 序列级硬处方（多镜成片必过，一票否决）
§1.1–§1.8 管**单镜**；本条管**整段成片**。经验证：单镜每条都"看起来对"，但整段仍会像 AI 废片——因为缺的是**跨镜的差异与呼吸**。任何 ≥3 镜的成片，交付前必须逐条满足下列硬处方，缺一即打回（对应 §7 质检门的一票否决项）：

**前置：真实摄影连续性。** 全片先建立 `lighting_ledger`，逐镜登记时间、主光、阴影方向、补光、曝光锚点和实用灯状态。连续时空内，任何一镜的主光翻转、阴影长度突变、背景比主体更亮的原因变化、或耀斑凭空消失/出现，都必须有明确的换时、转向、换景、灯光开关或天气理由；否则不允许进入下列处方。

1. **景别跨度**：整段至少覆盖 **3 个不同景别级差**（如远景 + 中景 + 特写），不得全段挤在同一景别（全全景、全中景都算失败）。至少 1 个特写/大特写承载情绪，至少 1 个远景/大远景承载空间。
2. **时长跨度**：镜长必须跨 **≥2 个时长档**（§5 三档）。**强制含 1 个 4.5s+ 抒情长镜作收尾**，且开场压 1 个稍长建置镜（首尾长镜包络）。**并且(§5.1 对比度硬规则):不允许连续 ≥4 个镜落在同一档且彼此差 <0.5s(节拍器匀速=失败)；整段最长镜÷最短镜 ≥3；中段镜长不得全挤在 1.5s 宽的窄带里。** 全段镜长挤在同一窄区间（如上一版失败片全挤 1.5–3.7s、中位数 2.67s）即失败。**成片后须按 §5.2 实测镜长分布核对,不许凭感觉判定。**
4. **意图多样性**：整段至少呈现 **3 种不同叙事意图**（§4 速查表的不同行），不得整段重复同一个动作情绪（如"跑—跳—跑—跳"到底 = 失败）。典型分工：建置 → 高潮/情绪 → 收束。
5. **运动多样性**：至少出现 **1 次有动机的推/拉/环绕/升降**（非平移跟拍），且至少 1 个固定/稳态镜做呼吸。全段只有平视侧向跟移 = 失败。
6. **光影变化**：整段至少出现 **1 次有物理原因的光比、遮挡、入画光源或实用灯状态变化**（§1.3）。不要为了制造变化而更换 `color_lock` 或重新调色。
7. **母题利用**：凡资产带**情绪出口或状态信息**（面屏/表情灯/损伤/挂牌/倒计时等），整段必须 **≥1 个特写或插入镜专门拍它**。有面屏却全程只拍全身、有挂牌却从不给插入 = 母题空转 = 失败。
8. **衔接动机 + 段落转场**：镜与镜之间至少有一处用 match-on-action / 视线 / 方向 / 声音桥主动缝合（§3.6），不得全程硬切。**并且:凡成片含 ≥2 段剧情(换地点/换时间/换事件),每个段落边界都必须按 §3.8 指定一种转场手法(动势匹配/空镜定场/声音桥/光影渐变/母题呼应/有动机硬切)并写明缝合依据;每段开头必须有建置镜。段与段之间出现"无动机直接硬切"= 失败**(这是"段落间全硬切、观众看懵"的元凶)。
9. **动作节拍炫技下限**：凡含奔跑/腾跃/追逐/打击/冲刺等动作节拍，每个动作镜**至少叠加 §4.5 中 ≥2 个不同类别的炫技手法**（速度感/冲击感/空间动势/剪辑动势/焦段心理）。**平视侧向跟拍一镜到底拍动作 = 失败**——摄影机必须参与动作，把速度与冲击放大到与题材设计相称的奇观级别。

> 这八条是把"六维知识"从建议升级为**成片处方**。它们不评判故事，只保证"整段拍出了电影的差异、呼吸与奇观，而不是把一个漂亮镜头复制 9 遍、把动作拍成干净的记录"。

## 2. 镜头调度决策逻辑：拍什么 + 为了说什么 → 怎么拍（核心二的总纲）

这是本模块的"发动机"。**它的第一性原理是:先判断内容与意图,再推导手法——绝不倒过来。** 对每一镜(来自总控切分出的镜位候选),按下面的顺序走,前两步是判断题、后面是执行题:

**第 1 步 · 定"拍什么"(内容锁定,来自剧本,本模块不发明)。** 先把这一镜画框里客观发生的事写清楚:谁(主体)、在哪(场景/地点)、做了什么(主动作)、有什么变化或关键物件(状态/道具)。这全部来自用户/上游 agent 给定的分场,本模块只如实接收与锁定,**不新增剧本没写的人物、动作或情节**。一句话写清,如"机器人在废墟停车场,弯腰把一具丧尸拖进垃圾桶,面屏显示待机白"。这一步答不清就回总控做最小澄清,不许硬编。

**第 2 步 · 定"为了说什么"(意图)。** 在"拍什么"之上,读出这一拍的叙事目的 + 用户给定的情绪节拍(若有,当前处于起点/拐点/落点哪一段):**这一镜到底要让观众感到什么、明白什么、记住什么**,它在整段里承担建置、推进还是收束。一句话写清,如"让观众感到主角在废墟中的渺小与孤独,并交代'清理丧尸是他日常'这一信息"。若用户未给情绪节拍,则从该镜动作本身与前后镜关系推断中性意图。**"拍什么"是客观内容,"为了说什么"是主观意图——两者都锁定后,才允许进入下面的手法选择。**

**第 3 步 · 定实拍光照(先成立物理世界)。** 在选任何“好看的光影”前，按 §1.4 填完本镜 `实拍光照卡`：时间/天气、唯一主光、阴影方向、有限补光、曝光锚点、材质响应、光学条件和与上一镜的连续性。若同一空间内主光与投影无法统一，或暗面靠无来源正面光才看得清，先重定时间、机位或场面调度；不许交给颜色滤镜或后期解决。

**第 4 步 · 定主导维度(手法开始:由前三步推导)。** 六维(景别/机位角度/运动/构图/光影/剪辑)里,**哪一维最能把第 1 步的内容 + 第 2 步的意图落成画面**?渺小 → 主导维度是"景别 + 机位角度"(大远景 + 高俯角);亲密 → "景别 + 光影"(特写 + 可见窗口/开放阴影的大面积有方向现场光);紧张 → "运动 + 剪辑"(手持 + 短切)。主导维度决定后,其余维度做**支撑**,不喧宾夺主。光影维必须服从已经成立的 `实拍光照卡`。主导维度必须能追溯回"为了说什么",答不出"这个维度是为哪句意图服务的"就是炫技先行,打回。

**第 5 步 · 查配方。** 先去 §4“内容 → 镜头调度对应关系库”，按第 1 步锁定的**内容类别**(C1–C12,一镜跨类就并查)直接查到“这类内容通常怎么拍”的七件套成熟配方(景别/机位角度/运动/构图/光影/画面内调度/剪辑时长);若你手里更明确的是“为了说什么”而非内容类别,则用 §4.4“意图→镜头卡速查表”从意图侧反查。两表只提供镜头表达，不能覆盖第 3 步的真实受光。

**第 6 步 · 组镜 + 过硬把控。** 把六维组合成一镜(景别 + 机位角度 + 运动起落幅 + 构图 + 已锁定的光质方向色温光比 + 前后衔接),**再补第七维 §3.7 画面内调度**(画框内谁在做什么、母题情绪出口显示什么/何时切换、次要运动),最后用 §1 逐条校验，尤其核对光照卡与实际构图是否相容。**没有画面内调度的镜,就是“机位对了但主体在发呆”的空镜——第七维不是可选项。**

**第 7 步 · 落成 `cinematography_plan`(§8)。** 先写死“本镜拍什么(内容)”“为了说什么(意图)”与“实拍光照卡”三个根字段，再让每一维都写清“是什么 + 为什么这样(动机,须能追溯回内容+意图)”，尤其运动写“起幅→落幅 + 动机”。光影字段必须把光照卡转写为模型能执行的方向、阴影、反射和曝光，而不是只写“日落”“暖调”“电影感”。

> **反炫技红线（已修订）**：红线反的只有一种炫——"**不服务任何意图、且拖累可读性**"的空转炫技；这种华丽环绕/升降砍掉换朴素镜，镜头调度门（§7）会拦。判断某个手法是否空转,只需问一句:**它能追溯回本镜第 1 步的内容或第 2 步的意图吗?** 不能就砍。**但动作/奇观节拍是例外：那里"炫酷"本身就是叙事意图**，速度、冲击、失衡、动势必须被摄影机主动放大到与设计相称的级别（见 §4.5），此时炫技是**被要求的**,不受红线压制。判据只有一条:**可读性 > 炫技**——只要给定动作仍看得清，就该往炫里拍；只有当炫技让动作看不清时才收。绝不要因为"怕炫"而把动作拍成干净平淡的记录。

## 3. 六大调度维度词典

每维给出：分类阶梯 · 心理效应 · 何时用 · 好莱坞级要点。

### 3.1 景别（Shot Size）——"给观众看多大范围"
| 景别 | 心理效应 | 何时用 |
|---|---|---|
| 大远景 / 远景 (ELS/LS) | 交代地理、规模；人物渺小、苍凉、宿命 | 世界建立、孤独、灾变全貌（出处：航拍小镇 SHOT42/55）|
| 全景 (FS) | 完整肢体语言、走位、人与环境关系 | 动作调度、双人关系、亮相 |
| 中景 (MS) | 对话与动作主力，兼顾表情与手部 | 叙事段落绝大多数镜 |
| 近景 (CU) | 情绪读取、把注意力收到脸/关键部位 | 情绪节拍、反应镜 |
| 特写 / 大特写 (BCU/ECU) | 决定性瞬间、内心、道具的分量、眼神 | 情绪最高点、关键证据道具、反转揭示（出处：面屏情绪大特写 SHOT52）|
| 插入 / 细节 (Insert) | 证据、因果的可见钉子 | 英雄道具状态、倒计时、手部动作 |

**要点：**
- **景别阶梯**：切换时跨一到两个景别级差（远→中、中→特），跳级太大观众会晕，原地磨蹭（中→中）观众会腻。
- **长镜内景别推进**：一个长镜内靠推近/环绕由松到紧，替代切点、聚焦情绪、保连续（出处 SHOT1/41/54/69）——抒情与聚焦的核心手法。
- **无对白片加重景别**：没有台词时，特写承担"说不出口的情绪"，插入承担"设定与因果"，务必给足。

### 3.2 机位与角度（Camera Position & Angle）——"从哪、以什么权力关系看"
| 角度 | 陈述的关系 | 何时用 |
|---|---|---|
| 平视 eye-level | 中性、认同、平等 | 默认；对话；让观众"站在主角这边" |
| 仰角 low-angle | 力量、威胁、英雄化、崇高、仪式 | 主角高光时刻、反派压迫、地标神圣化 |
| 俯角 high-angle | 弱小、被审视、被命运俯瞰、交代地理 | 角色失势、渺小、空间总览 |
| 航拍 / 顶视 aerial/top | 规模、几何、上帝视角、抽离 | 世界建立、命运感、图案化调度（出处 SHOT42/55）|
| 荷兰角 dutch | 失衡、眩晕、异常、精神危机 | 世界不对劲、受击、癫狂——慎用，用多失效 |
| 过肩 OTS / 主观 POV | 关系、对峙、强代入 | 对话对峙、主角视角悬疑 |
| 贴地低机位 / 极高机位 | 极端情绪强调 | 冲刺贴地速度感 / 命运俯压 |

**要点：角度 = 一句无声的权力关系陈述。** 仰拍谁，谁就大；俯拍谁，谁就小。同一场对峙，给 A 仰、给 B 俯，胜负关系不用台词就讲清了。轴线角度还负责"看与被看"（§3.4 框架式常与 OTS 配合）。

### 3.3 镜头运动（Camera Movement）——"摄影机自己怎么动"
| 运动 | 语义 | 何时用 |
|---|---|---|
| 固定 static | 凝视、仪式、稳定、喜剧凝视、审视 | 情绪定格、对称仪式镜、让观众"专心读脸/读局"（出处：面屏特写固定机位 SHOT49/52）|
| 摇 pan / 俯仰 tilt | 揭示、跟随、连接同一空间的两点 | 从 A 摇到 B 建立关系、跟人物转头 |
| 推轨 dolly-in / 拉 dolly-out | 推=聚焦情绪、加压、逼近内心；拉=抽离、释义、孤独、揭示更大真相 | 情绪加压用推，情绪释然/孤独用拉 |
| 平移 track / truck | 平行跟随、并列调度、横向揭示 | 跟人物横走、扫过一排事物 |
| 变焦 zoom | 快速强调、不安（视角不自然） | 突发强调——慎用，滥用廉价 |
| 跟拍 follow（斯坦尼康/云台） | 贴身临场、流畅陪伴 | 跟人物穿行空间、优雅长镜 |
| 手持 handheld | 纪实、紧张、呼吸感、失控 | 追逐、战斗、慌乱、贴身危机 |
| 弧形环绕 arc / orbit | 情绪包裹、戏剧升级、揭示 360°关系 | 双人对峙/拥抱升级、亮相环绕（出处：弧形跟拍 SHOT1/9/21/41）|
| 升降 crane / jib | 情绪抬升/收束、展开或收拢规模 | 结尾升起收束、揭开全景 |

**要点：**
- **相对位移判定法（拉片核心方法，反过来即调度法）**：主体在画面里稳定、背景向某方向滑移 → 摄影机在做环绕/跟移。要"贴身陪伴+缓慢揭示环境"就用这招：让主体钉在三分线，背景徐徐流过。
- **运动的加速度 = 情绪强度**：越激烈越快越抖，越抒情越慢越稳。
- **动静交替 = 呼吸**：动作段（手持/环绕）之后接一个固定长镜让观众喘息，全程乱动或全程死板都失效。
- **起幅→落幅**：每个运动镜都要设计"从哪个构图开始、到哪个构图结束"，运动是为了完成一次构图/景别的转变，不是漫无目的地飘。

### 3.4 构图（Composition）——"画面里怎么摆"
| 构图法 | 心理效应 | 何时用 |
|---|---|---|
| 三分法 | 自然、平衡、留呼吸 | 通用默认；主体压三分线，另一侧留逆光/环境 |
| 中心对称 | 秩序、仪式、庄严、荒诞凝视、对峙 | 地标、消失点大道、圣像、面屏特写、正面对决（出处 SHOT46/47/51/52）|
| 框架式 frame-in-frame | 看与被看、窥视、浪漫张力、纵深 | 门框/橱窗/前景人物/玻璃/舷窗做前景遮挡（出处 SHOT50/53/54/69）|
| 引导线 / 消失点 | 纵深、牵引视线、荒凉/宏大 | 街道/海岸线/轨道把视线引向主体或天涯 |
| 前景遮挡 foreground occlusion | 空间层次、偷窥感、真实感 | 隔物看人、增加纵深与临场 |
| 负空间留白 | 孤独、期待、渺小、失落 | 大片留白只放一个小主体（出处：逆光海面留白 SHOT1）|
| 平衡 / 失衡 | 稳定 vs 不安 | 稳定用对称/三分，不安故意失衡或荷兰角 |
| 视线/运动引导 | 预告下一个焦点 | 用人物视线方向、动势方向指向下一重点或下一镜 |

**要点：** 构图是"用画面几何替角色说话"。孤独 → 负空间 + 小主体；仪式/对决 → 中心对称；浪漫/窥视 → 框架式；宏大/荒凉 → 消失点引导线。宽画幅尤其适合对称与水平线压线。

### 3.5 光影与影调（Lighting & Tonality）——"用光雕刻情绪"
> 色彩完全服从视觉系统的 `color_lock`。本维只决定光源、方向、尺度、遮挡、阴影、弱反射、曝光和光学条件；不重新调色。

- **现场光逻辑，不用影棚三点布光逻辑。** 每镜只有一个主导光源；背光或亮边只有在主光真正位于主体后方时自然形成，不另加一盏“分离光”。
- **光质由光源尺度与天气决定。** 晴天直射日光偏硬，云层、窗口或墙面大面积反射偏软。“浪漫”不等于无来源柔光，“动作”不等于无来源硬光。
- **方向必须可验证。** 侧光、顶光、逆光或正面来光都要写明光源在空间中的位置、主体如何遮光和投影落向。耀斑只在亮源进入光轴时出现。
- **光比来自环境选择。** 若想要较低光比，选择云天、开放阴影或大面积窗口；若想要较高光比，选择直射日光、局部窗光或单一可见灯具。不通过额外补光把光比“调得完美”。
- **自然曝光不追求全图可读。** 优先保护一个叙事锚点；其他区域可因遮挡、距离或粗糙度自然偏暗。
- **真人镜头增加人物表面约束。** 皮肤保留毛孔与微纹理，整体哑光至微丝光；脸部高光小而有因。头发自然分束、低至中光泽，无剧情理由时不做发油湿亮感。

### 3.6 剪辑与镜头衔接（Editing & Transitions）——"镜头之间怎么接"
| 技法 | 作用 | 何时用 |
|---|---|---|
| 动作剪辑 match-on-action | 靠动作动势跨镜无缝接、隐藏切点 | 掉帽→踢帽→戴帽这类动势链（出处 SHOT45/48/49）|
| 动势 / 方向顺接 | 保持运动连续，观众不迷向 | 主体走向/扑咬方向顺接下一镜 |
| 视线匹配 eyeline match | A 看 → 切 A 所看之物 | 建立"谁在看什么"的关系 |
| 180 度线 | 保持左右方位一致，不越轴 | 对话/对峙/追逐的空间连贯 |
| 图形匹配 graphic match | 前后镜形状/构图相似，诗意转场 | 主题呼应、时空跳转 |
| 声音桥 sound bridge / L-cut / J-cut | 声音先入或延留，缝合两场 | 情绪延续、场景过渡 |
| 因果剪辑 | 动作 → 结果顺接 | 摆拍→吐照片这类因果（出处 SHOT56/57）|
| 平行剪辑 cross-cut | 两条线交替，制造紧张/对比 | 追逐、双线逼近 |
| 环形结构 / 首尾呼应 | 情感闭环、主题盖章 | 结尾物件呼应开场（出处 SHOT69↔56/57）|

**节奏见 §5。核心：切点必须有动机**——动作到位、情绪到点、信息交付完，才切；为切而切 = 碎。

### 3.7 画面内调度（表演 / 走位 / 母题）——第七维：摄影机之外的另一半镜头语言

> **为什么单列一维（本次补强的最致命缺口）：** 前六维只调度"**摄影机**"——它站哪、拍多大、怎么动、怎么构图、怎么打光、怎么接。但一个镜头的信息与情绪，有一半来自**画框之内主体自己在做什么**：走位、动势、微表情、次要运动、母题符号的状态变化。拉片里每一个"有电影感"的镜头，几乎都是**摄影机调度 × 画面内调度 × 剪辑**三者咬合的结果；只写摄影机、把画框内容留给模型自由发挥，出来的必然是"机位对了但画面空、演员在发呆"的 AI 废片。**镜头语言 = 摄影机怎么拍 × 画框内发生什么 × 镜头之间怎么接**——本维补上中间那一项。

**本维调度什么（五类，按需叠加）：**

| 类别 | 具体内容 | 承载的信息 |
|---|---|---|
| **① 主体走位 blocking** | 主体在画框内的进入/退出/穿越/靠近/远离；与其他主体的距离拉近或推开；朝向变化（背对→转正） | 权力关系、亲疏、意图转变；替代对白交代"谁向谁靠拢/who has the initiative" |
| **② 动作动势 action beat** | 一镜承载的那个**单一主动作**及其起势→发力→收势（出处 SHOT48 踢帽腾空、SHOT45 掉帽） | 动作节拍本身；也是 match-on-action 的接点(§3.6) |
| **③ 微表演 / 情绪出口** | 脸/眼神/手部的微动作；**功能性主角的母题情绪出口**（LED 面屏图案与颜色、指示灯、单一发光符号）的状态切换（出处 SHOT41 面屏怒红→白呆、SHOT49 戴帽同时面屏白→红→白的双重表演、SHOT52 面屏情绪大特写） | 内心、反应、"说不出口的情绪"——无对白片的主力信息通道 |
| **④ 次要运动 secondary motion** | 画框里主体之外的活物/环境动势：背景人群、飘动的布幔/棕榈、拍窗的手、飞过的鸟、飘落的灰（出处 SHOT54 内景暖调静止用餐 vs 窗外冷调丧尸拍窗的次要运动） | 让画面"活"、制造纵深与临场；冷暖/动静对照叙事 |
| **⑤ 母题状态 motif state** | 带信息的关键物件在镜内的可见状态与变化：倒计时、损伤、挂牌、开关、液位（见视觉系统 §5.1 母题词表与 §5.2 状态文字账本） | 因果与代价的可见钉子；环形呼应的锚点 |

**好莱坞级要点：**
- **每个镜头必须回答"画框内此刻在发生什么"**——哪怕是静止镜，主体也得有一个可读的**微动作或情绪出口状态**（面屏亮起、眼神移动、手指收紧），不能是"摆好 pose 等摄影机"。空画框 = AI 废片第一症状。
- **走位与摄影机运动要咬合，不是各走各的**：相对位移判定法（§3.3 要点）的另一半就是画面内调度——主体钉三分线、背景滑移，是"摄影机环绕"与"主体保持"两个调度的合谋；主体主动穿越前景遮挡，是走位配合框架式构图。
- **动作节拍必须落在画框内的具体动势上**，再由摄影机（§4.5）放大。先有"踢帽腾空"这个画面内动作，才谈得上用急推/升格/环绕去炫它。**没有画面内动作，炫技无处附着。**
- **母题情绪出口是无对白片的"台词"**：功能性/机器主角靠面屏图案与颜色切换表达情绪，同一角色的情绪 = 同一块屏的不同图案/色（在该角色的单人角色图与文字身份锁中登记字库）。凡资产带情绪出口，本维就要在关键镜里**写明它此刻显示什么、何时切换**，不能留空让模型乱猜。
- **一镜一主动作**（呼应 §1.8）：画面内调度也只承载一个主动作 + 一个情绪出口状态；把三个走位、五次表情塞进一镜同样会崩。

**落地要求：** 每份 `cinematography_plan` 的 `画面内调度` 字段（§8）必须写清本镜"画框内谁在做什么、母题出口显示什么/何时变"，与六维中的运动/构图/剪辑对齐。动作镜此维与 §4.5 炫技叠加联动填写。

### 3.8 段落 / 场级结构与转场调度——第八维:"一段事到另一段事怎么过"（本次补强的最致命缺口）

> **为什么单列一维（真实事故复盘）：** 前七维都在调度**单个镜头内部**——摄影机怎么拍、画框里发生什么。但一条 ≥2 段剧情的成片，看不懂、难受的最大来源**不在任何一个单镜里，而在"段与段之间"**：上一秒还在雪地对话，下一秒硬切到骑兽追逐，观众的脑子跟不上"现在在哪、发生了什么、为什么"。**症状就是"段落间全是硬切、越看越懵"。** 根子在于:只有"镜头"没有"场"的概念——把 N 个镜头平铺硬切,却从不交代一段事的**入(建置)、承(推进)、出(收束)**,也从不给段与段之间一个**转场动机**。本维专治这一层。

**核心概念:先分"场/段",再谈镜。** 一条成片不是 shot 的线性队列,而是**若干"叙事段落(segment/scene beat)"的序列**,每个段落内部才是若干镜。段落 = 用户给定分场里"一件相对完整的事/一个地点时间下的一段情绪"。调度顺序变成:**先把故事切成段 → 每段设计"入-承-出"的镜头小结构 → 再设计"段与段之间怎么过"**。

**A. 每个叙事段落内部必须有"入-承-出"三件套(缺则该段散架):**

| 位置 | 职责 | 硬要求 |
|---|---|---|
| **入 · 建置镜(establishing)** | 交代"这段在哪、有谁、什么状态" | 每段**开头必须有 ≥1 个建置镜**(大远景/远景/环境全景,或一个信息清晰的定场中景)。缺建置镜 = 观众不知道场景已切换 = 懵。**不许一段事直接从中景特写开场。** |
| **承 · 推进镜(development)** | 这段事的主体动作/关系/信息推进 | 段落主体,按 §2 逐镜调度;景别与运动在此起伏。 |
| **出 · 收束镜(resolution/beat-out)** | 给这段一个情绪或信息的落点,并**为转到下一段留出动势/钩子** | 每段**结尾应有一个可作为转场接点的镜**(一个情绪落点长镜、一个动势指向下一段的动作、一个空镜/道具特写)。它的落幅状态 = 下一段的接入依据。 |

**B. 段与段之间必须"指定转场手法",硬切必须有动机(本维的铁律):**

段落切换**默认禁止无动机直接硬切**。每一个段落边界(segment boundary)都必须在 `segment_plan` 里**显式登记一种转场手法**,从下面选,并写清"靠什么缝":

| 转场手法 | 怎么缝 | 适用 |
|---|---|---|
| **动势匹配切 match-cut / 动作顺接** | 前段末镜的动作动势/运动方向,接到后段首镜的同向动作或相似构图(§3.6 match-on-action / graphic match) | 两段有动作或形状可承接时(最高级,几乎无缝) |
| **空镜 / 定场过渡 establishing insert** | 前段收束后,插一个后段场景的大远景/环境空镜作"新场定场",再进后段动作 | 换地点/换时间,最通用的"让观众重新落地"的手法 |
| **声音桥 sound bridge (J/L-cut)** | 后段的声音(环境声/音乐/对白)先于画面进入,或前段声音延留压过切点(§3.6) | 情绪要连、地点要换时,听觉先把两段黏住 |
| **光影 / 影调渐变** | 用光比、色温、明暗的渐变过渡(如暖黄昏→冷夜),或渐隐渐显 | 时间流逝、情绪转折 |
| **母题 / 物件呼应 graphic/motif match** | 前段末与后段首用同一母题物件或相似构图形状勾连(§3.6 图形匹配) | 主题呼应、时空跳转 |
| **有动机的直接硬切** | **仅当**前后段有强因果或强冲突反差(如"按下按钮"硬切"爆炸"),硬切本身就是叙事重音时才允许;必须在 plan 里写明这个动机 | 冲击、反转、强因果——**不是"想不出转场就硬切"** |

> **铁律:段落边界处若填不出上面任一种"缝法",就是没想清楚这两段的关系——回 §2 重答这两段各自"为了说什么",不许用无动机硬切蒙混过关。** 无动机硬切是"段落间全是硬切、观众看懵"的唯一元凶。

**C. 段级节奏包络(与 §5 咬合):** 每个段落自己也是一条小的镜长曲线——**段首建置镜偏长(从容落地)、段中按动作强度起伏、段尾收束镜偏长(情绪沉淀 + 为转场留呼吸)**。段与段之间用镜长的"松→紧→松"制造呼吸,不要全片一个语速硬切到底。

**D. 落地要求:** 凡 ≥2 段剧情的成片,必须先产出 `segment_plan`(见 §8.3):列出所有叙事段落、每段的"入-承-出"镜位、以及**每个段落边界登记的转场手法与缝合依据**。它是 `continuity_plan` 的上层结构——`continuity_plan` 锁"镜与镜"的空间道具连续,`segment_plan` 锁"段与段"的叙事落地与转场动机。**单段成片(只有一段事)不需要 segment_plan,但仍需段内"入-承-出"。**

## 4. 内容 → 镜头调度对应关系库（"拍这类内容 → 这样拍" 的核心可查库）

**这是本模块的主索引，也是把"拍什么"翻译成"怎么拍"的核心资产。** §2 的第 1、2 步先判定这一镜"拍什么(内容)+为了说什么(意图)"，然后到本库按**内容类别**直接查到"这类内容通常怎么拍"的成熟配方，再按 §2 第 5 步组镜 + 过硬把控落地。

本库把镜头层反复出现的内容切成 **12 类拍摄对象（C1–C12）**。每一类给：**① 常拍的内容**（画框里客观发生什么）· **② 常见意图**（拍它一般为了说什么，仍以剧本给定的情绪为准）· **③ 手法配方**（景别 / 机位角度 / 运动 / 构图 / 光影 / 画面内调度 / 剪辑时长七件套的默认取值）· **④ 真实拉片印证**（本宇宙成片里的确凿用例与其确切参数，供溯源与教学，**不作复刻**）· **⑤ 易错要点**（这类内容最常翻车的地方）。

> **用法：** 内容命中哪几类就并查哪几类（一镜可跨类，如"追逐中的打击"= C7+C8）；配方是起点不是终点，最终取值仍要回 §3 六维词典按本镜意图微调，动作类必叠 §4.5 炫技。所有配方**题材无关**——换世界锁后取值随之调基调，方法不变（§6）。

---

### C1 · 世界 / 环境建置（拍"这是什么世界、在哪、什么状态"）

- **① 常拍内容：** 泳池露台、螺旋滨海豪宅、沙滩尸场、海滨大道、弧形高架廊桥等空间与末世/繁华环境的全貌；常含片名或段落标题压字。
- **② 常见意图：** 交代地理坐标与世界状态，奠定原子朋克太空时代复古基调，用尺度对比确立"渺小的人 vs 宏大荒诞的世界"。
- **③ 手法配方：**
  - **景别**：大远景 / 全景为主，给足纵深。
  - **机位角度**：航拍高俯 45°–60° 悬停俯瞰，或平视对称正视地标。
  - **运动**：缓推 / 悬停下降前推 / 极缓俯移，或彻底固定 locked-off。
  - **构图**：消失点引导线、对角线海岸线、中心对称，水平线压上/下三分。
  - **光影**：使用该时段真实的现场日光或实用灯，保留纵深与可见光比；色彩继承 `color_lock`，不把“高调”当作整体提亮。
  - **画面内调度**：放一个小主体（人 / 机器人 / 坐骑）点缀确立尺度，或纯空镜靠光线与时间感变化维持"活画面"。
  - **剪辑时长**：2–3.5s，多用于段首建置；开场可压到 3s+ 从容进入。
- **④ 真实拉片印证：** SHOT5 螺旋豪宅航拍 45° 斜俯、悬停→下降前推带红字片名 3.03s；SHOT31 沙滩大远景航拍高俯极缓俯移、对角线海岸线 2.33s；SHOT46 白骨机器人极小立海滨大道黄双线正中、大远景固定中心对称消失点 5.00s；SHOT67 动物主体立弧形高架廊桥内逆光、巨曲面顶板强透视消失点落在夕阳 3.50s 空镜转场。
- **⑤ 易错要点：** 空镜也要有一个**尺度锚点**（小主体或地标）或**光线/时间变化**，否则是死画；消失点 / 对称轴 / 水平线必须压准，歪一点整个环境就散；别用中近景拍环境——环境要靠大景别给纵深。

### C2 · 角色 / 坐骑登场亮相（拍"这是谁，记住他"）

- **① 常拍内容：** 主角、坐骑、配角首次进入画面的亮相；常带签名动作（挑帽、举枪、面屏切色）。
- **② 常见意图：** 让观众瞬间记住并认同这个角色，赋予英雄感 / 存在感 / 怪奇感，锁定角色识别符（面屏色、姿态、识别色）。
- **③ 手法配方：**
  - **景别**：中近→中全逐步揭示（英雄），或大远景确立渺小存在（反英雄 / 苍凉）。
  - **机位角度**：低机位平视略仰做英雄化；确立位置时用平视 / 俯瞰。
  - **运动**：弧形环绕 orbit + 转身、背景向一侧流动；或干净固定让角色自己"立住"。
  - **构图**：主体压三分线或严格中心对称；另侧留逆光空。
  - **光影**：仅在太阳真正处于主体后方时使用自然逆光边缘；否则使用有明确方向的侧光。面屏/指示灯只对附近表面产生弱自发光，不变成全脸补光。
  - **画面内调度**：给一个**标志性动作 + 识别色切换**（如举左轮挑帽、面屏蓝→绿显示"SECTOR CLEAR"）。
  - **剪辑时长**：3–3.5s 稍长起幅，让亮相"被看清"。
- **④ 真实拉片印证：** SHOT3 机器人举左轮挑帽、面屏蓝→绿"SECTOR CLEAR"、近景长焦浅景深平视略仰 3.43s 硬切；SHOT9 弧形环绕 orbit + 转身、背景向左流动的英雄亮相、面屏蓝眼动机光、平视略仰 3.43s；SHOT46 大远景固定反衬渺小存在。
- **⑤ 易错要点：** 亮相镜要有"签名动作 + 识别色变化"，不能只是站着摆 pose；英雄感靠略仰 + 环绕，不是硬怼大脸；逐步揭示比一次全给更有登场仪式感。

### C3 · 日常 / 功能性动作（拍"他在干什么活、他是台什么机器"）

- **① 常拍内容：** 角色执行功能动作——比如机器人扫地、踏步、拾物、机械关节运作等细节。
- **② 常见意图：** 交代身份职能（主角在干活），用机械质感与微距细节强化"这是台机器"，承接叙事节拍。
- **③ 手法配方：**
  - **景别**：特写 / 近景为主，多为插入镜(insert)。
  - **机位角度**：极低贴地机位，贴着机械部件。
  - **运动**：贴地跟移、背景向一侧划过，或固定靠画内物体动。
  - **构图**：微距聚焦机械部件 / 手部，前景金属占主。
  - **光影**：硬光刻画金属、液压、转轴质感。
  - **画面内调度**：只承载**单一功能动作**，并留一个 match-on-action 点（如帽子腾空）给下一镜接。
  - **剪辑时长**：0.7–1.5s 短 insert，点到即止。
- **④ 真实拉片印证：** SHOT13 机械脚踝特写（金属液压转轴）踏步腾空、极低贴地跟移背景左移 0.73s insert；SHOT48 近地微距拾牛仔帽抛起、极低贴地固定、变化全靠画内物动 1.30s，帽腾空作 match-on-action 接后镜。
- **⑤ 易错要点：** 功能动作用 insert 特写点到即止，别整个全景拖时间；机械质感靠微距 + 硬光，离远了没质感；一个动作留一个 match 点给下一镜，别拍成孤镜。

### C4 · 非战斗表演炫技（拍"他很酷、很潇洒"）

- **① 常拍内容：** 转枪 / 收枪、原地旋转甩衣摆等非战斗的耍帅表演；常兼作片头 credit 或过场。
- **② 常见意图：** 塑造酷帅人设（机械赏金牛仔），用炫技本身取悦观众，并以动作标点（收枪入套）表达"威胁解除"等状态。
- **③ 手法配方：**
  - **景别**：特写→中近景（转枪），或全景顶拍（旋转）。
  - **机位角度**：平视贴近随手部，后段可下摇 tilt down 揭示；或正上方顶拍 bird's-eye。
  - **运动**：跟随手部的手持微移 + 下摇轻拉；或顶拍固定、主体自转。
  - **构图**：道具（枪 / 帽顶）居中，背景超浅景深化为色块；顶拍用冷暖左右分割。
  - **光影**：金属锐利高光反射天空，黑白强对比；正午硬顶光时投影短硬随动。
  - **画面内调度**：一个连贯的炫技动势（枪绕指旋转→接枪→回插枪套；身体顺时针快转、下摆运动模糊）。
  - **剪辑时长**：1.5–2.5s，可作全片最短镜之一制造节奏陡变，用动势顺接下一镜。
- **④ 真实拉片印证：** SHOT4 黑手套转不锈钢左轮、特写超浅景深、平视贴近后段下摇到腰、收枪入棕色雕花枪套作动作标点 2.43s；SHOT7 顶拍全身原地快速旋转（皮衣下摆强运动模糊）、bird's-eye 固定主体自转、暖沙 vs 冷泳池左右分割、正午硬顶光、1.5s 全片最短之一、旋转动势顺接下一镜抛甩。
- **⑤ 易错要点：** 炫技要有一个**明确的起—转—收**动作弧，不能一直转显得空转；背景务必虚化或简化，让观众聚焦手上功夫；用它当过场时靠动势方向顺接下一镜，别硬切断。

### C5 · 双人相遇 / 关系建立（拍"两个人开始有关系了"）

- **① 常拍内容：** 两个角色走近、对视、进入同一画框的相遇时刻。
- **② 常见意图：** 建立两人关系的起点，制造吸引 / 试探 / 心动的张力。
- **③ 手法配方：**
  - **景别**：中景 / 中近景，双人同框或过肩。
  - **机位角度**：平视，或过肩越前景人物拍对面。
  - **运动**：主体走近使其在框内渐大，或缓推；机位常固定让"靠近"发生在画内。
  - **构图**：过肩框架式（前景一人的躯干 / 机械臂框住对面），双人平衡。
  - **光影**：使用可见窗口、云层或开放阴影产生的有方向大面积自然光；保留脸部暗侧和遮挡，不加对称美容填光。识别色由 `color_lock` 与服装/面屏材料继承。
  - **画面内调度**：一方主动走近、另一方回应（面屏切色、转身、抬眼），把"关系发生"演在画内。
  - **剪辑时长**：3–3.5s，给足对视停顿。
- **④ 真实拉片印证：** SHOT53 紫墨镜面屏走近、过肩框架（前景红裙躯干 + 机械臂）、中景固定、主体渐大 3.50s；SHOT16、SHOT35 同属相遇 / 关系推进节拍。
- **⑤ 易错要点：** "相遇"要让靠近发生在画框内（走位或缓推），不能两人已经站定了才拍；过肩框架能瞬间建立"我在看你"的关系向量，别拍成两个各自为政的单人镜。

### C6 · 信息 / 灾变揭示（拍"发生了什么大事、给观众看关键信息"）

- **① 常拍内容：** 泳池停尸现场、腐烂头颅、旧报纸标题"ZOMBIE VIRUS OUTBREAK"等揭示灾变真相或关键信息的画面。
- **② 常见意图：** 让观众读到"世界出事了 / 这是什么威胁"，交代设定与危机。
- **③ 手法配方：**
  - **景别**：插入特写（读信息：报纸 / 头颅），或大远景定场（读现场规模）。
  - **机位角度**：平视 / 低机位平视，让信息正对观众；现场用固定长焦。
  - **运动**：固定定镜供"静态扫读"，或正面后退跟拍让威胁压来。
  - **构图**：信息主体居中占满，或小主体点在大现场里显规模。
  - **光影**：清晰可读为第一，使用现场光的遮挡、阴影与光比建立灾变感；不另加冷色全局滤镜。
  - **画面内调度**：让关键物件入画 / 被翻开（机械脚从右入画踩住头颅、报纸正面奔来），信息"被递到眼前"。
  - **剪辑时长**：读信息可短至 0.97s 硬递，定场现场 2–2.5s 静态扫读；灾变奔来可拉到 5s。
- **④ 真实拉片印证：** SHOT6 泳池停尸现场全景、机器人小身影、大远景固定长焦 2.43s 静态扫读；SHOT10 腐烂头颅特写 + 机械脚从右入画、低机位平视固定 0.97s；SHOT34 旧报纸标题特写"病毒爆发"+ 正面后退跟拍 5.17s。
- **⑤ 易错要点：** 信息镜第一要义是**看得清读得到**，别为炫技牺牲可读性；定场揭规模靠"小主体 + 大现场"的尺度对比；关键物件要主动入画或被翻开，别静静摆着等观众找。

### C7 · 追逐 / 疾驰（拍"跑起来、追上来、快到极点"）

- **① 常拍内容：** 追逐、骑坐骑沿沙滩 / 公路高速奔驰，反派同向追赶；被障碍甩飞。
- **② 常见意图：** 制造速度爽感与紧张，让观众心率随之飙升。
- **③ 手法配方：**
  - **景别**：中景为主，夹贴身近景。
  - **机位角度**：侧向并行跟拍、后退跟拍或平视，偶尔贴地 / 荷兰角。
  - **运动**：大幅横向跟移 track / pan 让背景飞速划过；后退跟拍 track back 让主体缩向消失点；末段可失稳。
  - **构图**：三层纵深、一点透视消失点；主体钉三分线、背景高速飞驰（相对位移）。
  - **光影**：选择可成立的硬直射光与较高光比强化速度，但不更换 `color_lock` 或添加冷色调色。
  - **画面内调度**：坐骑与追赶物同框构成追逐关系；障碍（倒下的棕榈）介入把主体甩离。
  - **剪辑时长**：段内可长镜（4–5s）展现纵深疾驰，也可切成 0.6–1.6s 短碎切拉节奏；方向必须顺接不迷向。**必叠 §4.5 ≥2 类炫技。**
- **④ 真实拉片印证：** SHOT32 骑坐骑沿湿沙高速奔驰、反派同向追、大幅横向跟移背景右→左划过、三层纵深 4.77s；SHOT33 沿公路双黄线向纵深狂奔、后退跟拍主体缩向消失点、一点透视 4.00s；SHOT44 疾驰被倒棕榈甩离腾空、侧向并行跟拍 + 手持晃动末段失稳、棕榈干对角贯前景 3.00s。
- **⑤ 易错要点：** 只用平视侧跟一镜到底再干净也"平"——摄影机必须参与（相对位移 / 后退跟拍 / 甩镜）；方向要顺接，越轴就迷向；至少叠两类炫技手法，不能停在朴素跟移。

### C8 · 打斗 / 暴力冲击（拍"打中了、砸碎了、撞飞了"）

- **① 常拍内容：** 抛甩物体、顶枪抵头贴身对峙、抱摔高侧踢清群、砸碎玻璃、被击飞等冲突内容。
- **② 常见意图：** 传递打击的重量与冲击爽感，"炫酷"本身就是这一镜被授权的意图。
- **③ 手法配方：**
  - **景别**：近景 + 插入受击细节，或极低仰拍全身放大威慑。
  - **机位角度**：贴近、略仰 / 极低 worm's-eye，让动作压向观众。
  - **运动**：手持急推 crash-in / 急摇咬住命中点；强动感手持甩拍 + 快速横移；末段可由动到静收势。
  - **构图**：满构图、失衡；被甩物体强运动模糊横扫镜头前。
  - **光影**：硬光、高光比；命中 / 爆炸瞬间过曝闪白（火球撞蓝天）。
  - **画面内调度**：一个清晰的打击动作（顶枪、抱摔、挥砸）+ 母题情绪出口（面屏红凶脸 / 红怒→白笑）。
  - **剪辑时长**：极短切 0.8–1.5s + 命中帧 1–3 帧冲击定格；也可用一镜长镜由动到静收束。**必叠 §4.5 ≥2 类炫技。**
- **④ 真实拉片印证：** SHOT8 极低仰拍抛甩尸体、人体强模糊横扫镜前、worm's-eye 固定略跟摇 2.13s；SHOT39 顶枪抵丧尸头颈贴身对峙、红 LED 凶脸、平视略仰贴近 0.80s 极短强冲击；SHOT37 蘑菇火球满屏被炸飞翻转滑铲起身、强动感手持甩拍 + 快速横移、火球过曝橙撞蓝天 3.00s 一镜；SHOT59 挥臂砸抓娃娃机玻璃放射龟裂爆碎、近景固定冲击镜、变化全在碎裂 1.00s 硬切；SHOT41 格斗收势 + 面屏红怒→白笑、手持跟拍 + 小弧环绕末段近固定 11.40s 长镜由动到静。
- **⑤ 易错要点：** 打击要有明确的**接触帧**并强调它（定格 / 慢镜 / 闪白），否则没重量；把动作拍成干净平淡的记录 = 打回；面屏情绪出口要在打击前后切色，让机器"有情绪"。

### C9 · 情绪 / 内心抒情（拍"他此刻的心情"）

- **① 常拍内容：** 表情，如机器人面屏大特写（笑脸 / 悲伤 / 心动曲线 / 死机 ╳ / 爱心）、背身剪影远眺落日、戴帽微表演等承载内心、表达明确情绪的画面。
- **② 常见意图：** 让观众读到角色情绪，把无对白机器主角的"心"外化出来。
- **③ 手法配方：**
  - **景别**：近景→大特写为主；抒情远眺可用背身剪影中景。
  - **机位角度**：正面平视微仰贴近；背身用 over-the-back。
  - **运动**：固定或极缓推，留够停顿；情绪不靠运动靠画内变化。
  - **构图**：中心、浅景深虚化背景；或逆光暗剪影 + 负空间；纵深处放关联对象（红裙女伴小身影）。
  - **光影**：面屏 / LED 自发光作唯一或主要动机光（黑绿高对比笑、黄光悲伤、红逆光唯一主动光）。
  - **画面内调度**：**母题情绪出口按序切换**（面屏图案 / 色码：疑惑→惊喜→死机→爱心；红怒→白呆萌），这就是无对白片的"台词"。
  - **剪辑时长**：1–5s，情绪高光镜留够时间让表演走完。
- **④ 真实拉片印证：** SHOT17 面屏大特写绿弯眼笑、平视贴近固定、黑绿高对比自发光 1.17s；SHOT52 面屏大特写心动曲线疑惑→惊喜→死机(╳)→爱心、大特写平视微仰固定 5.00s 表演高光；SHOT49 双手戴牛仔帽、面屏红怒→白呆萌、强逆光 LED 唯一主动光 4.23s；SHOT65 侧脸大特写黄色悲伤 + 纵深处女伴小身影、浅景深长焦固定 2.43s；SHOT11 背身剪影扶帽远眺落日 + 海鸥入画、逆光暗剪影 1.57s。
- **⑤ 易错要点：** 情绪出口（面屏 / LED）必须写明**此刻显示什么、何时切换**，不能留空让模型乱猜；一镜只承载一条情绪弧（别把五种表情塞进一镜）；抒情靠光与停顿，不要靠运镜抢戏。

### C10 · 荒诞喜剧 / 反差幽默（拍"这画面又酷又好笑")

- **① 常拍内容：** 在废墟/荒芜上打造喜剧效果，如管道上独舞、宝丽来吐照片、过肩抱一捧泰迪熊、过山车并坐、约会中角落露出尸体等违和并置。
- **② 常见意图：** 用一本正经的反差制造黑色幽默，让恐怖与浪漫在同框里"荒诞地共存"。
- **③ 手法配方：**
  - **景别**：中景，或对称大特写把违和物摆正中。
  - **机位角度**：正面平视刻意中心对称，或极低仰拍配大留白。
  - **运动**：固定机位做"喜剧凝视"（让观众自己发现笑点），或车载 POV 固定 + 背景飞速横移。
  - **构图**：严格中心对称，把违和物 / 反差点放正中；恐怖元素藏进角落（右下尸体）。
  - **光影**：可以选择明亮环境，但仍保留现场光源方向、局部遮挡与自然光比；“正经”来自固定机位和表演，不来自棚拍式全面提亮。
  - **画面内调度**：一个"一本正经做荒诞事"的动作 + 母题出口反应（面屏红→绿）。
  - **剪辑时长**：可极短硬切制造突兀笑点（0.57–1.6s），或稍长"憋住"停顿后切。
- **④ 真实拉片印证：** SHOT14 管道上独舞、极低仰拍固定、天空大留白 0.97s；SHOT57 宝丽来吐照片特写→溶接 dissolve 影院两人依偎 4.63s 叠化转场；SHOT61 过肩抱一捧泰迪熊、面屏红→绿、固定过肩、ZEPHYR 灯箱对称轴动机光 1.63s 硬切；SHOT62 过山车前排并坐绿笑、车载 POV 固定 + 背景飞速横移 2.03s 硬切；SHOT56 草地并坐自拍 + 右下尸体 0.57s。
- **⑤ 易错要点：** 喜剧靠"正经的对称构图 + 荒诞的内容"反差，别用花哨运镜抢笑点；恐怖 / 违和元素点到即止藏角落，观众自己发现最好笑；憋住停顿再切，比急着切更有喜感。

### C11 · 仪式 / 浪漫长镜（拍"这一刻很美、很神圣、值得停留")

- **① 常拍内容：** 女伴天窗光柱下亮相、太空时代餐厅共餐、月牙湖公园并坐、黄昏长椅看落日、影院依偎等浪漫仪式时刻。
- **② 常见意图：** 沉淀情感、赋予神圣 / 浪漫仪式感，让观众在长镜里"停下来感受"。
- **③ 手法配方：**
  - **景别**：全景→中近景，双人同框或过肩。
  - **机位角度**：平视略俯 / 略仰，或高空顶俯后硬切平视（宏观→亲密）。
  - **运动**：缓慢推轨 push-in 或稳态固定长镜；宏观航拍后硬切到地面亲密。
  - **构图**：中心对称、天窗 god ray 圣像布光居中；框架式（幕墙 / 舷窗）；室内暖 vs 室外冷分区。
  - **光影**：使用可见天窗、窗户或单组实用灯建立方向；光柱只在尘雾介质可见时出现。受光区与环境暗区有清楚衰减，不用镜头正面柔光保证完美人脸。
  - **画面内调度**：两人共处的安静动作（共餐、并坐、依偎、看落日）+ 环境里的反差点（幕墙外丧尸拍窗）。
  - **剪辑时长**：4.5–9.5s 长镜，全片最长动态镜多出于此，减少切点保连续。
- **④ 真实拉片印证：** SHOT51 红裙女天窗光柱下叉腰立圆台、全景平视略俯固定、天窗 god ray 圣像布光、红裙唯一高饱和 2.53s；SHOT54 太空时代餐厅卡座共餐 + 幕墙外丧尸拍窗、缓慢 push-in 全景→中近景、室内暖 vs 室外冷 9.47s 全片最长动态；SHOT55 航拍月牙湖公园全景 + 末帧硬切地面双人并坐、高空顶俯→硬切平视 3.73s 宏观→亲密；SHOT64 黄昏海边长椅背对看落日 + 僵尸逼近被一击击飞、大远景剪影中心对称固定长镜 5.07s（暴力以剪影呈现，不破坏浪漫）。
- **⑤ 易错要点：** 仪式 / 浪漫要靠**长镜 + 少切点 + 对称聚光**沉淀，急切就破功；把恐怖元素以剪影 / 远景低调处理，别让它抢走浪漫主调；宏观→亲密的硬切（航拍接地面）是廉价又高效的情绪落点。

### C12 · 收尾 / 离场 / 太空（拍"结束了、飞走了、余韵")

- **① 常拍内容：** 火箭点火升空、母舰引擎爆发、舱内隔舷窗对坐、照片失重悬浮、"END"字幕收束。
- **② 常见意图：** 收束全片、留余韵，用尺度升华（飞向深空）与环形呼应（回到照片 / 并坐母题）给情感落点。
- **③ 手法配方：**
  - **景别**：大远景（升空 / 母舰）→ 近景（舱内）多层收拢。
  - **机位角度**：跟随式 / 多角度柔和停留；舱内平视。
  - **运动**：跟随式运镜送主体离场，或全片最长稳态长镜。
  - **构图**：深空黑负空间；舷窗 frame-within-frame 把地球 / 主体居中；对称收拢、环形呼应前文母题（并坐 / 合影）。
  - **光影**：引擎爆发橙金 vs 深空黑高对比；舱内暖冷交融柔和低对比。
  - **画面内调度**：点火→引擎爆发的奇观动作；舱内照片在失重中悬浮的余韵动作。
  - **剪辑时长**：5s 奇观镜 + 全片最长（近 20s）稳态收尾长镜，环形呼应开场 / 中段母题。
- **④ 真实拉片印证：** SHOT68 球形太空舱点火→切庞大母舰环形引擎爆发橙金、大远景跟随式运镜、深空黑负空间 5.13s；SHOT69 舱内捧合影→两人隔舷窗对坐照片失重悬浮→黑底血红"END"+ 署名字幕、近 20s 全片最长稳态长镜、舷窗 frame-within-frame 地球居中、环形结构呼应中段合影 19.78s。
- **⑤ 易错要点：** 收尾长镜要"稳"，减少切点让情绪落地，别在结尾还碎切；用环形呼应（回到开场 / 中段的母题物件）比新画面更有余韵；奇观（升空）与亲密（舱内）要分两镜给，别挤一镜。

## 4.5 动作场面炫技升级库（把动作拍到"炫酷"而不是"干净"）

**这是本次优化的核心补强。** 动作戏"看得清"只是及格；"炫酷"要的是**速度、冲击、失衡、动势**被摄影机主动放大。经验教训：一个漂亮的腾跃/奔跑若只用平视侧向跟拍一镜到底，再干净也是"平"——因为摄影机没有参与动作。**动作节拍必须从下面五类里叠加使用炫技手法，不能停在朴素跟移。**

| 升级类别 | 具体手法（可叠加） | 拍出的感觉 |
|---|---|---|
| **① 速度感** | 贴地低机位 + 运动模糊；高速平移跟拍；**速度渐变(speed ramp：起跳升格慢、落地瞬间降格快)**；**主体钉在三分线、背景高速飞驰(相对位移)**；随主体甩镜(whip/swish pan) | 主体"快到摄影机追不上" |
| **② 冲击感** | 急推(crash-in)/急拉咬住命中点；手持急摇随冲击抖动；**命中瞬间过曝闪白**；**冲击定格(freeze) 1–3 帧**；关键接触帧插入慢镜强调 | 一拳/一扑/一落地"砸进观众身体" |
| **③ 空间动势** | **弧形环绕跟拍(主体转、背景 360° 转)**；贴身跟拍穿越前景遮挡；荷兰角制造失衡；极低贴地 / 极高俯压机位；一个连续动势镜跟完"越过障碍物"的整段腾跃 | 动作有了立体空间与包裹感 |
| **④ 剪辑动势** | **match-on-action 动势链**(动作 A 起→切→动作 A 落，隐藏切点)；方向顺接不迷向；0.3–1s 极短碎切拉心率；跳切(jump cut)加速；因果剪辑(动作→结果顺接) | 剪辑本身在"加速"动作 |
| **⑤ 焦段心理** | 长焦压缩制造迎面压迫/宿命逼近；广角贴近制造畸变与张力；浅景深把飞驰主体从背景"拔"出 | 用焦段放大心理距离 |

**动作节拍炫技下限（硬要求）：** 每个动作节拍**至少叠加 ≥2 个不同类别**的手法（如"①速度感 + ④剪辑动势"，或"③空间动势 + ②冲击感"）。**单纯平视侧向跟拍一镜到底 = 未达标**，退回按本库重排。

**典型动作节拍 → 推荐炫技组合：**
- **腾跃 / 越障**：③连续动势环绕跟 + ①速度渐变(起跳升格) + ⑤长焦压缩，落地接②冲击定格。
- **奔跑 / 追逐**：①主体钉三分线背景飞驰 + ④短碎切方向顺接 + ③偶尔贴地/荷兰角，动静交替给一个手持贴身近景。
- **打击 / 碰撞**：②急推咬命中点 + 过曝闪白 + 冲击定格 + ④match-on-action，插入受击部位细节。
- **冲刺 / 提速**：①贴地低机位运动模糊 + 高速平移跟拍 + ⑤浅景深 + ④极短切。

> **与"反炫技红线"的关系（重要澄清）：** §2 红线反的是"**不服务任何意图、且拖累可读性**的炫"。而在动作/奇观节拍上，**"炫酷"本身就是这一镜的叙事意图**——观众要的就是速度与冲击的爽感。因此这里的炫技是**被授权且被要求的**，不受红线压制；红线只在"炫技让给定动作看不清"时才生效（可读性永远 > 炫技）。**授权炫，但不越可读性。**

## 5. 节奏与时长曲线（可量化的剪辑呼吸）

节奏本身就是情绪。**镜头时长不是"配一个大概值"就行——它是一条要被主动设计、并在成片后被实测核对的曲线。** 上一版失败片的死因之一就在这里:41 个切点里镜长中位数 2.67s、40 段中 37 段全挤在 1.5–3.7s,像节拍器一样等间隔切——**观众感到的不是节奏,是"匀速轰炸、没有呼吸"**。本节把时长从"建议"升级为"可量化、可核对的硬约束"。

- **三档时长语法：**
  - **动作/紧张段 = 0.6–1.6s 短镜密集切**：追逐、打斗、冲击、突发——碎切拉高心率。
  - **叙事/表演段 = 2–3.5s 常规镜**：占全片多数，交代动作与情绪读取。
  - **情绪/建立段 = 4.5–20s 长镜**：空间建立、浪漫、抒情收尾——长镜沉淀情绪、减少切点、保连续。
- **总曲线：越动作越碎、越抒情越长。** 一部作品的镜长曲线应随**用户给定的情绪节拍**起伏：情绪平稳段（中速）→ 危机/冲突段（碎切、镜长骤降）→ 抒情/收束段（镜长拉到最大）。若用户未给情绪节拍，则按各段动作强度定档（打斗追逐段碎、对话表演段常规、空间建立与收尾段长镜）。
- **首尾长镜包络**：开场压一个稍长的建置镜（从容进入），结尾压一个全片最长的抒情镜（情感沉淀 + 环形呼应）。
- **动静交替**：碎切动作段后接一个固定/缓慢长镜让观众喘息；不给喘息 = 疲劳，全程喘息 = 拖沓。
- **平均镜长**是节奏基调的粗标：越快剪（均值低）越紧张商业，越慢剪（均值高）越作者/抒情。据题材定基调后再局部起伏。

### 5.1 相邻镜时长对比度（防"节拍器式匀速切"的硬规则）

光"跨≥2 档"不够——若把长镜全堆在头尾、中间一大段全是 2.5s 匀速切，观众照样累。**真正的节奏来自"相邻镜之间的长短对比"**：

1. **禁止长时间同档匀速**：**不允许连续 ≥4 个镜落在同一时长档且彼此时长差 <0.5s**（这就是"节拍器"症状）。每 3–4 个常规镜之内，必须插入一个明显更短(短镜档)或更长(长镜档)的镜打破匀速。
2. **对比度指标(成片可量)**：整段镜长的**最长镜 ÷ 最短镜 ≥ 3**（上一版失败片实测仅 9.57÷0.74≈13 但那是两个孤例，主体全挤中段——所以还要看下一条）；且**中段(去掉首尾各一镜)不得所有镜长都落在 1.5s 宽的窄带里**。
3. **切点由内容决定，不由固定拍子决定**：每一刀落在哪，取决于"这一镜的动作到位了没、情绪读到了没、信息交付完了没"(§3.6 切点动机),**不是每隔 ~2.7s 到点就切**。同一段里,动作快的镜天然短、情绪重的镜天然长——让内容去撑开镜长差异。
4. **长镜要真的敢长**：收尾抒情长镜给到 **4.5s 起、能到 8–20s**;别把"长镜"做成 3.5s 的"稍长镜"充数(上一版最长的所谓收尾也才普通时长,情绪根本没落地)。

### 5.2 时长必须显式标注 + 成片后实测核对（把"看时长"落成动作）

**时长不能停在脑子里"感觉跨了档",必须写下来、并在成片后量出来核对：**

- **计划阶段**:每份 `cinematography_plan` 的 `剪辑与衔接` 字段必须写死**本镜目标时长(秒)**;`rhythm_plan` 汇总成一张**镜序→目标时长**的表,画出这条曲线,肉眼确认它有起伏、不是一条平线,且首尾是长镜。
- **拆镜阶段**(§4b):每个 clip 的目标时长 = 该镜 `rhythm_plan` 值;生成时按此时长出 clip,不足则补时长、超了则剪。
- **成片阶段(硬要求,治本)**:成片拼好后,**必须实际测量成片的镜长分布**——用工具按切点切出每段时长(如用 ffmpeg 的场景切分 `select='gt(scene,0.3)',showinfo` 导出切点时间戳,再算相邻差),得到一张**实测镜长表 + 中位数/均值/最长/最短/最长÷最短比**,与 `rhythm_plan` 计划曲线逐镜比对。
- **实测判据(任一不满足即打回重剪)**:①实测曲线形状与计划一致、有起伏;②不存在"连续≥4 个镜同档且差<0.5s"的匀速段;③最长镜÷最短镜≥3;④收尾镜是全片最长档且≥4.5s;⑤中段镜长不全挤在 1.5s 窄带。**上一版就是从没做过这步实测,才让"中位数 2.67s、全挤 1.5–3.7s"的匀速片蒙混出厂。**

## 6. 类型无关 / 台词无关的通用性说明

镜头语言是**通用语法**，不绑题材。视觉系统换一套世界锁（换成太空歌剧、黑色电影、田园牧歌），本模块的六维决策与硬把控**原样适用**——只是各维的具体取值随题材调基调。

**按题材偏重不同维度（基调建议，不是限制）：**
- **惊悚 / 恐怖**：偏重光影（低调、高光比、底光）+ 构图（失衡、暗部负空间、框架式偷窥）+ 剪辑（慢推后突切）。
- **浪漫**：偏重景别（近景/特写）+ 有明确现场来源的大面积侧光/窗光 + 运动（缓推、框架式）+ 长镜。不使用正面美容柔光或因浪漫而重新调色。
- **动作 / 追逐**：偏重运动（手持、跟拍）+ 剪辑（短碎切、平行剪辑）+ 机位（贴地、荷兰角）。
- **西部 / 史诗**：偏重景别（大远景）+ 构图（消失点、水平线）+ 机位（低机位英雄化、航拍）+ 长镜。
- **黑色幽默 / 荒诞**：偏重构图（严格中心对称）+ 机位（正面固定凝视）+ 节奏（憋停顿后切）。
- **科幻 / 悬疑**：偏重景别推进 + 揭示式运动（拉远/摇出）+ 冷暖光比对照。

**无台词 / 弱台词片的特别法则（画面必须能脱离台词独立叙事）：** 台词缺席、或台词单薄时，信息与情绪全部压到镜头调度上。**核心铁律:台词只做"点睛",不做"信息拐杖"——把台词全部静音后,观众仍应看懂"谁、在哪、发生了什么、什么心情"。做不到,就是画面没在叙事、全靠台词硬撑,台词一薄整片就空(上一版失败片的病灶之一)。** 具体手段:
1. 用**走位与视线**代替对白交代关系（谁看谁、谁靠近谁、谁背对谁）；
2. 用**特写 + 插入**把"内心"和"因果证据"拍出来（表情、手部、道具状态、母题情绪出口）；
3. 用**运动**代替旁白推进（推近=注意这里、拉远=事情更大了、跟随=跟着谁走）；
4. 用**声音设计**（环境声、音乐、动效）承担台词让出的信息通道；
5. 剪辑更依赖**动作剪辑与因果剪辑**保证"没有话也看得懂前因后果"；
6. **母题情绪出口 = 无台词片的"台词"**：功能性/机器主角靠面屏图案与颜色切换表达情绪，凡资产带情绪出口，关键镜必写明它此刻显示什么、何时切换（§3.7）。

> **脱台词自检（组镜与质检都要过）：** 逐段问一句——"把这段的台词全删掉，观众还看得懂这段在讲什么、主角什么心情吗?" 答"看不懂/只剩漂亮空镜"→ 该段信息全压在台词上，画面失职，回本节 1–6 用走位/视线/特写/插入/运动/母题出口把信息重新落到画面上。**注意:本系统不写台词、不改台词内容(那是上游编剧的事)；本条只保证"画面自己能站住",不越界去补台词。**

## 7. 好莱坞质感门 / 镜头调度门（接入总控阶段 5）

放行成片前，除视觉门外，本模块提供一道**镜头调度门**。它**只管"拍得够不够电影感"**，不管故事好坏（故事由用户/上游 agent 负责）。前置要求：该镜的动作与信息本身已经清楚（可读性达标）；本门在此之上只评质感，**永不为质感牺牲可读性**——若一个镜头因炫技而让给定动作看不清，先砍炫技保动作。

不以一个总分掩盖根因。所有硬项必须通过；“视觉硬把控”“实拍光照与连续性”“序列级硬处方”“意图匹配”任一低于 3 分直接打回；**§1.9 的真实摄影连续性或任何序列级硬处方不满足，无论其它项多高，一律退回重生成，不进放行**。

| 项目 | 通过条件 |
|---|---|
| 内容与意图先行 | 每镜先答清"拍什么(内容,来自剧本)"与"为了说什么(意图)"两个字段;二者缺一,或六维手法无法追溯回这两个字段(即"先挑运镜再套内容"的炫技先行),直接打回。 |
| 视觉硬把控（单镜） | §1.1–§1.8 逐条成立：主体分离、光比/色温服务情绪、动机光、胶片质感、构图秩序、运动有动机、一镜一意图。 |
| 实拍光照与连续性 | 每镜先有完整 `实拍光照卡`，再有光影描述；主光、阴影、补光、曝光、材质高光和光学效果相互成立，并与 `lighting_ledger` 连续。背光主体被无来源正面填亮、多方向阴影、暗面整体抬平、每条边均匀亮边、无条件耀斑，任一项即打回。 |

| 人物表面 | 真人镜头中皮肤保留毛孔与微纹理，整体哑光至微丝光，面部高光小而有因；头发自然分束、低至中光泽，无无理由的发油湿亮感。 |
| 序列级硬处方（成片） | §1.9 八条逐条成立（景别跨度 / 时长跨度含收尾长镜 / 意图多样 / 运动多样 / 光影变化 / 母题特写 / 衔接缝合 / 动作节拍炫技达标）；任一条不满足即一票否决。 |
| 意图匹配 | 每镜的六维组合确实服务其"拍什么 + 为了说什么"（§2 第 1、2 步写的那两句），每个手法都能追溯回内容或意图,无炫技空转。 |
| 主导维度清晰 | 每镜能指出哪一维承载核心意义，其余维度做支撑不抢戏。 |
| 六维协同 | 景别/机位/运动/构图/光影/剪辑互不打架（如浪漫镜没用硬光高对比、追逐镜没用死板固定长镜）。 |
| 画面内调度（第七维） | §3.7 落地：每镜画框内有可读的主体走位/主动作/微表演，母题情绪出口（面屏/指示灯等）显示什么、何时切换写明，次要运动到位；无"主体摆 pose 发呆的空镜"。 |
| 节奏曲线 | 镜长随给定情绪节拍（或动作强度）起伏，三档时长语法在位，动静交替，首尾长镜包络。**§5.1 对比度达标:无"连续≥4 镜同档差<0.5s"的匀速段、最长÷最短≥3、中段不挤在 1.5s 窄带；且已按 §5.2 实测成片镜长分布核对(不是凭感觉)。** 匀速节拍器式切(如中位数~2.7s 全挤 1.5–3.7s)= 打回。 |
| 运动动机与稳定 | 每次运动可说清"为什么这样动、起幅→落幅"，质地（手持/稳态/固定）匹配情绪。 |
| 连续性衔接 | 切点有动机，动作/视线/方向/声音桥接得上，不越轴、不迷向（与 `continuity_plan` 一致）。 |
| 段落转场（成片，≥2 段剧情） | 每个叙事段落有"入-建置镜/承/出-收束镜"三件套；每个段落边界在 `segment_plan` 登记了转场手法与缝合依据（§3.8），**无一处"无动机直接硬切"**；换场处有建置镜让观众重新落地。段与段硬切成一锅、观众看不懂"现在在哪/发生了什么"= 打回。 |
| 脱台词可读性 | 把成片台词全部静音后，观众仍能看懂每段"谁/在哪/发生了什么/什么心情"（§6 弱台词法则）。信息全压在台词上、画面只是漂亮空镜、台词一删就看不懂 = 画面失职，回 §6 用走位/视线/特写/插入/运动/母题出口把信息落回画面。 |

**修复优先级：** 先修第一个失效项。**实拍光照卡为空、太阳/阴影/补光互相矛盾或跨镜漂移→先回 §1.4 与 `lighting_ledger` 重定时间、主光、遮挡、曝光和机位，再重推其它维度；不得用滤镜、颗粒、雾或后期调色掩盖。**内容/意图没写清或手法追溯不回内容+意图→回 §2 从第 1、2 步重答“拍什么+为了说什么”,再据此重推手法；序列级硬处方崩→回 §1.9 逐条补；意图不匹配→回 §2 重走七步；节奏平→回 §5 重排镜长曲线；运动无动机→回 §3.3 换朴素镜或补动机；接不上→回 `continuity_plan` 和 `lighting_ledger` 锁空间、状态与光线；段落间硬切成一锅/看不懂→回 §3.8 补段级“入-承-出”与 `segment_plan`。**

**填写纪律：**
- **先填根、再填枝**：`本镜拍什么_内容`(客观内容,来自剧本)、`叙事意图_情绪`(为了说什么)、`色彩锁确认`和`实拍光照卡`是全镜的根，必须最先写死；六维与画面内调度是枝，每一维的“为什么”都要能追溯回这些根字段。填不出根就不许填枝。
- 每一维都要写“是什么 + 为什么（动机）”，尤其运动必须写“起幅→落幅 + 动机”；光影必须完整转写 `实拍光照卡` 的主光、阴影、补光、曝光与光学条件；`画面内调度` 必须写“画框内此刻发生的具体动作/表情/母题出口状态”。
- 真人镜头的 `人物表面` 不得留空；不使用“完美皮肤、精致光泽、光亮发型”一类会把人物推向油亮模型感的描述。
- **具体帧描述 > 类别标签**：每个字段写的是"这一帧模型该生成什么"，不是配方类别名。写"面屏由待机白切爱心红、主体身体前倾双手握住对方的手"，不写"表达浪漫情绪"；写"手持镜随主体腾跃急摇甩过、落地瞬间降格顿一下"，不写"动作炫技"。凡字段只填了类别标签（如"浪漫""紧张""亮相""炫技"）而无可生成的画面，即视为未完成，退回补写。
- 主导维度只能有一个；其余维度是支撑。
- 不得把两个转折、多次景别切换塞进同一份 plan（对应同一条生成 Prompt）——拆镜。
- `参考出处` 是可选溯源，缺省不影响。

## 8.2 从 plan 到成片 Prompt：三段式满级输出模板（**最终交付给生成模型的形态**）

`cinematography_plan`（§8）是**给人读的结构化调度方案**；生成模型最终吃的是一条**成片 Prompt**。**不要把 plan 的七个字段拼成一行流水或一张要点表丢给模型**——那样太像调度表，模型读不动、还原不到电影水准。要把 plan **重排书写成下面三大段落**，段内每句都"能生成一帧确定画面"。这套三段式结构是从可复现的满级真实 Prompt 提炼的骨架，是本 skill 每条镜头 Prompt 的**标准输出形态**。

### 三段骨架

```

【基础设定】

景别：<景别 + 焦段/景深的具体取景>。构图：<分区 + 占比 + 方向：主体钉哪条线/占几分之几、次要主体压哪侧、透视/引导线/地平线、留白给什么>。
运镜手法：<运动词 + 起幅→落幅 + 机位角度；动作镜叠加 ≥2 类 §4.5 炫技手法>。
画面内容：<逐拍可执行动作链——直接按名字 cue 资产(如"主角机器人""鸵鸟""雷管炸弹")，写它先做什么→再做什么→母题情绪出口在哪一拍从X切到Y→次要主体/环境同时在做什么→本镜以什么动势收尾；资产的长相/材质/服装一律不复述，以资产图为准>。
```

> **媒介宣告必须放在最前、且是肯定句：** 先用“真人实景电影镜头影像、真实摄影机、实体道具、现场物理受光”建立媒介，再把“原子朋克/复古未来”写成被摄世界的年代与美术设定。不用“超写实”“反 CG”等标签补救，而是写足光源、遮挡、阴影、曝光、皮肤/头发反射和实际材质。

> **色彩块与光照块不得合并：** `color_lock` 始终逐字不变；实拍光照块只写亮度、阴影、遮挡、弱反射、曝光和材质高光。修复假光时只重写实拍光照块，不重写色彩块。

> **资产不在【基础设定】里复述！** 角色/道具/坐骑等资产都有绑定好的资产图，形象一切以资产图为准——文字复述纯属冗余且会与资产图打架。**资产只在【画面内容】里按名字直接 cue**，配上它在本镜的动作与状态即可。【基础设定】只承载资产图里没有的两类信息：**场景**（地点/时间/灾变状态）与**声音**（配乐取舍 + 同期声/音效）。

> **三段与七维的映射**：【基础设定】= 场景锁 + `台词`/`音效`（资产靠资产图，不在此复述）；【氛围与画质】= 固定视觉锁的本镜实例（`光影`/`焦段_景深` + 世界锁）；【画面内容】= `分镜`/`景别`/`构图`/`镜头运动`/`机位与角度`/`画面内调度`/`动作炫技叠加` 的可执行落地，资产在此按名 cue。**七维一个都不能丢，只是换成模型能演的写法、按这三段重排。**

### 满级范例（由 §8.1 范例 A 那份 plan 落成的成片 Prompt，示范颗粒度）

> 下面把范例 A 的 plan 落成一条能直接喂给生成模型的三段式 Prompt。**注意长度与逐拍颗粒度**——这才是"不简化、能还原电影水准"的标准；停在一两句概述就是没写完。**资产（主角机器人等）不在【基础设定】里描述，只在【画面内容】里按名字 cue，长相/材质/服装全部以资产图为准。**

```
媒介宣告：真人实景电影镜头影像，由真实电影摄影机与中焦镜头拍摄；实景海滨置景、实体道具、实体表演、现场海岸日光、自然中景深、真实镜头光学和克制胶片颗粒。
【基础设定】
场景：海滨度假带-泳池露台通向海面的长街，黄金时刻白天，灾后衰败但表面安逸。地面散落酒瓶、宝丽来照片、暗色血迹（母题状态物，仅被瞥见、不强调），中景泳池救生圈，右侧弧形豪宅。
声音：不需要配乐、不要氛围配乐音，仅保留同期声——海浪声、海边鸟类叫声、微风拂过棕榈的叶片摩擦沙沙声、赤脚踏地的自然行走环境音。

【氛围与画质】
风格核心：被拍摄的世界是 1960 年代美国西海岸原子朋克，实景搭建、实体年代道具和有使用痕迹的真实材料；本镜的氛围是末日度假幻象下的慵懒忧郁。
视觉基调：中焦、中等景深、真实行走动态模糊，克制胶片颗粒和轻微光学呼吸；不堆摄影机品牌或额外滤镜。
色彩锁：色彩固定为复古暖橙 + 海盐蓝的高对比体系，保持现有的饱和、明快、干净与复古反转片调性。复古暖橙落在日照、暖木、旧漆、店招、锈蚀与少量叙事重点；海盐蓝落在蔚蓝天空、海水、玻璃、环境冷色与少量旧漆面。干净白色材料保持中性清洁；只有真正风化、蒙尘、盐蚀的局部材料降低饱和度。光照只改变同一颜色在受光、半影与阴影中的亮度和反射强弱，不改写色相、饱和度、色彩职责或整体调色；不添加新的全局滤镜。
实拍光照：日落前 25 分钟，晴空。唯一主光为左后方低角度太阳，略硬，太阳靠近左侧地平线；主体、酒瓶和救生圈的阴影向右前方延伸，边缘清晰。补光只来自天空、海面和浅色地面的弱反射，不加正面柔光；主体暗面明显低于受光面。面屏和地面照片是曝光锚点；太阳边缘与少量金属掠射高光可接近白，最深阴影允许自然沉下。只有太阳擦入左侧光轴时出现很轻的耀斑。
人物表面：本镜无真人皮肤与头发；机器人金属只在主光命中的掠射角出现窄高光，不满身发亮。
【画面内容】
分镜：单镜头一镜到底。
景别：中近景起幅（自主体腰腿部），随运动揭示到中景/近全身，主体占画高约60-80%、靠右；中焦中景深。构图：主体压右三分线，占画面约二分之一；左侧大面积留白给逆光海面与落日，海岸线作水平引导线延伸至左边框；前景散落酒瓶/照片/血迹，中景泳池救生圈，右侧弧形豪宅，地平线压上1/3。
运镜手法：低机位平视略仰起幅（几乎与腿同高），手持/斯坦尼康弧形跟拍（arc-follow）+ 微升——起幅贴腿部局部，机位绕主体缓慢弧移并随行走右移，落幅略抬升后退到背部全身；平缓匀速带手持呼吸感。
画面内容：主角机器人赤脚向海/右前方慵懒行走，面屏保持待机白、无表情切换；左手垂摆并渐向外舒展伸出；随行走步伐，机位从腿部局部弧移揭示到背部全身，背景城市街道与泳池露台徐徐流过交代地点；地面散落的酒瓶、宝丽来照片、暗色血迹静止入镜，血迹只被镜头一瞥掠过、不作强调；海面波光微动。全镜以主角走向泳池的行走动势收尾，供下一镜以入水动作做方向顺接。
```

### 拆镜时怎么写(呼应 SKILL §4b)

若本镜按 §4b 拆成多个 clip，**每个 clip 各写一份完整三段式 Prompt**（【基础设定】【氛围与画质】两段各 clip 基本复用、只随光影/资产状态微调，【画面内容】各 clip 分别写自己那一拍的逐拍动作链），并在每份 `分镜` 行标明"clip k / 共 N，目标时长 x s，承接上一 clip 的<尾帧动势>"。真实拉片里一条"一镜到底"的动作 Prompt 常在成片中对应 2–3 个切点镜——写 Prompt 时按叙事一镜给，落地生成时按 §4b 拆成多 clip 独立生成再缝合。

## 8.3 `segment_plan` Schema（段级结构与转场账本，≥2 段剧情的成片必产）

> **对接 §3.8：** 这是"段与段之间怎么过"的落地账本，位于 `cinematography_plan`（镜级）之上、`continuity_plan`（镜间连续）的同层协作对象。**凡成片含 ≥2 段剧情(换地点/换时间/换事件)必须先产 `segment_plan`,再逐镜排 `cinematography_plan`。** 它专治"段落间全硬切、观众看懵"。

```json
{
  "总段数": "N（把用户分场按'一件相对完整的事/一个时空下一段情绪'切成的段落数）",
  "段落": [
    {
      "段序": "seg_01",
      "这一段讲什么_内容": "客观：这段在哪、有谁、发生了什么（来自剧本，不发明）",
      "这一段为了说什么_意图": "这段要让观众明白/感到什么，在全片承担建置/推进/转折/收束",
      "入_建置镜": "shot_NN：本段开头交代'在哪/有谁/什么状态'的建置镜（景别须含远景/环境镜或信息清晰的定场镜；不许从中景特写直接开场）",
      "承_推进镜": ["shot_NN", "shot_NN … 本段主体动作/关系/信息推进的镜"],
      "出_收束镜": "shot_NN：本段情绪或信息落点，其落幅状态=下一段接入依据（情绪落点长镜/指向下一段的动作动势/空镜或道具特写）",
      "段内节奏": "段首偏长→段中随动作强度起伏→段尾偏长的镜长小曲线（与 §5 咬合）"
    }
  ],
  "段落边界转场": [
    {
      "边界": "seg_01 → seg_02",
      "转场手法": "动势匹配切 | 空镜定场过渡 | 声音桥J/L-cut | 光影渐变 | 母题/物件呼应 | 有动机硬切（六选一，来自 §3.8）",
      "缝合依据": "靠什么缝——写清前段末镜的落幅状态（位置/朝向/动势/母题出口/光线）如何接到后段首镜的起幅；有动机硬切须写清那个'动机/因果/冲突反差'是什么",
      "禁止项自检": "此处不是无动机直接硬切（填不出缝合依据=回 §2 重答两段关系）"
    }
  ]
}
```

**填写纪律：**
- **每个段落边界必须登记一种转场手法 + 缝合依据**，`缝合依据`留空或写"直接切"而无动机 = 不合格，退回 §3.8 重排。
- `入_建置镜`不得缺；缺建置镜的段落 = 观众不知道场景已切 = 打回。
- `出_收束镜`的落幅状态必须与下一段 `入_建置镜`的起幅在 `段落边界转场.缝合依据` 里对上，并同步写进相关镜的 `continuity_plan`。
- **单段成片**（只有一段事）不产 `segment_plan`，但该段内部仍需"入-承-出"三件套。

## 9. 与总控及其他模块的接口

- **上游依赖**：本模块在总控**阶段 3** 被调用，输入是总控阶段 0 从用户 `story_input` 切分出的分场/镜位候选（动作与信息本身已清楚）+ 视觉系统已批准的单人角色图与场景图 + 固定 `color_lock` + 可选的情绪节拍。本模块只在此之上生成 `cinematography_plan` 与 `lighting_ledger`，不改用户给定的故事与动作。
- **下游交接**：`cinematography_plan` 与 `lighting_ledger` 交回视觉系统，与 `style_lock`、`atmosphere_lock`、逐字不变的 `color_lock`、`photography_lock`、`human_surface_lock`、单人角色图、场景图和参考图绑定合并，组装成最终生成 Prompt：
  `固定视觉锁 + 摄影真实度契约 + 本集资产锁 + 单镜头动作（来自用户故事）+ cinematography_plan（景别/机位/运动/构图/实拍光照/剪辑）+ 画面内调度（§3.7 表演/走位/母题出口状态）+ 参考图绑定 + 当前镜头特有风险`。组 Prompt 时六维与画面内调度须转译成视频模型可执行的画面描述；光影必须保留主光、阴影、补光、曝光与光学触发条件，不得只写中文调度术语或泛化风格标签。
- **冲突优先级**（本模块内部及与其他模块）：
  `动作/信息可读性 > 摄影真实度契约与实拍光照卡 > 视觉系统世界锁/作者风格锁 > 视觉硬把控（§1）> 镜头调度意图匹配（§2/§4）> 具体炫技手法`。
  即：**可读性 > 世界观一致 > 电影感地基 > 意图配方 > 炫技**。任何一层不得推翻其上一层。
- **对成片放行的补充**：实际成片除过视觉系统视觉门外，还要过本模块 §7 镜头调度门；两者都过，质感与可读性才双双达标。故事好坏不在本系统评判范围内（由用户/上游 agent 负责）。

## 10. 常见修复（镜头调度专项）

- **“画面好看但像游戏 CG / HDR 渲染”**：先检查 `实拍光照卡`，而不是加“超写实”、胶片颗粒或脏旧贴图。逐项核对主光是否唯一、阴影是否同向、暗面是否被无来源正面填亮、材质是否只在正确角度反光、耀斑是否满足机位条件；任一失败，回 §1.4 重定光源、遮挡、曝光和机位，再生成。
- **“人脸像蜡像/油头满面，发型像涂了发油”**：同时检查镜头轴线上是否有无来源正面填光，以及 `人物表面` 是否明确写了皮肤毛孔/微纹理、哑光至微丝光反射、小面积有因高光、头发分束和低至中光泽。修正表面反射与光源方向，不要把整张画面降饱和或压暗。
- **“画面好看但没电影感/像 AI 废片”**：在实拍光照卡成立后，再查主体是否被光比/景深拔出、构图和运动是否服务意图、胶片特征是否克制。回 §1 与 §2 逐条修。
- **"每个镜头都居中怼脸，很平"**：景别与构图没有阶梯与变化。按 §3.1 排景别阶梯，按 §4 依意图换构图（对称只留给仪式/对决/喜剧凝视）。
- **"运镜很多但很晕/很空"**：运动无动机、无起落幅。回 §3.3，每个运动写清"为什么动、从什么构图到什么构图"；不服务意图的运动砍成固定镜。
- **"节奏平、拖沓/或全程碎切很累"**：镜长没随情绪起伏。回 §5 排三档时长曲线，动静交替，首尾压长镜。
- **"炫技盖过动作、看不懂了"**：违反冲突优先级。可读性 > 炫技，先确认给定动作在镜内清楚，再把华丽手法只留在真正承载意图的那几镜。
- **"两个镜头接不上/迷向"**：越轴或无衔接动机。锁 180 度线，用动作/视线/方向/声音桥接，回 `continuity_plan`。
- **"一段事到另一段事全是硬切、越看越懵/看不懂"**：缺场级结构。回 §3.8——先把片子切成叙事段落，每段补"入-建置镜/出-收束镜"，每个段落边界在 `segment_plan` 登记一种转场手法(动势匹配/空镜定场/声音桥/光影渐变/母题呼应/有动机硬切)并写清缝合依据；换场处补建置镜让观众重新落地。填不出缝法 = 这两段关系没想清，回 §2 重答各自"为了说什么"。
- **"浪漫/悲伤镜没味道"**：先选择可成立的窗光、开放阴影或可见实用灯，再用长镜、框架式构图和克制表演建立情绪；不用正面美容柔光，不因浪漫/悲伤更改 `color_lock`。
- **"追逐/打斗不带劲/不够炫"**：摄影机没参与动作，只做了干净的平视侧跟。回 §4.5 动作炫技升级库，每个动作镜叠加 ≥2 类手法（速度渐变 + 相对位移背景飞驰 / 弧形环绕 + 冲击定格 / match-on-action 动势链 / 贴地低机位运动模糊 + 极短切）；换手持跟拍 + 短碎切 + 贴地/荷兰角 + 硬光高对比。记住：动作节拍上炫技是被要求的，别怕炫。
