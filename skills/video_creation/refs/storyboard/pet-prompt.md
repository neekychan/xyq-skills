# 萌宠拟人 Prompt 编写指南

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意发散阶段的拟人化层级判定、红线、强制规则、高频模板见 `creative/pet-anthro.md`。

## Prompt 模板（L2 说话示例）

```
参考@图片1的形象作为橘猫，
温暖的客厅沙发背景，轻微虚化。
橘猫正面看向镜头，嘴角微张说话，口型与台词同步，
说话时轻轻歪头、眨眼，一只前爪微微抬起挥动，全程保持真实猫咪形体。
橘猫说：{新年快乐！祝大家天天开心，好运连连！}
软萌奶气的童音。近景固定机位，窗边暖光从画面左侧照亮猫脸，毛发边缘泛金光。
五官清晰不变形，画面稳定，保持无字幕，画面中禁止出现人类手部。
时长：5秒，比例：9:16
```
