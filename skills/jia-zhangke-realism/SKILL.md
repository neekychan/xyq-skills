# 贾樟柯纪实短片

## 核心原则

通过一个普通人的具体行动，观察中国县城在现代化、迁移和消费文化影响下的新旧并存。画面可以粗粝、平淡、热闹、艳俗或安静；人物可以失落，也可以好笑、尴尬或荒诞；时代变化不由摄影机解释，而让它自然进入同一构图。

**持久引擎（因果链）：**
**人物具体任务 → 空间中新旧杂糅的时代痕迹 → 个人小事与时代巨变同框 → 摄影机等待现实发生（不抢解释）→ 人物面对去留做出可见行动选择 → 流行文化从场景内部刺入形成反差 → 结尾留白不结论**

**质量测试（可证伪）：** 如果把人物从空间中移除，时代变化仍在画面中自行发生；如果把时代痕迹全部清理干净，人物的行动仍可完成——两者独立存在但同框才有意义，则创意成立。反之，若画面只是怀旧美术布景、或人物只是情绪符号而非行动者，则不通过。

## 输入诊断

生产前必须明确或合理假设以下维度：

- **输入类型**：完整剧本 / 故事梗概 / 简短想法 / 仅参考素材——决定处理方式（见路由表）
- **叙事基调**：进城务工 / 下岗 / 小镇青年 / 故土没落——决定场景类型与时代信息选择
- **时代背景**：1990年代 / 2000年代初 / 当代县城——决定影像媒介质感（胶片颗粒 / DV噪点 / 清晰数字）
- **目标市场与语言**：中国大陆 / 中文方言碎片环境音为主，无旁白无字幕（默认）；用户明确要求旁白时方可添加
- **画幅与规格**：16:9，1080p，24fps
- **时长意向**：默认10–180秒（阶段1.5由用户确认）
- **节奏类型**：慢节奏 / 中节奏 / 快节奏——决定单镜时长与固定/手持比例（阶段1.5由用户确认）
- **运镜倾向**：手持跟拍为主 / 固定长镜为主 / 混合模式——决定镜头运动方式（阶段1.5由用户确认）
- **角色参考素材**：用户是否已上传人物参考图——决定角色身份板生成路径
- **合规敏感点**：不涉及健康/金融等特殊品类；注意人物形象不得出现明显磨皮/精致妆容等与纪实风格相悖的特征

## 工作流

### 阶段 0：建立全局参数文档

创建全局参数文档，锁定以下参数：
- 片名（用户提供或AI生成）
- 画幅：16:9
- 分辨率：1080p
- 帧率：24fps
- 时长意向（默认10–180秒）
- 叙事基调（进城务工 / 下岗 / 小镇青年 / 故土没落）
- 视觉风格锚点：贾樟柯纪实美学（县城生活流，新旧并存，手持微晃/固定长镜头，环境音主导，不强制统一色调滤镜）
- 语言：中文方言碎片环境音为主，无旁白，无字幕

### 阶段 1：叙事基调解析

1. 若用户上传了音频文件，分析情感基调、语速节奏、有无人声碎片，输出推荐叙事基调。
2. 若用户上传了人物参考图，提取外貌特征（脸型、肤色、发型、服装细节），输出结构化描述，供后续角色参考图生成使用。
   - 面部特征：脸型（圆/方/长）、眼型、眉形、肤色（暗沉/蜡黄/粗粝）、皱纹/雀斑等皮肤纹理细节，明确是否有素颜/磨皮情况。
   - 发型：发色、长短、分线位置、发质（油腻/干枯/凌乱）。
   - 服装：具体款式（工装/夹克/棉服）、颜色（描述为褪色/陈旧+色相）、可见磨损细节（破洞/污迹/褶皱）。
   - 体型与姿态：身高体型大致感知、站姿/坐姿/动作状态。
   - 情绪基调：神情（疲惫/沉默/茫然/沧桑），与贾樟柯美学的契合度评估。
   - 纪实风格符合性检查：若参考图中人物存在明显磨皮、精致妆容、高设计感服装，注明「需在生成阶段向贾樟柯纪实风格纠偏」。
3. 按输入类型（见路由表）处理叙事内容。
4. 将叙事内容呈现给用户，**等待确认或修改后**方可进入下一阶段。

### 阶段 1.5：节奏、运镜与时长自定义

叙事线经用户确认后，**一次性**向用户展示以下三个维度，统一收集参数后进入阶段2。

**节奏类型（三选一）：**
- **慢节奏（沉浸式长镜）**：固定长镜头占比≥70%，单镜6–12秒，适合情绪沉淀、环境留白、时代氛围铺陈。参数：pace_type=slow，avg_shot_duration=8s，固定长镜头比例≥70%，禁止快切/急推。
- **中节奏（生活流）**：手持跟拍与固定长镜各约50%，单镜4–8秒，模拟日常观察节奏。参数：pace_type=medium，avg_shot_duration=5s，固定与手持各半。
- **快节奏（短切蒙太奇）**：单镜2–4秒，仅适用于预告片或情绪强烈的回忆/幻觉段落。⚠️ 选此项时须弹出警告："快节奏可能削弱纪实感，是否确认？"，用户二次确认后方可生效。参数：pace_type=fast，avg_shot_duration=3s，快切比例60%。

**运镜倾向（三选一）：**
- **手持跟拍为主**：肩扛感，轻微晃动，贴近人物，适合运动场景和人物跟拍。参数：camera_style=handheld。
- **固定长镜为主**：三脚架静止或极缓慢摇移，强调环境与人物关系，适合空镜和静态场景。参数：camera_style=static。
- **混合模式（推荐）**：人物运动时手持，静止时固定，由AI自动判断。参数：camera_style=hybrid。

**总时长（可选，默认30秒）：**
请用户输入短片总时长（10–180秒），若不输入则默认30秒。

**确认并传递参数：**
向用户输出确认清单（节奏/运镜倾向/总时长/预估镜头数），用户回复确认后，将pace_type、camera_style、total_duration、avg_shot_duration传递给分镜设计阶段。预估镜头数仅供时长参考，不作为强制数量约束；分镜根据人物事件自然划分实际镜头数。

### 阶段 2：分镜设计

生成分镜脚本。**必须严格遵循阶段1.5传入的pace_type、camera_style、total_duration、avg_shot_duration参数。** 加载 `references/formats/aesthetic-principles.md` 获取完整分镜设计规范。

镜头时长须足以呈现完整人物行动；镜头数量根据叙事事件自然划分。分镜完成后呈现给用户，**等待确认或修改后**进入下一阶段。

**分镜脚本须包含：**
- key_elements（视觉元素：人物+场景）
- shots（分镜列表，每个shot包含景别与构图、运镜方式、现场光线与色彩、环境音设计）
- audio_layers（独立音轨：环境音混合轨+可选配乐）

**每个shot描述必须包含的五个维度：**
1. 景别与构图
2. 运镜方式（固定长镜头 / 手持微晃，二选一或混用）
3. 现场光线与色彩
4. 环境音设计
5. 人物线动作与时代线背景元素（双标注，不得只描述人物或只描述环境）

详见 `references/formats/aesthetic-principles.md`。

### 阶段 2.5：角色参考图生成

分镜确认后，统计跨两个以上镜头出现的主要角色：
- 仅为这类角色生成参考图；一次性人物、远景路人和背景群众不生成。
- 若用户已上传对应参考图，直接绑定复用，不重复生成。
- 多名主要角色可批量生成后**一次性展示，统一请用户确认**，不逐人单独暂停。
- 确认后，将参考图绑定至对应角色key_element；后续涉及该角色的镜头视频生成时，以此图作为参考图输入。

角色身份板生成策略详见 `references/formats/media-generation.md`。

### 阶段 3：素材生成

- 逐镜生成视频片段；若用户已上传参考图像/视频，优先绑定复用，不重复生成。每段视频≤15秒，用一次生成即可拿到完整片段；成片总时长超过15秒时，拆成多个≤15秒片段分别生成，再做后处理拼接。
- 生成环境音/背景音轨（少用画外配乐，重视场景内声音元素）。
- 全部片段生成完毕后，呈现给用户预览，**等待确认后**进入剪辑阶段。

视频片段生成路径、参考图绑定规则、环境音生成与质量把控详见 `references/formats/media-generation.md`。

### 阶段 4：剪辑与交付

按分镜顺序线性拼接，叠加环境音轨，输出最终视频。提示用户导出。

**剪辑与输出规范：**
- 按分镜顺序线性拼接，遵循三段式意象流结构（开端→发展→结尾）。
- 切换方式：以硬切为主，偶用极缓渐隐（黑场0.5–1秒）；禁止花式转场。
- 整体节奏：缓慢、沉郁；不压缩镜头时长；保留固定长镜头的完整时长，让画面"呼吸"。
- 若单镜视频片段超出分镜设计时长，优先从末尾修剪，保留人物动作完整性。
- 环境音轨作为主音轨，音量高于一切其他轨道。
- 若有背景音乐轨，音量压低至环境音的30%以下，且不覆盖关键环境音时刻。凡环境音中出现方言碎片人声、场景内歌声或广播人声的时段，BGM音量进一步压低至环境音的15%以下；音量变化使用0.5–1秒渐变过渡。
- 片头/片尾可设0.5–1秒音频渐入/渐出，无需画面淡入淡出（保持硬切视觉）。
- 不添加任何字幕、标题、片头动画。
- 导出参数：MP4，1080p，16:9，24fps，无字幕，无水印。
- 默认版本：带环境音（无配乐）；如用户要求，可导出纯画面（静音）版本。

**依赖关系：** 阶段0 → 阶段1 → 阶段1.5 → 阶段2 → 阶段2.5 → 阶段3 → 阶段4；阶段3中素材生成依赖阶段2分镜。

**异常处理：** 若用户未提供任何输入，回复："请上传一段音频，或用一句话描述一个场景（例如：'一个年轻人在手机店外等候消息'），AI将自动生成叙事框架。"

## 输出契约

### 分镜脚本结构

```
key_elements:
  - id: character_01
    type: character
    description: [人物外貌、服装、发型、肤色等锁定细节]
    reference_image: [绑定的角色参考图路径，若有]
  - id: scene_01
    type: scene
    description: [场景空间类型、时代信息元素、新旧杂糅痕迹]
    reference_image: [绑定的场景参考图路径，若有]

shots:
  - id: shot_01
    duration: [秒数，遵循pace_type映射]
    camera_style: [handheld / static]
    framing: [景别与构图描述]
    action: [人物线动作]
    era_element: [时代线背景元素]
    lighting: [现场光线与色彩描述]
    ambient_sound: [环境音设计]
    observation_shot: [是否为观察镜头，若是标注四项条件]
    optional_surreal: [可选超现实事件标注，若有]

audio_layers:
  - type: ambient_mix
    description: [多层市井环境音叠加，具体音效组合]
  - type: music
    enabled: false  # 默认不加，用户明确要求时改为true
    description: [极简低沉风格描述]
  - type: narration
    enabled: false  # 默认不加，用户明确要求时改为true
```

### 视频生成方式

**时长≤15秒的成片**用一次视频生成即可拿到完整片段，分镜中的beat（0-3s/3-7s/…）是同一条prompt内的时间轴描述，不等于分段多次生成。**成片超过15秒时**，拆成若干≤15秒片段各自一次生成，再做后处理拼接。

## 静默自检

交付前内部跑一遍以下质检清单，重写弱项，不外显给用户：

- [ ] 输入类型是否已判断并按对应方式处理
- [ ] 叙事基调是否已确定（进城务工/下岗/小镇青年/故土没落）
- [ ] 时代背景是否已确定，影像媒介质感是否匹配且全片统一
- [ ] 阶段1.5参数（pace_type/camera_style/total_duration/avg_shot_duration）是否已收集并传入分镜
- [ ] 每个shot是否包含五个必需维度（景别构图/运镜/光线色彩/环境音/人物线+时代线双标注）
- [ ] 空间设计是否包含至少两种不同年代痕迹（新旧杂糅），未退化为纯怀旧布景
- [ ] 全片是否至少安排一个观察镜头（8–15秒，满足四项条件）
- [ ] 双线叙事是否落实：人物有具体可见任务，时代变化通过环境进入画面
- [ ] 是否安排了至少一个人物小事与时代变化同框的镜头
- [ ] 去留关系是否落实：结尾人物完成可见行动选择（非情绪凝视或空镜代替）
- [ ] 流行文化声音是否从场景内部出现，并与人物处境形成反差
- [ ] 角色参考图是否仅为主要角色生成，是否已绑定至key_element
- [ ] 视频提示词是否包含强制前缀和固定negatives
- [ ] 提示词中是否出现禁止词（磨皮/美颜/精致/高饱和/滑轨/稳定器/航拍/对口型/字幕）
- [ ] 成片≤15秒是否一次生成；>15秒是否已拆成≤15秒片段
- [ ] 剪辑是否遵循硬切为主、保留长镜头完整时长
- [ ] 全文语言是否为中文，无中英混杂（negatives固定英文短语除外）
- [ ] 是否在每个关键节点暂停等待用户确认
