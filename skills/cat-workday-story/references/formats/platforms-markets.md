# 平台与画幅参考

> 这些是可适配的模式与句式，按场景改写，不要逐字照搬。

本文件提供各发布平台的画幅和节奏参考。

## 画幅对照

| 比例 | 适用平台 | 说明 |
|---|---|---|
| 9:16 | 抖音、小红书、视频号、TikTok、Instagram Reels | 默认竖屏，最常用 |
| 16:9 | B站、YouTube | 横屏 |
| 1:1 | 小红书、Instagram | 方形 |
| 4:5 | 小红书、Instagram | 竖版接近方形 |

## 平台特性

### 抖音 / TikTok
- 竖屏9:16为标准。
- 前2秒必须有钩子。
- 节奏快，适合每2-3s一个视觉重点。
- 贴纸式文案效果好。
- 音乐驱动节奏。

### 小红书
- 9:16或4:5均可。
- 画面质感要求高。
- 适合精致可爱的职场梗。
- 标题式封面重要。

### 视频号
- 9:16竖屏。
- 节奏适中，适合完整故事。
- 社交传播靠共鸣感。

### B站
- 16:9横屏为主。
- 适合稍长内容（30s-60s）。
- 弹幕互动文化。

## 分辨率参考

| 级别 | 分辨率 | 适用场景 |
|---|---|---|
| 标准 | 720p | 默认 |
| 高清 | 1080p | 用户要求高清时 |
| 最高 | 平台可用最高 | 用户明确要求最高画质时 |
