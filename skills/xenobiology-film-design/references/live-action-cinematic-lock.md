# 纯真人电影写实锁（默认最高优先级）

所有项目默认读取本文件。它把异生设计落回可拍摄的现实：**先像演员、地点和摄影，再像异生物。** 若其它文件出现「仙气、通体微光、雕塑般、概念海报、游戏设定」等会与此冲突的旧表述，以本文件为准；除非用户明确要求，否则不采用。

## 1. 五道写实闸门

1. **演员闸门**：默认使用漂亮、真实、个体化的亚洲演员面孔；用户明确指定欧洲或其他面孔时，直接以该指定覆盖。每位角色在出图前先写一条**美貌档案**，所有性别表达得到同级的选角、脸部、妆发、服装、取景面积与雾面调色：女性可写清透、灵动、冷艳等具体气质；男性必须显式写为**俊美、精致、有辨识度的亚洲男性异生体，具有时装肖像级的选角与气质**，不能只写「亚洲男性」或落入粗犷硬汉、成熟精英、普通职业男主模板。妆面清透、低饱和并保留真实皮肤纹理；男性避免明显腮红色块，但嘴唇、耳缘和面颊仍保留极淡冷玫瑰底色，不把肤色做灰做死。发色不默认浅色或银白，须与服装主色和主锚点材质协调；深色服装可配自然黑、蓝黑、石墨或深茶发色，通过发丝反光、轮廓补光和背景明度分离。避免职业证件照式盘发、浓重商业妆、过度磨皮、对称脸、塑料人偶。
2. **假体闸门**：先写主锚点拓扑表：种类、准确数量、根部、比例、朝向、折叠状态与遮挡关系。画面里每个异生部件都必须能归入这套声明结构。收拢翼的全部翅面沿身体向下叠合成连续披风轮廓，不再生成竖立小翅、孤立翅片或第二套翼。锚点应像高级实体假体、可动道具或可被克制后期补全的组织，而不是浮在身体后的图案、饰品或一层发光材质。
3. **材质闸门**：每个材料只写可见的物理属性：壳的层理和磕碰、鳞粉的干湿差异、织物纤维、玻璃水痕、金属氧化、雨后水洼。不要用「全身发亮、通体珠光、玉化、仙气」替代材料。
4. **光线闸门**：每一处亮都能追溯到阴天窗光、天空反射、海面反光、顶灯、走廊灯、招牌或车灯。先定主光、补光与湿面反射；不要用可见雾层塑造空间，也不要无来源辉光、光环、粒子、能量丝、爆闪或强镜头炫光。
5. **摄影闸门**：场景图明确景别、镜头焦段、机位和可执行运动，优先 35mm/40mm/50mm 的观察式电影摄影、有限景深和真实透视。角色图由用户在角色内环选择：横屏 16:9 正背双视图时左严格正面、右严格背面，同一角色等高同尺度，完整收入头顶至腰线下方或大腿上段；竖屏 3:4 单人肖像时为单一连续构图，完整收入头顶至腰线下方或大腿上段，脸、发型、服装与可见主锚点清楚。两种格式均不得因性别把男性裁成胸像或大头照；双视图使用稳定、全清晰相机位和相同曝光。

## 2. 默认世界与色光

- **地点**：仍在使用的公寓、医院、研究楼、码头、商店、海洋观测站或高层露台。允许老旧与潮湿，但保留有人生活/维护的证据；不默认废墟。
- **泛白雾面调色**：按 `milky-fog-grade.md` 执行，**角色设定图也继承其色光基调**。「雾蓝」首先是一套摄影曲线：柔和冷环境底、低饱和中间调、抬起石墨阴影、珍珠乳白高光、清透肤色与均匀空气感；不是把服装、头发和皮肤全部染蓝。服装和锚点可用黑、灰绿、壳粉或其它项目本色，但必须落在同一曲线上。
- **颜色**：角色背景默认低饱和雾蓝；若整体配色更适合冷灰、灰绿或珍珠色，可替换背景色相，但不能丢失乳白高光、冷空气底与抬黑关系。高饱和深蓝、紫或暖色只由真实材质或画内灯承担。
- **默认禁用魔法光效**：生物荧光、发光眼、光环、漂浮光尘、能量脉冲、星尘、能量丝、魔法阵、耀斑均默认不写。用户明确要求时，也只允许一处、低亮度、能解释来源的局部变化。

## 3. 人-生物融合的写实做法

用 `人像基底 + 一组主锚点 + 物理连接 + 两种真实材料 + 环境回声` 设计。主锚点可以漂亮、面积可以大，**不必把物种的全部特征都做在身体上**；头脸默认保持人类状态，触角、复眼、额部器官等仅在用户明确要求或不可替代时使用。主锚点必须有：

- **连接**：从哪块骨骼/衣物结构/已见组织长出，遮挡关系如何成立。
- **重量**：翼、壳、鳍、触须在重力、风和雨中的下垂、折叠或颤动方式。
- **表面**：只挑两项可拍物性，例如深色蛾翼的哑光鳞粉与被雨压暗的膜缘；蚌壳的层状钙质与细小珍珠颗粒。不要给所有部位叠加同一种泛光。
- **环境回声**：只留一个重复证据，例如窗台壳屑、潮湿玻璃上的鳞粉印、积水里缓慢扩散的波纹；它必须来自角色行为或空间机制。它可代替额外的身体器官来补足物种逻辑。

美感来自漂亮的演员、克制表演、材料对比与真实光线；异生感来自结构与物种语汇，不来自魔法辉光或时装装置化。

## 4. 资产与提示词

默认把角色资产称为**真人化角色设定图**：每位角色只出一张由用户在角色内环选择的格式。A 为**横屏 16:9 正背双视图**：左侧严格正面，右侧严格背面；同一个角色出现两次，等高、同尺度、同一脸型、发型、发色、服装、材质、主锚点与曝光。两侧都完整收入头顶，下边界位于腰线下方至大腿上段，以同时读清面部和服装；左侧正面展示面部与服装前部，右侧不回头，展示后脑、服装背部、主锚点根部与折叠拓扑。只含两个视图，不加第三视图、脸部插图、文字、标签、边框或分隔线。B 为**竖屏 3:4 单人肖像**：单一角色、单一连续构图，完整收入头顶至腰线下方或大腿上段；脸是第一读点，头部正向或轻微三分之四侧，脸、发型、服装与可见主锚点同时清楚可读；不加三视图、脸部插图、拼格、文字、标签或边框。两种格式均默认使用漂亮、真实、个体化的亚洲演员；男性角色必须使用其「俊美、精致、有辨识度」美貌档案，并获得同级雾面调色。发型与发色从服装和锚点配色推导，不默认银白；深色服装与深色发可以和谐共存。背景默认低饱和雾蓝，也可按配色使用冷灰、灰绿或珍珠色，但必须维持统一的雾面摄影曲线。若主锚点是收拢翅膀，全部翅面必须自肩胛同一根部向下叠合成一套连续披风轮廓，不能另有竖立小翅、孤立翅片、方向相反的翼或翅状服装装饰。服装默认优先选择华丽仪式礼服、层叠结构外套或宫廷式设计；西装仅在用户明确指定职业、身份或权力感时使用。

角色设定图使用均匀大面积漫射冷主光与弱补光：真实面料、假体边缘、壳层和鳞粉完整对焦；正背双视图两侧曝光和色温一致。乳白雾面通过曝光曲线与背景空气感实现，不使用中间雾带、贴地烟、局部雾团、梦幻柔焦、浅景深或可见胶片颗粒。深色头发、深色衣物也必须保留内部纹理和轮廓分离。

场景资产称为**实景气氛板**：先写地点原有功能、自然天气、实用光与人类使用痕迹，再写异生痕迹。不要生成游戏地图、未来城市鸟瞰图、概念插画或纯装置建筑。

场景/视频提示词按下列顺序组织：

```text

[真人演员的动作与情绪]，
[完整物种语汇 + 根部/承重/折叠逻辑]，
[两种可拍的材料与一个环境回声]，
在[仍可使用的真实地点]，
[天气 + 有动机的主光/补光]，
[泛白雾面色光与电影摄影锁；空间深度不用可见雾层描述]。
```

## 5. 写实验收

- 缩略图首先读到的是一个可能被拍到的演员和地点，而不是 CG 生物装置。
- 放大后，主锚点有根部、厚度、重量与材料差异；没有浮贴、镜面对称装饰或全身同质高光；即使只保留一组主锚点也能成立。
- 关掉角色后，地点依然像有人维护和使用的真实空间。
- 每一处亮都能指出来源；删除所有无来源光效后画面仍成立。
- 空间深度让远景自然退后，不擦掉前景人像、衣物、锚点与雨后细节，也不生成贴地烟、漂浮雾团或横向雾带。
- 角色设计图是否严格为每角色一张用户选定的格式：A 为横屏 16:9 左正面、右背面、同一角色等高同尺度的双视图；B 为竖屏 3:4、单一角色、单一连续构图的肖像？两种格式是否均完整收入头顶至腰线下方或大腿上段，且男女使用相同取景面积和雾面调色？发色是否从服装与锚点配色推导而非默认浅色？即使主色不用雾蓝，是否仍保留柔和冷环境底、低饱和中间调、抬起石墨阴影、珍珠乳白高光和清透肤色？主锚点是否有准确数量与闭合拓扑；收拢翅膀是否全部沿身体向下形成连续披风，且不存在竖立小翅、孤立翅片、第二套翼或翅状服装装饰？
