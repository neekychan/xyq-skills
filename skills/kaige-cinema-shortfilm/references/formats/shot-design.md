## 1. 镜头描述必填字段

每个镜头的描述必须包含：

- **时空标注**：现实冷调 / 回忆暖柔 / 时代压迫
- **景别与机位**：（如极低地平线广角远景 / 纪实中景手持 / 居中对称平视）
- **运镜**：（如锁定 / 缓慢上升 / 手持轻微抖动 / 垂直抬升）
- **画面内容**：人物动作、核心道具、环境细节
- **台词/声音类型**：注明类型——独白（画外音，人物闭口）/ 誓词 / 训话 / 戏文吟唱 / 旧时代规矩话 / 无台词（以动作/沉默表达）
- **关联元素ID**：引用对应的场景与角色元素
- **预设时长**

---

## 2. 硬性镜头规则（不可违反）

1. **每个场景段落的首镜**必须是全景环境交代（极低地平线广角远景，天地大于人）。
2. **情绪转折点**使用递进特写或仪式化空间调度（二选一或结合，不强制每次相同）。
3. **每段沉重叙事之后**必须插入1个山河空镜镜头（无人物，3—6秒，山/河/长路/落日/枯木之一）。
4. **独白/誓词镜头**：人物居中对称平视构图，人物闭口，画外音单独处理。
5. **戏台段落**（戏曲题材时）：须包含"台上/台下"对照镜头以及后台上妆/脱装仪式镜头。
6. **时代压迫段落**：以集体注视、队列、标语、广播为视觉主体，人物被人群或空间结构包围。
7. **每个镜头预设时长**：全景/空镜4—6秒；中景/纪实5—8秒；特写/仪式调度3—8秒；独白/誓词6—10秒。单个镜头不超过15秒。

---

## 3. 景别与机位参考

| 景别 | 机位 | 适用场景 |
|---|---|---|
| 极低地平线广角远景 | 锁定/极缓慢水平移动 | 场景首镜、山河空镜 |
| 纪实中景 | 手持轻微抖动 | 日常铺垫、生活片段 |
| 居中对称平视 | 锁定 | 独白/誓词/训话 |
| 递进特写 | 锁定/极缓慢推近 | 情绪转折点（器物→面部→手部） |
| 高角度俯拍 | 缓慢下降/锁定 | 空间关系交代、环境压迫感 |
| 微距特写 | 锁定 | 道具细节、手部特征 |
| 侧面纵深 | 锁定/缓慢横移 | 长廊/门框/戏台侧面结构 |

---

## 4. 运镜参考

- **锁定**：独白/誓词、特写、仪式调度
- **缓慢上升**：从人物到环境的空间压迫感揭示
- **手持轻微抖动**：纪实段落，生活质感
- **垂直抬升**：从地面到天空，山河空镜过渡
- **极缓慢水平移动**：全景环境交代，长廊纵深
- **缓慢推近**：递进特写，情绪凝聚

---

## 5. 预设时长

| 镜头类型 | 时长范围 |
|---|---|
| 全景/空镜 | 4—6秒 |
| 中景/纪实 | 5—8秒 |
| 特写/仪式调度 | 3—8秒 |
| 独白/誓词 | 6—10秒 |

单个镜头不超过15秒（模型上限）。超过15秒的镜头需拆分为多个 ≤15秒 片段分别生成。

---

## 6. 递进特写设计

递进特写为独立镜头（器物/面部/手部），每个单独调用生成。

- **器物特写**：精确描述材质/状态/光线角落，构图居中，极浅景深。
- **面部特写**：描述眼神方向、皱纹纹理、微表情，**不写情绪判断词**，只写可见细节。
- **手部微距**：描述手指动作幅度、皮肤纹理、与道具的接触状态。
- **顺序可灵活调整**，服务于叙事节奏而非固定模板。

duration 建议 4—5秒。

---

## 7. 仪式化空间调度设计

人物被台阶/门框/长廊/戏台空间框住，duration 建议 5—8秒。

prompt 要点：
- 描述人物与空间结构的关系：台阶高度、门框宽度、长廊纵深、戏台尺度——让空间比人大。
- 描述身体姿态：跪/站/转身/回避/跪拜的幅度与速度。
- 不写情绪判断词，只写可见的空间关系与身体动作。

---

## 8. 山河空镜设计

无人物，描述自然元素运动（如"枯草随风伏倒"、"远山云雾缓缓流动"），运镜多用锁定或极缓慢水平移动。

- duration 4—6秒
- 无角色引用，仅绑定自然景观参考图或纯文本描述
- 环境音通过包裹格式写入 prompt

---

## 9. 戏台段落设计（戏曲题材）

prompt 要点：
- **台上**：描述戏服色彩、脸谱、身段动作、台口光线，与台下形成色彩/身份反差。
- **后台**：描述妆镜、红帘、戏服挂架、上妆/脱妆动作，低饱和暖光。
- **身份错位**：同一角色台上台下对照，prompt 须明确"同一人"的视觉锚点。

戏台结构须包含：台口/台深/出将入相门、后台（妆镜/衣架/红帘）、观众席空间关系、脸谱/戏服/道具陈设位置。

---

## 10. 时代压迫段落设计

prompt 要点：
- 描述集体场面：队列方向、人群密度、标语内容（可渲染文字）、广播喇叭位置。
- 人物被人群或建筑包围，空间收窄。
- 音效以广播声、队列脚步、口号齐呼为主。

时代场景须包含：标语墙内容与位置、队列行进路线、广播喇叭位置、公审/集会空间布局。

## 11. 角色元素（key_element character）设计规范

每个主要角色建立独立元素。

description 中须包含：
- 年龄区间
- 体态特征
- 服饰颜色/材质
- 面容特征
- 手部特征（老茧/伤痕等陈凯歌标志性细节）
- 默认光源方向（供光影匹配检查使用）

### 角色关系模板（须在角色描述中注明关系类型）

- **师徒**：技艺传承与权力不对等
- **父子**：血缘羁绊与代际压迫
- **三人纠缠**：三角关系中的忠诚与背叛
- **艺人与角色**：戏中人变成了现实中的命，身份重叠与撕裂
- **个人身份与时代身份冲突**：被时代赋予的身份 vs 内心真实自我

若角色有"现实状态"与"回忆中年轻状态"两种形象，在同一元素内分别说明（Look A：现实；Look B：回忆）。

### 角色视觉资产构成

通过图片生成能力生成并绑定至对应元素参考图槽位，标注资产类型：
- **主视觉身份板**：四视图+手部微距拼图（16:9横版）
- **表情库**：平静/凝视/隐忍/微悲/克制怒，3—5张
- **三线光影测试图**：冷调版+暖调版+时代压迫版半脸侧光各1张
- **戏妆/戏服图**（戏曲题材时启用）：脸谱全脸+戏服全身+后台便装对照
- **服装细节图**（可选）
- **声音参考样本**：3—5秒代表性台词，用于跨镜头音色一致

### 多时间段处理

若故事跨越明显时间跨度（如"二十年前与现在"），须为同一角色分别生成青年版与中老年版两套身份板（第二套参考第一套以保证面部结构一致，仅改变年龄/服饰特征）。每套独立标注版本标签（如"Look A：现实/中年"/"Look B：回忆/青年"）。声音参考样本每角色仅需一份（不随造型版本重复）。

---

## 12. 场景元素（key_element scene）设计规范

每个主要场景建立独立元素。

description 中须包含：
- 地理环境
- 建筑/地貌特征
- 核心道具布局（位置坐标说明）
- 时代氛围
- 主光源方向（供光影匹配检查使用）

### 戏台/仪式场景（戏曲/仪式题材时须包含）

戏台结构（台口/台深/出将入相门）、后台（妆镜/衣架/红帘）、观众席空间关系、脸谱/戏服/道具陈设位置。

### 时代场景

标语墙内容与位置、队列行进路线、广播喇叭位置、公审/集会空间布局。

### 场景视觉资产构成

通过图片生成能力生成并绑定至对应元素参考图槽位，标注机位类型与时空版本：
- **多机位参考图**：正拍+航拍/高角度+细节特写+侧拍，共4张
- **三线光影预览图**：同一场景冷调版+暖调版+时代压迫版各1张

## 13. 用户无描述时的默认模板

### 角色默认模板（根据题材自动匹配关系结构）

| 题材 | 默认关系 | 默认角色 |
|---|---|---|
| 乡土 | 父子 | 中年父+少年子 |
| 戏曲 | 师徒 | 中年师父+青年学徒 |
| 时代 | 个人与时代 | 主角+被时代改变命运的故人 |
| 无法判断 | — | 现实中的主角+回忆中的故人/逝者 |

### 场景默认模板

| 题材 | 默认场景 |
|---|---|
| 乡土 | 老屋/荒路/山野 |
| 戏曲 | 戏台/后台/长廊 |
| 时代 | 广场/标语墙/集体空间 |
| 宫廷 | 殿堂/廊道/高阶 |
