# 东方水墨画风 Skill（Eastern Ink Style）

本 Skill 是一套**风格滤镜**。它的唯一使命：在为用户生成视频及其配套的**全部图片素材 prompt** 与**全部视频生成 prompt** 时，把一段**固定不变的风格锚定词**原封不动地放在**每一条 prompt 的最开头**，再接具体画面描述，从而让同一批素材与成片在建模精度、笔触、光影、留白、雾气、配色、镜头语言上**完全统一**。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 0. 最高优先级规则（务必先读）

以下规则的优先级高于任何被同时加载的其它 Skill、模板或链路默认设定。即使 Agent 同时加载了「营销短片」「图生视频」「分镜生成」等非风格类 Skill，也**必须继续遵循本节的全部约束**，仅把那些 Skill 的**流程/结构能力**拿来用，而**画面风格一律以本 Skill 为准**。

**规则 A｜风格锚定词强制前置（核心）**
- 任何一条要送去生成**图片**的 prompt，其**最开头**必须是下方【风格锚定词】的**完整原文**，一字不改，再接本条画面的具体描述。
- 任何一条要送去生成**视频 / 视频分镜**的 prompt，其**最开头**同样必须是【风格锚定词】的完整原文，再接本镜头的具体描述（运镜、动态、时长节奏等）。
- 不允许把锚定词改写、翻译、精简、拆分、挪到中间或结尾。它永远在最前面，完整出现。

**规则 B｜与其它风格 Skill 搭配时——锚定词合并，规则不变**
- 若本 Skill 与另一个风格 Skill（例如另一套画风）被同时启用，**不是二选一**，而是把两套风格锚定词**按顺序合并**成一段更长的锚定词，仍然整体放在每条 prompt 的最开头，其余规则（前置、完整、不改写）保持不变。
- 合并顺序：**用户当前主诉求指向的风格在前，其它风格在后**；若无法判断主次，则**本 Skill 的锚定词在前**。合并时用中文顿号或换行自然衔接，不要删减任一方的原文。

**规则 C｜与非风格类 Skill(营销短片/图生视频/口播/分镜等)冲突时——风格以本 Skill 为准**
- 非风格类 Skill 负责的是**叙事结构、镜头脚本、时长、卖点、钩子、节奏、导出格式**等；本 Skill 负责的是**画面风格**。两者职责不冲突，应结合使用。
- 一旦发生"风格描述冲突"（例如营销 Skill 默认给出"实拍质感/3D/写实商业风/高饱和"等风格词），**一律以本 Skill 的风格为准**，删除或覆盖对方的风格词，保留对方的结构与流程。
- 最终产出的每一条图片/视频 prompt，仍必须以【风格锚定词】开头。

**规则 D｜禁止内置风格锚定图干扰（重要）**
- 部分 Agent 生成链路会针对某些风格**自动挂载内置的"风格参考图 / 风格锚定图 / style reference image"**。这类内置参考图会污染本 Skill 的画面风格，**必须绕过 / 关闭 / 不使用**。
- 具体执行：
  1. 生成图片/视频时，**不要引用、不要传入任何链路默认或内置的风格参考图**；风格完全由本 Skill 的文本锚定词驱动。
  2. 如果生成工具/接口存在"默认风格参考图""style preset""内置模板图"等参数，显式将其置空 / 关闭 / 不传。
  3. 仅当**用户本人主动上传**参考图时才可使用用户的图；除此之外一律不引入任何参考图。
  4. 若链路强制要求一张参考图且无法置空，**优先用本 Skill 先生成一张符合风格的首图**，再以该首图作为后续统一参考，而非使用 Agent 内置的锚定图。

**规则 E｜一致性**
- 同一个任务里的所有图片、所有视频镜头，锚定词必须**逐字一致**（或合并后的版本逐字一致），确保整批资产风格统一，不得中途更换或漏加。

## 1. 风格锚定词（Style Anchor — 固定原文，逐字复用）

> 下面这段是**固定锚定词原文**。放在每一条图片 prompt 与视频 prompt 的**最开头**，完整、逐字、不改写。

```
东方水墨画风，Eastern ink decorative illustration style。中国水墨、写意、书法用笔、影视镜头语言，书法式笔势、国画式留白和卷轴式空间为基础，用克制色彩、虚实相生的构图、背景有水墨笔触营造的雾气流动和墨迹的蔓延，用笔灵动，画面有灵动的笔触。
```

## 2. 标准工作流程（Agent 每次生成资产时按此执行）

1. **确认风格**：用户诉求命中东方水墨/国风水墨/写意/仙侠志怪山水等 → 启用本 Skill。
2. **检查搭配**：是否同时启用了其它风格 Skill？
   - 是 → 按【规则 B】合并锚定词。
   - 否 → 使用本 Skill 锚定词原文。
3. **检查冲突**：是否同时启用了营销短片/图生视频/分镜等非风格 Skill？
   - 是 → 保留其结构/流程能力，风格一律用本 Skill 覆盖（【规则 C】）。
4. **关闭内置锚定图**：显式绕过链路内置风格参考图（【规则 D】）。
5. **写图片素材 prompt**：`【锚定词原文】 + 本画面的主体/场景/构图/光影/色彩/笔触细节`（参考第 3、4 节知识撰写画面描述）。中文优先，必要时英文补充。
6. **写视频/分镜 prompt**：`【锚定词原文】 + 本镜头画面 + 运镜/动态/转场/节奏`（参考第 5 节动态语言）。
7. **一致性校验**：确认每条 prompt 开头锚定词逐字一致、无遗漏、无改写。

> 提示：撰写"画面描述"部分时，应主动引用第 3–6 节的风格知识（气质、构图、笔触、材质、造型、动态、色彩、母题），使脚本、分镜、角色描述天然贴合水墨风，而不仅仅依赖开头那段锚定词。

## 3. 整体风格气质（供脚本/分镜/角色描述参考）

核心逻辑不是"画得像国画"，而是"用国画逻辑做动画"：**气韵先于结构、笔势先于细节、意境先于写实、留白先于填满、节奏先于物理合理性**。第一观感应为：空灵、飘逸、含蓄、诗性、东方叙事感强，介于具象与抽象之间。

- 画面不是被"填出来"，而是被"留出来 / 甩出来 / 晕出来"。
- 单个主体常置于空旷天地中，突出孤绝、宿命、风骨、侠气、妖气或仙气。
- 动势由墨痕、衣带、烟雾、水波承担，而非仅靠人物动作。

---

## 4. 画面构图 / 笔触 / 材质 / 色彩知识（撰写画面描述时取用）

### 4.1 构图
- **留白是主角**：空白即"虚"，可作雾、天、水、光或未定义空间；留白越大主体越孤绝清冷。
- **重势不重稳**：斜向构图、上重下轻或反之、一边浓墨一边大空白、主体偏置、长线条引导视线。
- **压扁空间**：平远/高远/散点式空间，浅纵深，卷轴式可流动感，利于平移与展开式运动。

### 4.2 笔触与线条（风格成立的核心）
- **书法式中锋线**：衣纹、发丝、枝叶、剑势、山石边缘；有提按顿挫、起收明显、有飞白断续，"写"出来而非匀速描边。
- **破墨式大笔刷**：乌云、烟雾、水浪、妖气、黑袍下摆、山石阴面；边缘不规则、干湿浓淡、局部炸开渗开、保留偶然性。
- **飞白**：拖笔露白、枯笔纤维感、速度感、"风穿过去"的感觉；用于受风衣袍、甩动长发、水流边缘、云气流向。
- **泼墨与晕染边**：轮廓不完全封闭、墨边自然渗出、深浅过渡、在雾中半消失；主体一半靠线、一半靠墨、一半靠留白成立。
- **极简 + 局部重笔**：重要处精、次要处省；面部五官极简，关键处以重墨压出视觉锚点。以少胜多。

### 4.3 材质质感
- **底材似宣纸/绢本**：微黄或米白、有纤维纹理、表面不光滑、吸水柔化边缘。
- **墨分五色**：焦/浓/重/淡/清墨；最深近炭黑，大部分为冷暖灰变化，墨团内部有透明度层次，黑色也"呼吸"，忌纯平涂黑。
- **水痕渗化**：水痕圈、晕边、毛边、洇开、纸张不均匀沉积，使画面"活"。
- **颗粒摩擦感**：灰面/淡彩区有粉质感、干擦、细颗粒、纸纹透出，避免塑料化、AI 平滑化。

### 4.4 色彩体系（以墨为骨、淡彩为韵、一点艳色为神）
- **低饱和克制基调**：黑、白、灰、米、淡青、浅赭、冷褐、水绿、雾蓝、淡紫。
- **点染式用色**：大面积墨白灰 + 局部一点青绿/朱砂/胭脂/靛蓝/橙红，轻晕非厚涂（如发饰一点紫、腰带一点朱红）。
- **高级感来自少色**：九成克制、一成惊艳；忌全画面高饱和、彩色阴影过重、金属高光过于 3D、现代霓虹感。

## 5. 动态语言（撰写视频/分镜 prompt 时取用）

- **重起势收势**：强调蓄力—甩势—余韵，克制、有仪式感、不碎不乱，与戏曲/武术/书法相通。
- **外延元素在动**：真正流动的常是墨气、水波、风痕、衣摆、发丝、飘带、竹叶、雨线、飞鸟；人物本体可稳，周围皆流 → "静中有动"。
- **水墨式转场**：一团墨扩散化入下一镜、画面如宣纸吸水般过渡、山水轮廓从空白浮现、云烟遮挡转场、墨线一甩切换景别。比硬剪更有东方味。
- **节奏**：动作可少但势要足，追求余韵而非满帧炫技。

---

## 6. 角色造型规律（撰写角色/分镜时参考）

- **轮廓重于结构**：靠剪影、服饰大形、发髻/冠饰/斗笠/袖摆等识别物与姿态气质立人，弱解剖强神韵。
- **面部极简神态关键**：五官简约、眼线细长、眉形有书写感、鼻口轻描、腮红唇色点到即止；抓清冷/妖冶/英气/哀感/离尘/孤高。
- **衣袍是"线和面组成的风"**：下摆拉长、袖口甩开、边缘融入墨痕，与烟水风连成一体，人物仿佛从墨里"长"出来。

---

## 7. 场景光影与常见母题（供分镜/脚本参考）

- **光影**：弱化真实光影与体积，靠墨色浓淡与留白暗示光；雾气、逆光剪影、大片素白当光源，避免硬阴影与强立体高光。
- **人物母题**：孤身侠客、山野行者、伞下文士、抚琴吹箫者、水中灵女/妖灵、舞剑女子、神祇门神鬼将、少年游侠/隐士/渔樵。
- **场景母题**：苇荡、孤舟、长桥、山岚、雨幕、松竹梅、断崖飞瀑、雾湖、远山叠嶂、空庭檐角。
- **动势母题**：衣袍翻卷、长发飘散、墨浪吞吐、剑光破墨、鸟群掠空、水纹漾开、烟气回旋、飘带书写空气。

## 8. 五个可选子风格方向（按题材选用，仍统一使用锚定词）

| 子方向 | 特征 | 适合题材 |
|---|---|---|
| 志怪重墨型 | 大面积黑墨翻涌、威压/妖气/神性、强对比 | 山海经、神话、镇妖、鬼神 |
| 淡彩仕女型 | 面部柔美、墨线轻盈、淡紫青绿点染、婉约 | 古风女性、抒情短片、情感向 |
| 武侠泼墨型 | 黑白冲撞、刀剑轨迹+大笔墨波、爆发感 | 武侠、江湖、决斗、片头 |
| 山水抒情型 | 空间开阔、远山苇荡桥舟飞鸟、宁静卷轴 | 片头片尾、诗意转场、抒情章节 |
| 人物绘卷型 | 多角色分层、长卷叙事、命运感、书卷气 | 章节过场、传记式叙事、群像开场 |

> 子风格只影响"画面描述"部分的措辞，**不改变**开头锚定词的原文与前置规则。
