# 针绒缝童风格

一套可复用的动画风格化滤镜技能。核心机制:把一段**固定不变的风格锚定词**,原封不动地放在每一条**与角色相关**的图片编辑 prompt 与视频生成 prompt 的**最开头**,再接具体画面描述,从而保证同一批素材与成片的材质、纤维质感、光影、配色完全一致。

## 0. 风格锚定词(不可改动的核心资产)

以下这串词是本技能的唯一风格标准,任何与角色相关的图片转绘 prompt 与视频生成 prompt 都**必须**把它逐字放在**最开头**:

> **针绒缝童风格,无线稿,刺绣针脚缝边,材质模拟,棉布毛线纤维,轻度简化,圆润填充布偶,自然/真实色调,温暖布料综合色**

规则:
- **逐字复用、不改写、不翻译、不精简、不重排**;放在每条相关 prompt 的最前面,风格词与后续画面描述之间用逗号或换行分隔。
- 只有**与角色相关的图片资产**和**视频生成 prompt** 才加这串词;纯文字剧本、分镜说明等中间产物不需要加。

## 1. 核心原则 + 持久引擎

**核心原则:** 画风一致性来自"同一串风格锚定词被无差别地前置到每一次角色相关生成中"——风格不靠每次临时描述,而靠一个固定锚点在全链路复用。

持久引擎(因果链):
**用户上传角色素材 → 判定是否含明确角色主体 → 含主体则用风格锚定词直接转绘(不加任何额外内容) → 得到风格统一的角色资产 → 用户意图 + 风格化资产送入故事编写 → 生成高密度分镜脚本 → 每条视频 prompt 前置同一风格锚定词 → 产出画风一致的动画成片**

## 2. 质量测试(可证伪)

如果把成片里任意一帧角色画面单独拿出来,它的刺绣针脚缝边、棉布毛线纤维材质、圆润填充布偶体型、温暖布料综合色都能被一眼识别为同一套"针绒缝童"质感,且与用户上传的原始角色识别特征(发型/服装/配饰/体型)一致——则风格化成立。任何一帧掉出这套质感或角色跑形,即不通过,必须重做。

## 3. 输入诊断(动手前必须想清楚)

- **用户是否已上传角色相关图片素材?** —— 这是本技能的**前置必要条件**。若用户未上传任何图片素材,先追问并请其上传;不要凭空生成角色再套风格。
- **每张上传图片是否含明确角色主体?** —— 只有含明确角色主体(人物、宠物等有生命/拟人主体)的图片才做风格化转绘。**单独的物品图、空镜场景图、没有明确主体的风景图一律不转绘**,原样跳过。
- **产物是图片还是视频?** —— 只要风格化图片 → 到风格化转绘为止;要动画短片 → 继续进入故事编写与视频生成。
- **用户的意图/剧情描述是什么?** —— 用作故事编写的创作意图输入。
- **是否同时加载了其它风格类技能?** —— 若是,按第 4 节合并风格锚定词。
- **是否同时加载了非风格类技能(如营销短片、剧情短片等)?** —— 若是,按第 4 节冲突规则,本技能的风格化与锚定词前置规则优先保留。

## 4. 与其它技能的协同/冲突规则(硬规则)

**A. 与其它「风格类」技能搭配时——合并锚定词,规则不变:**
当本技能与另一个风格类技能同时被加载时,把两套风格锚定词**内容合并**成一串(本技能锚定词 + 另一技能锚定词,用逗号连接),仍整串放在每条角色相关 prompt 的最开头;"逐字前置、只对含角色主体的图片转绘、纯中间产物不加词"这些规则保持不变。

**B. 与「非风格类」技能(如营销短片、剧情短片、广告片等)搭配时——本技能的风格约束优先:**
即使同时加载了非风格类技能,也**必须遵守本技能以下部分,并与对方技能结合**:
- 非风格技能负责**叙事结构、卖点、分镜节奏、体裁**等内容层;本技能负责**画风层**。
- 无论对方技能如何组织 prompt,凡最终要送去生成的**角色相关图片 prompt 与视频 prompt,开头都必须前置本技能第 0 节风格锚定词**(若同时有风格类技能,则前置合并后的锚定词)。
- 用户上传的角色素材必须**先经过本技能风格化转绘**,再交给非风格技能流程使用;不要跳过风格化直接拿原图去做叙事生成。
- 若对方技能自带某种默认画风描述,与本技能锚定词冲突时,**以本技能锚定词为准**,删除对方画风描述词,保留其叙事/节奏/结构部分。

## 5. 工作流(分步 SOP)

### Phase 0 — 前置检查
确认用户已上传角色相关图片素材。若无,请其先上传后再继续。

### Phase 1 — 角色素材风格化转绘(逐张处理)
对用户上传的每一张图片:
1. **判定主体**:该图是否含明确角色主体(人物/宠物等)?
   - **含明确角色主体** → 进入第 2 步转绘。
   - **单独物品 / 空镜场景 / 无明确主体的风景** → **跳过,不转绘**,保留原图或据用户意图另行处理。
2. **风格化转绘(以原图为底的图片编辑)**:以**用户这张图为底图**做风格转绘。此时**图片编辑提示词直接、且仅使用第 0 节的风格锚定词本身**——
   > 针绒缝童风格,无线稿,刺绣针脚缝边,材质模拟,棉布毛线纤维,轻度简化,圆润填充布偶,自然/真实色调,温暖布料综合色

   **不要在编辑提示词里额外添加任何其它描述内容**(不加场景、不加动作、不加情绪、不加相机词);完全基于用户原图转绘,保留原图角色的发型/服装/配饰/体型等识别特征,只把其质感替换为针绒缝童风格。

   > (若同时加载了其它风格类技能,则此处用合并后的锚定词,规则见第 4.A 节。)
3. 生成风格化后的角色资产图片,展示给用户。

### Phase 2 — 若用户要动画短片:故事编写 + 视频生成
1. **故事编写**:把 Phase 1 得到的**全部风格化角色资产** + **用户的意图描述**,一起交给随附的故事编写 System Prompt(见 `references/story-system-prompt.md`,进入本阶段前**必须完整读取并严格遵循**),产出一段高密度、快节奏、多景别、运镜丰富的中文分镜视频提示词。
2. **组装视频生成 prompt**:把故事编写产出的画面提示词,在**最开头前置第 0 节风格锚定词**(有风格类技能协同则用合并锚定词),再接故事编写生成的分镜正文。
3. **生成视频**:目标成片时长 ≤15s 时,**一次生成即可拿到完整成片**——分镜里的 0-3s/3-7s/… 时间码是同一条 prompt 内部的时间轴描述,不是要分多次生成;只有成片时长超过 15s 时,才拆成多个 ≤15s 片段分别生成,再做后处理拼接。视频以用户上传并风格化后的角色资产为形象参考。
4. 把成片展示给用户。

## 6. 输出契约

- **图片产物**:每张风格化图片的编辑提示词 = 仅第 0 节风格锚定词(或合并锚定词),无额外内容;底图为用户上传的含角色主体的原图。
- **视频产物**:视频 prompt = `风格锚定词(或合并锚定词)` + 故事编写 System Prompt 产出的分镜正文;分镜正文遵循随附 System Prompt 的输出模板(风格题材 / 一句话剧情 / 角色锁定 / 画面提示词含时间戳分镜 / BGM / 环境音 / 默认约束)。
- **默认负向约束**(挂在视频 prompt 末尾):严格按上传的图片和风格笔触生成,保持无字幕、不要生成任何文字,不要生成 logo 与水印。
