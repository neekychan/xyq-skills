# 生成前质量自查清单

每次输出分镜或提示词后，必须逐条核对以下清单。不通过的项须修正后重新输出，不进入下一阶段。

---

## 清单

### 1. 戏剧冲突检查
- [ ] 是否存在"强行制造戏剧冲突"的镜头？
  - → 优先改为留白、转喻、声画分离或情绪余波表达

### 2. 情绪表演检查
- [ ] 是否有角色直接进行激烈情绪表演（大哭、大喊、崩溃）？
  - → 改为空镜、环境变化、物件细节或声音承载情绪

### 3. 镜头停留时间检查
- [ ] 所有镜头是否保留足够停留时间？
  - → 单镜头建议 ≥ 6 秒，避免 MV 式快速切换

### 4. 呼吸感检查
- [ ] 镜头之间是否缺乏呼吸感？
  - → 必须加入空镜、黑场、环境音或节奏缓冲

### 5. 情绪推进方式检查
- [ ] 情绪推进是否过于"解释性"？
  - → 减少说明感，增加观察感与感受空间

### 6. 东亚视角检查
- [ ] 东亚场景是否被拍成"猎奇化""观光化"视角？
  - → 回到本地人日常生活的观察视角

### 7. 提示词气质检查
- [ ] 提示词是否出现破坏文艺气质的直给表达？
  - → 删除过度戏剧化、口号化、表演化描述
  - → 核对禁止词清单（见 references/prompt-engineering.md）

### 8. 呼吸结构检查
- [ ] 全片是否符合"呼吸结构"：
  - 铺垫（吸气）→ 情绪停滞（屏息）→ 情绪释放（呼气）
  - → 若节奏始终单一，必须重新调整情绪曲线

### 9. 运镜合规检查
- [ ] 所有 shot 是否均从推荐运镜中选择？
  - → 核对运镜规范表（见 references/cinematography.md）
  - → 禁止运镜是否出现？如有，立即替换

### 10. 能力边界检查
- [ ] 是否存在危险场景（剧烈情绪爆发、快速运动、多人对峙、复杂场景转换）未使用替代方案？
  - → 必须在分镜层提前替换为声画分离/情绪前置/情绪后置/转喻方案

### 11. 参考素材一致性检查
- [ ] 若用户提供了参考素材，element 描述和 shot 设计是否与之冲突？
  - → 如有冲突，以参考素材为准修正描述

### 12. 禁止词扫描
- [ ] 提示词中是否包含禁止关键词？
  - → 逐词核对禁止词表，发现即删除替换
