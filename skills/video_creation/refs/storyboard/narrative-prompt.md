# 叙事类 Prompt 编写指南（故事/历史）

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意发散阶段的叙事骨架、故事类型速查、时代-画风映射见 `creative/narrative-suite.md`。科普/教程 Prompt → `storyboard/knowledge-prompt.md`。

## Prompt 模板（温馨寓言示例）

```
参考@图片1的形象作为小狐狸，
场景参考@图片3。
清晨森林中，晨光从画面右上方斜射穿透薄雾形成可见光束，树叶间洒下斑驳光影。
小狐狸从树洞中探出头，橙红毛发边缘被晨光照出细金边，好奇地嗅闻空气，然后小心翼翼地走出洞穴。
旁白（温柔女声）：{在大山深处的一片古老森林里，住着一只小狐狸。每天清晨，它都会独自出门寻找食物。}
镜头从树洞特写缓推至森林全景，低角度暖金色晨光逆照，雾中光束随镜头后拉逐渐铺满画面。
3D皮克斯风格动画，圆润造型，明亮色彩。
五官清晰，4K超高清，画面稳定，保持无字幕，禁止生成BGM。
时长：12秒，比例：16:9
```
