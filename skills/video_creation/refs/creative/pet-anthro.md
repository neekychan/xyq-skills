# 萌宠拟人/动物主角视频创作指南

适用：以宠物/动物为主角的视频——萌宠日常、动物拟人剧情、宠物说话/祝福、动物 IP 角色。

## 拟人化层级判定（先读，决定全部下游规则）

用户几乎从不声明拟人化程度，必须从意图反推层级，**全程锁定一级，禁止混搭**——写实动物混入人类肢体是本垂类最高频崩坏。

| 用户信号 | 层级 | 形态边界 |
|---------|------|---------|
| 记录日常/治愈/ASMR/真实质感 | **L1 真实动物** | 四足，只做动物行为，无人类动作 |
| 让宠物说话/祝福/摆姿势/卡点 | **L2 真实形体+拟人神态** | 形体仍是动物，允许表情、口型、前爪大幅简单动作 |
| 摆摊/做饭/打工/穿衣/用工具 | **L3 直立拟人** | 两足直立、穿衣、爪持道具操作 |
| Q版/卡通形象/吉祥物/品牌 IP | **L4 卡通 IP** | 3D 卡通/插画体，圆润造型，规避写实毛发 |

多段创作时在 creative_design.md 对应动物角色的「剧本要素/角色/描述」中记入 `拟人化层级：LN`，所有素材与视频 prompt 与之对齐；多动物同框必须同级。

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| "宠物熟练地摊煎饼/操作工具"（动作写给"手"） | 爪子渲染成人手，画面混入人类手部 | 写"前爪/肉垫"+具体持物方式，prompt 末尾加"画面中禁止出现人类手部" |
| 一拍塞多个精细动作（磕蛋+刷酱+卷饼） | 动作穿模、跳变、顺序错乱 | 一拍一动作，每 2-3 秒一个动作单独白描 |
| 把动物素材"转换为人类面孔/人体" | 用户要的是这只宠物出演，成片却成了陌生人，主体丢失 | 保留动物头脸与体型；用户给的人类角色设定（镖客/大官/穿盔甲等）由动物按拟人层级来演，靠服饰道具+口型+姿态实现，禁止改物种 |
| 多动物同框不锁体型与花纹 | 巨型猫、角色互换 | 每只写"正常家猫/犬体型"+毛色花纹差异点，每段重复 |
| 不指定音色 | 成年人声配奶猫，萌感尽失 | 按体型/年龄锁音色：幼猫幼犬=软萌奶气童音，跨段逐字一致 |
| 写实风格+L3 直立行走 | 直立姿态僵硬、下肢崩坏 | 用户未明确要求写实 → 默认 3D 卡通/动画风；用户明确要求写实 → 锁定"定点站立+仅上肢动作，不走动"，并向用户提示写实直立的稳定性风险 |
| 人类配角入镜（含"只露一只手"） | 人手/人体渲染崩坏，与"禁止人类手部"自相矛盾 | 人类配角一律不入镜：交互改为画外音示意或物品递向镜头 |

## 强制规则

1. **先定级再创作**：层级判定先于风格、分镜、台词等一切决策
2. **动物行为学动词**：L1/L2 的动作用 嗅、蹭、踩奶、竖耳、摇尾、歪头、舔爪 等具体动词，禁用"开心地玩耍"类抽象词
3. **爪部白描**：L2 及以上涉及操作时写"前爪/肉垫"而非"手"，描述持物方式（双爪捧住/肉垫按住/爪尖勾起）；直立/四足姿态与爪/手归属在角色设定时一次定死，全片不得段内摇摆或混用
4. **体型锚定**：每只动物的体型词（正常家猫体型/小型犬体型）在每段 prompt 中重复出现
5. **微动作萌点**：说话/口播场景必须加 1-2 个微动作（歪头、眨眼、抬爪轻挥、耳朵抖动），禁止大幅肢体动作
6. **声音设计**：说话场景明示口型同步；不说话的 L1 场景用环境音+动物原声（呼噜声、踩奶声、咀嚼声），禁配乐淹没

## 高频模板（结构套路）

### A 萌宠摆摊/做饭（L3）

固定镜头 + 动作序列分解：场景一句定调（清晨街角早饭摊，烟火气）→ 逐拍白描动作（每拍写明哪只爪做什么、道具状态变化）→ 结尾与镜头互动（递食物给镜头/抬头看镜头）。环境音：摊位声、食物滋滋声。

### B 拟人 Vlog（L2/L3）

第一人称或跟拍视角 + 人设标签（打工人/学生/家庭成员）+ 快切节奏。镜头词：手持微晃、呼吸感。人设靠道具和场景外化（工装裤、书包、围裙），不靠旁白自述。

### C 宠物说话/祝福口播（L2）

正面中近景 + 口型同步台词 + 微动作组合。动作克制原则与数字人讲解相同（落点不同：数字人求专业可信，宠物求软萌）。
