# 现实悬疑电影风：prompt 文法（锚定词拼接 / beat 结构 / 一致性）

> 可适配的模式与句式，按场景改写，不要逐字照搬（**但风格锚定词本身必须逐字前置、不可改写**）。

本文件说明如何把固定风格锚定词与每一条具体画面描述拼接成可直接使用的 prompt。风格锚定词是 SKILL.md 里那一整段，本文件用 `[风格锚定词]` 代指——实际写 prompt 时必须替换成完整原文并放在最前面。

## 一、拼接总则

一条 prompt 永远是两段式：`[风格锚定词]` + `具体画面`。
- 第一段：整段风格锚定词，逐字复制，放最前面（若与其他风格 skill 合并，见第五节，用拼接后的合并锚定词整段前置）。
- 第二段：只写这一条素材独有的内容（主体、动作、场景、光位、构图、景别、情绪）。
- **不要**在第二段重复写“去饱和 / 冷灰 / 深黑阴影 / 细腻颗粒 / 柔和反差 / 胶片滤镜”等——这些已由锚定词负责，重复只会互相打架。
- 全程正向措辞：描述“画面里有什么”，而不是“不要什么”。

## 二、图片 prompt 段（生成图片素材时用）

单张图片描述用“主体 + 光位 + 构图 + 情绪”四件套，接在锚定词后：

```
[风格锚定词] 一名中年男人独自站在空旷的旧工厂车间中央，背对镜头微微侧脸，顶部天窗漏下的冷白光斜切在地面，宏大横向全景，人物很小、环境很大，紧张压抑、克制的注视感
```

要点：
- **光位优先冷调硬调**：顶光、侧逆光、夜景路灯、荧光灯冷白、走廊尽头透进的窄光——最能触发锚定词里的“冷灰、深黑阴影、柔和反差”。
- **景别与构图优先宏大横向**：大远景 / 全景把人物压在空旷环境里最出悬疑感；特写用于线索道具、面部微表情；空镜（走廊、楼道、空房间、雨夜街道）适合做压抑氛围素材。
- **主体动作克制**：现实悬疑重“克制真实”，动作幅度小、静态凝视、缓步、停顿更贴合，避免夸张表演。

## 三、视频 beat 段（写视频 prompt 时用）

以整段锚定词开头，换行后写时间码 beat，每个 beat 描述“镜头运动 / 画面主体动作 / 光线 / 声音提示”：

```
[风格锚定词]
0-3s: 固定长镜头，中年男人静立在空旷车间，冷白顶光下尘埃浮动，环境只有低频嗡鸣与远处滴水声
3-7s: 镜头极缓慢横移，扫过锈蚀的机器与散落的物件，阴影里藏着看不清的轮廓
7-12s: 缓慢推进到男人侧脸，他微微转头看向画外，眼神克制而紧张
12-15s: 镜头缓缓拉远回到宏大横向全景，人物被空旷吞没，画面沉入深黑
```

要点：
- **稳、慢、克制的运镜**最像现实悬疑电影：固定长镜头、极缓慢横移/推拉、轨道感——避免手持晃动与快速剪切。
- beat 里写的是**内容与运镜**，风格仍只由开头的锚定词负责。
- ≤15s 的成片：以上多段 beat 写在**同一条 prompt** 里一次生成即可拿到完整片段；成片 >15s 才拆成多个 ≤15s 片段分别生成再拼接。

## 四、一致性段（图生视频 / 人物跨镜复现）

- **图生视频**：先按第二节生成一张满意的图片素材，再以它作为视频首帧 / 参考帧驱动视频，能最大程度锁住人物长相与场景。
- **跨镜一致**：同一人物 / 道具 / 场景在多条 prompt 里用稳定标签绑定，例如统一写 `Subject1（同一名中年男人）`、`Scene1（同一间旧工厂车间）`，每条 prompt 都复用同一描述，减少漂移。
- 人物特征（发型、服装、五官关键词）在每条 prompt 里保持**同样措辞**，不要换词。

## 五、与其他风格 skill 合并时的锚定词写法

当本技能与其他风格滤镜 skill 同时启用、要在同一批资产里叠加多种风格时，**不新造锚定词**，而是把各技能的完整锚定词各自逐字保留、整段拼接成“合并锚定词”，再整段前置：

```
[本技能整段锚定词]
[另一风格 skill 整段锚定词]
<本条具体画面描述>
```

- 顺序：用户点名的主风格在前，未指定时本技能锚定词在前。
- 不去重、不融合、不改写：即使两段都提到颗粒/色调，也各自原样保留。
- 合并锚定词一旦定下，本回合所有图片/视频 prompt 复用同一份。

## 落 prompt 前自检

- [ ] 每条 prompt 是否以整段风格锚定词（或合并锚定词）逐字开头，原文标点原样保留？
- [ ] 具体描述是否排在锚定词之后，且没有重复堆风格词？
- [ ] 光位是否用了冷调硬调（顶光/侧逆光/夜景/冷白荧光）？构图是否偏宏大横向？
- [ ] 视频运镜是否体现稳、慢、克制的电影感？beat 是否写在同一条 prompt 内（≤15s 一次成片）？
- [ ] 跨镜人物是否用稳定标签 + 同样措辞锁一致性？
- [ ] 若合并多风格，是否各锚定词整段逐字拼接、未去重、整段前置？
