# 剧本分析、资产拆解与分镜设计

先读 [风格知识库](style-guide.md)；立项或变更题材时读 [跨题材规则](genre-adaptation.md)。本文件负责戏剧内容和镜头结构，不再建立第二套视觉关键词。

## 剧本诊断与短剧化

1. **来源与成熟度**：区分小说原文、想法、分集纲、完整剧本、已有分镜。分析原文时记录章节/段落或场次，不虚构来源；缺失内容写为创作建议。
2. **人物引擎**：谁想要什么、谁阻止、失败代价、关系秘密、行动动机、当前掌握的信息。权谋/职场靠信息和利益，武侠/动作靠行动与抉择，言情/家庭靠关系推进，校园/成长靠目标和抉择，悬疑靠线索和误判，科幻靠设定造成的具体困境；不要一律改为吼叫复仇。
3. **结构与钩子**：开篇约 3 秒能否交代一个异常、冲突或悬念；中段每个关键节拍是否改变关系/信息/处境；结尾是否有明确选择、反转或未解问题。单纯美景可建立意境，但不能长期取代故事推进。
4. **可拍性**：把不可见心理转换为行为、物件、眼神、声音；角色内心原文可保留为 OS，但仍需要可见表演。统计场景切换、群众、打斗/追逐、特效/机械交互、角色造型和时长。
5. **改编方式**：用户只要分析就停在分析。用户授权写作则产出可修改版本，保留原文映射，说明新增、合并、删减及其目的。不得把建议当用户已经确认的设定。

诊断报告至少包含：剧情摘要、人物关系、核心冲突、成熟度与缺口、钩子、资产清单、预计时长/镜数、建议接续阶段。小说变剧本采用“场次/地点/日夜—出场角色—可见动作—对白/OS/VO”的格式。

对白按时代、题材、年龄、身份和关系区分声口：现代角色自然口语，古风可用清楚雅致的表达，科幻术语来自项目设定。删去解释观众已经看见的信息；旁白语体跟随项目，不默认文言意象，避免每镜重复说理。用户已有完整台词时，不为了时长擅自删除关键句。

## 制作参数与 key_element

按需记录下列字段，可用 Markdown 表格或项目 JSON；沿用宿主已有字段也可，但 ID 必须稳定。

| 类别 | 必需信息 |
|---|---|
| 项目 | 时代/世界观、允许与排除的元素、题材、台词语体、音乐方向、集数/制作范围、目标时长、画幅、语言、固定锚定词、目标与实际规格 |
| 角色 | character_id、姓名/称谓、年龄感、身份关系、脸型五官、体态、肤色/肤质、识别点、声音档案 |
| 造型 | look_id、所属角色、发型、内搭/外层/下装/鞋、配饰、2—3 色配色、材质/纹样、磨损或剧情状态、母版引用 |
| 场景 | scene_id、结构和四向布局、固定地标、材质纹样、世界坐标光源、色温/氛围、群像分布、状态变体 |
| 道具 | prop_id、尺寸、材质颜色、正反差异、识别点、当前状态、持有者/持握手、状态变体 |
| 声音 | voice_id、所属角色/旁白、音色/年龄感/语气/语速/口音、样本或工具音色 ID、实际制作方式 |

大型固定陈设（办公桌、货架、机台、床榻、御案、城门）归场景，不能每镜重新摆放；手持剑、信、手机、工牌、钥匙、药瓶、探测器等归道具。可移动家具若剧情确需移动，登记场景状态变化与移动事件，不能仅因体积大忽略其连续性。

角色默认共享暖白色温和细腻 SSS 肤质，已有身份设定优先；不以“惨白、青面、面如死灰”表达害怕或愤怒导致换肤色。宫装可写云纹金绣、薄纱和玉饰；现代服装写针织、棉布、剪裁与缝线；科幻装备写接缝、关节、哑光金属和发光元件；朴素衣物也以布纹、旧痕体现渲染精度。

群像场景登记群众规模、服装层级、站位区域与活动。群众属于背景层，仍要三维风格与时代一致；不把“主叙事角色通常不超过 3 人”误当清空会议室、车站、朝堂和集市。

场景以世界空间固定布局和固定光影文本为基准。例：“东侧高窗柔光，约 4500K，暖白漫反射，安静而紧绷，轻雾保持背景清晰。”同一场景状态逐镜引用这段基准，机位变化时重算光源在画面哪侧。点灯、破窗、日夜转换建立新状态和变化原因。设定板使用展示光，不代替剧情光源元数据。

## 镜表与时长

`shot_id` = 一次视频生成的片段；`cut_id` = 片段内部的实际镜头/机位。通常每段 10—15 秒、2—5 个内切镜；长于工具上限或 15 秒必须拆分，短场面无需凑满 10 秒。工具不支持内切镜时，改为一次生成一个实际镜头，再剪辑组装，记录此映射。

同一连续动作尽量同段完成；跨物理空间、巨大换位或工具上限才切新段。主叙事人物通常不超过 3 人以保持可读性，复杂群戏拆覆盖角度。镜头数量由戏剧职责和实际时长决定。

| shot_id / cut_id | 时长/段内时间 | 戏剧职责 | 场景/造型/道具 | 景别+机位+运镜 | 动作/表情/目光 | 台词/OS/VO/音效 | 起止状态/接镜 |
|---|---|---|---|---|---|---|---|
| 每行一个内切镜 | 估算与实测分开 | 信息/关系/行动改变 | 稳定 ID | 三项齐备 | 明确目标和过程 | 原文与说话者 | 姿态/持物/位置/方向 |

时长估算先按角色语速读台词；尚无样音时，古风戏剧念白可暂用约 2.5 字/秒，现代自然对白可暂用约 3—4 字/秒，均是可调整假设，需另加停顿并以实际朗读/音频实测复核。不要将慢速古风念白套给所有角色。主要台词落点和动作收势原则上预留约 1 秒，快节奏追逐或连续对话可调整并说明。动作、台词并行取实际覆盖时间，不把并行时长机械相加；OS/VO 也占时间，禁止挤成超速念白。

| 内容 | 初始估算 |
|---|---|
| 手/眼/物件细节 | 约 2—3.5 秒 |
| 带短句的脸部特写 | 约 3—5 秒，台词较长则按语音重算 |
| 近景对白 | 约 3.5—5 秒，另检查落点 |
| 中景关系/动作 | 约 4—6 秒，完整起势/执行/收势优先 |
| 复杂推进、绕行、揭示 | 在动作基础上留出可读运镜时间 |

总片长为剪辑时间线的实际长度；转场重叠、段头尾裁剪需扣除，不能只把模型标称时长相加。

## 人物表演与摄影机

- 每句台词有可见表演依据：具体目光目标、头部/手势/身体状态或有意克制。写清“看向谁/哪件物”，不要空洞注视；可通过听者反应表达潜台词。
- 情绪路径遵循因果，如“试探→察觉隐瞒→压住怒意”。转折处可放大表情或动作，但沉默、僵住、缓慢放下手也可以是强烈反应，不强迫每句甩袖拍案。
- 动作写起势→执行→收势，主次明确；台词落音和动作结束保留需要的余势。含蓄有力与第一份风格气质一致。
- OS 与外说台词分开，OS 期间嘴唇不动，按语义设计“抬眼→眉心收紧→视线落向关键道具”等表情路径。VO 不要求画面角色开口。
- 以近景、特写、大特写为情绪主力，中景/中全景交代关系和动作；确有需要时用远景俯瞰展势。空镜展示环境、物件、时间变化，不用一律禁止远景替代叙事判断。
- 每个内切镜写景别、机位和运镜。慢推、快推、拉远、横摇、跟随、弧线、升降按情绪选择；重要台词可收紧景别。固定镜通常保持精练，超过约 4 秒检查是否有有效的表演与信息变化，不为凑动势强制运镜。
- 过肩镜必须是两个不同角色：明确前景是谁的肩背、背景是谁的面部。正反打保持既定轴线及正确视线，单个“过肩”标签不能自动解决跳轴。
- 反应镜可“甲说→乙反应→回甲”，不每句话都照搬；非面部细节如攥衣、握手机、剑柄收紧服务当下情绪，避免连续堆叠超过两个造成碎片化。

## 空间锚点卡

每个生成片段写世界状态，再为**每个机位/内切镜**写可见投影。详见 [空间连续性](spatial-consistency.md)。

```yaml
shot_id: EP01-SH001
scene_id: SC01
scene_state: DAY-A
lighting_basis: 从场景状态逐字引用固定光影基准
world_state:
  fixed_landmarks: 门窗/固定家具/台阶等的位置与四向视图对应
  characters: 每人世界站位、朝向、姿态、持物、进出场状态
  departed: 离场角色原位的可见状态；无则写无
cuts:
  - cut_id: C01
    camera: 机位所在侧、拍摄方向、景别、运镜
    visible: 从此机位实际可见的地标，以及各角色屏幕左右/前后层级
    offscreen: 必须排除的关键元素，简记即可
    eyelines: 视线目标、画面方向及轴线侧
    end_state: 本内切镜结束的角色位置、姿态、持物和道具状态
handoff: 片段结尾状态与下段起始动作如何衔接
```

镜头背景从四向布局推导，不编造不存在的门窗；世界状态可以使用角色朝向，提交视觉 prompt 时则转为镜头相对可见描述。已有原图或定稿布局不清楚时提出具体缺口；用户授权原创场景时可设计布局草案，建立后保持一致。

离场角色的原位如果仍在画中，应写空椅/无人/由谁占据；角色离画不等于物件消失。实际移动写明从哪里到哪里，更新状态后再生成后续镜。

## 动作场面：武打、追逐与机械交互

打斗默认节奏：**起手（交代双方距离）→接触（兵器/身体细节）→命中或化解→结果（谁退、谁站稳）**。连续动作不靠满屏震动遮掩，镜头晃动仅在有效命中瞬间短暂使用。

每个交手节拍写全六项：谁先动、谁防守、接触点、交锋结果、受力结果、段末状态。含格挡/闪避/落空/反制与喘息，不能所有攻击都命中。示例动作说明：“乙横劈，甲右脚后撤、双手抬剑；刀刃撞在剑身中段，甲格挡成功但手腕下沉；甲顺势侧让，剑尖停在乙喉前，双方定住。”这是动作分解，不是完整生成 prompt。

4—8 秒一般不超过 3 个主要打击；8—12 秒可容纳 3—5 个主要动作，但以动作清楚为准。低机位、兵器细节、倒地视角、横移揭示可按需选，决胜一击才重点用慢动作，同段不堆叠过多强调手法。

追逐先建立路线、距离、障碍和出入画方向，再写起跑→加速→越障/躲避→落地→下一段位置。机械交互写操作方、控制部件、动作、设备反馈和结束状态；持手机、开车门、刷门禁同样保持持物手和接触位置。科幻能量效果按世界观说明来源与结果，不默认转成法阵或剑气。

## 完稿验收

对照原文检查关键动作、台词、伏笔和转折均有去向；题材和时代元素与原设定相符；各镜有拍摄理由，表演因果与角色身份一致；台词、OS、动作可装入时长；造型和道具状态稳定；世界空间、逐机位可见背景、视线轴线、光影状态正确；前后起止状态可接；音频与表演对应。修复镜表中的派生错误，不擅改用户锁定剧本。
