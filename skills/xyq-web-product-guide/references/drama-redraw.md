# 短剧重制转绘

使用手册：[短剧「重制转绘」使用手册](https://bytedance.larkoffice.com/docx/MnpVdCS6uosSv4x0lBZcys81nKK)。此链接供用户自行查看，Agent 只查本地内容。

## 用途与模式

上传已有短剧，解析角色、场景、道具及镜头，再按指定画风、比例和目标地区重新生成，尽量保留原剧情节奏和镜头结构，适合换画风或制作出海本土化版本。

- 接入 Seedance 2.5，分镜工作台提供多种模型以适配不同预算；完整可选模型列表未收录。
- 白模复刻：基于原视频生成白模作为运动参考，用于继承机位、运镜和切镜。
- 普通复刻：兼顾还原度与成本。具体价格差异未收录。
- 一次解析可切换多种画风和画幅比例；目标地区在确认解析后不能切换。
- 支持 17 种目标地区，按地区适配人物、语言与环境特征。已列举中国、日本、韩国、美国、印尼、巴西、南非、墨西哥，完整列表未收录，不补齐猜测。

“1:1 还原”等效果描述不是每次生成的结果保证。

## 上传限制

| 项目 | 支持范围 |
| --- | --- |
| 格式 | MP4、MOV |
| 单个视频时长 | 5–300 秒，即最长 5 分钟 |
| 单个文件大小 | 不超过 500 MB |
| 上传数量 | 最多 20 个视频 |
| 单项目总时长 | 最多 100 分钟短剧 |

上传素材需拥有版权或已获得授权。

## 从原片到成片

1. 打开“短剧 Agent”，在顶部标签切到“重制转绘”，点击“上传视频”或拖入视频。
2. 在“上传原片”页批量上传剧集。上传中或上传完成后可添加原片、调整集数顺序、重新上传或删除某集。设置右上角的风格、比例和目标地区；比例包括 16:9、竖屏等，完整选项未收录。
3. 全部上传完成且已选好风格和目标地区后，点击“确认顺序并解析”，核对确认框中的顺序、地区和预估积分。确认后不能再修改集数顺序、增删原片或切换目标地区。
4. 等待各集由“未解析”进入“解析中”“解析完成”。解析产出分集脚本、片段脚本、分镜、角色、场景、原片片段与关键帧。若有“解析失败”，点击“重新解析”，会对所有失败剧集一起重试，不影响其他集。
5. 解析完成后点击“资产本土化”，按已选目标地区与语言调整角色、场景等资产。完成后点“下一步”进入资产库。
6. 检查角色、场景、道具和素材的提示词及形象。角色卡右下角提供原片参考图，可对照检查、下载；不满意时微调或重新生成，右上角“批量”可批量生成资产图片。确认后点“下一步”进入“分集视频”。
7. 对各集点击“生成脚本”，或使用右上角“批量”处理多集。该步基于最新修改的本地资产库生成分镜脚本；不要将前面的原片解析脚本误当作已应用所有资产修改的最终脚本。
8. 进入单集分镜工作台逐片段精修。左侧是本集角色与场景资产，中间是片段脚本分镜，右侧预览可切换“转绘 / 原片 / 白模 / 对比”。
9. 按需点击片段栏上方的“白模参考”，勾选需生成白模的片段；白模生成后会自动引用为复刻素材。可点击右侧“对比”，左边原片、右边复刻版并排同步播放。
10. 各片段满意后点击右上角“合成全集”。回到分集列表查看状态，已完成的集可播放、编辑、下载。

## 积分与确认事项

- 原片解析会消耗积分，按视频总时长预估，以实际界面为准。
- 资产本土化也消耗积分，按视频总时长预估，以实际界面为准。
- 分镜脚本生成按原视频时长消耗积分，以实际生成为准。
- 固定单价、白模与普通复刻的差价、重试是否扣费及退款规则未收录；不从截图中的数值推导收费。其他积分与权益问题结合[积分 FAQ](credits-benefits-faq.md)回答。

## 常见问题

**为什么“确认顺序并解析”点不了？**

检查视频是否全部上传完成，以及风格和目标地区是否已选好；比例也应在解析前按需求设置。

**解析后还能增删集数、换顺序或目标地区吗？**

不能。请在确认解析前核对。画风与比例支持基于一次解析切换，不能把这个能力理解为地区也能切换。

**某集解析失败要全部重来吗？**

不影响其他集，点击“重新解析”会统一重试所有失败集。

**角色或场景本土化后不满意怎么办？**

到资产库核对描述与原片参考图，微调或重新生成资产，再基于更新后的资产库生成分集脚本。

**白模参考怎么用？**

进入单集分镜工作台，点击“白模参考”并勾选片段。生成后自动引用为复刻参考，可切到“白模”查看，或用“对比”比较原片和复刻版。

**100 分钟是单集上限吗？**

不是。单个视频最长 5 分钟；单项目最多 20 个视频，总计最多 100 分钟。

**能否保证镜头完全一致、多久完成、导出什么分辨率？**

白模用于保留镜头运动和结构，但不承诺效果完全一致。固定完成时间和完整导出规格未收录，不能把截图的分辨率当成支持上限；不足以回答时使用未命中提示。
