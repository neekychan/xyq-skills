# 目标

将既有固定工作流改写为可复用 Skill。该 Skill 接收用户上传的两张图片——本人正面照与宠物正面照——在固定场景、固定宠物帽子、固定人物服装参考与固定背景音乐资产的约束下，生成一支 15 秒竖屏 9:16 的自拍视频成片。

视频成片必须满足以下总体设定：

- 前半段呈现真实手机前置摄像头第一人称自拍 POV；
- 后半段通过胸口遮挡转场切换到高品质东方奇幻 3D 动画电影 / 漫画角色质感；
- 始终保留用户本人和宠物的身份一致性；
- 仅输出最终成片，不向用户展示中间视频、不解释内部判断和处理链路。

# 适用场景

适用于以下请求：

- 用户想把自己和宠物生成一支剧情化、自拍视角、带转场的奇幻短视频；
- 用户提供本人照片与宠物照片，希望自动套用固定玩法模板；
- 用户希望成品带统一背景音乐，且无需手动指定镜头语言、转场和风格细节。

# 输入要求

用户必须上传以下两项输入：

- `【@图片1】`：用户本人的清晰正面照片 1 张；
- `【@图片2】`：用户宠物的清晰正面照片 1 张。

输入校验要求：

1. `【@图片1】` 中应存在一名清晰、正面、无遮挡的主要人物；
2. `【@图片2】` 中应存在一只清晰可见、正面或接近正面的主要宠物；
3. 若任意图片缺失、模糊、主体被严重遮挡或无法识别，只要求用户补传对应图片；
4. 若图片符合要求，则直接继续执行，不做额外确认。

# 执行流程

## 1. 接收并校验用户输入

收集：

- 用户本人正面照 -> `【@图片1】`

## 2. 判断人物外观分支

分析 `【@图片1】` 中主要人物的外观性别倾向，并生成内部判断结果 `【@性别结果】`。

该判断仅用于选择服装分支，不向用户展示，不作为身份认定或标签输出。

## 3. 装载内置资产并进行分支路由

先装载 Skill 固定内置资产：

- 场景图 `【@图片3】`
- 宠物帽子图 `【@图片4】`
- 女生服装图 `【@图片5】`
- 男生服装图 `【@图片6】`
- 固定背景音乐 `【@BGM1】`

再根据 `【@性别结果】` 自动选择人物服装分支。

### 若进入女生分支

调用：

- 用户面部身份参考：`【@图片1】`
- 宠物身份参考：`【@图片2】`
- Skill 内置场景参考：`【@图片3】`
- Skill 内置宠物帽子参考：`【@图片4】`
- Skill 内置女生服装参考：`【@图片5】`

禁止调用：

- `【@图片6】`

### 若进入男生分支

调用：

- 用户面部身份参考：`【@图片1】`
- 宠物身份参考：`【@图片2】`
- Skill 内置场景参考：`【@图片3】`
- Skill 内置宠物帽子参考：`【@图片4】`
- Skill 内置男生服装参考：`【@图片6】`

- `【@图片5】`

## 4. 使用用户输入 + Skill 内置图片资产生成原始视频

使用所选分支的完整提示词与参考图生成原始视频 `【@视频1】`。

要求：

- 保持 `【@图片1】` 中人物的面部结构、五官比例、年龄感和身份特征；
- 保持 `【@图片2】` 中宠物的种类、毛色、花纹、脸部特征和身份一致性；
- 使用 Skill 内置的 `【@图片3】` 还原固定场景与世界观；
- 使用 Skill 内置的 `【@图片4】` 让宠物佩戴指定帽子；
- 人物服装必须仅来自当前分支允许调用的 Skill 内置服装图；
- 视频镜头、动作、转场、风格与画质要求严格遵循对应分支完整提示词。

## 5. 检查原始视频结果

若 `【@视频1】` 生成失败、文件损坏、无法播放或没有有效结果，则停止后续处理，并向用户简要说明生成失败。

若 `【@视频1】` 有效，则继续执行音频处理。

## 6. 对原始视频完全静音

对 `【@视频1】` 做完整静音处理：

- 移除或关闭原始音轨；
- 清除其中所有人声、环境声、对白、杂音、音效与模型自动生成音乐；
- 不改变画面内容、时长、比例、分辨率、帧率和播放速度。

## 7. 叠加固定背景音乐

将 `【@BGM1】` 叠加到已静音版本上，生成最终视频 `【@视频2】`。

要求：

- 从视频起始时间开始播放；
- 覆盖视频全长；
- 若 `【@BGM1】` 长于视频，则裁到视频结束；
- 若 `【@BGM1】` 短于视频，则循环或延展至覆盖全长；
- 结尾自然淡出；
- 最终视频中只能保留 `【@BGM1】`，不得残留 `【@视频1】` 的任何原始声音。

## 8. 检查并展示最终成片

检查：

- `【@视频2】` 能否正常播放；
- 视频画面是否完整；
- 原始声音是否已彻底移除；
- 背景音乐是否完整覆盖视频时长。

若成功，仅向用户展示 `【@视频2】`。

**LEFT → RIGHT → UP → DOWN → IN → OUT**

**大幅向左 → 大幅向右 → 明显向上 → 快速向下 → 收向胸口遮挡 → 从胸口快速拉开。**

- 不跳步骤；
- 不交换方向；
