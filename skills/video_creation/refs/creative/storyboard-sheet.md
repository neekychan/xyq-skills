# 分镜图创作与路由指南

本指南在**创意发散阶段**加载，用于所有涉及「分镜图 / storyboard / 分镜宫格图」的任务。职责：
- 先判定当前需求是否真正进入「分镜图→生图→视频」链路；
- 将分镜先归入 5 大一级用途之一，再在其下选二级呈现形式，并区分完成度（草稿/线稿级、精修级、成品级渲染）；
- 明确分镜图生成的**两类必备输入**（文字分镜描述 + 出现主体的参考素材图），并按规则决定是否需要向用户补齐参考图；
- 一次性用问卷补齐分镜创作必需信息，准备好填充 `storyboard/storyboard-sheet-prompt.md` 的生图 Prompt 骨架；
- 给出各类型的默认画幅比例（ratio）、默认 Seedance 模型、默认宫格数与默认完成度。

> 用途类型的**判定关键词、分镜结构建议、生图 Prompt 骨架、视频生成策略**等执行细节，全部在 `storyboard/storyboard-sheet-prompt.md` 的对应小节，本文件只负责「是否进入 + 归类 + 输入补齐」的意图层决策。

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 只因为用户说了“分镜”就当成分镜**图**任务 | 文本分镜脚本被误分流，主流程被绕开 | 先判断是否有分镜**图像**或明确“生成分镜图”诉求，再决定是否进入本文件，其他场景交回 `video_creation.md` 主流程 |
| 把“草稿/线稿”当成独立分镜类型 | 模板选择混乱，后续视频链路难以复用 | 始终先按内容归入 5 大一级用途之一，再在其下选二级呈现形式，并单独标注完成度（草稿/线稿级/精修级/成品级渲染） |
| 用户已上传完整分镜图，仍默认重新生成一套 | 浪费积分，角色/构图易漂移 | 默认优先使用用户已有分镜图，仅在用户明确要求“重画/补格/重构分镜”时才生新图 |
| 缺文字分镜描述就直接生图 | 模型自由发挥，分镜结构与诉求不符 | 必须先拿到/补齐「文字分镜描述」，没有就先帮用户拆出文字分镜表，再进入生图 |
| 成品级渲染却没有任何参考素材图就硬生 | 角色/场景/产品跨格漂移，用户高频反馈“人物不一致” | 成品级渲染缺参考图时，先按本文件规则向用户确认是否有角色图/场景图等参考素材 |
| 补信息时一轮轮零散追问 | 对话被问卷占满，用户体验差 | 使用一次性问卷，**一张表问完当前类型所需字段**，禁止多轮逐条追问 |
| 用错误用途类型模板（例如把产品广告当剧情分镜表） | 卖点/知识点被写成剧情，后续视频难以对齐目标 | 按本文件的 5 大一级用途 + 二级呈现形式判据和优先级归类，无法判定时宁可落入“其他/不进模板”，也不要硬套 |

## 用途与调用阶段

- 本文件只在**创意发散阶段**加载，用于：意图识别 → 是否进入分镜图链路 → 用途归类 → 输入补齐（含参考图确认）。
- 各类型的判定关键词、分镜结构建议、分镜生图 Prompt 骨架、一致性规则与视频生成策略见 `storyboard/storyboard-sheet-prompt.md`，在**分镜规划阶段**加载。
- 任意阶段如发现当前需求并不需要分镜图，应立即停止引用本文件，将控制权交回 `video_creation.md` 根流程。

## 进入/不进入判据表

**只在满足“图像分镜”诉求时才进入本文件。文字分镜脚本和纯视频需求不进入。**

| 场景描述 | 判定 | 行为 |
|---------|------|------|
| 用户上传分镜图/多宫格 storyboard/漫画分镜/草稿分镜等图片，希望据此生成**视频** | **不进入** | 分镜层已由用户填满，交回 `video_creation.md` 按 §0.2 时长走单段/多段流程，还原规则按 `storyboard/storyboard-to-video.md` 执行 |
| 用户上传分镜图，且明确要求**重画/补格/重构分镜图本身** | **进入** | 视为"需要生成分镜图"，先做分镜用途类型+完成度识别，再决定补画幅/标注/补格生图 |
| 用户说“先出一版分镜图/分镜宫格图/想先看分镜预览/先画 storyboard” | **进入** | 视为“需要生成分镜图”，进入本文件：先按 5 大一级用途归类，再在其下选二级呈现形式，补齐文字分镜描述与参考图，再准备调用分镜生图模板 |
| 用户给的是分镜脚本/文字分镜/四栏表，只要求“按照这套分镜做视频”，未提“生成/重画分镜图” | **不进入** | 视为“已有文本分镜”，交回 `video_creation.md`，走常规多段视频流程和 `storyboard/prompt-craft.md`，本文件不加载 |
| 用户只是说“帮我写个分镜脚本/文字分镜”，未提分镜图 | **不进入** | 纯文本策划场景，交由故事/剧本相关 creative ref 处理，不触发本文件 |
| 用户直接要求做视频（文生视频/图生视频/视频编辑等），未提“先看分镜预览/先出分镜图” | **不进入** | 直接走 `video_creation.md` 主流程和对应体裁 creative ref，本文件不加载 |

## 分镜输出与视频生成的衔接原则

- 无论是用户上传的分镜图，还是在本流程中新生成的多宫格分镜图，**都必须先向用户展示分镜结果并收集明确反馈**，用户明确确认“可以按这版分镜做视频”后，才能进入下游视频生成阶段。
- 若用户在确认阶段提出“哪几格需要修改/补格/重画”等意见，应优先在分镜阶段迭代：先更新文字分镜表，再局部重绘或补格，生成新的分镜图并再次整体展示，直到用户确认版本。
- 该确认机制同时适用于“已有分镜图路径”（用户上传分镜图）与“需生成分镜图路径”（刚生成的分镜宫格图）；两条路径都禁止在用户未确认分镜的情况下，直接调用 `sandbox_generate_video`。
- 后续 `storyboard/storyboard-sheet-prompt.md` 和 `video_creation.md` 中的分镜确认步骤，应与本节保持一致：先 `present_sandbox_file` 展示分镜文件，再通过 `dynamic_questionnaire` 或同等方式收集确认/修改意见。

## 分镜链路总览与强制门禁（结构化流程）

> 本节把「问卷 → 直接生图」的旧路径升级为「先锁结构，再出图，最后进视频」的多级门禁流程，用于压制“剧情/动作没锁就出成品图、越改越乱”的高频翻车点。所有分镜任务默认按本链路推进。

### 标准链路（12 步）

用户需求 → ①意图/垂类路由（判定是否进入分镜图链路 + 归入 5 大一级用途） → ②加载对应垂类执行层规则 → ③**垂类核心链路确认**（故事线/动作链/卖点链/信息链/节奏链） → ④**资产/角色/场景 Registry 与参考图确认** → ⑤**分镜脚本 / 逐格状态表**（逐格结构化字段） → ⑥分镜脚本确认 → ⑦**低保真分镜草图 / 关键帧试样**（验证剧情逻辑、人物调度、构图与节奏） → ⑧用户确认画面逻辑 → ⑨精修单格分镜图生成 → ⑩**单格质检与失败重绘** → ⑪拼接人看版故事版 + 分镜图确认 → ⑫视频分段脚本 / shot plan → 视频 Prompt 确认 → 分段生成视频 → 交付前定位表质检与重生成。

### 三道强制门禁（未过不得下探）

1. **门禁一｜故事线 / 核心链路确认门**：未完成对应垂类的核心链路表（故事线 / 动作链 / 卖点链 / 信息链 / 节奏链），**不得**进入分镜脚本 / 逐格状态表。
2. **门禁二｜分镜脚本 / 逐格状态表确认门**：逐格状态表未生成并经用户确认前，**不得**进入任何分镜生图（含低保真草图）。
3. **门禁三｜低保真 + 单格质检确认门**：低保真分镜草图未确认、单格质检未通过前，**不得**进入精修单格图与视频生成。

### 门禁使用规则

- 分镜图（人看版）未确认前，**禁止调用视频生成工具**（`sandbox_generate_video`）。
- 用户中途修改**故事线 / 核心链路 / 高优先级参考图**时，必须回到对应门禁重新确认与重算，**禁止**只在精修阶段做局部修补（详见「分镜修改与影响范围判定」）。
- 优先级说明：本次以 **剧情叙事类 + 动作/VFX 类** 作为门禁与结构化字段的完整落地对象（P0）；营销 / 知识 / 音乐 MV 类按同一框架逐步补齐（P1），未补齐前至少执行门禁一与门禁二。
- **宫格 ↔ 视频段一一对应**：分镜宫格默认按视频分镜段划分（几个 shot 就几格，一一对应），每个单格的“视频参考版无字图”将作为对应 shot 的首帧；宫格图与单格图均要求最高清输出。用户指定格数时以用户为准，但生成前须自检“分镜切分与单 shot 时长”是否匹配，不匹配时先与用户确认再调整。

## 分镜图生成的输入要求（必读）

分镜图生成依赖两类输入：**① 文字分镜描述（必备）**与 **② 出现主体的参考素材图（按完成度与一致性需求决定是否必备）**。进入本文件后，必须先确认这两类输入是否就绪，再决定是补齐还是直接生图。

### 输入一：文字分镜描述（必备）

「文字分镜描述」= 每一格/每一镜的画面内容、镜头或动作或对白、以及先后顺序。它是生图 Prompt 的骨架来源，**任何分镜图都不能跳过这一步**。来源分两种：

1. **用户已提供完整文字分镜**（脚本 / 四栏表 / 逐格描述）：
   - 直接把用户文字分镜结构化映射到 `storyboard/storyboard-sheet-prompt.md` 对应类型的占位符，不要擅自改写剧情/卖点/知识点。

2. **用户只给了主题或大致需求，要求“帮我生成分镜说明/分镜描述”**：
   - 由 Agent 负责**拆分镜**，先产出文字分镜表，再进入生图。拆分规则：
     - **宫格/分镜数**：用户没指定时，Agent 自行根据题材、目标时长、平台节奏决定，并给出推荐档位（如 6 / 9 / 12 / 16 格）供确认；不同类型的推荐档位见 `storyboard/storyboard-sheet-prompt.md` 各类「分镜结构建议」。
     - **每格的镜数/帧数**：用户若明确要求“每个分镜几镜几帧 / 每格几帧 / 一共多少镜”，**严格按用户指定的镜头数或帧数**拆分，不得擅自增减；用户未指定时，按对应类型的结构骨架（开端/发展/高潮/收束）合理分配。
     - 先以**文字分镜表**形式（逐格：画面内容 + 镜头/动作/对白 + 顺序号）呈现，作为生图 Prompt 的直接输入。
     - 文字分镜表生成后，必须先整体展示给用户并确认拆分是否合理（包括总格数与每格对应内容）；用户确认后再调用 `storyboard/storyboard-sheet-prompt.md` 进入分镜生图阶段。

### 输入二：出现主体的参考素材图（角色图 / 场景图 / 产品图等）

参考素材图用于**锁定出现主体的外观**（角色长相、服装、发型、场景结构、产品造型与 Logo 等），是保证「跨格/跨镜一致性」的关键。是否必须提供，取决于**完成度**与一致性需求，按下表决策：

| 情形 | 是否需要参考图 | 处理动作 |
|------|--------------|---------|
| 用户已提供参考素材图（角色图/场景图/产品图等） | **必须使用** | 生图时**必须引用**这些参考图（走「参考图生图」链路），严格保证角色/场景/人物/产品在所有格中一致；不得抛开参考图自由发挥 |
| 用户未提供参考图，且完成度 = 草稿/线稿级 | 可不提供 | 草稿/线稿阶段重在构图与节奏预演，不强求主体一致性，**允许在无参考图情况下直接生成**；可在交付时提示“后续精修需补参考图” |
| 用户未提供参考图，且完成度 = 精修级 / 成品级渲染 | **需要先确认** | 这类完成度对一致性要求高，缺参考图会导致主体漂移。应在问卷/澄清中**先向用户确认是否有参考素材图**（角色图/场景图/产品图）：<br>· 有 → 要求用户提供后再生图；<br>· 没有 → 提示一致性可能漂移，并建议**先生成角色/场景/产品设定图作为参考**，再据此生成精修/成品分镜 |

> 决策口诀：**草稿可无图；精修/成品缺图必问。** 凡进入精修级或成品级渲染且用户没给参考素材图，禁止直接硬生，必须先确认或先补设定图。

### 输入三：资产/角色/场景 Registry 与参考图优先级（一致性地基）

为压制“单格并行生图导致人物/场景/道具跨格漂移”（如角色应从门外出现却被画进厨房），在进入逐格状态表前，必须建立并确认一份**资产 Registry**，作为后续每格生图的唯一事实来源。

**Registry 必备条目：**

- **角色 Registry**：每个角色的外貌、服装、发型、关键识别点（武器/发饰/眼镜/龙角等）、表情范围、**出场格**与**禁出格**。
- **场景空间关系**：关键空间（如厨房 / 餐桌 / 客厅 / 玄关 / 门外楼道等）的相对位置、可用镜头区域与进出动线。
- **关键道具 Registry**：电话、饭菜、门、餐桌、行李等，标注出现格与状态变化。
- **角色调度表**：每个角色在每一格“在哪、朝向哪里、是否移动”。
- **空间坐标系（统一）**：为角色/场景/道具建立统一坐标——画面九宫格区位（左上/正中/右下…）+ 前景/中景/背景（景深）+ 朝向（面朝镜头/背对/侧身朝左右）；多人或多物场景必须给出相对坐标，禁止只写“在一起/同框”。
- **出场时机**：每个角色/关键道具标注 首次出场格、退场格、关键状态转换格（示例：儿子仅在 S8 门外首次出现，S10 才进入室内）。
- **角色锁（Character Lock）**：每个主要角色/动物/产品先生成四视图设定稿并锁定为参考 ID，按 `assets/character-lock.md` 的“四视图 + 逐镜头传参 + 视觉锁定由参考图承担”执行；每格/每镜头的生图与生视频都必须显式传入该锁定参考，禁止仅凭文字描述。


**参考图优先级（写死，不得颠倒）：**

`用户上传参考图` > `用户确认后的场景/角色/产品图` > `AI 生成的参考资产` > `纯文本描述`。

**资产失效与重算规则：**

- 一旦高优先级参考图发生变更（新增 / 替换 / 用户否定），必须依次：① 重新校验核心链路表 → ② 重算逐格状态表 / 角色出场表 → ③ 重绘所有涉及该角色 / 场景 / 产品的分镜格；不得保留旧图局部拼接。

## 分镜用途类型与优先级

> 每类的**判定关键词**、与相邻类型的边界对比、分镜结构建议详见 `storyboard/storyboard-sheet-prompt.md` 对应小节。本节只给定义与归类优先级。

### 1. 分镜用途类型（5 大一级用途）

在对用户提问、进入执行层前，分镜图需求必须先按下列 5 大一级用途归类，再在其下选择二级呈现形式（二级呈现形式的完整定义、判定边界与模板见 `storyboard/storyboard-sheet-prompt.md` 各一级用途小节及其 PE 模板索引）：

- **剧情叙事类**：核心是讲故事、塑造角色和情绪弧线。适合短剧、故事短片、情绪剧情等；通常在执行层落到「剧情分镜表」或「影视导演镜头表」等二级呈现形式模板中。
- **知识讲述类**：核心是解释知识、观点或课程内容，把文案逐句可视化。适合科普、教学、PPT/课程转视频等；主要在执行层对应「科普演示分镜图」等二级呈现形式。
- **营销转化类**：核心是卖产品、讲品牌或做种草转化。适合产品广告、带货视频、品牌故事等；主要在执行层对应「产品讲解分镜图」等二级呈现形式。
- **动作分解类**：核心是拆动作、拆姿态或拆步骤。适合舞蹈、武打、运动教学、操作流程等；主要在执行层对应「动作分解表」等二级呈现形式。
- **音乐 MV 类**：核心是跟随音乐、歌词、节拍和情绪设计画面。适合歌曲 MV、歌词视频、舞台视觉等；通常在执行层使用专门的 MV 分镜模板（见 `storyboard/storyboard-sheet-prompt.md` 中音乐 MV 小节），在一级用途上可与剧情叙事类/营销转化类/知识讲述类配合使用。

> 执行规则：问卷必须先让用户在上述 5 大一级用途中选 1 个主目标，然后再通过「二级呈现形式」「画风层级」「宫格结构」「时长档位」等分面标签与执行层 `storyboard/storyboard-sheet-prompt.md` 的二级呈现形式模板映射；如“剧情叙事类 + 漫画·条漫分镜”可落到「剧情分镜表」或「漫画分镜表」二级呈现形式，“音乐 MV 类 + 广告诉求”可落到「产品讲解分镜图 + 音乐 MV 分镜」组合。

### 1.0 结构化产物的呈现方式（统一用表格，强制）

垂类核心链路表、事件链表、人物关系矩阵、逐格状态卡等所有结构化产物，**无论是在本 skill 中定义字段，还是在对话中向用户输出结果，都必须使用 Markdown 表格**：一行一条目、表头字段固定、每格一行，便于用户逐行核对与修改。**禁止把这些产物用文本或长 bullet 平铺罗列**；除非用户明确要求纯文字。各表列模板见下方对应小节与执行层「逐格状态卡呈现模板」。

### 1.1 垂类核心链路确认（门禁一的确认对象）

归类完成后、进入逐格状态表前，必须先生成并让用户确认对应垂类的**核心链路表**。核心链路是该垂类分镜拆格的骨架，逐格状态表与拆格不得偏离已确认的链路。

| 垂类 | 核心链路 | 关键字段（表列） | 强约束 |
|------|---------|----------------|--------|
| 剧情/公益 | 故事线 | 一句话故事、主要角色与关系、开头状态、冲突/等待/误会、转折点、情绪高潮、结尾余韵 | 必须生成并确认故事线表，后续每格必须承接故事线中的某个节点 |
| 动作/VFX | 动作链 | 起势、发力、接触、变化、落点、恢复 | 每格必须对应动作链一环，禁止断链或攻守关系突然反转 |
| 营销 | 卖点链 | 人群、痛点、卖点、证明、CTA | 分镜覆盖完整链路，每格至少承载一个链路节点 |
| 知识 | 信息链 | 概念、步骤、例子、对比、结论 | 每格只讲一个信息点，按信息链顺序递进 |
| 音乐MV | 节奏/情绪链 | 歌词段落、节拍点、情绪曲线、表演段落 | 每格必须绑定所属乐段与对应歌词/节奏点 |

> 落地优先级：本次先把**故事线（剧情）与动作链（动作/VFX）**做成硬门禁与逐格强绑定；卖点链/信息链/节奏链先做“必须生成并确认”，逐格强校验按 P1 逐步补齐。

### 1.2 事件链 / 链路表约定

- 进入分镜脚本前，必须把核心链路展开为带 ID 的**事件链表**：剧情事件链（E01/E02/…）、动作链节点、卖点链节点、信息链节点、乐段节点。
- 事件链字段（可精简）：事件 ID、简要描述、所属阶段（开端/发展/高潮/收束）、核心情绪、**本节点新信息（观众新知道什么）**、人物关系证据、现实逻辑约束。
- 强约束：**任意分镜格必须绑定至少一个事件 ID**；无绑定的画面视为脱节，禁止进入分镜模板与生图。连续两格“新信息”完全相同时，必须合并或改写（压制“中段多格重复等待/失落”）。
- **事件链表呈现模板（Markdown 表格，展示给用户确认时必用）**：

  | 事件ID | 简要描述 | 所属阶段 | 核心情绪 | 本节点新信息 | 人物关系证据 | 现实逻辑约束 | 关联分镜格 |
  |--------|---------|---------|---------|-------------|-------------|-------------|-----------|
  | E01 | 母亲独自摆好两副碗筷 | 开端 | 期待/怅然 | 母亲在等某人回家 | 多摆一副碗筷 | 饭菜尚温 | S1–S2 |

### 1.3 人物关系矩阵与可视化要求

- 触发条件：涉及 **≥2 人** 的剧情 / 漫画 / 剧情向 MV 分镜，必须先填写人物关系矩阵。
- 强约束：后续逐格状态卡的“关系证据”必须**从矩阵中选取具体动作**，不得只写“同框 / 站位”。禁止把“多人站位”当作关系成立——**关系必须被画面看见**。
- **人物关系矩阵呈现模板（Markdown 表格，定义字段与向用户输出时均用此表）**：

  | 角色A | 角色B | 关系类型 | 当前关系状态 | 情绪张力 | 必须可视化的关系证据 |
  |-------|-------|---------|-------------|---------|---------------------|
  | 母亲 | 儿子 | 亲情 | 疏离/等待和解 | 高 | 背身、隔着餐桌、不对视 |

### 2. 用途归类优先级

当同一套分镜同时命中多个特征时，按以下顺序决策：

1. 先看是否为 **漫画画风 + 气泡对白** → 命中则优先在所属一级用途（通常为剧情叙事/知识讲述/营销转化）下选择“漫画分镜表/漫画·条漫分镜”作为二级呈现形式。
2. 其余分镜按**一级用途优先级**归类：
   **营销转化类 → 知识讲述类 → 动作分解类 → 剧情叙事类**；音乐 MV 作为依附于上述执行形态的附加维度，不参与一级用途争夺，只在执行层按需挂载「音乐 MV 分镜」二级呈现形式。
3. 无法归入上述 5 大一级用途及其二级呈现形式、或根本不构成分镜图（例如三视图、角色设定图、商品拼贴）时，统一视为“其他/无分镜”，**不进入分镜模板流程**。

> 任何情况下都禁止因为“整体是线稿/草稿”而新造一个“草稿/线稿型分镜”类型。

## 完成度维度（草稿/线稿 ≠ 类型）

完成度与用途类型/呈现形式**正交**，取值只分三档：

- **草稿/线稿级**：线条粗略、大量留白、可见构图辅助线；多用于前期创意讨论、结构预演。**可在无参考图情况下生成。**
- **精修级**：有上色与细节，可对外沟通，是大部分生产分镜的默认档位。**缺参考图需向用户确认。**
- **成品级渲染**：接近最终成片质感，光影与材质完整。**缺参考图需向用户确认。**

使用规则：

1. 先按内容归入 5 大一级用途，再在其下选二级呈现形式，并单独判定完成度；不要反过来。
2. 用户未明确说明时，**默认完成度 = 精修级**。
3. 用户只说“随便画草图/先打个草稿/简单线稿”时，完成度设为草稿/线稿级。
4. 真正用于对外投放的分镜图，优先建议精修级或成品级渲染，并确保参考素材图就绪。

### 完成度与低保真 → 高保真双阶段策略

为避免“一上来就出成品级写实图、结构问题被画质掩盖、用户只能在成品图上改剧情”，完成度与生成链路耦合如下：

- **默认双阶段**（用户未明确要求“直接成品级精修”时）：
  1. 角色 / 场景 / 产品**参考资产**：优先高质量生成，用于锁一致性；
  2. **第一版宫格分镜**：默认走**低保真草图 / 线稿**，重点验证剧情逻辑、人物调度、构图与节奏（门禁三的确认对象）；
  3. **精修分镜图**：仅在低保真草图确认后，用更强模型逐格生成，作为视频参考输入资产。
- **跳过条件**（需用户确认）：用户主动选择“直接成品级渲染、不需要草图阶段”时，可跳过低保真门禁，但必须在问卷中显式记录该选择并提示“结构风险自负”；即便跳过草图，仍需遵守逐格状态表与事件链绑定规则。

## 一次性问卷（信息补齐）

### 总规则

1. 问卷只在关键信息缺失时使用，**每轮视频创作最多调用一次**。
2. 问卷必须一次性列出当前用途类型所需的全部字段，让用户一口气填写；禁止“想到什么问什么”的多轮追加确认。
3. 用户在原始需求中已经给出的信息（题材、画风、比例、完成度、宫格数、参考图等）不得重复提问，直接沿用。
4. 问卷问题用简短选项 + 少量补充输入框的形式，避免过长叙述题。
5. 问卷必须先按照「1. 分镜用途类型（5 大一级用途）」让用户选择主一级用途（剧情叙事类/知识讲述类/营销转化类/动作分解类/音乐 MV 类），再在对应类型问卷中确认二级呈现形式与增强模块。

### 通用必填字段（所有类型共享）

以下字段在任何分镜类型中都适用，若用户未给出则在问卷中统一收集：

- **目标视频用途/平台**：如剧情短剧、电商带货、课程短视频、条漫配音等。
- **画面比例**：16:9、9:16、4:3、3:4、跟随原稿。默认取对应类型推荐值。
- **分镜完成度**：草稿/线稿级、精修级、成品级渲染。默认精修级。
- **分镜专业度**：普通版 / 高专业版。普通版仅保证基础画面结构；高专业版默认启用「场景区 + 角色区」等扩展区域，并在后续执行层输出完整的镜头参数区（景别/机位/运镜/单镜头时长等），适配导演故事板/TVC 等专业场景。**用户未显式选择时，按「用途类型 → 默认参数速查表」中的“默认专业度”填充；用户在问卷中做出选择时一律以用户为准覆盖默认值。**
- **宫格/镜头数预期**：给出 2–3 个推荐档位（如 6/9/12 格），并允许用户自填；如用户已指定“每格几镜几帧”，按用户值执行。
- **文字分镜描述来源**：用户已有文字分镜（请粘贴）/ 需要 Agent 帮忙拆分镜。
- **参考素材图**（关键）：是否已有角色图/场景图/产品图等参考素材？
  - 已有 → 请提供（生图将严格参考以保证一致性）；
  - 没有 + 完成度为精修级/成品级渲染 → 提示一致性可能漂移，并询问是否需要先生成角色/场景/产品设定图作为参考；
  - 没有 + 草稿/线稿级 → 可直接生成，无需参考图。
- **是否需要画面内序号**：是/否。
- **是否需要文字说明**：是/否（漫画、科普、产品类默认建议“是”）。
- **是否需要分镜参数**：是/否（影视导演镜头表默认建议“是”）。

### 剧情分镜表问卷

在通用字段基础上补充：

- **题材与氛围**：治愈/悬疑/都市情感/校园/家庭/童话等（多选）。
- **一句话故事（Storyline）**：用一句话概括“谁、在什么处境、发生了什么、如何收场”（门禁一确认对象）。
- **主角与关系 + 人物关系矩阵**：主要角色数量、关系（亲情/恋爱/同事）、简要人设（1 句/人）；≥2 人时填写关系矩阵（角色 A/B、关系类型、当前关系状态、必须可视化的关系证据）。
- **情绪弧线**：开头状态（人物关系/情绪/空间，如“麻木/疏离/等待”）、冲突或等待或误会的类型与位置、转折点简述、情绪高潮、结尾余韵。
- **故事落点**：更偏向温馨结局/开放式结局/反转爽点等。
- **二级呈现形式偏好**：多宫格剧情故事板 / 影视导演镜头表 / 漫画/条漫分镜 / 角色场景设定+分镜 / 纯画面连续分镜 / 剧情脚本表格 / 其他（用户自填）。
- **是否需要台词/旁白写入分镜格**：仅画面 / 画面 + 简短台词/旁白。
- **是否需要附加镜头/运镜参数说明**：不需要 / 只要基础分镜参数 / 影视级分镜参数（景别/机位/运镜/单镜头时长）；当用户选择高专业版或偏向“导演故事板”时，默认推荐“影视级分镜参数”。
- **是否已有分镜图**：已有（上传图为准）/需要从零生成。

### 影视导演镜头表问卷

在通用字段基础上补充：

- **题材与时代背景**：现代都市、古装、科幻、医疗、刑侦等。
- **拍摄视角偏好**：更注重运镜（推拉摇移）、光影设计、场面调度中的哪一项。
- **机位与景别细化程度**：只要核心镜头标注 / 每镜头都要景别+机位+运镜+大致时长。
- **是否已有文字分镜表/剧本**：有（以现有文稿为主，只补图像结构）/无（需要从故事梗概起草）。
- **分镜专业度默认建议**：影视导演镜头表通常建议选择“高专业版”，自动启用场景区 + 角色区扩展区域，并在执行层输出完整镜头参数区。

### 动作分解表问卷

在通用字段基础上补充：

- **动作类型**：舞蹈/武术对打/健身训练/体育动作/产品操作等。
- **动作链结构（门禁一确认对象）**：按 起势 / 发力 / 接触 / 变化 / 落点 / 恢复 拆出主干动作节点。
- **是否需要动作连续性表**：是/否（是则逐格记录 起始姿态 / 结束姿态 / 攻击方 / 防守方 / 动作方向 / 人物相对位置 / 与上一格承接 / 必须保持不变 / 禁止跳变）。
- **动作目标**：展示帅气效果 / 做标准教学 / 预演电影打斗。
- **二级呈现形式偏好**：动作关键帧分解图 / 姿态连续分镜 / 打斗/竞技分镜 / 操作流程分镜 / 运动轨迹示意分镜 / 动作导演镜头表 / 动作脚本表格 / 其他（用户自填）。
- **是否为双人或多人对练**：单人动作 / 双人攻防 / 多人动作。
- **动作拆解粒度**：粗略 4–6 格 / 详细 8–16 格。
- **是否需要在画面中标明动作要点文字**：是/否。
- **是否需要附加镜头/运镜参数说明**：不需要 / 只要基础视角说明 / 影视级动作镜头参数；动作教学通常以基础视角说明为主，电影动作设计可选高专业版。

### 漫画分镜表问卷

在通用字段基础上补充：

- **题材与调性**：日常搞笑/社畜吐槽/校园恋爱/治愈/奇幻冒险等。
- **主角数量与关系**：简要人设 + 关系。
- **故事长度与节奏**：四格短梗 / 6–9 格普通条漫 / 更长条漫片段。
- **对白风格**：偏吐槽/正剧/旁白主导。
- **是否已有关键台词**：如用户已写好对白，必须确认“完全照用/允许少量润色”。
- **宫格版式硬约束**：选择 9 宫格时必须严格 3×3 排布，格数与编号不得缺失或重复（禁止漫画页式自由排版）。
- **角色设定锁定**：列出每格必须继承的角色识别点（发型/发饰/武器/服饰/眼镜等），保证角色特征跨格不漂移。
- **是否输出双版本**：人看版（带编号/对白气泡）+ 视频参考版（干净无字、无气泡、无编号）；对白气泡由脚本后处理叠加，**禁止交给生图模型直接绘制中文气泡**。

### 音乐 MV 分镜问卷

在通用字段基础上补充：

## 分镜修改与影响范围判定

用户提出修改时，必须先判断修改类型，再决定重算/重绘范围，禁止“改了第 1 格或重写剧情逻辑却只局部重画中段、尾部保留旧图”：

| 修改类型 | 重算范围 | 处理动作 |
|---------|---------|---------|
| 视觉细节（光影、背景细节等） | 单格 | 只重绘该格 |
| 人物位置 / 情绪 / 动作因果 | 连续片段 | 重绘该格与紧邻的若干格，保证承接与铺垫连续 |
| 故事线 / 动作链 / 卖点链 / 信息链 | 整套 | 回到门禁一更新核心链路表与逐格状态表，再重新生成相关整段分镜 |
| 高优先级参考图（角色/场景/产品） | 全关联 | 按「资产失效与重算规则」重算所有引用该参考图的状态卡并重绘图像 |
