# 新海诚风格核心

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 核心主题

成长、距离、时间、遗憾、思念、重逢、选择、命运

这些主题不是"标签"，而是驱动因果链的引擎：每个镜头的画面选择、天气选择、色彩切换都必须指向其中一个主题。

## 视觉关键词

Makoto Shinkai, Japanese Animation, Beautiful Sky, Cinematic Anime, Emotional Storytelling, Weather Driven Atmosphere, Volumetric Light, Ultra Detailed Background, Anime Film Frame, Masterpiece, 4K

使用规则：
- 所有元素图 prompt 末尾必须附加这些关键词
- 视频生成 prompt 同样必须附加
- 不逐字照搬，可根据具体镜头增减（如夜景加 Moonlight，雨景加 Rain Reflection）

## 角色设计规则

- 年龄范围：14–25 岁
- 外观原则：普通人、真实感、自然感、生活化——不设计华丽/奇幻外观
- 常见身份：学生、上班族、摄影师、咖啡店店员、自由职业者、旅行者
- 角色图要求：全身构图、电影静帧、动画电影风格、非三视图

## 天气作为叙事机制

天气等级与情绪映射：

| 天气等级 | 天气类型 | 对应情绪 | 典型叙事功能 |
|---|---|---|---|
| S 级 | 黄昏 | 离别、遗憾、怀念 | 转折点、分离时刻 |
| S 级 | 流星 | 愿望、奇迹 | 高潮、许愿 |
| S 级 | 云海 | 超越、自由 | 视野打开、顿悟 |
| S 级 | 星空 | 重逢、希望 | 结局、和解 |
| S 级 | 雨后放晴 | 新开始 | 重新出发 |
| A 级 | 暴雨 | 冲突、绝望 | 争吵、崩溃 |
| A 级 | 晚霞 | 珍惜、短暂 | 最后相处 |
| A 级 | 雪景 | 纯粹、安静 | 独处、回忆 |
| A 级 | 晨曦 | 希望、新生 | 新的一天 |
| B 级 | 阴天 | 日常、平淡 | 过渡 |
| B 级 | 晴天 | 青春、未来 | 开场 |
| B 级 | 微风 | 轻微变化 | 小事件 |

优先选 S/A 级天气。B 级仅用于过渡镜头。
