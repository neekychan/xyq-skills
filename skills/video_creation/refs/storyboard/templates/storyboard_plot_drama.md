# 分镜图模板：剧情叙事型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以角色与情节推进为主的连续分镜，关注人物关系、情绪转折和故事结构，多出现在短剧/情感故事/亲情故事等场景。
- **典型场景**：治愈系短片、情感短剧、亲情/友情故事、日常生活片段、婚礼/求婚/告白等剧情片段。

## 2. 判定关键词
- 典型触发词：`剧情`、`故事`、`短剧`、`情感`、`恋爱`、`婚礼`、`分手`、`重逢`、`亲情`、`成长`。
- 当需求重心在“讲一个完整故事”，而非只是展示动作/卖点时，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：9/12/16 宫格最常见，可对应三幕式结构。
- **三幕式骨架**：
  1. 开始（1–4 格）：介绍主角、关系与起始状态，埋下轻微冲突或期待。
  2. 发展（4–8 格）：冲突升级、情绪起伏、关系变化，适当切换场景/时间。
  3. 收束（2–4 格）：给出结果/反转/开放式结尾，形成情绪闭环。
- **景别节奏**：环境建立用远景/中景，情绪转折和关键对话用近景/特写，注意适当留白避免信息过载。

## 4. 生图 Prompt（PE）模板

```text
你是一名剧情短片导演兼分镜师，请为下述故事生成一张 {宫格数} 宫格的剧情叙事分镜图（多宫格 storyboard），整体画幅为 {画幅比例说明，如“9:16 竖屏故事短片”}。

【故事信息】
- 题材与基调：{如“治愈系娃娃机奇遇/都市重逢/父女和解”等}
- 主角与关系：{主角姓名+外观+性格，关键关系如“父女/恋人/室友”}
- 故事梗概：{80–150 字概述起承转合}

【画面风格】
- 整体画风：{如“3D 毛绒治愈 / 写实胶片 / 2D 动漫”}
- 色调：{主色调，如“暖粉+草绿”“冷蓝+橙光”}，对应情绪变化可略有转变。

【场景分段】
- 第一幕：{时间+地点+主情绪}
- 第二幕：{时间+地点+冲突/转折}
- 第三幕：{时间+地点+收束/释怀}

【宫格与构图】
- 宫格数：{9/12/16}，按阅读顺序编号 S1–S{N}。
- 每格需明确：景别（远/中/近/特写）、角色数量与站位、动作与表情。

【输出要求】
- 为 S1–S{N} 逐格写出中文分镜说明，突出“此格在故事中承担的叙事功能”（例如“埋下伏笔/呈现矛盾/情绪爆发/反转/收束”）。
- 在说明中可补充简单的镜头语言提示（如“缓慢推近”“切到对方视角”）。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏，3 表示 16:9 横版，0 表示跟随参考图}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「剧情叙事类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 用户已有手绘/图像形式分镜时，优先整理并直接使用，不在视频阶段重新解读文本脚本。
