# 软萌3D视觉风格可执行参数

> 可适配的模式与句式，按场景改写，不要逐字照搬。

只写"圆润、毛绒、奶油感"不够稳定，模型仍可能做成普通可爱3D。每条提示词必须锁定以下可执行参数。

## 必填参数清单

| 参数 | 可执行范围 | 禁止范围 |
|---|---|---|
| 头身比 | 1:1.5 到 1:2，头大身小，偏Q萌比例 | 写实成人比例 |
| 眼睛大小 | 占脸部面积25%-35%，圆润饱满，有高光湿润感 | 细长眼、无高光死眼 |
| 四肢形态 | 短、圆、粗，圆柱或圆锥形，末端圆润收口 | 修长四肢、明显关节骨节 |
| 边缘倒角 | 所有形体边缘做圆角倒角处理（beveled edges），无锐利棱角；耳朵、尾巴、道具边缘均为柔和弧线 | 锐利硬边 |
| 材质粗糙度 | 毛绒：高粗糙度哑光，表面有细绒纹理；陶瓷/木质：中等粗糙度哑光；奶油质感：极低粗糙度不反光 | 高光反射面 |
| 光线方向 | 侧前方柔和漫射光（45°左右），补光从对侧弱反射 | 顶光直射、逆光硬边、冷色光 |
| 景深程度 | 浅景深，f/1.8-2.8等效，主体锐利，背景柔和虚化 | 全景深清晰到边角 |

## 角色一致性锁定属性

跨镜头不可漂移，必须在角色定义中逐项写明：

- **主色与配色**：身体主色、腹部/内侧副色、服装配色的具体色名（如"奶油橘+浅米白腹部+浅绿色围裙"）
- **服装与配件**：款式、颜色、图案位置（如"围裙左胸口有叶子刺绣"）
- **眼睛形状**：圆形/杏仁形/水滴形，高光数量和位置
- **耳朵与尾巴**：大小、角度、朝向；尾巴长度、蓬松度、颜色
- **体型比例**：头身比、四肢粗细、脸颊饱满度

每个镜头描述中，角色必须引用同一个角色标签，不能凭空描述新外观。

## 品牌风格禁止

提示词、分镜描述、资产描述中严禁：
- Pixar风格/皮克斯风格
- Disney风格/迪士尼风格
- DreamWorks风格/梦工厂风格
- Blender风格/Cycles渲染器名称
- 任何具体动画工作室、电影名称、IP角色名

用"原创软萌3D治愈动画风格"替代。风格锚点靠头身比、材质粗糙度、边缘倒角、光线方向、景深参数来表达，不靠品牌名。
