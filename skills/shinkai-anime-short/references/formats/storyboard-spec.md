# 分镜设计规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 色彩系统

### 晴空系
- 主色：天空蓝 | 辅色：云层白 | 点缀：阳光金 | 情绪：希望、青春、未来

### 黄昏系
- 主色：橙金色 | 辅色：紫红色 | 点缀：深蓝色 | 情绪：遗憾、怀念、离别

### 雨天系
- 主色：青灰蓝 | 辅色：雨雾白 | 点缀：暖色霓虹 | 情绪：孤独、思念、等待

### 夜景系
- 主色：深蓝 | 辅色：月光白 | 点缀：城市灯光橙 | 情绪：梦境、距离感、希望

色彩切换规则：随情绪曲线自动切换色彩系。相遇 → 晴空系，离别 → 黄昏系，思念 → 雨天系，重逢 → 夜景系。可在同一段情节内渐变过渡。

## 场景系统

| 场景类 | 典型场景 |
|---|---|
| A 城市场景 | 东京街道、商业街、天桥、电车站、十字路口 |
| B 校园场景 | 教室、操场、图书馆、天台、走廊 |
| C 自然场景 | 海边、神社、山路、森林、河堤 |
| D 雨景场景 | 公园、凉亭、公交站、便利店门口 |
| E 黄昏场景 | 放学路、铁路道口、河岸、桥梁 |
| F 夜景场景 | 城市夜景、高楼天台、灯火街区、电车站 |

## 光影规则

每个镜头**必须**声明三种光源，缺一不可：

| 光源类型 | 说明 | 典型选择 |
|---|---|---|
| 主光源 | 场景中最强的方向光 | 夕阳、月光、路灯、阳光 |
| 次光源 | 补充主光的弱方向光 | 反射光、窗户光、城市灯光 |
| 环境光 | 无方向的氛围光 | 天空漫反射、空气透视、体积光 |

## 镜头语言

| 编号 | 名称 | 要素 | 典型情绪 |
|---|---|---|---|
| M01 | 風吹镜头 | 头发飘动、衣服摆动、树叶摇晃 | 轻微变化、日常 |
| M02 | 云层镜头 | 固定机位、云层流动 | 时间流逝 |
| M03 | 电车镜头 | 列车经过、人物静止 | 离别、等待 |
| M04 | 仰望天空 | 强调天空、强调光线 | 希望、许愿 |
| M05 | 雨滴镜头 | 雨滴、积水、波纹 | 思念、忧伤 |
| M06 | 逆光镜头 | 体积光、镜头光晕、阳光穿透 | 感动、顿悟 |
| M07 | 回忆镜头 | 慢动作、柔光、低对比度 | 回忆、怀念 |
| M08 | 行走镜头 | 人物背影、城市环境、缓慢移动 | 孤独、旅程 |
| M09 | 奔跑镜头 | 追逐、寻找、重逢、高潮情绪 | 紧迫、渴望 |

## 分镜图生成规范

每镜必须包含以下字段：

| 字段 | 说明 |
|---|---|
| shot_id | 镜头编号 |
| scene | 场景（含地点/时间/天气） |
| characters | 出场角色 |
| action | 动作描述 |
| camera | 运镜（M01–M09） |
| weather | 天气等级（S/A/B） |
| light | 光源声明（主/次/环境） |
| color_system | 色彩系（晴空/黄昏/雨天/夜景） |
| emotion | 情绪 |
| duration | 时长（默认 5–8 秒） |
| key_elements | 绑定的角色/场景/道具图 |

## 落 prompt 前自检

- 天气等级是否优先 S/A？
- 每个镜头是否声明了三种光源？
- 镜头语言是否从 M01–M09 选用？
- 色彩系是否与当前情绪匹配？
- 时长是否在 5–8 秒范围内？
