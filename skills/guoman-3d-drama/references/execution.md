# 工具适配、生产记录与提交检查

技能说明规定工作流程，不使某个工具自动存在。根据当前环境已提供的工具、连接器或本地能力读取真实 schema，选择已授权的执行路径；不依赖来源文件中固定的旧工具名。

## 能力适配

| 能力 | 优先使用 | 能力不足时 |
|---|---|---|
| 图片生成/编辑 | 当前可用的生成或编辑工具，完整前缀置首 | 完成设定与提示词，准确标记待生成 |
| 视频多参考 | 已验收角色、对应方向场景与所需道具/合格帧，按实际引用协议绑定 | 先合成单镜关键帧，再用单首帧视频能力 |
| 单首帧视频 | 已验收、构图符合本镜的单画面关键帧 | 不把角色三视图/四宫格塞进首帧；无法生产时交付任务清单 |
| 片段内切镜 | 工具支持则按镜表一次生成多个内切镜 | 每个实际镜头独立生成后组装，重新计算时长与参考依赖 |
| 角色原生声音 | 工具支持音色引用时绑定真实声音身份 | 统一独立配音；画面与口型按实际能力处理 |
| 原生 OS | 工具可生成内心声音且保证不动嘴时使用 | 生成闭口表演+独立同声线 OS，不重复叠音 |
| 音乐/音效/TTS | 当前音乐、音效、语音工具或用户已有素材 | 提供准确音频层计划与缺口，不宣称已经合成 |
| 截帧/剪辑/转码 | 可用媒体处理工具或实际安装的 ffmpeg/ffprobe 等 | 先完成镜表与时间线；如需新工具，说明具体能力缺口 |

尺寸、比例、最长时长、参考数量、首尾帧、原生音轨、嘴型、种子、帧率均按实际工具确认，不在 prompt 中许愿式假定可用。先用核心设定和首镜检验能力，再扩大范围。题材与世界观按 [跨题材规则](genre-adaptation.md) 单独保存，工具负向模板不得默认注入“禁止现代元素”。

遵循宿主对媒体工具、浏览器和文件权限的规则。阅读、修改、打包此 skill 不等于请求生产媒体；用户只要方案/提示词时不生成。用户已明确授权的生产范围、自动完成偏好和预算限制持续有效，不每阶段重复索取相同确认。尚未获得所需授权时，先把可审阅的计划、提示词和缺口整理完。

## 生产顺序与状态

工作状态可采用：`planned → drafted → generated → accepted`；错误为 `rejected`，上游变化后为 `stale`。`accepted` 必须有实际检视依据，不等于“工具返回成功”。不同任务只建立必要文件，不强制制造空目录。

保存项目参数、剧本/分镜、资产索引、最终视觉 prompt、音频层、生成记录和时间线。所有 ID 稳定，素材版本可递增；生成记录包括工具/模型、真实参数、输入资产和用途、最终提交原文、任务 ID、输出文件/URL、实测规格、验收结果和失败原因。

默认节点为剧本/分镜草稿审阅、核心资产验收、首镜样片、剩余镜头、音画组装。用户授权连续完成时自行验收并推进；用户要求逐镜确认时遵循该模式。任意模式都不能跳过首镜质量检查，或让失败镜进入参考池。

资产图门槛针对本次制作范围的完整核心清单，而非只检查首镜人物。用户明确跳过资产图时记录原话与范围，视频仍保留角色/场景文字设定和风格前缀；文本直出并不保证与参考图模式相同的一致性。

## 风格检查脚本与清单格式

随附 `scripts/validate_prompts.py` 使用 Python 标准库，无第三方依赖。它检查**本次待提交批次**；历史生成记录另存，避免把旧版本和当前待提交任务混在一起。

清单字段：

- `project.scope`：本次制作范围；`core_asset_ids`：此范围所有核心图 ID，做视频时不能为空，除非用户明确跳过出图。
- `project.skip_asset_images`：`enabled`、`user_instruction`、`scope`。只有用户真实明确要求跳过时启用，范围必须与本次一致。脚本只检查字段，不能代替读取实际用户授权。
- `assets`：每项 `id`、`kind`、`source`、`status`、`locator`、`style_verified`。来源只允许 `project_generated`、`user_provided`、`user_designated`。可选 `source_asset_ids` 追踪关键帧/衍生图的输入；`kind` 为 character/scene/prop/keyframe/frame/video/reference。
- `status=accepted` 表示此素材已被检视为可用于所登记用途；`style_verified=true` 还表示视觉符合本风格。用户原始非本风格图可作为已检查的身份参考，但不能充当已就绪的核心本风格资产或直接视频参考。
- `visual_prompts`：每项 `id`、`kind`、`prompt`、`required_asset_ids`、`references`。kind 支持 image、image_edit、video、video_edit、video_extend。
- `references`：每项 `asset_id`、`purpose`，用途仅限 identity/costume/layout/prop/continuity/keyframe。**不能写 style**；实际传入的附件、平台自动参考也必须计入，不能只登记表面 prompt。
- 视频任务还需 `binding_mode`，为 multi_reference、single_keyframe 或 text_only。单首帧模式只引用一个 kind=keyframe 的有效单画面，并用 `source_asset_ids` 追溯其核心输入；text_only 仅在本范围明确跳过资产图时使用。
- `required_asset_ids` 为该镜必需内容资产；视频需通过直接引用或所引用关键帧的来源链覆盖这些资产。编辑/延长也要登记源视频为连续性引用。

以下是**演示清单**，图像路径示意已有验收资产，不能据此声称素材实际存在。实际任务必须换成真实 ID、文件和最终 prompt。

```json
    {"id": "SC01", "kind": "scene", "source": "project_generated", "status": "accepted", "locator": "assets/SC01.png", "style_verified": true}
  ],
  "visual_prompts": [

      "id": "EP01-SH001-v1",
      "kind": "video",
      "prompt": "国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。[摄影机] 16:9，近景平视缓慢推进。[主体] 穿灰蓝衬衫的青年先垂眼看掌中手机，再将手机屏幕熄灭，目光抬向画面右外侧，闭口停留。[空间] 公寓东窗柔光，暖白漫反射，轻雾透明；青年背后可见白色窗框，画面左缘为木质书架，保持绑定场景布局。[音频] 手机按键和轻微衣料声，无对白。[禁止] 无背景音乐、字幕、文字叠加、水印或无设定的古装法器。[时长] 10秒。",

```

运行方式（在 skill 目录执行，或给脚本绝对路径）：

```bash
python3 scripts/validate_prompts.py /absolute/path/to/visual-manifest.json
```

脚本返回 JSON 检查结果和退出码：0 通过，1 检查未通过，2 输入格式/读取失败。默认还检查本地 `locator` 是否存在（相对路径相对于清单目录）；远程 URL/工具 URI 只检查其声明，调用前需通过对应工具确认可用。

脚本不会自动修正文案或生成媒体。它无法判断美学效果、真实授权、真实世界空间、台词语义、URL 可访问性或多宫格是否真的已转成单画面；这些仍由实际检查负责。前缀通过只是必要条件。

## 提交、结果与重试

1. 核对本次授权范围、最新输入和资产版本，整理最终工具 payload。关闭默认风格图注入；若工具必须注入且无法关闭，报告此能力不满足本风格约束。
2. 对最终 prompt 原字符串和实际参考绑定运行检查，再提交。不能先验草稿、再由包装器加标题而不复检。
3. 保存返回任务 ID；异步任务按工具建议查询，报告新进展，不高频重复调用生成。
4. 超时或响应不明先查任务状态，不直接当失败重发，避免重复生产。确认失败后，默认同一任务最多额外重试 2 次，保留版本和具体原因；用户另有预算/次数约束则以用户为准。
5. 不为绕过失败而擅自换付费模型、服务商或扩范围。只有现有授权涵盖、能力满足且不会意外扩大费用时，才可采用明确记录的替代路径；否则保留已完成结果和可继续任务。
6. 视觉失败先定位前缀遗漏、参考冲突、身份绑定、布局、动作密度或时长问题，仅修相关部分。达到重试边界后停止该失败项，交付可用成果与具体阻塞，不无限重跑。
7. 上游素材变更后按来源链标记下游 `stale`，重新检视后再接续。复用任务 ID 或旧文件不等于新版本已经通过。

## 最终交付与诚实状态

只对真实产物说“已生成/已导出”。最终结果指向实际文件或可用链接，区分生成成功、视觉验收通过、剪辑导出成功。能力缺失时仍可完成剧本、设定、镜表、提示词、音频层和时间线，但必须明示剩余待执行项。
