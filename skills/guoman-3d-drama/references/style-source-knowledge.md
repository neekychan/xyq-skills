# 第一份 skill 的原始风格描写

用途：保留来源中的 3.1—3.4 全文，供核对风格细节或选取古风/奇幻表达。以下是来源资料，不是独立启动指令。通用执行标准见 [style-guide.md](style-guide.md)，题材适配见 [genre-adaptation.md](genre-adaptation.md)。其中古典服饰、建筑、法术、文言台词属于对应题材示例，不成为现代、科幻等项目的默认要求。

### 3.1 整体风格气质

「国漫3D渲染风」不是单纯写实 CG，也不是纯二次元平涂，而是**东方审美叙事 + 高精度三维建模 + 动画化渲染表现**的混合体系。追求的不是摄影机意义上的「真实」，而是比真实更凝练、更唯美、更戏剧化的视觉真实。

**核心气质层次：**

| 气质维度 | 描述要点 |
|---|---|
| 东方幻想感 | 仙侠、玄幻、神话、武侠、志怪等文化语义；意境、气韵、留白、空灵、尊贵、宿命感 |
| 影视级 CG 感 | 模型、材质、灯光、特效精致完整；画面有「渲染完成图」质感，不粗糙不草率 |
| 角色美型化 | 人物五官、脸型、身材比例经过审美强化；俊美、清冷、英气、仙气、威仪、灵动 |
| 半写实半风格化 | 保留动画角色的轮廓控制、皮肤柔化和情绪强化；不追求纯电影写实 |

**光影与色彩气质：**
- 整体调性偏**高亮、低对比**：画面不暗沉，高光区域柔和过渡，阴影区域不死黑
- **轻雾化**：画面带有若隐若现的环境雾气，强化空间纵深与仙气质感
- **柔光滤镜**：边缘与高光区域带有轻微泛光/光晕效果，营造温润而非冰冷的视觉感受
- 主色调常见：冷调（青银、月白、霜蓝）、暖调（琥珀、烛光橙、流霞金）、玄幻调（紫黑、深青、星河银紫）

### 3.2 角色造型典型质感

#### 面部与五官

- **脸型**：流畅干净收束，下颌线清晰但不过度硬朗；女性常见鹅蛋脸、心形脸；男性常见修长脸、清隽骨相
- **眼部**：眼睛比真人略大但不夸张；强调眼型流线感（丹凤眼、桃花眼、瑞凤眼、狭长冷眸）；睫毛、眼线、瞳孔高光精细处理，提升神采
- **鼻唇**：鼻梁清晰、鼻头精致，不过度写实毛孔化；嘴唇轮廓明确、色泽柔润
- **皮肤质感**：半透明陶瓷感，带次表面散射（SSS）；高光点精准，无过度油腻感；玉肌感、凝脂感是常用形容词

#### 发型与发丝

- 发丝建模精细，呈现**束感与飘逸感并存**的状态
- 常见发型：长发束冠、发髻飞扬、鬓发垂落、半披半束
- 发丝在光照下有**丝绸反光**，发色常见墨黑、乌发、银白、赤金、异色（紫、蓝）
- 动态镜头中发丝有轻微飘动，符合东方仙风审美

#### 服饰与材质

- **服装类型**：汉服、仙袍、武侠轻甲、道袍、宫装为主；有时融合奇幻元素（星纹、光纹、符文）
- **面料质感**：丝绸光泽（高反射、柔软垂感）、薄纱半透（透光度高）、金属刺绣（细密纹样+金属光）、皮革或玄铁（哑光质感）
- **服装配色**：通常 2-3 色主调，配合金银线描边；强调「同色系深浅搭配」而非高饱和撞色
- **配饰**：玉佩、发钗、耳坠、腰带、法器；材质常见玉石（半透绿/白）、金属（古铜/亮金/霜银）、宝石（宝蓝/深红/星紫）

#### 体态与气场

- 体型偏修长，肩线与腰线比例理想化
- 站姿常见：负手而立、衣袂飘动、单手持剑/拂尘/卷轴
- 气场词库：清冷孤傲、温润如玉、英姿飒爽、仙气飘飘、威仪赫赫、灵动跳脱

### 3.3 场景环境典型质感

#### 建筑与空间

- 东方古典建筑：飞檐斗拱、廊柱、石阶、朱门、雕栏玉砌
- 奇幻空间：悬浮岛屿、云端宫殿、幽深洞府、空中阵法平台
- 材质：青石地面（湿润反光）、木质廊柱（细腻木纹）、瓦片屋顶（釉面泛光）

#### 自然场景

- **植被**：竹林（翠绿、光透）、梅花（白/红点缀雪景）、桃花（粉雾弥漫）、古松（苍劲盘曲）
- **水体**：镜面湖水（高反射、低扰动）、瀑布（白雾化处理）、溪流（清澈见底+涟漪光斑）
- **天空**：云海翻涌、星河璀璨、晨雾迷蒙、暮光霞染
- **粒子特效**：花瓣飞舞、流光粒子、灵气光点、剑气光刃、符文流转

#### 光线特征

- **主光源**：侧逆光为主，强化轮廓光，营造立体与戏剧感
- **环境光**：柔和漫反射，整体高亮不暗沉
- **特效光**：法术光效、宝器光晕、阵法光网，通常为冷色或金色

### 3.4 叙事与脚本风格指引

在生成故事脚本、分镜描述、角色台词时，应与视觉风格保持一致：

**叙事基调：**
- 宏大与细腻并存：大场面宏阔壮丽，小场景克制精巧
- 情绪表达含蓄而有力：不直白倾诉，善用动作、眼神、环境烘托情感
- 节奏有层次：起势稳、转折有力、收尾余韵悠长

**语言风格：**
- 台词偏古典雅致，但不晦涩；可带文言句式，但以现代人可理解为准
- 旁白/画外音宜用凝练意象句，如「长风卷云，剑影如霜」「一步山河，万里江湖」
- 角色台词根据身份差异化：仙人简洁高冷、将领铿锵有力、少年灵动俏皮

**分镜描述规范：**
- 每个分镜先描述**画面构成**（主体+环境+光线），再描述**动态与情绪**
- 镜头词库：远景俯瞰（展势）、中景正面（定人）、近景侧逆光（塑神）、特写眼神（传情）、跟拍运动（追势）
