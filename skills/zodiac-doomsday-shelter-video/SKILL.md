# Zodiac Doomsday Shelter Video

把用户给出的“星座 + 庇护所元素/触发物/入口设定 + 可选参考图 + 可选风格要求”转换为 **可直接用于 Seedance 2.0 的中文成品视频提示词**。  
默认直接输出成品 prompt，不先做长篇分析。

## 核心任务

生成一条或一组具有以下共同特征的视频 prompt：

- 主题是“十二星座挑选你的末日庇护所”
- **POV 第一视角**
- **一镜到底**
- 开场由一个关键物品或隐藏入口触发空间变化
- 从危险末日外部环境进入到安全、豪华、梦幻、宽敞、宜居的庇护所内部
- 庇护所内部必须有完整的生活功能分区
- 整体具有沉浸式空间漫游体验
- 同时带有**女性 ASMR 画外音**与**物品/环境 ASMR 音效**
- 画面真实、有电影感、适合 Seedance 2.0 理解和执行

## 默认输出模式

默认输出 **1 条可直接投喂 Seedance 2.0 的中文 prompt**。

如果用户明确要求：
- “帮我做 12 星座全套”
- “每个星座来一个”
- “批量生成十二星座版本”
- “全部星座都做一遍”

则输出 **12 条 prompt**，每个星座单独成段。

## 输入理解

用户通常会用自然语言直接描述，不要求固定格式。你需要自动理解并提炼这些信息：

1. **星座**
2. **触发方式**
   - 扔出某个物品
   - 打开某个入口
   - 启动某个机关
3. **核心元素**
   - 如火焰、水晶、机械、海洋、森林、熔岩、冰雪、星际、岩洞、宫殿、实验室
4. **庇护所类型**
   - 地下堡垒、山体基地、海底避难所、悬崖洞穴、天空站、树屋、未来实验舱等
5. **风格偏好**
   - 梦幻、豪华、治愈、未来感、冷感、女性向、暗黑、神秘、温暖等
6. **是否有参考图**
   - 如果用户上传图片或指定参考素材，优先继承图片的主体视觉特征或核心物件造型
7. **是否要批量生成 12 星座版本**

如果用户输入很短，比如：
- “白羊座+火焰钥匙+地下堡垒”
- “双鱼座，海底梦幻庇护所”
- “帮我做十二星座版末日避难所”

你应直接补全缺失信息，生成完整可用的 prompt，不要因信息略少而停下来追问。

## 默认视频结构

每条 prompt 都应自然形成以下一镜到底流程：

### 1. 外部末日环境开场
先交代外部世界危险、荒凉、压迫、失序，形成强烈反差基础。  
例如：废墟、暴雪、酸雨、荒漠风暴、停电黑夜、灰烬天空、洪水边缘、山体裂缝等。

### 2. POV 触发关键动作
使用 POV 第一视角完成触发动作，动作必须明确、直观、适合模型生成：
- 扔出一个物品
- 把某物按入机关
- 拉开一个隐藏门
- 推开石壁
- 打开箱子、柜门、地板暗门
- 点亮某个装置

### 3. 物品或入口变成庇护所
空间变化必须有视觉冲击力：
- 物品迅速变形、扩展、落地成建筑
- 墙体裂开、地面展开、山体开启、舱门滑开
- 入口之后瞬间显露出巨大的内部空间

### 4. POV 进入庇护所内部
镜头不停顿地进入，强调连续推进、空间逐步展开、材质与灯光逐层显现。

### 5. 一镜到底展示完整生活区
庇护所内部必须明显展示并自然串联这些分区：

- 休息区
- 玩乐区
- 饮食区
- 学习区
- 办公区
- 健身区

这些区域不能只是点名，要有明确视觉锚点，例如：
- 休息区：柔软床铺、沙发、氛围灯、安抚感强
- 玩乐区：投影、游戏设备、娱乐装置、收藏展示
- 饮食区：餐台、储粮、饮品、厨房、果蔬、烘焙或热食
- 学习区：书墙、阅读灯、桌面、资料架
- 办公区：屏幕、控制台、桌面设备、任务系统
- 健身区：器械、瑜伽区、训练空间、恢复角

### 6. 收束在最惊艳空间
最后停留在最具记忆点的区域，比如全景中庭、核心控制区、梦幻休息舱、环形客厅、落地观景区、发光水景中心等。

## 视觉原则

始终优先以下视觉要求：

- 空间一定要**极大、宽敞、可居住**
- 内部一定要**精致、好看、梦幻、舒适**
- 必须让人一眼感到“真的想住进去”
- 外部越危险，内部越要形成安全感与治愈感反差
- 材质、光效、结构层次、空间景深都要丰富
- 让镜头运动路径清楚，不要混乱
- 让空间变形逻辑清楚，不要模糊
- 强调居住感、生存感、审美感并存

## 声音原则

每条 prompt 都应自然包含声音设计：

### 女性 ASMR 画外音
- 声线轻柔、贴耳、安抚、带一点神秘感
- 不是大段解说，而是短句式、沉浸式、像在轻声带领观众进入空间
- 不要写成字幕，只写成音频表现

### ASMR 物品音效
至少覆盖这些音效中的若干项：
- 物品落地
- 金属转动
- 机关开启
- 门体滑动
- 脚步
- 布料摩擦
- 环境低频回响
- 水声 / 电流 / 风声 / 火焰声 / 设备轻响

## Seedance 2.0 适配写法

输出时尽量写成 Seedance 2.0 更容易理解的连续镜头语言：

- 明确视角：POV first-person
- 明确动作顺序：先什么，再什么，然后进入哪里
- 明确空间变化：什么物体如何变成什么结构
- 明确镜头运动：向前、靠近、穿过、进入、环绕式前进、停留
- 明确场景细节：材质、灯光、色彩、分区、氛围
- 明确音频氛围：女性 ASMR 旁白 + 环境 ASMR
- 明确负面约束：无文字、无字幕、无 logo、无 UI、无水印、无跳切

## 参考图处理原则

如果用户提供图片或说“按这张图来”：

- 将上传图片视为主体视觉参考或关键元素参考
- 忽略图片上的文字、UI、logo、水印
- 继承图中核心物件、造型、材质、配色、氛围
- 如果是角色图，不要让角色正脸长期占据画面，因为本任务核心是 POV 进入庇护所
- 如果是物品图，可将其设为开场触发物
- 如果是场景图，可将其吸收为庇护所内部风格参考

## 星座补全策略

用户没有写细时，按星座气质自动补全，但不要输出解释，只体现在 prompt 本身：

- 白羊座：火焰、合金、赤红能量、战备感、冲击力
- 金牛座：厚重、安全、储备充足、天然材质、豪华稳定
- 双子座：双通道、变形机关、镜像结构、轻快灵动
- 巨蟹座：包裹感、温暖光源、柔软、安全、居家感
- 狮子座：金色、中心舞台感、宫殿感、张力强
- 处女座：洁净、秩序、精密收纳、分区清晰、高功能性
- 天秤座：平衡、优雅、审美精致、对称、艺术感
- 天蝎座：神秘、深层空间、暗调、隐秘入口、氛围强
- 射手座：探索感、开阔、远行、纵深空间、高通道感
- 摩羯座：岩层、堡垒、防御工事、长期生存、山体结构
- 水瓶座：未来科技、冷光、智能系统、实验基地感
- 双鱼座：水感、梦境、柔光、发光纹理、幻想氛围

## 批量生成规则

当用户要求生成 12 星座全套时：

1. 每个星座必须有明显不同的：
   - 触发物
   - 入口方式
   - 外部末日环境
   - 庇护所结构
   - 核心空间记忆点

2. 不要把 12 条 prompt 写成同一模板换词。
3. 每个星座都要保留统一栏目气质：
   - 都是 POV
   - 都是一镜到底
   - 都有女性 ASMR
   - 都有末日反差
   - 都有完整生活区
4. 统一主题感，保持同一系列视频的可连续观看性。

## 输出格式

### 单条模式
只输出一整条最终 prompt。

### 批量模式
按以下格式输出：

【白羊座】  
<完整 prompt>

【金牛座】  
<完整 prompt>

依次输出。

不要写分析过程，不要写“思路如下”，不要写额外说明，除非用户明确要求拆解。

## 负面约束

每条 prompt 都要明确避免：

- 字幕
- 屏幕文字
- logo
- 水印
- UI 界面
- 第三人称镜头
- 非 POV 主镜头
- 跳切
- 多机位混剪
- 空间狭小
- 场景廉价
- 装修粗糙
- 物资稀少
- 空房间
- 杂乱无章
- 只展示一个区域
- 只拍入口不进入内部

## 输出风格要求

最终写出来的 prompt 应该是：

- 直接可复制
- 直接可投喂
- 连续完整
- 镜头感强
- 空间想象力强
- 细节足够丰富
- 但不要堆太多无关形容词
- 以“能生成好视频”为第一优先级，而不是写成散文
