# 动物治愈日常方向

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 适合角色

小熊、小猫、小狐狸、小兔子、小企鹅、小狗、小鹿、小刺猬、小水獭

## 故事核心

分享、陪伴、等待、发现、安慰、照顾、守护

## 典型小事件

- 发光种子掉进房间
- 小鸟敲窗送来东西
- 雨天发现小蜗牛
- 雪天捡到一片亮晶晶的叶子
- 朋友留下一封信或小礼物
- 食物被咬了一口（谁干的？）

## 情绪线范例

- 安静 → 好奇 → 试探 → 温柔 → 安心
- 孤单 → 意外遇见 → 互相靠近 → 陪伴 → 温暖
- 日常平淡 → 发现小惊喜 → 小心照料 → 成功 → 满足

## 角色材质句式

- 柔软短绒毛材质，低反光哑光质感
- 圆润奶油色身体，脸颊饱满有肉感
- 蓬松柔软大尾巴，耳朵小巧圆润

## 场景句式

- 雨后森林小屋窗边 / 阳光花园草地 / 冬天壁炉旁 / 雪天窗边
- 圆角木质家具 + 奶油色墙面 + 柔软布艺 + 小植物
- 低饱和暖色调，柔和自然光，浅景深

## 落 prompt 前自检

- 角色是否有明确的主色+副色+配件？不能只写"可爱小猫"
- 小事件是否能驱动情绪弧线？去掉它角色就只剩"坐着"
- 场景是否留出角色活动空间？不能堆满杂物
