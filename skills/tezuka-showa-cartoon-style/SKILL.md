# 手冢治虫卡通风 · 可复用风格技能

## 这个技能是什么

这是一个**画风滤镜（style filter）技能**，不是一次性文案。它的唯一目标：让用户在一次任务中生成的**所有图片素材资产**和**所有视频片段**，都稳定地呈现同一套「手冢治虫时代卡通画风 / 昭和复古赛璐珞动画」质感，画面风格前后完全一致、不漂移。

实现方式极其简单也极其严格：**在每一条图片 prompt 和每一条视频 prompt 的最开头，原封不动地拼接同一段「风格锚定词」，然后再接该镜头 / 该素材的具体画面描述。**

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 风格锚定词（STYLE ANCHOR，逐字复用，禁止改写）

> 手冢治虫时代卡通画风，经典昭和日式卡通动画质感，2D，铅笔勾线，复古色彩。手绘赛璐珞上色质感，低饱和动画配色，细腻噪点，旧印刷网点感，柔化滤镜

**使用铁律：**

1. 这段锚定词是**逐字固定**的。生成任何图片 prompt、任何视频 prompt 时，都必须把它放在 prompt 的**最开头**，一字不改、不增删、不翻译、不调换语序、不做同义替换。
2. 锚定词之后紧接一个自然分隔（逗号或句号或换行），再写本条素材 / 本个镜头的**具体画面内容**（主体、动作、场景、镜头、光线、情绪等）。
3. **图片资产和视频资产一视同仁**：只要是本任务里要生成的画面资产，无论是分镜图、角色设定图、场景图、关键帧图，还是视频片段 prompt，开头都必须带这段锚定词。
4. 不允许「只在第一张图用一次、后面省略」。**每一条 prompt 都要带**，这是保证整批一致性的关键。

### 标准拼接格式

```
【STYLE ANCHOR】 + 【本条画面的具体描述】
```

示例（图片素材）：

```
手冢治虫时代卡通画风，经典昭和日式卡通动画质感，2D，铅笔勾线，复古色彩。手绘赛璐珞上色质感，低饱和动画配色，细腻噪点，旧印刷网点感，柔化滤镜，一位大眼睛圆脸的少女站在昭和街道的糖果店门口，暖黄夕阳逆光，中景，微微仰头微笑
```

示例（视频片段）：

```
手冢治虫时代卡通画风，经典昭和日式卡通动画质感，2D，铅笔勾线，复古色彩。手绘赛璐珞上色质感，低饱和动画配色，细腻噪点，旧印刷网点感，柔化滤镜，同一位少女推开糖果店木门走进店内，木门风铃轻响，镜头缓慢跟随平移，暖色调，节奏轻快
```

## 规则一：与其他「风格类」skill 搭配时 —— 锚定词合并，规则不变

当本技能与另一个风格类技能（例如「复古 DV 风」「国漫 3D 渲染风」等）被同时调用时：

1. **不做取舍、不覆盖**，而是把两套风格锚定词**合并拼接**成一段更长的锚定词，整体放在每条 prompt 的最开头。
2. 合并顺序：**用户当前主诉求的风格在前，辅助风格在后**；若无法判断主次，则按调用先后顺序拼接。
3. 合并后，**「逐字固定 + 放最开头 + 图片视频都带 + 每条都带」的所有铁律依然全部生效**，只是锚定词内容变长了而已。
4. 若两套风格词存在明显冲突的技术项（如「2D 手绘」对「3D 渲染」），**以本技能的手冢治虫质感为准保留**，冲突的对立项在合并时剔除，其余非冲突描述照常合并，保证画面主体质感仍是手冢治虫卡通风。

合并示例（本风格 + 某复古滤镜风）：

```
手冢治虫时代卡通画风，经典昭和日式卡通动画质感，2D，铅笔勾线，复古色彩。手绘赛璐珞上色质感，低饱和动画配色，细腻噪点，旧印刷网点感，柔化滤镜，[另一风格锚定词逐字拼接]，[本条画面的具体描述]
```

---

## 规则二：与「非风格类」skill 冲突时 —— 本技能的画风约束优先且必须结合

当本技能与非风格类技能（如营销短片 skill、短剧脚本 skill、分镜 skill、广告 skill 等）被同时加载时：

1. **职责分工**：非风格类 skill 负责**内容结构**（脚本、分镜逻辑、卖点、节奏、时长、转场编排等）；本技能负责**画面质感与风格锚定**。两者是叠加关系，不是替代关系。
2. **风格锚定不可被覆盖**：无论其他 skill 内部是否有自己的画面描述模板、prompt 模板或默认出图风格，**最终真正送去生成图片 / 视频的每一条 prompt，都必须由本技能在最开头注入上面的 STYLE ANCHOR**。其他 skill 产出的画面描述，一律作为「具体画面内容」拼接在锚定词之后。
3. **执行顺序**：先让非风格类 skill 产出内容 / 分镜 / 画面脚本 → 再由本技能对每一条要出图 / 出片的 prompt 统一套上锚定词 → 才允许提交生成。**任何未经本技能套壳的 prompt 都不得直接用于生成。**
4. 若其他 skill 明确规定了某种「写实 / 实拍 / 3D / 特定品牌视觉」的成片风格，与本技能冲突时，**画面质感以本技能为准**，其他 skill 的风格性描述让位；但其内容结构、节奏、信息编排等非风格部分照常遵循。
5. 一句话总结给 Agent 的执行心法：**「内容听别人的，画风听我的，且画风注入是出图前最后一道不可跳过的工序。」**

---

## 规则三：禁止内置「风格锚定图」干扰（强制绕过）

部分 Agent 链路会针对某些风格**预置内置的风格参考图 / 风格锚定图 / reference image**，这些内置参考图会污染本技能的画面质感，导致出图偏离手冢治虫卡通风。因此：

1. **一旦本技能被调用，必须绕过 / 关闭 / 忽略 Agent 链路里任何内置的风格锚定图、默认风格参考图、预设 style reference。**
2. 生成图片和视频时，**只以本技能的文字风格锚定词作为唯一风格来源**，不得叠加、不得混入任何系统预置的风格参考图。
3. 若生成接口存在「风格参考图」「style reference image」「预设风格」这类可选入参，**一律置空 / 关闭 / 不传**，确保风格完全由文字锚定词驱动。
4. 若链路强制注入内置风格图且无法关闭，应在能控制的环节（prompt 权重、negative 描述、显式声明「不使用任何预置风格参考图，仅遵循文字风格描述」）中**最大程度压制其影响**，并优先保证文字锚定词的主导地位。
5. 允许的例外：用户**自己主动上传**的参考图（角色设定、构图参考等）不在禁止之列——被禁止的只是 Agent **系统侧内置 / 自动挂载**的风格锚定图。

## 风格知识库（供 Agent 写分镜 / 角色 / 场景 / 脚本时参考形容）

以下知识**不是要逐字塞进 prompt**，而是让 Agent 在**构思画面内容、写角色设定、写场景描述、写故事脚本**时，自然地往这个方向靠，使内容本身也贴合手冢治虫卡通风的气质。真正出图时，仍以「锚定词 + 具体画面描述」为准。

### 一、整体风格气质
- 简洁、清澈、童真，同时带有戏剧化与人文温度；不是华丽写实，而是理想化的童话舞台感。
- 兼具「儿童绘本式纯真」+「漫画分镜式戏剧性」+「舞台剧表演感」+「寓言故事式哲思」。
- 昭和复古底色：暖旧、怀旧、略带感伤，即使题材明亮也保有一丝温柔的忧郁。
- 常见主题气质：天真与哲思并存、机械幻想与生命关怀并存、冒险与离别并存。

### 二、角色造型典型质感
- **大眼睛**是最鲜明符号：圆润清晰、高光醒目，情绪主要靠眼睛传达（善良、天真、坚毅、悲伤）。
- **脸部高度概括**：脸型圆润柔和，鼻子简化成小点 / 小线，嘴小但表情灵活，真实骨相弱化。
- **身体比例卡通化**：儿童角色头身比偏大，成人也保留简洁漫画比例；四肢不强调肌肉解剖，动作轻巧、舞台化、易读。
- **表情漫画化且真诚**：开心极明朗、惊讶眼嘴同步夸张、悲伤眼神清澈直接，戏剧张力强但不粗暴。

### 三、线条质感
- 铅笔勾线 / 墨线感，轮廓优先，外轮廓明确、内部结构线少。
- 线条整洁利落，粗细有节奏但不炫技（轮廓略粗、五官较细、发丝衣褶少量粗细变化）。
- 线服务于叙事与识别，而非描摹材质。

### 四、色彩与上色质感
- 手绘赛璐珞平涂质感，大色块明确，阴影层级少、边缘偏硬。
- **低饱和复古动画配色**：天空蓝、草地绿、暖黄、砖红、奶油白、浅橙浅褐；夜景偏蓝紫但仍有温度。
- 明快纯净但克制，不刺眼；整体明度结构温暖，即便悲伤场景也不彻底阴郁。

### 五、材质 / 后期质感（本风格标志）
- **细腻噪点**：画面均匀分布轻微颗粒，模拟老胶片 / 旧动画的质感。
- **旧印刷网点感**：平涂色块中隐约可见半调网点，像老漫画 / 老印刷品。
- **柔化滤镜**：整体轻微柔焦、边缘柔和，减弱数码锐利感，营造复古手绘温度。
- 材质重点是「情绪氛围」而非物理真实：不追求毛孔、金属微反射、写实布褶。

### 六、光影与场景
- 光线戏剧化但简洁：晨光、夕阳、逆光常见，光区暗区分明，光为情绪服务。
- 场景简洁而有梦感：识别性强、气氛明确、带童话舞台感。
- 科幻元素走**复古未来主义**：圆弧轮廓、简洁舱体、带玩具感 / 模型感的浪漫机械幻想，不冷硬工业。
- 自然场景重「生命感」：草木云风阳光明亮温柔、有呼吸感，是角色情绪的延伸。

### 七、动态与分镜（写视频脚本时参考）
- 动作重「读秒感」：靠明确姿态、清晰重心、关键帧停顿感，而非复杂运动模糊。
- 分镜戏剧性强：敢给特写，情绪镜头贴近眼睛与面部，动作方向明确，宏观场景与情绪特写切换鲜明。
- 节奏似儿童冒险故事：平静段温柔舒展、危机段直白紧张、高潮段情感饱和、结尾有余韵与感伤。

## Agent 执行清单（每次任务照此办理）

1. 确认本任务需要「手冢治虫卡通风」→ 锁定上方 STYLE ANCHOR。
2. 若同时有其他**风格类** skill → 按【规则一】合并锚定词。
3. 若同时有**非风格类** skill → 按【规则二】：内容用它们的，画风用本技能的，出图前统一套锚定词。
4. 按【规则三】绕过 / 关闭一切系统内置风格锚定图，风格只由文字锚定词驱动。
5. 写分镜 / 角色 / 场景 / 脚本时，参考「风格知识库」让内容气质也贴合。
6. 逐条生成 prompt：**每一条**图片 prompt 与视频 prompt 都以 STYLE ANCHOR 开头 + 具体画面描述。
7. 校验：是否每条都带锚定词？是否逐字一致？是否放在最开头？图片和视频是否都覆盖？——全部通过才可提交生成。
