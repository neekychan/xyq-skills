# 中国神话故事风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的「中国神话故事风」质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入、改写了锚定词，或被 Agent 链路的内置风格参考图干扰，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一套神话插画 / 同一部东方神话动画里出来的」（笔触、材质颗粒、发光质感、配色、人物气质不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一部中国神话作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **中国神话，2D hand-drawn character, Chinese mythology style，中国神话风格，描金线条插画，古风插画、装饰艺术、岩彩 / 壁画感、轻国漫视觉语言，朦胧发光的材质感，柔化、薄涂、雾化、叠擦的笔触，轻颗粒薄涂，柔边晕光，珠光一样的泛亮，雾中的内发光金粉一样的小点闪烁**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词保持上文原文（中英混排）不翻译、不改写；具体画面描述**优先用中文书写**，如确需英文版本仅作补充，且锚定词部分始终保持原文。

## 绕过 Agent 内置风格锚定图的干扰（硬规则，务必执行）

部分 Agent 生成链路会针对某些风格**前置内置一张「风格参考图 / 风格锚定图」**，用它去约束出图风格。这类内置参考图会与本技能的锚定词冲突，污染本技能的资产画风。**一旦本技能生效，必须绕过该内置风格锚定图设定：**

- **不使用任何系统 / 链路内置的风格参考图、风格模板图、默认风格底图**作为本次图片 / 视频生成的风格来源；本技能的风格**只由上文文本锚定词决定**。
- 调用生图 / 生视频工具时，**不要主动传入内置风格参考图参数**；若工具接口默认会挂载内置风格图，则显式置空 / 关闭该风格参考，或不填充任何「风格图 / style reference / 风格模板」类入参，仅以文本锚定词驱动风格。
- **唯一允许的参考图**是：用户显式提供的参考图，或本技能自己在本任务前序步骤中生成、用作视频首帧 / 衔接的图片素材。除此之外一律不引入外部风格锚定图。
- 若链路强制注入了内置风格图导致画风跑偏，视为执行失败：改为纯文本锚定词驱动重生，直到画风回到本技能定义的质感。

## 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述、绕过内置风格锚定图。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

## 与「非风格类」skill 冲突时的优先级（务必遵守）

当本技能与**非风格类** skill 同时被加载时（例如「营销短片 / 广告短片」「短剧」「口播视频」「分镜脚本」等业务型 skill）：

- **画风归本技能，业务归对方：** 对方 skill 负责结构、节奏、卖点、时长、镜头脚本、投放形态等**业务逻辑**；一切**关于画风 / 材质 / 笔触 / 配色 / 造型气质**的决定权归本技能。
- **锚定词不可被对方覆盖：** 即使对方 skill 自带风格描述、示例 prompt、默认画风词或内置风格参考图，也**不得替换、稀释或跳过**本技能的锚定词与注入规则。对方 skill 产出的每一条图片 / 视频 prompt，最终都必须在最开头逐字注入本技能锚定词后再送去生成。
- **结合方式：** 先让对方 skill 产出业务层面的分镜 / 脚本 / 画面清单，再由本技能对清单里的**每一条** prompt 做头部锚定词注入与「绕过内置风格图」处理，二者叠加交付；不是二选一。
- **发生正面冲突时以本技能为准：** 若对方 skill 明确要求「使用它自己的画风 / 用内置风格图 / 不许加前缀风格词」，与本技能规则直接矛盾，则在**画风相关部分以本技能为准**，并向用户一句话说明「已按中国神话故事风统一画风」。

## 整体风格气质与角色造型知识库（供分镜 / 脚本 / 画面描述参考）

写具体画面、分镜、角色、故事脚本时，具体描述部分应尽量贴合以下特征，让内容与锚定词同频（这些是「怎么描述画面」的参考，不替代锚定词）：

### 1. 整体气质（四字核心：梦 / 灵 / 柔 / 圣）
- **梦：** 空间漂浮、远近界限模糊，云、水、烟、光互相融化；光源服务情绪而非现实。
- **灵：** 万物有灵——花草会发光、水像活的、云像呼吸，星月灵兽都带人格化神性。
- **柔：** 五官柔、边缘柔、光柔、色彩过渡柔、布料柔，线条轻盈流动而非硬线。
- **圣：** 神圣感的抒情化——光轮 / 背光、仪式构图、中轴站姿、仰视感、发光核心物、环形焦点。

### 2. 题材母体（选材越贴近，识别度越高）
- **人物：** 上古神女、月神 / 日神 / 司时女神、祭祀巫女、灵河仙子、司云司水司光的神祇、半神半人的古典女性；气质清冷、悲悯、神圣、柔美而不可亵玩。
- **场景：** 云海、月轮 / 日轮、星轨、潮汐神水、山海异境、祭坛、远古帷幕 / 神庙残壁 / 壁画遗迹、空灵夜色与宇宙背景。
- **符号：** 飘带、祥瑞云纹、金轮 / 背光 / 法相、灵木花枝藤蔓、神鸟白鹿天马异兽、火焰日精月华、玉佩璎珞钿饰冠冕、古纹样与图腾圆盘。

### 3. 角色造型典型质感
- **脸型：** 小而窄、下颌柔和、五官集中、面部留白多，古典仕女式含蓄。
- **眼睛：** 细长、低垂、半闭，情绪克制，如「神明俯视众生」或「沉入神思」；不做二次元大眼高光。
- **鼻嘴：** 鼻梁轻描、嘴小唇色淡、表情克制。
- **发型：** 高髻、云鬓、长发如水；发饰偏玉石 / 金属 / 叶形 / 花形 / 灵禽形；发丝像墨线与薄雾结合，不追求根根分明。
- **身形：** 修长、轻、直，腰背挺拔不僵，手指纤长、姿态仪式化——人物像「神意的承载器」而非生活化角色。
- **服饰：** 广袖长裙、轻纱披帛、多层薄纱叠加，材质像被月光浸透的雾纱 / 月光纱 / 半透明绡；金边、玉饰、璎珞、流苏、环佩、神鸟纹 / 云雷纹 / 花叶纹。
- **飘带系统：** 飘带承担空间走向、节奏线、动势线，是「神话气韵」的可视化，务必让它像风 / 云 / 波 / 气机在流动。

### 4. 色彩体系
- **底色（低饱和矿物 / 雾调）：** 青灰、墨绿、靛蓝、藕紫、米金、烟粉、月白、岩土褐——像岩彩矿物、老壁画褪色层、被月光烟雾罩住的颜色。
- **点亮（高纯神性色）：** 金色、暖白、珠粉、玉青、浅湖蓝、萤火橙、月光黄——形成「暗底 + 柔光」「冷底 + 暖金」「灰雾底 + 宝石色点缀」。
- **常见配色路线：** 月夜神女系（靛蓝 / 月白 / 淡紫 / 轻粉 / 银金点）、上古祭祀系（土金 / 褐黑 / 古铜 / 赤金 / 暗红）、灵兽天象系（深蓝黑宇宙底 / 钴蓝青金 / 金线 / 珍珠白 / 星火橙）、水神云梦系（藕粉云气 / 湖蓝 / 月白 / 淡青绿 / 发光暖黄）。

### 5. 构图与镜头语言（利于写分镜）
- 竖幅海报式；中心神像式构图（主体中轴 + 背后圆轮 / 法相 + 放射线 + 下方朝拜式侍者）。
- S 形与竖向流动构图（身体 + 长发 + 袖带 + 水波连成流线，出「风」与「气」的动势）。
- 帘幕式前景（前景垂落织物 / 花枝 / 流苏，中景人物，后景云 / 水 / 夜色，像神话舞台）。
- 环形焦点（月轮 / 日轮 / 星盘 / 发光宝珠 / 水中光环，带命运感与宇宙秩序感）。
- 大留白与大面积朦胧区（雾 / 云 / 暗面 / 水面 / 夜空作气韵空间，不填满）。
- 「动画感」来自把故事高潮定格成一帧 + 明确动势线 + 清晰景别分层，而非运动速度。

### 6. 笔触与质感（与锚定词呼应，写画面时可强化）
- 柔化、薄涂、雾化、叠擦；先铺大色调再半透明罩染，局部细线 + 描金提神，最后加发光与颗粒统一气氛。
- 大量软边（轮廓局部虚化、发丝融进背景、袖边消失在光里）；硬边只留给面部 / 手 / 发饰 / 金属件 / 神兽眼 / 重要纹样 / 光轮结构线。
- 轻颗粒（纸面纹理 / 岩彩颗粒 / 斑驳旧化层）增古意与手工感；描金线作为神圣秩序与装饰骨架。
- 发光为「灵气感」而非科幻炫光：柔边晕光、珠光泛亮、雾中内发光、金粉般小点闪烁。

> 女频 / 轻松诙谐 / IP 化（如萌宠）等叙事偏好，可在**具体画面与脚本**里体现（角色设定、情节、气氛），画风仍严格由锚定词统一——两者不冲突。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否与业务型 skill（营销短片 / 短剧等）配合；视频画幅 / 时长偏好；是否需要图片先行作为视频首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，按上文知识库补齐一版贴合风格的分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。同时确认本次将**绕过内置风格锚定图**，仅以文本锚定词驱动风格。
2. **（如与业务型 skill 配合）先产出业务分镜 / 脚本。** 让对方 skill 负责结构与内容，得到画面清单；画风词一律不采用对方的，留待本技能注入。
3. **生成图片素材（逐张）。** 对每一张图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`，具体描述尽量贴合上文知识库，然后生成图片（不挂载任何内置风格参考图）。所有图片共用同一份锚定词。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将**本技能生成的那张图片**作为视频画面参考，视频 prompt 仍在头部注入锚定词（该图不属于「内置风格锚定图」，可用）。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动），并确认没有被内置风格图污染。
7. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。
- 生成调用不携带任何内置 / 默认风格参考图入参。
