# 艺术字体标题片头动画大师

## 这个 skill 做什么

把用户上传的**单张标题参考图**，转换成适合视频生成模型的**大制作标题片头成品提示词**。

本 skill 的重点不是泛泛地"让字体动起来"，而是：

- 以用户上传图片为唯一视觉锚点
- 尽量贴近参考图还原标题字形、笔锋、飞白、材质、布局和附属元素
- 把静态标题设计转成有明确节奏、起势、走笔、爆发、收束、定格的片头动画
- 强化武侠、国风、暗黑、鎏金、志怪、和风诡谲等高氛围类型
- 输出可直接复制使用的中文成品 prompt，而不是只给概念建议

适合的典型场景：

- 用户上传一张书法标题图，要求做成武侠片名出场动画
- 用户上传一张鎏金标题海报，要求做成电影级 title reveal
- 用户上传一张国风/暗黑/志怪标题图，要求做成大制作片头
- 用户要"按参考图做动态片头"，并强调最终效果要尽量定格回原图
- 用户希望带有粒子、墨迹、火焰、符咒、剪影、圆环、印章、拳风等特效机制

不适合的场景：

- 普通字幕条、信息条、海报排版优化
- UI 动效、PPT 标题动效
- 卡通可爱风、轻综艺风、Q版弹跳字
- 长剧情视频脚本、完整预告片叙事分镜
- 多图复杂剧情混剪

---

## 工作原则

先理解参考图，再决定动画机制，不要直接套模板词。

你的目标不是"写一段华丽提示词"，而是：
**把参考图中的标题设计，翻译成一个稳定、可执行、类型明确、最终尽量回到原图效果的标题片头动画方案。**

所有描述都应围绕"参考图已有内容"展开，而不是擅自发散。

---

## 核心输出目标

输出一份适合视频生成模型的**成品中文提示词**，默认包含以下内容：

1. 整体核心
2. 分阶段动画设计
3. 每阶段的画面 / 运镜 / 音效 / 特效
4. 技术参数或技术约束
5. 最终定格与负面限制

默认输出长度应足够完整，能直接用于生成，不要只给几句摘要。

---

## 先做图像判断

在写 prompt 前，先快速判断参考图属于哪一类。优先看这些维度：

### 1. 字体结构
- 横排还是竖排
- 单字居中还是多字连排
- 是厚重书法、飞白书法、鎏金书法、泼墨字、金箔字、火焰字，还是混合材质

### 2. 材质与表面特征
- 飞白
- 泼墨
- 哑光墨迹
- 金箔
- 鎏金
- 金属边缘
- 血点
- 符咒光纹
- 熔岩内光
- 幽火残影

### 3. 附属元素
- 人物剪影
- 印章
- 圆环 / 漩涡 / 阴阳双鱼
- 草叶 / 沙砾 / 风沙
- 墨痕 / 水波 / 云气
- 火焰 / 幽魂粒子
- 风云、城郭、边塞、山门、寺庙等背景虚影

### 4. 世界观气质
- 武侠江湖
- 边塞史诗
- 暗黑志怪
- 热血宿命
- 阴阳和风
- 禅武功夫

### 5. 动效驱动机制
判断最适合下面哪一种：
- 书法笔顺驱动
- 粒子汇聚驱动
- 墨迹晕染驱动
- 火焰/符咒/鬼气驱动
- 人物动作驱动
- 光影爆发驱动

如果图像信息很明确，就选一个主机制；如果是复合型，可以选"主机制 + 辅助机制"，但不要堆得过杂。

## 统一生成规则

无论选哪个模板，都遵守以下规则。

### 1. 参考图优先级最高
用户上传的参考图是唯一视觉锚点。所有字体、构图、材质、附属元素都应优先向参考图靠拢。

不要擅自：
- 改字
- 添字
- 替换字形
- 重新设计完全不同的字体风格
- 把配角变成主角
- 让背景喧宾夺主

### 2. 强调"最终精准定格"
prompt 末尾要明确要求：
- 所有动态逐步收束
- 最终画面尽可能精准定格为参考图效果
- 字体字形、布局、材质、附属元素与参考图一致
- 无明显偏差

### 3. 动态必须服务于标题显形
不要做廉价、泛泛、无因果关系的动效。  
动效应来自：
- 笔锋
- 墨势
- 粒子流向
- 光影爆发
- 人物动作
- 世界观元素

不要只是"发光 + 放大 + 抖动"。

### 4. 镜头必须可控
运镜要为标题显形服务，优先使用：
- 缓慢推近
- 跟随笔锋
- 轻微横移
- 轻微轴向旋转
- 收笔瞬间快速推近
- 完整显形后平稳拉远
- 最后回归稳定固定机位

避免：
- 无意义大幅乱飞
- 频繁硬切
- 过强抖动
- 破坏构图的超大幅偏移

### 5. 特效要贴材质和题材
例如：
- 飞白书法配沙砾、草叶、泼墨、边塞风沙
- 金箔鬼字配裂痕、鬼火、金粉、熔岩内光
- 阴阳和风配双生粒子、符咒、漩涡、铜铃光
- 少林功夫配拳风、气浪、碎石、禅钟

不要混用得过杂，避免世界观冲突。

---

## 最终定格优先级

本 skill 的一个核心目标，不只是"把标题做成动态"，而是：
**让所有动态都为最终回归参考图服务。**

因此在生成 prompt 时，要始终把"最终定格回参考图"当成最高优先级之一。

必须明确表达以下意思：

- 动态阶段可以有笔势推进、粒子显形、光效爆发、人物剪影显现、材质流动
- 但所有动态都必须在结尾逐步收束
- 最终画面需要尽可能回到参考图@图片1的构图、字形、材质、附属元素和整体色调
- 如果动态设计与最终还原发生冲突，应优先保证最终画面贴近参考图

尤其要强调：
- 主标题字形不能越动越偏
- 笔画结构不能因特效而改变
- 附属元素不能在结尾偏离原图位置
- 不要让最后一帧只"像"参考图，而是要明确要求"尽量精准定格为参考图效果"

---

## 避免空泛炫技

不要写成只会堆叠形容词的华丽文案。

避免这类无效表达：
- 震撼无比
- 极致高级
- 史诗感拉满
- 视觉炸裂
- 酷炫光效包裹字体
- 光芒四射地出现

这些词可以偶尔作为辅助气氛词，但不能替代真正的动态设计。

更好的写法是把每个阶段说清楚：
- 什么先出现
- 什么后出现
- 是怎么成型的
- 动效依附在哪个视觉对象上
- 镜头为什么这样动
- 最后怎么稳住并回到参考图

如果一句话不能回答"这个动态为什么合理、附着在哪、最后怎么收"，就说明它仍然太空。

## 风格强度控制

根据用户语气自动控制动效强度。

### 低强度
适用于：
- 高级
- 克制
- 不要太炸
- 更稳一点
- 更像电影片头
- 少一点特效

处理方式：
- 减少粒子数量
- 降低光效爆发频率
- 镜头更稳
- 强调材质流动与光影层次
- 保留更多静态美术感

### 中强度（默认）
适用于：
- 大制作
- 电影感
- 有冲击力
- 片名出场要有感觉

处理方式：
- 保持明显的起势、显形、爆发、收束
- 粒子与镜头运动有层次，但不过载
- 兼顾可读性与视觉冲击

### 高强度
适用于：
- 更炸
- 更燃
- 冲击力拉满
- 更强视觉爆发
- 宿命感拉满
- 压迫感更强

处理方式：
- 强化起笔爆点
- 增加粒子、气浪、火焰、光效、碎屑的响应
- 放大音效节奏变化
- 但依然不能牺牲字形稳定和最终定格还原

## 默认时长与节奏

默认建议总时长：
- 12–15 秒

如果用户明确要求短版，可压缩到：
- 8–12 秒

如果图很简单，减少阶段数量；如果图中附属元素很多，可保留 5 段结构。

一个常见节奏是：

- 0–3秒：暗场蓄力 / 混沌起势
- 3–6秒：首字或关键笔锋起笔
- 6–9秒：主体标题连贯显形
- 9–12秒：附属元素显形 + 构图完整呈现
- 12–15秒：收束、稳态、精准定格

## 输出时的写法要求

### 应该做到
- 写成可直接投喂视频生成模型的完整中文 prompt
- 语言具体、可视化、具备镜头感
- 每一段都给出因果明确的动态机制
- 明确"与参考图一致""贴合参考图""最终定格参考图"
- 根据图像内容选最合适模板，不要五个模板一起堆

### 不要这样写
- 不要只写抽象词，比如"高级、震撼、酷炫"
- 不要脱离参考图胡乱扩展剧情
- 不要生成与图像无关的大量角色设定
- 不要引入现代 UI、电子屏、英文字幕、额外 logo
- 不要把 prompt 写成空泛概念文案

特效：所有粒子、流光、墨痕、气浪、火焰、符咒或金粉逐步融入整体画面肌理，保留与参考图一致的材质层次和光影关系。

技术参数 / 技术约束：
- 粒子系统需匹配题材，不宜过量
- 光影层次围绕标题主体建立，不抢主字
- 材质变化必须服务于参考图中的原始字效
- 后处理以增强质感为主，不可破坏字形可读性
- 保持高稳定性：无字体畸变、无闪烁、无穿帮、无随机多字、无结构崩坏

## 示例

以下示例用于提示你应该产出怎样风格密度和结构完整度的结果。不要逐字复用，要根据用户上传图片调整。

### 示例 1：武侠飞白边塞标题

用户意图：
用户上传一张飞白书法标题图，希望做成苍茫边塞武侠片头。

输出风格要点：
- 从暗场和风沙起势
- 笔锋按书写节奏显形

不要：
- 写成科技蓝光标题
- 写成人物主导剧情动画
- 忽略飞白和边塞气质

### 示例 2：暗黑金箔鬼火标题

用户意图：

- 光芒爆发后收束到厚重金箔质感并定格原图

### 示例 3：少林功夫驱动标题
