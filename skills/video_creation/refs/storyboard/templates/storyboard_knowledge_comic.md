# 分镜图模板：知识讲解 · 漫画科普分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：通过漫画角色与对话气泡，用轻松故事或情境对话的方式完成科普/教学讲解的**漫画科普分镜**，每格既承载剧情推进，又明确输出一个知识点或生活建议。
- **典型场景**：
  - 儿童/青少年向科普：健康习惯、安全教育、科普常识等，用可爱角色对话讲解。
  - 职场/生活场景科普：如“加班健康提醒”“理财避坑”“社交礼仪”等，用社畜/同事/情侣对话呈现。
  - 品牌/机构想做“漫画版说明书”：用 IP 形象向用户解释规则、流程或注意事项。

## 2. 判定关键词与适用边界
- 典型触发词：`漫画科普`、`漫画讲解`、`条漫科普`、`角色对话科普`、`漫画版说明书`、`四格漫画讲知识`、`小漫画教你`。
- 适用判定：
  - 用户明确提出“希望用漫画/条漫形式讲知识”“想要有角色对话气泡的科普漫画”；
  - 画面以 2D 漫画画风为主，大部分格都有对白气泡/旁白，知识点通过对话或角色旁白输出；
  - 当需求同时强调“漫画格/分镜表/条漫布局”等关键词时，**构图、宫格布局、景别节奏可复用 `storyboard_comic_board.md` 的漫画分镜规范**，在此基础上叠加科普内容规划。
- 不适用场景：
  - 漫画只是风格选择，几乎没有对话气泡，主要是情绪插画或故事分镜 → 优先用“漫画/分镜表型”或剧情分镜模板；
  - 知识点非常严肃且文字密集，需要大量公式/定义展示 → 更适合“教学/科普分镜”或“图解信息分镜”；
  - 核心诉求是产品卖点或广告，而非知识普及 → 建议走“产品讲解型”模板，仅在视觉上借用漫画风格。

## 3. 分镜结构建议
- **推荐宫格数**：6–12 格；儿童向/轻量科普常见为 6 或 9 格，长篇故事可拆成多条漫画科普分镜。
- 规划方式：
  - 整体结构：
    - 开场 1–2 格：角色出场，提出问题/困惑/生活情境（“为什么总是熬夜？”）。
    - 中段 3–8 格：角色对话中逐格讲解知识点，每格聚焦一个小知识/步骤，用场景或比喻帮助理解。
    - 收尾 1–2 格：知识总结+轻微反转或幽默结尾，给出行动建议或记忆口诀。
  - 每格元素：角色站位+表情+对话气泡+（可选）板书/图示区，确保知识点文字不被角色遮挡。
  - 宫格布局可参考条漫/四格漫画常见节奏：上半部分引入与困惑，下半部分解决与收束；需要长对话时可将同一场景拆成连续两格，分段展示气泡。

## 4. 生图 Prompt（PE）模板

```text
你是一名漫画科普分镜师，请根据下述信息设计一张 {宫格数} 宫格的“漫画科普分镜”图，整体画幅为 {画幅比例说明，如“9:16 竖屏条漫”或“3×3 九宫格漫画”}，画面需包含清晰的角色对话气泡。

【知识主题与受众】
- 科普主题：{如“预防近视的小习惯/信用卡分期的真实成本/儿童正确洗手步骤”等}
- 目标受众：{如“低龄儿童/中学生/职场新人/父母群体”等}
- 语气与风格：{如“轻松搞笑/温柔治愈/认真但不吓人”等}

【角色设定】
- 主角：{姓名或称呼+外观特征+性格标签，如“社恐打工人小李”“好奇的小学生豆豆”等}
- 配角：{老师/医生/同事/家长/吉祥物等的外观与性格}
- 角色关系：{如“师生”“同事”“亲子”“室友”等}

【知识点拆分】
- 核心结论：{希望读者带走的 1–2 句最重要结论}
- 关键知识点列表：{拆成 3–7 条，每条可做一格或多格对话展开}
- 禁忌与误区（如有）：{需要在漫画中特别提醒的错误做法}

【画面风格】
- 漫画画风：{如“Q 版/日系校园/职场条漫/简笔漫画”等}
- 配色与氛围：{如“明亮糖果色”“蓝白理性风”“柔和粉色治愈”}
- 对话气泡样式：{圆形/方形/旁白框等，要求易读}

【宫格与布局】
- 宫格数：{宫格数，如 9 宫格}，按顺序编号 K1–K{N}。
- 布局风格：{如“竖版条漫自上而下阅读/3×3 九宫格”}；可在构图与景别上**参考 `storyboard_comic_board.md` 中的漫画分镜规范**。

【分镜输出格式】
- 为 K1–K{N} 每一格输出：
  - 场景与构图：{室内/室外/教室/办公室等，角色站位与远中近景说明}
  - 说话角色与气泡内容：{谁在说话，对话气泡中简短台词，建议 10–20 字一格，可拆多气泡}
  - 对应知识点：{本格承担的具体知识点或步骤}
  - 表情与肢体：{用表情/动作表现情绪与重点，如震惊/疑惑/恍然大悟}
  - 是否有图示/板书：{如有，说明板书/小图标中要画出什么示意}

【画幅与完成度】
- 画幅比例：{9:16 / 16:9 / 正方形}，默认 9:16 竖屏条漫。
- 完成度：{草稿/线稿级/精修}，连载/对外传播建议用精修级或接近成品级。
```

## 5. 一致性与避坑
- 每格只输出 1 个明确知识点或一个小问答，不要在单格中堆叠多个概念和长段解释，避免阅读负担过重。
- 对话气泡要简短、口语化，儿童向内容尤其注意避免专业术语堆砌；复杂解释可以拆成连续几格，由角色逐步讲完。
- 角色外观（发型、服饰、体型）跨格保持一致，角色称呼与人设也要前后一致，避免人物变形或“换人”。
- 场景背景在同一段对话内保持连贯，切换地点时用明显的背景变化或旁白说明，避免读者误解时间/地点。
- 注意知识正确性与风险提示：对于健康、安全、金融等高风险主题，应在分镜说明中预留“温馨提示/免责声明”位置，不要让漫画语气削弱必要的严肃信息。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中知识类执行模板，将本模板生成的“漫画科普分镜图”视为知识类分镜的一种变体：
  - 分镜阶段用漫画格承载知识点与对白，将文字分镜表中每格的知识点、台词与镜号对应起来；
  - 视频阶段按漫画格顺序生成镜头，确保**台词顺序与知识点顺序完全对齐**，禁止随意删减或重排。
- 画面形态与宫格节奏可沿用 `storyboard_comic_board.md` 中的漫画分镜执行策略：
  - 选择典型的条漫布局（竖版或 3×3 等），在视频 Prompt 中要求“尽量保留原漫画格的构图与分镜节奏”；
  - 若将漫画气泡内容转为语音或字幕，需结合 `storyboard/dialogue-rules.md` 控制每段台词时长，并在视频画面中预留字幕区，不让角色遮挡文字。
- 对于面向儿童或泛大众的科普，推荐用“参考图生视频”的方式，把漫画分镜关键格作为参考帧，仅加入轻微运动（镜头平移、角色小动作），避免过多运镜与特效分散注意力，确保观众有时间看清对白与知识点。
