# 分镜图模板：动作分解 · 操作流程分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：围绕产品使用、工具操作、手势演示或生产工序，将完整流程拆成若干清晰步骤，每格对应一个步骤或关键动作，强调“步骤清晰、可复现、带序号”的**操作流程分镜图**。
- **典型场景**：
  - 数码产品/App 的使用教程、功能演示流程（注册→设置→使用→结果）。
  - 生活用品、美妆护肤、家电等的开箱与使用步骤讲解。
  - 手工制作、烹饪、工厂工序、实验操作等需要严格按步骤执行的流程示意。

## 2. 判定关键词与适用边界
- 典型触发词：`操作步骤`、`流程分解`、`按步骤教学`、`使用教程`、`手势演示`、`工序拆解`、`一步一步来`、`1/2/3 步`。
- 适用判定：
  - 用户主要关心“怎么做”“按什么顺序做”，希望每一步动作与操作要点都被清楚标出；
  - 分镜用于教学/说明/培训，目标是让观众能够复刻完整流程，而不仅是理解概念。
- 不适用场景：
  - 仅展示产品卖点或广告情绪，不强调使用过程拆解 → 适合“产品讲解分镜图”；
  - 纯理论科普、原理讲解，不含具体操作动作 → 适合“教学科普分镜”或其他知识类模板。

## 3. 分镜结构建议
- **推荐宫格数**：6–12 格，覆盖“开场概览 + 主要步骤 + 结果或注意事项”，流程复杂时可扩展至 16 格。
- 规划方式：
  - 先用文字列出完整操作流程，从准备 → 正式操作各步骤 → 收尾与结果校验；
  - 将每个步骤绑定到 1 格，复杂步骤可拆成 2 格（正确示范与错误示范），严格保持“一个格只讲一个步骤”；
  - 第 1 格用于整体概览或工具/产品亮相，最后 1–2 格用于展示效果、成品或关键注意事项。
- **画面特征**：人物手势、工具/产品细节与界面内容要清晰可见，背景简洁，预留字幕区域用于标注步骤编号与操作要点。

## 4. 生图 Prompt（PE）模板

```text
你是一名教学导演兼产品体验设计师，请为 {流程类型，如“手机 App 注册流程/咖啡机使用教程/护肤三步法/实验操作流程”等} 设计一张 {宫格数} 宫格的操作流程分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏教程短视频”或“16:9 横版说明视频”}。

【流程基本信息】
- 流程名称：{如“智能牙刷使用全流程”“APP 新用户注册与首单下单”等}
- 使用场景：{如“电商详情页教程/售后说明视频/培训课件”等}
- 目标用户：{如“新手用户/专业技师/学生”等}
- 完成后结果：{观众完成全部步骤后能达到的状态或效果}

【步骤拆分要求】
1. 先用文字列出完整操作流程的步骤列表：
   - 步骤1：{准备阶段，如“打开包装，取出所有部件”}
   - 步骤2：{正式操作的第一步，如“插上电源，按下开关”}
   - …
   - 步骤N：{收尾或结果展示，如“查看操作结果/清洁工具并收纳”}
2. 对于需要特别提醒的步骤，可以在列表中标记“重点步骤”或“容易出错步骤”。

【分镜与编号】
- 宫格数：{宫格数，如 8/10/12 格}，按步骤顺序编号 P1–P{N}；
- 一般对应关系为：P1 概览或准备 → P2–P{N-2} 逐步操作 → P{N-1} 结果展示 → P{N} 注意事项或总结。

【分镜输出格式】
请依次为 P1–P{N} 输出以下信息：
- 步骤名称：{简短命名，如“准备工具”“加入材料”“启动设备”等}
- 步骤编号：{1/2/3…，与文字流程列表一致}
- 画面内容：{人物手势、产品/工具、界面或工位环境，强调操作动作与关键物件位置}
- 操作要点：{该步必须做到的关键动作或检查点，如“轻按而非用力按”“确认指示灯常亮”等}
- 视角与构图：{如“俯视特写看清按键”“侧面中景看清身体姿势与工具位置”等}
- 可选错误示范：{如需要，可简短描述常见错误姿势或误操作，用不同色调或符号区分}

【画幅与风格】
- 画面比例：{9:16 / 16:9 等，默认 9:16 用于移动端教程}
- 画风：{写实摄影感 / 3D 产品渲染 / 2D 插画 等}
- 标注方式：{是否在画面预留编号与文字说明区域，如顶部步骤标题+底部操作要点}
- 要求整套分镜中人物外观、产品造型与界面风格保持一致，步骤编号连续且与文字流程完全对齐。
```

## 5. 一致性与避坑
- 每格只承载一个清晰步骤，避免在同一格中混合两步以上操作，导致观众难以复现。
- 步骤编号必须与文字流程一致且连续，不得缺号或跳号，防止执行流程出错。
- 产品外观、界面布局与工具位置在各格保持一致，避免“按钮位置突然变化”“界面换皮”影响理解。
- 背景与拍摄视角尽量统一，除非刻意切换到“整体视角”或“细节特写”，并在说明中显式标注。
- 教学场景避免画面中过度堆叠文字，文字内容优先由脚本或后期叠加，分镜图阶段只为文字预留位置与空间。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“动作分解表”及相关教程类执行模板：
  - 分镜阶段用本模板将操作流程拆成 P1–P{N} 的步骤序列，为动作分解表中的“教学动作/操作类”提供结构化蓝本；
  - 视频阶段按步骤顺序逐镜复现，每个镜头只承担一个核心操作，保持“一镜一概念”的原则，避免在单镜中塞入多个步骤。
- 若流程包含明显肢体动作或器械运动（如拉杆、旋钮、拧盖、挥动工具等），对应视频 Prompt 中的动作描述与空间定位应参考 `storyboard/vfx-action-prompt.md` 的规则：
  - 明确手势方向、身体重心与空间方位，避免“动作说不清”“物体位置跳变”；
  - 对具有力度感或机械运动的步骤，可适度加入环境反馈（轻微震动、指示灯变化等），但不夸大为大型战斗特效。
- 本模板适合与“产品讲解分镜图”“动作脚本表格”组合使用：操作流程分镜负责步骤拆解与可复现性，产品讲解负责卖点与场景，脚本表格负责具体镜号、时长与执行备注，共同构成完整教程视频的前期规划。
