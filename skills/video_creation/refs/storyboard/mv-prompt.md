# MV 音乐视频 Prompt 编写指南

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意发散阶段的流程、分段规划、合成策略见 `creative/mv-creator.md`。

## 强制规则（Prompt 格式）

1. **禁止生成BGM归通用尾注**：MV 的音频来自用户提供的歌曲，不使用模型自动生成的音频。多段 MV 把"禁止生成BGM，保持无字幕"及风格词写入 storyboard.md `通用尾注`（只写一次，主 Agent 拼到每段末尾），段 Prompt 内不重复；每段的"音频驱动"句式、歌词口型、场景/着装等段级内容仍写在各段 Prompt。单段直接写进 Prompt 末尾
2. **Prompt 必须附歌词原文**：演唱段 Prompt 中必须写明 `口型严格同步: "{该段歌词原文}"`，给模型提供口型锚点
3. **"音频驱动"句式**：Prompt 使用 `使用@视频1中的音频驱动@图片1中的主角` 句式，而非"参考@视频1的音频"

## 逐段生成规则

每段视频的调用方式：

```json
{
  "ModelName": "seedance_2.0_fast",
  "ImageList": ["assets/{project}/character_sheet.png"],
  "VideoList": ["assets/{project}/song_segment_01.mp4"],
  "Duration": 15,
  "Prompt": "使用@视频1中的音频驱动@图片1中的主角生成MV，{场景/着装/氛围描述}。口型严格同步: \"{该段歌词原文}\"。禁止生成BGM，保持无字幕。"
}
```

**关键规则**：
- VideoList 传入对应时间段的黑屏视频片段
- Duration 与黑屏视频时长**严格一致**
- 使用"音频驱动"句式：`使用@视频1中的音频驱动@图片1中的主角`
- Prompt 中必须附上该段歌词原文：`口型严格同步: "{歌词}"`
- 每段可指定不同的着装和背景，制造视觉变化
- "禁止生成BGM"归 `通用尾注`（多段），不逐段重复；单段写进 Prompt 末尾

## Prompt 模板

### 角色演唱段
```
使用@视频1中的音频驱动@图片1中的主角生成MV，
舞台中央聚光灯下，面对镜头深情演唱，
镜头从中景缓推至面部特写，暖金色调，{风格关键词}。
口型严格同步: "{该段歌词原文}"
五官清晰不变形，禁止生成BGM，保持无字幕。
时长：15秒，比例：16:9
```

### 角色演唱段（换装换景变体）
```
使用@视频1中的音频驱动@图片1中的主角生成有多个镜头的MV，
更换着装和背景，整体轻快活泼阳光的氛围。
口型严格同步: "{该段歌词原文}"
{风格关键词}。
禁止生成BGM，保持无字幕。
时长：15秒，比例：16:9
```

### 画面叙事段（配歌不唱）
```
参考@图片1的角色形象，场景参考@图片2。
角色独自走在雨后的街道上，脚步缓慢，低头沉思，
路灯倒影在湿润地面上拉出长长的影子。
镜头从脚步特写缓缓升起至全身侧影，冷青蓝色调。
{风格关键词}。
五官清晰不变形，禁止生成BGM，保持无字幕。
时长：12秒，比例：16:9
```

### 空镜/间奏段
```
场景参考@图片1。
空旷的海边，海浪缓缓拍打沙滩，远处天际线泛着晚霞光芒，
海鸥从画面边缘飞过。无人物。
镜头固定，海浪声，宁静壮阔氛围。
{风格关键词}。
禁止生成BGM，保持无字幕。
时长：10秒，比例：16:9
```
