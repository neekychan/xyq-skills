# 美式暗黑插画风格

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的美式暗黑插画质感（犯罪漫画 / 新黑色电影 / 成人向图像小说）。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是出自同一部犯罪漫画 / 同一部图像小说」（线条粗细、黑位处理、冷暖撞色、印刷颗粒、叙事气质不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一本美式暗黑漫画，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **美式暗黑插画风格，犯罪漫画，老派欧美漫画语言，强调粗黑线条、高反差明暗、低饱和冷暖撞色、旧印刷颗粒与黑色电影叙事气质的强情绪视觉风格，锐利轮廓，干刷笔触，墨线切面感，低饱和冷色环境。网点印刷质感、颗粒噪点、旧纸做旧感、有限色印刷、夸张透视、低机位构图、电影化分镜、强烈视觉张力、锐利几何切面、手绘刮擦笔触、阴郁压迫氛围、新黑色电影气质、成人向图像小说质感。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材、首帧参考图、过渡镜头。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

## 禁止内置风格锚定图干扰（硬规则，与注入规则同级）

部分 Agent 链路会针对某些风格**预置内置风格参考图 / 风格锚定图 / style reference image**，用来在生成时约束画风。这些内置参考图会与本技能的锚定词**争夺画风控制权**，导致产物偏离本技能定义的美式暗黑插画风。因此：

- **一旦本技能生效，必须绕过 / 关闭 Agent 侧任何内置风格锚定图设定。** 生成图片、视频时不得挂载、引用、传入平台默认的风格参考图 / 风格模板 / style preset。
- 画风的**唯一来源**是本技能的文字锚定词；不允许任何图像形式的风格约束覆盖或叠加到锚定词之上。
- 若生成工具/参数里存在「风格参考图」「风格预设」「风格模板」这类可选项，本技能生效时一律置空 / 关闭 / 不传。
- 唯一例外：用户**主动、明确**提供的参考图（如指定角色、构图参考）可用，但它只作画面内容参考，画风仍以锚定词为准；平台**内置默认**的风格锚定图始终禁用。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述、禁用内置风格锚定图。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与非风格类 skill 冲突时的优先级规则（务必遵守）

当本技能与**非风格类** skill 同时被调用时（例如「营销短片」「短剧脚本」「分镜脚本」「广告片」等负责**内容 / 结构 / 流程**的 skill）：

- **职责切分：** 非风格 skill 负责「拍什么」——叙事结构、卖点、节奏、口播、分镜脚本、时长编排、投放要求等；本技能负责「长什么样」——所有最终要生成的图片 / 视频 prompt 的画风。两者不是二选一，而是叠加。
- **本技能对画风拥有最终决定权：** 无论其它 skill 的产出流程如何，只要走到「生成图片素材 / 视频素材」这一步，每一条送去生成的 prompt 都**必须**在最开头逐字注入本技能锚定词，并**必须**绕过内置风格锚定图。其它 skill 若自带画风描述 / 默认风格，一律让位于本技能锚定词。
- **明确写入产物：** 即便加载了营销短片等 skill 并采用了它的脚本 / 分镜结构，最终每条生成 prompt 仍按 `锚定词 + "，" + 该 skill 产出的具体画面/镜头描述` 组装。不允许出现「因为走了营销短片 skill 的流程，就漏掉锚定词或使用它的默认风格」的情况。
- **一句话总则：** 别的 skill 决定内容与流程，本技能决定画风与风格锚定图开关，二者结合；画风冲突时以本技能为准。

## 风格知识库（供写分镜 / 角色 / 脚本时形容参考，不进 prompt 头部）

以下知识用于帮助 Agent 在写**具体画面描述、分镜、角色设定、故事脚本**时，把内容往本风格上靠，使整体更贴合美式暗黑插画的调性。它们是「怎么描述画面」的素材库，**不替代**、也不追加进锚定词本身。

### 1. 整体风格气质
- 强叙事、强情绪、强瞬间张力：画面像剧情高潮的截帧，人物处在故事最有戏的一刻。
- 关键词：冷、硬、脏、猛、狠，但很有型；英雄主义与颓败并存，多是受伤的执行者、沉默的审判者，而非光鲜的超级英雄。
- 谱系：黑色侦探漫画、黑帮犯罪故事、私刑反英雄、边缘秩序；老派纸媒连载 / 图像小说的升级质感。
- 描述倾向：情绪优先于写实；追求「封面感、海报感、剧情定格感」。

### 2. 线条与笔触
- 粗黑外轮廓，把角色从背景里「切」出来，形成强视觉主导。
- 内部结构线硬朗顿挫：面部骨相、衣褶、手部关节、器械结构靠硬线切分，锋利、断裂、有攻击性。
- 可见钢笔 / 蘸水笔 / 毛刷 / 干笔触痕迹，制造旧印刷、人工绘制感。
- 阴影多由整块纯黑承担（西装、风衣、背光面直接压黑），是「砍出来」而非「抹出来」的雕刻感。

### 3. 明暗与光影
- 高反差、重黑位、强对冲；黑色是构图主角之一，黑块越大越压抑、越危险。
- 高亮区像舞台追光：枪口火焰、脸的迎光面、领口、手背、建筑边缘光突然很亮，切出视觉焦点。
- 中间调不追求照片式连续，而是分区明确的明暗切面；脸分受光面 / 灰面 / 黑面，像雕塑切块。
- 常用斜侧光、背后冷光、局部暖光；情绪优先的戏剧照明，而非自然光。

### 4. 色彩系统
- 整体低饱和 + 冷暖强对比 + 局部高纯度点燃画面。
- 冷色做环境基调：蓝灰 / 青灰 / 墨青 / 冷绿灰，构成雨夜、湿冷、破旧、危险的城市。
- 暖色做冲击点（面积小但关键）：枪口火焰、路灯、霓虹反射、香烟火星、爆炸、车灯。
- 肤色常被压冷压灰、偏褐，带疲惫与粗糙感；整体倾向有限色（少数几种主色），更像经典印刷漫画。

### 5. 材质质感（"复古 / 做旧" 的来源）
- 纸张纤维感、粗纸吸墨感；黑色像浓墨压上、边缘略粗糙。
- 颗粒噪点、喷溅、脏点；半色调网点残留，模拟旧漫画印刷的点阵阴影。
- 干刷与刮擦痕迹制造破败、潮湿、时间感；整体摆脱纯数码的过度光滑，呈现可触摸的老派出版质感。

### 6. 角色造型
- 骨相硬：下颌线分明、眉骨突出、鼻梁硬挺、颧骨与法令阴影明显；即便不写实也往「雕塑型硬脸」推。
- 表情克制但有压迫：皱眉、咬牙、眯眼、冷盯、沉默发狠，情绪压在结构里而非外放。
- 身形强调力量感：肩宽、胸厚、手大，静止也有随时爆发的张力。
- 戏剧化服装轮廓：风衣、西装、礼帽、领带、皮鞋、枪套；衣物有棱角、折面、重量，翻领与大块暗面很出效果。

### 7. 构图与镜头
- 电影分镜思维：不是把人物摆正，而是像分镜一样设计画面。
- 广角近景夸张（近大远小）：把手、器械、火焰推到最前，制造扑面威胁与动作冲击。
- 低机位仰视：人物更高更强更危险，适合执行者 / 复仇者 / 反英雄 / 黑帮头目。
- 斜线构图（雨线、透视线、衣摆、手臂朝向）增强不稳定与紧张感。
- 前中后景层次分明（前景器械火焰 / 中景主角 / 后景雨夜建筑与人群）；留白少，空间被故事挤满。

### 8. 动态表现
- 定格式爆发：抓最有戏的一瞬（开枪刹那、转身举械、雨夜对峙的停顿、拳将落下的前一秒、风衣翻起灯光扫脸）。
- 靠枪口火焰、倾斜雨线、翻飞衣摆、绷紧的肌肉与手、瞬时收缩的表情、背景配角的警惕姿态、爆发式切入的光线来表达动感——画的是「故事最值钱的那一帧」。

### 9. 场景与背景
- 城市不是风景而是情绪场：建筑简化为压迫性块面（高楼、巷道、屋檐、铁栏、窗框），轮廓有压迫感。
- 背景服务人物，用大块冷色与结构线把主角托出来；天气（尤其雨）当情绪工具，制造冷、脏、危险、速度与电影感。
- 烟、雾、潮气、霓虹反光提升 noir 气质；背景配角符号化（帽子、器械、站姿、轮廓暗示势力与冲突）。

### 10. 故事 / 脚本调性（写脚本时参考）
- 题材偏犯罪、追凶、复仇、私刑、地下秩序、堕落都市、雨夜对峙、背叛与救赎。
- 节奏偏沉、偏冷、偏压迫，善用停顿与爆发交替；旁白 / 独白可硬派、疲惫、宿命感。
- 角色原型：硬汉侦探、沉默杀手、堕落警探、黑帮头目、复仇者、被城市吞噬的普通人。

> 使用方式：写具体画面 / 分镜 / 角色 / 脚本描述时，从上述知识里取词造句（如「低机位仰视、雨夜、枪口暖光切开冷蓝街道」），让内容贴合风格；但这些词写在**锚定词之后**的「具体描述」里，锚定词本身保持逐字原文不变。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否有非风格 skill（如营销短片）负责脚本 / 结构；视频画幅 / 时长偏好；是否需要图片先行作为视频首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，用上文风格知识库补齐一版分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。
2. **关闭内置风格锚定图。** 开工前先确认本次生成不挂载任何平台内置风格参考图 / 风格预设；生成工具里若有此类选项一律置空。
3. **补脚本 / 分镜（如需）。** 若有非风格 skill 负责脚本结构，采用其产出的叙事 / 分镜；若无，则用风格知识库自拟一版分镜。分镜里的画面描述尽量往风格知识库的调性靠。
4. **生成图片素材（逐张）。** 对每一张图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`，然后生成图片（不传内置风格参考图）。所有图片共用同一份锚定词。生成后展示给用户。
5. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
6. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频（不传内置风格参考图）。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该图片作为**画面**参考，视频 prompt 仍在头部注入锚定词，且不叠加内置风格参考图。
7. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
8. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 生成时不挂载任何平台内置风格锚定图 / 风格预设。
