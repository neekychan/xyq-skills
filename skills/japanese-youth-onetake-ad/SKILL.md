# 日系青春一镜到底产品歌舞广告 Skill（Seedance 2.5 版）

## 目标

当用户提供产品图片，希望生成一支具有**日系青春校园感、清爽运动饮料广告气质、一镜到底、歌舞群舞、最后露出产品**的视频时，使用本 Skill 输出**Seedance 2.5 可直接执行的中文成品 Prompt**。

本 Skill 不只是写普通文生视频提示词，而是按 Seedance 2.5 的多模态能力组织任务：

- 图生视频 / 产品图参考生成
- 多图参考与素材职责分工
- 主体一致性控制
- 群像与主角优先级控制
- 动作、舞蹈、风、碎片等动态控制
- 一镜到底镜头运动控制
- 首尾状态控制
- 成片结构与节奏控制

核心风格不是照搬某个现成品牌或导演，而是提炼：**日本青春电影感、夏日校园、清爽运动饮料广告气质、过曝逆光、风、汗水、群舞、奔跑、胶片颗粒、青绿色阴影、暖白高光、真实人物质感**。

## 触发场景

使用本 Skill 的典型请求包括：

- 用户上传产品图，说“帮我生成一个 Seedance 2.5 日系青春广告片 prompt”。
- 用户说“宝矿力水特风格”“日本运动饮料广告感”“日系校园歌舞广告”。
- 用户希望“产品最后才露出”“一镜到底”“很多人齐舞”“风吹花瓣/碎片”。
- 用户要求图生视频、多图参考、AI 视频、视频生成、广告片 prompt、产品广告片提示词。
- 用户只给产品图，但表达想做清爽、校园、青春、群舞、日系电影感广告。
- 用户要求“Seedance 2.5”“一键成片”“用产品图片做广告短片”。

不适用于：纯平面海报、普通产品图精修、品牌 Logo 设计、非视频提示词需求。

## Seedance 2.5 任务判断

默认将本需求判断为：

- **任务类型**：图生视频 / 产品图参考生成 / 成片型广告 Prompt
- **主控制轴**：成片结构 + 镜头运动 + 动作节奏
- **次控制轴**：产品配色转译 + 主角主体一致性 + 群像调度
- **核心执行目标**：用产品图作为片尾产品与全片配色锚点，默认生成一条 **30 秒**连续镜头的日系青春校园歌舞广告片。

如果用户上传多张素材，应主动建立素材职责：

- 图1：默认作为产品外观、包装颜色、材质、片尾露出参考。
- 图2：如有人物，作为主角形象参考。
- 图3：如有场景，作为校园/光线/构图氛围参考。
- 视频1：如有舞蹈或动作，作为动作节奏参考。
- 视频2：如有运镜，作为一镜到底镜头运动参考。
- 音频1：如有音乐，作为慢-快-慢-快-停的节奏参考。

遵循**一个素材负责一个主任务**，不要把所有素材混成含糊的“参考这些图”。

## 工作流

### 1. 先做素材职责分工

如果用户提供图片、视频或音频，先简短说明每个素材的用途。

示例：

```markdown
## 素材职责分工
- 图1：产品外观、包装配色、材质和片尾露出参考。
- 图2：主角长相与服装参考。
- 视频1：舞蹈动作节奏参考。
```

如果用户只提供一张产品图，则默认：

- 图1 = 产品外观 + 包装配色 + 材质 + 片尾产品露出参考。
- 不把产品图误用为人物或场景参考。

### 2. 分析产品图

如果用户提供产品图片，先做简短但有导演转译价值的分析：

- **主色**：提取 2–4 个最重要颜色，如天蓝、白、柠檬黄、银灰、薄荷绿。
- **辅助色**：可用于服装、花瓣/碎片、环境光、操场线条、旗帜、窗帘的颜色。
- **材质感**：塑料瓶、金属罐、纸盒、玻璃、磨砂、透明、反光、冷凝水等。
- **情绪关键词**：清爽、酸甜、能量、夏天、轻盈、微苦、透明感、运动后补水感。
- **视觉转译**：说明这些颜色如何进入天空、制服、道具、碎片、花瓣、窗帘、运动场线条、片尾光线。

如果无法直接看到图片或图片信息不足，要求用户补充图片或描述主色/包装形态；如果用户要求直接生成，可基于用户文字描述做假设并标注“基于描述生成”。

### 3. 确认主角形象与主体一致性

如果用户没有提供主角形象，先给出默认方案并请用户确认：

> 默认主角：一位日系短发女生，17–20 岁，清爽短发，白色短袖衬衫或浅色运动校服，干净真实的皮肤质感，略带倔强和自由感，青春但不甜腻。

询问用户是否采用默认主角，或是否要换成：

- 男生主角
- 双主角
- 群像无固定主角
- 使用用户上传的人物图作为主角

如果用户已明确“直接生成”，可以在输出中写：

> 主角形象：默认日系短发女生；如需更稳定的人物一致性，建议补充 1–3 张主角参考图。

Seedance 2.5 主体一致性写法必须包含：

- 主角发型、年龄感、脸型气质、服装轮廓。
- 主角在全片连续出镜，不漂移、不换脸、不变装。
- 群像可以动态变化，但镜头优先识别主角。
- 多人齐舞时，主角位于视觉中心或运动引导位。

### 4. 输出 Seedance 2.5 成品 Prompt

输出应包含以下模块：

1. **任务类型与主控制轴**
2. **素材职责分工**
3. **产品配色分析**
4. **主角形象与一致性设定**
5. **Seedance 2.5 成品 Prompt**
6. **节奏结构：慢-快-慢-快-停**
7. **镜头 / 动作 / 群像调度重点**
8. **首尾约束**
9. **负面约束**
10. **可选参数建议**

除非用户明确指定其他时长，所有生成视频 Prompt 默认按 **30 秒**设计，并在成品 Prompt 中写明“时长约30秒”。

## 成片核心要求

### 一镜到底

完整 Prompt 必须明确：

- 全片是一条连续镜头，不切镜，不黑场，不硬转场。
- 可以使用自然遮挡完成空间转换，例如人群擦肩、校服衣角掠过镜头、花瓣/纸片遮满画面、主角转身、窗帘掀起、阳光炫光吞没画面。
- 镜头从特写、近景、旋转跟拍、穿越人群到大全景，再回到产品特写，形成连续流动感。
- 一镜到底不是分镜拼贴，不能写成互不连续的镜头列表。

### 日系青春校园感

场景优先选择：

- 日本夏日校园
- 操场
- 天台
- 体育馆走廊
- 教室窗边
- 海边坡道
- 河堤
- 自动贩卖机旁
- 旧校舍外墙

画面要求：

- 真实、自然、青春、清爽，避免过度奇幻、过度商业棚拍、过度 MV 化。
- 朦胧柔焦之外仍保留皮肤、发丝、汗水、校服布料和动作的真实细节。
- 人物真实可感，不要塑料皮肤，不要全部糊成光斑。

### 歌舞与群像

必须包含：

- 很多人出现，形成青春群像。
- 10–30 人参与齐舞或队形扩散。
- 主角的小动作引发群体同步动作。
- 舞蹈动作自然、轻快、可真实完成，不要机械、夸张、偶像舞台化。
- 动作可以包括奔跑、跳跃、转身、甩手、队形扩散、操场线条上的同步步伐。

Seedance 2.5 群像写法要特别强调：

- 主角优先，群像服务主角和节奏。
- 群演不需要每个人都清晰正脸，避免多人脸崩坏。
- 群演应有自然微动、呼吸感、衣摆和头发被风带动。
- 齐舞动作整体同步，但个人动作有轻微真实差异。

### 风与碎片/花瓣

必须包含：

- 强风，风是叙事动力、节奏动力和自然转场动力。
- 大量碎片、花瓣、彩色纸片、轻薄包装色纸、窗帘、校服衣摆、头发被风掀起。
- 碎片/花瓣颜色呼应产品配色，而不是随机彩色。
- 纸片/花瓣可以在关键时刻遮满画面，帮助一镜到底完成空间转移。

### 产品露出策略

必须明确：

- 前中段不要正面露出产品，不要过早出现包装特写。
- 产品色彩先通过环境、服装、花瓣、纸片、光线暗示。
- 片尾“停”的瞬间才出现产品：主角或群像停在逆光中，镜头自然落到产品上。
- 产品包装清晰、完整、稳定，但不过度硬广。
- 不生成额外文字、字幕、口播 slogan、品牌 Logo 替换或屏幕文字。产品图本身已有包装文字时，只保持产品图原貌，不新增文字。

## 影像风格

### 光影

使用日本青春电影式光影描写：

- 过曝逆光，人物轮廓轻微模糊，让穿透炫光成为画面主角。
- 自然光、窗边光、夏日操场反光、走廊尽头白色高光。
- 冷暖色调分离：阴影偏青绿/蓝绿，高光偏暖白/淡金。
- 35mm film grain、MiniDV texture、soft focus、dreamlike haze、washed-out colors。
- 保持真实，不要过度磨皮、塑料质感或 AI 过饱和。

### 摄影机与质感

可以写入：

- handheld camera，全程手持摄影，轻微呼吸感和步伐晃动。
- Fuji film color science、Japanese cinema lens、自然颗粒、轻微高光溢出。
- 特写、极近特写、旋转运镜、跟拍、穿越人群、大全景、低角度仰拍、逆光剪影。
- 镜头需要动态足，但不是炫技；摄影机像跟着主角奔跑、喘息、转身。

风格锚点可以使用：

- 日本青春电影气质
- 岩井俊二式诗意青春氛围
- All About Lily Chou-Chou 式青绿色怀旧情绪
- 清爽运动饮料广告的夏日透明感

避免写“完全模仿/复制某导演或某品牌广告”。

## 节奏结构：慢-快-慢-快-停

Prompt 中必须明确体现节奏曲线：

1. **慢**：产品配色转译出的校园空间，主角静止或缓慢抬头，风刚开始，环境安静。
2. **快**：主角突然奔跑，镜头手持跟拍穿过走廊/操场，人群加入，碎片暴起。
3. **慢**：旋转近景，柔焦逆光，人物与花瓣短暂停滞，情绪变得诗意。
4. **快**：群舞高潮，大全景，几十人齐舞，镜头绕行、后退、穿越队形，风和纸片铺满空间。
5. **停**：所有动作突然停住，只留下风声、呼吸和光线，镜头落到产品，产品最后才清晰露出。

## 首尾约束

Seedance 2.5 成片 Prompt 应加入明确首尾状态：

### 开头

- 不要产品正面特写。
- 从产品配色转译出的环境或人物细节开始，如窗边逆光、校服衣角、主角发丝、操场白线、被风掀起的窗帘。
- 产品可以只以颜色暗示，不出现完整包装。

### 结尾

- 动作突然停住，形成广告记忆点。
- 镜头自然落到产品，产品来自用户提供的产品图。
- 产品包装清晰、完整、稳定，处在自然逆光中。
- 不新增字幕、口号、Logo、水印。

## Seedance 2.5 成品 Prompt 写法规则

完整 Prompt 应使用中文为主，可以夹带少量英文风格词作为视觉锚点。保持成品级、可直接投喂 Seedance 2.5。

必须包含：

- “图1作为产品外观、包装配色、材质和片尾产品露出参考”。
- “全片一镜到底、无剪切、无黑场、无硬转场”。
- “产品只在最后清晰露出”。
- “慢-快-慢-快-停”。
- “日系青春校园、夏日、过曝逆光、青绿色阴影、暖白高光、35mm grain、MiniDV texture、soft focus”。
- “全程手持摄影、特写、旋转运镜、大全景、穿越人群”。
- “很多人、主角优先、齐舞、强风、铺天盖地花瓣/碎片/纸片”。
- “碎片/花瓣/服装/环境色呼应产品配色”。
- “人物质感真实，保留皮肤、发丝、布料、汗水细节”。
- “主角主体一致，不换脸、不漂移、不突然变装”。

## 负面约束规则

每次输出都要加入负面约束，避免模型跑偏：

- 不要字幕、不要屏幕文字、不要额外 Logo、不要水印。
- 不要提前露出产品正面，不要硬广货架展示。
- 不要剪切、不要跳切、不要分镜拼贴、不要黑场。
- 不要过度棚拍、不要赛博朋克、不要欧美高中感、不要偶像舞台 MV。
- 不要机械舞蹈、不要漂浮肢体、不要多人脸崩坏。
- 不要主角换脸、不要年龄漂移、不要服装突然变化。
- 不要过饱和、不要塑料皮肤、不要丢失人物质感。
- 不要新增包装文字、不要改写产品包装文字。

## 质量检查清单

输出前自查：

- 是否明确按 Seedance 2.5 处理，而不是普通文生视频？
- 是否判断了任务类型与主控制轴？
- 是否做了素材职责分工？
- 是否先分析了产品配色与材质？
- 是否处理了主角形象确认？
- 是否写了主体一致性要求？
- 是否明确“产品只在最后露出”？
- 是否是一镜到底而不是分镜列表？
- 是否有慢-快-慢-快-停？
