# 流派 01: 舞台唱演 (Stage Performance)

* **适用曲风**：流行唱将、摇滚乐队、Live 现场、Solo 舞台、燃系单曲
* **视听公式**：`[MCU 唱演与眼神聚焦] + [追光/光束阵列/频闪] + [360度高速环绕/冲撞变焦] + [冷焰火/逆光高亮]`
* **表演配比**：40%~50% MCU 歌手高光唱演 + 50%~60% 舞台光效/乐手/空镜，精准口型对嘴，展现歌手面部魅力与舞台爆发力。

---

## 一、正交积木库

* **起手式**：`微距眼眸特写随贝斯重音睁开` / `低机位仰拍主唱手持麦克风向前踏出大步` / `背光剪影中主唱缓缓抬头`
* **动作与唱演**：`主唱全程演唱，情绪激昂，右手随旋律挥舞` / `吉他手与贝斯手在侧方激烈扫弦对扫` / `双手紧握复古立杆麦克风微颤`
* **光影与材质**：`背后数十道金色舞台光束穿透体积冷雾` / `舞台边缘冷烟火喷涌产生金橙色光晕` / `强频闪光勾勒面部轮廓`
* **爆发与收尾**：`冲撞变焦至面部特写在 Drop 最后一拍瞬间定格` / `全场灯光骤暗仅留单道冷白顶光照耀主唱`

---

## 二、语法示范（15 秒 4 阶段高能唱演）

```text
@图片1 的人物作为唯一主唱，严格锁定五官、发型、妆容与黑色做旧皮夹克服装。@视频1 提供全段唯一背景音乐与节拍时间轴，不提供画面。画面动作与唱演口型必须严格跟随 @视频1 的音频作为 BGM，不擅自编曲，严禁生成任何与 @视频1 无关的背景音乐。

35mm变形宽银幕电影胶片质感，24mm广角大透视镜头，舞台硬核金色追光与频闪光束，青橙色调 (Teal & Orange) 强明暗反差，180度标准电影快门自然运动模糊。摇滚主唱在圆形镜面舞台中心展开高能唱演。

严格跟随 @视频1 的音频作为 BGM，不擅自编曲。主唱全程在唱，精准咬字口型：{我们在风暴中央点燃火光}。

第0-3秒 (中近景起手与光束齐爆)：圆形镜面舞台，黑色高反光地面。中近景仰拍，主唱向前踏出大步，背后数十道金色舞台光束穿透体积冷雾瞬间亮起，舞台边缘冷烟火喷涌，主唱眼神锁定镜头高亢演唱。
第3-7秒 (360度环绕与光影变幻)：随副歌第一声重鼓，镜头以主唱为圆心进行360度顺时针高速环绕，背景甩成金色与青色流光色环，主唱展开右臂仰头高歌，强频闪光勾勒轮廓。
第7-11秒 (Crash Zoom 眼神极特写)：全场背景瞬间骤暗为纯黑虚空，仅留单道冷白顶光照射，突发冲撞变焦(Crash Zoom)至主唱眼神极特写，主唱后仰高音呐喊，汗水飞溅清晰可见。
第11-15秒 (广角全景与定点收束)：广角全景展示整个暗黑镜面舞台与顶部环形灯架，主唱右手将麦克风稳稳立于地面定格，镜头缓缓垂直向上拉开，冷焰火余韵渐弱。

保持无字幕，不要生成水印/logo，人物五官与肢体稳定不变形，全片不要在同一画面中复制相同主角人物，严格以@视频1中的音频作为全片唯一背景音乐，严禁生成任何与@视频1无关的背景音乐或杂乱音轨。
```
