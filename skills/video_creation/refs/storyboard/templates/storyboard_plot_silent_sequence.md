# 分镜图模板：剧情叙事 · 纯画面连续分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以完全无台词/无字幕/无文字说明的纯画面连续分镜讲故事，通过角色动作、构图、光影和镜头衔接传达情绪与叙事，贴近默片、情绪短片和氛围叙事。
- **典型场景**：
  - 情绪氛围短片：某人独自行走街头，通过环境和表情呈现孤独/治愈。
  - 默片式故事：通过夸张肢体动作和表情变化推进情节，不依赖对白。
  - 无人声项目：仅配乐，用画面连续性和视觉节奏对齐音乐节奏。
  - 品牌情绪片：无解说、无硬广，只用意象和生活片段构建品牌气质。

## 2. 判定关键词与适用边界
- **典型触发词**：`纯画面`、`无台词`、`无字幕`、`默片`、`氛围叙事`、`只用画面讲故事`、`视觉叙事`、`情绪短片`。
- **适用判定**：
  - 用户明确表示“不需要对话/旁白/字幕”“想要全程靠画面和配乐表达故事或情绪”；
  - 对角色肢体语言、环境变化、镜头运动有较高要求，希望通过连续镜头制造情绪波动而非台词推进；
  - 适合需要多平台兼容的静音内容：即使关闭声音，依然能理解情绪和大致故事。
- **不适用场景**：
  - 用户重点在台词、金句、文案呈现 → 更适合“剧情脚本文字板”“台词驱动分镜”等模板；
  - 复杂对话、信息量很大的教学/产品讲解 → 需要文本辅助，优先教学/产品类模板；
  - 需要精确对口型、逐句字幕的 MV → 优先歌词类/对口型类 MV 分镜模板。

## 3. 分镜结构建议
- **推荐宫格数**：8/12/16 宫格，以“连续时间线”或“情绪曲线”组织，避免单格信息过多。
- **规划方式**：
  - 先确定**情绪曲线**：起始状态 → 情绪加深 → 高潮或转折 → 余韵/收束；
  - 再按时间线或空间动线拆格，每格承担一个明确的“视觉事件”：
    - 环境变化：光线/天气/空间从 A 到 B；
    - 角色动作：起身→走向某处→停下→回望等；
    - 物件细节：手、眼睛、道具、细微动作的特写；
  - 景别节奏建议：
    - 起始：1–2 格使用远景/中景建立环境与角色位置；
    - 中段：多用近景/特写观察表情和动作细节，增强情绪共鸣；
    - 高潮/转折：采用运动镜头（推拉/摇移）或构图强对比，制造视觉冲击；
    - 尾声：回到环境或留白构图，为情绪留出空间。
- **连贯性要求**：
  - 相邻格之间应当存在明确的**动作衔接**或**视线延续**，避免跳切到完全陌生场景；
  - 同一角色在连续镜头中的服饰、发型、光线方向保持统一；光影变化需有合理的时间/空间逻辑。

## 4. 生图 Prompt（PE）模板

```text
你是一名擅长默片与情绪短片的剧情分镜导演，请根据下述信息设计一张 {宫格数} 宫格的“纯画面连续分镜”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏情绪短片”或“16:9 横版默片片段”}。全程禁止输出台词气泡、字幕条或任何文字说明，只用画面讲故事。

【故事与情绪信息】
- 故事题材与基调：{如“深夜便利店治愈短片/雨中告别/清晨独行”等}
- 主角设定：{姓名或标签 + 外观 + 年龄 + 气质，如“短发女孩，20 岁，略带倦感但内心温柔”}
- 关键场景：{主要空间，如“便利店室内/街角/公交站”等}
- 情绪关键词：{如“孤独/治愈/释怀/紧张/压抑/期待”等}
- 故事梗概：{50–120 字概述起点、过程、结尾，不写台词内容，只写发生的事和情绪变化}

【视觉叙事目标】
1. 明确故事情绪曲线：{简述起始/发展/高潮/收束四段情绪走向}。
2. 仅依靠角色表情与动作、构图与光影、环境变化来传达故事与情绪。
3. 全程不出现任何可读文字：不画字幕、不画台词气泡、不画说明文本。

【宫格规划与编号】
- 宫格数：{宫格数，如 8/12/16}，按阅读顺序编号 S1–S{N}。
- 推荐结构：
  - S1–S2：建立环境与主角起始状态（远景/中景为主）；
  - S3–S{中段}：通过动作与细节特写推进情绪与事件（中景/近景/特写混合）；
  - S{高潮前一格}–S{高潮格}：情绪或事件高潮，用明显的构图变化或运动镜头呈现；
  - S{尾声开始}–S{N}：情绪收束与余韵，可回到环境或使用留白画面。
- 需要在规划中说明每格所处的时间段（如“清晨/夜晚”“几分钟后”“同一晚晚些时候”）以保证时间连贯。

【分镜输出格式】
请为 S1–S{N} 逐格输出以下字段的中文描述：

- 宫格编号：{如 S1}
- 时间与场景：{当下时间点 + 所在空间，如“深夜便利店室内”“雨中的公交站牌”}
- 景别与构图：{远景/中景/近景/特写 + 构图要点，如“角色居中偏右，背景灯牌虚化”}
- 角色与动作：{出现角色数量、位置与具体动作，如“女孩靠在玻璃窗边，用指尖描摹水滴”}
- 表情与情绪：{面部表情与情绪关键词，如“眼神略显疲惫，但嘴角有轻微笑意，情绪逐渐被治愈”}
- 光影与色彩：{主光源位置、明暗对比、色调，如“便利店暖黄灯光从室内打出，街道偏冷蓝，形成冷暖对比”}
- 镜头衔接：{上一格到此格的过渡方式，如“镜头缓慢推近女孩脸部”“切到女孩视角看街道灯光”等}

【画幅与风格要求】
- 画面比例：{9:16 / 16:9}，默认推荐 9:16 竖屏用于情绪短视频。
- 画风：{如“写实胶片感/3D 电影感/2D 动漫/插画风”等}，整张分镜图保持统一画风。
- 色调与氛围：{主色调与氛围，如“冷蓝+橙光，略带孤独但温暖结尾”“低饱和灰色，压抑到最后一点亮光”等}。

【特别限制】
- 不画任何文字元素（包括字幕条、说明框、广告文案、对话文本）。
- 如需要表现信息，请通过物件细节（手机屏幕上模糊的界面、通知图标等）、角色行为与环境变化隐喻完成，而不是文字。
```

## 5. 一致性与避坑
- 保证角色外观与服饰在整张分镜图的所有格中保持高度一致，仅允许小幅度姿态和表情变化。
- 保证光源方向与主要道具位置在同一场景的不同格之间前后一致，仅改变摄像机视角。
- 避免每格都给出全新场景或完全不同角色，导致故事支离破碎；应以几处核心场景为骨架，通过视角变化补充细节。
- 避免在画面内偷偷放入可读文字（大段招牌文案、手机消息内容等）成为主要信息来源，让视觉叙事退化为文字说明。
- 避免情绪曲线过于平铺：至少设置 1–2 个情绪波峰或转折点，并通过构图与光影明显标出。
- 对时间跳跃要有视觉依据（光线变化、服饰差异、环境改变），不要无提示地跨越长时间段。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“剧情叙事类”执行模板：
  - 分镜阶段完成“情绪曲线 + 纯画面动作线”的设计，为每格明确时间、场景、动作与镜头衔接；
  - 视频阶段以分镜图关键格为参考帧，在执行模板中关闭台词/字幕相关字段，强调配乐节奏与画面连续性；
  - 在生成 Prompt 中重点描述“镜头运动方式”“动作衔接”“光影渐变”，让模型优先还原视觉连贯性而非语言信息。
- 可搭配 `creative/narrative-arc.md` 中的情绪/叙事弧线建议，先用文字确定起承转合与情绪波动，再落到纯画面分镜上。
- 可搭配 `storyboard/prompt-craft.md` 优化每格的描述密度与镜头语言用词，避免分镜说明过于口语化或含糊。
- 当项目为系列情绪短片或默片合集时，建议配合 `assets/character-lock.md` 先锁定主角外观与常规动作习惯，在不同视频间保持角色识别度。
