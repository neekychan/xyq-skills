# 分镜图模板：影视级运镜型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：明确写出景别/机位/运镜方式的一类 storyboard，接近导演分镜表，用于指导复杂镜头调度和光影设计。
- **典型场景**：电影质感短片、广告 TVC、长镜头走位设计、悬疑/恐怖场景的运镜规划等。

## 2. 判定关键词
- 典型触发词：`运镜`、`机位`、`镜头语言`、`导演视角`、`调度`、`一镜到底`、`走位`、`景别`、`推拉摇移`。
- 当需求中出现“想设计镜头语言/运镜”“需要导演级分镜表”时，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：8–20 镜，按场景复杂度拆分；可采用表格形式，一镜一行。
- **结构骨架**：
  1. 建立场景（2–3 镜）：远景/全景，交代空间结构与人物站位。
  2. 情节推进（若干镜）：中景/近景为主，交替切换人物视角与环境细节。
  3. 高潮段落（2–4 镜）：多用运动镜头与特写，强化情绪爆发。
  4. 收束/转场（1–2 镜）：镜头语言回归平稳或通过特殊运镜进入下一场。
- **画面特征**：强调景别、机位高度、运镜方向与速度，对光源与阴影有明确描述。

## 4. 生图 Prompt（PE）模板

```text
你是一名电影分镜师，请根据下述片段说明生成一份影视级运镜分镜图/分镜表，整体画幅为 {画幅比例说明，如“16:9 横版电影画幅”或“9:16 竖屏电影感短片”}。

【片段信息】
- 类型与风格：{如“室内悬疑对话/ICU 病房亲情/公交亭恐怖”}
- 时长：约 {总时长秒数} 秒，预计 {镜头数} 个镜头。
- 故事要点：{简述开端-冲突-高潮-结尾}。

【画面风格】
- 画风：{如“写实电影摄影 / 电影级 3D 渲染”}
- 色彩与光影：{主色调 + 光源方向 + 对比度}。

【主体与场景】
- 主要角色：{姓名+外观+情绪基调}。
- 场景：{空间结构说明，如“窄长走廊 / 开放式客厅 / 夜间街道”等}。

【输出要求（表格式）】
- 按镜头编号 S1–S{N} 输出，每行包含：
  - 景别（远景/全景/中景/近景/特写）
  - 机位（高/平/低/主观视角等）
  - 运镜（推/拉/摇/移/跟/固定/一镜到底等）
  - 动作与情绪（人物行为、重要表情或台词）
  - 光影与时间（光源方向、亮度、色温、时间段）
- 在说明中可提示空间连贯性（如“遵守 180 度规则，机位始终在人物 A 右侧”）。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏，3 表示 16:9 横版，0 表示跟随参考图}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「剧情叙事类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 长镜头/一镜到底在分镜表中拆清关键节点（起点/中段/高潮/落点），视频生成按「多个连续镜头」实现近似效果。
