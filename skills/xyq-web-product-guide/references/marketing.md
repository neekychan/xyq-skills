# 营销 Agent

来源：[主手册](https://bytedance.larkoffice.com/wiki/PxZgwJwxti0dutk6WIdcwRA6nTd)。

## 快速上手

1. 首页 Agent 类型选择【营销 Agent】，或打开[营销 Agent](https://xyq.jianying.com/marketing-agent)。
2. 点击【+】上传商品图、素材或参考内容，也可用 `@` 引用已有资产。
3. 描述商品、核心卖点、目标人群、投放平台与视频时长。
4. 没有方向时浏览首页 Showcase 或创意库；有想法可直接描述。创意、Hook、风格均可选一个、多个或全部不选，由 Agent 自动补全。
5. 按需求设置模型、比例与画布，提交生成。结果可进入画布继续引用、编辑、组合、预览和导出。

示例输入：为便携榨汁杯做一条 15 秒抖音种草视频，卖点是便携防漏，面向通勤和健身人群，节奏轻快。示例商品信息须由用户核实。

## 各功能的作用

| 功能 | 用途与操作 |
| --- | --- |
| Showcase | 首页“探索营销能力”展示案例，预览后点击“使用”或“复刻”作为起点。 |
| 创意库 | 按营销场景浏览、搜索、预览，确定广告的内容结构和表达方式。 |
| Hook 库 | 选择视觉、结构、口播、声音等开场方式，设计前 3 秒。 |
| 风格库 | 选择全片视觉语言，统一色彩、光线、场景及人物气质。 |
| 画布 | 管理图片与视频，裁剪、旋转、超分，在会话中引用并继续生成，组合、预览和导出。 |

## 营销专项 Skill

- 视频翻译：上传原片，提出多语种与人物本土化需求。主手册推荐 Seedance 2.5；图片模型建议 Seedream 5.0 或旗舰生图模型 V2-Pro。
- 素材裂变：导入参考视频和商品信息，拆解原片创意，结合不同卖点、人群和场景生成差异化素材。
- 批量生成：上传商品图，按多个卖点和场景生成多条视频素材。
- 生意增长分析：主手册提及可按需调用，但没有写数据接入、支持平台和具体分析步骤。详细咨询使用未命中提示并给出主手册链接，不能补写接入方法。

以上为宿主营销 Agent 可调用的能力介绍，不是本产品问答 Skill 的工具接口；不编造专项 Skill 的内部名称、参数或按钮位置。
