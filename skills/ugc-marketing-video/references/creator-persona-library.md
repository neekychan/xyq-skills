# 达人形象丰富度库 / Creator Persona Library

Use this reference before calling `sandbox_generate_image` and before writing the script. The goal is to create a richer, product-matched creator who can support believable UGC sales content, rather than a generic "网红脸".

## Persona Selection Rule

Choose one primary creator persona from product category, buyer, price tier, platform, and proof scene. Bind the creator with 6 stable traits:

1. 年龄段 / age band
2. 角色身份 / creator role
3. 外观线索 / face, hair, body, outfit, grooming
4. 生活场景 / environment
5. 商品关系 / why this person uses or recommends the product
6. 口吻气质 / speaking style and trust texture

The generated portrait prompt and the video script must reuse the same persona. Do not make the portrait a beauty/fashion creator and then write the script as a parent, store staff, gamer, or office worker unless the user asks for a role change.

## Core Domestic UGC Personas

### 1. 实用型通勤女生

Best for: 日用品、包袋、通勤服饰、小家电、手机配件、饮品、轻食、App 工具。

- 年龄段: 24-32
- 外观: 清爽妆容、自然直发或低马尾、简洁上衣、托特包/手机/水杯等通勤道具
- 场景: 玄关、电梯口、办公桌、地铁站外、车内
- 信任感: 像同事朋友推荐，表达直接，节奏利落
- 口播质感: "我最近上班一直带这个"，"这个点真的省事"
- 适合证明: 容量、便携、快速、耐用、收纳、使用频率

### 2. 真实宝妈/家庭照顾者

Best for: 母婴、童装、儿童用品、食品、清洁、家居、家庭服务、教育产品。

- 年龄段: 28-40
- 外观: 低饱和家居穿搭、自然发型、轻妆或素颜感、温和但不精致过度
- 场景: 客厅、儿童房、餐桌、洗衣区、厨房、楼下小区
- 信任感: 实测、耐心、会关注安全和省心
- 口播质感: "家里有娃真的会在意这个"，"我自己试过才敢放家里"
- 适合证明: 安全、舒适、易清洁、省心、性价比、孩子/家人反应

### 3. 美妆护肤测评朋友

Best for: 护肤、美妆、香氛、个护、美容仪、洗护。

- 年龄段: 22-35
- 外观: 真实皮肤纹理、干净妆面、发丝自然、浴室镜前/梳妆台环境
- 场景: 梳妆台、浴室镜、窗边、卧室化妆区
- 信任感: 近距离试用、质地展示、结果克制
- 口播质感: "我先给你看质地"，"上脸这个感觉很明显"
- 适合证明: 质地、肤感、妆效、香味、使用步骤、前后状态

### 4. 男性实测/数码桌搭达人

Best for: 3C、数码配件、游戏、车品、运动户外、工具、家电。

- 年龄段: 24-38
- 外观: 干净短发、T 恤/卫衣/衬衫、桌搭或车内道具
- 场景: 电脑桌、车内、客厅、健身房、户外场地
- 信任感: 讲结果、讲效率、讲参数但要落回体验
- 口播质感: "这个我直接实测给你看"，"重点是它这个反应很快"
- 适合证明: 速度、稳定、兼容、耐用、安装、操作流程

### 5. 小红书生活方式种草达人

Best for: 家居、香氛、服饰、咖啡饮品、旅行、礼物、轻奢、小众设计。

- 年龄段: 23-34
- 外观: 干净穿搭、生活方式道具、自然光、画面有审美但仍像手机拍摄
- 场景: 家中窗边、咖啡店、衣帽间、旅行桌面、礼物包装区
- 信任感: 体验感、氛围感、细节审美
- 口播质感: "这个是我最近很喜欢的一个小东西"，"它不是那种很夸张的好看"
- 适合证明: 质感、搭配、氛围、礼物感、使用场景、细节

### 6. 快手实在型生活用户

Best for: 食品、农特产、家清、服饰、家电、低客单日用品、性价比商品。

- 年龄段: 30-48
- 外观: 朴素生活穿搭、真实厨房/客厅/货架环境、表情真诚
- 场景: 厨房、餐桌、客厅、门店、仓库、货架前
- 信任感: 价格实在、量足、能用、能吃、能省
- 口播质感: "这个咱就看实不实用"，"家里天天用这个挺划算"
- 适合证明: 份量、价格、耐用、复购、真实使用、家庭场景

### 7. 探店/本地生活达人

Best for: 餐饮、团购、酒旅、线下服务、医美/美容、运动馆、亲子乐园。

- 年龄段: 24-38
- 外观: 轻松出门穿搭、团购页/店内小票/门店背景等本地生活线索；只有脚本需要页面桥接时才出现手机
- 场景: 店门口、前台、餐桌、包间、服务区、街边
- 信任感: 路线清楚、套餐清楚、体验真实
- 口播质感: "我已经到店了，先给你看套餐"，"这个价能吃到这些挺值"
- 适合证明: 门头、环境、套餐内容、服务流程、核销路径、真实反应

### 8. 游戏/IP 活动玩家

Best for: 游戏下载、预约、皮肤、联动活动、线下展、IP 周边。

- 年龄段: 18-30
- 外观: 年轻休闲穿搭、耳机/手机/电脑/手柄、轻兴奋状态
- 场景: 桌面游戏区、沙发、线下展区、周边展示台
- 信任感: 玩家视角、福利清楚、玩法欲望
- 口播质感: "这次活动我真先冲了"，"这个奖励你看一下就懂"
- 适合证明: 角色/皮肤、福利页、预约页、试玩过程、周边细节

### 9. 服饰穿搭/试穿达人

Best for: 女装、男装、童装、鞋包、配饰、运动服、内衣家居服。

- 年龄段: follows target wearer or buyer
- 外观: 身形比例自然、穿搭完整、镜前/街拍/衣帽间场景
- 场景: 全身镜、衣帽间、街边、玄关、儿童房
- 信任感: 上身效果、版型、舒适度、搭配建议
- 口播质感: "这个版型我直接上身给你看"，"它显不显瘦看这个角度"
- 适合证明: 上身、转身、走动、面料近景、细节、尺码建议

## Persona Variation Dimensions

When generating multiple versions or avoiding repetition, change at least three dimensions:

- role: 通勤 / 宝妈 / 测评 / 探店 / 玩家 / 家庭用户
- scene: 家中 / 车内 / 办公桌 / 店内 / 街边 / 镜前 / 厨房
- proof action: 上手 / 试穿 / 开箱 / 对比 / 质地 / 使用流程 / 价格核对
- tone: 朋友式 / 实测式 / 省钱式 / 氛围式 / 专业但口语化
- framing: bust / waist-up / knee-up / full-body
- outfit: homewear / commute / sporty / clean beauty / street casual / store visit

## Portrait Prompt Enrichment Contract

Use the selected persona as input to `portrait-image-rules.md`. Do not use this file to write the final image prompt directly.

Every `sandbox_generate_image` request should follow the current `portrait-image-rules.md` logic:

- internally build a complete high-quality creator image prompt
- default to 4:5 high-realism native UGC portrait
- pass the complete internal prompt into `sandbox_generate_image`
- do not expose the internal prompt to the user
- keep phone-shot texture without making the creator hold a phone by default
- use `/workspace/出镜达人/creator_portrait_subject_1.png` as the stable output path for subject 1

## Persona Quality Check

Before script writing, confirm:

- The persona can plausibly use, recommend, test, or sell the product.
- The persona's scene can support the planned proof action.
- The persona tone matches the platform.
- The video script uses the same persona identity, not a generic "达人".
- The persona is specific enough to reduce face, outfit, and role drift.
