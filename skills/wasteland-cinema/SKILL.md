# 废土电影工坊

## 核心原则

不要只做"有废土元素的普通视频"，而要做"每一帧都散发着柴油、铁锈和狂热信仰的废土歌剧"。核心失败是：把青橙滤镜当万能覆盖层、把所有车辆堆成同一种造型、用电子游戏CG特效替代真实物理碰撞质感。

持久引擎（因果链）：

**用户剧情大纲 -> 废土四幕式剧情走向 -> 角色原型与部落体系设计 -> 故事板分镜规划（每分镜显式绑定场景元素） -> 角色全身三视图与场景四宫格资产生成 -> 资产完整性校验（每分镜均有场景绑定） -> 视频分镜生成（槽位映射 + 串行依赖 + 一致性校验） -> 废土工业音频生成 -> 时间线组装与渲染 -> 最终交付**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果移除任何一辆核心改装战车或废土据点场景，该分镜的画面叙事就会断裂或失去物理依托，则创意成立。** 反之，如果某个分镜脱离了场景资产绑定仍能独立存在（"无主背景分镜"），则该分镜不合格，必须重新绑定场景元素后才能进入视频生成。

## 输入诊断

生产前，识别或合理假设以下维度：

- 剧情大纲与核心概念：用户提供了什么样的废土故事线？是公路追击、据点攻防、还是流浪者生存？
- 目标市场与对白语种：旁白和对白使用什么语言？通常废土题材对白为英文（如 "Witness me!"），旁白可中文可英文。
- 画幅与分辨率：默认 16:9 / 720p（可超分至 1080p）。
- 废土美学方向：米勒式实拍废土（真实重型机械、粗粝手工拼装材质、极端沙漠日光）——非赛博霓虹、非塑料CG感。
- 角色原型：用户是否指定了部落体系、面部妆容、专属装备？还是需要根据大纲设计全新角色？
- 载具设计：核心战车的战术用途（重卡开路/越野追击/轻型侦察/火力投弹）与独特视觉轮廓。
- 场景类型：沙漠日景、沙暴、黄昏、夜景、据点内部——影响色彩规则与光线规则。
- 声音设计：角色是否有对白？是否需要声音克隆？旁白音色画像是什么？
- 参考素材：用户是否上传了角色参考图、场景参考图、参考视频？需评估其格式合规性（见下文资产校验规则）。
- 合规敏感点：暴力碰撞是否在合理叙事范围内？是否存在过度血腥？角色妆容是否有文化敏感风险？

## 工作流（步骤）

### 步骤 1：确立全局规范

建立全局视频参数文件，锁定以下核心规范：
- 画幅：16:9
- 分辨率：720p（可后续超分至 1080p）
- 视频风格：米勒式废土美学——狂暴公路、高饱和青橙色调、重型改装战车、原始荒野、去数字化
- 角色对白输出语言：通常为英文（与旁白语言可不同）

将以上规范写入项目目录下的参数文件，后续所有生成步骤均以此为基准。

### 步骤 2：设计故事板

根据用户提供的剧情大纲，设计完整故事板。故事板必须严格遵循用户的剧情走向、人物关系与核心概念，在此基础上细化以下设计：

**废土四幕式剧情走向（起-承-转-合）：**
1. **荒凉寂灭与暴政确立（Desolate Setup）**：展现无垠沙漠或重工业据点的死寂，首领俯瞰荒原、流浪者孤身独行，奠定压抑基调。
2. **狂热仪式与重机集结（Mobilization & Ritual）**：战争男孩涂抹白漆、集结改装猛兽，发动机发出震天咆哮。
3. **公路追击与钢铁撕裂（Pursuit & Collision）**：核心公路大战，高速切撞、喷火突袭，节奏达到沸点。
4. **神圣牺牲与烈火高潮（Fiery Climax & Sacrifice）**：高潮爆发，角色高喊誓词并在刺目火球中与敌车同归于尽。

上述四幕为经典结构参考，必须支持根据用户大纲生成全新的部落体系、面部妆容、专属装备和不同的"资源崇拜体系"。严禁强制复刻单一电影造型。

**核心元素设计：** 详细设计核心元素——改装卡车、不同体量战车、废土流浪者、可自定义的废土部落角色与据点场景。

**分镜规划关键规则：** 每个分镜（shot）均必须显式引用并关联一个具体的场景元素（element scene）。严禁留空或无场景关联。若某分镜缺失场景绑定，自动向前追溯并继承最近一个分镜的场景资产。

**音频轨设计：** 在故事板中同步规划旁白（VO）轨、角色对白轨、背景音乐轨和拟音轨。

> **停顿点 1——故事板确认：** 故事板设计完成后立即暂停，向用户展示完整的分镜列表、元素规划和音频轨设计。用户确认后才可推进。

### 步骤 3：确立与校验核心元素资产（角色与场景）

根据用户是否提供了参考图，分流处理：

#### 3A. 用户主动提供了参考图

首先解析这些图像，评估其视觉风格是否符合米勒式实拍废土美学，并执行以下专项校验：

**角色参考图校验：** 必须是无遮挡的全身三视图（正面、侧面、背面全部为直立全身角度）。坚决杜绝半身照、缺少角度、存在遮挡。

**场景参考图校验：** 必须为无人物、多角度、且内容呈 2x2 四宫格标准分配的拼图。四格内容须依次为：
- 全景定场（Establishing Shot）：宏大荒原地貌、地平线与据点整体形态
- 陈设特写（Props & Close-up）：废旧钢铁、铆钉、锈蚀铁刺或拼凑机械细节
- 纵深透视（Depth & Perspective）：据点廊道、重叠废墟等强透视空间
- 气氛光效（Atmospheric Lighting）：青橙对比、沙尘弥漫或逆光剪影

**若风格与格式均符合：** 提炼其物理细节与视角共性写入故事板描述，直接进行资产绑定。

**若风格或格式不符**（如平淡写实、赛博霓虹，或角色图非直立全身三视图/半身图/缺少角度，或场景图非标准四宫格/含人物）：不可直接绑定。将用户原图作为视觉与结构特征参考，以图生图路径重新生成一套符合影片美学的资产——包含正面/侧面/背面三个直立角度的全身三视图（不可为半身照），或重塑为无人物且四格标准分配的场景四宫格图。生成前须向用户展示提示词设计，获得确认后方可执行。生成后同样要得到用户认可，方可锁定为稳定资产。

#### 3B. 用户未提供参考图

从头生成以下资产（画幅 16:9，分辨率 2K）：

**人物三视图（character sheet）：** 提示词中强制加入全身多角度视图关键词，确保生成具备完整三视角度（正面、侧面、背面均为直立全身，严禁半身照）且特征高度连贯的单张角色参考图。

**场景参考图（4-grid scene collage）：** 强制生成无人物的、内容分配固定的四宫格。提示词中必须加入四宫格排版关键词和无人物关键词。四格内容依次为：左上全景定场、右上陈设特写、左下纵深透视、右下依据分镜背景灵活调整的真实气氛光效。

**战车设定图：** 生成展现狂暴机械、火焰喷射和生锈铆钉的重型战车参考大样。

> **停顿点 2——资产生成前确认：** 启动从头生成角色三视图、战车或场景参考图前，必须向用户展示提示词设计，获得确认后方可执行。生成后同样要得到用户认可，方可锁定为稳定资产。

#### 3C. 元素资产完整性校验（Asset Integrity Check）

在上述步骤完成后，系统**必须**主动对照故事板中规划的所有核心元素（角色、场景、道具等）进行全面核对，确保每一项元素都已成功生成了对应图像。同时深度检查是否每一个分镜都已明确指明了场景元素，严禁出现未绑定场景参考图或与相邻镜头背景不连续的"无主背景分镜"。若有任何元素遗漏或分镜未绑定场景资产，严禁进入下一步视频生成。

> **停顿点 3——资产完整性确认：** 将所有已生成且绑定的元素资产清单提交给用户。用户审查确认没有任何遗漏、完全对齐并同意锁定后，方可推进。

### 步骤 4：视频分镜生成与提示词对齐校验

生成视频分镜，执行以下多维逻辑校验与一致性强绑定规则：

#### 4.1 生成路径与参数
- 优先采用多模态生视频路径（MultiModalToVideo）。若完全无物理参考则降级为文生视频路径。
- 分辨率强制 720p。单镜头时长根据故事板节奏动态规划，控制在 4s - 15s 之间（硬性约束：单分镜最低时长绝对不可低于 4s）。
- 时长 ≤15s 的分镜用一次视频生成即可拿到完整片段，无需分段生成再拼接。成片超过 15s 时才拆成多个 ≤15s 片段分别生成再后处理拼接。

#### 4.2 视觉一致性与资产逻辑限制（Consistency Logical Constraints Check）

**最大参考资产输入上限：** 单分镜视频生成任务中挂载的参考图像数量上限绝对不可超过 4 个。多余非核心资产必须在预生成阶段自动剔除。

**物理槽位强制角色映射规则（Rigid Slot-to-Role Mapping）：**
- **image_1（槽位 1）：** 必须锁定绑定为该分镜明确关联的场景元素四宫格参考图。锁死背景纹理，杜绝无背景裸奔生成。若分镜缺失场景绑定，自动向前追溯并继承最近一个分镜的场景资产。
- **image_2（槽位 2）：** 必须锁定绑定为该分镜出场的主角色全身三视图。以此作为人物身份、彩绘与服装的最高权重视觉先验。
- **image_3（槽位 3）：** 锁定绑定为出场的核心载具/改装战车设定图。
- **image_4（槽位 4）：** 备用槽位。有次要角色或核心冷兵器、爆破长矛出场时绑定其设定图；若无则保持空闲，降低噪音干扰。

该槽位映射必须与提示词中对应的图片引用标记保持物理绝对咬合。

**语义与图像属性一致性非冲突校验：** 提交生成前，将该分镜在故事板中的描述与绑定的视觉资产进行一致性对齐。例如：若分镜脚本要求人物执行"口喷银漆、怒目狂颤"等动作，核对绑定的角色参考图中是否包含相应的视觉特征。若检测到资产图像与故事板描述存在物理冲突，严禁直接提交生成，必须先重新生成包含特定细节变体的参考图并绑定后才可推进。

**参考视频时空场景非冲突校验：** 当绑定了前序分镜的成片视频作为参考视频进行串行连续性生成时，交叉核对前序分镜的环境背景与当前分镜的场景四宫格资产是否在物理空间上属于同一场景。
- **跨场景强隔绝逻辑（Hard-Isolation Rule）：** 若前后分镜发生跨越场景空间的宏大切换（如从公路大飙车切入据点深处阴暗廊道），绝对禁止传入参考视频进行惯性引导。即使剧情连续，也必须强行隔绝视频参考，通过场景四宫格首帧重置，并调用硬切、沙尘转场或过曝转场，严防模型将两种不兼容的背景混淆导致画面形变。

#### 4.3 对白音画同步资产双重物理校验（Lip-Sync Co-occurrence Constraints）

若故事板分镜中规划了角色对白，系统必须校验：
1. 主角色全身三视图（需面部清晰无遮挡）是否在对应槽位就位；
2. 该角色的声音参考资产是否绑定。

若图像资产缺失，视频生成必须暂停提示。若声音资产缺失（即用户选择跳过），系统不得挂起生成，应直接调用默认的高质量废土语调模型进行声音与嘴形同步合成，保证无声音克隆素材时项目亦能顺畅完成。

#### 4.4 镜头连续性与时序生成控制（Sequential Generation Dependency）

**启用场景与类型限制：** 仅允许在以下四类具有极强物理惯性的相邻镜头间使用参考视频：
1. 连续车队狂飙
2. 战车物理撞击挤压、底盘撕裂
3. 角色飞跃起跳、雷管矛突刺动作承接
4. 相同视差角度的连续同向运镜匹配切（Match-cut）

**连续引用上限：** 参考视频的连续链条绑定最多不得超过 3 个连续分镜。第 4 个分镜必须重新通过高精度的参考图像与物理运动描述作为首帧重置，断开视频递归链。

**多源输入防画面分裂控制：** 同时接受多张参考图像和一个参考视频作为输入时，必须在参数中将资产明确分流为物理结构（参考图像）与运动轨迹（参考视频）两类不同权重的先验条件。配合提示词中的排他指令，绝不允许输出带有任何网格、黑排板和画面分割的视频。

**提示词运动矢量咬合：** 当绑定了前序参考视频时，当前镜头的视频提示词在主体动作与相机运镜层面，必须显式描述其与前一镜头终点帧的物理承接关系。例如：若前镜以"战车向左极速甩尾"结束，当前镜头必须在提示词首句写明承接关系，实现平滑惯性过切，严禁前后运镜速度与方向产生突兀的物理撕裂。

**串行生成逻辑：** 若判定前后分镜具备高度连续性（需要引入前一分镜的成片视频作为参考视频输入），必须放弃并行多路分镜生成，强制执行串行生成逻辑：必须等待前一分镜的渲染任务完成、生成并注册稳定的成片物理资产后，方可将其作为参考视频参数传入并启动当前分镜的生成。在时间线和渲染管道中建立严格的串行依赖（Shot N-1 -> Shot N）。

#### 4.5 提示词对齐校验

在生成视频前，系统必须强制将生成的视频提示词与对应的故事板分镜脚本进行深度比对校验，确认无任何场景参考、人物/道具参考、台词或对白等信息遗漏。若检测到某一分镜未指定或未绑定场景参考图，或出现无逻辑场景跳画，必须立刻终止视频生成并自动补齐场景绑定。

> **停顿点 4——分镜视频生成前确认：** 调用视频生成前，必须先向用户展示视频提示词、所绑定的参考图像以及镜头规划，并提供"故事板对齐校对报告"（列出已对比的项目：场景参考、人物/道具参考、台词对白等是否与故事板分镜脚本完全吻合、有无遗漏），经用户确认同意后再启动生成。

### 步骤 5：音频生成

生成各独立音轨层：

**角色声音样本确立：** 对于有对白的角色，若用户提供其原声音频（1s-15s 干净人声），直接注册为该角色的声音参考资产。若无，用户选择"跳过"即可，系统在后续生成视频分镜或对白时自动调用默认的高质量废土适用发声模型进行声音与嘴形同步合成。

**全局叙事旁白（VO）生成：** 采用固定的旁白音色画像设定统一生成独立旁白音频。旁白语调需呈现麻木、疲惫、冰冷无情且去情感化的极简主义，字里行间包含重度吸气声、长叹息与喉音震颤，语速极慢，短句之间预留大片物理静默。

**背景音乐生成：** 生成工业重金属与硬核拟音音乐。提示词中必须高密度堆叠工业噪音、拟音和暴力金属打击乐描述，严禁生成平庸、温和的常规摇滚。严禁在提示词中出现任何真实歌手、乐队或音乐家的名字。

详细的旁白音色参数、BGM 提示词词库和声学处理规范见 `references/audio-design.md`。

> **停顿点 5——音频生成前确认：** 生成旁白和背景音乐前，必须先向用户展示旁白文案、配音音色与音乐提示词方案，经确认后再启动生成。

### 步骤 6：图像与视频超分辨率提升（可选）

为追求电影级画质与流畅度，可执行以下超分操作：

**图像超分：** 在确认锁定角色/场景元素参考图前，可将图像超分至 4K，使铁锈、荒沙等纹理质感极度逼真。

**视频超分与插帧：** 分镜视频生成后，针对公路追逐、爆炸打斗等高张力动感镜头，可将 720p 分镜超分至 1080p，并将帧率提升至 60fps，呈现极致丝滑的电影流畅感。

> **停顿点 6——超分前确认：** 进行图像 4K 超分或视频 1080p/60fps 插帧超分前，必须先向用户汇报超分/插帧优化方案，获得批准后方可提交任务。

### 步骤 7：时间线组装与渲染

按照米勒式剪辑风格进行快速切镜与混合变速（Speed-Ramping），实现定格、极限慢放、抽帧卡顿以及音视频轨道的精确对齐。

> **停顿点 7——最终组装前确认：** 在进行最终时间线装配和渲染输出前进行综合确认，确认无误后再进行。

## 输出契约

### 全局视频参数文件模板

```
画幅: 16:9
分辨率: 720p（可超分至 1080p）
帧率: 24fps（动感镜头可插帧至 60fps）
视频风格: 米勒式废土美学
对白语言: 英文（默认）
旁白语言: 中文（默认，可调整）
```

### 故事板分镜模板

每个分镜须包含以下字段：

```
Shot N:
  场景元素 (element_scene): [必填，绑定场景四宫格资产 ID]
  角色元素 (element_character): [绑定角色三视图资产 ID，可多个]
  载具/道具元素 (element_prop): [绑定战车/武器设定图资产 ID]
  分镜描述: [画面内容、动作、运镜方式]
  对白 (dialogue): [角色台词，英文；若无则留空]
  旁白 (narration): [旁白文案；若无则留空]
  音效提示: [环境音、拟音提示]
  时长: [4s-15s]
  参考视频: [若与前序分镜连续，填写前序 Shot 编号；若跨场景则留空]
  生成顺序: [串行/并行]
```

### 视频提示词模板

每个分镜的视频生成提示词须按以下结构组织：

```
[色彩与光线规则] -> [材质与环境颗粒规则] -> [碰撞特效规则（仅碰撞节点）] -> [运镜与构图] -> [角色动作与对白] -> [音效提示]
```

提示词主体使用中文书写（当系统处于中文界面时）；角色对白与旁白内容使用 Final_Video_Spec 中指定的输出语言。

时长 ≤15s 的分镜用一次视频生成即可拿到完整片段。beat 分镜（如 0-4s/4-8s/8-12s）是同一次生成内部的时间轴描述，不等于要多次调用。成片超过 15s 时才需拆成多个 ≤15s 片段分别生成再后处理拼接。

## 静默自检

交付前内部跑清单并重写弱项。除非用户要求点评，否则不外显。

- 因果链是否每一环都成立（从大纲到最终交付无断链）？
- 每个分镜是否都显式绑定了场景元素？有无"无主背景分镜"？
- 角色三视图是否为正面/侧面/背面三个直立全身角度？有无半身照？
- 场景参考图是否为无人物四宫格？四格内容是否符合标准分配？
- 单分镜参考图像是否 ≤4 个？槽位映射是否正确（image_1=场景, image_2=主角色, image_3=载具, image_4=备用）？
- 串行依赖链是否超过 3 个连续分镜？若超过是否已断开递归？
- 跨场景切换时是否已隔绝参考视频？
- 对白分镜是否已校验角色图像和声音资产？
- 色彩规则是否按场景类型分别执行（而非全局青橙滤镜覆盖）？
- 材质损伤是否按受力部位不均匀分布？是否每个主体仅保留 2-3 个核心识别特征？
- 碰撞特效是否仅在碰撞节点出现？普通行驶是否保持物理克制？
- 旁白语调是否为沙哑、粗粝、去情感化的极简主义？
- BGM 提示词中是否包含任何真实歌手/乐队名称？
- 所有停顿确认点是否已执行？用户是否已在每个关键节点明确同意？
- 全文语言是否与目标市场一致、无中英文混杂（对白除外）？
