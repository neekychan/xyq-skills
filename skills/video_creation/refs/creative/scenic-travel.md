# 风光氛围与文旅视频创作指南（氛围空镜 / 文旅目的地）

适用：以风景、空间、氛围为主角的视频——治愈风光、城市/自然空镜、超现实意象、意境短片，以及景区/古镇/乡村/城市的文旅宣传。

## 范式路由（先读）

| 用户信号 | 范式 | 阅读路径 |
|---------|------|---------|
| 治愈/风景/空镜/氛围感/意境/延时，无明确地点推广意图 | §A 氛围空镜 | 通用层 + §A |
| 景区/古镇/乡村/城市宣传、文旅节庆、助农、"来XX玩" | §B 文旅目的地 | 通用层 + §A 运镜语法 + §B |
| 给定文案/语录配画面，落点在文案 | 转 `creative/quote-visual.md` | 按该文件模式判定；画面为风景时回读本文件 §A |

判据：有没有"让观众想去/想买"的召唤落点。没有 → §A 纯美学；有 → §B（§B 是 §A 的语法加一层人文与召唤）。

## 通用强制规则

1. **无人叙事靠时间做事件**：没有角色冲突时，用时间变化当剧情——晨雾散开、日落点灯、四季流转、潮起潮落，每段一个时间事件
2. **景别弧线**：开场定调（大全景或极特写二选一）→ 中段变化 → 收尾回到开场景别呼应，禁止全片同一景别
3. **声音即氛围**：环境音具体化（蝉鸣、风穿过松林、檐角风铃），禁止只写"舒缓音乐"

## §B 文旅目的地

1. **一地一符号**：提炼该地唯一视觉符号（非遗物品、吊脚楼、荷花、雪山）贯穿全片做记忆锚点，禁止景点大杂烩平铺
2. **人文烟火点缀**：至少 1 个本地人生活瞬间（摊主掀蒸笼、老人下棋、孩童奔跑），用远景/背影/手部，不抢风景主角地位。匿名点缀人物不做角色参考图，场景图保持纯空镜，人物由视频 Prompt 肢体白描即时生成
3. **结构**：奇观钩子（该地最强画面，3s 内）→ 空间漫游（§A 运镜语法串 2-3 个场景）→ 人文瞬间 → 召唤收尾（地名+一句到访理由，文案 ≤12 字）
4. **节庆/非遗题材**：民俗活动当"时间事件"用（舞狮起势、龙舟离岸、灯亮瞬间），拍过程不拍摆拍合影
