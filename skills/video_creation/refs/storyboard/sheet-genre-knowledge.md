## 三、知识讲述类

> **二级呈现形式**：科普演示分镜图、文案逐句可视化、知识点讲解故事板、PPT·课程转分镜、图解信息分镜、漫画科普分镜、讲解脚本表格。下方给出代表性骨架（科普演示分镜图）；其余二级呈现形式的细化模板见本章末「PE 模板索引」。

### 适用要点与判定关键词

- **定义**：以知识讲解、技能教学为核心的连续分镜图，形式类似 PPT/课件，每格对应一个知识点或步骤，配简洁图示/图表/场景示意，目标是“讲清楚”。
- **判定关键词**：`教学`、`课程`、`课堂`、`科普`、`讲解`、`教程`、`步骤`、`知识点`、`原理`、`操作说明`、`注意事项`。以“讲明白一个知识点/流程”为目的时归本类。
- **边界**：
  - vs 剧情叙事类：本类每格围绕一个知识点/步骤，逻辑类似 PPT 页。
  - vs 动作分解类：本类侧重“为什么这么做/步骤作用”，常配图表、文字块和流程箭头。
  - vs 营销转化类：本类可没有具体产品，讲任何知识。
  - 漫画科普：以“信息块 + 图示”驱动理解、卡通人物作为讲解者/吉祥物时归本类（二级选「漫画科普分镜」）。

### 分镜结构建议

- **推荐宫格数**：6–12 格，复杂课程拆为多条短视频。
- **结构骨架**：
  1. 引题与目标（1 格）：提出问题或常见误区，说明本节讲什么；
  2. 核心概念/公式（1–2 格）：给出关键定义或公式，可配简洁板书/图表；
  3. 步骤拆解或案例（3–6 格）：一格一步骤/一案例，画面突出“输入→操作→结果”；
  4. 小结与行动建议（1–2 格）：复盘要点，给出记忆口诀或下一步行动。
- **景别与信息密度**：讲师/IP 出镜多用中近景；板书/PPT 内容用近景或特写；每格只讲一个知识点，避免文字过多。

### 生图 Prompt 骨架

```text
你是一名在线课程导演，请为下述知识点设计一张 {宫格数} 宫格的科普演示分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏课程短视频”或“16:9 横版课件讲解”}。

【教学主题】
- 一级用途类型：知识讲述类
- 二级呈现形式：{科普演示分镜图 / 文案逐句可视化 / 知识点讲解故事板 / PPT·课程转分镜 / 图解信息分镜 / 漫画科普分镜 / 讲解脚本表格}
- 科普主题：{如“如何科学护肤/高铁安全科普/儿童财商启蒙”等}
- 目标受众：{如“小学生/职场新人/备考学生/中老年”等}
- 内容类型：{如“UGC-科普/UGC-生活/营销-产品演示”等}
- 风格题材标签：{如“轻松/幽默/严谨/治愈/校园”等}

【参考素材图（如有）】
- PPT 截图/板书照片/界面截图/实验照片：作为参考图，保证文字与结构还原；
- 讲解者/IP 形象参考图：保持讲解者外观一致；
- 若无参考图且为精修/成品级：先确认是否有现成课件/IP 形象图。

【画面与风格】
- 画风：{如“扁平矢量/水彩手绘/3D 动画/插画图解/信息可视化”等}
- 画面比例：{如“9:16/16:9”等}
- 信息密度：每格只讲一个清晰知识点或步骤，图文结合，避免拥挤。

【分镜与标注配置】
- 宫格数量：{宫格数}，按 1~{宫格数} 顺序编号 L1–L{N}。
- 完成度：{草稿/线稿级 / 精修级 / 成品级渲染}
- 是否带序号：{"是"/"否"}
- 是否带文字说明：科普分镜通常为 "是"。
- 是否带分镜参数：{"是"/"否"}

【推荐结构】
- 引入（提出问题或常见误区）→ 核心知识点（每格一个知识点或步骤）→ 总结与行动建议。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 L1 到 L{N} 的教学分镜要点（画面内容 + 文本标题 + 核心文案），供用户确认；确认后再按以下格式，为每格写出详细分镜说明：
1. L1：
   - 画面内容：{示意画面}
   - 文本标题：{简短标题，如“你真的会洗脸吗？”}
   - 核心文案：{一句话描述本格知识点，口语化}
2. L2：……
……直到 L{N}，保证每格只讲一个知识点或步骤，画面与文字匹配。
```

### 一致性与避坑

- 所有格视觉风格与配色一致，避免拼贴杂图。
- 讲解者（如有）外观统一，可作为“科普小助手”多格反复出现增强记忆。
- 文字量控制在“标题 + 1–2 行短句”级别，避免拥挤难读。
- 画面围绕文字内容设计，一眼看出当前格主题，避免“文字讲 A、画面画 B”错配。
- 必须围绕“知识点/步骤”组织，避免写成纯剧情短剧或表情包合集。

#### 信息链与教学分镜绑定检查（P1）

- 每格状态卡增加“信息链节点 ID + 文本标题 + 核心文案”；每格只承担一个知识点/步骤。
- 信息链所有节点必须被至少一个分镜格覆盖；无来源的画面视为脱节。

### 视频生成策略与 PE 模板

```text
请基于下述素材生成一条 {时长秒数} 秒的教学/科普视频，确保知识点讲解清晰易懂。

【输入素材】
- 分镜图：{路径或 ID}（{宫格数} 宫格，标明每格对应的教学步骤或知识点）
- 参考图：{PPT 截图/板书照片/界面截图/实验照片等}
- 目标画幅：{画幅说明}，ratio={ratio 代码}
- 目标模型：以用户指定的模型为准；用户未指定时，可用 seedance_2.0_fast 或 seedance2.0_fast_vision

【生成策略】
- “参考图生视频”：关键知识点镜头附加 PPT/板书参考图，确保文字与图形清晰；
- 镜头切换跟随讲解节奏、不宜过快，保证观众有时间阅读画面信息；
- 画面为文字预留明显区域，避免被人物/动画遮挡。
- 每个镜头只承担一个清晰的知识点或步骤，整体结构按照 creative/knowledge-explainer.md §科普的"具象钩子 → 建立载体 → 类比演进 → 恍然时刻 → 可带走的落点"规划：抽象概念必须先转化为事件化类比（载体做事→出结果），再写入分镜与视频 Prompt，禁止直接堆砌概念定义。

【质量要求与常见问题规避】
- 文字区域高可读：字号足够大、对比度充足，避免过度光效和复杂纹理；
- 讲解者外观跨镜一致，姿态变化自然；
- 避免生成为剧情短剧或表情包合集，强制保留“文本标题 + 核心文案”；
- 所有中文文字、镜头编号与镜头参数说明优先由脚本或后期文字层叠加，图像模型仅负责画面，不直接生成长篇中文文字，以避免模糊或错字。

【数字人口播场景追加要求】
- 若 plan 中指定使用数字人/讲解员出镜，画面与动作需遵守 creative/digital-human.md 与 storyboard/digital-human-prompt.md：以中景为主，限制为点头/微笑/小幅手势等微动作，背景简洁不与人物争抢注意力；台词需填满大部分段时长，尾部仅留 0.5–1 秒收嘴，禁止出现 ≥3 秒无台词的沉默表演段。
- 所有教学/科普口播段在调用 sandbox_generate_video 前必须按 storyboard/dialogue-rules.md 校验台词耗时区间，并用固定句式写出口型动作；讲解类段落优先保证台词说得完，其次再考虑插入额外动作或 B-roll。

【迭代建议】
- 控制信息量与时长：优先减少知识点数量或拆成多条短视频，而非一条堆叠过多信息；每次迭代只调整分镜或参考图其中一项，避免同时大改画面与文字。
```
