# App 视频创作

## 沉浸式短片

1. 首页选择【沉浸式短片】。
2. 点击输入框描述视频；有首帧参考图时可上传。
3. 按需求选择模型和时长，点击黑色【⬆️】按钮生成。
4. 查看成品。沉浸式短片不支持二次编辑；需要调整时可在本地优化，也可一键重新生成、修改诉求再生成，或基于生成视频进行延长。知识库没有收录延长功能的完整按钮路径及可选时长范围。

提示词可按“主体描述 + 画面运动 + 音效互动 + 台词 + 音色 + 运镜/环境 + 风格 + 限定信息”组织。希望有音效、台词或环境声时，要写进描述。

### Seedance 2.5 能力简介

- 单段视频最长 30 秒直出。
- 单次最多输入 50 个参考素材，类型包括图像、音频、视频；不能解释为每类各 50 个。
- 支持时间戳控制、多模态参考，增强局部编辑、白模控制、绿幕编辑与视频延长能力。
- 原生支持生成 10 余种语言；知识库未列出完整语言清单。

以上属于模型能力简介。回答 App 沉浸式短片的实际操作时，以该功能“不支持二次编辑”的说明为准，并介绍重新生成、修改诉求再生成或延长方式。不能据模型具备局部编辑能力推断 App 已开放相应操作，也不要搬用 Web 画布或故事板的流程。此限制仅适用于沉浸式短片，不泛化成所有 App 功能均不能编辑。

可额外提供[小云雀 Seedance 2.5 使用手册](https://bytedance.larkoffice.com/wiki/W5tHwoZIDi12dbk2z3KcFkuUnsf)供用户自行查看；本 Agent 不访问该链接。

## 智能生视频

1. 首页选择【智能生视频】。
2. 输入视频需求，按需上传素材。没有素材时也可描述需求，由 AI 生成和补充画面；可融合实拍与生成素材。
3. 在设置中调整视频时长、口播语言等；不想要字幕、贴纸等包装元素时，使用【画面包装】设置。
4. 点击黑色【⬆️】按钮提交。AI 先确认想法，输入有误可点击【修改】重新输入，随后分析意图、编写脚本、拆分分镜和旁白并自动剪辑成片。流程可匹配数字人口播、语音合成、字幕和转场。
5. 等待时可点击右上角缩小入口，将任务置于后台继续生成。
6. 成品可长按点赞和反馈，点击【保存到手机】使用，也可分享给好友或分享至抖音。

【分享至抖音】可呼起抖音发布，并解锁无品牌水印保存。这里的品牌水印仅指右下角【小云雀AI】，不等于移除所有 AI 标识，也不代表所有保存路径都无水印。

使用场景包括商品带货、科普、绘本故事、动画剧情、营销短片、参考图生视频与老照片动起来。案例中的“一分钟以内”等要求不是智能生视频的时长上限。

## 爆款复刻

入口：【智能生视频】输入框下方【复刻爆款视频】。

粘贴参考链接或上传本地视频，描述希望借鉴的内容及修改诉求后生成。可参考文案结构、剧情框架、配乐画风等。App 主手册没有列出完整支持链接的平台清单；不要从 Web 手册补入支持范围。用户问某平台是否支持且本地无依据时，使用未命中提示。

## 一镜到底

1. 首页选择【一镜到底】。
2. 依次上传 2～16 张图片。
3. 点击素材之间的区域设置转场，可描述镜头推进、拉远等效果并设置时长；也可只设转场时长，让产品自动处理画面。
4. 点击黑色生成按钮提交，等待连贯长镜头产出。

知识库没有收录完整的转场时长范围、总视频时长上限或图片文件限制，不将案例中的 2 秒、3 秒、5 秒当成唯一可选值。
