## 概述

跨镜空间一致性是3D古风短剧的核心质量保障。每个shot视频生成完成后，从中截取关键帧用于下一镜的参考；下一镜生成前通过四层过滤选出合适的参考帧。这套机制确保角色站位、背景元素、场景方向在跨镜时保持一致。

---

## 视频关键帧截取

每个shot视频生成完成后，根据下一镜的需求从该视频中截取**一帧或多帧**画面。

### 截帧数量最小化原则（强制）
若当前shot与下一镜之间人物未走动、站位未变、背景场景相同，只截取**一帧**最关键的画面即可——多截同质帧无意义且增加干扰。仅当下一镜需要不同视角的信息（如不同角色的清晰帧、不同方向的场景背景帧）且这些信息无法从单一帧中获得时，才截取多帧。

### 截帧内容选择
截取不限于站位中全景——须判断下一镜需要哪些参考：
- 下一镜聚焦男主→截取男主视角清晰的帧
- 聚焦女主→截取女主帧
- 需要场景背景→截取场景信息最丰富的帧
- 需要整体站位→截取中全景帧

### 景别兼容性截帧约束（强制）
截取帧的景别须在下一镜最宽内切镜景别对应的兼容区间内（见下方参考表）。一律不得截取全景/大全景帧——宽景别帧会拉扯模型向宽画面偏移导致切镜后突然变远、人物位置漂移。应从当前shot中截取景别落在下一镜兼容区间内的帧。

### 截帧前人物确认（强制）
截帧前须先查阅下一镜Storyboard确认下一镜实际出场人物——下一镜不在场的角色不截取其角色视角帧，因为不在场角色的视角帧中场景背景角度与下一镜不同，纳入后会导致模型误引入该角度的背景而造成场景漂移。站位帧可纳入（传递站位关系），但角色视角帧仅限下一镜在场角色。

### 场景方向一致性
所有纳入的帧的场景方向须与下一镜机位方向一致，不得将不同机位方向的帧混合纳入。多帧之间互补，覆盖不同视角、不同角色和不同区域。

### 注册绑定
截取的帧逐一注册并绑定到对应shot，供下一shot视频生成时作为空间一致性参考帧。

## 截帧后视觉内容分析（强制）

每张截取帧完成后，须对该帧执行一次视觉内容分析，输出结构化标签并绑定到该帧的元数据中，供后续选帧阶段做背景匹配过滤。

### 分析内容

1. **可见背景元素清单：** 逐项列出帧画面中实际可见的背景元素及其画面位置（如"画面中央偏后：雕花大门""左侧：镂空窗棂""右侧：玉石屏风"），不得笼统概括。
2. **场景方向：** 标注该帧的机位方向（正视纵深/反向纵深/左侧横向/右侧横向），与场景四宫格的四向定义对齐。
3. **在场角色与位置：** 列出帧中出现的角色及其在画面中的位置（左/中/右、前景/后景）。
4. **景别：** 标注该帧的景别（大特写/特写/近景/中景/中全景）。

### 背景匹配预检（强制）
分析完成后，将该帧的可见背景元素清单与下一镜空间锚点卡中"各角色背后/左侧/右侧可见背景元素"逐项比对：

- 若该帧的背景元素与下一镜空间锚点卡描述的背景元素**不一致**（如帧中背景是大门但下一镜空间锚点卡写的是高台），该帧须标注 `背景不匹配——不建议用于下一镜`，并在选帧阶段排除。
- 若匹配，标注 `背景匹配`。

此预检是前置过滤——在帧进入选帧池之前就排除背景不一致的帧，避免背景不匹配的帧在选帧时因景别/方向/角色等元数据通过而被误纳入。

## 选帧四层过滤

从第二个shot起，在生成前资产重检时，从所有已生成的前序shot中挑选空间一致性参考帧。Agent须回溯前序所有已生成shot已绑定的参考帧，根据当前shot的需求挑选最相关的帧——不仅限于紧邻的上一镜，也可回溯更早的shot（例如当前shot有某角色在中间shot缺席后重新出场且站位应与之前一致，可回溯该角色上次在场时的shot的角色视角帧）。

选帧须同时通过以下四层过滤，**任一层不通过则排除该帧**：

### 第一层：背景内容匹配过滤（强制·最高优先级）
检查该帧在截帧时生成的视觉内容分析标签中的"可见背景元素清单"，将其与当前shot空间锚点卡中各角色背后/左侧/右侧可见背景元素逐项比对——背景元素不一致的帧直接排除，不得纳入。

若帧没有视觉内容分析标签（如用户手动上传的帧），须先补做视觉内容分析再比对。

**关键原则：若前序帧通过景别/方向/角色过滤但未通过背景内容匹配过滤，同样不得纳入——背景不匹配的帧比没有参考帧更危险，会导致模型生成与空间锚点卡矛盾的背景。**

### 第二层：角色过滤
当前shot不在场角色的视角帧须排除，只保留站位帧、当前shot在场角色的视角帧。

### 第三层：方向过滤
帧的场景方向须与当前shot机位方向一致。

### 第四层：景别兼容性区间过滤（强制）
参考帧的景别须在当前shot最宽内切镜景别对应的兼容区间内（见下方参考表）。任何shot一律不得纳入全景/大全景帧。

若前序shot中只有宽景别帧可用且其景别不在当前shot兼容区间内，则不为当前shot纳入该帧——改用角色key_element图像 + 场景四宫格 + 提示词文字描述固定站位关系，不引入景别不匹配的参考帧。

### 无可用参考帧时的处理
若所有前序帧均未通过背景内容匹配过滤，则不为当前shot纳入任何参考帧，改用角色key_element图像 + 场景四宫格 + 提示词文字描述固定站位关系。

## 景别兼容性参考表

### 截帧时的景别兼容区间（当前shot截帧给下一镜用）

| 下一镜最宽内切镜景别 | 可截取的帧景别 |
|---|---|
| 大特写 | 大特写 / 特写 / 近景 |
| 特写 | 特写 / 大特写 / 近景 / 中景 |
| 近景 | 近景 / 中景 |
| 中景 | 中景 / 近景 / 中全景 / 特写 |
| 中全景 | 中全景 / 中景 / 近景 / 特写 / 大特写 |

### 选帧时的景别兼容区间（从前序shot中选帧给当前shot用）

| 当前shot最宽内切镜景别 | 可参考的帧景别 |
|---|---|
| 大特写 | 大特写 / 特写 / 近景 |
| 特写 | 特写 / 大特写 / 近景 / 中景 |
| 近景 | 近景 / 中景 |
| 中景 | 中景 / 近景 / 中全景 / 特写 |
| 中全景 | 中全景 / 中景 / 近景 / 特写 / 大特写 |

**一律不得截取或纳入全景/大全景帧。**

## 回溯补截

若视频生成阶段发现所需参考帧缺失（如当前shot需要女主近景帧但前序帧中没有），须回溯从前序shot视频重新截取对应类型的帧。

补截后同样须执行：
1. 视觉内容分析（可见背景元素清单、场景方向、在场角色与位置、景别）
2. 背景匹配预检（与当前shot空间锚点卡比对）
3. 四层过滤（背景内容匹配→角色过滤→方向过滤→景别兼容性）

全部通过后方可纳入当前shot的参考帧池。
