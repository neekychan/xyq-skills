# 雾山五行水墨武侠视频制作

## 核心原则

不要把水墨武侠做成"加了水墨贴片的普通动画"。真正的雾山五行美学是：笔墨张力与镜头动能深度耦合——静态时工笔细描温润清雅，爆发时焦墨枯笔狂乱炸裂，五行元素以矿物泼彩的物理质感而非 CGI 光效呈现。

持久引擎（因果链）：

**用户剧情/构思 → 素材分析与风格判定 → 角色三视图 + 场景四宫格（规范格式资产） → 故事板设计（五行角色 + 动态时长分镜 + 强场景绑定） → 逐镜视频生成（角色/场景/音频三重一致性绑定） → 配音配乐（五行风格化音效） → 时间线合成（武打卡点 + 水墨闪切）**

### 质量测试（可证伪）

每一镜视频生成前，必须通过以下测试：

**该镜头的角色参考图（三视图）、场景参考图（四宫格）、声音凭证（如有台词）是否均已生成、绑定并在提示词中显式指代？若任一缺失，该镜头不允许启动生成。**

没有通过这条测试的镜头，必然出现角色跳变、场景穿帮或口型断裂——这是水墨武侠视频最常见的失败模式。

## 输入诊断

生产前，识别或合理假设以下维度：

- **剧情/构思**：用户提供的故事大纲、角色设定或分镜意图（自由文本或口述）
- **目标市场/语种**：默认中国大陆/中文；若用户使用英文交互，配音与字幕切换为英文
- **画幅与分辨率**：默认 16:9 / 720p（视频）、2K（图像）
- **画风定位**：《雾山五行》水墨武侠风格——泼墨写意 + 矿物泼彩叠彩
- **用户提供的参考素材**：
  - 角色人设图：是否为正面/侧面/背面标准三视图？画风是否相符？
  - 场景参考图：是否为多角度无人物四宫格？是否包含人物？
  - 动作参考视频：提取攻击前摇、出招、碰撞、收招的帧级时间跨度
  - 配音音频样例：用于音色克隆提取
- **角色体系**：是否涉及五行使者（金木水火土）？各角色的色彩编码与爆发态设定
- **场景类型**：意境空镜 / 常规对打 / 高潮决战——决定色彩比例与明暗配比
- **打斗流派**：人类武侠写实 / 妖兽魔幻夸张 / 五行使者虚实结合
- **台词与配音**：角色对白内容、音色设定、旁白需求
- **合规敏感点**：暴力程度控制、妖兽形象审查边界

## 工作流（步骤）

### 阶段 1：确立全局规格

1. 基于用户提供的剧情或构思，初始化全局规格文档，显式设定：画幅 16:9、视频分辨率 720p、水墨武侠风格定位、配音及字幕语言。
2. 将规格文档写入工作目录，作为后续所有阶段的风格基线。

### 阶段 2：素材分析与风格判定

3. 识别并读取用户主动提供的人设参考图、场景参考图、动作视频、配音样例。
4. 对每类素材进行多模态特征分析：
   - **角色人设图**：判定是否为正面/侧面/背面标准三视图，画风是否与雾山五行水墨武侠风格相符。提取发型、服饰、配色、道具、五官线条特征。
   - **场景参考图**：判定是否为多角度无人物四宫格布局。若是，提炼四格内容（全景定场/陈设特写/纵深透视/气氛光效）；若否，提取场景内容、色彩倾向和标志地貌。
   - **色彩提取**：识别传统矿物颜料（石青、石绿、朱砂等）的配比与分布。
   - **线条风格**：分析笔触粗细顿挫、飞白与泼墨比例。
   - **动作节奏**：在视频参考中提取攻击前摇、出招、碰撞打击点和收招的帧级时间跨度。
5. 将分析结果写入规格文档，指导后续故事板设计与提示词编写。

### 阶段 3：资产规范判定与重塑/补全

根据素材分析结论，分三种情况处理：

**情况 A——风格与格式完全相符：** 用户提供的角色图为标准三视图且画风相符，或场景图为标准无人物四宫格 → 直接绑定使用，跳过对应元素的生成。

**情况 B——风格不符或格式不规范：**
- 角色图非三视图或画风不符 → 以用户图为内容参考，调用图生图能力重新生成符合水墨武侠风格的 2K 角色三视图。
- 场景图非四宫格或包含人物 → 以用户图为空间布局与色彩参考，重新生成 2K 无人物场景四宫格参考图，四格固定分配：Grid 1 全景定场 / Grid 2 陈设特写 / Grid 3 纵深透视 / Grid 4 气氛光效。

**情况 C——完全缺失：** 调用文生图能力原创补全 2K 角色三视图及多角度无人物四宫格场景参考图。

6. **绑定与闭环自检（铁律）：** 将所有符合水墨风格的资产绑定至对应 key_element。进入下一步前，逐一核对故事板中规划的每个角色、场景和关键道具是否均已成功生成并绑定图像资产。若发现遗漏，立即补全。严禁在资产未完全对齐的情况下启动逐镜视频生成。

### 阶段 4：故事板设计

7. 设计 key_element：
   - **角色元素**：严格基于五行色彩体系编码。读取 `references/industries/wuxing-characters.md` 获取各行使者爆发态的色彩配比、物理光影与运动质感设定。为每个有台词的角色规划配音音色描述。
   - **场景元素**：采用多角度无人物四宫格规范。读取 `references/industries/wuxing-scenes.md` 获取场景色彩比例与中式陈设水墨质感设定。
8. 设计 shot（镜头）：
   - **时长动态规划**：根据动作激烈程度、信息量及台词字数动态设定 duration（4s-12s）。读取 `references/craft/combat-choreography.md` 获取打斗分镜规则。严禁全量套用 5s 默认时长，严禁规划低于 4s 的分镜。
   - **场景强绑定**：每镜必须显式声明 scene_id。同一地点连续镜头必须指向完全相同的 scene_id。
   - **打斗分镜**：按角色类型标注打斗流派（人类/妖兽/五行使者）。五行招式须明确呈现形式。
   - **标志性镜头**：在高潮点或角色登场时规划"书法大字定格卡"（4s 特写镜头）。
   - **非战斗意境镜头**：规划慢节奏水墨空镜头与诗意转场。
9. 设计 audio_layer（独立音频轨道）：背景音乐、环境音效、打击与相克音效层。
10. **节点 A 暂停**：故事板输出后暂停，引导用户确认情节和分镜，通过后方可进入后续阶段。

### 阶段 5：逐镜视频生成与连贯性控制

11. **提示词与分镜一致性前置检查（铁律）：** 每镜视频生成前，必须核对：
    - **人物参考**：所有角色是否已在提示词中通过占位符或特征描述指代绑定。
    - **场景参考**：该镜头的 scene_id 对应的四宫格参考图是否已绑定并在提示词中显式指代。严禁在场景未绑定状态下启动生成。
    - **台词对白**：分镜中的台词是否已完整封装进语法块，对应角色声音凭证是否已正确绑定。
    - **动作/特效/运镜**：提示词中的动作描述、五行特效与运镜是否与分镜本完全吻合。
12. 生成每镜视频时，将对应的角色三视图和场景四宫格作为参考输入。若前后相邻镜头动作连贯性极高，可将前一镜视频作为动态参考引入。
13. 若镜头含角色台词，将对应角色的声音凭证作为音频参考传入，确保口型与音色跨镜头一致。
14. 视频输出分辨率严格 720p。时长严格读取故事板设定的 duration（4s-12s）。
15. **节点 B 暂停**：每批次重要资产生成完成后向用户展示。所有图像资产生成完毕后，展示完整的角色与场景绑定关系，得到确认后方可推进。

### 阶段 6：声音与配乐生成

16. **角色配音**：为有台词的角色生成 5s-10s 高保真音色采样，注册为该角色的声音凭证。若用户提供了配音样例，优先提取其音色特征。
17. **全局旁白**：生成具有古典说书人宿命感的老者声音旁白。
18. **环境与配乐**：生成传统中国风背景音乐（古筝/二胡/笛子 + 电子摇滚重打击乐）及高频刀剑打击、招式爆发音效。

### 阶段 7：时间线剪辑合成

19. 按照武打卡点和"黑白水墨闪"时值进行快速剪辑与音画对齐。利用 `render_video` 能力拼合时间线。

### 执行控制

- **资产生成前置确认（核心铁律）**：在生成任何新资产前，暂停并告知用户接下来的生成计划（含提示词或参考关系），得到用户确认后方可执行。
- **节点 A**：故事板输出后暂停确认。
- **节点 B**：资产产出后展示并确认绑定关系。

## 静默自检

交付前内部跑清单并重写弱项，不暴露给用户。

- 每个角色的三视图是否已生成/重塑并绑定？画风是否统一为雾山五行水墨武侠风？
- 每个场景的四宫格参考图是否符合"无人物、四格固定分配"规范？
- 故事板中每镜的 scene_id 是否显式声明？同一地点连续镜头是否指向相同 scene_id？
- 每镜 duration 是否在 4s-12s 范围内？是否根据动作类型动态设定而非全量 5s？
- 五行角色的爆发态色彩配比与物理光影设定是否读取并写入提示词？
- 视频提示词中角色参考、场景参考、声音凭证是否全部显式指代绑定？
- 场景四宫格的防分屏/防拼贴融合指令是否写入视频提示词？
- 台词是否封装进语法块？单句是否≤10字并标注停顿？
- 书法大字定格卡是否规划在关键高潮点或角色登场处？
- 打斗分镜的动能矢量轴线是否在连击转场中对齐？
- 写意碎落粒子是否使用物理介质描述而非 CGI/魔法粒子词汇？
- 焦墨烟尘是否被赋予炭黑与枯笔摩擦质感而非 3D 立体烟雾词汇？
- 色彩比例是否根据场景类型（文戏/对打/决战）正确选择？
- 全文语言是否与目标市场一致、无混杂？
- 资产生成前是否已暂停并获得用户确认？
