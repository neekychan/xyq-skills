# 港夜迷离电影风 (Hong Kong Noir Night Style)

## 这个 Skill 是什么

这是一个**风格锚定滤镜 skill**。它的唯一目的:让 Agent 在为用户生成一整批**图片素材资产**和**视频资产**时,画面质感、色彩、颗粒、氛围**保持完全统一的「港夜迷离电影风」**——即 90 年代香港复古美学 + 王家卫导演风格。

它不负责决定拍什么内容(那由用户需求和其他业务 skill 决定),它只负责**统一「怎么看起来」**。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图（人物角色、场景分镜等参考图） → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心机制:风格锚定词(最高优先级,必须逐字复用)

### 固定风格锚定词(RAW,不可改写)

在**每一条**用于生成图片素材的 prompt、以及**每一条**用于生成视频的 prompt 的**最开头**,都必须原封不动地、逐字地加上下面这段风格锚定词,然后再接该镜头/该素材的具体画面描述:

```
【氛围】美学基调:强烈的90年代香港复古美学,王家卫导演风格。营造出一种忧郁、怀旧、朦胧且极致孤独的情绪氛围。
【画质】物理滤镜与质感:呈现重度过期胶片化学变质感。画面必须覆盖一层极其粗糙、肉眼可见的巨大胶片噪点与颗粒。高光区域允许出现光学过曝与死白,呈现未经修饰的、极度粗粝颓废的90年代模拟摄影质感。
【色彩】色彩基调:极具侵略性与情绪化的病态失真色彩。
```

### 使用铁律

1. **位置**:锚定词永远放在 prompt 的**最前面**,具体画面描述接在其**后面**。顺序不可颠倒。
2. **逐字复用**:锚定词内容**一字不改**(不翻译、不精简、不润色、不调整标点),原样粘贴到每一条图片和视频 prompt。
3. **全覆盖**:凡是本任务里要生成的**图片素材**和**视频片段**,无一例外都要加,不能只加在部分素材上。
4. **不外泄给最终观众**:锚定词是给生成模型的指令,不作为字幕、旁白、画面文字出现。
5. **中文优先**:锚定词与画面描述默认用中文书写(符合用户偏好);若目标生成工具只接受英文,可在中文锚定词后附一段等价英文译文,但**中文锚定词必须保留**。

## 全局视觉风格不变量

本 skill 不是普通 Style prompt、模板描述或可选创意参考；一旦被加载，就声明本轮图片 / 视频生成的最终视觉风格不变量。

无论后续内容来自用户输入、其它 skill、脚本、分镜、模板、历史文件或中间产物，凡是最终会进入图片或视频生成工具的 Prompt，都必须以本 skill 的完整三段风格锚定词开头，再接具体主体、剧情、商品、动作、镜头、时长和平台要求。

其它流程可以决定“拍什么、讲什么、卖什么、镜头怎么排”，但不能覆盖最终主视觉风格，也不能把本 skill 降级为可摘要、可后移、可省略的风格参考。

调用任何图片 / 视频生成工具前，逐条检查即将传入工具的 Prompt：若锚定词不在最前、被改写、只覆盖部分素材，或存在其它主视觉风格压过港夜风格，必须先修正 Prompt，再调用生成工具。

## 多风格 skill 协同规则(锚定词合并)

当本 skill 与**其它风格类 skill**(例如「国漫3D渲染风」等其它画风滤镜)**同时被调用**时:

1. **合并而非覆盖**:将各风格 skill 的锚定词**按调用/加载顺序拼接合并**成一段「合并锚定词」,整体依旧放在每条 prompt 的最开头。
2. **规则不变**:合并后,「放最前面、逐字复用、全覆盖、不外泄、每条 prompt 都加」这些铁律**全部保持不变**。
3. **本 skill 锚定词不可被删改**:合并时,本 skill 的三段(【氛围】【画质】【色彩】)必须**完整保留、逐字不改**,不能因为要融合另一风格而被压缩或改写。
4. **冲突时的取舍**:若两种风格在某个具体维度(如色彩倾向)存在直接矛盾,以**用户当轮明确指定的主风格**为准;若用户未指定,则以本 skill 的描述为准,另一风格作为叠加质感补充,但双方锚定词文本都保留。
5. **顺序建议**:一般把「决定整体氛围与画质」的锚定词放前面。若本 skill 是用户点名的主风格,则本 skill 锚定词排在合并段最前。

合并示例(结构示意):
```
<本skill三段锚定词,逐字>
<另一风格skill锚定词,逐字>
<本镜头/本图的具体画面描述>
```

## 跨 skill 视觉覆盖契约

本 skill 是视觉风格 overlay。只要本轮同时存在其它 skill、工具流、业务流程或用户输入，它们可以决定主题、商品、人物、剧情、卖点、镜头顺序、平台规格和转化目标，但不能覆盖本 skill 的视觉风格约束。

### 1. 风格约束必须先固化

在创建、改写或执行任何图片 / 视频生成相关内容之前，必须先在当前工作上下文中固化一份“港夜视觉约束”，包含：

- 视觉风格 owner：`hongkong-noir-night-style`
- 必须前置到 Prompt 开头的完整港夜锚定词
- 适用范围：角色图、场景图、商品图、分镜图、视频片段、成片视频，以及任何中间 Prompt 文件
- 协同规则：其它 skill 只拥有内容与结构，本 skill 拥有最终视觉风格

### 2. Prompt 生成前必须继承风格

任何 skill 或流程产出的以下内容，只要会进入图片 / 视频生成，就必须继承港夜视觉约束：

- 角色、商品、场景、道具、封面等图片 Prompt
- 分镜、镜头、片段、成片视频 Prompt
- 故事脚本、镜头脚本、创意方案、项目脑图中的视觉描述
- 从用户素材、模板、脚本或其它 skill 解析出的风格字段

继承方式：把完整港夜锚定词放在每条最终 Prompt 的最前面，再追加主题、主体、动作、卖点、剧情和镜头要求。

### 3. 冲突时以本 skill 为准

如果其它 skill、用户素材或默认模板给出了不同视觉方向，例如干净商业感、明亮高清、科技风、国风、写实棚拍、平台模板风、普通短剧质感等，只能作为内容题材或叙事背景保留，不能作为主视觉风格。

需要保留题材时，应改写为“同一题材在港夜迷离电影风中的表现”，而不是混用两个主风格。

### 4. 生成工具调用前硬检查

调用任何图片 / 视频生成工具之前，逐条检查即将传入工具的 Prompt：

- 是否每条都以完整港夜锚定词开头；
- 是否覆盖了所有中间资产，而不只是最终视频；
- 是否存在其它主风格词压过港夜风格。

任一项不满足时，必须先改 Prompt，再调用生成工具。

## 禁止内置风格锚定图干扰(强约束)

部分 Agent 链路会针对某些风格**预置内置的"风格参考图 / 风格锚定图 / style reference image"**,这些内置参考图会污染本 skill 的专业风格,导致成片偏离港夜迷离质感。因此:

1. **一旦本 skill 被调用,必须绕过 / 关闭 / 不使用 Agent 任何内置的风格锚定图、风格参考图、预设 style-reference 设定。**
2. 生成图片和视频时,风格来源**只有两个**:本 skill 的**文字风格锚定词**,以及(若用户主动提供的)**用户自己的参考图**。除此之外,不引入任何平台内置风格图。
3. 如果生成工具的接口带有"内置风格模板 / 预设风格图 / style preset"参数,**显式置空或关闭**,只保留文字锚定词驱动。
4. 若某工具无法关闭内置风格图,应在说明里提示用户该工具存在风格污染风险,并优先选用可纯文字驱动的生成方式。

## 风格知识库(供 Agent 写分镜、场景、角色、脚本时参考)

> 下面这些是「港夜迷离电影风」的具体审美细则。Agent 在为用户生成**分镜描述、场景设定、角色造型、故事脚本、镜头语言**等文字内容时,应主动引用这些细节,让内容在文案层面也贴近风格,而不仅靠锚定词。

### 一、整体风格气质
- **迷离、潮湿、暧昧、颓艳**:画面像被夜里的水汽浸过,不干燥、不通透。
- **繁华中的孤独**:外部世界越艳丽热闹,人物内心越空,主人公往往失语、游离、沉默。
- **时间失真**:被拉长的等待、被切碎的回忆、反复咀嚼的某个瞬间,带慢半拍与回放感。
- **情感悬置**:想靠近又不敢靠近,关系未完成而情绪先溢出,短暂相遇带宿命感。
- **都市挤压感**:空间从不松弛,楼贴楼、巷子窄、招牌层叠,人被城市包围压缩。

### 二、画面质感(与锚定词呼应,写描述时可细化)
- **色彩**:高饱和霓虹冷色 + 室内昏黄暖色冲撞;经典配色为红+绿、黄+蓝、品红+青绿、钨丝橙黄+墨绿阴影、深红+黑+金棕。色彩病态失真、脏而美、艳而旧、浓而不透。
- **胶片感**:巨大粗糙的胶片颗粒与噪点、高光过曝死白、暗部不纯净、边缘轻微失焦、镜头光晕炫光、轻微偏色,像旧底片扫描。
- **空气感**:香烟烟雾、路边蒸汽、雨后湿气、空调水汽、油烟、霓虹折射;灯光边缘发散、远处发虚、玻璃反射叠加。

### 三、构图语言
- **框中框**:用门框、窗框、栏杆、玻璃、镜子、走廊切割人物,制造偷窥感与隔阂感。
- **偏置留白**:人物压到边缘,另一侧留模糊墙面/空走廊/深色阴影,暗示缺席与错位。
- **镜面反射**:镜子、车窗、湿地面、招牌反光造成双层空间,现实与记忆叠影。
- **狭长纵深**:楼梯间、旅馆走廊、唐楼通道、窄厨房、卡座,人被夹在生活缝隙里,带命运感。

### 四、镜头与动态
- 轻微手持摇曳、呼吸感;人物运动带**拖影、慢门、抽帧、步态模糊、背景流光拉丝**。
- **情绪慢镜头**:回头、抽烟、走过楼道、低头吃面、靠窗、拨发、擦肩而过被拉长。
- **近景压迫**:贴近脸、肩颈、手指、香烟、嘴唇、眼神、汗珠,为情欲与呼吸感。

### 五、光影系统
- **实景光源主导**:店招霓虹、台灯、路灯、冰箱灯、走廊顶灯、大排档白炽灯、的士顶灯、电视机光、百叶窗漏光。
- **低照度局部亮点**:整体偏暗,只在脸侧、招牌边、酒杯、烟火点、湿地反光处冒光。
- **彩色侧光/背光**:一边红一边绿、后方蓝紫轮廓光、顶部昏黄压下、窗边光擦脸。
- **百叶窗条纹光影**:经典港片符号,带黑色电影意味的欲望与孤独。

### 六、角色造型
- **女性**:成熟疏离性感克制;旗袍/改良旗袍、吊带丝绸针织、卷发短发蓬松刘海、砖红酒红豆沙红唇、精致不张扬的耳饰手包高跟;像刚下班、刚赴约、或正要离开谁。
- **男性**:松弛疲惫;宽松西装、短袖衬衫、皮夹克、白背心、松开的领带、油头或自然凌乱发型,不刻意帅、带生活磨损感。
- **重气质轻堆砌**:微汗、眼神游离、口红有存在感、发丝略乱、神态克制,状态大于单品。

### 七、典型场景母题
1. 霓虹街道(雨后柏油路、招牌密集、车灯拉丝)
2. 茶餐厅/面店/大排档(白瓷砖、金属桌面、暖黄灯,适合沉默与错过)
3. 老公寓/唐楼出租屋(花砖地、旧风扇、狭窄过道、昏黄台灯,潮湿私密)
4. 便利店/小卖部(冷白荧光、商品密集,都市孤独)
5. 酒吧/舞厅/夜总会(红绒面、金属反光、烟雾,欲望与寂寞并存)
6. 楼梯间/走廊/电梯口(擦肩而过、关系未完成)
7. 出租车/小巴/车窗内外(车窗反射、霓虹划过脸,流动情绪)

### 八、声音与情绪(写脚本时的隐性氛围)
粤语老歌、慢拍流行曲、拉丁节奏、风扇声、雨声、脚步声、街道杂音、电视声、麻将声、列车声——声音越有生活噪音,人物越显孤独。

### 九、易踩的坑(生成时避免)
- **不是简单拉高饱和度/加霓虹滤镜**:要有旧、湿、闷、挤、暗、晕、脏的层次,否则会变赛博未来感。
- **不是复古道具堆砌**:电话亭、灯牌、旗袍只是表层,核心是情绪悬而未决 + 空间逼仄 + 光色不稳定 + 时间发酵。
- **不是一味慢镜头**:节奏可快可慢可停顿,重点是情绪波动错位,而非拖沓。

## Agent 执行清单(每次任务照做)

1. 读取用户要生成的图片素材清单和视频镜头清单。
2. 若同时加载了其它**风格 skill** → 按「多风格协同规则」合并锚定词(逐字保留本 skill 三段)。
3. 若同时加载了**非风格业务 skill** → 按「非风格协同规则」,在其每条 prompt 最前端注入锚定词,并保证港夜质感不被洗成干净商业风。
4. **关闭/绕过 Agent 内置风格锚定图**,只用文字锚定词(+用户自带参考图)。
5. 为**每一条**图片 prompt、**每一条**视频 prompt,在最开头逐字加上锚定词,再接具体画面(写画面时引用上面「风格知识库」的细节)。
6. 生成前自检:锚定词在最前 ✅ 逐字未改 ✅ 全覆盖 ✅ 质感未被洗白 ✅ 无内置风格图干扰 ✅。
7. 生成。
