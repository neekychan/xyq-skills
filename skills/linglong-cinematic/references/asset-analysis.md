# 素材分析规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 目录

1. 角色参考图格式检测
2. 场景参考图格式检测
3. 风格一致性检测
4. 角色参考音频分析
5. 视频参考素材分析
6. 文档与剧本分析

---

## 1. 角色参考图格式检测

检测是否为全身三视图（正面、侧面、背面横向排列）。

- **符合标准** → 直接绑定到对应 character key_element。
- **不符合标准** → 标注"需重新制作全身三视图"，并提取角色形象特征供后续参考：
  - 面部比例
  - 肤色
  - 发型
  - 服装款式与配色
  - 装备型号

## 2. 场景参考图格式检测

检测是否为多角度、无人物的四宫格布局（2×2 网格）。

- **符合标准** → 直接绑定到对应 scene key_element。
- **不符合标准** → 标注"需重新制作四宫格场景图"，并提取场景关键视觉特征供后续参考：
  - 场景类型
  - 光源方向与色温
  - 主色调
  - 标志性环境元素

## 3. 风格一致性检测

对所有用户上传视觉素材检测灵笼风格一致性：

- 是否为半写实3D CG风格？
- 是否具备脏旧磨损质感？
- 色彩是否克制沉重？

**不符则标注偏差维度**（如"偏日系二次元""过于干净明亮""卡通化"），供规划模块决策。

## 4. 角色参考音频分析

提取音色特征并输出结构化描述：

1. **性别与年龄段**
2. **颗粒感**（光滑/沙哑/粗糙）
3. **语速基准**
4. **语调特征**（低沉/明亮/苍凉/冷硬）
5. **情绪基调**

供 key_element_audio 绑定及 narration_speaker_profile 使用。

## 5. 视频参考素材分析

提取四个维度输出结构化摘要：

1. **运镜特征**（固定/手持/跟随/航拍/推拉轨迹与速度）
2. **动作节奏**（快切/慢动作/实时感、剪辑频率）
3. **氛围调性**（光影风格、色温、情绪基调）
4. **场景类型匹配度**（与废土/灯塔/玛娜生态/龙骨村的对应关系）

提取的风格特征不得与灵笼风格矛盾。

## 6. 文档与剧本分析

用户上传文本文档（故事大纲、剧本、角色设定等）时，提取结构化信息：

1. **叙事节拍** —— 按幕/段落拆解推进节奏与情绪曲线。
2. **角色清单与描述** —— 外貌、性格、装备、造型变化，直接对应 key_element 设计。
3. **场景需求** —— 涉及的场景类型及关键事件。
4. **对白与旁白线索** —— 关键台词与语速倾向。

若设定与灵笼风格冲突（如日系二次元、明亮基调），标注偏差并建议调整方向。
