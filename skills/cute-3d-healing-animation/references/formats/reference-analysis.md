# 参考图分析模板

> 可适配的模式与句式，按场景改写，不要逐字照搬。

素材分析不是为了复刻，而是为了找到：为什么这张图可爱/治愈/高级/有故事感，以及哪些元素可以转化成原创软萌3D动画。

## 分析模板

### 1. 主体分析

- 画面主体是什么
- 主体的比例偏什么（头大/身大/圆润/修长）
- 角色可爱感主要来自哪里（比例/表情/材质/配色）

### 2. 表情分析

- 角色表情是什么
- 眼睛、嘴角、眉毛、姿态传达了什么
- 适合转化成什么情绪

### 3. 材质分析

- 画面材质偏什么（毛绒/软布/奶油感/柔软皮肤/陶瓷/木质）
- 适合保留的质感
- 需要避免的质感（高反光/塑料感）

### 4. 色彩分析

- 整体色调偏什么（暖/冷/低饱和/高饱和）
- 主色可以提炼为具体色名
- 辅助色可以使用
- 需要避免（刺眼/脏乱/冷灰）

### 5. 光影分析

- 光线来自哪里
- 适合转化为什么光源（晨光/夕阳光/窗边光/月光/暖室内光）
- 需要避免硬光、冷光、死白光

### 6. 场景分析

- 场景是否干净
- 视觉焦点在哪里
- 适合保留的空间方法

### 7. 故事感分析

- 这张图最适合延展成的小故事
- 角色可以从什么情绪变化到什么情绪

### 8. 原创转化方案

基于参考图，重新设计一个原创软萌3D治愈动画方案：
- 新角色（不照搬原图角色/IP）
- 新场景
- 新小事件
- 新情绪线
- 新视觉关键词

## 注意

参考图只用于分析风格、材质、构图、氛围和故事方法。不要照搬参考图中的具体角色、商标、IP特征和特殊造型。

## 落 prompt 前自检

- 分析是否覆盖了8个维度？
- 原创转化方案是否与参考图保持了风格/材质/氛围的关联，但没有照搬具体角色？
- 是否有品牌IP风险（照搬了可辨识的角色造型）？
