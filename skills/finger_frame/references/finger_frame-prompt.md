# finger_frame 重绘 Prompt 编写规范

本 skill 的玩法定位是**平行世界变身**：取景框内不是"原视频加滤镜"，而是同一个人在另一个世界的样子——全片一种**非写实漫画/动画画风**（赛璐璐、三渲二、美漫等），随手势从"该画风下的日常装扮"变身为"反差酷形象"（蒙面英雄/黑帮老大等）。变身改变的是装扮与气场，**不改变人物性别**。保持写实画风、只换装扮的输出视为失败，人脸也要重绘成对应画风的漫画脸。本文件是构造 `sandbox_generate_video` Prompt 的唯一依据。

## 一、Prompt 骨架（严格编辑任务，分阶段三重锚定）

**全片只用一种画风**（从画风库选），阶段之间变的是**身份/装扮**，不是画风——画风切来切去会稀释反差，同画风下"普通人→酷形象"的变身才是记忆点。

**单段（segments = 1）**：全片直接就是**变身后的形象**——一个阶段写到底：画风 + 变身形象（从形象库选）+ 匹配场景 + 脸部重绘句，没有"日常装扮"阶段。

**两段及以上（segments ≥ 2）**：身份递进结构——阶段一是该画风下的日常装扮，变身后是反差形象：

```
严格编辑<视频1>，按以下阶段重绘画面：
阶段一（0秒到X秒）：画面中人物双手举起、以拇指和食指张开围成矩形取景框[按原片补充实际动作]。将画面整体重绘为[画风一句]；人物保持与原视频相似的日常装扮（按画风重绘质感），人物的脸部和双手完全重绘为该画风的漫画质感：五官与手部皮肤按该画风重新绘制，不保留真实照片质感的人脸、手部与皮肤，画面中不残留任何真实拍摄质感的区域（包括手臂、饰品、背景）；背景为[原场景的该画风重绘版]。
阶段二（X秒到Y秒）：人物双手手指合拢、取景框收拢消失，随后再次张开双手重新围成取景框。从取景框重新张开的瞬间起，画风保持不变，人物变身为[反差形象：具体服装/面具/道具 2-3 件]，性别与原视频人物保持一致，气场彻底改变；背景切换为[匹配该形象的场景]。脸部与双手依然是该画风的漫画质感，不残留真实拍摄质感。
（更多段则合并进这两个阶段，时间区间、手部动作、切换时机、脸部重绘句都要写）
[对齐后缀，全文照抄，见下]
```

要点：
- **编辑任务直接写 `<视频1>`，不写 "参考<视频1>"**（否则被误判为参考任务）。
- **时间区间照抄 detect stdout 的 segment 行**（如 `segment 2: 4.96s - 10.71s` → "阶段二（约5秒到10.7秒）"），不自行推算；stdout 是唯一事实源。
- **每个阶段都要描述手部动作**：模型对"画面里正在发生什么动作"的遵循度远高于抽象指令。构造前先看原视频（sandbox_read 元信息 + 用户描述），把该阶段双手实际在做的动作写具体（举起围框/平移/合拢/交叉/拉开）；切换点必须写成"动作 → 从XX瞬间起切换"的因果句式。
- **三重锚定缺一不可**：时间区间给精度、手部动作给画面依据、"合拢再张开"手势线索兜底——单一锚定在部分模型上不稳定。
- **每个阶段必须写满三要素**，缺一不可：
  1. **画风**：**必须是非写实的绘画/动画媒介**（赛璐璐动漫、三渲二、美漫、水彩、黏土、像素等）+ 1-2 个材质/光照特征。**人脸也要按画风重绘成漫画脸**——禁止"写实电影感""胶片质感""真实皮肤细节"这类会让模型保留写实人脸、只换装扮的描述
  2. **人物装扮**：阶段一写"保持日常装扮（按画风重绘质感）"；变身阶段写反差形象的具体物件（面具/披风/西装/墨镜等 2-3 件），不写"漂亮的衣服"
  3. **场景**：阶段一为原场景的画风重绘版；变身阶段切换为匹配形象的场景（如黑帮老大→雪茄烟雾的暗色酒吧）
- 阶段数量：**至多 2 个**（日常 → 变身）。segments 更多时把相邻段合并（写成更长的时间区间），变身只发生一次——多次变身会稀释反差。
- **画风全片统一**：阶段之间禁止切换画风；变的只是人物装扮、气场与背景。
- **生成模型只负责整帧重绘，禁止在 Prompt 中提及取景框内外/蒙版/反转/合成**："框内是异世界、框外是现实"的窗口效果与手指交叉的内外反转，全部由合成脚本按模板在后期完成，与生成模型无关。Prompt 里写"框内如何如何"只会干扰模型；inversions 次数**不影响 Prompt 构造、也不增加风格数**（反转只是内外区域对调，不需要新形象），每个 segment 只写一种风格、描述整个画面。

## 二、对齐后缀（固定全文，每次照抄）

```
人物的外观可以大胆重塑（脸部、双手、服装、发型、妆造、场景按上述风格彻底改变，脸部必须重绘为对应画风的漫画脸、双手必须重绘为对应画风的漫画手，全画面不保留任何真实照片质感的区域），但必须全程严格保持与原视频相同的构图与镜头视角；人物在画面中的位置、大小、相对屏幕坐标逐帧保持不变，不要移动、放大或缩小人物；姿势与动作时序逐帧对齐；双手及每根可见手指的姿态和指尖屏幕位置逐帧对齐（对齐的是位置与动作，手部外观仍要按画风重绘）；面部朝向、视线方向、眨眼与口型逐帧对齐；不改变视频时长。保持无字幕，避免画面生成字幕，不要生成水印，不要生成 logo。
```

> 对齐的是**几何与时序**（构图/动作/指尖位置/面部朝向），重塑的是**外观**（画风/脸/手/服装/妆造/场景）——两者并不矛盾，后缀首句已显式授权外观重塑，防止模型因"严格保持"字样而只敢调色。特别注意：**"面部对齐""手指对齐"指的都是几何与时序对齐，不是保留原来的脸和手**——脸和手的画风必须变，线上实测"双手形态保持一致"这类措辞会让模型把整只手原样保留成写实照片质感。合成时框内外来自两条视频，若指尖位置漂移，框边缘会穿帮。

## 三、禁写清单（与对齐冲突，一律不写）

- 剧烈运镜、新视点、镜头推拉摇移
- 改变手部姿势、给手部添加持物
- 移动人物屏幕位置、面部特写变焦、多镜头剪辑、快速切换、改变时长
- 点名在世艺术家或暗示官方工作室联名（改为描述可观察的视觉属性）
- 单纯的调色/滤镜类描述（如"真实皮肤细节""电影感色调"单独成段）——必须伴随人物与场景改造
- 写实类画风描述（"写实电影感""胶片质感""真实皮肤/毛发细节"）——会让模型保留写实人脸只换装扮，丢掉"进入另一个世界"的画风反差
- "双手/手指的形态保持一致""手部保持不变"类措辞——线上实测会让模型把整只手原样保留成写实照片质感；只能写"姿态与指尖位置对齐"，外观交给重绘句

## 五、生成参数检查清单

- [ ] `VideoList`=[原视频（或裁剪/切段后的对应段）]，仅此一条
- [ ] `Prompt` 按骨架构造：编辑句式 + 逐阶段（时间区间照抄 segment 行 + 手部动作描述 + 手势切换因果句）+ 对齐后缀全文
- [ ] `Prompt` 全文不含"框内/框外/取景框里/蒙版/反转/合成"等后期概念——描述整个画面
- [ ] **全片单一画风**（从 4 种画风库中选），阶段间只变身份装扮不变画风
- [ ] 变身阶段含**反差形象**描述（面具/披风/西装等具体物件 2-3 件 + 匹配场景）——缺了就是"滤镜"不是"变身"
- [ ] 变身形象与原视频人物**性别匹配**（形象库"适用"列），且变身句写明"性别与原视频人物保持一致"
- [ ] 每个阶段末尾都有**脸部+双手重绘句**（"人物的脸部和双手完全重绘为[画风]的漫画质感…不保留真实照片质感的人脸、手部与皮肤"）——这是防"保留写实人脸/写实手只换装"的关键句，不可省略
- [ ] `Duration` = 对应输入视频段的实际时长（取整秒），不随意缩短
- [ ] `Ratio` 按原视频宽高比就近选（16:9 / 9:16 / 4:3 / 3:4）
- [ ] `ImageList`/`AudioList` 传 `[]`（编辑任务不需要）

## 六、切段模式的连续性（仅超长视频选"切段"时）

- 切段边界必须与 segments 边界对齐（手势合拢间隙处切，天然遮住段间跳变）。
- **画风与变身状态跨段连续**：所有段用同一画风；变身发生在哪一段，其后所有段都保持变身后形象，不回退不二次变身。
- 每段 Prompt 只写该段内出现的阶段；**阶段时间要换算为该段内的相对时间**（如全片 32~38 秒的相位，在从 30 秒切出的段里写"约2秒到8秒"）；段首直接写"视频开始时"。
