# 剪辑、音效与后期建议

## 剪辑原则

像素游戏视频剪辑必须像复古街机游戏片段，不要像电影预告片。

### 剪辑要求
- 节奏短促
- 动作反馈明确
- 每 2-4 秒有一次游戏反馈
- 尽量使用硬切
- 可以使用像素闪白
- 可以使用屏幕跳帧
- 可以使用关卡标题卡
- 可以使用复古游戏边框
- 保持低帧率节奏

### 禁止使用
- 复杂电影转场
- 大幅淡入淡出
- 真实镜头晃动
- 3D 运镜

## 15 秒剪辑节奏

| 时间段 | 内容 | 音效配合 |
|--------|------|----------|
| 0-3 秒 | 展示关卡、主角、UI、目标 | 开场 8bit beep 或 PRESS START 音效 |
| 3-7 秒 | 主角开始移动、跳跃或遇到敌人 | 走路声、跳跃声、小怪移动声 |
| 7-11 秒 | 主角收集金币、钥匙或触发机关 | 金币声、机关声、分数 tick 声 |
| 11-15 秒 | 主角通关、进入门、举起道具或定格 | 通关 jingle，UI 显示 STAGE CLEAR |

## BGM 建议

BGM 应该是：
- chiptune / 8bit loop
- 低保真电子旋律
- 方波音色
- 复古街机音乐
- 简单鼓点
- 节奏清楚
- 可循环

### 禁止使用
- 现代电影配乐
- 真实管弦乐
- 厚重史诗音乐

### 英文 BGM 提示词
```
8bit chiptune loop, retro arcade game music, simple square wave melody, playful rhythm, low fidelity electronic sound, 120 bpm, nostalgic video game atmosphere, seamless loop.
```

### 中文 BGM 提示词
```
8bit 复古街机游戏音乐，chiptune 循环旋律，方波音色，节奏轻快，低保真电子感，120 BPM，怀旧游戏氛围，适合横版卷轴冒险，能够无缝循环。
```

## UI 动效建议

UI 可以在剪辑中强化游戏感：

| 动效 | 说明 |
|------|------|
| 金币数从 00 变成 01 | 拾取金币时 |
| 分数从 0000 变成 0100 | 得分时 |
| 血条轻微闪烁 | 受伤时 |
| 生命数保持稳定 | 正常状态 |
| LEVEL 1-1 开场出现 | 关卡开始 |
| STAGE CLEAR 结尾出现 | 通关时 |
| PRESS START 闪烁 | 开场或结尾 |
| BOSS WARNING 闪烁 | Boss 关 |

UI 动效必须简单，不要做成现代游戏 HUD。

## 屏幕效果建议

### 可以添加
- 轻微 CRT 扫描线
- 轻微屏幕闪烁
- 低帧率跳帧
- 像素闪白
- 复古游戏机边框
- 轻微画面抖动
- 像素化转场

### 禁止添加
- 强烈故障艺术
- 真实镜头模糊
- 电影颗粒
- 复杂镜头光晕
- 真实景深
- 3D 屏幕变形
- 过度炫光
