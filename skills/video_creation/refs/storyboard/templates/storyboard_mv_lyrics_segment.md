# 分镜图模板：音乐 MV · 歌词逐段视觉化

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：按照歌曲的主歌/副歌/桥段/尾声或按歌词段落，将每个歌词片段映射到一个或多个画面的**歌词逐段视觉化分镜**，强调“歌词有段落、画面有对应”。
- **典型场景**：
  - 有完整歌词文本的歌曲 MV 规划。
  - Lyric Video / 歌词卡点视频。
  - 情绪氛围型音乐短视频，希望每段歌词有不同画面意象。

## 2. 判定关键词与适用边界
- 典型触发词：`按歌词段落出画面`、`每段歌词一格`、`歌词逐段可视化`、`歌词 MV`、`Lyric Video`。
- 适用判定：
  - 用户提供完整或大部分歌词文本，并希望**按段落/句子对齐画面**；
  - 关注“哪些画面对主歌/副歌/桥段负责”，而不仅是整体情绪。
- 不适用场景：
  - 只是想做情绪氛围 MV，不在意歌词逐句对应 → 可用“情绪氛围 MV 分镜”等其他 MV 模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–16 格，覆盖主歌/副歌/桥段/尾声四类乐段；
- 规划方式：
  - 先按音乐结构划分：引子 → 主歌 A → 副歌 A → 主歌 B → 副歌 B → 桥段 → 尾声；
  - 再为每一段选 1–3 个关键词歌词，对应 1–3 个画面；
  - 确保副歌位置的画面更集中、更有记忆点。

## 4. 生图 Prompt（PE）模板

```text
你是一名歌词 MV 分镜导演，请根据下述歌曲与歌词信息，设计一张 {宫格数} 宫格的“歌词逐段视觉化”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”或“16:9 横版 MV”}。

【歌曲与歌词信息】
- 歌曲名称：{歌名}
- 曲风与情绪：{如“抒情/摇滚/电子/治愈/孤独/热血”等}
- 节奏结构：{如“Intro-主歌A-副歌A-主歌B-副歌B-桥段-尾声”}
- 完整歌词：{粘贴歌词全文，保留分段}

【拆分要求】
1. 按乐段将歌词划分为：引子/主歌/副歌/桥段/尾声等；
2. 每段选 1–3 句代表性歌词作为可视化基准；
3. 为 {宫格数} 个宫格中的每一格，绑定到具体“乐段 + 句子”。

【分镜输出格式】
- 宫格编号：M1–M{N}，按歌曲时间顺序排列；
- 对于每一格输出：
  - 所属乐段：{如“主歌A / 副歌B / 桥段”}
  - 对应歌词：{逐字写出这格聚焦的歌词句子}
  - 画面内容：{人物/场景/意象，如何表达歌词含义与情绪}
  - 情绪与色彩：{如“偏冷、孤独”“暖色、释怀”等}
  - 节奏提示：{如“对齐副歌第一句进画面，在节拍第 4 拍切到下一格”}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16 面向短视频；
- 画风：{电影感写实 / 2D 动漫 / 3D 卡通 / 抽象视觉等}；
- 建议同一首歌保持统一画风与主色调，仅在桥段/尾声略微调整以体现情绪变化。
```

## 5. 一致性与避坑
- 保证**每个乐段都有对应画面**，避免整段歌词没有视觉承接。
- 副歌段落应比主歌更集中、视觉记忆点更强（构图、色彩、角色状态等）。
- 不要把太多歌词句子挤在一格画面中，导致字幕难以阅读；必要时拆成多格。
- 角色外观与场景设定在整支 MV 中需高度一致，避免“每段歌词一个完全不同人物”。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段完成“歌词 → 画面段落”映射；
  - 视频阶段以分镜图关键格为参考帧，并在 Prompt 中明确对应乐段与歌词；
  - 若有真实音轨，在生成时按时间轴对齐主歌/副歌/桥段的镜头切换。
- 适合与“歌词字幕/动态排版”模块搭配：画面负责意象与角色表演，字幕层负责歌词逐字呈现，两者节奏保持同步。
