# 粗糙低成本 CGI 风格

将用户上传图片中的主体，转换为**低质、笨拙、粗糙、廉价、民间手搓的老旧 CGI 风格**图像资产；如果用户需要视频，则必须先完成所有必要图片资产的风格化，再基于这些资产生成视频。

## 0. 最高优先级流程约束

**无论用户上传多少张图片，都必须先按本技能风格完成图片风格化转换，再根据用户意图生成视频。**

执行顺序固定为：

**上传参考图 → 逐张识别主体与用途 → 选定图像模型 → 逐张生成风格化图片资产 → 根据用户意图组织视频内容 → 选定视频模型 → 基于风格化图像资产生成视频**

硬规则：

- 不得跳过图片资产阶段直接生成视频。
- 不得只处理其中一张图片后直接进入视频生成。
- 所有会影响最终视频内容的上传图片，都必须先生成对应的风格化版本。
- 原始上传图只能用于识别主体、结构、颜色、姿势和空间关系。
- 视频模型的主要输入必须是已风格化的角色图、主体图、场景图或补充资产图。
- 如果某张上传图片是否参与视频不明确，先询问用户，不要默认丢弃。

## 1. 核心原则 + 持久引擎

**核心原则：主体身份不变，只改变渲染方式和材质质感。**

原图是什么，生成后仍然是什么：

- 人物仍是人物；
- 动物保留原物种；
- 产品保留原造型；
- 建筑保留原结构；
- 风景保留原空间布局。

不得增加主体、删除主体、改变主体身份、改变主体类别、改变核心轮廓或改变身体结构。

持久引擎：

**原始参考图 → 主体保真识别 → 粗糙低成本 CGI 风格化图片资产 → 用户意图驱动的视频脚本 → 基于风格化资产的视频生成**

## 2. 风格锚定词

每一条图片 prompt 和视频 prompt 都必须以前置的**核心风格锚定词**开始。

### 核心风格锚定词（固定，逐字复用）

> 低质、笨拙、粗糙、廉价、民间手搓的老旧 CGI 风格，模型切割粗糙，块面感明显，无高级质感，廉价贴图感渲染，2000 年代初家用电脑老旧 3D 软件效果，初学者课堂作业制作出来的廉价 CGI，早期低成本儿童 3D 动画，廉价国产 3D 动画，老式 CGI 卡通，低质量学生 3D 建模作业截图，拙劣低模 3D 质感，低分辨率斑驳贴图，呆滞表情，早期 CGI 渲染，胶片颗粒，怪诞，复古胶片，旧游戏色彩，强冷暖对比，怪核色调，老旧 CGI 默认灯光，单一方向光，硬阴影，环境光很平，缺乏全局光照，缺乏真实反射

使用规则：

- 锚定词必须完整前置，不要改写、翻译、精简或重排。
- 角色设定图 / 主体图：在锚定词后追加“白底或浅灰底、单主体居中、尽量完整展示身体或主要轮廓”。
- 场景图：在锚定词后追加场景描述，不强制白底。
- 视频 prompt：在锚定词后追加已风格化资产说明、用户意图、动作、镜头、节奏和声音描述。

## 3. 主体保真规则

生成前先锁定原图主体的：

- 类型；
- 数量；
- 身份特征；
- 主要颜色；
- 服装或毛色；
- 基础姿势；
- 主要轮廓；
- 身体结构；
- 相对位置；
- 辨识特征。

只改变渲染方式、材质、贴图、灯光和 CGI 粗糙程度，不改变主体本身。

### 动物主体

保持物种、体型比例、身体结构、头部轮廓、耳朵形状、眼睛位置、鼻口区域、四肢数量、尾巴形态、毛色、花纹、姿势和整体剪影。

不要改变动物种类，不要增加或删除身体部位，不要长角，不要变成人，不要变成牛，不要畸形变异。

### 人物主体

保持发型轮廓、五官位置、服装颜色、服装大轮廓、身体姿态、性别表达、年龄感和主要身份特征。

不要改变性别表达，不要改变年龄感，不要改变服装类型，不要增加或删除身体部位，不要改成人偶以外的新物种。

### 产品、建筑或风景主体

保持类型、数量、主要外形、颜色分布、结构比例、空间关系和辨识特征。

只改变材质和渲染风格，不改变主体类别，不增加无关元素，不删除核心结构。

## 4. 图像资产生成规则

在任何视频生成之前，必须先用选定的图像模型生成图像资产。

### 必须生成的资产

- 每张必要上传图对应的风格化版本；
- 至少 1 张角色设定图或主体设定图；
- 如用户需要视频，至少 1 张风格化场景图；
- 如主体复杂，可生成多角度、动作姿势、局部特写或道具资产图。

### 图片 prompt 结构

图片 prompt 按以下结构组织：

**核心风格锚定词 + 原图主体保真描述 + 当前图片资产用途 + 负向约束**

角色设定图 / 主体图需包含：

- 白底或浅灰底；
- 单主体；
- 主体居中；
- 尽量完整展示身体或主要轮廓；
- 保留原图主体身份、颜色、姿势、轮廓和结构。

场景图需包含：

- 与用户视频意图相关的空间环境；
- 同一套粗糙低成本 CGI 风格；
- 不抢主体；
- 不引入与原图主体冲突的新身份、新物种或新结构。

## 5. 视频生成规则

只有完成图像资产风格化后，才能使用视频模型。

视频必须基于：

- 已风格化角色设定图；
- 已风格化主体图；
- 已风格化场景图；
- 必要的补充资产图；
- 用户的视频意图；
- 本技能的主体保真规则和负向约束。

视频 prompt 按以下结构组织：

**核心风格锚定词 + 已风格化图像资产说明 + 用户视频意图 + 主体保真要求 + 镜头动作 / 分镜节奏 / 场景变化 + 负向约束**

视频表现可以包含：

- 动作僵硬；
- 镜头运动笨拙；
- 早期 CGI 式漂移；
- 运动不协调；
- 廉价动画感；
- 默认灯光和硬阴影。

视频不得重新发明主体，不得把主体变得精致、高级、写实或电影感。

## 6. 渲染执行规则

将真实摄影质感整体替换为**拙劣低模 3D 质感**：

- 毛发和头发不要真实细腻，不要一根根发丝，不要自然毛流；
- 皮肤、衣服、产品表面和建筑材质做成低分辨率贴图感；
- 模型切割粗糙，块面感明显；
- 不体现真实物体质感；
- 表面可带有低分辨率斑驳贴图；
- 画面可带有胶片颗粒、复古胶片感、旧游戏色彩、强冷暖对比和怪核色调；
- 人物或动物的眼睛可以简化为白色球体加黑色圆点，或廉价黑色椭圆；
- 五官可以略微错位，表情木讷、呆滞、半眯眼；
- 使用老旧 CGI 默认灯光、单一方向光、硬阴影和平环境光；
- 缺乏全局光照，缺乏真实反射；
- 整体像老式 3D 软件直接渲染出的低成本模型截图。

## 7. 负向约束

每次图片 prompt 和视频 prompt 末尾追加：

> 不要精致 3D，不要电影级渲染，不要真实毛发，不要高清皮毛，不要自然毛流，不要真实皮肤，不要真实布料，不要高级材质，不要皮克斯风，不要潮玩手办，不要写实摄影，不要增加主体，不要删除主体，不要改变主体身份，不要改变物种，不要改变人物性别表达，不要改变年龄感，不要改变服装类型，不要增加或删除身体部位，不要长角，不要变成人，不要变成牛，不要畸形变异，不要复杂背景，不要文字，不要字幕，不要 logo，不要水印，不要直接使用未风格化原图生成视频，不要跳过图像资产生成阶段

## 8. 工作流（SOP）

1. 确认用户已上传参考图片；没有图片则先要求上传。
2. 统计上传图片数量。
3. 逐张识别主体、用途和是否参与最终视频。
4. 锁定每张图的主体身份、颜色、姿势、轮廓、结构和辨识特征。
5. 选定图像模型。
6. 逐张生成粗糙低成本 CGI 风格化图片资产。
7. 如果用户只要图片，输出风格化图片资产并结束。
8. 如果用户要视频，先根据用户意图整理剧情、动作、镜头、场景、节奏、情绪、时长和比例。
9. 选定视频模型。
10. 基于已风格化图片资产生成视频。
11. 输出最终图片资产和视频结果。

## 9. 质量测试（可证伪）

出现以下任一情况，即判为不合格，需要重做：

- 跳过图片资产阶段直接生成视频；
- 未处理所有会影响最终视频的上传图片；
- 使用未风格化原图作为最终视频主要输入；
- 主体身份、物种、类别、数量、颜色、结构或轮廓发生变化；
- 动物变种、长角、变成人、变成牛或身体部位增减；
- 人物性别表达、年龄感、服装类型或身体结构被改变；
- 产品、建筑或风景的核心结构被改变；
- 风格变成精致 3D、电影级渲染、写实摄影、皮克斯风或潮玩手办；
- 画面出现文字、字幕、logo、水印或无关复杂背景；
- 多张资产之间画风、材质、灯光或粗糙程度不一致。

## 10. 输出契约

### 图片输出

- 白底或浅灰底的角色设定图 / 主体图；
- 必要的风格化场景图或补充资产图；
- 主体居中，尽量完整展示身体或主要轮廓；
- 严格保留原图主体身份和核心外形；
- 明确呈现粗糙、廉价、低模、老旧 CGI 质感。

### 视频输出

- 必须基于已风格化图片资产生成；
- 必须根据用户意图组织剧情、动作、镜头和节奏；
- 主体身份、结构、颜色和轮廓稳定；
- 画风、材质、灯光和粗糙程度一致；
- 动作可以僵硬、漂移、不协调，符合低成本 CGI 风格；
- 不出现字幕、文字、logo、水印；
- 不直接基于未风格化原图生成最终视频。

## 11. 静默自检

出图或出视频前确认：

- [ ] 是否已统计所有上传图片？
- [ ] 是否逐张判断图片用途？
- [ ] 是否所有必要图片都已先生成风格化版本？
- [ ] 是否没有跳过图片资产阶段直接生成视频？
- [ ] 视频是否基于已风格化图片资产生成？
- [ ] 主体身份、颜色、姿势、轮廓和结构是否保留？
- [ ] 是否只改变材质、贴图、灯光和渲染风格？
- [ ] 风格是否足够低质、笨拙、粗糙、廉价、老旧 CGI？
- [ ] 是否避免精致 3D、电影感、写实摄影、皮克斯风和潮玩手办？
- [ ] 是否没有文字、字幕、logo、水印和无关元素？
