# 利益点口播参考库 / Benefit Voiceover Library

Use this reference when writing the 3-7s and 7-12s script beats. The goal is to turn product features into human benefits with visible proof, short spoken lines, and SD2.0-friendly action logic.

## Voiceover Rule

Every benefit line must connect:

```text
用户需求 -> 商品动作/证据 -> 人话利益
```

Use one benefit per video as the main line. Secondary details may appear as short visual cues or proof close-ups.

Each spoken line should be short enough for about 2 seconds of speech. Prefer 8-18 Chinese characters. Use everyday speech rather than written advertising slogans.

## Benefit Transformation Patterns

### 1. 省事 / Convenience

Use for: 工具、小家电、App、收纳、通勤、日用品、团购流程。

Feature-to-benefit:

- 快速 -> "这个步骤省掉不少时间"
- 易操作 -> "不用研究，拿起来就会用"
- 一体化 -> "一个东西就能搞定这件事"
- 便携 -> "出门带它不占地方"

Spoken lines:

- "这个点真的省事。"
- "我最喜欢它不用折腾。"
- "拿起来就能直接用。"
- "出门带这个刚好。"
- "这个步骤一下就简单了。"

Proof actions:

- one-hand pickup
- open-use-close
- before/after process shortening
- phone tap to result
- item fits into bag or drawer

### 2. 舒服 / Comfort

Use for: 服饰、鞋、母婴、床品、个护、食品饮品。

Feature-to-benefit:

- 柔软 -> "贴身也不扎"
- 透气 -> "穿一会儿也不闷"
- 贴合 -> "动起来不勒不跑"
- 温和 -> "用完状态很舒服"

Spoken lines:

- "上身舒服是第一感觉。"
- "这个贴肤感挺自然。"
- "动起来也不别扭。"
- "它不是那种硬邦邦的。"
- "用完这个状态很舒服。"

Proof actions:

- fabric pinch and stretch
- try-on turn
- walking or sitting
- close-up texture
- user reaction

### 3. 效果 / Visible Result

Use for: 美妆、护肤、清洁、工具、健身、食品口感、摄影/数码。

Feature-to-benefit:

- 清洁力 -> "这个位置一下就干净了"
- 显色 -> "颜色上来很自然"
- 提亮/服帖 -> "看起来更精神"
- 效率 -> "几秒就能看到结果"

Spoken lines:

- "重点是结果看得见。"
- "你看这个变化很直观。"
- "这一块对比很明显。"
- "它不是只靠嘴说。"
- "我直接给你看效果。"

Proof actions:

- split before/after
- wipe or apply close-up
- swatch
- screen result
- side-by-side object comparison

### 4. 质感 / Texture And Quality

Use for: 服饰、家居、礼品、香氛、美妆、数码配件、轻奢。

Feature-to-benefit:

- 材质好 -> "拿在手里不是廉价感"
- 设计细节 -> "这个细节很加分"
- 做工 -> "边角处理得很干净"
- 包装 -> "送人也拿得出手"

Spoken lines:

- "这个质感比图片更清楚。"
- "你看这个细节处理。"
- "拿在手里不是廉价感。"
- "送人这个包装也体面。"
- "它好看但不夸张。"

Proof actions:

- slow close-up across material
- hand rub texture
- opening package
- place in lifestyle scene
- detail macro, then return to creator

### 5. 划算 / Value

Use for: 低客单、团购、食品、家清、服饰、家庭装、组合装。

Feature-to-benefit:

- 多件套 -> "这一套够用很久"
- 大容量 -> "家里囤着更安心"
- 团购价 -> "这个价吃到这些挺值"
- 赠品 -> "赠品不是凑数的"

Spoken lines:

- "这个价我觉得可以看。"
- "一套下来挺划算。"
- "家里常用的话很合适。"
- "重点是这些都包含了。"
- "这个福利别漏掉。"

Proof actions:

- lay out full bundle
- count package items
- show price/deal card on phone
- show product amount with scale anchor
- final product card CTA

### 6. 安心 / Trust And Safety

Use for: 母婴、食品、家清、服务、教育、护理、宠物。

Feature-to-benefit:

- 安全材质 -> "家里用会更放心"
- 温和 -> "日常用压力小"
- 流程清楚 -> "到店/使用不怕踩坑"
- 真实体验 -> "我试过流程再推荐"

Spoken lines:

- "家里用我会看这个细节。"
- "这个流程我走给你看。"
- "自己试过才敢推荐。"
- "日常用起来更放心。"
- "这个细节让我比较安心。"

Proof actions:

- show label or material detail
- parent hand demonstrating use
- store/service process
- clean application
- reaction after use

### 7. 好吃/好喝 / Taste

Use for: 食品、饮品、餐饮团购、零食、农特产。

Feature-to-benefit:

- 口感 -> "入口是这个感觉"
- 新鲜 -> "这个状态看着挺新鲜"
- 份量 -> "这个分量够实在"
- 方便 -> "想吃的时候很快"

Spoken lines:

- "入口这个口感很直接。"
- "这个分量挺实在。"
- "第一口我就懂了。"
- "它不是那种寡淡的味道。"
- "想吃的时候很方便。"

Proof actions:

- bite/sip reaction
- close-up texture
- plate or package amount
- preparation step
- store table spread

### 8. 体面/送礼 / Gifting And Social Value

Use for: 礼盒、香氛、饰品、家居、食品礼盒、节日商品。

Feature-to-benefit:

- 包装 -> "送人不用再二次包装"
- 设计 -> "看起来有心意"
- 组合 -> "不同人都能用上"
- 价格 -> "预算内也有体面感"

Spoken lines:

- "送人这个不会太随便。"
- "包装打开就挺体面。"
- "这个预算内很有心意。"
- "放在桌上也好看。"
- "节日送这个挺稳。"

Proof actions:

- unbox gift package
- place on table
- show contents in order
- creator holding gift
- close-up packaging and card

## Benefit Beat Template

```text
3-7s: 主体1把商品带回核心卖点，完成[一个证明动作]，镜头展示[可见证据]，主体1说 spoken_line: "[利益点口播]"，短花字: "[2-8字利益词]"。
7-12s: 主体1继续完成[结果/对比/细节动作]，用[比例参照/近景/反应]确认利益点，主体1说 spoken_line: "[结果确认口播]"。
```

## Claims Discipline

- Use user-provided claims as source truth.
- If a claim is not provided, speak from observable experience: "看起来", "用起来", "这一点", "这个状态".
- Strong medical, safety, financial, or guaranteed-effect claims require user-provided evidence; otherwise use mild experience language.
- The final video prompt should show the proof action, not only say the benefit.
