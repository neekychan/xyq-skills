# 折盒方构风格

把一段固定的「风格锚定词」注入到本次任务里**每一条**与角色相关的图片 prompt 与视频 prompt 的最开头，让同一批角色图片素材与视频成片拥有完全一致的折盒方构质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有与角色相关的东西都长成同一种画风」。

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 用户上传的角色图片素材先被风格化转绘 → 每条 prompt 头部统一注入锚定词 → 角色图片素材画风一致 → 风格化后的图像资产送入视频生成 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有**与角色相关的 prompt 开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次风格化后的任意两张角色图片、任意一段视频并排观看，若能明显看出它们「不是同一套折盒方构管线里出来的」（盒体几何感、折痕、哑印贴图、浅彩纸板色调不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一部折盒方构作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **折盒方构风格，无线稿，纸板直角折痕，材质模拟，哑印折盒贴图，高度几何化，矩形盒体方构，自然/真实色调，浅彩纸板实景色**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 使用前提（本技能的特殊工作方式）

本技能与普通「文生图」风格滤镜不同，它是**图生图（转绘）驱动**的：

1. **用户必须先上传一批自己已确定的角色相关图片素材。** 若用户还没上传素材，先请用户上传，不要凭空文生图。
2. 本技能的主职是：**通过风格锚定词把用户上传的角色图片素材做风格化转绘处理**，再把风格化后的图像资产整体送给视频生成。
3. 转绘处理时的编辑提示词**就是风格锚定词本身**——直接把上面那段锚定词逐字作为图片的编辑 / 转绘提示词，**不要再额外添加任何其他内容**，完全直接基于用户上传的原图转绘（保留原图的角色主体、构图、动作，只替换画风）。

## 转绘对象筛选规则（硬规则，务必执行）

**只有存在明确角色主体的图片才进行转绘。**

- ✅ **允许转绘：** 含明确角色主体的图片，如人物、宠物 / 动物角色等有主体的图。
- ❌ **禁止转绘：** 单独的物品图、空镜场景图、没有明确主体的风景图，一律**不转绘**、不改动、原样保留（可作为视频的场景 / 道具参考，但不进入折盒方构转绘流程）。
- 对每一张上传图片先判定「是否有明确角色主体」，判定为「无主体」的图直接跳过转绘并向用户说明「这张为物品 / 空镜 / 风景，按规则不转绘」。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条（角色相关）prompt 的**最开头**。图片转绘时锚定词即为完整编辑提示词；视频 prompt 中锚定词放最前，后接本条具体画面描述。顺序恒为「锚定词 → （视频才有的）具体画面」，不得颠倒。
2. **逐字一致：** 每条图片转绘 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要转绘的**所有**角色图片素材、需要生成的**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **图片转绘不加料：** 图片转绘阶段编辑提示词**只有锚定词**，禁止追加任何镜头 / 动作 / 场景 / 描述，完全基于用户原图。（视频阶段才写具体画面描述。）
5. **语言：** 锚定词与视频具体画面描述统一用中文书写；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它风格类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、图片转绘阶段只用合并锚定词不加料。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格类」skill 搭配时的兼容规则（务必遵守）

当本技能与非风格类 skill（如营销短片 skill、剧情短片 skill、任何决定「讲什么故事 / 做什么产物」的 skill）**同时被调用**时：

- **职责分层，不互相覆盖：** 非风格类 skill 负责「做什么」（题材、结构、分镜、卖点、时长），本技能负责「长什么样」（画风一致性）。二者叠加而非二选一。
- **本技能的注入规则具有最高优先级且不可被绕过：** 即使加载了营销短片等 skill 并按其模板产出分镜 / 脚本，最终真正送去生成的**每一条角色图片转绘 prompt 与视频 prompt，仍必须在最开头逐字注入本技能锚定词**。
- **落地方式：** 让对方 skill 先产出「画面 / 分镜 / 脚本内容」，再由本技能在**每条要生成的 prompt 头部统一注入锚定词**后才真正调用生成工具。对方 skill 的负向约束、时长、结构照常生效，本技能只在头部叠加锚定词，不删改对方内容。
- **一句话总纲：** 「别人决定拍什么，我决定它必须是折盒方构风格」——任何时候都不得因为加载了其它 skill 而跳过锚定词注入或转绘筛选规则。

## 输入

- **必需：** 用户上传的一批已确定的角色相关图片素材；本次要做的视频内容 / 意图。
- **可选：** 是否与其它风格 skill 叠加；是否与非风格类 skill（营销 / 剧情等）叠加；视频画幅 / 时长偏好。
- **素材缺失只追问缺失项：** 若用户尚未上传图片素材，请其先上传；若已给素材但没给视频意图，按 `references/story_system_prompt.md` 的默认补全策略补齐分镜，不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。
2. **接收并分类上传素材。** 逐张判定每张上传图片是否含明确角色主体（人物 / 宠物 / 动物角色）。有主体 → 进入转绘；无主体（物品 / 空镜 / 风景）→ 跳过转绘、原样保留并向用户说明。
3. **风格化转绘（逐张，图生图）。** 对每一张判定为「有角色主体」的图片，调用图片编辑 / 转绘工具，编辑提示词**就是锚定词本身（不加任何其他内容）**，基于用户原图转绘，保留原图角色主体与构图。所有角色图共用同一份锚定词。转绘后展示给用户。
4. **转绘质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏（丢主体、盒构不统一），仅重跑该图的转绘（锚定词不变），直到整批角色图观感统一。
5. **撰写动画脚本（调用随附 SP）。** 读取 `references/story_system_prompt.md`，将其作为动画故事编写的 system prompt，输入 = 「风格化转绘后的最终图像资产 + 用户的意图描述」，产出详细的高密度剧情短片分镜脚本作为视频生成参考。
6. **生成视频（逐段）。** 依据脚本，把风格化后的角色图作为视频画面参考，组装每段视频 prompt = `锚定词 + "，" + 该段镜头/动作/画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-2s / 2-5s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
7. **视频质检与返工。** 检查视频画风是否与转绘后的图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
8. **交付并展示。** 把最终的角色图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

- **图片转绘 prompt（编辑提示词）：**

```
折盒方构风格，无线稿，纸板直角折痕，材质模拟，哑印折盒贴图，高度几何化，矩形盒体方构，自然/真实色调，浅彩纸板实景色
```

（图片阶段**仅此锚定词**，不追加任何内容；基于用户原图转绘。）

- **视频 prompt：**

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作 / 分镜描述>
```

- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。

**示例（示意，具体画面按实际替换）：**

- 图片转绘（编辑提示词，直接对用户上传的角色图使用）：`折盒方构风格，无线稿，纸板直角折痕，材质模拟，哑印折盒贴图，高度几何化，矩形盒体方构，自然/真实色调，浅彩纸板实景色`
- 视频：`折盒方构风格，无线稿，纸板直角折痕，材质模拟，哑印折盒贴图，高度几何化，矩形盒体方构，自然/真实色调，浅彩纸板实景色，0-2s 纸板盒体角色从桌面弹起亮相，快速推近特写；2-5s 转身，环绕跟拍展示矩形盒体侧面折痕；5-9s 与第二个盒体角色正反打快切互动。`

## 静默自检（交付前内部跑一遍，不展示给用户）

- [ ] 用户是否已上传角色图片素材？未上传是否已请其先上传（而非凭空文生图）？
- [ ] 每张上传图是否都做了「有无明确角色主体」判定？物品 / 空镜 / 风景是否被正确跳过转绘？
- [ ] 图片转绘阶段编辑提示词是否**只有锚定词、未加任何其它内容**、且基于用户原图？
- [ ] 每一条图片转绘 / 视频 prompt 的**最开头**是否都逐字出现了锚定词（或合并锚定词）？
- [ ] 同一批任务内锚定词是否字节级一致、无任何一条被改写 / 漏注入？
- [ ] 若叠加了其它风格 skill，是否按合并规则拼接、规则未变、未删减本技能锚定词？
- [ ] 若叠加了非风格类 skill（营销 / 剧情），是否仍在每条真正送生成的 prompt 头部注入了锚定词、未被对方模板绕过？
- [ ] 撰写视频脚本时是否用了 `references/story_system_prompt.md`，输入为「转绘后图像资产 + 用户意图」？
- [ ] 转绘后图片之间、图片与视频之间画风是否通过了「同一部折盒方构作品」的一致性测试？
- [ ] 超过 15s 的成片是否才做了分段；≤15s 的是否一次生成？

发现弱项就在交付前重写对应 prompt 并重生，不要把本清单暴露给用户。
