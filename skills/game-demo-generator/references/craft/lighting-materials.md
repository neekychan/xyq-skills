# 光影与材质工艺规范

## 光影系统规范
### 全局光照设置
- 写实风格：采用物理正确的全局光照，间接光照反弹3次以上，阴影柔和，明暗过渡自然
- 风格化/奇幻：强化主光源，明暗对比强烈，体积光效果明显，暗部有补光避免死黑
- 赛博朋克：多光源霓虹照明，光源颜色丰富，反射强烈，湿滑地面有清晰的光源倒影
- 二次元：硬边阴影，阴影颜色偏冷或偏紫，无柔和过渡，高光为明显的色块

### 特定场景光影
- 室外白天：主光源为太阳光，角度45度最佳，阴影清晰，天空有环境光反射
- 室内场景：主光源为窗户天光或室内灯光，有明显的光照衰减，暗部有反弹光
- 夜晚场景：主光源为月光/灯光，对比度高，暗部细节丰富，有人工光源的辉光效果
- 战斗场景：额外添加技能光源，动态光影随技能释放变化，增强战斗氛围

## 材质参数规范
### 通用材质参数
| 材质类型 | 金属度 | 粗糙度 | 特殊属性 |
|---|---|---|---|
| 皮肤 | 0.0 | 0.3-0.5 | 次表面散射强度0.7，透射颜色为肉红色 |
| 布料（棉麻） | 0.0 | 0.8-0.9 | 无高光，纹理清晰 |
| 丝绸/缎面 | 0.0 | 0.2-0.3 | 各向异性高光，反射柔和 |
| 铁/钢 | 1.0 | 0.3-0.6 | 划痕、锈迹细节，反射环境 |
| 黄金/铜 | 1.0 | 0.2-0.4 | 有色反射，高光锐利 |
| 玻璃 | 0.0 | 0.05 | 透明度90%，折射指数1.5，反射环境 |
| 石头/混凝土 | 0.0 | 0.8-0.9 | 表面凹凸纹理，风化痕迹 |
| 木头 | 0.0 | 0.6-0.7 | 木纹纹理，磨损边缘 |
| 水/液体 | 0.0 | 0.0-0.1 | 折射、反射、波纹动画 |
| 霓虹灯管 | 0.0 | 0.5 | 自发光强度10，辉光效果 |

### 材质一致性要求
- 同一物体在不同镜头、不同光照下的材质参数保持一致
- 角色装备的材质在UI界面、实机场景、战斗镜头中表现统一
- 场景材质从近景到远景的质感过渡自然，无突兀变化
