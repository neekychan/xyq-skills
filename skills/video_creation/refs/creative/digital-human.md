# 数字人讲解视频创作指南

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 数字人大幅手势/肢体动作 | AI 生成的肢体动作易崩坏 | 限制为微动：点头、微笑、小幅手势 |
| 复杂背景与数字人争注意力 | 观众视线分散 | 使用简洁/纯色/轻微虚化的背景 |
| 台词量远少于视频时长 | 尾部大段静默，观感像卡顿 | 按台词内容量定时长（约 15-20 字/5 秒），禁止用沉默填充 |
| B-roll 要求生成表格/图表/信息图 | 模型无法渲染结构化内容 | 用实物、自然场景、动态演示替代 |
| 旁白音色不统一 | 多段拼接后声音割裂 | 角色描述中统一指定音色特征 |

## 强制规则

1. **风格选择**：用户未指定风格时**默认写实**（真人感口播效果最好）；用户指定了非写实风格或内容明显偏卡通/动漫时，按风格推荐表选择
2. **竖屏注意**：竖屏(9:16)出现胡言乱语/字幕的概率更高。用户已指定比例时照用、不回问、禁止改判；仅用户未指定时优先横屏。竖屏口播在 Prompt 强化防字幕约束

## 风格推荐

| 风格 | 适用场景 | Prompt 关键词 |
|------|---------|--------------|
| 写实/电影 | **默认首选**，真人感口播/出镜解说 | 电影级写实摄影，DSLR画质，自然光 |
| 3D皮克斯风 | 轻松科普/儿童内容 | 3D动画，皮克斯风格，圆润造型，次表面散射 |
| 日系动漫(2D) | 娱乐/二次元受众 | 2D日漫赛璐璐风格，清晰线稿 |
| 3D国漫CG | 历史/国风/武侠讲解 | 3D国漫CG风格，电影质感，次表面散射 |

其他风格详见 `creative/style-master.md` 速查表。

## 动作与表情指南

### 允许的动作（AI 可靠生成）

| 动作 | Prompt 描述 |
|------|------------|
| 点头 | 微微点头表示认同 |
| 微笑 | 嘴角微微上扬，自然微笑 |
| 歪头 | 头部轻轻歪向一侧，思考状 |
| 看镜头 | 目光直视镜头，与观众交流 |
| 小幅手势 | 单手轻轻抬起比划，幅度不超过肩宽 |
| 翻书/拿杯子 | 手持物品的微小动作 |

### 禁止的动作（AI 易崩坏）

| 动作 | 替代方案 |
|------|---------|
| 大幅挥手/招手 | 改为小幅手势 |
| 走动/站起/坐下 | 保持固定姿势 |
| 指向具体方向 | 改为 B-roll 直接展示所指对象 |
| 书写/打字 | 用画外音+画面展示代替 |
| 拥抱/握手 | 改为无身体接触的互动（点头致意、相视微笑） |

## B-roll 意象选择（多段口播）

口播过程中穿插与台词内容直接相关的辅助画面，**口播声音不中断**——声音持续，画面切走再切回。创意层只决定"配什么画面"，写进对应场的动作描述（观众看到什么）：

| 台词提到 | B-roll 画面 |
|---------|------------|
| 某个产品/物体 | 产品实物、使用场景 |
| 某个地点/场景 | 该场景实景画面 |
| 某个过程/原理 | 模拟动画、演示画面 |
| 某个数据/成果 | 数字弹出动画、图标动画 |

**禁忌**：禁止要求 B-roll 生成地图、表格、图表、数据可视化、信息图等结构化内容——模型无法准确渲染。用实物、自然场景、动态演示等具象画面替代。

**适用判定**：多段口播默认为每场设计 B-roll 意象；单段短口播（≤10s）不设计；用户明确要求"纯口播/直面镜头"时不设计，并在 creative_design.md 中注明纯口播。

B-roll 的插入频率、时长、段尾收束、景别节奏是分镜层执行参数 → `storyboard/digital-human-prompt.md`（分镜规划阶段加载）。
