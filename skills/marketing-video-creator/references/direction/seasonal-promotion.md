# Seasonal Promotion Prompt 画像

当 `primary_specialist: seasonal_promotion` 时使用。归属边界与模型编译层交接是 [`_shared-profile-preamble.md`](_shared-profile-preamble.md) 中的共享规则;请先阅读它。新增声明:本画像也不拥有固定时长。

## 目的

保留原始促销 Prompt 的指纹:活动真实、利益层级、资格条件、产品理由、达人角色、卡片或 UI、证明、获取路径与 CTA,保持可见,构成一个有节奏的信息系统。

## 必需载荷结构

按此顺序写出完整的 Prompt 载荷:

```text
【活动与事实锁】
<已核实的时机、优惠/利益、数字、单位、资格条件、截止时间、
获取路径、必需的免责声明,以及绝不能臆造的事实>

【产品身份锁】
<产品/SKU、包装、数量、套装或赠品关系、状态、证明>

【人物与表达】
<达人/主持人/顾客角色、信任基础、外形、场景、表达能量,
以及活跃时的剧情或 UGC 辅助处理>

【信息层级】
<现在为什么相关 -> 最强的已核实利益 -> 产品理由 -> 证明 ->
资格条件/获取路径 -> 一个口播 CTA>

【视觉包装与卡片/UI】
<活动图形、贴纸密度、精确提供的卡片/截图、
手机辅助、可读区域,以及从 UI 回到实物证明>

【五段式执行】
1. Hook/现在为什么相关：<可见与口播内容>
2. 核心利益或机制：<已核实的利益加资格条件>
3. 产品理由与证明：<产品动作与结果>
4. 获取路径与时机：<可读路径、时机,或已核实的截止时间>
5. 收束与行动：<产品/利益回想,以及一个口播 CTA>

【声音与连续性】
<口播/卡片中一致的精确数字与文案、音乐、拟音、产品/卡片/手机
状态、道具归属,以及结束状态>
```

这五个区块是功能性节拍,不是被强加的 15 秒模板。只有在已确认的分镜需要时,才缩放它们的时长并合并相邻功能;当资格条件、证明、获取路径或口播 CTA 处于活跃状态时,不要省略它们。

## 家族投射

- Hook 通过受众当下的需求、一个已核实的利益、产品结果、购买风险纠正、套装揭示、达人判断或已核实的时机来赢得注意。
- Style 提升可读性与活动个性,而不变成虚假紧迫感。
- Play 可以提供故事、达人、转场、挑战或揭示的容器,而促销保持对信息层级的归属。
- 卡片、截图、手机、赠品与套装是证据,具有稳定的数量与归属,而不是装饰性叠加层。

## 模型编译层交接

遵循 [`_shared-profile-preamble.md`](_shared-profile-preamble.md) 中的共享交接规则。新增必保留条款:保留已核实的措辞、就近的资格条件、产品证明、获取路径与可听 CTA。

## 检查

- 每一个数字、优惠、条件、截止时间与路径都经过核实。
- 一个利益拥有整个层级,并且在没有新信息时不重复。
- 产品理由与证明说明了这个利益为什么重要。
- 卡片/UI 处理清晰可读,不遮挡面部、手部、产品、Logo、证明或资格条件。
- 口播、可见与卡片文案一致。
