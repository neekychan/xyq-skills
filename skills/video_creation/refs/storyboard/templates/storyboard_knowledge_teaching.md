# 分镜图模板：教学 / 科普分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：服务于知识讲解、课程内容或科普说明的分镜，例如数学/物理/财商/急救等教学场景，强调逻辑清晰与信息密度。
- **典型场景**：短课预告、知识点讲解视频、实验演示、产品使用教程、平台功能教学等。

## 2. 判定关键词
- 典型触发词：`教学`、`课程`、`课堂`、`科普`、`讲解`、`学伴`、`学生`、`老师`、`教程`、`步骤`。
- 若需求以“讲明白一个知识点/流程”为目的，而非纯情绪或故事，则优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：6–12 镜，复杂课程可拆为多条短视频。
- **结构骨架**：
  1. 引题与目标（1 镜）：本节要讲什么、解决什么问题。
  2. 核心概念/公式（1–2 镜）：给出关键定义或公式，可配简洁板书/字幕。
  3. 步骤拆解或案例（3–6 镜）：一镜对应一步骤或一个案例，画面突出“输入→操作→结果”。
  4. 小结与行动（1–2 镜）：复盘要点，给出记忆口诀或行动建议。
- **景别节奏**：讲师/IP 出镜时多用中近景；板书/PPT 内容用近景或特写；注意为字幕/公式预留空间。

## 4. 生图 Prompt（PE）模板

```text
你是一名在线课程导演，请为下述知识点设计一张 {宫格数} 宫格的教学/科普分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏课程短视频”或“16:9 横版课件讲解”}。

【课程信息】
- 课程主题：{主题名称}
- 目标受众：{如“小学生/职场新人/备考学生”}
- 学习目标：{本节要解决的核心问题}

【画面风格】
- 整体风格：{如“写实教室场景 / 扁平信息图 / 2D 教学插画 / UI 截图结合”}
- 色调：{主色调，如“温暖米黄+粉色黑板”或“蓝白科技感”}，要求清晰易读。

【主体与场景】
- 讲解者：{老师/虚拟 IP/旁白+手绘角色}，外观与服饰锚定。
- 场景：{教室/实验室/桌面/手机 UI 截屏等}。

【宫格与构图】
- 宫格数：{宫格数，如 9 宫格}，按教学顺序编号 L1–L{N}。
- 每格需明确：是“引题/概念/步骤/案例/总结”中的哪一类。
- 为公式/文字内容留出明显区域，避免被人物遮挡。

【输出要求】
- 为 L1–L{N} 逐格写出分镜说明：景别 + 画面内容 + 本格要传达的知识点。
- 在说明中提示是否需要突出文字（例如“黑板上大号写出关键公式”）。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏，3 表示 16:9 横版，0 表示跟随参考图}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「知识讲述类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 仅需简单界面演示的需求可退化为「屏幕录制+轻量分镜」，避免过度复杂化。
