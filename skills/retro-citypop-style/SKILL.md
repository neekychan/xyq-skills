# 复古City Pop风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的复古 City Pop 质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一套画风 / 同一部作品里出来的」（平涂质感、描边、撞色、网点、光影不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一张唱片封面 / 同一支 City Pop MV，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **90s 日系复古商业插画、复古 City Pop 风格，波普漫画、赛璐璐平涂、黑描边、糖果撞色、明快配色，暗部丝网印刷网点、明艳夏日都市感，极装饰化，高饱和高纯度、高对比、大色块明暗对比强烈，电影级光影，大面积平涂、清晰描边，几何化构图。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格类」skill 冲突时的优先级规则（最高优先级，务必遵守）

当本技能与**非画风类** skill（如营销短片、广告脚本、分镜脚本、口播、带货、活动主视觉、故事生成等)同时被调用时：

- **职责分层，不抢戏：** 非风格 skill 负责「拍什么 / 讲什么 / 结构与节奏」（剧本、卖点、分镜逻辑、时长节奏、CTA 等）；本技能只负责「所有画面长成同一种 City Pop 画风」。两者叠加而非互斥。
- **锚定词注入不可被覆盖：** 无论其它 skill 的产物模板、prompt 模板、示例格式如何规定，**只要最终要落地生成图片 / 视频**，每一条图片 prompt 与视频 prompt 的**最开头**都必须逐字注入本技能的锚定词。其它 skill 若自带风格描述 / 画风词，将其视为「具体画面描述」的一部分，排在锚定词**之后**，不得取代或前置于锚定词。
- **格式适配：** 其它 skill 要求的分镜表 / 脚本字段（如镜号、景别、时长、台词、运镜）照常填写；只是在真正传给生成模型的那条 prompt 里，画风部分统一由本技能锚定词承担并置于句首。
- **冲突判优：** 若其它 skill 明确指示「使用某内置 / 默认画风」或「不要加画风前缀」，本技能的锚定词注入规则**优先级更高**，以本技能为准；把对方的画风指令降级为可选的画面描述参考。
- **一句话原则：** 加载了任何其它 skill，都不改变「每条落地 prompt 句首逐字注入 City Pop 锚定词」这一条铁律。

### 禁止内置风格锚定图干扰（硬约束，务必遵守）

部分 Agent 链路会针对某些风格**预置内置的「风格参考图 / 风格锚定图 / 默认风格底图 / 隐式风格垫图」**，在生成图片或视频时自动作为参考混入。这类内置参考图会污染本技能的 City Pop 画风一致性，**必须绕过**：

- **一旦本技能生效，禁用任何内置 / 默认 / 隐式的风格锚定图、风格参考图、风格垫图。** 本次任务的画风**只**由本技能的文字锚定词决定，不接受任何未经用户显式提供的参考图。
- **只允许用户显式提供的参考图。** 若用户本轮明确给了参考图 / 首帧图 / 上一步生成的素材，才可作为参考；除此之外一律不挂载任何风格参考图。
- **图生视频衔接例外：** 当需要「用前面生成的某张 City Pop 图片作为视频首帧 / 画面参考」时，该图片是本技能自己产出的合规素材，可作为参考；这不属于被禁止的「内置锚定图」。
- **调用生成工具时的做法：** 若生成工具支持关闭 / 不传风格参考、风格强度、预设风格等参数，则显式关闭 / 置空；若无法关闭，则在 prompt 中以文字锚定词为唯一画风来源，并在自检中确认产物未被内置风格带偏。
- **自检兜底：** 若发现产物出现明显不属于 City Pop 锚定词描述的画风特征（疑似被内置参考图带走），判定为受干扰，需绕过 / 关闭该参考后按纯锚定词重生。

## 风格知识库（供 Agent 写分镜 / 角色 / 场景 / 脚本时形容参考）

> 说明：本节是**创作参考**，帮助 Agent 在写「具体画面描述」「分镜」「角色设定」「故事脚本」时，让内容本身就贴合 City Pop 气质。它**不替代**锚定词——画风仍由句首锚定词负责，本节只让「画什么」也更对味。

### 整体气质
- 一句话定义：**被音乐包装过的理想化都市夏日**——夏天、都会、海风与霓虹、轻松消费主义、音乐陪伴下的浪漫独处或轻社交、对黄金年代的理想化回望。
- 情绪基调：明媚、浪漫、时髦、松弛、轻奢、青春、怀旧理想主义；不热血、不粗粝、不沉重，隔着一层「广告滤镜」的漂亮与克制。
- 本质是「都会精致感 + 度假松弛感」的混合：高楼与海岸、商业街与棕榈树、汽车旅馆与跑车、霓虹看板与蓝天白云、室内音乐设备与窗外海景并置。

### 场景母题（高频符号库）
- 都市×度假并置：高楼/商业街/屋顶 + 海岸/海湾/棕榈树/沙滩。
- 音乐文化物件（City Pop 的灵魂）：黑胶唱机、卡带机/收录机、复古音响、收音机、耳机、麦克风、DJ 设备、可视化音符与节奏线。
- 交通与移动性：敞篷车、复古跑车、游艇、公路、飞机、摩托、海边道路——强调「在路上 / 去海边 / 夜晚穿梭街区」的流动生活。
- 消费与品牌感：大字标题、包装饮料（可乐/汽水/鸡尾酒/柠檬片/冰块）、霓虹招牌、汽车旅馆 Diner/Motel 灯牌、海报式文案、商业陈列构图。
- 复古电子：CRT 电视、随身听、老式电脑、复古仪表与旋钮。

### 色彩体系
- 「设计后的色」而非自然色：高纯度、高对比、大色块平涂，少复杂渐变。
- 主色：钴蓝/天蓝/电光蓝、日落橙/番茄红/珊瑚红、柠檬黄、薄荷绿/湖水绿、桃粉/洋红/霓虹粉、奶油白/米白，配深黑描边。
- 经典搭配：蓝天+白云+红车；深蓝夜空+粉紫霓虹；热带绿叶+橙黄招牌；桃粉车身+蓝紫暮色；海洋蓝+金黄手写字。
- 冷暖对冲强但脏色少：复古但不破败、不发灰泛黄，而是被丝网印刷/商业海报语言强化后的明快复古（暗部才用丝网印刷网点提示层次）。
- 三种时间氛围可切换：正午强光蓝天（最商业热闹）、黄昏紫蓝时刻（最浪漫、最 City Pop）、霓虹夜晚（最都市、最情绪）。

### 光影质感
- 图形化光影而非物理渲染：高光概括成少量几何亮块，暗部压成统一深色面，靠强对比撑出「电影级光影」的戏剧感。
- 车漆/玻璃/水面/屏幕的「亮」来自高反差配色与硬边高光，不是真实材质渲染。
- 平涂主导：大面积纯色块 + 少量硬边阴影，几乎无摄影级明暗过渡；皮肤与衣料也走平涂。
- 复古来源 = 印刷感 + 时代物件 + 图形语言：轻网点、丝印颗粒、轻微错版/叠印感（宜轻不宜重，重则脏旧）。

### 线条与造型
- 外轮廓明确、黑色（或深色）描边存在感强，物体边界清晰，不靠模糊塑形。
- 造型几何化、简化：建筑/汽车/电视/招牌/音响处理成方块面、梯形面、圆角矩形、重复平行线、图案化窗格，带平面设计的秩序感。
- 画面偏满、信息密度高，像视觉拼贴海报；但主视觉中心明确（一位女孩 / 一台唱机 / 一辆车 / 一段大标题字），其余元素围绕它服务。
- 前中后景层次分明：前景（植物/饮料/设备/人物局部）→ 中景（主角/车/桌面/电视）→ 后景（建筑/海湾/天空/招牌）。
- 大字标题是构图的一部分（承担平衡构图、强化广告/唱片封套世界观），不是事后说明文字。

### 角色造型
- 人设关键词：自信但不咄咄逼人、明艳但不俗艳、时髦轻松略带漫不经心、都市感与海边假日感兼具——「会出现在唱片封面和度假广告里的都市女孩」。
- 五官发型：黑发或深蓝黑发、发丝有光泽大块面；五官简练、眼睛偏大睫毛明确、鼻嘴小而精致；带昭和/平成初期少女漫画 + 动画海报的处理。
- 穿搭：吊带背心、宽松外套、高腰短裤/短裙、墨镜、大耳环、耳机、凉鞋/高跟鞋、明亮撞色服饰；强调轻盈、青春、消费时代时髦感。
- 比例偏修长，表情轻快自信，是「时代情绪的代言人」而非写实肖像。

### 与相邻风格的边界（避免跑偏）
- 不是「泛黄做旧」复古：拒绝旧纸磨损、脏灰、年代感写实；要干净鲜亮、现代设计化复古。
- 不是 Vaporwave：拒绝数码故障、雕像/网格/纯电脑图形的赛博拼贴；要夏日现实场景 + 都市休闲消费 + 有人物生活气息。
- 不是普通日系动漫海报：必须带都市/海滨环境 + 商业设计感 + 音乐或广告符号 + 生活方式意象，而非只有人物与叙事。

### 写脚本 / 分镜时的取材建议
- 场景优先选：海边公路兜风、屋顶露台黄昏、商业街霓虹夜、汽车旅馆/Diner、海湾游艇、听歌的房间（唱机/耳机/CRT）。
- 每个镜头尽量落一到两个 City Pop 符号（车、唱机、招牌、饮料、棕榈、耳机），并给明确的时间氛围（正午/黄昏/霓虹夜）。
- 情绪推进宜轻盈舒展、留白浪漫，配合「正在放歌」的背景感；避免强冲突、悲情、写实苦难基调。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否叠加非风格类 skill（如营销短片）；视频画幅 / 时长偏好；是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，参照上文风格知识库补齐一版贴合 City Pop 的分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。同时确认已按「禁止内置风格锚定图」约束关闭 / 不挂载任何非用户显式提供的参考图。
2. **（如叠加非风格 skill）先出脚本 / 分镜，再落画风。** 让非风格 skill 完成剧本、卖点、分镜结构、时长节奏；本技能只在每条要落地生成的 prompt 句首注入锚定词。
3. **生成图片素材（逐张）。** 对每一张需要的图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`，然后生成图片。所有图片共用同一份锚定词。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏（含疑似被内置风格图带走），重写该图的**具体画面**部分（锚定词不动）、确认已绕过内置参考图后重生，直到整批图片观感统一。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该 City Pop 图片作为视频的画面参考（属合规参考，非内置锚定图），视频 prompt 仍在头部注入锚定词。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
7. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
