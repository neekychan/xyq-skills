# 流派 06: 唯美情绪蒙太奇 (Impressionist Vibe)

* **适用曲风**：独立音乐 (Indie)、Ambient、治愈系氛围、时尚大片、轻音乐
* **视听公式**：`[微距材质（发丝/水滴/光斑）] + [逆光丁达尔体积尘埃] + [慢快门动态模糊] + [情绪流动]`
* **表演配比**：0% 唱演，全片纯视觉意境与情绪流动，自动跳过所有口型相关设置。

---

## 一、正交积木库

* **起手式**：`极近距离微距拍摄眼睫毛上的水珠颤动` / `阳光透过白色亚麻窗帘在地板投下斑驳光影` / `指尖轻轻滑过水面泛起涟漪`
* **动作与调度**：`主角在逆光麦田/海边缓慢回眸` / `白色裙摆随海风轻柔摆动` / `仰望树梢漏下的破碎阳光`
* **光影与材质**：`暖金夕阳低色温光线` / `大光圈浅景深产生的奶油般虚化圆形光斑 (Bokeh)` / `空气中漂浮的金色微尘`
* **爆发与收尾**：`一阵强风吹过发丝完全遮住镜头随后拉开` / `夕阳完全沉入地平线，画面过渡为深蓝夜色并定格`

---

## 二、语法示范（15 秒 3 阶段唯美意境）

35mm胶片人像质感，85mm大光圈浅景深定焦镜头，暖金夕阳光线与柔和丁达尔效应，微弱胶片颗粒与奶油般圆形光斑(Bokeh)。女主角在黄昏海边漫步。

严格跟随 @视频1 的音频作为 BGM，不擅自编曲，全段纯视觉与情绪意境。

保持无字幕，不要生成水印/logo，画质细腻无噪点，人物形体稳定自然，严格以@视频1中的音频作为全片唯一背景音乐，严禁生成任何与@视频1无关的背景音乐或杂乱音轨。
