# 彩铅线条风格

把一套**固定不变的风格锚定词**，完整、原样地复用进本技能处理的**每一张图片素材**与**每一条视频 prompt**的最开头，从而保证同一批素材与最终成片的画风、笔触、色调、质感完全一致。

## 1. 核心原则 + 持久引擎

**核心原则：风格靠"锚定词前置"锁死，剧情靠"图像资产驱动"生长。** 画风一致性不是靠每次现编描述，而是靠把同一段风格锚定词原封不动地放在每一条生成 prompt 的最前面；剧情与运镜则完全围绕用户上传并已风格化的图像资产来发散。

持久引擎（因果链）:
**用户上传图片资产 → 风格锚定词前置转绘（锁画风）→ 得到统一画风的图像资产 → 结合用户意图用动画故事方法编写高密度分镜 → 风格锚定词前置的视频 prompt → 统一画风的动画成片**

### 风格锚定词（固定，逐字复用，不可改写）

> 彩铅风格，细线/轻线稿，灰铅发散潦草手绘，轻微肌理，铅粉速写纸粒，写实/自然形态，蓬松头像，低饱和/莫兰迪，灰阶赭点

- 这段锚定词必须**原样出现在每一条图片 prompt 与每一条视频 prompt 的最开头**，一字不改、不精简、不翻译、不重排。
- 图片风格化转绘时，**直接把上面这段风格锚定词当作图片编辑提示词使用，不要额外添加任何其他内容**——完全基于用户上传的原图转绘。
- 视频 prompt 里，锚定词放最前面，其后再接由动画故事方法生成的分镜正文。

## 2. 质量测试（可证伪）

一次成片如果满足以下任一条，即判不合格，必须重做：
- 任何一张风格化图片或任何一条视频 prompt 的开头**没有原样前置完整的风格锚定词**；
- 风格化转绘时**掺入了锚定词以外的编辑描述**（如"更精致""换背景""加特效"），导致偏离原图；
- 成片中角色的画风、笔触密度、纸粒质感、色调在不同镜头间**不一致**；
- 最终画风偏离"彩铅 / 轻线稿 / 低饱和莫兰迪"的目标质感（如变成高饱和、写实照片、赛璐璐等）。

## 3. 输入诊断（落 prompt 前必须想清楚的维度）

- **图片资产（必需）**：用户是否已上传一批确定的图片（角色 / 场景分镜）？没有则先要求上传，不得凭空生图。
- **资产类型**：每张图是角色主体、还是纯场景 / 空镜 / 单独物品？（转绘策略见工作流）
- **创作意图**：用户想讲什么故事 / 什么情绪 / 什么题材？
- **产物类型**：只要风格化图片，还是要图片 + 视频动画成片？
- **成片时长**：默认 15 秒（≤15s 一次生成完整成片；>15s 才拆成多个 ≤15s 片段再拼接）。
- **是否叠加其他风格技能**：若同时加载了其他风格类技能，按「多技能协作规则」合并锚定词。

## 4. 多技能协作规则（硬规则，冲突时优先执行）

### 4.1 与其他"风格类"技能搭配 —— 锚定词合并
- 当本技能与另一个风格类技能同时生效时，**把两套风格锚定词的内容合并**成一段，仍然整段前置到每一条图片 / 视频 prompt 的最开头。
- 合并后**规则不变**：仍是逐字复用、原样前置、图片转绘只用合并后的锚定词、不额外加描述。

### 4.2 与"非风格类"技能搭配（如营销短片、剧情短片等）—— 风格优先、职责分层
- 即便同时加载了非风格类技能（例如营销短片、带货短剧、故事分镜类技能），本技能对**画风、笔触、色调、风格锚定词前置**的要求**必须无条件保留并优先执行**。
- 职责分层：非风格类技能负责它擅长的部分（如营销卖点结构、剧情节奏、投放平台规范），本技能负责**风格锁定**——两者结合，而不是相互覆盖。
- 具体结合方式：先按本技能把图片资产风格化；再让非风格类技能产出剧情 / 卖点 / 结构；最终视频 prompt = **本技能的风格锚定词（置于最前）** + 非风格类技能产出的正文。任何情况下，锚定词前置这一条不得被非风格类技能的模板挤掉。

## 5. 工作流（分步骤 SOP）

### 阶段一：图片素材风格化（必做，先于视频）

> 用户必须先上传一批自己已确定的图片资产。本阶段把这些素材统一套上彩铅线条风格。

1. 读取用户上传的每一张图片。
2. 判断该图是否含**明确的角色主体**（人物、拟人角色、宠物等）：
   - **含角色主体的图 / 场景分镜**：进行风格化转绘。
   - 纯物品图、空镜、无明确主体的风景图：如用户要求可转绘；否则可按用户意图保留。
3. 对每张需转绘的图片，执行图生图风格化编辑：**编辑提示词 = 风格锚定词（原样、完整），不追加任何其他内容**，完全基于用户原图转绘，保持原图的构图、主体、姿态、场景关系不变，只改变其为彩铅线条画风。
4. 若叠加了其他风格技能，编辑提示词改用**合并后的锚定词**（见 4.1），其余不变。
5. 逐张产出风格化图片，汇总成一套"统一画风的图像资产"，供阶段二使用。

### 阶段二：动画故事编写与视频生成（按需）

1. 把阶段一得到的**全部风格化图像资产** + **用户的意图描述**，一起交给本技能内置的动画故事编写方法（见 `references/story-director-system-prompt.md`），生成一段高密度、剧情完整、运镜丰富的中文视频提示词与分镜脚本。
2. 组装最终视频 prompt：**风格锚定词（原样置于最前）** + 故事方法产出的分镜正文。若叠加其他技能，锚定词用合并版并始终置顶。
3. 生成视频：
   - 成片 **≤15 秒**：用一次视频生成即可拿到完整成片，beat 分镜（0-2s / 2-5s / …）是同一条 prompt 内部的时间轴描述，不需要分段多次生成。
   - 成片 **>15 秒**：拆成多个 ≤15s 片段分别生成，再做后处理拼接、配乐、必要的收尾。
4. 把风格化图片与最终视频展示给用户。

## 6. 必读 reference（硬规则）

- 编写动画故事脚本与视频分镜前，**必须**读取本技能下的 `references/story-director-system-prompt.md`，并严格按其规则产出高密度剧情短片提示词（含节奏密度约束、运镜密度、角色锁定、声音分层、镜头连贯、场景规则等）。
- 该 system prompt 是本技能视频脚本产出的唯一方法源，不得凭记忆糊或跳过。

## 7. 输出契约

- **风格化图片**：每张对应用户上传的一张原图，画风统一为彩铅线条风格，构图 / 主体 / 姿态保持与原图一致。
- **视频 prompt**：结构固定为
  `风格锚定词（原样，最前）` + `按 references/story-director-system-prompt.md 输出模板生成的分镜正文（风格题材 / 一句话剧情 / 角色锁定 / 画面提示词含时间码 beat / BGM / 环境音 / 台词 / 画面质感 / 默认负向约束）`。
- **视频生成方式**：≤15s 成片一次生成完整片段；>15s 才分段生成后拼接。
- **默认负向约束**（挂在视频 prompt 末尾）：严格按上传图片与彩铅线条风格生成，保持无字幕、不要生成任何文字；不要生成 logo 与水印。
