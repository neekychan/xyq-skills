# 美式游戏概念艺术风 (American Game Concept Art Style)

## 这个 Skill 是什么

这是一个**「风格滤镜」技能**。它不负责生成图片或视频本身,而是负责保证:**同一个项目里,所有图片素材资产和所有视频片段,都长在同一套美术风格里**。

它的工作方式非常简单直接:

> **在每一条即将送去生成图片 / 视频的 prompt 的最开头,原封不动地拼接下面这段「风格锚定词」,然后再接具体画面描述。**

不管这条 prompt 是用来生成:
- 角色立绘 / 场景概念图 / 分镜关键帧 / 道具素材 (图片资产)
- 首帧图生视频 / 文生视频 / 视频延长片段 (视频资产)

**开头都必须是同一段风格锚定词**,这样才能让整批素材和成片风格统一、可复用。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 【核心资产】风格锚定词 (Style Anchor)

⚠️ **这是本 skill 的唯一真理源。以下这段文字必须逐字、完整、原样拼接到每一条生成 prompt 的最开头,不得删改、不得意译、不得精简、不得替换顺序。**

```
双城之战同人艺术风格,2D 动漫,美国游戏概念艺术风格,硬朗线稿,块面厚涂,赛璐璐阴影,欧美 AAA 游戏概念美术、数字油画厚涂、电影级戏剧光影、蒸汽朋克与魔法科技幻想的高完成度视觉风格。画面具有明显手绘笔触与材质纹理,色彩以中低饱和为底、局部高纯度点缀,强调冷暖对比、情绪光和世界观叙事,整体呈现出粗粝、华丽、压抑、史诗化的美术气质。
```

### 拼接格式(强制)

```
<风格锚定词>,<本条画面的具体描述>
```

**示例:**

```
双城之战同人艺术风格,2D 动漫,美国游戏概念艺术风格,硬朗线稿,块面厚涂,赛璐璐阴影,欧美 AAA 游戏概念美术、数字油画厚涂、电影级戏剧光影、蒸汽朋克与魔法科技幻想的高完成度视觉风格。画面具有明显手绘笔触与材质纹理,色彩以中低饱和为底、局部高纯度点缀,强调冷暖对比、情绪光和世界观叙事,整体呈现出粗粝、华丽、压抑、史诗化的美术气质。一个红发少女站在蒸汽弥漫的地下工坊里,手握发光的能量核心,侧逆光勾勒轮廓,冷青色环境光配暖金色核心高光,厚涂笔触,电影级构图。
```

## 强制规则 (MUST FOLLOW)

### 规则 1 — 锚定词永远在最前面
每一条图片 prompt 和每一条视频 prompt,**第一段文字必须是完整的风格锚定词**,然后才是本条画面的具体内容。不允许把锚定词放中间或结尾,不允许只放一部分。

### 规则 2 — 全资产覆盖,无一例外
一个项目里所有需要生成的视觉资产都要套用,包括但不限于:
- 角色设定图 / 立绘 / 表情动作图
- 场景概念图 / 分镜关键帧 / 背景板
- 道具、装备、载具、UI 元素等素材
- 所有视频片段(文生视频、图生视频、视频延长)

**只要是走生成的视觉资产,开头都必须带锚定词。** 文生视频与图生视频的 prompt 同样适用。

### 规则 3 — 与其他【风格类】skill 搭配时:合并锚定词,规则不变
如果本 skill 与另一个风格类 skill 同时被调用(例如同时要「美式游戏概念艺术风」+「复古 DV 风」),则:
- **把两段风格锚定词按"本 skill 锚定词在前、其它风格锚定词在后"的顺序合并拼接**,用逗号连接,共同构成新的合并锚定词;
- 合并后的锚定词**整体**依然放在每条 prompt 的最开头,规则 1 / 规则 2 完全不变;
- 若多个风格描述出现语义冲突(如两者对饱和度要求相反),以本 skill 的描述为准,冲突项以本 skill 优先。

合并格式示例:
```
<本skill锚定词>,<其它风格skill锚定词>,<本条画面的具体描述>
```

### 规则 4 — 与【非风格类】skill 冲突时:本 skill 的风格约束优先且必须共存
当本 skill 与非风格类 skill 同时被加载时(例如同时调用「营销短片 / 短剧 / 分镜脚本 / 视频生成」等流程类、内容类 skill):
- 那些 skill 负责**流程、脚本结构、镜头编排、叙事节奏、分镜数量、时长控制**等;
- 本 skill 负责**所有最终送生成的图片 / 视频 prompt 的视觉风格**;
- **两者必须共存,不是二选一。** 即使加载了营销短片 / 短剧等 skill 并按它的流程产出脚本和分镜,**最终每一条真正送去生成图片和视频的 prompt,仍必须在最开头拼接本 skill 的风格锚定词**;
- 其它 skill 如果自带风格描述、示例风格词或默认画风,**一律以本 skill 的锚定词为准**,不得覆盖、不得省略本 skill 的锚定词;
- 生成脚本、分镜、场景与角色的文案描述时,应参考本文档后面的「风格知识库」,让叙事与画面描述本身也贴合本风格气质。

### 规则 5 — 禁止内置风格锚定图干扰(重要)
某些 Agent 生成链路会针对特定风格**预置内置的"风格参考图 / 风格锚定图 / style reference image"**,这些内置参考图会干扰甚至污染本 skill 的资产生成,导致成片偏离目标风格。因此:
- **在本 skill 被调用的情况下,必须绕过 / 关闭 / 忽略 Agent 链路中任何内置的风格锚定图、默认 style reference、预置风格图设定;**
- 风格的唯一来源是**本文档的文字风格锚定词**,不依赖任何内置参考图;
- 如果生成工具或链路强制要求传入风格参考图,**优先选择"不传参考图 / 传空 / 使用纯文本风格"** 的模式;若确实无法关闭,则使用**本项目内自己已生成的、已符合本风格的素材**作为参考图,严禁使用 Agent 内置的、非本项目的风格锚定图;
- 任何时候,内置风格图都不得覆盖文字锚定词所定义的风格。

### 规则 6 — 锚定词零改写
风格锚定词是打磨好的成品,**禁止**在拼接时做任何"优化""润色""翻译成英文""缩写""改标点""改语序"。要英文版可作为补充另附,但送生成的中文 prompt 里用的必须是原文锚定词。

## 风格知识库(供 Agent 生成分镜 / 场景 / 角色 / 脚本时参考)

> 下面这部分不是拼进 prompt 的锚定词,而是**知识参考**:当 Agent 需要写分镜脚本、设计场景、刻画角色、编写故事风格文案时,应主动往这些特征上靠,让叙事内容本身也贴合本风格,再叠加锚定词生成,效果最统一。

### 整体气质
- 宏大、戏剧化、情绪浓烈;高贵但粗粝;写实中带强设计感。
- 画面像高完成度概念设定图,却又有完整影视镜头的沉浸感——"会动的顶级游戏原画"。
- 关键词:粗粝、华丽、压抑、史诗化。

### 角色造型
- 结构真实感强但做英雄化 / 戏剧化强化:五官立体、骨点清晰、鼻梁眉弓颧骨下颌线明确,轮廓有雕塑感。
- 表情张力大、微表情丰富。
- 服装即叙事:能看出身份、阶层、功能、地域文化;贵族 / 学院 / 工业 / 贫民 / 地下改造风格区分鲜明;常带机械感、维多利亚感、蒸汽朋克感、炼金科技感;皮革、金属、织物材质区分明显。

### 材质与画面质感
- 明显手绘笔触:硬朗线稿 + 块面厚涂,边缘不绝对干净,阴影带笔触感,保留颜料堆叠 / 擦抹 / 干刷纹理。
- 赛璐璐阴影与厚涂结合:块面分明但过渡有绘画感。
- 材质厚重、旧化、颗粒化:皮肤细腻不塑料;金属有磨损氧化;墙体街道机械带脏污裂纹灰尘;空气里常悬浮烟尘、蒸汽、潮气、工业颗粒——世界像被真正使用过。

### 光影(戏剧光 / 情绪光)
- 强明暗对比,大面积暗部 + 局部高亮;大量逆光、侧光、轮廓光。
- 光带色彩倾向:冷蓝、暖金、毒绿、霓虹紫红;烟雾尘埃蒸汽让光束可见,增强空间层次。
- 光在讲故事:暖金光=秩序 / 文明 / 上层;冷青绿紫霓虹=危险 / 污染 / 地下科技 / 异化;红光=冲突 / 暴力 / 崩坏。

### 色彩系统
- 中低饱和底色 + 局部高纯度强调色;冷暖对比明显。
- 常见配色编码:
  - 金 / 米白 / 深蓝 / 古铜 → 上层文明、学院、精英秩序;
  - 墨绿 / 青蓝 / 紫红 / 荧光粉 → 地下科技、危险实验、混乱能量;
  - 灰褐 / 铁锈红 / 脏黄 / 暗黑 → 工业区、机械废土、贫民气息。
- 用色服务于:阵营区分、阶层区分、情绪推进、心理变化——是"叙事编码配色"而非单纯好看。

### 场景设计
- 世界观密度高但不乱,前中远景层次分明;机械结构、管道、桥梁、塔楼、烟囱构成复杂城市肌理。
- 风格融合:蒸汽朋克 + 维多利亚工业美学 + 魔法 / 炼金科技 + 美式幻想城市 + 末世地下空间。
- 常见对比:华丽学院式建筑 vs 老工业钢铁骨架 vs 发光能量核心 vs 肮脏潮湿危险的地下街区。

### 镜头与构图
- 强透视、大前景压迫 + 远景纵深;倾斜构图、对角线构图、中心聚焦。
- 角色常置于巨大空间 / 结构体 / 灯光装置中形成史诗感;画面边缘常压暗、虚化、留纹理突出主体。
- 景别:特写强调脸部结构 / 情绪 / 笔触 / 皮肤层次;中景强调人物与环境关系;全景强调城市结构与世界观规模。每帧都像可单独做海报的原画。

### 动态表现(视频尤其注意)
- 动作带重量感,非纯流畅卡通;停顿 / 爆发 / 挥击 / 坠落有物理冲击力。
- 运动中保留绘画式拖影、烟尘、碎屑、光效残留;情绪爆发镜头带强烈构图变化和色彩爆点。
- 融合"游戏宣传片冲击感"与"动画叙事表演性"。

### 可选叙事基调适配
- 若项目需要女频 / 轻松诙谐基调,可在保持上述美术质感的前提下,让角色表情更灵动、加入可爱 IP 元素(如猫等),用暖金光与轻快节奏中和"压抑",实现"华丽史诗质感 + 轻松诙谐叙事"的平衡。

## Agent 使用流程(建议)

1. **接收创作需求** → 确认这是一个需要统一风格的图片 / 视频批量生成项目。
2. **忽略内置风格图** → 按规则 5,关闭 / 绕过链路中任何内置风格锚定图,只以本文档文字锚定词为准。
3. **写脚本 / 分镜 / 角色 / 场景** → 参考「风格知识库」,让文案描述本身贴合风格气质;若有营销短片 / 短剧等流程 skill,按其流程产出结构(规则 4)。
4. **组装每条生成 prompt** → 一律 `<锚定词> + , + 具体画面描述`;若同时有其它风格 skill,先按规则 3 合并锚定词。
5. **逐条生成图片资产** → 每条图片 prompt 开头都带锚定词。
6. **逐条生成视频资产** → 每条视频 prompt(含图生视频 / 文生视频 / 延长)开头都带锚定词。
7. **自检** → 生成前逐条核对:开头是否是完整原文锚定词?是否所有资产都覆盖?是否绕开了内置风格图?

## 自检清单 (Checklist)

- [ ] 每条图片 prompt 最开头是完整、逐字、未改写的风格锚定词?
- [ ] 每条视频 prompt(含图生视频 / 文生视频 / 延长)最开头也是同一段锚定词?
- [ ] 项目内所有视觉资产(角色 / 场景 / 分镜 / 道具 / 视频)都覆盖到了?
- [ ] 与其它风格 skill 搭配时,已按"本 skill 在前"合并锚定词,规则不变?
- [ ] 与营销短片 / 短剧等非风格 skill 共存时,最终生成 prompt 仍强制带本 skill 锚定词,未被其默认画风覆盖?
- [ ] 已绕过 / 忽略 Agent 链路中所有内置风格锚定图?
- [ ] 锚定词零改写、零翻译、零精简?
