# 国漫3D渲染风短剧

将东方审美叙事、高精度三维建模与动画化渲染贯穿同一部短剧。题材、时代和世界观由故事决定，国漫3D渲染风格在所有题材中保持一致。视觉标准采用固定风格契约，内容制作覆盖从剧本到成片；只执行用户本次要求的阶段，已有成果从最近的有效阶段接续。

## 固定风格契约

每一条**最终提交给图片或视频工具的正向 prompt**，以及交付给用户直接复制的完整视觉提示词，必须从第一个字符起逐字保留以下前缀：

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。
```

- 不删字、不翻译、不重排、不用“同上/沿用风格/STYLE_ANCHOR”替代。镜号、标题、角色描述、图片占位符、英文正文均放在此前缀之后或 prompt 字段外；负向提示词留在负向字段或正文尾部。中文前缀在英文正文中也保持不变。
- 适用范围包括角色/场景/道具设定图、换装、图像编辑、风格转化、分镜首帧/尾帧/关键帧、补帧生成、图生视频、文生视频、视频编辑/延长和失败重试。纯截帧、裁剪、转码、拼接和音频任务不机械注入视觉前缀。
- 风格文本是唯一风格来源。**禁止主动调用或注入内置风格参考图、预置风格底图、平台风格样例和外部风格图。** 角色图、场景图、道具图及合格跨镜帧只用于身份、造型、布局或连续性，不赋予其风格控制职责。每张参考图登记来源和用途；详见 [风格契约与视觉知识库](references/style-guide.md)。
- 本 skill 内制作模板不得覆盖此风格契约。外部内容工具仅填充具体画面、动作和音频内容；不自动叠加其他风格。用户明确要求兼容的附加风格时，原锚定词仍完整置首，附加描述紧随其后，并检查是否冲突。
- 约束限于本项目的视觉任务，遵守宿主指令和用户明确选择；不声明超越系统权限，也不在无关任务中永久生效。用户明确要改成其他主风格时，说明本 skill 的适用范围已变化。

## 跨题材边界

固定前缀中的“东方奇幻动画美术风格”定义视觉表现，不要求剧情必须是东方古代、修仙或神话。现代人物可以穿西装、校服、运动服，使用手机、汽车；科幻人物可以穿机能服、操作舱门与机器人。材质、光影和动画化建模始终按风格契约执行。

将项目记录为“题材 + 时代/世界观 + 允许/不应出现的元素 + 台词语体 + 音乐方向”。只有世界观明确为古代时才排除不合设定的现代物品；穿越、混合时空和未来社会按各自规则处理。不得因套用旧模板把现代角色改穿古装、把手机改成玉佩或把自然口语改成文言。具体适配见 [跨题材制作规则](references/genre-adaptation.md)。

## 资产图先行，视频后置

固定依赖链：**剧本/素材分析 → 列齐核心角色、场景和关键道具 → 在固定风格下生成或验收全部核心资产图 → 依托有效资产和分镜生成视频。**

核心资产指本次制作范围实际需要的全部角色造型、场景视图、关键交互道具；只做一镜时按该镜范围，做一集时按全集范围。草拟分镜可与资产规划交错，但核心图未齐不得调用视频生成。缺图或风格不合格时回退补齐；用户已有符合风格的图可验收复用，无需重画。

唯一流程例外是用户明确要求“跳过资产图 / 直接出视频 / 不需要出图”。记录原话和适用范围后可跳过出图；固定风格前缀、人物文字设定、空间校验仍执行。“一键完成”“继续”本身不等于要求跳过资产。

## 启动与范围

先读取已提供的文件和现有制作记录，不要求用户重复上传或重复回答。

| 输入状态 | 接续方式 |
|---|---|
| 只有点子/粗纲 | 梳理人物欲望、阻力、核心冲突与结尾钩子，形成可拍摄剧本草稿，再做资产与分镜 |
| 小说/原文 | 提取可见行动和因果链，给出符合原题材和世界观的短剧改编方案；保留来源映射，不能把原文没有的情节当原著事实 |
| 剧本或半成品 | 盘点已有剧本、镜表、资产、音频、视频，补当前阶段的缺口；保留已确认内容 |
| 材料齐全 | 验收风格、身份、空间和引用有效性，直接接续用户要求的阶段 |
| 只要分析/分镜/提示词/审查 | 交付该阶段成果；不因技能覆盖全流程而自动调用媒体生产 |

记录题材、时代/世界观、允许与排除的元素、台词语体、音乐方向、目标集数与时长、画幅、语言和已有资产。画幅默认 16:9 横版；中文剧本和中文正文为默认，用户可改；固定中文风格前缀始终不变。用户未指定目标时长时，按现有内容估算并写明假设。

普通外貌、陈设、分镜与参数细节可在授权创作范围内提出可修改草稿，不逐项阻塞。会改变故事走向、角色身份、用户定稿或依赖缺失关键素材的事项集中说明。原稿的分析与改写分开记录；用户否决的修改不得写回。

## 完整制作流程

### 1. 剧本分析与内容开发

输出故事类型、成熟度、人物关系、核心冲突、情绪转折、开篇约 3 秒吸引点、结尾钩子，以及角色/场景/道具和素材缺口清单。为原文关键动作、台词、伏笔建立镜号去向，避免分镜漏戏。

仅有点子则写成可拍摄剧本；已有剧本则按请求分析或优化。对白依题材、时代、年龄和身份设计：现代口语清楚自然，古风可雅致，科幻术语需可理解。动作和目光承载潜台词，表演幅度服从喜剧、悬疑、情感等实际类型。镜头可放大关键转折，但不能凭空添加冲突或让每句台词都爆发。草稿与定稿状态分开。

### 2. 全局制作参数与资产登记

锁定画幅、目标时长、输出规格、风格前缀、色彩方案和世界观边界。登记稳定的 `character_id`、`look_id`、`scene_id`、`prop_id`、角色声音档案及对应文件。

角色记录年龄感、脸型、五官、体态、发型、服饰材质/纹样、配饰和识别点。同一角色跨镜保持肤色与肤质；无用户特殊设定时，人物默认同一暖白色温体系，有明确肤色/年龄/身份设定则保留，不将不同人物统一成同一张幼态脸。

场景记录四向布局、固定地标、门窗/家具位置、人群背景层及**世界空间中的固定光源**。主角服装和环境的工艺细节服从身份与场景，不把民居、办公室、校园、飞船全部宫殿化，也不为精致感堆砌与身份无关的装饰。大型固定家具归场景，小型可交互物品归道具。

### 3. Storyboard 与空间锚点

每个生成片段对应一个 `shot_id`，可含若干内切镜 `cut_id`；内切镜不是额外生成调用。保留 10—15 秒作为默认片段目标，每段不超过 15 秒，并服从实际工具的更低上限；叙事或工具只需更短时使用更短片段，不灌水补时。

优先将同一连续动作放在同段。每段列出戏剧职责、场景/造型/道具引用、各内切镜的景别+机位+运镜、动作起势→执行→收势、表情/目光目标、台词/OS及估算时长、起止状态、空间锚点卡和接镜方式。主叙事角色通常不超过 3 人，背景群众另按分布登记。

人物戏以近景和特写为主，中景用于关系与动作，必要的场景建立远景可按第一份风格知识库服务叙事。运镜有原因，克制或固定镜头可用于蓄势；不为满足数量而机械切镜。武打保留起手、接触、命中/化解、结果和完整受力链。

### 4. 角色、场景、道具设定图生成

使用完整风格前缀和专用模板，先建立核心视觉资产。标准交付：

| 资产 | 默认形式 |
|---|---|
| 角色设定 | 2K 级目标、16:9；生成两张图，一张角色面部特写试光镜头图；一张角色全身立绘三视图，正面/侧面/背面全身，干净白底； |
| 场景设定 | 2K 级目标、16:9；柔和均匀展示光 |
| 关键道具 | 2K 级目标、16:9 白底，尺寸/材质/正反面/状态可识别 |
| 多套造型/状态 | 依托同一角色母版或道具母版，仅改变本次指定部分 |
| 镜头关键帧 | 单一电影画面，按实际镜头画幅 |
| 角色音色 | 按需制作约 10—15 秒样本，或复用已指定音色 ID |

用户成片比例优先；设定板的横版排布仅是默认，可按用户要求调整。2K 是目标规格，记录工具实际支持和返回的像素，不把低清图标成原生 2K。

逐图检查风格、身份、服饰、手持物、场景图和群像。非本风格用户图先做身份/空间特征提取与必要的风格转化，不将其当风格图。出齐并验收本次核心资产后，进入视频阶段。

### 5. 逐镜视频生成

1. 每次调用前重读当前镜的最新资产绑定、版本、起止状态及新增用户输入；核心资产与本镜必需引用均应有效。
2. 首镜按能力绑定相关角色造型、场景方向及道具；若工具只支持单首帧，先生成通过验收的单画面关键帧，不能直接把角色三视图或空镜图填入首帧字段。
3. 后续镜从合格前序片段截帧并做视觉分析，按**背景内容 → 角色 → 方向 → 景别兼容性**四层过滤；需要时回溯补截。无匹配帧就使用有效设定图和明确布局，不硬塞冲突图。
4. 逐个内切镜核对其机位可见背景和离场位置状态，保持世界空间不变；反打时正确重算画面左右，不能逐字复用上一机位的屏幕位置。
5. Prompt 结构：**原样锚定词 → 摄影机 → 主体 → 空间 → 音频 → 禁止 → 时长**。保存工具实际接收的完整文本；图像标记按真实工具引用协议映射。
6. 生成后检视视频首、中、尾与关键动作/口型，记录文件和实际时长。错误镜不进入有效参考池。

默认先展示首镜作为风格、布局和表演样片，再按用户选择逐镜推进或连续完成。用户已明确授权自动完成时，首镜通过内部验收后继续，不重复要求同一授权；首镜不过关则修正后再扩散到后续镜。无授权执行媒体时，先完成可审阅的计划、资产清单和提示词，留在待生成状态。

重生成保存原 prompt 版本，只改用户指定或为修复已识别错误所必需部分；改动影响空间、造型或结尾状态时，标记下游引用待复核。失败重试边界见执行参考。

### 6. 音频制作

区分角色对白、角色内心 OS、第三人称旁白 VO、音效和 BGM。角色对白与 OS 绑定同一声音身份；OS 期间嘴唇不动，表情按内容逐拍变化，且声音长度计入镜头。

工具支持时对白/OS/同步音效随视频生成；不支持则按声音档案独立制作并剪辑对齐。BGM 独立生成或使用用户提供的合法素材，按题材、人物和情绪选择配器，后期混音。默认视频不内嵌 BGM、不烧录字幕；用户要字幕时在剪辑阶段生成可校对字幕轨。

### 7. 剪辑组装与导出

按镜表建立时间线，核对动作落点、眼神、轴线、场景、光影、道具状态和音画同步；同空间优先硬切，跨空间按叙事少量使用短转场。不要用转场遮盖空间错误。

对白/OS/VO 清晰优先，BGM 相对人声低约 8—12 dB 作为起调参考，按实际听感和电平调整；不得重复叠加已内嵌音轨。保留无声、呼吸和情绪停顿，检查首尾截断、峰值和字幕。

默认时间线 24fps，输出分辨率按实际素材与用户目标确定；工具仅提供 720p 就如实记录，升格、插帧和超分需明确标注。导出后检视成片，交付视频文件/可用链接、必要字幕、镜表、资产与音频索引及制作记录。没有真实工具结果时，不声称已产出媒体。

## 生产检查与接续

视觉 prompt、资产与引用采用 [execution.md](references/execution.md) 的清单格式，可用随附脚本检查：

```bash
python3 scripts/validate_prompts.py /absolute/path/to/visual-manifest.json
```

脚本验证可确定的前缀、引用用途、资产依赖和绑定条件；**不能保证生成模型不漂移**。每次实际视觉提交都要检查最终 prompt，生成后仍须视觉验收。

按本次交付阶段核查适用项：固定前缀零遗漏；实际生产时核心图先于视频；未注入风格图；题材、时代、对白与配乐未被古风模板改写；原剧本关键内容有去向；角色/造型/道具/离场状态按剧情连续变化；场景四向与当前机位一致；已有实际视频时首镜已验收；台词和动作时长可容纳；OS 不动嘴；实际混音无重复音轨；输出可打开；剩余缺口与失败如实标明。纯文字交付将资产生成、首镜验收、混音和导出标为待执行，不要求提前生产或声称已经验收。
