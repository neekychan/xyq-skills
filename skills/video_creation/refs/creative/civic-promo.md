# 政企公益宣传视频创作指南（警示教育 / 公益情感 / 机构形象 / 节点仪式）

适用：不以卖货转化为目的的宣传片——政务警示、普法安全教育、公益短片、企业/机关形象片、表彰开业等仪式节点。

## 与营销/文旅的边界（先判）

| 落点 | 走向 |
|------|------|
| 有产品/服务的转化意图（卖点/种草/促销） | `creative/marketing-ad.md`，不读本文件 |
| 吸引人到访/游玩/体验某地 | `creative/scenic-travel.md` §B |
| 树形象、促共识、做警示、办仪式 | 本文件，按下表选节 |

本垂类受众双层：名义受众是公众，**实际验收人是机构/甲方**——仪式感与情绪正确优先于传播技巧，禁用猎奇、擦边、过度娱乐化表达。

## 子类路由

| 用户信号 | 子类 | 核心结构 |
|---------|------|---------|
| 反诈/消防/交通/防溺水/普法/风险提示 | §A 警示教育 | 错误示范 → 后果具象化 → 正确做法 → 口诀收尾 |
| 捐赠/关怀/环保/志愿者/正能量故事 | §B 公益情感 | 个体小故事 → 情绪顶点 → 克制收尾+主题字 |
| 企业文化/机关形象/招商招聘 | §C 机构形象 | 大→小→大：宏大开场 → 一线人物特写 → 价值升华 |
| 表彰/年会/开业/封顶/周年庆/节庆贺片 | §D 节点仪式 | 标题动效 → 高光段落 → 庄重收尾 |

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 让模型生成国徽/国旗等政治符号或领导人形象 | 符号变形即重大事故，非质量问题 | 一律不入生成画面：用光影意象替代（金色光带、红绸、晨光、旗帜一角虚化背景），或构图留白交后期叠加 |
| 生成警察/军人等制服公职人员形象 | 制服与徽章细节崩坏即合规事故 | 公职角色改为社区工作者/网格员（红马甲，证件徽章不给特写），或仅用画外音/字卡提示职务身份 |
| 配色随意（公益用高饱和荧光色等） | 色彩立场错误，甲方一票否决 | 按子类锁色：§A=蓝白基调（可用警示红点缀对比）、§B=低饱和治愈色、§C=机构属性色（政务=蓝白，企业=品牌色+灰白）、§D=红金 |
| 旁白写成书面语长句 | 机械朗读感、播音腔 | 短句+排比，标注停顿气口与情绪起伏 |
| 警示片只讲道理不见后果 | 无记忆点，白拍 | 后果必须具象化为画面（账户清零的提示音、空荡的座位），再给口诀 |
| 公益片结尾喊口号 | 情绪崩塌，前功尽弃 | 让故事说话：留白镜头+一行主题字 |
| 落版/口诀/标题做成画内文字让模型生成 | 文字渲染崩坏 | 字卡一律交后期叠加：AI 生成段保持禁字幕、构图预留留白；口诀用旁白或齐声念出 |
| 群体场景生成写实人脸特写 | 群演脸崩坏 | 群体用背影/远景/剪影/手部特写，仅主角可近景（参考图流程内人物） |

## 强制规则

1. **旁白先行**：本垂类是文案驱动，先定旁白再配画面，画面节奏服从旁白气口
2. **一片一主题**：单支片只允许一个主题词（安全/传承/荣耀/感恩），多主题拆多支
3. **口诀收尾（§A 专属）**：警示片最后 3 秒必须是可复述的口诀（≤12 字，对仗或押韵）
4. **仪式三件套（§C/§D）**：金色粒子、光带游走、缓慢上摇运镜——庄重感的安全牌，但全片使用不超过 2 处，过量即廉价
5. **真实人物素材优先**：用户提供员工/活动照片时以实拍素材为锚，AI 只做空镜、转场与动效补充

## 结构模板

### §A 警示教育（15-30s）
钩子（错误行为进行中，3s）→ 后果具象化（5-8s）→ 正确做法演示（5-8s）→ 口诀+机构落版（3-5s）。多人齐声念口诀是有效变体。

### §B 公益情感（20-60s）
以一个具体人物的具体困境开场（禁止宏大叙事开场）→ 帮助/转变发生（情绪顶点给特写）→ 收尾克制：空镜或背影 + 一行主题字渐显。反转结构（误会→真相）是最强变体。

### §C 机构形象（30-90s）
全景航拍/延时建立体量感 → 切入 2-3 个一线人物工作特写（手、汗水、工具，不必露正脸）→ 回到全景，旁白升华到价值主张。人物段占比 ≥50%，全是大场面 = 没有记忆点。群像与匿名人物（手/背影/侧影）不做角色参考图，用肢体白描+场景图呈现，仅具名主角走参考图流程。

### §D 节点仪式（10-30s）
主题字动效开场（从中心舒展/光带描边）→ 高光内容段（成果画面/团队列阵/数据字卡）→ 庄重收尾（标语+机构名落版，BGM 渐弱）。
