## 二、营销转化类

> **二级呈现形式**：产品卖点九宫格（产品讲解分镜图）、广告 TVC 镜头表、痛点-解决方案分镜、场景种草分镜、品牌故事分镜、商品图参考分镜、营销脚本表格。下方给出代表性骨架（产品讲解分镜图）；其余二级呈现形式的细化模板见本章末「PE 模板索引」。

### 适用要点与判定关键词

- **定义**：围绕某产品或一组产品做广告、种草、说明的分镜图，画面以产品本身及其使用场景为中心，突出卖点、质感和使用流程。
- **判定关键词**：`产品`、`广告`、`TVC`、`卖点`、`品牌`、`新品`、`带货`、`电商`、`种草`、`优惠`、`使用教程`、`开箱`。以“讲清楚产品优势/卖点”“做电商带货/品牌宣传”为主且产品存在感强时归本类。
- **边界**：
  - vs 剧情叙事类：本类几乎每格能看到产品并突出卖点，服务转化。
  - vs 动作分解类：本类拆的是“产品使用流程/卖点顺序”（开箱→使用→效果对比）。
  - vs 知识讲述类：本类强调“这款产品如何解决你的问题”，知识点服务卖点。
  - 高规格广告分镜即便标注大量镜头参数（接近导演镜头表），用途上仍归本类，可在二级呈现形式选「广告 TVC 镜头表」。
  - 完成度：产品广告低完成度草稿 → 草稿/线稿级，用途仍为本类。

### 分镜结构建议

- **推荐宫格数**：常用 6 / 9 / 12 宫格，对应不同时长和卖点数量。
- **结构骨架**：
  1. 开场场景建立（1 格）：品牌/产品整体外观与目标人群，弱露产品；
  2. 痛点呈现（1–2 格）：没有产品时的困扰或对比场景；
  3. 卖点逐个展开（3–6 格）：每格清晰对应一个核心卖点或使用场景；
  4. 对比/结果（1–2 格）：使用前后对比或真实体验；
  5. 收尾行动号召（1–2 格）：Logo + Slogan + 价格/福利或“立即购买”CTA。
- **景别节奏**：环境建立用中远景 → 卖点展示用中近景/特写 → 收尾回中景，确保产品与 Logo 清晰可见。

### 生图 Prompt 骨架

```text
你是品牌创意分镜师，请为下述 {产品名称} 设计一张 {宫格数} 宫格的产品讲解分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏短视频”或“16:9 横版广告”}。

【产品信息】
- 一级用途类型：营销转化类
- 二级呈现形式：{产品卖点九宫格 / 广告 TVC 镜头表 / 痛点-解决方案分镜 / 场景种草分镜 / 品牌故事分镜 / 商品图参考分镜 / 营销脚本表格}
- 产品品类：{如智能手表/咖啡机/护肤精华/珠宝项链/家居清洁用品等}
- 产品名称或系列：{产品名称}
- 核心卖点：{核心卖点列表，按重要性排序}
- 目标用户：{如“都市白领/运动爱好者/年轻妈妈/学生党”等}
- 使用场景：{如“早晨洗漱/通勤/健身房/晚宴/旅行”等}

【参考素材图（如有）】
- 产品精修图/三视图/包装细节图：要求严格保持产品颜色、造型、Logo 位置一致；
- 使用场景照片/模特参考图：保持人物与场景一致；
- 若无参考图且为精修/成品级：先确认是否有产品精修图，缺图会导致产品外观漂移。

【画面与风格】
- 风格题材标签：{如“写实/工业风/轻奢/治愈/生活化/科技感”等}
- 画风：{如“写实摄影/3D 渲染/插画/扁平商业插画”等}
- 画面比例：{如“9:16/16:9”等}
- 适配场景：{如“信息流广告/电商详情页视频/品牌短片”等}

【分镜与标注配置】
- 宫格数量：{宫格数}，按阅读顺序编号 S1–S{N}，形成完整“买家旅程”。
- 完成度：{草稿/线稿级 / 精修级 / 成品级渲染}
- 是否带序号：{"是"/"否"}
- 是否带文字说明：{"是"/"否"，"是" 时每格配一句短文案}
- 是否带分镜参数：{"是"/"否"，"是" 时在描述或画面边缘写出景别/机位}

【推荐分镜结构】
- 第 1 格：品牌/产品整体亮相；
- 第 2–{N-2} 格：依次拆解核心卖点或使用场景；
- 倒数 1–2 格：结果/对比 + Logo 与行动号召。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 S1 到 S{N} 的卖点分镜要点（画面内容 + 该格主卖点/文案），供用户确认；确认后再按以下格式，为每格写出详细分镜说明：
1. S1：
   - 画面内容：{整体产品展示，环境与光线氛围}
   - 产品信息/文案：{画面中出现的文案或标签}
   - 卖点/场景：{该格强调的核心卖点或使用情境}
2. S2：……
……直到 S{N}，确保每格兼顾“产品 + 场景 + 卖点”。
```

### 一致性与避坑

- 产品外观（颜色、造型、Logo 位置）所有格必须一致，不能中途变型号或配色；有产品图时严格对齐。
- 色调、光线和道具风格统一，符合品牌调性。
- 人物（如有）衬托使用场景、不喧宾夺主，外观跨格统一。
- 避免完全没有产品的纯景物画面，除非是“痛点引出”或“情绪铺垫”镜头。
- 分镜顺序形成完整“买家旅程”，避免无关静物大图堆叠。
- 当产品讲解分镜承载政企/公益宣传意图（如安全教育类产品、政务 App 等）时，可参考 creative/civic-promo.md：避免让模型直接生成国旗/国徽/领导人形象，相关符号用光影意象或留白交后期叠加实现。

#### 卖点链路与分镜绑定检查（P1）

- 每格状态卡增加“本格核心卖点”字段，与卖点链（人群→痛点→卖点→证明→CTA）节点绑定；连续格不得重复同一卖点功能，重复则提示合并或改写。
- 每格标注“观众新知道什么”，避免同一卖点反复出现；无卖点链节点绑定的画面视为脱节。

### 视频生成策略与 PE 模板

```text
请基于下述素材生成一条 {时长秒数} 秒的产品讲解视频，整体风格与分镜图一致，清楚传达产品卖点。

【输入素材】
- 分镜图：{路径或 ID}（{宫格数} 宫格，含镜头顺序与卖点结构）
- 参考图：{产品精修图/三视图/包装细节图/使用场景照片}
- 目标画幅：{画幅说明}，ratio={ratio 代码}
- 目标模型：以用户指定的模型为准；用户未指定时，优先 seedance_2.0_fast，精修可选 seedance2.0_fast_vision / seedance2.0_direct

【生成策略】
- “参考图生视频”：从分镜图选关键宫格作参考帧，锁定产品造型、材质和氛围；
- 镜头节奏：开头 1–2 镜建立场景与品牌气质，中段按顺序展示各核心卖点，结尾 1–2 镜突出 Logo/Slogan 与优惠；
- 带货场景部分镜头预留字幕/价格区，避免产品被文案遮挡。
- 分镜中的“开场痛点-卖点展开-社会证明/体验-行动号召”结构应与 creative/marketing-ad.md 中的 A–H 类型结构对应：先在 creative_design.md 中用“[受众] 想要 X，但 Y 挡在路上，因为 Z”的一句话洞察锁定情感根基，再选择问题-解决/情绪叙事/对比等叙事类型，分镜与视频 Prompt 只是在这一结构上的具体落地。

【质量要求与常见问题规避】
- 产品外观、Logo 与关键文字清晰可见，不被字幕/UI 遮挡；
- 避免同条视频频繁切换风格或光线，保证视觉统一；
- 重点防止“产品型号/颜色前后不一致”“场景与品牌调性不符”；
- 所有中文文字、镜头编号与镜头参数说明优先由脚本或后期文字层叠加，图像模型仅负责画面，不直接生成长篇中文文字，以避免模糊或错字。

【口播/旁白追加要求】
- 带口播/旁白的广告在进入视频阶段前须按 storyboard/dialogue-rules.md 校验每段台词字数与段时长匹配，并用标准句式写出口型动作；口播信息量超过段时长时，应按 creative/marketing-ad.md 的“画面呈现卖点、口播补充”原则压缩文案，而不是强行加速语速。

【迭代建议】
- 1–3 次 Run 内完成可用成片：第1次验证结构与卖点顺序，第2次修正产品造型/材质偏差与光线，第3次仅必要时微调，不建议超过 3 次大改。
```
