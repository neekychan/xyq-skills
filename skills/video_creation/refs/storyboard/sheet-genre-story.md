## 一、剧情叙事类

> **二级呈现形式**：多宫格剧情故事板（剧情分镜表）、影视导演镜头表、漫画·条漫分镜、角色场景设定+分镜、纯画面连续分镜、剧情脚本表格。下方给出代表性骨架（剧情分镜表）；其余二级呈现形式（含影视导演镜头表、漫画·条漫分镜）的细化模板见本章末「PE 模板索引」。

### 适用要点与判定关键词

- **定义**：以完整故事推进为核心的分镜图/多宫格套图，每格是故事关键节点，靠人物行为、表情和场景变化串联；**不强求**每格写专业镜头术语。
- **判定关键词**：`剧情`、`故事`、`短剧`、`情感`、`恋爱`、`婚礼`、`亲情`、`成长`、`治愈`、`悬疑剧情`、`vlog 纪实故事`。需求重心在“讲一个完整故事”而非拆动作/讲知识/展示卖点时，归入本类。
- **二级呈现形式边界**（同属剧情叙事类，仅呈现形式不同）：
  - 影视导演镜头表：系统标注景别/机位/运镜/时长的“导演视角”分镜，适合需要专业镜头语言的剧情短片；细化模板见 PE 索引。
  - 漫画·条漫分镜：2D 漫画/条漫画风且大部分格带对白气泡，用对白驱动故事；细化模板见 PE 索引。
  - 角色场景设定+分镜 / 纯画面连续分镜 / 剧情脚本表格：分别侧重设定先行、纯画面无字、表格化脚本。
- **与其他一级用途的边界**：
  - vs 动作分解类：本类动作只服务剧情；动作分解类可脱离剧情做动作教学。
  - vs 营销转化类：本类主角是人/故事，产品只是道具。
  - 完成度：低完成度线稿仍按内容归本类，仅在「完成度」标为草稿/线稿级。

### 分镜结构建议

- **推荐宫格数**：6 / 9 / 12 格，长剧情可 16 格，对应短篇三幕式结构。
- **三幕式骨架**：
  1. 开始（约 1–4 格）：介绍主角、关系与起始状态，埋下轻微冲突或期待；
  2. 发展（约 3–8 格）：冲突升级、情绪起伏、关系变化，可适度切换场景/时间；
  3. 收束（约 2–4 格）：给出结果/反转/开放式结尾，形成情绪闭环。
- **景别节奏**：环境建立用远景/中景，情绪转折和关键对话用近景/特写；多人物注意左右站位与视线方向连续性；儿童/治愈题材放缓节奏，留足情绪停顿。

### 生图 Prompt 骨架

```text
你是一名剧情短片导演兼分镜师，请为下述故事生成一张 {宫格数} 宫格的剧情分镜表（多宫格 storyboard），整体画幅为 {画幅比例说明，如“9:16 竖屏故事短片”或“16:9 横版电影感短片”}。

【基础设定】
- 一级用途类型：剧情叙事类
- 二级呈现形式：{剧情分镜表 / 影视导演镜头表 / 漫画·条漫分镜 / 角色场景设定+分镜 / 纯画面连续分镜 / 剧情脚本表格}
- 适配场景：{适配场景，如“治愈短片/剧情短剧/儿童动画短片”等}
- 内容类型：{内容类型二级，如“UGC-情感/UGC-短剧/影视剧-短剧/UGC-vlog”等}
- 风格题材标签：{风格题材，如“治愈/古风/悬疑/电影感”等，3–5 个}
- 画风：{画风，如“仿真人写实/3D 动画/2D 动漫/水墨手绘”等}
- 画面比例：{画面比例，如“9:16/16:9”等}

【参考素材图（如有）】
- 角色参考图：{角色立绘/定妆图，要求严格保持长相、发型、服装一致}
- 场景参考图：{关键场景设定图，要求保持空间结构一致}
- 若无参考图且为精修/成品级：先确认是否需要生成角色/场景设定图作为参考。

【角色与场景】
- 主要角色设定：{姓名+年龄+性别+外观特征+服装+性格标签}
- 核心经历：{一句话描述角色当前处境}
- 场景设定：{主要场景及空间结构}

【分镜形态与完成度】
- 分镜形态：{连贯性套图/分镜单图}
- 宫格数量：{宫格数}，按 1~{宫格数} 的阅读顺序排列。
- 完成度：{草稿/线稿级 / 精修级 / 成品级渲染}

【标注信息配置】
- 是否带序号：{"是"/"否"，"是" 时每格显眼位置写 1,2,3...}
- 是否带文字说明：{"是"/"否"，"是" 时每格配一句简短中文说明或对白}
- 是否带分镜参数：{"是"/"否"，"是" 时角落小字标注景别/机位/运镜；影视导演镜头表建议为 "是"}

【剧情结构】
- 故事梗概：{80–150 字概述起承转合}
- 整体需包含：开端（场景与人物现状）→ 冲突/事件 → 高潮 → 结局/余韵。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出第 1 格到第 {宫格数} 格的分镜要点（画面内容 + 台词/旁白等），供用户确认；确认后再按以下格式，为第 1 格到第 {宫格数} 格依次写出中文分镜说明：
1. 第1格：
   - 画面内容：{主要人物和环境，正在发生什么}
   - 情绪氛围：{平静/紧张/温暖/压抑}
   - 景别建议：{远景/中景/近景/特写}
   - 文字/旁白（若需要文字说明）：{屏幕文字、台词或旁白}
2. 第2格：……
……直到第 {宫格数} 格，保证故事连贯可读，最后一格形成清晰的情绪收束。
```

> 选用「影视导演镜头表」二级呈现形式时，需在每格补充景别/机位/运镜/单镜头时长等镜头参数，并将“是否带分镜参数”设为“是”；选用「漫画·条漫分镜」时，每格补充对话气泡“角色名：台词”。两者的细化骨架见本章末 PE 模板索引中的对应模板文件。

### 一致性与避坑

- 角色外观、服饰、发型跨格统一，仅在剧情需要时合理变化（受伤、换装）；有参考图时严格对齐参考图。
- 同一场景结构前后一致（门窗/桌椅/地形不漂移），时间/地点跳转时显式标注“切换到 ×× 场景”。
- 多人物镜头注明每人站位（左/中/右）、视线方向和关键动作，避免前后左右互换。
- 分镜序号连续、清晰，避免缺号或重复号。
- 选用漫画·条漫分镜时，每格明确谁在说话（“角色名：台词”或气泡尾巴指向），避免台词归属不清；禁止生成纯表情包九宫格/三视图设定图冒充剧情分镜。
- 重要角色与核心场景在进入视频阶段前，应按 assets/character-lock.md 与 assets/ref-image-design.md 生成四视图角色设定稿与场景空镜参考图，并在每次 sandbox_generate_video 调用时通过 ImageList 逐镜头传入，避免仅依赖文字描述。

#### 剧情分镜校验器（P0，强制）

进入生图前必须生成并确认两张表：

1. **逐格剧情状态表**：每格的场景区域、人物出现/禁止出现、人物位置与姿态、情绪变化、绑定事件 ID、参考图 ID、与前后格关系。
2. **新增信息检查表**：每格“观众新知道什么”；连续两格相同则必须合并或改写（压制中段重复“等待/失落”）。

强制规则：剧情类**禁止**从问卷直接跳到高保真生图，必须依次通过“故事线确认（门禁一）→ 逐格状态表确认（门禁二）→ 低保真草图确认（门禁三）”；单格 Prompt 必须引用状态表字段，不得自由描述人物与空间。

### 视频生成策略与 PE 模板

```text
请基于下述素材生成一条 {时长秒数} 秒的剧情叙事类视频，忠实还原分镜图中的故事节奏与情绪变化。

【输入素材】
- 分镜图：{分镜图路径或 ID}（{宫格数} 宫格，已按三幕式排布）
- 参考图：{主角立绘/关键场景设定图，如有}
- 目标画幅：{画幅说明}，ratio={ratio 代码}
- 目标模型：以用户指定的模型为准；用户未指定时，探索可用 seedance_2.0_fast，定稿可选 seedance2.0_direct / seedance2.0_fast_vision

【生成策略】
- 优先“分镜/角色图 → 参考图生视频”：每幕选 1–2 个关键格作参考帧，锁定角色外观与场景氛围；
- 需精细节奏时可在少量关键段落叠加“多镜脚本”，避免整条依赖长脚本导致角色/场景失控；
- 长剧情建议拆成多条短视频，逐条验证片段效果。
- 若 plan 中内容类型或题材表明为互联网短剧/剧情短剧（如内容类型含“UGC-短剧/影视剧-短剧”等），视频 Prompt 需额外加载 creative/short-drama.md 与 storyboard/short-drama-prompt.md：前 5 秒按“爆款起手”规则给出冲突/悬念，段尾按“下一集问题”原则设计钩子，爽点强度按阶梯递进，禁止写成平铺解释戏。
- 选用影视导演镜头表呈现时，镜头描述与运镜指令复用 storyboard/prompt-craft.md 的“运镜指令表”和“空间关系构建”规则，严格按镜头表的景别/机位/运镜顺序生成；含高强度打斗或特效段时参考 storyboard/vfx-action-prompt.md 构造各时间段。
- 多镜头剧情视频的整体弧线与镜头时长分配应参考 creative/narrative-arc.md：起-承-转-合完整，高光镜头给足时长，高潮后保留 1 个余韵镜头，避免高潮后戛然而止。

【质量要求与常见问题规避】
- 故事逻辑清晰，镜头切换贴合三幕式，无意义跳剪；
- 角色一致性：外观/服饰/发型跨镜统一，避免“换脸/换衣”；
- 场景一致性：同场景门窗/桌椅/地形跨镜大致一致，避免“场景瞬移”；
- 多人物站位：群像场景尽量固定主角在画面一侧，减少识别负担；
- 所有中文文字、镜头编号与镜头参数说明优先由脚本或后期文字层叠加，图像模型仅负责画面，不直接生成长篇中文文字，以避免模糊或错字。

【含台词/旁白场景追加要求】
- 有台词或旁白的镜头，在调用 sandbox_generate_video 前必须按 storyboard/dialogue-rules.md 做一次文本耗时校验：引用 count_chars 工具的耗时区间，装不下则先改稿或拆段，禁止“先生成再看能否说完”。
- 台词句式统一使用“[角色名]嘴唇随每个字清晰地一开一合，说：{台词}。说完嘴唇合拢”，并对同画面中不说话的角色显式写“嘴唇紧闭不说话”，避免生成“有声音但嘴不动”的画面。

【迭代建议】
- 有效 Run 控制在 3–5 次：先稳定分镜与主角造型，再微调参考图与模型；每次只改一个主变量（分镜/参考图/模型/ratio）。
- 每轮合成后的完整视频都应按 review/quality-control.md 的“五维自检表”快速检查：叙事弧线是否完整、角色是否跨段换脸/换衣、风格与配色是否统一、是否出现字幕/水印、台词是否被截断，再决定是回到分镜调整还是仅局部补镜。
```
