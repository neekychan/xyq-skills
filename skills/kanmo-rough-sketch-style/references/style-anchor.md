# 风格锚定词与组合规则

> 本文件定义「刊墨糙描风格」的固定风格锚定词，以及它在图片风格化、视频生成、与其他技能组合时的复用规则。规则不随场景改变。

## 一、固定风格锚定词

```
刊墨糙描风格，粗黑线/强轮廓，干裂刊墨硬线，轻微肌理，旧刊纸张印刷晕，写实/自然形态，怪比例市井，低饱和/莫兰迪，低饱和旧印调
```

**硬规则：**
- 这段锚定词内容**固定不变**：不删改、不精简、不翻译、不重排、不替换任何一个词。
- 它必须出现在**每一条**需要生成/编辑的图片提示词的**最开头**，以及**每一条**视频生成提示词的**最开头**，再接后续画面内容。
- 锚定词的优先级高于其他一切表达偏好。任何后续描述都不得与锚定词描述的视觉特征相矛盾。

## 二、锚定词各要素含义（供落 prompt 时把握画风，不改动锚定词本身）

- **刊墨糙描风格**：整体为旧书刊、木刻/铜版印刷式的墨线粗描基调，带手工刻印的糙硬气质。
- **粗黑线/强轮廓**：主体用粗重的黑线勾勒，轮廓感极强、边界分明。
- **干裂刊墨硬线**：墨线呈干枯、开裂、硬朗的笔触，像旧刊物上刻印后的断续硬线。
- **轻微肌理**：画面带轻微的颗粒/刻痕肌理，不做完全平滑处理。
- **旧刊纸张印刷晕**：底子透出旧刊物纸张的印刷晕染、油墨渗透与泛黄气息。
- **写实/自然形态**：形体走写实、自然的比例与结构，不做卡通化简化。
- **怪比例市井**：在写实基底上带一点怪异夸张的比例与浓郁的市井烟火气。
- **低饱和/莫兰迪**：整体低饱和、莫兰迪灰调。
- **低饱和旧印调**：色彩统一压成低饱和的旧印刷色调，像年久的印刷品。

## 三、与其他「风格类」技能搭配：锚定词合并规则

当本技能与另一个风格类技能同时被触发时：

- **合并处理，规则不变**：把本技能的锚定词与对方风格技能的风格锚定词**合并**成一段合成锚定词，仍然整段前置到每一条图片编辑提示词与视频提示词的最开头。
- 合并时本技能锚定词的内容**保持完整原样**，不因对方风格而删改。
- 合成后的锚定词依然遵循「整段前置、内容固定」的核心规则。
- 若两套风格在某些视觉描述上冲突，保留双方各自的锚定词原文并置，不做取舍改写（由生成模型综合处理），除非用户明确指定以某一方为准。

## 四、与「非风格类」技能搭配：结合规则（强约束）

当本技能与非风格类技能同时被触发时（例如同时调用「刊墨糙描风格」技能与「营销短片」「剧情短片」等非风格技能）：

- **本技能的风格锚定规则不被覆盖。** 即使加载了其它非风格技能，也必须遵循本技能所要求的部分：**每一条图片编辑提示词与视频生成提示词，仍然以本技能的锚定词开头。**
- 非风格技能负责它擅长的部分（如叙事结构、卖点表达、分镜密度、平台适配等），本技能只接管「画风」这一层——两者**结合而非互斥**：先由非风格技能产出内容/脚本骨架，再由本技能在每一条 prompt 最前面统一前置锚定词。
- 若非风格技能自带的风格/画风描述与本锚定词冲突，**以本技能锚定词为准**，非风格技能中与画风相关的描述让位于锚定词。
- 结合后仍需通过本技能的静默自检（尤其是「每一条 prompt 是否都以锚定词开头」这一条）。
