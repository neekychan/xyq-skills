# 演唱 / Live 类 MV Prompt Engineering Skill

## Skill 目标
这个 Skill 面向 **30 秒内的演唱 / live performance 视频生成**。用户给出新音频后，先输出简练的音频理解、推荐生成方案、时间轴和问卷；确认后在后台生成可直接喂给 2.5 模型、可用于复刻和评测的高精度 PE，不在聊天正文展开。

统一收口：
- 单支视频时长必须 **≤30 秒**。
- 目标是 **单支视频直接生成**，不是完整演唱会制作流程。
- 对话首轮只展示：**音频理解摘要、推荐生成方案、时间轴设计、问卷确认**。主提示词、控制点、负向词和关键帧引用必须在后台完整生成并随视频生成任务提交，默认不在聊天正文展开；只有用户明确索要 PE 时才展示。
- 高复刻的含义不是“泛泛 live 感”，而是尽量达到历史案例里的 **人物锚定强度、舞台锚定强度、嘴型设计强度、镜头设计强度和时间轴精度**。
- 但这些控制强度不能被误解成固定主唱和固定舞台：**人物造型、舞台设定、灯光设计、情绪爬坡和时间轴都必须先根据新音频重新设计**，再借用历史 archetype 的机位纪律和演唱控制逻辑。
- 如果用户已经给出一整段细到可执行的 PE / 视频脚本，不要把它抽象成更泛的模板；优先保留用户原词里的主唱锚点、舞台锚点、嘴型锚点、动作锚点和机位锚点。
- 不设计 BGM 回灌、音轨替换或二次混音；输入音频仅用于结构、歌词、节拍与表演同步。

## 适用场景
优先用于：
- 用户上传新的演唱音频，想做舞台感、演唱会感或 live house 感视频。
- 用户要的是“演唱类 prompt”“像之前那个演唱会片段一样的高精度提示词”。
- 用户关注对口型、动作、神态、舞台空间、灯光和镜头节奏。

只在以下专业现场或拟现场空间使用：
- 演唱会主舞台、live house、电视打歌舞台、专业灯光舞台。
- 专业录音棚或声学棚。

禁止把家里、卧室、厨房、客厅、普通街角等生活化场景包装成 Live。

不适用：
- 主表达是团舞编舞：使用 `kpop-dance-mv-pe` skill。
- 主表达是 rap performance 态度输出：使用 `rap-performance-mv-pe` skill。
- 主表达是乐队表演：使用 `band-performance-mv-pe` skill。
- 主表达是场景化、叙事化美术空间里的情绪演唱：使用 `lyrical-vocal-performance-mv-pe` skill。
- 主表达是纯 CG 概念奇观。

## 输入边界
必需输入：
- `audio_path`，或明确指定的演唱音频片段。

可选输入：
- 歌词文本。
- 人物参考图。
- 舞台参考图。
- 指定服装、乐队配置、画幅比例。
- 指定是独唱、双人对唱、带乐队主唱或偏观众互动型。
- 已写好的完整脚本 / 提示词 / 时间轴拆解。
- 参考视频文件或链接及要分析的具体时间段。

默认值：
- 如果用户没指定表演结构，先主动给一版推荐生成方案，而不是直接写最终 prompt。
- 默认画幅 `16:9`。
- 如果用户没指定场景，默认按 **高质感专业舞台演唱** 处理，在演唱会主舞台、室内 live house、专业灯光舞台或专业录音棚 / 声学棚中选最适合音频的类型。
- 如果没有观众要求，不强行塞满观众，但必须保留清晰的舞台空间感和灯光层次。
- 音频超过 30 秒时，推荐最完整且有起承转合的 ≤30 秒片段并等待确认。
- 如果没有可靠歌词或乐句时间码，先从音频获取歌词 / 乐句切点、闭口辅音、长音、换气和重音锚点；在未获得可靠口型锚点时，不得宣称“精准对口型”。

## 音频来源与准入
- 用户上传或明确提供可用音频时，直接使用。
- 用户只给歌曲／BGM 名，或明确要求找音乐，且没有可用的 `audio_path`／`video_path` 时，调用 `pippit_omni_search`；`SearchType` 必须为 `mv_music`，`Query` 只做最小清洗，不得擅自添加歌手、版本、语种、年代或曲风。
- 将返回的候选音频提供给用户确认。
- 用户选定后统一绑定为 `canonical_audio`。
- 音频来源记录为 `uploaded_audio` 或 `copyright_music_asset`；版权库音频记录 `asset_id`、版本和选定片段。
- 无已确认可用音频，不进入生成。

### extract_lyrics 调用

- 在 `canonical_audio` 已确认并取得可访问的 `audio_path` 后，音频含人声或当前任务需要歌词信息时，调用 `extract_lyrics`，传入该 `audio_path`，获取歌词文本及对应时间戳。
- 将返回结果作为原有音频理解流程的输入，用于识别歌词关键词、歌词句段、hook、高潮及现有的画面或口型时间映射。
- 纯器乐或无歌词音频跳过该调用；工具未返回歌词时，继续按照原有音频结构分析流程执行，不阻断后续生成。

## 已验证高精度 archetype
### Archetype A：极简冷蓝立麦抒情主唱
这是历史对话里抒情演唱类的**参考级强模板之一**，不是所有新音频的固定默认舞台。只有当用户明确说“按之前那个冷蓝立麦演唱标准来”，或新音频确实匹配这种克制抒情、冷色舞台、慢推近长镜头的方向时，才从这一套派生；否则必须先根据新音频重新设计主唱造型、舞台、机位和时间轴，再借用这套模板的演唱控制强度。

核心锚点：
- 单人主角，一位欧美流行女歌手。
- 深色长卷发，冷艳高级感强，舞台气质成熟、克制、深情。
- 夸张厚重的黑色仿皮草大衣，内搭黑色亮片礼服或闪光黑裙。
- 银色立式麦克风必须存在。
- 场景是 **极简冷色调演唱会舞台**：深蓝到青蓝的朦胧烟雾空间，轻微雾气，深邃空间感，强轮廓光勾勒头发和皮草边缘，正面柔和补光照亮脸部。
- 演唱方式是抒情流行 / 灵魂感强的高潮段：开头长音张口中等偏大，纵向开口明显；中段歌词连贯清楚；结尾有余韵和轻微气声收尾。
- 动作设计克制而有力量：双手主要扶握银色麦克风杆，手指有细微抓握变化，身体随着旋律轻微晃动，肩膀和胸腔有呼吸起伏，头部在长音时轻微后仰或侧偏。
- 神态是核心：闭眼或半闭眼沉浸投入，随后缓慢睁眼，眼神深邃、略带哀伤和坚定。
- 镜头语言是 **中景长镜头 + 缓慢推近**，几乎没有剧烈晃动和快切。

### Archetype B：赛博歌姬大型主舞台
这是历史 thread `497e5ba1` 沉淀出来的 live 派生：
- 赛博歌姬登上大型演唱会主舞台。
- 时间轴按“舞台建立 → 律动推进 → 高潮放大 → 收束”设计。
- 高光时刻由灯光爆闪、大全景交叉和局部特写共同放大。

## 两个已验证参考视频锚点

### 20 秒专业录音棚冷蓝近景语法
来自 20 秒参考片段的可继承视觉锚点：
- 深蓝背景与柔化光斑，冷色强轮廓光勾勒发丝，正面柔光保留肤色、唇形和眼神光。
- 专业精致妆造；近景突出唇齿、长音开口、自然闭口与轻微胸腔 / 喉部换气。
- 内敛神态、低速推拉或平移，剪辑跟随乐句起承转合。

该参考片段本身没有可见麦克风设备；若采用 Live 的录音棚路线，只继承其深蓝布光、妆造、近景口型和呼吸语法，并补齐且锁定头戴式录音棚耳机、大振膜电容麦、避震架与防喷罩，避免麦克风遮死嘴型。

### 13 秒立麦体积光现场语法
- 立式麦与人物绑定；侧面近景可表现约 2–5 cm 的麦嘴关系、抓握—松开—微调和真实局部遮挡。
- 景别按近景亲密感 → 正面中景建立 → 情绪特写 → 远景高潮，抽象为“近—中—远”升级。
- 后景使用位置固定、透视可信的放射状体积光；人物前景、立麦中景、灯阵后景形成纵深。
- 主机位为正面中远景，辅机位为约 45° 侧面近景；切点按新音频重音和高潮重排。
- 高点通过更大口型、颈部发力、轻微后仰、灯束和远景同时放大。

## Live 核心定义与对口型执行
Live 类型的核心不是“有舞台灯光的人物镜头”，而是 **具体专业场景中的可信演唱**。推荐方案与后台 PE 必须同时成立以下四层：
- **场景层**：明确是大型演唱会、live house、极简舞台、专业录音棚或声学棚，写清空间纵深、灯光和必要环境资产；不能退化成无空间语义的普通棚拍，更不能使用家庭或生活化场景。
- **麦克风路线三选一锁定**：手持麦 / 立式麦 / 录音棚麦。选定后全片保持同一类型，不允许麦克风消失、变形、无动作换手或跨路线跳变。
- **逐段演唱层**：时间轴每一段都写明对应乐句或演唱状态、嘴型难点、闭口辅音、长音起点、换气点、下颌 / 喉部发力、手部动作、身体重心、眼神和结束状态，不能只写“深情演唱”。主要歌词段优先中近景，确保嘴、麦克风和持麦手可读。
- **动作神态层**：动作由唱法和歌词驱动，包括吸气、胸腔 / 肩部轻微起伏、长音下颌打开、头部轻偏或后仰、握麦力度变化、闭眼到睁眼等；禁止无歌词时机械张嘴、舞蹈化挥臂或说唱式压镜手势。

### 三条设备路线与麦嘴手几何
1. **手持麦**：固定同一支麦、持麦手和换手规则；麦头通常距嘴约 2–8 cm，随音量合理远近，不遮死口型。
2. **立式麦**：固定麦头高度、麦杆、底座与人物站位；人物必须握麦或扶麦架并面对麦头演唱，保持手—麦—嘴连续关系。
3. **录音棚路线**：固定头戴式录音棚耳机、大振膜电容麦、避震架和防喷罩；人物始终面对防喷罩与麦克风演唱，嘴—防喷罩—麦振膜同轴且距离可信。

现场不得无麦空唱。录音棚不得缺耳机、麦克风、防喷罩或突然改成舞台手麦。手指与麦体 / 麦架接触必须真实，麦头、防喷罩和嘴的距离与方向必须可信。

若没有可靠歌词或乐句时间码，先从音频获取歌词 / 乐句切点；在未获得可靠口型锚点时，不得宣称“精准对口型”。无歌词或纯器乐空拍时不得机械张嘴，动作转为呼吸、聆听、等待进句或专业舞台互动。

成片验收必须检查嘴型与音频重音、闭口辅音和长音起点是否同步，同时检查麦克风连续性、手部稳定性、呼吸发力与神态推进；不合格则重新生成，不能用远景、遮挡或快切掩盖。

## 音频驱动优先级
Live / 演唱类 Skill 不能因为存在 archetype，就把所有新音频都写成同一个冷蓝立麦舞台。必须遵守：
- 先根据新音频判断更适合大型演唱会主舞台、赛博舞台、live house、极简抒情舞台、灯串小舞台、专业录音棚 / 声学棚还是其他专业现场空间。
- 先根据新音频设计主唱人设、服装、麦克风、舞台纵深、灯光和观众存在感，不能把同一套黑色皮草 / 银色立麦 / 深蓝烟雾默认套给所有歌。
- 先根据新音频结构设计时间轴：哪里先立舞台，哪里推近主唱，哪里做高潮放大，哪里回收情绪。
- archetype 的作用是提供 **可信演唱、舞台组织、机位纪律和情绪爬坡逻辑**，不是固定舞美模板。

## 参考视频高精度复刻流程
问卷中必须询问是否有参考视频，支持上传本地视频或提供链接。用户已经主动提供参考视频时，不再重复询问“是否有”，直接进入分析：
- 链接必须先取得可分析的实际视频文件；若链接无法访问、无法下载或只拿到页面文本，要明确要求用户上传视频，不能假装已看过。
- 用户指定时间段时，只精确裁取并分析该区间；未指定时分析完整视频，并结合新音频时长选择对应复刻范围。
- 使用 `analyze_media` skill 分解参考视频，至少提取：具体专业场景、主唱人物与造型、手持 / 立式 / 录音棚麦路线、麦与嘴和手的空间关系、逐句口型、换气和发力、身体动作、神态推进、景别运镜、灯光和剪辑连续性。
- 把结果分成“必须复刻的硬锚”和“可按新音频重排的变量”。场景、人物、麦克风路线、表演纪律和主机位属于硬锚；口型和动作的时点按新音频歌词、乐句、换气与高潮重新映射。
- 必须基于拆解结果**改写本轮推荐生成方案、时间轴和后台 PE**，不能分析完仍沿用通用演唱会模板。硬锚同时进入主提示词、控制点和负向词。
- 若用户在首轮问卷后才上传或补充链接，必须暂停生成，分析后按原来的简练格式重新给出修订后的推荐生成方案、时间轴和问卷；**旧确认自动失效**，用户重新确认后再进入后台 PE，不要借此在正文展开技术提示词。
- 若用户只说“参考风格”而非高精度复刻，才允许只继承舞台与镜头语法；否则默认按场景、人物、麦克风、口型、动作神态和机位的高精度复刻处理。
- 生成后对照参考逐项验收场景、造型、麦克风连续性、口型、换气发力、动作神态和镜头；缺失关键硬锚时不能宣称复刻完成。

## 工作流程
### 1. 先做音频理解
至少要明确：
- 总时长。
- 情绪是抒情、爆发、热烈、悲伤、释放还是温柔推进。
- 哪一段适合做主唱近景，哪一段适合放大舞台空间和灯光。
- 高潮段是否需要更大的景别、更强的灯光和观众反馈。
- 演唱更适合克制推进、层层堆高，还是一开始就强输出。
- 歌词 / 乐句、闭口辅音、长音、换气、重音、高潮和结尾锚点。

### 2. 先判断是否已有“可直接执行脚本”
如果用户已经给出一整段细到可执行的脚本 / PE：
- 不要把它抽象成一版更泛的模板。
- 先保留它的 **主唱锚点、服装锚点、舞台锚点、麦克风锚点、嘴型锚点、动作锚点、机位锚点、控制点和负向词**。
- 再把它整理到本 Skill 的固定输出结构里，方便直接生成与评测。
- 除非用户主动要求简化，否则不要删去服装名词、灯光名词、嘴型描述或机位描述。

### 3. 再生成推荐生成方案
如果用户没有明确锁定表演结构、人物风格或舞台设计，不要立刻只给最终 prompt；先输出一版 **推荐生成方案**。

推荐生成方案至少包含：
- 推荐专业空间类型、选择理由和纵深设计。
- 推荐表演结构：独唱、双人对唱、主唱 + 乐队氛围，或主唱 + 观众互动感。
- 演唱者风格：抒情沉浸型、爆发感染型、冷感高级型、现场燃场型等。
- 主唱外观锚点：发型、服装、麦克风类型、妆面、气质。
- 舞台锁定：空间、灯光、烟雾、轮廓光、观众存在感。
- 演唱锁定：嘴型类型、闭口辅音、长音、换气、呼吸感、手部动作、身体带动、重心和神态推进。
- 麦克风路线锁定：三选一及逐段手—麦—嘴 / 嘴—防喷罩—麦振膜几何。
- 机位锁定：主机位类型、景别区间、镜头节奏、允许项和禁止项。
- 高潮从唱法、灯光、空间和景别如何共同升级。

输出完推荐生成方案后，必须紧跟 **问卷确认**，默认已采用推荐项：
- 是否有参考视频：没有 / 上传视频 / 提供视频链接；若提供，继续记录要参考的具体时间段，默认按高精度复刻处理。
- 表演结构、专业空间、主唱人设与造型是否采用推荐项。
- 麦克风路线、舞台、灯光、演唱动作与机位是否采用推荐项。
- 生成模式选择：**直接生成视频 / 先生成分镜关键帧图片预览 / 我要调整**。

如果用户明确说“直接生成”或“不改”，按问卷默认项执行；但输出结构里仍要保留问卷确认这一段。

### 4. 再设计时间轴
live 类的时间轴要围绕 **专业空间 / 舞台建立 → 主唱可信推进 → 高潮放大 → 收束**，不机械等长切片。

推荐逻辑：
- 前段先立住舞台环境和主唱状态。
- 中段加强可信演唱、表情和镜头亲密度。
- 高潮段必须明显扩展到更大的空间感、灯光感或情绪爆发。
- 尾段可回到近景情绪收束，也可保留大场面余韵。

每段写明音频证据、歌词 / 口型、闭口辅音、长音、换气、麦克风互动、动作神态、身体重心、景别运镜、灯光变化和结束状态。

### 5. 如果用户选择先生成分镜关键帧图片预览
先输出一组 **3–5 张关键帧预览图方案**：
- 关键帧 1：舞台 / 专业空间建立，主唱造型与空间第一次锁定。
- 关键帧 2：主唱中近景，口型、麦克风几何与表情状态锁定。
- 关键帧 3：高潮前的灯光 / 观众 / 机位升级节点。
- 关键帧 4：高潮大场面主画面。
- 关键帧 5：情绪收束或最终定格（按时长可合并）。

每张关键帧都要写清：时间点、主唱状态、麦克风路线、手—麦—嘴关系、景别、舞台、灯光、观众存在感、服装与情绪关键词。关键帧一旦确认，就通过 `ImageList` 绑定，并成为后续视频 PE 的视觉硬锚；主提示词、控制点和负向词必须共同引用。

### 6. 后台生成并提交 PE
方案和问卷确认完成后，在后台生成可直接投喂模型的主提示词、控制点、负向词和关键帧引用，并合并进视频生成任务。聊天正文不要重复展开这些技术内容；只有用户明确说“把提示词发我 / 给我 PE”时，才把完整 PE 放进单独代码框。

用户确认直接生成时，只回复一句：`方案确认，开始生成 {duration}s 专业演唱 Live MV。`

## 推荐生成方案设计规则
### 主唱与舞台锚点必须补齐
推荐方案里至少补齐：
- 主唱外观锚点。
- 服装和麦克风锚点。
- 舞台空间锚点、灯光锚点、烟雾 / 深景锚点。
- 观众存在感强弱。

### 演唱设计必须补齐
推荐方案里至少写清楚：
- 嘴型属于哪一种：抒情长音、爆发高点、连续歌词、气声收尾等。
- 闭口辅音、长音起点与换气点。
- 手部动作主要是什么。
- 身体带动和呼吸感如何体现。
- 神态如何推进。

### 机位锁定必须补齐
推荐方案里至少写清楚：
- 主机位是什么：缓慢推近、中景长镜、大全景交叉、稳态跟拍中的哪一种。
- 允许哪些辅助镜头。
- 明确禁止哪些镜头，例如快切、乱飞、大幅摇摄，以及用远景、遮挡或快切掩盖口型。

## 控制点模板
```text

1. 只出现专业现场 / 拟现场空间，禁止家庭、普通街角及其他生活化场景。
```

## 生成后严格验收
在开场、每个主要乐句、每次麦克风动作、高潮和结尾逐点检查：
- 空间是否确属专业现场 / 拟现场，且纵深、设备和灯光成立。
- 麦克风路线是否唯一连续；手—麦—嘴关系和接触是否可信；录音棚耳机、电容麦、避震架和防喷罩是否完整。

- 人物妆造、服装、设备、站位和光源坐标是否连续。
- 近—中—远或既定机位升级、高潮和 ending 是否成立；关键帧与参考视频硬锚是否保留。
- 是否没有 BGM 回灌、音轨替换或二次混音。

任一关键节点出现无麦空唱、路线跳变、口型错拍、手麦穿模、录音棚设备缺失、生活场景、关键帧或参考硬锚缺失，本次 clip 判失败并重新生成，不得宣称完成。**不合格必须重做，不能用远景、遮挡或快切掩盖口型。**
