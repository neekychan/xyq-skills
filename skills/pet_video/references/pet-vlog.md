# 类型 A：萌宠 Vlog 创作指南

## 设计原则

**核心卖点**：伪纪实感——观众相信这只动物真的在过这样的生活。

**先定情绪，再选叙事引擎**：Vlog 覆盖的情绪最广（上班=心疼、旅游=放松、等主人=治愈），叙事引擎只是骨架，真正决定成败的是情绪杠杆有没有落地（见 `pet-rules.md` 情绪杠杆表）。同样"上班 vlog"，目标是心疼就走"逞强+付出无回报"（挂电话才卸下表情、别人下班它加班），目标是搞笑才走"佛系摆烂"——别让"上班"这个题材默认联想帮你决定情绪。

**叙事引擎**（选一个驱动整条片子，不要混用）：
- **时间线**：按时间顺序跟拍一段经历（一天/一次出行/一个事件）
- **空间线**：按地点切换展示不同场景（逛街/探店/旅游打卡）
- **任务线**：围绕一个具体任务展开（做饭/装修/搬家/学技能）

**引擎只是骨架，挂肉的是事件**：每个镜头必须过 `pet-rules.md` 强制规则10 的事件判别式（「作用力→反应」句式，纯状态镜头全片 ≤2）。时间线引擎最容易退化成"状态罗列"——每段演一种情绪状态（赶/困/累），没有任何事情发生——退化的片子就是"空"。事件从事件锚点（SKILL.md §四步骤4）取，**施压源可由动物配角出演**（老板/同事/店员用其他动物，红线只禁人类入镜）——独角戏撑不起冲突，"被压迫的苦"没有施压者立不住。

**旅行/出行 vlog 的典型段落序列**（时间线的常用落地，按需增删，不是死模板）：
收拾行李 → 出发路上 → 景点快切打卡（3-4 个）→ 黄昏过渡 → 一天结束的晚安。

**段落节奏预算（60s 版参考；核心：开头快、中段密、结尾缓，别让哪一段拖沓）**：
- **收拾行李 ≤10s**：只留 1-2 个动作（塞小鱼干进箱 + 挎包出门），交代"要出门"的期待感即可，**别把开头拍成流水账**；时长紧张（<40s）直接砍掉从景点切入
- **出发路上 ≈15s**：走完整的"旅途小弧线"（见下），这是共鸣密度最高的一段
- **景点打卡 ≈20-25s**：**3-4 个景点快切**，每个景点 4-6s 只留一个记忆点（自拍合照/一个反应），**其中一个景点安排"和当地小吃同框"**（前爪举着糖葫芦/烤串/小吃在地标前自拍或边走边啃）——比单独拍一段"美食品尝"更紧凑、更有边玩边吃的旅行感。**景点和小吃必须用地名 text 搜索命中的真实特色**（见 SKILL.md §四步骤1"地名触发"），别凭记忆编
- **黄昏过渡 → 晚安 ≈10-15s**：节奏放缓收尾，给情绪落点留呼吸

**一天的时间流逝感（光线就是叙事线）**：让画面光线跟着一天走——清晨/上午出发（自然晨光）→ 白天景点（明亮日光）→ **黄昏过渡**（金色时刻、暖橙光）→ 夜晚酒店晚安（暖黄床头灯 → 熄灯渐暗）。**每段 Prompt 里写明该时段的光线**，观众能"看"到一天过完——这是旅行 vlog 沉浸感和放松感的重要来源，也让"晚安"收尾水到渠成。
- **硬要求只有一条：白天和晚安之间必须有一个"傍晚/黄昏时段"的过渡画面，禁止从明亮日光的景点直接跳到夜晚躺床**——没有黄昏这一拍，一天的流逝感就断了。
- **过渡形式任选贴合目的地和叙事的（不强制吃晚饭）**：夕阳店里吃当地晚餐（暖橙逆光洒在餐桌毛发上）/ 夕阳下漫步老街或湖边 / 城墙、山顶看日落 / 傍晚回酒店路上华灯初上……选一个即可，一拍就够。
- **有夜间景点时（夜市/灯光秀/古城夜景等"晚上才好看"的地标）**：不要混进白天快切段，把它排在**黄昏过渡之后、晚安之前**——序列变成"白天景点 → 黄昏过渡 → 夜间景点 → 回酒店晚安"，黄昏照旧当桥，晚安顺势接"玩累了回来"更自然。地名 `text` 搜索时留意结果里"夜景/晚上必去"的说法，**把景点按适合时段归位**（白天景点放白天、夜景放夜里）。
- **铁律：全片画面按一天时间单向排序（晨 → 昼 → 黄昏 → 夜 → 晚安），禁止时间回跳**——夜景之后不能再出现白天画面，混乱的时间线比少一个景点伤害大得多。
- 结尾的"晚安"是情绪落点，要拍出"旅途结束、舒服躺下"的松弛感——**两个硬要求**：① **像人一样躺睡在床上**（拟人化：头枕枕头、身子钻进被窝盖好被子、侧躺/仰躺，而不是猫式蜷成一团趴在床角——躺姿是"住酒店过夜"的关键拟人信号，拟人程度不够就没有 vlog 味）；② **用自拍视角收尾**（前爪把自拍杆/手机举在床头，睡眼惺忪对镜头道一句晚安再放下手机、关灯），比第三人称拍它睡觉更像真人 vlogger 的睡前打卡。落点：躺被窝里对镜头眨眼打哈欠 + 一声满足困倦的 `<喵呜…>` + 画面渐暗。

**"出发路上"走一条完整的旅途小弧线**（高铁/大巴/自驾途中是最有生活共鸣的段落，观众都体验过旅途的无聊与期待）。别只写"走向门口/上车"就切景点——按下面的自然递进拍（**玩累 → 看倦 → 睡着 → 惊醒**，自带因果和幽默感，每拍 3-4s）：
1. **玩手机/掌机打发时间**：前爪捧着**迷你手机**刷视频、或抱着**迷你 Switch/游戏机**歪头按键，玩到入迷嘴角上扬——道具要"迷你版"贴合体型（见下"人设外化"）。⚠️ 玩手机/掌机时爪子在忙，用**固定机位正对上半身+带背景**，别硬凹自拍（见"自拍怎么写才不崩·忙爪"）。
2. **趴窗看风景**：玩累了放下掌机，四足趴在车窗边，前爪搭窗沿，看窗外飞速后退的田野/山脉，耳朵随风声微动——最治愈的旅途画面。
3. **在座位上昏睡**：看着看着开始点头（小鸡啄米式一点一点），身子慢慢滑下去，缩在座位上彻底睡着，呼吸起伏。
4. **提示铃惊醒**：到站广播/提示铃"叮咚"响起，猛地弹起惊醒，耳朵竖起、一脸懵——配一声迷糊的 `<喵？>`，顺势接"到站下车"切景点段。
> 弧线整体 ≈15s；**翻包掏零食小口啃**可作为替换桥段插在 1/2 之间。这些静态坐姿桥段姿态最稳、最不易崩。时长紧张时可压缩为"玩掌机→昏睡→惊醒"三拍，但弧线的"睡着被叫醒"结尾别丢——它是路上段的萌点引爆器。

**vlog 标志视角：宠物手持自拍（自拍必须是主视角，不能只在开头用一次）**。vlog 的天然形态是"主角自己举着相机拍"，比第三人称旁观更有临场感和参与感。硬性要求：

- **每个段落至少一个自拍镜头**，尤其**景点打卡必须是"和标志性景点自拍合照"**（主角的脸占画面近处、经典地标在背景），而不是第三人称远远地拍主角走过景点——"和景点合照"才是旅游 vlog 最出片、最像真人 vlog 的画面。别把自拍只用在开头收拾行李那一下，后面景点/美食全切回第三人称。
- **自拍怎么写才不崩（线上主流打法，按"爪子忙不忙"分两种）**：
  - **爪子空着时（走路/看风景/打卡）→ 主角自主持自拍**：写"**宠物前爪握着自拍杆/手机，第一人称自拍视角，镜头从斜上方俯拍主角的脸和身后场景，画面轻微晃动**"。自拍杆比"爪子贴脸举手机"更能让观众一眼看出在自拍，也更好渲染。
  - **爪子在忙时（吃饭/收拾行李/开门）→ 别硬凹自拍**：改"**镜头固定在一处，正对主角上半身/脸部，同步带入身后真实场景**"（模拟"手机架着拍自己干活"）——这也顺带避开了"爪子又拿东西又举相机"的矛盾。
  - **片头可用经典"鱼眼贴脸自拍"**：`鱼眼超广角贴脸自拍，镜头轻微畸变，主角顶着表情凑近镜头`——网感强、抓人。
- **真实感锚点（让画面像真人 vlogger 拍的，不是动画）**：Prompt 里加"**超真实沉浸式第一视角、真实手持镜头呼吸感、轻微运动模糊、GoPro/POV 跟拍感、超细腻真实毛发、自然光影、生活流 vlog 质感**"，并显式排除"**不要低幼卡通风、不要儿童动画感**"。
- 景点大远景、美食特写可切固定机位第三人称，但**自拍视角应占一半以上镜头**，尤其"和地标自拍合照"不能省。

**出行姿态与道具（避免"四足走路又拎行李箱"的矛盾姿态）**：出行 vlog 常要主角"带着行李/举着相机赶路"，若坚持四足着地又要爪子拎箱子/举手机，模型会崩（分不清箱子怎么被四条腿的猫拖着走）。三种正解，按场景选：

- **默认允许 L2 直立行走**：出行 vlog 里让主角**两足直立走、前爪自然拎行李箱/握自拍杆**，是最顺的解法——这属于 vlog 场景的合理拟人，**除非用户明确要"纯四足真实猫"，否则可以直立行走**（此时画风仍保持真实，见 `pet-rules.md` 画风默认真实）。直立只用于"行走+持物"这类必要动作，不需要全程直立。
- **道具用能挂/握的形式**：行李用**背带斜挎在身上 / 拉杆箱**，相机用**自拍杆**——挂在身上或握在爪中，比"四足还凭空拎着一个箱子"好渲染得多。
- **移动与持物分开**：真要保持四足真实感时，就别让它"边四足走边拎箱"——移动镜头里箱子跟在旁边（如系着牵引绳自己滚）或已在画面外，持物动作放在**定点站立/坐下**的镜头里（坐着用前爪扒拉行李、站定举自拍杆），别把"移动"和"拎道具"塞进同一个动作。

**节奏控制**：
- 快切是 Vlog 的命脉，每个画面 3-6 秒，观众注意力稍纵即逝
- 场景间不需要叙事过渡，靠角色一致性串联
- 开头 2 秒必须抓人（动物的反差动作/有趣场景/悬念）

**人设外化方法**：
- 不靠旁白自述"我是一只打工猫"，靠画面里的**道具+场景**让观众自己理解
- 道具要与动物体型匹配——迷你版书包/缩小版公文包比正常人类尺寸更出效果
- 同一个道具（如标志性围巾）贯穿全片是角色锚定利器

**音频层次**：
- 底层：环境白噪音（交通声/风声/室内嗡嗡声）——营造"在场感"
- 中层：BGM 贯穿，风格统一（不要每个场景换 BGM）
- 顶层：关键动作的点缀音效（开门声/脚步声/食物声）
- **关键节点加宠物原声叫**：在情绪节点让主角发一声原声叫（不是台词，是真实动物叫），比纯画面更有"活的宠物"临场感。落点举例——准备出发时一声期待的 `<喵～>`（雀跃）、景点打卡时一声惊叹的 `<喵！>`（兴奋）、晚安镜头一声满足的 `<喵呜…>`（困倦收尾）。挑 2-3 个情绪节点即可，别每个镜头都叫，用 `<>` 音效符号写进对应镜头。
- **语言层按时长分**：短片（≤15s）可不加旁白，留白更有沉浸感；**叙事向多段（≥30s）建议内心 OS 独白**（按 SKILL.md §二发声方式确认的结果执行）——长片纯画面+叫声的信息密度撑不住叙事，一句吐槽心声顶十个表情

**高频题材的差异化设计**（"拆家装无辜""偷吃被抓"这类题材灵感库里案例很多，容易和现成案例撞车，做之前先想一层升级，选一个方向而非照抄）：
- **嫁祸型反转**：证据/嫌疑指向另一个无辜的物体或角色，而不是停在"被抓包→卖萌"这一层
- **身体诚实型反转**：表情/台词在演无辜，但尾巴/耳朵/瞳孔等身体部位不受控地暴露真实情绪，形成"表演"与"本能"的反差
- **品种性格利用**：用该品种的公认刻板印象强化喜剧效果（如二哈=拆家届扛把子、橘猫=佛系吃货、柯基=矮胖冲刺），让"这个品种做这件事"本身自带笑点，而不是换成任何动物都成立的通用桥段

## 分段策略

- **Vlog 倾向完整叙事、多段**：一个有沉浸感的 vlog（收拾行李→路上→打卡→美食→晚安）装不进 15s，通常 40-60s。用户没指定时长时按完整版给足（见 SKILL.md §二"Vlog 时长要给足"），不要缩成 15s 单段。
- 每个场景 = 一个生成调用，用 `render_video` 顺序拼接
- 角色一致性靠每段传入同一张参考图 + 主体出场镜头锚定体型词
- **段数最少化**：先按 `{{.max_video_duration}}`s 满额切分再定段数——**每段时长必须 ≤ `{{.max_video_duration}}`s（运行期的真实模型上限，不要凭想象填 30s）**。如上限 15s、要 60s 成片 = **4 段×15s**；上限 30s、要 60s = **2 段×30s**。每段内用镜头1/镜头2 分场景，不要为凑段数把单段切太短——单段内运镜更连贯，拼接点越少越好
- **各段并行生成**：切好段、构造好每段 Prompt 后，各段之间无先后依赖，**一次性并行发出所有 `sandbox_generate_video`**（见 SKILL.md §五第三步），不要逐段串行等待
