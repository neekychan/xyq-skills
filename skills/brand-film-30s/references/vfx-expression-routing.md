# VFX Expression Routing

Use this reference when a brand film, TVC, product-promotion film, or Seedance 2.5 prompt may use CGI/VFX, motion graphics, animation, mixed media, virtual production, impossible transformation, product mechanism visualization, or generated-video spectacle.

VFX is not decoration. Pick it only when it makes the product truth, category tension, brand asset, or audience fantasy more visible than live action alone:

**audience pressure -> product truth -> VFX expression -> visible proof -> brand memory**

## Seedance VFX Rule

Write VFX like a shot-list item, not a concept paragraph. Each VFX beat should have one subject, one action, one dominant camera move, one visible source, one path, one material interaction, and one readable brand/product consequence.

Required fields when VFX is central:

```text
VFX expression:
Trigger:
Source and path:
Physical / material behavior:
Camera proof:
Light integration:
Brand / product consequence:
Generation constraints:
Sound:
```

Compact sentence:

```text
{real light/object/action} triggers {VFX event}; the effect starts at {specific origin}, travels along {visible surface/path}, touches {ground/glass/skin/product edge/screen} with {reflection/occlusion/shadow/motion blur/depth change}; the camera uses {one dominant move} to prove scale; {logo/product shape/human identity} stays readable.
```

Avoid: abstract glow, random particles, dense UI, tiny labels, multiple camera moves in one beat, VFX covering logo/product edges/faces/hands/text, or effects that change product identity, lens color, logo shape, or wardrobe.

## Twelve VFX Types

| VFX type | Use when | Prompt focus |
|---|---|---|
| **Invisible VFX / clean photoreal enhancement** | real-life credibility matters but the image needs subtle control, cleanup, screen replacement, wire removal, sky/atmosphere enhancement, or practical stunt assist | natural camera, matched grain, lens distortion, realistic reflections, contact shadows, no identity distortion |
| **CG product beauty / macro material choreography** | product surface, texture, shape, ingredient, mechanism, packaging, or premium material is the hero | macro lens, PBR material, specular highlights, caustics, refraction, condensation, clean logo/pack lockup |
| **Material transformation / morphing** | the product changes a visible state: dull to bright, chaos to order, dry to hydrated, heavy to light, ordinary to iconic | continuous morph, same object/same composition, visible before-after trace, product as trigger |
| **Particle / data / swarm system** | invisible orchestration, AI, platform intelligence, network effects, scent diffusion, community energy, or attention needs form | particles represent something specific, path has direction, data converges into a result, no random tech dust |
| **Fluid / pyro / volumetric FX** | sensation is liquid, air, scent, heat, cooling, smoke, mist, breath, drink, weather, or appetite | volumetric light, density change, turbulence, splash/mist/smoke behavior, product-triggered direction |
| **Rigid-body destruction / assembly** | the brand breaks a barrier, survives impact, assembles complexity, rebuilds order, or proves strength | weight, collision, debris, scale reference, controlled collapse/rebuild, locked proof frame |
| **Set extension / digital matte / world extension** | real foreground needs future city, mythic landscape, luxury scale, travel scale, impossible architecture, or brand world | foreground realism, parallax, atmospheric depth, scale cues, matching light direction |
| **Motion graphics / kinetic typography** | process, data, finance, B2B workflow, platform logic, measurement, or slogan needs to become legible | few readable elements, vector lines from real objects, grid/easing discipline, final brand symbol or line |
| **Screen replacement / interface cinema** | app, SaaS, AI, device, or platform must appear without becoming a UI walkthrough | minimal readable UI, screen glow on hands/face, one action/result, physical-world consequence |
| **Virtual production / LED-volume look** | the route needs immersive environment control, travel without travel, premium reflections, car/vehicle movement, sci-fi space, or controlled weather/light | real foreground, tracked camera parallax, interactive reflections on skin/glass/metal/car body |
| **Stylized animation / stop-motion / tactile miniature** | charm, metaphor, handmade texture, object personality, food appetite, family warmth, or playful product world matters more than realism | frame-by-frame feel, paper/clay/fabric texture, practical tabletop shadows, product as character/rule |
| **Mixed media / collage / projection / scanography** | audience identity lives in feeds, archives, fandom edits, fashion lookbooks, screenshots, posters, zines, or creator tools | one media rule, repeated motif, projection/screen light on real subjects, synchronized fragments |

## Fast Category Fit

| Category tension | Strong VFX response | Use cautiously |
|---|---|---|
| Invisible AI / orchestration | system visualization, motion graphics, screen replacement, data-to-reality | giant sci-fi city that hides product proof |
| Luxury desirability | CG product beauty, set extension, fluid light, fashion mixed media | generic gold dust |
| Beauty transformation | material morph, macro product beauty, fluid/volumetric mist, invisible enhancement | over-medical mechanism claims |
| Auto safety / performance | practical stunt assist, rigid-body proof, sensor visualization, virtual production | fake crash spectacle with no proof angle |
| Food / beverage appetite | fluid simulation, stop-motion, macro texture, tactile live action | sterile lab CGI |
| Fashion identity | mixed media, set extension, stylized animation, projection, body-led VFX | tech particles without styling logic |
| B2B / productivity | motion graphics, data systems, interface cinema, assembly/reorganization | abstract glowing dashboards |
| Travel / service platform | set extension, invisible VFX, map/data lines, virtual production | fantasy world that erases service credibility |
| Sport / performance | practical stunt + VFX assist, time-slice, rigid-body impact, scale VFX | impossible movement with no body truth |

## Prompt Patterns

### Pattern A: Photoreal product mechanism

```text
VFX表达：photoreal CG product mechanism visualization。
触发机制：主体1触碰/打开/使用产品1，产品内部机制被短暂可视化。
来源与路径：机制从产品1的真实接触点开始，沿产品结构、液体路径、光路或机械路径运行。
物理/材质行为：半透明剖面、微粒流动、液体/光线/机械结构按真实路径运行。
镜头验证：微距镜头慢推，浅景深，产品边缘保持清晰高光。
光影融合：CG机制有接触阴影、折射、反射和运动模糊，与实拍材质一致。
品牌/产品后果：机制回到真实产品外观，形成清晰logo/pack lockup。
生成约束：no floating mechanism, no product shape change, no logo distortion。
声音：近距离材质声 + 低频启动声 + 最后一个清脆锁定音。
```

### Pattern B: World-scale transformation

```text
VFX表达：large-scale environmental transformation。
触发机制：产品1或品牌1的动作改变场景规则。
来源与路径：变化从一个明确起点开始，沿建筑、道路、房间、自然元素或人群运动方向连续扩散。
物理/材质行为：环境连续变化，保留真实重量、尺度、灰尘、反射和碰撞。
镜头验证：广角低机位或高位俯拍保留人物/产品作为尺度参照，镜头移动产生真实视差。
光影融合：变化中的物体投下阴影，反射环境光，尘雾/雨/空气粒子增强深度。
品牌/产品后果：变化最终形成产品能力或品牌信念的可见证据。
生成约束：no wallpaper background, no arbitrary spectacle, keep product cause visible。
声音：短暂静默 -> 低频上升 -> 空间移动声 -> 品牌音符。
```

### Pattern C: Data-to-reality conversion

```text
VFX表达：data particles converting into physical action。
触发机制：产品1接收一个简单输入/信号。
来源与路径：数据点从屏幕、物体边缘、桌面或空间节点流出，沿真实空间路径移动。
物理/材质行为：数据点汇聚成订单、方案、路线、作品、完成状态或物理变化。
镜头验证：跟拍粒子路径，穿过前景物体时有遮挡关系，落到实体物上时产生微光和接触阴影。
光影融合：粒子亮度照到手、桌面、墙面或产品边缘。
品牌/产品后果：混乱信息变成一个清晰结果，品牌1作为组织者出现。
生成约束：minimal readable UI, no tiny labels, no random tech dust。
声音：键入声/通知声 -> 细碎粒子声 -> 有秩序的节拍。
```

### Pattern D: Mixed-media identity build

```text
VFX表达：mixed-media collage synchronized by one brand rule。
触发机制：主体1的动作/音乐/产品1颜色让不同媒介片段开始同步。
来源与路径：照片、屏幕、纸张、投影、手绘线条或实拍人物从同一个构图/动作/颜色规则出发。
物理/材质行为：媒介片段按同一节奏切换、叠加或拼合。
镜头验证：保持一个重复构图或动作，避免每帧都换语言。
光影融合：投影光或屏幕光落在真实人物和产品上。
品牌/产品后果：碎片最终拼成品牌1的态度、社群或产品符号。
生成约束：one media rule only, no random moodboard, keep product proof visible。
声音：快门、磁带噪声、点击声或节拍作为统一线索。
```

### Pattern E: Photoreal light compression for reflective products

Use for eyewear, lenses, glass, mirrors, chrome, vehicle lights, watch crystal, polished packaging, and products whose proof depends on controlling glare, reflection, clarity, speed, or visual focus.

```text
VFX表达：photoreal light-compression effect, realistic reflections on product surfaces。
触发机制：主体1戴上/打开/转动产品1的瞬间，真实环境中的 glare、高光或眩光被产品1的镜片/玻璃/金属边缘重新组织。
来源与路径：光线来自明确可见的玻璃幕墙、天空、地面反射、车灯、棚灯或水面反光；先在产品表面收缩成细线，再沿产品边缘或真实空间表面滑动，最后汇聚成一条可读路径、轮廓光或品牌符号。
物理/材质行为：产品表面保持原本材质，深色镜片仍然深黑，透明玻璃仍然有折射，金属边缘有冷白高光；光轨贴着地面、玻璃、皮肤、车身或产品边缘运动，不凭空漂浮。
镜头验证：使用一个主镜头运动，例如 macro dolly-in、low-angle push-in、side tracking shot、slow orbit 或 locked proof frame；保留主体、产品、地面/背景和光轨之间的尺度关系。
光影融合：光效有地面微反射、前景遮挡、接触阴影、镜片/玻璃反射、运动模糊和景深变化；logo、产品轮廓和关键材质不被光效覆盖。
品牌/产品后果：产品1把刺眼、混乱、速度、压力或杂散信息整理成清晰方向，证明产品带来控制感、专注、保护、速度或高级质感。
生成约束：no abstract floating light, no random particles, no transparent screen on lenses, no logo distortion, no product shape change, keep the product identity stable and readable。
声音：环境噪声先变窄，光线收束时出现短促 whoosh、玻璃/金属细响或低频电子 pulse，最终落到干净 sonic logo。
```

## Final Check

- Does the VFX answer the category tension, or is it only visually loud?
- Can the audience understand what changed in the first viewing?
- Is the product or brand the cause, proof, tool, witness, or final memory?
- Does the prompt say where the effect starts, where it travels, and what surface it touches?
- Is there one dominant camera movement per VFX beat?
- Are scale, light, shadow, reflection, occlusion, motion blur, and sound specified?
- Are product identity, logo shape, lens/surface material, and human identity protected from distortion?
- Is there one final proof frame where the brand/product remains readable?
