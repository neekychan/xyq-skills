# 故事板设计规范

这些是可适配的模式与句式，按场景改写，不要逐字照搬。

## 概述

故事板是连接视频规范与实际生成的桥梁。它将创意需求转化为三个结构化部分：关键元素、镜头列表、独立音频层。每个部分都有明确的格式和质量要求。

## 关键元素设计

### 关键主体（角色）

- 每个角色分配唯一的元素 ID（如 `[Char_Detective]`、`[Char_Victim]`）。
- 如果角色在项目中具有多种状态或外观（不同的服装、年龄），在描述中明确说明：
  - Look 1: 深色风衣，凌乱黑发，疲惫眼神，下巴胡茬
  - Look 2: 白色衬衫，整齐发型，精神饱满
- 角色描述应包含足够细节以在镜头间保持一致性：面部特征、体型、发型/颜色、服装与配饰、显著标记。

### 关键地点/场景

- 每个场景分配唯一的元素 ID（如 `[Scene_Office_Noir]`、`[Scene_Alley_Night]`）。
- 描述场景中重要物体的位置和朝向，特别是道具或发生重大动作/表演的区域。
- 示例：昏暗的侦探办公室，百叶窗半闭投射条纹光影。办公桌居中偏左，上面有一盏绿罩台灯和一部老式电话。右侧墙壁有一扇半开的门，门后走廊隐约可见。

### 关键道具

- 推动剧情或具有象征意义的物品分配元素 ID（如 `[Prop_Dagger]`、`[Prop_Letter]`）。
- 描述形状、材质、颜色、尺寸、状况和独特标记。

### 角色音色参考

- 如有语音需求，生成或处理用户上传的音色参考素材。
- 音频时长要在 15 秒以内。

### 用户提供的资产

- 如果用户提供了参考媒体并将其指定为关键元素，描述必须与之匹配。
- 不要与所见或所听到的内容相矛盾。
- 在故事板的 asset 字段中标记为已绑定。

## 镜头设计

### 长镜头优先原则

- 优先采用带内部剪辑的长镜头（每个镜头 10-15 秒）。
- 在镜头内部设计节奏，而不是拆分为许多短镜头。
- 剪辑频率应跟随叙事节奏。
- 任何镜头不得超过 15 秒（当前模型的最大时长限制）。

### 每个镜头描述必须包含的字段

1. **场景**：引用地点/场景元素 ID（如 `[Scene_Office_Noir]`）。
2. **故事内容**：
   - 角色和关键物体的动作与动态。
   - 对话和表演。
   - 写出准确的台词（口头对话或内心独白/画外音 OS）。
   - 使用元素 ID 引用角色（如 `[Char_Detective] 缓缓转身`）。
3. **电影摄影**：
   - 景别：远景 / 中景 / 近景 / 特写 / 大特写。
   - 摄像机角度：平视 / 低角度 / 高角度 / 俯视 / 仰视 / 荷兰角。
   - 摄像机运动：固定 / 平移 / 推入 / 拉出 / 环绕 / 手持跟随 / 升降。

### 内部剪辑镜头

当镜头包含内部剪辑时，在场景/设定描述之后，按照剪辑顺序列出故事内容和电影摄影：

```
Shot_03:
  场景: [Scene_Office_Noir]
  时长: 12s
  内部剪辑: 是

  Beat 1:
    电影摄影: 中景，低角度，固定
    故事内容: [Char_Detective] 坐在办公桌后，手指轻敲桌面。台灯的绿光映在他脸上。

  Beat 2:
    电影摄影: 推入至特写，平视
    故事内容: [Char_Detective] 拿起桌上的 [Prop_Letter]，展开阅读。眉头紧锁。
    对白: {这不可能...}
```

### 镜头间连贯性

- 标注哪些镜头与前序镜头具有极高连贯性（同一场景的连续动作、同一角色的连续表演）。
- 对于高连贯性镜头，在生成时将前序镜头的视频作为参考输入。
- 非连贯镜头不需要视频参考。

## 独立音频层设计

### 背景音乐

- 设计至少一个全局背景音乐轨道。
- 如果视频较长（3 分钟或以上）且有明显的间歇或转折点，规划多个音乐片段：
  - 每个片段有自己的 `audio_id`（如 `[BGM_01_MainTheme]`、`[BGM_02_Tension]`）。
  - 每个片段定义覆盖的镜头范围（如 Shot_01 - Shot_03）。
- 描述音乐风格、乐器、节奏和情绪基调。

### 旁白

- 如果使用大段旁白解说来推进故事，在音频层中设计旁白轨道。
- 类型设为 `narration`。
- 定义语音特征（如低沉男声、温柔女声）和语调（如沉稳、急促、回忆感）。
- 写出准确的旁白脚本。
- 使用 `layout_instruction` 将旁白限制在相关的镜头范围内。
- 旁白脚本语言遵循视频规格中的输出语言。

### 音效

- 按需设计关键音效（如脚步声、门铃声、雨声）。
- 标注音效出现的镜头和时间点。

## 故事板自检清单

- 每个角色是否有唯一的元素 ID？
- 多外观角色是否明确标注了各 Look？
- 场景描述是否包含重要物体的位置和朝向？
- 每个镜头是否在 15 秒以内？
- 镜头是否优先采用长镜头带内部剪辑？
- 每个镜头是否包含场景引用、故事内容、电影摄影三要素？
- 内部剪辑镜头是否按剪辑顺序列出了各 beat？
- 是否设计了至少一个全局背景音乐轨道？
- 旁白是否定义了语音特征和准确脚本？
- 用户提供的资产是否已正确绑定并标记？
- 是否标注了需要连贯性参考的镜头对？
