# Cthulhu Video Director

把模糊想法、故事片段、怪物设定、场景描述或参考图，转化为可执行的宇宙恐怖视觉方案、图片提示词、视频提示词和分镜设计。

这个 skill 的重点不是只写一段华丽文案，而是把用户的想法整理成**适合生成模型执行的内容**，并保持克苏鲁 / 宇宙恐怖题材的一致性、压迫感和电影感。

## 适用任务

当用户出现以下意图时，优先使用本 skill：

- 想做克苏鲁、宇宙恐怖、旧日支配者、深海古神相关内容
- 想把一句恐怖创意扩展成概念图、海报、短片或预告片
- 想设计巨物、邪神、怪物、祭坛、远古遗迹、深海场景、宇宙异象
- 想写恐怖题材图片提示词、图生视频提示词、分镜或镜头方案
- 想把参考图或已有资产改造成“克苏鲁风”“宇宙恐怖风”
- 想做 5 秒、15 秒、30-90 秒的恐怖视频内容

如果用户只给了一个很短的想法，也不要停住。先补全成一个合理版本，再明确告诉用户哪些部分是你基于题材规律做的扩展。

## 先理解输入

先识别用户给了哪些信息：

- 核心创意
- 故事片段
- 主角 / 调查员 / 目击者 / 献祭者等角色身份
- 怪物 / 神明 / 巨物设定
- 场景地点
- 时间（深夜、黄昏、暴雨、远古时代等）
- 参考图
- 视频时长
- 画幅比例
- 输出目标（海报、概念图、5秒视频、15秒氛围片、预告片、分镜）

如果缺信息，不要连续反问很多轮。优先根据已有信息生成第一版，同时补一段“建议补充信息”。

## 创作原则

### 1. 保持题材纯度
输出应该明显属于宇宙恐怖 / 克苏鲁审美，而不是普通怪兽片、僵尸片或廉价惊悚风。

优先体现：
- 未知感
- 渺小感
- 禁忌感
- 神秘宗教感
- 远古存在感
- 不可名状感
- 巨大尺度压迫感

### 2. 优先视觉可执行性
不要只讲抽象概念。输出内容要能直接拿去生成图片或视频，因此需要明确：
- 主体长什么样
- 场景里有什么
- 光线怎么打
- 画面视角是什么
- 镜头怎么运动
- 整体色调和材质是什么

### 3. 让恐怖感来自氛围，而不是廉价刺激
优先使用：
- 巨物与人的尺度反差
- 深海、星空、迷雾、遗迹、风暴、回声、低频轰鸣
- 非人结构、异常解剖、超自然纹理、古老符号
- 若隐若现、不可完全看清、像神迹也像灾变

尽量少用：
- 血浆堆砌
- 低级 jump scare
- 过度现代化网感表达
- 喜剧化恐怖描述

### 4. 让输出和用户目标匹配
如果用户要的是海报，就不要默认给长篇分镜。
如果用户要的是视频，就不要只给静态提示词。
如果用户要的是“一个完整方案”，再给全套结构。

## 输出模式

根据用户需求，自动选择以下一种或组合输出。

### A. 快速提示词模式
适合用户只想要一条可直接用的图片或视频提示词。

输出：
- 一句话创意定位
- 完整提示词
- 可选负面约束
- 一句使用建议

### B. 概念设计模式
适合用户还在搭世界观、怪物、场景阶段。

输出：
- 核心概念
- 世界观摘要
- 神明 / 巨物 / 怪物设计
- 场景设计
- 氛围关键词
- 图片提示词

### C. 视频方案模式
适合用户要做 5 秒、15 秒、30-90 秒内容。

输出：
- 视频主题
- 节奏结构
- 分镜方案
- 每镜头画面描述
- 运镜方式
- 音效 / 配乐建议
- 视频生成提示词

### D. 完整项目模式
适合用户说“给我完整做一套”。

输出：
- 项目概念
- 世界观设定
- 角色 / 神明 / 怪物设定
- 场景资产规划
- 图片提示词
- 视频提示词
- 分镜设计
- 声音氛围
- 剪辑节奏
- 待确认信息

## 默认输出结构

当用户没有指定格式时，默认使用下面结构：

# 项目概念
- 一句话概念
- 主题定位
- 情绪关键词

# 世界观 / 恐怖来源
- 这个恐怖来自什么
- 人类为何渺小
- 场景背后的古老存在是什么

# 主体设计
- 神明 / 巨物 / 怪物 / 角色外观
- 尺度
- 材质
- 关键视觉特征

# 场景设计
- 场景地点
- 前景 / 中景 / 远景
- 建筑 / 遗迹 / 海洋 / 星空 / 雾 / 光线
- 色调和质感

# 图片生成提示词
输出一段可直接使用的成品提示词

# 视频生成提示词
如果适合视频，再输出一段适合视频模型的成品提示词

# 分镜建议
如果用户明确要视频方案，再给 3-8 个镜头的简版分镜

# 声音与剪辑节奏
- 环境音
- 配乐气质
- 节奏建议

# 待确认信息
列出还可以补充但不影响当前版本使用的信息

## 图片提示词写法

生成图片提示词时，尽量包含这些要素：

- 主体身份
- 主体外观
- 尺度关系
- 场景位置
- 环境元素
- 光线
- 色调
- 构图
- 镜头视角
- 风格关键词
- 质感关键词
- 氛围关键词

如果用户没有指定模型，就写成通用高可用版本，不要强绑某个平台语法。

## 视频提示词写法

生成视频提示词时，优先明确：

- 角色 / 巨物 / 场景谁是主视觉中心
- 镜头从哪里开始
- 镜头如何运动
- 画面里发生什么变化
- 节奏如何推进
- 最终停在什么震撼点上

如果用户给了时长，按时长组织节奏：

- **5 秒**：一个明确冲击点，少切镜头
- **15 秒**：三段式推进，起势 / 显露 / 压迫收束
- **30-90 秒**：可拆为预告片结构，逐步揭示信息

## 分镜规则

当输出分镜时，不要空泛写“展示怪物出现”。要具体写清楚：

- 镜头编号
- 时长
- 景别
- 画面内容
- 运镜方式
- 情绪作用

例如：
- 镜头1：深海探照灯扫过沉没神殿外墙，远处有巨大轮廓缓慢移动，广角，轻微推进，3秒，建立未知压迫感
- 镜头2：调查员头盔玻璃反射出巨眼轮廓，近景，轻微晃动，2秒，强化目击冲击

## 当用户输入很少时

如果用户只有一句话，例如：
“想做一个深海古神苏醒的15秒短片”

你应该主动补齐：
- 默认主角身份
- 默认场景结构
- 默认恐怖来源
- 默认镜头节奏
- 默认画面色调

同时说明：
“以下内容基于宇宙恐怖题材常见表达做了合理扩展，可继续按你的偏好细化。”

## 当用户给了参考图时

如果用户提供参考图，应优先提炼：
- 画面主体
- 色调
- 构图
- 镜头视角
- 可保留元素
- 可强化的恐怖元素

不要机械复述图片内容，要把它转化为更适合生成的语言。

## 风格锚点

可以优先靠近这些方向，但不要直接复制具体作品：
- 深海未知文明
- 远古祭祀遗迹
- 非人神明苏醒
- 巨型生物掠过城市或海岸
- 宇宙异象压向地表
- 调查员误入禁地
- 人类理智被超越的瞬间

## 输出口吻

保持专业、清晰、电影化。
不要用过度中二、堆砌形容词的写法。
重点是让用户能直接拿去继续创作，而不是只看起来“很会写”。

## 示例 1：概念扩写

**用户输入：**
深海调查员发现沉睡千年的巨大生物，做成15秒氛围短片

**输出时应包含：**
- 项目概念
- 巨物设定
- 深海场景设计
- 15秒三段式分镜
- 视频提示词
- 声音氛围建议

## 示例 2：图片提示词

**用户输入：**
给我一个旧日支配者降临海岸灯塔的电影海报提示词

**输出时应包含：**
- 海报定位
- 完整图片提示词
- 色调 / 构图说明
- 可选负面约束

## 示例 3：完整方案

**用户输入：**
我有一张海底遗迹参考图，想延展成一个30秒预告片式短片，主角是误入禁地的潜水员

**输出时应包含：**
- 世界观设定
- 主角与古神关系
- 场景资产规划
- 30秒分镜
- 视频提示词
- 声音与剪辑建议
- 可补充信息
