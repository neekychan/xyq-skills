## 一、Film DNA 摄影体系

Film DNA 决定全片的影像画质、影调风格与色彩科学，由 4 个正交维度组装而成：

```text
Film DNA: {画质与片基媒介}，{镜头规格与焦段}，{光影系统与体积感}，{色彩科学与影调反差}，{快门与动态质感}。
```

| 维度 | 选项积木池（选 1 组，保持全片统一） |
|---|---|
| **画质与片基** | `High-Fashion 顶级先锋时尚大片质感` / `35mm变形宽银幕电影胶片质感` / `IMAX 65mm超高清数字大片` / `16mm复古颗粒独立电影` / `高对比日漫赛璐珞动画` |
| **镜头与焦段** | `35mm浅景深人像定焦镜头` / `24mm广角大透视镜头` / `85mm电影长焦压缩景深` / `微距探针特写镜头` |
| **光影系统** | `直闪摄影 (Direct Flash) 与强反差黑白` / `硬核阴影 (Hard Shadow) 与大几何建筑光影` / `戏剧性侧光与强轮廓光 (Rim Light)` / `舞台硬核追光与频闪光束` / `逆光丁达尔体积冷雾` |
| **色彩科学** | `极致高反差黑白搭配局部电光红点缀` / `柯达 500T 胶片颗粒与低反差暗部过度` / `青橙色调 (Teal & Orange) 强反差` / `赛博朋克电光蓝与冷白高光` / `高饱和青粉撞色` |
| **快门质感** | `1/500s 高速快门冷酷定格` / `90度窄快门锐利动作停顿 (Hit)` / `180度标准电影快门自然运动模糊` / `慢快门光斑拖尾` |

## 二、四层标准提示词结构（吸收 prompt-craft 工业规范）

Prompt 在发送给模型时，**严禁携带任何 `【Layer N】` 或 `Layer N:` 结构标签**。Prompt 呈现为清晰流畅的纯文本段落，逻辑上严格按以下四层组织：

```text
第一层：素材职务与音频绑定
  - @图片1..@图片N 声明各角色职务（纯人物定妆照，严禁传入场景图）；
  - @视频1 声明：严格跟随 @视频1 的音频作为全段唯一背景音乐，不提供画面，不擅自编曲，严禁生成任何其他无关音轨（【红线】严禁在 Prompt 中具体描述音频的乐器、BPM 或编曲细节，防止模型自行编曲）。

第二层：一句话全局概述
  - 主体 + 空间置景 + 核心表演/事件 + Film DNA 摄影定位（一句话让模型先拿到全片全局图景）。

第三层：画面阶段（按秒数区间与镜头序号连续推进，保持提示词精简纯粹）
  - 必须按秒数区间与景别动作连续推进（如 `镜头1 (0-6s 大光圈虚焦特写)`、`镜头2 (6-18s 中近景侧拍)`、`镜头3 (18-24s 特写拉移)`、`镜头4 (24-30s 空镜远景)`）；
  - **【红线禁令】严禁在镜头标题括号内重复堆砌歌词文本与唱演标签（如严禁写 唱演：小满那天... / 唱演：本来就没有大满）**！
    - 原因：视频生成模型已物理输入 @视频1 音频切片，会直接根据音频物理波形与声学事件自动对齐节拍与口型起止，标题只保留 `(秒数区间 + 景别动作)`，杜绝冗余的歌词标题噪音；
  - 每个阶段包含：景别角度 → 运镜与排版动能 → 动作四阶发力过程 → 环境光物理反射 (Rim Light/漫反射) → 绝大多数镜头不写任何歌词（纯画面叙事与画外音）；仅在极少数正面特写确需开口时在正文句末自然注明 `{歌词}`。

第四层：技术约束与全量负向尾注
  - 包含保持无字幕、不要生成水印/logo、肢体解剖稳定、严格对齐 @视频1 音频、严禁生成其他BGM；
  - 在 `storyboard.md` 中，全片逐字相同的质量约束统一收录于 `## 通用尾注` 小节，各 `shot_NN` 的 Prompt 不逐段重复书写，调用生视频前由主 Agent 自动拼接至 Prompt 末尾。
```

## 三、高密度秒数阶段编排法、景别呼吸律与四大动能体系

快节奏曲目（舞曲/K-pop/摇滚/说唱/动态漫）每 15 秒单段内编排 **6~8 个高能微镜头（1.0s ~ 2.0s 一阶段，按秒数连续推进）**。

### 🌟 体系一：拒绝立牌与跑步机！8 大多变肢体动能与多机位破风冲刺 (Dynamic Kinematics & Locomotion)
严禁全片 2 分钟频繁出现“平视正面中景看镜头”的呆板立牌，**严禁使用“背对镜头狂奔”或“正面大步跑向镜头”这类单一平视原地跑步机动画**！每个镜头必须从以下 8 大动能力学中抽取：
1. **多机位破风冲刺三连击 (Multi-Angle Sprint Transitions)**：
   - 奔跑冲刺段落**严禁单一机位到底**，必须在 2~3 秒内串联 2~3 个剧烈视角跳切：
     - ① `斜下方15度贴地飞驰跟拍，特写马丁靴每一次凶猛抓地与火星喷溅`；
     - ② `硬切侧面45度大透视超车，身体前倾45度破风，背景拉成极速动态模糊流线与放射状速度线(Radial Speedlines)`；
     - ③ `重拍瞬间单膝急刹滑行(Knee Slide & Lock)，鞋底在地面摩擦出长长火花划痕定格`；
2. **高空坠落与背跃倒悬 (Falling / Reverse Freefall)**：主角背向镜头坠入深邃数据虚空，发丝与风衣向上倒悬翻飞，周围金色数据碎片逆向向上飞散；
3. **单膝跪地滑行与擦出火花 (Knee Slide & Sparks)**：极低机位，马丁靴与膝盖在镜面/柏油路上极速滑行摩擦出火星与同心光环；
4. **背对镜头逆风大步前行 (Back View Walking into Void)**：大景别背影，风衣下摆在暴风中烈烈作响，大步走向通道尽头；
5. **90度天顶垂直俯瞰 (God's Eye Top-Down)**：镜头垂直从天顶直下俯拍，主角躺倒或驻足在巨大的几何光影与地面数据线条上；
6. **大角度侧倾与单手横斩 (Dynamic Slash & Lean)**：身体重心大角度侧倾，单手向画外凶猛挥砍撕裂空间；
7. **具象化具动能手势 (Active Hand Interactions)**：拒绝呆板握拳与拉扯领口，采用 `指尖在虚空极速输入发光指令`、`单手擦拭嘴角血迹/雨水`、`单掌按压镜面震碎玻璃`、`猛然拔出背部充能插头`；
8. **身体像素化分解与双分身错位 (Pixel Dissolve & Twin Shift)**：身体局部化为蓝色数据方块飘散，左右两个残影分身反向跳跃。

### 🌟 体系二：动作四阶力学闭环与特写叙事因果链 (Action-Causality Triad)
1. **动作四阶发力闭环**：
   描写任何人物动作时，必须带出完整的物理发力过程：
   `[1. 重心与预备蓄力 (Anticipation)] → [2. 瞬态发力与破风轨迹 (Explosive Motion)] → [3. 重音阻尼顿停/定格 (Impact Hit & Lock)] → [4. 环境物理反馈 (Sparks/Debris/Ripple)]`。
2. **特写叙事动机与因果链铁律（严禁目录式三屏并置）**：
   - **【红线禁令】严禁无因果关系的静态部位并置（如单纯并置眼/手/鞋三特写，沦为商品目录与模型卡）！**
   - 任何局部特写必须严格遵循三阶因果链：
     - 链条 A: `[视线察觉：瞳孔微距倒映前方警报红光] → [动作执行：双手猛烈推开控制阀] → [环境反馈：全屏蒸汽与管线爆裂]`；
     - 链条 B: `[蓄力准备：鞋底重重踏碎发光数据芯片] → [动作交互：单手横刃切断虚空锁链] → [大景别爆发：锁链碎片四散化为金色火星雨]`。

### 🌟 体系三：场景「全局定调世界观，微镜头轻量聚焦」法则 (Global Setting vs Lightweight Shots)
1. **防止过度死板与限制模型发挥的黄金平衡**：
   - **❌ 错误做法 A（微观每镜重复堆砌 3 层，锁死模型）**：在每一个微镜头里都把地面、建筑、粒子全部罗列一遍——导致 Prompt 严重膨胀超载，Attention 权重稀释，破坏模型自发的空间构图与透视发挥；
   - **❌ 错误做法 B（负向词写白底，导致死板毛坯空洞）**：写“极简纯白底 / 冷白通道”——模型把白底当成真实指令，渲染出毫无质感的毛坯白墙，人物像贴纸悬浮；
   - **✅ 正确的全局与微观分工机制**：
     - **① 全局定调（第二层 Layer 2，整段只写 1 遍）**：
       - 在整段 Prompt 开头用一句话交代宏观世界观场域、基础材质与光影色调（如：`赛博朋克国潮动态漫美学，深黑镜面地面搭配流动代码雨与赛博建筑纵深，高饱和亮橙与电光青对撞...`），给模型潜空间注入高上限的美学基准；
     - **② 微镜头轻量聚焦（第三层 Layer 3，每镜只写 3~6 字关键光影锚点）**：
       - 微镜头只需聚焦于**机位角度、主体动作四阶发力、排版动能与关键光影交互 (Rim Light)**；
       - 特写镜头（如瞳孔微距、单手拔插头）：只需写明人物动作与光影倒影（如 `灰蓝瞳孔深处倒映警报红光`），**完全无需重复描述大楼或地面**；
       - 大景别/冲刺镜头：仅需简明点出 1 句空间关系（如 `背景为深蓝数据深渊` 或 `马丁靴在地面踩出金色火星`）；
       - **将具体的建筑排布、透视角度与环境细节 100% 交由视频模型自由生成**！
   - **爆白瞬态限制**：白光过曝只允许作为 1~2 帧瞬态闪光 (`1-Frame Invert Flash` 或 `2-Frame Light Leak`)，闪光过后立即切入实体空间。
2. **环境光物理投射三要素 (The Lighting Interaction Triad)**：
   - ① **边缘轮廓光 (Rim Light)**：场景主色（冰蓝/烈橙/金光）勾勒发梢、下颌、肩膀与皮衣边缘；
   - ② **漫反射阴影 (Ambient Shadow)**：背光面沉入冷/暖漫反射暗调；
   - ③ **镜面反射高光 (Specular Highlight)**：瞳孔与金属配饰倒映环境光源。

### 🌟 体系四：景别呼吸律与非人脸特写铁律
- **严禁连续 2 个镜头使用相同平视正面机位**！
- **非人脸微镜头占比必须 $\ge 35\% \sim 40\%$**：强制分配 40% 的镜头给**厚底鞋踩踏水洼、机械手臂关节、瞳孔微距倒影、虚空锁链断裂、旋转时钟齿轮、地铁横切**，且每个非人脸镜头必须具备明确的动作因果与物理交互，彻底摆脱单一立牌感！

## 四、Kinetic 光学运镜、排版动能与微观冲击帧 (Optical & Typography VFX)

在编写分镜微镜头时，可从以下高能光学积木中抽取注入：

| 特效积木 | 视觉语言与动能机制 | Prompt 描述句式模板 |
|---|---|---|
| **1. Digital Punch Zoom 数字变焦卡拍（K-pop/舞曲招牌）** | 随底鼓重拍/身体重击，画面瞬时放大 8%~15% 后顺势微弹回，强力卡拍且不打碎队形 | `随重拍底鼓画面做一次 10% 数字变焦 (Digital Punch Zoom) 瞬间放大并弹回强化卡点` |
| **2. Speed Ramp 变速抽帧卡点** | 动作在重音落地瞬间骤降至 5% 快门极慢定格，下一帧抽帧瞬间恢复原速砸实 (Hit) | `动作在重拍落地瞬间骤降至极慢速门定格，随后抽帧瞬间恢复原速砸实定格姿态` |
| **3. Crash Zoom 光学暴冲** | 焦距在 6 帧内从广角队形暴冲至眼部微距，背景压缩扁平化 | `镜头在 6 帧内光学暴冲 (Crash Zoom) 推到眼部极限微距，眼神锐利对焦` |
| **4. Whip Pan 极速横甩高光拖尾** | 镜头向侧方极速横甩拉出水平运动高光条带，甩停瞬间硬切下一布景 | `镜头向左侧极速横甩 (Whip Pan) 拉出粉色高光拖尾，甩停瞬间硬切下一布景` |
| **5. Fast 360 Orbit 相机绕人环转** | 相机在视线高度 0.8s 极速绕人圆周环绕，背景甩成流光色环（适合 Intro / Bridge） | `虚拟相机在视线高度以 0.8 秒极速完成 360 度圆周环绕 (Fast 360 Orbit)，背景甩成流光色环` |

| **7. 3-Frame RGB Glitch 瞬态故障桥** | 转场瞬间 3 帧色散与细扫描线，通道咬合瞬间眼神凌厉对焦 | `转场瞬间产生 3 帧极简 RGB 色散与扫描线 (RGB Glitch)，通道咬合瞬间眼神凌厉对焦` |
| **8. 2-Frame Film Burn 漏光爆白切屏** | 画面边缘 2 帧高光漏光瞬间爆白切断画面，硬切下一套造型与布景 | `画面边缘产生 2 帧高光漏光 (Light Leak) 瞬间切屏，硬切露出下一套造型与布景` |
| **9. 3D 实体前后夹心排版 (Typography Sandwich)** | 超大实心无衬线粗体字矗立在身侧身后，部分笔画穿插在肩膀手腕前方形成前后视差 | `紧凑实心无衬线粗体字【OVERFLOW】呈现前后夹心视差，大字部分笔画穿插在肩膀前侧` |
| **10. 字体内嵌透视镂空蒙版 (Mask Windowing)** | 巨大文字如钢印横扫，字体内嵌镂空窗口透出下一场景细节并瞬间切屏 | `巨大黑色粗体字【CUT】横扫切割全屏，字体笔画内部作为镂空蒙版透出侧脸特写并硬切` |

| **12. Hard Shadow Decoupling 影子剥离与出画** | 强光在平整墙面投射出巨大剪影，角色身体迅速滑出画幅，焦点落在墙面虚化残影 | `强单向光将巨大硬剪影打在水泥墙上，角色身体横向滑出画面，焦点定在墙面残留的虚化剪影` |

## 五、Prompt 发布前自检清单

每次发出 `sandbox_generate_video` 调用前核对：
- [ ] **光影物理融合检查**：每个微镜头明确写明场景主光对角色发梢、下颌、肩膀的轮廓光 (Rim Light) 与漫反射阴影，杜绝抠图贴纸感。
- [ ] **动作力学与多机位检查**：无连续 2 个平视正面立牌镜头，包含了 8 大动能力学之一与四阶发力过程，非人脸特写 $\ge 35\%$。
- [ ] **排版动能力学检查**：文字使用了实心粗体、前后夹心/透视蒙版与动能动词，无静态悬浮字牌。
- [ ] **微观卡点与冲击帧检查**：军鼓/Drop 爆发处包含了 1 帧反相闪击 (Invert Flash) 或数字变焦 (Punch Zoom)。
- [ ] **歌词意象具象化**：歌词核心词（快门、换脸、影子、出画、过线、Freeze）已 1:1 转化为具体的物理镜头。
- [ ] **全量负面尾注**：包含“保持无字幕，不要生成水印/logo，人物五官与肢体稳定不变形，全片不要在同一画面中复制相同主角人物，禁止自行生成其他BGM”。
