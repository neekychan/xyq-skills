# VFX/动作特效 Prompt 编写指南

本指南在**视频生成阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。规划阶段的弧线、角色设定、特效属性见 `creative/vfx-action.md`。

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| "两人激烈交锋" | 画面静态或两人站桩不动 | 连招式描写：冲→砍→挡→反击，每拍有肢体动作 |
| "释放火焰攻击""使出降龙十八掌" | 角色站着不动，特效凭空飞出 | 特效附着动作："右拳猛推，掌心喷出金色气浪" |
| 全片 4 段动作密度一样 | 视觉疲劳，无高潮感 | 四段式弧线递进：碰撞→缠斗→升级→爆发 |
| "两人贴身缠斗"但无接触描写 | 两人贴脸站着发呆 | 近距离必须有武器碰撞/肢体接触 |
| A挥刀砍来，B伸手/胳膊挡住 | 空手接白刃 | 防御对等：武器攻 → 武器挡/闪避 |
| "两人同时向对方冲去" | 位置跳变，渲染成对称但不交汇 | 画面方位词："画面左侧A从左向右冲，右侧B从右迎击" |
| 开头花 3-5 秒对峙/亮相/蓄力 | 浪费宝贵时长 | 第一帧就开打 |
| "能量""力量""气" | 模型不知道长什么样 | 具象化："蓝色水龙""金色雷电残影""紫色剑影群" |
| 武器碰撞写"剑与剑相交""兵器碰撞" | 两把武器平行贴合如两块板子，无碰撞感 | 写明交叉角度："剑刃呈X形交叉僵持""斜劈被横挡，刃面成十字卡住" |
| 战斗间对话写两人近距离面对面站着说话 | 两人贴脸聊天，像在逛街不像在打架 | 对话只出现在两种场景：①武器僵持中说话（兵器交叉抵住，边较力边说）；②远距对峙说话（两人相隔 5 步以上，各自持武器戒备姿态）|
| A劈砍/攻击，B只描述"举剑格挡"无身体反应 | B 站着不动等着被砍，像木桩 | 防御必须有身体动态：后仰/侧身/重心后移/脚步后撤/膝盖弯曲卸力，不能光写武器动作不写身体 |
| 多人对决写"左/中/右"一字排开，或位置都在"前方" | 三人站成同一平面无纵深，两个攻手变成互相对视，目标反而像旁观者 | 首选：镜头放在一方身后（过肩/背后视角），近景方背对镜头，深处方面朝镜头冲来。次选：侧拍全景，左右对峙用「侧身朝左/右」。每个画面阶段精确描述 ≤3 人，多余角色降为画面边缘一笔带过 |
| 武侠文学词入 Prompt（"十有七虚""渊停岳峙""一派宗师气概""盈盈一笑"） | 摄像机拍不到，模型无法执行 | 通用规则见 `prompt-craft.md` 红线表「文学词入 Prompt」；武侠题材高频词照此具象化 |
| 只写逐招编排不写整体氛围（"A刺→B挡→A踢→B闪"） | 动作有但缺乏速度感和冲击力，画面像慢动作回放 | 连招编排之外必须叠加战斗氛围三要素：高速动态+碰撞震动+环境碎裂（见强制规则 §11） |

## 强制规则

1. **特效长在角色身上**：挥刀时刀刃裹火焰、冲拳时拳风带雷电、翻身闪避时身后拖水墨残影。禁止"召唤兽式打斗"——角色站着不动释放独立特效体在空中碰撞
2. **打斗是连招（≥2-4 拍动作链），不是单招**：每组攻防包含起手→跟进→终结，不是"A打一下→B挡一下"的回合制
3. **近距离必须有物理接触**：出现"贴身/近身/缠斗/逼近"时，必须紧跟武器碰撞或肢体接触描写
4. **防御对等**：武器攻击 → 武器格挡/闪避；特效攻击 → 同属性特效/护盾/闪避。禁止空手接白刃（除非剧情要表现实力碾压）
5. **空间定位/朝向规则**：见 `prompt-craft.md`「多人场景的空间关系构建」（绝对朝向、过肩镜头、切镜重标、≤3人、对立双方朝向相对，漏标默认面朝镜头）。VFX 补充——2v1 时两个攻手同阵营朝向一致，均写「背对镜头」面朝深处目标，目标写「面朝镜头」
6. **全片默认无旁白、无BGM**：靠打击音效和环境碎裂驱动节奏。角色可有战吼（≤10字）
7. **第一帧就开打**：默认不需要对峙/亮相/蓄力铺垫，全部时长用于战斗。仅当用户明确要求"登场""亮相""出场"时才加入，且不超过总时长 30%
8. **先定视觉风格和特效属性**：开始分镜前必须确定全局画面风格、每个角色的特效颜色/形态/意象，对决双方特效须有色彩对比
9. **特效描述跨段逐字一致**：确定每个角色的特效描述后（如"剑身流动淡蓝色半透明光纹，剑尖拖出淡蓝光痕"），凡是该特效出现的段必须逐字复制同一描述，禁止换词（"淡蓝色光纹"→"银蓝色剑光"→"蓝色残影"= 四种外观）
10. **打斗段必须选定动量锚点运镜模式**：每个打斗画面阶段写 `[镜头动作]` 前，先从动量锚点三模式中选一种（A 主角动量跟随 / B 受力反馈跟随 / C 一镜到底），将对应的 **Prompt 运镜指令块整块复制**到该阶段开头。禁止只写一句总纲然后自己展开，禁止打斗段只写"全景侧拍""固定机位"等静态运镜
11. **战斗氛围三要素（缺一不可）**：逐招编排是骨架，氛围指令是血肉——模型需要整体氛围指令才能生成有冲击力的画面。每段 VFX prompt 必须包含：
    - **高速动态**：写明整体速度感（"高速激烈的近身交锋""拳脚如闪电般迅猛交错"），并用动态模糊强化（"高速动作拖曳出动态模糊的轨迹"）
    - **碰撞震动**：每次武器/拳脚碰撞必须有镜头物理反馈（"碰撞瞬间镜头剧烈震动""爆发强烈的冲击波气流"）
    - **环境碎裂**：碰撞的冲击波必须波及环境（"冲击波席卷地面，碎片四散飞溅""气浪震碎脚下碎石"）

## 打斗动作速查

### 连招构造模板

每组攻防是一条**连续动作链**，包含 2-4 个连续动作。不要一拍一拍交替。

**动作链结构**：`连招意图 + 碰撞反馈 + 环境破坏`

写连招时写**动作意图**而非逐帧编排——模型更擅长执行"连续劈砍三刀"这样的意图级指令，而非"第一刀从左上斜劈到右下，第二刀横扫中路，第三刀下劈"这样的编排级指令。把省下的 prompt 配额用于碰撞反馈和环境破坏。

| 要素 | 写法 | ❌ 过度编排 |
|------|------|-----------|
| 连招（2-4拍） | 「A连续劈砍三刀，B持盾逐一格挡后退」 | 「A右手斜劈45°，B盾牌左移15cm挡住，A左手横斩，B盾牌右移…」 |
| 碰撞反馈 | 「每次刀盾碰撞爆发白色冲击波，镜头随碰撞剧烈震动」 | （漏写碰撞反馈） |
| 环境破坏 | 「冲击波震碎脚下地面，碎石四散弹飞」 | （漏写环境破坏） |

**碰撞反馈速查**（每次碰撞至少用一种）：

| 碰撞类型 | 反馈写法 |
|---------|---------|
| 武器相交 | 碰撞瞬间爆发白色/金色冲击波气流，镜头剧烈震动 |
| 拳脚碰撞 | 冲击波向四周扩散，空气被击穿产生可见冲击纹 |
| 特效对撞 | 两色光芒交织炸裂，画面闪白0.5秒 |
| 重击命中 | 受击方被冲击波推飞，轨迹上留下动态模糊残影 |
| 爆炸/远程投射命中 | 冲击波掀动镜头本身，画面剧烈倾斜甚至短暂旋转（仅弧线"升级/爆发"阶段可用） |

### 空间距离-接触感对照表

| 距离 | 适合的动作 | 接触感描写 | 音效 |
|------|-----------|-----------|------|
| 贴身（<0.5m） | 肘击、膝顶、头槌、扭锁 | 肌肉碰撞、布料摩擦 | 闷响、骨节声 |
| 近距（0.5-1.5m） | 拳击、短兵器、勾拳 | 拳风、兵器碰撞 | 破空声+碰撞 |
| 中距（1.5-3m）**默认** | 踢击、长兵器、连招交锋 | 剑风、枪尖划过 | 金属摩擦 |
| 远距（>3m） | 特效投射、远程攻击、冲锋 | 空气压缩、地面碎裂 | 爆炸+冲击波 |

**常态交锋保持中距离**，给双方留出移动、闪避、冲刺空间。近身画面必须有实际接触。拉开距离时要有推力来源（被击退/主动后跳/冲击波推开）。

### 防御对等表

| 攻击方式 | 合理防御 | 禁止的防御 |
|---------|---------|-----------|
| 武器挥砍（刀/剑/棍） | 武器格挡、盾牌抵御、闪身躲避 | 空手抓刀、伸手挡刀 |
| 拳脚攻击 | 前臂架住、侧踢拦截、闪避后退 | 用脸硬接 |
| 特效攻击（火/冰/能量波） | 同属性特效抵消、能量护盾、附魔格挡、闪避 | 空手拍开能量波 |
| 远程投射（飞刀/箭矢/气刃） | 武器拨挡、特效护盾、侧身闪避 | 伸手接住飞刀 |

### 打斗密度参考

每 4-5 秒至少 **2 组攻防交换**（A攻B防 = 1组）。此比例适用于任意段长——更长的段按同比例延续攻防密度，禁止前 15 秒密集、后半段只剩走位和对视。

15 秒打斗视频的密度参考：
- 0-4s：2 组攻防（开场爆发，首次碰撞）
- 4-9s：3 组攻防（高速贴身缠斗）
- 9-12s：2 组攻防（升级，环境开始破坏）
- 12-15s：1 组终极碰撞 + 爆炸收束

### 1v多碾压局写法

以上连招/防御对等/密度参考都围绕**双人对决**设计。**1v多（一人瞬杀群敌）**的写法模式完全不同：

| 维度 | 双人对决 | 1v多碾压局 |
|------|---------|-----------|
| 攻防 | 攻防交替，防御对等 | 主角单向输出，敌人无有效防御 |
| 空间 | 两人相对位移 | 主角在多个位置闪现/瞬移 |
| 节奏 | 连招（起手→跟进→终结） | 连续击倒不同敌人，每次 1-2 招解决 |
| 递进 | 动作密度+特效规模递增 | 击倒速度递增 + 同屏残影数量递增 |

**1v多写法要点**：
1. **每次击倒只给 1-2 招**：碾压感 = 一招致命，不是跟每个敌人打十秒
2. **用闪现位置制造空间节奏**：写清每次出现的方位（"画面左侧→右侧→背后"），禁止不交代位置直接切
3. **残影/分身数量递进**：开始 1-2 道残影 → 中段 3-4 道 → 收束时所有残影合拢至本体
4. **敌人是背景群体**：不需要个体区分，统一描述（"黑衣持刀""铠甲士兵"），不做参考图
5. **收束仪式感**：最后一个敌人倒下后，给主角 1-2 秒收势定格（衣袂飘动/残影消散/环境余震），不要打完就结束

### 2v1 / 多v1 协同写法

2v1 最高频的翻车是**写成两段 1v1 拼接**——A 打完换 B 打，镜头在两人之间轮流切单人特写，协同感为零。核心原则：**两个攻手的动作必须在时间或空间上交织，而非轮流**。

**三种协同模式**（按需混用，一段内选 1-2 种）：

| 模式 | 写法 | 画面效果 |
|------|------|---------|
| **夹击** | A、B 同侧或从前后两侧夹攻，同时面朝目标出招。目标在画面另一侧或纵深中 | 同阵营朝向一致面朝目标，用前后或左右制造夹击感，禁止 A、B 面朝彼此 |
| **控制+输出** | A 缠住/格挡/压制目标，B 趁机从侧面/背后打出关键一击 | 两人动作有因果（A 的控制是 B 输出的前提） |
| **接力连招** | A 将目标击退/击飞向 B 的方向，B 接住继续打 | 目标像被传球一样在两人之间弹 |

**镜头规则**：
- **对峙朝向必须相对**——2v1 首选过肩/背后视角：镜头放在目标身后，目标背对镜头占近景，两个攻手在画面深处面朝镜头冲来（或反过来）。禁止所有人面朝镜头。"三人冲入""三人站在"这类让所有人朝同方向的描述 = 同阵营出场，必须改成"两人从画面深处冲向近景的目标"
- **禁止切单人特写轮流拍**——用中景/全景同时框住三人，保持空间关系可见
- 需要给某人特写时，画面边缘必须保留另一个攻手的局部（手/武器/残影）
- 两人的特效颜色必须有对比（如红+蓝），观众才能在快速画面中区分谁在出招

## 运镜-动作同步表

运镜不是标注，是画面本身的一部分——镜头在做什么，观众就看到什么。

| 动作节拍 | 推荐运镜 | 禁忌 |
|---------|---------|------|
| 冲锋/突进 | 低角度高速推进，镜头微震；战争/军事/巷战题材可选主观 FPV 高速穿越视角，贴地穿梭掩体/弹坑/坍塌建筑 | 禁止慢速环绕（跟不上） |
| 碰撞/对撞 | 急推碰撞点特写，碰撞瞬间画面微震或闪白 | 禁止固定远景（冲击力丧失） |
| 闪避/身法 | 跟焦追踪，镜头随角色急转 | 禁止固定机位（失去动态感） |
| 蓄力/凝聚 | 环绕运镜 + 缓慢推进 + 抖动 | 禁止快切（蓄力需持续张力） |
| 大范围爆发 | 从特写急拉至超广角，展现波及范围 | — |
| 连招密集交锋 | 快速切镜，在两人之间来回跳切（选用一镜到底模式时改为镜头在双方之间连续环绕） | — |
| 终结/定格 | 慢动作特写 + 中心构图，锚定碰撞/命中/落地类物理事件，同步列出 ≥3 件悬停物（血珠/汗滴/尘土/碎石/火星/衣料纤维，按场景选） | 只写"慢动作"三字无悬停物清单=无效冗余；慢化脱离物理事件；非终结节点禁止逐招套用悬停清单 |
| 角色登场 | 局部跟拍 → 减速上移 → 环绕到正面 | — |
| 粒子/群体特效 | 一镜到底 + 环绕运镜，不切镜 | — |

### 运镜链（复合运镜）

一段 3-5 秒内运镜应随动作节拍变化，形成**运镜链**：

`[起始运镜+画面] → [过渡运镜+中间画面] → [收束运镜+落幅]`

| 运镜链类型 | 组合方式 | 适用场景 |
|-----------|---------|---------|
| 渐进揭示链 | 局部特写 → 缓慢上移/后拉 → 揭示全貌 | 角色登场 |
| 压迫-环绕链 | 缓慢拉远 → 180°环绕到角色背后 | 压迫感氛围 |
| 跟拍-切入链 | 中景跟拍 → 急推动作细节特写 | 打斗衔接 |
| 爆发-扩散链 | 特写蓄力 → 快速拉远 → 环绕捕捉爆发范围 | 大招释放 |

## 动量锚点运镜

运镜-动作同步表和运镜链解决"每个节拍配什么镜头"，但打戏画面质量的天花板取决于**镜头锚点策略**——镜头持续跟谁、怎么跟。以下三种模式按锚点对象区分，整段镜头必须选定一种并保持到底，禁止中途无理由切换锚点。

### 模式选型

| 打法类型 | 推荐模式 | 原因 |
|---------|---------|------|
| 主角连续攻击/闯关/碾压 | **A. 主角动量跟随** | 观众贴着主角冲进战场，推进感和速度感最强 |
| 力量型重击/一击制胜/击飞 | **B. 受力反馈跟随** | 打击感来自"被打的人"，观众看到命中→后仰→击飞→撞击的完整受力链 |
| 完整攻防段落/多回合缠斗 | **C. 一镜到底连续跟随** | 攻防关系清晰，前后招式连贯，空间不跳变 |

同一段 Prompt 可组合使用（如 A 冲刺切入 → B 重击命中 → C 缠斗段落），但每个画面阶段只选一种锚点，切换时用碰撞/闪避等动作节点衔接。

### A. 主角动量跟随

**锚点**：镜头锁定主角侧后方，以主角身体动量为驱动，像动作游戏 ACT 视角一样跟随冲刺、闪避、转身、挥剑、跃起和落地连续移动。

**禁忌**：突然跳切、变成远景监控视角、镜头与主角运动方向脱节。

**Prompt 运镜指令块**（整块复制到该画面阶段开头，替换 `{主角名}` 后直接使用）：
```
镜头始终紧贴{主角名}侧后方，以{主角名}的身体动量作为镜头锚点，
像动作游戏ACT视角一样跟随{主角名}的冲刺、闪避、转身、挥剑、跃起和落地连续移动。
{主角名}向前突进时，镜头同步向前推进，保持{主角名}肩背和武器轨迹处在画面中心；
{主角名}侧身闪避时，镜头跟随身体横向滑移，制造擦身而过的速度感；
{主角名}旋身挥剑时，镜头顺着旋转方向轻微环绕，让衣袖、头发和剑光形成连续弧线；
{主角名}跃起时，镜头从低角度快速抬升，再跟随落点向下俯冲。
整段镜头运动流畅连贯，不突然跳切，不变成远景监控视角。
画面中要有明显速度线、动感模糊、衣袖拖影、发丝甩动、尘土飞扬和武器光残影。
命中瞬间可以有轻微镜头震动和短暂停顿，但镜头核心始终跟随{主角名}动量。
```

### B. 受力反馈跟随

**锚点**：命中瞬间镜头从攻击方切换到被击中的敌人，跟随敌人的受力轨迹——后仰、倒飞、撞击、余震。

**禁忌**：命中后丝滑滑过去无停顿（失去重量感）、只拍出招方不拍受击方、受击后敌人原地不动。

**Prompt 运镜指令块**（整块复制，替换 `{敌人名}` 后直接使用）：
```
镜头以被击中的{敌人名}为主要锚点，不要一直拍出招的人，而是重点跟随{敌人名}被命中后的受力轨迹。
命中瞬间镜头快速推近至{敌人名}近景并短暂停顿，{敌人名}身体明显后仰，肩膀被打开，
衣袖和头发因惯性滞后甩动，脚步踉跄后退。
镜头从近景跟随{敌人名}身体后仰方向，再拉到中景展示{敌人名}倒飞轨迹，
倒飞轨迹上留下动态模糊残影。
{敌人名}撞到障碍物时，镜头在落地或撞击瞬间再次轻微震动，
画面出现尘土、碎石、火星、冲击波。
命中那一刻要有很短的停顿感，不要让动作完全丝滑滑过去，要让观众感到这一击有重量。
画面中要有明显速度线、动感模糊、衣袖拖影、发丝甩动、尘土飞扬。
```

### C. 一镜到底连续跟随

**锚点**：镜头不切，从开场蓄力到收束定格一条线串完，镜头在攻守双方之间自然流转。

**禁忌**：频繁切镜、突然跳到无关角度、使用"切到""镜头跳到"等中断词（用"镜头顺势""镜头自然环绕"替代）。

**Prompt 运镜指令块**（整块复制到该画面阶段开头）：
```
整段画面采用连续一镜到底运镜，不频繁切镜，不突然跳到无关角度。
镜头在交锋过程中持续环绕流转，不固定在一个角度拍摄。
镜头从一方侧后方缓慢靠近开始，冲刺出招时镜头顺势推进跟随攻击方向；
对方格挡或闪避时，镜头绕过两人侧面，从另一个角度捕捉反击；
反击时镜头自然环绕半圈到对手身后，不中断动作；
一方被击中后，镜头短暂跟随受击方向，展示身体后仰和脚步后退；
追击时镜头再顺势回到攻击方侧后方，跟着下一段连招推进。
整个镜头运动像一条连续的线，持续绕着交战双方流转变换视角，
让观众从不同角度看到每一次攻防，每一次变化都跟随动作逻辑自然发生。
画面中要有速度线、动感模糊、衣袖拖影、尘土飞扬和命中瞬间轻微镜头震动。
```

### 动量运镜红线

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 只写"镜头跟随主角"无具体行为 | 镜头不知道怎么跟，退化为远景固定 | 整块复制运镜指令块，每种动作都有对应的镜头行为 |
| 受击后没有身体反应描写 | 被打的人站着不动，像打空气 | 整块复制 B 模式运镜指令块，受力链完整写出 |
| 一镜到底但写了"切到""镜头跳到" | 前后矛盾，模型混乱 | 用"镜头顺势""镜头自然环绕"等连续运动词 |
| 动量跟随但没有速度感元素 | 跟随了但没有速度感 | 运镜指令块已包含速度感元素，整块复制即可 |
| 只在开头写一句运镜总纲，后续动作描写不再提镜头 | 运镜指令被内容密度稀释，模型忽略 | 整块复制运镜指令块，每个动作都带镜头跟随描述 |

## Prompt 时间段骨架（VFX 专用）

每个 3-5 秒时间段按以下骨架构造（六部分缺一不可）：

```
[动量锚点运镜指令块 + 镜头动作] + [空间定位] + [战斗氛围定调] + [角色A动作链+附着特效] + [角色B应对链+附着特效] + [碰撞反馈+环境碎裂]
```

`[动量锚点运镜指令块]` = 从动量锚点三模式（A/B/C）中选定一种，将对应的 Prompt 运镜指令块**整块复制**放在该阶段最前面（替换变量后直接使用，禁止缩写或只写一句总纲）。同一段内可在不同画面阶段切换模式，但切换点必须在碰撞/闪避等动作节点上。

战斗氛围定调放在具体动作之前——先给模型整体节奏指令（"高速激烈的近身缠斗，拳脚如闪电般密集交错"），再给连招细节。

**完整示例**（15 秒双人对决）：

```
参考@图片1的形象作为剑客，
参考@图片2的形象作为刺客，
场景参考@图片3的荒野断崖。

0-4秒画面：低角度高速推进镜头微震。高速激烈的近身战斗一触即发。
画面左侧剑客从左向右疾冲，长剑高举连续劈砍，剑身裹着蓝色寒冰之气，
高速动作拖曳出蓝色动态模糊残影。画面右侧刺客双匕交叉格挡，
匕首边缘缠绕赤红火焰。每次碰撞爆发强烈的冰火冲击波，
镜头随碰撞剧烈震动，冲击波震碎脚下碎石四散飞溅。
<密集金属碰撞声> <冲击波低沉轰鸣>

5-9秒画面：镜头紧跟动作节奏高速环绕，拳脚如闪电般迅猛交错。
刺客借力后仰闪避，双匕连续挑刺旋切，
火焰残影拖成三道红色动态模糊弧线。剑客横剑连挡后退，
寒冰碎片随每次碰撞迸射飞溅。每一次交锋镜头都随之震动，
冲击波席卷地面，碎裂的地面碎片四散弹飞。
<双匕连击的密集金属声> <地面碎裂声>

10-13秒画面：剑客嘶吼，双手握剑蓄力，蓝色寒气从剑身猛烈扩散，
脚下冻结出冰晶圆环。缓慢推进镜头+画面剧烈抖动，
空气中可见冰晶粒子悬浮翻飞。

13-15秒画面：从蓄力特写急拉至超广角。剑客重剑劈落，
巨大冰柱从地面沿劈击轨迹炸裂而出，碰撞瞬间画面闪白，
刺客被冲击波击飞，高速旋转的身影拖曳出红色动态模糊轨迹。
整个断崖表面龟裂成蛛网状，碎石冰晶漫天飞舞，
冲击波向四周疾速扩散掀起尘幕。
<冰柱爆裂的轰鸣> <地面碎裂的沉闷震响>

五官清晰不变形，4K超高清，电影级特效。
保持无字幕，不要生成水印，不要生成logo，禁止生成BGM。
时长：15秒，比例：16:9
```

## 镜头弧线：Shot 间衔接

### 动作流不能断

每个 shot 的第一个时间段，用具体画面状态承接上一个 shot 的结束动作，后半句开始新的攻防。禁止写"承接上一镜/接着刚才/延续上一段"这类无画面信息的指代词，必须重述角色姿态、方位、受力点和环境锚点。

| ❌ 断裂 | ✅ 连贯 |
|--------|--------|
| S1 结尾"R1俯身闪避" → S2 开头"R1反击横斩" | S1 结尾"R1俯身闪避" → S2 开头"R1闪避中顺势下蹲旋身，蓝色能量刃从侧方扫出" |

### 单人炫技的递进

- 节奏核心：蓄力→释放→更大释放
- 蓄力本身有视觉事件（结印、符文流转、能量积聚、武器嗡鸣）
- 每次释放的特效规模递增
