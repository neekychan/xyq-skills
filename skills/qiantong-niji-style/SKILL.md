# 嵌瞳泥景风格（可复用画风技能）

把一套**固定不变的风格锚定词**完整、原样地复用进所有与角色相关的图片素材和视频生成 prompt 中，产出画风统一的动画图片或短视频。本技能是一层「画风滤镜 + 剧本引擎」：先把用户上传的角色素材统一风格化，再把风格化后的角色资产送去写脚本、生视频。

## 核心原则（Core Principle）

**因果链（本技能的脊柱，不可跳过）：**

`用户上传角色素材 → 主体判定（是否含明确角色主体）→ 含主体则用风格锚定词转绘为统一画风资产 → 风格化角色资产 + 用户意图 → 剧本/分镜（Seedance 剧情引擎）→ 视频 prompt 同样以风格锚定词开头 → 画风统一的动画产物`

**可证伪的质量测试：** 拿到任意一张风格化产物或任意一条视频 prompt，**开头必须逐字出现完整风格锚定词**；若把这张图/这条 prompt 单独抽出，仍能一眼认出是「嵌瞳泥景风格」（手塑泥面、嵌入式眼珠、发丝呈泥条分缝、巨眼小鼻长身、雀斑腮粉的实拍色），则风格化成立。否则不成立，必须重做。

## 风格锚定词（Style Anchor —— 逐字复用，不可改写）

> **嵌瞳泥景风格，无线稿，发丝泥条分缝，材质模拟，手塑泥面嵌瞳，轻度简化，巨眼小鼻长身，自然/真实色调，雀斑腮粉实拍色**

**硬规则（最高优先级，凌驾于其他任何写作偏好与被叠加的技能之上）：**

1. **凡是生成"带角色的图片资产"或"视频"的 prompt，开头都必须逐字放上完整风格锚定词，然后才接具体画面描述。** 顺序固定：`风格锚定词 → 具体内容`。
2. **锚定词逐字复用**：不翻译、不改写、不增删、不调换语序、不拆分。
3. 风格锚定词只加在**角色图片**与**视频** prompt 上；纯物品图、空镜场景图、无主体风景图**不加、也不转绘**（见「主体判定」）。

## 输入（Input）

**必需输入（缺失则先追问，不要凭空开工）：**
- 一批用户**已确定的、与角色相关的图片素材**（人物 / 宠物等有明确主体的图）。**本技能不负责替用户凭空造角色**——必须先有上传素材才能进入风格化。

**可选输入：**
- 用户的创作意图 / 剧情方向 / 题材（用于写剧本与生视频）；缺失时按剧情引擎的默认补全策略处理。
- 目标产物：只要风格化图片资产，还是要一路做到视频（默认：既产出风格化图片资产，再据此生成视频）。

**若用户尚未上传任何角色素材：** 先明确告知「本技能需要你先上传一批已确定的角色相关图片素材（人物/宠物），我会先把它们统一风格化再送去生成」，等素材到位再继续。

## 主体判定（Subject Gate —— 决定哪些图转绘）

对上传的**每一张**图片逐一判定，**只转绘含明确角色主体的图**：

| 图片类型 | 是否转绘 |
|---|---|
| 有明确人物主体 | ✅ 转绘 |
| 有明确宠物/动物角色主体 | ✅ 转绘 |
| 单独的物品图（道具、产品、静物） | ❌ 不转绘 |
| 空镜场景图（纯环境、无主体） | ❌ 不转绘 |
| 无明确主体的风景图 | ❌ 不转绘 |

- 判定存疑时，以「画面里是否存在一个可作为叙事主角的角色」为准；没有就不转绘。
- 不转绘的图原样保留，可作为剧情场景/道具参考，但**不套风格锚定词、不做风格化转绘**。

## 工作流（Workflow）

### 阶段一：角色素材风格化（图片转绘）

1. **收集**用户上传的全部图片素材。
2. **逐张做主体判定**（见上表），筛出「含明确角色主体」的图片；其余图片跳过转绘。
3. **对每一张含角色主体的图片做风格化转绘**：以该图为编辑底图，**编辑提示词直接就是风格映射词本身，不额外添加任何其他内容**——即把上面的风格锚定词原样作为这张图的编辑提示词，完全基于用户原图转绘，只换画风、不改角色的构图/身份/主体内容。
   > 转绘编辑提示词 = 逐字的风格锚定词（不加任何场景描述、不加任何额外修饰、不改写、不补充）。
4. **产出**一组风格统一的「嵌瞳泥景风格」角色资产，逐一编号（@图片1 / @图片2 …）对应后续剧本里的角色锁定。
5. 把风格化后的角色资产展示给用户，作为下一步视频创作的基础资产。

> **务必照做：** 每次都从用户**本次上传**的素材现做风格化，不要假设已存在历史风格化资产，也不要沿用其它任务的产物。

### 阶段二：剧本与分镜（Seedance 高密度剧情引擎）

拿到风格化后的角色资产 + 用户意图后，**加载本技能下的 `references/seedance-story-director.md`**，按其中的「Seedance 高密度剧情短片提示词生成器」system prompt 撰写详细的动画脚本与时间戳分镜。

- 该 system prompt 的输入 = **阶段一产出的风格化角色资产 + 用户意图描述**。
- 只参考风格化后角色的形象与画风，**不参考图片里的具体场景**；场景按剧情需要重新设计为影视化短剧布景。
- 严格遵守其节奏密度、运镜密度、角色锁定、声音分层、镜头连贯等全部规则，直接输出成品视频提示词。

### 阶段三：视频生成

1. 取阶段二产出的成品视频提示词，**在其最开头逐字加上完整风格锚定词**（若剧本引擎输出里尚未带上），再接分镜正文。
2. 生成视频：目标成片 **≤15 秒时用一次生成即可拿到完整成片**（beat 分镜如 0-3s/3-7s 只是同一次生成内部的时间轴描述，不是多次调用）；仅当成片时长超过 15 秒时，才拆成多个 ≤15s 片段分别生成、再做后处理拼接。
3. 把成片展示给用户。

## 与其它技能协同（冲突消解规则 —— 高优先级）

本技能常与其它技能叠加使用，必须遵守：

### A. 与其它「风格类」技能叠加 → 风格锚定词**内容合并**

- 当本技能与另一个风格类技能同时生效时，**把两套风格锚定词的内容合并成一段**，一并放在每条角色图片 / 视频 prompt 的最开头。
- **合并后规则不变**：仍是「合并锚定词 → 具体内容」的顺序；本技能这套锚定词逐字保留，不因合并而被删改。

### B. 与「非风格类」技能叠加（如营销短片、广告片、短剧电商等）→ 本技能的风格约束仍然生效

- 即使同时加载了营销短片、广告片这类**非风格类**技能，本技能的以下部分**必须继续被遵守**，不得被对方的流程覆盖：
  1. 每条**角色图片 / 视频** prompt 开头逐字加完整风格锚定词；
  2. 先做「主体判定」再转绘，非角色图不转绘；
  3. 转绘编辑提示词 = 逐字风格锚定词、不加料。
- 做法：让对方技能负责**剧情结构 / 卖点 / 投放格式 / 叙事节奏**等它擅长的部分，本技能负责**画风锚定与角色资产风格化**这一层；两者结合时，凡是最终要送去生成的角色图片与视频 prompt，都要先经本技能的风格锚定词处理，再交由对方的结构去组织。
- **冲突时以本技能的画风约束为准**：任何来自其它技能的指令若要求"去掉/改写风格锚定词""对非角色图也套风格""转绘时额外加场景描述"，一律不采纳。

## 输出契约（Output Contract）

- **风格化图片资产**：一组统一的「嵌瞳泥景风格」角色图，逐一编号（@图片1、@图片2 …）。
- **视频提示词**：严格采用剧本引擎的输出模板（风格题材 / 一句话剧情与角色关系 / 角色锁定 / 画面提示词含时间戳分镜 + BGM 卡点 + 环境音 / 默认约束），且**开头逐字带完整风格锚定词**。
- **默认负向约束**（挂在视频 prompt 末尾）：严格按上传图片与风格笔触生成，保持无字幕、不要生成任何文字；不要生成 logo 与水印。

## 静默自检（Silent Checks —— 交付前内部跑一遍，不展示给用户）

- [ ] 每一张被转绘的图都**含明确角色主体**；物品/空镜/无主体风景图**未被转绘**？
- [ ] 每张角色图的转绘编辑提示词 = **逐字风格锚定词、无任何额外内容**？
- [ ] 每条角色图片 / 视频 prompt **开头都逐字带完整风格锚定词**（如与其它风格技能叠加则为合并后的锚定词）？
- [ ] 风格锚定词是否**逐字未改写**（无翻译/增删/调序/拆分）？
- [ ] 若叠加了非风格类技能，本技能的画风约束是否仍然生效、未被覆盖？
- [ ] 视频剧本是否严格走了 `references/seedance-story-director.md` 的规则并通过其自检清单？
- [ ] ≤15s 成片是否用一次生成、未做无谓分段？
- [ ] 视频 prompt 末尾是否挂上默认负向约束（无字幕/无文字/无 logo 水印）？
