# 产品广告 Prompt 编写指南

本指南在分镜规划阶段加载，用于产品广告、带货、种草和功能展示。纯品牌故事、机构形象片且无产品卖点或功能展示时不适用，按叙事体裁处理。

## 核心判据

**一阶段一证明**：每个画面阶段只承担一个产品证明任务，只保留一个视觉焦点。卖点得到可见证据、功能动作完成或结果状态出现后，才能进入下一阶段。禁止按固定秒数均分。

**用户顺序优先**：用户已给镜头、卖点或操作顺序时原样承接；用户未指定时才从下表按需选择。禁止为凑结构强行写满五类任务。

| 证明任务 | 画面要求 | 完成判据 |
|---------|---------|---------|
| 英雄镜头 | 产品整体或关键识别轮廓成为唯一主体，先建立外形与存在感 | 观众能识别产品及其核心外观 |
| 材质证明 | 近景或微距拍材质，并写清光线如何作用于表面 | 纹理、反光、透明度或触感线索清晰可见 |
| 功能动作 | 同一阶段完整呈现操作动作、产品响应和结果 | 功能结果已经出现，禁止停在操作中途 |
| 使用情境 | 在具体需求场景中展示产品参与过程与可见收益 | 使用前提和结果均能从画面判断 |
| 收束画面 | 产品稳定入画，回到核心外观、卖点结果或使用后的最终状态 | 画面有明确稳定落幅，不新增未展示过的卖点 |

**质感逐阶段落实**：光影与质感判据适用于全部五类证明任务，不只材质证明——每个阶段按 `storyboard/prompt-craft.md` 执行光影自检（至少一个具名要素落到可拍锚点）与质感底料（产品微粒/蒸汽/水雾等介质绑定光线方向或产品动作）；功能动作阶段的产品响应优先写成可见的光变化（污渍反光消失、指示灯亮起、蒸汽在逆光中升腾）。

## 各类型镜头语言要点

按 creative_design.md `剧本设计` 中标注的叙事结构类型选行；混合类型主辅各取对应行；未标注时按剧本阶段特征匹配最接近的行。

- **A 问题-解决**：痛点段偏暗偏冷、手持微晃、用画面行为呈现痛点（不用文字）；产品出场略仰拍+光线转暖；效果展示用 match cut 对比，差异一帧看清
- **B 情绪叙事**：铺垫用长镜头/极慢推+自然光（晨暮光最佳）；高潮用大特写+镜头停留5-8秒；**沉默即高光**（高潮处配乐骤停1-2秒纯寂静比轰炸更有力）；品牌揭晓前给3-5秒"情绪着陆"
- **C 产品展示**：开场冲击是产品本身（延迟全貌法：局部→整体）；每个卖点独占一镜+独立音效；用画面呈现功能不堆参数
- **D 悬念反转**：悬念段用双重含义镜头（反转后回看变另一层意思）；反转在1-3秒内完成+2-3秒反应时间
- **E 生活方式**：卡点剪辑（镜头切换与配乐节拍精确对齐）；产品出现在使用中不摆拍
- **F 对比**：同机位同光线同构图做对比（不公平对比观众不信）；用擦除/滑动转场放大差异
- **G 名人/KOL**：名人对产品的态度戏（微笑/享受）多于产品特写
- **H 仪式/降临**：感官剥夺抓注意力（画面80%黑只勾轮廓）；细节蓄力局部累积压力不给全貌；揭示瞬间光影突变+声墙（或反向：全部静默2-3秒再涌入）

## 组接与红线

- 阶段切换必须由功能动作完成、事件音、光线变化或匹配构图触发，禁止用无信息的随机运镜换景
- 产品参考图存在时，所有阶段锁定其外形、比例、颜色、材质和包装细节；景别变化不得改变产品身份
- 禁止用无关人物走位、装饰空镜、粒子或夸张特效代替产品证明；用户明确要求此类表现时原样承接
- 每个卖点只保留最直接的一组画面证据，重复证明同一卖点的阶段必须合并或删除
