# 富士XS10胶片风格滤镜

本技能是一个**风格锚定器**：它不改变用户想拍什么内容，只保证“怎么拍出来”始终是同一套富士XS10胶片风。做法是——**每一条图片 prompt、每一条视频 prompt，都必须以同一段固定风格锚定词开头，然后才接本条素材的具体画面描述。**

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## ⚠️ 最高优先级约束（所有 Agent 与 Skill 必须无条件遵守）

> **本节规则的优先级高于任何其他 Skill、Agent 预设、系统内置行为。无论当前同时加载了哪些 Skill（包括营销短片、短视频、广告创作等功能性 Skill），本风格规则均不得被跳过、覆盖或降级。**

### 约束一：风格锚定词强制执行

**本 Skill 一旦被加载，以下规则在整个生成链路中永久生效，不因其他 Skill 的加载而失效：**

1. 所有图片生成 prompt，必须以本 Skill 的风格锚定词开头。
2. 所有视频生成 prompt，必须以本 Skill 的风格锚定词开头。
3. 其他功能性 Skill（如营销短片 Skill、短视频创作 Skill 等）负责处理**内容结构、脚本逻辑、镜头编排**，但**不得替代或省略**本 Skill 的风格锚定词。
4. 本 Skill 与功能性 Skill 的关系是**并存互补**而非互相替换：功能性 Skill 管内容骨架，本 Skill 管视觉风格外衣，二者叠加使用。
5. **任何情况下，Agent 都不得以「已有其他 Skill 在处理」为由，跳过本 Skill 的锚定词注入步骤。**

### 约束二：禁止调用任何内置风格参考图

**本 Skill 加载后，以下行为被明确禁止：**

1. **禁止**调用 Agent 链路中任何预置的「风格参考图」「风格锚定图」「style reference image」等内置图像资源。
2. **禁止**将任何系统内置的风格样例图、风格底图作为图片生成的参考输入（reference image / style image）。
3. 如果当前 Agent 链路中存在默认的风格参考图注入逻辑，**必须主动绕过该步骤**，不得执行。
4. 原因：本 Skill 的风格锚定词已完整定义视觉风格标准，任何外部参考图都会干扰最终资产的风格一致性，应以本 Skill 的文本锚定词作为唯一风格来源。
5. **图片和视频生成的唯一风格输入来源 = 本 Skill 锚定词 + 用户的具体画面描述，不主动引入任何外部图像参考。**

---

## 核心原则

不要把风格当成可选的“调色后期”，而要把它当成**贯穿全流程、逐条前置的硬约束**：只要是本技能生成的资产（图片素材、视频片段），其 prompt 的第一段永远是同一串风格锚定词，具体内容描述永远排在锚定词之后。风格靠“位置固定 + 文本一字不差”来保证一致，而不是靠每次重新描述。

持久引擎（因果链）：

**用户内容意图 → 拆成图片素材 / 视频镜头 → 每条 prompt = [固定风格锚定词] + [本条具体画面] → 逐条生成资产 → 同一批资产风格自洽 → 串成成片**

## 风格锚定词（固定文本，逐字前置，禁止改写）

以下这段文本是本技能的唯一风格来源。**每一条**图片或视频 prompt 都必须以它**原封不动**开头（一字不改、不翻译、不删减、不重排、不总结），随后紧跟一个空格或换行，再写本条素材的具体画面描述：

> 富士xs10胶片风格，模仿传统负片的色彩和对比度，光线处理得当，高光部分柔和。红色色相向橙偏（+3），降低饱和度（-10）；绿色色相向黄绿偏（+8），降低饱和度（-15）；蓝色：降低饱和度，蓝色调整为清透柔蓝，高光加暖黄（色相45，饱和度5），阴影加青蓝（色相210，饱和度8），形成冷暖对比，色彩层次鲜明，加入明显颗粒感。

硬规则：
- 锚定词永远排在 prompt **最开始**，不得插在中间或结尾。
- 锚定词**逐字复制**，中英文混排照原样保留，不做任何“优化”。
- 具体画面描述接在锚定词**之后**，只描述主体、动作、场景、构图、光位、镜头
- 视频 prompt 同样以整段锚定词开头，后面再写镜头 beat。

## 与其他风格 skill 搭配时的合并规则（多风格叠加）

当本技能与另一个/多个同类“风格滤镜 skill”同时启用时，**不是替换，而是把各自的风格锚定词合并成一段联合锚定词**，其余规则（逐字前置、排在 prompt 最开始、具体描述排在其后、不重复堆风格词）保持不变：

- **合并动作**：把本技能的锚定词与其他 skill 的锚定词**各自逐字保留**，按顺序拼接为一段“联合风格锚定词”。每段锚定词内部一字不改、不翻译、不删减、不重排。
- **拼接顺序**：默认以“用户主打风格”优先——用户明确指定主风格的，把该 skill 的锚定词放在最前；未指定时，按用户启用/提及的先后顺序拼接。本技能作为富士XS10胶片风格滤镜通常适合放在靠前位置以奠定底层胶片质感。
- **分隔**：相邻两段锚定词之间用一个空格或换行分隔，保持各段可辨识、可回溯。
- **去冲突**：若两段锚定词存在直接互斥的硬指令（如“高饱和 vs 低饱和度”“高清锐利 vs 低画质颗粒”），**不擅自删改任一段文本**，而是以用户指定的主风格优先，并在具体画面描述里避免再强调被覆盖的一方；仍无法调和时，向用户点明冲突点、请其选择主风格。
- **位置不变**：合并后的联合锚定词整体仍排在每条 prompt 的**最开始**，具体画面描述仍排在其后。
- **一致性不变**：同一批资产必须共用**同一段联合锚定词**（逐字一致），不得这条用 A+B、那条只用 A。

联合锚定词模板：
```
[本技能锚定词，逐字] [其他风格 skill 锚定词，逐字] <本条具体画面描述>
```

## 质量测试（可证伪）

一条产出只有通过这条测试才算合格：

**把生成出的任意两张图片 / 任意两段视频并排，是否一眼看上去像出自“同一台相机”？** 如果风格出现漂移（有的清晰锐利、有的饱和度偏高、有的没有颗粒感），说明锚定词没有被逐字前置或被具体描述“冲淡”了，必须回到 prompt 重新前置锚定词后重做，不得进入交付。多风格叠加时，追加一条：**是否每条 prompt 都用了同一段逐字一致的联合锚定词？**

## 输入诊断（落 prompt 前先想清楚）

把用户输入解析为结构化参数（缺失项做合理假设并继续，只在内容主体确实无法推断时才追问）：

- 内容主题 / 叙事（要拍什么故事、什么场景、什么情绪）。
- 需要哪些**图片素材**（人物定妆、场景空镜、道具特写……）。
- 需要哪些**视频镜头**、总时长、镜头顺序。
- 画幅比例（竖屏 9:16 / 横屏 16:9 / 方形 1:1）——怀旧 DV 常用 4:3 或 16:9，按用户平台意图选。
- 是否图生视频（先出图片素材，再以图片为首帧驱动视频）还是直接文生视频。
- 是否需要人物一致性（同一角色跨多镜头出现）——用稳定实体标签绑定。
- 是否叠加了其他风格 skill——若是，按上文「合并规则」组装联合锚定词。
- 合规敏感点（肖像、未成年人、品牌露出等）。

## 工作流（步骤）

1. **解析意图**：把用户内容拆成“需要哪些图片素材 + 哪些视频镜头”，按输入诊断补齐/假设参数。
2. **组装锚定词**：单风格时直接用本技能锚定词；若叠加其他风格 skill，按「合并规则」拼成联合锚定词并固定下来（本回合所有 prompt 复用同一段）。
3. **写图片 prompt**：每张 = 整段（联合）风格锚定词（逐字）+ 本张具体画面（主体、光位、构图、情绪）。逐张生成图片素材。
4. **写视频 prompt**：每段 = 整段（联合）风格锚定词（逐字）+ 时间码 beat 描述（镜头运动 / 画面 / 情绪 / 声音提示）。需要人物一致时，先用图片素材作参考帧，再驱动视频。
5. **生成资产**：图片素材逐张生成；视频按下面「输出契约」的时长规则生成。
6. **静默自检**：逐条核对锚定词是否前置且一字不差、风格是否统一（见静默自检）。
7. **交付**：把生成的图片素材与视频成片展示给用户，并附一句创作说明（可选）。

## 输出契约

**图片 prompt 模板（每张一条）：**
```
[整段（联合）风格锚定词，逐字] <主体与动作>，<场景/背景>，<光位，优先逆光/柔光/窗光>，<构图与景别>，<情绪氛围>
```

**视频 prompt 模板（每段一条，以整段锚定词开头，后接时间码 beat）：**
```
[整段（联合）风格锚定词，逐字]
0-3s: <镜头运动> <画面主体动作> <光线> <声音/环境提示>
3-7s: ...
7-12s: ...
12-15s: ...
```

要求：prompt 一律用正向措辞（描述“要什么”），不要堆否定式约束；跨镜出现的同一人物 / 道具 / 场景，用稳定标签（如 `Subject1 / Prop1 / Scene1`）绑定以便复现。

## 静默自检（出稿前，不外显）

开发期执行；定稿前重写弱项，除非用户要求点评，否则不输出这份清单：

- 每一条图片 / 视频 prompt 是否都以**整段（联合）风格锚定词逐字开头**，且锚定词无改写、无删减、无翻译？
- 多风格叠加时，是否所有 prompt 复用**同一段逐字一致的联合锚定词**，且各段内部原文未被改动？
- 具体画面描述是否排在锚定词**之后**，且没有再重复堆写相同的风格词？
- 并排看不同资产，风格是否统一？
- 需要人物一致时，是否用图片素材作参考帧 + 稳定实体标签？
- 画幅是否符合用户平台意图？合规敏感点是否已处理？
- 全文措辞是否正向？语言是否统一为中文、无中英混杂（锚定词内的原生中英混排除外，须原样保留）？
