# 专业视频创作

## 核心原则

不要直接跳到生成视频。一支好的叙事视频是一系列有序依赖的产物：先定义规范，再设计故事板，然后逐层填充元素与镜头，最后组装。每个阶段都有明确的交付物和暂停点。跳过阶段或一次性跑完整个流程，会导致角色不一致、镜头脱节、音画错位。

持久引擎（因果链）：

**创意需求 -> 视频规范 -> 故事板（元素+镜头+音频层）-> 元素资产 -> 镜头视频 -> 音频层 -> 最终组装 -> 交付**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果把故事板中的任何一个镜头删掉，整部视频的叙事线就会出现断裂或缺失。** 每个镜头都必须承载不可替代的叙事功能——推进情节、建立角色、或传达情感。如果某个镜头删掉后叙事不受影响，说明该镜头是冗余的，应当合并或移除。

## 输入诊断

生产前，识别或合理假设以下维度：

- 视频类型：叙事短片 / 品牌叙事 / 剧情短片 / 其他
- 标题与主题：视频的名称和核心主题
- 宽高比：16:9 / 9:16 / 1:1（默认 16:9）
- 总时长：目标视频总长（影响镜头数量和分段策略）
- 视觉风格：整体视觉基调（如 Neo-Noir、赛博朋克、水彩动画、写实纪录片等），需要提供具体的风格锚点而非泛泛描述
- 输出语言：旁白和对白使用的语言（与提示词语言独立——提示词始终用中文书写，但旁白/对话严格遵循此处指定的语言）
- 目标受众：视频面向的观众群体
- 角色清单：主要角色的身份、外观、性格特征；若角色有多种状态（不同服装、年龄），需明确说明每个 Look
- 场景清单：关键地点及其重要物体的位置与朝向
- 关键道具：推动剧情或具有象征意义的物品
- 音乐与音频需求：背景音乐风格、是否需要旁白、音效设计
- 合规敏感点：暴力 / 血腥 / 健康 / 金融 / 儿童等敏感内容需保守处理
- 用户已提供的素材：角色参考图、场景图、音乐素材、音色参考等（直接影响生成策略——已有素材直接绑定，避免重复生成）

## 工作流（步骤）

### 阶段 1：编写视频规范

将用户的创意需求解析为一份结构化的视频规格文档（`Final_Video_Spec`），包含以下字段：

- 标题
- 视频类型
- 宽高比（默认 16:9）
- 总时长
- 视觉风格（含具体风格锚点）
- 输出语言（旁白与对白语言）
- 角色清单（每个角色的身份特征、外观描述、各 Look 变体）
- 场景清单
- 关键道具
- 音频需求（背景音乐风格、旁白需求、音效方向）

完成后暂停，展示规范文档，请用户确认后再进入下一阶段。

### 阶段 2：设计故事板

基于已确认的视频规范，设计完整的故事板，包含三个核心部分：

**关键元素（Key Elements）**
- 关键主体（角色）：每个角色的元素 ID、外观描述。若角色有多种状态或外观，在描述中明确说明（如 Look 1: ...; Look 2: ...）。
- 关键地点/场景：每个场景的元素 ID、环境描述（含重要物体的位置和朝向）。
- 关键道具（如有）：元素 ID 与外观描述。
- 角色音色参考：如有语音需求，处理或生成音色参考素材，音频时长在 15 秒以内。
- 用户提供的资产：如果用户提供了参考媒体并指定为关键元素，描述必须与之匹配，不得与所见内容矛盾。

**镜头列表（Shot List）**
- 优先采用带内部剪辑的长镜头（每个镜头 10-15 秒），在镜头内部设计节奏而非拆成许多短镜头。
- 任何镜头不得超过 15 秒。
- 每个镜头描述必须包含：
  - 场景：引用场景元素 ID（如 `[Scene_Office_Noir]`）。
  - 故事内容：角色和关键物体的动作与动态；对话和表演。写出准确的台词（口头对话或画外音 OS）。用元素 ID 引用角色。
  - 电影摄影：景别（远景/中景/特写）、摄像机角度（低角度/高角度）、摄像机运动（固定/平移/推入/拉出）。
- 当镜头包含内部剪辑时：在场景描述之后，按剪辑顺序列出故事内容和电影摄影。

**独立音频层（Audio Layers）**
- 背景音乐：设计至少一个全局背景音乐轨道。若视频较长且有明显间歇或转折点，规划多个音乐片段（每个有自己的 audio_id 和范围）。
- 旁白：若使用大段旁白推进故事，定义语音特征、语调和准确脚本，并限定在相关镜头范围内。

**资产扫描与绑定**：故事板设计完成后，扫描当前上下文，查找用户已提供或之前生成的、与故事板条目匹配的资产（元素图像、背景音乐等）。对每个匹配项，在进入生成步骤前将其绑定到对应的故事板插槽，避免重复生成。

完成后暂停，展示故事板，请用户确认后再进入下一阶段。

### 阶段 3：设置元素资产

为故事板中的每个关键元素准备视觉资产：

- **用户已上传元素资源**（如角色参考图、场景图）：直接将其绑定为对应 key_elements 的资产，不重新生成。
- **用户未提供资源的元素**：为所有缺失的元素生成图像。
  - 角色图像生成规则：为每个角色生成 1 张参考图像，使用水平并排布局——画面左侧显示角色头像（紧凑构图，聚焦面部，用于确认身份、肤色、眼睛、发际线）；右侧显示角色全身照（展示全身，用于服装、发型、妆容、鞋子和轮廓）。
  - 同一角色不同外观：使用图生图方式，后续外观参考之前生成的图像以保持一致性。
  - 画面中不要生成文字，保持画面整洁。

完成后暂停，展示所有元素资产，请用户确认后再进入下一阶段。

### 阶段 4：生成镜头视频

为故事板中的每个镜头生成最终视频片段：

- 每个镜头的参考输入必须包括：
  1. **元素资产**：对于镜头中的每个角色，参考故事板中对应的元素图像；按需参考场景/道具图像。在提示词中用图片标签（`<<<image_1>>>`, `<<<image_2>>>` 等）标记每个角色，以便模型正确读取面部和造型。
  2. **连贯性视频参考**（可选）：仅当当前镜头与前一个镜头具有极高连贯性时，将前一个镜头的视频作为参考输入。

- 提示词编写遵循四层顺序：摄像机 -> 主体 -> 空间 -> 音频。详见 `references/formats/video-prompt-grammar.md`。

- 视频生成方式：每个镜头 ≤15 秒，一次生成即可拿到完整片段。多段 beat（如 0-3s/3-7s/...）是同一条提示词内部的时间轴描述，不是分段多次生成。

完成后暂停，展示所有镜头视频，请用户确认后再进入下一阶段。

### 阶段 5：生成音频层

基于故事板生成所有音频层：

- **背景音乐**：按故事板中设计的音乐轨道生成。
- **旁白**：按故事板中定义的语音特征、语调和脚本生成旁白音频。旁白音频限定在相关镜头范围内。
- **音效**：按需生成或标注。

完成后暂停，展示音频资产，请用户确认后再进入下一阶段。

### 阶段 6：最终组装

所有资源就绪后进行最终组装：

- 将所有镜头视频按故事板顺序拼接。
- 叠加音频层（背景音乐、旁白、音效）。
- 添加字幕（在后期剪辑时添加，不在视频生成阶段处理）。
- 引导用户导出最终成片。

### 暂停规则

不要一次性运行所有步骤。在以下每个关键阶段停下来，与用户确认后再继续：
1. 规范定稿后
2. 故事板完成后
3. 元素资产完成后
4. 镜头视频生成后
5. 音频生成后

使用卡片或消息邀请用户审查后再推进。

### 用户素材处理规则

用户已提供或预先存在的媒体主要影响阶段 3-5：
- 在填充生成内容前，先将用户素材绑定到对应的故事板位置。
- 避免重复生成用户已提供的内容。
- 如果用户素材与故事板描述存在差异，以用户素材为准并更新故事板描述。

### 镜头视频提示词模板

```
<<<image_1>>> <角色A元素描述>
<<<image_2>>> <角色B元素描述>
[可选: <<<image_3>>> <场景/道具元素描述>]

<摄像机运动/镜头变化>。
<角色动作与表情，按故事时间顺序，含身体部位与程度描述>。
<空间与环境变化，背景运动>。
{对白内容} (背景音乐描述) <音效描述> no music no subtitles
```

注意：
- 提示词始终用中文书写，但对白/旁白内容严格遵循视频规格中的输出语言。
- 若分镜脚本表明该镜头有单独的旁白音轨，不要在视频提示词中写入旁白文本，以避免音频冲突。
- 为防止模型添加不需要的背景音乐，始终包含 'no music'。
- 字幕在后期剪辑时添加，始终包含 'no subtitles'。
- 使用正向措辞描述画面内容，不写否定式约束。

## 静默自检

交付前内部跑清单并重写弱项。不暴露给用户。

- 因果链是否每一环都成立（规范 -> 故事板 -> 元素 -> 镜头 -> 音频 -> 组装）？
- 质量测试是否通过（每个镜头是否承载不可替代的叙事功能）？
- 角色在不同镜头间是否外观一致（是否使用了图生图或参考图绑定）？
- 每个镜头是否 ≤15 秒？是否作为一次生成的完整片段？
- 镜头间的连贯性参考是否正确使用（仅在前序镜头具有极高连贯性时才添加）？
- 提示词是否遵循四层顺序（摄像机 -> 主体 -> 空间 -> 音频）？
- 提示词中是否正确标记了每个角色的图片标签？
- 是否包含了 'no music' 和 'no subtitles'？
- 旁白是否与视频提示词分离（不在同一镜头的视频中重复）？
- 用户已提供的素材是否已正确绑定，没有重复生成？
- 每个阶段是否在完成后暂停等待用户确认？
- 全文语言是否与目标市场一致，提示词用中文书写但旁白/对白遵循输出语言？
