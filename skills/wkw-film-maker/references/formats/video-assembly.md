# 时间线合成与质检验收规范

本规范定义了所有视频素材生成完毕后，进行时间线拼接、声画合成、多轨混音与最终质检验收的完整标准。

---

## 一、时间轴无缝拼接与剧情连贯性质检

### 1.1 拼接单元
- 必须以15秒为一个大视频层单元进行时间轴拼合
- 按分镜脚本顺序排列各段视频
- 段与段之间采用硬切（Hard Cut），不使用叠化、闪白、淡入淡出等软转场（除非分镜脚本中明确设计了特殊转场动作）

### 1.2 核心质检指标：视觉状态账本核对

必须站在观众视角，完整审视拼接后的长视频，逐段检查相邻15秒段落的接缝处：

**物理状态核对清单**：
- [ ] 角色A的物理位置是否与上一段结尾完全一致
- [ ] 角色B的物理位置是否与上一段结尾完全一致
- [ ] 角色A的姿态（站立/坐姿/手部动作/身体朝向）是否衔接
- [ ] 角色B的姿态是否衔接
- [ ] 角色A的衣物细节（干湿/褶皱/扣子状态）是否一致
- [ ] 角色B的衣物细节是否一致
- [ ] 角色手中的道具（香烟/酒杯/雨伞/信件）是否存在且状态一致
- [ ] 环境光源方向（左侧光/右侧光/顶光/逆光）是否一致
- [ ] 环境色盘（暖黄/冷绿/霓虹色）是否一致
- [ ] 时间相关道具（时钟显示/天色/灯光明暗）是否一致

若发现任何穿帮或逻辑断层，必须精准定位是哪个段落出了问题，打回重制对应段落。

### 1.3 动作衔接检查

- 前一段结尾的动作（如：伸手推门、转头、手指即将触碰物体）在后一段开头的1秒内是否完成闭环
- 动作的速度和力度是否连贯（前一段是缓慢伸出手，后一段不能变成猛推）
- 动作衔接点的音效是否连续（如：推门声从前一段末尾延续到后一段开头）
- 视线方向是否连贯（前一段角色看向画面右侧，后一段开头不能突然看向左侧）

### 1.4 剧情逻辑检查

- 整体观看一遍，剧情是否通顺
- 对白/内心独白是否连贯，是否存在跳跃或矛盾
- 前后段落是否存在逻辑断层（如：前一段在室内，后一段突然到了室外但没有出门的过渡动作）
- 角色关系和情感发展是否自然递进
- 结尾是否平稳收束，没有留下未解释的悬念扣子

## 二、多镜头节奏控制

### 2.1 自动切镜节点检查

- 检查每个15秒视频内部的自动切镜节点，画面切换必须自然
- 切镜点应与说话者切换、动作转折点、情绪变化点同步
- 严禁出现无切镜的、像PPT幻灯片或慢动作静态画一样的生硬长镜头（单镜头持续超过5秒无动作变化即视为不合格）
- 对白/内心独白出现时，镜头焦点或景别切换必须与说话者同步（谁说话镜头给谁，或通过过肩镜头展现听者反应）

### 2.2 节奏曲线控制

- 全片节奏应有张有弛，不能全程紧绷也不能全程拖沓
- 情感高潮段落：切镜频率加快（3-4秒一切），特写增多，音乐加强
- 情感沉淀段落：切镜频率放缓（5-6秒一切），中全景增多，音乐减弱或留白
- 开篇：快速建立场景和人物状态
- 结尾：最后一个镜头应比其他镜头停留时间长2-3秒，给观众余韵

## 三、三维空间与光影阻隔质检指标

逐镜头检测以下项目，不合格的段落打回重制：

### 3.1 前景检查
- [ ] 是否存在前景遮挡物（百叶窗、窗帘、门框、石柱、前景人物等）
- [ ] 前景是否实现了合理的散景虚化（不应与主体同样清晰）
- [ ] 前景是否有效营造了窥视感或空间层次感
- [ ] 前景没有错误遮挡主体的关键表演区域（如眼睛、嘴部）

### 3.2 主体检查
- [ ] 主体是否在焦平面上清晰锐利
- [ ] 主体面部微表情是否可辨识
- [ ] 主体动作是否自然、符合物理规律
- [ ] 主体没有出现反关节、瞬移、漂浮等异常

### 3.3 背景检查
- [ ] 背景是否有明确的透视深度（不是平面贴图感）
- [ ] 背景是否有适度虚化（景深效果）
- [ ] 背景光源是否产生合理的焦外光斑
- [ ] 背景中的活动元素（路人、车辆、霓虹灯）是否自然

**硬标准**：凡是画面扁平、像二维拼贴、无焦深层次的生成段落，必须打回重制。

## 四、动作与表情质量把关

### 4.1 严禁项
- 严禁通过静态插帧或首尾帧生成的生硬镜头
- 严禁角色出现"木偶感"——关节僵硬、动作不连贯、像被线操控
- 严禁角色全程呆立或始终死板地盯着镜头
- 严禁面瘫——任何角色出场超过2秒没有面部微表情变化即为不合格

### 4.2 必查项
- [ ] 角色有正常的物理质量惯性运动（走路有重心转移，转身有身体带动）
- [ ] 角色有连贯、生动的肌肉微表情（眼神变化、嘴角微动、下颌线条变化）
- [ ] 眼神的忧郁、低垂、视线闪躲等情绪是否到位
- [ ] 角色有符合剧本动机的肢体交互（递东西、点烟、倒水、开门等）
- [ ] 多角色互动时，视线交汇和身体朝向是否合理（谁在看谁、身体朝向谁）
- [ ] 手部动作自然（手指不粘连、不出现多余手指、抓握动作合理）
- [ ] 衣物随动作自然摆动（旗袍下摆、西装衣角、头发的物理运动）

## 五、多轨声音拼合与音效渲染

### 5.1 音轨分层

最终合成必须包含以下独立音轨：

| 音轨 | 内容 | 来源 |
|---|---|---|
| 对白轨 | 角色对白和内心独白 | 视频素材自带（从15秒视频中无损提取） |
| 音效轨 | 环境拟音（脚步声、打火机声、雨声等） | 视频素材自带 + 必要时补充增强 |
| 音乐轨 | 纯乐器BGM | 阶段6单独生成的BGM音频 |

### 5.2 BGM卡点对齐

- 音乐剪辑点必须与画面内部自动切镜的重拍完全对齐
- BGM的强拍（大提琴拨弦、手风琴声部进入、小提琴高音）应配合画面中的关键动作（开门、转头、对视、点烟）
- BGM的情绪起伏应与剧情情感曲线同步
- BGM音量在对白出现时自动降低（侧链压缩效果），确保对白清晰可辨
- BGM不能从头铺满到底，关键情节点可以留白（只有音效和对白），增强戏剧张力

### 5.3 对白与音效处理

- 视频素材自带的对白/内心独白与音效（Foley）必须无损提取，单独编入对应轨道
- 对白声场必须与对应的景别大小匹配：
  - 特写：声音干脆、直接、无混响
  - 中景：声音自然、带少量房间混响
  - 全景：声音较小、带明显空间混响
  - 室外：声音散失、无明显反射、带环境底噪
- 内心独白：比正常对白音量略小，带一点点房间混响，仿佛从记忆深处传来
- 环境音效的声像定位应与画面中声源位置一致（画面左侧的脚步声从左声道发出）

### 5.4 音量平衡标准

- 对白：最大音量的基准（0分贝参考）
- 音效：比对白低3-6分贝，不压过对白
- BGM：比对白低8-12分贝，作为情绪铺垫不抢戏
- 整体动态范围：最响到最轻之间有15-20分贝的动态，避免全程响度一致的疲劳感

## 六、转场与出片管理

### 6.1 转场规范

- 多镜头切片内部（15秒视频内的自动切镜）：自然硬切
- 15秒段落之间：优先使用动作衔接切（前一段动作在后一段完成），其次使用门开合、人物走过遮挡镜头、镜头横摆等电影化硬转
- **严禁使用**：各种现代短视频的花字特效、闪白转场、旋转转场、缩放转场、无物理依据的特效转场
- 允许使用的特殊转场：
  - 动作匹配转场（前一段关门动作匹配后一段开门动作）
  - 视线匹配转场（角色看向某处，切到该处所看到的画面）
  - 道具转场（前一段手拿起酒杯，后一段酒杯放下但已换场景）
  - 光影转场（灯光熄灭再亮起，场景已换）

### 6.2 最终输出清单

完成所有质检和修正后，输出以下产物：

1. **完整连载视频文件**：最终合成长视频，包含全部画面、对白、音效和BGM
2. **内部镜头切片清单**：列出每段15秒视频包含的子镜头及其时间码、景别、内容摘要
3. **物理音效对齐节点**：标注关键Foley音效的时间码和对应画面动作
4. **音轨层级分配清单**：标注各音轨的音量自动化节点、BGM出入点、留白段落
5. **海报封面图**：16:9主封面 + 3:4 + 4:3三个比例

### 6.3 最终全片质检（交付前最后一遍）

以观众视角完整观看一遍最终成片，确认：
- [ ] 全程无PPT静态感，画面始终有生命力
- [ ] 全程无默片段落，声音丰富且层次清晰
- [ ] 角色表情生动自然，眼神有戏
- [ ] 三维景深贯穿全片，无扁平画面
- [ ] 多段衔接零穿帮，视觉状态账本完全对齐
- [ ] 方言对白地道自然，口型同步
- [ ] BGM与画面情绪完美契合，卡点精准
- [ ] 故事完整、逻辑通顺、结尾有余韵
- [ ] 王家卫美学风格统一（色调、光影、节奏、表演风格）
- [ ] 无字幕、无水印、无标识、无杂乱文字
