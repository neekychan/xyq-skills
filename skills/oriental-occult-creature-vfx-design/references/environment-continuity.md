# 真实环境与场景连续性

本文件规定如何让空镜、怪物图与后续视频看起来发生在**同一个可拍摄地点**。任何含环境的资产都先建立场景身份，再决定是否生成图片；不得用两条互不关联的文生图 Prompt 分别生成空镜与怪物背景。

## 一、真实感底线：环境先于怪物存在

先把地点当成真实勘景来设计，再让灵异进入其中。每个地点必须能回答：它原来做什么、由什么建成、如何老化、哪里积水或积灰、唯一主光从哪里来、人在其中如何通行。没有这些物理事实，不生成怪物图。

真实感来自可验证的因果，不来自“UE5、超写实、影视级 CG、模型精度拉满”等标签堆叠：

- 同一画面只保留 2–3 种主材料，并写明各自的粗糙度、反光、破损和污渍规律；石、铜、木、泥、骨不能共享同一种黑亮粗糙表面。
- 潮湿必须局部发生在渗水线、积水、黏液或接触区域；禁止全场均匀湿亮。
- 画面保留大块安静表面，微裂纹、坑点、粒子只集中在叙事焦点；禁止用满屏高频噪点冒充精度。
- 使用有来源的实景光、真实曝光衰减、空气透视和有限景深；能量是局部异色光，不是全局染色滤镜。
- 漂浮碎片、烟尘、水花与火星必须服从受力方向、重力和距离衰减。

## 二、场景身份卡（每个地点必填）

```text
SCENE_ID（唯一且稳定）:
世界层（现实层 / 诡域层；若跨层，写明不变部分与变化动因）:
地点原功能与时代:
固定空间骨架（至少 5 个不可漂移锚点）:
入口、主通道、地面高差与主体位置关系:
固定道具与损坏状态:
材料账本（材料 / 粗糙度 / 反光 / 局部湿度 / 破损 / 积尘污渍）:
固定主光源、方向、色温与实景灯位置:
天气、雾尘与地面状态:
色彩与曝光基线:
CAMERA_SLOT（机位名 / 焦段 / 机高 / 朝向 / 地平线）:
禁止漂移项（门窗数量、柱位、祭坛位置、光源方向等）:
```

东方元素必须进入空间结构、施工方法与使用痕迹，不得只贴纹样：例如墓砖砌法、夯土层、青铜榫卯、神龛尺度、朱砂封缝、香灰沉积应有明确位置和功能。

## 三、同场景配对资产

每个实际地点使用一个 `SCENE_ID`。空镜不是独立“好看的场景图”，而是可选的**同场景干净底板**：

1. 先在图片清单中说明是否真的需要 `scene_master_<SCENE_ID>`。若只需怪物定形，不默认额外生成空镜。
2. 用户批准后，先生成干净底板；将它登记为 `PAIR_ID: <SCENE_ID>-<CAMERA_SLOT>` 的母版。
3. 含怪物、角色或特效的同机位资产必须通过编辑/参考图派生自该母版，只改变已经声明的变量；不得重新独立文生图。
4. 同一 `PAIR_ID` 锁死空间骨架、机位、焦段、地平线、光源、天气、地面、固定道具和既有损坏。允许变化的只有主体、动作、特效强度与由动作造成的新破坏。
5. 若没有批准生成干净底板，只生成含怪物的主图，并把其背景登记为该地点的场景母版；后续若新增空镜需求，先报数确认，再通过移除主体的编辑方式从这张主图派生，不得独立生成无关空镜。

同地点换机位时可以新增 `CAMERA_SLOT`，但仍复用同一 `SCENE_ID` 的固定空间骨架。相邻镜头若要求无缝衔接，必须复用同一 `PAIR_ID`。

## 四、怪物必须压进真实空间

怪物与环境至少同时出现以下证据：

- 明确接触阴影、环境遮挡和脚掌/身体压地；
- 地面凹陷、泥水挤出、碎石受力、粉尘或水花方向与动作一致；
- 环境污渍反向沾到怪物，怪物材质也影响附近地面与墙体；
- 能量遵循“来源 → 传导路径 → 亮度衰减 → 邻近材质反射”的链条；
- 前、中、后景都有空气透视，怪物远端不能和面部一样锐；
- 建立环境量尺表：至少两种有稳定现实尺寸的建筑/器物锚点（门洞、柱距、车辆、栏杆、砖块模数等）及其与怪物的比例。怪物设计资产不放人物或人形剪影。

## 五、连续性质检与下游绑定

交付前逐对检查母版与派生图：

- 固定空间骨架、入口、柱位、地面高差是否一致；
- 主光方向、色温、天气、雾尘和既有损坏是否一致；
- 同机位的焦段、机高、地平线和透视是否一致；
- 怪物是否有接触重量，而不是悬浮在背景前；
- 怪物开大资产是否只含怪物与环境量尺,没有人物、路人、人形剪影或剧情对峙构图；
- 材料能否在缩略图和去色画面中仍被区分；
- 是否出现新的无来源建筑、光源、纹样、漂浮碎片或全局发光。

任一核心锚点漂移，就判定该派生图失败；只重做派生图，不另起一张“更好看但不同地点”的背景。

交给 video creation 时同时提供 `SCENE_ID / PAIR_ID / CAMERA_SLOT`：空镜使用对应干净底板；怪物镜头优先使用已经含同一背景的怪物图；从空镜过渡到怪物显形时，只把同一 `PAIR_ID` 的母版与派生图作为起止参考，不加入第三张气氛图。禁止把不同 `SCENE_ID` 的场景图和怪物图混在同一段视频里，也禁止为了“加强风格”额外绑定无关场景图。
