# 视频生成与时间线合成规范（阶段10-11执行标准）
## 阶段10：视频片段生成规范
### 生成参数
- 生成能力：MultiModalToVideo
- 模型：Seedance 2.0
- 分辨率：720p
- 单片段时长：严格15s，每个Storyboard Shot对应一个视频片段
- 参考输入：必须包含该Shot已确认并绑定的所有资产图（代言人三视图、产品三视图、对应场景资产、必要重复道具资产）+ 用户上传原始参考图
- 非首个片段可参考前一个已完成片段作为视频连续性参考，但不得生成或注册新的关键帧图。

### 生成内容要求
1. **严格遵循Storyboard Shot**：不得改变表格分镜的镜头顺序，不得改变代言人动作结果，不得改写台词或旁白，不得新增未确认情节、角色、场景、道具、产品、Logo、文字或标签。
2. **授权规则**：如果用户未授权品牌Logo，不得生成任何Logo或文字；如果用户授权品牌Logo，仅允许在分镜明确指定的位置、尺寸和时长内出现。
3. **一致性要求**：
   - 代言人：保持面部结构、体型比例、发型、妆造、服装结构、姿态气质稳定，不得出现身份漂移、变脸、变形、手部畸形。
   - 产品：保持比例、结构、材质、颜色、表面状态、品牌识别点稳定，不得出现结构变形、比例漂移、材质漂移。
   - 汽车：保持车身比例、灯组、轮毂、腰线、漆面反射连续，不得出现车身比例错误、轮毂漂移、灯组变形。
   - 3C产品：保持屏幕比例、边框厚度、机身材质、镜头模组、交互状态连续，不得出现屏幕乱码、边框漂移、接口错位。
   - 跨片段一致性：多个Shot之间保持色彩、材质、空间风格、灯光方向和情绪递进稳定。
4. **动效要求**：
   - 严格执行3s重点与7s高潮逻辑，确保画面动效不间断、不间歇。
   - 允许动作：代言人转身、行走、停驻、抬头、回望、手部触碰产品、服装随动作产生自然褶皱、车辆平稳加速、车灯点亮、轮胎滚动、产品旋转、屏幕交互、光线扫过金属边缘、镜头Orbit/Tracking/Push-in/Pull-out/Whip-pan。
   - 禁止动作：剧烈肢体变形、身份漂移、产品结构错误、车辆比例漂移、3C屏幕乱码、随机文字、未经授权Logo、无依据新道具、破坏性转场。
5. **片段首尾连续性**：
   - 因每个15s片段独立生成，必须在开头重复上一片段结尾的动作余势、镜头运动方向、音乐节拍、转场音或视觉符号，保证承接自然。
   - 必须在结尾预留下一片段的动作方向、转场音、光影滑移、几何重合物或镜头速度，保证衔接顺畅。
   - 可使用声音桥、镜头运动桥、光影桥、几何桥、动作桥、产品高光桥实现衔接。
   - 禁止用黑场、白场、渐隐、渐显、叠化解决衔接问题。

## 阶段11：时间线合成规范
### 合成顺序
1. 所有视频片段生成完成后，严格按Storyboard Shot的编号顺序将片段推送至时间线，不得改变分镜顺序。
2. 不得随意变速，不得插入未确认的新镜头，不得裁剪已确认的片段内容。

### 音轨管理
1. 必须打开视频轨音量：Video track volume: ON。
2. 默认不执行额外音频素材生成，不额外生成独立BGM、旁白或音效，保留视频原生音轨。
3. 若用户额外提供音频文件，按用户要求绑定，但不得自动替换视频原声。

### 片段衔接检查
合成时必须逐一检查以下连续性要素，如有不连续需调整：
1. 视觉连续性：代言人外观、面部结构、体型比例、妆发、服装是否一致；产品结构、材质、色彩比例是否一致；灯光方向、空间风格是否一致。
2. 动作连续性：前后片段动作方向是否承接，有无跳轴、动作断层。
3. 声音连续性：前后片段音乐节拍、SFX尾音、转场音、低频冲击、呼吸节奏是否连续。
4. 转场合规性：衔接处是否为无缝转场，有无黑场、白场、渐隐、渐显、叠化、无意义空镜。
5. 必要时可保留片段首尾重复的动作或重复音效，提升分段生成后的连续性。

### 成片质检（合成完成后必须执行）
1. 内容合规：画面中不得出现未经授权的字幕、随机文字、Logo、水印、品牌标识、产品标签；若用户授权Logo/品牌字样，只允许在确认分镜指定位置出现。
2. 元素一致性：代言人不得身份漂移、变脸、变形；产品不得结构变形、比例漂移、材质漂移；汽车不得车身比例错误、轮毂漂移、灯组变形；3C产品不得屏幕乱码、边框漂移、接口错位。
3. 节奏合规：每3s必须有视觉重点，每7s必须有高潮点，每个15s片段首尾具备衔接逻辑。
4. 结尾要求：结尾必须形成品牌记忆、产品Hero Moment、全球Campaign余韵或购买欲望。
5. 整体调性：全片必须保持高奢/时尚/运动/汽车/3C大牌品牌调性、情绪TVC质感与全球广告宣传片节奏。
6. 禁用元素：不得出现破裂、分割、破碎、裂缝、切割、爆破、碎片等破坏性视觉元素。
