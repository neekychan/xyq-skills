# Hook 参考库 / Domestic UGC Hook Library

Use this reference before writing the first 0-3 seconds of the script. A hook must create a reason to keep watching and must connect back to product proof by 3-7 seconds.

## Hook Selection Rule

Pick one hook type based on product category, platform, audience anxiety/desire, and available proof. The first shot should include:

- product visible or entering frame
- creator face, hand, or phone screen as a human bridge
- one short spoken line, normally 6-14 Chinese characters
- one optional short in-frame text, 2-8 Chinese characters
- clear transition into the 3-7s selling point

## Hook Types

### 1. 痛点直击 Hook

Use when the buyer has an obvious problem.

Patterns:

- "你是不是也遇到过这个？"
- "这个问题我终于解决了。"
- "之前我也觉得没必要。"
- "每天最烦的就是这一步。"
- "别急，先看这个细节。"

Best for: 清洁、收纳、护肤、服饰尺码、育儿、通勤、工具、App。

Visual: creator points to the problem, product appears within the same shot.

### 2. 结果前置 Hook

Use when the product has visible result.

Patterns:

- "先看结果，再说值不值。"
- "这个变化你看得出来吗？"
- "用完是这个状态。"
- "三秒给你看重点。"
- "它厉害的是这个结果。"

Best for: 美妆、清洁、穿搭、食品口感、健身、工具效率、前后对比。

Visual: show final result first, then creator brings product into frame.

### 3. 价格/福利 Hook

Use when offer, coupon, group-buying, bundle, gift, presale, or limited-time benefit matters.

Patterns:

- "这个价格我先放前面。"
- "今天重点是这个福利。"
- "券后这个价可以看一下。"
- "买之前先看套餐。"
- "这波赠品挺实在。"

Best for: 抖音电商、快手、团购、本地生活、低客单、促销活动。

Visual: price card/product card/phone page appears briefly, then product proof follows.

### 4. 实测挑战 Hook

Use when a simple test can prove the selling point.

Patterns:

- "我直接测给你看。"
- "别听介绍，看实测。"
- "这次我用真实场景试。"
- "它到底行不行，看这一下。"
- "先做个小测试。"

Best for: 数码、家电、车品、清洁、运动、食品、耐用性、容量。

Visual: creator sets up one clear test, no complex multi-step challenge in first shot.

### 5. 朋友提醒 Hook

Use for recommendation, seeding, buying guide, or avoiding wrong purchase.

Patterns:

- "这个我想提醒你一下。"
- "别只看外观，看这里。"
- "买这个前先看这点。"
- "我踩过坑，所以说实话。"
- "这个细节很多人忽略。"

Best for: 小红书、服饰、美妆、母婴、家居、数码、礼物。

Visual: creator speaks to camera, then shows close-up proof.

### 6. 日常场景 Hook

Use when repeated use or lifestyle fit is more persuasive than a hard sell.

Patterns:

- "我最近天天用这个。"
- "出门前我一定会带它。"
- "家里这个位置离不开它。"
- "这个小东西真的省事。"
- "我把它放在这里刚好。"

Best for: 日用品、家居、通勤、食品饮品、香氛、App、收纳。

Visual: creator naturally uses the product before explaining.

### 7. 探店到场 Hook

Use for local service and group-buying.

Patterns:

- "我已经到店了。"
- "先给你看套餐里有什么。"
- "这个团购我替你试了。"
- "门店环境先看一眼。"
- "核销流程我走一遍。"

Best for: 餐饮、酒旅、休闲娱乐、美容美发、亲子、本地服务。

Visual: store sign or package contents first, then creator reaction.

### 8. 游戏/活动福利 Hook

Use for games, IP campaigns, app events, downloads, and reservations.

Patterns:

- "这次活动奖励先看。"
- "这个皮肤我先冲了。"
- "预约福利别漏了。"
- "这次联动有点东西。"
- "进游戏先领这个。"

Best for: 游戏、IP、展会、活动页、周边。

Visual: phone screen or game page is bridged by creator hand, then returns to real reaction.

## Hook Anti-Repetition Rule

For multiple videos, rotate hook mechanism:

- pain point
- result first
- offer first
- test first
- friend reminder
- daily routine
- store arrival
- reward/event

Do not reuse the same first spoken line across generated variants. Change both visual action and spoken line.

## SD2.0 Hook Prompt Rule

Write hooks as positive, visible actions:

```text
0-3s: 主体1在[场景]中完成[一个清楚动作]，商品在画面中出现，主体1看向镜头说 spoken_line: "..."，画面上方出现短花字: "..."。镜头在商品放稳或口播结束后切到下一镜。
```
