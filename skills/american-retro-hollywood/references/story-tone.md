# 故事脚本口吻 / 氛围叙事 / 分镜节奏词库

这些是**可适配的模式与句式,按场景改写,不要逐字堆砌**。用于让分镜脚本、旁白/对白、整体叙事口吻贴合「美式复古好莱坞」的幽暗浪漫气质。

## 叙事气质与主题

- 基调:**含蓄、克制、暧昧、略带不祥**。不直白、不喧闹,重暗示与留白。
- 常见母题:旧日恋情的追忆、无法言说的秘密、命运的宿命感、优雅表象下的暗涌、时间与遗忘、诱惑与危险。
- 情绪弧线:从宁静的怀旧,缓慢滑向不安或哀伤;高潮往往是一个凝滞的瞬间,而非爆发。

## 旁白 / 对白语感

- 语速:缓慢、有停顿,像回忆在慢慢浮现。
- 句式:偏文学化、意象化;多用比喻与感官描写(光、气味、温度、声音)。
- 情感:含蓄内敛,把强烈情绪压在平静的表述之下。

写法示例(旁白口吻):"那年的光,总是斜斜地落在她肩上,像一句始终没说出口的话。"

## 分镜节奏

- 剪辑节奏:**慢**。长镜头、静态凝视、缓慢的推拉,给情绪留时间。
- 转场:柔和的淡入淡出、叠化,呼应梦境感;避免快切、硬切、炫技转场。
- 镜头设计:多用中近景肖像捕捉微表情;用空镜(窗、烛火、尘埃、雨)承接情绪;古典中心构图带来仪式感。
- 声音气质:低沉的环境声、老唱片般的配乐、雨声/钟声/风声等怀旧音效;留白与静默同样是表达。

## 短片 beat 参考模板(≤15s,同一条 prompt 内的时间轴)

- 0-3s:一个静谧的中近景或空镜建立氛围(光、尘埃、人物侧影)。
- 3-7s:主体动作缓慢展开,情绪浮现(一个眼神、一个转身)。
- 7-12s:一个细节特写或转折暗示(手、道具、光影变化)。
- 12-15s:凝滞的收束画面,留下余韵与记忆点。

## 落 prompt 前自检(叙事层)

- 叙事是否含蓄克制、有暗示与留白,而非直白喧闹?
- 节奏是否偏慢、转场是否柔和(淡化/叠化)、是否给情绪留时间?
- 声音与空镜是否参与叙事、强化怀旧压抑感?
- 情绪弧线是否滑向不安/哀伤的凝滞瞬间,而非爆发?
