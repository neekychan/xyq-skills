# 平台规格与市场本地化

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 全局规格参数

| 参数 | 默认值 | 备注 |
|---|---|---|
| 画幅 | 16:9 | 电影横屏 |
| 视频分辨率 | 720p | 适配用户需求 |
| 图像分辨率 | 2K | 确保纹理与线条细节 |
| 视频单镜时长 | 4s-12s | 根据动作类型动态设定，严禁低于 4s |
| 画风定位 | 雾山五行水墨武侠 | 泼墨写意 + 矿物泼彩叠彩 |
| 配音语言 | 跟随用户交互语言 | 默认中文 |
| 字幕语言 | 跟随配音语言 | |

## 时长匹配规则

| 镜头类型 | 时值范围 | 说明 |
|---|---|---|
| 极速打斗/瞬发切招/特写镜头 | 4s-6s | 侧重爆发力和视觉冲击，短时长保持剪辑高频紧凑 |
| 连击/招式交汇死锁角力/大招对碰 | 6s-9s | 需展现复杂动量变化、多段打击、粒子爆散及镜头推拉 |
| 台词对白/蓄势文戏/写意空镜/妖兽吐息大爆轰 | 9s-12s | 确保台词读音字数（单句≤10字，按每秒 2-3 字计算）有充裕唇形对齐时长 |

## 视频生成模型规格

- 单镜视频统一使用视频生成能力，单次生成 ≤15s 完整片段
- 成片超过 15s 时，拆成多个 ≤15s 片段分别生成，再做后处理拼接
- 视频生成工具一律严格读取并继承故事板中该分镜设定的 duration 属性
- 在动作切换明显时主动切镜

## 容错与异常处理

若视频生成因权限、额度或系统错误报错，不进行任何其他模型降级，直接暂停任务并将报错原因反馈给用户，由用户决定如何处理。

## 落 prompt 前自检

- 画幅是否为 16:9？
- 视频分辨率是否为 720p？
- 图像分辨率是否为 2K？
- 单镜时长是否在 4s-12s 范围内？
- 时长是否根据镜头类型动态匹配？
- 配音/字幕语言是否与用户交互语言一致？
