# 分镜图模板：剧情叙事 · 剧情脚本表格

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：用表格化脚本形式呈现剧情分镜，以“场次/镜号/画面/台词/景别/时长/备注”等字段组织信息，强调落地执行的拍摄/生成脚本清单，适合需要明确每一镜执行细节、方便制片/执行团队对齐的项目。
- **典型场景**：
  - 短剧项目：每集有完整剧本，需要拆解为可执行的镜头表。
  - 品牌剧情广告：需要向多方沟通脚本细节，用镜头表控制时长与节奏。
  - IP 剧情企划：需要沉淀长期使用的标准化脚本格式，方便团队协同。
  - 需要与现实拍摄衔接的项目：先在 AI 中用脚本表验证节奏，后续交给真实拍摄团队。

## 2. 判定关键词与适用边界
- **典型触发词**：`镜头表`、`分镜表`、`脚本表格`、`场次/镜号`、`Shot list`、`拍摄清单`、`执行脚本`、`导表`。
- **适用判定**：
  - 用户提供较完整的剧情梗概或剧本，并希望精确拆解为“每一镜的画面+台词+景别+时长”；
  - 项目需要多人协作（导演/制片/剪辑/美术），分镜结果将作为沟通/执行文档使用；
  - 对时长、节奏、镜头数量有明确约束，需要在前期脚本表阶段就做好控制。
- **不适用场景**：
  - 用户只想快速生成一条松散的情绪小故事，不在意每一镜的字段细节 → 更适合通用“剧情叙事型”模板；
  - 完全没有故事信息，只想看几张角色/场景图 → 更适合角色设定或场景设定模板；
  - 教学或产品讲解类项目，字段结构与剧情脚本表不同 → 优先教学/产品类分镜模板。

## 3. 分镜结构建议
- **推荐宫格数 / 镜头行数**：12–24 行（镜头），可按场次分组；分镜图中可采用“表格版式”呈现这些行。
- **规划方式**：
  - 先按**场次**拆分故事：场次编号 SC1/SC2/...；每场包含若干镜号 SH1、SH2 等；
  - 再为每一镜设计核心字段：
    - 画面内容（What we see）；
    - 台词/旁白（What we hear）；
    - 景别（远/中/近/特写）；
    - 时长（秒数或拍数）；
    - 机位/运动（固定/推拉/摇移等，可简写）；
    - 备注（情绪提示/技术要求/特效说明）。
  - 建议每个场次控制在 3–8 镜，总镜头数控制在 {宫格数} 左右，避免前期脚本过于膨胀。
- **版式建议**：
  - 分镜图整体采用表格视觉：清晰分出列标题（场次/镜号/画面/台词/景别/时长/备注）；
  - 可将表格置于画面主要区域，周围留适度留白，确保可读性；
  - 若需要辅助画面参考，可以在表格旁附少量缩略分镜格，但核心信息仍以文字表格为主。
- **时长与节奏**：
  - 建议在脚本表阶段就为每一镜预估时长，统计总时长是否符合 {目标总时长} 要求；
  - 注意场次切换处的节奏：场次起始和结束镜可稍微加长，强化段落感；场次内镜头节奏则根据情绪密度灵活调整。

## 4. 生图 Prompt（PE）模板

```text
你是一名剧情短片导演兼执行制片，请根据下述故事信息，生成一张以“剧情脚本表格”形式呈现的分镜图。分镜图的核心内容是一张结构清晰的镜头脚本表，包含场次/镜号/画面/台词/景别/时长/备注等字段，用于指导后续的拍摄或视频生成。整体画幅为 {画幅比例说明，如“16:9 横版导演分镜表”或“9:16 竖屏短剧脚本表”}。

【故事信息】
- 项目类型：{如“短剧第一集/品牌剧情广告/校园故事短片”等}
- 题材与基调：{如“都市情感/家庭治愈/职场喜剧/悬疑反转”等}
- 主角与关系：{主要角色姓名或标签 + 身份 + 关系，如“年轻情侣/父女/同事”等}
- 故事梗概：{100–200 字概述主要情节与结局}
- 目标总时长：{如“60 秒/90 秒/180 秒”等}

【脚本表结构要求】
请在分镜图中以表格形式呈现剧情脚本，表头至少包含以下字段：

1. 场次 (SC)：{场次编号，如 SC1/SC2，对应时间与地点}
2. 镜号 (SH)：{每个镜头在场次中的编号，如 SH1/SH2}
3. 画面内容：{此镜头画面中主要看到的场景与角色动作}
4. 台词/声音：{角色对白、旁白或重要声音提示，如环境音、音效}
5. 景别：{远景/中景/近景/特写，必要时补充机位高度信息}
6. 时长：{预估时长，单位为秒或拍数}
7. 备注：{情绪提示、技术需求、特效/转场说明，如“快切”“慢推”“叠化”等}

【宫格与镜头数量规划】
- 推荐镜头数：{宫格数，如 12/16/24}，请合理拆分到不同场次中；
- 场次划分建议：
  - SC1：开场场次，介绍主角与起始状态；
  - SC2：主要冲突或事件发展场次；
  - SC3：高潮或转折场次；
  - SC4：收束或尾声场次（如有）。
- 对每一场次，建议控制在 3–8 镜，避免场次过长或过短。

【输出格式要求】
请按场次与镜号顺序，为每一镜输出一行脚本信息，使用中文描述，格式示例：

- 场次：SC1（清晨，城市天台）
- 镜号：SH1
- 画面内容：{如“远景，城市天台全景，主角站在天台边缘眺望城市”}
- 台词/声音：{如“无台词，仅有城市环境音与配乐前奏”}
- 景别：{如“远景，固定机位”}
- 时长：{如“4 秒”}
- 备注：{如“开场建立环境，情绪偏平静，镜头保持稳定”}

请对 SC1–SC{场次数量} 中的所有镜头依次输出以上字段，确保：

- 画面内容与台词相互呼应，不出现严重信息矛盾；
- 景别与时长在整片中形成节奏变化，不是全程单一景别与时长；
- 备注字段简洁明确，可被导演/剪辑/美术直接理解与执行。

【画幅与排版建议】
- 表格在画面中居中或略偏上，保证行列间距一致，可读性高；
- 若需要，表格下方或侧边可以附一排简略分镜图标，标注关键镜头的构图示意，但不作为主要信息承载；
- 画风可偏简洁的设计稿风格：线条清晰、文字可读，配色低干扰，以利团队使用。

【特别说明】
- 本模板以“文字脚本表”为主，不要求生成具体角色细节图像，可通过抽象图标/简略构图辅助理解；
- 若用户提供完整剧本台词，可在“台词/声音”字段中简要摘取关键句，而非逐字抄录全文。
```

## 5. 一致性与避坑
- 字段命名保持统一：场次、镜号、画面、台词/声音、景别、时长、备注等列在整张表中不可随意更换叫法或顺序。
- 场次与镜号应严格按时间顺序排列，不要在表中频繁回跳时间导致执行困难。
- 画面内容与台词必须互相匹配：避免画面描述“夜晚街道”，台词却写成“早上好”；避免画面表现沉默，台词字段却写大量争吵。
- 景别与时长要考虑整体节奏：不要全片全部定格 3 秒中景；至少在关键情绪点使用特写或更长时长。
- 备注字段避免堆砌模糊形容词（如“很酷”“很燃”）；要用具体可执行的动作或技术词（如“手持跟拍”“从角色右侧慢推近”等）。
- 控制镜头数与总时长在合理范围：脚本表阶段即应初步校验总时长，避免后期剪辑才能发现严重超时。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“剧情叙事类”或“导演分镜表执行”相关模板：
  - 分镜阶段先以脚本表完成场次与镜头结构设计，明确每镜的画面、台词、景别与时长；
  - 视频阶段在执行模板中以脚本表为主输入，结合少量关键画面参考图，让模型按镜头表顺序生成或拼接视频；
  - 建议在 Prompt 中显式传递场次与镜号信息，便于后续剪辑对齐镜头顺序。
- 可搭配 `creative/narrative-arc.md` 确定故事三幕式结构与情绪节奏，然后将 arc 拆解到脚本表的场次与镜头上。
- 可配合 `storyboard/prompt-craft.md` 优化脚本表各字段的描述方式，提升模型理解与执行效率（例如统一景别/机位用词）。
- 若项目为系列短剧或品牌长线 IP，建议结合 `assets/character-lock.md` 先锁定角色与关键场景的设定，再为每一集生成对应的剧情脚本表，保证角色与世界观的一致性。
