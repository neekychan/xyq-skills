Build a compact internal brief before writing:

- product/category / 商品或品类
- source facts used / 使用的信息来源: user text, title, link, image, video, script / 用户文本、标题、链接、图片、视频、脚本
- target wearer/user, buyer decision-maker, presenter/host, and whether the image person should be protagonist / 目标穿着者/使用者、购买决策者、展示者/达人，以及图片人物是否作为主角
- target buyer / 目标用户
- use scene / 使用场景
- pain point or desire / 痛点或欲望
- primary selling point / 主卖点
- secondary selling point, only if needed / 次卖点，仅必要时使用
- visible proof point / 可视化证明点
- product actions or result shots / 产品动作或结果镜头
- CTA or intended next action / CTA 或下一步动作

For local/store content, also include:

- location type / 地点类型
- reason to visit / 到店理由
- signature product/service / 招牌产品或服务
- environment proof / 环境证明
- price/value or reservation/purchase hook / 价格、价值感、预约或购买钩子
- group-buying package contents, original price, deal price, redemption method, valid time, applicable stores, reservation rules, exclusions, and CTA / 团购套餐内容、原价、团购价、核销方式、有效期、适用门店、预约规则、不可用规则和 CTA

## Category Content Strategy / 品类内容策略

Before choosing the script structure, identify the product category and choose the matching content strategy. Different categories need different proof, visuals, creator roles, music, pacing, and CTAs.

在选择脚本结构前，先判断商品品类，并匹配对应内容策略。不同品类的视频证明方式、镜头重点、达人角色、音乐、节奏和 CTA 都不同。

Choose category, audience, and protagonist from the full input evidence. Product text and links identify the product need; images identify the product look and may also provide the protagonist when the image person matches the product need.

品类、人群和主角要从完整输入信息判断。商品文本和链接判断商品需求；图片判断商品外观，也可以在图片人物与商品需求匹配时提供主角。

Combine:

综合判断：

- Category / 品类: what the product is / 商品是什么
- Usage scene / 使用场景: commute, office, dating, travel, gym, school, parenting, gifting, home cleaning, cooking, party, store visit / 通勤、办公、约会、旅行、健身、上学、带娃、送礼、清洁、做饭、聚会、探店等
- Target user / 目标人群: gender, age, role, lifestyle, skill level, income/price sensitivity / 性别、年龄、身份、生活方式、熟练度、价格敏感度
- Purchase motivation / 购买动机: look better, save time, solve pain, feel safe, taste good, gift well, show status, collect, replace old item / 变好看、省时间、解决痛点、安全放心、好吃好喝、送礼体面、身份表达、收藏、替换旧物
- Proof type / 证明方式: try-on, before/after, stress test, comparison, close-up texture, sound, taste reaction, parent/child use, store atmosphere / 试穿、前后对比、压力测试、对比、材质特写、声音、入口反应、亲子使用、门店氛围
- Creator identity / 达人身份: friend, expert, parent, store explorer, reviewer, stylist, office worker, student, partner, collector / 朋友、专家、家长、探店达人、测评者、穿搭师、上班族、学生、伴侣、收藏者

Scene overlay rules / 场景叠加规则:

- Commute/office / 通勤办公: emphasize efficiency, clean appearance, portability, low interruption, durability / 强调效率、体面、便携、低打扰、耐用
- Dating/party / 约会聚会: emphasize appearance upgrade, confidence, compliments, scent/taste/texture, social proof / 强调颜值提升、自信、被夸、香味/口味/质感、社交证明
- Travel/outdoor / 旅行户外: emphasize portability, weather resistance, comfort, battery/capacity, easy storage / 强调便携、抗天气、舒适、电量/容量、好收纳
- Family/parenting / 家庭带娃: emphasize safety, comfort, cleaning ease, time-saving, parent trust / 强调安全、舒适、易清洁、省心、家长信任
- Student/dorm / 学生宿舍: emphasize value, compactness, easy use, shareability, visual fun / 强调性价比、小巧、好用、可分享、有趣
- Gifting / 送礼: emphasize occasion, recipient type, packaging, reaction, thoughtfulness, price tier / 强调节日、收礼人、包装、反应、心意、价格档位
- Store/local service / 门店本地生活: emphasize location, route, atmosphere, signature item, price/value, reservation/group deal / 强调位置、路线、氛围、招牌、价格价值、预约/团购
- Replacement/upgrade / 替换升级: emphasize old-vs-new comparison, pain removal, performance improvement, why now / 强调新旧对比、痛点消失、性能提升、为什么现在买
- Game/IP/event / 游戏/IP/活动: emphasize play desire, character or skin appeal, event entrance, reward value, social participation, download/reserve/ticket/check-in action / 强调玩法欲望、角色或皮肤吸引力、活动入口、福利价值、社交参与和下载/预约/购票/打卡动作

Offer-first rules / 价格优惠前置规则:

- When the user provides a concrete offer such as `买一赠一`, `第二件半价`, `到手价`, `限时券`, `团购价`, `满减`, `包邮`, `赠品`, `预约福利`, or `开票时间`, place that offer in the first 0-3 seconds as a spoken hook or short overlay / 用户提供买一赠一、第二件半价、到手价、限时券、团购价、满减、包邮、赠品、预约福利或开票时间时，把该优惠放在 0-3 秒作为口播钩子或短画面关键词
- Keep offer overlays short and stable: `买1赠1`, `到手¥39`, `团购¥99`, `限时领券`, `预约送礼包`; detailed terms go into spoken copy or publishing caption copy / 优惠画面文字保持短且稳定：买1赠1、到手¥39、团购¥99、限时领券、预约送礼包；详细规则放口播或发布文案
- After an offer hook, return to the product and selling point by 3-6 seconds: show product-in-hand, package, store item, game reward page, or service process / 优惠钩子之后，3-7 秒回到商品和卖点：展示手持商品、包装、门店项目、游戏福利页或服务流程
- Connect price to proof: show why the offer is worth it through quantity, result, taste, texture, package contents, function, or experience / 价格必须连接证明：通过分量、结果、口味、质感、套餐内容、功能或体验说明为什么值

### Apparel: Women's Wear / 女装

- Core effect / 核心效果: fit, body proportion, styling transformation, fabric movement, occasion match / 版型、显身材、穿搭变化、面料动态、场景适配
- Visual proof / 视觉证明: try-on before/after, full-body mirror shot, walking turn, close-up of waist/shoulder/hem/fabric / 上身前后对比、全身镜、走动转身、腰线/肩线/下摆/面料特写
- Creator role / 达人角色: stylish friend, try-on reviewer, outfit planner / 会穿搭的朋友、试穿测评、搭配建议者
- Avoid / 避免: only flat-lay, only packaging, hiding the full silhouette / 只拍平铺、只拍包装、看不清全身版型
- CTA / 转化: size suggestion, color choice, outfit save, product card, limited drop / 尺码建议、颜色选择、收藏穿搭、商品卡、限量上新
- Variant switch / 款式切换: when showing multiple outfits, first show all garments on a rack/bed/in hand, then switch outfits only through a deliberate transition such as hand covers lens, mirror cut, dressing-room reset, or creator holds the next garment to camera; never morph clothes on the body mid-shot / 多款试穿时，先在衣架/床面/手上展示全部款式，再用遮镜、镜前切换、试衣间重置、手拿下一件靠近镜头等明确转场切换；不要让衣服在身上中途变形

### Apparel: Men's Wear / 男装

- Core effect / 核心效果: clean fit, practicality, texture, easy styling, commute/date/casual scenes / 版型利落、实穿、质感、好搭、通勤/约会/休闲场景
- Visual proof / 视觉证明: standing and walking fit, shoulder/chest/length check, fabric close-up, pocket/detail demo / 站立走动版型、肩胸衣长检查、面料特写、口袋/细节演示
- Creator role / 达人角色: practical reviewer, style upgrade friend, boyfriend/husband styling angle / 实用测评、形象升级朋友、男友/老公穿搭角度
- Avoid / 避免: exaggerated fashion language, no-body try-on / 过度时装化表达、没有真人上身
- CTA / 转化: size recommendation, capsule wardrobe, buy one staple, product card / 尺码推荐、胶囊衣橱、入一件基础款、商品卡
- Variant switch / 款式切换: for multiple shirts, jackets, pants, or colors, use a visible reset cut between outfits; keep the pose and camera angle similar only after the cut, not during a morph / 多件上衣、外套、裤装或颜色切换时，用明确重置切点；切后可保持相似机位和姿势，但不要在同一镜头内变形

### Apparel: Kids' Wear / 童装

- Core effect / 核心效果: comfort, easy movement, softness, durability, cute styling, parent trust / 舒适、活动方便、柔软、耐穿、可爱搭配、家长信任
- Visual proof / 视觉证明: child moving, stretching, sitting, fabric touch, easy-on/easy-off, wash/durability cue / 小朋友活动、伸展、坐下、摸面料、好穿脱、耐洗线索
- Creator role / 达人角色: parent reviewer, caring family member / 家长测评、照顾者视角
- Avoid / 避免: over-commercial child posing, unsafe activities, claims without comfort proof / 过度商业摆拍、不安全动作、没有舒适证明的宣称
- CTA / 转化: age/height size guide, parent save, seasonal bundle / 年龄身高校准、家长收藏、换季套装
- Variant switch / 款式切换: show children's clothing variants on hangers or folded stack first; avoid rapid on-child outfit swaps unless separated by a clear parent-held garment or dressing-room transition / 童装多款先用衣架或叠放展示；避免小朋友身上快速换装，除非用家长手持衣服或试衣转场明确分隔

### Shoes / 鞋子

### Daily Goods / 日用品

### Cosmetics And Makeup / 化妆品与美妆品

- Visual proof / 视觉证明: half-face test, swatch, close-up application, natural light result, wear-test cue / 半脸测试、试色、上脸特写、自然光结果、持妆线索
- Creator role / 达人角色: beauty reviewer, friend recommendation, makeup tutorial creator / 美妆测评、朋友安利、教程型达人

### Skincare / 护肤品

- Creator role / 达人角色: routine sharer, sensitive-skin reviewer, ingredient-aware friend / 护肤流程分享、敏感肌测评、懂成分的朋友
- Avoid / 避免: medical claims, instant cure promises, overclaiming before/after / 医疗宣称、立刻治愈、夸大前后对比
- CTA / 转化: routine match, skin-type suggestion, patch-test reminder, product card / 流程适配、肤质建议、试敏提醒、商品卡

- Creative fit / 适配创意: expert talk, case story, factory visit, problem-solution, data reveal, founder/executive narrative / 专家讲解、案例故事、工厂探访、问题解决、数据揭示、创始人/高管叙事
- CTA / 转化: book demo, contact consultant, download whitepaper, search brand, follow account / 预约演示、联系顾问、下载资料、搜索品牌、关注账号

### Category Selection Rule / 品类选择规则

- If one category is clear, use that category's strategy before writing / 品类明确时，先套用品类策略再写脚本
- If the product crosses categories, choose the category that best matches the purchase motivation / 跨品类商品按购买动机选择主品类
- If the same category appears in different scenes, adapt the proof shot and CTA to the scene, not just the category / 同一品类出现在不同场景时，要按场景调整证明镜头和 CTA，不要只套品类模板
- If the category and scene conflict, prioritize the user's stated conversion goal and visible proof / 品类和场景冲突时，优先满足用户说的转化目标和可见证明
- Always combine category strategy with platform strategy: Douyin stronger hook, Kuaishou more practical proof, Xiaohongshu more experience-led trust, WeChat more trust-based recommendation / 始终把品类策略和平台策略结合：抖音强钩子，快手重实用证明，小红书重体验信任，微信视频号重可信推荐
- For products where safety, health, children, pets, skincare, supplements, or performance claims matter, keep claims conservative and show observable proof only / 涉及安全、健康、儿童、宠物、护肤、营养补充、性能宣称时，宣称要克制，只展示可观察证明
- If the user requests multiple categories, produce separate content strategies instead of one generic script / 用户要求多个品类时，分别输出策略，不写成泛用脚本
- If a category is not listed, infer by analogy from the closest category and state the chosen strategy internally / 未列品类时，按最接近品类类比处理
