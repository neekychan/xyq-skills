# 分镜图模板：音乐 MV · 概念视觉

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以**抽象概念、象征意象与视觉创意**为核心的 MV 分镜，不依赖歌词或写实人物，强调“概念统一、视觉冲击、隐喻表达”。
- **典型场景**：
  - 电子/实验/前卫曲风的概念 MV。
  - 品牌主题曲、艺术短片式 MV。
  - 用超现实/符号化画面表达主题的视觉作品。

## 2. 判定关键词与适用边界
- 典型触发词：`概念 MV`、`视觉创意`、`超现实`、`象征/隐喻`、`艺术感`、`抽象视觉`、`未来感`。
- 适用判定：
  - 用户希望用统一的视觉概念/世界观贯穿全片；
  - 接受抽象、象征性表达，弱化具体叙事与歌词对应。
- 不适用场景：
  - 需要逐句歌词或人物演唱 → 用“歌词逐段 / 表演·对口型”模板；
  - 只是要情绪氛围而非强概念 → 用“情绪氛围”模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–12 格，按“概念母题 + 变奏”组织；
- 规划方式：
  - 先确立一个核心视觉概念（母题）：如“镜面世界”“数字解构”“自然与机械”；
  - 围绕母题设计 3–4 组视觉变奏，每组配 2–3 格；
  - 通过统一的视觉语言（材质、几何、色系、符号）串联全片。

## 4. 生图 Prompt（PE）模板

```text
你是一名概念视觉 MV 分镜导演，请根据下述信息，设计一张 {宫格数} 宫格的“概念视觉”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”}。

【概念与歌曲信息】
- 歌曲名称与曲风：{歌名 / 电子·实验·前卫等}
- 核心视觉概念（母题）：{如“镜面世界 / 数字解构 / 赛博自然”}
- 主题关键词：{如“孤独、重生、连接、解构”}
- 视觉语言基调：{材质、几何形态、色系、象征符号}

【拆分要求】
1. 全片围绕同一核心概念母题展开，避免概念散乱；
2. 设计 3–4 组视觉变奏，每组 2–3 格，体现概念的不同侧面；
3. 用统一的材质/几何/色系/符号保证视觉一致。

【分镜输出格式】
- 宫格编号：M1–M{N}；
- 对于每一格输出：
  - 所属变奏组：{母题的哪一侧面}
  - 画面内容：{超现实场景/抽象元素/象征物}
  - 视觉语言：{材质、几何、色彩、符号}
  - 隐喻与意图：{这格在表达什么概念/情绪}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16；
- 画风：{超现实 CG / 3D 概念渲染 / 抽象数字艺术}；
- 全片材质、色系、符号系统高度统一，仅在变奏间做有控制的演化。
```

## 5. 一致性与避坑
- **概念统一**优先于单格惊艳，避免每格风格各异、互不相关。
- 抽象不等于随意：每格要能落到母题的某一侧面，保持可解读性。
- 材质/色系/符号系统贯穿全片，是概念 MV 的视觉锚点。
- 若穿插人物，应作为概念元素处理（剪影/符号化），并保持形象一致。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段确立母题与视觉语言；
  - 视频阶段以概念关键格为参考帧，Prompt 中强调材质、运动形态与转场变形（morph）；
  - 善用形变/粒子/光影转场强化概念连贯，节奏跟随音乐结构推进。
- 风格与转场创意可参考 `creative/` 下风格相关约定；运镜与镜头语言可参考 `storyboard/prompt-craft.md`（如有）。
