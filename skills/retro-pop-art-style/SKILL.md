# 复古美式波普艺术风格（Retro American Pop Art Style）

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的复古美式波普艺术质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一套印刷 / 同一本复古波普画册里出来的」（配色、网点半调、套印质感、轮廓线、褪色墨层不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一本复古波普艺术作品集 / 同一支广告，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **复古美式波普艺术风格，商业插画和印刷封面视觉为基础的风格，高饱和、高对比、强平面化的视觉特征，大面积纯色块、粗黑有力的轮廓线、直接的复古配色，暗部带有渐变半调网点、旧纸张纹理、轻微套印偏移和褪色墨层的彩印质感。整体气质鲜明、传奇、张扬，具有强烈的年代感与视觉识别度。复古、戏剧化，兼具漫画分镜的冲击力，画面表现夸张。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它风格 / 画风类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格类」skill 搭配时的优先级规则（务必遵守）

当本技能与**非风格类**功能 skill（如营销短片、广告脚本、分镜生成、口播视频、电商带货、剧情短剧等业务流程 skill）同时被调用时：

- **职责分层，各管一段：** 非风格类 skill 负责「内容与流程」（讲什么、脚本结构、分镜节奏、时长、投放目的、CTA 等）；本技能负责「画风」（所有图片 / 视频产物长成什么样）。二者不是二选一，而是叠加。
- **画风归属本技能，不可被覆盖：** 即使加载了营销短片等 skill 并使用了它的分镜 / 脚本 / prompt 模板，最终交给生成模型的**每一条**图片 / 视频 prompt，仍必须在最开头逐字注入本技能锚定词。业务 skill 若自带任何画风描述、风格模板或默认视觉设定，一律让位于本技能锚定词，不得替换、稀释或前置到锚定词之前。
- **合并进对方模板：** 如果业务 skill 输出的是成形的 prompt / 分镜文本，就把本技能锚定词插入到该 prompt 的最前端（锚定词 → 业务 skill 的具体画面 / 镜头描述），而不是丢弃业务 skill 的内容。
- **冲突判定：** 凡涉及「画面长什么样、颜色、质感、笔触、轮廓、渲染观感」的表述，以本技能为准；凡涉及「讲什么、怎么排布、投放 / 转化逻辑」的表述，以业务 skill 为准。发生直接矛盾时，画风维度以本技能为最高优先级。

### 绕过 Agent 内置风格锚定图的干扰（务必遵守）

某些 Agent 链路会针对特定风格**前置内置一张 / 一组风格参考图（风格锚定图 / style reference / 垫图）**，用它来统一画风。这类内置参考图会与本技能的锚定词冲突、污染本次资产的画风。**在本技能生效时：**

- **禁止引入任何内置风格锚定图 / 默认 style reference / 系统预置垫图**参与本次图片与视频生成；本次画风只由本技能锚定词（或合并锚定词）决定。
- 若生成链路默认会自动挂载内置风格参考图，**必须显式绕过 / 关闭 / 不传该参考图**（例如不传 style-reference 图、不启用内置风格预设、把风格来源指定为本技能锚定词），确保没有任何未经用户指定的参考图进入生成。
- **例外：** 用户本人明确提供的参考图（首帧衔接图、指定角色图、指定分镜图）不属于「内置风格锚定图」，可正常使用；被绕过的只是 Agent 链路**自动内置、非用户指定**的那类风格参考图。
- 交付前自检：本次是否有任何「非用户指定」的风格参考图被悄悄挂入？若有，去掉后重生。

## 风格知识库（供写分镜 / 角色 / 场景 / 脚本时对齐气质，非注入 prompt 的锚定词）

> 用途：当 Agent 需要为本次任务补分镜、设计角色造型、描述场景光影、撰写故事脚本 / 文案时，参考本节，让「具体画面描述」这部分也贴合复古波普气质。本节是**创作参考**，不替代上面的锚定词，也不逐字塞进 prompt。

### 整体气质
- 关键词：鲜明、传奇、张扬、复古、戏剧化、夸张、强视觉识别度、强年代感。
- 观感基调：像 1950–1970 年代美式商业广告、漫画封面、罐头 / 海报 / 杂志印刷品；响亮、锋利、醒目，俗艳却高级、轻佻却极具设计感。
- 叙事调性适配：适合传奇感、英雄感、戏剧冲突、广告式高光时刻、复古怀旧、诙谐俏皮的题材。

### 色彩系统
- 高饱和、高对比、高纯度；原色 + 补色大胆撞色（红/黄/蓝、粉/青/黄、橙/蓝、红唇+冷底）。
- 直接的复古配色：番茄红、芥末黄、湖蓝、薄荷绿、复古粉、奶油米、墨黑，常配旧纸张的暖褐底。
- 允许非自然色（粉色阴影、蓝色皮肤高光、黄底紫影），服务情绪与图形秩序而非真实光照。
- 每个画面设一个极强视觉锚点（一抹纯红、一块荧光色），制造视线焦点。

### 印刷 / 材质质感（本风格的灵魂）
- 半调网点（halftone）：规则圆点阵列表现暗部与渐层，近看是机械印刷颗粒，远看形成明暗。
- 套印偏移：颜色叠印轻微错位，边缘偶尔溢出轮廓，模拟老式彩印套色不准。
- 褪色墨层：颜色像被岁月压过一层，饱和中带旧、带哑光，非全新数字化的干净。
- 旧纸张纹理：微微泛黄、纤维颗粒、折痕 / 磨损感，强化年代感。
- 拼贴感：色块、文字、图形、网点像被剪贴 / 压印上去，具杂志拼版气息。

### 轮廓与笔触
- 粗黑有力的外轮廓线，边界干净利落，图形化描边而非厚涂笔触。
- 内部结构线简化，重点部位用重线强调；笔触更像「丝网印刷压印 / 漫画墨线 / 马克笔平涂 / 版画滚墨」的媒介痕迹，而非古典油画的揉擦晕染。
- 明暗简化为切割式块面（亮面一块、暗面一块、投影一块），高光可作为纯白块 / 圆点 / 条状图形出现。

### 角色造型
- 五官标志性、夸张：眼睛轮廓鲜明、睫毛夸张、嘴唇颜色浓烈、脸颊 / 鼻翼阴影图形化。
- 表情戏剧化、放大化，情绪高点常伴符号化图形（爆炸框、放射线）。
- 发型 / 服饰强调图案价值：条纹、圆点、棋盘格、几何块面；配饰有强图标属性；发型轮廓像 logo 一样易识别。

### 场景与光影
- 场景平面化、海报化，弱化真实透视纵深；背景常为纯色块 / 放射线 / 网点底 / 复古图案。
- 光影为「设计出来的」而非物理写实：投影呈夸张几何形，阴影形状服务情绪。
- 常见环境：复古美式街景、老式加油站 / 餐厅 / 汽车、霓虹招牌、广告牌、罐头 / 唱片 / 杂志等消费符号。

### 构图与镜头（写分镜可用）
- 海报感构图：主体居中、大头特写、半身像配纯色背景，一眼识别、信息密度高。
- 重复 / 并列 / 复制：同一角色或物体多色重复排列（沃霍尔式），制造流行文化「商品陈列」感。
- 图文并置：拟声词（BANG / WOW / POP）、标语、对白框、字幕块作为画面元素参与构图。
- 动画节奏偏「视觉打击点」：关键帧停顿、动作定格、像翻漫画页 / 网点扩散 / 爆炸框的图形化转场；可接受分帧感、局部动整体静。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否与营销短片等业务 skill 叠加；视频画幅 / 时长偏好；是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，参考上文风格知识库补齐一版分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。若同时有非风格类业务 skill，按「非风格类优先级规则」明确：画风用本技能锚定词，内容 / 流程用业务 skill。
2. **绕过内置风格锚定图。** 生成前确认本次不引入任何非用户指定的内置风格参考图 / 默认 style reference；风格来源只认锚定词。
3. **生成图片素材（逐张）。** 对每一张需要的图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`（具体描述可参考风格知识库对齐气质），然后生成图片。所有图片共用同一份锚定词。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该图片作为视频的画面参考，视频 prompt 仍在头部注入锚定词。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
7. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。
