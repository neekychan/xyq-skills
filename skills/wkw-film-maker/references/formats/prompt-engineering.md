# 提示词编写规范

本规范覆盖图像提示词、视频提示词和BGM提示词的编写标准。**最高优先级铁律：所有提示词必须完全且固定使用中文书写，严禁出现任何英文单词、英文字标或英文字符。**

---

## 一、图像提示词规范

### 1.1 多模态视觉逆向解析逻辑

在编写图像提示词前，必须分析用户上传的任何参考图特征，并在提示词中复刻：
- **角色参考图**：提取五官比例、骨相特征、妆容（复古红唇、精致眼线）、服饰材质纹理（重磅真丝旗袍刺绣、呢子大衣粗糙质感）、穿搭特征
- **场景参考图**：提取建筑流派、空间几何结构、低照度主光源方向、色温、环境磨损度（斑驳墙纸、潮湿反光石砖地面）、大气透视
- **道具参考图**：提取表面材质（绿瓷点唱机、黄铜烟灰缸）、物理体积与高光反射率
- **分镜参考图**：提取摄影机机位（低角度仰拍、窥视视角）、构图法则（框架式构图、三分法则）、景深畸变特征

### 1.2 美学风格自适应机制

根据剧本题材或参考图，自动映射视觉风格词汇：

**真人实拍风格（默认兜底）**：
- 次表面散射、毛孔细节、真实光学景深、物理级光线追踪、定焦镜头质感、胶片颗粒、低照度高对比度
- 皮肤质感：真实皮肤纹理、毛孔可见、皮下血管隐约、不磨皮不过度美化
- 光影：明暗对照法、柔和漫射、定向光源、自然衰减

**其他风格（按需选用）**：
- 水墨流派：宣纸晕染、焦墨枯笔、留白构图、水墨粒子消散、低饱和度国风色卡
- 注意：王家卫风格默认强制采用真人实拍风格，不使用动漫/3D/水墨风格

### 1.3 三维空间景深解算与微观描述

- **空间深度**：提示词必须显式规定前景、主体、背景三层结构。通过大光圈浅景深、焦外圆形光斑、光影阻隔建立空间秩序
- **微观细节**：特写镜头必须描述瞳孔倒影、肌肉微表情、皮肤次表面散射、毛孔结构、衣物纤维纹理、缭绕的香烟烟雾
- **情绪与动作**：拒绝僵硬状态，描述生动且富有情绪张力的动态神情（下颌紧绷、眼眶湿润、指节因用力泛白、眼神快速扫视、视线低垂避开对视）

### 1.4 角色参考图（多视角设定图）提示词规范

**排版布局**：纯白背景，四张子图水平横向排列，从左到右依次为：
1. 左侧大幅半身特写（占整图约40%宽度）
2. 正面全身
3. 侧面全身
4. 背面全身

**视角精细分工**：
- **半身特写**：面部占画幅上部三分之二，眼神带有一丝忧郁，不直视镜头（或直视镜头但眼神复杂），精准呈现皮肤、发丝与五官细节
- **正面全身**：头顶至足部完整入画，标准站立姿态，还原服装正面剪裁
- **侧面全身**：完整左侧身体剪影，保留服装侧面轮廓及层次
- **背面全身**：服装背面细节完整、材质纹理清晰可见

**环境光影控制**：绝对纯白背景，柔和均匀的工作室环境光，无强方向性生硬阴影，面部使用柔和软光补光。

**正向风格词**：极度超写实摄影、照片级真实感、电影画质、超高清分辨率、影棚光照、清晰聚焦、专业人像摄影
**负向排除词**：无文字、无水印、无标识、无多余人物、无动漫、无插画、无彩色背景、无背景道具、无床、无窗帘、无烟雾、无3D渲染感、无塑料皮肤

### 1.5 王家卫电影海报封面提示词规范

**美学核心**：
- 高对比度、暗调光照，强烈冷暖色彩对比（绿与红、蓝与黄）
- 主体处于幽暗环境中，带有朦胧烟雾或雨水反光
- 胶片颗粒质感、低照度电影光影、浅景深
- 人物神情暧昧、孤独、若有所思

**排版排字描述**：
- 画面下方或上方带有精美、干净的复古衬线体电影标题
- 极具诗意的中英双语电影台词排版（艺术排版、干净的电影演职员表文字、诗意双语字幕）
- 平视或微仰视角，暧昧的自然采光
- 呈现怀旧、精致、孤独的电影感海报风格

**负向排除词**：无混乱排版、无杂乱文字、低画质、混乱色彩、无卡通感、无现代感

### 1.6 电影级光影与曝光微调规范

**低照度面部软光**：
- 人物面部光照必须避免生硬、高对比度的直射强光
- 强制使用具有包覆感、柔和过渡的低照度漫射软光
- 柔和勾勒皮肤与发丝的次表面散射质感
- 在黑暗背景中突出面部轮廓，明暗交界线过渡丝滑
- 杜绝曝光过度导致的细节丢失和死白

**特定方向漫反射与霓虹反射**：
- 场景必须建立单一且方向明确的实用光源（壁灯、台灯、霓虹灯、路灯）
- 光线在非光滑表面（复古墙纸、布料、哑光木质）上呈现定向漫反射
- 在潮湿地面或玻璃上呈现斑驳的霓虹倒影
- 明确规定光线随距离的自然衰减（光衰减）
- 确保前景、主体、背景的光亮层级与光源方向逻辑绝对自洽

## 二、15秒多镜头分段视频提示词模板

生成15秒视频的提示词时，**必须且只能**严格采用以下四个模块结构。单次输出纯提示词文本控制在1500字至3000字之间。

### 模块一：【全局视觉与美学基调】

```
【全局视觉与美学基调】
- 美学风格：真人实拍风格，王家卫式[具体美学方向，如：都市怀旧/霓虹迷幻/海派繁花]美学，强调低照度高对比度光影，融入强烈的冷暖色彩对比与空间阻隔。严格遵守美学配额制：全片倾斜构图、抽帧降格、极度对称构图与极速横摆镜头配额各最多一次，其余镜头均采用常规电影视听语言。
- 镜头与景深：三十五毫米大光圈电影镜头，大光圈浅景深，精准的焦平面控制与焦外散景，框架式构图，手持摄影带有微弱呼吸感。
- 色彩与光照：柯达胶片调色，[具体色盘描述]，主光源方向明确且在物体表面产生柔和的定向漫反射，面部使用温润包裹的自然漫射软光塑造立体轮廓，杜绝高对比度曝焦与死黑，画面带有细腻的胶片颗粒质感。
```

### 模块二：【人物与场景设定】

```
【人物与场景设定】
- 人物资产：引用角色参考图[角色A占位符]、[角色B占位符]，指定各角色的五官微观特征、瞳孔反光、发丝状态与衣物材质（如：真丝旗袍纹理、呢子大衣质感）。角色动作自然，不强制面对镜头，眼神带有含蓄的情绪表达。

```

## 三、语音与声效包装符与常识防火墙

### 3.1 环境与物理音效（Foley）

- 使用尖括号 `<...>` 包装音效描述
- 必须详细描述音效的物理属性（衣料摩擦、金属撞击、水渍踩踏、火焰燃烧）
- 严禁出现任何"背景音乐""BGM""旋律""节奏""配乐"等描述
- 音效必须与画面空间匹配（小房间声音干、走廊有回声、室外声音散失）

### 3.2 多角色对话/内心独白

- 使用 **方言前缀{角色名："对白文本"}** 格式包装
- 普通话可省略方言前缀，但加了更明确
- 方言必须加前缀：粤语{...}、上海话{...}、闽南语{...}、东北话{...}、四川话{...}、重庆话{...}、河南话{...}
- 对白文本必须完全符合Final_Video_Spec的输出语言配置
- 尽量使用该方言地道的文字、叹词和特殊句式书写
- 角色A的对白必须绑定角色A的音色资产，角色B的对白必须绑定角色B的音色资产
- 内心独白内容必须前后呼应、逻辑严密，极具文学色彩与诗意
- 严禁出现无意义或跳跃性的台词

### 3.3 屏幕文字

- 使用方头括号【...】包装屏幕上出现的文字内容（如门牌号码、招牌文字、信纸上的字迹）
- 视频本身不添加字幕（字幕后期合成），仅描述场景中自然存在的文字道具

### 3.4 行为常识防火墙

- 拒绝一切无逻辑的夸张奇观
- 强制动作描写符合重力、惯性和摩擦力等物理学常规交互：
  - 推门需描述施力过程、门开启匀速、重心微微前倾
  - 拿取物品需有伸手-握住-提起的完整动作链
  - 走路时重心随步伐交替转移，衣料随动作自然摆动
  - 液体在容器中随动作产生符合物理规律的晃动
  - 烟雾向上升腾并逐渐扩散，受气流影响产生飘动
- 角色互动时注意视线交汇的物理合理性（谁看谁、何时移开目光）

### 3.5 负向约束尾缀

每段视频描述尾部必须带上纯中文负向词：**无字幕，无音乐，无文字，无标识**

## 四、纯乐器背景音乐（BGM）提示词规范

### 4.1 曲风与情绪定位

- **核心基调**：突出暧昧、缠绵、孤独且带有时代怀旧感的原声器乐重奏。节奏必须具备强烈的旋律性与情感张力（慢速、忧郁、宏大、浪漫的节拍）以便剪辑卡点。
- **风格标签词**：原声、忧郁弦乐、复古探戈、性感萨克斯风、浪漫、怀旧、亲密重奏、剧场级原声录音。
- **禁止项**：绝对禁止在提示词中写入任何知名音乐人、歌手或特定乐队的名字，防止版权审核拦截。

### 4.2 王家卫标志性乐器库

编写BGM提示词时，必须组合调用以下至少2-3种特色乐器：

| 乐器 | 音色特征与情绪功能 |
|---|---|
| 大提琴/低音提琴 | 深沉、忧郁且极具顿挫感的拨弦，作为节奏或情感的主旋律根基 |
| 小提琴/中提琴 | 绵延不绝、如泣如诉的拉奏，渲染极致的伤感与压抑 |
| 手风琴 | 注入阿根廷探戈般的暧昧、缠绵、激情与忧伤 |
| 萨克斯风 | 点缀都市深夜的孤独、慵懒与情欲暗流 |
| 古典吉他 | 质朴、慵懒且带有一丝漂泊感的弹拨 |
| 爵士钢琴 | 缓慢、克制的琴键敲击，营造深夜小酒馆的幽闭与亲密感 |
| 电吉他（带重混响） | 八九十年代港风的迷幻与疏离 |
| 怀旧手风琴 | 民谣怀旧感，岁月泛黄的质感 |

### 4.3 方言美学特色BGM配方

选定方言后，必须严格套用对应的中文乐器与意境组合：

**粤语（经典港风）配方**：

### 4.4 器乐与编曲结构控制

- 必须在提示词中显式声明"纯乐器"或"无声乐"，避免模型随机产生合成人声
- 描述音场质感：亲密原声录音棚录音、温暖黑胶唱片质感、干声混音、无重度电子合成器
- 避免大空间混响或现代电子合成器
- 速度标记：慢速、行板、缓慢四三拍或四四拍
- 动态范围：从极弱的独奏到全乐队合奏的情感高潮，再回归独奏的寂寥
