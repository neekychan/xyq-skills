## 核心原则
### 持久引擎（因果链）
用户剧情需求 → 宫崎骏式成长叙事重构 → 角色/场景/机械设定图多模态绑定 → 15秒分段多切片分镜设计 → 视觉状态账本跨段衔接 → 全手绘赛璐珞质感逐镜生成 → 久石让式交响配乐合成 → 电影级动画成片

核心创作逻辑：**整个世界都在呼吸**——不只是人物在动，风、水、草、云、齿轮、蒸汽都必须遵循物理规律自然运动，角色通过具体行动完成成长弧光，拒绝善恶二元对立，传递自然崇拜、反战、环保、女性独立的人文内核。

### 可证伪质量测试
成片必须同时满足以下所有条件才算合格：
1. 任意连续3秒画面内，至少有3种不同层级元素在自然运动（如发丝摆动+草叶摇晃+云层移动），无静态PPT感
2. 主角从开篇到结尾有可观测的行为变化（从逃避到面对/从胆怯到勇敢/从破坏到和解），成长不靠旁白解释
3. 所有冲突方均有合理动机，无纯粹邪恶的脸谱化反派
4. 任意机械/飞行器部件运动符合物理逻辑，齿轮、螺旋桨、蒸汽管道无穿帮或无逻辑滑动
5. 画面全程保持手绘二维动画质感，无三维塑料感、无照片写实感、无廉价卡通贴图感
6. 任意段落衔接处，角色位置、道具状态、天气光影与上一段结尾完全一致，无瞬移或穿帮

## 输入诊断
开始创作前必须确认以下维度，缺失项必须与用户沟通确认，不得自行假设：
1. **核心技术规格**：
   - 视频生成模型：Seedance 2.0（最高画质）/ Seedance 2.0 Fast（快速预览）
   - 输出分辨率：720p / 1080p（仅Seedance 2.0支持）
   - 画面比例：16:9（默认电影横屏）/ 9:16 / 1:1
   - 输出语言与口音：普通话（默认）/ 日语感中文配音 / 儿童自然口语 / 少女成长叙事口吻 / 乡村生活化口音 / 自定义
2. **故事核心要素**：
   - 故事梗概与情绪基调
   - 核心成长命题（离开家/寻找名字/理解自然/拒绝战争/学会独立/与恐惧和解等）
   - 世界观规则（自然法则/魔法规则/机械规则/神灵规则，必须前后一致）
   - 多角色清单（含主角、配角、动物/精灵角色的性格、视觉特征、标志道具）
3. **视觉与声音偏好**：
   - 主色盘方案（森林生命色/天空飞行色/海浪童话色/蒸汽机械色/神隐夜灯色/自定义）
   - 是否包含飞行/蒸汽机械/神灵/战争等特殊元素
   - 背景音乐风格偏好
4. **素材提供情况**：
   - 用户是否自行提供角色/场景/机械参考图，若提供则直接绑定使用，无需重复生成

确认所有信息后，必须创建`Final_Video_Spec.md`作为全局唯一规格文件，严格按照`references/formats/final-video-spec-template.md`模板填写，后续所有步骤严格遵守该规格，不得私自更改。

## 工作流（强制暂停点规则：每个阶段完成后必须暂停等待用户确认，严禁一次性跑完所有步骤）
### 阶段1：规格确认与全局规格书生成【强制暂停】
1. 向用户确认输入诊断中列出的所有技术规格与故事核心要素
2. 若用户已提供完整剧本，完整录入`Final_Video_Spec.md`的原著故事内容字段，100%忠实原著剧情，不得删改核心事件
3. 向用户展示完整的`Final_Video_Spec.md`，确认无误后进入下一阶段

### 阶段2：故事框架与分镜脚本设计【强制暂停】
1. 若用户未提供完整故事，先与用户沟通确认故事框架、主角成长弧光、奇幻规则、核心冲突
2. 按照`references/formats/storyboard-design.md`规范，将完整剧本拆分为多个15秒shot段落，每个段落内部规划3-5个子镜头
3. 为每个段落设计明确的【前景-主体-背景】三层结构、自然运动细节、角色动作与对白
4. 建立视觉状态账本，为每个段落结尾记录终态锚点（角色位置/姿态/道具/天气/光影/情绪），确保下一段落开头3秒内完成继承
5. 向用户展示完整分镜脚本，确认无误后进入下一阶段

### 阶段3：多角色与场景设定图生成【询问并暂停】
1. 询问用户是否自行提供角色/动物/机械/场景参考图，若用户提供则暂停等待上传，收到后注册为逻辑资产并绑定到对应key_element
2. 若用户选择生成，按照`references/formats/key-element-generation.md`规范生成：
   - 角色设定图：四视角（半身特写+正面全身+侧面全身+背面全身）纯白背景手绘风格
   - 场景设定图：包含空间透视、水彩质感、自然层次、生活细节、明确光源方向
   - 机械/飞行器设定图（若有）：包含完整齿轮、螺旋桨、管道等运动结构，逻辑自洽
   - 动物/精灵设定图（若有）：包含多视角、情绪表达器官、运动方式说明
3. 展示所有设定图，等待用户确认，若有修改意见则调整后重新生成，直到满意为止

### 阶段4：角色设定视频生成与音色提取【强制暂停】
1. 分别引用每个角色的设定图，生成4-6秒角色动态视频，展示角色说话状态、面部表情、基本动作（呼吸/转头/眨眼等）
2. 提取每个角色动态视频中的音频音色，绑定为该角色专属key_element_audio，作为后续所有镜头的统一音色参考
3. 若有动物/精灵角色，提取并绑定专属音效资产
4. 向用户汇报音色提取完成，确认后进入下一阶段

### 阶段5：分段视频素材生成【逐步生成并暂停确认】
1. 按照分镜顺序逐段生成15秒shot视频，每段生成时必须：
   - 引用对应角色、场景、机械的key_element图像资产
   - 绑定对应角色的key_element_audio音色资产
   - 严格按照`references/formats/prompt-writing.md`规范编写全中文提示词，遵循Motion Stack时间线结构
   - 校验当前段落开头与上一段结尾的视觉状态账本锚点完全衔接
2. 每生成完一段视频，立即展示给用户确认，检查是否存在瞬移、表情呆板、三维塑料感、角色漂浮、机械运动错误等问题，若有问题则重制该段，直到用户确认通过后再生成下一段
3. 所有段落生成完成后，更新完整视觉状态账本，确认所有衔接无误

### 阶段6：背景音乐方向确认与生成【强制暂停】
1. 向用户推荐久石让式交响配乐乐器库：钢琴、弦乐群、小提琴、大提琴、长笛、双簧管、单簧管、圆号、竖琴、钟琴、手风琴、木琴、轻柔合唱、儿童音乐盒音色
2. 根据剧情情绪确认配乐方向：
   - 森林治愈：钢琴+长笛+弦乐铺底
   - 飞行冒险：圆号+弦乐群+木管上行旋律
   - 海浪童话：竖琴+钢片琴+轻柔木管
   - 蒸汽机械：低音弦乐+手风琴+轻打击
   - 战争阴影：低沉铜管+大提琴+稀疏鼓点
3. 生成对应风格的纯乐器背景音乐，确认与全片情绪匹配

### 阶段7：时间线合成与剪辑【强制暂停】
1. 按照`references/formats/video-assembly.md`规范，将所有15秒shot段落拼接为完整长视频
2. 导入多轨音频：角色对白、环境音效、动物/精灵音效、背景音乐、旁白（若有）
3. 完成音量微调、淡入淡出、卡点对齐，确保音乐不遮盖对白
4. 采用自然硬切或电影化转场（动作衔接/风吹遮挡/云层掠过/门开合等），严禁使用短视频花字、闪白等炫技转场
5. 按照质检清单逐项检查成片质量，若有穿帮或质感问题则打回重制对应段落
6. 展示完整成片，等待用户确认

### 阶段8：电影海报封面设计【分步确认】
1. 按照`references/formats/poster-design.md`规范，先生成16:9主封面图，展示给用户确认
2. 用户确认通过后，延展生成3:4和4:3两个比例的封面图
3. 所有封面必须为原创设计，严禁复刻任何现有动画海报或IP角色
