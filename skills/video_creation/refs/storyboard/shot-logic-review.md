# 镜头逻辑自审

用于单段 Prompt 的画面阶段自审，以及多段 storyboard 的 shot 间自审。目标是检查同一物理场景内的镜头状态是否连续、自洽、可生成；不替代 `storyboard-format.md` 的分段规则，也不替代 `prompt-craft.md` 的 Prompt 写法规范。

## 场景状态表

按时间顺序维护内部状态表，不写入最终交付内容：

| 状态项 | 检查内容 |
|--------|----------|
| 角色位置 | 角色在场景中的具体位置、与关键物件的距离、画面左/右/前/后关系 |
| 银幕侧 | 同一角色在连续镜头中的画面左侧/右侧关系 |
| 朝向 | 面朝镜头、背对镜头、侧身朝左/右、视线目标 |
| 注视轴 | 看书/看手机/读信等动作中，眼睛→目标内容面→镜头侧是否一致 |
| 对峙互视轴 | 对立双方是否真实面朝彼此；同框时近景/远端、左/右双方的绝对朝向是否相对 |
| 姿态 | 站立、坐下、跪地、倒地、倚靠、奔跑、停步等身体状态 |
| 动作结果 | 上一阶段动作是否完成，下一阶段是否承接该结果 |
| 手中道具 | 道具在谁手里、哪只手、是否交接/掉落/收起 |
| 环境锚点 | 桌边、门框、台阶、墙面、车门、柜台、石头堆等可见承接物 |
| 情绪状态 | 情绪是否有触发事件和表情递进 |
| 画面焦点 | 镜头为什么从当前主体切到下一主体，叙事焦点是否有因果 |
| 机位路径 | 运镜起点/终点、移动方向、机位高度、景别跨度是否可连续到达 |

## 必须拦截的冲突

- **位置冲突**：上一镜角色在门口、桌边、画面左侧或场景远端，下一镜没有走位或转场却出现在窗边、画面右侧或另一空间。
- **银幕方向冲突**：同一场对话、追逐、对峙中，角色左右关系无机位说明地翻转；跨轴导致 A/B 位置互换。
- **朝向冲突**：上一镜背对镜头离开，下一镜立刻正面站定；上一镜侧身朝左，下一镜无转身动作变成侧身朝右。
- **对峙互视轴冲突**：两人/两拨人对峙、拦路、谈判、战前对望时，禁止同框主要对立双方都面朝镜头，或视线平行朝同一画外方向。前后纵深必须写近景一方背对/侧背对镜头、远端一方面朝镜头；左右对峙必须写左侧侧身朝右、右侧侧身朝左，双方身体正对彼此、各自只露侧脸/半侧脸。若必须同时看清双方完整正脸，改为正反打切镜或俯拍全景，不在同一正面镜头里强行露双方面部。
- **注视轴冲突**：看书、看手机、读信、看菜单等动作中，人物持续正脸直视镜头，或书页/屏幕/纸面无剧情理由地正对镜头。先判定镜头焦点：展示内容时用侧面/过肩/俯拍看向目标；不展示内容时从目标侧拍人物和道具背面，禁止内容面朝镜头。
- **动作状态冲突**：上一镜动作已经完成，下一镜又重复同一动作；上一镜动作未完成，下一镜直接进入结果状态。
- **道具状态冲突**：上一镜右手拿杯子、剑、手机、信件等道具，下一镜没有交代却空手、换手、道具消失或凭空出现。
- **身体/环境锚点冲突**：上一镜撞到柜台、靠墙、倒在地上、抓住栏杆、跨过门槛，下一镜没有起身/松手/迈步却站在空地或换了锚点。
- **情绪跳变冲突**：上一镜平静交谈，下一镜突然崩溃、大笑或暴怒，但没有触发事件、表情递进或身体反应。
- **镜头焦点冲突**：同一场景连续镜头的叙事焦点无因果跳转，观众看不出为什么从 A 切到 B。
- **机位路径冲突**：连续运镜中，上一阶段的机位位置、镜头高度或景别已经收束到特定主体，下一阶段却无切镜、后撤、升降或转向说明地切到大范围空间、反向角度或另一主体。必须明确是切镜，或补足可连续执行的机位路径。
- **注视轴穿越冲突**：连续运镜拍摄小道具注视动作时，不得无说明地从目标内容面侧穿到人物正脸侧；若要换侧，必须明确切镜，或先让角色抬头、放下道具、转动道具后再换机位。
- **机位-景别自矛盾冲突**：同一画面阶段的机位描述内部互斥——远机位词（全景/远景/侧拍）与近机位诉求（面朝镜头/占近景大半画面/正脸口型）并存于同句。近景说话人需正脸口型时景别定中景/中近景/近景，远端角色用「画面深处身影明显偏小」带过；不得让近景主体同时挂全景侧拍。
- **阶段密度冲突**：同一阶段同时要求多个无因果关系的核心动作，或同一段里塞入多个复杂物理交互，且无法通过分阶段、降密度、中远景、遮挡、环境反馈、音效或动作结果镜头稳定执行。

## 单段 Prompt 自审

单段视频中的多个时间段、切镜和画面阶段，必须被当作同一条连续镜头链检查。

- 每个阶段开头先写清当前状态：角色位置、朝向、姿态、视线、手中道具、环境锚点。
- 后一阶段必须承接前一阶段的动作结果；禁止把动作结果提前写到阶段开头。
- 切镜不能改变物理事实。镜头从全景切到过肩、近景或特写时，角色左右关系、距离和锚点必须与全景一致。
- 运镜必须先判定为连续运动或切镜。连续运动必须写清从哪里到哪里、沿哪个方向移动、景别如何变化；大跨度景别或角度变化无法自然连续时，改为明确切镜。
- 对峙/拦路/谈判阶段先判定对立双方的互视轴：同框优先过肩或前后纵深，至少一方背对/侧背对镜头；左右同框时双方侧身方向必须相对，身体正对彼此，画面只露各自侧脸/半侧脸。只写"互相看着""望向对手"不合格。
- 小道具注视动作先判定镜头焦点是人物表情还是目标内容，再写清头脸朝向、眼睛落点、镜头所在侧和道具内容面朝向；禁止同一阶段同时写"正脸特写"和"正在看手中物"。
- 有台词的近景说话人先定景别再写朝向：需正脸口型时机位为中景/中近景/近景，禁止同句并存"全景/远景/侧拍"与"面朝镜头/占近景大半画面"；远端角色降为"画面深处身影明显偏小"。
- 如果阶段之间状态无法自然承接，优先补走位、转身、交接道具、起身、停步、环境反馈；仍无法承接时，删减次要动作或降低动作复杂度。
- 单段内不拆调用；用户给出的多个镜头只作为画面阶段组织。信息密度过高时，先删减 Agent 自产的非核心细节、降低动作复杂度或改写镜头承载方式。

## 多段 storyboard 自审

多段 storyboard 要同时检查 shot 内部阶段和相邻 shot 的状态连续性。

- 同一物理场景、同一角色连续出现时，后段开头必须具体承接前段结尾状态，不能只写"接上一段""继续刚才"。
- 前段结尾动作未完成时，不得切到下一段；要么让前段完成动作，要么把动作链合并到同一段。
- 相邻段合计不超过单段时长上限时，先判断能否通过阶段、切镜或可见转场合并为一个 shot；同场景连续段必须优先合并。
- 冲突来自跨段无状态，且合并不丢失用户硬约束时，优先合并为一个 shot。
- 必须跨段时，后段开头复述可见起始状态；需要尾帧参考时按 `storyboard-format.md` 的衔接机制处理。尾帧衔接是无法合并后的兜底，不是替代合并的理由。

## 修正优先级

1. 能通过补起始状态、走位、转身、交接道具、起身/停步、环境锚点承接解决的，直接重写 Prompt。
2. 相邻段合计不超过单段时长上限，且能通过阶段、切镜或可见转场保留用户硬约束时，优先合并为一个 shot；同场景连续段必须合并。
3. 必须跨段但同场景同角色连续时，后段开头显式承接前段结尾状态；需要尾帧参考时走衔接机制。尾帧衔接只用于无法合并后的跨段承接。
4. 机位路径无法连续时，优先明确切镜；若必须连续运镜，补足后撤/升降/平移/转向等中间路径，并降低景别跨度。
5. 对峙互视轴错误时，优先改为过肩镜头或前后纵深；需要同框看双方表情时用左右侧拍，让双方正对彼此并各自侧露半脸；需要完整正脸时用正反打切镜，或全景俯拍保留空间关系，禁止为了露双方面部让所有人面朝镜头。
6. 小道具注视动作按镜头焦点选机位：展示内容优先过肩，其次侧面/俯拍；看人物表情则只拍道具背面、边缘或反光。需要看清脸时，让角色短暂抬眼后回看目标，避免持续阅读/查看与持续直视镜头并存。
7. 复杂手部交互、吃东西、搬运、扑倒、拥抱、连续形变等高风险内容，优先改为中远景、遮挡、环境反馈、音效或动作结果镜头。
8. 禁止为了通过镜头逻辑自审删改用户确认过的台词、动作、素材用途或硬约束。
