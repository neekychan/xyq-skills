# 东亚文艺片创作

## 核心原则

不依赖"事件推进"完成叙事。真正推动影片前进的，是人物情绪在时间里的缓慢变化。每一个镜头的目标，都不是让观众理解"发生了什么"，而是让观众感受到：有什么东西，正在人物心里慢慢改变。强调的不是信息量，而是情绪停留后的余韵。

**持久引擎（因果链）：**

情绪起点 → 环境共振铺垫 → 微小行为暗示情绪位移 → 符号/物件承载时间流逝 → 声画分离承载情绪高点 → 空镜/余韵释放 → 情绪终态与起点形成回环

> 每一环都不可跳过：没有铺垫就没有高点，没有高点就不需要释放，没有释放就没有余韵。全片节奏模拟一次完整的呼吸：吸气（铺垫）→ 屏息（高点）→ 呼气（释放）。

**质量测试（可证伪）：**

> 剪掉某个镜头后，如果观众对情绪变化的感受不会断裂，则该镜头无效——它只是在传递信息，而非承载情绪。每一个保留的镜头，必须让观众"感到"什么在改变，而非"知道"什么在发生。

## 输入诊断

生产前必须明确或合理假设以下维度：

**必需输入：**
- 情绪主题（一句话描述观众最终应感受到什么情绪变化）
- 预估时长（决定是单次生成 ≤15s 还是分镜拼接）
- 画幅比例（16:9 横屏 / 9:16 竖屏 / 其他）

**可选输入：**
- 参考影像（剧照、电影截帧、摄影作品）——提取光源、色彩、景深、空间关系
- 已有视频素材——判断运镜与情绪阶段
- 文字剧本或大纲——识别情绪节点而非事件节点
- 参考音乐或音效

**素材缺失时只追问缺失项**，不要求用户一次性给全所有输入。

## 工作流

### 全片流程与阶段逻辑

以下六个阶段必须**按顺序执行**，每个阶段完成后**暂停等待用户确认**，禁止一次性连续执行完整流程。

**依赖关系：** 阶段2→1；阶段3→2；阶段4→3；阶段5→2；阶段6→3,4,5。

---

**阶段 1：确认情绪轨迹**

与用户确认影片的"情绪轨迹"，而非剧情梗概。核心不是"观众看懂发生了什么"，而是"观众能感受到什么正在慢慢变化"。

将确认结果整理为 Final_Video_Spec，包含：
- 片名
- 情绪主题（一句话）
- 时长预估
- 画幅比例
- 语言
- 视觉气质（参考导演/影片气质方向）

→ **暂停，等待用户确认。**

---

**阶段 2：分镜设计**

读取 `references/cinematography.md` 和 `references/east-asian-emotion.md`。

设计分镜结构，重点不是推进事件，而是设计情绪的停顿、留白与流动。

输出分镜文档，包含三部分：
1. **Key Elements**（角色、场景、重要物件）
2. **Shot 列表**（每个 shot 含：场景锚定、人物状态与微小动作、运镜指令、情绪方向、时长）
3. **Audio Layer**（背景音乐方向、旁白方向、环境音方向）

分镜设计规范详见 `references/cinematography.md` 的"Shot 设计规范"章节。

→ **暂停，等待用户确认整体节奏与情绪结构。**

---

**阶段 3：生成 Key Element 图像**

读取 `references/prompt-engineering.md`。

生成角色、场景、重要物件的参考图像。重点确认"气质是否对"，而不是信息量是否足够。

- 角色参考图采用横向并排构图：左侧头肩特写（面部特征、肤色、发型）+ 右侧全身（服装质感、身形轮廓）
- 场景参考图记录光源方向、时间段、生活痕迹
- 重要物件单独生成，描述其在不同情绪阶段的状态变化
- 若用户已提供参考图像，直接绑定至对应 key element，不重复生成

生成后**逐条核对** `references/quality-checklist.md`。

→ **暂停，等待用户确认视觉方向。**

---

**阶段 4：逐 Shot 生成视频**

读取 `references/cinematography.md` 的"能力边界与替代方案"和 `references/prompt-engineering.md`。

按照分镜逐 shot 生成最终视频。参考 key element 图像直接生成视频，严格遵循镜头中的情绪描述、空间关系与呼吸节奏，不以强剧情冲突作为驱动。

**视频生成方式：**
- ≤15s 的单个镜头用一次视频生成即可拿到完整片段
- 分镜中每个 shot 的时长（最短 6 秒，最长 15 秒）在一次生成内完成
- 不需要将单个 shot 拆成多次生成再拼接

**Shot 视频参考绑定规则：**
- 每个 shot 生成时，默认使用该 shot 所涉及人物和场景的 key element 图像作为参考
- 仅当当前 shot 与前一 shot 存在极强视觉连续性（如同一人物同一空间的前后续动作）时，才额外绑定前一 shot 的视频作为参考
- 通常情况下不加视频参考

**能力边界强制检查（生成前）：**
以下场景大概率导致生成失败，必须在分镜层提前替换为替代方案：
- 剧烈情绪爆发（哭泣/大喊/摔东西）→ 声画分离 / 情绪前置 / 情绪后置 / 转喻
- 快速肢体运动（奔跑/打斗/冲撞）→ 情绪前置（爆发前一秒）或情绪后置（爆发之后）
- 多人激烈互动（对峙/争执）→ 转喻（环境突变替代人物情绪）
- 单镜头内复杂场景转换 → 拆分为独立镜头，用黑场/空镜连接

替代方案详见 `references/cinematography.md` 的"能力边界与替代方案"章节。

生成后**逐条核对** `references/quality-checklist.md`。

→ **暂停，等待用户确认。**

---

**阶段 5：音频设计**

声音不只是补充画面，而是承担"情绪延续"的作用。

Audio Layer 包含三层：
1. **背景音乐**：按情绪阶段设计方向（平静日常 → 情绪积累 → 情绪高点 → 情绪释放），避免在提示词中出现知名音乐人姓名
2. **旁白**：如有，与画面情绪方向一致，优先级高于模型自动生成的同期声
3. **环境音**：优先通过视频生成时附带生成；若需独立补充，按情绪阶段设计（环境音从"满"到"空"的变化本身就是情绪语言）

音频阶段方向：

| 情绪阶段 | Audio Layer 方向 |
|---|---|
| 平静日常 | 环境音为主：鸟鸣、远处车声、钟摆、水龙头 |
| 情绪积累 | 加入单一乐器线：钢琴单音、大提琴长音 |
| 情绪高点 | 声画分离——画面给空镜/物件，音乐承载全部情绪重量 |
| 情绪释放 | 回归环境音，但比开头更"空"——风声、远处人声消失 |

→ **暂停，等待用户确认。**

---

**阶段 6：最终剪辑合成**

整体遵循"呼吸感"剪辑逻辑：留白、停顿、余韵，优先保证情绪连续性，而不是信息效率。

**镜头间过渡规则：**
- 禁止硬切；所有镜头间使用 1—2 秒黑场淡入淡出，或插入 6—8 秒环境空镜作为缓冲
- 情绪单元内部（3—4 个镜头）使用短黑场（约 1 秒）
- 情绪单元之间使用长空镜过渡（8—12 秒）或长黑场（2 秒）

**音画关系：**
- 所有音频转换使用淡入淡出，时长 1—3 秒
- 情绪高点段落：降低画面轨音量，提升音乐轨至主导地位
- 情绪释放段落：逐渐淡出音乐，环境音单独留存并轻微降音量，制造"空寂感"
- 旁白与视频自带的同期声如重叠，须在时间线上手动偏移；旁白优先级高于同期声

**慢镜头处理：**
- 慢镜头段落（原速 2—3 倍降速）需相应延长该 shot 的占位时长
- 不对同一段素材叠加超过一次降速处理

**整体节奏检查：**
- 连续超过 3 个镜头无任何音效/音乐变化时，须在第 3 个镜头结尾引入微弱音效层
- 全片结束最后一个镜头结束后，保留 2—3 秒纯黑场加音频淡出，然后进入片尾字幕（如有）

→ **暂停，等待用户确认最终成片。**

## 输出契约

### Final_Video_Spec（阶段 1 产出）

```
片名：[影片名称]
情绪主题：[一句话描述观众应感受到的情绪变化]
时长预估：[XX 分钟/秒]
画幅比例：[16:9 / 9:16 / 其他]
语言：[对白/旁白语言]
视觉气质：[参考导演/影片气质方向，如"是枝裕和的日光低对比柔和色调"]
情绪轨迹：[起点情绪] → [中段情绪位移] → [终态情绪]
```

### Storyboard（阶段 2 产出）

**Key Elements：**
```
[Element ID] | 类型（角色/场景/物件）| 描述（外貌/空间/状态）| 情绪阶段变化
```

**Shot List：**
```
[Shot ID] | 场景锚定（引用 Element ID + 光线时段 + 主光源方向）| 人物状态与微小动作 | 运镜指令（从推荐运镜中选择）| 情绪方向（铺垫/积累/高点/释放）| 时长（≥6秒）
```

**Audio Layer：**
```
[时间范围] | 情绪阶段 | 音乐方向 | 环境音方向 | 旁白（如有）
```

### Prompt（阶段 3/4 产出）

提示词一律用**英文**撰写（供模型执行），结构说明和与用户的交流用中文。

提示词结构模板：
```
[风格锚定词] + [光线条件] + [主体/人物状态] + [具体动作（微小）] + [环境细节] + [情绪方向] + [质感词] + [运镜指令]
```

具体词库与模板见 `references/prompt-engineering.md`。

## 静默自检

每次输出分镜或提示词后，必须逐条核对 `references/quality-checklist.md`。不通过则修正后重新输出，不进入下一阶段。

关键自检项（完整清单见 reference）：
- 是否存在强行制造戏剧冲突的镜头？→ 改为留白、转喻、声画分离
- 是否有角色直接进行激烈情绪表演？→ 改为空镜、环境变化、物件细节
- 所有镜头是否保留足够停留时间？→ 单镜头 ≥ 6 秒
- 镜头之间是否缺乏呼吸感？→ 加入空镜、黑场、环境音
- 情绪推进是否过于"解释性"？→ 减少说明感，增加观察感
- 东亚场景是否被拍成"猎奇化""观光化"视角？→ 回到本地人日常视角
- 提示词是否出现破坏文艺气质的直给表达？→ 删除过度戏剧化描述
- 全片是否符合"呼吸结构"：铺垫（吸气）→ 情绪停滞（屏息）→ 情绪释放（呼气）
