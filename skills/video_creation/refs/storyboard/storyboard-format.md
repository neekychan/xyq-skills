# storyboard.md 格式与验算规则

剧本（creative_design.md）确认、参考素材就绪后，将剧本拆解为镜头级分段方案并构造每段的完整 Prompt，写入 `assets/{project}/storyboard.md`。后续视频生成阶段直接按 Markdown 中的 `shot_NN` 小节逐段调用，不再做 Prompt 构造。

## 分镜原则

1. **调用次数最少化**：强相关内容必须合并为一段，景别变化、核心场景切换、情绪递进或角色阵容变化都不是天然拆段理由；能用一次调用完成的，绝不拆成两次；能用两次的，绝不拆成三次
2. **节奏紧凑**：段时长必须匹配段内有效内容量。动作段台词少时缩短段时长（动作密集 4-8s 足矣），不要用长时空镜注水。creative_design.md 中有台词的场次，对应段必须保留台词——缩短段时长来适配密度，而非砍台词
3. **切点落在动作完成后**：前段结尾已演完的动作禁止在后段开头重演，后段以前段结尾的静止状态起拍。**例外——动接动（match on action）**：前后段为同一连续动作链且后段有尾帧衔接（`⇐` 段）时，切点可落在动作进行中的自然掩护点（开门/坐下/起身/递物/转身/迈步，动作戏可用落步/挥臂过顶），后段以该动作的下一相位起拍，用运动掩盖剪切点；非 `⇐` 段一律动作完成后切
4. **参考素材驱动景别**：有四视图设定稿的角色可用特写/近景；只有单张参考图的场景用中远景更安全

### 强相关内容合并

同一段连续动作链、同一轮对话攻防、同一场情绪递进、同一物理空间关系、同一道具/接触状态连续变化，能在单段时长上限内完成时，必须优先合并为一个 `shot_NN`。用户写了多个镜头、多个时间段、多个景别，不等于需要多次生成；能用同一段内的画面阶段、切镜或可见转场表达，就合并。

合并判定按以下顺序执行：
- 总时长不超过 D_max 时，先合并为一个 `shot_NN`
- 场景、角色、情绪或动作目标变化时，先尝试用阶段、切镜、遮挡擦镜、光影、视线、声音或匹配剪辑串联
- 信息密度过高时，先简化 Agent 自产的非核心环境细节、降低复杂物理交互难度、改用中远景/遮挡/环境反馈/音效/动作结果镜头
- 合并后仍必须保留用户确认过的台词、动作、素材用途、时长和硬约束

只有以下情况才拆成多个 `shot_NN`：
- 合并后会超过 D_max
- 用户明确要求逐镜头、一步步生成或本轮只生成指定单个镜头
- 合并会丢失用户确认过的台词、动作、素材用途、时长或硬约束
- 降低密度后仍无法建立可理解的时间线、因果链或可见转场

### 跨段动作与环境锚点

跨段连续性不只看角色是否相同，还要看动作状态和物理环境是否承接。

- 前段结尾的角色位置、姿态、动作结果、视线目标、手中道具，后段开头必须具体承接；禁止让角色瞬移、反向奔跑或重复已经完成的动作
- 剧烈动作必须选定环境锚点，例如石头堆、柜台角、门框、栏杆、桌边、车门、台阶；后段承接时必须继续出现该锚点或其物理反馈
- 如果前段发生撞击、扑倒、倚靠、抓握、推门、跨入门槛等动作，后段开头要写清身体与锚点的关系，例如背部仍压在石头堆上、手仍扣住柜台边、右脚刚跨过门槛
- 禁止用"接上一段""延续刚才""继续这个动作"代替具体起始状态；每段都是独立生成，必须像全新镜头一样重新描述当前画面

### 跨场景转场与尾镜收束

核心场景切换时，禁止只写"画面切到另一个场景"。转场必须由可见动作、光影、视线或声音完成。

- 离开前场景：可在前段末尾写角色走入暗处、推门离开、镜头上摇到天空、焦点漂移到物件
- 进入新场景：可在后段开头写角色推门进入、缓缓睁眼、镜头从新场景物件移向角色；但不得写"承接上一段的停顿"
- 尾镜余韵只在末段有明确视觉收束事件（转身离去/镜头拉远/定格）时使用 0.5-1s，禁止每段都加
- 收束/余韵不单独成段：写在最后一个内容段的末尾，禁止为收束、余韵、定格新增无台词段；「情绪→镜头语言配方」的结局/定格行是末段结尾的拍法，不是独立段
- **黑场收尾禁入 Prompt**：段末禁止写"渐隐/淡出/画面入黑/画面渐暗/暗角收拢"类指令——模型会把它渲染成画面上的黑色光晕伪影。结尾写实体画面（远景/留白/定格），黑场淡出属于成片合成层，不由视频模型生成
- 一旦加入停顿、收束或转场，必须同步占用该段 Duration，不能额外透支总时长

转场类型选择（段内切镜与相邻段间通用；跨段拼接由 `render_video` 完成，默认硬切）：

| 转场类型 | 适用场景 | 时长 |
|---------|---------|------|
| 硬切 | 同场景内的景别切换，紧张节奏 | 0s |
| 遮挡擦镜 | 自然过渡，人物走过画面 | 0.5-1s |
| 渐隐/渐显 | 时间跳跃、梦境切换 | 1-2s |
| 匹配剪辑 | 两个相似构图间切换 | 0s |
| 留白过渡 | 情绪段之间的呼吸（仅用户要求舒缓或情绪高潮后确需消化时使用） | 1-2s 空镜/静止 |
| 声音桥（J-cut/L-cut） | 对白/旁白驱动的相邻段跨场景衔接 | J-cut：在前段 Prompt 最后一个画面阶段的音效 `<>` 里写入后段场景的环境声先入（如后段是雨夜，前段尾写 `<远处雨声隐约渐起>`）；L-cut：在后段 Prompt 首阶段音效 `<>` 里延续前段的尾音/环境声。只写环境声/尾音不写台词 |

**调用次数硬约束**：

`sandbox_generate_video` 单次调用的 Duration 上限记为 **D_max**（数值以 技能加载里 分流Duration 为准），范围 4-D_max 秒，这是模型硬限制，任何单段时长不得超过 D_max 秒。

总时长与最大调用次数的分档表以技能里 §1.0「调用次数最少化」为准；本文件只约束单段时长落在 4-D_max 秒。核心铁律：≤D_max 秒一律 1 次调用（零例外）；超出后按自然断点拆分——**拆分只决定段数**：以最少段数为目标，禁止把可合并内容切成大量 4-5 秒碎段。**段长按段内内容量取值，不向 D_max 看齐**：有台词段的 Duration 下界 = 台词耗时下限 + 0.5s，上界 = 耗时中值 + 1s 再加不与说话并行的独立动作时间（均不超过 D_max）；为凑满 D_max 拉长段时长 = 无声空转，不是节省调用。音频驱动段（MV，Duration 与对应音频段严格一致）与体裁 ref 明定的功能性时长（诗词句后静默、数字人 B-roll 收束、VFX 收势定格）按对应体裁 ref 取值，不适用本区间。

## 衔接机制

多段拼接时，`sandbox_generate_video` 每次调用无状态，相邻段的空间方位可能不一致。衔接机制只用于确需跨段的相邻段，不能替代可合并段的合并。对**同场景的连续段**，截取前段最后一帧作为后段的画面状态参考，帮助模型衔接空间状态。

### 判定规则

标记 `⇐NN` = 后段需要 shot_NN 的尾帧作为画面状态参考。**必须同时满足以下两个条件**：

1. **同场景**：前后两段在同一物理空间
2. **同角色**：主体角色延续（至少一个主要角色在两段间连续出现）

**不标 `⇐` 的情况**（标 `—`）：
- 跨场景（室内→户外、A 地→B 地）
- 纯空镜/转场段
- 闪回、平行叙事线

### 链深度约束

`⇐` 只能指向紧邻前一段：shotN 的衔接列只能是 `—` 或 `⇐(N-1)`，禁止跨段（`shot_03⇐01` 非法）。且不许连续两个 `⇐`——若 shotN 标了 `⇐(N-1)`，则 shot(N+1) 必须标 `—`。视频生成固定最多两轮，`⇐` 段的依赖段必须是 `—` 段。

**自检必须基于序列，禁止逐对核对**：按段号顺序抄出全片衔接列（例：`—, ⇐01, —, ⇐03, ⇐04, —`），扫描相邻两项——两项均为 `⇐` 即三级链违规。逐对单看每个 `⇐` 都合法，三级链只在序列中可见。违规修法：将后一个 `⇐` 改为 `—`，并在该段 Prompt 开头补写环境锚点与主体位置/朝向描述。

### 性能说明

每个 `⇐` 段必须等待其依赖段生成完成后才能开始（从并行变为串行）。这是空间连续性的必要代价，不构成减少标记的理由。

## storyboard.md 格式模板

```markdown
# storyboard.md

视频比例：16:9
最大分镜时长：D_max 秒

## 总览

| Shot | 场次 | Duration | 衔接 | 景别 | 核心情绪 |
|------|------|----------|------|------|---------|
| shot_01 | 1-2 | 12 | — | 中景 | 紧张 |
| shot_02 | 3 | 10 | ⇐01 | 近景 | 决绝 |
| shot_03 | 4 | 12 | — | 远景 | 苍凉 |

总时长：34s

## 通用尾注

{全片每段完全相同的约束合并写一次，视频生成时由主 Agent 原样拼接到每段 Prompt 末尾。收录范围见 prompt-craft.md「质量约束」：整体风格词、画质兜底、角色稳定、防水印/logo、禁 BGM、保持无字幕等全片逐字一致的约束。普通字幕由后期统一添加，段 Prompt 禁止写旁白字幕、台词字幕或对白字幕；只有剧情明确需要的画面内文字/特效字幕（如弹幕、手机屏幕字、招牌、术法文字、漫画拟声词）可留在段内。}

## shot_01

- ImageList:
  - assets/{project}/character_hero_sheet.png
  - assets/{project}/scene_forest.png
- VideoList: []
- AudioList:
  - assets/{project}/voice_narrator.mp3
- Prompt: |
  {完整的视频 Prompt，按 prompt-craft.md 规范构造}

## shot_02

- ImageList:
  - assets/{project}/character_hero_sheet.png
  - assets/{project}/scene_tavern.png
- VideoList: []
- AudioList: []
- Prompt: |
  {完整的视频 Prompt，按 prompt-craft.md 规范构造}

## shot_03

- ImageList:
  - assets/{project}/shot_01_lastframe.png
  - assets/{project}/character_hero_sheet.png
  - assets/{project}/scene_forest.png
- VideoList: []
- AudioList:
  - assets/{project}/voice_narrator.mp3
- Prompt: |
  @图片1 作为该次视频前的画面状态，参考@图片2的角色形象，场景参考@图片3。{后续正常 Prompt...}
```

**格式要求**：
- 必须是 Markdown 文档；每个 `shot_NN` 二级标题对应一次 `sandbox_generate_video` 调用，顺序即生成顺序
- `总览` 表列固定为：`Shot`、`场次`、`Duration`、`衔接`、`景别`、`核心情绪`，表下附总时长汇总行
- `通用尾注` 小节紧跟总览表，只写一次，收录全片每段逐字相同的质量约束（详见 `prompt-craft.md`「质量约束」的进尾注/留段内分拣）；多段视频必写，单段视频不写本节
- 每个 `shot_NN` 小节只包含 `ImageList`、`VideoList`、`AudioList`、`Prompt`
- `ImageList`、`VideoList`、`AudioList` 只写 sandbox 路径列表；空列表写 `[]`，不得写 URL，不得写素材说明文本
- `Prompt` 必须写在当前 `shot_NN` 小节内，使用 `Prompt: |` 后接缩进文本，禁止只在总览表中摘要
- **段 Prompt 不重复通用尾注**：进了 `通用尾注` 的约束一律不再写进任何 `shot_NN` 的 `Prompt`；视频生成时由主 Agent 把 `通用尾注` 原样拼到每段 Prompt 末尾。段 Prompt 禁止写旁白字幕、台词字幕或对白字幕；只有剧情明确需要的画面内文字/特效字幕（如弹幕、手机屏幕字、招牌、术法文字、漫画拟声词）写在该段 `Prompt` 内、不进尾注
- 纯画面段仍保留为独立 `shot_NN` 小节，只在 `Prompt` 中明确无台词/旁白，不单独输出总览表

## 工作流程

### 第一步：分段规划

按分镜原则将剧本场次合并为视频段，确定每段的调用级参数、素材和 Prompt。调用级参数写入 `总览` 表，素材列表和 Prompt 写入对应 `shot_NN` 小节。

### 第二步：Prompt 构造

按 `storyboard/prompt-craft.md` 规范，为每段构造完整 Prompt。Prompt 必须自包含（不依赖其他段的上下文）。全片逐字相同的质量约束（画质、风格、防水印、禁 BGM、保持无字幕等）不逐段重复，统一写入 `通用尾注`；音色跨段一致、衔接锚点、剧情明确需要的画面内文字/特效字幕等段级内容仍写在各段 Prompt 内。分拣规则与多段拼接注意事项详见 `storyboard/prompt-craft.md`「质量约束」与「多段拼接 Prompt 注意事项」。

有音色锚定音频的角色/旁白，AudioList 传入对应的 voice mp3，Prompt 中用 `@音频N` 引用音色。

### 第三步：自审

storyboard.md 写完后必须自审。机械项（段结构完整性、Duration 范围与加总、衔接序列合法性、`⇐` 段素材与开头、素材数量档位、`@` 引用越界、台词密度、尾注重复）由 `refs/tools/validate_storyboard.py` 一次裁决，禁止人肉重算脚本已覆盖的项；本节各项只保留语义判断。

**输出规则**：验算过程在内部推理中完成，**不向用户输出算式和通过项**。只输出不通过的项及其修正方案。全部通过时一句话说明即可。

**① 台词保真与纯画面段**：台词密度与字数核对由脚本裁决，**不重新调用工具或重新计算**。

**纯画面段**：段内台词+旁白字数 = 0，且 creative_design.md 对应场次也无台词/旁白。creative_design.md 中有台词的场次对应的段不是纯画面段——这说明台词被错误丢弃，必须还原。

全片验算：
- creative_design.md 中有台词的场次，对应段必须保留台词，禁止删减
- 纯画面段不超过总时长 1/3；无台词/旁白的段，段时长 > 段内独立视觉事件数 × 6 秒 → 缩短段时长或补视觉事件，禁止用静止画面填充
- creative_design.md 中无对应场次来源的纯画面段 = 违反「收束/余韵不单独成段」→ 并入相邻段末尾（0.5-1 秒）
- **疏密点名回应**：脚本 WARN 点名的低密度段必须逐段回应——段内无台词时间在 creative_design.md 有对应的用户指定动作/事件 → 保留并注明依据；无 → 缩短段时长。禁止整批默认通过

**② 镜头语言**：

每段检查：
- 用户指定景别按原文；Agent 自产景别只随主体焦点、动作结果、情绪转折或空间节点的实质变化切换——听者反应、说话方手部/道具细节、环境反馈的插入镜头属于焦点实质变化（调度模式见 `storyboard/dialogue-rules.md`「对白段镜头调度」）。无实质变化时保持连续，禁止按固定秒数轮换或为丰富而切镜
- 连续运镜的起点、终点、移动方向、机位高度和景别变化必须可连续到达；大跨度景别或角度变化无法自然连续时，必须明确切镜

逐段检查，每项不通过必须修正 Prompt：

**空间关系（≥2 人场景）**：
- 空间三要素是否齐备：景别 + 各人物相对大小（近大远小） + 人物之间的可见间隔物。缺任一项 → 模型会把所有人挤到同一平面
- 人物间距是否超出景别容量：距离 >5 步却用中景 → 换全景/远景，或分阶段交替切单人
- 每个画面阶段是否标了绝对朝向（面朝/背对/侧身朝左/右）。只写"面朝某人"= 不合格
- 对峙场景是否用过肩镜头（首选）或前后纵深（次选）
- 同框精确描述 ≤3 人，超出的降为背景/画外

**跨阶段空间一致性**：
- 同一段内切镜前后，人物的左右位置关系是否翻转（A 在画面左侧 → 切镜后跑到右侧 = 越轴）
- 从全景切到过肩/特写时，人物在画面中的方位是否与全景一致

**相邻段视觉连续性**：
- 前段结尾和后段开头的主体位置是否大幅跳动（画面左侧 → 下一段右侧 = 视线断裂）
- **角色银幕方向跨段一致**：同一角色在前段的画面侧（左/右）在后段不能翻转。逐段维护 {角色: 银幕侧} 表比对，翻轴即拦截
- 切点是否落在动作完成后（前段结尾动作未完 → 后段开头重演 = 重复）
- 衔接序列合法性（三级链/跨段/`⇐` 段素材与开头格式）由脚本裁决；本项只判**漏标**：同场景 + 同角色、前一段是 `—` 段却标了 `—` → 改为 `⇐(N-1)`
- **特效/风格措辞跨段一致**：同一角色的特效描述（颜色/形态/光效）在所有出现段逐字一致，禁止换词（"淡蓝色光纹"→"银蓝色剑光"→"蓝色残影"= 三种外观）；风格后缀在所有段逐字一致
- 前段结尾和后段开头是否复用同一环境锚点；涉及撞击、扑倒、倚靠、抓握、推门、跨入门槛时，后段是否写清身体与锚点的物理关系
- 跨场景段是否有可见动作、光影、视线或声音完成过渡；只写"切到新场景"或"承接上一段"不合格

**情绪-镜头匹配**：
- 该段核心情绪是否对应了合理的景别+运镜+节奏（对照「情绪→镜头语言配方」表——紧张段不该用缓推远景，温情段不该用快切手持）

**同角色多形象映射（存在时）**：
- 每个 shot 的角色形象必须与 creative_design.md 对应场次的 `出场形象` 一致；未标形象时使用基础形象
- 普通段的 ImageList 只传当前形象图；段内确有形象切换时才同时传切换前后两张，并在 Prompt 的对应画面阶段分别绑定（绑定句式见 `assets/character-lock.md`「多角色场景引用规则」表——用形象名标签区分，禁止用外观文字区分）
- 同一角色各形象沿用同一个角色名，默认沿用同一条音色路径；仅 creative_design.md 已记录的明确音色例外可使用例外路径。把形象拆成不同角色、擅自按形象换音色或无差别传入全部形象均不合格

**③ 台词/旁白检查**（有台词或旁白时，检查项见 `storyboard/dialogue-rules.md` 检查清单）

**④ 时长保真**：Duration 范围与加总由脚本裁决。本项只判**可合并段**：相邻段时长之和 ≤ D_max，且能通过阶段、切镜或可见转场保留用户硬约束 → 必须合并为一段（调用次数最少化）。同场景相邻段是强合并场景，不是唯一合并场景。总段数超过调用次数表上限 → 拦截

**⑤ 指令覆盖**：回溯用户原始输入，逐条扫描其中的每个具体要求——时长、比例、风格、每句台词、每个动作/场景描述、角色设定、BGM/音效/字幕需求。确认每一条在 storyboard 的某段 Prompt 或 render 参数中有对应落点。遗漏任一条 = 不合格，按类型补入对应落点后纳入本轮集中修正；普通字幕只补到后续合成参数，不补进段 Prompt。

**⑥ 字幕策略**：普通字幕不写入任何视频 Prompt。旁白字幕、台词字幕、对白字幕均由后期对整片统一添加；分镜 Prompt 只负责让模型生成声音、口型、画面动作和必要音效。即使用户要求字幕，也只在后续合成参数中处理，不得在段 Prompt 中写 `【字幕：...】`、`屏幕出现台词字幕`、`对白以字幕显示`。只有画面叙事本身需要的文字可写入 Prompt，例如弹幕、手机屏幕文字、招牌、术法文字、漫画拟声词、UI 文案、标题卡等；这类文字必须服务画面内容，不得用来复刻旁白/台词全文。

验算不通过时调整分段或 Prompt，**禁止反向修改 creative_design.md 中用户确认过的台词文案**。**自审-修正以一轮为上限**：自审一次性列全 ①-⑥ 的所有不通过项，集中修正一次；复核只核对本轮修正项本身，禁止重启全量验算、禁止引入新的修改项。

## 情绪→镜头语言配方

**适用边界**：本表只补齐用户未指定的镜头字段。creative_design.md 中用户明确给出的焦段、景别、机位、运动路径、方向、速度、焦点、轴线或时间点全部锁定，禁止用本表替换；只指定部分字段时保留已指定部分，再补齐其余字段。"电影感""有质感""运镜丰富"等抽象偏好不锁定具体镜头字段。

按 creative_design.md 各场标注的核心情绪选择未锁定的景别、运镜与切镜节奏：

| 情绪段落 | 景别配方 | 运镜 | 切镜节奏 | 视觉技巧 |
|---------|---------|------|---------|---------|
| 震惊/发现 | 大特写（瞳孔/表情） + 硬切至主观视角 | 快速推轨推至面部 | 0.5-1s 内完成切镜 | 浅景深锁面部，背景虚化 |
| 紧张/悬疑 | 特写（面部+手部交替） + 中景环境 | 手持微晃 + 缓慢推进 | 景别跳切不给喘息 | 荷兰角、暗角压迫、高对比侧光、长焦压缩空间 |
| 追逐/逃跑 | 跟拍中景 + 甩摇切视角 + 低角度仰拍 | 手持跟拍 + 甩摇 | 极快切（2-3s 换一次视角） | 晃动感、广角+运动模糊、呼吸声叠加 |
| 对峙/冲突 | 正反打特写（两人交替） + 过肩镜头 | 固定或微推，爆发瞬间带冲击震颤 | 台词卡点切（说完一句切） | 180°轴线严守，空间关系不跳 |
| 温情/回忆 | 中景→缓推至近景 | 缓慢推轨或横移，平稳无晃 | 长镜头（5-8s 不切） | 柔光、暖色温、浅景深 |
| 愤怒/爆发 | 中景→快推至大特写 | 急速推轨，带手持冲击晃动 | 1 次猛切定住 | 硬光、高对比、环境音骤停 |
| 孤独/沉思 | 大远景（人物渺小） + 固定机位 | 固定或极慢后拉 | 不切，持续5s+ | 大量留白、环境音放大 |
| 结局/定格 | 缓慢后拉从近景至远景 | 升降后拉，平稳收稳 | 渐慢至静止 | 画面逐渐留白，远景收束 |

**跨档渐变**：同一段内情绪跨行（如爆→收、紧张→释然）时，各画面阶段的运镜与光影按当时情绪对应行取质感，并写出渐变过程——运镜晃动明显→漂移减弱→平稳收稳，光影随转折点变化（灯亮/云移/光束进入/色温转冷暖）；禁止情绪已转折而镜头质感与光线全段不变。

## 旁白分配策略

| 段落类型 | 旁白处理 | 说明 |
|---------|---------|------|
| 开场建置 | 旁白主导，介绍世界观和角色 | 画面信息不足时用语言快速建立情境 |
| 角色互动/对话 | 角色台词为主，旁白暂停 | 旁白和台词同时会打架 |
| 动作/追逐段 | 旁白暂停或仅一句短评 | 让动作和音效说话 |
| 情感高潮 | 旁白暂停 2-3 秒后再说点睛之语 | 给观众消化情绪的时间 |
| 结尾余韵 | 旁白给出总结或留白 | 提炼主题或留下悬念 |
| 空镜/转场 | 可标记"纯画面" | 纯画面段不超过总时长 1/3 |
