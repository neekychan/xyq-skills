加载时机见 SKILL.md Ref 总表：模式 A 展示候选前必读；色卡确认后、进垂类前必读一次。以下是**设计原则 + 可变维度**，不是固定模板——每次从维度里重新组合，不要每次都产出同一个方案。玩法确定后仍走 `palette-usage.md` 的转写规范；涉及图/视频制作时必须加载对应创作 skill（**仅当 `<available_skills>` 列表中存在**——不存在时玩法只作为建议交付，制作走 §一.3 停机）。

## 玩法 A：色卡盲盒（随机色卡 → 命题创作）

**核心趣味**：把随机色卡当"命题"，先抽卡后创作。**色卡的诗意标题是第一交付物**——抽卡要像开盲盒抽到一句诗，而不是抽到一组色值。

- 展示候选时的解读格式以 SKILL.md 步骤 2 的四要素为唯一定义（《标题》＋气质解读＋词库色名＋适合什么片），本文件不另行定义。
- 用户选定后，以标题为题眼反推创意：标题直接当片名 / 标题当情绪关键词 / 让用户先许愿一个主题再抽卡看"缘分"。
- 模式 B 同样受益：提取完成后主动把标题推到台前——「这组图提炼出来叫《XX》，要不要就照这个题眼拍？」把标题从装饰字段升级为**创作入口**。
- 适合：用户没想法、想要灵感起点时。这是模式 A 的默认延伸玩法。

## 玩法 B：色卡叙事（一张色卡贯穿一支片）

**核心趣味**：整支片的画面严格活在一张色卡里，形成强烈的"作者感/胶片感"。

- 流程：确定色卡 → 垂类流程每段生成都带色卡 → **`render_video` 时把分享卡 `card_*.png` 作为最后一个素材拼进成片**（定格 1~1.5s 片尾色卡，即 SKILL.md「交付收口」第 1 条）——成片自带"这支片的配方"，标题真正出现在画面里。
- 可变维度：全片单色卡 / 上下半场双色卡（情绪转折点换色，如冷调转暖调表达救赎）/ 主角色与环境分属色卡的主色与辅色。
- 适合：剧情短片、氛围片、品牌感内容。双色卡变体是情绪叙事的强杠杆。

## 玩法 C：色卡巡游（Color Walk / 一色一景）

**核心趣味**：把色卡的每一格颜色展开成一个场景/一站，颜色本身是叙事线索。参考线上热点「用 JK 打开大西北色卡」（多场景 + 统一动作 + 服饰颜色递进）与城市 Color Walk（把一座城拆成专属色谱）。

- 结构：N 格色卡 → N 个镜头/场景，每段画面以对应格的颜色为绝对主导，转场时下一格颜色先以小物件入画再铺满。
- 可变维度：
  - 载体：城市地标 / 一条街的店铺 / 四季 / 一日时辰（晨昏昼夜）/ 穿搭（每站换该色系服装）/ 美食。
  - 统一元素（必选其一做"锚"）：同一主角同一动作重复 / 同一构图机位 / 同一句台词变奏——颜色在变，锚不变，节奏感才成立。
  - 节奏：卡点快切（每段 1.5~3s，需配快节奏 BGM）/ 慢巡游（每段 4~6s，治愈向）。
- 适合：旅行、城市宣传、穿搭、萌宠多场景 vlog。**此玩法色卡格数 = 分段数**，向用户确认时注明每格对应的场景。

## 玩法 D：色卡复刻（提取致敬对象的色系）

**核心趣味**：从用户喜欢的电影截图/摄影作品/往期视频里提取色卡，让新片"长在同一套颜色里"。**用户说"续集/系列/跟某片保持一致"就是本玩法**。

- 流程：用户上传截图或视频 → 模式 B 提取 → 展示"你喜欢的其实是这套颜色" → 确认 → 新内容全程沿用。
- 可变维度：致敬电影调色 / 延续自己往期爆款的视觉记忆 / 品牌视觉规范落地（主色范围 + 禁用色向用户确认后在移交垂类时一并写清）。
- 适合：系列化创作者、品牌内容、想要"某部电影那味儿"的用户。提取多张截图比单张更稳。

## 玩法 E：色卡对比实验（同内容双色卡）

**核心趣味**：同一创意用两张对比色卡各出一版（如暖调朝阳版 vs 冷调夜雨版），直观看到颜色如何改变情绪。

- 流程：确定创意 → 抽/选两张气质相反的色卡 → 同一 Prompt 骨架只换色卡参考图，各生成一版 → 并排展示让用户选定稿。
- 成本提示：生成量翻倍，先和用户确认；适合单段短内容（≤15s），不适合多段长片。**只在用户先开口要对比时提**，不主动推销。

## 玩法 F：孤色主体（Color Isolation）

**核心趣味**：环境严格活在色卡里，主体是画面中唯一"不服管"的颜色，天然成为视觉焦点——「唯一的暖橘活在冷玫瑰夜色里」，自带电影感。

- 流程：确认色卡 → 比对主体固有色与色板色相（`palette-usage.md` §三）→ **色相冲突正是本玩法的燃料**（暖橘主体 × 冷调色卡最出效果）→ Prompt 里色系定义句只约束环境（定义句照写，主体加豁免句），主体加固有色豁免句（写法与 `palette-usage.md` §三共用）。
- 可变维度：主体全程孤色 / 情绪转折时主体被环境色吞没（表达融入或失去自我）/ 主体色随剧情逐渐向色卡靠拢。
- 适合：萌宠（固有毛色）、单人叙事、品牌产品出镜。主体固有色与色卡冲突时，优先把这个"缺陷"转成本玩法卖点。

## 提议玩法时的原则

1. **最多提 2 个候选玩法**，两个候选必须来自不同玩法族且成片形态差异明显。按用户素材与意图选最贴的：有上传素材优先 D，多场景意图优先 C，没想法优先 A，主体固有色与色卡冲突优先 F。
2. **每个候选必须写成四行**，禁止照抄本文件原文压缩了事：
   - ① 一句钩子；
   - ② 具体到能想象画面的例子（**自造，禁止复用本文件的举例**）；
   - ③ 从该玩法可变维度里已替用户选定的 1~2 个组合（如 C 必须点名锚元素 + 节奏）；
   - ④ 成片长什么样一句话（段数、时长、节奏感）。
3. 玩法只改变**创意结构**，不豁免任何规则：三步转写、垂类 skill 加载、垂类红线全部照常。
4. 玩法 C/E 这类多段/多版本结构，向用户说明段数与时长预算后再动手。
