# 故事结构与分镜规范

## 故事流程拆解原则
收到用户主题后，先拆解为4-6个关键叙事环节，形成完整情感弧光，再分配镜头：
- 环节数量：精简版60s建议4个环节，标准版90s建议5-6个环节，不得少于4个
- 每个环节对应一个叙事功能节点，标准结构参考：
  - **建立世界** → **触发事件** → **情节推进** → **情感高潮** → **余韵收尾**
  - 节日主题参考：准备材料 → 制作礼物 → 等待相遇 → 赠送惊喜 → 温暖余韵
  - 日常主题参考：平凡日常 → 发现小美好 → 互动分享 → 治愈瞬间 → 温柔收尾
- 每个环节必须包含：核心场景、参与角色、关键动作/道具、情绪基调
- 环节之间逻辑连贯、情绪递进，禁止无因果跳跃

## 关键元素规划规范
### 角色元素
- 每位主要角色建立独立元素：正面全身参考图（清晰展示造型、服装、发型、肤色）+ 至少1张表情/动作变体图
- 角色符合「微缩人偶」美学：比例略Q版，材质细腻（布料纹理、皮肤哑光质感），与模型场景自然融合
- 第二位及之后的角色生成时，必须以第一张角色图为风格参考，保证整体画风统一

### 场景元素
- 每个主要场景建立独立元素：全景参考图（展示空间结构、光线氛围、道具摆放）
- 可根据剧情设置白天/夜晚、晴天/雨天等光线变体
- 场景细节要丰富：微缩街道要有小路灯、小招牌、迷你植物；室内场景要有迷你家具、小摆件，增强真实感

### 道具元素
- 有叙事功能的核心道具（信件、花束、小礼物、杯子等）单独建立元素，保证跨镜头一致性
- 道具尺寸必须符合微缩比例：大于人偶的道具要明确尺寸对比，操作时需要多人合力

## 分镜设计规范
### 时长节奏
- 单镜头建议时长：普通叙事镜头4s-6s，情感高潮/特写镜头6s-8s，余韵收尾镜头8s-10s
- 60s精简版：10-12个镜头，平均单镜头5-6s
- 90s标准版：14-18个镜头，平均单镜头5-7s
- 禁止单镜头超过10s，避免节奏拖沓

### 景别与运镜
- 开场：大远景或俯瞰全景，建立微缩世界空间感，强化移轴效果
- 叙事推进：中景为主，展示角色互动与动作流程
- 情感表达：面部近景或道具特写，捕捉细节情绪（如人偶的眼神、手部小动作、道具细节）
- 运镜克制：以缓慢推拉、轻微横摇、慢跟随为主，镜头运动速度平缓
- 禁止快速推拉、剧烈晃动、快速剪辑，避免破坏温柔治愈氛围

### 叙事结构
严格遵循四段式结构：
1. **开篇（10%-15%时长）**：建立世界，展示微缩场景全貌，交代环境与主角日常状态
2. **展开（40%-50%时长）**：触发事件发生，角色开始行动，情节逐步推进
3. **高潮（20%-25%时长）**：情感爆发点，核心互动/惊喜/治愈瞬间，用特写镜头强化
4. **收尾（15%-20%时长）**：情绪回落，展示结果与余韵，全景或空镜收尾，留足留白

### 跨镜一致性强制规则
- **尺寸规则**：凡远大于单个人偶的道具（咖啡杯、信封、花盆等），必须描述为"多人合力"完成操作，禁止单人轻松使用大型道具，避免比例失调
- **主体规则**：每个动作必须明确执行主体（哪位角色/两人一同），禁止使用"有人""某人"等模糊表达
- **写实规则**：禁止出现发光道具、悬浮物体、骑乘虫类等破坏微缩写实感的内容
- **一致性规则**：同一角色的服装、发型、道具状态在所有分镜中保持一致；场景内固定道具位置不得无故移位

## 音频层设计规范
### BGM
- 1-2条BGM轨道（开场轻柔，高潮可稍加强度，收尾回归平缓）
- 风格：钢琴独奏/钢琴+弦乐，轻柔温暖，无人声，节奏舒缓
- 时长覆盖整片，前2s渐入，后2s渐出，避免突兀开始/结束

### 旁白（可选）
- 分镜设计阶段标注旁白文本对应的镜头ID
- 语气：温柔叙事，短句为主，适当留白，避免过于密集
- 风格参考：「那一天，阳光把整个小镇都染成了金色。他站在门口，等了很久。」
- 旁白音频必须在视频生成前完成，作为音频条件输入驱动口型同步

### 音效
- 保留轻柔环境音：风声、雨声、脚步声、轻碰道具的声音，音量低于BGM
- 禁止嘈杂、尖锐的音效，保持整体氛围安静治愈
