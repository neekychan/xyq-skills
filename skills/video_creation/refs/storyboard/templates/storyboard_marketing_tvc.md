# 分镜图模板：营销转化 · 广告 TVC 镜头表

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以广告片结构为骨架，按镜号逐镜写出景别/机位/运镜/时长/画面内容/卖点/旁白的**TVC 镜头表**，用于品牌广告、产品宣传片等高规格营销视频。
- **典型场景**：
  - 品牌 TVC、形象广告、上新大片。
  - 线下大屏/电梯广告/影院广告脚本。
  - 电商大促节日主题广告、品牌故事片。

## 2. 判定关键词与适用边界
- 典型触发词：`TVC`、`广告片`、`广告镜头表`、`品牌广告`、`广告脚本`、`片头片尾`、`镜头语言`、`导演分镜`。
- 适用判定：
  - 用户目标是“做一支完整广告片”，并关心**镜头节奏 + 品牌画面 + 卖点节奏**。
  - 需要交付给导演/制片/投放团队使用，镜头信息必须结构化清晰。
- 不适用场景：
  - 仅需要电商九宫格商品展示 → 优先用“产品讲解型”模板。
  - 只有简单卖点列表，无需镜头参数 → 可用基础“产品讲解分镜图”。

## 3. 结构与字段建议
- **推荐镜头数**：8–20 镜，时长常见为 15/30/60 秒。
- 每镜推荐字段：
  - 镜号：C1、C2、…
  - 时间轴：起止时间（如 0–2s、2–4s）。
  - 景别：远景/全景/中景/近景/特写。
  - 机位/运镜：俯拍/仰拍/平视 + 推/拉/摇/移/跟/固定等。
  - 画面内容：主体、动作、场景、道具。
  - 产品卖点：本镜突出哪一个卖点或信息。
  - 旁白/台词：画面对应的文案/口播。
  - 音效/音乐：节奏变化、卡点说明。

## 4. 生图 Prompt（PE）模板

```text
你是一名广告导演兼分镜师，请为下述 {产品/品牌} 设计一份广告 TVC 镜头表（含分镜图），整体画幅为 {画幅比例说明，如“16:9 横版广告片”或“9:16 竖屏信息流广告”}。

【项目信息】
- 品牌/产品：{品牌名 + 产品名}
- 广告时长：{15/30/60} 秒
- 广告目标：{如“建立品牌记忆/突出核心卖点/促成交/拉新”等}
- 目标人群：{如“都市白领/年轻妈妈/学生党”等}

【整体风格】
- 视觉风格：{如“写实电影感/高级棚拍/2.5D 商业插画/3D 产品大片”等}
- 色调与氛围：{如“明亮清爽/高对比科技感/温暖生活化”等}

【输出要求】
- 先按广告结构给出分段：开场引入 → 痛点呈现 → 卖点展开 → 体验/对比 → 品牌收束；
- 推荐镜头数：{镜头数，如 10–16 镜}，编号 C1–C{N}；
- 为每个镜头输出：
  - 时间轴：{起止秒数}
  - 景别：{远景/全景/中景/近景/特写}
  - 机位/运镜：{如“平视+固定”“低机位推近”“航拍俯视跟拍”等}
  - 画面内容：{人物/产品/场景/关键动作}
  - 产品卖点：{对应的优势点或信息}
  - 旁白/台词：{对应台词/旁白，没有则写“无”}
  - 音效/配乐：{如“环境声+轻快背景音乐，在 8 秒处卡点切镜”}

【可选：分镜图生成】
- 若需图像分镜图，请按镜头表生成对应单格分镜（1 镜 1 图或多镜拼接板），用于后续参考图生视频。
```

## 5. 一致性与避坑
- 广告结构要清晰：**不要把卖点和痛点混在一起**，避免观众看不出节奏。
- 产品外观、Logo、包装在不同镜头中必须一致，避免型号/颜色前后不一。
- 注意字幕/价格/口播文字的可读性，给 UI/文字预留足够空间。
- 景别与运镜安排要服务卖点，而不是抢戏：卖点重点段落多用近景/特写，弱化无关花哨运镜。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”“影视导演镜头表”两类执行模板：
  - 当已有 TVC 镜头表时，可直接作为视频 Prompt 的文字骨架，再补充少量分镜图参考；
  - 当还没有镜头表时，可先用“产品讲解分镜图”生成多宫格分镜，再用本模板升格为带镜头参数的 TVC 表。
- 视频阶段优先使用“参考图生视频”：
  - 对关键镜头（开场 Logo、主卖点、大收尾）从分镜图中选取参考帧锁定构图；
  - 按镜头表的时间轴与景别/运镜描述写视频 Prompt，保持节奏与信息顺序一致。
