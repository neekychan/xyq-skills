# 竖屏运镜规则

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 竖屏检测触发条件

满足以下任一即启用竖屏规则：
- 用户提及"竖屏"/"抖音"/"Reels"/"9:16"/"短视频平台"
- 参考图高 > 宽（竖向构图）

未明确说明时默认 16:9 横屏。

## 竖屏运镜原则

竖屏（9:16）与横屏（16:9）的核心差异在于**纵向空间的表达优先级**：

1. **纵向运动优先**：拉升/俯冲/螺旋在竖屏中更有冲击力，因为纵向空间更充裕
2. **水平穿越受限**：宽幅穿越（如沿建筑长边飞行）在竖屏中表现不佳，需缩短水平距离或转为对角穿越
3. **上下构图引导**：穿越结构时优先选择上下排列的入口（如门洞→上方窗户），而非左右排列

## 竖屏适配规则

### 风格适配
| 横屏风格 | 竖屏适配 |
|---|---|
| 低空贴地（水平前飞） | 保留贴地，但增加纵向起伏（地面→跃起→落地） |
| 高空俯冲 | 增强俯冲深度，竖屏纵向空间天然适合大落差 |
| 螺旋环绕 | 收窄螺旋半径（横屏 5m → 竖屏 2-3m），主体占据更多画面 |
| 急速穿梭 | 缩短水平穿越距离，增加纵向穿越（如从上方穿桥洞→下方穿路面） |

### 穿越结构适配
- 横屏"穿宽门" → 竖屏"穿高门"（优先选择高窄结构）
- 横屏"沿走廊飞" → 竖屏"沿楼梯飞"（纵向替代水平）
- 横屏"穿建筑间缝隙" → 竖屏"穿楼层层间缝隙"

### 速度节奏
- 竖屏中加速/减速的感知更强（纵向运动更直观）
- 可适当增加速度变化频率
- 竖屏穿越的"压迫→释放"感更强烈

## prompt 竖屏标记

竖屏模式下在 prompt 中加入画幅提示：
- `vertical 9:16 aspect ratio, FPV portrait orientation`
- `emphasizing vertical depth and height changes`
