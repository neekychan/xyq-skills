# UI设计与像素锚定规范

## UI元素清单（全链路必须包含）
所有游戏Demo必须生成以下UI界面，保持视觉风格100%统一：
1. **开始界面**：游戏Logo、[Start]按钮、设置/退出按钮，背景为游戏主视觉图
2. **选人界面**：角色立绘展示区、职业选择标签、技能预览栏、[确认选择]按钮
3. **加载界面**：加载进度条、提示文字、背景为场景概念图
4. **对话UI**：NPC头像框、对话文字区、[继续]提示，底部半透明黑底
5. **战斗HUD**：
   - 左上角：玩家血条、蓝条、等级标识
   - 右上角：小地图、任务追踪栏
   - 底部中间：技能栏（4-6个技能图标+快捷键提示）、普通攻击按钮
   - 底部左右：道具快捷栏
6. **结算界面**：Victory标题、奖励图标、经验值条、[继续]按钮

## 像素锚定硬规则
所有带HUD的截图生成后，必须精确记录以下UI元素的像素位置，标记为「视频生成禁止形变区」：
- 血条/蓝条：左上角固定位置，宽度、高度、坐标精确到像素
- 技能栏：底部居中位置，每个技能图标的精确坐标
- 对话框：底部固定区域，文字显示范围精确坐标
- 小地图：右上角固定位置，尺寸精确
- 所有按钮：交互热区精确坐标

视频生成时，上述区域必须保持：
✅ 位置绝对固定，无任何位移
✅ 尺寸大小不变，无缩放变形
✅ 元素清晰锐利，无模糊、无伪影、无AI生成扭曲
✅ 动态变化仅允许：血条长度增减、技能CD灰化、文字逐字显示、按钮点击高亮反馈

## 色彩一致性规范
1. 第一张UI图生成后，立即提取全局色彩LUT（查找表），记录主色调、辅助色、强调色色值
2. 所有后续UI图、场景图、视频必须统一应用该LUT，确保三段视频从开始到结束色调、亮度、对比度完全一致
3. 禁止出现段落间偏色、色温漂移、饱和度突变
4. UI元素颜色固定：血条红色、蓝条蓝色、技能CD灰色、高亮反馈白色描边
