# 三组六格分镜板结构 / Storyboard Structure

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 全片结构概览

| 分镜组 | 时间段 | 主题 | 视觉基调 | 格数 |
|---|---|---|---|---|
| Section A | 0–15s | 植物信息展示 | 纯白/极浅灰底，信息图风格 | 6 格 |
| Section B | 15–30s | 植物种植过程 | 写实自然绿棕，纪录片美学 | 6 格 |
| Section C | 30–45s | 植物功效与使用场景 | 生活中性明亮，人文质感 | 6 格 |

每组每格约 2.5 秒，全片共 18 格。

---

## Section A：植物信息展示（0–15s）

> 整体视觉基调：纯白或极浅灰底，植物主体居中，简洁清爽的信息图（infographic）风格；内容直接源自 Plant_Asset_01 的分析结果，科普优先，无叙事戏剧性。

### 六格内容

| Grid | 内容 | 视觉描述 |
|---|---|---|
| A1 | 植物登场 | 纯白底，植物完整形态居中渐显，学名与中文俗名以优雅无衬线字体从底部浮现，极简动效 |
| A2 | 形态解构 | 白底，叶片/花序/果实局部放大呈现，细线条指示箭头标注各器官名称，干净精准 |
| A3 | 产地分布 | 白底叠加极简地图轮廓，原产地区域高亮，配合产地名称与气候标签卡片动态出现 |
| A4 | 生长条件 | 白底，以简洁图标组合呈现生长所需条件——温度区间、光照强度、土壤类型、适宜海拔 |
| A5 | 核心成分 | 白底，关键活性成分或营养元素名称以浮动标签形式逐一显现，可叠加简化分子式或结构示意 |
| A6 | 生命周期概览 | 白底，简洁横向生命周期序列图动态展开（播种→萌发→生长→开花→结果），为 Section B 做衔接铺垫 |

### 旁白台词框架

报出学名与别称 → 描述核心形态特征与产地 → 点明生长习性与主要成分 → 简要预告生命旅程

---

## Section B：植物种植过程（15–30s）

> 整体视觉基调：写实科学纪录片美学，自然田园色调（自然绿与泥土暖棕为主色，占比 ≥ 90%）；植物主体清晰、背景虚化，强透视与景深节奏。

### 六格内容

| Grid | 内容 | 视觉描述 |
|---|---|---|
| B1 | 播种入土 | ECU 超特写，lock-off。种子落入湿润、松散泥土颗粒中的微观瞬间 |
| B2 | 破土萌发 | 微时差（Time-lapse），低角度仰拍。种皮裂开，根系下扎，嫩芽顶开土粒破土而出 |
| B3 | 茎叶抽生 | 中景 Time-lapse，光影飞速位移。茎秆逐节抽高，复叶如扇面般规律向外展舒 |
| B4 | 田间灌溉 | 手持纪实，急速推拉变焦。晶莹水雾喷洒在叶片表面，形成完美表面张力的水珠 |
| B5 | 人工剪护 | 中景。剪刀进行精确修剪或工匠施肥，展现人工对自然规律的精确引导 |
| B6 | 穗头收获 | 特写，慢速推轨。果实/穗头重量增加，随重力下垂，呈现饱满的收获状态 |

### 旁白台词框架

描述种植条件 → 呈现生长过程关键节点 → 点明人工干预的意义

---

## Section C：植物功效与使用场景（30–45s）

> 整体视觉基调：写实纪录片延续，色调过渡至生活中性明亮；温暖天光，人文质感。

### 六格内容

| Grid | 内容 | 视觉描述 |
|---|---|---|
| C1 | 古法采摘 | 手持纪实中景。双手精准利落地割下或采摘成熟植物器官的动作细节 |
| C2 | 工艺粗加 | 稳定特写。植物在石磨、切刀或晾晒场下的物理初加工，表现材质的碎裂 |
| C3 | 微观质感转化 | ECU 极度特写。植物细胞壁破裂，原汁液飞溅或纤维交织重组的微米级形变 |
| C4 | 终态产品呈现 | 生活化中景，自然柔和光。植物转化为餐桌美食、服装纤维、药材或建材 |
| C5 | 日常人文应用 | 宽景，温暖天光。人们在家庭、医疗或社会日常中使用该衍生产品的温情画面 |
| C6 | 文明美学收束 | 极平稳的轨道退行，景深虚化。成品在光影下定格，收束全片人文情绪 |

### 旁白台词框架

列举核心功效与用途 → 串联加工到应用的转化链 → 升华植物与人类文明的关系

---

## 旁白 VO 台词撰写规范

- **语言风格**：深沉磁性的纪录片解说腔——语速平稳、信息密度高、情感克制有力量感；避免口语化和广告腔
- **绑定规则**：台词与 Grid 编号严格绑定，每格对应约 2.5 秒台词量
- **叙事弧**：三组台词在叙事逻辑上首尾相连——Section A 预告生命旅程 → Section B 呈现生命旅程 → Section C 升华人文意义
- **合规约束**：涉及药用功效时以"传统用途"措辞表述，不做医疗效果断言

## 视觉焦点轴线对齐（Eye Tracing）

强制标注 2×3 矩阵中 18 个镜头的中心坐标 (X, Y)。前一个镜头的尾帧视觉重心必须与后一个镜头的首帧实现动量守恒，确保 45 秒全片在每组 6 镜头的高频推进下依然保持纪录片级的极度流畅，消除由于频繁切镜带来的跳跃感。

详细规范见 `references/craft/color-arc-eye-tracing.md`。
