# 日本昭和动漫风（Showa Urban Anime Style）

## 这个 Skill 是做什么的

这是一个**风格锚定滤镜类 Skill**。它的唯一目标：让用户在一次视频创作中产出的**所有图片素材资产**和**所有视频片段**，都稳定统一地呈现同一套「昭和末期日本都市动漫风」质感。

实现方式极其简单也极其严格：**把一段固定的风格锚定词，一字不改地放在每一条图片 prompt 和每一条视频 prompt 的最开头**,然后再接该镜头 / 该素材的具体画面描述。

> 这段锚定词是这个 Skill 的「宪法」。它决定了成片的画风一致性。无论 Agent 在生成分镜脚本、角色设定、场景描述还是逐条 prompt，都必须遵守下面的规则。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 一、核心规则：风格锚定词（最高优先级）

### 1.1 固定锚定词（禁止改写、删减、翻译、重排）

在生成**任何一张图片素材**或**任何一段视频**的 prompt 时，prompt 的**最开头**必须原封不动地加上下面这段锚定词，然后紧跟一个句号或换行，再写具体画面内容：

```
昭和末期日本都市动漫风，成人向动画、OVA 黄金时代，复古胶片印刷质感，1980—1990 年代复古日系赛璐璐动画质感。低饱和但高风格浓度的 80 年代都市动画配色，细腻噪点，旧印刷网点感，柔化滤镜硬朗、棱角分明的面部结构。色彩上以黑、墨蓝、酒红、棕金与冷灰蓝为主，整体低饱和、压暗，光影采用硬边块面分区，带有手绘赛璐珞时代特有的明暗处理。整体还覆盖着旧印刷网点、纸张颗粒、轻微褪色与 VHS 年代扫描感，使画面兼具动画、插画、杂志封面与老海报的复合质感，散发出一种霓虹都市、成人浪漫、神秘危险的独特魅力。
```

**硬性要求：**

- **位置**：锚定词永远在 prompt 最前面,不可后置、不可插在中间。
- **完整性**：必须逐字完整,不得摘要、删句、改写措辞或翻译成英文。若目标模型只接受英文,可在锚定词后附一份英文补充版,但**中文锚定词原文必须保留在最前**。
- **每一条都要加**:不是只在第一张图加,而是**每一张图片素材、每一段视频**都要加。这是保证一致性的唯一手段。
- **拼接格式**：`[锚定词] + 。 + [本镜头/本素材的具体画面描述]`。

### 1.2 正确示例

图片素材 prompt:
```
昭和末期日本都市动漫风，成人向动画、OVA 黄金时代，……散发出一种霓虹都市、成人浪漫、神秘危险的独特魅力。深夜写字楼天台，一名穿宽肩风衣的成熟男性背对城市霓虹独立，低头点烟，冷灰蓝夜色，硬边块面光影，海报式竖构图特写。
```

视频片段 prompt:
```
昭和末期日本都市动漫风，成人向动画、OVA 黄金时代，……散发出一种霓虹都市、成人浪漫、神秘危险的独特魅力。镜头从女主角酒红礼服的背影缓慢推近到侧脸,她抬眸凝视窗外雨夜霓虹,发丝轻动,慢速运镜,轻微 VHS 扫描抖动。
```

### 1.3 反面示例(禁止)

- ❌ 把锚定词删成一句「昭和复古风」——丧失一致性。
- ❌ 只在开头素材加锚定词,后面的镜头省略——画风会漂移。
- ❌ 把锚定词翻译成英文后丢掉中文原文——措辞漂移导致风格不稳。
- ❌ 把锚定词放到画面描述后面——权重被稀释。

## 二、与其他「风格类 Skill」搭配时的合并规则

当本 Skill 与其它**同类风格锚定 Skill**（如另一套复古 DV 风、国漫 3D 渲染风等）同时被调用时:

1. **锚定词内容合并,规则不变**:将两套风格 Skill 的锚定词**拼接**成一段,仍然整体放在每条 prompt 的最开头,后接具体画面描述。
2. **合并顺序**:以用户当次更强调 / 更晚指定的风格为主导放在前,另一套紧随其后;若用户未指明主次,按被调用顺序拼接。
3. **冲突时的处理**:两套锚定词若在某一维度直接矛盾（例如一套要求高饱和、一套要求低饱和）,以本 Skill 的描述为准保留低饱和,矛盾项择一,不做互相删改之外的改写。
4. **合并后仍是「一字不改地整体前置 + 每条都加」**:合并不改变第一章的所有硬性要求。

## 三、风格知识库（供 Agent 写分镜 / 角色 / 场景 / 脚本时参考）

> 下面这些不是要塞进 prompt 的模板句,而是让 Agent 在**构思故事、设计角色、编排分镜、描述场景光影**时,能主动往这套美学靠拢的知识。生成的一切文字描述都应在气质上贴合以下特征。

### 3.1 整体风格气质

- **关键词**：冷艳、成熟、都会、危险、疏离、欲言又止、成人浪漫。
- **叙事底色**：不是青春热血,而是深夜都市里的男女关系、秘密、交易、欲望与背叛;霓虹背后的孤独;高级场所中的静默对峙;爱情与危险交织的成人戏剧。
- **情绪密度**：人物看似克制,但情绪浓度极高——张力靠眼神、距离、沉默传达,而非夸张动作。

### 3.2 色彩系统

- **主色**：黑、墨蓝、酒红 / 铁锈红 / 暗玫瑰红、棕金、冷灰蓝。
- **配色逻辑**：整体压暗、低饱和;局部提亮脸部、唇色、眼神、耳饰、霓虹光点;背景常压黑以衬托肤色与服饰。
- **经典组合**：红与黑（酒红西装 / 礼服 + 黑发 + 黑背景 + 冷白皮肤）= 昭和成人戏剧的标志性色彩关系。
- **禁忌**：避免糖水系高亮清透、避免高饱和紫蓝粉赛博感、避免明亮少女红。

### 3.3 光影处理

- **硬边块面**：脸部阴影是明确的大块面（鼻梁、眼窝、脸颊呈几何切面式暗部）,2—3 阶明暗分层,而非柔和渐变。
- **高光节制**：头发是少量、偏干的笔触式反光,不是玻璃丝带式高亮;眼睛是冷静克制的点状反射。
- **混合光源**：夜景 + 室内暖光交错,常带城市灯光 / 霓虹 / 车窗倒影,营造深夜都会、酒店走廊、会所外立面般的氛围。

### 3.4 角色造型

- **面部**：脸型修长削薄、骨相分明,下颌利落,颧骨鼻梁转折明确;鼻子高挺窄长、折线感强;嘴唇薄而轮廓锐利、口红存在感强。
- **眼睛**：眼型狭长、外眼角上挑;睫毛锋利干净如眼线;瞳色偏浅（灰蓝绿）带玻璃质反光;眼神审视、克制、危险、略带倨傲。
- **发型**：黑发为主;女性多蓬松短卷 / 厚重刘海 / 长卷;男性厚实后梳、精英或机车感。
- **服装**：女性——挂脖礼服、贴身剪裁、露肩、大耳饰、红唇;男性——宽肩西装、衬衫、领带、深色长外套,黑帮精英 / 商务精英 / 都市危险人物气质。服装为身份、欲望、场景服务,而非可爱化。

### 3.5 场景与构图

- **典型场景**：深夜写字楼 / 天台、酒店走廊与大堂、高级会所、雨夜街道、霓虹招牌下的街角、车内、公寓室内暖光。
- **构图语言**：海报化 + 电影特写意识;大量极近距离面部裁切（半张脸、双人贴近、视线交错）制造亲密与压迫;双人并置强调「关系场」而非互动;全身像具有角色海报般的仪式感。

### 3.6 材质与质感

- **物理质感**：细腻噪点、旧印刷网点、纸张颗粒、轻微褪色、VHS 扫描感;边缘轻微柔化 / 糊边,而非数码洁净锐利。
- **上色痕迹**：手绘赛璐珞叠色的颗粒变化、颜料堆叠、彩铅 / 粉质覆盖感;复合质地介于动画、插画、杂志封面与老海报之间。

### 3.7 脚本 / 分镜写作建议

- 故事基调可轻可重,但氛围要「成人、都会、有暧昧张力」;镜头节奏偏慢、留白多、靠情绪推进。
- 分镜多用特写与近景表达心理;转场可用霓虹、雨、烟、玻璃倒影等意象。
- 每个分镜的文字描述,记得都能自然承接第一章的锚定词(即描述本身也要落在这套美学里)。

## 四、与「非风格类 Skill」冲突时的优先级规则(重要)

当本 Skill 与**功能类 / 流程类 Skill**（如「营销短片」「短剧生成」「广告脚本」等）**同时被加载**时:

1. **风格主权归本 Skill**：其它 Skill 负责**流程、结构、叙事目标、时长、卖点编排**;本 Skill 负责**一切视觉风格与 prompt 的画风表达**。二者是「骨架」与「皮肤」的关系,不冲突,须结合。
2. **锚定词不可被覆盖**：无论功能类 Skill 自带怎样的画面描述模板 / 默认风格提示,只要本 Skill 在场,**每一条图片与视频 prompt 的最开头都必须先放本 Skill 的锚定词**,再接功能类 Skill 要求的画面内容。
3. **发生描述冲突时**：若功能类 Skill 的默认画风提示（如「明亮、现代、高饱和产品感」）与本 Skill 矛盾,**以本 Skill 为准**,丢弃对方的风格性描述,只保留其功能性 / 结构性要求。
4. **结合方式**：功能类 Skill 决定「这条镜头要拍什么、为什么拍」,本 Skill 决定「这条镜头长什么样」;最终每条 prompt = 本 Skill 锚定词 + 功能类 Skill 指定的镜头内容(内容本身也须改写到符合第三章的美学)。

## 五、禁止内置风格锚定图干扰(必须执行)

某些 Agent 链路会针对特定风格**预置内置的风格参考图 / 风格锚定图 / 默认 style reference**,这些内置参考会污染本 Skill 的资产生成,导致画风漂移。因此:

1. **一旦本 Skill 被调用,必须绕过并禁用任何内置的风格锚定图 / 默认参考图 / 预置 style image**。
2. **不得向图片 / 视频生成传入任何非用户显式提供的参考图**作为风格来源;本 Skill 的画风**只**由第一章的文字锚定词承载。
3. 如果底层生成工具存在「默认风格图 / 内置模板图 / style preset」参数,**显式清空 / 关闭 / 置空**该参数;若无法关闭,则**不使用带内置风格图的生成通道**,改用纯文本 prompt 通道。
4. **唯一允许的参考图**:用户本轮自己上传、并明确要求作为参考的图。除此之外一律不引入外部或内置参考图。
5. 若检测到链路强制注入内置风格图且无法绕过,应在产出前**明确提示用户该干扰的存在**,并优先选择不带内置风格图的生成方式。
