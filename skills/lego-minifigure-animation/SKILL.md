# 乐高 Minifigure 动画制作

## 核心原则

LEGO 动画的核心张力在于：用积木的几何约束与 Minifigure 的有限可动性，表达完整的叙事弧光。限制即风格——积木的棱角、塑料材质的光泽、Minifigure 的固定表情与 C 型手，共同构成了一个自洽的视觉世界。在这个世界里，角色动作必须可视化、可搭建，场景必须符合积木几何逻辑，叙事必须靠镜头语言而非心理描写推进。

**持久引擎（因果链）：**

**用户输入（主题/角色/场景/冲突/情绪/受众）→ Logline（主角+目标+阻碍+风险）→ 三幕结构（建立问题→冲突升级→高潮与结局）→ Key Element 设计（角色 Minifigure 化 + 场景积木化）→ 故事板（Sequence→Shot Group→Shot 三层）→ 参考图生成（角色 turnaround + 场景多版本）→ 逐镜头视频生成 → 音频层生成（对白/旁白/BGM）→ 最终剪辑合成**

**质量测试（可证伪）：**

> 如果把所有 Minifigure 换成真人比例角色、把所有积木场景换成写实场景，这个剧本是否仍然成立且更好？如果答案是"是"，说明叙事没有利用 LEGO 媒介的独特性，创意不成立——应重做，让积木材质、Minifigure 比例或积木搭建逻辑成为叙事不可分割的一部分。

## 输入诊断

生产前必须明确或合理假设以下维度：

**必填项（缺失则追问，不全则只追问缺失项）：**

- **主题与故事意图**：用户想讲什么故事？（冒险 / 喜剧 / 品牌宣传 / 情感短片 / 科幻 / 奇幻）
- **角色列表**：每个角色的名称、身份、外观关键词（发型、服装配色、配件）。
- **场景列表**：故事发生在哪些场景？（室内/室外、白天/夜晚、现实/幻想）
- **冲突与情绪曲线**：核心矛盾是什么？情绪从哪里出发、到哪里结束？
- **目标受众**：儿童 / 青少年 / 成人 / 全年龄？决定对白深度与叙事复杂度。
- **对白语言**：中文 / 英文 / 其他？决定台词与旁白的语言。
- **时长意图**：短片时长预估（影响 Shot Group 数量与节奏）。

**可选项（缺失则用合理默认值，不打断流程）：**

- **画幅比例**：默认 16:9；若用户指定 9:16 或 1:1 则覆盖。
- **风格参照**：用户是否提供了风格参考图或参考视频？
- **参考素材**：用户是否上传了角色图、场景图、剧本文本、音频等素材？若有，需先分析提取信息（见下方"参考素材分析"）。
- **体裁路线**：品牌片 / 故事短片 / UGC / 教育内容？默认故事短片。
- **合规敏感点**：是否涉及儿童内容、品牌商标、暴力、健康等敏感领域？

## 参考素材分析

若用户提供了参考素材，先分析并提取以下信息，供后续阶段使用：

**文字素材**（剧本、故事大纲）：
- 提取主题、角色列表及外观描述、主要场景、冲突节点、情绪曲线。
- 若文字中描述了真人/写实/Anime 风格角色，需转换为 LEGO Minifigure 等效描述。

**图像素材**（角色参考图、场景概念图）：
- 提取角色造型特征（发型、服装配色、配件、面部印刷细节），确保后续 Key Element 描述与之一致，不得矛盾。
- 提取场景构成要素（建筑布局、道路、关键道具位置），转换为积木搭建逻辑描述。
- 若图像为非 LEGO 风格，提取核心特征后转译为 Minifigure/积木等效表达，而非直接使用原图。

输出结构化文字摘要，供故事板设计和素材生成阶段使用。

## 工作流

> **里程碑确认规则（强制）：** 每个阶段完成后**必须暂停**，向用户展示成果并等待确认，不得自动连续执行完整流程。用户确认后才进入下一阶段。

> **依赖关系：** 阶段 3 依赖 1、2；阶段 4 依赖 3；阶段 5 依赖 4；阶段 6 依赖 5；阶段 7 依赖 4；阶段 8 依赖 5、6、7。

### 阶段 1：分析用户输入

分析用户输入的以下维度：主题、角色、场景、冲突、情绪曲线、目标受众。

- 若用户提供了参考素材，先执行"参考素材分析"流程，提取结构化信息。
- 将分析结果整理为摘要，向用户展示并等待确认。

**输出：** 结构化输入摘要（主题、角色列表、场景列表、冲突概述、情绪曲线、受众定位、对白语言、时长意图、画幅比例）。

### 阶段 2：生成剧本

基于已确认的输入摘要，生成剧本：

**Logline 结构：** 主角 + 目标 + 阻碍 + 风险。一句话概括故事核心。

**三幕式结构：**
- 第一幕（建立问题）：介绍主角与世界观，建立核心冲突。
- 第二幕（冲突升级）：主角遭遇阻碍，矛盾加深，出现转折。
- 第三幕（高潮与结局）：冲突达到顶点，主角行动解决（或未解决）问题，收束主题。

向用户展示剧本（Logline + 三幕概要），等待确认。

**输出：** Logline + 三幕结构文档。

### 阶段 3：建立 Final Video Spec

基于已确认的剧本，建立最终视频规格文档，包含：

- **片名**
- **时长意图**（总时长预估，决定 Shot Group 数量）
- **画幅比例**（默认 16:9）
- **风格锁定**：LEGO Minifigure 动画
- **对白语言**
- **体裁路线**（品牌片 / 故事短片 / UGC / 教育内容）

将规格文档写入文件保存。

**输出：** Final_Video_Spec 文件。

### 阶段 4：设计故事板

基于 Final Video Spec，设计完整故事板。加载 `references/industries/lego-design-vocabulary.md` 获取角色与场景设计用词。

#### Key Element 设计

**角色（element character）：**
- 必须使用 LEGO Minifigure 比例与风格；禁止真人、写实或 Anime 比例角色。
- 每个角色详细记录：发型颜色与款式、服装配色与图案、配件、面部印刷细节。
- 确保跨镜头外观一致。
- 若角色在剧情中存在多个造型（时间跨度、变装），逐一列出各造型描述。

**场景（element scene）：**
- 所有场景元素（建筑、道路、家具、车辆、树木、水体）必须符合 LEGO 积木搭建逻辑。
- 使用积木几何造型，避免有机曲线结构。
- 标注场景中关键道具或动作发生区域的位置关系。

#### Shot 设计

将镜头组织为三层结构：

- **Sequence（序列）**：一个完整剧情段落。
- **Shot Group（镜头组）**：时长 8–15 秒，含 3–8 个镜头，围绕一个剧情目标展开。
- **Shot（单镜头）**：最小叙事单元。

每个 Shot 必须包含：
- **景别：** ECU / CU / MCU / MS / MLS / LS / ELS
- **运镜：** Static / Push In / Pull Out / Pan / Tilt / Tracking / Orbit / Handheld
- **角色动作：** 仅可视化动作（如"拿起咖啡杯"、"转头看向电脑"）；禁止不可视化描述（如"陷入思考"、"感到痛苦"）。
- **对白（dialogue）：** 写出角色的完整台词原文。
- **音效标注：** 环境音、动作音、转场音。

镜头语言服务剧情逻辑，避免无叙事目的的炫技运镜。

**禁止在镜头描述中设计任何画面内字幕或浮现文字**（如"画面中心浮现大字：……"）；字幕处理统一交由后期合成阶段负责，不在 Shot 层级规划。

#### 音频层设计

**BGM：**
- 全片至少一条 BGM 轨道，标注音乐风格、情绪、节奏及起止区间。
- 若片中有明显情绪转折点，可分段设计多条 BGM 轨。

**环境音 / 动作音效：**
- 在对应 Shot 的音效字段标注（如积木碰撞声、脚步声、城市环境音）。

**旁白 VO（可选）：**
- 若有旁白驱动叙事，设计为独立 audio layer（type: narration）。
- 记录 narration speaker profile（如"[沉稳男声，叙述语气]"）及完整脚本。
- 标注对应镜头区间。

向用户展示完整故事板，等待确认。

**输出：** 完整故事板文档（Key Elements + Shot 列表 + 音频层设计）。

### 阶段 5：生成参考素材

基于已确认的故事板，生成 Key Element 参考图。

#### 素材扫描与绑定

扫描当前上下文中用户已提供的素材（图像、音频等）。对匹配的素材，直接绑定到对应 Storyboard 槽位，不重复生成。

#### Key Element 图像生成

加载 `references/formats/video-prompt-grammar.md` 获取图像 prompt 文法。

对尚无素材的 Key Element，生成参考图：

**角色参考图：**
- 每个角色生成一张横版拼排的 character turnaround sheet。
- 包含正面、侧面、背面、表情图。
- 分辨率 2K。
- prompt 模板见 `references/formats/video-prompt-grammar.md` 的"图像提示词"章节。

**场景参考图：**
- 根据剧情需要输出白天版、夜晚版及关键动作版。
- prompt 模板见 `references/formats/video-prompt-grammar.md` 的"图像提示词"章节。

向用户展示所有参考图，等待确认。

**输出：** 角色参考图（每角色一张 turnaround sheet）+ 场景参考图（每场景多版本）。

### 阶段 6：逐镜头生成视频

基于已确认的参考图，逐镜头生成视频。加载 `references/formats/video-prompt-grammar.md` 获取视频 prompt 文法。

#### 视频生成规则

- 单次生成时长不超过 15 秒。≤15 秒的镜头用一次生成即可拿到完整片段；若某 Shot Group 总时长超过 15 秒，拆成若干 ≤15 秒片段分别生成，再做后处理拼接。
- 分辨率 720p。
- 每个 Shot 的参考输入：
  1. 该镜头涉及的所有角色 element 图像 + 场景 element 图像（必须）。
  2. 前一 Shot 视频作为参考视频（可选，仅当与前镜头连续性极强时使用，通常跳过）。
- prompt 结构见 `references/formats/video-prompt-grammar.md` 的"视频提示词"章节。

逐镜头生成完成后，向用户展示所有视频片段，等待确认。

**输出：** 所有 Shot 的视频片段。

### 阶段 7：生成音频层

基于已确认的故事板音频层设计，生成所有音频。

#### 对白 / 旁白生成

- 使用文本转语音能力生成对白与旁白。
- 旁白需匹配 narration speaker profile。
- 若有角色音频绑定，用于保持角色音色一致。

#### BGM 生成

- 使用文本转音乐能力生成 BGM。
- prompt 中避免出现知名艺术家名字。
- 按故事板设计的 BGM 轨道分别生成。

向用户展示所有音频，等待确认。

**输出：** 对白/旁白音频 + BGM 音频。

### 阶段 8：最终剪辑合成

基于所有视频片段与音频层，进行最终剪辑合成：

- 按故事板 Sequence → Shot Group → Shot 顺序拼接视频片段。
- 叠加对白/旁白音频轨。
- 叠加 BGM 音轨（按起止区间对齐）。
- 叠加环境音/动作音效（按 Shot 音效字段对齐）。
- 若需要字幕，在此阶段添加（基于对白文本生成）。
- 输出最终成片。

**输出：** 最终视频成片。

## 输出契约

### Final Video Spec 模板

```
片名：[片名]
时长意图：[总时长预估]
画幅比例：16:9（或用户指定）
风格锁定：LEGO Minifigure 动画
对白语言：[语言]
体裁路线：[品牌片 / 故事短片 / UGC / 教育内容]
```

### Key Element 角色模板

```
角色名称：[名称]
身份：[身份]
发型：[颜色 + 款式]
服装：[配色 + 图案]
配件：[配件列表]
面部印刷：[面部细节描述]
造型变体：[若有多个造型，逐一列出]
```

### Key Element 场景模板

```
场景名称：[名称]
时段：[白天 / 夜晚 / 黄昏]
建筑布局：[积木搭建描述]
关键道具位置：[道具与动作区域的位置关系]
场景变体：[白天版 / 夜晚版 / 关键动作版]
```

### Shot 模板

```
Sequence [编号]: [序列名称]
  Shot Group [编号] (时长 [8-15]s): [镜头组目标]
    Shot [编号]
      景别: [ECU/CU/MCU/MS/MLS/LS/ELS]
      运镜: [Static/Push In/Pull Out/Pan/Tilt/Tracking/Orbit/Handheld]
      角色动作: [可视化动作描述]
      对白: "[台词原文]"
      音效: [环境音/动作音/转场音]
```

### 音频层模板

```
BGM 轨 [编号]:
  风格: [音乐风格]
  情绪: [情绪]
  节奏: [BPM 或描述]
  区间: [起止 Shot 编号]

旁白轨 (若适用):
  speaker profile: [音色描述]
  脚本: [完整旁白文本]
  区间: [对应 Shot 编号]
```

### 视频生成方式说明

- **≤15 秒的镜头**：用一次视频生成即可拿到完整片段，无需分段。
- **>15 秒的 Shot Group**：拆成若干 ≤15 秒片段分别生成，再做后处理拼接。
- Shot Group 内的 beat 节拍（如"开场→动作→收尾"）是同一条 prompt 内的时间轴描述，不等于要多次调用生成。

## 静默自检

交付前内部跑一遍以下清单，弱项直接重写，不外显给用户：

**LEGO 风格一致性：**
- [ ] 所有角色是否为 LEGO Minifigure 比例与风格？有无混入真人/写实/Anime 比例？
- [ ] 所有场景元素是否符合积木搭建逻辑？有无有机曲线结构？
- [ ] 角色跨镜头外观是否一致（发型、服装、配件、面部印刷）？

**叙事质量：**
- [ ] Logline 是否包含主角+目标+阻碍+风险四要素？
- [ ] 三幕结构是否完整（建立问题→冲突升级→高潮与结局）？
- [ ] 角色动作是否全部可视化？有无不可视化描述（如"陷入思考"）？
- [ ] 镜头语言是否服务剧情逻辑？有无无叙事目的的炫技运镜？
- [ ] Shot 描述中是否出现了画面内字幕或浮现文字？（不应有）

**技术规格：**
- [ ] 角色参考图是否为 turnaround sheet（正面/侧面/背面/表情）？
- [ ] 场景参考图是否包含所需时段版本？
- [ ] 单次视频生成是否 ≤15 秒？超时是否已拆分？
- [ ] BGM prompt 中是否出现了知名艺术家名字？（不应有）
- [ ] 画幅比例是否与用户指定一致？

**流程合规：**
- [ ] 每个里程碑是否都已暂停并等待用户确认？
- [ ] 用户上传的素材是否已扫描并绑定，未重复生成？
- [ ] 全文语言是否与目标市场一致，无中英混杂？
