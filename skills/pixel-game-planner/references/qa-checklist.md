# 审核清单与返修规范

## 审核清单

剪辑完成后必须按以下三类检查：

### 一、像素风审核

- [ ] 是否真正像素风
- [ ] 是否不是普通插画
- [ ] 像素颗粒是否统一
- [ ] 边缘是否清晰
- [ ] 是否没有高清 3D 污染
- [ ] 是否没有写实摄影感
- [ ] 是否没有马赛克滤镜感

### 二、游戏逻辑审核

- [ ] 是否有横版关卡
- [ ] 是否有平台、敌人、道具
- [ ] 是否有 UI
- [ ] 是否能看出游戏目标
- [ ] 主角是否从左向右推进
- [ ] 道具和敌人是否有互动逻辑
- [ ] 结尾是否有通关反馈

### 三、视频动作审核

- [ ] 动作是否像逐帧动画
- [ ] 是否保持低帧率感
- [ ] 是否没有丝滑真实动画
- [ ] 是否没有 3D 旋转
- [ ] 镜头是否保持横版卷轴
- [ ] UI 是否稳定
- [ ] 角色比例是否稳定

## 必须重跑的情况

出现以下情况时必须建议重跑：

1. 画面变成高清 3D
2. 画面变成普通插画
3. 像素颗粒不统一
4. 角色边缘模糊
5. UI 乱码严重
6. 动作过度丝滑
7. 镜头出现 3D 旋转
8. 角色比例变化明显
9. 横版关卡逻辑丢失
10. 画面不像游戏截图

## 返修格式

如果画面或视频不达标，按以下格式给出返修建议：

```
返修问题：
- 问题 1：
- 问题 2：
- 问题 3：

返修方向：
- 强化 8bit pixel art
- 限制色板
- 固定横版卷轴视角
- 降低动作复杂度
- 增加 UI 和平台逻辑
- 删除高清 3D / 写实 / 平滑插画倾向

重跑提示词补强：
【给出可直接追加到提示词末尾的补强句】
```

### 补强句示例

```
请严格保持 8bit pixel art，低分辨率像素块，统一像素颗粒，清晰像素边缘，限制色板，横版卷轴游戏视角，画面必须像真实复古街机游戏截图，不要高清 3D，不要写实，不要普通插画，不要马赛克滤镜，不要丝滑动画，不要 3D 镜头旋转。
```
