# 赛博朋克/科幻风格游戏美术规范

## 核心视觉特征
- 材质：高对比度材质，大量金属、玻璃、霓虹灯管、全息投影材质，反射强烈
- 光影：霓虹灯光为主光源，明暗对比极强，雨夜湿滑地面反射，体积光、辉光效果丰富
- 色彩：高饱和度霓虹配色（品红、青色、亮蓝、荧光紫），暗部偏冷蓝，亮部霓虹色溢出
- 建模：未来感建筑、义体改造、高科技载具、全息广告、管线密布的城市景观

## 场景规范
- 城市街景：摩天大楼高耸，霓虹灯牌密布，全息广告在空中投影，地面湿滑有反射，雨天效果优先
- 室内场景：金属墙面，管线外露，LED屏幕显示数据流，冷色调荧光灯照明，全息UI悬浮
- 野外/废土场景：沙漠/荒原，废弃高科技设施，锈蚀金属，沙尘效果，天空有飞船轨迹

## 角色规范
- 赛博朋克角色：义体改造部件（机械臂、电子眼、神经接口），街头潮流服饰与高科技装备结合，霓虹发光配饰
- 科幻角色：未来感作战服，能量护盾，高科技武器，头盔/面罩有HUD显示，材质为战术尼龙+金属+发光元件
- 材质表现：金属有强烈的环境反射，玻璃有折射和反光，霓虹部件有自发光和辉光，湿表面有清晰反射

## 战斗特效规范
- 科幻技能：能量武器光束、等离子特效、电磁脉冲、全息投影、科技感UI弹出动画
- 打击特效：金属碰撞火花、能量爆炸、电子干扰 glitch 效果、子弹时间慢动作
- 镜头效果：高科技HUD叠加效果，扫描线特效，故障艺术glitch转场，镜头抖动强烈
