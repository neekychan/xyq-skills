# JOJO日系漫画风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的《JOJO 的奇妙冒险》系列画风。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一套画风 / 同一部 JOJO 作品里出来的」（造型语言、色彩系统、镜头压迫感、版画质感不统一），则本技能执行失败。反之，若熟悉 JOJO 的人会认为它们出自同一部荒木飞吕彦风格作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **《JOJO 的奇妙冒险》系列画风，JOJO漫画感，高张力的时尚雕塑感，超现实又带攻击性的色彩系统，强烈到近乎压迫的镜头语言，具有版画感和雕刻感，先锋时尚、戏剧舞台感与超现实色彩融合在一起的高张力视觉风格，核心在于强造型、强气场、强戏剧性。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格」类 skill（营销短片 / 分镜 / 脚本等）搭配时的优先规则（务必遵守）

当本技能与**非风格类**功能 skill 同时被加载时（例如营销短片 skill、短剧 / 分镜 skill、Seedance 视频 prompt skill、广告脚本 skill 等）：

- **职责分离：** 那些 skill 负责「拍什么、讲什么故事、走什么营销结构 / 分镜节奏 / 脚本框架」；本技能负责「所有产出长成 JOJO 画风」。二者不是替代关系，而是叠加关系。
- **画风归本技能：** 无论其它 skill 内部是否自带任何画风 / 风格描述 / 默认美术设定，本次任务里所有图片与视频的**画风一律以本技能锚定词为准**。其它 skill 里出现的画风类措辞在本任务中一律让位于本技能锚定词。
- **锚定词照常注入：** 由其它 skill 产出的每一条图片 / 视频 prompt（含它生成的分镜、首帧图、每个镜头），在**最终送去生成前**都必须在最开头补上本技能锚定词（若同时叠加多个风格 skill，则补上合并锚定词），再走该 skill 原本的生成流程。
- **不牺牲功能：** 遵守本技能不代表丢弃其它 skill 的能力——营销结构、卖点、CTA、分镜时间轴、故事脚本照常执行，只是每条最终 prompt 头部统一戴上 JOJO 锚定词。
- **顺序处理：** 建议先让功能类 skill 产出内容 / 分镜 / prompt 骨架，再由本技能统一在每条 prompt 头部注入锚定词，最后送生成。

### 禁止内置风格锚定图干扰（硬约束，最高优先级）

部分 Agent 链路会针对某些风格**前置内置一张 / 一组「风格参考图 / 风格锚定图 / style reference / 默认风格图」**，用于给生成模型兜底画风。这类内置参考图会与本技能的专业锚定词**冲突并污染**产物画风。因此：

- **一旦本技能生效，必须绕过 / 关闭 / 忽略 Agent 任何内置的风格锚定图、默认风格参考图、预置 style reference。** 本次任务的画风**只**由本技能的文字锚定词（或合并锚定词）决定。
- 生成图片 / 视频时，**不要**把 Agent 内置的风格图作为参考图 / 首帧 / style image 传入；若生成接口默认会带上内置风格图，需显式清空 / 覆盖该参考，仅保留用户自有素材（如用户明确提供的角色图、首帧图）与本技能锚定词。
- 唯一允许的参考图是**用户在本任务中明确提供的素材**，或**本技能流程中前一步生成、并已注入锚定词的图片**（用作视频首帧衔接）。除此之外的任何系统内置风格图一律不得混入。
- 若链路机制上无法完全屏蔽内置风格图，则在 prompt 中显式声明以本技能锚定词为唯一画风依据、忽略其它预置风格参考，并把该情况向用户说明。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否叠加营销 / 分镜 / 脚本类功能 skill；视频画幅 / 时长偏好；是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，按常规创作补齐一版分镜草案并说明（可参考下文「风格知识库」保证内容贴合 JOJO 气质），再统一注入锚定词；不要反复追问已明确的信息。

## 风格知识库（供 Agent 写分镜 / 角色 / 场景 / 脚本时形容参考）

> 以下知识**不是**要塞进锚定词，而是帮助 Agent 在写「具体画面描述」「分镜」「角色设定」「故事脚本」时，把措辞往 JOJO 气质上靠，让整批内容从骨子里贴合风格。锚定词管画风一致，本知识库管内容气质一致。

### 1. 整体风格气质
- 高张力的**时尚雕塑感**：人物像被设计过的大理石雕像 + 高定时装模特，既是战士又是秀场明星。
- 关键词群：华丽、夸张、雕塑感、强结构、高反差、超现实配色、戏剧化姿态、时尚感、攻击性、宿命感、贵气、妖异、舞台感、漫画式压迫构图。
- 不追求自然治愈，追求**强、艳、贵、怪、张扬**；静止画面也要有「随时爆发」的能量。

### 2. 角色造型质感
- 人体：解剖结构明确，块面被概括过，轮廓紧绷；躯干拉伸、脊柱旋转、肩胯反向对抗（「JOJO 立」的骨架）。
- 面部：眉眼深邃、眼窝深、鼻梁高直、下颌利落，冷艳锐利带压迫感；情绪偏蔑视 / 冷静 / 疯狂 / 执念 / 戏谑等高戏剧化表情。
- 气质：雄丽与妖异并存，不被传统性别审美框死；力量感与装饰性、艳丽感共存。
- 服装：时装秀级造型 + 战斗人格外化——夸张立领 / 深 V / 开胸、金属配件拉链铆钉链条、心形圆环几何镂空、紧身与裸露结合、图案化设计；混合高级时装 / 摇滚 / 朋克 / 古典纹样 / 宗教感装饰 / 超现实元素。

### 3. 姿态与手势（JOJO 立）
- 扭转强、重心奇特、四肢延展夸张、肩胯反向对抗，姿态带「宣言感」。
- 兼具 T 台硬照的摆拍感 + 战斗前紧绷感；静止也像马上爆发。
- 手部表演性极强：手指张开夸张、指向 / 托腮 / 遮面 / 翻腕等戏剧化手势，常成为画面节奏焦点。

### 4. 光影与材质
- 硬阴影、强烈明暗切割、局部戏剧舞台灯光、雕刻般体块塑造。
- 版画 / 铜版雕刻般的排线与明暗组织，制造印刷冲击感而非柔和空气感。
- 材质混合：石雕感（人体）、金属感（配饰）、皮革感（紧致服装）、丝绸 / 宝石感（贵气色彩）、版画感（黑白排线）、舞台灯光感（颜色被灯光重定义）。

### 5. 色彩系统
- 情绪逻辑先于真实逻辑：颜色为气场 / 高潮服务，可非真实化（肤色、发色、背景都能为情绪变色）。
- 高纯度撞色与补色对冲：紫绿对撞、粉蓝反差、金橙配青、荧光黄配深紫、冷蓝皮肤配暖红背景。
- 少用温吞灰蒙的自然中间色主导；点缀金属色、高饱和宝石色，营造装饰艺术式贵气。

### 6. 镜头与构图
- 近景压迫：低机位仰拍、面部 / 手部 / 眼部极端特写、前景压迫式构图。
- 海报式定格构图：人物占主体、身体走强对角线、背景为气氛服务、留白带压迫感，每格像「角色宣言海报」。
- 节奏元素：放射线、速度线、异形背景、重复纹理、高反差块面，让静止画面也有爆炸感。

### 7. 背景与氛围
- 背景是「气场放大器」而非环境说明：抽象色块、速度线、放射纹、几何纹样、不真实天空 / 空间色彩、舞台灯光式切换。
- 氛围混合：史诗感、宿命感、诡异感、华丽感、荒诞感、贵族式华丽——高美学自觉的高戏剧燃烧。

### 8. 故事 / 脚本气质
- 角色气场先于剧情逻辑抵达观众；情绪表达夸张外放（怒 / 冷笑 / 震惊 / 疯狂 / 自信 / 蔑视皆放大到舞台尺度）。
- 叙事偏「宣言 / 对峙 / 宿命交锋」，讲究定格瞬间的仪式感与张力，而非平淡日常。

> 用法示例：写分镜时不要只写「一个人站着」，而写「低机位仰拍，人物脊柱扭转、肩胯反向对抗摆出 JOJO 立，手指夸张张开指向镜头，背景放射状抽象纹样与紫绿撞色，硬阴影切割面部」——这样即使锚定词管住画风，内容本身也已贴合 JOJO 气质。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。同时确认已按「禁止内置风格锚定图干扰」绕过 Agent 内置风格图。
2. **确认功能 skill 分工（如有）。** 若同时加载营销 / 分镜 / 脚本类 skill，明确由它们出内容骨架、由本技能统一注入锚定词，画风以本技能为准。
3. **生成图片素材（逐张）。** 对每一张需要的图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`（具体描述可参考风格知识库往 JOJO 气质靠），然后生成图片，且不传入任何内置风格参考图。所有图片共用同一份锚定词。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频，同样不传入内置风格参考图。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该图片（已注入锚定词生成的那张）作为视频的画面参考，视频 prompt 仍在头部注入锚定词。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
7. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。
