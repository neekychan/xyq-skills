# 音频制作、剪辑组装与成片交付

使用已有剧本、镜表和实际视频，不另造故事。音频提示词不加视觉锚定词；如为修口型调用生成式视频工具，该视频 prompt 仍须原样前缀。

## 声音分工

| 类型 | 身份与制作 | 同步要求 |
|---|---|---|
| 角色对白 | 绑定 character_id + voice_id，原生视频音频或独立 TTS/配音 | 说话角色、台词与口型对应，听者不误开口 |
| 角色内心 OS | 与该角色对白使用同一声音身份；原生能力支持则内嵌，不支持则独立声轨 | 嘴唇不动，表情按 OS 情绪逐拍变化，长度计入镜头 |
| 第三人称 VO | 独立 narration_speaker_profile，不能把角色 OS 混为通用旁白 | 声音与所叙述画面同步，避免压住关键对白 |
| 音效 SFX | 原生同期或独立素材，登记声源和落点 | 衣料、脚步、击中、门响、设备反馈与画面动作对齐 |
| 背景音乐 BGM | 独立音乐轨，按情绪段落生成或使用用户素材 | 视频默认不内嵌，后期控制进入、退出和对白避让 |

每个声音档案记录音色、年龄感、声线厚薄、气息、口音、语速、常态与强情绪变化，固定工具音色 ID 或可复用样本。没有工具支持的音色绑定，不声称仅凭文字就能保证跨镜音色一致；优先统一后期配音。

必要时先做约 10—15 秒角色样本，包含中性短句与一个剧情情绪转折；已有可用音色无需重复生成。情绪控制允许变化，声音身份保持一致。

## 音频层计划

每条轨登记 `audio_id`、类型、说话者/voice_id、文本或声音描述、覆盖 shot_id、开始时点、目标长度、音源文件、是否已内嵌视频。全部时间以秒记录，后期以实际文件校准。

对白、OS、VO 保留原文；括号中的表演指示不被念出。对音频工具使用其真实语气/停顿字段，不假定花括号或 `(OS)` 对所有工具有效。文字仅可作工具已支持的语法映射。

语速依角色、类型和情绪设定；无样音时，古风剧场感念白可暂按约 2.5 字/秒，现代自然对白可暂按约 3—4 字/秒，停顿和气息另算，先朗读复核并在生成后测实际时长。超出镜头时，优先调整镜头覆盖或切换反应镜头，不把声音挤成明显变调的快放。用户授权精炼台词时才改台词。

### BGM 设计

按戏剧功能写情绪走向、配器、密度、节奏、覆盖长度、高潮与留白。古风可选古琴/箫，现代情感可选钢琴/轻弦乐，校园喜剧可选拨弦/轻打击，科幻可选合成器/脉冲/音色纹理，悬疑可用稀疏节拍、低音纹理或留白。选择服从具体场景，同一题材也不强制固定配器；国漫3D是视觉规则，不要求每部剧都用民族乐器。默认无歌词和人声，除非用户要求主题歌。

一条 BGM 足够时不额外拆曲；关系/时空/情绪有明显转折时可分段，给音乐尾音和剪辑余量。允许剧情需要的无音乐段。工具只返回较短段时按真实能力续作或剪辑，不能循环接缝明显却宣称完整配乐。

### OS 特别检查

OS 与角色对白统一音色；画中角色不动嘴，不能让视频原声再读一次。画面配合具体表情路径，如“目光停在封蜡→指尖捏紧信角→抬眼望向门外”，而非空泛的“若有所思”。

## 时间线组装

1. 读取实际文件时长、分辨率、帧率和音轨；确认镜表采用有效版本，没有混入失败或过期镜头。
2. 每个片段记录源入点、源出点、时间线开始位置、实际保留时长与速度。内切镜已存在于生成视频中时不重复当独立片段拼一次。
3. 根据剧情顺序裁去失败开头/多余等待，保留必要台词落点与动作收势。片段之间动作进度、目光、道具、进出场状态必须可接。
4. 同空间优先硬切；跨空间可按需要用约 0.3 秒以内的短淡化，或由声音先行/延后形成自然转场。重叠转场改变总时长，要反映在时间线上。
5. 跳轴和空间错位回到镜头设计或生成修正，见 [空间连续性](spatial-consistency.md)。不要认为插入任何过肩镜都能修复，也不用转场遮掩穿帮。
6. 绑定音轨和字幕。无字幕需求时交付干净画面；用户要字幕时按最终台词生成可编辑字幕轨，校对说话者、内容、时间、断句、人物/地点/设定专名与安全区，避免依赖模型烧录乱码。

## 混音与音画同步

以人声可懂为先。BGM 比人声低约 8—12 dB 可作为初始混音关系；实际素材响度、频段与密度不同，必须试听，不把相同增益值等同于相同听感。高潮抬升约 3—5 dB 只用于不会遮挡人声的区段，台词进入时适当自动或手工压低配乐。

对白与 VO 音量相近，角色 OS 可以调整空间感但保留清晰度。短淡化约 0.5 秒仅作起点，不裁掉辅音、字尾或动作音效。避免削波、忽大忽小、头尾爆音、左右声道意外不平衡。

逐轨核对内嵌标记：视频已含对白/OS/音效时，不再叠加同一条独立音频。若替换原声，明确移除或静音的轨；需要保留的环境声和音效应有可用独立来源，不能在静音后假定它们仍存在。

检查闭口 OS、口型、击打接触、脚步落地、物件接触、设备反馈和关门时点。镜头被剪短、放慢或重生成后，重算其音轨与字幕，不继续使用旧时间偏移。

## 导出与验收

默认时间线 24fps，画幅按用户要求。输出分辨率按源素材与交付目标选定；720p、1080p 等如实记录，不能仅拉大画布就称原生高清。超分是后处理，插帧是后处理，不等于补回缺失的真实细节。

输入帧率或尺寸不同，先选择统一时间基准与缩放策略；保留构图，不自动裁掉人物头部、手部和剧情关键物件。慢动作先确认动作完整与可用帧，不为“流畅”无差别插帧导致手脸变形。

导出后至少检视开头、结尾、每次转场、关键表演/武打落点，并完整试听对白、OS、VO 和混音；可行时完整播放成片。记录实际时长、像素、帧率、编码和声音情况。检查可播放、无黑帧、无意外静音、字幕可读且无错位。

交付成片文件或实际可访问链接，并提供按需字幕、最终镜表、素材/音频索引与有效制作记录。缺少任何生成或剪辑能力时，交付已完成素材、可执行时间线和明确缺口，不把任务清单当成视频文件。
