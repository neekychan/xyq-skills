# 流派 07: 动感歌词排版 (Kinetic Typography PV)

* **适用曲风**：动感 J-Pop、说唱 (Rap)、高能概念曲、高密度词作、电子舞曲
* **视听公式**：`[3D 前后夹心视差排版 (Typography Sandwich)] + [语义材质绑定 (水银/光轨/代码)] + [8大高阶平面转场] + [因果同步与逐词显现] + [唱演与文字严格分轨]`
* **表演配比**：严格执行**唱演与文字分轨**（唱演镜展示五官不写大字，排版镜展示纯文字力学与动作卡点，主角不对嘴）。

## 一、 3D 前后夹心视差排版 (Typography Sandwich & Parallax Layering)

拒绝文字全在身后的死板“广告牌背景板”，也拒绝文字全在身前的廉价“压屏字幕”。必须构建 **3 层 3D 空间三明治结构**：

1. **三层空间划分**：
   * **最前景 (Foreground)**：微焦悬浮的极简对焦十字框、条形码刻度、以及**大字中穿插到歌手肩膀/前臂身前的局部笔画**；
   * **中景 (Midground)**：核心歌手或舞者（做破画框动作、指尖划过虚空、穿透字母）；
   * **后景 (Background)**：顶天立地的超大动态文字、同心圆环与极简纯色色块。
2. **标准 Prompt 描写句式**：
   * `超大白色粗体字【IGNITE】呈现3D前后视差图层：【IGN】矗立在身后，而巨型【ITE】的一半笔画悬浮穿插在她的肩膀与手腕前方。`
   * `大字【OVERFLOW】在身后排列，其中字母'O'的镂空处作为透视视窗，歌手从中景破屏而出。`

## 四、 因果同步与逐词显现 (Causal Sync & Staggered Reveal)

1. **主体动作引发文字生成（因果绑定）**：
   - 文字必须由主体的**视线凝聚、指尖划过、手腕抖动或脚跟蹬地**作为物理触发源，杜绝无缘无故从天而降。
2. **多词短语逐词显现（Staggered Reveal）**：
   - 包含多个单词的短语，按节拍逐词弹出或连续点亮（如 `【FREE】` $\rightarrow$ `【YOUR】` $\rightarrow$ `【MIND】`），禁止整句一次性全部糊上。
3. **语义动作一致性（Semantic Action）**：
   - 动作与文字含义直接对应（文案为 `【BREAK】` 时文字真实碎裂；文案为 `【STEP INTO】` 时真实跨步迈入字影）。

