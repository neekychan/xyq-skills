# 分镜图模板：动作分解 · 动作脚本表格

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：用表格形式将动作视频的镜号、动作描述、关键帧、时长、速度和备注等信息结构化记录，形成可直接执行或交给制作团队的**动作脚本表格**，强调“信息完整、易查阅、可落地执行”。
- **典型场景**：
  - 动作电影/短剧拍摄计划中的动作场面执行清单。
  - 动作游戏宣传片、动作 PV 的镜头级动作脚本规划。
  - 教学类动作视频的拍摄安排表，用于控制每个步骤的镜头时长和速度。

## 2. 判定关键词与适用边界
- 典型触发词：`动作脚本表`、`镜号表`、`执行清单`、`镜头时长`、`动作描述`、`关键帧`、`备注栏`、`拍摄脚本`。
- 适用判定：
  - 用户需要一份可以直接交给拍摄/后期团队使用的文档，包含镜号、动作内容、时间与技术参数，而不仅仅是图像分镜；
  - 项目以动作为核心，重视执行层面的具体安排与核对。
- 不适用场景：
  - 只需视觉参考的分镜草图，不需要详细时长和备注 → 适合“动作分解表”“姿态连续分镜”等模板；
  - 纯文案脚本或旁白为主的项目 → 适合剧情/科普类脚本模板，而非动作脚本表。

## 3. 分镜结构建议
- **推荐宫格数（表格行数）**：8–20 格，每格对应一个镜号或动作单元，视项目时长与动作复杂度增减。
- 规划方式：
  - 先确定整体动作段落的镜头数量与结构（如“开场 3 镜 + 主体动作 8 镜 + 收束 2 镜”），再为每个镜头分配一行；
  - 表格列建议至少包含：镜号、动作描述、关键帧说明、预期时长、速度（慢动作/正常/快剪）、执行备注（如特效/安全/道具准备）；
  - 如需与图像分镜或镜头表对齐，可在备注中写入对应的分镜格编号或参考图 ID。
- **画面特征**：以结构化文字为主，可选附加小图标或缩略图；重点是信息完整与对齐，并不要求每行都有精细画面示意。

## 4. 生图 Prompt（PE）模板

```text
你是一名动作导演兼执行制片，请为 {动作项目类型，如“动作短片拍摄/武打场面设计/动作游戏宣传片/教学动作合集”等} 设计一份 {表格行数，如 12/16/20 行} 的动作脚本表格分镜图，整体画幅为 {画幅比例说明，如“横版表格版式”或“竖屏分镜脚本”}。

【项目与场景信息】
- 项目名称：{如“城市天台打斗短片”“篮球训练教学合集”等}
- 场景与时长：{主要场景说明与总时长预期}
- 主要角色/对象：{出场人物或动作主体列表}
- 整体动作结构：{如“引入→主体动作→高潮→收束”等}

【表格结构设计】
- 行数：{表格行数，与镜头或动作单元数量一致}
- 列配置：至少包含以下列：
  - 镜号：{S1/S2…或 A1/A2…}
  - 动作描述：{本镜或本步骤的连续动作内容，强调动作链而非单招}
  - 关键帧说明：{该镜需特别关注的画面瞬间，如“起跳最高点”“武器相交瞬间”等}
  - 预期时长：{秒数或帧数}
  - 速度：{慢动作/正常/快剪等}
  - 备注：{特效需求、安全注意事项、道具/场景准备等}

【脚本分镜输出格式】
请按行号依次输出动作脚本表格内容：
- 行1（镜号 {镜号示例，如 S1}）：
  - 动作描述：{该镜或步骤的完整动作链，包含起手→跟进→收束}
  - 关键帧说明：{至少 1 个关键画面瞬间}
  - 预期时长：{秒数}
  - 速度：{如“正常剪辑”“慢动作 0.5 倍速”等}
  - 备注：{特效、道具、安全或与其他分镜的对应关系}
- 行2（镜号 {S2}）：……
- ……
- 行{N}（镜号 {S{N}}）：按同样格式完成，覆盖整个动作段落。

【画幅与风格】
- 画面比例：{16:9 横版/9:16 竖版等，表格类推荐 16:9}
- 画风：{以清晰可读的文字表格为主，可选搭配简洁线稿示意}
- 排版说明：{是否需要高对比色的镜号列、是否在关键帧列中预留缩略图位置等}
- 要求脚本表格中的镜号、动作描述与其他分镜/镜头表保持一一对应，方便执行与复核。
```

## 5. 一致性与避坑
- 镜号、时长和动作内容必须与图像分镜和镜头表保持严格对应，避免不同文档之间信息不一致。
- 动作描述应聚焦可执行的身体动作与空间关系，不要写抽象情绪或无法拍到的隐喻句（参考 storyboard/prompt-craft.md 的“只写摄像机能拍到的内容”原则）。
- 关键帧说明要具体到画面事件（如“刀刃交叉僵持”“脚刚落地时尘土飞扬”），避免笼统写“高潮”或“精彩瞬间”。
- 备注列用于集中记录安全注意事项、特效需求与道具准备，避免散落在动作描述中导致执行人员遗漏。
- 表格行数与项目时长合理匹配，避免过度细分到无法执行，也避免过于粗略难以把控节奏。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“动作分解表”“影视导演镜头表”以及相关执行模板：
  - 分镜阶段用本模板整理出完整的动作脚本表格，将 A1/S1–S{N} 的动作信息与时长作为 sandbox_generate_video 调用时的脚本主干；
  - 视频阶段按脚本表格为镜头划分时间段，并与图像分镜和镜头表一起传入，确保模型在每段时间内执行对应的动作链。
- 一旦脚本表格中包含武打、追逐或高强度动作特效段落，视频 Prompt 的动作描述与运镜部分必须参考 `storyboard/vfx-action-prompt.md`：
  - 在对应时间段的 Prompt 中嵌入动量锚点运镜指令块，并按脚本表格的动作链构造“空间定位 + 战斗/动作氛围 + 连招 + 碰撞反馈 + 环境反应”的完整结构；
  - 对多镜头连续动作段，保证同一角色的特效描述逐段完全一致，遵守该文档的“特效描述跨段逐字一致”规则。
- 本模板适合与“动作导演镜头表”“打斗/竞技分镜”“操作流程分镜”等组合使用：脚本表负责执行层面的时间与备注，其他模板负责画面与动作设计，三者共同支撑高可执行性的动作视频制作流程。
