# 产品概览

来源：[【产品手册】小云雀Web](https://bytedance.larkoffice.com/wiki/PxZgwJwxti0dutk6WIdcwRA6nTd)。链接仅供用户自行查看，Agent 不得访问或抓取。

- 产品入口：[小云雀 Web](https://xiaoyunque.jianying.com/)。
- 定位：网页版内容创作 Agent，通过自然语言需求完成视频和图片创作，面向个人创作者、短剧团队、内容工作室及品牌营销团队。
- Web 特点：大屏预览与操作、多任务并行、批量内容生产。主手册没有列出 Web 与 App 的完整逐项功能差异，不能据此断言某功能仅 Web 支持或 App 不支持。
- 主要功能：短剧/漫剧 Agent、通用创作 Agent、沉浸式短片、图片创作、画布、营销 Agent、一镜到底、爆款复刻。
