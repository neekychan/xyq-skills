# 视频 Prompt 编写指南

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 写剧本式叙述（"表情从不解到悲伤"） | 模型无法理解抽象情绪 | 写视觉指令（"眉头紧锁，嘴角下撇，眼眶泛红"） |
| 动作只写结果（"下马靠近"） | 画面僵硬，缺少过程感 | 写出可见过程（"翻身下马，缓步上前"），有记忆点的动作才追加肢体+程度细节 |
| 逐帧编排每一拍动作 | 信息密度超载，指令执行率下降 | 动作链写概括性意图（"连续劈砍三刀""几组高抬腿和空翻"），相同动作不重复描写 |
| 长段只写一段笼统画面 | 模型自由发挥，节奏失控 | 9s 以上必须分画面阶段（细则见「Prompt 构造检查清单」#3），每阶段有独立重心 |
| 旁白说完后画面无变化 | 剩余时间变成角色呆坐/空等的死画面 | 每个画面阶段都必须有视觉事件（动作/运镜/环境变化），旁白覆盖的时间段和无旁白的时间段都要有独立的画面变化 |
| 段头先写入场/环境铺陈再进正题 | 开头 1-2 秒无叙事事件，节奏拖沓 | 进晚出早：起拍即核心动作/对白进行态——只删 agent 自产铺陈；用户明确写出的段头镜头与体裁首镜建置（开场钩子/爆款起手）除外 |
| 运镜只写"缓推至特写" | 速度/距离/方向不明确 | "3秒流畅前推轨，从中景推至面部大特写" |
| 无环境音效描述 | 画面无空间感 | 用 `<>` 标注至少1个环境音（`<风吹芦苇沙沙声>`） |
| 光影只写"月光"或"暖光" | 光源方向/色温不明确 | "残月从左上方45°斜照，冷白色月光投射树影，面部半明半暗" |
| 近景/特写材质只写物体名（"一双鞋""一盘肉""她的手"） | 画面平面无光影层次，缺质感 | 材质名 + 光如何作用于表面："鞋面漆光反射窗边冷光""肉排边缘焦褐纹理，油光渗出""指节皮肤纹理清晰，冷光下泛青白" |
| 台词/旁白与画面混写 | 模型难以区分说话时机 | 按分层结构：先写画面阶段，再在对应位置插入台词/旁白 |
| 旁白集中写在所有画面描述之后 | 每段开头 1-2 秒无声空窗，多段拼接节奏拖沓 | 旁白嵌入对应时间段的画面描述中，与画面同步启动 |
| 台词没写嘴部动作 | 生成"有声音但嘴不动"的旁白式画面 | → 见 `storyboard/dialogue-rules.md` 口型驱动规则 |
| 短视频塞过多台词 | 语速异常/台词截断/胡言乱语 | → 见 `storyboard/dialogue-rules.md` 台词节奏规则 |
| 多人场景空间/朝向/站位问题 | 全员挤同一平面、面朝镜头、跨段站位漂移 | → 见「多人场景的空间关系构建」「多人对话场景的跨段空间一致性」 |
| 连续运镜跨过过大景别或角度跨度 | 机位漂移，空间突然跳变 | 先判定连续运动还是切镜。连续运动写清起点、终点、移动方向、景别变化；跨度过大时明确切镜 |
| 单段塞过多核心动作 | 动作全部跳变/穿模/残缺 | 保留核心动作链，删除非核心细节；复杂物理交互优先改成中远景、遮挡、环境反馈、音效或动作结果镜头 |
| 长段没有时间锚点 | 动作顺序漂移，台词堆到结尾 | 逐阶段写"第0-3秒/第3-7秒/最后1秒"，每阶段先写起始状态再写动作变化 |
| 文学词/抽象词入 Prompt（武侠文言、四字成语、"以不可能的角度"等） | 摄像机拍不到，模型无法执行或产生 artifact | 替换为可观测画面："密集光痕快得看不清轨迹""双脚落地纹丝不动，肩背挺直""嘴角微微上扬" |
| 物体/武器/特效形变（剑身弯曲再弹直、数道剑影合一、光柱缩成一点、物体连续变形） | morphing 重灾区，形态连续变化导致严重崩坏 | 用一次性光与粒子替代形变：冲击白光、火星迸发、碎裂粒子、光痕拖尾；形变靠音效暗示（嗡鸣/弹响） |
| 台词被转述或漏写 `{}`（"她说要走"／`说：台词`） | 台词丢失或模型分不清说话内容边界 | 从用户原文逐字复制，用 `{}` 包裹：`说：{完整台词原文}`（口型句式见 `dialogue-rules.md`） |
| 言行矛盾不展示（"她笑着答应了"） | 只有情绪标签，潜台词不可见 | 同帧写身体与台词的裂缝："嘴角上扬说好，手中杯子攥紧，后退半步" |

## 核心原则

**Prompt 是视觉指令，不是故事文本。** 每一句话都必须可直接转化为画面元素（构图、动作、光影、运镜、音效）。模型只能看见画面、听见声音，不理解叙事逻辑和情感抽象。

**自检口诀：写每一句时自问"摄像机拍得到吗？"** 拍得到就留，拍不到就删。从 `creative_design.md` 取材时，比喻/习语/形变类描写必须在写入 Prompt 的当下即转译为可拍摄画面（光效、粒子、具体表情动作、音效），禁止先照抄原文再靠自审逐句返修。

**Prompt 做减法比做加法更重要。** 模型对信息密度有硬天花板——塞得越多，每条指令被执行的概率越低。写完 Prompt 后做一遍删除测试：**逐句删，删掉后画面核心不变的句子就不该存在。**

必须删除的"非视觉"内容：
- **比喻**："像盖上一个盒子"、"如潮水般涌来"
- **未作为音频输出的心理描写**："他心想"、"沉默本身就是回答"、"一阵酸楚涌上心头"。用户原文中明确需要保留的心声，按 `storyboard/dialogue-rules.md` 的内心独白规则写成可听见内容，并明确角色嘴唇紧闭
- **抽象情绪标签**："震惊地"、"悲伤地"、"温度彻底消退"
- **否定式描写**："不是咬牙，而是…"（模型只能拍"是什么"，拍不出"不是什么"）

应该写的"可视化"内容：
- **具体面部动作**："睫毛颤了一下"、"喉结滚动"、"眼眶泛红"
- **具体肢体动作**："肩胛骨后收，下巴微抬两厘米"
- **走位+空间关系**："从展柜后快步绕出，凑近对方半步"

> 台词/旁白语音规则 → 有台词或旁白时另加载 `storyboard/dialogue-rules.md`（判定见 §1.2c 加载总表）

## 画面描述的"可执行"深度

画面描述初稿是"发生了什么"，定稿是"观众看到什么、听到什么"。四个维度都要达到可执行级别：

| 要素 | ❌ 不够 | ✅ 可执行 |
|------|--------|----------|
| **空间** | "走廊昏暗" | "深色木质护墙板、冷调壁灯未亮、浅灰大理石地面，全景，角色居中全身入画" |
| **表演** | "表情变化" | "眉毛微蹙→嘴角下压→喉结滚动，内在强忍" |
| **光影** | "灯光昏暗" | "惨白顶光 vs 走廊冷光，玻璃隔断划出两个光区，面部半明半暗" |
| **音效** | "有声音" | "水流声(持续低)+碗碟碰撞(间歇)+皮鞋声(事件强)" 分层标注 |

- **质感底料**（写实/电影感场景）：可常驻一种悬浮介质，按题材换皮——剧情尘屑/汗雾、美食蒸汽、产品微粒、风光光束/花瓣，且必须绑定该阶段光线方向或角色动作，绑不上=堆砌，删；全片同一介质写入通用尾注一次
- **光影自检**：至少一个具名要素（方向/质地/色温三选一）落到可拍锚点，禁止"光线柔和/画面明亮"类空描述；色温已由通用尾注锁定时段内不重复

## 镜头语言骨架

每段 Prompt 的主体句应覆盖镜头、主体、时空、动作、情绪外化和画面质感：

`[景别]，[构图]，[机位角度] 拍摄 [主体] 在 [时间/空间] 中 [核心动作]，呈现 [行为趋势/情绪外化]。画面采用 [光影] 和 [色彩]，焦段为 [焦段]，[动态模糊/运镜]。`

使用骨架时按画面需要取舍，不机械填满；缺主体/动作/空间/光影中任一项，模型就会自由发挥。

### 镜头语言小型速查

| 维度 | 选择 → 适用场景 |
|------|----------------|
| 景别 | 远景/全景：环境、多人站位、宏大空间；中景：对话、常规互动；近景/特写：情绪爆发、细节、关键道具、口型 |
| 角度 | 仰拍：权威、压迫、英雄感；俯拍：弱小、被监视、空间全貌；过肩/背拍：对峙、窥视、避免全员直视镜头 |
| 焦段 | 广角：空间纵深、速度、夸张动作；标准：日常叙事、自然透视；长焦：压缩空间、突出孤立、虚化背景 |
| 光影 | 硬光/高对比：危险、冲突；柔光/低对比：温情、日常；逆光/侧光：神秘、神圣、内心冲突 |
| 构图 | 见「构图法速查」：三分法/中心对称/对角线/画框构图 |

### 布光法速查

用户指定布光法或需要精确控制面部光影时查此表，写在 Prompt 的光影描述位置：

| 布光法 | 情绪/适用 | Prompt 写法 |
|--------|----------|------------|
| 伦勃朗光 | 古典戏剧感、人物刻画 | "侧上方45度主光，暗部脸颊形成三角形亮区，古典油画质感" |
| 蝴蝶光 | 冷艳高级、气场强势 | "正面高位主光，鼻下投射对称蝴蝶阴影，凸显颧骨与下颌" |
| 硬质侧光 | 双面性、内心撕裂、审讯 | "90度硬质正侧光，左脸高光右脸全黑，明暗交界如刀刻" |
| 顶光 | 审判感、极度重压 | "单源顶光垂直照射，眼窝沉入浓重阴影" |
| 逆光轮廓 | 神圣感、空灵、英雄出场 | "大逆光勾勒发丝和肩膀轮廓，正面处于阴影中" |
| 底光 | 恐怖、诡异、超自然 | "底光自下而上照射，面部阴影方向反转，诡异扭曲" |

## Prompt 构造检查清单

构造完 Prompt 后、调用工具前检查：

**必查项（所有场景）：**

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | **素材引用完整** | 每个 `@图片N`/`@视频N` 都标注了用途（角色形象/场景/首帧/运镜参考） |
| 2 | **动作可见化** | 无只写结果的笼统动词（"靠近""离开""互动"）；动作链写概括意图，仅记忆点动作细化到肢体+程度，相同动作不重复描写 |
| 3 | **画面阶段化** | 9s以上按事件节拍分阶段，禁止均分。焦点、动作结果、空间、运镜或声画触发实质变化才新开；每阶段一个重心，前后状态衔接 |
| 4 | **叙事推进** | 观众看完这段多知道了什么？"没有新信息"→ 增加内容或缩短时长。纯空镜以时间事件（雾散/光移/灯亮）视为有效推进 |
| 5 | **空间关系**（≥2人） | ①对峙场景优先用过肩镜头；②每个画面阶段都标了绝对朝向（切镜后重标）；③同框精确描述 ≤3 人，多余降为背景；④对立双方朝向相对，无全员面朝镜头 |
| 6 | **指令覆盖** | 回溯用户原始输入，逐条确认每个具体要求（时长、比例、风格、台词、动作、场景、角色设定、BGM/音效/字幕）有对应落点。字幕落点规则见「防字幕/水印」 |

**推荐项（按场景选用）：**

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 7 | 运镜精确 | 用户指定项原样承接；Agent 自产连续运镜写清起终点、方向、景别、速度。变速、受力偏转或停住须由可见事件触发；下阶段承接出速，段末标明收稳、余振或同速。大跨度无法连贯则切镜 |
| 8 | 景别变化（13s+叙事） | 景别随主体焦点、动作结果、情绪或空间节点变化；无触发时保持连续，禁止定时轮换或为丰富而切镜 |
| 9 | 环境互动 | 至少1处环境元素变化（风/光/雾/水/粒子） |
| 10 | 风格锚定（多段拼接） | 全局风格关键词 + 质量约束已归入 `通用尾注`（只写一次），段 Prompt 内不重复；含段级差异的画面内文字/特效字幕等约束留在对应段 |
| 11 | 视觉叙事独立（有旁白/台词时） | 关掉声音只看画面仍能传递 ≥50% 叙事信息 |
| 12 | **核心属性前置** | 用户需求中的核心属性（颜色/材质/关键道具/风格）在 Prompt 开头和约束段各出现一次 |
| 13 | 长段时间锚点 | 9s 以上必须分阶段并写自然语言时间锚点；每个阶段总时长与 Duration 对齐 |
| 14 | 负向约束克制 | 只写短、具体、绑定对象的必要否定；禁止泛泛堆叠"不要崩坏/不要变形" |

> 有台词/旁白时的追加必查项 → 见 `storyboard/dialogue-rules.md` 检查清单

## Prompt 分层结构

按以下顺序组织 Prompt，每层独立可读：

```
第一层：素材绑定 + 音色绑定
  @图片N 的用途标注（角色/场景/道具/首帧）。角色只绑名字，禁止括号复写外观（括号槽位仅音色使用）
  有音色锚定时在角色定义处一并声明台词/旁白音色绑定（句式逐字按「音频符号规范」表）

第二层：一句话概述
  主体 + 地点 + 事件 + 题材/风格（+ 特殊运镜，仅贯穿全段时写），一句话让模型先拿到全局图景
  例：「写实纪录片风格，温暖午后的森林草坡上，一只熊猫幼崽从坡上滚下来」

第三层：画面阶段（按时间推进，台词/旁白/音效嵌入对应阶段）
  每个阶段开头先标注所有出场角色的位置+绝对朝向（面朝/背对镜头），切镜后必须重标
  阶段1 (0-Xs)：各角色起始状态(位置+朝向+姿态) → 运镜 → 动作变化(概括意图，记忆点动作细化) → 台词/旁白(嵌入动作对应时刻) → 环境互动 → <音效>
  阶段2 (X-Ys)：同上，起始状态承接阶段1结束状态
  台词句式：角色名嘴唇随每个字清晰地一开一合，说：{台词}。说完嘴唇合拢
  旁白句式：旁白：{旁白内容}

第四层：约束
  质量约束 + 风格关键词 + 技术参数（时长/比例）+ 贯穿全段的画面细节（机位基调/环境氛围/声音底床）
```

## 长段阶段化

长段不是把短 Prompt 拉长，而是把同一核心动作链拆成可执行阶段。

- 9 秒以上必须写自然语言时间锚点，8 秒及以下可选
- 时间锚点用秒级自然语言，例如"第0-3秒""第3-7秒""最后1秒"，禁止毫秒级、复杂表格或和 Duration 不对齐的时间段
- **时间轴必须连续无空洞**：相邻阶段首尾相接（0-3秒→3-7秒），禁止跳空（"0-3秒…5-6秒"）——空洞时段模型自由发挥
- **相对时间可用**：阶段内可写"3秒后周围的人纷纷摇头""按下快门后画面定格1秒"表达先后与停顿
- **禁止用时间戳控制频率/频次**（"一秒摇头3次"）——模型不兑现按秒计数的重复，写动作意图（"连续快速摇头"）
- 每个阶段先写起始状态：角色位置、姿态、朝向、视线、手中道具、环境锚点；再写动作变化
- 单段可包含多个阶段或事件，但必须形成可理解的时间线、因果链或主题目标；完全无因果关系且降密度后仍无法串联的内容，才按 `storyboard-format.md` 分段规则拆分
- 长段内部必须维持同一空间拓扑，禁止角色瞬移、反向奔跑、重复前阶段已完成动作
- 多句对白按时间顺序嵌入对应阶段，写清谁先开口、谁停顿、谁反应

## 多人场景的空间关系构建

模型不理解"深处""前方"的物理距离，只执行画面指令——谁占多大面积、谁在焦点上、中间有什么。

### 空间三要素（≥2人场景缺一不可）

| 要素 | 作用 | 不写的后果 |
|------|------|-----------|
| **景别** | 决定画面能容纳的空间范围 | 中景框不下远距对峙，模型强行把远处的人拉近 |
| **相对大小** | 用人物大小差异暗示远近（近大远小） | 所有人一样大 = 同一平面，无纵深 |
| **间隔物** | 两人之间可见的物理空间 | 模型无法判断距离，默认贴在一起 |

**写法公式**：`[景别] + [各人物相对大小（近大远小）] + [人物之间的可见空间]`

**人物大小用「景别 + 身体截取 + 相对大小」描述**（如"占近景大半画面""全身可见但身影明显偏小"），禁止用分数标注人物/产品大小（"占画面1/3"）——分数不在模型训练语言内，不兑现且跨段不可校准；分数仅可描述画面区域带（"地平线位于画面下三分之一"）。几何级精确构图交给参考图/首帧，Prompt 只写景别与运动。

**朝向必须用绝对朝向**：写「背对镜头」「面朝镜头」「侧身朝左/右」，禁止只写「面朝某人」——模型不理解相对朝向。

### 对峙场景的朝向控制

模型倾向于让所有角色面朝镜头。以下写法按执行可靠性排序：

**首选：过肩镜头**——写「过肩镜头，从A肩后拍向B」，模型几乎必定让A背对、B面朝镜头。肩入前景的一方 = 此刻施压方（逼迫/摊牌戏从施压者肩后拍被逼者）。红线：过肩阶段只允许面朝镜头一方带口型说台词；背对方要开口，先切正反打，或该句按画外声处理（不写嘴部动作）。

| 场景 | 写法 |
|------|------|
| 对话对峙 | `过肩镜头，从A肩后拍向B。A背对镜头作为右侧前景只露后脑和肩膀，B在画面左侧中景面朝镜头` |
| 2v1 战斗 | `镜头在A身后。A近景背对镜头，画面深处B和C面朝镜头冲来` |
| 撤离/远去 | `镜头在角色身后。A和B背对镜头向画面深处远去` |

**次选：前后纵深**——近景方「背对镜头」身形大，远端方「面朝镜头」身影小，写明间隔物。

**慎用：侧身朝向**——动作密集时易被忽略，退化为全员面朝镜头。仅在需要同时看到双方表情时使用。

**口型-机位对齐**：近景说话人需要正脸口型时，主镜头景别定为中景/中近景/近景，机位词禁止再冠「全景」「远景」「侧拍」——远机位与「面朝镜头、占近景大半画面」互斥。远端角色用「画面深处身影明显偏小」带过，不与近景说话人争夺同一机位定义。

### 同框人数控制

每个画面阶段精确描述朝向的角色 **≤3 人**。超过时次要角色降级：`画面边缘闪过C的身影` / `画外传来C的声音` / `背景中C的模糊身影`。禁止同一阶段为 ≥4 人各标位置+朝向。

**旁观者不静止、反应不同步**：降级/虚化的在场角色至少带一个微动作（视线追随、呼吸起伏、手中物停顿），禁止静止布景；多人反应写先后层次（谁先僵住、谁半拍后抬头），禁止"纷纷/同时"式同拍反应——群体场面写 2-3 个有先后差异的个体动作，其余背景带过。

| ❌ 缺要素 | ✅ 三要素齐全 |
|----------|-------------|
| `中景。A在画面深处，B在画面右侧` | `中近景。B骑马在画面右侧面朝镜头，占近景大半画面；A在画面深处山道正中，全身可见但身影明显偏小。两人之间是十余步空旷石径` |

### 景别与空间容量

人物间距超出景别容量时，模型会压缩距离：贴身~1步→近景/中景；2-5步→中景/全景；5步以上→全景/远景；极远（渺小感/两军对峙）→远景/大远景。**判据**：距离超过 5 步却用中景 = 距离被压缩，换全景/远景，或分两个画面阶段交替切单人。

### 相对大小暗示远近

近→远档位：充满画面 / 占近景大半画面（胸部以上）→ 腰部以上入画为画面主体 → 全身可见但身影明显偏小 → 远端小人影/剪影。同框两人档位差越大距离感越强；近端取高档、远端取低档。

### 常见空间关系速查

| 关系 | 景别 | 写法要点 |
|------|------|---------|
| 拦路对峙 | 全景/远景 | 一方远端（小）一方近景（大），写明间隔；或分阶段先拍A视角再切B |
| 尾随跟踪 | 中景跟拍 | 被跟者在前方，跟踪者在后方虚化，写明间距 |
| 围困包围 | 仰拍全景 | 被围者居中（小），包围者从四周边缘挤入（大/局部） |
| 并肩同行 | 侧面中景 | 两人间距一臂，步伐同向，侧面跟拍平移 |
| 隔物对望 | 中景/全景 | 写明隔断物（窗/栅栏/河流），两人分占两侧 |
| 居高临下 | 仰拍+俯拍切 | 高处者俯拍在上、低处者仰拍在下；或全景侧拍写明高度差 |
| 追赶 | 跟拍全景 | 逃者在前（背影）追者在后（正面），写明间距递减 |

## 环境锚点与物理反馈

动作连续性依赖具体物理物件，不依赖叙事解释。剧烈动作必须绑定环境锚点（石头堆/柜台角/门框/栏杆/台阶/墙面等），写清接触关系：背部撞在石头堆上、手扣住柜台边、膝盖跪在台阶上。后续阶段/段承接时继续写同一锚点及物理反馈，避免环境凭空消失。禁止只写"被扑倒""撞了一下"；必须写倒在哪里、撞到什么、用哪只手支撑、身体朝向哪里。

## 多人对话场景的跨段空间一致性

跨段镜头不锁定空间关系，人物相对位置就会每段漂移。**生成多段对话戏前，先定下两件事，逐段原样复制**：

1. **站位锁（一句固定文本）**：写清每个人的固定位置+朝向+相对关系（例：`三人围红木圆桌：张大叔坐画面右侧面向左、黄老爷坐主位正对镜头、师爷坐画面左侧面向右`），所有段落逐字复制这句——缺了它各段就会座位各写各的。切机位只是摄影机换角度，人物**绝对位置不变**。

2. **轴线锁（180° 规则）**：选定一条贯穿对话的假想轴线，所有机位在轴线**同一侧**做推/拉/环绕；跨轴会导致左右关系翻转（A 本在左变到右）。

> 本节只针对**拆成多段并行生成**的对话戏；单段一次生成内部空间自洽，不受此限。

## 任务类型与句式

三种基本任务类型，句式不可混用：

| 类型 | 句式 | 说明 |
|------|------|------|
| 参考 | `参考@图片N中的[主体]` / `参考@视频N中的[动作/运镜]` | 提取素材元素生成新内容 |
| 编辑 | `严格编辑@视频N，将[原特征]修改为[新特征]` | 在原视频上局部修改 |
| 延长 | `延长@视频N，[后续内容]` | 时间维度续写原视频 |

**⚠️ 编辑/延长任务中直接用 `@视频N`，禁止写成"参考@视频N"，否则模型会误判为参考任务。**

**参数锁定**：编辑/首尾帧/延长任务的比例（编辑任务还含时长）由模型锁定对齐输入素材，被锁定的参数禁止再写进 Prompt——冲突指令不兑现，只耗注意力。锁定明细与首尾帧画幅要求见 `storyboard/prompt-patterns.md`「参数锁定」。

## 素材引用系统

**IMPORTANT**：Prompt 中素材引用只允许官方命名 `@图片1`~`@图片9`、`@视频1`~`@视频3`、`@音频1`~`@音频N`；禁止 `@图N`、`图片N`、`图1`、原始文件名等非标准引用。

**引用-传参一致（调用前红线）**：Prompt 中每个 `@图片N`/`@视频N`/`@音频N`，对应 List 的第 N 项必须存在且为 sandbox 实际路径；引用无落点 → 禁止发起调用，先补齐 List。素材多时逐个标注用途，避免图、视频、角色混淆。

### 图片引用

| 用途 | 写法示例 |
|------|----------|
| 角色形象 | `参考@图片1的形象作为{角色名}` / `@图片1的女生作为主体` |
| 场景环境 | `@图片2作为{场景名}` / `@图片3作为背景` |
| 首帧/尾帧 | `@图片1 作为首帧画面` / `@图片1 作为尾帧画面` |
| 画面状态参考/物品/材质 | `@图片1 作为该次视频前的画面状态` / `手中提着@图片3的包` / `材质参考@图片3` |

### 视频引用

| 用途 | 写法示例 |
|------|----------|
| 运镜/动作/特效复刻 | `@视频1仅参考运镜节奏与轨迹，不继承其人物、场景与色调` |
| 延长视频 | `延长@视频1 5秒`（Duration 为新增时长） |
| 音色参考 | `旁白的音色参考@视频1` + 补充音色特点描述 |

使用参考视频必须标注具体用途（动作/运镜/节奏/特效/场景氛围/音效之一或多种），并用"仅参考X，不继承Y"句式排除人物身份、场景、色调；禁止"参考@视频1"或"完全参考所有效果"式全量引用——模型会把参考视频中的无关主体一并带入。参考运镜且新画面与原视频内容不同时，配合`[时间+动作/画面]`落到本段：`参考@视频1的一镜到底环绕跟拍，0-6秒镜头从右侧跟拍主角前行扫过货架，6-10秒环绕至主角右侧`；参考素材本身已足够精准（动作/运镜照搬）时只做指代（`严格参考@视频1的动作与运镜，顺序保持一致`），不再复述具体细节。MV 的音频驱动句式按 `storyboard/mv-prompt.md` 执行，不改写成参考视频句式。

### 音频引用

音色锚定句式逐字按「音频符号规范」表。使用参考音频必须标注具体用途（音色/语速/情绪/呼吸/环境声/节奏）；只参考音频时，不要凭空要求参考图片或视频。

## 主体定义

多主体场景逐个绑定素材，格式：`参考@图片N的形象作为[角色名]`；禁止复写图上可见的静态外观（发色/五官/服装）——视觉锁定由参考图承担，文字只写图上不可见或本段需改变的特征。一张图含多人需区分个体时，用一个可辨识特征定位（如"@图片N中左侧黑衣者作为[角色名]"）。角色参考用三视图设定稿，重要角色排 prompt 前部。后续每次提及主体必须明确指代，禁止省略。

## 音频符号规范

| 内容类型 | 符号 | 写法 |
|----------|------|------|
| 音乐/BGM | （） | `（背景播放快节奏摇滚乐）` |
| 音效 | <> | `<远处传来狗叫声>` |
| 台词（有音色锚定） | {} | 第一层声明 `参考@图片N的形象作为{角色名}，台词音色参考@音频N（{音色具体描述}）`；画面阶段中只写 `角色名嘴唇张合说：{完整台词}` |
| 台词（无音色锚定） | {} | `角色名（音色特征），表情，说：{完整台词}` |
| 旁白（有音色锚定） | {} | 第一层声明 `旁白音色参考@音频N（{音色具体描述}）`；画面阶段中只写 `旁白：{旁白内容}` |
| 旁白（无音色锚定） | {} | `旁白（音色特征）：{旁白内容}` |
| 画面内文字/特效字幕 | 【】 | `【手机屏幕显示：登机口关闭】` / `【术法文字：风】` |

小语种台词需标注语种：`用日语说道{こんにちは}`

**声音分层纪律**：`<>` 内区分两层——**环境床**（持续低强度底噪，如 `<雨声持续，低>`）与**事件音**（绑定可见动作源，如 `<玻璃碎裂，同步碎片飞溅>`）。事件音必须能在画面中找到发声动作；只写"有声音"或只堆环境音 = 不合格。所有声音（人声、事件音、环境床）与画面同一时间锚点绑定、嵌入对应画面阶段，禁止堆到 Prompt 末尾。

## 质量约束（附加在 prompt 末尾）

**用户显式要求优先**：以下所有默认约束在用户明确要求相反操作（如要 BGM/特定风格）时必须让步。用户明确要求普通字幕时，只记录到后续合成参数 `show_subtitle`，不得让视频模型在画面中生成台词字幕、旁白字幕或对白字幕。

**进尾注 vs 留段内（多段视频）**：多段视频中，全片每段逐字相同的约束合并写入 storyboard.md 的 `通用尾注` 小节，不在任何 `shot_NN` 的 Prompt 里重复；由主 Agent 视频生成时原样拼到每段 Prompt 末尾。**进尾注**：整体风格词（画风/渲染/配色/光线/色温/比例）、**色板锚点（原样搬运 creative_design.md 整体风格中已命名的主色/辅色/点缀色，全片逐字一致，禁止分镜层新造；无 creative_design.md 时按主色 1 + 辅色 1-2 + 点缀色 1 命名并全片沿用）**、角色稳定、画质兜底、防水印/logo、禁 BGM、保持无字幕。**留段内**（有段级差异，禁止进尾注）：剧情明确需要的画面内文字/特效字幕（清单见「防字幕/水印」）、旁白/台词嵌入画面阶段、每段自己的画面/运镜/焦段/光圈/景深/衔接锚点。单段视频无 storyboard.md，下列约束照旧直接写进该段 Prompt 末尾。

**角色稳定**（进尾注）：`五官清晰不变形、人体结构正常、服装发型一致`

**画质兜底**（进尾注）：`4K超高清、画面稳定无模糊、电影质感`。焦段、光圈、景深按对应画面阶段写，禁止进尾注

**防字幕/水印**：`不要生成水印，不要生成logo，保持无字幕` 进尾注。普通/旁白/台词/对白字幕不写入任何视频 Prompt，由后期对整片统一添加。只有画面叙事本身需要的文字可写入 Prompt，例如弹幕、手机屏幕文字、招牌、术法文字、漫画拟声词、UI 文案、标题卡等；这类文字必须服务画面内容，不得用来复刻旁白/台词全文。

**禁止BGM**（≥2段拼接时进尾注）：`禁止生成BGM，保留自然环境音效`。`（）` 括号内的指定音乐指令仍然生效，写在对应段内。单段视频可保留 BGM。

**负向约束原则**：负向约束只在必要时使用，必须短、具体、绑定当前镜头对象。先写清正向画面，再写否定约束。正确：`不要生成字幕`、`不要让角色直视镜头`。错误：`不要崩坏、不要变形、不要模糊、不要奇怪`。


## Prompt 技术参数

Prompt 开头或末尾明确技术规格：`时长：10秒，比例：16:9`。被模型锁定的参数不写（见「任务类型与句式」参数锁定）。
## 竖屏 vs 横屏

竖屏（9:16）生成字幕和胡言乱语的概率**显著高于**横屏（16:9）。**用户已指定比例时照用，禁止改判**；仅用户未指定比例时才优先选择横屏。竖屏+大量台词时，时长不要远超内容量，并在尾注强化防字幕约束。

## 运镜体系

**动态描述顺序**：镜头/运镜 → 主体动作与表情 → 空间位置变化 → 音频信息。

### 运镜指令表

写 Prompt 时从下表选取运镜写入。禁止自由描述运镜（如"镜头慢慢飘过去"）。

**固定与摇移**（机位不动，镜头转向或不动）：

| 运镜 | Prompt 写法 |
|------|------------|
| 固定镜头 | 运镜：固定机位，镜头位置和拍摄方向都保持不变，画面构图稳定，由主体动作或画面内部变化形成运动感。 |
| 镜头上/下/左/右摇 | 运镜：固定机位[方向]摇，镜头位置不移动，只沿垂直/水平方向转动，画面重心向[方向]连续变化。 |

**推拉与变焦**（机位前后移动，或焦距变化）：

| 运镜 | Prompt 写法 |
|------|------------|
| 镜头前推/后拉 | 运镜：镜头[前推/后拉]，机位沿镜头朝向向[前/后]移动，主体在画面中逐渐[变大/变小]，空间层次产生自然视差。 |
| 变焦推进/拉远 | 运镜：变焦[推进/拉远]，机位保持不动，只通过焦距变化让画面范围逐渐[收紧/放宽]。 |
| 急速变焦 | 运镜：急速变焦推进，机位保持不动，画面范围快速收紧到目标区域，形成突然强调。 |
| 柯克变焦 | 运镜：希区柯克式变焦，机位移动与反向变焦同时发生，主体大小基本保持稳定，背景透视发生明显变化。 |

**平移与升降**（机位整体位移）：

| 运镜 | Prompt 写法 |
|------|------------|
| 镜头左/右移 | 运镜：镜头[方向]移，机位整体横向平移，拍摄方向基本不变，前景与背景形成自然视差。 |
| 镜头上升/下降 | 运镜：镜头垂直[方向]，拍摄方向基本稳定，机位高度连续变化，视角随之变化。 |

**环绕**（绕主体旋转）：

| 运镜 | Prompt 写法 |
|------|------------|
| 环绕拍摄 | 运镜：环绕拍摄，镜头围绕主体平稳旋转约180度，主体保持在画面核心位置，背景产生连续旋转视差。 |
| 盘旋抬升/下降 | 运镜：盘旋[方向]，镜头围绕主体旋转的同时逐渐升高/降低，主体保持锁定。 |

**跟拍**（镜头跟随主体运动）：

| 运镜 | Prompt 写法 |
|------|------------|
| 跟随拍摄 | 运镜：跟随拍摄，镜头跟随主体运动方向移动，与主体保持相对稳定的距离和构图。 |
| 迎面跟拍 | 运镜：迎面跟拍，镜头位于主体前方并随其运动同步后退，保持正面信息稳定可见。 |
| 侧面跟拍 | 运镜：侧面跟拍，镜头在主体侧方与其平行移动，构图稳定并形成横向空间视差。 |
| 手持拍摄 | 运镜：手持拍摄，镜头带轻微自然晃动和近距离临场感，可随主体动作产生小幅调整。 |
| 稳定器行进 | 运镜：稳定器行进，镜头以稳定、连续的方式向前或跟随移动，运动平滑，晃动幅度低。 |

**主观与航拍**：

| 运镜 | Prompt 写法 |
|------|------------|
| 第一视角 | 运镜：第一视角，镜头模拟角色视线和身体移动，带轻微头部晃动和主观视角的运动反馈。 |
| 穿越机运镜 | 运镜：穿越机运镜，镜头以第一视角高速穿行空间，贴近场景边界和主体灵活飞行，带明显速度感与滚转俯仰变化。 |
| 高空航拍 | 运镜：高空航拍，镜头以高角度俯视画面，并保持稳定滑行，用于呈现空间关系和整体布局。 |
| 俯冲下降 | 运镜：俯冲下降，镜头从高处向目标方向快速下降并靠近，形成明显速度感和压迫感。 |
| 拉升离场 | 运镜：拉升离场，镜头从主体附近向后上方移动，主体逐渐变小，画面范围扩大。 |

**转场与特殊**：

| 运镜 | Prompt 写法 |
|------|------------|
| 横滑揭示 | 运镜：横滑揭示，镜头从遮挡关系中横向滑出，逐步露出被遮挡的主体或关键信息。 |
| 前景擦过 | 运镜：前景擦过，近处遮挡物从镜头前掠过并短暂覆盖画面，随后露出新的画面内容。 |
| 穿越镜头 | 运镜：穿越镜头，镜头持续快速向前推进，并产生短暂运动模糊，穿过明确的前景边界或空间层次，进入后方画面，最后落到新的构图或目标上。 |
| 甩摇 | 运镜：甩摇，镜头快速水平转动并产生短暂运动模糊，最后落到新的构图或目标上。 |
| 焦点转移 | 运镜：焦点转移，镜头位置可以不变，焦点从一个画面层次平滑切换到另一个画面层次。 |
| 子弹时间 | 运镜：子弹时间，主体动作骤然极慢近乎凝固，镜头围绕凝固的主体快速环绕，随后动作恢复正常速度。 |
| 回弹变速 | 运镜：回弹变速，画面在动作高点骤然减速拉长，随后猛然加速回弹至正常节奏，形成节奏顿挫感。 |

### 运镜要诀

- **组合运镜写清关系**：一个画面阶段可用多个运镜（如手持跟拍 + 甩摇、缓推 + 焦点转移），组合时写明叠加还是先后、先后则标清切换时机（如"前 2 秒缓推，随后甩摇至新目标"）；运镜服务于画面内容，禁止堆砌与主体动作无关的运镜指令
- 运动类运镜必须带速度（`缓慢`/`快速`/`N秒内完成`）：用户指定则继承，未指定按段落情绪取；固定机位类除外

### 构图法速查

| 构图 | 写法 | 效果 |
|------|------|------|
| 三分法 | "角色置于画面右侧三分线，左侧大面积留白" | 平衡、留白叙事 |
| 中心对称 | "角色精准踩在画面中轴线，两侧建筑镜像" | 秩序/压迫/仪式感 |
| 对角线 | "屋脊线条从左下角直插右上角" | 动感、失衡张力 |
| 画框构图 | "透过拱门/窗框/门缝向内拍摄" | 引导视线+纵深 |

> 反光叙事："聚焦于刀面/水面/镜面倒影中呈现另一角色"——倒影写成模糊/变形的虚影，禁止倒影中出现可看清五官的人脸；焦点转移、前景遮挡揭示按运镜指令表的「焦点转移 / 横滑揭示 / 前景擦过」标准写法使用

## 避雷事项

- **模糊形容词**：好看/很美/很酷 → 用具体描述（如"金色逆光勾勒轮廓线"）
- **剧烈动作按体裁 ref 写**：用户要求的打斗/追逐/跑酷按 `storyboard/vfx-action-prompt.md` 的空间定位+动量锚点写法执行（未加载时补加载），禁止擅自降速改成缓慢温吞动作；日常走动写"缓步/自然步态"减少滑步。真弱项规避见下方"模型已知弱项规避"
- **矛盾要求**：超高速 + 极度稳定等互斥指令
- **台词保真**：禁止用"说台词"替代完整对白；`{}` 内台词/旁白必须从 creative_design.md / storyboard.md / 用户原文逐字复制，禁止同义替换、缩写、润色、拆句重组
- **搜索图只准参考外形**：搜索图禁止原图直接生视频，必须重绘。引用语限定"仅参考@图片N的外形与结构"
- **风格漂移**：动漫/2D/3D 必须在 prompt 中明确声明，否则偏移为写实
- **图像模型令牌**：8K/虚幻引擎5/masterpiece/RAW/Lumen 等图像生成词禁止入画面描写与风格串——视频模型不兑现，只耗注意力；画质由尾注"4K超高清"统一承担，段内质感用材质/光影/纹理表达
- **时长超出内容量**：时长远大于内容量会导致胡言乱语/重复台词，应缩短时长
- **超过 4 人场景**：先分批生图（每张≤4人），再用多张图生成视频
- **模型已知弱项规避**：复杂机械变形用中景/全景规避细节，或拆段。多人紧密肢体接触（拥抱/搬运/扑倒）用镜头暗示代替正面拍摄

## 多段拼接 Prompt 注意事项

以下规则仅适用于多段拼接（总时长 >15s）：

- **音色跨段一致**：有音色锚定音频的角色/旁白，AudioList 传入对应 voice mp3，在 Prompt 第一层角色定义处用 `@音频N` 绑定音色；绑定与退回句式按本文件「音频符号规范」表执行
- **角色反指代锚定**：每段提及角色必须用角色名回指，禁止"她/他/那个人"等空指代——无状态生成不跨段记忆代词，弱锚会让模型当成新人物换脸。角色名已在段首绑定 `@图片N`，回指无需重复外貌描述
- **每段完全自包含**：`sandbox_generate_video` 无状态，每次调用完整描述画面。素材逐段准入：只传本段真正出镜的角色/场景/道具图与本段真正发声的角色/旁白音色，不出镜的角色图、不发声的音色禁止传入——否则角色串镜、音色错配；同一角色在哪几段出镜就在哪几段各自传入
- **画面状态衔接**（仅 storyboard 中标记了 `⇐NN` 的段）：将 `shot_NN_lastframe.png` 作为 ImageList **第一张**，Prompt 开头写 `@图片1 作为该次视频前的画面状态`，其余素材从 `@图片2` 起顺延编号。用于衔接同场景连续段之间的空间方位。判定规则和示例见 `storyboard/storyboard-format.md`「衔接机制」
- **场景参考图跨段统一**：同一场景的多个段落必须使用同一张场景参考图。禁止因景别变化而切换场景图（如全景用 scene_A，特写用 scene_B）——这会导致环境突变
- **风格与质量约束收进通用尾注**：分拣规则见本文件「质量约束」的「进尾注 vs 留段内」
- **Duration 匹配内容密度**：内容足→给足，内容少→别注水。台词所需秒数以 `count_chars.py` 输出的耗时区间为准，禁止按字数手算
- **AudioList 禁止无图使用**：传入 AudioList 时 ImageList 不能为空——至少传入角色参考图或场景参考图作为画面锚定，避免纯音频参考导致画面失控
