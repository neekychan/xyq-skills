# 营销广告创作指南

广告不是"把产品拍好看"，是**用一个观众潜意识熟悉的叙事节奏，让品牌成为情绪的答案**。本指南两部分：先挖洞察（创意根基），再选叙事结构（A-H 8 类）。

## 一、洞察挖掘：创意的情感根基

**洞察不是事实、不是数据、不是消费者说的话**——洞察是消费者内心深处的**矛盾**，说出来会让他们觉得"对，就是这样，但我从没想过怎么表达"。没有好洞察，创意就没有情感根基。

### 输出格式（一句话锁定）

> **「[受众] 想要 [X]，但 [Y] 挡在路上，因为 [Z]」**

示例：
- "年轻妈妈想要无罪恶感的独处时间，但社会期望让她们觉得'自私'，因为'好妈妈'的定义从不包含'照顾自己'"
- "Z世代想展示真实自我，但点赞机制让他们不自觉表演，因为'真实'本身已变成一种人设"

### 四种发现方法（按需选用，不必全跑）

| 方法 | 怎么做 |
|------|--------|
| **张力发现** | 找受众内心矛盾：文化张力（社会说X但人们想Y）/ 品类张力（品类承诺X但体验是Y）/ 人性张力（知道该X但控制不住Y）。撕扯面→冲突段，释放面→高潮段 |
| **JTBD** | 问"消费者雇佣产品完成什么任务"，分功能任务/情感任务/社交任务三层。**广告应打情感任务** |
| **HMW** | 把问题写成"我们如何能…"，写窄/中/宽 3 个粒度，选**中等粒度**作创意起点（太窄受限，太宽失焦）|
| **假设颠覆** | 列 5 个品类内"理所当然"的假设，逐一问"如果反过来呢？" |

### 洞察质量 6 点检验（全过才能用）

1. **真实**——基于真实行为/心理，不是臆测
2. **共鸣**——受众会说"对，就是这样"
3. **张力**——含矛盾或冲突，不是平淡事实
4. **可创作**——能自然延展出画面，不是死胡同
5. **专属**——竞品无法用同样的洞察（"我们关心你的健康"谁都能说 = 不合格）
6. **简洁**——一句话能说清（需一段话解释 = 不够锋利）

### 洞察 → 叙事映射

| 洞察组成 | 映射到广告结构 |
|---------|--------------|
| "[受众] 想要 [X]" | 开场段——建立情感认同（"这说的就是我"）|
| "但 [Y] 挡路" | 冲突段——制造叙事推力 |
| "因为 [Z]" | 转折段——揭示深层原因（"原来是这样"）|
| 品牌如何解决 | 高潮/产品出场——品牌作为转折点 |
| 解决后的新状态 | 收束段——品牌锁定 |

## 二、A-H 8 类叙事结构

选对类型 = 给观众一个潜意识熟悉的节奏，再在节奏里制造惊喜。每类有固定的叙事结构、情绪曲线、阶段时长占比。

### 类型速查

| 类型 | 叙事结构（阶段·占比） | 情绪节奏 | 适合品类 |
|------|---------------------|---------|---------|
| **A 问题-解决** | 痛点20% → 产品出场15% → 效果展示25% → 情感升华25% → 品牌15% | 低开→转折→高走→余韵 | 快消、日用、功能性产品、家电、SaaS |
| **B 情绪叙事** | 氛围铺垫15% → 故事发展35% → 情感高潮30% → 品牌揭晓20% | 慢起→层层递进→爆发→柔落 | 品牌形象片、高端、节日、公益、金融、教育 |
| **C 产品展示** | 视觉冲击15% → 卖点逐展30% → 使用场景25% → 技术背书15% → 收尾15% | 高开→波浪递进→柔落 | 科技、汽车、美妆、消费电子、相机 |
| **D 悬念反转** | 悬念铺设30% → 误导加深25% → 反转揭晓30% → 品牌15% | 好奇→确信→打碎→重建 | 创意广告、病毒传播、年轻化、品牌重塑 |
| **E 生活方式** | 生活场景30% → 态度表达25% → 品牌融入25% → 调性收尾20% | 音乐驱动→画面跟拍→态度输出 | 运动、时尚、饮料、旅行、户外、潮牌 |
| **F 对比** | 使用前/对比25% → 差异放大25% → 产品解答30% → 品牌20% | 不满→惊讶→信服→满足 | 护肤、清洁、效果类、美发、家居改造 |
| **G 名人/KOL** | 名人登场20% → 产品互动25% → 生活场景30% → 品牌背书25% | 识别→好奇→信任→认同 | 各品类（尤其美妆、时尚、食饮、奢侈品）|
| **H 仪式/降临** | 感官铺垫15% → 细节蓄力25% → 存在揭示20% → 力量展现25% → 余韵15% | 极慢蓄压→断裂释放→突然寂静 | 概念车/旗舰发布、奢侈品、高端科技、超跑 |

### 类型专属创意红线

- **C**：卖点数量随时长缩放——15s 1个 / 30s 2-3个 / 60s 4-5个，超上限砍卖点不加时长
- **D**：误导必须真诚——观众不知道有反转时，误导段单独看完全合理
- **E**：展示"向往但不一定拥有"的状态；剧本加不完美元素（摔倒/出汗/大笑）增真实
- **F/G**：对比变化幅度真实可信（不"一夜变个人"）；名人写成"可信的使用者"，先立个人魅力再引入产品，不是代言人念卖点

各类型的具体景别/机位/运镜由分镜阶段按 `storyboard/marketing-prompt.md`「各类型镜头语言要点」实现，禁止写进 creative_design.md。

### 时长缩放通则

- **15s**：只适合 A/C/F（节奏快、可压缩）。砍中间段，保留"钩子→核心→品牌"。B/H 不推荐（蓄压需时间）
- **30s**：D 悬念反转最佳时长；E/F 也适配
- **60s**：全部类型均可，标准展开
- **90s+**：B/E/H 最佳；D 不推荐（太长会被猜到反转）

### 结构选择决策

| 品类/目的 | 首推 | 备选 |
|----------|------|------|
| 快消日用 | A | F |
| 品牌形象片 | B | H |
| 科技/汽车新品 | C | H |
| 概念车/奢侈品 | H | B |
| 创意/病毒 | D | E |
| 运动/时尚 | E | G |
| 护肤美妆 | C | F |
| 食品饮料 | E | A |
| 节日/公益 | B | D |

**混合类型**：可混合，但指定**主类型60-70% + 辅类型30-40%**，避免五五开两边做不透。常见组合：A+D（悬念包装痛点）、C+E（卖点+生活场景）、B+E（群像蒙太奇+情感弧线）。

选定类型（含混合主辅比）在 creative_design.md `剧本设计` 的总时长预算行后注明（如「结构：C 产品展示70% + E 30%」），供分镜阶段按类型选取镜头语言。

## 三、创意方案具象化铁律

写广告创意方案时，每个阶段必须是**具体画面描述**（观众看到什么），不是抽象概念。

| ❌ 抽象（禁止） | ✅ 具象（要求） |
|---------------|---------------|
| "用铁粉表达引力隐喻" | "车前3米地面积水被车头灯照亮，倒影出完整车头轮廓" |
| "展现科技感/高级感" | "产品在纯黑背景中显得高大而有压迫感，硬光勾出棱线轮廓" |

**判断标准**：如果方案需要"隐喻/象征"才能传达，说明太抽象。好方案靠视觉策略传情绪——展示什么、不展示什么、什么光影氛围、什么节奏；具体景别/机位/运镜由分镜规划实现。品类惯例反转时，反转的是展示**方式**，不是用隐喻**替代**产品展示。

## 四、失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| 跳过洞察直接想画面 | 创意没情感根基，自嗨 | 先用"想要X但Y挡路因为Z"锁定洞察 |
| 选错叙事类型 | 节奏与品类不匹配 | 按品类决策表选主类型 |
| 痛点/卖点用文字字幕堆 | 像说明书不像广告 | 用画面行为呈现（防水=水下拍，不打"IP68"）|
| 品牌硬贴在结尾 | 观众无感 | 品牌是情绪的答案，与高潮无缝衔接 |
| 创意方案写成抽象概念 | 无法转成 Prompt | 套具象化铁律，能画出分镜草图才合格 |
