# 萌宠视频红线与强制规则

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 动作写给"手"（"宠物熟练地操作工具"） | 爪子渲染成人手 | 写"前爪/肉垫"+具体持物方式，Prompt 末尾加"画面中禁止出现人类手部" |
| 一拍塞多个精细动作（磕蛋+刷酱+卷饼） | 动作穿模、跳变 | 一拍一动作，每 2-3 秒一个动作单独白描 |
| 把动物素材"转换为人类面孔/人体" | 主体丢失 | 保留动物头脸与体型；人类角色设定由动物按拟人层级来演，靠服饰道具+口型+姿态实现 |
| 多动物同框不锁体型与花纹 | 巨型猫、角色互换 | 每只写"正常家猫/犬体型"+毛色花纹差异点，每段重复 |
| 不指定音色 | 成年人声配奶猫 | 按体型/年龄锁音色：幼猫幼犬=软萌奶气童音，跨段逐字一致 |
| 默认用 3D 卡通/动画画风 | 破坏萌宠视频的真实感（vlog/日常尤其忌讳） | **萌宠视频默认真实/写实画风**——大部分萌宠内容要的就是"真的猫真的狗"，动画风基本没必要。只有两种情况用卡通：① 用户明确要求卡通/动画/Q版；② L4 卡通 IP（本质就是卡通形象）。L3 直立拟人同样默认写实，模型可稳定生成真实画风的两足直立，不要用卡通规避或降级到 L2 |
| 人类配角入镜（含"只露一只手"） | 人手/人体渲染崩坏 | 人类配角一律不入镜：交互改为画外音示意或物品递向镜头 |

## 强制规则

1. **先定级再创作**：层级判定先于风格、分镜、台词等一切决策
2. **物种习性落进分镜（真实感的核心）**：
   - 动作用行为学动词：嗅、蹭、踩奶、竖耳、摇尾、歪头、舔爪等具体动词，禁用"开心地玩耍"类抽象词
   - **情绪外化优先用身体语言**——尾巴/耳朵才是猫狗的"表情"：开心=猫尾竖直微弯+呼噜声 / 狗大幅摇尾吐舌；害怕紧张=飞机耳 / 夹尾巴；烦躁=猫尾快速甩打；亲昵信任=慢眨眼、蹭脸颊 / 舔脸。比给动物安拟人表情更像"真的"（L1/L2 必须；L3/L4 也保留 1-2 个物种签名动作，如卡通猫也要有猫式伸懒腰）
   - **每个分镜至少顺带一笔习性小细节**：主线动作之外补一个"没用的小动作"（等待时舔爪理毛、路过纸箱忍不住看一眼、狗睡前原地转三圈再卧下）——这些恰恰是养宠观众认证"像真的"的来源
   - 习性可做反差梗：嘴上说不怕、耳朵已压成飞机耳——正是情绪杠杆「身体诚实」的原料
   - 对该物种/品种的习性拿不准时，用 `pippit_omni_search`（`text`）搜一下再写，禁止凭想象编造习性
3. **爪部白描**：L2 及以上涉及操作时写"前爪/肉垫"而非"手"，描述持物方式（双爪捧住/肉垫按住/爪尖勾起）；姿态在角色设定时一次定死，全片不得混用
4. **体型锚定**：Prompt 开头定义体型词（正常家猫体型/小型犬体型），并在**主体出场镜头 + 易崩镜头（大幅动作/多动物同框/景别切换）**重复一次锚定；一致性主要靠 ImageList 参考图保证，不必每个镜头都堆体型词
5. **微动作萌点**：说话/口播场景必须加 1-2 个微动作（歪头、眨眼、抬爪轻挥、耳朵抖动），禁止大幅肢体动作
6. **声音设计**：说话场景明示口型同步；不说话的 L1 场景用环境音+动物原声（呼噜声、踩奶声、咀嚼声），禁配乐淹没
7. **物种保真（铁律）**：用户上传的动物照片，成片中主体必须保持动物形象，禁止转人形
8. **品种行为锚定**：选定品种后，品种性格标签必须体现在**行为节奏**上，而不只是道具/台词。橘猫=佛系→动作慢悠悠、该吃吃该睡睡；英短=高冷→不屑、扭头、傲娇表情；二哈=蠢萌→破音、眼神闪躲、动作夸张。仅在道具或台词里出现品种梗、而行为节奏与品种无关，视为没利用好——判据：换成另一个品种，记忆点还成立吗？成立就是没用好

> 注意：品种性格必须**服从目标情绪**（见下）。橘猫佛系是喜剧向标签，若本片目标是「心疼」，佛系会消解心疼（它自己都不在乎，观众凭什么心疼）——此时改用「逞强」演法（嘴上说不累、身体很诚实）。别让品种默认标签把情绪带偏。

9. **个体人设锚定**：在品种性格之上，给主角 **2-3 个"个体级"特点/习惯/喜好**——**用户在问卷里提供的优先用**（那是主人眼中这只宠物最真实的样子），用户没提供就自己设计。三条要求：
   - **具体可拍**：必须是能落成动作/反应的（"睡觉必须肚皮朝天""听到零食袋响就飞奔""喝水前先用爪子拍两下"能拍；"活泼可爱""高冷傲娇"这种抽象形容词不能拍，要翻译成行为）
   - **至少一个习惯在片中出现两次**：第一次立人设，第二次在不同场景回环呼应成梗（如"听到零食袋响就飞奔"——收拾行李时对着零食袋冲过来一次，景点闻到小吃摊再冲一次）——出现一次是设定，出现两次才是人设
   - **落到镜头动作/反应，禁止旁白自述**（"它是一只爱睡觉的猫"是念简历；画面里它在售票处队伍里都能睡着才是人设）

10. **事件判别式（防"空"铁律）**：剧情 =「外部作用力 → 被迫反应」，不是情绪状态展示。每个镜头必须能压缩成一句「**[不受主角控制的作用力（人/物/规则/时间）] 对主角做了什么 → 主角如何反应**」；只能写成「主角很X」（很累/很开心/很委屈）的是**状态镜头**，全片 ≤2 个（定场/收尾各一），超了回去重写分镜。情绪不直接演——身体语言必须作为对某个作用力的**反应**出现，而不是无源的状态表演（"被X之后耳朵才塌下去"是反应，"全程耷拉着耳朵"是表演）。施压源必须在画面或声音层可感知，**可由动物配角出演**（老板/同事/店员等对手角色用其他动物——红线只禁人类入镜）；没有施压者的"被压迫感"立不住，长片全程独角戏撑不起剧情。

## 情绪杠杆（构造创意前先定，比手法更上位）

萌宠视频靠情绪变现。**先定「本片要观众产生什么情绪」，再选撬动它的杠杆**——手法（反转/叙事引擎/品种反差）是工具，工具要服务于情绪，不能反过来让题材默认联想决定情绪。杠杆也不是拿来直接抄进分镜的抽象方针——它最终必须落成事件锚点（SKILL.md §四步骤4）里的 **3-5 条「作用力→反应」事件**，每条有施压源、具体可拍、与目标情绪同向。

| 目标情绪 | 撬动杠杆（把它落到某个镜头/台词，不是念出来） | 常见做反的坑 |
|---------|------------------------------------------|------------|
| **心疼/可怜** | 逞强 + 付出无回报：嘴上说不累、身体很诚实（挂电话后才卸下表情）；别人下班它加班的对比；一个舍不得用的小东西 | 用「佛系/摆烂」——它不在乎，观众也就不心疼；结尾转成"解脱真爽"的欢快收尾——把攒了一整片的心疼自己消解掉 |
| **治愈/温暖** | 日复一日被看见（同机位重复蒙太奇拍"每天"）+ 兑现团聚瞬间；身体本能漏出的爱（等待时耳朵没放松） | 只拍一次、把"每天"用旁白念出来；吊到团聚却不兑现 |
| **好笑** | 破绽藏不住：装无辜时身体出卖它（尾巴拍地、屏幕弹 VICTORY）；铺垫越正经反转越好笑 | 停在"装无辜"就收尾，缺"证据出卖它"的最后一拍 |
| **放松/有趣** | 嘴硬 vs 身体诚实的同框反差；题眼专属细节（第一次坐飞机→安检/耳压，而非通用画面） | 四拍全可预判、换个题材剧本不用改 |
| **呆萌/解压** | 笨拙但有执念（塞不进还硬按、一粒不掉）+ 机械重复闭环（同机位往返三趟） | 只做程度递进不做闭环；把具体画面梗抽象成概念 |

**红线撞上情绪高潮时不要砍 payoff**：如"禁止人类手部"挡住了主人入画的团聚镜头——改用**声音层**（门开、钥匙声、一句台词）/ **剪影** / **局部特写**兑现情绪，禁止因为合规直接删掉情绪最高点。
