# 角色造型 / 场景陈设 / 道具时代感词库

这些是**可适配的模式与句式,按场景改写,不要逐字堆砌**。用于让生成的角色、场景、道具在细节上落进「美式复古好莱坞 / 70 年代」的时代与气质。

## 角色造型

### 妆发
- 女性:柔和的复古妆,眼影偏暖棕/烟灰,眼线含蓄,唇色暗玫瑰或裸棕;发型偏自然蓬松的中长卷发、大波浪,或简约低盘发,发丝带光泽但不油亮。
- 男性:干净或略带凌乱的复古油头/中分,鬓角明显;可有淡淡胡渣,面容带疲惫或深沉感。
- 共性:肤质柔润偏粉,不追求磨皮般的光洁,保留自然质感与微汗光。

### 服装(70 年代美式质感)
- 面料:天鹅绒、灯芯绒、粗花呢、真丝、棉麻,厚重而有垂坠感。
- 色彩:呼应主色相——橄榄绿、棕红、焦糖、赭黄、暗酒红、米白、烟褐。
- 款式:高腰阔腿裤、大翻领衬衫、针织开衫、丝绸衬裙、复古礼服、风衣;线条流畅、略显慵懒。
- 配饰:金属质感的复古首饰、宽檐帽、丝巾、老式腕表、圆框/金丝眼镜。

写法示例:"身着橄榄绿天鹅绒大翻领衬衫,暗玫瑰唇色,自然蓬松的棕色大波浪,肤色柔润偏粉"。

## 场景陈设

- 空间:老式公寓、木质书房、昏暗客厅、旧剧院、教堂、酒馆、雨夜街道、老式酒店大堂。
- 材质:深色木饰面、绒面沙发、厚重窗帘、老式壁纸(暗花纹)、黄铜与铜锈、旧地毯、斑驳墙面。
- 光源陈设:钨丝台灯、烛台、壁灯、透过窗帘的自然光、老式吊灯——都作为画面里的**实用光源**参与布光。
- 氛围元素:飘散的尘埃、薄雾/烟气、半拉的窗帘、摇曳的烛火,增强梦境感与压抑感。

写法示例:"昏暗的木质书房,厚重的暗红窗帘半掩,一盏黄铜钨丝台灯,空气中浮动着被光照亮的尘埃"。

## 道具时代感(70 年代)

- 老式转盘电话、黑胶唱机与唱片、卷盘录音机、老式打字机、胶片相机、怀表、火柴与烟。
- 玻璃酒具(威士忌杯、醒酒器)、瓷器茶具、金属烟灰缸、皮质公文包、旧报纸与信件。
- 交通:老式轿车、复古摩托;街景中的霓虹旧招牌、老式路灯。
- **避免任何现代科技物件**(智能手机、现代屏幕、现代 logo),以免破坏时代感。

## 落 prompt 前自检(角色/场景层)

- 妆发服装是否落在 70 年代美式复古体系、色彩是否呼应主色相?
- 场景材质与光源陈设是否营造昏暗、厚重、实用光的氛围?
- 道具是否具时代感、是否已排除现代物件?
- 是否有尘埃/薄雾/烛火等元素强化梦境与压抑感?
