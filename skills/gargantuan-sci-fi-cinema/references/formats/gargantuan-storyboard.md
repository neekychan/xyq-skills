## 1. 巨物感五大强制约束（核心规则）

**每套分镜设计必须至少使用3/5项，且第1项（低角度仰拍）为必选项。**

### 约束1：低角度仰拍（必选）
所有涉及巨物本体的镜头，必须采用极低角度仰拍（Worship Shot）。镜头位置贴近地面/海面，向上拍摄巨物，产生"人类仰视巨神"的压迫感。禁止平视或高角度俯拍巨物。

### 约束2：参照物尺度对比（必选其一）
每个场景必须包含一个尺度参照物：人类（维修工人/飞行员/路人）、渔船/货轮、汽车、建筑、直升机。参照物必须在画面中可见且与巨物同框，比例差距越大越好。禁止巨物单独出现在画面中无参照。

### 约束3：天气与大气效果（推荐）
每个场景必须有天气元素：暴雨、大雾、闪电、乌云、海浪、蒸汽、烟雾、沙尘。天气不仅增加真实感，更重要的是增强空间距离感（雾中轮廓、雨中光束、浪中尺度）。禁止在完全晴朗无天气状态下拍摄巨物。

### 约束4：水面/地面受力表现（推荐）
巨物必须有与环境的物理互动：海中行走时海水没过小腿、脚步踩出深坑、掀起V字形浪墙；地面站立时踩裂混凝土、踏碎建筑、地面凹陷。表现"重量感"而非"漂浮感"。禁止巨物在海面/地面行走时水花静态或地面无痕迹。

### 约束5：逐步揭露/延时露出（推荐）
避免第一个镜头就展示巨物全貌。采用：雾中轮廓→部分身体→完整全貌→压迫性特写，逐步升级的揭示节奏。或者：远景极小→镜头后拉→巨物逐渐占据画面→最终填满。禁止开门见山直接展示巨物全身大特写。

## 2. 巨物布景设计规范

### 2.1 尺度即恐惧（核心原则）

巨物电影中，真正的恐惧来源不是怪物长什么样，而是"它有多大"。每一个场景都必须回答：人类在这里有多渺小？用参照物、低角度、广角变形三种手段叠加。

示例：
- 机甲足部 vs 维修工人（工人如蚂蚁）
- 怪兽头部 vs 渔船（渔船如树叶）
- 巨手拍海 vs 海面（海坑深50米）

尺度对比必须成为叙事的一部分。

### 2.2 环境先于巨物

巨物不能凭空出现。所有室外镜头优先建立：天空、海面、远景城市轮廓，随后再出现巨物局部，最后巨物全貌进入。

节奏：Environment → Partial Reveal → Full Body → Scale Impact

### 2.3 工业/生物真实性

**机甲：** 外观状态根据剧情阶段动态决定——
- 出厂/部署阶段：干净工业质感（崭新金属面、无明显战损、少量制造油渍）
- 首次战斗后：轻微刮痕和战损
- 持续战斗或重伤后：重度战损、锈蚀、油污
- 重工业感、铜缆外露、液压关节始终保留
- 禁止：塑料感、CGI光滑感、无材质细节

**怪兽：** 生物恐怖感、粗糙皮肤纹理、荧光脉络、尖刺骨刺、巨口獠牙、血液颜色。
- 禁止：光滑皮肤、无纹理细节、卡通化

### 2.4 天气规则

天气属于叙事，不只是装饰：
- 大雾 = 隐藏恐惧
- 暴雨 = 灾难降临
- 闪电 = 巨物出场号角
- 海浪 = 重量感证明

同一场景天气禁止随机变化，必须有叙事理由。

### 2.5 光线规则

光源必须合理：机甲眼窗光、怪兽荧光、工厂焊接光、暴雨天光、闪电瞬间硬光、月光。禁止无光源的"画面自己发光"。体积光（光柱/光束）是增强巨物感的关键手段。

## 3. 巨物叙事结构

采用 Pacific Rim / MonsterVerse 经典结构：

**埋伏（暗示存在）→ 揭示（局部出现）→ 确认（全貌暴露）→ 冲突（对抗/战斗）→ 终极压迫（第三方介入或终极一击）→ 余波（灾难后果）**

每一个镜头必须推动：巨物尺度认知、人类恐惧感、环境破坏程度三者之一。禁止重复信息。禁止空镜没有叙事作用。

## 4. 章节设计

默认采用三章节（短片适用）：

### 第一章：预兆（Presage）
建立环境、暗示巨物存在、人类视角发现异常。主要镜头：大远景海面、雾中轮廓、参照物颠簸、低角度仰拍预备。节奏缓慢，恐惧感来自"未知"。

### 第二章：降临（Arrival）
巨物完整出现、尺度完全揭露、与人类/城市产生第一次接触。节奏加快，压迫感来自"已知但无法对抗"。

### 第三章：冲击（Impact）
战斗/破坏/终极压迫。巨物释放全部力量，环境彻底破碎。节奏最快，视觉冲击拉满。

**章节标题** 采用正式史诗风格。例如：《深渊》《觉醒》《天罚》《巨兽》《海啸》《末日》《第一波》《最后一道防线》。用户可修改标题。

**章节标题卡** 推荐底材：海面波纹、混凝土裂痕、钢铁纹理、怪兽皮肤、机甲装甲。字体：重工业衬线体/腐蚀金属风格。颜色：深灰/锈铁/荧光蓝绿/冷白。

## 5. 镜头设计原则

巨物电影的镜头不是为了炫技，镜头必须服务于**尺度感、压迫感、重量感**三者。镜头运动尽可能克制有力。大量采用：固定机位低角度、缓慢后拉、长时间停留、真实物理震颤。

禁止：快速推拉、频繁切镜、手持抖动（除非灾难混乱场景）、MV式剪辑、夸张镜头语言。

**每一个镜头必须包含：**
空间目标、巨物状态、人类/参照物位置、压迫感来源、主要光源、镜头运动、镜头时长、声音来源、镜头结束状态。

示例：
- 空间——深海海面
- 巨物——怪兽头部从雾中露出
- 参照物——渔船在下方
- 压迫感——未知轮廓
- 光线——荧光微弱脉动
- 镜头——缓慢后拉
- 时长——10秒
- 结束——雾散全貌暴露

## 6. G系列运镜系统

| 代号 | 名称 | 描述 |
|---|---|---|
| G-00 | Static Low-Angle | 固定极低角度仰拍，巨物占据画面，人类极少或极小。最常使用。 |
| G-01 | Slow Dolly Back | 缓慢后拉，逐步揭露巨物完整尺度，从局部→全身。 |
| G-02 | Slow Dolly Forward | 缓慢推进，从远景→巨物细节（眼窗/皮肤纹理）。 |
| G-03 | Worship Rise | 从地面向上摇起，先见足部→小腿→躯干→头部，完整建立巨物尺度。 |
| G-04 | Scale Reveal | 参照物先入画，巨物后入画，用参照物比例建立尺度。 |
| G-05 | Surface Tension | 聚焦水面/地面受力，巨物踩入→凹陷→浪墙/裂痕。 |
| G-06 | Fog Reveal | 雾中逐步显露，轮廓→局部→全貌，恐惧感逐步升级。 |
| G-07 | Impact Hold | 冲击瞬间固定机位，不切镜，张力来自画面内动作而非剪辑。 |
| G-08 | Dual Charge | 对称构图，机甲和怪兽从两侧同时向中心冲锋。 |
| G-09 | Hand from Sky | 第三方巨手/巨物从画面上方砸下，极低角度仰拍。 |
| G-10 | Submerged POV | 水下视角，巨物从上方海水轮廓中显露。 |

## 7. 经典镜头组合

- **组合一：** 海面大远景→雾中轮廓→局部显露→完整全貌→低角度仰拍特写
- **组合二：** 工厂维修（人类尺度）→镜头后拉→机甲全貌（巨物尺度），单镜头完成尺度跳跃
- **组合三：** 渔船颠簸→雾中轮廓→怪兽俯视，人类视角恐惧升级
- **组合四：** 机甲海中行走特写（腿部）→镜头上摇→头部全貌→眼窗亮起
- **组合五：** 对称构图→双向冲锋→碰撞→冲击波→慢动作碎裂
- **组合六：** 人类仰视→巨物低头俯视→眼神交汇→咆哮/发光
- **组合七：** 天空乌云→巨手砸下→海面凹陷→冲击波扩散→水下视角

## 8. 巨物镜头节奏

| 镜头类型 | 推荐时长 |
|---|---|
| 揭示镜头（雾中/远处） | 8–15秒 |
| 尺度对比镜头（含参照物） | 6–12秒 |
| 海中行走/受力表现 | 8–15秒 |
| 工厂维修（人类尺度） | 6–10秒 |
| 冲锋/战斗镜头 | 5–10秒 |
| 冲击/拍击瞬间 | 3–8秒（可慢动作延长） |
| 终极压迫（俯视/对视） | 10–20秒 |
| 结尾余波 | 15秒左右 |

始终保持：慢节奏建立尺度，快节奏释放冲击。

## 9. 跨镜连续性

所有镜头保持一致：巨物配色、发光元素颜色、皮肤/装甲纹理、天气状态、太阳/闪电方向、海面波浪方向、浪墙形态、参照物位置、巨物站位、光线方向、镜头轴线。

若跨章节，仍保持连续，除非剧情明确发生时间变化、天气变化、地点变化。
