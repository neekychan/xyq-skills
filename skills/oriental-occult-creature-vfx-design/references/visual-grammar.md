# 全片视觉语法(东方灵异玄幻 · 抓诡特效)

本文件是全片视觉的**底片与共享语汇**:两层世界的反差、民俗质感、能量与镜头规则、角色设计法,以及出图的 Prompt 组织。真实勘景、场景身份与空镜/怪物配对规则见 `environment-continuity.md`,怪物开大态见 `monster-design.md`,符咒与打斗特效见 `vfx-and-talisman.md`。所有资产统一 16:9 横画幅。

这些是可迁移的创作模式,不是复刻清单。用其因果、节奏与视觉关系开发新世界,**不逐字照搬、不重用任何具体名称、门派、怪物、道具、场景组合或镜头顺序**。

## 一、一句话判断

看一张图能否立刻读出:**这是一个本来就存在、可以走进去拍摄的湿冷东方地点,灵异规则正在侵入它**。怪物出现后,固定空间骨架、实景光源和材料老化仍能被认出。若只看到堆料的怪、均匀黑亮表面和乱轰的光,就是失败。

## 二、两层世界的对照(全片底片)

题材吸引力来自「室内一小撮异物」与「规则级/尺度级诡域」之间的巨大反差。锁死这两层,是全片一致性的根基。

| 层次 | 情绪与材质 | 光线与色彩 | 构图任务 |
|---|---|---|---|
| **现实层** | 潮湿木材、旧纸符、砖墙、香灰、铜锈、布幡、灰尘 | 冷黑蓝为底,嵌一盏暖黄实景光(油灯/手电/香火) | 让人物被门框、神龛、货架、阴影困住,异物具体可拍 |
| **诡域层** | 坍塌结构、浮空残骸、雾气、裂缝、能量流、怪物体表 | 铁锈红/墨黑天空,能量为唯一高饱和异色 | 用门洞、柱距、车辆、栏杆和砖块模数建立可量化空间,让怪物相对建筑结构主导画面 |

**跨层原则**:两层之间的切换要由一个具体动因(符燃尽、门开、镜面破、香灭)带动,不无来由地变天。能量异色在两层都保持同一套颜色规则(见 `vfx-and-talisman.md`)。

## 三、材质与光线规则

- **摄影底片**:以真实电影勘景、实景置景和现场摄影为基底,再把生物与特效压进画面;追求真实镜头中的奇观,不追求游戏引擎宣传图或纯 3D 展示图。
- **材料账本**:每个 `SCENE_ID` 只选 2–3 种主材料,分别写清粗糙度、反光、破损、积尘和局部湿度。至少约一半画面保留低频安静大面;微裂纹、坑点和污渍只在结构转折与叙事焦点出现。
- **湿冷不等于全局湿亮**:潮气落在渗水线、积水、泥浆、苔藓和接触区;干燥石面、旧木、香灰、尸革各自保持不同反光。禁止石、金属、皮肤、泥水共享同一种黑亮粗糙材质。
- **主光**:每个地点锁定有来源的实景主光、方向和色温,保留真实曝光衰减、空气透视与有限景深。玄幻能量是唯一高饱和异色,只照亮邻近表面并随距离衰减。
- **接地**:怪物必须产生接触阴影、遮挡、地面压痕、泥水/粉尘受力与材质互染;远端细节随雾尘和景深自然减弱。
- **禁忌**:干净实验室光、霓虹赛博、游戏引擎/纯 3D 渲染感、抛光 CGI、全场湿亮、均匀微裂纹、全局锐化、无受力漂浮碎片、全身平均发光、满屏乱色、血浆内脏、跳吓糊脸。

## 四、角色设计法(三层识别 + 造型公式)

沿用「人像优先 + 成体系锚点 + 真实空间」:

1. **骨架层**:漂亮/可共情的人形,保留脚踝、指关节、后颈、被门框切割的半身,让人物可被压迫、可恐惧。
2. **身份锚点层**:抓诡者/术者/凡人各有一组稳定识别特征(职业装束、法器佩戴方式、符囊、伤痕),跨镜不变。
3. **与灵异的关系层**:角色如何携带/触发/对抗规则——符在何处、法器怎么拿、被侵蚀时身上留下什么可见痕迹。

每个角色至少保留三个跨镜头复用的「锁定词」。

## 五、镜头语言(节拍)

1. 异物大特写或手部特写,建立材质与规则。
2. 人物近景,给出判断、恐惧或隐瞒。
3. 中远景揭示异常侵入场景。
4. 低角度或大远景,把人物置入不可控的巨大空间(怪物/诡域登场)。
5. 跟拍、横移或快速推进,让抓诡/施法/打斗进入肉身与能量的行动。
6. 关键物或能量特写后切人物反应;以一张新关系或新威胁收尾。

每次从特写扩展到大场面,都由同一个物件、动作或能量变化连接,不无动因地展示奇观。特效打斗的运镜与强度弧线见 `vfx-and-talisman.md`。

## 六、Prompt 组织与连续性

### 全片锁定词(挂在每条 prompt 末尾)

用固定词块锁死视觉 DNA,跨所有资产共享,不在同一项目中随意改写:

```text
WORLD: 东方民俗现实层(湿冷/旧木/香灰/铜锈,时代可现代/近代/古代)与灵异诡域层(铁锈红/坍塌/雾/能量),冷黑蓝为底,单一暖光点
SCENE: [SCENE_ID + 地点原功能 + 5个固定空间锚点 + 固定损坏 + CAMERA_SLOT/PAIR_ID]
CHARACTER: [角色身份锚点 + 法器/符囊佩戴方式 + 稳定造型特征]
CREATURE: [环境母题(墓穴/山洞/海底机关/上古遗迹/废墟)+ 造物家族(现实材料/古兽动物/魂灵/未知造物)+ 构成逻辑 + 巨大尺度 + 材质二联 + 开大攻击态(轮廓清晰)]
TALISMAN: [核心符咒本体的纸张/尺寸/裁切/朱砂或墨迹/符胆结构/自然旧化;未激活]
TALISMAN-VFX: [使用时的触发 + 能量固定颜色/形态/意象 + 作用/代价;只在视频镜头实际施法时调用,去仙侠掐诀]
MATERIAL: [2–3种主材料各自的粗糙度/反光/局部湿度/破损/污渍;保留安静大面]
LIGHT: [固定实景主光位置/方向/色温],低照度,真实衰减,能量仅作局部异色光
CAMERA: 16:9真实电影现场摄影,[焦段/机高/朝向/有限景深],真实空间透视与空气透视
EXCLUDE: UE5/游戏引擎宣传图/纯3D展示/抛光CGI/全局锐化/全场湿亮/均匀裂纹/同质材质/无受力漂浮碎片/全身平均发光/霓虹乱色/仙侠掐诀修真
```

### 出图顺序与场景配对

任何出图都先执行 `SKILL.md` 的图片清单确认门。确认后按已批准范围执行:

1. 先完成文字版场景身份卡和锁定词,不消耗图片积分。
2. 若清单批准了空镜,先生成 `scene_master_<SCENE_ID>` 干净底板;它是地点母版,不是独立气氛图。
3. 怪物开大图或角色入景图从对应母版编辑/参考派生,锁死 `PAIR_ID / CAMERA_SLOT`;怪物资产不放人物,用环境量尺表证明体量。若未批准空镜,只生成含主体的场景主图并将其背景登记为母版。
4. 每位角色只生成一张已批准的**角色综合参考卡**,同一画布内含正面、侧面、背面全身三视图和头部特写;不再生成独立肖像。另生成已批准的**一张未激活核心符咒本体参考卡**;不生成符咒特效图。
5. 逐对执行 `environment-continuity.md` 的连续性质检;失败重做属于新增生成,须先重新报数确认。

### Prompt 骨架

```text
[主体:谁/什么怪/什么开大态,一句可视化描述]
[动作/姿态或角色三视图排布]
[SCENE_ID / PAIR_ID / CAMERA_SLOT 与固定空间锚点]
[材料物理:各材料粗糙度、反光、局部湿度、破损与安静大面]
[环境接触:阴影、压痕、遮挡、污渍互染、受力碎屑、尺度参照]
[光线与能量:实景主光来源 + 能量来源/传导/衰减/邻近反射]
[画幅与镜头:16:9,真实现场摄影,焦段/机高/景深/空气透视]
[全片锁定词块]
[EXCLUDE 排除项]
```

### 角色综合参考卡 Prompt

每个角色只有一张图片,所有识别信息集中在同一 16:9 画布:

```text
同一角色、同一套服装与发型、统一比例
画布主体依次排布:正面全身 / 侧面全身 / 背面全身
同一画布留出一个头部特写区,用于锁定五官、发型、妆容、伤痕与肤质
中性无叙事背景,均匀设计光,视图之间不重叠,全身从头到脚完整
EXCLUDE: 第二张图片/独立肖像/单独半身照/不同服装/不同年龄/不同角色/剧情场景/动作表演
```

### 核心符咒本体参考卡 Prompt

这张图是前期道具参考,不是施法关键帧。整个项目默认只生成一张:

```text
单张核心符咒本体,未激活静息态,正面平铺或近乎正视,完整四边清晰可见
[纸张:手工纸纤维/厚薄/尺寸/裁切/折痕/自然旧化]
[绘制:朱砂或墨迹的真实渗纸、笔锋轻重、原创符头/符胆/符脚结构]
单一素色哑光无叙事背景,均匀柔光只为看清本体,轻微真实接触阴影
16:9参考卡,主体居中,不带标题、说明文字、边框或拼贴排版
EXCLUDE: 铜镜/剑/铃/印/冰棱/火焰/人物/手/墙地场景/发光/粒子/能量线/符阵/法阵/燃烧/漂浮/多张符纸/伪古文口号/特效演示
```

符面不要依赖一整段可阅读汉字来证明“东方”;优先用原创的符头、符胆、符脚、笔锋、章法和纸墨关系建立识别,避免生成似是而非的咒语句子。

### 三条原创 prompt 参考(示意,勿照搬)

- 现实层道具特写:一枚受潮起皱的旧黄符贴在铜绿门环上,水痕只沿门框下缘聚集,油灯从画外右侧投出有限暖光,真实微距摄影与浅景深,+锁定词。此例仅用于后续场景/视频镜头,不属于前期“核心符咒本体参考卡”。
- 巨物开大态:沿用 `SCENE_ID: scrapyard-01` 的厂房柱位、地面水沟与钠灯方向;锈铁和压扁废车构成的巨兽脚掌压入湿泥,泥水向外挤出,暗红能量只沿承重缆线从胸核向四肢衰减;以 4.5 米卷帘门、6 米柱距和标准轿车建立环境量尺,画面没有人物,35mm 实景电影底板上的写实生物特效,+锁定词。
- 同场景干净底板:沿用相同 `SCENE_ID / PAIR_ID / CAMERA_SLOT`,保持厂房柱位、地面水沟、钠灯、天气和损坏不变,仅移除怪物及其新增破坏;这张图只在图片清单已获用户批准时生成。
