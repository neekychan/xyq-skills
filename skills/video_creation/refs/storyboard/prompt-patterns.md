# 常见场景 Prompt 模式

本文件是 `storyboard/prompt-craft.md` 的配套示例册：按任务场景给出可直接套用的 Prompt 骨架。句式规范、素材引用、音频符号等规则以 `prompt-craft.md` 为准。

## 一致性控制（角色/场景统一）

```
参考@图片1的形象作为男人，@图片2作为走廊场景。
男人拖着沉重脚步走在走廊，步伐渐缓，在家门口停下。
面部特写，深呼吸调整情绪。<钥匙转动锁芯声>
门开后，小女儿从玄关跑出迎接，男人蹲下张开双臂。室内暖光。
五官清晰不变形，4K超高清，画面稳定。
时长：12秒，比例：16:9
```

## 运镜与动作复刻

```
参考@图片1的形象作为男人，在@图片2的电梯中，@视频1仅参考运镜与惊恐表演节奏，不继承其人物、场景与色调，惊恐时希区柯克变焦，环绕镜头展示电梯内视角
```

## 视频延长（Duration 设为新增时长）

```
将@视频1延长15秒。1-5秒：光影透过百叶窗在桌杯上滑过。6-10秒：一粒咖啡豆从上方飘落。11-15秒：英文渐显"Lucky Coffee"。
```

## 首帧/尾帧锁定

用户指定某图为视频起点/终点画面时用本句式，禁止退化为"与@图片N构图一致"式描述逼近：

```
@图片1 作为尾帧画面。一只长毛犬在花野中欢快小跑奔向镜头，耳朵随风飘动，最终收束定格到尾帧画面。
```

- 首尾帧同时指定：`@图片1 作为首帧画面，@图片2 作为尾帧画面`，两图画幅必须一致（见「参数锁定」）
- Prompt 主体写通往尾帧的**过程动作**，结尾状态由尾帧图承担，不再文字复述构图细节

## 参数锁定（编辑/首尾帧/延长）

模型按输入素材自动锁定以下参数，被锁定的参数禁止再写进 Prompt；调用时按表传 `TaskType`（其余任务不填）：

| 任务 | TaskType | 比例 | 时长 |
|------|----------|------|------|
| 视频编辑 | `edit` | 锁定 = 输入视频比例 | 锁定 ≈ 输入视频时长（可能有 ≤0.3s 压缩） |
| 首帧/首尾帧 | `keyframe` | 锁定 = 首帧图画幅；尾帧画幅与首帧不一致会被拉伸，必须选画幅一致的首尾帧 | 可自定义 |
| 视频延长 | `extend` | 锁定 = 输入视频比例 | 可自定义（Duration = 新增时长） |

首帧图/输入视频与用户要求的比例不一致时，在生成前解决素材，禁止靠 Prompt 改比例。

## 视频编辑（角色替换/元素修改）

```
@视频1中的女主唱换成@图片1的男主唱，动作完全模仿原视频，不要出现切镜，乐队演唱音乐。
```

## 两段视频无缝转场衔接

VideoList 传入两段视频，Prompt 写明衔接顺序、转场触发点与画面演变方式，并声明不改动原视频内容：

```
将@视频1和@视频2无缝衔接起来，不要改变上传的两个视频。@视频1结尾处视角飞行至顶端快速折返，垂直向下俯冲，俯冲过程中麻将牌慢慢变成高楼，场景对应变化，无缝自然地过渡到@视频2。
```

- 转场动作要绑定可见触发点（挥手/俯冲/变焦/旋转变装），并写清 A→B 的演变对象（"X 慢慢变成 Y"）
- 必须保留 `不要改变@视频1和@视频2` 类约束，否则模型可能重绘原片内容
- 需要保画面弃声音时显式声明：`原视频音频无需保持，但严格保持画面内容不变`

## 对白/台词短剧

```
参考@图片1的形象作为女主，参考@图片2的形象作为总裁。
画面（0-5秒）：特写女主撕契约镜头，纸屑飘落，总裁单膝跪地伸手阻拦
台词1（总裁，卑微慌乱）：{苏晚！契约还没结束，你不能走！}
画面（6-10秒）：女主抬脚避开他的手，将撕碎的契约纸扔在他脸上
台词2（女主，冷漠反杀）：{契约？顾总，当初是你说我不配，现在求我？晚了！}
音效：华丽又带张力的背景音，契约撕碎声响
```

## MV / 口型对齐

先将音频转成黑屏视频放入 VideoList，Duration 与音频时长严格一致：

```
使用@视频1中的音频驱动@图片1中的主角生成MV，整体轻快活泼阳光的氛围。口型严格同步: "{该段歌词原文}"
```

完整 MV 流程详见 `creative/mv-creator.md`。
