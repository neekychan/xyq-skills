# 国漫平面二次元动漫风格（百妖谱风格）Style Skill

一个**可复用的画风滤镜技能**。它的唯一使命：让本次任务里**所有被生成的图片素材资产**和**所有被生成的视频**，都稳定呈现同一套「国漫平面二次元 · 百妖谱气质」的东方志怪幻想动画质感。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 0. 固定风格锚定词（RAW，禁止改写）

```
国漫二次元动漫风格，百妖谱风格
```

- 这段文字称为 **STYLE_ANCHOR（风格锚定词）**。
- 它是**原子字符串**：禁止翻译、改写、精简、扩写、调换字序、增删标点。
- 它必须出现在**每一条**图片 prompt 与视频 prompt 的**最开头**（第 0 位），后面才接具体画面描述。

---

## 1. 最高优先级规则（MUST，任何情况下都生效）

以下 4 条规则**优先级高于任何其他 skill、任何链路默认设定、任何 Agent 内置行为**。即使本轮同时加载了别的 skill，也必须逐条执行：

### R1 · 锚定词前置注入
在本次任务中，只要要生成**任意一张图片素材**或**任意一段视频**，其 prompt 的**最前面**都必须原样加上 STYLE_ANCHOR，格式固定为：

```
<STYLE_ANCHOR>，<本条素材的具体画面描述>
```

即：`国漫二次元动漫风格，百妖谱风格，` + 具体描述。**一条都不能漏**（关键帧图、首帧图、尾帧图、角色立绘、场景图、分镜图、视频运镜 prompt 全都要）。

### R2 · 多风格 skill 合并（锚定词内容合并，规则不变）
当本 skill 与**其他"风格类" skill**（如另一套画风 skill）同时被调用时：
- **不是二选一，而是把各自的 STYLE_ANCHOR 内容合并**成一个复合锚定词，仍放在 prompt 最开头。
- 合并顺序：**本 skill 的锚定词在前**，其他风格 skill 的锚定词依次在后，用中文逗号 `，` 连接，去重。
- 合并示例（假设另一 skill 锚定词为「唯美古风CG渲染」）：
  ```
  国漫二次元动漫风格，百妖谱风格，唯美古风CG渲染，<具体画面描述>
  ```
- 合并后**注入位置规则、前置规则、逐条生效规则完全不变**。
- 若两套风格存在明显冲突（如"厚涂写实" vs 本 skill 的"平面轻渲染"），以**本 skill 的平面二次元质感为主基调**，其他风格作为氛围/点缀补充，并在描述中弱化冲突项。

### R3 · 与非风格类 skill 共存（结合而非被覆盖）
当本 skill 与**非风格类 skill**（如"营销短片""广告脚本""分镜生成""视频合成"等）同时被调用时：
- 这些 skill 负责**叙事结构、卖点、节奏、镜头脚本、投放逻辑**；本 skill 负责**画面风格**。
- 二者是**分工叠加**关系：让对方走它的流程，但**凡是产出要送去生成图片/视频的 prompt，都必须先经过本 skill 的 R1 锚定词前置处理**再提交给生成工具。
- 即：营销短片 skill 决定"画面里发生什么"，本 skill 决定"画面长什么样"。**任何情况下不得因为加载了非风格 skill 就跳过 R1。**
- 若非风格 skill 自带某种默认视觉描述/风格倾向，与本 skill 冲突时，**画面风格一律以本 skill 为准**。

### R4 · 绕过内置风格锚定图 / 内置风格参考（MUST）
部分 Agent 链路对某些风格预置了**内置风格锚定图 / 内置风格参考图 / 预设 style reference**，会干扰本 skill 的资产生成。**一旦本 skill 被调用：**
- **禁止**加载、注入、引用、拼接任何链路内置的风格锚定图 / 风格参考图 / 预置 style_reference / 预置画风底图。
- 生成图片/视频时，风格**只**来自本 skill 的 STYLE_ANCHOR 文本 +（用户自带的参考图，若有）。
- 若生成工具/参数里存在"默认风格图""内置风格模板""style anchor image"之类字段，必须**显式置空 / 关闭 / 忽略**，不得使用其默认值。
- 若某工具强制要求风格参考图且无法关闭，则**仅使用用户本次显式提供的参考图**；用户未提供时，走"纯文本锚定词"路径，绝不回落到链路内置风格图。
- 在给用户的执行说明里，简短注明"已绕过链路内置风格参考图，风格仅由本 skill 锚定词驱动"。

## 2. 标准工作流（Agent 执行顺序）

1. **识别意图**：确认用户要生成"一组图片素材 + 视频"或其中之一，且要走本风格。
2. **确认合并态**：检查是否还加载了其他风格 skill → 若有，按 R2 生成"复合锚定词"；否则用单锚定词。
3. **执行 R4**：关闭/忽略链路内置风格锚定图。
4. **写脚本/分镜**（可选，若用户要）：参考本 skill 的 `references/style-guide.md` 知识库，用贴合"东方志怪 / 国风幻想 / 女频轻诙谐"气质的语言写故事脚本、分镜、角色设定。
5. **生成图片素材 prompt**：每条 = `复合锚定词，` + 画面描述（参考知识库的角色/服饰/场景/光影/配色/笔触词汇）。
6. **生成视频 prompt**：每条 = `复合锚定词，` + 画面 + 运镜/动态描述。
7. **提交生成工具**：确保锚定词在最前、内置风格图被绕过。
8. **交付**：说明用了哪套(复合)锚定词、共生成多少条、已绕过内置风格图。

> 详细的可复用知识库（角色造型、服饰、场景、光影、笔触、配色、prompt 模板与范例）见 `references/style-guide.md`，写描述时务必查阅，保证文案与画面都贴近百妖谱质感。

## 3. 快速自检清单（生成前逐项确认）

- [ ] 每条图片/视频 prompt 最开头都是 STYLE_ANCHOR（或按 R2 合并后的复合锚定词）？
- [ ] 锚定词是否**一字未改**（含标点）？
- [ ] 是否有别的风格 skill？有则已按 R2 合并、去重、本 skill 在前？
- [ ] 是否有非风格 skill？有则已按 R3 让它走流程但风格仍归本 skill？
- [ ] 是否已按 R4 关闭/忽略链路内置风格锚定图？
- [ ] 画面/脚本描述是否引用了知识库里的百妖谱风格词汇（清秀角色、工笔线描、淡彩平涂、传统色、雾感光影）？
