## 四、动作分解类

> **二级呈现形式**：动作关键帧分解图（动作分解表）、姿态连续分镜、打斗·竞技分镜、操作流程分镜、运动轨迹示意分镜、动作导演镜头表、动作脚本表格。下方给出代表性骨架（动作分解表）；其余二级呈现形式的细化模板见本章末「PE 模板索引」。

### 适用要点与判定关键词

- **定义**：以「连续动作拆解」为核心，每格展示动作过程中的一个关键姿态或步骤，重点是身体姿势、动作轨迹与力的方向。
- **判定关键词**：`打斗`、`战斗`、`动作`、`格斗`、`搏斗`、`追逐`、`拳击`、`武侠`、`舞蹈分解`、`动作拆解`、`教学动作`、`运动训练`。重点在“把动作过程拆清楚/看是否流畅标准”时归本类。
- **边界**：
  - vs 剧情叙事类：本类可脱离剧情做动作教学/设计参考。
  - vs 知识讲述类：本类文字多为操作要点而非理论讲解。
  - vs 营销转化类：即便出现产品也多是道具，核心是身体动作拆解。
  - 需要系统镜头参数的电影级动作设计，可在二级选「动作导演镜头表」，但用途仍归本类。
  - 完成度：极粗略线稿且仅作动作构图草稿 → 草稿/线稿级；可用度较高的动作教学/设计分镜（即便线稿）仍归本类。

### 分镜结构建议

- **推荐宫格数**：4–16 格，把一个动作拆成起势→过程→爆发→收势四段，每段再细分 1–4 格。
- **结构骨架**：
  1. 起势（1–2 格）：动作准备或起跳前瞬间，交代重心与方向；
  2. 过程（若干格）：动作中段关键姿态，保证连贯性与方向一致；
  3. 爆发/极值（1–2 格）：动作幅度最大或打击瞬间；
  4. 收势/转场（1–2 格）：回到稳定姿态或接入下一动作。
- **画面特征**：多用全身/中全身景别，背景适度简化，突出身体重心、四肢方向与运动轨迹；对练场景清楚区分双方站位与攻防关系。

### 生图 Prompt 骨架

```text
你是一名动作指导，请为 {动作类型，如“二次元舞蹈/武术对打/篮球灌篮展示/健身动作教学”} 设计一张 {宫格数} 宫格的动作分解表，整体画幅为 {画幅比例说明，如“9:16 竖屏动作教程”}。

【动作与场景设定】
- 一级用途类型：动作分解类
- 二级呈现形式：{动作关键帧分解图 / 姿态连续分镜 / 打斗·竞技分镜 / 操作流程分镜 / 运动轨迹示意分镜 / 动作导演镜头表 / 动作脚本表格}
- 动作名称：{如“古装剑法四连斩/现代舞旋转跳跃/俯卧撑标准动作”等}
- 目标用途：{如“体育教学/电影打斗设计/舞蹈分解/运动教程”等}
- 适配场景：{如“动作短片/武侠动作短片/健身教学短视频/舞蹈卡点视频”等}
- 内容类型：{如“UGC-生活/UGC-动作/影视剧-短剧/影视剧-动画”等}

【参考素材图（如有）】
- 角色/动作定格参考图：要求保持体型、服装、护具颜色一致；
- 场景参考图：保持地面与背景结构一致；
- 若无参考图且为精修/成品级：先确认是否需要补角色定妆/场景设定图。

【角色与场景】
- 角色设定：{性别、年龄、体型、服装风格}
- 场景设定：{如“拳击台/街头篮球场/练功房/健身房”，说明地面与背景结构}
- 画风：{仿真人写实/3D 动画/线稿示意图/2D 动漫等}

【分镜形态与完成度】
- 分镜形态：{连贯性套图/分镜单图}
- 宫格数量：{宫格数，如 8/12/16 格}，按时间顺序编号 A1–A{N}。
- 完成度：{草稿/线稿级 / 精修级 / 成品级渲染}

【标注信息配置】
- 是否带序号：{"是"/"否"，教学/设计场景推荐为 "是"}
- 是否带文字说明：{"是"/"否"，"是" 时每格配简短动作要点}
- 是否带分镜参数：{"是"/"否"，"是" 时简单标注视角/景别}

【分解逻辑】
- 从“起始准备姿势”开始，依次拆分关键动作节点，最后回到“结束姿势或站稳姿势”。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 A1 到 A{N} 的动作分镜要点（姿势描述 + 动作要点等），供用户确认；确认后再按以下格式，为每格写出详细分镜说明：
1. 第1格：
   - 姿势描述：{身体朝向、重心位置、手脚位置}
   - 动作要点：{发力方向或关键肌群}
   - 视角与构图：{如“全身中景，侧面视角，背景简洁”}
2. 第2格：……
……直到第 {宫格数} 格，完整覆盖从起势到收势，保证动作连贯清晰。
```

### 一致性与避坑

- 角色外观跨格一致（性别、体型、服装、护具颜色不变），只通过姿态变化表现动作。
- 背景与地面线条各格统一，便于观察重心与位移，避免空间错乱。
- 明确动作方向（左/右/前/后）与视角（正/侧/俯视），避免前后镜头方向打架。
- 多人物动作（对练、搏击）说明双方站位与攻防关系，避免“多人物站位动作不符”。
- 保持“动作过程”为首要输出目标，避免被剧情/产品说明分心。
- 在视频中复现动作分解表时，Prompt 中对每个画面阶段的空间定位必须遵守 storyboard/vfx-action-prompt.md 的“空间定位先行”和“对立双方朝向必须相对”规则：用绝对朝向（背对/面朝镜头、侧身朝左/右）结合景别与间隔物描述，而不是只写“双方对峙/靠近”。

#### 动作连续性表与相邻格自检（P0，强制）

- 逐格状态卡在动作/VFX 类中必须补充字段：起始姿态 / 结束姿态、攻击方 / 防守方、动作方向、人物相对位置、与上一格承接、与下一格铺垫、必须保持不变、禁止跳变。
- 每格必须绑定动作链节点（起势/发力/接触/变化/落点/恢复）之一；无绑定视为断链，禁止生图。
- 相邻格自检：若上一格“结束姿态”与下一格“起始姿态”不承接，或攻守关系无因果地反转，判为失败，需重写状态卡并重画该格（压制“第 4→5→6 格动作链断裂”）。

### 视频生成策略与 PE 模板

```text
请基于下述素材生成一条 {时长秒数} 秒的动作展示视频，突出动作连贯性和力量感。

【输入素材】
- 分镜图：{路径或 ID}（{宫格数} 宫格，对应动作关键帧）
- 参考图：{动作定格照片/角色立绘，如有}
- 目标画幅：{画幅说明}，ratio={ratio 代码}
- 目标模型：以用户指定的模型为准；用户未指定时，可用 seedance_2.0_fast 或 seedance2.0_fast_direct / seedance2.0_fast_vision

【生成策略】
- “参考图生视频”：从动作分解表选 3–5 个关键格作参考帧，引导关键姿态与节奏；
- 保证角色在整个动作段落位置与方向连贯，避免突然左右跳；
- 教学类内容部分镜头预留字幕区，叠加动作要点。
- 若动作分解表对应打斗/特效/高运动量画面（如武侠对打、魔法对决、跑酷追逐），则 creative_design.md 中的弧线与角色/特效设定应按 creative/vfx-action.md 规划（四段视觉强度弧线、特效具象化、环境破坏递进），视频 Prompt 则按 storyboard/vfx-action-prompt.md 的强制规则构造各时间段，不得只写“连续对打几招”。

【质量要求与常见问题规避】
- 关节与四肢姿态自然可信，避免极不合理扭曲；
- 重心转移流畅，打击/爆发瞬间可加运动模糊或镜头运动但不淹没动作本身；
- 多人物打斗持续保持攻防关系与站位一致；
- 教学类节奏不过快，让观众看清每一步；
- 所有中文文字、镜头编号与镜头参数说明优先由脚本或后期文字层叠加，图像模型仅负责画面，不直接生成长篇中文文字，以避免模糊或错字。
- 动作教程/教学场景在进入视频阶段前，应按 creative/knowledge-explainer.md §教程的"步骤即镜头"规则审视每条视频：每个镜头只承担一个动作要点或步骤，复杂示范拆成多镜，而不是在单镜内塞满多个动作链。

【迭代建议】
- 先一次性设计好分镜再生成视频，有效 Run 控制在 3 次内：第1次验证整体节奏与连贯性，第2次修正错误姿态/站位，必要时第3次微调镜头节奏，不推倒重来。
```
