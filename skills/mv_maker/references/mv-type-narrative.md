# 流派 02: 电影叙事 (Cinematic Narrative)

* **适用曲风**：民谣、抒情情歌、电影原声 (OST)、叙事曲、剧情微电影
* **视听公式**：`[35mm 胶片质感] + [三幕剧冲突与悬念] + [焦点拉移 (Rack Focus)] + [空间与色温反转]`
* **表演配比**：20%~30% 情感特写唱演 + 70%~80% 电影剧情弧与意象空镜，少量唱演 + 大量剧情与空镜蒙太奇。

---

## 一、正交积木库

* **起手式**：`大光圈虚焦中静止道具（水滴/未寄出的信/老旧钟表）平滑拉焦至人物眼神` / `隔着雨水玻璃窗侧颜凝视`
* **动作与叙事**：`主角在空旷街道上逆风奔跑` / `两人在长椅背对背沉默` / `指尖抚过泛黄旧照片`
* **光影与材质**：`夕阳低角度长阴影` / `老旧电影暖黄钨丝灯与冷蓝月光交织` / `空气中浮动的细微胶片尘埃`
* **爆发与收尾**：`在情绪爆发点猛然推门冲入大雨中` / `车辆尾灯划过雨夜街道留下一道红色光轨，画面渐隐`

---

## 二、画外音原则与 20%~30% 唱演上限门禁 (Voice-Over vs Lip-Sync)

电影叙事 MV（民谣、抒情情歌、剧情短片）最忌讳沦为「大头对嘴假唱个人秀 (Karaoke)」。必须严格执行**画外音 (OST) 与唱演分离原则**：

1. **【核心铁律】有歌词 ≠ 必须动嘴**：
   - 音乐中的歌词人声天然属于 **画外声 (Voice-Over / OST)**；
   - 在 70%~80% 的镜头中，即便背景歌声正在演唱，角色也必须**沉浸在剧情行动与微表情中（如整理旧物、窗边发呆、漫步街头、眼神望向远方、收拾抽屉）**，Prompt 中必须显式标注：`【无唱演/画外音】人物闭口不唱，专注剧情动作与情绪流露，不开口`；
2. **【单段唱演上限】每 30 秒分段最多仅允许 1 处核心唱演（≤ 5~6 秒）**：
   - 每段分镜中只挑出 **1 句最核心的情感爆发句或记忆点**（如副歌第一声高音、结尾念白）给到 MCU 正面/侧面特写动嘴咬口型；
   - 严禁把段内的 3~4 句歌词连续全部写成唱演镜头（否则动嘴时长直接飙升到 70%+，彻底丧失电影留白美感）。

## 三、语法示范（15 秒 3 阶段电影叙事）

```text
@图片1 锁男主角面部五官、发型与深灰风衣。@视频1 提供全段唯一背景音乐与节拍时间轴，不提供画面。画面动作与节奏必须严格跟随 @视频1 的音频作为 BGM，不擅自编曲，严禁生成任何其他无关背景音乐。全段纯电影叙事与氛围建立，不对嘴。

16mm独立电影颗粒质感，50mm人像定焦镜头，低反差莫兰迪冷色调，雨夜霓虹漫反射。男主角在雨夜街头凝视与奔跑。

严格跟随 @视频1 的音频作为 BGM，不擅自编曲，全段纯视觉叙事。

第0-5秒 (雨棚凝视与水滴特写)：雨夜便利店门外雨棚下，冷白便利店灯光透出。中近景侧拍，主角站在雨棚下，手握冷萃咖啡凝视玻璃上的雨滴倒影，镜头平稳固定。
第5-10秒 (焦点拉移与雨中冲刺)：随大提琴旋律切入，焦点从玻璃水滴瞬间拉移至后方昏暗街口撑伞走过的模糊背影，主角视线迅速转动，猛然迈步冲入雨夜潮湿街道中。
第10-15秒 (低角度奔跑与驻足定格)：低角度跟随主角在泛着冷光柏油马路上大步奔跑，暖黄街灯在地面水洼反射出金黄光斑，在弦乐高潮重音处主角突然在空旷十字路口驻足喘息，抬头望向漆黑夜空定格。

保持无字幕，不要生成水印/logo，人物神态与动作自然无畸变，全片不要复制相同人物，严格以@视频1中的音频作为全片唯一背景音乐，严禁生成任何与@视频1无关的背景音乐或杂乱音轨。
```
