# 巨物科幻素材分析规则

> 本文件定义素材分析阶段的完整规则。遵循 Pacific Rim / MonsterVerse 巨物电影叙事原则：先分析世界尺度，再分析巨物本身，最后分析人类视角。

## 目录
1. 剧本/故事文本分析
2. 视觉参考素材分析
3. 分析限制
4. 剧本完整性判断

---

## 1. 剧本/故事文本分析

### 一、时代背景

判断故事所处年代。例如：近未来2050年机甲防御时代；现代-day怪兽苏醒；远古时期巨兽封印；后末日废土世界；外星入侵时代。若用户未说明，AI根据故事自动推断最合理年代。

### 二、空间分析

识别主要空间：深海海沟、太平洋海域、暴雨云层、超高挑空工业厂房、巨型装配平台、废弃城市、海岸线、火山口、外星地表、轨道空间站、地下机甲基地、破碎街道、倾覆货轮、海面漩涡、乌云风暴眼。

寻找每个空间的：巨物尺度适应性、天气条件、光线条件、海水深度、地面承重、空间体积、人类可活动范围。

### 三、巨物分析（核心）

**机甲提取项：**
- 名称、高度、重量、配色、材质、装甲结构
- 头部设计（眼窗形状/光源颜色/天线形态）
- 关节结构（液压/暴露机械/隐藏式）
- 战损状态（全新/轻微战损/重度战损）
- 发光元素（眼窗/条纹/关节处）
- 人类尺度参照（维修工人大小对比）

**怪兽提取项：**
- 名称、高度、重量、材质质感、生物特征
- 发光元素（荧光脉络/眼眸/口腔内部）
- 攻击方式（物理撕咬/能量攻击/尾击）
- 血液颜色、皮肤纹理、骨刺位置
- 人类尺度参照（渔船/建筑大小对比）

### 四、参照物分析

提取可用于尺度对比的元素：人类、维修工人、渔船、货轮、汽车、建筑、桥梁、直升机、工厂平台。

建立尺度对照表：

| 巨物 | 高度 | 参照物 | 参照物高度 | 比例 |
|---|---|---|---|---|
| [机甲名] | XXm | 维修工人 | 1.8m | XX:1 |
| [怪兽名] | XXm | 渔船 | 15m | XX:1 |

### 五、天气与大气分析

提取：暴雨、大雾、闪电、乌云、海浪、海啸、地震、火山灰、辐射风暴、外星大气。

分析每种天气对巨物感的增强效果：
- 暴雨 → 遮蔽视线，增加巨物轮廓的模糊感与压迫感
- 大雾 → 隐藏巨物全貌，逐步揭露恐惧
- 闪电 → 瞬间照亮巨物，制造视觉冲击
- 海浪 → 证明巨物重量感
- 乌云 → 压低天空，增加末日氛围

### 六、战斗/灾难程度分析

判断：
- 轻度接触（只有压迫感无战斗）
- 中度战斗（拳脚相交）
- 重度毁灭（城市破碎、海啸、爆炸）

匹配对应视觉强度。

### 七、声音设计分析

提取：低频轰鸣、脚步震动、钢缆绷断、液压啸叫、怪兽嘶吼、海浪拍击、暴雨白噪音、电弧闪光声、金属扭曲声。

建立声音层次表：

| 层次 | 声音元素 | 出现场景 |
|---|---|---|
| 底层 | 风声/海浪/暴雨/雷电/远处低频轰鸣 | 始终存在 |
| 中层 | 机甲液压声/钢缆绷紧声/焊接火花声/怪兽脚步震动/海水拍击/雾中低频回响 | 随场景出现 |
| 顶层 | 碰撞冲击波/金属扭曲/玻璃破碎/建筑倒塌/海啸轰鸣 | 冲击时刻 |

## 2. 视觉参考素材分析

若上传图片或电影截图，提取以下信息：

### 光线
- 自然光方向（暴雨天光/夕阳逆光/乌云漫射/月光）
- 人工光源（焊接火花/警示灯/机甲眼窗/怪兽荧光/工厂射灯）
- 体积光（雾中光束/雨中光柱/海面反光）

### 摄影语言
- 极低角度仰拍（Worship Shot）
- 超广角（14mm/16mm）夸大前景
- 深景深（f/8–f/11）保证巨物全清晰
- 镜头运动（缓慢后拉/静止仰视/微晃震感）
- 构图（对称/低角度/巨物占据2/3画面）

### 巨物语言
- 机甲：重工业感、液压关节、铜缆外露（战损/锈蚀程度根据故事阶段判断，非默认属性）
- 怪兽：生物恐怖感、荧光脉络、尖刺骨刺、巨口獠牙
- 尺度：巨物占据画面主体，人类不可见或极小

### 色彩
- 机甲配色：红黑金/白条纹/冷白眼窗
- 怪兽配色：灰黑石化/蓝绿荧光/青蓝光眼眸
- 环境色：深墨绿海面/灰暗工厂/乌云暴雨/雾白
- 对比色：机甲冷白 vs 怪兽蓝绿 / 深海暗色 vs 荧光脉络

### 材质
- 机甲：钢板、铜缆、液压管（战损/锈蚀/油污根据故事阶段判断，非默认属性）
- 怪兽：岩石、木质化石感、荧光脉络、尖刺、黏液
- 环境：混凝土、钢梁、海水、泡沫、雾气、暴雨

## 3. 分析限制

- 不分析真实人物身份
- 不复制真实演员形象
- 不复制电影完整镜头
- 仅学习：巨物电影语言、尺度表现手法、光线规律、构图逻辑、美术语言、工业/生物设计特征、空间组织方式、天气增强手法

## 4. 剧本完整性判断

**可直接进入视觉设计（满足以下条件）：**
- 具备巨物设定
- 具备主要空间
- 具有事件推进（冲锋/战斗/揭示）
- 能够推断尺度对比关系

→ 无需扩展

**需要故事扩展（出现以下情况）：**
- 只有一句创意
- 只有巨物名称
- 没有人类视角
- 没有空间转换
- 没有天气设计
- 没有尺度参照
- 没有冲突事件
- 没有结局

→ 自动标记"需要故事拓展"

**输出格式：**
完整性判断（需要故事拓展 / 无需故事拓展）+ 缺失内容清单（巨物设定、人类视角、空间信息、天气设计、尺度参照、冲突事件、结局、科幻元素真实性、机甲/怪兽设计细节、参照物设定）。
