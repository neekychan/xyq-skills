# 巨物变异末日视觉设计系统（方法层）

本文件只负责**把视觉语言转成原创设计图资产、变异后动效视频规划、提示词与交付物的方法**。所有美学决策以其它文件为准，避免重复与冲突：

- **巨物/角色造型、配色、材质、尺度、镜头、原型、示例 prompt、变异呈现分级** → 一律遵循 `apocalypse-visual-grammar.md`（可辨源生物 + 完整巨化异变逻辑 + 真实尺度压迫 + 写实末日世界 + 人与巨物同源的变异标记；避免四不像怪兽、无源尖刺堆料、悬浮无体量模型、卡通/塑料 CGI/霓虹赛博）。
- **写实灾难 + 毒荧光变异调色** → 遵循 `disaster-grade.md`，按需加挂，不在本文件复制其模块。

本文件只补充四样 `apocalypse-visual-grammar.md` 未展开的通用工具：全局视觉锁、三段呈现层次、变异后动效视频规划、交付格式。所有设计图资产统一 16:9 横画幅。

## 1. 全局视觉锁（全片视觉契约）

先写一句能约束所有画面的总述，再锁定下列变量；写成**全片锁定词**，原样挂到每条 prompt 末尾（与 `apocalypse-visual-grammar.md` 的 WORLD/SUBJECT/MUTATION/SCALE/MATERIAL/LIGHT/CAMERA 锁定词保持一致，不要另起一套）。

示例总述：

> 一头由兵蚁巨化异变而来的数十米巨物，几丁质甲缝渗出脉动的青绿生物荧光，正在踩塌一座真实崩塌的现代都市；变异标记同样爬过被感染幸存者的眼与血管，人以真实尺度被碾压，读起来可信而压迫。

| 变量 | 需要决定什么 | 推荐基调 |
| --- | --- | --- |
| 源生物 | 巨物变异自哪种可辨真实生物、保留哪些源特征 | 蚁/蜂、螳螂/甲虫、甲壳/深海节肢、头足、爬行/两栖、真菌/植物；每部短片只选 1 种主源生物，异变要调动该源生物巨化后的**完整语汇协同**，不是等比放大 |
| 变异逻辑与标记 | 巨化如何改写力学、叠加哪套自洽异变标记、统一标记色 | 必含一套成体系标记（甲壳增生/生物荧光/结晶或金属侵入/多节段/增生瘤等协同）+ 一处高饱和变异荧光色（默认毒性青绿；可蓝紫/赤红/惨白）作点睛，且同时出现在人与巨物身上 |
| 灾难母题/空间 | 灾难在哪种真实都市空间发生 | 街道、地铁、写字楼、天台、高架、地标、军事应对现场；选 2–3 个反复出现 |
| 尺度语言 | 用什么真实参照建立体量、用什么构图压迫 | 人/车/楼/地标被碾压；低角度仰拍 + 局部框取 + 烟尘大气透视；避免悬浮无参照 |
| 材质三联 | 什么使它一眼属于此世界 | 必含「变异组织质感」（湿甲壳/软体/菌肉/结晶）；再从灼蚀混凝土/碎玻璃/烟尘灰/湿反光里选，只选 3 种 |
| 主色温 | 光线如何塑造末日 | 冷调蓝灰/青黑/废墟色为底，火光/探照灯暖冷点缀，变异荧光暗处点睛；变异前日常可偏暖形成反差 |
| 禁忌项 | 什么会打破世界或越界 | 四不像通用怪兽、源生物不可辨、随机尖刺堆料、悬浮无尺度模型、卡通/橡胶怪兽、塑料 CGI、霓虹赛博、干净科幻界面；以及血浆内脏、脓疮溃烂、密集孔洞、无源尖刺；**以及「把一只动物等比放大扔进城市」的太常规做法**；具体版权巨兽形象（哥斯拉、异形等） |

锁定词是所有设计图共享的视觉 DNA，不在同一项目中随意改写。

**贯穿全片的一条原则——不要「随便放大一只怪兽」**：「太常规」不是因为它巨大（真实压迫的巨大正是要的），而是因为源生物不可辨、异变无逻辑、无尺度参照、世界不真实。做对它要：(1) 锚定**可辨源生物 + 完整巨化异变逻辑**；(2) 用**真实尺度参照 + 写实材质**把巨物压进真实世界；(3) 用**统一变异标记**缝合人与巨物。造型细则见 `apocalypse-visual-grammar.md`。

## 2. 三段变异呈现层次

无论造型走哪条路线，都用三段层次控制「变异与尺度显现到什么程度」，避免每张设计图都同一强度。注意：升级的是「异变语汇的完整度 + 尺度压迫的强度」，不是「堆更多料」，也对应「变异前→变异后」的谱系：

1. **潜隐（变异前/铺垫）**：源生物接近真实常态，变异标记只含蓄可辨（一处荧光、一处增生），或巨物仅露远景剪影/局部；空镜或远景就能感到不寻常。
2. **显现**：成体系异变标记已明确覆盖巨物关键部位，真实尺度参照出现并开始被碾压（对应视觉语法 L2–L3）。
3. **压迫（变异顶点/灭世）**：完整巨化异变 + 统一标记 + 强烈真实尺度压迫，巨物/灾难主导整体，仅靠一处真实参照（地标残骸、逃亡人群）锚定「这是真实世界」；空间气质随之翻转。

每张设计图只升级一个变量：异变语汇的丰富度、材质密度、尺度参照的强度或呈现层级（变异前/变异后）。

## 3. 变异后动效视频规划（交给 video creation 生成动效视频）

这是本环节区别于纯静帧设计的关键交付物：为每个巨物（及每个有异变形态的角色）产出一份**只规划视觉动效、不写剧情台词**的运动规划，供 video creation 直接据此生成动效视频。按下表逐项填写：

| 规划项 | 要回答什么 | 示例（巨蚁） |
| --- | --- | --- |
| 运动性格 | 基于源生物 + 巨化力学，这具身体如何移动 | 六肢交替的沉重步态，头胸随重心前倾摆动，巨化后每步都伴地面震颤与碎裂 |
| 变异动效标记 | 变异标记如何随运动而"活" | 甲缝青绿荧光随呼吸脉动明灭，受激时甲片开合、荧光骤亮；背部结晶节段随发力微微生长 |
| 关键动效节拍 | 3–6 个可复用标志性动作节拍 | ①远景剪影登场压迫 ②巨物踩塌天桥的破坏节拍 ③一条腿局部→全身的尺度揭示 ④低头面向镜头的嘶吼/威慑 ⑤荧光骤亮的异变爆发 |
| 镜头与尺度运动 | 用什么运镜强化体量与压迫 | 低角度仰拍缓慢上摇露出全身；手持穿越烟尘逼近；前景人物/车辆被碾压的对比运动 |
| 特效与环境联动 | 巨物运动如何带动环境 | 步伐扬起烟尘、震落玻璃、荧光孢子飘散、火光被气浪扰动 |
| 时长与节奏建议 | 动效片段的时长与快慢基调 | 3–6 秒/节拍，沉重迟缓与爆发骤动交替，制造压迫呼吸感 |
| 可变 / 不可变 | 哪些锁死跨镜头一致，哪些可在成片阶段变化 | 锁死：源生物结构、荧光标记色、步态力学；可变：机位、地点、破坏对象 |

被感染/异变角色的动效规划同理：常态→异变的变形节拍、变异标记在皮肤/眼/血管的显形动效、保留人形的姿态锚点。

## 4. 建议交付格式（设计图资产 + 动效规划 + 视觉锁定包）

本环节只交付**视觉设计包**，不写剧情、对白、事件时间线或逐镜分镜（这些交给 video creation）。除非用户要求更短版本，按以下顺序给出：

1. 一句视觉总述与主视觉命题（长什么样、什么气质、什么尺度，非故事）。
2. 全局视觉锁（七项）。
3. 巨物卡、角色卡、地点卡，各 3–7 条（造型规则见 `apocalypse-visual-grammar.md`）。
4. 调色/材质/尺度/镜头规则与禁忌项（见 `apocalypse-visual-grammar.md`；写实灾难调色见 `disaster-grade.md`）——作为视觉约束。
5. **设计图资产**：风格基准图；每个巨物的 16:9 三视图 + 变异前/变异后对照 + 关键部位/破坏痕迹特写；每位角色的三视图与头部特写（被感染角色附变异前/后）；末日场景气氛图（3 张左右）；关键帧气氛图（可选）。全部实际产出图像，统一 16:9。
6. **变异后动效视频规划**：每个巨物/异变体一份（第 3 节格式）。
7. **视觉锁定包**：WORLD/SUBJECT/MUTATION/SCALE/MATERIAL/LIGHT/CAMERA 锁定词 + 排除项；标明哪些词必须跨镜头锁死、哪些变量（地点、动作、尺度、变异呈现层级）允许在分镜阶段变化。

每份交付都写明交接说明：接下来由全能创作Agent（video creation）基于本视觉设计包与动效规划规划剧情、分镜与成片，视觉约束不得被推翻。
