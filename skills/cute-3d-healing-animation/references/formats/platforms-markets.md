# 平台规则与市场适配

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 画幅比例

| 平台/用途 | 推荐比例 | 备注 |
|---|---|---|
| 电影感/横屏展示 | 16:9 | 默认推荐 |
| 抖音/快手/短视频竖屏 | 9:16 | 需调整构图重心偏上 |
| 小红书/方形卡片 | 1:1 | 适合单张资产图展示 |
| B站/YouTube横屏 | 16:9 | 与电影感一致 |

## 视频时长与镜头数

| 总时长 | 镜头数 | 每镜时长 |
|---|---|---|
| 30秒 | 6-8 | 3-5秒 |
| 60秒 | 10-14 | 4-6秒 |
| 90秒 | 15-20 | 4-6秒 |
| 2分钟 | 20-28 | 4-7秒 |
| 3分钟 | 30-40 | 4-7秒 |

## 剪辑节奏

- 镜头1-3：建立氛围，节奏最慢
- 镜头4-6：出现小事件，节奏微快
- 镜头7-9：温柔互动，回到慢节奏
- 镜头10-12：治愈收尾，最慢
- 每镜结尾留0.5秒稳定画面方便衔接
- 结尾停留2-3秒，适合循环结尾

## 转场规则

- 柔和硬切或轻微叠化
- 不要快速闪切、故障转场、放大旋转

## 音频规则

- BGM：轻柔木琴/钢片琴/弦乐/温暖环境氛围，节奏不要太快
- 音效：每个镜头1-2个自然音效，不要堆砌
- 台词：默认无台词，仅音效+表情叙事；有台词时写在{}中
- BGM跨镜头连续播放，不嵌入任何单镜视频

## 负面约束（组装时检查）

不要廉价3D / 塑料玩具感 / 过度反光 / 背景脏乱 / 角色表情僵硬 / 眼神空洞 / 动作夸张 / 跑跳翻滚 / 镜头乱飞 / 快速旋转 / 突然变焦 / 频繁切换场景 / 角色变形 / 手部错误 / 颜色刺眼 / 强硬阴影 / 冷灰脏光 / 低清模糊 / 水印文字logo

## 落 prompt 前自检

- 画幅比例是否与目标平台匹配？
- 镜头数和时长是否匹配？
- 剪辑节奏是否符合4段式慢-快-慢-最慢规律？
- 转场是否只用硬切或轻微叠化？
