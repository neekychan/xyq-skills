# 表格分镜规范

> 这些是可适配的模式与句式，按场景改写，不要逐字照搬。

本文件定义"正式表格分镜"的完整规范，供规划层在阶段6输出分镜表时遵循。

## 总体规则

- 每15s输出一个独立表格分镜表。
- 每张表总时长严格为15s；若最后一段不足15s，按实际剩余时长成表并标明。
- 每张表建议包含8-15个镜头或内部切镜，信息密度高。
- 每张表必须覆盖完整"小猫工作日"动作链，而不是静态职业造型展示。

## 四重表达（每张表必须完成）

1. **小猫身份建立**：让观众看清这是用户上传的小猫，保留毛色、脸型、眼睛和神态。
2. **职业身份建立**：通过服装、道具、场景和动作，让观众一眼看出职业。
3. **职场梗推进**：至少出现一个该职业的日常梗或职业刻板印象。
4. **情绪/笑点回收**：每15s至少有一个小猫反差萌、崩溃、犯困、摸鱼、无辜或得意的情绪点。

## 节奏要求

- 每2-3s必须有一个视觉重点。
- 每7s必须有一个笑点、梗点、职业名场面或情绪高潮。
- 开头0-2s必须建立职业钩子。
- 结尾必须形成可截图传播的"打工猫名场面"。

## 表格字段

每张分镜表必须使用以下字段：

| 字段 | 说明 |
|---|---|
| 镜头序号 | 该表内镜头编号，如1-12 |
| 时间段 | 如0-2s、2-4s...，精确到秒 |
| 景别与视角 | 特写/近景/中景/全景/俯视/平视/仰视等 |
| 运镜方式 | 固定/推/拉/摇/移/跟/升降等 |
| 画面内容 | 该时间段内画面呈现的具体内容 |
| 小猫动作与表演 | 小猫在该镜头中的具体动作、表情和表演 |
| 职业身份锚点 | 该镜头中体现职业身份的视觉元素（服装/道具/场景/动作） |
| 职场环境/道具/光影 | 场景描述、道具清单、光线与色彩设定 |
| 职场梗/文案点 | 该镜头承载的职场梗或贴纸文案（如有） |
| 转场逻辑 | 从上一镜到本镜的转场方式与逻辑 |
| 首尾衔接策略 | 首行：如何承接上一段；尾行：如何为下一段预留接口 |
| 生成注意事项 | 该镜头生成时需特别注意的技术点（如身份锁定、道具一致性、光影匹配等） |

## 首尾衔接规则

- **每张表首行**必须说明：如何承接上一段，或如何从小猫照片进入工作日开场。
- **每张表尾行**必须说明：如何为下一段预留动作、道具、镜头方向或情绪接口。
- **最后一张表**必须以封面级名场面结束，不能黑屏、白屏、淡出或无意义空镜。

## beat 结构参考

每个15s表格的内部时间轴建议：

```
0-2s:   职业钩子建立——小猫身份+职业身份第一眼可辨
2-3s:   视觉重点推进——第一个动作或场景展开
3-5s:   工作日常铺垫——小猫开始干这个职业的活
5-7s:   职场梗铺垫——梗点或冲突酝酿
7s:     笑点/高潮——第一次笑点、梗点、职业名场面或情绪高潮
7-10s:  情绪延续——高潮后的反应或升级
10-12s: 第二波梗——新的职场日常或第二个梗点
12-14s: 情绪升级——崩溃、摸鱼、犯困或得意
14-15s: 名场面定格——可截图传播的打工猫名场面，为下一段预留接口
```

## 修改规则

- 任何分镜修改都必须重新输出完整表格分镜（不是只改某一行）。
- 重新输出后必须再次等待用户确认。
- 修改后需检查与前后表格的首尾衔接是否仍然成立。
