# 场景空间、跨镜参考帧与轴线

本机制继承“背景内容匹配→角色→方向→景别兼容性”的四层过滤和回溯补截。参考帧是内容连续性依据，不是风格来源，也不保证模型自动保持空间；生成结果仍须验收。

## 两层空间记录

**世界空间**记录门窗、台阶、固定家具和设备等固定位置，角色实际站位、朝向、持物和光源所在侧；机位移动不会改变这些事实。

**镜头空间**记录从某个机位看到的左右、前后层级、可见/遮挡/画外元素和视线方向。机位反打时必须重新投影，不能因“保持一致”而要求大门永远在画面左边、侧光永远来自屏幕右边。

场景四向图与文字布局统一编号：A→B、B→A、左侧横向、右侧横向；必要时补充局部坐标。每次切换机位，就根据该方向计算人物背后能看到什么。镜表可保留世界坐标说明，最终 prompt 用镜头相对描述。

### 例：正反打

办公室北侧书柜、南侧玻璃门、东侧窗户固定不动。甲在靠北位置，乙在靠南位置。摄影机在乙肩后拍甲，甲背后可见北侧书柜；切到甲肩后拍乙，乙背后可见南侧玻璃门。前一镜的书柜背景不能硬带入后一镜；正反打可以使用不同方向场景图，无合格帧时不用前序帧。镜头仍应在已经选定的对话轴线同侧，写清前景肩部与背景正脸属于不同人物。

## 每镜生成前

1. 重读当前镜最新镜表、角色造型、道具状态、场景状态、资产绑定及用户新上传素材。
2. 确认当前制作范围的核心资产图齐备且已验收；用户明确跳过出图时记录原话与适用范围。
3. 对每个内切镜确认机位、可见地标、遮挡、角色和离场位置；相邻镜的动作/持物/出入画方向可接。
4. 检查参考池所需方向、角色、状态是否存在；缺失先回溯补截，而不是因缺图就接受不匹配参考。

## 截帧与视觉分析

只从合格且版本仍有效的已有片段取帧。先读目标镜的需求，再截帧；站位、背景未变且一帧能覆盖时只截一帧。只有需要互补人物细节、可见区域或有效状态时才截多帧，避免无意义堆图。

选清晰、无转场叠影、无遮挡关键信息、手脸稳定、动作状态适合接续的帧。不能把错误末帧当强制起点：它可能已漂移，需另找合格帧或修复前镜。

逐张实际查看后记录：

| 字段 | 内容 |
|---|---|
| frame_id / file | 可用本地文件或工具资产 ID |
| source_shot / version / timestamp | 来源片段、版本、实际截取时点 |
| scene_id / state | 所属物理场景与日夜/陈设/光影状态 |
| camera_direction / axis_side | 四向编号、机位方向及轴线侧 |
| visible_background | 每个实际可见地标的屏幕位置、遮挡和层级 |
| characters | 在场角色、造型、屏幕位置、姿态和视线 |
| props / departed | 道具持有/状态，离场人物原位状态 |
| shot_scale | 大特写/特写/近景/中景/中全景/远景 |
| quality | 清晰度、身份、风格、空间是否合格 |
| target_match | 针对哪个目标镜，匹配/不匹配及原因 |

不凭文件名或预期填标签，截图后必须看图。预检匹配结果与目标镜绑定，同一帧对新镜要重新判断，不能永久标为“背景匹配”。

## 四层过滤

筛选范围为**本项目同一场景状态、版本有效且质量合格的所有已生成前序片段**，不只看紧邻前镜。任一层不通过即排除，并记录理由。

### 1. 背景内容匹配

核对目标机位实际可见的地标及相互关系，不能把书柜背景用于玻璃门背景的反打。重叠可见区域必须一致；裁切导致某地标不在特写中，并不代表世界里没有它。目标需要而帧未提供的信息由已验收场景布局补充，不能编造或为迁就帧修改正确布局。

缺少标签的用户帧先分析；来源版本已失效、场景时间状态不同、家具被移动或离场座位状态不符，也排除。背景不匹配优先于角色脸清晰或景别接近。

### 2. 角色过滤

角色视角帧以当前镜实际出场角色为对象。下一镜不在场的人物特写不能仅因背景相似而带入。站位帧若包含当前镜不在场的人物，优先选空场/合适帧或裁去该人物；无法避免误生人物时排除。身份细节改用角色母版，不靠不合适的空间帧强行传递。

### 3. 方向过滤

场景拍摄方向、轴线侧与目标内切镜兼容。相反方向不能混在同一个方向的参考集合。一个生成片段含正反打时，按 `cut_id` 分配方向参考；工具不能分配时，采用清晰场景布局/对应单首帧，或将正反打拆成独立生成，不能把相反背景无说明地一起塞入。

### 4. 景别兼容性

沿用下表作为人物戏的默认兼容区间，优先参考目标实际内切镜；同方向多内切镜可按其中最宽景别筛选，但还要复核特写是否被拉宽。

| 目标景别 | 默认可参考景别 |
|---|---|
| 大特写 | 大特写 / 特写 / 近景 |
| 特写 | 特写 / 大特写 / 近景 / 中景 |
| 近景 | 近景 / 中景 |
| 中景 | 中景 / 近景 / 中全景 / 特写 |
| 中全景 | 中全景 / 中景 / 近景 / 特写 / 大特写 |
| 有叙事理由的远景/大全景 | 同方向且信息足够的远景；必要时从场景资产重建 |

不要用全景/大全景帧约束人物近景或特写，以免模型复制宽构图。人物特写可以用于身份，但缺少环境信息时不能声称它单独锁住整个场景。

## 无匹配帧与回溯补截

依次选择：前序已存合格帧 → 从前序合格视频补截并分析 → 有效角色/道具图+场景对应方向图+明确布局文字 → 必要时生成本镜单画面关键帧。补截后照样走背景预检和四层过滤。

如果所有帧不匹配，不纳入前序帧是合法结果；不能为满足“从第二镜开始有参考帧”而引入错误背景。资产缺失回退资产阶段；视频模型无法接收多参考时按 [执行适配](execution.md) 降为单首帧方案。

## 提示词中的参考职责

在完整视频 prompt 的空间段写清：该帧只用于列明的背景布局、姿态或道具状态；本镜景别、机位、构图和运镜按摄影机段。参考帧中的左右位置仅在对应机位成立，不能覆盖世界空间的真实关系。

跨镜起止状态列明动作进度、持物手、朝向、角色离画后的原位状态。变化必须来自可见动作或明确叙事跳时，不能随机出现。

## 生成后与剪辑检查

查看首、中、尾和各内切镜转换处，核对身份、脸/手、造型、地标、视线、道具和光影。首镜合格后才允许作为后续依据；错误镜不进入参考池。

跳轴需要可理解的过轴运镜、中性正面/沿轴镜、交代空间的过渡或重拍；单加一个过肩镜并不保证修复。不得用淡化掩盖换位和穿帮。

重生成前镜时将依赖其帧的后镜标记待复核。仅修正颜色而空间状态没变时可检查后复用；人物身份、场景布局、道具状态或结尾动作变了则更新相关后镜。有效性取决于实际画面，不只取决于文件仍存在。
