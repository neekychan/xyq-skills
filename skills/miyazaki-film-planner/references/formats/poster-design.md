# 宫崎骏动画电影海报设计规范
## 一、美学设计目标
1. 生成符合手绘动画电影美学的艺术封面。
2. 主角处于自然或奇幻世界中，与风、云、森林、海浪、飞行器、动物精灵形成叙事关系。
3. 严禁复刻任何现有动画角色、现有影片海报或已知 IP 场景。

## 二、核心视觉要素
1. **画面情绪**：温暖、冒险、童年、希望、自然敬畏、轻微忧伤但最终向光。
2. **构图原则**：主角位于画面中央或三分线位置，背景展现广阔的世界观场景（天空/森林/海面/奇幻城镇），前景有自然元素（草叶/风/花瓣/飞鸟）增强层次感。
3. **风格要求**：高质量二维手绘动画风格，柔和轮廓线，水彩背景质感，赛璐珞分层，自然笔触，温暖柔和的自然光。
4. **细节要求**：体现风的运动感（发丝/衣角/草叶飘动），云层有体积感，光影柔和，空气中有微小尘埃或光粒子。

## 三、多尺寸出图控制
1. 第一步：生成 16:9 主封面图，提交用户确认。
2. 第二步：确认后，以此风格为参考，延展生成 3:4 和 4:3 两个比例的封面图。

## 四、禁止项
1. 禁止复刻任何现有动画角色、IP 标志、经典海报构图。
2. 禁止三维塑料感、照片写实感、廉价卡通贴图感。
3. 禁止杂乱排版、过多文字、低清晰度、水印标志。
4. 禁止过度对称构图、夸张广角透视（除非剧情有特殊需求）。
