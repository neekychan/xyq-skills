# 特摄战斗设计指南

适用于用户上传皮套角色、特摄英雄与怪人对战、变身、战队协同、巨大英雄与怪兽。素材形象保护优先于风格化和特效升级。

## 一、子类型路由

| 子类型 | 核心观感 | 关键约束 |
|--------|----------|----------|
| 人形皮套对战 | 套装辨识度、招式姿势、接触火花 | 头盔、胸甲、腰带、配色和体型严格锁定 |
| 英雄对怪人 | 身份反差、能力互克、一次终结技 | 双方轮廓和特效色明确区分 |
| 战队协同 | 阵营、队形、接力与组合技 | 精确角色最多 3 个，避免多人形象互换 |
| 明确变身 | 变身装置、形态变化、首轮爆发 | 单片最多一次变身，用户必须明确要求 |
| 巨大英雄对怪兽 | 微缩场景、重量、尺度和建筑参照 | 固定绝对比例，动作缓起快落、落地有惯性 |
| 复古实拍特摄 | 日光、皮套材质、微缩模型、烟火与火星 | 保留实拍粗粝感，避免变成光滑 3D 动画 |
| 现代电影特摄 | 高细节装甲、克制粒子、动态摄影 | 材质更精细，仍保持皮套原造型 |

## 二、上传素材形象锁

### 角色定义顺序

根据素材可见信息逐项写：

1. 头盔或头部：外轮廓、角、耳、复眼或面罩形状。
2. 胸肩：胸甲几何、肩甲层次、主色块和标志纹样。
3. 腰部：腰带、变身装置或核心部件的位置和形状。
4. 四肢：护臂、手套、膝甲、靴子和条纹分区。
5. 材质：橡胶皮套、磨砂装甲、金属边缘、布料连接处。
6. 比例：身高关系、肩宽、头身比和怪人体型。

只选 3 至 5 个最有辨识度的锚点写入首段。角色在旋转、烟尘或强光后再次出场时重复 2 至 3 个关键锚点。

### 默认不可改变

- 不变身、不升级、不换装、不解下面罩。
- 不改变头盔、复眼、胸甲、腰带、颜色分区和标志纹样。
- 不把皮套改成机器人、真人脸或其他物种。
- 不自动增加披风、翅膀、额外武器和发光器官。

## 三、特摄实拍感

从以下要素中选择 3 至 4 项，保持统一：

- 自然日光或明确棚灯，光线能看出皮套纹理。
- 略低机位，让英雄姿态更有力量，怪人更具压迫感。
- 接触时产生局部火星、短促烟雾和装甲颤动。
- 落地扬尘、碎石或浅水飞溅证明重量。
- 轻微手持感，碰撞时短促微震，平时保持可读。
- 微缩建筑、道路、车辆、树木作为尺度参照。
- 复古风保留烟火、钢丝感和模型质地；现代风提高细节与光效，避免过度光滑。

## 四、人形皮套战斗

### 动作语言

- 起手姿势简洁、轮廓清楚，避免手指复杂变化。
- 拳脚以大幅、清楚、可读的动作弧线为主。
- 装甲限制需要体现在肩部和腰部动作幅度中。
- 命中反馈使用装甲轻颤、身体后仰、退步、火星和闷响。
- 终结技前先建立双方距离和方向，再完成蓄势、突入、命中、受击和落地。

### 怪人能力

- 能力从身体部件、武器或口部等可见位置发出。
- 怪人每次只用一种主要能力，避免轮廓被特效吞没。
- 怪人倒地或击退后保持同一个体，禁止复制成多个同款怪人。

## 五、变身流程

只在用户明确提出变身时使用。一次生成内最多一次形态变化。

1. 定义变身前人物与手中装置。
2. 明确装置由哪只手操作，装置何时进入腰带或身体接口。
3. 用一个主要视觉机制完成变化：装甲片闭合、光带扫描、粒子覆盖或轮廓重构。
4. 变身过程保持人物站位和相机方向稳定，减少大幅移动。
5. 定义变身后造型，并列出两个与变身前连续的身份标志。
6. 变身后只安排一轮简洁交锋或一次终结技，避免同片再解除变身。

## 六、巨大英雄与怪兽

### 尺度锚点

- 明确双方高度关系，例如英雄与怪兽等高，建筑只到小腿或腰部。
- 同一组建筑、道路、车辆和树木在各镜头保持尺度一致。
- 先拍脚步与地面，再拉开展示全身和城市参照。

### 重量与惯性

- 转身先由肩胯带动，四肢稍后跟随。
- 冲撞前需要短距离加速，命中后双方继续沿受力方向移动。
- 落地屈膝或脚掌压入地面，烟尘和碎片沿外侧扩散。
- 怪兽尾巴、翅膀或长肢体存在惯性滞后，避免瞬时换向。
- 建筑破坏集中在一处，保持人物轮廓和战斗结果清楚。

## 八、单段策略

- 无变身：完整一轮攻防、一次能力展示、一次终结或悬念。
- 有变身：变身占总容量约三分之一，随后只保留一轮交锋和一次清楚命中。
- 战队：精确角色最多 3 个，使用夹击、接力或控制加输出；角色颜色和位置固定。
- 巨物：动作节拍更少，优先重量、尺度和结果，主要动作不超过 4 个。

## 九、专用尾注

```text
严格保持参考素材中的头盔、复眼或面罩、胸甲、腰带、配色、纹样、皮套材质和体型比例。
用户未要求变身，视频全程保持当前形态，不换装、不升级、不露出皮套下的人脸。
接触火星和烟尘短促局部，不能遮住角色轮廓、接触点和受击方向。
同一怪人或英雄不得复制、融合或更换身份。
```
