# 武打动作片段 Prompt 编写规范

本文件在构造视频 Prompt 前加载，与 `fight-rules.md` 和主类型 Ref 并行读取。

## 一、先做七项规划

构造 Prompt 前先确定：

1. **战斗命题**：双方为什么打、各自想获得什么，用可见动作或站位表达。
2. **动作差异**：双方各自的战斗策略与身体节奏。例：重拳压迫对轻巧反击，长兵控制距离对短兵贴身。
3. **空间地图**：起点、障碍物、移动路线和终点。默认设计一次阵地转移——平面（庭院打进回廊）或垂直（地面打上石台、屋顶）——转移必须由攻防驱动（被击退撞破障碍、借跃斩登上高处），写进预算表大事件列；8 秒以内的短片或用户点名单一场景时可不转移，打透一个场景即可。
4. **强度曲线**：攻防升级路线和一次决定性爆点，无需完整起承转合。
5. **镜头契约**：可读性多机位、一镜到底、主角动量跟随、受力跟随、真第一人称中选一项主导。
6. **段落契约**：独立单段停在精彩处即可，不强求胜负；明确多段的非最终段停在可续写姿态，最终段才需要总决胜。
7. **目标映射**：逐镜头写清攻击者、目标、防守者和阵营，避免主体标签写反。

动作应表达人物：谨慎角色先试探再反击，鲁莽角色持续压迫，老练角色借环境与节奏取胜。避免给所有角色同一套高速连招。

七项规划的对外落点是第三节的分镜预算表：规划完成先填表，填不进表的设计当场删减，再写 Prompt。

## 二、Prompt 总骨架

```text
[任务模式与素材引用]
[主体A定义：静态特征、体型、服装或皮套、武器、持握手、战斗策略、特效身份]
[主体B定义：同上]
[全局风格、色调基调、节奏基调（如：全程快节奏，招式迅疾凌厉，攻防转换毫不停顿）、时代、光线、场景地理和可互动环境]

镜头1或连续阶段1：开场即交锋中——[镜头运动] + [空间站位随动作带出] + [进行中的攻防闭环] + [接触与受力] + [环境和音效]
镜头2或连续阶段2：……
高潮镜头或高潮阶段：[镜头处理] + [全速决定性动作] + [受力跟随] + [余波与落点]

动作连贯清晰，攻防因果与空间方向稳定，接触点可见，受力反馈符合[本片强度档]。
保持主体身份、脸部或头盔、体型、服装或皮套、武器数量与持握手全程一致。
禁止人物复制、融合、瞬移换位，禁止肢体增生、关节反折、武器穿模或无原因消失。
保持无字幕，不生成随机文字、水印和 logo。
[主类型专用尾注，按本片元素裁剪]
```

末尾 4 行基础尾注加专用尾注是骨架的固定组成部分，执行规则见第十节。

镜头序列必须逐镜分行：切镜类语法每行以 `镜头N：` 开头，一镜到底每行以 `连续阶段N：` 开头，行数与分镜预算表一一对应；场景段独立成段，镜头1 同样需要行首标记，禁止与场景描述融合成一段。禁止把多个镜头压成一段连续散文——散文里的"镜头升高、镜头环绕"会被模型执行成单镜头连续运镜，切镜意图全部丢失。类型 Ref 中的散文形态示例仅示范一镜到底与动量跟随语法；选切镜类语法时按分行形态输出，禁止模仿散文示例。

Prompt 中每个字都必须可渲染。打击强度、镜头语法、声音策略不写抽象声明词（如“打击强度为电影级克制”“主导镜头为可读性多机位”“声音策略以原生音效为主”），全部体现在各镜头的具体动作、受力与运镜描述中；战斗动机用一个可见动作或空间状态表达（如“主体A横剑挡在山门前”），禁止“胜负决定仙门存亡”一类叙事设定句。字数全部投给攻防与特效描述。

编辑与延长模式严格使用 `fight_scene/SKILL.md` 规定的开头句式。编辑 Prompt 逐字以 `严格编辑<视频1>` 开始，延长 Prompt 逐字以 `延长<视频1>` 开始，尖括号不可改成 `@视频1`。新片参考模式才使用 `@图片N` 或 `@视频N` 定义主体。续段从上一成片末尾 5 秒继续，禁止复述或重演尾段已经发生的动作。

## 三、镜头数量随时长缩放

| Duration | 多机位建议 | 一镜到底建议 |
|----------|------------|--------------|
| 2 至 8 秒 | 2 至 3 个镜头，保留一次核心交换与命中 | 2 个连续阶段，突入与终结 |
| 9 至 15 秒 | 3 至 5 个镜头，完整起承转合 | 3 至 4 个连续阶段，路线清楚 |
| 时长高于 15 秒且当前模型允许 | 5 至 7 个镜头，加入环境互动和二次升级 | 4 至 6 个连续阶段，景别由运动自然变化 |

### 分镜预算表（生成前唯一输出的规划产物）

规划完成后、调用生成前，在回复中输出一张预算表（禁止写成文件）：一镜一行，**先分秒数、再填交换与事件**——写不进秒数的内容当场删减，不许压进同一镜。秒数只用于本表核算，Prompt 中仍用镜头顺序词、禁止时间戳。

| 镜头/阶段 | 秒数 | 语法与景别 | 攻防交换 | 大事件 | 切点与声音 |
|-----------|------|-----------|---------|--------|-----------|
| 1 | 6 | 多机位·中全景 | 交换×3（劈-架-撩反击） | 无 | 武器掠镜切出；<金属交鸣> |

填表约束（任一不满足先改表再写 Prompt）：

- 各镜秒数之和 = Duration，单镜 2 至 6 秒。
- Prompt 镜头行与本表行一一对应：表有几行，Prompt 就有几个 `镜头N：`（或 `连续阶段N：`）行。
- 单镜交换次数 ≈ 秒数 ÷ 2（上下浮动 1）——密集感靠交换频率与招式轮换，不靠一镜塞满。
- 大事件列只写改变位置、武器、形态、目标或胜负的事件，全片合计守 `fight-rules.md` 的 2、3、5 预算，成组并发元素整组计一。9 秒以上默认其中一件是阵地转移（平面或垂直，由攻防驱动），用户点名单一场景时除外。
- 高潮镜头的攻防交换列只含决定性动作、受力与余波，铺垫动作放前一镜；高潮前一镜的切点与声音列含一次降速标记（极短停顿或声音抽空）。
- 末镜攻防交换不得为 0：余波与回稳并入高潮镜，或与再扑起手同镜；纯收势不单独成镜。
- 语法与景别列相邻行至少改变一项机位要素（方位角/高度/景别），全片含一次高低角机位与一次短弧环绕（一镜到底不受此限，按运镜转向写）。
- 切点从格挡、遮挡、转身、落地、武器掠镜中选（一镜到底写运镜转向）；声音每镜至少一项接触音或环境音，表中规划的 `<>` 音效必须在 Prompt 对应镜头以 `<>` 标签原样落地，禁止只留在表里。

使用事件顺序，不写精确秒点。密集攻防和招式轮换是这类视频的核心爽点，放心写满：每个交锋镜头至少 3 次可见接触（命中、格挡或闪避各计一次），全片按每 2 秒至少一次交换的密度铺排；拳、肘、膝、摔、劈、扫、刺等招式持续轮换，同一招式不连续超过两次。远程法术对轰按类型 Ref 的远程交换单元换算：一次"投射—拦截—反制"闭环计一次可见接触，密度指标照常适用，投射与拦截方式持续轮换。高强度动作模型可以执行，不要为求稳而减招。每镜头是一条连续攻防链，链内密集往返但不切换武器、形态或插入大招流程——要换就换镜头。开场即交锋，第一句就写到接触点，不给对峙蓄势单独成镜（用户点名以静制动或要求铺垫时除外）；独立的建立与收束镜头合计不超过全片四分之一。改变位置、武器、形态、目标或胜负的事件按 `fight-rules.md` 的 2、3、5 节拍上限计数，招式交换次数不计入节拍、不设上限。

节奏紧凑靠两条写法保证：其一，每个攻击动词带速度修饰——疾刺、急斩、瞬间突入、毫不停顿、一气呵成；无速度词的单发动作句会被模型执行成慢动作。其二，攻防不脱手——交换之间禁止“后跃拉开距离”“悬浮蓄力”“剑气重新凝聚”“再次对峙”一类脱离重整过渡，上一次接触的收势直接衔接下一次进攻，被击退方立即回身反扑；唯一允许的降速是高潮前的一次极短停顿或声音抽空。远程法术对轰范式下"不脱手"按远程口径执行：中远距对射本身是常态而非脱手，但结印凝聚必须与位移、防御或压制并行，独立悬浮蓄力仍然禁止，上一发的拦截结果直接衔接下一发投射或反制。

## 四、动作六段闭环

每次关键命中按以下顺序写：

`身体驱动 → 攻击轨迹 → 接触位置 → 受击反应 → 材质与镜头反馈 → 下一姿态`

可执行写法示意：

> 主体A左脚踏稳湿地、转髋送肩，右肘横向撞向主体B左侧护甲；主体B抬前臂架挡，仍被冲力推退两步，鞋底刮起一道积水。接触瞬间护甲边缘轻颤，镜头短促微震，响起沉闷撞击和金属余颤。主体B退到石柱旁压低重心，顺势准备反击。

六段闭环分两档使用，密集感与字数预算才能共存：

- **压缩闭环**（快速交换用）：一句写完攻击、防守与接触反馈，句内必带速度词、具体招法和一笔接触声响。例：主体A垫步抢中线，直拳、摆拳、顶肘三连疾攻，拍挡声连响，主体B架开两记、第三肘擦颊掠过，反手贯拳又被主体A拧腰潜闪。
- **完整闭环**（每镜头至多一次，决定性命中用）：按六段完整展开。

### 打戏语言

攻防句用武指级技术词，密度靠具体招法名堆出来，禁止“攻击、打过去、挡住、躲开”类泛词：

| 类别 | 词例 |
|------|------|
| 徒手攻 | 直拳、摆拳、勾拳、贯拳、鞭腿、正蹬、侧踹、扫堂腿、膝撞、顶肘、盘肘、掌根击、擒拿锁腕 |
| 兵器攻 | 劈、砍、撩、抹、带、扎、刺、点、崩、挑、绞、截、扫、回马式反手斩 |
| 防守 | 拍挡、挂挡、架桥、截击、格开、摇闪、潜避、侧闪、卸力、借力打力、缠腕夺械 |
| 步法身法 | 垫步突进、滑步、插步换位、拧腰转胯、沉身、寸步逼近、贴身抢入、错步绕背 |
| 连招衔接 | 虚招引手、连消带打、后发先至、抢占中线、贴身短打、顺势牵带、一压一放 |

类型 Ref 中的门派与题材专用招法（如咏春摊膀伏、枪法拦拿扎）优先于通用词。

检查点：

- 攻击有落点，闪避有方向，击退有来源。
- 防守动作与攻击类型匹配。
- 受击方身体与脚步都产生反馈。
- 下一镜头能从当前姿态继续，不重演已经完成的动作。

## 五、镜头语法模块

### A. 可读性多机位

适合大多数双人对决：

- 首镜头直接从进行中的交锋切入，双方距离和场景几何随攻防带出，禁止静态对峙建立单独成镜。
- 交锋机位在侧后跟拍、俯压、仰拍、越肩与短弧环绕间轮换，保留双方上半身、脚步与武器轨迹；短弧环绕（90° 至 180° 绕至侧面或背面，落点明确）优先用在攻守转换和高潮碰撞；大招起手、处决与高潮命中可切近景或特写打点，命中后一拍内回到可读景别。
- 接触点只做一次短促近景，随即回到能看清攻防的景别。
- 终结动作全速完成，用受力跟随或急拉全景交代结果，不加慢放。
- 切镜落在格挡、遮挡、转身、落地或武器掠过镜头等动作节点。

### B. 连续环绕一镜到底

适合完整攻防、走廊闯关和粒子扩散：

- 全片声明连续拍摄，不切镜。
- 相机路径由角色动作驱动：突进时推进，闪避时横移，绕柱时弧形环绕，击退时短暂跟随受击方向。
- 用人物擦过镜头、柱体遮挡、穿门和贴近武器轨迹完成景别变化。
- 每个阶段写清摄影机上一阶段的落点与下一阶段方向。
- 禁止使用“切到、跳到、快速剪辑、多个机位”等词。

### C. 主角动量跟随

适合 1v多、跑酷接战和单人压制：

- 镜头保持在主角侧后方或肩后，跟随冲刺、闪身、旋转和落地。
- 主角改变方向时，镜头沿同一运动弧线跟转，避免瞬移换边。
- 环境物体从前景高速掠过，增强速度和路线感。
- 命中可短暂转向受击者，下一拍立即找回主角。

### D. 受力反馈跟随

适合重击、击飞、机甲撞击和怪兽对轰：

- 命中前先保留攻击者完整发力。
- 接触瞬间镜头短暂停顿，再跟随受击者后仰、退步、撞击或落地。
- 衣料、头发、装甲部件和尘土按惯性滞后。
- 镜头震动短促，撞击结束后稳定下来展示结果。

### E. 慢动作（默认禁用）

- 默认全片不用慢动作，一切命中、碰撞、大招和终结都保持全速，冲击感靠受力反馈和镜头微震表达。
- 唯一例外：千钧一发的闪避——兵刃或招式擦着要害掠过的瞬间，可用一次极短慢放展示擦过距离（如刀锋贴着脸颊削断发丝），随即立刻恢复全速反击。
- 全片至多一次，禁止用于命中、对轰、起跳、落地或终结。

### F. 机位轮换与轴线（切镜类语法通用）

- 同侧积极轮换：交锋双方的连线是轴线，机位在轴线同侧的 180° 半圆内轮换——相邻镜头至少改变一项机位要素（方位角、高度或景别），全片至少一次高低角机位（俯压或仰拍）、至少一次短弧环绕；禁止全片停在同一侧向水平机位（舞台剧感），也禁止跳切到轴线对侧。
- 越轴只有两种合法方式：环绕运镜连续带过，或插入一个正对轴线的中性镜头；越轴后双方左右关系随之更新并保持。

真第一人称的完整规则见 `fight-pov.md`。

## 六、打击强度曲线

默认开场就处于交锋中段，攻防交换全程保持高频、招式持续轮换：写实靠连环拳脚、摔擒与兵器往返，玄幻靠每次接触的贴附特效迸发；大范围爆发仍全片唯一，密集感来自接触频率和招式变化，而非大招流程堆叠。

### 写实片段

采用三层递进（第 1 层可极短或省略，直接从压迫中开场）：

1. **试出破绽**：短促试探、格挡、步法调整。
2. **持续压迫**：组合拳、连续兵器压制或近身控制，环境开始响应。
3. **决定性反击**：一次清楚命中和完整受力链。

### 特效片段

采用四层递进（可直接从第 2 层属性交锋中开场，能力随首次接触显形）：

1. **能力显形**：小范围贴体或贴兵器光效。
2. **属性交锋**：双方色彩与材质对撞，每次接触都有贴附特效迸发，仍能看清身体动作。
3. **防线突破**：护盾、装甲或环境结构出现清楚变化。
4. **高潮爆发**：唯一一次大范围效果，之后回到人物落点和余波。

### 静势速胜（以静制动）

适用于一招制敌与实力碾压题材：

1. **静止蓄势**：长对峙、细节特写、环境音渐弱，弱势方或群敌持续逼近；蓄势段合计不超过全片一半。
2. **唯一决定性交锋**：一次完整六段闭环完成胜负，强者动作极简，与对手的密集动作形成反差。
3. **余韵收势**：败者延迟倒下、兵器断裂或衣带断开等物证显现，胜者收势。

全片可以只有 1 至 2 个主要动作节拍，静止蓄势段不受攻防交换频率约束。

### 变身显圣

主类型为变身显圣时不使用以上曲线，改按 `fight-transform.md` 的四段结构（压迫开场、变身序列、唯一一击、显圣收尾）执行；攻防交换频率、开场即交锋、末镜交换不为 0、结尾禁止单方败象与建立收束镜头占比条款对该类型不适用，其余骨架、分行、符号与尾注规则照常。

避免各镜头强度完全相同。高潮之前至少保留一次短暂降速、停顿或声音抽空。

## 七、声音设计

新片与续段默认靠原生音效驱动节奏，声音与动作同一事件发生。编辑模式沿用原片声音，只有用户明确要求时才修改声音层。

1. **运动层**：衣料、脚步、兵器破风、装甲伺服。
2. **接触层**：拳脚闷响、金属撞击、护盾裂响、怪兽撞击。
3. **环境层**：积水、碎石、木板、玻璃、竹叶、建筑回声。
4. **呼吸层**：蓄力吸气、受击闷哼、恢复喘息、短促战吼。

决定性一击可在命中前制造极短静默，命中时释放主音效。BGM 只有用户明确要求时加入，并在场景段落开头用 `（）` 标明贯穿风格。

用户提供音频素材时，按 `AudioList` 顺序在 Prompt 中明确引用：`@音频1` 用于指定角色音色、音乐节奏或动作音效。多个音频分别绑定用途，禁止含糊写成“参考音频”。

动作叙述中的声音可写入散文描述，独立音效提示统一用 `<>` 标签，两类并存不冲突。`<>` 标签全片不超过镜头数加 2，每镜头至多 2 个，优先保留接触与决定性事件的声音。

## 八、特效描述公式

为每名角色固定：

`主色 + 材质 + 形态 + 附着位置 + 运动方式 + 消散方式`

示意：

> 主体A使用深青色半透明水纹剑气，贴附在剑刃两侧，挥剑时形成薄而锐利的弧形尾迹，命中后碎成细小水珠并迅速蒸散。

同一角色在所有镜头中复用同一组关键词。特效遮挡人物关节或接触点时，降低亮度、范围或粒子密度。

## 九、结尾落点

默认全程聚焦交锋，结尾不强求胜负：停在最后一次清楚命中的受力反馈、一次击退后的再逼近、或再扑起手的瞬间都成立。结尾落在一个完整接触或进行中的攻势上，不停在挥击中途，也不用大爆光完全遮住双方。

未经用户点名胜负时，结尾禁止单方败象——倒地不起、跪地、缴械、兵器拄地喘息、瘫靠墙柱都算；受击方回稳（撑地弹起、借物卸力站定）后直接衔接再扑起手或对手再压上，收在攻防进行时。余波与回稳合计不超过两个动作节拍：禁止把收剑、站定、特效归敛、对峙蓄势连成一串收势链——收势链按文字占比会被渲染成结尾数秒的无对抗画面。

- 用户明确要求胜负、KO、缴械、逃脱或悬念时，才安排对应结果画面并确保其在画面中可见发生。
- 明确多段的非最终段：完成本段交锋后停在稳定站位，武器、伤势、特效余态、镜头方向和环境声清楚可见，供下一轮从末尾 5 秒续写。

## 十、负面约束尾注

新片参考、纯文本和续段的基础尾注已内联在第二节骨架末尾，执行规则：

- 第 1 行的 `[本片强度档]` 替换为实际强度档名（写实克制、电影夸张或玄幻拉满）。
- 第 2 行允许删去本片不存在的元素（无头盔、无皮套、无武器时删去对应词），真人片必须保留“脸部”。
- 第 3、4 行逐字保留。
- 专用尾注按本片实际元素裁剪，未出现的元素行删去（例：无轻功动作删去轻功行）。加载两个类型 Ref 时以主 Ref 为准，与本片设定冲突的行删去（例：拟人动物动画片删去“保持真人写实物理”行）。特摄、动画、第一人称、游戏 UI 等类型按各自 Ref 追加专用尾注。

编辑模式改用以下尾注：

```text
严格只修改用户点名的内容，保持原片时长、原声音、字幕、UI、已有文字、logo、主体身份、镜头节奏和其他未提及内容不变。
不新增随机文字、水印、logo、人物复制、肢体异常或武器跳变。
```
