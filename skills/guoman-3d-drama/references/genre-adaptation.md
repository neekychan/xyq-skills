# 跨题材制作：固定画风，按故事建立世界

立项、改题材、准备设定图和套用旧模板时读取。本文件规定时代、道具、对白、音乐的选择方式；视觉表现始终服从 [风格契约](style-guide.md)。

## 项目世界观记录

| 字段 | 填写方式 |
|---|---|
| 题材与情绪 | 例如现代都市悬疑、校园喜剧、历史权谋、未来救援；不是互斥列表，可组合 |
| 时代与地域 | 当前社会、历史时期、近未来、遥远未来或原创世界，明确故事实际所在地 |
| 世界规则 | 科技/法术水平、社会关系、特殊能力的条件与代价；普通现实题材可记“无超自然设定” |
| 元素边界 | 允许的服饰、建筑、交通、通信、道具；排除与本项目矛盾的元素，不统一禁现代 |
| 台词与声音 | 语言、自然口语/雅致/行业语体、角色声口、音乐方向、主要环境声 |
| 稳定视觉项 | 原样锚定词、三维建模、材质、明度/对比/雾化/柔光规则、人物与场景版本 |

已有原稿优先。缺少普通细节可在授权创作范围内补成明确可修改的设定；影响故事因果的规则应集中提出具体缺口，不用补设定把现实剧情变成超自然故事。

## 题材适配表

以下是可选制作方向，题材范围不限于表中。

| 题材/世界 | 角色、场景与道具 | 台词与表演 | 声音与配乐 | 需要防止的误套用 |
|---|---|---|---|---|
| 古风/历史/武侠 | 时代相符服制、木石建筑、兵器、信件 | 按身份雅致或市井，动作完整 | 器乐/弦乐/环境声依场景 | 非奇幻历史不强塞法术；允许的穿越物件按设定保留 |
| 现代都市/职场/情感 | 西装、便装、公寓、会议室、手机、汽车 | 自然口语、关系与潜台词 | 钢琴/弦乐/电子/城市声可选 | 不换古装，不把手机变玉佩，不默认古琴 |
| 校园/成长/喜剧 | 校服/运动服、教室、操场、书包等 | 符合年龄的口语、节奏和反应 | 轻打击/拨弦/校园环境声可选 | 不把学生做成成年宫装角色；笑点不用每句甩袖 |
| 家庭/日常/治愈 | 各年龄家人、厨房、客厅、生活用品 | 细节、沉默、视线和自然交流 | 稀疏钢琴/原声/生活音可选 | 保留老人年龄，不把所有人美化为同龄少年 |
| 悬疑/推理/惊悚 | 依据案件时代设置证物、空间与信息 | 信息差、视线、停顿与可追溯线索 | 稀疏声响、低音纹理、静默 | 不用漆黑高反差代替固定画风；不随意增造线索 |
| 科幻/未来/机甲 | 机能服、舱室、设备、机器人及明确技术规则 | 人物目的先于术语，操作有反馈 | 合成器/脉冲/机械与通信声可选 | 不把技术转成法术，不给设备默认加古代云纹 |
| 末世/废土/生存 | 功能衣物、磨损、残损空间、资源道具 | 行动代价、疲惫与抉择 | 风声、金属、稀疏节奏可选 | 不把清透渲染误解为物件必须崭新，不涂黑所有画面 |
| 奇幻/神话/架空 | 按独立世界决定文化、形制与能力边界 | 按族群/身份/关系确定语体 | 依世界和情绪选声，不必固定民族配器 | 不把所有奇幻都归为修仙，不增原稿没有的法阵 |
| 穿越/混合时空 | 为每个时空及穿越物件记录来源、作用和状态 | 声口差异来自人物经历 | 根据时空切换选择声音对照 | 不把剧情所需的时代错位当穿帮自动删除 |

## 在制作链中的应用

1. **分析与改编**：保留题材核心机制；时代变化属于内容改编，不能在单纯换渲染时顺手执行。
2. **资产拆解**：每个角色造型、场景、道具引用世界观。手机、门禁卡、机甲关节与玉佩一样登记形制、材质、持有者和状态。没有必要出现的法术、光纹、古典建筑不入清单。
3. **设定图**：采用统一模板的几何和布局；在锚定词后立即说明时代、职业、服装和空间。把抽象“东方气质”落实为轮廓、柔光、材质与配色，不靠乱加古代饰物实现。
4. **分镜/视频**：维持空间锚点、四层选帧、动作起止与表演一致。现代/未来道具的显示/开合/充能等状态须记录；屏幕上决定剧情的文字应准确后期制作并校对。
5. **音频**：画风不限制配器。对白声口、OS、VO、环境音和 BGM 分开设计；自然现代对白不强制使用古风念白速度。
6. **剪辑验收**：除了画风、空间与声音，还检查是否无故古装化、设备变法器、现代对白文言化、配乐默认古琴化。发现后只修相关模板和素材，已验收内容保留。

## 完整示例：现代角色设定图

示例项目为现代都市悬疑。用户已有的衬衫、腕表和手机属于内容，转换画风时保持。以下为完整视觉 prompt 示例，未调用生图。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作现代都市短剧角色林遥 C01 的统一设定板，16:9。林遥是一位32岁女性建筑师，修长面部轮廓，清晰而柔和的下颌，略长的眼型，黑色齐肩短发，左眼下方一颗小痣，暖米色皮肤带细腻柔和的次表面散射，保留成熟年龄感。穿灰蓝棉质衬衫、深灰直筒长裤、白色低帮鞋，左腕细银色腕表，衬衫织纹、领口缝线与衣料垂坠清晰，三视图配饰数量与位置相同。常态嘴唇轻合，目光专注，双手自然垂下。左侧三分之一是面部特写，右侧三分之二为正面、侧面、背面全身站姿，均为同一人。白底、柔和均匀展示光，发束反光细腻，轻雾与柔光不遮五官和衣物细节。服装保持现代职业装，不添加古装发冠、玉佩或法术粒子，无文字标签、水印和多余人物。
```

## 完整示例：未来场景四向图

舱室是原创未来场景；四向图用于布局，作为视频首帧前仍需生成合格单画面关键帧。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。制作未来轨道站维修舱 SC02 的四向空间设定板，16:9、2×2网格，四格为同一个长方形舱室。北墙中央为圆形气密门，南墙中央为窄观察窗，东墙中部是固定维修台，西墙中部是两列封闭储物柜；地面中央通道贯通南北。材料为暖白涂层、霜银金属、深青防滑地面和局部透明玻璃，接缝、铰链、磨损细腻，仪表显示为低亮蓝色图形。左上从南向北看气密门，维修台在画面右侧；右上从北向南看观察窗，维修台在画面左侧；左下从西向东看维修台，北门在画面左缘；右下从东向西看储物柜，北门在画面右缘。四格结构、尺寸、陈设位置与数量一致。柔和均匀展示光，暗部有细节，透明轻雾不遮接缝与地标，高光柔和不过曝。空场无人物，无古代殿宇、符箓、法阵、格内文字标签和水印。视频剧情照明另登记为北侧门框柔和暖白灯与顶面漫射光。
```

## 完整示例：现代短镜视频

此示例设定镜表和相关资产已实际验收。生产时须按工具真实语法绑定 C01-L01、SC01、P01，或绑定由这些资产生成的单画面关键帧；以下 ID 只是演示，不可冒充实际素材。

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。现代都市悬疑短剧 EP01-SH001，9:16竖版。
[摄影机] 单个近景，平视，摄影机在林遥南侧向北拍摄，缓慢推进到面部特写，让手机发现引向她的反应。
[主体] 林遥 C01 穿已锁定的灰蓝衬衫造型 C01-L01，右手握黑色手机 P01。起始看向手机，拇指按下侧键熄屏，眉心收紧；随门外脚步声停住，抬眼看向画面右侧的门外，手机仍握在右手胸前。她不动嘴，呼吸稍停，最后保持视线与持物状态，未离开原位。
[空间] 公寓书房 SC01-DAY：东侧窗户柔和日光，暖白漫反射，阴影保留细节，轻雾透明。此机位北墙书柜在她背后，东窗与房门都在画面右外侧不可见；没有第二个画中角色。绑定角色图用于身份，场景图用于布局，道具图用于手机形制，不复制设定板排布。
[音频] 后期独立制作林遥同一声音身份的内心OS：“这条消息，是我明天发的。”先有轻微侧键声，随后画外门边两步脚步声；视频只保留闭口表演，声音按时间线加入，不重复原生朗读。
[禁止] 无内嵌BGM、字幕、文字叠加、水印；不添加古装、法器或发光法阵，不改变手机持握手、人物造型和房间结构。
[时长] 8秒。OS按实际朗读长度安排，留出抬眼与视线停留，片段结尾手机仍在右手胸前。
```
