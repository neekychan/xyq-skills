## 五、音乐 MV 类

> 用途上可服务剧情叙事、营销转化或知识讲述，但在分镜执行层统一走「音乐 MV 类」骨架。
> **二级呈现形式**：音乐 MV 分镜图（剧情 MV）、歌词逐段视觉化、情绪氛围 MV 分镜、表演·对口型 MV 分镜、舞蹈·唱跳 MV 分镜、概念视觉 MV 分镜、歌词字幕·动态排版分镜。下方给出代表性骨架；其余二级呈现形式的细化模板见本章末「PE 模板索引」。

### 适用要点与判定关键词

- **定义**：以音乐、歌词、节拍和情绪为主线的分镜图/多宫格 storyboard，可用于剧情 MV、舞台表现 MV 或纯情绪向 MV。画面必须与乐段和歌词段落有清晰对应。
- **判定关键词**：`音乐视频`、`MV`、`歌词视频`、`Lyric Video`、`按歌词出画面`、`卡点`、`主歌`、`副歌`、`桥段` 等。
- **边界**：
  - vs 剧情叙事类：剧情分镜以故事为主，音乐只是配乐；本类以音乐和歌词为一号约束，故事服务歌曲。
  - vs 营销转化类：广告 MV 若核心是卖货，可在用途上归为营销，但在分镜执行层仍使用本类 MV 模板约束节奏。
  - vs 情绪氛围视频：本类要求大部分格有明确的乐段/歌词对应，而纯情绪片可以不逐段对齐歌词。

### 分镜结构建议

- **推荐宫格数**：8–16 格，对应“引子/主歌/副歌/桥段/尾声”等乐段。
- **结构骨架**：
  1. 引子：1–2 格，建立情绪与主空间；
  2. 主歌：3–6 格，按歌词段落铺陈剧情或意象；
  3. 副歌：3–6 格，画面节奏与运动感明显提升，形成记忆点；
  4. 桥段/过门：1–2 格，用场景/意象/道具过渡；
  5. 尾声：1–2 格，情绪回落或开放式收束。
- 每格需同时考虑：所属乐段、对应歌词、画面情绪与色彩变化。

### 生图 Prompt 骨架

```text
你是一名音乐 MV 分镜导演，请为下述歌曲设计一张 {宫格数} 宫格的音乐 MV 分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”或“16:9 横版 MV”}。

【歌曲与歌词信息】
- 一级用途类型：音乐 MV 类
- 二级呈现形式：{剧情 MV 分镜 / 歌词逐段视觉化 / 情绪氛围 MV 分镜 / 表演·对口型 MV 分镜 / 舞蹈·唱跳 MV 分镜 / 概念视觉 MV 分镜 / 歌词字幕·动态排版分镜}
- 歌曲名称：{歌名}
- 曲风与情绪：{如“抒情/摇滚/电子/治愈/孤独/热血”等}
- 节奏结构：{如“Intro-主歌A-副歌A-主歌B-副歌B-桥段-尾声”}
- 完整歌词：{粘贴歌词全文，保留分段}

【画面风格】
- 视觉风格：{电影感写实 / 2D 动漫 / 3D 卡通 / 抽象视觉等}
- 主色调：{主色调 + 对比色，例如“冷蓝+霓虹粉”等}
- 角色与场景：{主要角色设定 + 主场景，如城市夜景/教室/舞台等}

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 M1 到 M{N} 的分镜要点，包括「所属乐段 + 对应歌词句 + 画面意象/角色状态」，供用户确认；确认后再按以下格式，为每格写出详细分镜说明：
1. M1：
   - 所属乐段：{如“主歌A”或“副歌B”}
   - 对应歌词：{逐字写出本格对应的歌词句}
   - 画面内容：{角色/场景/意象如何表达这句歌词}
   - 情绪与色彩：{如“孤独冷色调”“热烈暖色调”}
   - 节奏与卡点：{对齐哪一拍或哪句歌词做切镜}
2. M2：……
……直到 M{N}，确保所有关键乐段都有对应画面。
```

### 一致性与避坑

- 保持角色外观与服装在整支 MV 中高度一致，仅在剧情需要时做小幅变化（如换外套/加道具）。
- 主色调与视觉风格在不同乐段间应是同一体系内的变化，避免“每段一套完全不同风格”导致割裂。
- 为歌词字幕预留清晰区域，避免复杂纹理/高频闪烁影响阅读。
- 禁止将大量歌词挤在单一格上，导致字幕过密看不清。

#### 乐段/歌词链与分镜设计卡（P1）

- 每格必须绑定所属乐段（主歌/副歌/桥段/尾声）与对应歌词句；每个 shot 生成分镜设计卡：事件 ID、镜头功能（建置/推进/反应/冲突/转折/收束/解释）、观众新增信息、与上一段关系、人物关系可见证据、段尾状态。
- 分镜设计质量验算：每个 shot 至少绑定一个事件 ID；相邻 shot 新增信息不得完全重复；连续 3 个 shot 不得同一镜头功能/景别/构图。

### 视频生成策略与 PE 模板

```text
请基于下述素材生成一条 {时长秒数} 秒的音乐 MV 视频，使画面节奏与主歌/副歌/桥段大致对齐，并尽量呼应分镜图中的画面与情绪。

【输入素材】
- 分镜图：{路径或 ID}（{宫格数} 宫格，已标明每格对应的乐段与歌词）
- 参考图：{主视觉海报/角色立绘/演出现场等，如有}
- 歌曲信息：{歌曲名 + 情绪 + 结构}
- 目标画幅：{画幅说明}，ratio={ratio 代码}
- 目标模型：以用户指定的模型为准；用户未指定时，探索可用 seedance_2.0_fast，定稿可选 seedance2.0_direct

【生成策略】
- 按乐段规划镜头长度：主歌段镜头相对平稳，副歌段增加运动感与特写；
- 将分镜图中的关键格作为参考帧，引导角色造型、场景氛围与色彩；
- 在副歌和高潮处适度增加运镜与节奏变化，但避免花哨到抢走歌词注意力。
- 若已提供完整歌曲音频，音频准备与分段建议参考 creative/mv-creator.md 复用其“音频转黑屏视频 + 按前奏/主歌/副歌/间奏拆段”的链路：将整首歌曲先转为黑屏视频再按结构切成若干片段，在每个段的 sandbox_generate_video 调用中将对应片段放入 VideoList，Duration 尽量与该段音频时长严格对齐，并在 Prompt 末尾统一添加“禁止生成BGM”。分镜图主要决定各段画面内容与节奏，不直接替代音频分段步骤。

【质量要求与常见问题规避】
- 角色造型与场景在全片保持统一，避免中途“换人/换世界观”；
- 保证歌词字幕区域足够清晰，不被强光、纹理或复杂动作遮挡；
- 所有中文歌词文字、镜头编号与镜头参数信息优先由脚本或后期文字层叠加，图像模型仅负责画面，不直接生成长篇中文文字，以避免模糊或错字。
- 需要口型同步的演唱段，Prompt 需结合 creative/mv-creator.md 的“使用@视频1中的音频驱动@图片1中的主角生成MV，口型严格同步: {该段歌词原文}”句式：在 Prompt 中逐段粘贴完整歌词原文，并确保 Duration 与该段音频完全一致；非演唱段则以歌词意象为主，可弱化口型约束。
- 剧情向 MV 建议按 creative/narrative-arc.md 的弧线模板为整首歌规划“引子-发展-高潮-余韵”结构，再将结构拆映射到音乐段落与分镜格，以免画面只跟节奏不讲故事。
```
