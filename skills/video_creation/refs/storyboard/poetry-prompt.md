# 古诗词 Prompt 编写指南

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意发散阶段的范式路由、意象转译、诗风定调、完整度策略见 `creative/poetry-recital.md`。

## 诗词体裁时长参数（分段定时长用）

分段与定时长时按下表取值（即分段规则中"诗词吟诵分速与句后静默按体裁 ref 取值"的落点），不使用 `count_chars.py` 的通用语速口径：

| 文本类型 | 语速 | 说明 |
|---------|------|------|
| 诗句原文（吟诵腔） | 2 字/秒 | 计量时对诗句原文调用 `count_chars.py --mode slow`（吟诵口径）；字数=纯汉字数，标点不计；音步停顿已含在语速内不另计时 |
| 自创文本（自述/讲解/旁白/台词） | 3 字/秒 | 用 `count_chars.py` 默认口径计量，禁止拉慢到吟诵速率 |
| 静默 | **0s，无任何名目** | 诗词链路不存在设计静默：锚点句后留白、引诗后静默、情语留白、画面呼吸空间、余韵段全部禁止；句间只有 TTS 自然换气，禁止刻意停顿；禁止用静默/定格阶段凑满段时长 |

**朗诵段 Duration 口径（硬等式）**：朗诵段 Duration = 该段诗句吟诵耗时 + ≤1s 收尾缓冲（技术容差，非留白），**画面事件与吟诵并行呈现，不单独占用时长**——"独立视觉事件支撑无台词时间"的通用条款不适用于朗诵段，**不存在无吟诵的画面段落**。段时长富余想放更多画面 → 补入下一联诗句与之并行，而不是留无声画面。自检：逐段报「吟诵耗时 / Duration」两个数，必须满足 0 ≤ Duration − 吟诵耗时 ≤ 1s——超出 1s 即缩段或补联；低于吟诵耗时即装不下，加长段（不超单段上限）或把整句挪到相邻段。**每句诗全片只吟诵一次**：同一诗句原文禁止写入多个镜头或多段的声轨（出镜吟诵过的句子不得再以旁白重复，禁止"尾音延续"式重写句文），吟诵跨切点时句文只写在起始镜头。**主 Agent 任务简报或 creative_design 给出的总时长/时长分配与本口径冲突时，以本口径为准缩段，并在返回结果中报告修正后的实际总时长**——"总时长约 N 秒"的简报数字和"吟诵+画面铺陈"的分配意图都不是铺时依据。

## 画面轨编排（先于模板执行）

- **段内多镜头，换句必切**：用"切至"显式切镜并逐镜头标时间锚点（格式同 `storyboard/prompt-craft.md`「长段阶段化」）；运镜阶段 ≠ 切镜，禁止整段单镜头慢摇。**吟诵每进入新分句（逗号/句号/分号分隔的最小单位）画面必须切镜**——分句数就是镜头数下限：「层峦耸翠，上出重霄；飞阁流丹，下临无地」= 4 分句 ≥ 4 镜（高频失败：把一联当一个单位只给 1 镜）。五言/七言每镜约 2-3s，骈文分句约 3-4s，每个镜头的时间窗必须装得下该镜头诗句的吟诵耗时（字数÷2）；句内可加切、不设上限。豁免仅两类：锚点句可一镜到底（分句合并计 1 镜，吟诵连续不加静默）；出镜开口镜头为保唇形连续可一镜到底。出镜开口段若仍切镜，切走后吟诵转画外延续（旁白形态）——说话人不在画面的镜头禁止写"嘴唇开合"。切镜处必须同时改变景别或机位角度，禁止同构图切镜（视觉上等于闪烁）。句读只定切点时机，画面内容按锚点对齐制取材——非锚点镜头不必对应当前句意。**吟诵贯穿所有镜头，无一例外**：每个镜头都必须有吟诵覆盖（开篇钩子画面与第一句吟诵并行起播），相邻诗句只留 TTS 自然换气、禁止刻意停顿，禁止任何无吟诵的纯画面镜头
- **切点写法（防切镜被生成模型合并）**：每个切点独立成行以"切至镜头N（X-Y秒）"起头；切点两侧的运镜必须各自收束在本镜头内，**禁止跨切点的桥接运镜措辞**（"缓推至下一画面""后拉进入""镜头移向"等跨镜头延续描述会被模型合并为一个长镜）；切点不写转场特效，硬切即可
- **台词花括号强制**：旁白/吟诵的诗句文本一律用 `{}` 包裹（`旁白（{音色}，{语气}）：{诗句原文}` / `吟诵：{诗句原文}`），无论写在独立行还是镜头行内——脚本机械校验按 `{}` 提取台词，缺花括号 = 台词保真与超载校验全部失效，视为格式错误必须补上
- **景别混合**：段内禁止全大景别；远/全景、中景、近景/特写混合编排，近景/特写优先给点景人物动作（执桨/抚水/执卷）与意象细节（檐铃/波纹/灯焰）
- **前景层次**：每段至少一个镜头用前景遮挡制造纵深（枝叶/纱幔/檐角/芦苇入前景，虚化）
- **点景人物**：各段画面人物从 creative_design.md 的「出场形象」字段承接，人物必须写"在做什么"（动词），禁止呆立入画。段内多镜头时「出场形象」人物只需占其对应镜头，**其余镜头按气氛补时代生活群像**（渔樵耕读、游人商旅、乐伎童叟，逐镜身份不同，时代服饰一致）——群像与当前句意松耦合，气氛不违和即可，禁止因句中无人而整镜空景。人物在画面中至少"全身可见、身影清晰可辨"档并借光线/位置成为视觉焦点之一，禁止缩成远景小点（视觉上等于空镜）；正脸只出现在出镜开口镜头。全片人景结合镜头数 ≥ 纯空镜镜头数，纯空镜连续不超过 2 镜且必须有吟诵覆盖
- **运镜速度**：按镜头内容取——锚点句镜头可缓速，事件/人物镜头用正常速度或跟随，禁止全段一律缓速
- **编排自检（报数）**：storyboard 自审时逐段报五个数——镜头数（≥ 段内吟诵分句数，锚点句/出镜开口一镜到底按 1 计，先数分句再数镜头、两个数字都要写出来）、段时长校验（报「吟诵耗时 / Duration」两个数，Duration − 吟诵耗时 ≤1s，超出即缩段或补联，禁止靠无声镜头撑时长）、人景结合镜头数（全片 ≥ 纯空镜数）、前景遮挡镜头数（每段 ≥1）、跨切点桥接运镜措辞数（必须为 0）；任一不达标先补齐再交付

## Prompt 模板（单段骨架，按范式与形态选用）

> 下列骨架含风格词、禁 BGM、无字幕等全片共用约束。**多段视频**中这些约束改走 storyboard.md `通用尾注`（只写一次，由主 Agent 拼到每段末尾），段 Prompt 内删去、只保留本段的镜头/旁白/音效；**单段视频**照骨架原样写入。分拣见 `storyboard/prompt-craft.md`「质量约束」。
>
> **花括号区分**：骨架中的 `{}` 是待填占位符，填完后删除——**唯一例外是台词文本**：`：{诗句原文}` 处的花括号在成品 Prompt 中必须保留（同 `prompt-craft.md` 台词句式，模型与脚本校验都按 `{}` 识别说话内容）。成品示例：`旁白（温润男声，吟诵语气，沉静辽阔）：{潦水尽而寒潭清}`——音色语气括号内不留花括号，只有诗句/台词包 `{}`。高频失败：填模板时把台词花括号一并删掉，台词保真与超载校验全部失效。

画外朗诵/讲解段：

```
场景参考@图片1。
镜头1（0-X秒）：{景别+构图（前景遮挡可选）}，{意象主体 + 点景人物动作，或锚点句最强意象}，{运镜}。
旁白（{音色}，{吟诵语气·按音步停连/讲述语气}，{情绪}）：{该镜头覆盖的诗句原文或讲解词；诗句必须逐字}
<{环境床或绑定动作的事件音}>。
切至镜头2（X-Y秒）：{变化后的景别/视角 + 画面内容}，{运镜}。
…（按画面轨编排规则续写，锚点句所在镜头给最大景别反差，吟诵连续）
{风格关键词，逐字复制}。
禁止生成BGM，保持无字幕。
时长：{引用 count_chars.py 耗时区间 + ≤1s 收尾}秒，比例：{比例}
```

出镜开口段（吟诵/自述/台词通用）：

```
参考@图片1的{人物名}形象，场景参考@图片2。
{神态/动作：举杯/抚须/凭栏远眺}，开口{吟诵/自述}，嘴唇随每个字清晰开合，{运镜：中近景缓推}。
{人物名}（{音色}，{吟诵语气·按音步停连/自述语气}，{声音质感描述}），{吟诵/说}：{诗句原文逐字，或自创文本}
{与意象呼应的环境音}。
{风格关键词，逐字复制}。
五官清晰，禁止生成BGM，保持无字幕。
时长：{引用 count_chars.py 耗时区间 + ≤1s 收尾}秒，比例：{比例}
```
