# 萌宠视频 Prompt 编写规范

本文件在**构造 Prompt 前**加载，与 `pet-rules.md` 并行读取。

## Prompt 骨架

```
[参考图引用 + 动物形象描述（品种+体型+毛色）]
[场景环境 + （BGM，风格一句定调）]

镜头1：[运镜：xxx] + 体型锚定词 + 主体动作 + 空间变化
镜头2：[运镜：xxx] + 体型锚定词 + 主体动作 + 空间变化
...

[台词{} / 音效<>]
[防崩尾注]
```

**运镜**：每个镜头都以 `[运镜：xxx]` 开头（推/拉/摇/移/固定/跟拍/手持/环绕/俯拍/仰拍），不可省略；全片至少 2 种运镜，相邻镜头有差异——只在第一个镜头写运镜、后面只写动作，生成时后段镜头会单调得像同机位硬拍。若某镜头只有动作没有运镜可写，说明它该并入上一镜头。运镜不是随机换花样：每个运镜在预算表里写清动机（跟拍聚焦奔跑动态/固定营造宁静收束/推近放大委屈），动机对不上情绪就换运镜。

**BGM**：写在场景环境处（贯穿全程），不要留到所有镜头描述完才补——否则会被理解成只在结尾才响起。多段/多镜头时 BGM 风格描述必须统一，允许节奏变化（"轻快，节奏偏快"），但风格词不可变（前段"轻快搞怪"后段变"舒缓丧感"是违规的）。

**音效**：每段至少 1 个 `<音效>`。安静场景也要有环境音（`<室内嗡嗡声>``<风声>`）；反转/冲突/笑点必须有音效强化（`<刹车声>``<玻璃碎裂声>``<叮>`）。缺音效的片子像默片，张力大幅下降。

## 分镜预算表（构造 Prompt 前先填）

写镜头描述之前，先输出一张预算表（单段流程写在回复中；多段流程并入 `creative_design.md`，随确认门一起给用户）：一镜一行，**先分秒数、再填动作**——秒数装不下的动作当场删，不许压进同一镜。秒数只用于本表核算，Prompt 中仍用"镜头N"、禁止时间戳。

| 镜头 | 秒数 | 运镜+动机 | 动作（≤3个） | 情绪功能 | 声音 |
|------|------|----------|-------------|---------|------|
| 1 | 5 | 鱼眼贴脸自拍——起床糊脸感 | 翻身+前爪捂耳 | 事件：闹钟响→抗拒 | <闹钟声>+{再睡五分钟} |

填表约束（任一不满足先改表再写 Prompt）：

- 各镜秒数之和 = Duration，单镜 3-8 秒
- 每镜动作 ≤3 个（一拍一动作、每 2-3 秒一个，见 `pet-rules.md` 红线）；"够+搬+踩+晃+扒+叼"式动作链必须拆镜或删减
- 运镜列必须带动机（这个运镜服务什么情绪/信息），动机只进表、不进 Prompt
- 情绪功能标「事件：作用力→反应」或「情绪停留」；全片至少 1 镜情绪停留（上一镜作用力的反应放大或余韵，如加班一天后趴桌那一拍，非无源状态），禁止镜镜塞满动作
- 声音列每镜至少 1 项（音效/台词/环境音），并在 Prompt 中落到对应镜头描述之后

## 特殊字符规范

| 内容 | 符号 | 示例 |
|------|------|------|
| 音乐 | （） | （背景中播放着快节奏的摇滚乐） |
| 音效 | <> | <远处传来狗叫声> |
| 台词 | {} | {你好，世界} |
| 字幕 | 【】 | 【第一章：启程】 |

**台词内容要求**（发声方式=说人话时）：`{}` 里必须是一句完整、有实际信息量的话，不能是纯拟声词/感叹词（如"嗷""妈呀"）——纯感叹词没有兑现"说人话，剧情表达力最强"的设计初衷，跟发声方式=叫声没有区别。写完后自检：去掉语境单独读这句台词，是否传达了具体信息或有网感记忆点。

**内心 OS 独白同样是台词**（发声方式=内心 OS 时）：画外音独白必须写成「画外音内心独白：{台词}」——**`{}` 不可省略**，它是触发语音生成的台词符号，丢了 `{}` 独白只会被当画面描述、不会发声。

## 防崩尾注（每段 Prompt 末尾必加）

**通用**：
- "画面稳定，保持无字幕"
- "画面中禁止出现人类手部"
- "不要生成水印，不要生成 logo"

**按层级追加**：
- L1/L2："保持真实猫咪/犬类形体，禁止任何人形变化"
- L3："保持拟人动物体型比例，爪部为动物爪而非人手"
- 多动物同框："视频全程不要在同一画面中复制相同动物"

## 高频问题规避

| 问题 | 规避方法 |
|------|---------|
| 角色 ID 漂移 | 人脸区域单独裁剪作为独立参考图；不使用多视图；重要素材放 Prompt 前部 |
| 生成字幕 | "保持无字幕"；竖屏改横屏可降低概率 |
| 双胞胎问题 | 每次涉及主体时明确指代；加"不要复制相同动物" |
| 风格漂移 | Prompt 中明确风格关键词——**萌宠默认写"真实/写实画风、真实猫咪/狗狗毛发质感"**，锁死真实感；仅当用户明确要卡通/L4 IP 时才写"3D 卡通动画风格"等卡通关键词 |
| 延长衔接跳变 | 后期对前段末尾删减 6 帧、后段开头删减 1 帧 |

## Seedance 多镜头技巧

- 单次生成支持内部分镜，按画面阶段描写，用事件节拍而非固定秒数划分
- 尽量用满单次时长上限，生成尽量少的片段拼接（单次内运镜更自然）
- 用"镜头1""镜头2"而非精确时间戳

## 素材引用规范

- ImageList/VideoList/AudioList 按 Prompt 中 `@图片N`/`@视频N`/`@音频N` 出现顺序排列
- Prompt 中只用 `@图片N` 引用，禁止使用原始文件名
- 每段 Prompt 必须在开头引用参考图并描述角色外观，不依赖"和上一段一样"

## 生成前自检清单（每段调用 `sandbox_generate_video` 前对照，聚焦这 9 项）

0. **事件密度（防"空"）**：逐镜头压缩成「作用力→反应」一句话——压不出来（只能说"主角很X"）的状态镜头全片 ≤2（判别式见 `pet-rules.md` 强制规则10）；本段消耗的事件能对上事件锚点里的条目，对不上就回去补事件锚点
1. **情绪引爆 + 收尾钩子（最影响吸引力）**：情绪锚点里声明的引爆点，在 Prompt 里有对应镜头兑现了吗？最后一拍是否**停在情绪峰值之后**（而非峰值前就收尾），且是可截图/可转发的钩子（物证/破绽/字幕卡/数字钩子/纯声音团聚）？停在"装无辜""钥匙插锁孔"这种峰值前一拍 = 白做铺垫。
2. **音色传参（最易漏）**：只要为该角色生成过音色锚定音频，本段 AudioList 就**必须传入该路径**，且 Prompt 里有 `@音频N` 引用——生成了音频却不传 AudioList = 白做。（单段流程不生成音色锚定，无此项）
3. **运镜**：每个镜头都有 `[运镜：xxx]`，全片 ≥2 种运镜，预算表里每个运镜都写了动机
4. **BGM + 音效**：场景处有 `（xxx BGM）`（符号是圆括号，多段风格词统一）；全片 ≥1 个 `<音效>`，反转/冲突/笑点处有强化
5. **台词**：`{}` 内是完整有信息量的人话（非拟声词），体现品种反差；体型词在主体出场/易崩镜头有锚定
6. **防崩尾注**：3 条通用（无字幕 + 禁人手 + 无水印logo）+ 层级/多动物追加项
7. **Duration**：用户指定→用其值；未指定→= `{{.max_video_duration}}`，不自行缩短
8. **分镜预算表**：构造前已输出，各镜秒数之和 = Duration、每镜动作 ≤3、至少 1 镜情绪停留，Prompt 镜头数与表一致
