# 小孩温馨生活方向

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 适合角色

小女孩、小男孩、双胞胎、小朋友和小动物互动

## 故事核心

撑伞、送花、烤棉花糖、窗边看雪、发现小生命、照顾小东西、分享食物

## 典型小事件

- 发现一只迷路的小虫子
- 早餐盘里多了一朵小花
- 窗外下雪了想出去但太冷
- 烤棉花糖分给毛绒小伙伴
- 给小动物做一张小床

## 情绪线范例

- 平淡 → 发现小东西 → 想照顾 → 小心行动 → 被回应 → 满足微笑
- 等待 → 等来了 → 开心但害羞 → 鼓起勇气 → 温暖互动 → 安心

## 角色材质句式

- 柔软圆润小脸蛋，脸颊有自然红晕
- 头发蓬松柔软，有自然弧度
- 穿着宽松柔软棉质服装，颜色低饱和
- 四肢短圆，动作笨拙但认真

## 场景句式

- 家里厨房窗边 / 花园小径 / 雪天门口 / 小小阁楼 / 阳台花架旁
- 柔和室内暖光或自然光，窗帘或树叶投下柔和阴影
- 木质+棉布+陶瓷材质，低饱和奶白/浅粉/浅蓝配色

## 落 prompt 前自检

- 角色比例是否偏萌（头大身小），不要写实成人比例？
- 互动是否安全温柔？避免任何危险或惊吓元素
- 小孩角色的表情是否自然？避免过度夸张
