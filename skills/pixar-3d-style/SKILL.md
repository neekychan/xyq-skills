# 皮克斯 3D 动画风 · 风格滤镜技能

## 这个技能是做什么的

这是一个**画风统一技能**。它的唯一目标：让某一次任务里**所有被生成的图片素材资产和视频资产**，都稳定地呈现**同一套「经典皮克斯式 3D 动画电影质感」**。

实现方式非常简单也非常刚性：在**每一条**送去生成图片或视频的 prompt 的**最开头**，原封不动地拼上一段固定的**风格锚定词**，然后再接该画面 / 该镜头的具体内容描述。

只要本技能被调用，Agent 在这次任务里生成的每一张图、每一段视频，都必须走这个拼接规则，不允许遗漏、不允许改写风格锚定词。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 一、风格锚定词（最高优先级 · 逐字复用）

下面这段是**固定风格锚定词**，是本技能的核心资产。**逐字（byte-for-byte）复用，禁止改写、翻译、精简、增删、调序：**

```
3D渲染，经典皮克斯式 3D 动画电影质感，三维渲二维质感，写实卡通化风格，圆润的造型，整体布光带有摄影棚级控制感，高级 CGI 渲染，柔和高光，通透阴影
```

### 拼接规则（强约束）

1. **位置**：风格锚定词必须放在**每一条**图片 prompt 与视频 prompt 的**最开头**，其后紧跟一个逗号或换行，再接具体画面 / 镜头描述。
2. **适用范围**：本次任务中**所有**需要生成的资产都要加，包括但不限于：
   - 分镜 / 关键帧 / 概念图等**图片素材资产**
   - 首帧图 / 尾帧图 / 参考图
   - 图生视频、文生视频等**视频资产**的 prompt
3. **完整性**：即使一次要生成多张图、多个镜头，**每一条 prompt 都要独立带上**完整风格锚定词，不允许"只在第一条加、后面省略"。
4. **不可污染**：不得把与皮克斯风格冲突的质感词（如"写实照片级""赛博朋克霓虹""油画笔触""2D 手绘线稿""胶片颗粒噪点"等）与本锚定词混用；如与画面需求冲突，以本风格锚定词为准。

### 标准拼接格式

**图片 prompt：**
```
{风格锚定词}，{画面主体}，{场景/环境}，{角色造型与表情}，{光影}，{色彩}，{镜头与构图}
```

**视频 prompt：**
```
{风格锚定词}，{镜头内容}，{角色动作与表演}，{运镜方式}，{光影氛围变化}，{时长/节奏提示}
```

### 示例（供 Agent 理解拼接方式）

- 图片：`3D渲染，经典皮克斯式 3D 动画电影质感，三维渲二维质感，写实卡通化风格，圆润的造型，整体布光带有摄影棚级控制感，高级 CGI 渲染，柔和高光，通透阴影，清晨的温馨小厨房里，一只圆滚滚的橘猫踮脚去够料理台上的牛奶，大眼睛闪着期待的光，窗外洒进金色晨光，奶油黄与木质棕主色，中近景略微仰视`
- 视频：`3D渲染，经典皮克斯式 3D 动画电影质感，三维渲二维质感，写实卡通化风格，圆润的造型，整体布光带有摄影棚级控制感，高级 CGI 渲染，柔和高光，通透阴影，橘猫成功够到牛奶后开心地抱住瓶子转圈，尾巴轻扫，镜头缓慢环绕并轻微推进，晨光下毛发边缘泛起柔和轮廓光，节奏轻快治愈`

## 二、与其他技能的协作规则（务必遵守）

### 2.1 与其他「风格类」技能搭配 —— 锚定词合并

当本技能与另一个风格类技能（如另一套画风滤镜）**同时被调用**时：

- **不是二选一，而是合并**。将各风格技能的锚定词**按调用顺序拼接合并**，组成一段更长的合并锚定词，仍然整体放在每条 prompt 的最开头。
- 合并时**各锚定词逐字保留**，用逗号连接，不改写、不删减任一方内容。
- 上面「一、」中的所有拼接规则（位置、适用范围、完整性、每条都加）**对合并后的锚定词同样生效**。
- 若两种风格存在直接冲突的质感描述，保留双方原文并置即可，由后续画面描述自行侧重，不擅自删除某一方。

### 2.2 与「非风格类」技能搭配 —— 本技能的风格约束优先且必须保留

当本技能与**非风格类**技能（如营销短片、短剧脚本、分镜生成、广告创意、故事板等业务流程技能）**同时被调用**时：

- 非风格技能负责**内容 / 结构 / 流程**（讲什么故事、几个镜头、卖点、脚本结构等）。
- 本技能负责**画风 / 质感**。**无论加载了哪个业务技能，只要本技能在场，所有最终送去生成图片和视频的 prompt，都必须遵守本技能的锚定词拼接规则。**
- 即业务技能产出的每一条画面 / 镜头 prompt，在真正提交生成前，都要在最开头补齐本技能的风格锚定词。业务技能自带的任何"默认画风 / 示例风格描述"若与本锚定词冲突，**以本技能锚定词为准并覆盖之**。
- 一句话原则：**业务技能决定"画什么"，本技能决定"长什么样"，两者结合，画风约束不可被业务技能覆盖或省略。**

### 2.3 禁止内置风格锚定图 / 参考图干扰（强制）

部分 Agent 链路会为某些风格**预置内置风格参考图 / 风格锚定图 / reference image**，这会干扰本技能的资产生成，导致画风偏离。因此：

- **一旦本技能被调用，必须绕过并禁用 Agent 侧任何内置的风格锚定图 / 风格参考图 / 默认风格底图设定。**
- 生成图片与视频时，**不得自动挂载**任何非用户显式提供的内置风格参考图；风格的唯一来源是本技能的**文本锚定词**。
- 若生成工具存在"默认风格参考""风格预设图""style reference preset"等参数，需将其**关闭 / 置空 / 显式不传**，仅依赖文本锚定词控制画风。
- 仅当**用户本人显式提供**了参考图时才可使用；系统 / 链路自带的内置风格图一律忽略。

## 三、皮克斯 3D 动画风 · 风格知识库

> 本节供 Agent 在撰写分镜、角色设定、场景描述、故事脚本、镜头语言等**具体内容**时参考取词，使内容在细节层面也贴合皮克斯质感。写 prompt 具体描述部分时，可从这里挑选恰当的词汇，与风格锚定词配合使用。

### 3.1 整体风格气质

- **理想化写实**：保留现实世界的材质、体积、光线可信度，但比现实"更美一点、更暖一点"。
- **温暖亲和**：几乎没有冷硬、尖锐、疏离感的设计，观感友好治愈。
- **童话式真实**：既非纯幻想也非严格写实，落在"可信但更梦幻"的中间地带。
- **情绪清晰、电影感强**：一眼能读出情绪（快乐 / 感动 / 冒险 / 孤独 / 希望），画面像精心布光的电影镜头而非普通动画截图。
- 关键词：圆润、温暖、明亮、柔和、高可读性、理想化写实、电影级布光、情绪驱动、童话式真实、干净细腻、富有空气感。

### 3.2 角色造型

- 头身比适度夸张（常大头小身），五官集中、表情幅度大。
- **眼睛大而有神**，虹膜清晰，**眼部高光是灵魂**，眼神有聚焦感与思考感。
- 脸部轮廓圆润，颧骨 / 下颌 / 鼻梁柔化；外轮廓干净、形体转折明确但不繁复，曲线多于硬折线。
- 肢体比例服务性格：英雄角色更流畅舒展，笨拙角色更短圆厚重，机灵 / 神经质角色保留适度棱角但不写实锐利。
- **非人角色拟人化**（动物、玩具、汽车、机器人等）：保留本体最关键结构识别，只在"眼睛—嘴—姿态"注入情感，做"最小改造下的最大情感表达"，让它"像它自己"又"像一个角色"。
- 微表情丰富：开心时眼神发亮 + 苹果肌抬起 + 面部被光照活；难过时眼睑、嘴部 tension、头部姿态共同作用。

### 3.3 光影质感（风格重中之重）

- **主光源明确**，整体布光带**摄影棚级控制感**（呼应锚定词）。
- 高光**柔和不爆闪**，阴影**通透有空气感**（呼应"柔和高光、通透阴影"）。
- 常用**边缘轮廓光 / 逆光辉光**把角色从背景中"托"出来，毛发 / 绒毛边缘泛柔光。
- 偏好金色晨光 / 傍晚暖阳；室内暖光与窗外冷光形成柔和对比。
- 常用景深、体积光、空气透视增强梦幻感。核心：光影"真实到能增强情感"，而非"真实到骗过眼睛"。

### 3.4 色彩系统

- **高饱和但不刺眼**，综合色偏暖，主色明确、辅色克制，色彩服务情绪与叙事。
- 阴影区保留丰富色相，而非简单压黑；极少出现脏灰混乱或赛博霓虹。
- 常见配色：
  - 温馨家庭：奶油黄、木质棕、柔暖橙、天青蓝
  - 冒险场景：清透蓝天、鲜艳服装、自然绿植、明亮高光
  - 成长 / 孤独主题：整体可看的基础上，加入灰蓝、灰紫、低饱和橙

### 3.5 材质表现

- **皮肤**：平滑细腻，轻微次表面散射，健康通透，不强调真人毛孔瑕疵。
- **服装**：织物属性明确但不繁复，褶皱服务动作与形体；棉布、毛呢、牛仔、编织物等温暖质感。
- **物体 / 环境**：木头温润有手工感；金属干净、反射克制；塑料圆滑明亮童趣；毛发绒毛蓬松柔软带轮廓光；水 / 玻璃 / 冰雪清澈易读。
- 总规律：真实材质逻辑存在，但瑕疵、污损、粗粝被大幅审美化，一切为"好看"与"可读性"让路。

### 3.6 场景与环境

- 场景有明确功能性与叙事性，真实逻辑存在但被适度理想化，整洁、层次分明、易读。
- 家居温暖生活化；城市有秩序带童话感、不压迫；自然色彩纯净、空气感强；奇幻场景想象力强但材质空间仍可信。
- 环境是"角色情绪的延伸"：同一空间可通过色温、拥挤度、光照、道具传达不同心理状态。

### 3.7 镜头语言与电影感

- 构图主次分明；中近景强化角色表演，广角突出冒险与空间张力，浅景深适度用于聚焦。
- "皮克斯感"不止渲染风格，还包括：像电影一样选镜头、像摄影一样布光、像戏剧一样安排站位、像绘画一样控制色块与节奏。

### 3.8 与相邻风格的区分（避免跑偏）

- 比迪士尼 2D 童话：更强三维空间与体积、更强现代电影摄影感、情绪更生活化。
- 比梦工厂：更温柔真诚细腻抒情，而非更夸张闹腾的喜剧冲击。
- 比普通 3D 卡通渲染：不是简单"大眼 + 光滑"，而是有完整角色设计逻辑、叙事布光逻辑、情绪美术系统，每个元素都服务讲故事。

## 四、故事 / 脚本风格倾向（内容层参考）

当本技能被用于生成分镜脚本、故事梗概或角色设定的**文字内容**时，可默认贴合皮克斯一贯的叙事气质：

- 以**小人物 / 小角色的真挚情感**为核心，重视成长、陪伴、亲情、勇气、自我认同等母题。
- 基调轻松温暖、诙谐可爱，苦中带甜、笑中带泪，结局给人希望与治愈。
- 善用**拟人化 IP 角色**（如猫、玩具、小动物、小物件）作为情感载体，赋予其鲜明性格与讨喜设计。
- 冲突不靠残酷血腥，而靠误会、成长、选择、和解来推进。

> 说明：以上叙事倾向为默认风格底色，若用户或业务技能对故事内容有明确指定，以用户 / 业务指定的内容为准；但**画风锚定词的复用规则始终不受内容影响，必须保留**。

## 五、执行清单（Agent 自检）

在本次任务中每次即将生成图片 / 视频前，逐项确认：

- [ ] 这条 prompt 的**最开头**是否原封不动带上了完整风格锚定词？
- [ ] 若同时调用了其他风格技能，是否已把各锚定词**合并**后整体前置？
- [ ] 若同时调用了业务（非风格）技能，业务产出的每条画面 prompt 是否都补齐了本锚定词，且未被业务默认画风覆盖？
- [ ] 是否已**绕过 / 禁用**任何内置风格锚定图 / 风格参考图，仅用文本锚定词控风格？
- [ ] 具体画面描述是否参考了本技能风格知识库，使造型 / 光影 / 材质 / 色彩 / 镜头贴合皮克斯质感？
- [ ] 多图 / 多镜头时，是否**每一条**都独立带全了锚定词，无遗漏？
