# creative_design.md 格式与质量校验

## creative_design.md 格式模板

多段创意设计阶段产出 `assets/{project}/creative_design.md`。格式如下：

```markdown
# 创意设计

## 整体风格
{全局风格关键词，包含画风/渲染/配色/光线/色温/情绪/音效设计等，所有素材和视频 prompt 统一使用。配色须落为色板锚点：主色 1 个 + 辅色 1-2 个 + 点缀色 1 个，命名具体色名（如"主色雾灰蓝，辅色暖橙，点缀色暗红"），供后续分镜通用尾注原样搬运；有参考图时色板须与参考图实际色调一致。视频比例写入「用户硬约束」，禁止写在本节。禁止写运镜/景别/机位偏好——镜头语言由分镜规划决定}

## 用户硬约束

- 总时长：{用户指定或问卷确认的总时长；未指定写"未指定"}
- 语言：{用户指定或从用户原文可确定的台词/旁白语言；未指定写"未指定"}
- 字幕：{用户明确要求时写"需要"；明确不需要时写"不需要"；未指定写"未指定"}
- BGM：{用户明确要求的 BGM 风格或"不需要 BGM"；未指定写"未指定"}
- 视频比例：{用户指定或问卷确认的视频比例；未指定写"未指定"}
- 素材使用：{用户对上传素材用途的明确要求；未指定写"未指定"}

## 用户额外要求
{简要逐条记录用户明确提出、且未被上述固定字段覆盖的要求，包括全片原则与绑定具体场次的动作、台词、时间线、镜头指令、画面或声音禁忌、输出形式等。只记录用户明示内容，禁止加入 Agent 推断；未指定写"无"。绑定具体场次的要求必须同时完整写入对应场，本节只作保真摘要，禁止代替剧本设计。}

## 故事线
{自然语言描述完整故事创意，包含起承转合、核心冲突、情绪走向与结局}

## 剧本要素

### 角色

#### {角色名}

- 描述：{默认外观、性格、武器/能力的完整描述}
- 音色：{该角色跨场次、跨形象共用的默认音色描述，性别与年龄段必须与“描述”行的角色形象一致；无台词写“无”}
- 音色例外：{仅用户或剧情明确要求某形象声音发生变化时，写“形象名 → 例外音色及出现场次”；否则写“无”}

用户的全局配音指定默认只约束旁白音色与全片腔调风格（语速、腔调、年代感）。写入各角色音色行时保留这些风格属性，性别与年龄段服从该角色描述；冲突时写同风格的对应性别/年龄变体。仅用户对该角色明示反串时才允许音色与形象不一致，并在该角色音色行注明。

**同角色多形象（仅剧情确有显著外观变化时填写，普通角色不写）**：

- 身份锚点：{所有形象必须保留、能证明是同一角色的稳定特征，如骨相、五官比例、瞳色、不可替换标记}

| 形象名 | 类型 | 完整外观 | 相对基础形象的保留项 | 相对基础形象的显著变化项 | 出现场次 |
|--------|------|----------|--------------------------|----------------------------|----------|
| {基础形象名} | 基础 | {由头到脚完整外观} | {身份锚点} | 无 | {场次范围} |
| {变化形象名} | 变化 | {由头到脚完整外观} | {身份锚点及其他保留项} | {服装整体、年龄阶段、形态/物种状态、妆造等显著结构变化} | {场次范围} |

每个多形象角色必须有且只有一个基础形象。表情、姿势、光线、脏污、轻微伤痕、小配饰或局部颜色变化属于镜头状态，不得拆成独立形象；未标形象的场次默认使用基础形象。同一角色所有形象默认共用角色级音色；只有 `音色例外` 已明确记录时，才允许对应形象使用例外音色，禁止 Agent 仅因形象变化自行换声。

#### {角色名2}
...

### 物品

**IMPORTANT - 物品准入（双条件 AND）**：一件道具只有**同时**满足以下两条才在本章单列并在素材阶段生成独立 prop 图——①**脱离角色独立出镜**：有不依附持有者的单独镜头/特写/空镜（信物被单独推特写、法宝悬浮展示、道具易主的交接特写）；②**跨多个分镜复现且需锁定外观**：在 ≥2 个分镜出现且款式/纹样/材质不能漂移。不满足即并入：角色全程随身、不脱手、无独立出镜的武器/配饰（剑、斧、刀、随身佩饰），一律写进该角色的实体描述与四视图 Prompt（"右手持一柄 X，{材质/形态}"），**禁止在本章单列、禁止生成 prop 图、禁止进 shot 的 ImageList**；随身武器的帧间一致性由 Prompt 文字约束维持（见 `vfx-action.md` 道具一致性约束）。角色随身武器必须在其四视图 Prompt 中显式描述，并在参考图质量自检中确认武器可见。外观简单、无视觉锁定诉求的叙事承载物（轿子、书信、令牌、车辆等），即便沾边双条件也归入场景或角色描述作环境/剧情元素提及，不单列、不生成 prop 图。本章无任何满足准入的道具时，正文只写 `（无）`，禁止写为何没有的解释。

#### {物品名}

- 描述：{外观、材质、使用方式、视觉效果的完整描述}

#### {物品名2}
...

### 场景

**IMPORTANT - 场景准入**：一个场景实体 = 一个**独立物理空间**。同一空间内的不同动作、时段、光线（写作业 vs 自述、白天 vs 夜晚）是同一场景，合并为一条，差异写进该场景描述或对应场的动作描述，禁止拆成多个场景。用户括号里的分镜/运镜/叙事标记（`开头`/`切画面`/`镜头X`/`转折`/`高潮` 等）是分镜提示不是场景——只从中提取空间信息命名场景，标记本身丢弃；不含空间信息的标记（"转折""结尾"）不产生场景实体。自检：每个场景名必须能回答"这是哪个物理空间"，答不出即删除或并入。多个场次共用同一物理空间时只写一条场景实体。场景表须等于 `剧本设计` 各场「场标」地点**去重后的集合**——场标出现的每个空间都要有对应场景实体，场景表也不得出现场标里没有的空间。

#### {场景名}

- 描述：{环境、光线、氛围、空间结构、配色的完整描述}

#### {场景名2}

## 剧本设计

`剧本设计` 用标准分场剧本格式书写。**第一行必须写总时长预算**，再写分场，每场由「场标 + 动作描述 + 角色台词」三类元素构成：

```markdown
**总时长预算**：{N} 秒（用户/问卷表述为"N秒左右"时原样写"{N} 秒左右"，禁止去掉"左右"）

### 第 {N} 场 · {场名}

**场标**：{内景/外景} · {地点} · {白天/黑夜/黄昏/清晨}

**出场形象**：{角色名}·{形象名}；普通单形象角色只写角色名

**用户原文时间线**：{用户明确给出的时间段，如 0-2s/2-4s；无则不写本行}

{动作描述：用正常段落、现在时视觉化叙述本场的人物行为、场景状态、情绪推进。只写观众看得见的画面。禁止写 Agent 自产的镜头/景别/运镜/逐秒区间；用户原文明确给出的镜头、景别、运镜和时间线必须保留。}

> {角色名}：{对白逐字原文，原话、原顺序、原语言}

{动作描述续……台词与动作按用户原文的发生顺序交替排列}

- 参考视频素材：{路径或"无"}
- 预估时长：{N} 秒

### 第 {N+1} 场 · {场名2}
...
```

场标术语统一用直白中文：内外景写「内景」「外景」，时间写「白天」「黑夜」「黄昏」「清晨」。**动作描述用正常段落散文书写；台词另起一行，用 `> {角色名}：{对白}` 引用块**——「不混写」只指排版上把台词与动作分行，不指打乱二者的发生顺序。

**素材路径规则**：所有参考素材路径必须使用以 workspace 为根的相对路径（如 `assets/{project}/character_xxx.png`、`upload/xxx.png`），禁止使用裸文件名。

**剧本要素与素材分离**：`剧本要素` 只写角色、物品、场景的实体定义，禁止写素材路径。所有图片、音频、视频路径必须集中写入 `素材绑定关系` 表。

**剧本设计是创意设计的核心**——用标准分场剧本写：每场写清场标、谁参与、做了什么（动作描述）、说了什么（台词逐字）、情绪或关系如何推进。禁止用关键词串联（如"仪式→希望→绝望"）代替剧情。

**IMPORTANT - 用户输入保真校验**：`creative_design.md` 必须以用户原始输入为边界。硬约束字段（总时长、语言、字幕、BGM、视频比例、素材使用）必须完整落入 `用户硬约束`；未被固定字段覆盖的用户明示内容必须简要落入 `用户额外要求`；用户明确给出的场景、角色、时间线、片段顺序、动作、台词、声音/BGM、氛围、结尾方式必须完整落入 `剧本设计` 或 `整体风格`。用户原文明确指定的镜头/景别/运镜/机位也必须保留在对应场的动作描述中，作为后续分镜规划的输入。台词/对白/旁白逐字保留；动作描写在后续 Prompt 中可转译为可执行视觉描述，但必须保留主体、动作链、顺序和结果。禁止遗漏用户明确要求；禁止新增与用户输入冲突的信息。用户输入不完备时，只补齐未指定缺口，补齐内容不得覆盖、替换、重排或削弱用户已明确的信息。除营销/商品场景中用户明确给出的产品卖点外，不要求在本节额外提炼“目标、卖点”等意图层描述。

**IMPORTANT - 分场边界**：分场剧本不是分镜表、不是镜头表、不是 Agent 自产逐秒时间轴、不是视频生成调用列表。只有叙事功能改变、时间/地点跨度明显变化、冲突层级升级、情绪落点改变时才新开一场。同一地点、同一组角色、同一连续行动目标下的多个动作和台词必须合并进同一场。禁止按单句台词、单个动作、单次切镜拆场；禁止把 Agent 自产的 5-15 秒短镜头粒度写进 creative_design.md。用户原文已给出的时间线只作为该场内的顺序与节奏约束保留，不构成强制拆场理由。纯转场/纯产品空镜（无台词且叙事功能无改变）禁止单列为场，必须并入相邻场作为其画面内容。

**IMPORTANT - 细节下沉**：动作描述只写画面方向、核心意象和情绪落点。禁止任何 Agent 自产的、以"镜头/画面"为主语的摄像机视角叙述，禁止 Agent 自产的景别、机位角度、运镜方式、切镜与剪辑转场（含"画面切至""定格""渐暗"等语义变体）、逐秒区间——判据：句子在描述"用什么镜头怎么拍"而非"观众看到什么"即违规，改写为观众看到的画面与情绪效果。删除测试：删去某句动作/情绪描写后，本场"谁做了什么"与情绪走向仍完整 → 该句属分镜层细节，必须删。**唯一豁免**：用户原文明确指定的时间线或镜头指令（运镜/景别/机位）属用户要求，逐字保留在对应场的动作描述中——本禁令只针对 Agent 自产的时间轴和镜头语言。具体分镜划分、运镜、景别、镜头内动作顺序由后续分镜规划完成。

**IMPORTANT - 台词逐字保真**：每一句 `> {角色名}：{对白}` 中的对白必须是用户原文台词的逐字原话——原话、原顺序、原语言（角色名、专有名词原文如此的除外），禁止转述成动作描述、禁止省略、禁止合并多句、禁止改写语言。用户原文有几句台词，分场剧本里就有几行对白。引用块内只放角色实际说出口的话——动作、招式、神态一律写进动作描述，禁止用 `> {角色名}：（动作）` 充当对白行。连续两行 `>` 对白属于同一角色 → 大概率漏了中间他人的对白或动作节拍，回原文核对补齐。

**IMPORTANT - 台词-动作顺序保真（落笔即有序）**：有台词的场，落笔分两步——①先按原文顺序把本场全部 `> {角色名}：{对白}` 行排成骨架；②再在台词行之间填动作描述。台词行是钉子，动作是行间填充，写完即天然有序：每句台词落在紧接说话前的动作之后、说话后的动作之前，说话人「边说边做/说完就做」的动作跟台词绑在一起。台词若是后续一整串连锁动作的触发原因（如一句呼喊/惊呼引出接下来数个动作），台词必须写在该串动作**之前**。禁止先写覆盖全场的动作总述、再把台词堆在场末；动作描述里转述了某句话的内容（喊话/回应/拒绝/呼唤）而对应 `>` 对白行排在别处 = 倒叙，必须删去转述、把对白行放回该位置。自检：只读所有 `>` 对白行，顺序须与原文台词顺序完全一致。

**IMPORTANT - 预算先行**：`总时长预算` 在分场前确定，取值只有三个来源：用户指定时长 / 问卷确认结果 / 技能 §0.2 内容量估时结果。**预算是分场规模的上限闸门，不是成片总时长**——最终总时长由分镜规划阶段按内容量精算，可以低于预算，禁止凑满。所有分场的 `预估时长` 加总必须 ≤ 预算；超出时砍场次或压缩场内容，**禁止反向扩预算**。Agent 自产的旁白/台词只能在预算内填充，不得作为扩预算依据；发现用户原文台词耗时下限累加已超预算时，禁止静默重设——预算由用户决定（指定时长/问卷选择）的，按技能 §0.2 台词超载拦截出问卷让用户处理；预算为估算结果的，按耗时下限重设。

**IMPORTANT - 叙事密度校验**：写完通读每一场——相邻两场实质相同（如都是"主角在赶路"）必须合并；某场读完观众得不到任何新信息，信息密度为零，必须删除或合并。`预估时长` 表示该场自然承载时长，只做后续分镜规划参考，不为单次视频生成时长上限切碎分场。

**IMPORTANT - 故事完整性校验**：剧本设计必须覆盖故事线中的完整弧线（起承转合）。最后一场必须落在钩子上（悬念/反转/情绪爆发）。

**IMPORTANT - 多形象校验**：仅多段剧情允许把同一角色拆为多个形象。每个多形象角色必须有且只有一个基础形象；每个变化形象必须达到显著外观变化判定并至少绑定一个实际场次；每场 `出场形象` 必须与角色形象表、素材绑定关系一致；所有形象默认共用角色级音色，只有已记录的明确音色例外可偏离。任一条件不满足时，合并回基础形象或补齐绑定后再进入素材生成。

**IMPORTANT - 字幕落点**：用户明确要求普通字幕时，只在 `用户硬约束` 中记录字幕需求，禁止写入剧本动作、台词或 `【字幕：...】` 屏幕文字；后续由 `render_video.show_subtitle` 统一添加。只有画面叙事本身需要的文字可写入剧本设计，例如弹幕、手机屏幕文字、招牌、术法文字、漫画拟声词、UI 文案、标题卡等；这类文字必须服务画面内容，不得用来复刻旁白/台词全文。
