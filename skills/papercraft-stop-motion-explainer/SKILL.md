# 纸艺定格科普视频生成器

把科学、教育或知识主题做成完整的纸艺定格动画科普创作包：画风规则、角色与场景设计、讲解脚本、字幕、提示词、分镜、片段切分方案、纸艺音效和审核标准。

适用于触感强、手作感强的科普视觉：分层纸片、卡纸剪裁、微缩纸雕布景、纸偶定格动作、立体书式展开、纸质道具、真实层间投影。默认假设用户要一个完整的、能直接拿去制作的视频包。

## 三条默认交付形态

除非用户明确要求改变，按以下形态交付，不必逐次询问：

1. **成片带讲解。** 纸艺擅长呈现结构，抽象因果必须靠人声说清。字幕要不要则在确认点 1 问用户，默认推荐不要。
2. **不加背景音乐。** 纸艺定格的说服力来自材质的真实声音——纸的摩擦、卡纸的滑动、纸片落定的轻响，这些是"真的用手做出来的"的直接证据。任何持续音乐床都会盖掉它们，画面立刻从"手工拍摄"退回"加了纸质滤镜的动画"。科普片的信息密度也不需要音乐额外推动情绪。
3. **视频片段按画面落点切分，不等分。** 详见 STEP 5。

## 轻量请求旁路

用户明确只要某一个产物时，不要跑完整流程，直接走对应捷径，但画风规则照常保持：

- 只要单图提示词：STEP 1 → STEP 2 → 读 `visual-design.md` + `prompt-library.md` → 输出提示词与反向提示词
- 只要系列图提示词：同上，按系列图骨架输出
- 只要视频片段提示词：STEP 1 → STEP 2 → 读 `prompt-library.md`（多段时加 `segment-continuity.md`）→ 输出
- 只要分镜：STEP 1 → STEP 2 → STEP 4 → STEP 5
- 只要创意方向：STEP 1 → STEP 2

只有用户要完整创作包、完整制作方案，或没有明确缩小范围时，才走下面的完整流程。

## 阶段确认

完整流程有三个确认点，都用确认表单，不要用纯文本让用户回复数字：

1. **STEP 2 后**：选创意方向 + 选目标时长 + 是否需要字幕（三项一张表单问掉。时长直接决定分镜和片段切分；字幕决定布景是否要预留底部安全区，这一步不定后面无法补救）
2. **STEP 3 后**：确认预览图代表的视觉方向
3. **STEP 5 后**：确认分镜与片段切分方案

表单要短，给具体选项而不是开放式追问；当前结果足够稳时把推荐项放第一位。字幕默认推荐"不要"。每个表单都提供"到此停止，导出当前创作包"这一项。

除这三处之外不要额外插入确认——每步一确认会把用户拖在表单里，反而看不到完整方案。中间步骤有需要用户定的细节时，合并到最近的下一个确认点。

## STEP 1：理解需求

分析主题和制作目标。保留用户原始领域词，不要把科学主题改写成另一个主题。

输出简洁的需求理解：科普主题或知识点 / 目标观众 / 目标时长 / 平台与画幅 / 交付类型 / **核心学习目标（观众最后应记住的一句话）** / **视觉隐喻（这个概念如何变成纸质物体、模型、纸偶、层级、路径或机关）**。

后两项是整片的地基，值得多花一点心思——学习目标决定讲解脚本的落点，视觉隐喻决定所有画面设计是否成立。

信息缺失时直接选合理默认：泛知识观众、30 秒、横屏 16:9、一个纸艺讲解员加一个核心纸艺模型。不要为这些默认单独问一轮。

## STEP 2：画风基因与创意方向

先输出必须贯穿全片的画风规则（清单见 `visual-design.md` 第一节），并点明本片的媒介逻辑：这个概念如何借纸的物质性变成可以拿在手里的模型，以及靠哪几层结构承载讲解。场景要像真实搭建并逐帧拍摄，不是有纸质纹理的普通插画。

然后给 3 到 5 个创意方向，每个从不同视觉隐喻或叙事结构解释同一主题。每个方向包含：标题 / 核心想法 / 讲解角度 / 纸艺视觉隐喻 / 最适合的时长与观众 / 标志性画面瞬间 / 风险或限制。

可参考的方向类型：立体书旅程（每翻一页揭示一层）、纸艺科学家实验室（纸偶主持人演示机制）、分层剖面模型（核心对象像剖面图打开）、微缩自然剧场（生态、地理、天文在纸雕景观中展开）、纸片机关板（齿轮、箭头、滑轨解释因果）。

**确认点 1**：用表单让用户一次选定创意方向、目标时长（15 秒快版 / 30 秒标准版 / 60 秒完整版 / 自定义）、是否需要字幕。时长和字幕未定前不要往下做资产设计——时长决定分镜规模与片段切分，字幕决定布景要不要预留底部安全区。

## STEP 3：设计视觉资产并出预览图

读 `references/visual-design.md`，按已选方向设计：纸艺角色（只在角色能帮助讲解时才做）、纸片场景、分层布景表（4 到 7 层）、道具资产库。

然后规划 1 到 3 张视觉预览图。用户需要实际图片时生成，否则输出预览图说明与提示词。预览图用于确认风格方向，不是最终生产帧。比例跟随项目视频比例。

推荐预览组合：整体世界预览（完整布景 + 主角色 + 核心对象）；机制预览（科学模型 + 纸箭头 + 标签 + 可动讲解道具）；情绪或结尾预览（文化连接或最终记忆画面）。

用户选了要字幕时：**字幕会占据画面底部 10% 到 15%**，中景的核心讲解对象和纸艺标签牌不要压在这个区域。这一步没预留，等到渲染字幕时就来不及了。不要字幕时这条放宽，但核心对象仍不宜压在画面最底部。

**确认点 2**：用表单确认视觉方向（继续 / 修改某张预览 / 收敛为单一方向 / 换创意方向）。确认前不要写最终提示词。

## STEP 4：写讲解脚本与分镜

读 `references/narration-subtitle.md`。

**讲解只讲概念，不描述画面。** 这是本类视频最容易失败的地方：讲解的职责是解释观众看不见的东西——因果、机制、原理、意义。画面已经呈现的内容不用嘴再说一遍，"第一页展示了公交站台""接下来翻到第二页"这类播报句一律禁止，视觉隐喻的机械结构（页、格、滑轨、拉片）也不进入讲解词。

判定标准：**把这句话从画面里拿出来单独听，它还带信息吗？** 不带就重写。

**先写讲解，再切分镜。** 讲解是科普片的主干，画面服务讲解——先定这句话要传达什么概念，再设计什么纸艺动作能让它可见。顺序反了就会写出播报稿。

按目标时长换算字数（约 4 字/秒，是硬约束）：15 秒 50-60 字、30 秒 100-120 字、60 秒 210-240 字。结构「钩子 → 机制 → 落点 → 记忆句」。超字数砍内容，不要压语速。

**多段片子还要按段分配字数**：每段起草配额 = 段长 × 4 字，最终以**各段字/秒差值不超过 0.5** 为准。工具会自动调语速填满该段时长，字少了拖慢、字多了赶快，所以 40 字配 14 秒、75 字配 16 秒的成片就是前段慢吞吞、后段赶着说。算法与调整优先级见 `narration-subtitle.md` 第二节。

然后按讲解节奏切分镜。分镜表保持简短，只列该时长真正需要的镜头：15 秒约 4 个、30 秒 5-6 个、60 秒 7-9 个，每镜只解释一个知识节拍。

必备列：时间 / 知识节拍 / 讲解句 / 画面动作 / 纸艺运动 / 运镜与转场 / 纸艺音效

逐句核对：这句讲解的**概念**，画面上有没有对应的纸艺动作把它变可见？缺了就补设计一个动作，而不是把讲解改成描述那个画面。

## STEP 5：切分视频片段

**目标时长在单次生成上限之内时跳过本步，直接进 STEP 6。** 需要 2 段以上时，读 `references/segment-continuity.md`。

多段片子成败的关键，核心三条：

- **不要按上限等分切。** 各段都恰好等于生成上限，说明切分是按工具能力切的而不是按画面切的，接缝落在随机时刻必然跳。先在分镜里找**天然接缝点**——画面静止且完整的那一拍（纸片刚落定、机关刚到位、镜头刚停稳、刚被翻页或云片遮满、一句讲解刚说完），再倒推每段秒数。允许不等分（14+16、13+17），只要不超上限、不短于 8 秒。
- **最好的接缝是被遮挡的接缝。** 分镜里有翻页、纸门开合、云片横移时，把接缝放在遮挡最满的那一帧，残留的不连续肉眼无法察觉。
- **下一段从上一段的尾段视频继续。** 截取上一段末尾 3 到 5 秒作为延长任务的视频输入，不要只抽一帧——单帧丢掉了镜头正在怎么动、以什么速度动，模型只能重新起步，接缝处会出现"运动突然停住又重新加速"的断裂。

输出**片段预算表**（格式与填表约束见 `segment-continuity.md` 第五节）：片段 / 时长 / 覆盖镜头 / 起始状态 / 结束状态 / 接缝类型 / 讲解落点 / 讲解字数与字每秒 / 接续方式。相邻行的"结束状态"与"起始状态"必须逐字一致。

填完表核算各段的字/秒，**差值超过 0.5 就调整**——优先把某句讲解挪到相邻段，其次微调句长，最后才改接缝位置。各段语速不一致会让成片出现前慢后快的突变。

**确认点 3**：用表单确认分镜与片段切分（继续写提示词 / 修改分镜 / 改时长 / 回到预览图）。

## STEP 6：写提示词并生成片段（含讲解）

读 `references/prompt-library.md`。共用画风锚点、光源方向、色调、景深强度这四组措辞**跨片段逐字复用**——措辞漂移是画风漂移的直接原因，在接缝处表现为材质和光影跳变。

每个片段的提示词写成一条**连续动作链**，按「先…接着…最后…」三个递进节拍描述，靠同一条运镜贯穿，不在片段内部做硬切。片段结尾的动作必须落定（纸片停稳、机关到位、镜头减速），并且能逐字对应预算表里的"结束状态"。

**讲解在调用生视频工具时一并要求，不做后期配音。** 每段提示词里逐字写出该段讲解句原文、音色语气与语速要求，让工具连同画面一起输出人声。只写"讲解本段内容"这类概括会让工具自己编词，编出来的通常就是播报画面。写法见 `prompt-library.md`。

**讲解句必须整句落在同一个片段内，绝不能被接缝切断。** STEP 4 排讲解、STEP 5 切片段时就要对齐——某句话跨在接缝上，就把接缝挪到这句话说完之后。

多段片子按顺序生成，每生成完一段用 `sandbox_bash` 执行 ffmpeg 截取其**末尾 3 到 5 秒的视频**，作为下一段延长任务的视频输入：

```bash
mkdir -p assets/papercraft/seam
ffmpeg -n -sseof -5 -i '上一成片路径' -map 0:v:0 -map 0:a? -c:v libx264 -preset medium -crf 18 -c:a aac -b:a 192k -movflags +faststart 'assets/papercraft/seam/tail_唯一后缀.mp4'
```

`-sseof -5` 从末尾往前 5 秒精确定位。上一段不超过 5 秒时直接用整段。输出路径用唯一后缀，不要覆盖上一成片。

延长任务首句使用工具要求的延长语法字面量，随后锁定末帧的纸片位置、机关状态、镜头位置与运动方向、光源方向，再写本段新的动作链。**必须写明"从末尾可见状态继续，不重复已有动作"**——少了这句，模型经常把上一段结尾的动作再演一遍，成片出现明显的重复卡顿。

工具不支持延长任务时才降级为尾帧参考图，此时接缝必须选在镜头基本静止的落点上，并在提示词里补写镜头的运动状态与方向。详见 `segment-continuity.md` 第三节。

所有片段的提示词都要求**无字幕、无文字、无水印、无 logo、无背景音乐**，并附上反向提示词。字幕不能让视频模型画，它输出的文字几乎必然错字、变形、跨帧抖动；字幕统一在 STEP 7 由渲染合成工具生成。

## STEP 7：拼接与字幕合成

讲解已随片段生成，这一步只做两件事：接起片段，渲染输出成片。

**1. 核对接缝。** 用 `sandbox_bash` 导出接缝前后各若干帧逐帧比对（接缝绝对位置由各段时长累加得出）：

```bash
ffmpeg -n -ss 14.3 -i out/full.mp4 -t 0.5 -q:v 2 assets/papercraft/seam/check_01_%03d.png
```

看纸片位置、镜头运动方向与速度、层间投影方向、纸张色温与纹理密度、景深强度是否连续。还要听两侧语速是否一致——前慢后快说明各段字数与段长不成比例，回 STEP 4 重新分配字数后重生成。任何一项不连续就重新生成那一段，接缝连续性由生成阶段决定，后期补不回来。

**2. 拼接片段。** 各段编码参数一致时用 concat demuxer 无损拼接，不引入二次压缩：

```bash
printf "file '%s'\n" "$PWD/out/seg_01.mp4" "$PWD/out/seg_02.mp4" > assets/papercraft/concat_list.txt
ffmpeg -n -f concat -safe 0 -i assets/papercraft/concat_list.txt -c copy -movflags +faststart out/full.mp4
```

`-c copy` 报错说明各段编码参数不一致，改用 filter 重编码：

```bash
ffmpeg -n -i out/seg_01.mp4 -i out/seg_02.mp4 \
  -filter_complex '[0:v:0][1:v:0]concat=n=2:v=1:a=0[v]' -map '[v]' \
  -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p -movflags +faststart out/full.mp4
```

各段必须同分辨率同比例，不一致时回 STEP 6 以同一比例重新生成，不要靠缩放拼合。

**3. 渲染输出成片。** 调用 `render_video` 渲染最终成片。按确认点 1 用户对字幕的选择传 `show_subtitle`：要字幕传 `true`，不要字幕传 `false`。静默设置，不向用户复述参数。

要字幕时一并提交字幕要素（规格细则见 `narration-subtitle.md` 第四节）：字幕文本按讲解句逐句拆分、每句起止时间、底部安全区、白字深描边样式。

时间轴以**成片人声实际出现时间**为准，不是分镜表的理论秒数——实际语速与按 4 字/秒的预估必有偏差。切换点避开视频接缝。

**接缝的掩护靠视觉，不靠声音。** 讲解随片段生成，接缝处人声也会断一次，一句话被切断就成了双重断点。接缝必须落在**动作落定或纸艺遮挡帧**上，遮挡型优先；每句讲解整句留在同一片段内，接缝落在两句之间的呼吸间隙。

接缝仍可见时重生成那一段，不要靠后期硬调。反复需要兜底说明切分点选错了，回 STEP 5 重挑接缝点。

## STEP 8：审核清单

只标出对用户目标真正重要的问题，不要逐条复述全部通过项。

**讲解内容**（首要检查项）：有没有在播报画面？出现"第一页""翻开""可以看到""展示了"这类词就要重写。每句话离开画面单独听，是否仍带信息？讲的是概念与因果，还是眼睛已经看到的东西？视觉隐喻的机械结构（页、格、滑轨、拉片）有没有混进讲解词？记忆句清楚、短、可复述？

**画风**：能看到纸张纤维、折痕、缝隙和剪裁边缘？能看到卡纸厚度？层间有真实投影？像微缩摄影而不是平面插画？避开了塑料 CG 和真人写实？

**角色与场景**：角色像纸偶、五官剪纸化、关节像分件组装、动作有定格物理感？有清楚的前景中景背景远景？道具都是纸艺材质并服务讲解？标签箭头没挡住核心模型？每镜只解释一个知识节拍？

**讲解与字幕**：字数匹配时长（约 4 字/秒），没有靠加快语速塞内容？多段片子各段字/秒差值在 0.5 内？每句讲解的概念都有对应的可见纸艺动作？讲解已在生视频提示词里逐字写出、语速写成了具体数值而非"从容"这类形容词？每句整句落在同一片段内、没被接缝切断？字幕开关已问过用户、`show_subtitle` 按其选择传值？要字幕时：单行不超过 15 字（竖屏 12 字）、在底部安全区内、没压住核心讲解对象、时间轴按成片人声实际出现时间对齐？

**片段拼接**（多段片子）：片段切分按画面落点而非按上限等分？各段时长是否恰好都等于生成上限（是则切分失败，回 STEP 5）？接续用的是上一段尾段视频而不是单帧？每个接缝都落在动作落定或遮挡帧上？至少一个接缝用了遮挡？两侧的纸片位置、镜头方向速度、投影方向、色温纹理、景深都连续？各段分辨率与比例一致、没有靠缩放拼合？后续段提示词都写了"不重复已有动作"？

**声音**：全片无背景音乐？讲解人声清晰、语气匹配观众、语速没有被赶？各段音色一致、接缝处听不出换人？**各段语速一致、没有前慢后快**？纸艺音效对应画面上真实在动的物件、且明显低于人声？音效不是夸张卡通音效？

**运镜与转场**：运镜符合微缩摄影逻辑？转场符合纸片物理逻辑？接缝两侧镜头运动方向一致或先停稳再转向？

**运镜与转场**：运镜符合微缩摄影逻辑？转场符合纸片物理逻辑？接缝两侧镜头运动方向一致或先停稳再转向？
