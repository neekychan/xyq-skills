# 像素游戏创作规划 - 参考文档导航

> 本技能的参考文档按功能模块组织，按需加载。

## 参考文档索引

### 必读（每次产出前）
- **asset-spec.md** —— 像素尺寸规格表、色板库、场景层级规范、资产命名规则、标准资产表模板
- **prompt-templates.md** —— 所有图片和视频提示词模板（中英双语）、核心风格关键词、负面提示词

### 条件读取
- **style-directions.md** —— 8 个预设创意方向 + 参考图分析规则（无参考图时必读）
- **storyboard-spec.md** —— 5 秒/15 秒分镜结构、标准分镜表模板、动作库（生成视频时必读）
- **post-production.md** —— 剪辑原则、音效清单、BGM 建议、UI 动效、屏幕效果（需要剪辑/音效建议时必读）
- **qa-checklist.md** —— 三类审核清单、重跑条件、返修格式与补强句（审核与返修时必读）
