# 一致性锁定规则

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## key_element 一致性锁定

key_element 的描述字段是**唯一权威来源**。shot 描述中如需提及角色或场景，仅引用 element ID，不重写任何已在 key_element 中定义过的属性（发色、服装、光源等），防止描述冲突导致生成结果偏离。

### 角色描述锁定

- 角色描述一经锁定，全流程禁止修改——所有 shots 只引用同一套描述。
- 若存在换装变体，每套服装作为独立命名的外观变体（Look）写入描述。
- 在单独 shot 中不得重新描述或局部覆盖角色外观。

### 场景描述锁定

- 场景描述同样锁定。
- 同一场景在不同 shots 中复用时，空间布局、光源色温、道具陈列描述须完全一致，不得随 shot 局部修改。
- 道具须与角色美术风格一致，避免写实感道具出现在手绘风场景中。

### 道具组锁定

若全局道具（如串灯、盆栽）跨多个场景复用，建立独立 key_element，shot 描述中通过 element ID 引用，避免每次重新描述导致外观漂移。

## 参考图绑定与防漂移

### 角色元素图

- 每个角色生成一张横版双联参考图：左侧胸部以上头肩特写，右侧全身正面。
- 换装变体以主角原始参考图为基础，按 Look 描述替换服装，保持五官与发型不变。
- 参考图经用户审核通过后，绑定稳定的标识，全流程不得替换。

### 场景元素图

- 生成无人物的场景全景图。
- 画面中需留出人物自然站立/坐立的位置区域（不得被道具完全填满）。

### 视频生成参考规则

- 主角 key_element 图（必选）：始终使用已审核通过并绑定的元素图。
- 若当前 shot 涉及换装，使用对应 Look 的元素图。
- 严禁临时替换或使用未绑定的图像。
- 场景 key_element 图（必选）：同一场景在不同 shots 中必须引用完全相同的标识，不得使用"相似但不同"的场景图。
- 前一个 shot 的视频（可选）：仅当该 shot 与上一 shot 为同一场景且动作连续时才加入参考；跨场景切换时不引用前一视频。
- 连续剧模式中，跨集不引用前集视频，只复用 key_element 图。角色标识全剧共用，不得按集重新绑定。

## 批量生成一致性保障

在批量生成 shots 之前，确认所有 key_element 图均已通过用户审核并绑定稳定的标识。如有 shot 生成结果出现明显角色/场景偏差，优先检查引用的标识是否正确，而非重新生成元素图。

## 落 prompt 前自检

- [ ] key_element 描述是否在 shot prompt 中仅以 ID 引用（无外观重写）？
- [ ] 同一场景跨 shot 时是否引用了完全相同的场景元素图？
- [ ] 换装 shot 是否使用了对应 Look 的元素图？
- [ ] 跨场景切换时是否避免了引用前一 shot 的视频？
- [ ] 连续剧模式下角色标识是否全剧统一？
