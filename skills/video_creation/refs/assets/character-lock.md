# 角色锁定协议

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 只在第一个镜头传角色参考图 | 后续镜头角色完全变人，面部崩坏 | 每个镜头的 ImageList 都传入该镜头所有出场角色的参考图 |
| 使用多张独立图片（面部特写与全身视图分开生成） | 多张图之间外观不一致（发色/五官/服装漂移） | 一张四视图设定稿（正面脸部特写 + 正/侧/背全身），一次生成确保一致性 |
| 在 Prompt 中复写参考图上可见的外观（发色/五官/服装括号描述） | 与参考图信息重复，占用模型信息密度预算，文图冲突时降低还原度 | 已传参考图的角色只写 `参考@图片N的形象作为{角色名}`；仅图上不可见或本段需改变的特征写入 Prompt |
| 同一角色换形象后沿用错误参考图，或把多个形象都塞进每一段 | 形象串台、服装随机混合、模型误认成多人 | 每段只传当前形象图；仅形象切换发生在段内时同时传切换前后两张图并明确阶段 |
| 新增角色不参考统一风格基准 | 新角色画风与已有素材割裂 | 按降级链取风格基准：style_anchor > 主角四视图 > 已有角色图（见"新增角色风格对齐流程"） |
| 群像/类型角色也套四视图 | 浪费参考图,群体角色像复制人,视频中氛围角色过度锁死 | 群像/类型角色生成 `character_xxx_group.png`,只锁定年龄层、服饰、发型和群体气质 |

## 强制规则

1. **个体角色四视图**：主角、重要配角、需跨镜头识别为同一个人的角色必须用一张四视图设定稿（规范见 `assets/ref-image-design.md` §一）。**用户已上传该角色照片时例外**：用户原照直接用作参考图，禁止再生成四视图，锁定卡描述从原照可见特征提取
2. **逐镜头传参**：工具是无状态的——每次调用都必须通过 ImageList 传入该镜头所有出场角色的参考图
3. **视觉锁定由参考图承担**：镜头 ImageList 已传该角色参考图时，Prompt 只绑定角色名（`参考@图片N的形象作为{角色名}`），禁止复写图上可见的静态外观。需要文字描述的仅三类：①图上不可见的特征；②本段需改变的特征（写明"此段不按参考图"）；③无参考图的角色——此时锁定卡描述逐字复制，禁止近义词改写
4. **单图不超 4 人**：每张参考图中人物不超过 4 个，超过时分批生成
5. **风格基准统一**：启用风格锚定的项目，所有角色参考图（含中途新增角色）生成时 ImageList 必须传入 `@style_anchor`，引用语见下文四视图规范
6. **音色锚定逐镜头传参**：有音色锚定音频的角色，每次 `sandbox_generate_video` 调用必须通过 AudioList 传入该镜头所有说话角色的 voice mp3。AudioList 不能单独使用——ImageList 必须同时有图片素材
7. **群像类型图例外**：孩童、老人、村童们、村民、路人、围观群众等无姓名、无独立身份锁定诉求的群像/类型角色，不生成四视图，改用 `character_xxx_group.png`。群像参考图只锁定群体造型范围，不保证每个个体跨镜头完全相同
8. **多形象仍是同一角色**：仅多段 creative_design.md 明确声明时允许同一角色有多个形象。所有形象共用一组身份锚点和一个角色名，默认共用一个角色级音色文件；仅 creative_design.md 已记录的明确音色例外可使用对应例外文件，禁止仅因换装/年龄/形态变化自行换声
9. **形象逐段准入**：每个 shot 只传入该段实际出现的形象图；同一角色在 shot 内发生明确形象切换时，才同时传入切换前后形象图，并在 Prompt 画面阶段中明确何时由哪个形象切到哪个形象。未标形象时使用基础形象

## 角色锁定卡模板

为每个需要身份锁定的重要个体角色创建一张锁定卡，记录到 `creative_design.md` 中。锁定卡用于生成参考图和跨段一致性校验；视频 Prompt 不逐字引用卡中描述（见强制规则 3），仅无参考图角色例外。群像/类型角色不建锁定卡，只在 `素材绑定关系` 表中记录群像参考图路径。

```
### [角色名] 锁定卡

| 字段 | 内容 |
|------|------|
| 面型 | {描述，如：鹅蛋脸} |
| 眼型+瞳色 | {描述，如：大杏眼、棕色瞳孔} |
| 发色 | {描述，如：乌黑} |
| 发型+长度 | {描述，如：齐肩直发} |
| 肤色 | {描述，如：白皙肤色，脸颊微红} |
| 体型 | {描述，如：纤瘦，约165cm} |
| 标志特征 | {描述，如：左耳银色耳钉、鼻梁小雀斑} |
| 默认服装 | {描述，如：白色衬衫、藏蓝百褶裙} |
| 参考图文件 | {sheet: character_xxx_sheet.png 或 用户原照: upload/xxx.png} |
| 音色锚定文件 | voice: voice_xxx.mp3（主要角色+有台词时生成） |
```

多形象角色在同一张角色锁定卡中追加下表，禁止为每个形象新建独立角色锁定卡：

```markdown
| 形象名 | 类型 | 身份锚点/保留项 | 显著变化项 | 参考图文件 | 出现场次 |
|--------|------|-----------------|------------|------------|----------|
| {基础形象} | 基础 | {身份锚点} | 无 | assets/{project}/character_xxx_base_sheet.png | {场次} |
| {变化形象} | 变化 | {身份锚点及保留项} | {变化项} | assets/{project}/character_xxx_{appearance}_sheet.png | {场次} |
```

锁定卡顶部的 `音色锚定文件` 默认对所有形象统一生效，不在形象表中重复定义音色；存在已明确记录的音色例外时，在表后单列 `音色例外：{形象名} → {例外 voice 路径}`。

## 参考图生成规范

### 四视图角色设定稿

四视图的完整规范（比例、布局、裁切、背景、姿态、风格锚定引用语、Prompt 模板）详见 `assets/ref-image-design.md` §一，此处不重复。核心要求：16:9 比例，正面脸部特写+正面/侧面/背面全身横向排列，三个全身视图从头顶到脚尖严禁裁切，纯白背景均匀平光。

### 群像/类型角色参考图

群像/类型角色（判定见强制规则 7）的完整判定与模板详见 `assets/ref-image-design.md` §一「群像/类型角色例外」。核心要求：2-4 个不同个体，中景/中近景展示全身或大半身，统一年龄层/服饰时代/发型气质，五官和身形有轻微差异，文件命名 `character_xxx_group.png`。

## 多角色场景引用规则

| 场景 | ImageList 排列 | Prompt 引用方式 |
|------|---------------|----------------|
| 单角色镜头 | [sheet, scene] | 参考@图片1的角色形象，场景参考@图片2 |
| 双角色镜头 | [A_sheet, B_sheet, scene] | @图片1的[A角色名]与@图片2的[B角色名]，场景参考@图片3 |
| 群像/类型角色镜头 | [group_ref, scene] | 参考@图片1的{群体类型}造型范围，场景参考@图片2 |
| 图片槽位紧张(>6角色) | 优先保留有台词角色的四视图设定稿 | 远景配角可只传正面全身图 |
| 有音色锚定的对话镜头 | [A_sheet, B_sheet, scene], AudioList: [voice_A, voice_B] | @图片1的A + @图片2的B，A台词音色参考@音频1（{A音色具体描述}），B台词音色参考@音频2（{B音色具体描述}） |
| 单角色当前为变化形象 | [A_appearance_sheet, scene] | 参考@图片1的{A角色名}·{当前形象名}作为本段角色形象，场景参考@图片2 |
| shot 内发生形象切换 | [A_before_sheet, A_after_sheet, scene] | @图片1与@图片2均为同一{A角色名}，前阶段使用{切换前形象}，切换后使用{切换后形象}，场景参考@图片3 |

**排列优先级**：四视图设定稿 > 群像类型图 > 场景图 > 道具图。重要素材排前面。

## 新增角色风格对齐流程

新角色的风格基准按以下优先级取用（降级链）：

1. **style_anchor.png（首选）**：启用风格锚定的项目，新角色与首批角色引用同一锚点、同源生成，零代际漂移。ImageList 传入 `@style_anchor`，引用语同四视图规范；
2. **主角四视图（升三轮项目）**：标定确认"概览图 → 人物"风格迁移不佳、已由主角图兼任人物锚的项目，新角色引主角图；
3. **已有角色图（兜底）**：仅限无锚点的存量项目。这是"复印件参考复印件"，每一代都会漂移，连续新增多个角色时漂移会累积——有条件时回到 ①（为项目补生成锚点并落盘）。

生成后用 `sandbox_read` 对比检查：
- 线条粗细、上色风格、瞳孔画法与已有素材一致；
- **新角色五官是否趋同于锚点人物**——趋同则强化引用语、降参考强度后重生成。

## 失败模式

> 红线表已覆盖的高频翻车点不在此重复。

| 失败 | 后果 | 修法 |
|------|------|------|
| 多个角色五官趋同于锚点人物 | 锚点人物特征泄漏进角色设定稿 | 引用语强化"严禁参考人物五官、体型"，降参考强度；仍泄漏则角色图改引无人物版锚点，人物渲染以技法语言在 Prompt 写满 |
| 群像角色长得完全一样 | 村童/老人/路人像复制粘贴,画面假 | 群像图要求 2-4 个不同个体,服饰同类但五官、身形、表情有轻微差异 |
| 同一画面超过4人 | 出现少人/多人/重复人物 | 先分批生图（每张≤4人），再用多张图生成视频 |
| 遗漏配角参考图 | 配角形态不可控 | 所有出场角色都需要参考图，包括动物、幼儿 |

## Prompt 模板（多角色镜头示例）

```
参考@图片1的形象作为林薇，参考@图片2的形象作为陈默，
场景参考@图片3。
便利店暖色灯光下，林薇拿着一杯咖啡转身，与走进来的陈默四目相对，两人表情微微惊讶。
镜头从林薇面部特写缓慢后拉至中景，暖光柔焦，温馨氛围。
五官清晰不变形，人体结构正常，4K超高清，画面稳定，保持无字幕。
时长：8秒，比例：16:9
```

> 本示例为 **A 写实模式**。B 风格化模式下，"暖光柔焦、温馨氛围"等光影氛围描述须按 `assets/ref-image-design.md` §〇.4 翻译为画种程式语言。画质词（如"4K超高清"）仅为**视频镜头 Prompt** 的约定；参考图 Prompt 仍按《参考图设计与生成指南》通用红线禁用技术黑话，两类 Prompt 不混用。
