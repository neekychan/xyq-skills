# 分镜图模板：歌词 / MV 分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：围绕歌词或音乐节奏设计的镜头序列，多为情绪化 MV、舞蹈片段或情绪短片，强调「画面随音乐走」。
- **典型场景**：单曲 MV、情绪向歌词卡点视频、舞蹈翻跳 MV、歌词海报轮播等。

## 2. 判定关键词
- 典型触发词：`歌词`、`MV`、`配乐`、`BGM`、`伴奏`、`旋律`、`主歌`、`副歌`、`卡点`、`节奏`。
- 当需求中明确提及“根据这段歌/歌词做视频”时，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：8–16 镜，覆盖整首歌的关键乐段。
- **结构骨架**：
  1. 开场引子（1–2 镜）：建立情绪与主空间，可弱化人物。
  2. 主歌段落（3–6 镜）：跟随歌词讲述情节或情绪，镜头变化相对平稳。
  3. 副歌/高潮段（3–6 镜）：节奏更密集，适当加入运镜与情绪爆发画面。
  4. 过门/桥段（1–2 镜）：可用环境/道具/抽象意象作过渡。
  5. 尾声收束（1–2 镜）：情绪回落或开放式结尾。
- **景别节奏**：主歌以中景、近景为主；副歌可穿插远景与特写，加强情绪对比。

## 4. 生图 Prompt（PE）模板

```text
你是一名 MV 分镜导演，请根据下述歌曲信息设计一张 {宫格数} 宫格的歌词/MV 分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏短视频”}。

【歌曲信息】
- 歌曲名称：{歌曲名}
- 情绪基调：{如“孤独/治愈/热血/怀旧”}
- 节奏结构：{如“前 10 秒纯音乐引子，随后主歌-副歌-主歌-副歌-桥段-尾声”}
- 关键词歌词：{选取 5–10 句关键歌词，按时间顺序列出}

【画面风格】
- 整体画风：{如“电影感写实 / 2D 动漫 / 3D 卡通 / 粒子抽象”}
- 色调：{主色调及对比色，如“冷蓝+霓虹粉”}

【主体与场景】
- 主要角色：{姓名/外观/服饰/性格}
- 主要场景：{城市夜景/教室/卧室/舞台等}，可按「现实/回忆/幻想」分层。

【宫格与构图】
- 宫格数：{宫格数，如 12 宫格}，按时间顺序编号 M1–M{N}。
- 每格对应一个歌词片段或节奏小节。
- 需在说明中标明“属于主歌/副歌/桥段/尾声”。

【输出要求】
- 为 M1–M{N} 逐格写出中文分镜说明，包含：景别 + 角色/场景 + 与哪句歌词呼应。
- 在说明末尾注明节奏提示，如“对齐鼓点第 3 拍卡点切镜”。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏，3 表示 16:9 横版，0 表示跟随参考图}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「音乐 MV 类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 有音乐文件时以音乐节奏为一号约束，分镜只做辅助。
- 纯情绪向 MV 可弱化叙事，加强意象与色彩的统一性。
