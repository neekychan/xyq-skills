# 分镜图模板：动作分镜型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：强调打斗、追逐、战斗、舞蹈等高动作量场景，对肢体姿态与节奏切分有明确约束的分镜。
- **典型场景**：舞蹈教学、角色舞蹈 PV、武术/格斗动作展示、运动/健身动作分解、跑酷/追逐段落设计等。

## 2. 判定关键词
- 典型触发词：`打斗`、`战斗`、`动作`、`格斗`、`搏斗`、`追逐`、`拳击`、`武侠`、`舞蹈动作分解`、`关键帧`。
- 当需求重点在于“拆动作”“看动作过程是否流畅”时，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：4–12 格，多用于动作关键帧拆解。
- **结构骨架**：
  1. 起势（1–2 格）：动作准备或起跳前瞬间，交代空间与方向。
  2. 过程（2–6 格）：动作中段的关键姿态，保证连贯性与方向一致。
  3. 爆发/极值（1–2 格）：动作幅度最大或打击瞬间。
  4. 收势/转场（1–2 格）：回到稳定姿态或接入下一个动作。
- **画面特征**：角色多为全身/中全身景别，背景可适度简化，重点突出身体重心、四肢方向与运动轨迹。

## 4. 生图 Prompt（PE）模板

```text
你是一名动作指导，请为 {动作类型，如“二次元舞蹈/武术对打/篮球灌篮展示”} 设计一张 {宫格数} 宫格的动作分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏动作教程”}。

【动作信息】
- 动作名称与风格：{如“街舞 locking 组合 / 太极推手 / 花式投篮”}
- 节奏：{慢节奏/中速/快速}，每格约 {每格秒数} 秒。

【画面风格】
- 整体风格：{如“写实运动摄影 / 二次元热血漫画 / 3D 写实”}
- 色调：{主色调，如“冷蓝+荧光灯光”“暖橙+舞台灯光”}。

【主体与场景】
- 角色：{性别、年龄、体型、服装风格}，强调服饰与发型的一致性。
- 场景：{舞台/街头/擂台/球场等}，背景可简化但需体现空间方向。

【宫格与构图】
- 宫格数：{宫格数，如 8 宫格}，按动作时间顺序编号 A1–A{N}。
- 每格说明中需明确：身体重心位置、四肢方向、视线方向和运动趋势（向左/向右/向前/向后）。

【输出要求】
- 为 A1–A{N} 逐格写出分镜说明：景别 + 动作要点 + 身体姿态 + 场景简述。
- 在说明中可标注节奏提示，如“对齐音乐第 4 拍起跳”。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏，0 表示跟随参考图，3 表示 16:9 横版}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「动作分解类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 简单动作循环（如舞蹈卡点）可减少分镜格数，集中做 4-6 个关键姿态。
