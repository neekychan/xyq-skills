## 1. 五个独立的全局锁

不要把画风、氛围、色彩和光照写成一段混合文字。四者分开，才能在改正光照时不破坏用户已满意的色调。

### 1.1 `style_lock`：原子朋克世界与实拍媒介

```text
真实摄影资产照片，由真实相机与真实镜头拍摄，具有自然景深、真实镜头光学、克制的胶片颗粒和实际尺度。被摄对象是实景搭建、实体道具、真人演员、实体服装与实际材料。被拍摄的世界是 1960 年代美国西海岸原子朋克（原子时代/太空时代复古未来）：圆角浇筑混凝土、飞碟屋顶、海岸公路、旧汽车旅馆、发射设施、棕榈长街、模拟仪表、氧化铝、划痕镀铬、老化玻璃钢、裂纹水磨石、旧皮革与晒褪漆面。将“原子朋克”当作被拍摄世界的年代与美术设定，不当作插画、概念设计或游戏渲染类型标签。
```

角色、物种、故事和局部造型可变；上述年代、空间、材料和实拍媒介不变。不用“超写实”“电影级”“反 CG”等空泛标签代替具体的摄影事实。

#### 1.1.1 画面内容补充
结合规划的场景需求构造实际画面内容主体。
- 城市场景下，画面内应该包含多个建筑、街道、广告牌、房屋、树木等丰富的主体。
- 海边画面内应该包含沙滩、遮阳伞等明显的设施。
规划画面时需要对画面内容有明确设计。

### 1.2 `atmosphere_lock`：氛围

```text
温暖而忧郁的西海岸原子朋克氛围：乐观的太空时代未来日常被某种失序或中断留下痕迹，漂亮、宁静、略带不安，但不使用暗黑恐怖滤镜。氛围通过空间功能、中断的日常痕迹、物件排布和克制表演建立，不通过把全图提亮、压暗或重新染色建立。
```

### 1.3 `color_lock`：固定色彩块

下面这一段在每张角色图、场景图和每条视频 Prompt 中逐字复用。不因光照、时段、天气或情绪变更它。

```text
色彩固定为60年代西海岸原子朋克的复古暖橙与海盐青蓝关系，但整体环境材料保持低至中等饱和度的复古胶片感，不使用高饱和青橙滤镜。海盐青蓝主要来自晴朗天空、海面、远景空气、玻璃反射和少量晒褪青绿色旧车漆；暖橙只来自具有明确物理来源的火箭顶端、遮阳篷、旧漆、店招、信号灯、热源、锈蚀或关键服饰。暖橙是小面积、高价值的视觉强调，不得染成全局阳光、阴影或建筑底色。建筑、道路与大部分城市材料以晒褪沙色、灰褐混凝土、旧铝、低饱和骨灰白、氧化金属和褪色玻璃钢为主；白色材料保持略有风化的中性灰白，不做纯白无菌表面。色彩对比来自天空冷色、自然日光和局部暖色物件，而不是统一青橙调色。光照只改变同一颜色在受光、半影与阴影中的亮度和反射强弱，允许光源色温、曝光、阴影、环境反射和材质特性造成局部且物理合理的色相、饱和度与明度变化，但不得让整体色调漂移成另一套风格。
```

色彩不是固定面积配比。不要强迫每个角色或道具同时穿橙色和蓝色，也不要做青橙描边套装。

#### 1.3.1 色彩职责与材料归属

固定色调不等于每件物体使用相同配色。先把颜色分配给真实空间、材料和叙事重点，再由光照改变它们的局部明暗：

| 视觉职责 | 色彩与材料归属 | 使用纪律 |
|---|---|---|
| 冷色空间 | 鲜艳蔚蓝天空、海盐蓝环境色、海水、远景玻璃、少量旧漆面 | 可形成大面积冷色空间；不强迫每件道具都带蓝色 |
| 暖色重点 | 复古暖橙日照、暖木、旧漆、店招、热源、警报、锈蚀和少量叙事重点 | 面积可小但须有材料、光源或叙事依据；不做无来源橙色描边 |
| 中间调底色 | 晒旧灰褐混凝土、灰尘沥青、褪沙墙面、旧铝、铬锈、旧棕 | 承接建筑、道路和生活痕迹；只在材料本身风化处降低饱和度 |
| 角色与机械重量 | 炭黑、旧棕、氧化金属、搪瓷、旧皮革与自然织物 | 由身份、功能和材质决定；不套统一青橙配色 |
| 干净白面 | 搪瓷、白漆、骨白混凝土等实际白色材料 | 受光区保持干净中性；背光或遮挡区可以自然变暗，不为“通透”整体提亮 |

“风化骨白”是一种可选材料，不是全片底色；“复古暖橙 + 海盐蓝”是整体冷暖秩序，不是两种颜色必须同时出现在每个资产上的配额。

#### 1.3.2 同一色调在不同时段的摄影落实

- **白天：** 先确定太阳方位，再让天空、地面或海面提供弱反射。蔚蓝天空与暖橙日照保持原色彩职责，硬光投影同向；不得为了“明快”抬平阴影。
- **黄昏：** 低角度暖橙日光与海盐蓝环境阴影可以同框，但二者来自太阳与天空，不靠额外橙蓝滤镜。耀斑只在太阳进入光轴时出现。
- **夜晚：** 从画内钠灯、钨丝灯、旧店招或仪表中选择一个主导光源，其余灯光自然衰减。保持色彩锁，不做均匀蓝橙夜景。
- **室内/舱内：** 可使用窗光或一组可见实用灯建立主光；旧黄铜、陶瓷、玻璃钢、模拟仪表和磨损材料保留真实反射，不做纯白无菌空间。

### 1.4 `photography_lock`：真实光照与曝光

```text
使用现场可见或可推断的自然光和实用灯拍摄，只设一个主导光源。光线在真实空间中被帽檐、面部转折、衣物、建筑和物体遮挡；阴影方向与主光一致，阴影面明显低于受光面。补光只来自天空、地面、墙面、海面或画内灯具的弱反射，不使用镜头轴线上的美容光。以中间调和叙事主体设定自然曝光，保留真实光比、局部遮挡和不完美明暗；允许极小镜面高光接近白，允许最深阴影自然损失少量细节。耀斑、体积光和雾化只在光源进入光轴且空气介质成立时少量出现。
```

禁止使用以下快捷方式追求“好看”：

- 无来源的正面大柔光、环形眼神光或左右对称填光；
- 每条边都有亮边的轮廓光；
- 受光面、暗面与背景同时被抬到等亮的 HDR 影调；
- 所有材质都在同一角度出现同强高光；
- 让光照字段覆盖或重新解释 `color_lock`。

### 1.5 `human_surface_lock`：人物表面

```text
真人皮肤保留毛孔、微纹理、细小干燥区、轻微局部色差和自然不对称，整体是哑光至微丝光的真实皮肤，不做塑料平滑或美容磨皮。额头、鼻梁、面颊和上唇只在主光真正命中的小区域保留克制高光，其余皮肤不泛油。汗水只在天气或动作明确要求时局部不均匀出现。头发保留单根与发束分离、低至中等自然光泽和少量不完美碎发；除非剧情明确要求，不做发油造型、湿发、发胶硬亮感或大面积镜面反光。棉、麻、羊毛与旧皮革按真实粗糙度反射，不做树脂涂层般的统一亮面。
```

## 2. 逐图实拍光照卡

每张图在 Prompt 中都要写明下列字段。填不出光源方位和阴影方向时，不进入生成。

| 字段 | 要求 |
|---|---|
| 时间与天气 | 写明上午/正午/日落前/蓝调/夜晚与晴/云/雾/雨后 |
| 主光 | 只写一个主导光源，写清它在主体和镜头哪一侧、高度、大小、硬软与是否入画 |
| 遮挡与阴影 | 帽檐/鼻影/衣褶/建筑如何遮光，投影向哪里延伸，边缘多硬 |
| 环境弱反射 | 只使用画内可成立的天空/地面/墙面/海面/灯具，且明显弱于主光 |
| 曝光锚点 | 指定主体脸部/表情屏/服装识别区/空间入口中的一项优先正常曝光 |
| 可接受损失 | 写明哪些小面积反射可接近白，哪些最深遮挡可自然丢失少量细节 |
| 材质响应 | 混凝土、金属、玻璃、皮革、皮肤、头发等各自在什么角度反射，不用一个“通透”统括 |
| 光学条件 | 耀斑/体积光/雾化是否真正满足光轴和空气介质条件 |

`color_lock` 是常量，这张卡是变量。只改这张卡来修复假光，不动 `color_lock`。

## 3. 资产输出白名单

### 3.1 角色图

用角色图锁定：单一身份、年龄段、身形、剪影、面部/面板、发型、服装层次、材料、识别色、磨损和与角色绑定的道具。

硬规则：

- 一个命名或反复出现的角色 = 一张独立图 = 一次独立生成调用。
- 一张角色图里恰好只有该角色一名可识别主体；不出现伴侣、其他可识别人脸或其它完整人形。
- 用一个全身或四分之三全身主视角，姿态自然、中性、可读，不演绎剧情动作。
- 不生成多视图、多姿势、表情小格、面部嵌图、细节嵌图、拼贴、设定板排版、标题或文字标注。
- 不用无缝白色/灰色棚拍背景和对称影棚布光。选择一面有实际纹理和空间深度的简洁实景墙面、门廊或半开放建筑阴影处，但不让背景变成剧情场景。

#### 单人角色图 Prompt 模板

```text
【资产类型】一张真实摄影的单人角色资产照片，只用于锁定该角色的身份与造型。

【唯一主体】画面中恰好只有一名可识别角色：[姓名/称谓]。[年龄段、身形、面部特征、发型、自然神情]。[服装层次、年代剪影、织物/皮革/金属材料、识别色、局部磨损]。[若有：与该角色绑定的一件道具，作为造型的一部分]。

【身份设计】[该角色在原子时代世界中的社会功能、制造历史或生活背景]。[主材质色、只选一项可复用的局部识别色、暖色来源、禁止配色]。[若适用：固定的面屏/表情符号字库或招牌物件母题；只呈现当前资产确需锁定的一项，不做小格展示]。

【世界与媒介】[style_lock 逐字复用]

【氛围】[atmosphere_lock 逐字复用]

【色彩】[color_lock 逐字复用，本段不与光照合并]

【构图与相机】单一主视角，[全身/四分之三全身]，相机约在胸口至眼平高度，50–85mm 自然人像透视，无广角夸张。人物以放松中性站姿展示比例、服装和剪影，不摆时尚广告姿势。背景为[简洁真实墙面/门廊/半开放建筑阴影处]，有真实纹理、轻微景深和接地阴影，不是无缝棚拍纸背景。

【实拍光照】[photography_lock 逐字复用]。本图光照卡：[时间天气]；主光为[可见/可推断光源]，位于人物[左/右][侧前/侧后/上方]，[硬/软]；[帽檐、鼻梁、下颌和衣褶]的阴影向[方向]落下，人脸暗侧明显比受光侧暗；只有[墙面/地面/天空]的弱环境反射，不做镜头轴线正面补光。曝光锚定[面部中间调与服装识别区]，允许[最深的颈下/帽下/衣褶阴影]自然沉下。

【人物表面】[human_surface_lock 逐字复用]

【画面边界】整张图是一个连续、未分栏的真实摄影画面：唯一可识别人物就是上述角色，只使用一个主视角、一个自然中性姿态和一个完整背景，不嵌套其它画面或文字。面部与头发服从真实表面锁；照明只来自既定主光和现场弱反射，暗面自然保留，不追加美容光或整体提亮。
```

### 3.2 场景图

用场景图锁定：地点的旧时功能、空间层次、建筑语法、主材料、纵深、入口/出口、可用动线、中断的日常痕迹与该时段的真实受光。

硬规则：

- 只记录地点，不演绎主要角色的剧情。
- 默认不出现命名或反复角色。需要尺度时，使用极小、无身份、无可读面部的远景行人或车辆。
- 不使用约会、打斗、奔跑、坐在野餐垫上等本集具体事件来填充画面。
- 至少有前景、中景、后景三层，并有道路消失点、海面地平线、高塔、圆顶或棕榈列中的一项纵深锚点。

#### 纯场景图 Prompt 模板

```text
【资产类型】一张真实摄影的地点场景资产照片，只用于锁定地点、空间、材料和可用动线，不演绎本集剧情。

【地点】[场景名与旧时社会功能]。前景是[具体材料与中断痕迹]，中景是[主要建筑/设施与可用动线]，后景以[海面地平线/道路消失点/发射塔/圆顶/棕榈列]建立纵深。使用[风化混凝土、氧化铝、老化玻璃钢、划痕镀铬、裂纹水磨石、旧皮革、晒褪漆面]中的准确组合，不把每种材料全部堆入。

【地点设计】[曾经乐观的社会功能] + [灾难或失序后被中断的日常痕迹] + [一至两个可复现的原子朋克场景符号]。[冷色空间、暖色重点、中间调底色和干净白面分别归属于哪些真实材料或光源]。

【世界与媒介】[style_lock 逐字复用]

【氛围】[atmosphere_lock 逐字复用]

【色彩】[color_lock 逐字复用，本段不与光照合并]

【构图与相机】[广角 24–35mm 或符合场景的自然焦段]，地平线稳定，真实透视，前中后景可读，并为未来的人物走位留出空间。构图服务空间辨识，不做封面海报摆拍。

【实拍光照】[photography_lock 逐字复用]。本图光照卡：[时间天气]；主光为[太阳/大面积窗光/可见实用灯组]，位于场景[方位与高度]，[硬/软]；建筑、柱子、车辆和地面投影统一向[方向]延伸；补光只来自[天空/海面/地面/墙面]弱反射。曝光锚定[空间入口/主建筑受光面/道路消失点]，允许最深的建筑遮挡区自然沉下；金属、玻璃、混凝土和灰尘依各自粗糙度响应。

【画面边界】整张图是一个连续、未分栏的真实地点摄影画面，视觉主体只有地点、建筑、设施、材料与动线；若需要尺度参照，只保留无身份、无可读面部的极小远景行人或车辆。画面保持空间观察状态，不出现本集事件、封面式表演、嵌套画面或文字；照明只来自既定主光和现场弱反射，保留建筑遮挡与自然暗部。
```

### 3.3 道具与状态的处理

道具、开关、倒计时、损伤、液位和缺失状态仍需要被设计和连续管理，但默认不为它们另出图。

- 贴身装备、手持物、首饰、帽子等并入所属角色图与角色文字锁。
- 固定在地点的仪表、入口、交通设施、损坏设施等并入场景图与场景文字锁。
- 只在视频镜头计划里登记状态 A/B 与变化时点，不为它自动新增图像资产。

## 4. 从变量到原子朋克设计

| 输入 | 原子朋克转译 |
|---|---|
| 人类 | 中世纪中叶服装剪影、自然旧面料、实用配件、晒痕与尘土；避免现代潮牌 |
| 机器人 | 外露关节、铆钉面板、模拟指示灯、划痕搪瓷、可读的服务/市政功能；避免无缝镜面人形 |
| 动物/怪物 | 保留可信生物结构，最多叠加一种时代工业干预，如旧运输挽具或黄铜编号牌 |
| 外星生物 | 用玻璃钢、陶瓷、搪瓷、黄铜、透明塑料和旧航天造型建立年代性；避免霓虹生物荧光 |
| 交通工具 | 尾鳍、圆角舱体、旧式公共设施、氧化饰条与功能性损伤；避免现代超跑和战术 SUV |
| 室内 | 圆角柜体、水磨石、乙烯基座椅、磨损玻璃、铬合金五金、模拟仪表和可见旧灯具 |

每个角色或场景选择少量有逻辑的年代证据，不把世界词库全部堆在一张图里。

### 4.1 资产内部设计卡（只增加知识，不增加图类）

为每个角色或场景先填写内部设计卡，再组装图片 Prompt。内部设计卡用于保证世界厚度，不代表要分别生成细节图、道具图或关系图。

角色内部设计卡至少记录：

- **剪影与尺度：** 远看如何辨认，身体/结构比例为何如此；
- **社会功能或制造历史：** 它原本在这个乐观原子时代社会里做什么，由谁制造或服务谁；
- **材料与制造逻辑：** 哪些结构是铆接、搪瓷、玻璃钢、织物、皮革、黄铜或旧铝，磨损为何出现在当前位置；
- **色彩职责：** 主材质色、一项可复用的局部识别色、暖色来自日照/热源/锈蚀/店招中的哪一种，以及明确禁止的无因配色；
- **人格与动作：** 一个能体现身份的自然姿态、习惯动作或功能动作；角色资产图仍保持中性，不演绎剧情；
- **绑定信息：** 贴身道具、损伤、面屏/表情字库和招牌物件以文字记录并入该角色，不另出图。

场景内部设计卡至少记录：

- **曾经的社会功能：** 旅馆、维修站、公共泳池、发射服务设施、住宅或交通节点等；
- **被中断的日常：** 只用具体物件、磨损、停摆设施和空间空缺表现，不靠统一暗调；
- **建筑与空间语法：** 圆角体量、飞碟屋顶、长廊、路面、入口/出口、可用轴线和前中后景；
- **材料与色彩职责：** 冷色空间、暖色重点、中间调底色和白色材料分别落在哪里；
- **可复现符号：** 一至两个属于当前地点的地标、店招、设施或几何母题，供后续镜头维持地点辨识。

## 5. 内部视觉母题与状态连续性

本节恢复原版中用于保持“味道”的设计知识，但所有内容都只作为文字锁和镜头规划依据，不自动扩张资产图片。

### 5.1 `motif_lexicon`：每个原创项目单独建立

母题把抽象画风锚定成可复现符号。根据用户当前内容建立四类词表，每项都写成“具体视觉符号 + 何时出现 + 如何保持一致”：

| 类别 | 设计内容 | 登记位置与使用规则 |
|---|---|---|
| 情绪出口母题 | 功能性角色可使用固定面屏、指示灯或单一符号表达情绪 | 记录进角色 `emotion_codebook`；固定图案—情绪—颜色对应，只在相关镜头调用 |
| 招牌物件母题 | 承载身份、记忆或因果的服饰、工具、纪念物或功能物 | 记录进角色 `embedded_prop_notes` 或场景 `embedded_state_notes`；跨镜保持形态、磨损和归属 |
| 场景符号母题 | 让地点一眼可辨的地标、几何、店招、设施或材料组合 | 记录进场景 `scene_symbols`；后续镜头按需要露出一个作空间锚点，不逐镜堆砌 |
| 荒诞并置母题 | 美好日常与失序痕迹、内静与外动、温情仪式与背景威胁等构图关系 | 只在用户内容需要这种情绪对撞时写入镜头调度；不通过暗调或重调色制造 |

硬规则：

- 母题必须从当前用户内容、当前角色功能和当前场景社会历史中生成，不从示例作品继承固定元素。
- 牛仔帽、宝丽来、红波点裙、丧尸、鸵鸟、塑料模特等只能在用户明确要求时出现，不能作为原子朋克的默认母题。
- 母题具体到能生成，例如“维修员胸前一枚磨损的黄铜工号牌”，不要只写“身份象征”。
- 母题不是每镜的装饰清单。只有服务当前内容、情绪或连续性时才调用；不用为了强调画风反复堆满画面。
- 母题词表本身不生成任何额外图片，只作为角色图、场景图和后续视频镜头的文字规划依据。

### 5.2 `visual_continuity_ledger`：关键物件与状态文字账本

当用户内容要求观众看清倒计时、余量、开关、损伤、数量、缺失、位置或归属变化时，把它写成可比较的视觉状态，而不是藏在解释句里：

```json
{
  "items": [
    {
      "id": "state_01",
      "bound_to": "char_01 | scene_01",
      "visual_evidence": "能在画面中直接看见的物件或状态",
      "initial_state": "开场状态",
      "change_points": ["shot_03：具体变化"],
      "final_state": "结尾状态",
      "must_not_drift": ["颜色", "位置", "数量", "磨损", "开关", "归属"]
    }
  ]
}
```

- 贴身物件绑定角色，固定设施绑定场景；均通过既有角色图/场景图和文字锁管理，不另出独立图。
- 若状态变化承担因果，镜头规划必须给它可读的插入、动作或前后对照；这是视频镜头，不是素材阶段的“某一帧”。
- 警示橙、锈红和红色指示灯只用于真正的警示、热源、损伤或状态重点，不能泛化成装饰。
- 上一镜实际输出只能继承已经正确的状态，不能覆盖本账本或把错误人物、错误光线继续传下去。

## 6. 参考图职责

只使用三种职责：

- `character_identity`：对应一张单人角色图，锁身份、剪影、服装、材料、识别色和磨损。
- `scene_location`：对应一张场景图，锁空间、建筑、材料、纵深与可用光源。
- `previous_shot_output`：仅在视频生成时用上一镜实际输出维持位置、朝向、损伤、手持物与光线连续。它不是新资产类型。

每张参考填写：

```json
{
  "id": "ref_01",
  "role": "character_identity | scene_location | previous_shot_output",
  "scope": "资产开发 | 全集 | 当前镜头",
  "priority": "高 | 中 | 低",
  "bind": ["只锁哪些身份、材料、空间、状态或方向字段"],
  "must_keep": [],
  "must_not_copy": ["文字", "水印", "布局", "无关人物"],
  "notes": "这张图只锁什么"
}
```

冲突优先级：`用户明确要求 > color_lock 不变 > 逐图实拍光照卡 > style_lock > 当前单人角色图 > 场景图 > 上一镜实际输出`。上一镜不得把已经错误的假光传给下一镜。

## 7. `world_contract`、`asset_registry` 与连续性账本

```json
{
  "world_contract": {
    "style_lock": "原子朋克年代/空间/材料/实拍媒介",
    "atmosphere_lock": "温暖、忧郁、漂亮且平静不安",
    "color_lock": "每张图逐字复用的固定色彩块",

    "human_surface_lock": "哑光至微丝光皮肤、自然发束、非油亮表面",
    "motif_lexicon": {
      "emotion_outlets": [],
      "signature_objects": [],
      "scene_symbols": [],
      "absurd_juxtapositions": []
    }
  },
  "asset_registry": {
    "characters": [],
    "scenes": []
  },
  "visual_continuity_ledger": {"items": []}
}
```

`asset_registry` 里不增加其他图像数组。

## 8. 视觉质检门

任一项失败即不放行：

| 项目 | 通过条件 |
|---|---|
| 输出范围 | 默认只有必要的角色图和场景图 |
| 单人角色 | 每张恰好一名可识别角色，无伴侣、群像、多视图、嵌图或拼贴 |
| 纯场景 | 场景图无命名主角和本集具体剧情动作，空间、材料、纵深与动线可读 |
| 原子朋克画风 | 1960 年代西海岸原子时代年代、建筑、服装、材料与实体制造证据稳定 |
| 设计厚度 | 角色/场景的社会功能、制造逻辑、材料归属、识别色和可复现场景符号已在内部设计卡中具体记录 |
| 母题原创 | 母题来自当前内容且按需调用；没有照搬示例作品固定元素，也没有扩张成额外图片 |
| 状态连续 | 关键物件和状态在文字账本中可前后比较，颜色、位置、数量、磨损、开关和归属不漂移 |
| 色彩不变 | `color_lock` 完整复用，没有被光照、时段、天气、情绪或新滤镜改写 |
| 光照真实 | 主光来源、遮挡、阴影方向、弱反射、曝光锚点和材质高光能由同一空间因果验证 |
| 非完美影棚光 | 无镜头轴线美容光、无对称补光、无每边亮边、无暗部全提亮；有合理的局部偏暗与遮挡 |
| 人物表面 | 皮肤有微纹理且不泛油，面部高光小而有因；头发自然分束、低至中光泽且无发油湿亮感 |
| 材质真实 | 各种材质在受光、半影与阴影中呈现不同粗糙度与反射，不是统一树脂涂层 |
| Prompt 完整度 | 角色与场景使用各自模板，且资产类型、内容、画风、氛围、色彩、光照、材质、构图/排除项全部写足 |

修复时只改第一个失效锁。光照假就重写逐图实拍光照卡；不降饱和、不改色相、不增加全局滤镜。人脸油亮就修正皮肤/头发反射和正面补光；不把人脸整体压暗。
