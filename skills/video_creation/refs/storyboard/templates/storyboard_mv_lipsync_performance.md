# 分镜图模板：音乐 MV · 表演·对口型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以**歌手/人物正面表演与对口型（lip-sync）**为核心的 MV 分镜，强调“人物在唱、口型对得上、表演有张力”。
- **典型场景**：
  - 歌手个人 MV、翻唱视频、虚拟人/数字人演唱。
  - 需要明确正脸近景、口型与歌词同步的演唱镜头。
  - 直拍/竖屏演唱、舞台演出特写。

## 2. 判定关键词与适用边界
- 典型触发词：`对口型`、`lip-sync`、`歌手演唱`、`翻唱`、`正脸近景`、`数字人唱歌`、`舞台特写`。
- 适用判定：
  - 重点是人物演唱表演与口型同步，而非意象或剧情；
  - 需要稳定、可识别的人物正脸与多角度演唱镜头。
- 不适用场景：
  - 不出现人物或不需要口型 → 用“情绪氛围”或“概念视觉”模板；
  - 以舞蹈动作为主 → 用“舞蹈·唱跳”模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–12 格，覆盖不同景别与机位的演唱镜头；
- 规划方式：
  - 主歌：以中近景、半身演唱为主，建立人物与情绪；
  - 副歌：增加正脸特写与情绪爆发镜头，强化记忆点；
  - 穿插不同机位（正面/侧面/俯仰）与场景，避免单一固定镜头；
  - 标注每格对应的歌词句，便于口型对齐。

## 4. 生图 Prompt（PE）模板

```text
你是一名演唱·对口型 MV 分镜导演，请根据下述信息，设计一张 {宫格数} 宫格的“表演·对口型”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”}。

【人物与歌曲信息】
- 人物设定：{形象、造型、气质，需全片一致}
- 歌曲名称与曲风：{歌名 / 抒情·流行·摇滚等}
- 关键演唱段落：{主歌/副歌的代表性歌词句}
- 表演基调：{如“深情、克制、爆发、俏皮”}

【拆分要求】
1. 按演唱段落安排景别：建立 → 推进 → 副歌爆发 → 收束；
2. 每格标注：景别（特写/近景/中景）、机位（正/侧/俯/仰）、对应歌词句；
3. 副歌段安排至少 1–2 个正脸情绪特写，作为视觉记忆点。

【分镜输出格式】
- 宫格编号：M1–M{N}；
- 对于每一格输出：
  - 对应歌词：{这格演唱的歌词句}
  - 景别与机位：{如“正脸特写 / 侧面近景 / 俯拍中景”}
  - 人物表演：{表情、眼神、口型状态、肢体语言}
  - 场景与光影：{背景环境、打光方向与氛围}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16，利于人物竖屏特写；
- 画风：{写实演唱 / MV 质感 / 舞台灯光感}；
- 人物五官、造型、发型在全片严格一致，仅服装/场景按段落变化。
```

## 5. 一致性与避坑
- **人物一致性是第一优先级**：五官、发型、造型不能跨格漂移，建议提供并锁定角色参考图。
- 口型应贴合歌词，避免“张嘴却对不上词”的违和；可在每格标注对应歌词句。
- 避免全片同一机位、同一景别，造成单调；副歌要有景别与情绪升级。
- 灯光与场景可变化，但人物主光方向与肤色基调需统一。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段确定景别/机位/对应歌词；
  - 视频阶段以正脸演唱关键格为参考帧，Prompt 中强调口型与歌词同步、表情连贯；
  - 若平台支持音轨/口型驱动，按歌词时间轴对齐口型。
- 口型与对白同步规则复用 `storyboard/dialogue-rules.md`（对口型本质是“演唱口型同步”）；人物一致性复用 `assets/character-lock.md`（如有）。
