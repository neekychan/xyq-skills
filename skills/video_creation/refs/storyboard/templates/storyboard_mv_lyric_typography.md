# 分镜图模板：音乐 MV · 歌词字幕·动态排版

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以**歌词文字本身作为主视觉**，通过字体设计、动态排版（kinetic typography）呈现歌词的 MV 分镜，强调“字即画面、排版即节奏”。
- **典型场景**：
  - Lyric Video（歌词视频）、卡拉 OK 式歌词卡点。
  - 字体设计感强的动态歌词短视频。
  - 作为其他 MV 类型的“字幕层”叠加方案。

## 2. 判定关键词与适用边界
- 典型触发词：`歌词字幕`、`动态排版`、`kinetic typography`、`歌词卡点`、`字体动画`、`lyric video`。
- 适用判定：
  - 用户希望歌词文字本身成为画面主体，强调排版与动效；
  - 需要逐句/逐字呈现歌词，并与节拍卡点同步。
- 不适用场景：
  - 文字仅作辅助、画面以意象/人物为主 → 用“情绪氛围/概念视觉/表演”模板，本模板可作字幕层搭配。

## 3. 分镜结构建议
- **推荐宫格数**：8–16 格，按歌词句/卡点划分；
- 规划方式：
  - 按主歌/副歌划分文字密度与排版强度，副歌排版最具冲击力；
  - 每格定义：呈现的歌词句、字体风格、排版构图、入场动效方向；
  - 关键词（歌名、副歌 hook 句）做放大/变色/特殊字体强调。

## 4. 生图 Prompt（PE）模板

```text
你是一名动态歌词排版（kinetic typography）MV 分镜导演，请根据下述信息，设计一张 {宫格数} 宫格的“歌词字幕·动态排版”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏”}。

【歌曲与排版信息】
- 歌曲名称与曲风：{歌名 / 抒情·摇滚·电子等}
- 完整歌词：{粘贴歌词，保留分段}
- 字体与视觉基调：{如“衬线优雅 / 无衬线现代 / 手写感 / 故障风”}
- 背景处理：{纯色 / 渐变 / 弱化的实拍或纹理}

【拆分要求】
1. 按歌词句/卡点拆格，副歌 hook 句单独强调；
2. 每格定义：呈现歌词、字体风格、排版构图、入场/退场动效方向；
3. 文字层级清晰：主句最大、辅句次之，关键词重点强调。

【分镜输出格式】
- 宫格编号：M1–M{N}，按歌曲时间顺序；
- 对于每一格输出：
  - 对应歌词：{逐字写出这格呈现的歌词}
  - 字体与样式：{字重、字体风格、颜色}
  - 排版构图：{对齐方式、文字大小层级、留白}
  - 动效提示：{如“从下方滑入”“逐字打字机”“副歌爆炸放大”}
  - 节拍卡点：{文字切换/强调对应的拍点}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16；
- 背景以纯色/渐变/弱化纹理为主，确保文字清晰可读；
- 全片字体系统与配色统一，仅在副歌做层级与动效升级。
```

## 5. 一致性与避坑
- **可读性第一**：字号、对比度、留白要保证歌词清晰，避免文字与背景糊在一起。
- 字体系统与配色全片统一，避免每格换一套字体导致杂乱。
- 文字与节拍卡点对齐，切换不要早于/晚于关键拍点。
- 一格不要堆太多文字；长句拆分逐行/逐字呈现。
- 注意生成图中文字的正确性，关键歌词句建议在脚本层校对。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段确定每格歌词、排版与动效方向；
  - 文字层建议以脚本/后期渲染保证字形准确，而非完全依赖生成模型写字；
  - 视频阶段以排版关键格为参考，结合打字机/滑入/缩放等动效，按节拍卡点切换。
- 适合作为“字幕层”与“情绪氛围 / 概念视觉 / 表演·对口型”等模板叠加：画面层负责意象/人物，字幕层负责歌词逐字呈现，两者节奏同步。
