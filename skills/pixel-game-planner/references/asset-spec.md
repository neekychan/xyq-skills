# 像素尺寸规格表

## 角色与道具尺寸

| 尺寸 | 适用资产 | 说明 |
|------|----------|------|
| 16x16 | 金币、钥匙、小图标、小道具 | 最小可读单元 |
| 24x24 | 小怪、飞行怪、小宠物 | 略大于道具，轮廓可辨 |
| 32x32 | 主角、小型 NPC、基础敌人 | 标准主角尺寸 |
| 48x48 | 更清晰的主角或重要 NPC | 需要更多细节时使用 |
| 64x64 | Boss、小型首领 | 用于 Boss 或终点门 |
| 96x96 | 大型 Boss 或终点门 | 终点门、大型 Boss |

## 关卡与画面尺寸

| 尺寸 | 比例 | 适用场景 |
|------|------|----------|
| 320x180 | 16:9 | 标准横版关卡逻辑 |
| 384x216 | 16:9 | 更清晰的横版首帧 |
| 640x360 | 16:9 | 上采样输出，保持像素逻辑 |
| 216x384 | 9:16 | 竖屏像素短视频逻辑 |

# 色板库

必须限制色彩数量（8-12 色），避免现代插画式渐变。

### 森林关

# 场景层级规范

像素游戏画面必须有清晰层级：

| 层级 | 内容 |
|------|------|
| 前景 | 平台、地面 tile、草丛、石块、金币、陷阱 |
| 中景 | 主角、小怪、NPC、宝箱、机关、终点门 |
| 背景 | 森林、城堡、星空、地下城墙体、城市灯牌、远山 |
| UI 层 | 血条、金币数、分数、生命数、关卡名、STAGE CLEAR |

# 资产命名规则

命名格式：`PX-[类型]-[序号]-[名称]`

| 类型代码 | 说明 | 示例 |
|----------|------|------|
| HERO | 主角 | PX-HERO-01-红围巾小猫 |
| ENEMY | 敌人 | PX-ENEMY-01-巡逻史莱姆 |
| NPC | NPC | PX-NPC-01-商店老爷爷 |
| PROP | 道具 | PX-PROP-01-金币 |
| LEVEL | 关卡 | PX-LEVEL-01-森林跳台关 |
| UI | 界面 | PX-UI-01-复古血条金币分数 |
| START | 首帧 | PX-START-01-森林关卡首帧 |
| END | 尾帧 | PX-END-01-通关定格尾帧 |
| FX | 特效 | PX-FX-01-像素爆炸特效 |
