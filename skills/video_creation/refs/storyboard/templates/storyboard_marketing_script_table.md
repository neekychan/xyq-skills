# 分镜图模板：营销转化 · 营销脚本表格

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以“镜号/画面/卖点/口播文案/时长/CTA”等字段为骨架的营销脚本表格，将带货或广告视频拆成结构化的脚本清单，便于执行拍摄或生视频。
- **典型场景**：
  - 电商短视频带货脚本规划；
  - 品牌或品类广告的脚本拆解，给主播/配音/剪辑使用；
  - 多商品选品合集的脚本表，统一规划每个镜头的卖点和口播。

## 2. 判定关键词与适用边界
- 典型触发词：`脚本表`、`镜号表`、`带货脚本`、`分镜脚本`、`口播稿`、`广告脚本拆解`、`时长规划`、`CTA 文案`。
- 适用判定：
  - 用户希望拿到一份可以“直接给主播/配音/剪辑使用”的结构化脚本，每行对应一个镜头或段落；
  - 重点是把卖点与口播文案写清楚，并给出时长与是否有 CTA，而不是只生成纯画面分镜图。
- 不适用场景：
  - 用户只想要多宫格分镜图做视觉参考，而不关心具体脚本字段 → 更适合“产品讲解分镜图”或其他分镜模板；
  - 需求是完整广告镜头语言（景别/运镜/时长），并非口播脚本为主 → 可归为“广告 TVC 镜头表”；
  - 需要的是长篇品牌文案或文稿，不打算制作视频 → 更适合文案撰写流程，而非分镜/脚本表模板。

## 3. 分镜结构建议
- **推荐镜头数**：8–20 行脚本，常见视频时长 15/30/60 秒，视卖点数量与节奏而定。
- **表格字段建议**：
  1. 镜号：C1、C2… 或 S1、S2…，按时间顺序排列；
  2. 画面描述：简短写画面内容、景别与主体动作；
  3. 卖点/信息：本镜要讲的核心卖点或信息点；
  4. 口播文案：主播或旁白的具体文案（短句）；
  5. 预估时长：该镜头或该句话的时长（秒数范围）；
  6. CTA：是否包含 CTA，以及 CTA 具体文案（如“戳下方链接”“马上加入会员”等）。
- **结构骨架**：
  - 开场 1–2 镜：引入场景/人群与痛点或需求；
  - 中段若干镜：逐镜展开产品卖点或选品理由；
  - 社会证明/体验段：展示使用感受或用户评价；
  - 收尾 1–2 镜：强化优惠/稀缺感 + 明确 CTA。
- **规划方式**：
  - 先列出所有需覆盖的卖点与信息段，再根据目标时长估算每个段落的时长与镜头数；
  - 将表格视为执行脚本：用简洁可读的短句，避免一个镜头塞过多卖点和长文案；
  - 时长估算可参考 storyboard/dialogue-rules.md 中的口播耗时建议，避免“说不完”的问题。

## 4. 生图 Prompt（PE）模板

```text
你是一名电商带货导演兼文案策划，请为下述 {产品/选品组合名称} 设计一份“营销脚本表格”（用途类型 = 营销脚本表格），并可选生成对应多宫格分镜参考。整体目标时长为 {目标时长秒数} 秒，主要投放场景为 {投放平台与广告类型，如“抖音信息流带货”“电商详情页讲解视频”等}。

【产品与项目基本信息】
- 品类与产品名称：{如“厨房收纳套装”“护肤三件套”“手机新品发布”等}
- 选品结构：{单品/多品合集，简要说明每件产品角色}
- 核心受众：{如“新手妈妈/租房打工人/科技发烧友”等}
- 核心诉求：{用户想解决的问题或达到的目的，如“省时省力”“提升颜值”“提高效率”等}

【卖点与信息规划】
- 卖点列表：{列出 3–8 个核心卖点或信息点，按优先级排序}
- 社会证明素材：{如用户好评/真实体验/权威背书等}
- 优惠与活动信息：{如满减/限时价/赠品/会员权益等}
- CTA 语句备选：{2–4 条 CTA 文案，如“点下方链接立即入手”“把这条收藏起来”等}

【脚本表格输出配置】
- 推荐镜头数：{镜头数，如 10–15 镜}，按 C1–C{N} 编号。
- 表格字段：镜号、画面描述、卖点/信息、口播文案、预估时长（秒）、CTA（有/无及文案）。
- 若需要分镜图参考：在每行脚本旁附一行“画面分镜说明”，用于后续生图。

【脚本表格输出要求】
请先以纯文字列表形式给出完整脚本表格，按以下格式逐行输出：
1. 镜号：C1
   - 画面描述：{如“中近景，主播坐在桌前，桌面摆放产品”}
   - 卖点/信息：{该镜要讲的核心信息，如“解决早晨收纳混乱问题”}
   - 口播文案：{完整一句口播，如“每天早上找东西很抓狂？先从桌面收纳开始。”}
   - 预估时长：{如“3–4 秒”}
   - CTA：{有/无 + CTA 文案，如“先看完再决定要不要入手”}
2. 镜号：C2
   - 画面描述：{下一镜画面与动作}
   - 卖点/信息：{对应卖点}
   - 口播文案：{对应口播}
   - 预估时长：{秒数范围}
   - CTA：{有/无}
……
直到镜号 C{N}，确保开场、中段卖点展开、社会证明和收尾 CTA结构完整。

【可选：分镜图生成】
- 若需根据脚本表生成分镜图，请在脚本表中每行额外添加“分镜图说明”字段，简要描述该镜对应的单格分镜画面（景别 + 主体动作 + 场景），以便后续按 storyboard-sheet-prompt.md 中“产品讲解分镜图”模板生成图像分镜。
```

## 5. 一致性与避坑
- 一个镜头只承载一个核心卖点或信息，避免在同一行脚本中塞入多个卖点和复杂口播，导致信息无法被观众完整接收。
- 口播文案要与画面描述严格对应，避免出现“画面已经展示效果，但口播还在讲痛点”的错位；必要时调整镜头顺序而不是硬挤文案。
- 预估时长必须合理：长句文案需要更长时长，短句则不宜占用过多时间。可参考 storyboard/dialogue-rules.md 的耗时建议，对长句进行拆分。
- CTA 不宜出现在每一镜，避免观众产生抗拒；建议集中在开头暗示与结尾明确呼吁，中段以卖点解释和体验为主。
- 脚本表格中的称呼、价格、活动信息等需跨行统一（同一产品名称与价格不要前后不一致），并根据投放平台规范避免敏感或夸大表述。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”“广告 TVC 镜头表”营销执行模板：
  - 营销脚本表格可以作为文字骨架，先用本模板拆出镜号、画面描述、卖点与口播，再根据项目需求选择是否进一步生成分镜图（按产品讲解分镜图模板）或镜头表（按广告 TVC 模板）；
  - 视频 Prompt 编写时直接引用脚本表格内容，将每一镜的画面描述与口播文案映射到对应时间段。
- 视频生成流程建议：
  - 先根据脚本表格生成多宫格或单镜分镜图，锁定画面结构与产品位置；
  - 再按脚本表格的时间轴调用 sandbox_generate_video，将每一镜的时长和口播文案作为约束，必要时使用 count_chars 工具校验口播可否在对应时长内说完。
- 模型选择建议：探索阶段使用 seedance_2.0_fast 快速验证节奏与画面结构，定稿阶段可根据画面复杂度和还原要求选择 seedance2.0_fast_vision 或 seedance2.0_direct。
- 在剪辑与拼接阶段，确保最终视频的镜头顺序与脚本表格完全一致，避免后期随意删改镜头导致卖点缺失或 CTA 被削弱；所有字幕与价格信息由脚本或后期叠加，不在图像生成阶段直接绘制长文本。
