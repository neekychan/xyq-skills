# 营销视频复刻

用户提供了一条参考营销视频要复刻：先打版反解，再**按打版报告判定生产路线**——

- **路线 A 关键帧驱动（默认，口播类）**：不拿原视频的画面片段做参考，把每个分镜的关键帧截出来、按需替换人物与商品，以关键帧为首帧/画面锚点逐段生成视频。适合口播讲解为主、分镜规整的种草带货片。
- **路线 B 参考视频驱动（动作/运镜/卡点类）**：画面的运动、节奏、镜头语言是原片创意本体时，关键帧锚不住它们——切段后的原片直接作为生成参考（VideoList），画面运动感、BGM 与卡点节奏从原片一体继承；角色/商品替换走图像指代；音乐版权撞墙的段才降级静音参考 + render 混回。适合变装、舞蹈、卡点、强运镜、快切类片子。

每一步的产物都是下一步的输入，不要跳步；路线判定在打版后立即做，选定后全程只走一条路线，不混用。

# 第一步：取得参考视频

用户直接上传视频或提供任务内视频素材时，直接使用，不调用链接解析工具。

用户提供完整 URL、但当前还没有对应的 sandbox 视频路径时，必须调用 `pippit_video_tool_share_url_parser_sandbox`：

- 可以解析 `https://...` 视频地址或社交媒体分享链接；
- 不解析 `./upload/video.mp4`、`/path/video.mp4` 等本地路径；
- 不解析不完整链接、分享口令中的普通文字或素材占位符。

链接解析后，只使用工具返回的 sandbox 视频路径作为参考视频。`pippit_omni_search` 原始结果中的 `asset_id`、`pippit_asset_id`、`vid` 或远程 `video_url` 都不是 sandbox 路径，不能填入反解工具的 `InputPath`；此前调用过搜索工具但仍未取得真实 sandbox 路径时，继续完成本步骤。当前请求存在多个可能的参考视频且用户没有说明主视频时，让用户指定一个，不自行选择。

## 第二步：反解参考视频（视频打版）

调用 `marketing_video_templating`，把用户的参考视频路径传给 `VideoPath`。工具产出《爆款分析报告》写入 `assets/marketing/爆款分析报告_{视频相关信息}.md`，包含角色表、逐分镜时间线（起止时间、说话角色、逐字口播、语速、情绪、音色、画面描述）、叙事结构链。**每个分镜的起始时间就是该分镜的关键帧时间点**。

- 打版只需做一次；同一个视频已有打版报告时直接复用，不要重复调用。

## 第三步：路线判定（必做，打版后立即执行）

从打版报告提取三个判定输入：

1. **口播覆盖率** = 有台词分镜的时长合计 ÷ 全片时长（角色表写明全片无说话角色时为 0）；
2. **平均每镜时长** = 全片时长 ÷ 分镜数；
3. **动作/运镜/卡点信号**：逐分镜「画面描述」或报告结论中出现卡点、变装、舞蹈、转身换装、快切、一镜到底、运镜（推/拉/摇/移/跟/环绕）等描述，或报告「视频类型」判定为视觉展示/变装/舞蹈/卡点类。

判定规则：

- 命中动作/运镜/卡点信号，**或**平均每镜时长 < 2 秒（快切），**或**口播覆盖率 < 30% 且画面主体是动作与视觉变化而非讲解 → **路线 B**；
- 否则（口播讲解为主、分镜规整、画面服务口播）→ **路线 A（默认）**；
- 拿不准一律走 A；用户明确要求「动作/运镜/卡点要和原片一样」时直接走 B；
- 报告显示原片是测评/买家秀/探店实拍、核心价值在真实素材信任感时，先告知用户「这类片子的说服力来自真实素材，AI 重绘画面可能降转化，建议只复刻脚本结构、画面实拍」，用户仍要求生成再走 A。

把判定结论写进 creative_design.md 开头：选定路线、三个指标的数值、命中的信号、一句话理由。后续所有步骤按选定路线执行。

## 第四步：收集用户的产品信息

确认用户需要的产品卖点、产品图片（有就带上）、额外要求（换什么人、换什么商品、时长等，使用什么脚本）。产品卖点完全没给且无法从上下文推断时，一次性向用户问清，不要分多轮挤牙膏，也不要编造卖点。**用户没要求换人物或换商品时，对应的关键帧/画面不做替换。**

## 第五步：生成口播脚本

调用 `marketing_voiceover_script`：`analysis_doc` 传打版报告路径，`selling_points` 传用户卖点原文，`extra_requirements` 传额外要求原文（需要什对话内容等），`ImagePaths` 传产品图路径列表。产出口播脚本写入 `assets/marketing/{product_name}/{yyyy-mm-dd}_{seling_point}_口播脚本.md`，每个分镜带「角色」字段。

- 路线 B 且用户不要求改口播/文案时跳过本步，口播直接沿用原片台词。

# 路线 A：关键帧驱动（口播类默认路线）

## A1 素材原料生产

生成的视频**不使用参考视频的画面片段**（生视频时 `VideoList` 不传原片分段），画面一律以编辑后的关键帧为首帧驱动：

1. **截关键帧**：按打版报告每个分镜的起始时间，从参考视频截取分镜起始关键帧处的画面：
   `ffmpeg -ss {分镜起始时间} -i 参考视频.mp4 -frames:v 1 -q:v 2 assets/marketing/keyframe_{分镜序号}.png`
   每个分镜一张，与分镜一一对应。
2. **关键帧净化（必做，先于替换）**：截出的每张关键帧先用图片编辑能力抹掉原片烙在画面上的平台水印——抖音图标、抖音号、二维码、「抖音搜索」栏等平台标识一律抹除，无论该帧后面要不要换角色/商品都要做。首帧净化了，生视频链路就**无需再为水印加任何提示**；打版和口播脚本的各字段也不把平台水印当作要复刻的画面元素，一律忽略不写。
3. **角色与商品替换（生图能力，按需）**：对照用户要求与角色表逐张处理——
   - 用户要求换讲解人：用图片编辑/生成能力把关键帧中的人物替换为该分镜说话角色的锚定形象（角色形象参考图与音色锚定音频的生成和复刻路线一致——每角色只做一次，全片复用）；
   - 使用图片编辑/生成能力时，需要使用`sandbox_read`工具读取每张图片的caption，来确定是否图片里有需要替换的人物/参考图。不要凭空根据打版信息臆断。
   - 如果出现多角色要把握好角色对应关系，不要所有角色都变成一个人物。
   - 用户要求换商品：把关键帧中的商品替换为用户产品（参考用户产品图编辑）某些商品与原图可能差别过大，比如圆形改为方形，需要根据用户实际提供商品做合理的关键帧参考生成。；
   - 不需要替换的关键帧原样保留，不要为换而换；
   - 处理后的图仍按 `keyframe_{分镜序号}.png` 命名，在 creative_design.md 素材绑定表里逐分镜记录用的是哪张。
5. **音色锚定**：
   - 首先判断**是否需要分多段视频生产**，如果一次即可生成完整视频则不需要此步骤，如果需要多段视频生产则需要此步骤。
   - 如果需要进行音色锚定时，每个出声角色调用一次 `sandbox_generate_audio` 生成一小段锚定音频，需要使用 seedaudio_1.0 音频模型， `assets/marketing/voice_{角色编号}.mp3`，全片复用——音频只是生视频时的音色参考，不合成到成片。
6. **提取原片音轨（BGM 原料，必做）**：复刻成片的 BGM 默认继承原片，口径对齐视频复刻链路的音频安审处理——生成阶段全程不拿原片音轨做参考（避免原片音乐/人声进生成触发音乐版权拦截），原片音轨只在最终 `render_video` 阶段混回一次。先用 `ffprobe` 确认原片含音轨，有则提取：
   `ffmpeg -i 参考视频.mp4 -vn -af volume=0.2 -c:a libmp3lame -q:a 4 assets/marketing/original_bgm.mp3`
   必须低音量预处理：原片音轨里含原口播人声，全音量混入会盖过新口播，只作氛围底。只提取一次，全片复用；原片无音轨、用户自带 BGM 或明确不要 BGM 时跳过本步骤（用户自带 BGM 时改用用户素材路径）。

## A2 关键帧驱动逐段生视频

**每段调用 `sandbox_generate_video` 之前，先逐项过一遍自查清单，任一项不满足就先补齐再生成：**

1. 该段的 `ImageList` 传的是**编辑后**关键帧（已净化水印、已按需完成角色/商品替换），不是原片直接截图；段内多镜时关键帧按分镜顺序传；
2. 替换范围与用户要求一致：要求换的角色/商品都已换，没要求换的一张没动；多角色时角色↔形象图↔锚定音频的对应关系没串；
3. 该段有台词时 `AudioList` 已传对应角色的锚定音频，且全片同一角色用的是同一段；
4. `VideoList` 为空（路线 A 任何情况下都不传）；
5. prompt 四要素齐全：分镜规划（每镜的画面动作、景别构图、产品露出、谁说了什么、画面切换）＋「不要任何字幕/标题/文字贴纸」＋「去除抖音图标/抖音号/平台水印/二维码」＋「不要生成背景音乐」；
6. `Duration` 落在模型单段上下限内、与该段分镜时长合计一致（±1~2 秒弹性）；
7. `assets/marketing/original_bgm.mp3` 已按 A1 第 6 步备妥（或已确认跳过），render 阶段要用。

- **先 `load_skill` 加载 `video_creation` 技能**：拆段策略、当前模型的单段时长上下限和生视频参数口径都以它为准；按分镜顺序依次累积分镜时长拆成生成段，加上下一镜会超过单段上限就切段。它自带的确认门/表单流程不适用于本路线，读到策略即可，逐段生成按下面执行，不要中途停下来等确认。
- 按拆好的生成段逐段生成。段内有多个分镜时，用各分镜的编辑后关键帧依次作为画面锚点；每次 `sandbox_generate_video` 调用：
  - `ImageList`：传该段各分镜的编辑后关键帧图作为首帧/画面锚点（多镜段按分镜顺序传，需要时再叠加角色形象图、用户商品图做指代）；
  - `AudioList`：该段有台词时传对应角色的锚定音频，prompt 里明确「{角色身份}用参考音频的音色说：{该段口播文案}」；
  - **`VideoList` 一律不传**——画面以关键帧为首帧驱动，动作按口播脚本与打版报告的分镜规划描绘生成；
  - `Duration` 按该段时长取值，单段上限以 `video_creation` 的模型策略为准（不写死）；落在上下限内即可，允许 ±1~2 秒弹性，不为凑整秒返工；
  - **严禁添加任何字幕**：生视频 prompt 里必须显式写明「画面不要生成任何字幕、标题或文字贴纸」——即使原片或关键帧图上自带字幕也不能继承到生成画面里；字幕只在生视频全部完成后的 `render_video` 渲染阶段酌情添加（按口播脚本各分镜的口播字段配字幕），不要在生视频阶段处理；
  - **去掉平台水印**：复刻成品不能带原片的平台标识——生视频 prompt 里必须显式写明「忽略并去除画面中的抖音图标、抖音号、平台水印和二维码，不要保留或生成任何平台标识」，即使关键帧图上带着也要在生成画面里去掉；
  - 同一角色跨段始终使用同一张形象图 + 同一段锚定音频；
  - **不要生成背景音乐**：生视频 prompt 里显式写明「不要生成任何背景音乐，只保留人声台词与必要的环境音」——BGM 统一在 render 阶段混入原片音轨，避免成片叠两层音乐。
- 全部完成后用 `render_video` 按段顺序拼接，并把 A1 提取的 `assets/marketing/original_bgm.mp3` 传给 `bgm_audio_path`——原片音轨只在这里混回一次，任何生视频调用都不得携带原片音频；用户自带 BGM 时传用户素材路径，A1 已跳过则不传该参数。**字幕只在这个阶段酌情添加**（按口播脚本各分镜的口播字段配字幕），生视频阶段不加任何字幕。最终交付物 = 成片 + 全部编辑后关键帧。
- [IMPORTANT] **关键帧只是首帧/画面锚点，走到视频生成 prompt 时仍然需要把分镜规划写清楚：每个分镜的画面动作、景别构图、产品露出方式、某个角色（旁白）说了什么、画面有什么切换，都要在 prompt 里说明白**

# 路线 B：参考视频驱动（动作/运镜/卡点类）

原则：**画面的运动、节奏、镜头语言从原片继承**——原片切段后作为生成参考（VideoList），不做逐镜关键帧替换；角色/商品替换走图像指代。音轨口径对齐视频复刻链路：**默认保留原片音轨进参考**（BGM、卡点节奏随之继承进生成，这正是路线 B 要的），只有音乐版权撞墙的段才降级为静音参考、render 阶段把原片音轨混回一次。

## B1 切段与参考分段（整片优先，最少段数）

- 先 `load_skill` 加载 `video_creation` 技能，只为确认当前模型的**单段时长上限**；它自带的按分镜拆段策略不适用于本路线。
- [IMPORTANT] **切段单位是整片，不是打版分镜**：先拿原片总时长和模型单段上限比较——总时长 ≤ 上限，**全片只切 1 段、一次生成**（例如模型能生成 15s，13 秒的原片就一整段生成，绝不允许切成 2~3 段）；总时长 > 上限才切段，段数取「总时长 ÷ 上限」向上取整的**最小值**，每段时长尽量顶满上限，切点落在分镜边界上。**段数越少效果越好，单段装得下就绝不分段。**
- 每个生成段从原片切出对应时间段，**默认保留原片音轨**，作为该段的参考视频：
  `ffmpeg -ss {段起始} -to {段结束} -i 参考视频.mp4 -c:v libx264 -crf 18 -preset fast -c:a aac assets/marketing/ref_seg{段号}.mp4`
- 换口播的场景（AudioList 会传新锚定音频）：prompt 里必须写明「参考视频只参考画面与音乐节奏，忽略并不要复刻其中的人声台词」；若生成结果串入了原片人声，该段改用静音参考重新生成（静音副本做法见 B3 版权拦截处理）。

## B2 角色与商品替换（图像指代，不逐镜重绘）

- 用户要求换人/换商品时：用图片编辑/生成能力为每个新角色出 1 张形象锚定图、为用户产品出 1 张商品图（每角色/每商品只做一次，全片复用），不做逐分镜关键帧替换；
- 需要音色锚定时口径同 A1 第 5 步（每角色一段 `voice_{角色编号}.mp3`，全片复用）；
- 用户不要求替换时本步跳过。

## B3 参考驱动逐段生视频

**每段调用 `sandbox_generate_video` 之前，先逐项过一遍自查清单，任一项不满足就先补齐再生成：**

1. 段数合规：原片总时长 ≤ 模型单段上限时全片只有 1 段；超上限时段数 =「总时长 ÷ 上限」向上取整的最小值、每段顶满上限——发现自己在逐分镜切段就是错了，回 B1 重切；
2. 该段 `VideoList` 传的参考分段时间段与原片对应区间一致（没切错位置、没漏段）；默认带原片音轨，只有该段撞过音乐版权拦截或串入原片人声时才用 `_silent` 静音版；
3. 有替换时 `ImageList` 已传角色形象图/商品图，prompt 里「@图片N」指代与图片顺序一一对应；多角色时角色↔形象图↔锚定音频没串；
4. 换口播的段：`AudioList` 已传对应角色锚定音频，且 prompt 含「参考视频只参考画面与音乐节奏，忽略并不要复刻其中的人声台词」；沿用原片口播的段 `AudioList` 为空；
5. prompt 要素齐全：「画面动作、节奏、运镜、景别变化严格跟随@视频1，背景音乐与卡点节奏跟随@视频1」＋「不要任何字幕/标题/文字贴纸」＋「去除抖音图标/抖音号/平台水印/二维码」；
6. `Duration` 与该段参考分段时长一致（±1~2 秒弹性），不超出模型单段上限；
7. 重试纪律：音乐版权拦截才允许降级静音重试一次，仍被拒只许再去掉 BGM 描述试一次；已走静音路径的段已记录（B4 混回要用）。

每次 `sandbox_generate_video` 调用：

- `VideoList`：传该段的参考分段 `ref_seg{N}.mp4`（默认带原片音轨），prompt 写明「画面动作、节奏、运镜、景别变化严格跟随@视频1，背景音乐与卡点节奏跟随@视频1」；
- `ImageList`：有替换时传角色形象图/商品图，prompt 写明「画面中的人物替换为@图片N 的形象，动作与穿着节奏跟随参考视频」「商品替换为@图片M 的产品」；
- `AudioList`：该段台词要换口播时传对应角色锚定音频，prompt 明确「{角色身份}用参考音频的音色说：{该段口播文案}」；沿用原片口播则不传（原口播随参考音轨继承）；
- `Duration` 按该段时长取值，允许 ±1~2 秒弹性；
- prompt 必须显式写明「画面不要生成任何字幕、标题或文字贴纸」「忽略并去除画面中的抖音图标、抖音号、平台水印和二维码」；
- **音乐版权拦截处理（撞墙才降级）**：生视频返回音乐版权类拒绝时，给该段参考做静音副本并验证无音轨，其它参数完全不变、用静音参考重试**一次**：
  `ffmpeg -i assets/marketing/ref_seg{N}.mp4 -an -c:v copy assets/marketing/ref_seg{N}_silent.mp4`
  并用 `ffprobe` 确认静音副本无音轨。仍被拒则去掉 prompt 里「背景音乐/卡点跟随参考」相关描述再试一次。不得反复重试。**记录哪些段走了静音路径**，B4 混回要用。

## B4 渲染合成

全部段落完成后用 `render_video` 按段顺序拼接。原片音轨是否混回、怎么混，按 B3 的实际路径决定：

- 所有段都带音轨参考一次通过 → 生成段已自带继承的 BGM/原声，**直接拼接，不传 `bgm_audio_path`**（再混一遍等于叠两层音乐）；
- 有段走了静音路径 → 提取原片音轨（命令同 A1 第 6 步）传给 `bgm_audio_path` 混回一次，音量按口播策略：沿用原片口播/原声是内容主体 → 不压音量（去掉 `volume=0.2`）；换了新口播或只有部分段走静音 → 保持 `volume=0.2` 低音量，避免盖过新口播、也避免在已继承 BGM 的段落上叠太响。

字幕只在这个阶段酌情添加。最终交付物 = 成片。

## 边界

- 打版和口播两个工具只做分析反解与文案，不生成画面；画面生成永远在路线 A 的 A2 或路线 B 的 B3。
- 原片音轨的使用按路线区分：路线 A 任何生成环节都不得携带原片音轨，只允许在 `render_video` 阶段以 `bgm_audio_path` 混回一次；路线 B 默认允许参考分段带原片音轨（BGM/卡点节奏随参考继承），仅在音乐版权拦截或串入原片人声时对该段降级静音参考，并由 render 阶段混回兜底。
- 两条路线不混用：路线 A 的 `VideoList` 一律不传、逐镜截关键帧做首帧驱动；路线 B 不截关键帧、不做逐镜替换，画面参考只走 `VideoList` 原片分段。
- 禁止向用户提及A路线，B路线，输出要用用户可懂的语言，禁止提及内部策略。
