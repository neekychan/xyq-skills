# 音乐 MV

用户教程：[小云雀音乐 MV 教程｜从一首歌到一支成片](https://bytedance.larkoffice.com/docx/C9ZbdUfqwozkjlxWBKuc0f1En2d)。链接仅供用户自行查看，不得访问或抓取。

## 用途与入口

以音乐为核心，通过 Agent 分析节奏、歌词、情绪和歌曲结构，形成创意方案、故事线、分镜脚本与逐镜提示词，再生成和精修视频。Agent 对话流适合首次制作；画布适合逐镜修改、素材管理、多版本尝试与批量制作。

在 Web 创作输入框点击【技能】，进入技能商店，选择左侧【音乐MV】分类，点击对应技能卡片的【使用】。可选卡片包括【电影叙事 MV片段】【Live 现场演唱 MV】【K-pop 团体舞蹈MV】【音乐MV分镜创作】【视觉概念MV片段】【说唱表演MV片段】。

## 准备与选择音乐

- 准备 mp3 或 wav 音乐，优先选择段落清楚、情绪变化明显的版本。
- 输入框左下角【+】→【本地上传】添加音频，并说明“使用这首歌制作音乐 MV”。也可在对话中检索并选择平台可用歌曲；核对歌曲及版本，识别错误时重新指定音源。
- 也可在画布使用音频模型生成音乐；教程示例使用 Seed Audio 1.0。示例中的 30 秒是创作需求，不是全部音乐或 MV 的时长上限。
- 若当前入口没有上传按钮，使用平台可用音源或切到画布入口。不能保证任意歌曲都可检索到。
- 人物或主体可以用文字设定，也可提供人物图、艺人素材、商品图、视觉参考。提前确定横屏或竖屏及发布渠道。

建议先输入：“使用这首歌制作音乐 MV。先分析节奏、歌词、情绪及主歌、副歌、桥段结构，给我三个视觉方向，暂时不要生成视频。”确认 Agent 使用了正确音源并返回音乐摘要或段落结构后继续。

## 确定方向

| 方向 | 适合内容与描述重点 |
| --- | --- |
| 剧情 MV / 电影叙事 | 抒情、叙事、独立音乐；明确故事与情绪变化 |
| K-POP 舞蹈 / 女团打歌 | 快歌、团体舞台；明确成员造型、队形和副歌齐舞 |
| 演奏风 / Live | 器乐、乐队、Live House；突出鼓点、吉他段落和现场表演 |
| 说唱表演 | Rap、Hip-Hop、街头；明确表演场景、运镜和重拍切镜 |
| CG / 视觉概念 | 电子乐、视觉专辑、Teaser；明确材质、空间和视觉高潮 |
| 对口型演唱 | 艺人、数字人、单人演唱；明确人物一致性、情绪和口型表现 |

描述公式：MV 类型 + 主体 + 场景或世界观 + 色彩质感 + 副歌动作或视觉高潮 + 横竖画幅。方向分类不代表每种方向都有同名独立按钮。

示例需求：“制作竖屏 K-POP MV，五人虚拟女团，统一黑银造型；主歌在镜面练习室，副歌进入灯光舞台齐舞，桥段用低饱和近景。先输出音乐分析、创意和分镜让我确认。”这是提示词示例，不是人数、画幅或效果保证。

## 检查创意与分镜

先审分镜，再生成视频。检查以下四点：

1. 歌曲结构：主歌铺陈、副歌升级、桥段反转或留白，每镜对应具体音乐段落。
2. 节奏卡点：转场、动作落点、景别切换对齐重拍，避免平均切镜。
3. 人物一致：逐镜复用身份、服装、发型与视觉标记，有参考素材时明确约束。
4. 视觉递进：高潮增加动作幅度、运镜或场景信息量，避免只加快切镜。

逐镜提示词公式：主体一致性 + 动作 + 场景 + 景别与运镜 + 光线色彩 + 情绪 + 节奏点 + 画幅。

可要求 Agent 先检查人物是否一致、镜头是否重复、副歌是否有视觉高潮、转场是否卡重拍，修正后再生成。

预期中间产物：音乐分析标出主歌、副歌、桥段、高潮和重拍；创意方案说明主题、人物、世界观、色彩、镜头语言与画幅；分镜脚本逐镜列出时间段、主体、动作、景别、运镜和转场；逐镜提示词保持人物及美术设定一致。

## 生成、精修与导出

1. 确认分镜后先测试关键段落，优先试副歌或较难的舞蹈、演奏、对口型镜头。
2. 效果合适再扩展成片。失败镜头局部重生，保留已经通过的镜头。
3. 每次调整人物、动作、运镜、光线中的一至两项，便于判断改善原因。
4. 在画布调整镜头顺序、裁剪片段、修改字幕、替换素材、提高清晰度。多轨剪辑操作见[画布与故事板多轨编辑](multitrack.md)。
5. 导出前检查画幅、分辨率、字幕安全区、音画同步和目标平台要求；重拍有明确落点，人物造型一致，口型、舞蹈与演奏无明显错位，字幕不挡脸和关键动作。

教程没有提供完整导出按钮路径、音频大小上限、MV 总时长上限或统一收费标准；相关问题不要从示例推断。积分问题查[积分与权益 FAQ](credits-benefits-faq.md)。

## 常见问题

- **人物越生成越不像？** 固定身份、发型、服装、脸部特征与标志性配饰，每个相关镜头复用；有参考图时可明确“人物参考只约束身份与造型”。
- **卡点不明显？** 要求标出重拍和副歌第一拍，把切镜、动作落点、灯光变化分别绑定具体拍点，不只写“节奏感强”。
- **镜头像素材拼盘？** 先选一个贯穿元素，例如镜子、红线或银色舞台，让它在主歌、桥段、副歌中以不同形态出现。
- **动作变形？** 减少单镜动作复杂度，一个镜头只安排一个核心动作；舞蹈、演奏先做短段测试。
- **不满意必须整条重做吗？** 先定位人物、动作、运镜或美术问题，在画布局部修改对应逐镜提示词并重生，保留其余镜头。
- **怎么做多个版本？** 在画布同屏管理音频、歌词、创意、分镜、参考素材和成片；复制已验证分镜结构，替换风格或人物；保留母版分镜，为横屏、竖屏、Teaser、完整版建立独立分支。
