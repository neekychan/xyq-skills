# 风格契约与视觉知识库

所有题材共享以下视觉标准。题材、时代、职业、物件和台词从剧本与 [跨题材制作规则](genre-adaptation.md) 取得。第一份来源中的 3.1—3.4 全文另存于 [原始风格描写](style-source-knowledge.md)，供核对与按题材选词。

## 风格锚定词

```text
国漫3D渲染风格，高清3D渲染，高亮、低对比、轻雾化、柔光滤镜效果，高精度三维建模，细腻渲染，东方奇幻动画美术风格。
```

每条完整图片/视频正向 prompt 从第一个字符起逐字写入此句一次，正文紧随其后。场景图、道具图、图像编辑、风格转化、关键帧、重试和视频延长均适用。不能翻译、改序、删字，也不能用“同上”或变量名替代实际提交的前缀。镜号与图片引用标记放在前缀后或独立参数字段。

“东方奇幻动画美术风格”保留原文，定义东方动画的美术与渲染气质。现代、科幻、历史、架空世界都可采用这一视觉表现；正文紧接项目时代与实际内容，不能由前缀自动推断仙侠剧情、古装或法术。

## 参考输入的职责边界

| 输入类型 | 是否使用 | 用途与限制 |
|---|---|---|
| 内置风格图、平台默认风格底图、外部风格样例 | 禁止主动使用 | 不以默认注入、风格加强或一致性为名混入 |
| 用户明确提供的角色/服饰/道具/场景图 | 可用 | 提取身份、物件、结构、布局；非本风格先转化渲染，保留世界观与内容 |
| 本项目已验收的角色/造型/道具图 | 可用 | 锁定身份、造型和物件状态 |
| 已验收场景四视图或单向图 | 可用 | 锁定地标、材质和布局，展示板构图不进入视频 |
| 本项目合格视频截帧 | 可用 | 经四层过滤用于空间、状态和动作连续性 |
| 外部新搜集的参考图 | 不主动引入 | 只在用户明确指定内容参考任务时使用，不自行搜风格图 |

图片和视频的风格输入来源为固定文本锚定词及与之兼容的具体画面描写。参考图只承担内容职责，逐张登记来源与 identity、costume、layout、prop、continuity 或 keyframe 用途。已有资产可以锁定内容，也必须视觉验收其渲染是否合格；不能只改用途标签就声称消除了图像风格影响。

工具的默认风格图注入须关闭或绕过；强制注入且无法关闭时，说明该工具不满足本风格约束，在已有授权内采用可满足条件的工具或交付完成的制作资料。不得谎报符合。

## 整体风格气质

保留第一份的核心体系：**东方审美叙事 + 高精度三维建模 + 动画化渲染表现**。追求比现实更凝练、唯美、有戏剧表现力的视觉真实。

| 气质维度 | 执行描述 |
|---|---|
| 东方审美与幻想气质 | 用意境、气韵、留白和轮廓节奏组织画面；空灵、尊贵、宿命感按故事需要选取；无需添加古代物件 |
| 影视级 CG 感 | 模型、材质、灯光、特效精致完整，具有渲染完成图的细节与空间层次 |
| 角色美型化 | 五官、脸型、体态经过动画审美强化，清冷、英气、温润、威仪、灵动等由人物身份决定 |
| 半写实半风格化 | 保留动画角色的轮廓控制、皮肤柔化和情绪强化，不用纯真人摄影或二维平涂替代 |

光影保留**高亮、低对比**：画面清透，高光过渡柔和，阴影不死黑。**轻雾化**强化纵深，**柔光滤镜**让边缘与高光轻微泛光，温润而不过曝；不能变成灰雾遮脸或失去材质细节。

冷调可用青银、月白、霜蓝；暖调可用琥珀、烛光橙、流霞金；奇幻调可用紫黑、深青、星河银紫。这些是配色选择，不要求每镜使用全部颜色。都市玻璃、金属设备、未来舱室也沿用这套柔和光影与配色关系。

## 角色造型与材质

- **面部**：脸型线条流畅、下颌清晰但不过硬；鹅蛋脸、心形脸、修长脸、清隽骨相都是可选造型。眼睛比真人略大而不夸张，重视眼型流线、精细睫毛、瞳孔高光；鼻梁与鼻头清晰，唇轮廓明确、色泽柔润。保持年龄、性别表达、族群特征和个体识别，不锁成同一张幼态 V 脸。
- **皮肤**：细腻、半透明的陶瓷/玉肌质感，柔和次表面散射（SSS），高光精准不过油。不追求过度写实毛孔，不以恐惧或愤怒改变皮肤底色。无特殊设定可用暖白底色；已有不同肤色或非人角色设定须保留，统一的是渲染和光照体系。
- **头发**：精细发束与飘逸感并存，受光有丝绸反光。长发束冠、发髻、半披半束用于相应设定；现代短发、马尾、卷发及未来发型同样用精细发束表现。运动幅度遵循发长、动作和环境，不让室内短发无故飘飞。
- **服饰**：保留 2—3 色主调、同色系深浅层次及清晰材质差异。丝绸柔软垂坠、薄纱半透、金属刺绣细密、皮革哑光；现代棉布/针织表现织纹与缝线，科幻复合材料/金属表现结构与柔和反射。汉服、仙袍、轻甲、道袍、宫装仅在合适题材使用。
- **配饰与道具**：玉石半透、金属反射、宝石透光、木材纹理等体现精度；手机玻璃、塑料外壳、电子设备也可细腻渲染。“避免塑料玩偶质感”不等于禁止物件的真实塑料材质。
- **体态与气场**：保留有控制的肩腰比例、动作轮廓与清冷、温润、英气、灵动等表现；年龄、职业和功能决定体型。负手、持剑、衣袂飘动只适用于相应人物，普通日常角色依其行为设计。

## 场景环境与光源

建筑与空间首先遵守剧本设定。古典飞檐斗拱、廊柱、石阶、朱门，或悬浮岛、云端宫殿是对应题材的词库；都市公寓、街道、校园、办公室、舱室使用自己的结构和地标，保持高精度建模、细腻材质与东方动画构图。

青石可湿润反光，木构有细腻木纹，瓦面釉光柔和；玻璃、涂料、混凝土、金属接缝也按实际结构描述。高制作精度不要求每个空间华丽，寒舍、社区小店、宿舍与工业舱室均可朴素可信。

自然环境保留竹林透光、梅花雪景、桃花轻雾、苍松轮廓、镜面湖水、瀑布白雾、清溪涟漪、云海/星河/晨雾/暮光等表现。花瓣、雨丝、尘埃可按场景使用；灵气、剑气、法阵、符文必须有世界观依据，不能出现在普通校园或办公室充当默认装饰。

场景剧情主光可用柔和侧逆光勾勒体积，环境光用柔和漫反射保持清透。现代窗光、灯具、仪表屏，古代烛火，奇幻光效均登记为**世界坐标中的光源**。机位变化后重算其屏幕位置，不能为了“光影一致”让物理光源绕人移动。

## 叙事、情绪与镜头

保留宏大与细腻并存、动作/眼神/环境烘托情感、节奏有层次的原则。含蓄有力可通过停顿、视线转移、收紧手指表达，激烈动作也要有剧情原因；喜剧与动作类型可扩大表演，不能每句台词机械爆发。

分镜先写**画面构成（主体+环境+光线）**，再写**动态与情绪**。远景俯瞰用于展势，中景定人，近景侧逆光塑神，特写眼神传情，跟拍追势；景别服务戏剧职责。

第一份中的古典雅致台词、文言句式、意象旁白保留为古风/神话表达选项。现代都市、校园、家庭使用人物自己的自然口语；科幻设定词来自故事，不自动改为修仙话术。具体选择见 [跨题材制作规则](genre-adaptation.md)。

## 特殊情况与提交检查

1. **夜景/悬疑/末世**：以霜蓝、深青、局部暖光和层次清晰的暗部表现时段；用遮挡、负空间、距离、视线和声音营造压力。固定锚定词完整不变，保持可读阴影，不用死黑和高反差硬光替换主风格。
2. **设定板**：柔和均匀展示光，轻雾和柔光不遮五官、衣纹、结构与地标。场景实际剧情光位另作元数据，展示光不取消三维体积，也不取代成片光影基准。
3. **风格组合**：内容 skill 提供剧本和镜头，本前缀置首不变；用户要求兼容的附加风格时在原句后追加，不删改原句。不主动引入冲突画风；如用户改主风格，说明适用范围变化并遵循用户新要求。
4. **冲突词**：正文中的真人摄影、超写实毛孔、二维平涂、欧美卡通、塑料玩偶、高反差硬光等目标风格描述须核对并改为本风格。不把负向词或道具材质误判为风格目标。
5. **生成前**：检查最终工具 payload 的实际 prompt，防止包装器加标题、摘要或漏掉编辑/重试前缀；检查所有实际附件用途，关闭内置风格图注入。资产未齐时回到资产阶段，除非用户明确要求跳过。
6. **生成后**：检查精细三维结构、细腻材质、清透明度、低对比、轻雾、柔光、动画轮廓与题材正确性。蜡像油光、粗糙塑料、过曝、灰雾遮脸、身份/布局漂移需修复。文字约束提高一致性，不能代替真实视觉验收。
