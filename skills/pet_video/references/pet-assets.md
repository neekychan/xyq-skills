# 萌宠视频参考素材生成指南

本文件在多段流程生成参考素材前加载。

## 角色参考图

**用户上传了动物照片 → 直接用作参考图，跳过生成。**

未上传时，用 `sandbox_generate_image` 按层级生成：

| 层级 | 参考图风格 | 要点 |
|------|-----------|------|
| L1 | 真实动物照片风格 | 正面全身，突出品种特征和毛色花纹 |
| L2 | 真实动物照片风格 | 正面半身，突出面部和前爪，可含微表情 |
| L3 | 真实动物照片风格 | 拟人直立姿态，穿着用户指定服装，爪部细节（动物爪非人手） |
| L4 | Q版卡通风格 | 圆润比例，大头小身 |

命名：`assets/{project}/character_{name}_ref.png`

Prompt 构造要点：
- ImageList 不传（纯文生图）
- Prompt 中明确品种、体型、毛色花纹、配饰
- L1-L3 写真实关键词（"真实动物照片风格""细腻真实毛发质感"）；仅 L4（或用户明确要卡通）加卡通关键词（"3D 卡通动画风格""Q版插画风格"）
- 加"白色纯色背景，无其他元素"

## 音色锚定

**触发条件**：台词角色出现在 ≥2 个不同段时需要音色锚定。

音色推荐表：

| 动物类型 | 推荐音色 |
|---------|---------|
| 幼猫/小猫 | 软萌奶气的童音 |
| 成年猫 | 慵懒中性的嗓音 |
| 幼犬/小狗 | 活泼可爱的童音 |
| 大型犬 | 浑厚低沉的中年男声 |
| 仓鼠/兔子等小宠 | 轻细软糯的童音 |

生成方式（`Text` 固定用此句式，只替换角色名——锚定音频只是给生视频提供音色参考，禁止把创意台词、剧情内容或角色介绍写进 `Text`）：
```
sandbox_generate_audio({
  Text: "大家好，我是{角色名}的配音！",
  VoiceDesc: "{音色描述}",
  OutputPath: "assets/{project}/voice_{name}.mp3"
})
```

## 自审清单

参考素材生成后，逐项检查：

0. **命名规范**：参考图必须命名为 `assets/{project}/character_{name}_ref.png`（后缀必须 `_ref`，禁止 `_face`/`_img` 等变体）；音色必须 `assets/{project}/voice_{name}.mp3`
1. **参考图质量**：主体完整、品种/毛色与角色卡一致、层级姿态正确
2. **路径写入**：每张参考图和音频路径已写入 `creative_design.md` 的素材绑定关系
3. **路径格式**：完整 sandbox 路径（如 `assets/{project}/character_xxx_ref.png`），禁止裸文件名
4. **音色锚定不是生成完就结束**：生成了音色锚定音频后，必须在该角色出场的**每一次** `sandbox_generate_video` 调用里通过 `AudioList` 实际传入对应音频路径（Prompt 中用 `@音频N` 引用）——只生成音频文件、不传参等于没做，是最容易被漏掉的一步，逐段生成视频前对照 `creative_design.md` 的素材绑定关系逐一核对
