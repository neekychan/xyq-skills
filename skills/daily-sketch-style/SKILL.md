# 日常速写风格 (Daily Sketch Style)

一个**画风滤镜类**可复用技能。它不负责凭空创作,而是把用户**已经确定并上传的一批图片资产**(角色/场景分镜),用一段打磨好的**固定风格锚定词**统一转绘成「素描速写风格」,再整体交给视频生成,保证全流程画风一致。

## 风格锚定词(FIXED — 禁止改写)

> **素描速写风格,速写线条勾勒轮廓、形体轻度简化,细线条勾勒。**

上面这段文字是本技能的**唯一风格锚定词**。它必须:

1. **原封不动**地出现,不得改写、删减、翻译、扩写、调整语序。
2. 放在**每一条图片风格化 prompt 的最开头**。
3. 放在**每一条视频生成 prompt 的最开头**。
4. 在整批素材(所有图片 + 所有视频段)中保持**逐字一致**。

## 强制工作流(必须按顺序)

本技能的用法是固定的,**不接受跳步**:

### Step 0 — 前置校验:用户是否已上传图片资产?

- 本技能**必须**基于用户已确定并上传的图片资产工作(角色形象或场景分镜)。
- 如果用户**尚未上传任何图片**,不要凭空生成图片,而是先明确要求用户上传其已确定的图片资产(角色/场景分镜),再继续。

### Step 1 — 图片资产风格化(转绘)

对用户上传的**每一张**图片,生成一条图片编辑/转绘 prompt。规则如下,**极其严格**:

- **图片风格化的编辑提示词 = 风格锚定词本身,不得添加任何其他内容。**
- 即:直接把风格映射词 `素描速写风格,速写线条勾勒轮廓、形体轻度简化,细线条勾勒。` 作为该图的编辑 prompt,完全基于用户原图转绘。
- **禁止**在图片编辑 prompt 里追加任何画面描述、构图指令、色彩指令、氛围词、质量词、镜头词或其他任何补充说明。
- 每张图各自独立转绘,保持用户原图的主体、构图、内容不变,只改画风。

> 用图片编辑能力时:`picture_list` 传入用户原图 URL,`query_list` 每一项都**只填**风格锚定词,不加任何其他字。

### Step 2 — 汇总风格化后的图像资产

- 收集 Step 1 输出的全部**风格化后**的图片(角色/场景分镜)。
- 这些风格化后的图,才是送给后续故事撰写与视频生成的图像资产。

### Step 3 — 撰写动画脚本/分镜(挂载专用 System Prompt)

- 加载并**严格遵循** [references/story-system-prompt.md](references/story-system-prompt.md) 作为动画故事编写的 system prompt。
- 该 SP 的输入 = **Step 2 得到的风格化后图像资产** + **用户的意图描述**;输出 = 详细的动画脚本与分镜,用作视频生成参考。

### Step 4 — 视频生成 prompt

- 把 Step 3 产出的每一段视频 prompt,**最开头统一加上风格锚定词**,再接该段的具体画面/分镜描述。
- 视频段之间的风格锚定词保持逐字一致。

## 与其他技能协同的冲突规则(重要)

### A. 与其它「风格类」技能搭配 → 风格锚定词合并,规则不变

- 当本技能与另一个风格类技能(如另一套画风滤镜)同时启用时,把两套风格锚定词的内容**合并**成一段,一起放在每条图片/视频 prompt 的最开头。
- 合并后,本技能规定的所有约束(逐字一致、放最前、图片编辑 prompt 只用风格词、不加其他内容)**依旧生效**。

### B. 与「非风格类」技能冲突(如营销短片、剧情短片等) → 本技能的风格部分优先且必须被遵守

- 当本技能与非风格类技能(例如营销短片技能、Seedance 剧情技能等)同时被调用时,**即使加载了其它技能,也必须遵守本技能所负责的部分**:
  - 图片资产的风格化仍然只用风格锚定词转绘,不掺入其它技能的画面/文案指令。
  - 所有图片/视频 prompt 的**最开头**仍然必须挂载本技能的风格锚定词。
  - 其它技能负责的内容(如营销卖点、剧情结构、投放规格等)在**风格锚定词之后**融合,不得覆盖、稀释或替换风格锚定词。
- 一句话:**风格锚定词 = 不可协商的硬约束;其它技能的产出在其之后叠加,而非取代。**

## 快速自检(输出前)

- [ ] 用户是否已上传图片资产?(未上传则先索要)
- [ ] 每条图片编辑 prompt 是否**只有**风格锚定词,零额外内容?
- [ ] 每条图片/视频 prompt 的**最开头**是否都逐字挂载了风格锚定词?
- [ ] 全批素材(图 + 视频)的风格锚定词是否逐字一致?
- [ ] 若与其它风格技能搭配 → 风格词是否已合并且规则不变?
- [ ] 若与非风格技能冲突 → 本技能的风格约束是否仍被完整遵守?
- [ ] 故事脚本是否严格按 [references/story-system-prompt.md](references/story-system-prompt.md) 产出?
