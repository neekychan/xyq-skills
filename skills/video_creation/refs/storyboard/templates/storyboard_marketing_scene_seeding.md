# 分镜图模板：营销转化 · 场景种草分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：围绕真实生活场景展开的“场景种草”分镜图，把产品自然地放进日常情境中，通过生活方式与使用体验来种草，而非强硬广告。
- **典型场景**：
  - 种草类短视频：“今天分享我的桌面收纳好物”“我的洗护搭配”等；
  - 生活方式 vlog 中的好物推荐片段；
  - 内容电商号的场景化带货、穿搭/家居/美食场景展示。

## 2. 判定关键词与适用边界
- 典型触发词：`好物推荐`、`生活方式`、`场景种草`、`真实体验`、`日常使用`、`搭配分享`、`vlog`、`居家/通勤/旅行场景`。
- 适用判定：
  - 用户强调“把产品放在具体生活场景里自然种草”，希望观众看到“真实使用过程”“体验感画面”；
  - 产品虽然重要，但镜头更关注场景氛围、生活方式和使用细节，而不是硬核功能说明。
- 不适用场景：
  - 只需要严谨讲清功能、参数、卖点 → 优先使用“产品讲解型分镜图”；
  - 更像品牌理念或情感故事，产品露出很少 → 可归为“品牌故事分镜”；
  - 偏知识讲解/教程，重点是教学步骤而不是种草体验 → 可归入“教学科普分镜”等非营销类。

## 3. 分镜结构建议
- **推荐宫格数**：6–9 格，适合日常场景的轻量种草；多产品组合或多场景 vlog 可用 12 格。
- **结构骨架**：
  1. 场景引入（1 格）：建立生活场景与人物身份，引导观众代入；
  2. 问题/需求点（1 格，可选）：点出当前场景中的小困扰或需求；
  3. 产品自然出现（1–2 格）：用“顺手拿起”“镜头带到”等方式让产品进入画面；
  4. 使用过程与细节（2–4 格）：展示真实使用动作、质感细节、搭配方式；
  5. 场景氛围收束（1–2 格）：使用后的轻松、美好或仪式感画面；
  6. 轻度 CTA（1 格，可与收束合并）：低压的“链接在简介/戳小黄车”等行动号召。
- **规划方式**：
  - 先确定 1–2 个主场景（如“周末早晨厨房”“夜晚书桌”），每个场景控制在 3–5 格之内，避免频繁切换；
  - 使用格优先用中近景和手部特写，让观众看到真实操作和质感；
  - CTA 文案保持轻度种草语气，如“有兴趣可以了解一下”，避免强推。

## 4. 生图 Prompt（PE）模板

```text
你是一名生活方式内容创作者的分镜导演，请为下述 {产品/组合名称} 设计一张 {宫格数} 宫格的“场景种草分镜图”（用途类型 = 场景种草分镜），整体画幅为 {画幅比例说明，如“9:16 竖屏种草短视频”或“16:9 横版生活方式大片”}。

【产品与生活方式信息】
- 产品类型：{如收纳盒/香薰蜡烛/护肤套装/咖啡机/桌搭好物等}
- 产品数量：{单品/多件搭配组合}
- 生活方式标签：{如“极简/家居治愈/通勤效率/旅行摄影”等}
- 目标受众：{如“打工人/学生党/精致妈妈/独居青年”等}

【场景设定】
- 核心生活场景：{如“周末早起在厨房做早餐”“夜晚写日记的书桌一角”等}
- 场景细节：{光线、家具、桌面物品等氛围细节}
- 人物角色（如有）：{角色身份与状态，如“下班后很累的都市白领”等}

【种草逻辑】
- 需求/小痛点：{场景中出现的轻度困扰或需求，如“桌面凌乱”“早晨时间紧张”等}
- 产品如何自然出现：{如“镜头跟随手部收拾桌面”“打开柜门露出收纳好物”等}
- 使用动作与体验细节：{1–3 条真实操作与感受，如“质感很温润”“声音很安静”等}
- 场景氛围变化：{使用前后氛围差异，如“从凌乱到整齐”“从昏暗到温暖”等}
- 轻度 CTA 句式：{如“喜欢这种感觉的可以自己试试”“感兴趣的可以搜同款”等}

【分镜排布】
- 宫格数量：{宫格数，如 6/9/12 格}，按阅读顺序编号 S1–S{N}。
- 推荐结构：场景引入 → 需求/小痛点 → 产品自然出现 → 使用过程与细节 → 氛围收束 → 轻度 CTA。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 S1 到 S{N} 的分镜要点（每格对应的场景、动作与种草信息），供用户确认；确认后再按以下格式，为每格写出详细中文分镜说明：
1. S1：
   - 场景与光线：{生活场景整体画面、时间段与光线氛围}
   - 人物状态：{角色此刻在做什么、情绪如何}
   - 文字/旁白：{一行生活化开场语，如“周末的早晨，慢慢醒来”}
2. S2：
   - 场景细节：{桌面/家具/环境中的小乱点或需求点}
   - 种草伏笔：{一句话暗示接下来要分享好物}
   - 文字/旁白：{如“这些小东西其实很好改变”}
……
直到 S{N}，保证每格兼顾“场景氛围 + 产品呈现 + 体验感”，整体语气偏真实分享而非硬广告。

【画幅与风格约束】
- 画面比例：{9:16 / 16:9}，移动端种草场景默认使用 9:16 竖屏。
- 画风：{生活化摄影/仿真人写实插画/柔和插画等}，整体色调偏真实、舒适，不宜过度商业化。
- 要求同一场景中的家具布局、灯光方向和产品位置前后统一，人物外观与服装保持一致，确保观众能感受到连贯的生活片段。
```

## 5. 一致性与避坑
- 场景连续性优先于花哨构图：同一场景前后格中家具、窗户、桌面布局应基本一致，避免“桌子换位置/背景突然大变”破坏真实感。
- 产品要自然地出现在场景中，不要凭空出现或瞬移；使用动作要符合常识，避免夸张、不真实的操作方式。
- 生活方式调性要与品牌一致，避免在同一视频中混搭截然不同的气质（如极简风与重工业风强行混合）。
- 种草语气保持轻度推荐，不要在场景段落里塞满价格信息与促销口号，避免观众感知到强推。
- 若使用多产品搭配，注意颜色与风格协调，避免某个产品明显不属于该场景，造成违和。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”与营销类执行模板：
  - 在计划与分镜阶段，将场景种草分镜归为产品讲解分镜的“场景化种草”变体，在文字分镜中按“场景→产品使用→体验感→轻度 CTA”顺序整理 S1–S{N}；
  - 视频 Prompt 编写时复用产品讲解视频的结构字段，只是减少硬卖点条目，增加场景与体验描述字段。
- 视频生成时仍优先使用“参考图生视频”：
  - 若用户提供生活场景照片或桌搭实拍图，将其作为关键参考帧，在分镜对应的段落中逐镜调用，锁定场景布局与灯光；
  - 产品精修图作为附加参考，确保产品外观与包装在所有镜头中统一。
- 镜头节奏建议：开场 1–2 镜建立生活场景与人物状态，中段 3–5 镜展示产品使用与细节，结尾 1–2 镜给出舒适氛围和轻度 CTA；避免只拍产品特写而忽略场景过渡。
- 当场景种草视频同时承担带货功能时，可在 plan 中叠加 creative/marketing-ad.md 的结构约束（受众洞察 + 问题/需求 + 解决方案 + CTA），保证视频既保留生活感，又能完成转化目标。
