# 视觉质感词库：色调 / 光影 / 画质 / 构图

这些是**可适配的模式与句式，按场景改写，不要逐字堆砌**。目的是让每条 prompt 里"具体画面描述"部分与第 0 节锚定词的气质咬合，而不是重复锚定词本身。

## 整体气质基调

一句话定调：**幽暗浪漫、含蓄诡谲、梦境感、怀旧而压抑**。画面不追求清晰锐利、不追求明亮鲜艳，而是像一段被时间浸泡过的旧胶片记忆——温暖、朦胧、略带不安。

可用形容：慵懒的午后光、教堂般的静默、褪色的华丽、暧昧的暗示、时间凝固感、旧照片的温度、隐约的不祥、克制的情欲、老电影的仪式感。

## 色调（去饱和 + 特定色相）

- 主色相:**橄榄绿 + 棕红**为骨架,辅以焦糖、赭黄、暗酒红、灰绿、烟褐。
- 饱和度:整体**去饱和、低调**;鲜艳色一律压暗、蒙上一层灰。
- 影调:**压低高光**(高光不刺眼、带乳白晕散)、**浓郁暗部**(暗处深沉但保留层次,不死黑)。
- 综合色偏移:整体轻微偏暖偏黄绿,像旧胶片的褪色偏色。
- 肤色:**柔润偏粉**,红润但不油亮,带一点朦胧的桃色。

写法示例:"暖黄绿色调笼罩全场,高光被压成柔和的乳白,暗部沉入棕褐,肤色柔润偏粉"。

## 光影（柔光 + 低照度 + 自然主义）

- 光质:**柔光/柔焦**,光线边缘发散、无硬阴影;可用纱幕、窗帘、灯罩造成的漫射。
- 光位:**侧前方柔光**为主,塑造面部体积又不生硬;辅以窗光、烛光、台灯等**实用光源**。
- 色温:**温暖钨丝灯色温**(偏橙黄的暖白),室内灯火气。
- 曝光:**轻微欠曝、低照度摄影**,画面整体偏暗,靠局部光提亮主体。
- 附加:**暗角**(四周压暗聚焦中心)、**微弱光晕/glow**(高光处柔和晕散、像旧镜头的散射)。

写法示例:"侧前方一盏钨丝台灯投下暖橙柔光,面部半明半暗,画面轻微欠曝,四角自然压暗,高光处泛起微弱光晕"。

## 画质质感（70 年代胶片）

- 载体感:**20 世纪 70 年代胶片美学、35mm 颗粒**,细腻可见的银盐颗粒,均匀漂浮。
- 锐度反差:**低锐度、低反差**,柔和过渡,不追求数码般的锐利边缘。
- 层次:**油画般层次**,明暗过渡如笔触叠加,厚重而温润。
- 镜头:**柔焦镜头**,焦内也带一层朦胧;可有轻微的旧镜头畸变与散射。

写法示例:"35mm 胶片颗粒均匀漂浮,低反差柔和影调,油画般的明暗层次,柔焦带来朦胧的旧镜头质感"。

## 构图与机位

- 机位:**静态机位**为主(固定/极缓慢运动),稳定、克制、舞台感。
- 构图:**古典中心构图**,主体居中或对称,庄重、仪式化。
- 景别:**中近景肖像**为主,聚焦人物面部与情绪。
- 景深:**适度景深**,主体清晰、背景柔化但不过度虚化,保留环境信息。
- 调度:**舞台化场面调度**,人物走位、道具摆放像戏剧舞台般经过设计。

写法示例:"静态机位,古典中心构图,人物中近景居中,适度景深让背景陈设柔化,舞台化的走位与陈设"。

## 落 prompt 前自检（视觉层）

- 色调是否去饱和、是否落在橄榄绿/棕红体系、是否压高光浓暗部?
- 光是否为柔光、侧前方、暖钨丝色温、轻微欠曝、带暗角与微弱光晕?
- 质感是否点到 70 年代胶片/35mm 颗粒/柔焦/低锐度低反差/油画层次?
- 构图是否静态机位、古典中心、中近景、适度景深?
