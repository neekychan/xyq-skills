## 一、视觉资产体系与多成员/伴舞规则 (Visual Asset Matrix)

为确保视觉资产纯净高效并杜绝脸漂与角色失踪，MV 视觉资产采用极简高效矩阵：

```text
               ┌────────────────────────────────────────────────────────┐
               │              MV 视觉资产矩阵 (Visual Asset Matrix)        │
               └──────────────────────────┬─────────────────────────────┘
                                          │
                    ┌─────────────────────┴─────────────────────┐
                    ▼                                           ▼
   【主角资产组 (1~4 张单人纯白底定妆照)】              【场景环境 (100% 纯文本驱动)】
   - 单人构图、纯白无缝背景、五官四维精准锚点           - 严禁生图模型生成场景图，避免拉低审美
   - 锁定各成员五官、发型、妆容与胶囊系列服装版型       - 场景、光影、材质与超现实符号全权由视频 Prompt 驱动
   - 对应 ImageList[0..N-1] 全量传入                 - 每一个分镜微镜头必须明确交代背景与光影
```

### 资产准备与绑定四大铁律：

1. **场景 100% 由视频 Prompt 纯文本驱动（严禁场景图）**：
   - 实践表明：生图模型生成的场景图极易产生呆板质感与土味构图，传入 `ImageList` 反而会锁死并拉低视频模型的审美上限；
   - **Phase 2 仅生成主角人物的单人定妆照，严禁生成任何场景参考图**！场景空间、光影系统、地面材质与超现实符号完全交由生视频 Prompt 描写，充分释放视频模型的动态光影与空间构建能力。
2. **【防白底人物漂浮铁律 (Anti-White-Void)】**：
   - 由于人物参考图是「纯白无缝背景（为了最大化锁定干净的五官特征）」，在生视频 Prompt 中，**每一个分镜微镜头必须明确交代其空间场景与背景细节**（如背景颜色、光照系统、地面物理材质、空气体积雾、悬浮粒子、大字排版等）；
   - 若连续几个微镜头属于同一场景且背景未变，可维持同一空间；一旦换景或镜头起手，必须清晰描述空间与背景；
   - **【红线禁令】严禁 Prompt 出现只有人物动作而无背景/环境描述的真空状态**，防止人物像贴纸一样悬浮在空无一物的纯白底上！
3. **一个角色只生一张图（必须声明单人纯白底）**：每个角色仅生 1 张半身到七分身单人照，严禁三视图拼图，严禁多角色合影；
4. **多成员全量传入铁律（严禁漏传成员图）**：
   - 当制作女团/男团/多角色 MV 时（如 4 位成员），**每一次调用 `sandbox_generate_video` 时，必须将所有 4 位成员的图片全部传入 `ImageList`**（如 `ImageList: [member1, member2, member3, member4]`）！
   - **即便当前镜头是某一成员的单人唱演特写，也必须全量传入所有成员图**，确保视频中背景、伴舞或后序镜头中全员能随时同框出镜且 ID 绝对稳定；
5. **伴舞团纯文本免图规则（严禁为伴舞生参考图）**：
   - 齐舞排场需要更多人（如 4 位主角 + 6~8 位伴舞）时，**伴舞只在视频 Prompt 中用纯文字描述驱动**（例如：`后方8位伴舞身穿统一纯黑哑光修身服，以整齐划一动作衬托前排四位主角`）；
   - **严禁为伴舞额外生成参考图**，伴舞在各镜头间面部无需锁图，穿统一服装自然融入背景即可。
