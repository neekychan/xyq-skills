# 卓别林电影风格短片生成器

## 核心原则 + 持久引擎

**核心原则**：以小人物的温柔对抗时代的坚硬，用喜剧外壳包裹悲剧内核，最终留下不灭的希望感。

持久引擎(因果链):
**普通人设定 -> 困境出现 -> 笨拙对抗 -> 冲突升级 -> 人性闪光 -> 温暖结局 -> 走向远方**

## 质量测试（可证伪）

如果去掉主角的善良与坚持，故事就无法成立；如果结局没有保留希望感、而是让主角突然获得世俗成功，则创意不合格。

## 输入诊断（创作前必须明确的维度）

### 用户提供素材类型
- 完整剧本：直接进入制作流程
- 故事创意/梗概：自动补全人物背景、事件过程、情感高潮、结尾
- 图片参考：作为角色/场景视觉参考
- 视频参考：作为表演/节奏参考

### 基础参数确认
1. **片名**：用户指定或自动生成
2. **时长**：1分钟 / 2分钟 / 3分钟 / 5分钟
3. **画幅**：默认4:3（经典默片比例），可选1.33:1、16:9
4. **影片模式**：
   - A 纯默片（默认）：无对白，仅字幕卡+配乐+音效
   - B 默片风格+现代配乐：保留默片视觉，搭配现代风格音乐
   - C 默片风格+对白：保留黑白复古视觉，添加人物对白
5. **字幕语言**：中文 / 英文 / 其他
6. **故事主题**：爱情 / 生存 / 梦想 / 孤独 / 贫穷 / 人性

### 镜头数量参考
| 时长 | 推荐镜头数 |
|------|------------|
| 1分钟 | 6~12镜 |
| 2分钟 | 12~20镜 |
| 3分钟 | 18~30镜 |
| 5分钟 | 30~50镜 |

## 工作流（执行步骤）

### 沟通规则
禁止提及内部步骤编号，使用自然语言描述当前阶段，例如"接下来设计角色与场景"。
**里程碑确认**：每一步完成后必须暂停，向用户展示当前成果并等待确认，确认后再进入下一步。

1. **收集创作信息**
   收集用户提供的故事创意/剧本/参考素材，确认基础参数（片名、时长、画幅、影片模式、字幕语言）。
   若用户未指定参数，使用默认值：时长2分钟、画幅4:3、纯默片模式、中文字幕。

2. **分析故事素材**
   从素材中提取核心要素：
   - 角色：名称、身份、年龄、性格、服装特征
   - 场景：地点、时间、室内外、情绪氛围
   - 道具：标志物品、喜剧道具、情感道具
   - 主题：识别核心情感主题
   若剧本不完整，自动补充人物背景、事件过程、情感高潮、结尾，形成完整故事线后提交用户确认。

3. **生成视频规格文档**
   将确认后的全局参数（片名、时长、画幅、影片模式、视觉风格、故事主题）整理为正式规格文档。

4. **设计核心元素与分镜**
   - 设计角色：每个角色定义为独立元素，包含名称、身份、性格、1920年代风格服装特征；同一角色有多个造型时分别标注
   - 设计场景：每个场景定义为独立元素，包含地点、时代、室内外、情绪氛围、光影特征
   - 设计道具：重要道具定义为独立元素，描述外观、材质、年代特征
   - 设计镜头列表：每个镜头包含场景引用、人物动作、情绪功能、喜剧元素、时长、摄影语言（景别、角度、运动）
   - 设计音频层：配乐风格、音效节点、字幕卡位置（每30~60秒插入一张字幕卡，用于传递关键信息）
   分镜设计完成后提交用户确认。

5. **素材绑定检查**
   检查上下文，将用户提供的参考图片/视频绑定到对应角色、场景、道具的素材槽位。

6. **生成视觉素材**
   - 生成所有角色参考图：全身、黑白、默片风格、1920年代服装，2K分辨率
   - 生成所有场景参考图：黑白胶片质感、高反差光影、1920年代真实街景/建筑，2K分辨率
   - 生成所有道具参考图：符合年代特征，2K分辨率
   - 生成所有字幕卡：默片风格，白字黑底/黑字白底，复古衬线字体，2K分辨率
   视觉素材全部生成后提交用户确认。

7. **逐镜头生成视频**
   每个镜头时长5~10秒，720p分辨率，生成时必须绑定：
   - 该镜头涉及的所有角色、场景、道具参考图
   - 若与前一镜头连续性极强，可添加上一镜头视频作为连续性参考
   所有镜头生成完成后提交用户确认。

8. **生成音频**
   - 生成配乐：默认钢琴独奏，可选Ragtime、弦乐、小型乐队风格
   - 生成必要音效：脚步声、碰撞声、环境音等，匹配画面动作
   音频生成完成后提交用户确认。

9. **最终合成**
   - 轨道1：视频镜头与字幕卡交替排列，直切转场，章节节点使用淡入淡出
   - 轨道2：音效，音量-8dB
   - 轨道3：音乐，音量-12dB
   - 字幕卡显示时长2~3秒，与视频镜头直切衔接
   - 结尾必须采用卓别林式结尾：人物走向远方，画面渐暗，音乐缓慢结束，保留希望感，禁止主角突然获得世俗成功
   合成完成后提交最终成片。

**视频生成规则**：单个镜头时长≤10秒，单次生成即可完成单个镜头；全片按分镜拆分为多个独立镜头分别生成后再合成。

## 输出契约

### 分镜输出格式
每个镜头必须包含以下字段：
```
[镜头编号]
时长：X秒
景别：远景/全景/中景/近景/特写
角度：平视/仰拍/俯拍
运动：固定/摇/推/拉/跟
场景：[引用场景元素ID]
人物：[引用角色元素ID] + 动作描述
情绪功能：[交代/推进/喜剧/高潮/转折]
喜剧元素：[误会/错位/重复/节奏反差/追逐/无]
字幕卡：[无/文本内容]
```

### 视觉风格统一要求
所有画面必须符合：
- 纯黑白，高反差 monochrome
- 35mm胶片颗粒感
- 1920年代复古电影质感
- 人文现实主义风格
- 无彩色、无CGI、无3D渲染、无未来元素、无现代数码产品、无动漫/游戏风格

## 静默自检（交付前内部检查）
1. 故事是否符合"普通人面对困难坚持到底继续前行"的核心原则
2. 结局是否保留希望感，没有让主角突然获得世俗成功
3. 所有画面是否为纯黑白默片风格，无现代元素乱入
4. 喜剧设计是否使用肢体喜剧而非刻意讲笑话
5. 字幕卡是否按30~60秒间隔插入，信息传递清晰
6. 镜头数量是否匹配时长要求
7. 结尾是否为人物走向远方渐暗的经典卓别林式结尾
8. 配乐音效音量是否符合标准，无对白时旁白轨道是否关闭
9. 所有参考素材是否正确绑定，角色造型是否前后一致
10. 全片语言是否与目标字幕语言一致，无混杂
