# 素材生成规范

## 分辨率与质量要求
- 静态图片（角色、场景、道具、字幕卡）：2K分辨率，高质量渲染
- 视频镜头：720p分辨率，5~10秒时长，帧率24fps（经典电影帧率）
- 所有素材必须保持统一的黑白胶片质感，颗粒度一致

## 角色图生成规则
1. 每个角色首张图使用文生图，必须生成全身像，清晰展示服装细节与面部特征
2. 同一角色的后续造型/不同角度图使用图生图，引用首张角色图作为参考，保证形象一致性
3. 角色表情需要符合默片表演风格：夸张但不做作，清晰传递情绪
4. 禁止生成半身像、裁切不完整的角色图

## 场景图生成规则
1. 每个主要场景生成一张全景参考图，明确时代特征、光影氛围
2. 场景中不得出现现代元素：汽车款式不得晚于1920年代、不得出现现代广告牌、电线杆样式符合年代
3. 室内场景需要符合1920年代底层生活/工作环境特征：简陋的家具、老旧的器物、磨损的墙面
4. 街景场景需要有足够的年代细节：马车、老式汽车、复古路灯、鹅卵石路面、年代感服饰的路人

## 道具图生成规则
1. 关键道具单独生成参考图：例如手杖、礼帽、花、面包、工具等
2. 道具必须符合1920年代特征，不得出现现代塑料制品、现代设计
3. 道具质感要真实：磨损的皮革、生锈的金属、旧纸张的纹理

## 视频生成规则
1. 每个镜头单独生成，时长5~10秒，不得超过10秒
2. 生成时必须绑定该镜头涉及的所有角色、场景、道具参考图，保证视觉一致性
3. 连续镜头（同一场景同一动作衔接）可添加上一镜头视频作为参考，保证动作连贯性
4. 人物动作必须符合默片表演风格：夸张的肢体语言、清晰的情绪表达，动作节奏略快于现实
5. 严格按照分镜指定的景别、角度、运镜方式生成，不得随意更改
6. 视频中不得出现彩色元素、现代物体、穿帮内容

## 字幕卡生成规则
1. 字幕卡使用专门擅长文字渲染的模型生成，保证文字清晰无错字
2. 风格统一：白字黑底（或黑字白底），复古衬线字体，四周有细白边，带35mm胶片颗粒和轻微划痕
3. 文字居中对齐，字号适中，留出足够边距
4. 中文使用复古宋体风格，英文使用经典衬线字体（类似Times New Roman的复古版本）
5. 字幕卡上不得出现任何装饰图案、图像，保持简洁

## 一致性检查
所有素材生成后必须检查：
1. 角色造型是否前后一致：服装、胡子、配饰等细节是否统一
2. 场景光影是否统一：同一场景的不同镜头光影方向、强度一致
3. 胶片颗粒感是否统一：所有素材的颗粒度、对比度一致
4. 年代元素是否准确：无现代元素乱入
