# 玄幻与超能武打设计指南

适用于真人仙侠、元素武斗、暗黑神话、超能力近战、法术与武器混合对决。核心原则是先让人物真实交锋，再让特效放大招式、身份和结果。

## 一、子类型路由

| 子类型 | 战斗核心 | 特效尺度 | 适合的动作 |
|--------|----------|----------|------------|
| 仙侠剑斗 | 身法、剑术、御物与剑气 | 中到大 | 近身试剑、短距飞剑、一次剑阵或剑气终结 |
| 元素武斗 | 身体动作驱动元素 | 中到大 | 火拳、水刃、雷步、岩甲等贴体能力 |
| 暗黑神话 | 重量、异形能力、压迫和环境污染 | 大但克制频率 | 巨兵器、兽化局部、咒纹、地形变化 |
| 超能力近战 | 能力影响空间和攻防规则 | 中 | 短距位移、重力、念力、护盾、速度差 |
| 法术对决 | 施法手势、投射、防御与反制 | 大 | 全程远程交换单元、终局相持对轰（见第四节） |
| 武器附魔 | 冷兵器或现代武器带固定属性 | 小到中 | 刃面附着、命中释放、轨迹残留 |
| 神兽或法相 | 人物动作与大型意象同步 | 大 | 单次显形、压制或终局碰撞 |

## 二、特效身份卡

每名角色固定一套，写在 Prompt 开头：

1. 主色：双方优先使用可快速区分的色彩。
2. 材质：火焰、水流、雷弧、沙尘、冰晶、墨雾、金属粒子、暗影裂纹等。
3. 形态：贴体纹路、刃面薄光、拳锋尾迹、环形护盾、链状束缚、兽形轮廓。
4. 起点：掌心、脚下、武器刃面、背部装置、符纹或环境媒介。
5. 运动：沿身体发力方向推进，随武器轨迹弯曲，命中后扩散或碎裂。
6. 消散：化为灰烬、水滴、光屑、烟雾、碎晶或回流角色体内。

同一角色全片保持同一关键词。双方属性只在用户要求时互换或融合。

## 三、近战与特效的先后关系

每个特效动作按以下因果组织：

1. 人物先完成身体驱动：踏地、转腰、挥臂、刺剑、结印或拉弓。
2. 特效从身体、武器或环境媒介显形。
3. 特效沿清楚路线移动，保留人物轮廓和攻击落点。
4. 对手做出格挡、闪避、护盾或反向能力。
5. 接触发生后再出现爆发、破裂、击退和环境余波。
6. 镜头展示双方落点与能力状态，避免爆光直接结束。

能力不能代替人物表演。每个镜头至少有一个清楚的肢体动作和一个清楚的对手反应。

## 四、远程法术对轰范式

用户说"法术对轰、斗法、隔空对决、远程对决"，或玄幻需求带"史诗、大场面"一类尺度词且未点名近身时，本节替代第三节成为全片的攻防组织方式；近战最多作为一次破盾后的短暂贴身插曲，不得反客为主。

### 远程交换单元

远程对轰的"一次交换"等价于近战的一次可见接触，按以下闭环组织：

`施法动作（结印、挥袖、引动媒介）→ 投射成形与飞行路线 → 对方拦截结果（屏障承接、同类抵消、拍偏、引爆、位移闪避）→ 反制投射或压制推进`

- 每次投射必须有明确起点、路线、目标和拦截结果，禁止无归属光团互飞。
- 拦截本身就是表演：屏障被砸出涟漪、投射被拍偏轰在山壁、连珠弹幕被逐发斩碎，各计一次可见接触。
- 施法手势与拦截动作就是本范式的"肢体动作"，仍要写到手、袖、步法与身体重心。

### 距离与蓄势

- 中远距是常态，不构成"脱手"；距离变化由击退、压制推进、闪现绕侧或高度差机动造成，并写明原因。
- 结印与凝聚必须与位移、防御或压制并行完成（边侧掠边结印、屏障后凝聚下一发），独立的悬浮蓄力不得单独成镜；唯一例外是高潮对轰前的一次极短蓄势停顿。

### 对轰词表

| 类别 | 词例 |
|------|------|
| 投射 | 连珠弹射、雷矛掷出、剑气离刃飞射、符箓引爆、锁链法索、坠星砸落 |
| 拦截 | 屏障承接、同属性对消、拍偏、斩碎弹幕、引雷入地、卷袖化解 |
| 压制与机动 | 弹幕压进、侧掠走位、闪现绕后、御器爬升、借掩体切入射角 |
| 高潮 | 两股能量正面相持推移、僵持中此消彼长、一方灌力破防 |

### 高潮与爆发预算

- 常规投射对撞与屏障碎裂属于普通交换，不占用场景级爆发预算。
- 唯一一次场景级爆发建议用于终局对轰：双方全力光束或能量洪流正面相持，僵持推移后一侧破防，冲击改变地形；之后回到双方落点与余波。

## 五、强度与复杂度控制

### 1. 一镜头一个主特效

辅助粒子只用于证明速度、材质或余波。单镜头同时出现法阵、神兽、雷暴、火海和空间裂缝会遮蔽动作。

### 2. 一片只有一个场景级爆发

高潮可以是：

- 护盾首次破裂。
- 剑阵完整展开。
- 法相或神兽单次显形。
- 能量对撞改变地形。
- 角色能力进入第二形态。

选择其中一项，其余能力作为小尺度铺垫。

### 3. 环境破坏有层级

- 前段：脚下尘粒、草木、衣摆和水面被能力扰动。
- 中段：局部裂纹、石块悬浮、树干结霜或墙面灼痕。
- 高潮：一处地面、墙体、山石或云层发生可见改变。
- 收束：碎片落地、残光消散、角色从烟尘中显形。

### 4. 变形与召唤

单片最多一次形态变化或一次大型召唤。形态变化需要前后外观定义和身份保留项；大型召唤需要与角色手势、视线和攻击方向同步。

## 六、动作与能力的组合方式

| 组合 | 设计方法 | 视觉收益 |
|------|----------|----------|
| 属性贴体拳脚 | 元素沿手臂或腿部发力方向聚集，命中才释放 | 保留拳拳到肉和能力身份 |
| 武器附魔 | 光效薄贴刃面，挥动形成可追踪尾迹 | 武器轨迹清楚，稳定性高 |
| 护盾反制 | 防守者先稳定架势，盾面在接触处局部变形或开裂 | 防御有身体参与和结果 |
| 短距位移 | 起点留残影，终点有落脚和惯性 | 速度快但空间仍可理解 |
| 远程投射 | 明确起点、飞行路径、目标和命中结果 | 避免光团无归属 |
| 法相同步 | 人物完成动作，大型轮廓在身后同步复现 | 强调人物是能力源头 |
| 元素借景 | 水边用水、沙地用沙、雷雨用电 | 特效与场景互相证明 |

## 七、镜头偏好

- 能力显形：局部近景到中景，展示起点与人物动作。
- 高速近战：侧后跟拍或主角动量跟随，特效尾迹保持薄而清楚。
- 护盾或重击：受力反馈跟随，展示盾面变化和防守者脚步。
- 大范围爆发：先特写人物动作，再急拉到广角展示波及范围，最后回到人物落点。
- 粒子扩散、法相显形：适合连续环绕一镜到底，减少切镜造成的形态漂移。
- 高空入场：御剑或俯冲入场先给全景锁定方位与高度差，用衣袂、残影或云雾拖尾表达速度，落地或悬停有受力与气浪反馈。
- 御剑与空中缠斗：垂直纵深是该题材的主要视觉资产——机位随高度差轮换（俯冲跟随、仰视踏剑爬升、螺旋绕柱上升、掠云横移），禁止全程侧向水平机位。
- 对轰：先用广角锁定双方方位，再靠近碰撞点，避免只有特效、人物消失。
- 远程对决全程：机位在"施法者近景—投射飞行跟随—拦截者受力反馈"三点间轮换，广角交代双方相对方位后再切局部；相持对轰时沿能量流轴线侧向缓移，两端人物轮流入画。

## 八、Prompt 示例

### 示例 A：真人仙侠双剑对决（多机位切镜——镜头序列逐镜分行）

```text
真人仙侠电影质感，人物面部与服装保持写实。主体A穿月白窄袖长袍，右手持细长剑，以轻快步法和深青色半透明水纹剑气为能力；水纹薄贴剑刃，挥动时形成弧形尾迹，命中后碎成水珠。主体B穿黑金护肩长衣，双手持宽刃重剑，以沉重压迫和暗金色砂砾状剑芒为能力；砂砾沿重剑刃面滚动，碰撞后化为金色尘沙。双方特效身份和兵器全程不变。

月夜山门石台，地面有浅水和断裂石碑。
镜头1：中全景，镜头随主体B重踏石台的下劈冲势自高处俯冲切入，带出主体A在画面左侧、主体B在右侧、相距五步；主体B双手重剑横扫，暗金沙砾沿刃面聚集，主体A向后滑步避开，水面被剑风划出弧线，随后右脚点地突入，以连续两次轻刺逼近主体B肩侧。<重剑破风><水花溅响>
镜头2：侧向中景，镜头随主体A旋身短弧环绕到两人侧面。主体B转动重剑横挡，每次碰撞都在清楚接触点溅出水珠与金砂，主体B脚下石面出现细小裂纹；主体A借第二次碰撞旋身到主体B侧后，水纹剑气收成一道薄弧，主体B转身下劈，暗金沙砾凝成局部护壁。<剑刃交鸣><金砂摩擦><石面低沉开裂>
镜头3：仰拍近景，镜头压低仰角贴近两剑交点，碰撞前环境声短暂抽空；水弧沿护壁裂口穿过，主体B重心后移、退到断碑旁，护壁碎成金色尘沙。<护壁碎裂><水珠迸裂>
镜头4：全景。主体B借断碑卸力站定，随即蹬碑反扑，重剑撩起金砂直取主体A中路；主体A旋身举剑迎击，水纹剑气重新贴刃亮起。<蹬碑闷响><金砂横扫>
```

### 示例 B：暗黑神话近战与护盾破裂（一镜到底环绕——散文连贯形态，仅适用此语法）

```text
暗黑神话真人风。主体A是披暗红破旧斗篷的重甲战士，右手持短柄战锤，锤头缠绕暗红熔岩裂纹，以正面压迫为主；主体B是银灰轻甲守卫，左臂固定六边形蓝白晶体盾，右手持短剑，以移动防守和反击为主。装备数量、手别和能力颜色全程固定。

废弃地下祭坛，地面布满浅灰尘土，六根石柱围成圆形。镜头沿主体A右后方推进，跟随其拖锤冲入；战锤自下向上抡向晶体盾，主体B沉肩屈膝承受冲击，盾面接触处出现一圈细小裂纹，鞋底向后划出两道尘痕。镜头绕到主体B侧面，主体B借盾面弹开战锤，短剑刺向主体A肩甲接缝；主体A旋身用锤柄拨开，暗红裂纹沿锤柄回流。两人绕石柱换位，主体A让战锤擦过柱面蓄势，碎石沿旋转方向飞出；主体B举盾迎击，晶体盾在第二次重击中从中心向外碎裂，蓝白碎片全速迸散，主体B被推退到石阶边缘、单脚抵阶稳住重心，短剑反手刺向主体A小臂；主体A旋锤磕开剑尖，熔岩裂纹明暗交替，战锤重新抡起直逼盾碎的空当。

<战锤破风><晶盾低频震鸣><石柱碎屑><晶体破裂><盔甲呼吸声>
```

### 示例 C：远程法术对轰（多机位切镜——按第四节远程交换单元组织）

```text
真人仙侠电影质感，人物面部与服装保持写实。主体A穿绯红宽袖法袍、束高马尾，双手结印施法，以金红色符焰为能力；符焰自掌心印诀成形，凝成雀形火印飞射，命中或被拦后碎成金红火屑。主体B穿玄青鳞纹长褂、披散长发，左手持乌木法杖，以靛蓝色雷光为能力；雷光沿杖首凝聚成矛，掷出时拖出锯齿状电弧，消散为靛蓝光尘。双方特效身份全程不变。

黄昏荒原祭坛，两侧各立一圈残缺石环，地面是龟裂红土。全程快节奏，法术投射与拦截毫不停顿。
镜头1：广角全景，镜头自侧面横移切入交战中段，带出主体A立于左侧石环上、主体B踞于右侧祭坛沿、相距二十步；主体A双手疾速结印，三枚雀形火印连珠掷出，主体B挥杖引雷成盾，雷盾承接两枚、火屑迸溅，第三枚被杖尖拍偏、轰在身后石环上炸出缺口。<火印破空><雷盾震鸣>
镜头2：主体B近景到投射跟随，主体B旋杖疾引，靛蓝雷矛离杖飞射，镜头贴着雷矛电弧推进；主体A侧掠走位边掠边结印，袖摆翻卷，符焰在身前撑开半透金红屏障，雷矛砸上屏障炸开涟漪，主体A顺势隔着屏障反掷一道火链缠向主体B手腕。<雷矛炸响><火链锁鸣>
镜头3：俯压中全景，主体B急退半步挥杖斩断火链，雷光沿断口逆烧；两人隔着祭坛互射加速，火印与雷矛在中线连续对撞互消，红土被冲击掀起环状尘浪，主体A借尘浪掩护跃上更高的断柱抢占射角，主体B引雷入地、电弧沿龟裂地缝追袭断柱根部。<连环对撞><电弧窜地>
镜头4：仰拍近景，断柱根部炸裂，主体A蹬柱腾身，空中双手合印，金红符焰全数回卷凝成一道火凤洪流；主体B双手举杖，靛蓝雷光自石环四周汇入杖首，环境声短暂抽空。<符焰汇聚>
镜头5：沿能量流轴线侧移的广角，火凤洪流与雷光巨柱在祭坛上空正面相持，交汇点白热膨胀、僵持推移，主体A沉腰灌力，火凤一侧渐渐压过，雷柱崩散，主体B被冲击掀退撞上石环、拄杖滑地卸力，红土翻起两道深沟；镜头回到两端，主体B杖首残雷再亮、蹬石环反身再掷，主体A袖间火屑重聚迎上。<洪流相持><雷柱崩散>
```

## 九、单段策略

- 8 秒以内：一种能力显形、一次有效交锋、一次结果。
- 9 至 15 秒：两轮攻防和一次能力升级，最多一个大型效果。
- 时长高于 15 秒且当前模型允许：允许环境借力、护盾变化和一次终结爆发，主要动作节拍不超过 5 个。
- 人物、法术、场景和镜头同时复杂时，优先减法术种类，保留身体动作和胜负结果。
- 远程对轰范式同样按上表控制节拍：投射与拦截的交换次数不计入节拍，抢占射角、破盾、终局相持才计。

## 十、专用尾注

```text
每个特效严格绑定对应角色和动作，颜色、材质、形态全程一致，禁止属性互换。
保留人物轮廓、关节、武器和接触点清晰可见，粒子和爆光不遮住关键攻防。
大型特效只出现一次，爆发后展示双方落点、受力结果与环境余波。
```
