# 深边圆画风格 · 可复用动画风格化技能

本技能负责为用户提供的图片资产（角色 / 场景分镜）套上统一的「深边圆画风格」画风，再把风格化后的资产整体送入视频生成，产出画风一致的图片或视频动画产物。

## 0. 风格锚定词（唯一权威定义，禁止改写）

**深边圆画风格锚定词（下称「风格锚定词」）：**

```
深边圆画风格，粗黑线/强轮廓，深色压痕外廓，明显笔触，砂粒浓彩涂层，高度几何化，几何圆钝，低饱和/莫兰迪，灰绿粉肤柔撞
```

- 该锚定词是本技能的核心资产，**逐字固定**，禁止改写、增删、翻译、调换顺序或"优化"。
- 所有需要生成的**图片素材 prompt** 与**视频生成 prompt**，其**最开始**都必须原样加上这段风格锚定词，随后再接具体画面 / 剧情内容。
- 风格锚定词是「画风滤镜」，只约束视觉质感，不约束题材、动作、剧情。

## 1. 使用前提（硬性）

本技能**必须先有用户上传的一批已确定图片资产**（角色形象图或场景分镜图）才能工作。

- 若用户尚未上传任何图片资产 → 先明确要求用户上传其已确定的图片素材（角色 / 场景分镜），不要凭空生成。
- 图片资产是「主体与画面来源」，本技能不负责从零构想角色，只负责统一画风并驱动生成。

## 2. 标准工作流

### Step A · 图片资产风格化转绘（核心步骤，必做）

对用户上传的**每一张**图片资产，逐张做风格化转绘（图生图 / 图片编辑）：

- **编辑提示词 = 风格锚定词本身，不加任何其他内容。**
- 即：直接把第 0 节的风格锚定词整段作为图片编辑 prompt，完全基于用户原图转绘，**不要**追加画面描述、不要补充细节、不要改动构图/主体/内容。
- 目的：只把画风换成「深边圆画风格」，保留原图的主体、构图、场景内容不变。

> 转绘 prompt 写法（唯一写法）：
> `深边圆画风格，粗黑线/强轮廓，深色压痕外廓，明显笔触，砂粒浓彩涂层，高度几何化，几何圆钝，低饱和/莫兰迪，灰绿粉肤柔撞`

**转绘范围规则：**
- 对存在明确角色主体（人物、拟人角色、生物）的图片 → 转绘。
- 对场景分镜图（含明确叙事场景）→ 转绘。
- 单独的无主体纯物件图 / 纯 logo / 纯文字图 → 不转绘（无风格化意义）。

逐张转绘完成后，得到一批**风格统一的图片资产**，作为后续视频生成的输入素材。

### Step B · 撰写动画脚本与分镜

把 Step A 产出的**风格化后图片资产** + **用户的意图描述**，一起交给本技能配套的剧情短片 system prompt 撰写详细动画脚本与分镜。

- system prompt 全文见 [references/story-system-prompt.md](references/story-system-prompt.md)。
- 加载该 system prompt 作为脚本撰写的行为规范，产出「高密度剧情、快节奏、多景别、运镜丰富」的中文视频提示词。

### Step C · 视频生成

将脚本 / 分镜落成最终视频生成 prompt：

- **视频生成 prompt 的最开始，同样原样加上第 0 节的风格锚定词**，随后再接分镜画面描述。
- 送入视频时使用 Step A 风格化后的图片资产作为参考素材（保持角色/场景一致）。

## 3. 与其他「风格类」技能搭配 —— 锚定词合并

当本技能与其他风格技能（如木柱刻彩、国漫3D渲染等）同时被调用时：

- **规则不变**：图片风格化 prompt 与视频 prompt 的最开始，仍必须放风格锚定词。
- **做法**：把本技能的风格锚定词与其他风格技能的锚定词**内容合并**成一段，整体放在 prompt 最开始，随后再接画面 / 剧情内容。
- 合并时各技能的锚定词均逐字保留，不改写、不裁剪；顺序上本技能锚定词与其它锚定词平级拼接即可。

## 4. 与「非风格类」技能冲突 —— 本技能优先保留画风

当本技能与非风格类技能（如营销短片、剧情短片、广告生成等）同时被调用时，**即使加载了其它技能，也必须遵守本技能对"画风"的以下硬性要求**：

1. 所有图片素材风格化 prompt 与视频生成 prompt 的**最开始**，都必须原样挂载本技能的风格锚定词——这一条不被任何其它技能覆盖。
2. 图片资产必须先经 Step A 的风格化转绘，再进入其它技能的生产流程。
3. 其它技能负责的部分（如营销结构、卖点脚本、投放节奏、叙事节奏等）照常执行；本技能只"占用"画风这一层，二者结合、互不删减。
4. 若其它技能试图规定与本技能冲突的画风 / 色调 / 笔触 → 以本技能的风格锚定词为准。

一句话：**本技能只锁"画风"，其它技能管"内容/结构"，两者叠加，画风锚定词永远在最前且不可删。**

## 5. 输出前自检

- [ ] 用户是否已上传图片资产？未上传则先索要。
- [ ] 每张需转绘的图片，编辑 prompt 是否就是纯风格锚定词、未加任何多余内容？
- [ ] 图片风格化 prompt 与视频 prompt 的最开始是否都原样带了风格锚定词？
- [ ] 与其它风格技能同用时，是否做了锚定词内容合并（逐字保留）？
- [ ] 与非风格技能同用时，画风锚定词是否仍在最前且未被覆盖？
- [ ] 脚本撰写是否遵循了 [references/story-system-prompt.md](references/story-system-prompt.md) 的密度/节奏/运镜/声音规则？
