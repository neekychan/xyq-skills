# 真人说唱 Performance MV Prompt Engineering Skill

## Skill 目标与分类边界
这个 Skill 面向 **30 秒内的真人说唱表演视频生成**。用户给出新音频后，先输出简练的音频理解、推荐生成方案、时间轴和问卷；确认后在后台生成可直接喂给 2.5 模型、可用于复刻和评测的高精度 PE，不在聊天正文展开。

统一收口：
- 目标是 **≤30 秒、单支短视频直接生成**，不是 storyboard，也不是多镜拼装流程。
- 核心是 **口型 + 手势 + 压场感**；必须对口型，不得以氛围、快切或运镜代替口型准确性。
- Rap 属于 Performance：场景可按音频选择室内或户外，包括城市夜景、工业内景、地下空间、停车场、涂鸦巷道、仓库、屋顶、霓虹街区、荒漠、公路或等价空间；场景必须服务人物，不锁死单一模板。
- 对话首轮只展示：**音频理解摘要、推荐生成方案、时间轴设计、问卷确认**。主提示词、控制点、负向词和关键帧引用必须在后台完整生成并随视频生成任务提交，默认不在聊天正文展开；只有用户明确索要 PE 时才展示。
- 高复刻不是“泛泛像说唱”，而是尽量达到历史案例里的 **人物锚定强度、口型强度、手势强度、场景锁定强度、运镜锁定强度和逐段时间轴精度**。
- 控制强度不能被误解成固定场景模板：**角色造型、场景、时间轴、镜头起伏都必须先根据新音频重新设计**，再借用历史 archetype 的控制逻辑组织 prompt。
- 如果用户已经给出一整段细到可执行的 PE / 视频脚本，不要把它抽象成更泛的模板；优先保留用户原词里的角色、场景、口型、手势、动作、运镜、时间轴、控制点和负向词锚点，只做必要结构化整理。
- 不设计 BGM 回灌、音轨替换或二次混音；保留用户提供的目标音频作为唯一音频驱动。

## 适用与不适用场景
在以下情况使用：
- 用户上传新的说唱音频，要求生成同类型真人 rap performance 视频。
- 用户要“高复刻度说唱 MV 提示词”或“按照之前那个 rap 参考那个标准来”。
- 用户明确要求对口型、手势、步伐、场景、运镜都要强控制，可直接拿去评测。
- 用户要求快嘴、强 punch、拖拍或 hook 驱动的真人说唱短视频。

不适用：
- 团舞编舞主导的视频。
- 舞台演唱 / live 氛围主导的视频。
- CG 奇观或强剧情叙事主导的视频。
- 纯剧情、纯氛围、无需真人准确说唱口型的视频。

## 输入边界与默认值
必需输入：
- `audio_path`，或明确指定的说唱音频片段。

可选输入：
- 歌词文本、句尾时间码。
- 角色参考图、场景参考图。
- 参考视频文件或链接及指定时间段。
- 指定性别、人设、造型、人数、画幅比例。
- 指定单人压场、双人对切或小团体陪衬。
- 已写好的完整脚本、提示词或时间轴拆解。

默认值：
- 不要只写“做说唱”就直接生成最终 prompt。若用户没锁定角色方案，先主动给一版推荐生成方案。
- 默认画幅 `16:9`；用户明确要竖版短视频时改成 `9:16`。
- 如果没有场景图，默认选择能放大人物攻击性的城市夜景、工业内景、地下空间、停车场、涂鸦巷道、荒漠公路或用户语境里的等价空间。
- 若需求很泛，优先走 **单主角压场 archetype**，不默认增加人群、复杂剧情或场景奇观。
- 音频超过 30 秒时，推荐 flow、hook 与收束最完整的 ≤30 秒片段并等待确认。
- 没有可靠歌词或时间码时，先获得音节密度、句尾、停顿、重拍与 hook 锚点；未取得可靠锚点不得宣称精准对口型。

## 音频来源与准入
- 用户上传或明确提供可用音频时，直接使用。
- 用户只给歌曲／BGM 名，或明确要求找音乐，且没有可用的 `audio_path`／`video_path` 时，调用 `pippit_omni_search`；`SearchType` 必须为 `mv_music`，`Query` 只做最小清洗，不得擅自添加歌手、版本、语种、年代或曲风。
- 将返回的候选音频提供给用户确认。
- 用户选定后统一绑定为 `canonical_audio`。
- 音频来源记录为 `uploaded_audio` 或 `copyright_music_asset`；版权库音频记录 `asset_id`、版本和选定片段。
- 无已确认可用音频，不进入生成。

### extract_lyrics 调用

- 在 `canonical_audio` 已确认并取得可访问的 `audio_path` 后，音频含人声或当前任务需要歌词信息时，调用 `extract_lyrics`，传入该 `audio_path`，获取歌词文本及对应时间戳。
- 将返回结果作为原有音频理解流程的输入，用于识别歌词关键词、歌词句段、hook、高潮及现有的画面或口型时间映射。
- 纯器乐或无歌词音频跳过该调用；工具未返回歌词时，继续按照原有音频结构分析流程执行，不阻断后续生成。

## 不可妥协的表演约束
1. 主角身份、脸、发型、服装、配饰、身体状态与运动轨迹全片固定。
2. 口型必须匹配说唱音节密度、爆破音、闭口音、拖拍、断句和停顿，禁止明显晚拍、嘴型松散及唱歌式无依据大张口。
3. 指向镜头、摊手、切分摆臂、点头、肩颈起伏、身体前压等动作必须绑定句尾、重拍或语义，不做无节奏乱挥。
4. 主角始终是视觉与情绪中心；环境、陪衬、空镜和特效不得遮挡脸、嘴和主要手势。
5. 场景坐标、人物走位、运动方向和主机位纪律保持连续；快切不能用于掩盖口型或动作错误。
6. 如果设定持续行走，必须保持稳定推进，不能突然停住摆 pose、瞬移或反向。
7. 高能句和 hook 必须从口型、姿态、景别或空间中至少两项明显升级。

## 已验证高精度 archetype
### Archetype A：荒漠公路后退跟拍快嘴 Rap
这是历史对话里沉淀出的**参考级强模板之一**，不是所有新音频的固定默认场景。只有当用户明确说“按之前那个公路 rap 标准来”“公路 rap”，或新音频确实匹配荒漠压场、持续前推、强攻击性气质时，才从这一套派生；否则先根据新音频重新设计角色、场景和时间轴，再借用这套模板的控制强度。

核心锚点：
- 单人主角，不要额外角色。
- 主角是极具攻击性与镜头掌控力的 rapper，可沿用：黑人男性、赤裸上身、精干强壮、肌肉线条清楚、胸口腹部手臂纹身明显、脏辫发型、发梢带红色或橙红色染发、醒目银色字母项链、黑色修身牛仔裤、高辨识度腰带。
- 场景固定为 **白天阳光下的荒漠公路**：一条笔直延伸的柏油路，两侧是干燥灌木、荒地和远处低矮山丘，整体暖色，美国西部荒野感。
- 主角始终位于公路中央，持续朝镜头方向走来，背景不要频繁变化。
- 表演方式是 **典型 rap performance**，不是舞蹈：边走边 rap，肩膀、胸腔和上半身随鼓点轻微起伏，头部点拍，步伐稳定、有力、持续向前。
- 手势是整段视频最重要的节奏器之一：指向镜头、指向自己头部、双手摊开、手掌向前推出、节拍切分式摆臂、短促敬礼感动作、强调语义的点指动作。
- 镜头语言必须以 **连续后退跟拍** 为主：摄影机始终在人物正前方一边后退一边保持人物位于画面中心，景别以中景到中全景为主，偶尔轻微推近强调嘴型和表情，但不能乱飞，不能做大幅横摇、无人机感运镜或夸张环绕。
- 允许轻微真实 handheld 生命感，但整体仍是专业 MV 摄影机的稳定跟拍质感。
- 可有轻度超现实点缀，例如扑克牌、轻微地面波纹或空间扭曲，但只能点缀，不能遮挡脸、嘴型和主表演，不能替代人物压场，不能升级成 CG 奇观。

### Archetype A：0–30 秒每 5 秒时间轴参考
- `0–5s`：先建立人物造型、纹身、项链、脏辫、公路场景；中景 / 中全景后退跟拍，主角直视镜头，嘴型高速同步，手势以指向镜头和切分式摆臂为主。
- `5–10s`：镜头保持相对恒定距离，更强调嘴型和上半身表现；手势频率提高，出现指头部、摊手、向前推出等动作。
- `10–15s`：进入更强输出段，眉眼更凶、更自信，镜头略推近但仍保持后退跟拍，不脱离公路中央走位。
- `15–20s`：维持向前 performance，可插入轻度超现实元素，但不能变成主表达。
- `20–25s`：高峰段，口型更狠，手势更有攻击性，镜头仍以后退跟拍为主，景别略近。
- `25–30s`：收尾高能段，继续沿公路中央向前走，最后一两秒通过眼神锁镜头、向前指向或身体前压完成收束。

## 音频驱动优先级
Rap 类 Skill 不能因为存在 archetype，就把所有新音频都写成同一支视频。必须遵守：
- 先提取总时长、歌词 / 音节密度、flow、拖拍、punch、爆破音、闭口音、句尾、停顿、重拍、hook、高能句和结尾。
- 先判断哪些句子适合近景口型压迫，哪些拍点适合切镜或放大手势，hook 是否需要更强 hero shot 或空间放大。
- 先判断歌曲态度偏凶狠、冷感、街头、自信、克制、松弛还是张扬。
- 先根据新音频判断更适合荒漠公路、城市夜景、地下空间、工业厂房、停车场、霓虹街区、仓储空间还是其他场景。
- 先根据新音频的人设气质重新设计主角外观、服装、发型、配饰和攻击性强弱，不能把同一套黑人脏辫 / 裸上身 / 项链默认套给所有歌。
- 先根据新音频结构设计时间轴：哪些句子适合持续跟拍，哪些句子适合近景压口型，哪些句子适合 hook 放大，哪些句尾适合停顿、转身或收势。
- 将音频证据映射到口型近景、手势爆点、人物走位、景别变化和空间放大节点；没有音频证据时不机械平均切片。
- archetype 提供的是 **控制逻辑、镜头纪律、表演纪律和 prompt 密度**，不是固定世界观。

## 参考视频高精度复刻流程
问卷中必须询问是否有参考视频，支持上传本地视频或提供链接。用户已经主动提供参考视频时，不再重复询问“是否有”，直接进入分析：
- 链接必须先取得可分析的实际视频文件；若链接无法访问、无法下载或只拿到页面文本，要明确要求用户上传视频，不能假装已看过。
- 用户指定时间段时，只精确裁取并分析该区间；未指定时分析完整视频，并结合新音频时长选择对应复刻范围。
- 使用 `analyze_media` skill 分解参考视频，至少提取：主角人数与身份、人物造型锚点、场景空间、口型与 flow、节奏型手势、身体重心和运动轨迹、景别、主运镜、剪辑点、轻度特效、ending 及负向限制。
- 把结果分成“必须复刻的硬锚”和“可按新音频重排的变量”。人物、场景、表演纪律、运动轨迹和主运镜属于硬锚；口型 / 手势爆点、剪辑点、景别和特效时点按新音频歌词、句尾、重拍与 hook 重新映射。
- 必须基于拆解结果**改写本轮推荐生成方案、时间轴和后台 PE**，不能分析完仍沿用通用 rap 模板。硬锚同时进入主提示词、控制点和负向词。
- 若用户在首轮问卷后才上传或补充链接，必须暂停生成，分析后按原来的简练格式重新给出修订后的推荐生成方案、时间轴和问卷；旧确认自动失效，用户重新确认后再进入后台 PE，不要借此在正文展开技术提示词。
- 若用户只说“参考风格”而非高精度复刻，才允许只继承气质和镜头语法；否则默认按人物、场景、表演、口型和运镜的高精度复刻处理。
- 生成后对照参考逐项验收角色、场景、口型强度、手势、运动轨迹和主运镜；缺失关键硬锚时不能宣称复刻完成。

## 工作流程
### 1. 先做音频理解
至少明确总时长、flow 类型、情绪、音节密度、爆破音 / 闭口音、句尾、停顿、重拍、hook、高能句、结尾，以及口型近景、手势爆点、走位、景别和空间放大节点。

### 2. 先判断是否已有“可直接执行脚本”
如果用户已经给出一整段细到可执行的脚本 / PE：
- 不要把它抽象成一版更泛的模板。
- 先保留其 **角色锚点、场景锚点、口型锚点、手势锚点、动作锚点、运镜锚点、时间轴锚点、控制点和负向词**。
- 再整理到本 Skill 的固定输出结构里，方便直接生成与评测。
- 除非用户主动要求简化，否则不要删去人物外观细节、环境细节、动作词、镜头词或精确时间锚点。

### 3. 再生成推荐生成方案
如果用户没有明确锁定人物风格、人数关系或表演设计，先输出一版 **推荐生成方案**，至少包含：
- 推荐表演结构：单主角压场、双人对切，或主角 + 陪衬人群，并说明理由。
- 角色风格：例如冷脸强压迫型、街头松弛型、暗黑攻击型、时装高冷型。
- 人物外观锚点：发型、肤色 / 气质、纹身、首饰、上装 / 下装、身体状态等至少 **4 项清晰具体维度**。
- 场景锁定：空间类型、时间、天气、光线、主色调、背景元素和空间调度规则。
- 表演锁定：口型强度、眼神状态、手势密度、肩颈、身体重心、步伐和停顿方式。
- 运镜锁定：主机位类型、辅助镜头、景别区间、相机运动允许项和禁止项。
- 特效点缀上限：是否允许轻度超现实元素，以及允许到什么程度。

### 4. 再设计时间轴
说唱类不是平均切片。默认围绕 **主角亮相段 → 主表演段 → hook / 高能句放大段 → 收束段** 设计：
- 开头快速立住主角和态度。
- 中段持续强化口型、手势、身体重心和镜头推进。
- hook 或高能句做更强压场感、景别变化或空间切换。
- 收尾用停顿、回看镜头、转身离场或最后一句 punch 收束。
- 每段写明音频证据、口型难点、手势与身体动作、人物坐标、景别运镜、场景反应和结束状态。

### 5. 问卷确认
输出推荐方案和时间轴后，必须紧跟问卷，默认已采用推荐项：
1. 参考视频：没有 / 上传视频 / 提供链接；记录目标时间段，默认按高精度复刻处理。
2. 人物结构、角色外观锚点、造型与场景：采用推荐 / 调整。
3. 口型、手势、身体、走位、运镜与特效上限：采用推荐 / 调整。
4. 生成方式：直接生成视频 / 先生成 3–5 张分镜关键帧图片预览 / 我要调整。

如果用户明确说“直接生成”或“不改”，按问卷默认项执行；输出结构里仍保留问卷确认段。

### 6. 关键帧模式
先输出 **3–5 张关键帧预览图方案**：
- 关键帧 1：主角亮相，角色风格与主场景第一次锁定。
- 关键帧 2：中近景口型与手势状态锁定。
- 关键帧 3：高能句前的姿态推进或空间切换节点。
- 关键帧 4：hook 段压场 hero shot 主画面。
- 关键帧 5：停顿收束或终极定格，按时长可合并。

每张关键帧写清时间点、角色与外观、口型状态、手势、身体重心、人物坐标、景别、场景、灯光和情绪关键词。关键帧一旦确认，必须成为后续视频 PE 的视觉硬锚；通过 `ImageList` 绑定，并由主提示词、控制点和负向词共同引用。

### 7. 后台生成并提交 PE
方案和问卷确认完成后，在后台生成可直接投喂模型的主提示词、控制点、负向词和关键帧引用，并合并进视频生成任务。聊天正文不要重复展开；只有用户明确说“把提示词发我 / 给我 PE”时，才把实际使用的完整 PE 放进一个代码框。

## 推荐生成方案补齐规则
### 人物与场景锁定
- 补齐主角身份与至少 4 项具体外观锚点，以及服装、配饰、纹身、发型等视觉锚点。
- 补齐空间类型、时间、天气、主色调与背景元素。
- 写明主角在空间中的运动轨迹，例如持续朝镜头前进、始终保持在路中线。

### 表演锁定
- 写清口型偏咬字狠、拖拍、低声压迫还是 hook 打开。
- 写清手势是密集型、克制型、标志性固定手势还是强节拍手势。
- 写清身体是站姿稳压、前顶、慢步推进、转身停顿还是肩颈控制主导。
- 写清哪些句尾需要定点停顿或强手势爆点。

### 运镜锁定
- 写清主机位是后退跟拍、前压近逼、低机位前推还是固定点位观察。
- 写清允许的辅助镜头。
- 明确禁止大幅横摇、乱飞、夸张无人机感和无意义环绕。

## 控制点模板
```text
控制点：
1. 主角必须始终是绝对视觉中心，不能被环境、陪衬和空镜稀释。
2. 如果是单人 archetype，全片只能有单人主角，不允许额外角色闯入。
3. 对口型必须命中音节密度、爆破音、闭口音、拖拍、断句和停顿，不能明显晚拍、嘴型松散或唱歌式长音大张口。
4. 手势、抬手、指向镜头、点头、肩颈和身体前压必须与句尾、重拍或语义对应。
5. 如果设定持续行走，必须全程稳定推进，不能突然停住摆 pose、瞬移或反向。
6. 场景必须锁定，不能频繁切换背景或无依据地从户外跳到室内。
7. 运镜必须遵守主机位规则，不能乱飞、无意义横摇、突然变成无人机感镜头或随意环绕。
8. 高能句和 hook 必须从口型、姿态、景别或空间至少两项明显加强人物压场感和镜头冲击力。
9. 允许环境补充镜头，但占比不能高于人物主表演镜头，且不得遮挡脸、嘴或主要手势。
10. 人物身份、人脸、身体状态、服装、配饰、发型、场景坐标和运动方向全片稳定。
11. 快切不得掩盖口型、动作或身份连续性错误。
12. 关键帧模式下，最终视频必须对齐已确认关键帧中的角色风格、主场景、口型强度、手势状态、姿态、景别和运镜方向。
13. 保留目标音频，不进行 BGM 回灌、音轨替换或二次混音。
```

## 负向词模板
```text
负向词：口型不准，口型晚拍，音节密度不匹配，闭口音不闭口，嘴型松散，像在假唱，唱歌式拖音大张嘴，手势和节奏脱节，无意义乱挥，人物没有压场感，角色风格不清，主角存在感弱，陪衬抢戏，动作拖沓，镜头太软，环境镜头过多，脸或嘴被特效遮挡，景别乱跳，人物换脸，服装漂移或频繁变化，人物比例失真，面部崩坏，走位瞬移，运动方向反转，背景跳变，背景喧宾夺主，主机位失控，大幅横摇，乱飞，无人机感，无意义环绕，碎切掩错，情绪不够狠，不像说唱视频，更像普通摆拍 vlog，hook 不升级，公路 archetype 偏离路中线或停止前进，忽略关键帧参考，关键帧与视频角色状态不一致，BGM 回灌，替换音轨，二次混音。
```

## 生成后验收
生成后必须在开场、每个主要句组、高能句 / hook 和结尾逐点检查：
- 人物身份、脸、造型、场景坐标、走位和运动轨迹是否连续。
- 音节密度、爆破音、闭口音、拖拍、断句、句尾、停顿与口型是否同步。
- 手势、步伐、肩颈、重心和身体前压是否命中节拍 / 语义且接续自然。
- 主机位、景别、环境与特效是否服务人物，未遮挡嘴和主要手势。
- hook 放大、ending 和关键帧硬锚是否成立。
- 参考视频的角色、场景、口型强度、手势、运动轨迹和主运镜硬锚是否逐项成立。
- 成片是否保留目标音频，且没有 BGM 回灌、音轨替换或二次混音。

任一关键节点出现口型错拍、手势脱节、人物重生、造型漂移、轨迹反转、镜头掩错、主角被稀释、关键参考硬锚缺失或 BGM 回灌，本次 clip 判失败并重新生成，不得宣称完成。

### 阶段一：方案确认

三、时间轴设计

## 质量门禁
输出前与成片后自检：
- 总时长 ≤30 秒；目标音频是唯一音频驱动，没有 BGM 回灌、音轨替换或二次混音。
- 明确强调 **口型 + 手势 + 压场感**，并把对口型设为必须通过项。
- 补齐角色结构、人物风格、至少 4 项具体人物外观锚点、场景锁定、表演锁定和运镜锁定。
- 音频证据已映射到口型、手势、身体、人物坐标和镜头，时间轴与节奏绑定而非机械平均切段。
- 场景可室内外但始终服务人物；公路 archetype 只在匹配时启用。
- 首轮只展示音频理解摘要、推荐生成方案、时间轴设计和四组问卷，没有提前展开 PE。
- 问卷紧跟方案和时间轴，包含参考视频的没有 / 上传 / 链接，以及直接生成 / 先看关键帧 / 我要调整。
- 参考视频已真实取得并分析；类型硬锚已改写进推荐方案、时间轴、主提示词、控制点和负向词，并按新音频重映射节拍。
- 后补参考时已暂停生成、宣告旧确认失效并重新确认。
- 后台已生成可直接投喂模型的完整主提示词、控制点、负向词和关键帧引用，而非在聊天正文重复展示。
- 用户已有可执行脚本时，原角色、场景、口型、手势、动作、运镜、时间轴、控制点和负向词锚点均未被泛化或删减。
- 用户选择历史公路 rap archetype 时，完整保留具体人物造型、荒漠公路、持续向前走、后退跟拍、快嘴口型、节奏型手势、轻度超现实上限及 0–30 秒每 5 秒时间轴。
- 关键帧模式已产出 3–5 张可读预览，覆盖亮相、口型 / 手势、高能句推进、hook 和收束，并进入最终 PE。
- 生成后已逐节点验收；任一关键失败项出现时已判失败并重新生成，而非宣称完成。

## 用户解释口径
- 如果用户只给新音频，这个 Skill 输出的是 **同等级强控制度的说唱类 prompt**，不是对旧视频逐镜头硬复刻。
- 如果用户在问卷中选择“直接生成”，立即进入生成，只回复简短状态句；后台 PE 随生成任务提交，聊天正文不展示。
- 如果用户已经写出一段细到可执行的脚本，优先保留原脚本锚点，不要为求泛化把它写虚。
- 如果用户没有给角色结构、人物风格或表演设计，先主动给一版推荐生成方案，再通过问卷确认让用户决定是否调整。
- 如果用户要求“还是之前那个 rap 参考的感觉”，默认保留：**强口型、强手势、人物压迫感、镜头硬朗、场景服务人物、角色风格明确** 这六个核心锚点。
- 如果用户选择“先生成分镜关键帧图片预览”，关键帧必须被主提示词、控制点和负向词共同引用。
- 如果参考链接失效、无法下载或只返回页面文本，明确要求上传实际视频，不得假装看过或声称已完成分析。
- 如果用户在确认后补充参考，旧确认自动失效；先真实分析并重写方案、时间轴和后台 PE，再请用户重新确认。
- 如果成片没有通过口型、手势、身份连续性、运动轨迹、主运镜、参考硬锚或音轨验收，不得用“已完成”口径，必须说明失败节点并重新生成。
