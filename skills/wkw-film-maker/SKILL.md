## 核心原则

### 持久引擎（因果链）
原著忠实度 → 视觉化行为翻译 → 三维景深构建 → 多角色音色绑定 → 高频自动切镜 → 状态账本连贯 → 诗意声画合成

本技能的核心思维模型：以"像摄像机一样思考"为起点，将所有文学性心理描写严格翻译为可拍摄的物理动作与微表情；通过前景-主体-背景三层景深构建窥视感空间；利用15秒分段内3-5个自动切镜实现电影节奏；以视觉状态账本保证多段衔接零穿帮；最终通过方言对白、环境音效与特色器乐BGM完成王家卫式诗意美学闭环。

### 最高执行铁律
1. **拒绝静态PPT感与沉闷默片**：严禁设计无动作、慢动作或纯PPT过渡的静态分镜，拒绝生成无声、无对白的纯默片素材。人物必须有极其生动细腻的情绪表情（尤其是眼神的忧郁与试探），角色可自由移动、转头、互动，动作自然且富有故事感，不强制面对镜头。
2. **充分释放自动切镜潜力**：将长剧本拆分为多段15秒视频，每段15秒内部规划3-5个高频镜头切片（自动切镜），单次生成即可完成段内多镜头叙事。
3. **空间三维深度与光影阻隔**：拒绝将三维画面二维化或扁平化，画面必须具有清晰的前景-主体-背景三维空间景深。善于利用门框、窗帘、玻璃等前景遮挡物制造窥视感与空间阻隔。
4. **双模态多角色参考流**：不生成多宫格参考，直接使用多角色设定图与场景设定图进行多模态参考绑定，最大化还原多角色与场景一致性。
5. **纯中文提示词铁律**：所有提示词必须完全且固定使用中文书写，禁止包含任何英文单词、英文字标或英文字符。所有画面描述、风格描述、动作指令及负面词等，均必须采用纯中文。

### 可证伪质量测试
如果观众在任意3秒画面内无法同时感知到：①至少一层前景遮挡形成的空间阻隔感、②角色面部存在可辨识的情绪微表情（非面瘫）、③画面存在明确的光源方向与景深虚化，则该片段不合格，必须打回重制。如果相邻两段15秒视频衔接处出现角色瞬移、道具状态突变、光源方向反转，则该衔接不合格。

## 输入诊断

在开始任何创作前，必须明确或合理假设以下维度，并向用户确认：

| 诊断维度 | 选项/要求 | 默认值 |

| 参考素材 | 用户是否自带角色/场景参考图 | 无则生成 |

**方言-BGM乐器对应关系（必须牢记）**：
- 粤语：大提琴拨弦 + 慢速萨克斯风 + 复古电吉他（重混响）—— 八九十年代香港霓虹宿命感
- 上海话：爵士钢琴 + 慵懒萨克斯风 + 低音提琴拨弦 —— 《繁花》式海派复古华丽
- 闽南语：古典吉他 + 怀旧手风琴 + 忧郁小提琴/长笛 —— 海岛雨夜浪漫漂泊感
- 普通话/其他：大提琴拨弦 + 忧郁小提琴 + 复古探戈手风琴 —— 经典暧昧孤独美学

## 工作流（八阶段强制暂停SOP）

**全局规则**：每一阶段涉及的用户沟通确认点均为硬性暂停点，严禁一次性跑完。若用户提出修改，必须回退至对应步骤重新确立。所有阶段产出规格必须严格遵守第一阶段确认的Final_Video_Spec，不得私自更改。

---

### 阶段1：读取输入与规格确认【强制暂停点】

1. 读取用户输入的故事素材或剧情需求。
2. 向用户提出五项前置选择（模型、分辨率、画面比例、输出语言/方言、故事内容确认）。
3. 将确认结果写入 `Final_Video_Spec.md` 顶部，后续所有步骤严格遵守。
4. 若用户未提供具体故事，必须先沟通确认故事框架和核心内容，得到确认后才进入阶段2。
5. 暂停，向用户展示规格确认结果，等待确认。

---

### 阶段2：故事框架与分镜脚本设计【强制暂停点】

1. 读取 `references/formats/multimodal-analysis.md` 和 `references/formats/storyboard-design.md`。
2. 以"影视剧本总编剧/原著忠实守护者"身份进行剧本改编：
   - 像摄像机一样思考：镜头拍不到的绝对不写，杜绝主观心理叙事描述。
   - 像剪辑师一样思考：精简过长日常寒暄与风景描写，直奔主题节奏。
   - 像原著作者一样思考：100%尊重原著情节、人物关系与核心走向，禁止擅自增减情节或添加无根据的戏剧冲突，遵循原著自然平稳收尾，拒绝刻意留下廉价悬念。
3. 执行场景时空严格拆分：地点/空间/时间发生任何转移，必须划分为新的独立分镜场景，冠以标准场景标题。
4. 建立**视觉状态账本（Visual State Ledger）**：为每段15秒视频的衔接点建立状态锚点（记录角色物理位置、姿态、道具状态、环境光影），确保前后素材连贯不脱节。
5. 每段15秒视频拆解为3-5个内部子镜头（自动切镜），每个子镜头包含：前景-主体-背景空间层次、生动面部动作、自然连贯的多角色对白/内心独白与环境音效。
6. 对白/内心独白使用阶段1确认的方言/语言书写，使用地道方言词汇和语气助词。
7. 严格使用标准化符号排版：【※】场景标志、【△】动作描写（顶格）、【 】技术性标注、（ ）语气与微表情控制。动作与对白采用分离式电影排版。
8. 暂停，向用户展示完整分镜脚本，等待确认。

---

### 阶段3：多角色与场景设定图生成【询问并暂停】

1. 读取 `references/formats/prompt-engineering.md` 中图像提示词章节。
2. **交互检查**：明确询问用户是否需要上传自己的角色参考图和场景参考图。
   - 若用户选择上传：暂停等待用户上传资产，收到后进行绑定。
   - 若用户选择生成：继续以下生成流程。
3. **多角色参考图生成**：为每个角色分别生成独立的"多视角角色设定图"——四图水平排列的单张横向拼版图（左侧大幅半身特写占40%宽度，往右依次正面全身、侧面全身、背面全身），纯白背景，柔和工作室光，真人实拍风格，强调皮肤毛孔、发丝质感与次表面散射。
4. **场景参考图生成**：生成具备真实物理透视、低照度光影、细节逼真、符合选定美学色盘的场景设定图，明确前景-主体-背景三层空间结构。
5. 展示所有生成的设定图，暂停并请求用户确认。若用户不满意，根据反馈调整后重新生成。

---

### 阶段4：角色设定视频生成与音色提取【强制暂停点】

1. 读取 `references/formats/video-generation.md`。
2. **4.1 生成角色设定视频**：分别引用每个角色的参考图，使用多模态参考生成能力，锁定使用快速模型生成4-6秒的角色设定/对白短视频，展示角色初始说话状态和声音特征，提示词中包含简短台词和语气描述。
3. **4.2 提取音色**：从每个角色设定视频中分别提取音频音色特征。
4. **4.3 注册并绑定音色资产**：将提取出的音频注册并绑定为对应角色的声音参考资产，确保后续所有对白、内心独白均使用该音色，杜绝无声默片或声音串音。
5. **4.4 失败处理**：若无法提取音频、音色不可用或方言明显错误，必须暂停并告知用户该角色音色提取失败，请用户选择重生成角色设定视频或提供音频参考。**严禁使用任何TTS/语音合成路径冒充"从视频提取出的音色"。**
6. 暂停，向用户汇报所有角色音色提取成功。

---

### 阶段5：视频素材生成【逐步生成并暂停确认】

1. 读取 `references/formats/prompt-engineering.md` 中视频提示词模板章节。
2. 逐段生成15秒视频：使用多模态参考生成能力，同时传入绑定的多角色参考图与场景参考图作为多模态输入，并引入对应角色的声音参考资产作为口型驱动源。
3. 每段15秒视频的提示词必须严格遵循四模块结构：【全局视觉与美学基调】→【人物与场景设定】→【剧本与动作时间线】（含0-3.5s/3.5-7.5s/7.5-12s/12-15s四个时间切片，每个切片含镜头机位、前景/主体/背景视觉画面、听觉声效）→【生成约束与负面提示词】。
4. 每段视频提示词中必须：
   - 在第一个时间切片精准继承上一段结尾的状态锚点（位置、姿态、道具、光影）。
   - 在最后一个时间切片为下一段建立清晰的终态锚点。
   - 对白使用方言前缀格式（如粤语{角色名："对白文本"}），绑定对应角色声音资产。
   - 环境音效使用<...>包装，仅描述物理拟音，严禁出现BGM/旋律描述。
   - 尾部带上纯中文负向词：无字幕，无音乐，无文字，无标识。
5. 每段15秒视频生成后，必须暂停并与用户确认，同时根据视觉状态账本校验衔接状态，得到首肯后再生成下一段。

---

### 阶段6：背景音乐BGM方向确认与生成【强制暂停点】

1. 根据阶段1选定的输出语言/方言，主动向用户推荐对应的特色乐器组合与BGM风格（见输入诊断中的方言-BGM对应表）。
2. 与用户沟通确认BGM方向，允许用户调整乐器组合和情绪基调。
3. 确认方向后，使用纯乐器BGM生成能力生成背景音乐。提示词必须：
   - 声明纯乐器/无声乐。
   - 组合至少2-3种王家卫标志性乐器。
   - 描述音场质感（亲密原声录音棚、温暖黑胶质感、干声混音）。
   - 严禁写入任何知名音乐人、歌手或乐队名字。
   - 全程使用纯中文描述。
4. 暂停，向用户展示BGM，等待确认。

---

### 阶段7：时间线合成与剪辑【强制暂停点】

1. 读取 `references/formats/video-assembly.md`。
2. 导入所有音轨（Foley环境音效、多角色对白/内心独白、背景音乐BGM）与视频轨。
3. 在时间线上执行精确卡点与无缝硬切：
   - BGM的音乐剪辑点、强重音、乐器段落必须与画面内部自动切镜的重拍完全对齐。
   - 15秒段落之间采用动作衔接切、门开合、镜头横摆等电影化硬转，严禁使用花字、闪白、无物理依据的转场特效。
   - 多镜头切片内部采用自然硬切。
4. 执行全面质检：
   - 视觉状态账本核对：相邻段落接缝处角色位置、姿态、衣物、道具、光源方向是否完全契合。
   - 动作衔接：前一段结尾动作在后一段开头是否完成闭环。
   - 三维景深：每个镜头是否有前景阻隔、主体清晰、背景虚化。
   - 表情质量：角色是否有生动微表情，拒绝面瘫和僵硬。
   - 声音质量：对白声场与景别匹配，无串音、无默片段落。
5. 若发现任何不合格项，精准定位并打回对应段落重制。
6. 暂停，向用户展示合成初版，等待确认。

---

### 阶段8：王家卫电影海报风格封面图设计【分步延展并暂停确认】

1. 先生成16:9比例的主封面图——高对比度低照度光影、强烈冷暖色彩对比、复古衬线体电影标题、诗意中英双语台词排版、平视视角、暧昧孤独氛围。
2. 暂停展示16:9封面图，与用户沟通确认。
3. 用户确认通过后，以16:9图为风格参考，延展生成3:4和4:3两个比例的封面图。
4. 完成全案输出。

## 静默自检

交付每一阶段产物前，内部执行以下质检清单，发现弱项立即重写，不将问题暴露给用户：

1. **纯中文检查**：所有提示词、剧本、描述中是否夹杂任何英文字符（包括品牌名、技术参数缩写如4K/24fps/F1.2等——这些必须翻译为中文如"超高清分辨率/电影标准帧率/大光圈"）。
2. **景深三层次检查**：每个镜头描述是否明确包含前景、主体、背景三层。
3. **微表情检查**：每个出场角色是否被赋予了具体的面部肌肉/眼神描写，而非笼统的"悲伤""开心"。
4. **状态账本检查**：每段15秒视频的首尾是否有明确的状态锚点记录，衔接处是否可能出现穿帮。
5. **默片检查**：每段视频是否包含至少一处对白/内心独白或明确的环境音效，杜绝无声段落。
6. **静态检查**：是否存在超过3秒的无动作静态描写或慢动作堆砌，是否有PPT式过渡。
7. **方言一致性检查**：对白文本是否使用了确认的方言书写，BGM乐器组合是否与方言匹配。
8. **BGM隔离检查**：视频提示词中是否意外写入了BGM/旋律描述（BGM只在阶段6单独生成，视频素材本身严禁包含音乐描述）。
9. **原著忠实度检查**：是否擅自添加了原著中不存在的情节冲突或廉价悬念结尾。
10. **配额检查**：全片倾斜构图、抽帧降格、极度对称构图、极速横摆是否各控制在最多1次。
