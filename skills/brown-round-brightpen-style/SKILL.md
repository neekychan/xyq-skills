# 棕圆亮笔风格

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片编辑 prompt 与视频 prompt 的最开头，让**用户上传的一批图片资产**被统一转绘成同一套棕圆亮笔画风，并让由这批资产生成的视频成片与图片资产画风完全一致。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

> **关键用法区别（务必先读）：** 本技能**不从零画角色/场景**。用户必须**先上传一批自己已确定的图片资产**（角色形象或场景分镜），本技能的第一职责是**用风格锚定词把这些图片资产风格化转绘（图生图 / 图片编辑）**，然后把风格化后的资产**整体**送去做视频生成。做图片风格化时，**直接使用风格锚定词作为该图片的编辑提示词，不要再额外添加任何其它内容**，完全基于用户原图做画风转绘。

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 用户图片资产被统一转绘为同一画风 → 视频画风与风格化后的图片资产一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把风格化后的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一套画风 / 同一部作品里出来的」（描边粗细、包边圆钝度、颗粒肌理、几何化程度、配色不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一套棕圆亮笔风格作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **棕圆亮笔风格，粗黑线/强轮廓，深棕圆钝包边，轻微肌理，轻蜡纸面颗粒，高度几何化，圆扁可爱简形，高饱和/鲜艳，亮橙绿高明度**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟本条内容。顺序恒为「锚定词 → 具体内容」，不得颠倒。
2. **逐字一致：** 每条图片编辑 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要处理的**所有**图片资产与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **图片风格化时锚定词即全部提示词（本技能专属硬规则）：** 对用户上传的图片资产做风格化转绘时，**编辑提示词 = 风格锚定词逐字原文，且不得追加任何其它描述**（不加镜头、不加动作、不加"保持人物一致""高清"等任何额外话术）。完全依赖原图内容 + 锚定词完成转绘。
5. **视频 prompt 不污染具体描述：** 视频阶段，锚定词只负责画风；镜头、动作、构图、人物、场景、台词、音效等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
6. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它「风格 / 画风」类 skill 搭配时的合并规则（务必遵守）

当本技能与其它风格 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体内容。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、图片风格化阶段仍只用（合并后的）锚定词作为编辑提示词、不污染视频具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与「非风格类」skill 搭配时的结合规则（务必遵守，最高优先级之一）

当本技能与非风格类 skill 同时被调用时（典型如「营销短片 / 广告短片 / 剧情短片 / seedance 类」创作 skill，或任何决定"讲什么故事、怎么分镜、怎么运镜"的 skill）：

- **职责分层，互不覆盖：** 那些 skill 负责**内容与叙事**（讲什么、分几个镜头、怎么运镜、台词、节奏）；本技能负责**画风一致性**（所有产物长成棕圆亮笔风格）。两者叠加而非二选一。
- **本技能的注入规则不可被架空：** 即使加载了其它 skill 并按它的模板产出 prompt，最终交给图片编辑 / 视频生成的**每一条 prompt 仍必须在最开头逐字注入本技能锚定词**；图片资产风格化阶段仍必须只用锚定词作为编辑提示词。其它 skill 的输出模板一律视为"锚定词之后的具体内容"。
- **顺序：** 先用其它 skill 产出叙事 / 分镜 / 镜头文本 → 再由本技能在每条 prompt 头部注入锚定词后才真正提交生成。任何时候"叙事 skill 的模板"都不能挤掉或替换头部锚定词。
- **冲突判定：** 若其它 skill 要求把风格描述写在中间或省略画风，以本技能为准——锚定词必须在最前且逐字完整。

## 输入

- **必需：** 用户上传的一批**已确定的图片资产**（角色形象图 / 场景分镜图），以及一句创作意图（想做成什么样的视频 / 讲什么）。
- **可选：** 是否与其它风格 skill 叠加；视频画幅 / 时长偏好；哪些图片对应哪个角色 / 分镜；是否需要某张风格化后的图片作为视频首帧参考。
- **素材缺失只追问缺失项：** 本技能强依赖用户上传的图片资产——**若用户没有上传任何图片，先明确请用户上传图片资产**（这是本技能的前置条件）。若图片已给但缺分镜 / 意图，可按常规补齐一版分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认前置条件与锚定词形态。**
   - 先确认用户已上传图片资产；未上传则请用户先上传。
   - 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。
2. **风格化转绘用户图片资产（逐张，本技能核心步骤）。** 对用户上传的**每一张**图片，调用图片编辑 / 图生图，**编辑提示词 = 锚定词逐字原文（不追加任何其它内容）**，基于该原图做画风转绘。所有图片共用同一份锚定词。逐张生成后展示给用户。
3. **图片质检与返工。** 对照质量测试检查风格化后一致性；若某张明显跑偏（描边 / 包边 / 颗粒 / 配色不统一），对该图重新用同一锚定词转绘（锚定词不动），直到整批风格化图片观感统一。
4. **撰写动画脚本 / 分镜（调用内置 system prompt）。** 结合**风格化后的图片资产** + 用户意图，调用 `references/seedance_story_system_prompt.md` 里的「Seedance 高密度剧情短片提示词生成器」，产出详细动画脚本与分镜，作为视频生成参考。
5. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词逐字原文 + "，" + 该段（来自 Step 4 的）镜头 / 动作 / 画面 / 声音描述`，用**风格化后的图片资产**作为画面参考再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
6. **视频质检与返工。** 检查视频画风是否与风格化后的图片资产一致；跑偏则改具体描述后重生（锚定词不动）。
7. **交付并展示。** 把最终的风格化图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

**图片风格化 prompt（用户原图 → 转绘）：**

```
<锚定词逐字原文>
```
（仅此一段，**不追加任何其它内容**，配合用户原图作为输入。）

**视频 prompt：**

```
<锚定词逐字原文>，<本段具体画面 / 镜头 / 动作 / 声音描述>
```

- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。

**示例（示意）：**

- 图片风格化（对用户上传的角色原图）编辑 prompt：
  `棕圆亮笔风格，粗黑线/强轮廓，深棕圆钝包边，轻微肌理，轻蜡纸面颗粒，高度几何化，圆扁可爱简形，高饱和/鲜艳，亮橙绿高明度`
- 视频 prompt：
  `棕圆亮笔风格，粗黑线/强轮廓，深棕圆钝包边，轻微肌理，轻蜡纸面颗粒，高度几何化，圆扁可爱简形，高饱和/鲜艳，亮橙绿高明度，0-2s 圆头小角色（@图片1）从画面右侧蹦入，Fast Push In 推至特写；2-5s 它抬手指向前方，眉毛猛挑；5-9s 环绕跟拍展示奔跑……`

## 内置故事 System Prompt

本技能捆绑了一份专门用于动画故事编写的 system prompt，位于 `references/seedance_story_system_prompt.md`。它的输入是**风格化处理后的最终图像资产 + 用户意图描述**，输出是详细的高密度动画脚本与分镜，供视频生成参考。在 Step 4 撰写脚本时加载并遵循它；它产出的分镜文本作为"锚定词之后的具体内容"进入视频 prompt。

## 静默自检（交付前内部跑一遍，不展示给用户）

- [ ] 是否已确认用户上传了图片资产，并对**每一张**都做了风格化转绘？
- [ ] 图片风格化阶段，编辑提示词是否**只有锚定词逐字原文、未追加任何其它内容**？
- [ ] 本次每一条视频 prompt 的**最开头**都逐字出现了锚定词（或合并锚定词）？
- [ ] 同一批任务内锚定词是否字节级一致、无任何一条被改写 / 漏注入？
- [ ] 视频阶段锚定词之后是否都保留了具体画面描述，没有被风格词挤掉？
- [ ] 若叠加了其它风格 skill，是否按合并规则拼接、规则未变、未删减本技能锚定词？
- [ ] 若叠加了非风格类（如营销短片）skill，其叙事模板是否被安放在锚定词之后、而没有架空头部锚定词？
- [ ] 图片之间、图片与视频之间画风是否通过了「同一套棕圆亮笔风格作品」的一致性测试？
- [ ] 超过 15s 的成片是否才做了分段；≤15s 的是否一次生成？

发现弱项就在交付前重写对应 prompt 并重生，不要把本清单暴露给用户。
