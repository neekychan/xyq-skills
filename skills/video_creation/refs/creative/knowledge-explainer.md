# 知识科普/教程创作指南

> 落点信号：讲清楚一件事、解释原理、科学现象、"为什么"（→ §科普）；教程、教学、步骤演示、"怎么做"（→ §教程）。
> 复合意图："用故事讲原理"落点=讲原理，本文件为主，仅借 `creative/narrative-suite.md` §A"情绪弧线/钩子"单条，不整节读入。

## 节奏总纲（与故事类相反，先读）

科普/教程是**信息密度驱动**体裁：旁白高密度贯穿、每秒画面都有信息，与故事类"留白/高潮停顿/缓推建世界"的节奏相反。

- 旁白按用户时长**写足**：旁白耗时区间须覆盖总时长的 75% 以上（创意阶段按经验估写，分镜阶段由 `count_chars.py` 工具输出坐实），不足则补知识点/例子/追问，禁止用空镜运镜填时长。总时长超出叙事公式合计时，扩展"类比演进"段的知识点数量，其余段不拉长
- 开场直入事件，禁止空镜/大远景/环境铺陈式开场
- 全片无"旁白暂停让画面说话"的段落——画面事件与旁白始终并行

## §科普（原理/科学现象/解释）

### 事实检索（写创意前先做）

科普是强事实依赖体裁，机制解释、数据、案例写错即硬伤。写创意前主动联网搜索该主题，补齐两类信息——①**机制/原理的权威表述**（与自身记忆冲突时以检索结果为准）②**具体翻车案例或反直觉事实**（供钩子与落点取材，真实案例比编造案例更抓人）。检索 1-2 次、取信权威来源即可；无法联网时按记忆执行，不确定的数字/案例一律模糊处理或不写，禁止编造统计数据与出处。**检索时机**：若触发切入角度提案或意图澄清问卷，先提问、等用户回答后再检索。

### 切入角度提案（写创意前先做）

用户只给主题、未指定讲法时，先按不同**叙事结构**构思 2-3 个切入角度（类比演绎 / 破除误解 / 对比实验 / 时间线溯源……），并入意图澄清问卷让用户选择，标注推荐项及一句话理由；问卷不触发时单独就角度提问一次。判据：**换叙事结构才算一个角度**，同一结构换措辞不算（"AI为什么出错" vs "揭秘AI错误"是同一个角度）。用户已指定讲法或明确要求直接做 → 跳过本步。

### 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 抽象设问/概念空镜开场 | 观众 3 秒划走 | 钩子 = 一个可拍的具体翻车/反差事件（有主体、有动作、有后果） |
| "本期视频带你了解X""今天我们来学习X"式开场 | 套话预告，无信息缺口 | 直接进翻车事件或反直觉事实，让观众自己产生"为什么" |
| 类比载体静态陈列配旁白 | 画面沦为配图，"有画面的PPT" | 类比必须"发生"：载体做事→出错/变化→承担后果 |
| 每个镜头换一个比喻世界 | 叙事割裂，无记忆点 | 全片类比统一在一个载体/世界观内连续展开 |
| 原因/要点并列罗列 | 平铺无张力，观众中途流失 | 悬念链：每镜结尾抛出下一镜要回答的问题 |

### 强制规则

1. **钩子具象化**：开场必须是一个可拍的具体事件（谁、做了什么、翻车/反差在哪），禁止用抽象提问配空镜。提问式钩子合格的唯一形态：问题绑定一个反常的具体画面（画面本身就是悬念，如"水库上漂着九千六百万个黑球"）。自检：钩子能否用一句"主体+动作+意外结果"描述？不能 → 重写
2. **可视化路径分流**（每个知识点先分型再定画面，禁止不分型一律套类比）：
   - **抽象机制**（概率、算法、场、免疫应答）→ 类比事件化：知识点 = 类比载体的一段遭遇（动作→变化→后果）。自检：删掉旁白后这段画面仍是一个有起因和结果的事件
   - **真实过程/真实案例**（火山喷发、事故经过、生物行为）→ 直接还原真实画面或案例重演，**禁止强行套类比**——真实过程本身比比喻更准更震撼
   - **数据/对比型**（A比B多多少、快多少）→ 实物对比画面：数量用可数实体堆叠、差距用体积/高度/速度反差呈现，禁止图表
3. **载体贯穿**（仅约束类比路径）：走类比的知识点共用一个载体/世界观，禁止逐镜更换比喻世界；与真实还原、实物对比路径的镜头可以共存
4. **一镜一概念**：每个镜头只传达一个知识点
5. **悬念链**：镜头间禁止"原因一/原因二"式并列，每镜结尾埋下一镜的问题或反直觉事实，最后一个知识点处汇合成"原来如此"的认知高潮。自检：相邻两段的逻辑连接词必须是"因此/但是/结果"，出现"然后/另外/其次" → 该衔接重写
6. **落点可带走**：收尾给观众一个用得上的行动或判断（怎么用/怎么避坑/怎么验证），禁止"了解了X，才能更好Y"式空泛升华。判据：落点合格＝"下次遇到__，就__"能填出具体内容（例："下次AI报数字，先让它给出处"）；填不出 → 重写

### 叙事公式（骨架按选定的切入角度取）

**类比演绎**（抽象机制主导时）：

```
具象钩子 (5s)
  → 一个可拍的翻车/反差事件，主体+动作+意外结果

建立载体 (10s)
  → 引入贯穿全片的类比载体，与观众日常经验挂钩

类比演进 (15-20s)
  → 载体连续遭遇各知识点，每段结尾钩住下一段

恍然时刻 (10s)
  → 前面埋的线索汇合，认知高潮"原来如此"

可带走的落点 (5s)
  → 一句观众能立即使用的行动/判断收尾
```

**破除误解**（多数人认知有误时，教学实验验证过的结构——先呈现误解再重建，比直接陈述事实记得牢）：

```
误解陈列 (5-8s) → 把大多数人的错误认知演出来（有人照着做/照着说）
当场翻车 (8-10s) → 按错误认知行动，现实给出意外结果
拆解 (15-20s) → 逐层揭示为什么错，按分流规则选可视化路径
重建+落点 (8-10s) → 正确认知落定，给可带走的判断
```

**对比实验 / 时间线溯源**：骨架 = 钩子 + 逐轮对比（或逐期演变）+ 结论落点，每轮对比/每个时期一个镜头，悬念链照常适用。

### 类比转化速查

| 抽象概念 | 事件化类比（动作→后果） |
|---------|---------|
| 引力/黑洞 | 铁球砸上布面凹陷，周围弹珠滚落坠入 |
| DNA复制 | 拉链拉开，每颗旧齿当场咬合出新齿 |
| 免疫系统 | 城堡哨兵识破伪装的入侵者并围剿 |

原则：类比选自观众日常经验，且必须写成"载体做事→出结果"的事件，按此思路自行扩展。

## §教程（步骤演示/教学/"怎么做"）

科普规则中钩子具象化、一镜一概念（此处为一镜一步骤）、落点可带走照常适用；类比载体规则不适用——教程画面直接演示真实操作。

1. **步骤即镜头**：按操作步骤分镜，每镜完整呈现"操作动作→即时结果"，禁止只拍成品或只拍讲解者
2. **错误对照**：高频出错的步骤补一个"错误做法→翻车后果"对照画面，比正确演示更抓人
3. **钩子用成品或翻车**：开场先亮最终成果或最常见的失败现场，再回到第一步

## 题材-画风推荐

| 题材领域 | 推荐画风 | 理由 |
|---------|---------|------|
| 天文/物理/太空 | 3D CG / 写实科幻 | 宏观尺度需要真实感 |
| 生物/化学/医学 | 3D动画 / 微观可视化 | 微观世界需要建模 |
| 历史/人文/社会 | 青绿山水 / 工笔淡彩 / 写实 | 文化感+时代感 |
| 数学/逻辑/编程 | 日系简洁插画 | 清晰传达逻辑关系（避免信息图/图表风——视频模型渲染文字不稳定） |
| 工程/技术/日常/教程 | 写实 / 3D建模 | 与现实物件对应 |
| 儿童科普 | 3D皮克斯风 / 2D动漫 | 亲切有趣 |

## 失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| 抽象概念无可视化方案（既无类比也无还原/对比画面） | 观众听不懂，看不进去 | 按可视化路径分流规则选路径，类比参考速查表 |
| 一个镜头讲多个概念/步骤 | 信息过载 | 一镜一概念 |
| 画风与题材不匹配 | 违和感 | 按题材-画风推荐表选择 |
| 静音测试不过：关声音看不出每段在讲什么 | 信息全压给旁白，观感=有配图的播客 | 该段画面重写为事件化类比/操作演示 |
| 旁白耗时远小于总时长 | 段尾空转，节奏拖沓 | 补知识点/例子写足，或降总时长 |
| 数据知识点写成图表/数字屏幕画面 | 视频模型渲染文字不稳定，数字错乱=硬伤 | 换实物对比：可数实体堆叠、体积/高度/速度反差 |
