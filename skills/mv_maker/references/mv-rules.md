# MV Maker 核心红线与防翻车铁律 (mv-rules.md)

本文件定义全流派通用的**强制红线、素材职务规范与防翻车约束**。在构造任何 Prompt 或调用生成工具前必须逐条遵守。

---

## 一、音乐与母带铁律（禁止伪造音乐、乱配BGM与口型时差错位）

1. **@视频1 分段音频精准切片与起始偏移铁律（口型对齐核心）**：
   - 当制作第 N 段视频（时间区间为 `T_start ~ T_end`）时，制作黑屏 MP4 必须显式使用 `-ss T_start -t (T_end - T_start)` 截取该分段对应的精确音频切片；
   - **【红线禁令】严禁直接将从 0s 开始的完整原曲黑屏视频传给中后段视频！** 否则模型在生成 Verse/Chorus 时实际上听到的是 Intro 前奏音频并据此动嘴，导致成片拼接后口型 100% 严重错乱！
2. **@视频1 作为唯一背景音乐与节奏强绑定铁律（严禁具体描述音频内容）**：
   - 有上传音频时，传入的黑屏视频（`@视频1`）是**整段视频唯一合法且必须严格对齐的背景音乐与节奏基准**；
   - **【标准声明句式】**：`@视频1 提供全段唯一背景音乐与节拍时间轴，不提供任何画面内容。画面动作与节奏必须严格跟随 @视频1 的音频作为 BGM，不擅自编曲，严禁生成任何其他无关背景音乐或杂乱音轨。`
   - **【红线禁令】严禁在 Prompt 中具体描述音频的编曲、乐器、BPM 或曲风细节（如禁止写“175BPM J-Core失真电吉他碎拍”等）**！文字若出现乐器和编曲描述，模型 cross-attention 会误以为需要根据文字重新生成音乐，从而脱离 @视频1 的真实音轨自行编曲，导致背景声画脱节与假声音干扰。
3. **AI 自主音乐创作与禁止脚本伪造 BGM 铁律**：
   - 当用户未上传音频但需要制作带音乐的 MV 时，**必须统一调用 `sandbox_generate_audio` (Type: "music") 按照专业 MusicPrompt 与歌词结构工程生成真实物理音频**；
   - 音频生成完毕后，自动将其作为目标母带音频，无缝接入 `audio-director` 事实源分析与后续 MV 制作管线；
   - **【红线禁令】严禁使用 Python / numpy / scipy 脚本合成正弦波、白噪音或假音乐充当母带**；仅在用户显式明确要求“纯画面无声版”时才交付无声音视频。
4. **原生视频直拼不剪辑与 FFmpeg 成片合成法则**：
   - 视频生成模型产出的各段视频与音频天然对齐，**严禁对生成的视频做二次 `-t` 硬裁切或重新编码（`-an`）**；
   - **【FFmpeg 纯脚本合成】**：成片拼接与母带混流统一使用 `sandbox_bash` 运行 FFmpeg 脚本完成，直接拼接生成的原生视频并混入母带音频；
   - **【末端容错法则】**：若视频总长与音频母带末端存在轻微 gap，**统一以视频为准**，保留完整生成的画面，音频自然对齐；
   - **【歌词字幕法则】**：若用户需要字幕，直接根据 `beats.md` 歌词时间轴生成 `/workspace/assets/lyrics.srt` 并由 FFmpeg 烧录，禁止依赖平台 ASR 自动转写。
5. **用户上传音频版权与权限预检硬门禁 (Copyright Enforcement for Uploaded Audio)**：
   - 当用户上传外部音频（分支 A）时，`extract_lyrics` 是必须执行的版权与权限预检步骤；
   - 若工具返回“`音频权限预检未通过，禁止继续生产。请更换有权限的音频后重试；在预检通过前不得继续调用视频生成、分镜或渲染工具。`”，**必须立即停止生产，明确告知用户该音乐无版权不可以使用，禁止开展后续视频生成、分镜或渲染流程**；
   - **【AI 原创音乐免卡点豁免】**：若音乐是由 AI 自主创作生成（分支 B），属于系统全新生成的原创声学资产，**无需经过版权卡点/预检**，可直接基于生成的歌词与时间轴进入后续 MV 制作管线。
6. **禁止口号式纯文字假卡点**：
   - 未传入物理音频（干声 / 黑屏 MP4）时，严禁在 Prompt 中写虚假的 `on the beat` 或 `每四拍闪烁一次`。无音频时应使用视觉动作力学（重量转移、步伐停顿、镜头推拉）作为节奏支撑。

## 二、素材职务显式声明与场景纯文本驱动铁律 (Asset Roles & Scene Text-Driven)

严禁在 Prompt 中直接书写模糊的“参考@图片1”或“参考@视频1”。每个多模态素材必须在 Prompt 开头赋予唯一、不可混淆的**职务说明句**：

| 素材类型 | 标准职务声明格式 | 作用与约束 |
|---|---|---|
| **单人主角时 `@图片1`** | `@图片1 的人物作为唯一主角，严格锁定五官、发型、妆容与服装款式。` | 锁定主角 ID，防止面部漂移 |
| **女团/多人时 `@图片1..@图片N`** | `@图片1 为Member1 C位主唱，@图片2 为Member2 领舞，@图片3 为Member3 Rap担当，@图片4 为Member4 副主唱，分别锁定各成员五官、发型与服装。全片各段必须全量传入 ImageList。` | 确保全员 ID 稳定且随时同框 |
| **`@视频1` (黑屏音频)** | `@视频1 提供全段唯一背景音乐与节拍时间轴，不提供任何画面内容。画面动作与节奏必须严格跟随 @视频1 的音频作为 BGM，不擅自编曲，严禁生成任何其他无关背景音乐或杂乱音轨。` | 强力锁定音频源，严禁具体描述音频内容，防止模型自行编曲 |
| **`@音频1` (干声人声)** | `@音频1 是干声人声音轨，严格驱动口型咬字，不要重新演唱其他旋律。` | 防止整轨伴奏混淆口型驱动 |

### 场景纯文本驱动与防白底漂浮铁律 (Anti-White-Void)：
1. **场景纯文本驱动（严禁生成场景参考图）**：严禁在 Phase 2 使用生图工具生成场景空镜图，ImageList 仅传入纯白底主角定妆照，场景空间与光影完全交由视频 Prompt 文字驱动；
2. **【红线禁令】严禁使用“纯白底/纯白空间/冷白通道”作为背景**：杜绝 Prompt 中出现“极简纯白底”、“纯白高反差空间”等空白描述，防止视频模型渲染出毛坯未完成式的空洞死板白墙；
3. **「全局定调世界观，微镜头轻量聚焦」黄金平衡法则（绝不每镜重复堆砌 3 层）**：
   - **宏观定调（Layer 2 全局概述，整段只写 1 遍）**：在整段 Prompt 开头用一句精炼语言交代世界观、材质与光影主色（如：`赛博朋克国潮动态漫美学，深黑镜面地面搭配流动代码雨与赛博建筑纵深...`），给模型注入宏观美学场域；
   - **微镜头轻量聚焦（Layer 3 画面阶段，绝不逐镜死板罗列 3 层）**：
     - 各微镜头专注描写**机位、主体动作、排版动能与光影反射 (Rim Light)**；
     - 特写镜头只写人物动作与局部倒影（如 `瞳孔倒映警报红光`），**完全无需重复描述大楼与地面**；
     - 大景别镜头仅带 3~6 字轻量锚点（如 `背景为深蓝数据深渊`），**把具体的建筑形态、几何纵深与动态细节 100% 留给模型自由发挥**；
   - **禁止过度写死微观道具坐标**（如“左边第3根柱子距人物2米...”——会造成 cross-attention 过载并破坏模型自发的透视美感）；
4. **瞬态爆白与实体场景严格区分**：白光过曝只允许作为 1~2 帧瞬态闪光 (`1-Frame Invert Flash` 或 `2-Frame Light Leak 爆白切屏`)，闪光过后必须立即露出具体实体场景，严禁持续数秒的白色死板真空。

## 三、3D 实体文字特效与视觉分轨原则 (Typography & Visual Separation)

1. **拒绝廉价压屏字幕**：
   - 严禁在歌手纯面部特写中添加“普通平面字幕”、“歌词浮现”等描述，防止文字糊脸或导致嘴部与五官扭曲。
2. **3D 实体化文字精准定位（Intro / Rap / 标题层专属，齐舞绝不遮脸）**：
   - 3D 实体前后视差文字 (Typography Sandwich) 与穿透大字 (Letter Punch-Through) 必须**精准限制在 Intro 歌名/Logo 亮相、Rap 高能段落与专属标题转场**；
   - **【齐舞绝不遮脸铁律】**：在副歌齐舞（Chorus）与 Killing Part 中，必须以**展示成员五官神态、清澈眼神光与完整齐舞队形**为绝对第一优先级，**严禁使用全屏立体大字遮挡舞者身体或五官（VFX 必须把脸让出来）**。
3. **纯文字排版镜头（Kinetic Typography Shots）**：
   - 独立规划为 1.5~3.0 秒的高能短镜头，采用 3D 实体化文字力学与爆炸收拢，主角不对嘴。

## 四、流派自适应表演与口型硬分流纪律

1. **流派自适应口型硬分流门禁（非舞台唱演类默认不对嘴）**：
   - 绝大多数高级 MV（尤其是动态漫、电影叙事、赛博电子、情绪蒙太奇）中，**角色是故事叙事者或视觉符号，而非手持麦克风的商演歌手**；
   - 唱演与口型比例必须根据 `beats.md` 识别到的真实曲风流派严格执行分流：
     - **08 概念动态漫 (Graphic Anime)**：**【默认 0% 唱演，全片不对嘴】**（除非用户明确指定角色开口唱）！全片核心为**破风动能冲刺、3D 实体文字穿透、超现实符号与重音冲击帧**，人物保持坚毅、冷酷神态，Prompt 第一层显式声明 `全片纯视觉图形轰炸与超现实符号卡点，不对嘴。`，彻底杜绝口型穿帮与单调动嘴；
     - **04 电子 / 赛博 / 粒子 (Cyber & Electronic)**：**【0% 唱演，全片不对嘴】**，全片为粒子光流、空间折叠与建筑纵深；
     - **06 唯美情绪蒙太奇 (Impressionist Vibe)**：**【0% 唱演，全片不对嘴】**，全片为微距材质、光斑与逆光氛围；
     - **07 动感歌词排版 (Kinetic Typography)**：**【唱演与文字严格分轨】**，排版镜头 100% 不对嘴，仅在独立歌手特写段落对嘴；
     - **02 电影叙事 (Cinematic Narrative)**：**【剧情为主，极低口型 (0%~20%)】**，**有歌词 ≠ 必须动嘴！背景歌声天然作为电影画外音 (OST) 存在**，绝大部分镜头为人物肢体动作、视线对峙、道具摩挲与环境蒙太奇，Prompt 显式标注 `【无唱演/画外音】人物闭口演戏，不开口`，单段最多仅允许 1 处（≤ 5秒）特写自白或副歌高潮动嘴；
     - **01 舞台唱演 (Stage Performance)**：**【40%~50% MCU 唱演口型】**，主唱面部特写精准咬字；
     - **03 编舞 / K-pop (Choreography)**：**【齐舞 + Killing Part 专属对嘴】**，齐舞与特写交替。
2. **景别口型限制**：
   - **仅在中近景 (MCU) 与近景 (CU)** 启用口型；
   - 远景 (Wide Shot)、全景 (EWS)、人物背面或空镜头中，**严禁添加口型提示词**，防止人物嘴部在远景中产生诡异抽搐。
3. **口型锚点句式**：
   - 确需唱演的段落必须包含：`全程在唱，精准咬字口型：{当秒对应歌词}`。歌词必须逐字使用原曲词作，禁止擅自润色。

## 五、镜头序号制铁律（严禁在 Prompt 中使用毫秒时间戳）

1. **镜头序号优先于时间戳**：
   - 官方指南与实践表明，视频生成模型对精确毫秒时间戳（如 `0.000–4.000秒`）遵从度极低且易引发时序混乱；
   - **Prompt 内部必须统一采用镜头序号制 + 音乐事件触发**：
     - 正确写法：`镜头1：中近景仰拍，主唱手持麦克风向前踏步，镜头随重音急速推近... 镜头2：随副歌第一声鼓点落下，360度顺时针高速环绕... 镜头3：突然切主唱眼神特写，在重拍定格...`
     - 毫秒秒数仅留在内部的 `beats.md` 预算表中，严禁写入生视频 Prompt。

## 六、长时长注意力和前 50% 英雄时序

Seedance 2.5 原生支持 30 秒生成，但潜空间注意力在后半段存在衰减趋势：
1. **英雄动作前置**：全段最核心的视觉奇观、最高爆发的动作与镜头转场必须写在 **Prompt 前半段（前 50% 时序内）**。
2. **后半段平稳演进**：后半段主要维持动作演进与段尾姿态稳定，避免在最后 3 秒塞入高难度新动作。

## 七、防变形、防克隆人、全员绑定与伴舞规范

1. **写实歌手 Photoreal 锁定**：
   - 制作写实向人物 MV 时，必须在 Film DNA 中声明 `超写实真人电影质感 (Photoreal Live-action)`，防止模型在科幻/霓虹场景中将歌手意外金属化。
2. **多成员全量 ImageList 传入铁律**：
   - 女团/男团等多人企划（如 4 位成员），每一次 `sandbox_generate_video` 必须**全量传入所有成员参考图**（如 `ImageList: [member1, member2, member3, member4, setA, setB]`），严禁因单镜特写而偷懒只传 1 张图，确保整部 MV 无论全景还是特写，4 位成员的 ID 始终被强力约束。
3. **伴舞团纯文本免图规则 (Backing Dancers)**：
   - 齐舞排场需要伴舞团（如 4 位主角 + 6~8 位伴舞）时，**伴舞只在视频 Prompt 中用纯文字描述驱动**（例如：`后方8位伴舞身穿统一纯黑哑光修身服，以整齐齐舞动作衬托前排四位主角`）；
   - **严禁为伴舞额外生成参考图**。伴舞在各镜头间面部无需锁图，穿同款服装自然融入背景即可。
4. **群像与防双胞胎 (Anti-Twin)**：
   - 单张画面主角团参考人物不超过 4 人；
   - 负面尾注必须包含：`保持无字幕，不要生成水印/logo，人物五官与肢体稳定不变形，全片不要在同一画面中复制相同主角人物，严格以@视频1中的音频作为全片唯一背景音乐，严禁生成任何与@视频1无关的背景音乐或杂乱音轨。`

## 八、禁用词与反模式清单

| 禁用项 | 为什么禁止 | 正确替代写法 |
|---|---|---|
| 独立标签 `段尾状态：xxx保持静止` | 独立写标签会导致模型误解为全局静止指令，引发画面冻结/人物僵死 | 内在化写进最后一个微镜头末尾（如 `镜头5:...定格`），下段起幅承接 |
| 结构脚手架标签 `【Layer N】` | 会被模型直接渲染为画面文字，或干扰提示词理解 | 仅作为思维结构，Prompt 呈现为纯文本段落 |
| 毫秒时间戳 `0.000–4.000秒` | 模型对绝对时间戳遵从度低，易导致动作断层 | 改用 `镜头1:` / `镜头2:` + 音乐事件触发 |
| 孤立形容词 `cinematic / 8k / epic` | 空洞无信息量，模型无法解析具体光影 | 写入具体的 Film DNA（如 `35mm变形宽银幕，柯达500T低反差影调，金色体积雾`） |
| `fast / 极速运动` | 导致画面产生严重运动模糊和肢体熔化 | 改用重量转移与分镜头描述（如 `右脚侧滑顿停，镜头瞬间推近`） |
| 单镜头堆叠 4 个以上动作 | 导致动作冲突、模型肢体抽搐 | 拆分为分时序微镜头，每镜聚焦单一动作链与单一运镜 |
| 无依据全局慢镜头 (Slow-motion) | 抹杀音乐内部节拍张力，沦为 PPT | 仅在长音、Bridge 空间反转或极特写时使用，并标明乐理依据 |

## 九、乐理自适应整数秒切片、杜绝浮点切片与尾段容错铁律 (Integer Seconds Slicing)

1. **乐理自适应纯整数秒切片（严禁 24.2s / 13.7s 这类浮点切片）**：
   - 视频生成模型 `sandbox_generate_video` 的 `Duration` 参数**底层仅支持纯整数秒**；
   - 分段规划不需要死板硬卡每段都是 15s 或 30s，**应顺应歌曲真实的乐段呼吸与小节（如 Intro 8s、Verse 12s、Chorus 24s 等自适应时长）**；
   - **【红线禁令】每个分段的起止时间点与 Duration 必须严格对齐到纯整数秒（如 0~8s、8~20s、20~44s），严禁出现 24.2 秒、13.7 秒这类浮点小数切分**！
     - 为什么禁止浮点切分：模型无法接收浮点 Duration，浮点秒切片会导致黑屏 MP4、模型生成时长、Prompt 秒数阶段与成片母带四者之间发生毫秒级撕裂，时差累积后口型全崩。
2. **尾段向上取整容错原则（最后画面多一点完全没关系）**：
   - 当全曲总时长末尾存在碎秒（如全曲 62.4 秒，前几段整数切片覆盖到 60 秒，剩下 2.4 秒尾巴）时：
     - 受限于模型最低生成时长（通常 $\ge 4$ 秒），**最后一段尾巴直接向上取整生成（例如设 `Duration: 4` 或 `Duration: 5`）**；
     - **【尾段多一点画面完全合规】**：最后一段多生成 1~2 秒的画面完全没关系，正好作为 Outro 尾声留白、定格姿态或回味空镜；黑屏音频通过 `apad` 自动补齐静音，最终在 FFmpeg 合成时以原曲母带为基准完成收尾。
3. **尽量用满单段上限，生成最少数量的片段**：
   - 官方指南明确：**Seedance 模型支持单次生成内进行多镜头分镜与运镜演进，且单段内镜头运动与人物连贯性更自然**；
   - 分段规划时**严禁将连续乐段过度细拆为 4~8 秒的微小碎段**（导致全片产生十几个零散片段、拼接繁杂且破坏镜头内部节奏）；
   - **大块乐段贪心合并**：若相邻短乐段（如 Intro 4s + Verse 8s = 12s）合计 $\le \text{上限}$，合并为一个片段生成；以最少的分段数覆盖全曲（如 60s 歌曲在 30s 模型下通常仅生成 2~3 段，在 15s 模型下生成 4~5 段）。
4. **单段生成硬性上限（严禁任何 > 30s 的分镜）**：
   - 每次调用 `sandbox_generate_video` 的 `Duration` 参数必须满足：
     - 最低时长：$\ge 4$ 秒（或 Seedance 2.5 下 $\ge 2$ 秒）；
     - 最高时长：严格受限于 SKILL.md 中声明的模型单段上限（通常为 15 秒或 30 秒），严禁超限！
   - **【绝对禁止超限合并】**：若某一乐理大段（如 Intro 12s + Verse 18s + Pre-Chorus 12s = 42s）跨度较长，**绝对禁止合并为 42 秒的单一分镜！** 必须强制在 30s 之前（如 24s 句尾）拆分为两个合规的 shot（如 `shot_01: 24s`，`shot_02: 18s`），并分别切片对应的黑屏音频，否则会导致底层生视频模型 API 直接报错拒绝！
5. **主 Agent 超限切片门禁**：
   - 无论 `beats.md` 给出何种乐段，主 Agent 规划分镜时必须严格执行单段 $\le 30$ 秒上限校验，凡是 $> 30$ 秒的乐段一律自动拆分为 A/B 子段，并通过动作匹配剪 (Match Cut) 无缝串联。
6. **分镜自检规则**：分镜表必须包含「生成时长」列，且每一行的时长均为合法纯整数秒且必须 $\le 30$ 秒。

## 十、多段并行生成与无串行依赖铁律 (Parallel Generation)

1. **MV 天然属于跳切艺术，严禁尾帧/视频串行依赖**：
   - MV 乐段之间（Verse $\rightarrow$ Pre $\rightarrow$ Chorus $\rightarrow$ Bridge $\rightarrow$ Outro）天然由换景、换布景盒 (Concept Box)、换机位的大跳切 (Jump Cut / Box Cut / Match Cut) 构成；
   - **严禁将上一段生成的视频或尾帧传入下一段（VideoList 严禁包含上一段生成产物）**！串行传递会导致模型画质二次压缩劣化、上段动作残留变形与光影污染。
2. **各分段独立并行生成**：
   - 各分段（Seg）在逻辑上彼此完全独立，**可直接并行调用 `sandbox_generate_video`**；
   - 每一个 Seg 均独立传入全量角色参考图（`ImageList: [member1..4]`）和该分段专属的黑屏音频切片（`VideoList: [seg_audio.mp4]`）；
   - 所有片段生成完成后，统一使用 FFmpeg 顺序拼接并合入原曲母带。

## 十一、歌词意象具象化与美学防降级铁律 (Lyric Imagery & Anti-Downgrade)

1. **严禁将先锋概念/时尚大片降级为廉价商演齐舞**：
   - 当歌词包含“快门”、“换脸”、“影子出画”、“过线”、“画面切断 (Cut)”、“Freeze”、“折叠”等高概念视觉意象时，**严禁机械套用千篇一律的“女团普通齐舞 + 手臂波浪 (Arm Wave) + 杂乱激光舞台”**！
   - 必须通过**高定时尚杂志直闪摄影 (High-Fashion Direct Flash Editorial)、极简包豪斯水泥空间/纯黑高反差光缝、快门爆闪连拍跳切与影子剥离**等先锋视觉语言，将歌词意象 1:1 转化为画面物理奇观。
2. **严禁 5 秒以上长镜头发呆**：
   - 快节奏电子舞曲/K-pop/说唱必须保持 **1.0s ~ 2.0s 高频微镜头链**，每个重音（Drop / Snare / 快门声 / 切分音）必须绑定物理跳切、变焦 (Punch Zoom) 或闪光定格，杜绝人物在长镜头中机械肢体抽搐。
3. **杜绝土味廉价服化道**：
   - 避免生成反光廉价的塑料皮衣；先锋/概念曲目优先采用**高定廓形极简西装、解构剪裁、冷调金属细件与高级超模骨相**。

## 十三、环境光物理投射与材质融合铁律 (Environmental Lighting & Shading)

1. **消除“抠图贴纸感”：环境光必须物理投射在角色身上**：
   - **痛点根因**：参考图为纯白底，若 Prompt 仅描述“人物站在蓝色通道/红色爆炸中”而未写明光线交互，视频模型就会将角色像贴纸一样贴在背景上，产生严重的分层脱节；
   - **【光影交互三要素铁律 (The Lighting Interaction Triad)】**：
     - 凡是画面存在特定场景光源（霓虹光、爆炸光、激光、冷白光柱等），Prompt **必须显式描写环境光对人物发丝、皮肤与服装的物理投射**：
       - ① **边缘轮廓光 (Rim Light / Edge Highlight)**：场景主色（如冰蓝/亮橙）必须勾勒在人物发梢、下颌、肩膀与服装边缘（如 `冰蓝色霓虹光在角色银发与夹克肩部勾勒出强烈的冷光轮廓 (Rim Light)`）；
       - ② **漫反射阴影 (Ambient Shadow)**：背光面必须沉入环境色漫反射暗调（如 `面部背光侧沉入深邃的冷青色漫反射阴影`）；
       - ③ **瞳孔与金属镜面高光 (Specular Reflection)**：人物瞳孔与金属配饰必须倒映出环境光源形态（如 `灰蓝瞳孔与金属拉链上清晰倒映出闪烁的橙色警报光斑`）；
   - **【红线禁令】严禁无光影物理交互的真空描写**，确保角色与场景在同一个 3D 光影空间中有机融合！

## 十四、storyboard.md 格式规范与用户确认门禁 (Confirmation Gate)

1. **Phase 3 必须输出 `./assets/storyboard.md`**：
   - 格式严格遵循 `references/mv-storyboard.md`（参考标准分镜格式），包含：
     - 视频比例与最大分镜时长；
     - `## 总览` 表格（Shot, 乐段, Duration, 衔接, 景别, 核心情绪/声学事件 与总时长）；
     - `## 通用尾注`（全片通用的画质兜底、防变形克隆人、防水印、禁BGM、保持无字幕等）；
     - `## shot_NN` 小节（`ImageList`、`VideoList`、`AudioList` 与缩进的 `Prompt: |`，Prompt 内不重复通用尾注）；
2. **推送与确认门禁 (Confirmation Gate)**：
   - 完成写入后，必须调用 `present_sandbox_file(filepath="./assets/storyboard.md", interrupt=false)` 推送分镜；
   - 紧接着触发 `dynamic_questionnaire` 征求用户确认（`满意，开始生成视频 (推荐)` / `需要调整分镜与画面`）；
   - **【硬门禁】未收到用户确认前，绝对严禁调用 `sandbox_generate_video`**；
3. **Phase 4 消费执行**：
   - 用户确认后，Agent 逐段读取 `storyboard.md`，将 `## 通用尾注` 追加到 Prompt 末尾，调用 `sandbox_generate_video` 生成视频。

## 十五、特写叙事动机与动作因果链铁律 (Narrative Motivation & Action Causality)

1. **严禁商品目录式无因果部位陈列**：
   - **【红线禁令】绝对严禁无因果关系的静态三屏/双屏部位陈列（如左屏眼睛/中屏拳头/右屏靴子）**！此类画面如同角色模型设计卡 (Model Sheet)，割裂影视叙事；
2. **特写三阶因果链 (The 3-Phase Action-Causality Loop)**：
   - 任何局部微镜头必须遵循因果驱动：
     - **链条 A: [视线察觉 $\rightarrow$ 焦点目标 $\rightarrow$ 动作反应]**（如 `瞳孔微距倒映崩塌红光 → 双手猛推操纵杆 → 全景喷射突破音障`）；
     - **链条 B: [蓄力发力 $\rightarrow$ 物理交互 $\rightarrow$ 环境反馈]**（如 `马丁靴碾碎地面数据卡片火星四溅 → 顺势低空滑跪 → 单手横刃斩断虚空锁链化为火雨`）；
3. **动作多样性与杜绝重复单一手势**：
   - 严禁全片频繁单一重复“握拳”或“拉扯夹克领口”；
   - 手部动作必须多样具象：`单手擦拭嘴角雨水`、`指尖在虚空快速敲击发光指令`、`猛然拔出背部充能插头`、`单掌按压震碎镜面玻璃`、`双手反向撕裂全息投影窗`。

## 十六、破风动能位移与严禁原地跑步机 (Kinematic Locomotion & Multi-Angle Sprint)

1. **严禁单一机位原地跑步机动画**：
   - **【红线禁令】严禁编写“背对镜头狂奔”或“正面大步跑向镜头”这类单一平视原地动画**（视频模型会直接渲染为人物在原地踏步、背景滚动的假跑尴尬画面）；
2. **重心前倾与重力反作用力 (Low Center of Gravity & Thrust)**：
   - 冲刺描写必须包含身体物理做功：`身体极度前倾45度压低重心破风狂冲，每一步重重蹬地踏碎地面溅起高光火星与碎石，发丝与衣摆拉成笔直线条`；
3. **冲刺镜头多机位剧烈跃迁 (Multi-Angle Sprint Jump)**：
   - 奔跑冲刺段落**严禁单一机位到底**，必须在 2~3 秒内串联 2~3 个剧烈视角跳切：
     - ① `斜下方15度贴地飞驰跟拍，特写马丁靴每一次凶猛抓地与火星喷溅`；
     - ② `硬切侧面45度大透视超车，身体前倾45度破风，背景拉成极速动态模糊流线与放射状速度线(Radial Speedlines)`；
     - ③ `重拍瞬间单膝急刹滑行(Knee Slide & Lock)，鞋底在地面摩擦出长长火花划痕定格`；
4. **环境物理交互与速度线**：
   - 冲刺中必须包含：`放射状速度线 (Radial Speedlines)`、`空气压缩音爆环 (Shockwave Cones)` 与 `撞碎前方半透明玻璃墙/单手撑翻护栏` 等环境物理反馈。

## 十七、歌词画外音与精准唱演门禁 (Lyrics Voice-Over vs Targeted Lip-Sync)

1. **背景歌词天然属于画外音 (BGM / OST)**：
   - 物理音频 `@视频1` 已经在播放包含人声的完整歌曲，视频生成模型会直接基于物理音频流感知节拍与发音；
   - **【红线禁令】绝大多数微镜头（空镜头、道具特写、手部特写、背影全景、远景、走位与日常剧情演戏镜头）Prompt 中严禁出现任何歌词文本，严禁出现“精准咬字口型”或任何口型相关字样！**
   - 为什么严禁在非人脸镜头贴歌词：在手部特写、背影或空镜中写口型歌词会导致模型 cross-attention 混乱，甚至在画面角落生成异化人脸/嘴部破坏构图；
2. **严禁逐镜机械贴歌词（杜绝目录式贴词）**：
   - 严禁在分段内的每个微镜头末尾无脑机械追加一句歌词；
   - 70%~100% 的微镜头中，Prompt 仅需专注描写**机位、主体动作、光影材质与叙事因果**，不需要写任何歌词文本；
3. **极少数确需唱演镜头的书写规范**：
   - 仅在正面/侧面中近景 (MCU) 且明确需要角色开口的高光时刻（如副歌爆发、终极独白），在句末自然说明：`女主角轻声开口唱演：{当秒对应的歌词}`；
   - 所唱歌词必须严格落在当前分段的 `[T_start, T_end]` 时间轴内，严禁跨段时序倒错。
