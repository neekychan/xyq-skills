# 符咒 & 打斗特效(灵异能量体系)

本文件把**符咒本体静帧**与**施法动态特效**严格分开:前期图片只生成一张未激活的核心符咒本体参考卡;「触发—能量—作用—代价」与打斗/开大特效仍完整规划为文字,只在 video creation 的具体施法镜头实际使用时调用。能量视觉必须固定颜色、形态和意象并跨镜一致。造色底片见 `visual-grammar.md`,巨物开大态见 `monster-design.md`。

> **题材定调:去仙侠化。** 本片是东方灵异玄幻抓诡,不是仙侠修真。**避免「结印/掐诀」一类仙侠手印手势作为主要施法方式**;能量的来源更贴近符、法器、物件与环境本身(符燃、铃响、镜照、血引、器物共鸣、地脉迸发),而非凭空掐诀放术。参考素材里的结印镜头只学其「能量汇聚—爆发」的视听节奏,不照搬掐诀动作。

## 一、特效具象化铁律(先于一切)

抽象能量不能直接拍。每一种能量都要落成**固定的颜色 + 固定的形态 + 固定的意象**,并跨所有镜头不变:

- 反例:"释放能量" / "发出法术光"。
- 正例:"雨水汇聚成的水剑,通体红蓝流光"(色=红蓝,形=水剑/流光,意象=汇聚成型)。

为全片建立一张**能量色表**,每种能量对应唯一的色+形+意象,写进 `TALISMAN-VFX:` 锁定词块。下表为从参考素材提炼的可选色语汇(择用,勿全上;每片建议锁 1–2 种主能量色):

```text
能量意象 | 固定颜色 | 固定形态 | 触发来源(去仙侠化)
汇聚成型 | 红蓝流光 | 元素凝成兵器/实体 | 符燃 + 环境元素(雨/尘/铁屑)被牵引汇聚
镇煞净化 | 冷冽蓝白 | 寒气/冰棱/结晶扩散 | 铃响 / 器物共鸣,寒气自地面炸开
引魂阴牵 | 幽绿/墨紫 | 雾丝/游魂/符纹流动 | 招幡 / 旧物,黑雾渗出
封锁束缚 | 暗金/靛蓝 | 符链/同心符阵/能量壁 | 符纸贴附 / 地脉符文亮起
崩毁爆发 | 暗红火光 | 冲击波/环形气浪/龙卷 | 巨物开大 / 器物过载
```

## 二、符咒本体卡与施法规划（静态/动态分离）

### 2.1 核心符咒本体参考卡（唯一默认静帧）

整个项目的符咒图片环节默认只生成**一张** `talisman_core_reference.png`,用于锁定核心符咒道具本身。它不是施法关键帧,也不是符咒、法器和特效的组合展示。

画面硬性要求:

- 只出现一张核心符咒纸,未激活、完整四边可见、正面平铺或近乎正视。
- 只展示纸张纤维、尺寸比例、裁切、折痕、朱砂/墨迹渗纸、笔锋、原创符头/符胆/符脚和自然旧化。
- 使用单一素色哑光无叙事背景与均匀柔光,只留轻微真实接触阴影。
- 不出现铜镜、剑、铃、印、冰棱、火焰、人物、手、墙地场景、祭坛、发光、粒子、能量线、符阵、法阵、燃烧、漂浮或第二张符纸。
- 不靠大段可阅读汉字或伪古文口号表现东方感;用原创章法、笔锋和纸墨关系建立识别。

符咒本体卡填写:

```text
符咒编号与原创名称:
用途类别（只描述功能,不画特效）:
纸张材质、尺寸与裁切:
底色与纸张纤维:
朱砂/墨迹颜色、渗纸与笔锋:
原创符头 / 符胆 / 符脚结构:
折痕、磨损、污渍与保存状态:
未激活状态的跨镜锁定词:
```

默认只选择**全片最核心的一种符咒**进入图片清单。其它符咒先保留文字设定;只有用户明确要求并重新确认新增张数后才追加本体图。

### 2.2 文字版施法规划（不生成特效图）

抓诡里的「符—法器—能量」必须像有规则的系统,而非随手发光。每种施法继续完整填写下列文字字段,但不要把这些特效画在 `talisman_core_reference.png` 上:

```text
施法名(原创):
载体:符纸 / 法器(铃/镜/剑/幡/印/血/器物) / 咒音 —— 避免仙侠掐诀手印为主
触发:什么动作或条件启动?(贴物、点燃、敲响、照映、滴血、共鸣)
可见征兆:观众第一眼看到什么?(必须能被镜头拍到)
能量形态:引用能量色表的 色+形+意象
作用:对巨物/环境/人产生什么可见效果?
代价 / 限制:施法者失去什么?冷却?反噬?符会烧尽?
失效条件:什么情况下符/法器会破、会哑?
```

**原则**:观众能 5 秒内理解「这个符/法器是干嘛的」;施法有代价、有失效,才有打斗张力。

### 2.3 视频使用时调用

前期交付 `TALISMAN` 本体锁定词与 `TALISMAN-VFX` 文字规划,不交付符咒特效静帧。video creation 在具体镜头出现贴符、燃符、掷符、破符或法器联动时,再读取对应规划并生成动态;镜头未使用该符时不调出特效。若下游确实需要额外特效参考图,返回本 Skill,先列出新增图片清单和张数并等待用户确认。

## 三、打斗 & 开大特效体系

### 强度弧线(四段式)

一场特效对决按强度递进,每段换性质,不同质升级:

1. **开场碰撞**:第一次能量接触,确立双方语汇(符/法器 vs 现实巨物)。
2. **高速缠斗**:连招与反制,能量形态互相作用(锁 / 破 / 弹 / 被巨物碾压)。
3. **升级加码**:巨物开大(见 `monster-design.md`,如卷吸废料越战越大)或术者祭出更高阶法器/符。
4. **终极爆发**:全片密度峰值,短促(勿超 15 秒),爆点前后各留一次呼吸;常以撕裂天空/塌陷成坑/龙卷吞噬定格。

### 碰撞组合规划

特效之间要有**因果对撞**,不是各放各的:符链锁 → 巨物挣裂石壳 → 术者补咒 → 巨物卷吸废车增大反扑。每次对撞明确「谁作用于谁、结果是什么、能量与材料如何变形」。

### 一致性约束

- **特效长在主体身上**:能量从符/法器/巨物体表明确发出,不凭空漂浮。
- **同一能量跨镜不变色不变形**:色表锁死。
- **防御对等**:攻有其形,防有其形,能量互作用可见。
- **四段物理链**:每次能量写清“来源 → 传导路径 → 亮度衰减 → 邻近材质反射”。禁止沿全身裂缝平均点亮或用一团泛光覆盖胸口。
- **空间定位**:能量与角色/巨物在同一真实 `SCENE_ID`,有前后景、遮挡、投影、局部反射与环境破坏;光强随距离衰减,不能把整张图染成同一颜色。
- **粒子服从受力**:尘、雨、碎石、火星只在碰撞路径、气流或重力下运动;无事件时不铺满画面。

### 运镜与动作同步(动量锚点)

打斗运镜跟随动量,交给 video creation 分镜时遵守本约束(不在此写逐镜):

- **A 主角/术者动量跟随**:镜头随施法方向或斩击弧线运动。
- **B 受力反馈跟随**:镜头随被击/被锁的巨物形变、崩块运动。
- **C 一镜到底**:连续动作不切,靠调度与能量流串联。

暗环境为默认;开阔场景用于终极爆发与巨物登场。看不见 > 看得见:关键时刻拍「看到能量/巨物的人的脸」。

## 四、特效方法库(基于用户参考提炼 · 可复用)

以下从参考素材抽象出的**展现方式、镜头手法与关键词**,仅供视频镜头真正进入施法/打斗时调用;不得提前塞进核心符咒本体参考卡。只学表现手法,不复用具体角色、兵器名、招式名或世界设定,并按「去仙侠化 + 现实巨物」的题材调性取用。

### 4.1 可复用特效展现方式

| 手法 | 效果描述 | 适用节点 |
|---|---|---|
| 元素汇聚成型 | 环境中的雨/尘/铁屑/碎石被牵引,汇聚凝成兵器或实体 | 蓄力、施法成型 |
| 世界失色 / 时间静止 | 除主体外画面失去颜色,雨水/落尘凝固不动 | 能量觉醒的强调帧 |
| 能量流光 / 冲击波 | 主体周身持续散发流光,踏步/出招迸发环形冲击波 | 登场、发力 |
| 粒子特效 | 雾气、水流、尘埃、火星沿受力方向和距离衰减 | 撞击、卷吸或局部氛围,禁止全屏均匀漂浮 |
| 能量壁 / 符阵法阵 | 地面展开同心圆符文阵,垂直能量壁拔起,壁面涟漪 | 束缚、防御(去仙侠:用符文/机械纹而非仙家法阵) |
| 巨物开大变形 | 巨物卷吸废料增生 / 巨化撑破空间 / 裂口翻出触手 | 升级加码 |
| Glitch 视觉错位 | 能量过载时人物轮廓出现数字/影像错位抖动 | 力量失控的临界 |
| 元素法相 / 巨型虚影 | 主体身后浮现由能量/材料构成的巨型法相虚影 | 终极爆发的威压 |
| 撕裂天空 / 云层 | 剑气/冲击波把乌云从中劈开、云层漩涡撕裂 | 收尾大招 |
| 龙卷 / 漩涡吸卷 | 能量与碎石汇成通天龙卷,吸卷、绞杀、吞噬 | 终极爆发 |
| 弧形能量刃 | 斩击喷涌弧形剑气/扇形能量刃,轨迹留残气 | 攻击兑现 |

### 4.2 可复用镜头构建手法

- 由脚到全身的缓推,水珠/尘屑沿身滑落建立质感开场。
- 局部特写(脚部/手部/器物)→ 迅速拉远揭示全身与空间。
- 特写与大场景**无缝切换**,中景推近至面部特写聚焦神态。
- 镜头后拉并升空,低机位仰拍切换超广角全景,强化压迫与威压。
- 动态跟拍能量/斩击弧线;巨物登场用大透视、大远景和门洞/柱距/车辆等环境量尺建立压迫,不依赖人物充当比例尺。
- 以**震撼定格尾帧**收束(巨物昂首/法相完整形态/主角背向异象)。

### 4.3 视频特效的实拍可信度与画面质量约束

```text
真实电影现场摄影底板 / 有来源的实景主光 / 合理曝光与高光回滚
35mm或与CAMERA_SLOT一致的焦段 / 明确机高与地平线 / 有限景深 / 空气透视
2–3种材料具有不同粗糙度与破损 / 潮湿只在渗水与接触区 / 保留安静大面
接触阴影 / 地面压痕 / 遮挡 / 污渍互染 / 受力明确的碎石与水花
能量来源明确 / 沿固定结构传导 / 亮度随距离衰减 / 只照亮邻近材质
克制胶片颗粒 / 自然运动模糊 / 不过度锐化 / 不把暗部全部提亮
```

> 不再使用“UE5、光线追踪、超写实3D渲染、影视级CG、模型精度拉满、粒子丰富、压迫感拉满”作为画质捷径;这些词会诱发游戏宣传图、统一粗糙度、全局锐化和满屏碎屑。色调服从 `visual-grammar.md`,场景与机位服从 `environment-continuity.md`;剔除掐诀、修真、渡劫、仙家法阵等措辞。
