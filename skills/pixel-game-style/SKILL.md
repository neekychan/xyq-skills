# 像素游戏风 (Pixel Game Style)

## 这个 Skill 是做什么的

这是一个**风格滤镜类技能**。它不负责决定「讲什么故事 / 拍什么内容」，只负责保证：**无论生成多少张图片素材、多少段视频，它们看起来都出自同一套「像素游戏风」视觉体系**。

实现方式只有一个核心动作：**在每一条要送去生成图片或视频的 prompt 的最开始，原封不动地拼接一段固定的「风格锚定词」，然后再接该镜头 / 该素材的具体画面描述。**

只要坚持这一个动作，同一批资产的像素颗粒、配色、光影、构图气质就会保持一致。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心机制：风格锚定词（最高优先级，必须逐字复用）

### 固定风格锚定词（STYLE ANCHOR）

> 像素游戏风，16-bit retro pixel art style，复古游戏风 /retro game aesthetic，现代像素艺术，低分辨率语言，高审美构图，数字马赛克质感，现代 pixel art 插画，电影感光影

以上这段就是**风格锚定词**。它是本 skill 的资产，**必须逐字、完整、原样使用，不得改写、翻译、删减、调换顺序或用同义词替换**。

### 唯一强制规则

1. **每一条**送去生成**图片素材**的 prompt，最开头都必须是上面这段风格锚定词，然后紧跟一个逗号或换行，再接该图片的具体画面描述。
2. **每一条**送去生成**视频**的 prompt，最开头都必须是上面这段风格锚定词，然后紧跟一个逗号或换行，再接该视频镜头的具体运动 / 画面描述。
3. 风格锚定词永远在 prompt 的**最前面**，是「前缀」，不是「后缀」，也不能夹在中间。
4. 具体画面内容（角色、场景、动作、镜头、光线细节）写在风格锚定词**之后**。
5. 一次任务里如果要生成 N 张图 + M 段视频，就要拼接 N+M 次，每一次都带上完整锚定词，**不能因为"前面已经写过了"就在后续 prompt 里省略**。

### 拼接格式

```
【风格锚定词】，【本条画面/镜头的具体描述】
```

**图片 prompt 示例：**

```
像素游戏风，16-bit retro pixel art style，复古游戏风 /retro game aesthetic，现代像素艺术，低分辨率语言，高审美构图，数字马赛克质感，现代 pixel art 插画，电影感光影，一只黑猫坐在旧书店的木质窗台上，暖黄色台灯光，深棕色书架层层堆叠，窗外是傍晚紫粉色天空，正面居中构图
```

**视频 prompt 示例：**

```
像素游戏风，16-bit retro pixel art style，复古游戏风 /retro game aesthetic，现代像素艺术，低分辨率语言，高审美构图，数字马赛克质感，现代 pixel art 插画，电影感光影，黑猫从窗台缓缓起身伸懒腰，尾巴轻轻摆动，暖灯光晕轻微闪烁，镜头缓慢横移，2 秒循环
```

## 与其他风格 Skill 搭配时的合并规则

当本 skill 与**其他同类风格 skill**（例如复古 DV 风、国漫 3D 渲染风等）被同时调用时：

1. **合并处理，不覆盖**：把各风格 skill 的锚定词**按顺序拼接**成一段合并锚定词，本 skill 的锚定词保持完整、逐字不变，只是与对方的锚定词前后相连。
2. **规则不变**：合并后的锚定词整体仍然只放在每条图片 / 视频 prompt 的**最前面**，后面再接具体画面描述。
3. 合并顺序：一般以**用户最先指定 / 最主要的风格**在前；若用户未说明，则本「像素游戏风」锚定词在前。
4. 合并示例：

```
【像素游戏风锚定词】，【另一风格 skill 的完整锚定词】，【本条画面的具体描述】
```

5. 若两套风格在具体气质上冲突（如"高清写实"与"低分辨率像素"直接矛盾），仍以本 skill 的像素质感为准，并在具体描述里做协调，但**双方锚定词文本都不删改**。

---

## 与非风格类 Skill 冲突时的优先级规则（重要）

当本 skill 与**非风格类 skill**（例如营销短片 skill、短剧脚本 skill、分镜生成 skill、广告脚本 skill 等）被同时加载时：

1. **职责分离**：非风格 skill 负责**内容、结构、脚本、分镜、卖点、节奏、时长**；本 skill 只负责**视觉风格**。两者不是二选一，而是叠加。
2. **风格锚定词不可被覆盖**：无论其他 skill 的模板、示例 prompt、生成流程长什么样，**只要进入"生成图片 / 生成视频"这一步，每条 prompt 最前面都必须先拼上本 skill 的完整风格锚定词**，然后再接那个 skill 产出的画面 / 镜头描述。
3. **改写而非丢弃**：如果营销 / 短片 skill 自带 prompt 模板或示例，要把它们的画面描述部分**接到风格锚定词后面**，而不是让它们的模板替换掉锚定词。
4. **显式声明**：在最终交付时，需明确说明"所有图片与视频 prompt 均已按像素游戏风 skill 前置风格锚定词"，确保风格不被其他 skill 的流程稀释。
5. **一句话原则**：**内容听非风格 skill 的，长相听本 skill 的，二者都要执行，风格锚定词一步都不能少。**

---

## 禁止内置风格锚定图干扰（必须绕过）

部分 Agent 链路会针对某些风格**内置前置的"风格参考图 / 风格锚定图"**。这类内置参考图会污染本 skill 的像素质感，导致资产偏离目标风格。因此：

1. **一旦调用了本 skill，就必须禁用 / 绕过 Agent 任何内置的风格锚定图、风格参考图、默认风格底图机制**，不得把它们作为图片或视频生成的参考输入。
2. 生成图片 / 视频时，**风格只能来自本 skill 的文本风格锚定词**，不引入任何系统内置的风格图作为 style reference / image reference / init image。
3. 如果生成工具默认会挂载一张风格底图，需在调用参数里**显式关闭 / 置空该风格参考图**，只保留文本锚定词（以及用户自己主动上传的、用于内容而非风格的参考图）。
4. 用户**自己主动提供**的角色图 / 场景图（用于保持内容一致性）不在禁止之列；被禁止的只是**系统内置的、非用户主动指定的风格参考图**。

## 风格知识库（供 Agent 写分镜 / 角色 / 脚本时形容参考）

以下知识用于**生成分镜、角色设定、场景描述、故事脚本**时的措辞参考，帮助内容在文字层面就贴合像素游戏风，让最终画面更统一。写具体画面描述时，可从这里挑取合适的词汇接在风格锚定词后面。

### 1. 整体风格气质
- 复古游戏感：让人联想 8-bit / 16-bit、FC / SFC / GBA、90 年代街机的视觉记忆。
- 插画化表达：不是单纯游戏素材，而是像一张完整的封面、场景设定图或宣传海报。
- 强情绪氛围：强调光线、配色、场景情绪，把世界浪漫化、理想化。
- 低分辨率语言 + 高审美构图：保留像素颗粒与块面感，同时具备成熟的电影感与设计感。
- 怀旧与梦幻并存：既有电子游戏的童年记忆，也有被美化的乌托邦式浪漫。
- 一句话：**用电子游戏记忆重新编码现实 / 幻想世界，做成更浪漫、更纯粹、更可收藏的视觉。**

### 2. 画面质感 / 材质
- 颗粒感明确可见：边缘、体块、明暗都是一格格像素拼出来，轮廓带轻微台阶状锯齿。
- 精致的粗糙：不是分辨率低，而是每个像素块的位置、颜色、明暗都被精心控制；远看完整，近看有方块结构。
- 离散色阶：颜色过渡靠有限色阶与邻近色块交错、局部抖动，而非摄影式柔滑渐变。
- 数字马赛克质感 + 复古屏幕显示感 + 手工逐点绘制的工艺感。
- 常见词汇：颗粒化的光、块状化的空气感、色带式天空、数字拼贴层次。

### 3. 配色特征
- 高饱和但不脏；主色明确，冷暖对比鲜明；用色"少而准"（1–2 主色 + 1–2 高亮点缀 + 深色轮廓压暗）。
- 典型配色方向：
  - **霓虹黄昏 / 迈阿密晚霞系**：紫蓝夜空、粉紫晚霞、金黄月亮、玫红洋红橙粉灯牌 → 赛博复古、热带夜景、synthwave / vaporwave。
  - **晴空海岸糖果色**：高纯度蓝天、白云、青绿海水、粉色主体、棕榈树深绿黄绿 → 夏日海边、乐园感、元气理想化。
  - **温暖室内复古棕金系**：蜂蜜色灯光、木质棕、米白浅咖、书页黄、红橙点缀 → 治愈系、旧书店 / 老宅 / 昭和日系、温暖回忆。
  - **经典游戏海报原色系**：宝蓝、正红、金黄、草地绿、粉色公主裙 → 街机封面、童话冒险、像素英雄叙事。

### 4. 光影特点
- 光源非常明确：月亮 / 夕阳 / 店铺灯 / 室内台灯 / 天空高光 / 招牌霓虹，画面明暗围绕它组织。
- 块状发光：用几级亮色块、边缘高光、轮廓提亮、像素化反射来表现光，观感像灯箱 / 老游戏发光贴图 / 被美化的 CRT 夜景。
- 情绪性氛围光：月光 + 霓虹、暖灯 + 木楼梯阴影、正午阳光 + 高反差白云、傍晚天空 + 水面倒影；追求浪漫、故事、怀旧、梦境感，而非严格物理写实。

### 5. 构图特点
- 正面、居中、图标化：主体居中，识别度高，像游戏封面 / 关卡开场 / 章节插图。
- 分层如舞台：前景（道路、栏杆、植物、桌灯）／中景（人物、建筑、车、宠物）／远景（城市、海面、云、城堡）／背景（天空、月亮、色带）。
- 大形体简洁 + 小细节丰富：整体轮廓一眼看懂，局部装饰（星星、招牌窗格、按钮、书脊）耐看。

### 6. 角色造型
- 轮廓硬朗、图形化：边缘清晰，外轮廓明确，常带深色 / 黑色轮廓线参与塑形。
- 造型夸张简化：棕榈叶概括成节奏大块，汽车是经典侧面剪影，五官用极少像素概括，城堡 / 房屋 / 售货机具几何符号性。
- 人物偏 Q 化或低细节：头身比略偏可爱，表情简洁，服装靠色块分层；高完成度时可在头发、褶皱、姿势上加表现力。
- 适配用户偏好：可塑造可爱的 IP 化角色（如像素黑猫），走轻松诙谐、女频友好的气质。

### 7. 题材母题
- 城市夜景霓虹（棕榈树、月亮、公路、老车、招牌、倒影、高楼剪影）。
- 海边夏日假日（蓝天白云、沙滩、海面、售货机、粉色设施）。
- 治愈系生活场景（书房、楼梯、书架、台灯、宠物、窗边、木屋）。
- 童话冒险 / RPG 海报（骑士、公主、城堡、草地、像素标题字）。

### 8. 文字与版式（如画面需要文字元素）
- 像素字体 / 复古标题、游戏提示对话框、街机 UI 边框、复古招牌字样，强化游戏界面感与海报感。
- 让作品带有"这真是某款游戏的截图 / 宣传页"的代入感。

### 9. 情绪关键词
怀旧、梦幻、浪漫、治愈、复古、街机感、电子感、童话感、游戏封面感、夏日感 / 夜色感 / 温暖回忆感。

## 标准工作流程（Agent 执行时按此走）

1. **确认内容需求**：明确用户要生成哪些图片素材（角色图、场景图、道具图等）和哪些视频镜头；若同时加载了脚本 / 分镜 / 营销类 skill，让它们产出内容与镜头结构。
2. **写内容描述**：用上面「风格知识库」的词汇，为每个素材 / 每个镜头写具体画面描述（角色、场景、光线、构图、动作、镜头运动）。
3. **前置拼接锚定词**：把固定风格锚定词逐字放在**每一条** prompt 的最前面，后接该条的具体描述。若有其他风格 skill，按合并规则拼接。
4. **关闭内置风格图**：生成前显式绕过 / 关闭 Agent 内置的风格锚定图，只用文本锚定词驱动风格。
5. **生成并核对**：生成图片与视频；核对是否每条 prompt 都带了完整锚定词、风格是否统一。
6. **交付说明**：交付时说明所有 prompt 均已前置像素游戏风锚定词、已绕过内置风格图，风格保持一致。
