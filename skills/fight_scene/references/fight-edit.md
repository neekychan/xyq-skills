# 武打视频严格编辑

本文件只在用户要求修改现有视频时读取，并且必须在唯一问卷之前读取。目标是先把编辑输入整理到当前模型可接受的时长，再进行唯一一次视频生成。

## 一、编辑边界

- Prompt 首句逐字使用 `严格编辑<视频1>`，尖括号必须保留，禁止使用 `@视频1` 或“参考视频1”。
- 只修改用户点名的对象、特征或动作。源片时长、声音、字幕、UI、已有文字、logo、主体身份、镜头和其他内容默认保持。
- 预处理只解决生成工具的时长合法性，不借机重剪叙事、改速、消音或移除画面元素。
- 当前轮仍只调用一次 `sandbox_generate_video`，预处理不计为视频生成。

## 二、先检查源片

1. 用 `sandbox_read` 确认用户指定的视频和说明。
2. 用 `sandbox_bash` 调用 `ffprobe` 读取真实时长和音频流：

```bash
ffprobe -v error -show_entries format=duration -show_streams -of json '源视频路径'
```

3. 从 `SKILL.md` 读取当前模型已经渲染的上限。上限 30 秒时下限 2 秒；上限 15 秒时下限 4 秒。
4. 在调用问卷前判断源片属于合法整数时长、超上限、低于下限或非整数时长，并把所需选择合并进本轮唯一问卷。

## 三、合法时长源片

源片时长是工具支持范围内的整数时，直接将完整源片作为 `VideoList` 第一项，`Duration` 等于源片时长。禁止套用新片缺省上限。

## 四、超上限源片

用户已给出合法的起止区间时直接采用。区间缺失时，在唯一问卷中确认本轮编辑区间：

- 优先提供与用户修改目标匹配的可见动作区间。
- 无法判断时提供开头、居中、结尾几个合法区间，并允许文本填写精确起止时间。
- 说明本轮只交付所选区间的编辑结果，源片其余部分不会进入当前生成。

确认后先创建目录，再裁出所选区间。`片段秒数` 必须是当前模型支持范围内的整数：

```bash
mkdir -p assets/fight_scene_edit
ffmpeg -n -ss '起点秒数' -i '源视频路径' -t '片段秒数' -map 0:v:0 -map 0:a? -c:v libx264 -preset medium -crf 18 -c:a aac -b:a 192k -movflags +faststart 'assets/fight_scene_edit/clip_唯一后缀.mp4'
```

将裁出的片段作为 `<视频1>`，`Duration` 等于片段秒数。

## 五、低于下限或非整数源片

这两种情况无法同时满足“原时长完全不变”和工具合法时长，必须取得用户授权：

- 低于下限：推荐补足到当前模型最短时长，结尾复制最后一帧并延续或平缓衰减原音频；另一个选项是停止，等待用户提供合法源片。
- 非整数时长：确认向下裁到整数秒，或向上补足到整数秒。选项必须标明会减少或增加多少时长。

用户选择补足后，先检查是否有音频流。创建目录并使用唯一输出路径：

```bash
mkdir -p assets/fight_scene_edit
ffmpeg -n -i '源视频路径' -vf 'tpad=stop_mode=clone:stop_duration=补足秒数' -af 'apad=pad_dur=补足秒数' -t '目标整数秒' -c:v libx264 -c:a aac -movflags +faststart 'assets/fight_scene_edit/padded_唯一后缀.mp4'
```

无音频流时去掉 `-af` 与音频编码参数。用户选择裁短时，使用第四节的裁切命令，从 0 秒开始裁到确认的整数时长。用户选择停止时，不调用视频生成。

## 六、编辑 Prompt 与调用

```text
严格编辑<视频1>，仅将其中的[原特征]修改为[新特征]，未提及内容保持不变。
```

- 每项修改写出原对象、原特征、新特征、出现位置和作用范围。
- 不为编辑任务套用新片的默认音效、字幕或 UI 规则。
- `VideoList[0]` 必须是完整合法源片，或用户确认后裁切、补足的合法片段。
- `Duration` 必须与 `<视频1>` 的预处理后整数时长一致。
- 调用前检查 Prompt 字面量以 `严格编辑<视频1>` 开始，全文没有 `严格编辑@视频1`。
- 工具返回成功后立即交付；返回任何错误后停止，禁止再次生成。
