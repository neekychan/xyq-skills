# 色彩弧光与视觉焦点轴线 / Color Arc & Eye Tracing

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 一、色彩弧光（Color Arc）

全片色调随叙事推进有意识地演变，三段递进、不可互换。

### 三段色彩弧光设定

| 段落 | 色彩弧光 | 主色调 | HSL 参考区间 | 情绪基调 |
|---|---|---|---|---|
| Section A (0–15s) | 清爽白底信息图 | 白、极浅灰、冷中性 | 高亮度 (L: 85–100%)，低饱和 (S: 0–15%) | 理性、科学、克制 |
| Section B (15–30s) | 写实自然绿棕 | 自然绿 + 泥土暖棕 | 绿 H:80–140, S:30–60%；棕 H:20–40, S:40–70% | 生机、成长、土地 |
| Section C (30–45s) | 生活中性明亮 | 中性暖灰 + 柔和天光 | 暖灰 H:30–50, S:15–35% | 人文、温暖、升华 |

### 色彩弧光审计标准

1. **组内一致性**：每组 6 格画面的色调应在该组设定区间内，无突变
2. **跨组过渡**：A→B 和 B→C 的色调过渡应平滑，不出现色彩突变
3. **植物色彩连续性**：植物叶形与花色在全片 18 格中保持一致（叶绿、花色不因段落转换而改变）
4. **与 Plant_Asset_01 基色对齐**：Section B/C 的视频调色参考底色应与解析图中识别的主导色一致

### 色彩弧光自检

```
Section A: [ ] 白/浅灰底？ [ ] 低饱和？ [ ] 无写实色调？
Section B: [ ] 自然绿+泥土棕为主(≥90%)？ [ ] 与解析图基色对齐？
Section C: [ ] 中性暖灰？ [ ] 柔和天光？ [ ] 温暖但不饱和过高？
跨组:    [ ] A→B 平滑？ [ ] B→C 平滑？ [ ] 植物色彩全程一致？
```

## 二、视觉焦点轴线对齐（Eye Tracing）

### 核心原则

前一个镜头的尾帧视觉重心必须与后一个镜头的首帧实现**动量守恒**——即观众的视线在镜头切换时不需要大幅度跳跃，保持纪录片级的极度流畅。

### 标注规范

强制标注 2×3 矩阵中 18 个镜头的中心坐标 (X, Y)：

```
Section A 矩阵:
┌──────────┬──────────┬──────────┐
│ A1 (X,Y) │ A2 (X,Y) │ A3 (X,Y) │
├──────────┼──────────┼──────────┤
│ A4 (X,Y) │ A5 (X,Y) │ A6 (X,Y) │
└──────────┴──────────┴──────────┘

Section B 矩阵:
┌──────────┬──────────┬──────────┐
│ B1 (X,Y) │ B2 (X,Y) │ B3 (X,Y) │
├──────────┼──────────┼──────────┤
│ B4 (X,Y) │ B5 (X,Y) │ B6 (X,Y) │
└──────────┴──────────┴──────────┘

Section C 矩阵:
┌──────────┬──────────┬──────────┐
│ C1 (X,Y) │ C2 (X,Y) │ C3 (X,Y) │
├──────────┼──────────┼──────────┤
│ C4 (X,Y) │ C5 (X,Y) │ C6 (X,Y) │
└──────────┴──────────┴──────────┘
```

坐标原点为画面中心 (0.5, 0.5)，X 为水平方向，Y 为垂直方向，范围 [0, 1]。

### 动量守恒规则

| 规则 | 说明 | 偏差阈值 |
|---|---|---|
| 组内连续 | 同组内相邻 Grid 的视觉重心偏差 | ≤ 20% |
| 组际衔接 | A6→B1、B6→C1 的视觉重心偏差 | ≤ 25% |
| 全片流畅 | 任意相邻镜头的视觉动量方向一致或自然衰减 | 无突变反转 |

### 示例（以 Section B 为例）

```
B1 → B2: 视觉重心从画面下方(种子) → 画面中下方(嫩芽破土)，动量向上
B2 → B3: 视觉重心从中下方 → 画面中部(茎叶)，动量继续向上
B3 → B4: 视觉重心从中部 → 画面中上部(叶片表面水珠)，动量上移后稳定
B4 → B5: 视觉重心从中上部 → 画面中部(剪刀修剪)，动量自然下移
B5 → B6: 视觉重心从中部 → 画面中下部(穗头下垂)，动量向下收束
```

### 视觉焦点轴线自检

```
[ ] 18 格是否全部标注中心坐标 (X,Y)？
[ ] 组内相邻 Grid 偏差是否 ≤ 20%？
[ ] 组际衔接偏差是否 ≤ 25%？
[ ] 动量方向是否一致或自然衰减？
[ ] 是否消除频繁切镜带来的跳跃感？
```
