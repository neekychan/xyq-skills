# 分镜图模板：音乐 MV · 情绪氛围

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：不强绑定歌词逐句，而以歌曲整体**情绪、色调、意象**为核心驱动画面的 MV 分镜，强调“情绪有层次、画面有氛围”。
- **典型场景**：
  - 只有旋律/哼唱、无完整歌词或不需要逐句对应的歌曲。
  - 纯音乐、Lo-fi、氛围电子、治愈/孤独/疗愈类曲目。
  - 以“感觉”为主、用意象与光影叙事的情绪短视频。

## 2. 判定关键词与适用边界
- 典型触发词：`情绪氛围 MV`、`氛围感`、`意境`、`治愈/孤独/emo`、`纯音乐配画面`、`不要逐句歌词`。
- 适用判定：
  - 用户更关注整体情绪与色彩基调，而非歌词逐段映射；
  - 接受“画面跟情绪/段落走”，不要求每句歌词对应一格。
- 不适用场景：
  - 用户提供完整歌词且要求逐句对应 → 用“歌词逐段视觉化”模板；
  - 重点是字幕呈现 → 用“歌词字幕·动态排版”模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–12 格，按情绪曲线而非歌词划分；
- 规划方式：
  - 先定情绪曲线：铺垫 → 累积 → 高潮 → 释怀/余韵；
  - 每个情绪阶段配 2–3 个意象画面（自然、空间、人物状态、抽象光影）；
  - 高潮段画面密度与色彩对比最强，余韵段留白、放慢。

## 4. 生图 Prompt（PE）模板

```text
你是一名情绪氛围 MV 分镜导演，请根据下述歌曲信息，设计一张 {宫格数} 宫格的“情绪氛围”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”}。

【歌曲与情绪信息】
- 歌曲名称：{歌名，可空}
- 曲风与情绪：{如“Lo-fi/治愈/孤独/释怀/夜晚都市”等}
- 节奏与能量：{如“慢-起伏-高潮-回落”}
- 核心意象关键词：{如“雨夜、霓虹、海边、窗光、独行背影”}

【拆分要求】
1. 不按歌词逐句，而按情绪曲线划分为：铺垫/累积/高潮/余韵；
2. 每个阶段给 2–3 个意象画面，明确该画面承担的情绪；
3. 用色彩与光影变化体现情绪推进，而非剧情冲突。

【分镜输出格式】
- 宫格编号：M1–M{N}，按情绪时间线排列；
- 对于每一格输出：
  - 所属情绪段：{铺垫/累积/高潮/余韵}
  - 画面意象：{自然/空间/人物状态/抽象元素}
  - 情绪与色彩：{冷暖、明暗、饱和度倾向}
  - 光影与镜头感：{如“逆光剪影、慢推、虚焦霓虹”}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16；
- 画风：{电影感写实 / 胶片颗粒 / 2D 插画 / 抽象视觉}；
- 全片保持统一主色调与画风，高潮段可强化对比，余韵段降饱和、增留白。
```

## 5. 一致性与避坑
- 避免画面只是“好看的空镜堆砌”，每格都要落在明确情绪阶段上。
- 主色调与画风需贯穿全片，仅用明暗/饱和度变化体现情绪推进。
- 若出现人物，外观与造型需在全片保持一致。
- 高潮与余韵的对比要拉开，避免全片一个情绪平面。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段完成“情绪曲线 → 意象画面”映射；
  - 视频阶段以情绪关键格为参考帧，Prompt 中强调情绪、光影与运镜，弱化具体叙事；
  - 运镜以慢推/慢摇/虚实变化为主，节奏跟随音乐能量起伏。
- 情绪基调与色彩规划可参考 `creative/` 下的风格/调色相关约定；运镜语言可参考 `storyboard/prompt-craft.md`（如有）。
