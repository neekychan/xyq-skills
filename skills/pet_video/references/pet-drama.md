# 类型 B：萌宠拟人短剧创作指南

## 设计原则

**核心卖点**：用动物演人类的故事套路，反差萌 × 剧情张力。

**剧情来源**（选一个方向发散，不要每次都用霸总）：
- **经典梗翻拍**：霸总、宫斗、修仙、逆袭、甜宠、末日——把互联网热梗的"人"全换成动物
- **职场日常**：开会、述职、摸鱼、加班——用动物的反差放大职场情绪
- **家庭关系**：猫妈/狗爸带崽、兄弟争宠、跨物种友情
- **冒险/任务**：探险、寻宝、逃跑、拯救——适合连载
- **用户自定义**：用户给了故事梗概时，按其方向展开，不替换主题

**角色设计要点**：
- 用品种天然性格差异制造戏剧张力（橘猫=贪吃/憨/社牛，英短=高冷/傲娇，柴犬=倔/忠诚）
- 视觉区分靠**品种+毛色+一个标志性配饰**，不要依赖服装细节（模型记不住复杂服装）
- 同框最多 4 个动物角色，超过 4 个画面会乱

**台词心法**：
- 短剧台词要"出圈"——有记忆点、有情绪爆点、适合二次传播；写完自检：去掉语境单独读，是否有网感、会不会被截图传播——"很好吃""比别人强"这类空洞比较句不算出圈
- 每句 ≤15 字，节奏快，不拖
- 情绪转折点的台词最重要，花最多心思打磨

**冲突要有真正的转折**：
- 冲突不能停在"发生了→双方对峙"就结束，必须有至少一个观众没预料到的转折点（意外揭穿/反转身份/意外和解/弄巧成拙），落地到具体某一镜头或台词里，不能只停留在角色卡文字设定层面（如角色卡写了"表面强势实际心虚"，就要有一个镜头让这层心虚具体暴露出来）
- 结尾必须有明确收尾（谁赢/如何和解/新状态），不要停在"对峙中"就结束——短剧要让观众感觉"看完了一个完整故事"

**音频设计**：
- 每个角色锁独立音色，用体型/性格匹配（不要全用童音）
- BGM 跟着情绪走（紧张→温馨→搞笑的切换靠 BGM 传递）
- **音效（强制）**：每段至少 1 个关键剧情音效，缺音效的短剧像默片、张力大幅下降。例：怒吼时 `<警报声>`、纸箱落地 `<纸箱放地上的声音>`、尾巴摇摆 `<铃铛声>`、角色登场 `<脚步声>`

## Prompt 示例

### L3 短剧（双角色对话）

```
参考@图片1的橘猫老板形象（正常家猫体型，橘色短毛，穿黑色西装，戴墨镜）和@图片2的白猫员工形象（正常家猫体型，纯白长毛，穿蓝色工装），真实写实画风，细腻真实毛发质感。
现代办公室，落地窗外是城市天际线，冷色调灯光。

镜头1：中景，橘猫两足直立站在办公桌后，双前爪交叉放在桌面上，嘴角下垂严肃表情。
橘猫说：{这个季度的鱼罐头销量下降了30%}，参考@音频1的低沉威严男声。

镜头2：切近景，白猫站在桌前，双前爪紧握在身前，耳朵后压，眼睛微微眯起紧张表情。
白猫说：{老板，我有一个大胆的想法}，参考@音频2的轻细怯懦女声。

镜头3：切回中景双人，橘猫缓缓摘下墨镜，露出好奇表情，一只耳朵竖起。

保持拟人动物体型比例，爪部为动物爪而非人手，画面稳定，保持无字幕，不要在同一画面中复制相同动物。
```
调用时 `ImageList: [character_boss_ref.png, character_staff_ref.png]`，`AudioList: [voice_boss.mp3, voice_staff.mp3]`——**音色锚定一旦生成，必须在角色出场的每段里都这样传入，不能只在 Prompt 文字里描述音色而不传 AudioList**。

## 分段策略（先于 Prompt 编写确认，铁律）

- **同一场景合并为一段**：同一地点 + 同一时间 + 同一组角色 = 同一段，用画面阶段（镜头1/镜头2/镜头3）分隔，**禁止拆成多次 `sandbox_generate_video`**
- **场景切换才拆段**：地点/时间/角色组合变化时才拆
- **时长 ≤ {{.max_video_duration}}s 不拆段**：即使多镜头也合并为一次调用
- 拆段前自问：本段与上一段同一场景吗？总时长 ≤ 上限吗？两个"是"却仍想拆 → 决策有误，合并（拆错会导致角色漂移 + render 漏调 + 成片不交付）

## 连载管理

文件组织：
```
assets/{project}/
  creative_design.md         # 全局创意（角色卡、世界观）
  character_{name}_ref.png   # 共享参考图（跨集复用）
  voice_{name}.mp3           # 共享音色（跨集复用）
  ep01/
    shot_01.mp4 ... output.mp4
  ep02/
    shot_01.mp4 ... output.mp4
```

- 参考图和音色是**项目级资产**，跨集复用
- 每集结尾留钩子（悬念/新角色暗示/未解决冲突）
