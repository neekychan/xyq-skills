# 分镜图模板：动作分解 · 动作导演镜头表

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以导演视角记录动作场面的镜头表，将每个镜头的景别、机位、运镜、动作内容与速度（慢动作/正常/快剪）结构化罗列，形成可直接用于拍摄或视频生成的**动作导演镜头表**。
- **典型场景**：
  - 电影/短剧中的武打场面、追车戏、群体动作场面的镜头规划。
  - 广告或 MV 里的高动作量段落，需要精确控制景别、机位与运镜节奏。
  - 动作游戏、影视预告片的动作剪辑规划，用于输出专业镜头语言的分镜脚本。

## 2. 判定关键词与适用边界
- 典型触发词：`运镜设计`、`动作镜头表`、`镜号`、`景别`、`机位`、`慢动作`、`快剪`、`摄影机移动`、`一镜到底动作场面`。
- 适用判定：
  - 用户明确提到“想设计运镜/机位”“需要导演级动作分镜表”“按镜号写动作脚本”，希望对每个镜头的参数进行专业标注；
  - 场面以动作为核心（打斗、追逐、炫技动作），同时关注镜头语言与速度感。
- 不适用场景：
  - 仅需要简易动作分解，不关心具体机位与运镜细节 → 适合“动作分解表”“姿态连续分镜”；
  - 纯剧情对话或少量动作，不以动作场面为主 → 适合“剧情分镜表”“影视导演镜头表”等模板。

## 3. 分镜结构建议
- **推荐宫格数（镜头数）**：8–20 格，每格对应一个镜号，一镜一行，覆盖从场面建立到高潮收束的完整动作段落。
- 规划方式：
  - 先用文字概括动作段落的整体弧线（如“开场冲入 → 中段近身缠斗 → 高潮大招 → 收势定格”），再根据弧线拆分镜头数量；
  - 每格固定包含：镜号、景别、机位位置与高度、运镜方式、速度（慢动作/正常/快剪）、主要动作内容与情绪；
  - 按现场拍摄或虚拟摄影机逻辑安排镜头顺序，保证机位与场面空间关系连贯，避免无意义跳轴。
- **画面特征**：镜头表可用表格或多宫格形式呈现，重点是文字镜头参数与动作内容说明，可选附带简单画面草图帮助理解构图。

## 4. 生图 Prompt（PE）模板

```text
你是一名动作导演兼分镜师，请为 {动作片段类型，如“武侠打斗场面/城市追车戏/动作游戏宣传片高潮段”等} 设计一份 {镜头数，如 10/16/20 镜} 的动作导演镜头表分镜图，整体画幅为 {画幅比例说明，如“16:9 横版电影画幅”或“9:16 竖屏动作短片”}。

【片段与场景信息】
- 片段名称：{如“屋顶对决”“地下停车场追车”“城市夜景跑酷”等}
- 场景设定：{时间、地点、光线与空间结构，如“夜晚、雨天、城市高楼屋顶，灯光对比强烈”等}
- 主要角色：{出场角色列表及基本外观设定}
- 整体动作弧线：{如“冲入战场→贴身缠斗→升级大招→终结定格”等}

【镜头表结构】
- 镜号范围：S1–S{N}，其中 {N} = {镜头数}；
- 每个镜号需包含：景别、机位、运镜、时长、动作内容、速度（慢动作/正常/快剪）、情绪重点。

【镜头分镜输出格式】
请依次为 S1–S{N} 输出以下信息（按镜头顺序）：
- 镜号：{如“S1”“S2”…}
- 景别：{远景/全景/中景/近景/特写}
- 机位与视角：{机位高低与位置，如“低角度仰拍，机位在主角侧后方”“俯视拍摄整个大厅”等}
- 运镜方式：{推/拉/摇/移/跟拍/一镜到底/手持等，可组合}
- 时长与节奏：{该镜预期时长秒数及是否慢动作/快剪}
- 主要动作内容：{该镜中的关键动作链与交锋事件，注意是连续动作而非单帧摆拍}
- 情绪与氛围：{紧张/压迫/解放/炫技等}
- 空间与站位：{画面中主要角色的站位与朝向，遵守轴线与空间连贯性}
- 可选音效/特效提示：{如“金属碰撞声密集”“爆炸冲击波”“粒子残影”等}

【画幅与风格】
- 画面比例：{16:9 / 9:16 等，电影级动作推荐 16:9}
- 画风：{仿真人写实 / 电影概念插画 / 3D 动画 等}
- 展示形式：{纯文字表格 / 表格+小画面草图等，说明每格是否需要附带画面示意}
- 要求镜头号连续、镜头语言专业一致，角色与场景在整个镜头表中外观与空间关系稳定。
```

## 5. 一致性与避坑
- 镜头号必须连续且与动作弧线匹配，不要随意插入“无动作静态镜头”，避免打断动作流。
- 景别、机位和运镜描述使用统一术语体系（远景/近景、推拉摇移、一镜到底等），避免同一含义反复换说法导致执行混乱。
- 相邻镜头的机位高度和方向要遵守轴线原则，避免角色左右位置在剪辑后突然互换。
- 动作内容必须以连续动作链描述，而非单招互殴；每镜至少包含起手→跟进→收束的动作结构。
- 镜头表中涉及高强度战斗或特效段落时，应提前规划好动量锚点运镜模式，避免“镜头跟不上动作”“速度感缺失”。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“影视导演镜头表”和“动作分解表”相关执行模板：
  - 分镜阶段用本模板输出 S1–S{N} 的动作镜头表，在调用视频生成时作为镜头参数与动作内容的主参考；
  - 视频阶段按镜头表顺序构造多镜脚本，每个镜头的景别、机位与运镜指令须复用 storyboard/prompt-craft.md 中的运镜与空间构建句式。
- 涉及打斗、追逐或大规模动作特效的镜头段落，视频 Prompt 必须参考 `storyboard/vfx-action-prompt.md`：
  - 为每个关键 3–5 秒时间段在脚本中嵌入“动量锚点运镜指令块 + 空间定位 + 战斗氛围/动作氛围 + 连招动作链 + 碰撞反馈与环境碎裂”的结构；
  - 明确每个镜头的镜头锚点（主角动量跟随 / 受力反馈跟随 / 一镜到底），并在段落内保持一致，避免无理由切换锚点。
- 本模板适合与“打斗/竞技分镜”“运动轨迹示意分镜”“动作脚本表格”组合使用：镜头表负责机位与运镜，其他模板负责动作结构与空间路径，三者共同约束成片中的动作质量与镜头语言。
