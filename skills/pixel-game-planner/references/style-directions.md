# 像素游戏创意方向

## 8 个预设方向

### 方向 1：森林金币冒险
- 名称：森林金币冒险
- 主角：红围巾小猫 / 绿帽冒险家
- 关卡：森林跳台关，从左向右推进
- 敌人：巡逻史莱姆、跳跃蘑菇怪
- 道具：金币、钥匙、宝箱、终点旗帜
- 核心玩法：走路、跳跃、拾取、闪避、通关
- 视觉重点：绿色森林背景、木质平台、金币闪烁

### 方向 2：地下城钥匙逃脱
- 名称：地下城钥匙逃脱
- 主角：蓝帽探险家 / 火把骑士
- 关卡：地下城石壁关，有机关和暗门
- 敌人：骷髅兵、蝙蝠、幽灵
- 道具：钥匙、火把、宝箱、传送门
- 核心玩法：找钥匙、开门、躲避机关、逃脱
- 视觉重点：火把光照、石墙壁面、暗色基调

### 方向 3：宇宙街机射击
- 名称：宇宙街机射击
- 主角：宇航员 / 飞船
- 关卡：星空背景，纵向或横向卷轴
- 敌人：外星虫、飞行眼球、机械球
- 道具：能量球、星星、护盾
- 核心玩法：射击、闪避、收集能量
- 视觉重点：深紫星空、霓虹光效、像素弹幕

### 方向 4：城堡骑士闯关
- 名称：城堡骑士闯关
- 主角：银甲骑士 / 披风勇士
- 关卡：城堡内部，有平台和楼梯
- 敌人：骷髅兵、蝙蝠、机械球
- 道具：宝剑、盾牌、宝箱、金币
- 核心玩法：挥剑攻击、跳跃平台、开门通关
- 视觉重点：灰紫石墙、火把橙光、金色装饰

### 方向 5：城市夜景霓虹跑酷
- 名称：城市夜景霓虹跑酷
- 主角：连帽跑者 / 霓虹机器人
- 关卡：城市屋顶和灯牌，横向卷轴
- 敌人：飞行无人机、机械守卫
- 道具：能量饮料、金币、传送门
- 核心玩法：跑酷、跳跃、滑行、闪避
- 视觉重点：蓝黑夜色、霓虹粉蓝灯牌、城市轮廓

### 方向 6：神庙机关解谜
- 名称：神庙机关解谜
- 主角：探险考古学家 / 小沙狐
- 关卡：神庙内部，有机关和石板
- 敌人：石像守卫、蛇
- 道具：宝石、机关按钮、钥匙、宝箱
- 核心玩法：解谜、触发机关、收集宝石、开门
- 视觉重点：沙金色石墙、青绿宝石光、古老符文

### 方向 7：雪山平台跳跃
- 名称：雪山平台跳跃
- 主角：蓝围巾企鹅 / 白毛雪人
- 关卡：雪山冰壁，有滑冰平台和雪堆
- 敌人：雪球怪、冰晶蝙蝠
- 道具：雪花星星、热可可、宝箱
- 核心玩法：跳跃、滑行、躲避雪球
- 视觉重点：冰蓝白色调、雪花飘落、冰面反光

### 方向 8：机械工厂 Boss 关
- 名称：机械工厂 Boss 关
- 主角：工程师机器人 / 工装小人
- 关卡：机械工厂内部，有齿轮和传送带
- 敌人：机械守卫、飞行机器人、Boss
- 道具：螺丝帽金币、能量核心、修理包
- 核心玩法：躲避齿轮、攻击弱点、Boss 战
- 视觉重点：铁锈橙、钢蓝、齿轮转动、蒸汽喷射

## 参考图分析规则

当用户提供参考图时，必须先分析参考图，**但不能照抄**。参考图只能用于提取风格规律、像素比例、色板和构图逻辑，最终必须转成原创方案。

分析内容：

```
参考图分析：
- 像素尺寸倾向：
- 色板倾向：
- 角色比例：
- 角色轮廓：
- UI 特征：
- 场景层级：
- 关卡结构：
- 动作帧特征：
- 可借鉴方向：
```

分析完成后，基于提取的风格规律，选择或创建一个**原创**方向，不直接复刻参考图的角色/关卡/配色。
