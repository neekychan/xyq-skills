# 分镜图模板：剧情叙事 · 角色场景设定 + 分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：在正式剧情分镜前，先输出角色参考区与场景参考区，再输出剧情分镜区的一类模板。重点是**先锁定角色与场景设定，再用分镜讲故事**，适合角色一致性要求高、多场景、多集项目。
- **典型场景**：
  - 长线 IP 角色设定 + 剧情分镜（如系列短剧、番剧、连载故事）。
  - 多主角、多场景的情感故事或奇幻剧情。
  - 影视级预制作：先做角色/场景设定板，再做导演分镜表。

## 2. 判定关键词与适用边界
- 典型触发词：`角色设定`、`角色小传`、`场景设定`、`场景设计`、`世界观设定`、`人物造型先统一`、`先画角色和场景再分镜`。
- 适用判定：
  - 用户强调“角色/场景一致性很重要”“先确定角色外观和场景气质”，再谈分镜结构。
  - 同一项目中角色会反复出现在多集/多条短视频里，需要跨作品保持形象统一。
- 不适用场景：
  - 只需要一次性剧情分镜、对角色长线一致性要求不高 → 直接用通用“剧情叙事型”模板。
  - 纯动作/纯产品/纯教学场景 → 优先走对应类型模板。

## 3. 版式结构与分镜建议
整体分为 **三大区域**：
1. **角色参考区**
   - 展示主要角色的多角度形象：正面、侧面、背面、半身、全身、典型表情。
   - 标注姓名/身份/年龄/气质/服装/标志性道具。
2. **场景参考区**
   - 展示主场景与关键空间：俯视平面图、主视角、重要动线（门/窗/楼梯/舞台等）。
   - 标注时间（白天/夜晚）、光影方向、主色调与氛围。
3. **剧情分镜区**
   - 使用 6/9/12 格讲完一个短篇故事，按三幕式结构排布。
   - 每格需要明确景别、主角站位、关键动作与情绪。

推荐流程：**先画角色区 + 场景区 → 再补剧情分镜格**，所有后续剧情分镜必须对齐前两区设定。

## 4. 生图 Prompt（PE）模板

```text
你是一名剧情短片美术总监兼分镜师，请为下述故事生成一张包含【角色场景设定 + 剧情分镜】的分镜图，整体画幅为 {画幅比例说明，如“16:9 横版导演分镜板”或“9:16 竖屏故事短片”}。

【故事信息】
- 题材与基调：{如“治愈系娃娃机奇遇/都市重逢/父女和解”等}
- 主角与关系：{主角姓名+身份+外观+性格，关键关系如“父女/恋人/室友”}
- 故事梗概：{80–150 字概述起承转合}

【版式结构】
- 上半部分：角色参考区 + 场景参考区
- 下半部分：{宫格数，如 6/9/12} 宫格剧情分镜区
- 分镜区按阅读顺序编号 S1–S{N}，对应故事三幕式结构。

【角色参考区要求】
- 为每个主要角色输出 2–4 个关键视角：正面/侧面/半身/全身，自然站姿。
- 标注：姓名/身份/年龄/外观特征/服装/常用道具/气质关键词（如“温柔内向/外向活泼”）。
- 角色外观必须在后续剧情分镜格中 **完全保持一致**（五官、发型、服饰、身形、关键道具）。

【场景参考区要求】
- 至少输出 1–2 个核心场景：如“娃娃机店”“夜间街道”“家庭客厅”等。
- 对每个场景说明：空间结构（门窗/吧台/柜台位置）、主色调、时间（白天/夜晚）、光源方向。
- 后续剧情分镜中涉及该场景的格子必须与参考区中空间关系大致一致。

【剧情分镜区要求】
- 宫格数：{宫格数，如 9/12}，按三幕式结构拆分：
  - 开始：1–3 格，交代人物与起始状态；
  - 发展：3–6 格，冲突升级与情绪变化；
  - 收束：2–3 格，结果/反转/余韵。
- 为 S1–S{N} 逐格写出中文分镜说明，包含：景别 + 角色站位 + 关键动作 + 情绪。

【画幅与风格】
- 画幅比例：{9:16 / 16:9 / 1:1}，推荐 16:9 用于导演板，9:16 用于短视频。
- 画风：{如“仿真人写实 / 3D 动画 / 2D 动漫 / 水彩插画”等}
- 色调：{主色调，如“暖粉+草绿”“冷蓝+橙光”等}，在不同幕间可轻微变化但须整体统一。
```

## 5. 一致性与避坑
- **角色统一**：剧情分镜区内所有格的角色外观与角色参考区严格一致，禁止随意换装/换发型。
- **场景统一**：同一场景的门窗/桌椅/主要道具位置前后一致，仅允许视角变化。
- **信息分层清晰**：角色参考区/场景参考区/剧情分镜区三块区域视觉区分明显，避免混在一起难以阅读。
- 避免过度堆叠文字：设定信息放在参考区，剧情分镜格只写必要说明。

## 6. 视频生成策略（搭配剧情叙事/影视级运镜模板）

- 使用本模板时，视频阶段默认先将**角色参考区 + 场景参考区**落盘为独立参考图，用于后续所有镜头的一致性约束。
- 剧情分镜区可按“剧情叙事型”或“影视级运镜型”模板写出详细镜头脚本，再组合：
  - 角色与场景参考图 → 作为所有镜头的 ImageList 基础。
  - 分镜区中的关键格 → 选 3–5 格作为视频参考帧，锁定关键画面与构图。
- 适合先在一个项目内确定好角色与场景设定，再持续复用到多集内容中，减少后续反复调参的成本。
