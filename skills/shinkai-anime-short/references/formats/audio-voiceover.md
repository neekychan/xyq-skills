# 音频规范：旁白与 BGM

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 旁白风格

第一人称、青春文学、克制表达、轻微伤感。

核心特征：
- 第一人称叙述（"我曾经以为……""很多年以后……"）
- 短句为主，句号分隔，制造呼吸感
- 不直说情绪，用画面/天气/物件暗示
- 克制——不说"我好悲伤"，说"那天的天空，我至今还记得"
- 轻微伤感底色，但不绝望——最终走向希望或和解

示例句式（可适配改写，不要逐字照搬）：
- "我曾经以为，那只是一个再普通不过的黄昏。直到很多年以后，我依然记得那天的天空。"
- "雨停了。但没有人在的公交站台，积水倒映着霓虹，好像另一个世界。"
- "那封没有寄出的信，和那张过期的电车票，一起留在了那个夏天。"
- "我们之间隔着的不是距离，是时间。"

## BGM 方向

| 风格参照 | 乐器配置 | 情绪适配 |
|---|---|---|
| 秒速五厘米 | 钢琴独奏 | 内敛、遗憾、远距离思念 |
| 言叶之庭 | 钢琴 + 环境音（雨声/虫鸣） | 等待、雨中相遇、安静陪伴 |
| 你的名字 | 钢琴 + 弦乐（小提琴/大提琴） | 命运、奇迹、激烈重逢 |
| 天气之子 | 钢琴 + 电子（合成器 pad） | 超现实、牺牲、晴空代价 |
| 铃芽之旅 | 钢琴 + 吟唱（人声哼唱） | 旅途、成长、温暖治愈 |

选择规则：
- 故事主题偏"距离/遗憾" → 秒速五厘米 / 言叶之庭
- 故事主题偏"命运/重逢" → 你的名字
- 故事主题偏"牺牲/超现实" → 天气之子
- 故事主题偏"旅途/成长" → 铃芽之旅
- 混合主题时以高潮情绪为准

## 落 prompt 前自检

- 旁白是否第一人称？
- 旁白是否克制（无直白情绪宣泄）？
- BGM 配器是否与故事主题匹配？
- 旁白节奏是否与画面情绪同步？
