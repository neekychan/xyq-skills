# 品牌分析规范（阶段2执行标准）
## 品牌调性分析必须覆盖维度
1. **品牌所属类型**：高奢/时尚/运动/汽车/3C/混合类型，明确核心品类与跨界属性。
2. **质感来源拆解**：
   - 高奢感来源：材质稀缺性、工艺精度、空间留白、光影克制、时间沉淀感、文化符号
   - 时尚感来源：廓形先锋性、色彩趋势、妆发造型、姿态张力、镜头语言潮流度
   - 运动性能感来源：面料功能性、动作爆发力、速度感、人体工学、环境挑战感
   - 汽车工程感来源：车身比例、漆面质感、机械精度、速度动势、道路与环境关系
   - 3C科技感来源：材质工艺（金属/玻璃/陶瓷）、交互流畅度、光影极简性、未来感空间
3. **全球广告语气**：冷调克制/情绪饱满/先锋实验/沉稳大气/年轻活力/奢华尊享，明确适配的全球市场语境。
4. **目标人群情绪**：精准描述受众观看时的情绪反应，如向往、自信、平静、震撼、归属感、身份认同等。
5. **视觉禁忌**：明确列出绝对不能出现的元素、色彩、构图、动作，如暖色调、杂乱背景、夸张表情、廉价材质等。
6. **可用镜头语法**：列出适配的镜头类型、运镜方式、景别组合，如大光圈特写、慢门追踪、轨道平移、航拍等。
7. **可用音乐节奏**：明确BPM范围、音乐类型（电子/古典/摇滚/氛围音乐等）、情绪递进逻辑。

## 品牌理念分析必须覆盖维度
1. **品牌精神**：3-5个核心关键词，如"探索未知""极致工艺""自我表达""永续经典"等。
2. **主张关键词**：可发展为Slogan的核心短语，具备全球传播性。
3. **代言人与品牌关系**：明确代言人在叙事中的角色——是品牌精神的化身、产品的使用者、故事的主角、还是观察者？
4. **产品与人物关系**：产品是人物的延伸、身份的象征、解决问题的工具、还是共同探索的伙伴？
5. **产品与场景关系**：产品是场景的核心、融入环境的一部分、还是打破场景常规的变量？
6. **广告传播核心情绪**：全片贯穿的核心情绪，如突破束缚的自由、掌控一切的自信、静谧奢华的享受等。
7. **全球Campaign可扩展性**：该创意是否适配不同市场、不同文化语境，是否具备系列化延伸的潜力。
8. **适合的TVC叙事母题**：列出适配的经典叙事结构，如英雄之旅、自我突破、时间沉淀、极致探索、情感共鸣等。
