# 视频Prompt文法规范

所有视频生成Prompt必须遵循以下结构，使用正向描述，禁止否定式约束。

## 通用基础Prompt结构
```
[游戏风格]，[画面质量]，[视角]，[时间轴动作描述]，[UI状态描述]，[光影/材质/特效描述]，[音效描述]
```

### 基础参数（所有视频必须包含）
- 画面质量：4K超高清，60fps，游戏实机画面，PBR材质，全局光照，抗锯齿，各向异性过滤
- 稳定性：UI元素像素级稳定，无抖动，无变形，无伪影，角色模型一致，场景色调统一
- 真实感：模拟真实游戏运行效果，操作流畅，物理正确，光影自然

---

## 引导流（Video A）专用指令
### 交互段落核心描述
```
模拟真实PC游戏键鼠操作：
1. 鼠标指针平滑移动到[Start]按钮上，按钮产生白色高亮描边，轻微放大1.05倍，点击后按钮发出蓝色波纹扩散反馈
2. 界面转场采用淡入淡出效果，转场时间0.3秒
3. 选人界面中，鼠标悬停在职业标签上时，对应3D角色模型亮起边缘光，播放待机动画，技能图标弹出预览小窗
4. 加载进度条平滑增长，无跳变，提示文字每2秒切换一次
5. POV转场：从全黑逐渐提高曝光，模拟人眼苏醒效果，景深从模糊到清晰，转动视角时镜头有自然的头部晃动
```

### 禁止事项（正向表述）
- 所有UI按钮保持清晰锐利，边缘平滑
- 转场过程中UI元素无撕裂
- 3D角色模型在所有界面中造型、配色、材质完全一致

---

## 剧情流（Video B）专用指令
### 叙事段落核心描述
```
1. NPC交互：角色走到NPC前方2米处，NPC头顶弹出白色[F 对话]提示，按下F键后对话框从底部平滑滑入，动画时间0.2秒
2. 对话文字：采用等宽游戏字体，逐字打印显示，打字速度每秒8个字，[继续]提示箭头在右下角每0.5秒闪烁一次
3. 对话过程中背景保持动态：风吹动树叶和衣物，NPC有轻微的idle呼吸和动作，环境粒子效果持续
4. 移动追踪：第三人称越肩视角跟随角色奔跑，镜头有自然的上下起伏和移动惯性，穿过场景时近景物体有运动模糊
5. 遭遇触发：到达任务点时，镜头轻微Zoom in，屏幕边缘出现暗红色警告渐变，远处Boss轮廓逐渐清晰
```

### 禁止事项（正向表述）
- 对话框保持绝对静止，无抖动无模糊
- 文字显示清晰，无乱码无AI生成扭曲
- 小地图和任务栏位置固定，追踪标记平滑移动

---

## 战斗流（Video C）专用指令
### 战斗段落核心描述
```
1. 战斗动作：快节奏ARPG战斗，角色高频位移，闪避动作有0.2秒无敌帧拖影特效，普通攻击有刀光轨迹，技能释放有对应元素粒子特效（火焰/冰霜/雷电等匹配游戏风格）
2. 打击感：每次命中敌人时，镜头有0.1秒轻微震动，敌人有硬直动作，伤害数字向上弹出后淡出，命中位置有火花/血液粒子飞溅
3. UI动态反馈：玩家受击时血条平滑减少，边缘有红色受伤特效，技能释放后对应图标灰化显示CD倒计时，能量条随攻击和受击平滑增长
4. 大招特效：能量满时技能图标闪烁金色光效，按下大招键后镜头进入0.5秒慢动作，角色摆出释放姿势，随后全屏华丽特效爆炸，光照瞬间增强后恢复
5. 结算：Boss倒地后逐渐消散为金色粒子，地面掉落发光装备，2秒后结算界面从中心扩散弹出，奖励图标依次弹出有弹跳动画
```

### 禁止事项（正向表述）
- 血条、技能栏、小地图位置绝对固定，无任何位移
- UI图标保持清晰，无变形无AI重绘
- 战斗动作流畅，无卡顿无穿模
- 特效层次分明，不遮挡核心UI元素
