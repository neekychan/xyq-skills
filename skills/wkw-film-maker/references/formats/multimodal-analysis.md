# 多模态解构规范

本规范用于深度分析剧本或用户参考素材，将抽象文本转化为可拍摄的视觉、听觉与表演要素。所有解构结果必须服务于"摄像机可捕捉"这一核心原则。

---

## 一、角色动作与表情性能解构

必须深度分析剧本，提炼角色的真实表演潜能，拒绝面无表情与僵硬姿态。

### 1.1 面部微观动作

识别剧本中的情绪转折，提炼肌肉联动描述。特别注重眼神刻画：
- **隐忍的爱意**：眼眶微湿、视线快速扫视对方后迅速移开、瞳孔微微放大、嘴唇轻抿
- **被拒绝后的落寞**：视线向下低垂避开对视、下颌紧绷、嘴角微微下撇但迅速恢复、眨眼频率降低
- **时间的焦虑**：频繁抬腕看表（或看时钟）、眉头微蹙、舌尖轻抵腮帮、手指无意识敲击
- **释怀的遗憾**：眼眶泛红但嘴角浮现淡淡笑意、缓慢深呼吸、肩膀从紧绷到放松、视线投向远方

**关键原则**：东方美学的含蓄克制——情绪不通过大哭大笑表达，而通过眼部肌肉、下颌线、呼吸节奏的微观变化传递。

### 1.2 物理交互反馈

分析角色与环境道具的交互力学，所有动作必须符合物理常识：
- **手指划过墙壁**：指尖轻触斑驳墙面，指甲与墙皮产生细微摩擦，手指经过处留下淡淡痕迹，手腕随步伐自然摆动
- **手握酒杯**：杯壁凝结的水珠顺指缝滑落，酒液随呼吸微微晃动，指节因握持力度微微泛白
- **打火机点烟**：拇指拨动齿轮的清脆声响，火苗在气流中摇曳，点燃瞬间面部被暖光照亮，随后烟雾从唇间缓缓溢出
- **雨水打湿风衣**：布料因吸水颜色变深加重，肩膀处最先湿透，雨滴沿衣摆滴落形成水洼，行走时布料与腿部摩擦产生沉重感

### 1.3 多角色互动与视线

规划多人物之间的视线交汇与身体朝向，打破人物始终正对镜头的呆板格局：
- **擦肩而过**：狭窄走廊中两人错身时，其中一人视线微抬又迅速垂下，肩膀几乎相触但最终错开，步伐有0.5秒的微顿
- **烟雾中注视**：一人在烟雾缭绕中微微侧头，目光穿过烟柱落在另一人背影上，眼神随对方移动而缓慢跟移
- **对坐无言**：两人隔桌而坐，一方低头搅拌咖啡，另一方望向窗外，偶尔视线在玻璃倒影中交汇又迅速移开

## 二、三维空间与镜头深度解构

分析场景资产，确立清晰的三维景深属性。画面必须有前景-主体-背景的明确分层。

### 2.1 前景层识别（框架式阻隔）

识别可用作焦外散景的前景遮挡物，制造窥视感与空间阻隔：
- 半开的百叶窗：横向条纹光影切割画面，叶片缝隙中透出主体
- 飘动的窗帘：薄纱质地在微风中轻摆，形成半透明的流动遮挡
- 玻璃窗上的雨滴倒影：水珠折射扭曲后方景物，形成印象派般的朦胧
- 走廊的石柱/门框边缘：占据画面一侧1/4到1/3，形成画中画框
- 前景人物的肩膀/后脑勺：过肩镜头中作为天然的前景框架
- 铁栏杆/铁丝网：几何线条切割画面，营造被囚禁/被观察的感觉

### 2.2 主体层焦距

明确主体的物理位置，计算光圈虚化范围：
- 主体必须处于绝对清晰的焦平面上
- 低照度下确保皮肤质感与微表情清晰可辨
- 焦点转移时（如从前景肩膀转移到后方人物），必须有明确的焦点呼吸过程描述
- 特写镜头中：瞳孔倒影、皮肤毛孔、发丝边缘必须清晰

### 2.3 背景层纵深

提取背景的透视线、深度层次与漫反射光源：
- 远处闪烁的霓虹灯：在潮湿表面形成反射，焦外呈现圆形/六边形光斑
- 昏暗街灯下的雨丝：逆光照射下雨丝呈现银白色细线，距离越远越模糊
- 走廊壁灯的纵深排列：形成透视消失点，最近的灯最亮最远的灯渐变为光点
- 背景人物活动：适度虚化但可辨识动作（如服务员走动、路人经过），增添生活气息

## 三、声学纯净度解构

### 3.1 对白与独白声学环境

根据场景判定声音声场特征：
- **空旷旅馆房间**：人声带有0.5-1秒的自然混响，高频衰减，声音略显空洞
- **狭窄面摊/小餐馆**：环境嘈杂（碗碟碰撞、邻桌交谈、锅铲声），人声干涩直接，混响极短
- **雨夜街道**：雨声作为持续底噪覆盖中高频，人声被雨声部分遮蔽，需要略微提高音量
- **密闭电话亭**：空间极小，人声带有闷感和轻微共振，外界声音被玻璃隔绝变得低沉
- **楼梯间**：脚步声和人声在水泥墙面间反射，产生明显回声

### 3.2 物理音效定位（Foley）

提取细微的材质碰撞声，增强沉浸感。**严禁在视频提示词中描述任何BGM/音乐**：
- 高跟鞋在潮湿瓷砖上：清脆的"哒哒"声，带轻微水响
- 打火机：齿轮摩擦声+火苗点燃的"噗"声
- 烟草燃烧：极其细微的"沙沙"声，吸气时短暂加剧
- 雨水击打雨伞：沉闷的"噗噗"声，雨势变化时节奏改变
- 丝绸旗袍摩擦：走路时衣料间发出的细微"窸窣"声
- 酒杯放置：杯底与桌面接触的轻响，若用力则伴随酒液晃动声
- 老式时钟：秒针沉闷的"嗒、嗒"声，整点报时的悠长钟声
- 电车/公交车经过：远处的金属摩擦声和鸣笛声由远及近再远去

## 四、文本剧情改编解构（剧本大师核心引擎）

在分析及改编原始故事文本时，必须将纯文学、描写性或抽象的文字，严格解构、翻译为纯视觉与物理行为表现。

### 4.1 文学情感的"视觉化行为翻译"

**严禁保留心理描写或带有"仿佛""似乎""感到极其"等主观描述。** 遇到角色抽象情绪时，遵循物理常识和行为逻辑，逆向解构为摄像机拍得到的动作与表情：

| 文学描写 | 视觉化翻译 |
|---|---|
| 犹豫不决 | 在门槛前踱步，右手抬起悬在半空（手指距门把手五厘米），停顿两秒，接着缓慢缩回手，视线向下移，脚尖在地面画了半个圈 |
| 内心悲伤 | 双目泛红（眼白布满血丝），泪水顺着右颊缓缓滑落（经过颧骨时速度加快），双唇轻颤（下唇微微向内抿），一动不动地盯着手中已熄灭的烟头（烟灰已经很长但没掉落） |
| 强烈愤怒 | 面部咬肌紧绷（下颌角线条突出），胸口剧烈起伏（呼吸频率加快），猛地拍击桌面（手掌完全展开），水杯中水面泛起环形涟漪，双眼死死盯着对方（瞳孔收缩） |
| 天气炎热 | 蝉鸣声凄厉持续，衬衫背部被汗水浸透呈现深色汗渍并紧贴皮肤，手指不停拉扯领口（第二颗纽扣已解开），额前发丝被汗水黏在皮肤上 |
| 心动暧昧 | 递东西时指尖意外触碰，双方同时缩回手（0.3秒的停顿），一方低头整理不存在的褶皱，另一方假装看别处但耳朵微微泛红 |
| 等待焦虑 | 反复看表（第三次抬腕），烟抽到过滤嘴才发现，脚在地面不停轻点，听到脚步声立刻抬头又在看清来人后失望地转开视线 |
| 孤独失落 | 一个人坐在餐厅角落，面前的食物几乎没动，筷子整齐地搁在碗上，窗外人流快速走过（形成对比），端起茶杯发现茶已凉透 |

### 4.2 冗长风景与日常寒暄解构

- 将原著中大段空泛的自然景色描写，凝练为一到两个带有强情绪色彩的电影氛围描述动作。例如不要写"暴雨如注，天色昏暗，路上行人匆匆"，而写"△ 暴雨击打在铁皮屋顶上发出密集声响，路面积水反射着店铺招牌的红绿灯光，一双高跟鞋踩碎倒影"。
- 过滤废话和无效的社交礼仪性寒暄（"吃了吗""今天天气真好"之类），使每一句对白都直切主题，推动核心事件向前走。
- 绝不删减任何原著剧情节点，但可以利用行为举止（递烟的动作、倒酒的力度、视线的方向）强化人物态度，替代冗长的对话说明。

### 4.3 改编三原则

1. **摄像机原则**：写出来的每一个字都必须是镜头能拍到、麦克风能收到的。如果一个描述无法通过画面或声音呈现，就必须改写。
2. **剪辑师原则**：如果一个场景或一句台词删除后不影响观众理解剧情和人物关系，就删除它。保持极高的信息密度。
3. **原著作者原则**：剧情走向、人物关系、核心冲突、结局处理必须100%忠于原著。允许做的是"翻译"（文学语言→视听语言），不允许做的是"篡改"（加戏、改人设、改结局、加冲突）。
