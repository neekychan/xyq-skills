## Shot 设计规范

### Key Elements 设计

**角色（element character）：**
优先描述稳定的外貌特征（年龄感、肤色、发型、衣着质感），刻意避免"完美妆容"描述；允许不均匀肤色、自然状态。角色的情感特质写入描述（如"习惯用沉默替代表达"）。

**场景（element scene）：**
描述空间的"生活痕迹"——旧墙纸、摆放凌乱但有序的厨房、窗台上的盆栽。记录主要光源方向（如"左侧窗边自然光"）和时间段（如"黄昏五六点"）。

**重要物件：**
反复出现的符号性物件须单独注册为 key element，并描述其在不同情绪阶段的状态变化（如同一杯茶：冒热气 → 无热气 → 被收走）。

> 若用户已提供参考图像或影像素材，element 描述必须与参考内容保持一致，不得与之冲突。

### 每个 Shot 描述必须包含

1. **场景锚定：** 引用对应 element scene 的 ID，标注光线时段和主光源方向。
2. **人物状态与微小动作：** 描述人物正在做什么细微的事（微表情渐变、目光移开、手指轻微动作），禁止描述剧烈肢体动作或情绪爆发。
3. **运镜指令：** 从推荐运镜中选择一种，明确写出。
4. **情绪方向：** 这个镜头在情绪弧线中处于哪个阶段（铺垫/积累/高点/释放）。
5. **时长：** 标注推荐秒数（≥6 秒）。

## 运镜规范

**推荐运镜（必须从以下方式中选择）：**

| 运镜方式 | 情感类比 | 推荐时长 |
|---|---|---|
| 固定镜头（static camera） | 安静坐在对面，看着你但不说话 | 8—15 秒 |
| 极慢推进（very slow push-in） | 靠近一个正在想事情的人，不想打扰但想看清 | 10—15 秒 |
| 微弱手持（subtle handheld / breathing motion） | 用眼睛注视某人，呼吸带来的自然晃动 | 6—10 秒 |
| 缓慢横移（slow lateral tracking） | 在房间里走过，余光扫过桌面窗台 | 8—12 秒 |
| 固定特写（static close-up） | 盯着一个人的手或侧脸出神 | 6—10 秒 |

**禁止运镜：**
- 快速推拉（主体一致性崩溃）
- 甩镜/急摇（运动模糊失控，帧间连续性崩溃）
- 环绕运镜（多角度人物一致性无法保证）
- 无人机高空俯冲（与文艺片气质冲突）
- 单镜头内频繁切换景别（主体变形）

## 镜头节奏铁律

- 单镜头时长最短不低于 **6 秒**
- 叙事段落推荐 **3—4 个镜头**组成一个情绪单元，总时长 **30—50 秒**
- 镜头之间用 **1—2 秒黑场或空镜**过渡，禁止硬切
- 全片节奏遵循**呼吸结构**：吸气（情绪铺垫）→ 屏息（情绪高点）→ 呼气（情绪释放/空镜）

## 能力边界与替代方案

### 稳定场景（可直接生成）

- 人物情绪缓慢变化：微表情渐变、目光移开、呼吸节奏改变
- 静态/微动态人物状态：发呆、沉默、凝视、缓慢行走
- 环境与人物情绪共振：风吹头发、雨打玻璃、光线缓移过脸庞
- 物件特写的隐喻表达：冷掉的茶、未发出的消息
- 空间氛围呈现：空旷走廊、雨后街道、黄昏天台

### 危险场景（大概率崩溃，必须使用替代方案）

| 危险场景 | 崩溃表现 | 替代方案 |
|---|---|---|
| 剧烈情绪爆发（哭泣/大喊/摔东西） | 面部变形、表情跳帧 | 声画分离：画面给空镜/物件，情绪交给配乐承载 |
| 快速肢体运动（奔跑/打斗/冲撞） | 肢体畸变、运动模糊堆积 | 情绪前置（爆发前一秒）或情绪后置（爆发之后） |
| 多人激烈互动（对峙/争执） | 双人面部一致性丢失 | 转喻：用环境突变替代人物情绪 |
| 单镜头内复杂场景转换 | 连续性崩溃 | 拆分为独立镜头，用黑场/空镜连接 |

### 情绪爆发替代策略

当剧情必须呈现强烈情绪时，从以下策略中选择：

1. **声画分离：** 画面给环境/物件/空镜，情绪完全由配乐和音效承载
2. **情绪前置：** 生成"即将爆发前一秒"——眼眶湿润但未落泪、手指攥紧但未捶桌
3. **情绪后置：** 生成"爆发之后"——空了的椅子、摔碎的杯子、雨中无人的街道
4. **转喻：** 用环境突变替代人物情绪——突然熄灭的灯、被风吹落的纸、关上的门

## 视觉美学体系

### 色彩方向

- **饱和度：** 中低（保留色彩信息，但绝不鲜艳）
- **高光：** 柔和溢出，允许窗边光/逆光轻微过曝
- **阴影：** 有层次，暗部保留细节，不死黑
- **肤色：** 偏暖黄，真实不修饰，允许不均匀

**参考影像气质：**
- 是枝裕和的日光低对比柔和色调（《步履不停》）
- 王家卫的暖黄深绿情绪色块（《花样年华》）
- 李沧东的黄昏金色与暗部蓝灰（《燃烧》）
- 侯孝贤的胶片感自然偏暖（《最好的时光》）

### 推荐光源

- 窗边自然光（侧光为主，制造面部明暗分割）
- 黄昏/清晨方向光（低角度，长投影）
- 阴天散射光（均匀柔和，适合外景情绪段落）
- 室内实际光源（台灯、日光灯管、电视屏幕光）

**禁止光线：** 正面平光（消除情绪感）、彩色霓虹/人工强光（商业气质）、完全黑暗无光源。

## 慢镜头作为情绪放大器

- 不在动作场面使用慢镜头
- 在微小瞬间使用（回头、伸手、闭眼、雨滴落入水面）
- 慢镜头为原速的 2—3 倍，不过度降速（避免画面糊化）
