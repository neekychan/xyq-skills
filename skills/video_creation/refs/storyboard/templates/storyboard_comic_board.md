# 分镜图模板：漫画 / 分镜表型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以漫画格、条漫或手绘分镜表形式呈现的故事板，常用线稿、素描草图承载剧情结构。
- **典型场景**：漫画分镜设定、条漫大纲、影视项目导演分镜表、预演用草图故事板（previs）等。

## 2. 判定关键词
- 典型触发词：`漫画`、`条漫`、`手绘`、`线稿`、`分镜表`、`导演分镜表`、`storyboard`、`previs`。
- 当需求强调“先画草图/漫画格分镜”“不追求最终渲染质量”时，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：4–16 格，视故事复杂度而定。
- **结构骨架**：
  1. 开场建立（1–2 格）：交代主角、场景与起始状态。
  2. 冲突发展（若干格）：以动作与表情变化推进故事节奏。
  3. 高潮与转折（1–3 格）：事件爆发或情绪转折，构图更紧张。
  4. 收尾与余味（1–2 格）：给出结果或开放式悬念。
- **画面特征**：多为黑白线稿或低饱和色彩，重点在于构图与节奏，而非材质细节。

## 4. 生图 Prompt（PE）模板

```text
你是一名漫画分镜师，请基于下述故事信息生成一张 {宫格数} 格的漫画/分镜表型分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏条漫”或“16:9 横版导演分镜表”}。

【故事信息】
- 类型：{如“校园日常/都市奇幻/悬疑推理”}
- 主角与配角：{角色姓名+外观+性格}
- 故事梗概：{50–100 字概述起承转合}

【画面风格】
- 线稿风格：{如“黑白铅笔草稿/墨线漫画/灰度分层”}
- 色彩：{是否上色，如“单色线稿”或“有限色上色”}

【主体与背景】
- 主体：{主角姿态与表情的风格说明}
- 背景：{场景类型，如“教室 / 城市街道 / 室内房间”等，简化为轮廓即可}

【宫格与构图】
- 宫格布局：{如 2×2/3×3/4×4 或不规则布局}，编号 C1–C{N}。
- 每格需给出：画面中的主体位置（左/中/右、远景/中景/近景）、关键动作或表情。

【输出要求】
- 为 C1–C{N} 逐格写出分镜说明：景别 + 主体动作 + 背景简述。
- 说明中强调“线稿/漫画格”的简化程度，不需要复杂光影。

【画幅参数】
- 推荐 ratio={ratio 代码，2 表示 9:16 竖屏条漫，0 表示跟随参考图，3 表示 16:9 横版故事板}。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「剧情叙事类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 漫画格已有明确分镜编号与台词时，视频生成阶段尊重原信息，不重新解读故事。
