# 复古肌理迷幻插画风 · 风格滤镜技能

## 这个技能是什么

这是一个**画风锁定技能**。它的唯一职责，是保证在一次创作任务里，所有由 AI 生成的**图片素材**和**视频镜头**，都统一呈现「复古肌理迷幻插画风」这一种视觉质感——不跑偏、不掉色、不写实化、不被其它默认风格污染。

它通过一个固定不变的**风格锚定词（Style Anchor）**来实现这一点：无论生成什么画面，锚定词都原封不动地拼在每一条 prompt 的**最开头**，具体画面描述接在后面。

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 一、核心机制（最高优先级，必须严格执行）

### 1.1 固定风格锚定词

以下这段文字是本技能的**风格锚定词**，是一个整体，**禁止改写、删减、翻译、重排、意译或省略**：

```
复古肌理迷幻插画风格，高饱和霓虹撞色+亚克力质感笔触，复古胶片肌理，迷幻荧光配色，神秘主义叙事，日系旧动画海报感，80—90 年代旧印刷品、VHS/CRT 屏幕噪点、昭和少女漫画、迷幻宗教感、哥特童话和低保真数码失真，柔焦色散，描边错位
```

### 1.2 拼接规则（强制）

对于本次任务中**每一条**图片生成 prompt 和视频生成 prompt：

1. **锚定词永远放在 prompt 的最开始**，一字不差。
2. 锚定词之后，用中文逗号或句号自然衔接**具体画面描述**（场景、角色、动作、构图、镜头、光影等）。
3. **图片素材**和**视频镜头**采用同一套锚定词，保证素材与成片风格连续统一。
4. 锚定词不因分镜、场景、角色不同而改变——它是全片统一的「底色」。

**正确示例（图片）：**
```
复古肌理迷幻插画风格，高饱和霓虹撞色+亚克力质感笔触，复古胶片肌理，迷幻荧光配色，神秘主义叙事，日系旧动画海报感，80—90 年代旧印刷品、VHS/CRT 屏幕噪点、昭和少女漫画、迷幻宗教感、哥特童话和低保真数码失真，柔焦色散，描边错位。一位空灵少女仰望夜空，身后是巨大的荧光翅膀，深靛蓝背景，教堂塔楼剪影，星光点点，中轴海报式构图。
```

**正确示例（视频）：**
```
复古肌理迷幻插画风格，高饱和霓虹撞色+亚克力质感笔触，复古胶片肌理，迷幻荧光配色，神秘主义叙事，日系旧动画海报感，80—90 年代旧印刷品、VHS/CRT 屏幕噪点、昭和少女漫画、迷幻宗教感、哥特童话和低保真数码失真，柔焦色散，描边错位。镜头缓慢上摇，少女的黑色长发在紫光中轻轻飘动，荧光泪滴滑落，背景霓虹烟雾流动，画面带轻微 VHS 噪点抖动。
```

### 1.3 多风格 skill 搭配时的合并规则（强制）

当本技能与**其它同类画风/风格 skill**（例如另一个「国漫3D渲染风」「复古DV质感」等）**同时被调用**时：

1. **不是覆盖，而是合并**。把各风格 skill 的锚定词**按调用顺序拼接成一段更长的锚定词**，再整体放在每条 prompt 的最开头。
2. 合并时各锚定词之间用中文逗号连接，**每一段锚定词内部内容保持原样，不删改**。
3. 合并后的拼接规则不变：**合并锚定词 → 放最前 → 接具体画面描述**。
4. 若多个风格词存在语义冲突（如两种质感描述），**不做取舍删改**，全部保留，让模型综合呈现融合质感。

**合并示例：**
```
[本技能锚定词]，[另一风格 skill 的锚定词]。具体画面描述……
```

### 1.4 禁止内置风格锚定图干扰（强制，最高优先级之一）

部分 Agent 链路会针对某些风格**预置内置的「风格参考图 / 风格锚定图」**，这些参考图会污染本技能想要的画风。因此：

1. **一旦本技能被调用，必须绕过 / 关闭 / 忽略 Agent 任何内置的风格锚定图、默认风格参考图、预设风格 reference。**
2. 在调用图片/视频生成工具时，**不得附带任何系统预置的风格参考图**；风格只由本技能的**文字锚定词**决定。
3. 如果生成工具支持「参考图」参数，除非是**用户本人主动提供**的素材图，否则**一律不传入任何内置风格图**。
4. 若链路强制注入内置风格图无法关闭，需在 prompt 中显式声明：`忽略任何内置/默认风格参考，仅以本文字风格描述为准`，并把该声明紧跟在锚定词之后。

## 二、与非风格类 skill 冲突时的协作规则（强制）

当本技能与**非风格类 skill**（例如「营销短片」「短剧脚本」「分镜生成」「广告 KV」等叙事/流程类 skill）**同时被调用**时，遵循以下原则：

1. **职责分层，不互相覆盖**：非风格 skill 负责**内容与流程**（故事结构、分镜编排、脚本节奏、营销卖点、镜头调度等）；本技能负责**视觉画风的最终锁定**。
2. **本技能对「视觉呈现」有最终决定权**：无论其它 skill 生成了怎样的画面描述，只要进入**图片/视频 prompt** 环节，都必须由本技能在其**最前面强制拼接风格锚定词**，并执行 §1.4 的绕过内置风格图规则。
3. **不得因为加载了其它 skill 就跳过锚定词**：即使营销短片 skill 自带一套 prompt 模板，也要把本技能锚定词插入到它每条 prompt 的最开头。
4. **内容向本风格靠拢**：在写分镜、脚本、角色设定、场景描述时，主动参考本技能第三节的「风格知识库」，让故事基调、场景选择、角色气质本身就贴合复古迷幻插画的调性，而不只是靠后期滤镜。
5. **冲突裁决**：若非风格 skill 的指令与本技能的画风规则冲突（如要求「写实摄影感」），**画风以本技能为准**；内容流程以非风格 skill 为准。

## 三、风格知识库（供 Agent 写分镜/角色/脚本时参考）

> 用途：当 Agent 需要撰写场景分镜、角色设定、故事脚本、镜头描述时，从这里取词、取气质，让**内容本身**就贴合风格，而非只靠锚定词兜底。

### 3.1 整体风格气质

一句话概括：**旧动画海报审美为骨架，胶片颗粒与扫描噪点为皮肤，荧光酸性色彩与 CRT 错位边缘为标识，神秘少女/黑猫/翅膀/教堂/泪滴等象征母题为叙事核心。**

核心情绪关键词（冷处理的强情绪，安静但浓烈）：

- 空灵 + 压抑
- 纯真 + 怪诞
- 神圣 + 邪异
- 甜美 + 冷酷
- 梦幻 + 不祥

画面不追求清晰叙事事件，而是制造**「被异象照亮的瞬间」**：人物常仰视、失神、沉默、凝望远方，像处在超现实启示、预言、幻觉或情绪高潮中。属于**氛围叙事**，非动作情节驱动。

### 3.2 色彩系统（最强识别点）

- **荧光撞色组合**：蓝紫+荧光绿 / 橘黄+靛蓝 / 酸性黄绿+深紫 / 粉紫+电蓝 / 高饱和橘红（嘴唇·高光）+冷色背景。
- **冷暖反常**：肤色偏黄绿，阴影用纯蓝紫而非灰黑，高光带荧光边缘，黑色里混蓝绿紫偏移。
- **大面积纯色压场**：深靛蓝 / 黑紫 / 高浓度蓝色块 / 紫光渐变背景，突出主体，强化平面海报感。
- 目标不是真实，而是**化学发光 / 夜视仪 / 显像管偏色 / 褪色海报重新显影**的幻觉感。

### 3.3 肌理与质感（「复古」的关键）

- **颗粒噪点**：胶片颗粒、扫描噪点、纸张纤维、粉质/砂质雾化颗粒——刻意保留的低保真美学。
- **柔焦糊化**：边缘发虚、晕边、轻微色散、柔雾、光晕扩散，营造梦核 / 旧屏幕回放 / 记忆滤镜观感。
- **色偏与套印错位**：绿色描边、红蓝偏移、轮廓套印不准、局部霓虹外发光——像老印刷错位 / CRT 的 RGB 偏移 / 低清截图溢色。
- 质感落点参照：老海报扫描件、VHS 截图、旧动画设定集翻拍、褪色印刷品。

### 3.4 角色造型语言

- **气质**：脆弱、冷静、空灵，带一点病娇 / 神谕感；表情不夸张、不大笑，眼神飘忽、空洞、上视、麻木沉静，像「情绪容器」。
- **五官**：大眼但不一定极圆，睫毛夸张纤长，嘴唇高饱和玻璃感，鼻子简化，面部偏平面——旧少女漫画 + 美妆广告插画 + 旧动画特写帧的融合味。
- **身形**：细长、单薄、纸片人般轻盈，肢体安静、仪式化，弱动态反而增强神秘感。
- **线条**：不追学院派体积与复杂透视，重轮廓优雅与图形概括，局部可简化甚至消失，强平面装饰性。

### 3.5 场景 / 光影 / 象征母题

- **象征物（心理具象化，非写实生物）**：翅膀、黑猫、怪异剪影、烟雾状灵体、星光、荧光泪滴、荧光眼睛、教堂、塔楼、夜空。
- **典型场景**：月夜、教堂前、星空下、荧光烟雾中、紫光房间、超现实旷野。
- **光影**：低照度夜色为主，主体靠荧光高亮/边缘光提亮；光源逻辑可反自然；高光集中在眼睛、嘴唇、泪滴、翅膀边缘作为「情绪钉子」。
- **氛围词**：灵异梦境、末世童话、神启时刻、月夜仪式、孤独神秘、少女忧郁、非现实宗教感。

### 3.6 构图特点

- **海报式中心构图**：主体突出，背景服务情绪，大面积留空；适合专辑封面、海报、书封、KV。
- **超现实比例**：如巨大黑猫 vs 微小少女的「象征比例」，强化压迫感 / 神谕感 / 守护与威胁并存。
- **视线引导**：人物脸 → 眼睛/嘴唇/泪滴 → 荧光高亮区 → 神秘象征物；依赖局部高亮作情绪锚点。
- **仰望式构图**：人物朝上看或重心上延，制造对未知的凝望与悬浮超现实感。

### 3.7 可直接取用的标签词库

- **画风**：复古迷幻插画、昭和/旧日系动画海报感、哥特童话、少女神秘主义、荧光夜色、低保真印刷感、梦核、暗黑浪漫。
- **质感**：粗颗粒、纸张纹理、老胶片噪点、扫描件质感、柔焦发雾、轻微失焦、套印错位、霓虹描边、厚重纯色背景、粉蜡笔/喷枪混合触感。
- **角色**：冷感少女、空洞凝视、上仰视线、细长肢体、苍白皮肤、高饱和嘴唇、夸张睫毛、轻病态美感。
- **氛围**：灵异梦境、末世童话、神启时刻、月夜仪式、孤独神秘、少女忧郁、非现实宗教感。

## 四、执行清单（Agent 每次生成前自检）

生成任何图片素材或视频镜头前，逐条确认：

- [ ] 是否把**固定风格锚定词**原封不动放在了 prompt 的**最开头**？
- [ ] 具体画面描述是否接在锚定词**之后**？
- [ ] 图片素材与视频镜头是否使用了**同一套**锚定词？
- [ ] 若有其它风格 skill 同时生效，是否已把锚定词**按顺序合并**、内容不删改？
- [ ] 是否已**绕过/忽略** Agent 任何内置风格锚定图 / 默认风格参考图？
- [ ] 是否**未传入**任何非用户主动提供的风格参考图？
- [ ] 若与非风格 skill（营销短片等）搭配，是否仍**强制拼接锚定词**并让内容向本风格靠拢？
- [ ] 分镜/角色/脚本描述是否参考了第三节风格知识库，使内容本身贴合调性？

全部满足后，方可提交生成。
