# 用户分镜图 → 视频还原规则

本文件仅适用于**用户上传的分镜图**。多段流程由分镜规划工具按创意脚本中的分镜图素材绑定加载；单段流程（总时长 ≤L）由主 Agent 与 `storyboard/prompt-craft.md` 一同加载，此时第二节仅「装箱/切点/总览表」机制不适用（无需拆段），**时长权重分配与旁白→格映射照用**，其余各节照用。本流程内自产的分镜宫格图不适用本文件——其宫格↔shot 对应、无字视频参考版、单格首帧规则见 `storyboard/storyboard-sheet-prompt.md`。

用户上传分镜图 = 分镜层已由用户填满。分镜图具有双重身份：**内容脚本**（格序即叙事顺序）+ **视觉参考**（构图/角色/场景/色调的最高优先级锚点）。视频生成模型支持直接以分镜图为参考生成视频，禁止只提取图中文字信息而丢弃图像本身。

**保真与发挥的边界**：分镜图锁定的只有三样——**格的画面内容、出场顺序、角色与场景外观**（跳格、乱序、擅改画面 = 违背用户）。除此之外都是你的导演创作空间且**必须主动设计**：

- **转场**：硬切/连续运镜串联/光影过渡；相邻格空间相关时（如中圈俯视→全场俯瞰）优先用一个连续运镜串联，不要逐格硬切
- **格内动态**：每格是**关键帧不是定格照片**——必须把格内画面展开为动作过程（人物走动、对视、转身，环境中旗帜挥舞、灯光流动、人浪起伏），禁止静态画面加平移缩放了事
- **补充镜头**：允许在格间插入分镜图之外的短镜头，强化情绪和节奏；前提是与格内容同世界观、不打乱格顺序、不挤占关键格的还原时长
- **节奏与氛围**：每格停留时长按叙事权重分配（非均分）、情绪铺陈、氛围音设计

把分镜图当幻灯片逐格等长放映 = 放弃导演职责。

**看图前置（铁律）**：执行本文件任何规则前，必须先用 `sandbox_read` 打开分镜图**逐格查看画面内容**——路径字符串不是图。分段、写 Prompt、轻 Prompt 自检全部以实际看到的逐格画面为依据，禁止凭文件名或他人转述的格描述推断。

## 一、分镜图直传（铁律）

- **每段 `sandbox_generate_video` 的 ImageList 必须包含分镜图**，且 Prompt 第一句声明还原范围：`@图片N 为分镜图，本段按其第 X–Y 格的画面内容与出场顺序展开`——还原对象是**内容与顺序**，转场、运镜、节奏由 Prompt 的画面阶段自行设计
- 分镜图在参考图优先级中与"用户上传参考图"同级——高于一切 AI 生成参考资产
- **风格隔离（分镜图完成度低于目标成片时必写）**：分镜图为线稿/草图/黑白/低保真，而目标成片是彩色/写实/3D/动画正片时，Prompt 必须①正向声明成片风格（写实实拍/3D 动画等），②追加排除句：`严格排除：黑白、单色、线稿、素描、草图、分镜稿/故事板质感`——否则线稿质感会渗入成片。分镜图本身即目标风格（如成品级插画分镜）时不写排除句
- 格数多于 `prompt-craft.md` 画面阶段密度建议时，**格保真优先**——用连续运镜串联相邻格降低阶段数，禁止跳格削足适履
- `⇐` 衔接段的 ImageList 第一张仍为尾帧（`@图片1 作为该次视频前的画面状态`），分镜图顺延为第二张，格区间声明相应改用 `@图片2`

## 二、格→段装箱（分段规则）

分段以**格**为最小单位，替代按场次自然断点拆分：

1. **旁白/台词→格映射先行**：creative_design.md 未显式标注句→格对应时，先按语义建立「逐句→格」映射表（写奖杯的句子配奖杯格），再进入预算计算；禁止先装箱后随意分配台词
2. **格时长预算**：`总时长 ÷ 格数` 只是基准值，**必须按叙事权重再分配**——高潮/收束格放大至基准 1.5~2 倍，铺垫/过渡格压缩至一半，被连续运镜串联的相邻格合并计算；全部格等长 = 未做权重分配，重排。含台词/旁白的格以 count_chars 耗时下限为该格预算下限。用户未指定时长 → 按格内内容量估算（纯画面格 2~4s）
3. **装箱**：按格顺序累计预算，累计 ≤L（单镜头时长上限）装入同一段；**切点必须落在格边界**，禁止一格跨两段。装箱以格预算累计判断，格预算本身已含动作/运镜时间——预算按台词耗时下限计算的段，需确认段尾留有 0.5~1s 无台词收尾空间，不足则前移切点一格
4. **单格超载**（一格台词/动作预算 >L）：该格独立成段，段内用画面阶段展开
5. **总览表增加「覆盖格区间」列**（如 `格1–3`）。全片验算增加一项：所有格被覆盖、无跳格、无重复、顺序与图一致
6. 调用次数最少化、段间 `⇐` 衔接等通用分段规则照常适用

## 三、Prompt 骨架与轻 Prompt

**骨架（每段 Prompt 按此顺序组织，时序串联而非自由段落）**：

1. **基调句**：一句情绪与节奏基调——只写图上看不见的抽象基调（情绪走向、节奏快慢），色调/画风图上可见则不写
2. **分镜图声明**：第一节第一条的还原范围声明
3. **逐格时序链**：用「开场是…→接着…→最后收在…」的先后连接词逐格推进；每个格槽位只写该格的**动作展开 + 运镜 + 到下一格的转场方式**——转场按格间关系逐处选定（硬切/连续运镜/光影过渡，判据见文首），禁止全程套用同一种；格间补充镜头插在对应位置
4. **收尾要素**：台词与口型、氛围音、段间衔接

**轻 Prompt 判据**：对图像的理解是有损的——按常规规范写满视觉细节，写入的是推测内容，会与分镜图真实画面冲突，模型两头听从导致还原度下降。因此：

- **分镜图上看得见的静态视觉信息（角色外观/服装/场景陈设/构图/色调），一律不写进 Prompt**，交由格区间声明 + 分镜图承载
- Prompt 只写分镜图无法表达的信息：**时序先后、运镜与切镜节奏、格内动作展开、补充镜头、台词口型、段间衔接、氛围音**
- 自检：Prompt 中任一句视觉描写，若其内容在分镜图上看得见 → 删。**本节禁的是复写图上已有的静态信息，不禁新增**——格内动态展开和格间补充镜头是图上没有的内容，必须写足
- **两类例外禁止误删**：①用户文字覆盖——用户文字需求与图面内容冲突时（如"球衣换成红色"），差异点必须写进 Prompt 并声明"此处不按分镜图"；②第一节的风格隔离句——成片风格声明与排除句描述的是目标成片而非分镜图，不属于复写图面信息

## 四、参考图裁剪

- 分镜图本身即角色/场景一致性锚点：**图中已出现的角色/场景/道具，不再生成四视图/场景图等参考资产**——基于图像推测生成的参考图与分镜图真实画面冲突，是负资产
- 仅为分镜图上**未出现**但剧情需要的新增主体生成参考图
- 用户另行上传的角色/产品图照常使用，与分镜图并列传入
