# 刊墨糙描风格

一套可复用的动画风格化技能。核心是一段**固定不变的风格锚定词**，它被完整、原样地复用进本技能处理的**每一条图片编辑提示词**和**每一条视频生成提示词**的**最开头**，从而保证所有图片素材与最终视频产物画风高度统一。

## 风格锚定词（固定不变，最高优先级）

> **刊墨糙描风格，粗黑线/强轮廓，干裂刊墨硬线，轻微肌理，旧刊纸张印刷晕，写实/自然形态，怪比例市井，低饱和/莫兰迪，低饱和旧印调**

这段词是本技能的脊柱。所有需要生成/编辑的图片 prompt 与所有视频 prompt，**都必须以这段词作为开头**，再接后续内容。锚定词内容不得删改、精简、翻译或重排。完整的复用规则、与其他风格技能的合并规则、与非风格技能的结合规则，读取本技能下的 `references/style-anchor.md`。

## 1. 核心原则 + 持久引擎

**风格一致性优先于一切表达自由。** 只要产物涉及可被风格化的画面（角色、场景），锚定词就必须原样前置——这是本技能存在的唯一理由。

持久引擎(因果链):
**用户上传的确定素材 → 用锚定词把素材逐张风格化转绘 → 得到统一画风的角色/场景资产 → 用锚定词前置的视频 prompt 把这些资产送入视频生成 → 画风统一的动画成片**

## 2. 质量测试（可证伪）

把成品的任意一张风格化图片或任意一帧视频单独抽出来看：**如果去掉锚定词描述的那套视觉特征（刊墨糙描、粗黑线强轮廓、干裂刊墨硬线、旧刊纸张印刷晕、怪比例市井、低饱和旧印调），画面就不再成立、不再能被认出是「刊墨糙描风格」**——则风格化成立。若某张图/某帧看起来像普通写实或其他画风，说明锚定词没被正确前置或被稀释，必须重做。

## 3. 输入诊断（开工前必须想清楚的维度）

把用户输入解析为结构化参数：
- **图片素材是否已上传**：本技能的前置硬条件是用户先上传一批已确定的图片素材。**没有上传素材不能进入风格化与视频生成**——只追问缺失的素材，不臆造。
- **素材类型判定**：逐张判断是「有明确角色主体（人物、宠物、拟人角色等）」还是「单独物品图 / 空镜场景图 / 无明确主体的风景图」。前者需转绘，后者不转绘（见 `references/image-restyle.md`）。
- **产物类型**：用户要的是风格化图片，还是最终动画视频？若要视频，图片风格化是必经中间步骤。
- **是否叠加了其他风格技能**：若同时触发了另一个风格类技能，按合并规则处理锚定词（见 `references/style-anchor.md`）。
- **是否叠加了非风格技能**：若同时触发了营销短片、剧情短片等非风格技能，本技能的风格锚定规则不被覆盖（见 `references/style-anchor.md`）。
- **创作意图**：用户对最终动画的题材、情节、情绪的描述，用于驱动分镜脚本。

## 4. 路由表（按输入选路线）

| 输入特征 | 选用路线 | 必读 reference |
|---|---|---|
| 需要理解/合并/结合锚定词规则 | 应用风格锚定词，处理与其他技能的组合 | `references/style-anchor.md` |
| 用户上传了图片素材，要风格化 | 逐张判定是否转绘，用锚定词做编辑提示词 | `references/image-restyle.md` |
| 要把风格化资产做成动画视频 | 用故事编写系统提示词生成分镜脚本 | `references/storyboard-system-prompt.md` |

## 5. 强制加载 reference（硬规则）

开工前，**必须**按路由结果加载对应 references，把规则与句式落进实际产出，不得跳过、不得凭记忆糊：
- 风格锚定词的复用/合并/结合规则：`references/style-anchor.md`
- 图片素材风格化转绘规则：`references/image-restyle.md`
- 动画故事编写系统提示词（视频生成必读）：`references/storyboard-system-prompt.md`

## 6. 工作流（分步 SOP）

**Phase 0 — 前置检查（硬门槛）**
- 确认用户已上传图片素材。若未上传，停下并只追问缺失的素材，不进入后续步骤。
- 读取 `references/style-anchor.md`，确定本轮锚定词（若叠加了其他风格技能，先按合并规则合成锚定词）。

**Phase 1 — 图片素材风格化转绘**
- 读取 `references/image-restyle.md`。
- 逐张判定素材：有明确角色主体的图片才转绘；单独物品图、空镜场景图、无明确主体的风景图不转绘，原样保留进入下一阶段。
- 对每一张需转绘的图片，生成一张风格化图片：**编辑提示词直接、完整地使用锚定词，不额外添加任何其他内容**，完全基于用户原图转绘。
- 得到一套统一画风的角色/场景资产。

**Phase 2 — 若用户只要图片：交付**
- 把风格化后的图片资产展示给用户，流程结束。

**Phase 3 — 若用户要动画视频：编写分镜脚本**
- 读取 `references/storyboard-system-prompt.md`（动画故事编写系统提示词）。
- 以「Phase 1 得到的风格化图像资产 + 用户的创作意图描述」为输入，按该系统提示词产出详细的高密度动画脚本与分镜，作为视频生成的参考。

**Phase 4 — 视频生成**
- 每一条视频生成 prompt 都**以锚定词开头**，再接分镜脚本内容。
- **成片 ≤15s 时用一次视频生成即可拿到完整片段**；分镜里的时间码 beat（0-2s/2-5s/5-9s/9-12s/12-15s）是同一条 prompt 内部的时间轴，不是要分多次生成。只有成片 >15s 时，才拆成若干 ≤15s 片段分别生成，再做后处理拼接。
- 把成片展示给用户。

## 7. 输出契约

**图片风格化产物**：每张对应一张用户原图，编辑提示词 = 锚定词（不含其他内容）。

**视频分镜脚本**：严格按 `references/storyboard-system-prompt.md` 第九节的输出模板产出（风格题材 / 一句话剧情与角色关系 / 角色锁定 / 画面提示词含时间码分镜 + BGM + 环境音 + 台词 + 画面质感要求 / 默认约束）。所有视频 prompt 以锚定词开头。

**视频成片**：≤15s 一次生成完整片段；>15s 才分段生成再拼接。默认无字幕、不生成任何文字、不生成 logo 与水印。

## 8. 静默自检（出稿前，不外显）

- [ ] 用户是否已上传图片素材？未上传则不应进入风格化/视频阶段。
- [ ] 每一张需转绘的图片，编辑提示词是否就是锚定词本身、没有夹带其他内容？
- [ ] 单独物品图 / 空镜 / 无主体风景图是否被正确跳过、未转绘？
- [ ] 每一条视频 prompt 是否都以锚定词开头？
- [ ] 若叠加了其他风格技能，锚定词是否按合并规则正确合成、规则未变？
- [ ] 若叠加了非风格技能，本技能的锚定规则是否仍被完整遵循、未被覆盖？
- [ ] 分镜脚本是否覆盖高密度节奏、多景别、运镜、BGM 卡点、声音分层、角色锁定、防同脸声明？
- [ ] 成片是否 ≤15s（是则一次生成完整片段）；>15s 是否已切成 ≤15s 片段？
- [ ] 末尾是否挂载默认负向约束（无字幕、无文字、无 logo、无水印）？
