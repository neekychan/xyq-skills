# 分镜图模板：动作分解 · 打斗/竞技分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：围绕武打、格斗、体育竞技等对抗场面，将每一次攻防交换拆成可视化的分镜单元，突出招式连贯性、力量对抗和战斗节奏的**打斗/竞技分镜图**。
- **典型场景**：
  - 武侠/奇幻对打、刀剑格斗、魔法对决的动作设计与教学。
  - 拳击、综合格斗（MMA）、跆拳道等搏击运动的攻防回合拆解。
  - 篮球突破对抗、足球攻防、电子竞技技能对拼等竞技场景的攻防节奏规划。

## 2. 判定关键词与适用边界
- 典型触发词：`打斗分镜`、`战斗动作拆解`、`拳击攻防`、`竞技对抗`、`搏击教学`、`攻防回合`、`比赛回合分解`。
- 适用判定：
  - 用户希望看到“每个攻防回合怎么打”“招式和攻防节奏是否合理”，关注攻防过程而非单个定格姿势；
  - 场景以对抗/比赛为主，存在明显双方或多方的攻防关系。
- 不适用场景：
  - 仅关注身体姿态是否标准的健身/瑜伽教学 → 更适合“姿态连续分镜”；
  - 只是想看整体战斗氛围或故事推进，不要求逐招拆解 → 可用“剧情分镜表”“影视导演镜头表”等模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–16 格，以一个完整的战斗或比赛片段为单位，覆盖从开场试探到结果判定的攻防弧线。
- 规划方式：
  - 先按战斗/比赛节奏划分四段：开场试探 → 贴身缠斗/中段交锋 → 升级/高强度爆发 → 收势/判定结果；
  - 每段分配 2–4 格，每格对应一组清晰的“攻防交换”（谁攻、谁防、产生了什么结果）；
  - 在每格中标注双方站位（画面左/右/前/后）、攻击方向和防御方式，必要时附加特效与环境破坏提示。
- **画面特征**：更多使用全身/中全身景别，背景简化但保持空间方向；打斗类格子要能看清武器/拳脚轨迹和身体重心变化。

## 4. 生图 Prompt（PE）模板

```text
你是一名动作导演兼武术指导，请为 {战斗类型，如“武侠双人对打/拳击比赛一回合/奇幻魔法对决”等} 设计一张 {宫格数} 宫格的打斗/竞技分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏动作短片”或“16:9 横版电影感打戏”}。

【对决与场景信息】
- 对决双方与阵营：{如“白衣剑客 vs 黑甲刺客”或“红方拳手 vs 蓝方拳手”等}
- 比赛/战斗目标：{如“决出胜负/守护某物/通过试炼”等}
- 场景与环境：{擂台/山崖/城市街道/球场等，说明地面材质与空间结构}
- 战斗段时长：{本段大致时长秒数，如 10–20 秒}

【节奏与结构规划】
- 战斗/比赛节奏划分：{如“开场试探 → 中段贴身缠斗 → 高潮爆发 → 收势判定”}
- 每段分配格子数量：{如“试探 2 格，缠斗 4 格，爆发 4 格，收势 2 格”等}
- 整体战斗强度弧线：{参考“碰撞→缠斗→升级→爆发”的递进描述}

【分镜与编号】
- 宫格数：{宫格数，如 12 格}，按时间顺序编号 C1–C{N}；
- 每格需绑定到明确的战斗阶段与攻防事件，避免出现“空镜无动作”的格子。

【分镜输出格式】
请依次为 C1–C{N} 输出以下信息（按时间顺序）：
- 所属阶段：{如“开场试探/贴身缠斗/升级段/终局一击”等}
- 空间定位：{谁在画面左/右/前/后，面朝方向，景别，如“中景过肩视角，镜头在 A 身后，B 面朝镜头”}
- 攻方动作链：{连续 2–4 拍的动作意图与招式，如“连续三拳逼退对手”“连续三刀压制对方防守”等}
- 守方应对链：{对应的格挡/闪避/反击方式，强调防御对等，避免空手接白刃}
- 碰撞反馈与环境反应：{武器/拳脚碰撞产生的冲击波、镜头震动、地面碎裂等}
- 情绪与节奏：{此格战斗节奏是加速/减速/蓄力，角色情绪如冷静/愤怒/压制感}

【画幅与风格】
- 画面比例：{9:16 / 16:9 等，默认 16:9 横版用于电影级打斗，9:16 用于竖屏短视频}
- 画风：{仿真人写实 / 3D 动画 / 2D 漫画 等}
- 特效风格：{如“蓝色冰霜剑气 vs 红色火焰匕首”等，确保双方特效颜色和形态具象且对比明显}
- 要求整套分镜中角色外观、武器与场景风格高度一致，战斗强度随时间递进。
```

## 5. 一致性与避坑
- 保证每一格都有明确的攻防事件与动作链，而不是静态对峙或站桩互殴；开场第一格就进入实质交锋。
- 对立双方的朝向与站位在整套分镜中保持连续，遵守“对立双方朝向必须相对”的规则，避免上一格面对面、下一格两人同时面朝镜头。
- 特效必须附着在角色动作上（武器/拳脚/身形残影），禁止“大招特效在空中互撞、角色站着不动”的写法。
- 战斗强度与密度要有递进，不要每格密度完全一样导致视觉疲劳；同时避免在单格中堆过多动作，牺牲可读性。
- 有武器对撞时写明交叉角度与碰撞反馈，避免两把武器平行贴合没有冲击感。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“动作分解表”相关执行模板：
  - 分镜阶段用本模板清晰拆分战斗/竞技的攻防回合，将 C1–C{N} 作为动作关键帧与战斗结构蓝本；
  - 视频阶段以分镜图中 3–5 个关键格作为参考帧，锁定角色造型、站位和战斗强度的递进，在调用 `sandbox_generate_video` 时按“动作分解表”链路传参。
- 对于包含武打、魔法对决或高运动量追逐的片段，视频 Prompt 编写必须遵守 `storyboard/vfx-action-prompt.md` 的强制规则：
  - 为每个 3–5 秒时间段构造“动量锚点运镜指令块 + 空间定位 + 战斗氛围定调 + 攻守双方动作链 + 碰撞反馈与环境碎裂”的完整骨架；
  - 明确选择主角动量跟随 / 受力反馈跟随 / 一镜到底等运镜模式，整段战斗内保持锚点一致；
  - 在 Prompt 中逐字复用角色特效描述与空间定位句式，避免跨段换词或位置跳变导致模型翻车。
- 适合与“影视导演镜头表”“动作脚本表格”等模板组合使用：本模板负责战斗结构与攻防节奏，其他模板分别承载镜头语言与执行脚本信息，共同为高质量打斗视频提供蓝本。
