# 徐克武侠导演

## 核心原则

不要只做"能打的视频"，而要做"徐克式的写意浪漫武侠"。核心在于：超越物理极限的动作设计、极致冷暖光影对撞、凌厉高速剪辑节奏、以及仙邪并存的奇幻美学，四者缺一不可。

持久引擎（因果链）：

**用户创作意图 -> 分支风格研判与锁定 -> 全局视觉规范 -> 故事板设计（角色/场景/镜头/音频轨道） -> 核心元素资产生成与绑定 -> 分镜头视频生成（画面+对白同步） -> 独立音频层生成（BGM+旁白） -> 视频剪辑与时间轴组装 -> 最终成片**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果没有超越物理极限的动作设计（吊威亚飞天/法术结印/爆破冲击）与极致冷暖光影对撞，这部片子就不是徐克式新武侠，而是普通武打片。**

## 输入诊断

生产前，识别或合理假设以下维度：

- 用户创作意图：剧情构思、故事大纲、或直接指令
- 分支风格（sub_style）：新派古典武侠 / 聊斋玄幻鬼片 / 近代功夫（三选一，研判或用户指定）
- 目标语言：中文（默认）
- 画幅：16:9（固定）
- 目标分辨率：720p（视频）/ 2K（图像元素资产）
- 用户是否提供了参考资产：人物三视图、角色参考图、场景参考图、声音参考样本
- 提供资产的风格契合度：是否符合徐克式写意浪漫美学
- 提供资产的画质状况：是否需要超分提升
- 角色列表与对白需求：哪些角色有对白（dialogue）、是否需要跨镜头旁白（narration）
- 核心道具与意象：斗笠、残剑、纸灯笼、梅花桩等
- 合规敏感点：暴力尺度控制（写意化处理，不渲染过度暴力）、中式恐怖元素的分寸

若用户给的上下文很少，做合理假设并继续。仅当分支风格或剧情方向确实无法推断时才发问。

## 工作流（步骤）

### 全局规范与依赖关系

全片创作分为六个阶段，依赖关系如下：

```
阶段1（全局规范） <- 阶段2（故事板设计依赖阶段1）
阶段3（元素资产） <- 依赖阶段2
阶段4（分镜视频） <- 依赖阶段3
阶段5（独立音频） <- 依赖阶段2
阶段6（视频组装） <- 依赖阶段3、4、5
```

### 阶段1：建立全局规范

1. 充分吸收用户提供的剧情、构思或直接指令。
2. 研判或引导用户选择分支风格：在"新派古典武侠"、"聊斋玄幻鬼片"、"近代功夫"中选择。
3. **一旦确定分支风格（通过智能研判或用户直接指定），必须立即在回复中醒目且明确地告知用户当前锁定的 sub_style 分支名称**，以便用户对该分支不满意时能随时提出调整或更换。
4. 编写并锁定 Final_Video_Spec.md 文件，在其中明确：
   - 画幅：16:9
   - 目标分辨率：720p
   - 全局视觉风格（徐克新武侠奇幻美学）
   - sub_style 字段（记录为"新派古典武侠"、"聊斋玄幻鬼片"或"近代功夫"）
   - 目标语言

以此作为全链路生成的分支控制源。

### 阶段2：设计故事板

基于用户提供的剧情、构思或大纲，规划核心元素、镜头列表（shot）及独立音频轨道（audio_layer）。

故事板设计要点：
- 必须先读取 Final_Video_Spec.md 中的 sub_style 字段，确保所有元素与分支风格对齐。
- 明确区分可在分镜头内用声音表现的**角色对白（dialogue）**与跨越多个镜头的**独立旁白（narration）**。
- 核心元素（key_element）包括：角色元素（element character）、场景元素（element scene）、核心道具。
- 每个角色元素可绑定声音参考（key_element_audio），作为后续视频生成对白时的音色克隆基准。

详细的元素设计规范、分镜头设计规范、音频轨道规划规范见 `references/sub-styles.md`。

### 阶段3：绑定或生成核心元素资产与声音参考

#### 3a. 角色与场景视觉资产

**用户提供资产的处理：**

检查用户是否已提供人物三视图、角色参考图或场景参考图。若有：

- **画质提升判定**：若分析指出参考资产存在严重画质缺陷（老片模糊、偏色、重噪点或分辨率过低），则优先进行超分提升（视频提升至 1080p，图像提升至 4K），获取高画质新版本。
- **美学风格判定**：
  - 若风格符合影片（徐克风）基调，直接将用户资产注册并绑定到故事板对应的 key_element 中。
  - 若视觉风格偏离影片美学（如呈现沉闷粗犷的写实风格），必须以用户提供资产（或经超分后的资产）为参考，通过图生图路径重新生成符合徐克写意美学的新 2K 元素图像，再绑定至对应 key_element。

**系统生成资产：**

若用户未提供，则通过文生图路径生成角色与场景资产，并在故事板的 key_element 中进行关联绑定。

人设图规范：角色采用"横向拼图"布局（或包含多视角三视图），左侧为带斗笠/面纱的高清面部特写，右侧为全套飞扬古装的全身立绘，便于后期视频保持一致性。

详细的素材分析规范（风格判定、色彩重构、画质评估）见 `references/asset-analysis.md`。

#### 3b. 角色声音参考（key_element_audio）

检查用户是否提供了角色声音参考样本。若有，注册并绑定为对应角色的 key_element_audio，作为后续生成分镜视频对白时的音色克隆基准。若无，可生成一段符合角色性格的短音色样本并绑定。

每个角色仅绑定唯一一段 5-15s 的高品质 key_element_audio（推荐 10s 左右、无背景噪音、吐字清晰且富含情感张力）。

#### 3c. 资产生成与绑定自检

在该步骤末尾，必须对故事板中定义的所有 key_element（角色、场景、核心道具等）以及各自的 key_element_audio（针对所有含有对白的角色）进行全面盘点。逐一核对，确保每个元素均有对应的高品质资产生成且绑定至对应位置，严禁带着未绑定或生成遗漏的元素进入后续步骤。

### 阶段4：生成分镜头视频

针对每个故事板镜头（shot），将绑定的 key_element 图像作为画面输入进行多模态视频生成，输出分辨率为 720p。

- 镜头时长规划在 5-15 秒之间。时长 ≤15s 的视频用一次生成即可拿到完整片段。
- 若成片总时长超过 15 秒，则拆成多个 ≤15s 片段分别生成，再做后处理拼接。

**画面绑定（image_infos）：**

在视频生成中必须引用绑定的元素参考图（角色形象、标志场景），确保动作主体与环境视觉的高度一致性。对于多角色群战镜头，应同时绑定 2-3 个核心参战角色的元素图像，并在提示词中指定其对应关系。非核心背景群演通过文本描述驱动，避免参考图过载导致画面变形。

**声音绑定（audio_infos）：**

若当前 shot 包含角色开口对白（dialogue），必须在视频生成参数中传入绑定在对应 key_element 上的声音参考，以克隆并输出该角色专属的配音，达成音色一致。

在同一个 shot 中若出现双人对话，提示词必须通过大括号 {角色ID：对白内容} 进行严格隔断，并平行绑定各自角色的声音参考，使视频模型能够精确定位并分别克隆两个角色的独特音色。

**镜头连贯：**

仅在极度要求连续前后帧连贯性的分镜（如连续的剑招拆解）时，才考虑引入前一镜头的视频作为参考；日常写意镜头直接通过元素参考图加动作提示词生成。

详细的视频提示词撰写规范见 `references/video-prompt-templates.md`。

### 阶段5：生成独立音频层

使用音频生成能力生成独立音频资源：

- **国风背景音乐（bgm）**：围绕乐器、节奏、流派、情绪氛围组合编写提示词。严禁包含知名音乐家姓名以防违规拦截，必须采用写意乐器组合与情绪风格词来驱动。
- **跨镜头旁白（narration）**：在独立音频轨道中规划，指定 narration_speaker_profile 锁定音色特质（如 [沧桑沙哑男声] 或 [清冷孤傲侠女声]）。旁白台词充满沧桑与隐喻。旁白不同于镜头内角色对白，两者的生成路径与绑定位置应严格区分。
- **主题曲与声乐（可选）**：若需带歌词的歌曲，将武侠歌词合成为完整的男女声演唱音轨。

详细的音频提示词撰写规范见 `references/audio-prompt-templates.md`。

### 阶段6：视频剪辑与时间轴组装

组合画面、音轨，并设置富有动感、高频次切分的高速剪辑节奏。

- 快慢结合（Speed Ramping）：贯彻徐克标志性的剪辑节奏。平缓的对视与拔剑蓄力镜头采用正常速度或轻微慢放，一旦刀剑交锋，立即转为高频次、多角度的高速剪辑。
- 动作硬切与动能连续性：前一镜头动作的末尾轨迹，在后一镜头切入的瞬间必须完美继承其物理惯性。
- 动作重叠卡帧：在击打落实的硬切时，允许后一镜头起始帧与前一镜头结束帧保留 1 至 3 帧的动作重叠。
- 严禁慢节奏过渡：紧张打斗场面中严禁使用淡入淡出、擦除等软转场，必须采用动作点硬切。
- 音画同步：动作硬切的切换瞬间必须精确卡在重战鼓点、镲重击或刀剑格挡/爆破的峰值瞬态上。
- 动态避让：当角色对白或旁白音轨处于激活状态时，BGM 音量自动淡出降低 10-12dB，对白结束后 0.5s 内平滑恢复。

详细的剪辑节奏、转场控制与声场规范见 `references/editing-and-assembly.md`。

### 控制与停顿点

全流程设有关键停顿点，确保用户把控质量：

1. **全局规格与故事板设计后（阶段1和2后）**：暂停，在回复中明确告知并向用户展示当前锁定的分支风格（sub_style），邀请用户确认故事大纲、分镜表和全局视听基调，并提示用户若对当前分支风格不满意可提出更换。
2. **生成新元素资产前（阶段3前）**：在实际执行生成动作前，必须向用户呈现将要使用的生成提示词和构图意图，暂停并获得用户确认后方可触发生成。
3. **元素资产生成后（阶段3后）**：先执行严格的元素资产绑定自检，向用户清晰列出"已注册绑定的元素资产核对清单"（逐个确认所有角色、场景、核心道具、角色声音参考的绑定状态），确保无遗漏。展示自检清单与生成的图像后，暂停并邀请用户进行一致性、配音音色与美术视觉确认。
4. **生成分镜头视频前（阶段4前）**：在生成每个分镜视频前，必须向用户明确展示该 shot 绑定的元素参考图以及相应的动态动作栈提示词设计（若镜头含对白，一并展示配音方案），暂停并获得确认后方可执行。
5. **生成音频层资产前（阶段5前）**：向用户呈现音频提示词、台词脚本和配音色调描述，暂停并获得确认后方可执行。
6. **最终时间轴组装前（阶段6前）**：所有分镜头视频与音频层生成完毕后暂停，由用户对素材质量、动作力度和声画剪辑点进行总体评估，确认后再进行最终缝合渲染。

## 静默自检

交付前内部跑清单并重写弱项，不暴露给用户。

- 分支风格（sub_style）是否已明确锁定并告知用户？
- Final_Video_Spec.md 是否已编写并包含画幅/分辨率/风格/sub_style/语言？
- 所有 key_element（角色、场景、道具）是否均有对应的高品质资产并绑定？
- 所有含对白的角色是否均绑定了 key_element_audio？
- 元素资产绑定自检清单是否已向用户展示并获得确认？
- 视频提示词中角色服装、发饰、道具描述是否与 key_element 设定图完全一致？
- 群战镜头是否绑定 2-3 个核心角色参考图，非核心群演是否用文本描述？
- 双人对话镜头是否通过 {角色ID:对白} 隔断并平行绑定声音参考？
- 旁白是否在独立音频轨道生成，视频提示词中是否加入 no music 防止内置噪音？
- 负向提示词是否包含 no subtitles？
