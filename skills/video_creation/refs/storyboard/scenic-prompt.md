# 风光氛围与文旅 Prompt 编写指南

本指南在**分镜规划阶段**加载，用于构造 `sandbox_generate_video` 的 Prompt。创意发散阶段的范式路由、叙事结构、文旅目的地策略见 `creative/scenic-travel.md`。

## 红线（高频翻车点）

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 画面无任何运动元素（纯静态风景） | 成片像幻灯片 | 每个镜头必须有一个"呼吸"：雾散、光移、水流、云走、草动，写进 prompt |
| 一段内多种运镜混切（推+摇+航拍乱跳） | 节奏混乱，氛围尽失 | 一镜一运镜，全片运镜种类 ≤3 种且节奏统一（全慢或张弛有序） |
| 形容词堆砌的意境描述（"绝美震撼仙境"） | 模型无法落地抽象词 | 物理白描：写光的方向、雾的高度、水面反射的内容 |
| 旁白塞满全片 | 挤压氛围留白 | 先按 `storyboard/dialogue-rules.md` 用 `count_chars.py` 校验；旁白应明显少于同等时长台词，允许整段无旁白 |
| FPV/航拍引导线、路径标注出现在成片 | 穿帮 | prompt 写明"引导线/标注不出现在画面中" |
| 文旅片只有风景没有人 | 没有"去了能干什么"的代入感 | 文旅片必须有人文烟火点缀（见 creative/scenic-travel.md §B 规则 2） |

## §A 运镜语法表（一镜一选）

| 运镜 | 适用 | 写法要点 |
|------|------|---------|
| 缓推/缓拉 | 定调、收尾 | 标注速度"缓慢匀速"，配呼吸感 |
| 航拍下移/上升 | 揭示体量（山城、梯田、建筑群） | 写明起点与终点画面内容 |
| FPV 穿越 | 连续空间（巷道、林间、桥洞） | 写明完整路径与穿过的物体 |
| 延时 | 时间事件（云、光影、人流） | 写明被压缩的时间过程 |
| 固定机位 | 微小动态（雨滴、烛火、雾） | 画面内必须有持续运动元素 |

## 情绪与光的对应

情绪参数（配色/光影/音频）从 `creative/style-master.md` 情绪行取用；空镜的情绪 80% 由光决定——prompt 中光的描述（方向、色温、质感）权重高于景物本身。

## 已提供风景图时（图生视频）

1. **原图三不改**：构图、色调、画面内容一律不改动，prompt 显式写"保持原图构图与色彩色调，建筑/景物不扭曲不变形不消失"
2. **只加两样东西**：动态元素（云流动/水面波光/人流延时）+ 一种运镜（从语法表选 1）
3. **循环视频**：用户要循环/壁纸时，写明"以原图为首帧且为尾帧"，动态元素只选可周期性运动的（云、水波、星闪、草动），禁单向不可逆变化（日落、雾散、灯亮）
