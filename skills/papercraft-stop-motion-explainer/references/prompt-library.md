# 提示词库

本文件在撰写图像或视频提示词前读取。画风词汇从 `visual-design.md` 第一节取，逐字复用。

## 一、共用画风锚点

所有提示词都包含这一组词。**跨片段、跨图时逐字复用，不要改写成同义表达**——措辞漂移会直接导致画风漂移，多片段拼接时表现为材质和光影在接缝处跳变。

```text
手工纸艺定格动画风格，微缩纸雕舞台，多层卡纸剪裁，可见纸张纤维、折痕、拼贴缝与剪裁边缘，
可见卡纸厚度，层与层之间有真实物理投影，微距摄影感，轻微景深，
清晰的前景中景背景远景层次
```

再固定三项，全片不变：**光源方向**（如"光从左上斜入"）、**色调基调**、**景深强度**。这三项是接缝连续性的基础。

## 二、单图提示词

一张图只传达一个主要概念。把所有知识细节塞进一张图，结果是每一样都看不清。

```text
[主题与核心对象]，[核心对象的纸艺构造方式]，
[共用画风锚点]，
[层次描述：前景什么遮挡 / 中景什么主体 / 背景什么环境 / 远景什么底板]，
[光源方向]，[色调]，
[需要时：纸质标签牌、纸箭头或知识卡片的位置]，
无字幕，无文字，无水印，无 logo
```

保留用户主题里的领域词，不要把科学主题改写成另一个主题。

## 三、系列图提示词

需要多个关键帧时使用。每张图包含图号与目的、相比上一张的变化、共享画风锚点、一致性锚点、提示词正文。

- 同一纸张材质语言、同一光源方向、同一空间层级、同一角色身份锚点。
- 每张图只解释一个知识步骤。
- 除非用户要求变化，保持同一画幅比例。

## 四、视频片段提示词

单个片段的时长按 `segment-continuity.md` 的片段预算表确定，不要默认等分。

### 结构

```text
[接续声明：首段跳过；后续段用尾段延长语法开头]
[共用画风锚点]
[场景与层次：前景 / 中景 / 背景 / 远景各是什么]
[光源方向]，[色调]，[景深强度]

先[第一个动作节拍：主体 + 纸艺动作 + 机关行为]，
接着[第二个动作节拍]，
最后[第三个动作节拍，落定在稳定状态]。

[运镜：一条贯穿整段的连续运镜，写清起点、方向、速度]
[前景与背景的视差关系]
[纸艺音效：对应画面动作的声音，逐个绑定到具体动作]

讲解人声：「[本段讲解句原文，逐字写出]」
[音色与语气]，语速约每秒 4 字，匀速，全程一致，讲解人声为主，纸艺音效为轻点缀。

保持纸张纹理、剪裁边缘、分层布景与真实层间投影全程一致。
纸偶动作为定格式小幅移动，有短暂停顿和轻微回弹。
无字幕，无文字，无水印，无 logo，无背景音乐。
```

### 讲解写在提示词里

讲解由生视频工具随画面一起输出，不做后期配音。每段提示词交代：

- **讲解句原文逐字写出。** 写"讲解本段内容"这类概括，工具会自己编词，编出来的通常就是播报画面（"第一页展示了…""接下来翻到第二页…"），这是本类视频最常见的失败。
- **讲解只讲概念，不描述画面**：因果、机制、原理、意义。判定标准是把这句话从画面里拿出来单独听，还带不带信息。视觉隐喻的机械结构（页、格、滑轨、拉片）不进入讲解词。
- **音色与语气**：亲子或教育主题用温暖、清晰、轻柔；课堂或技术讲解可中性；避免过度戏剧化的解说腔。
- **语速写成具体数值**：「语速约每秒 4 字，匀速，全程一致」。只写"从容""平缓"这类形容词，工具会按本段字数与时长的比例自行决定语速，多段之间必然不一致（前段慢吞吞、后段赶着说）。各段这句措辞逐字复用。
- **声音层次**：讲解人声为主，纸艺音效为轻点缀，无背景音乐。

**多段片子的音色描述逐字复用同一段措辞**，与画风锚点同一类约束：措辞一变声音特质就漂移，接缝处会听出换人。

**每句讲解整句落在同一片段内**，片段边界落在两句之间的呼吸间隙。一句话被切成两半，成片会出现半句话断开、下半句气口音色都变了的听觉断裂。

### 片段内部要有递进

一个片段最容易犯的错是"一个动作被拉长"——同一个缓慢推近从头拖到尾，观众十几秒里没获得新信息。

写成一条**连续动作链**，按「先…接着…最后…」三个递进节拍描述。一个片段可承载 2 到 3 个知识节拍，允许纸机关连续动作：先拉片揭示、接着标签翻出、最后镜头推近到细节。三个节拍靠**同一条运镜贯穿**，不在片段内部做硬切——需要硬切说明该拆成两段。

时长变长是为了让动作更完整、更有呼吸，不是加快或加大动作。运动幅度始终克制。

### 结尾必须落定

片段结尾动作要落定：纸片停稳、机关到位、镜头减速。停在动作中途会让接缝出现明显跳动。

结尾状态要能逐字写进预算表的"结束状态"列：纸片位置、机关开合、角色姿态、镜头位置与速度、光源方向，五项齐全。

### 多片段的接续首句

首段不需要接续声明。后续段用**尾段延长**（主路径）：

首句逐字使用工具要求的延长语法字面量（尖括号是任务语法的一部分，不能改成 `@视频1`），随后锁定末帧的纸片位置、机关状态、镜头位置与运动方向、光源方向，再写本段新的动作链，并写明：

```text
从末尾可见状态无缝继续，不重复<视频1>中已经完成的动作。
```

工具不支持延长任务时降级为尾帧参考图：

```text
以 @图片1 为起始画面，保持画面中全部纸艺元素的位置、层次、光影与材质完全不变，
从该状态自然继续动作。镜头延续上一段的[运动状态与方向]，速度不变。
不重复 @图片1 中已经完成的动作，从当前姿态继续下一个动作。
```

两种写法都必须有"不重复已完成动作"这句。少了它，模型经常把上一段结尾的动作再演一遍，成片出现明显的重复卡顿。

## 五、反向提示词

每次生成都附上：

```text
光滑塑料 3D，高亮 CG 渲染，真人实拍，普通扁平矢量插画，没有纸张纹理的普通卡通，
金属科幻表面，玻璃材质，赛博朋克霓虹，数码故障特效，油画笔触，
真实毛发或皮肤毛孔，没有纸张纤维，没有剪裁边缘，没有层间投影，边缘过度平滑，
高速镜头环绕，融化或液体变形，
字幕，文字，水印，logo，背景音乐，配乐
```

末行排除项的依据：视频模型画出的文字几乎必然错字变形抖动，字幕改由 `render_video` 在拼接后开启生成；背景音乐会盖掉纸的摩擦声、滑动声、落定声，这些是纸艺质感的直接证据。排除的是音乐，不是讲解人声。
