# BGM 音乐 Prompt 编写

成片拼接完成后，为整片配一条统一 BGM。本文件只在多段成片配乐流程启用时加载。

BGM 由 `sandbox_generate_audio({ Type: "music", Text: "{音乐 Prompt}", OutputPath: "assets/{project}/bgm.mp3" })` 生成，再经 `render_video` 的 `bgm_audio_path` 融入成片。

## 与段内禁 BGM 的关系

多段流程的每段视频 Prompt 默认写“禁止生成BGM”，因为每段各自生成的 BGM 拼接时会风格断裂、音量跳变。BGM 收归成片后用一条统一音轨整体铺底——段内禁、成片整体加，是同一策略的两端，不冲突。

## 编写步骤

1. 读 `storyboard.md` 全部分镜，提取每段的情绪、节奏、场景，归纳整片的情绪弧线（如“平静铺陈→冲突紧张→情绪高潮→收束”）。**同时累加所有分镜 `duration` 得到成片总时长**，BGM 时长必须等于该值。
2. 把情绪弧线映射成音乐走向：乐器选择、节奏快慢、情绪起伏、力度强弱。
3. 按整片基调 + 用户所选风格写 Text，**Text 中显式写明音乐总时长（如“总时长 36 秒”），使生成的 BGM 与成片时长一致**。

## Text 写法

**Text 只描述音乐本身**——乐器、节奏、旋律、情绪、力度。分镜剧情是用来**推导**音乐走向的依据，**不写进 Text**。禁止出现角色名、物体、画面事件、剧情动作（如“小膀胱越撑越大”“细菌捣乱画面”）。把剧情翻译成音乐语言：紧张剧情→“弦乐张力递进”，欢快剧情→“轻快木吉他节奏”。

- **整体基调先行**：开头一句定义整片音乐风格、主奏乐器与基调，如“中国古典器乐，古琴为主箫笛辅奏，月夜哲思基调”。
- **总时长对齐（必写）**：成片总时长 = 所有分镜 `duration` 之和。Text 必须显式写明音乐总时长等于该值（如“总时长 36 秒”），生成的 BGM 时长由 Text 控制，必须与成片一致，避免循环突兀或截断。
- **时间分段（可选）**：片长或情绪起伏大时按时间锚点分段写，让音乐情绪跟随剧情推进。锚点用“第0-10秒”或“0:00–0:10”，与成片实际时长对齐，最后一段锚点须收在总时长处，禁止毫秒级。每段只写该时段的乐器、节奏（可标 BPM）、情绪、力度变化，不写画面在演什么。
- **段间渐变而非骤切**：相邻段情绪/速度差异大时，写清过渡方式（如“前3秒延续上段慢速，0:32起逐拍加快至65BPM”），避免音乐情绪硬切。
- **全局约束收尾（推荐）**：Text 末尾用一句“全局约束”锁定整片统一项——乐器范围、有无打击乐、音色偏好、调式、动态范围、留白，防止音乐生成模型中途跑偏。
- **纯音乐无人声**：非用户明确要求人声/歌词时，Text 必须包含“纯音乐无人声”。

Text 示例骨架（按需取舍，不机械填满；速度可用“快/中/慢”或精确 BPM）：

```
纯音乐无人声，总时长 {N} 秒，{整体风格 + 主奏乐器 + 基调}。
0:00–0:{N1} {乐器/节奏(约X BPM)/情绪/力度}；
0:{N1}–0:{N2} {情绪递进/乐器叠加/过渡方式}；
…末段 {收束方式}。
全局约束：纯器乐无人声；乐器仅限 {乐器范围}；{有无打击乐}；音色偏好 {质感}；调式 {调式}；动态范围 {大/小}，留白 {充足/紧凑}。
```

## 乐器 / 情绪 / 节奏词表

| 维度 | 可选词 |
|------|--------|
| 主奏乐器 | 钢琴、原声吉他、弦乐、大提琴、小提琴、长笛、合成器、电子节拍、鼓组、古琴、古筝、二胡、箫、竹笛、竖琴 |
| 情绪基调 | 温暖治愈、舒缓平静、悬疑紧张、激昂热血、恢弘大气、忧伤怀旧、轻快活泼、神秘空灵、月夜哲思 |
| 节奏力度 | 舒缓铺底、节奏渐强、鼓点推进、张力递进、情绪爆发、渐弱收束；速度可标精确 BPM（慢约40-55、中约60-90、快约100+） |
| 全局约束 | 乐器范围、有无打击乐、音色质感（如丝弦古琴/洞箫）、调式（五声/大调/小调）、动态范围、留白程度 |

## 红线

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 只写“配个 BGM”“加点音乐” | 风格随机，与画面情绪脱节 | 按分镜情绪弧线写明乐器、节奏、情绪走向 |
| 漏“纯音乐无人声” | 生成带人声音乐，盖住台词旁白 | 非用户要求人声时必加“纯音乐无人声” |
| 时间锚点与成片时长不符 | 音乐情绪与画面错位 | 锚点对齐成片实际秒数 |
| Text 不写总时长 | BGM 时长与成片不一致，循环或截断 | Text 必写“总时长 N 秒”，N = 各分镜 duration 之和 |
| 不读分镜直接套模板 | 音乐与剧情无关 | 先读 `storyboard.md` 归纳基调再写 |
| Text 写进剧情/画面/角色 | 音乐生成模型被无关词干扰 | 剧情只作推导依据，Text 只留乐器/节奏/情绪/力度 |
