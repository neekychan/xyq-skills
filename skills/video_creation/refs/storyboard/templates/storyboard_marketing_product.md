# 分镜图模板：产品讲解型

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以商品功能/卖点展示为主的分镜图或 storyboard，多出现“广告/TVC/卖点/品牌”等词，配合电商口播或短广告脚本。
- **典型场景**：电商短视频广告、新品发布、产品功能演示、品牌升级故事片尾、直播预热视频等。

## 2. 判定关键词
- 典型触发词：`产品`、`广告`、`TVC`、`卖点`、`品牌`、`新品`、`带货`、`电商`、`种草`、`优惠券`、`口播脚本`。
- 若需求描述以“讲清楚产品优势/卖点”为主，并明确有促销/转化目标，优先归为本类。

## 3. 分镜结构建议
- **推荐镜头数**：6–12 镜，可对应 6/9/12 宫格。
- **结构骨架**：
  1. 开场场景建立（1 镜）：目标人群 + 使用场景，弱露产品。
  2. 痛点呈现（1–2 镜）：没有产品时的困扰或对比场景。
  3. 卖点逐个展开（3–6 镜）：每镜清晰对应一个核心卖点（功能、质感、对比、细节）。
  4. 社会证明/体验感（1–2 镜）：真实使用场景、用户表情或前后对比。
  5. 收尾行动号召（1–2 镜）：Logo + Slogan + 价格/福利信息。
- **景别节奏**：环境建立用中远景 → 卖点展示用中近景/特写 → 收尾回到中景，确保 Logo 清晰。

## 4. 生图 Prompt（PE）模板

```text
你是品牌创意分镜师，请为下述 {产品名称} 设计一张 {宫格数} 宫格的产品讲解分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏短视频”}。

【画面风格】
- 整体风格：{画风，如“写实棚拍 / 2.5D 插画 / 3D 写实产品渲染”}
- 色调：{主色调，如“清爽蓝白 / 温暖米金”}，整体对比度 {高/中/低}，强调品牌调性。

【主体设定】
- 产品外观锚定：{颜色、材质、形状}，确保所有格子中形态一致。
- 目标人群：{人物设定，可空，如“30 岁都市白领女性”}。

【背景与场景】
- 主要使用场景：{卫生间/厨房/办公室/卧室/车内等}。
- 背景复杂度：{简洁纯色背景 / 生活化实景}，避免喧宾夺主。

【宫格与构图】
- 宫格排布：{宫格数，如 9 宫格}，按阅读顺序从左到右、从上到下编号 S1–S{N}。
- 每格需明确：产品位置（画面左/中/右、前景/中景）、人物是否出镜、是否需要留出文案/口播区域。

【输出要求】
- 为 S1–S{N} 逐格写出一句中文分镜说明，包含「景别 + 主体动作/产品展示 + 場景」。
- 在说明中用括号提示构图关键点，例如“(中景，产品居中，背景虚化)”。
- 统一画风与光线，确保产品造型与颜色在所有格子中保持一致。

【画幅参数】
- 推荐 ratio={ratio 代码，如 2 表示 9:16 竖屏}，可根据投放平台改为 3（16:9 横版）或 0（跟随分镜图原始比例）。
```

## 5. 视频生成策略

- 对接 `storyboard-sheet-prompt.md` 中「营销转化类」的视频生成策略与 PE 模板，本模板仅提供分镜图画面/版式细节。
- 优先走「分镜/产品精修图 → 参考图生视频」路径。
- 用户已提供成品级分镜图时，视频阶段不大改镜头顺序。
