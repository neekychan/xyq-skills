# 萌宠萌娃闯祸记

## 核心原则

不要只拍"宠物和萌娃同框的可爱画面"，而要拍"它们一起闯了祸、被大人发现后齐僵"的喜剧弧线。喜剧引擎不是互动本身，而是闯祸——两主角的行动造成的、可以被镜头拍到的物理状态变化。

持久引擎（因果链）：

**角色规格锁定 → 双主角设定图（特写+三视图） → 闯祸主题确定 → POV分镜规划（闯祸弧线） → 场景道具参考图 → 逐段视频生成（跨段截帧首帧衔接） → 封面图矩阵 → 时间轴合成**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果画面中没有"祸"留下的可见物理证据（破损/散落/被占/被推翻），大人台词就悬空、被抓包就没有张力。** 每段视频的收段画面必须同时呈现「双主角呆萌僵立」+「背景中清晰可见的祸的痕迹」——两者同框才能构成完整的被抓包喜剧构图。

## 输入诊断

生产前，识别或合理假设以下维度：

- **宠物角色**：物种/类型、主要外形特征关键词、体型大小参照（如"灰色宠物龙，体型约如成年猫"）
- **萌娃角色**：主要外形特征关键词、与宠物的体型比例关系（谁更大、大约几比几）
- **是否有角色参考图**：用户上传的参考图（面部或主体清晰），还是仅有文字描述
- **视频总时长**：15s（单段）/ 30s（2段）/ 45s（3段）
- **视频语言**：大人画外台词使用的语言
- **画面方向**：竖屏 9:16（默认）或横屏 16:9
- **互动主题**：用户描述剧情方向，或由 AI 提案后用户确认
- **视频模型**：画质优先（默认）或速度优先
- **POV约束**：画面内始终呈现宠物+萌娃双主体，大人不入画但画外台词保留
- **音频策略**：所有台词/SFX通过视频模型内嵌生成，不单独配音
- **跨段衔接策略**：每段视频结尾截帧作为下一段首帧静帧输入
- **合规敏感点**：所有内容须为轻松喜剧/萌系日常，宠物间的争抢推搡须在喜剧范围内，禁止暴力血腥

若用户给的上下文很少，做合理假设并继续。仅当角色信息或互动主题确实无法推断时才发问。

## 工作流（步骤）

### 前置检查

用户须至少提供以下之一，否则立即索取，不得继续执行：
- 已有角色参考图（面部或主体清晰），或对宠物/萌娃的文字描述（如"灰色宠物龙/麒麟，体型约如成年猫"、"黑白哈士奇幼犬"）
- 一段简短场景文字（如"厨房烤肉失控"、"帮忙叠衣服"）

### Phase 1：规格锁定

向用户确认以下规格，确认后写入规格文件（项目名称、宠物角色、萌娃角色、双主体体型比例关系、总时长、段数、画面比例、视觉基调、模型选择、POV约束、音频策略、跨段衔接策略）：

- **宠物角色**：物种/类型、主要外形特征关键词、体型大小参照
- **萌娃角色**：主要外形特征关键词、与宠物的体型比例关系（谁更大、大约几比几）
- **视频总时长**：15s（单段）/ 30s（2段）/ 45s（3段）
- **视频语言**：用户指定
- **画面方向**：竖屏 9:16（默认）或横屏 16:9
- **互动主题**：用户描述剧情方向，或由 AI 提案后用户确认
- **视频模型**：画质优先（默认）或速度优先

**【强制暂停点一】** 将规格摘要发给用户确认，未收到确认前不得继续。

### Phase 2：角色形象锁定

生成「1张主体特写 + 3视图」四图水平合排设定图（纯白背景，超写实摄影风格）。四个分区：①左侧大幅主体特写（占整图约40%宽度）、②正面全身、③侧面全身、④背面全身。宠物角色与萌娃角色分别生成独立设定图。

- **若用户上传了参考图**：先分析判断是否已是「主体特写 + 三视图」合排格式——若是则直接使用，无需重新生成；若非合排格式，提取视觉特征后，以参考图为基础一次生成四图合排设定图。
- **若仅有文字描述**：直接文生图一次生成四图合排设定图。

生成规格：2K分辨率，超写实摄影风格（Hyper-realistic photography）。整图作为角色形象基准，①特写分区作为后续视频生成的主要角色参考输入。

**【强制暂停点二】** 将角色设定图（含特写 + 三视图）分别发给用户确认，此图为后续所有生成的视觉基准，未确认不得继续。

### Phase 3：POV 分镜规划

基于已确认的规格与角色形象，设计完整故事板。读取 `references/formats/storyboard-design.md` 获取分镜设计规范。

- **单段（15s）**：设计1个镜头，时长15s。
- **双段（30s）**：设计2个镜头，每段15s，明确跨段剧情衔接节点（第1段结尾的画面状态即是第2段开头的起始状态）。
- **三段（45s）**：设计3个镜头，每段15s，同样明确相邻段的衔接节点。

每个镜头描述中须包含：POV形式说明（第一人称POV：大人视角拍摄，大人不入画但画外台词保留）；2–3个互动节拍及对应情绪信号；双主体同框说明；跨段衔接备注（多段时标注本段结尾定格画面描述）；逐秒时间线与音频设计；大人画外台词内容及触发时机（必写）。

同时在故事板中登记本片涉及的**场景/道具关键元素**（写明外观描述：材质、颜色、形态、所处环境光），供 Phase 4 生成参考图、并供视频生成时绑定，确保跨段场景一致。

**多片段必须先完成完整剧情策划**（时间线锚定、情绪弧线设计、动作/状态连续性检查），先向用户呈现「剧情大纲」（各片段时间节点、场景、核心动作与情绪关键词），经用户确认后再展开逐秒分镜细节。

**【强制暂停点三】** 输出完整分镜后邀请用户审查，等待确认后再继续。

### Phase 4：关键元素生成（场景 / 道具）

针对故事板中登记的每个场景/道具元素：

- **若用户已上传对应参考图**：提取特征后直接使用，绑定到对应场景/道具元素，无需重新生成。
- **若无参考图**：按故事板描述生成参考图（2K，超写实摄影风格，与角色设定图基调统一）。
- 纯空旷场景（如普通桌面、地面）若无显著道具特征，可不单独生成，由视频提示词直接描述；仅对**有明确形态/材质、需跨段保持一致的场景或道具**（如指定的小床垫、特定餐具、玩具）才生成参考图。

**【强制暂停点四】** 将场景/道具参考图发给用户确认，作为后续视频的视觉基准，未确认不得继续。

### Phase 5：视频生成

按照「跨段截帧首帧衔接」规则逐段生成。读取 `references/formats/video-prompt-grammar.md` 获取提示词文法。

**时长说明：每段15s的视频用一次视频生成即可拿到完整片段，多段 beat（0-3s/3-7s/…）是同一次生成内部的时间轴描述，不等于要多次调用。只有成片总时长超过15s时，才需要拆成多个15s片段分别生成，再做后处理拼接。**

1. **第1段**：以双角色设定图（各自特写分区为主参考）+ 该镜头绑定的场景/道具元素图一并作为参考输入直接生成。分辨率720p，画面比例依规格方向（9:16或16:9）。
2. **第2段及后续段**：从上一段已生成视频中提取最后1帧或最后0.5s内最佳构图帧作为截帧；以该截帧作为下一段视频的首帧输入，确保视觉连续性丝滑无割裂。

**双主角一致性自检：** 生成后确认双主角均完整出现在画面内，且与设定图形象一致；若任一主角缺失、形象漂移或体型比例明显失当，打回重新生成并追加对应参考约束。

**【可选：超分辨率提升】** 用户对视频内容满意后，可对单段或全片将分辨率从720p提升至1080p或更高。建议在用户确认内容满意后再执行，对不满意的片段无需超分。

**【强制暂停点五】** 将所有段视频（含可选超分结果）发给用户预览确认后，再进入封面图阶段。

### Phase 6：封面图生成

读取 `references/formats/platforms-markets.md` 获取封面图比例与裂变规则。

**第一轮 · 主封面（比例由视频方向决定）：**

1. 从已确认视频中提取最具冲击力的高光帧（优先级：「被抓包齐僵」定格瞬间 > 情绪顶点表情 > 喜剧落点构图），**将候选高光帧发给用户确认，等待用户明确选定后再继续**。
2. 以宠物角色特写分区 + 萌娃角色特写分区 + 用户选定的高光截帧为多参考，生成主封面（2K），叠入用户确认的片名与金句；要求双主角清晰、体表形态与设定图一致，留出大面积干净负空间用于文字排布。比例依视频方向：
   - **竖屏视频（9:16）** → 主封面为 **3:4 竖图**（小红书 / 抖音）
   - **横屏视频（16:9）** → 主封面为 **4:3 横图**（B站 / 朋友圈）

**第二轮 · 尺寸裂变（另外两个比例）：** 主封面经用户确认后，以主封面为唯一参考裁切裂变另外两个比例，文字排版与内容保持统一：
- **竖屏路径**：3:4 主封面 → 裂变 **16:9 横版** + **4:3 横图**
- **横屏路径**：4:3 主封面 → 裂变 **16:9 横版** + **3:4 竖图**

封面图只允许叠入用户确认的片名与金句，禁止出现任何其他文字、水印、随机字幕。

**【强制暂停点六】** 高光截帧选定、主封面确认两处均须等待用户明确确认；主封面确认后方可裂变，全部封面确认后再进入合成阶段。

### Phase 7：时间轴合成

按故事板顺序将多段POV视频拼接合成，硬切转场，输出最终成片。

合成规则：
- 所有台词、音效均由视频模型内嵌生成，保留视频原生音频轨，不得静音，不得替换为独立配音。
- 镜头间优先使用「动势匹配」或「物理遮挡」转场；禁止黑场叠化，除非场景有明确时间跳跃意图。
- 严禁对任何片段进行变速处理，防止音画失同步。
- 多片段拼接时，相邻片段衔接处做0.1–0.2s音频交叉淡化，避免声音硬切。
- **响度一致性（多片段必检）**：合成前检查所有片段整体响度，若相邻片段音量差异明显，须做响度标准化处理。

**依赖关系：** Phase 2→1；3→1,2；4→3；5→2,3,4；6→5；7→5,6。

**绝对禁止一次性跑完所有步骤，每个强制暂停点均须等待用户明确确认后方可继续。**

## 静默自检

开发期执行；定稿前重写弱项。除非用户要求点评，否则不要把这份清单输出给用户。

- 闯祸弧线是否完整？每段是否有明确的「祸」——可见的物理状态变化？
- 收段画面是否同时包含「双主角呆萌僵立」+「祸的物理痕迹」两者同框？
- 大人画外台词是否指向可见证据（如"你把床垫咬了！"），而非抽象行为（如"不许欺负弟弟"）？
- 台词与角色反应是否写在同一时间窗口内（音画因果锁定）？是否避免了跨节拍拆分？
- 双主角体型比例是否跨段锚定一致？
- 物理真实感细节是否包含至少3条（接触锚定/接触阴影/物质交互状态/体型比例锚定）？
- POV约束是否满足：大人不入画、低角度、手持呼吸感、双主体全程同框？
- 角色静止（freeze pose）是否正确描述为「角色动作停止但摄像机维持呼吸感、背景继续运动」，而非「画面静止/暂停」？
- 成片时长是否 ≤15s？若是，是否作为一次生成的完整片段（多段 beat 写在同一条 prompt 内）？若 >15s，是否已切成15s片段分别生成再拼接？
- 跨段衔接是否使用截帧首帧输入确保视觉连续性？
- 封面图是否只叠入用户确认的片名与金句，无其他文字水印？
- 所有内容是否为轻松喜剧/萌系日常，无暴力血腥？
- 提示词正文是否用中文书写（台词内容例外，遵循用户指定视频语言）？
