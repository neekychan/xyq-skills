## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心规则

1. **锚定词位置固定**：永远放在 prompt 的第一句，任何情况下不得后置或省略。
2. **锚定词内容不修改**：不裁剪、不改写、不替换其中任何词汇，原文整段复用。
3. **与其他风格技能搭配时**：若同时启用另一个风格滤镜类技能，将两者的风格锚定词**依次拼接**（本技能锚定词在前，另一个在后，或协商顺序），合并后整段置于 prompt 最开头，规则不变。
4. **图片与视频统一**：无论是生成图片素材还是生成视频，均遵循同一套锚定词前置规则，保证全套素材风格一致。

## 工作流

### 第一步：接收用户画面描述

获取用户对画面内容的描述（人物、场景、动作、情绪、构图等），这是锚定词之后的「画面主体部分」。

若用户未提供具体描述，主动询问：希望呈现什么场景或瞬间？

### 第二步：拼装 prompt

按以下结构拼装最终 prompt：

```
[风格锚定词全文]，[用户的画面描述]
```

**示例：**
- 用户描述：「少女站在教室窗边，望向窗外落叶」
- 最终 prompt：「参考电影为《情书》，岩井俊二式日式青春电影影像风格，90年代日式胶片摄影风格，真人写实风格，摄影作品，画面清透、柔和、带有回忆感，具有明显胶片颗粒、轻微噪点、柔焦质感和低对比影调，色调以低饱和、冷白、淡蓝、浅绿、柔灰为主，光影上使用自然光、强逆光、窗光、泛光、柔和高光和空气感眩光，构图轻盈留白，全画面处于极度夸张的柔焦与柔光扩散状态，带有手持摄影般的生活化瞬间感，整体氛围纯净、忧伤、朦胧、诗意，少女站在教室窗边，望向窗外落叶」

### 第三步：生成资产

- **图片素材**：使用图片生成能力，以拼装好的 prompt 生成图片。
- **视频片段（≤15s）**：使用视频生成能力，以拼装好的 prompt 一次生成完整片段，无需分段。
- **视频片段（>15s）**：拆分为多个 ≤15s 分镜，每段分别拼装 prompt（锚定词均前置），逐段生成后用后处理拼接为完整成片。

### 第四步：交付

将生成的图片或视频呈现给用户。如用户对风格有微调意见，在**保持锚定词完整不变**的前提下，仅调整「画面主体部分」描述后重新生成。

## 输出契约

| 字段 | 规范 |
|---|---|
| prompt 结构 | 风格锚定词（原文全段）＋逗号＋画面主体描述 |
| 锚定词位置 | 恒为 prompt 第一句，不可移位 |
| 图片风格一致性 | 同一批素材全部使用同一锚定词，不逐张调整 |
| 视频单段时长 | ≤15s 一次生成；超过 15s 则分段生成后拼接 |
| 多风格叠加 | 锚定词拼接后整体前置，不拆散插入 |

## 静默自检

交付前在内部确认以下各项，不向用户展示此清单：

- [ ] 风格锚定词是否完整出现在 prompt 最开头，一字未删
- [ ] 若有多风格叠加，各锚定词是否均已拼接且置于最前
- [ ] 画面主体描述是否接在锚定词之后，未与锚定词混淆
- [ ] 视频超过 15s 时是否已正确拆分分镜
- [ ] 同批次所有图片 / 视频是否使用了相同的锚定词前缀
