# 邵氏武侠电影风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的 1970 年代香港邵氏经典武侠电影质感。这是一个**风格滤镜**技能:它不决定画什么,只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则(因果链)

不变的因果链:`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现,画风一致性就成立;任何一条 prompt 漏注入或改写了锚定词,这条因果链即断裂。

**可证伪质量测试:** 把本次生成的任意两张图片、任意一段视频并排观看,若能明显看出它们「不是同一套胶片 / 同一部邵氏武侠片里出来的」(胶片颗粒、硬光布光、Technicolor 色调、复古质感不统一),则本技能执行失败。反之,若观者会认为它们出自同一部 1970 年代邵氏武侠电影,则成立。

## 风格锚定词(本技能的核心资产)

以下为固定风格锚定词,**逐字使用,不得改写、删减、翻译或重排**:

> **1970年代香港邵氏经典武侠电影美学。强烈的舞台感与戏剧张力。摄影器材与胶片:使用 Eastman Color 5247 彩色胶片拍摄。极重的邵氏老电影粗颗粒感。光影塑形:非自然主义的棚内布光。典型的高调硬光照明,拒绝现代柔和阴影,光线直白、生硬且极具冲击力。光学与放映特效:伴随老式放映机带来的轻微胶片划痕与污点,以及画面明暗的不规则帧闪烁,充满粗粝的录像带时代感,呈现Technicolor(特艺彩色)色调与高对比度,焦点清晰聚焦于双眼。画面运用戏剧性的轮廓光,展现复古香港电影美学,保留了真实的胶片颗粒感及变形镜头特有的光晕效果。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则(硬规则,最高优先级)

1. **位置固定:** 锚定词永远放在每条 prompt 的**最开头**,后面紧跟本条画面的具体描述。顺序恒为「锚定词 → 具体画面」,不得颠倒。
2. **逐字一致:** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖:** 本次任务里需要生成的**所有**图片素材与**所有**视频片段,无一例外都要在头部注入锚定词;包括中途返工重生的素材。
4. **不污染具体描述:** 锚定词只负责画风;镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后,不要因为有了锚定词就省略画面描述。
5. **语言:** 锚定词与具体画面描述统一用中文书写(与锚定词语言一致);如确需英文版本,仅可作为补充,且锚定词部分不翻译、保持中文原文。

## 绕过 Agent 内置风格锚定图的干扰(硬规则,务必执行)

某些 Agent 链路会针对特定风格**前置内置一张「风格参考图 / 风格锚定图」**并悄悄塞进图片或视频生成请求里做风格引导。一旦本技能生效,这类内置参考图会与本技能的锚定词**争夺画风控制权,污染产物**,必须绕过:

- **禁用内置风格参考:** 调用图片 / 视频生成工具时,**不得**携带、引用或启用任何 Agent 侧内置的风格锚定图 / 风格参考图 / 默认风格预设。本技能的画风**只由上文锚定词文本决定**。
- **参数层面清空:** 若生成工具存在 `style` / `style_reference` / `style_image` / `reference_image`(风格用途)/ 预设风格 ID 之类的入参,一律**留空或显式关闭**,不要沿用链路默认值。
- **仅允许的例外:** 只有当用户**自己明确提供**参考图(如指定首帧、指定角色形象、图生视频衔接)时才可传参考图;此时该图作为**内容 / 构图参考**,画风仍以锚定词为准,且不得叠加 Agent 内置风格图。
- **冲突时以本技能为准:** 若链路强制注入内置风格图导致画风偏离锚定词,视为执行失败,应改走「纯文本 prompt + 锚定词」的生成方式重做,而不是接受被污染的产物。

## 与其它风格 skill 搭配时的合并规则(务必遵守)

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时:

- **合并而非替换:** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词,整体放在 prompt 最开头,后接具体画面。本技能的锚定词按用户 / 加载顺序排入,不单独另起。
- **规则不变:** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述,以及「绕过内置风格锚定图」规则同样生效。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重:** 若多个风格锚定词出现完全重复的短语,可去重一次,但本技能锚定词的实质内容不得删减。
- **冲突时:** 若两套风格存在直接矛盾的表述,保留双方原文并列即可(不臆改),由生成模型融合;不要为了「调和」而改写任一方锚定词。

## 与非风格类 skill 冲突时的结合规则(务必遵守)

当本技能与**非风格类** skill(如营销短片、口播带货、分镜脚本、广告投放、电商短视频等)同时被调用时,双方各司其职、不得互相覆盖:

- **职责边界:** 非风格类 skill 负责**内容与结构**(卖点、脚本节奏、转化钩子、时长编排、口播文案、CTA 等);本技能负责**画风**。两者叠加,不是二选一。
- **画风不可被覆盖:** 即使加载了营销 / 带货 / 脚本类 skill,凡是最终要**生成图片素材或视频**的每一条 prompt,仍必须在最开头逐字注入本技能锚定词,并同样执行「绕过内置风格锚定图」规则。营销类 skill 里若自带任何默认画风 / 风格描述,一律让位于本技能锚定词。
- **注入点:** 让营销类 skill 先产出分镜 / 脚本 / 画面文案,再由本技能在每条画面 prompt 头部拼接锚定词后送生成——即「营销定内容,邵氏定画风」。
- **本技能优先级:** 在「画风一致性」这一维度上,本技能规则的优先级高于任何非风格类 skill 的默认视觉设定;若发生直接冲突,以本技能为准。

## 输入

- **必需:** 本次要生成的画面清单(要哪些图片素材、要哪些视频片段及其内容 / 分镜)。
- **可选:** 是否与其它风格 skill 叠加;是否与营销 / 脚本类 skill 结合;视频画幅 / 时长偏好;是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项:** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜,按常规创作补齐一版分镜草案并说明,再统一注入锚定词;不要反复追问已明确的信息。

## 工作流(Steps)

1. **确认锚定词形态。** 若仅本技能生效,锚定词 = 上文原文。若与其它风格 skill 搭配,先按「合并规则」拼出合并锚定词,后续全程复用这一版。确认生成工具已按「绕过内置风格锚定图」规则清空风格预设。
2. **生成图片素材(逐张)。** 对每一张需要的图片,组装 prompt = `锚定词 + "，" + 该图具体画面描述`,然后生成图片(不带任何内置风格参考图)。所有图片共用同一份锚定词。生成后展示给用户。
3. **图片质检与返工。** 对照质量测试检查画风一致性;若某张明显跑偏,重写该图的**具体画面**部分(锚定词不动)并重生,直到整批图片观感统一。
4. **生成视频(逐段)。** 对每一段视频,组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`,再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**,无需分段拼接;分镜 beat(如 0-3s / 3-7s)只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时,才把它拆成多个 ≤15s 片段分别生成,每段头部同样注入同一份锚定词,再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接,可将该图片作为**内容**参考,视频 prompt 仍在头部注入锚定词,且不叠加内置风格图。
5. **视频质检与返工。** 检查视频画风是否与图片素材一致;跑偏则改具体描述后重生(锚定词不动)。
6. **交付并展示。** 把最终的图片与视频产物展示给用户;需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足:

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内,`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜(时间轴)时,分镜写在具体描述内,锚定词仍只出现一次且在最前。

# 风格知识库(供 Agent 写分镜 / 角色 / 场景 / 脚本时参考)

以下知识不是锚定词,而是帮助 Agent 在写**具体画面描述、分镜、角色设定、故事脚本**时更贴合邵氏武侠气质的创作参考库。写具体描述时多从这里取材,让内容与画风双向统一。

## 一、整体风格气质

- **不是「真实江湖」,而是「被设计出来的江湖」。** 追求传奇感、仪式感、宿命感、杀伐感,而非生活写实。
- **情绪偏冷、偏狠、偏肃杀:** 冷艳、阴郁、诡谲、决绝,爱是隐忍的,恨是沉着的,复仇是长久酝酿的,出手极狠。
- **仪式感极强:** 出场、亮兵器、报姓名、对峙、走位、拔刀、收招都程式化,武打像一场生死礼法。
- **一句话气质:** 华丽、诡艳、肃杀,带血色浪漫,既有舞台戏剧感,也有刀光剑影中的古典悲剧美。

## 二、画面质感(与锚定词呼应,写描述时可强化)

- **强烈棚拍 / 舞台感:** 室内景多,背景带舞台感,天空、雾气、月光、风感都有人工控制痕迹;画面像被「雕刻」过。
- **硬光、雕塑感强:** 主光明确,阴影清楚,常见侧光、逆光、顶光制造压迫感;烟雾配合光束形成层次;戏剧性轮廓光勾边。
- **Technicolor 浓艳 + 老胶片厚重:** 颜色浓但带旧胶片时代的厚重感,不是数码糖水艳丽。
- **胶片肌理:** 粗颗粒、轻微褪色、黑位重、高光泛光、划痕污点、帧闪烁、变形镜头光晕——旧、厚、沉、雾、梦、血。
- **焦点聚双眼:** 面部特写时焦点清晰落在双眼上,强化眼神戏。

## 三、色彩与光影

- **典型色调:** 深红 / 血红、墨黑 / 乌青、绛紫 / 赭褐、孔雀蓝、幽绿、金 / 铜、米白灰白侠客服。
- **经典配色对撞:** 红与黑、金与黑、蓝与灰、白衣与血色、冷月光与暖烛火对冲。
- **红色语义:** 不是喜庆,而是权力、欲望、危险、死亡、宿命、血——红灯笼、红帷帐、血衣、红烛带不安定的艳丽。
- **黑色语义:** 不是空,而是压——深色背景、夜色、阴影、黑袍、黑发构成压迫感,人物从暗处走出极具戏剧效果。
- **雾气烟感:** 薄雾、烟尘、香火烟、夜雾、光束穿雾,让画面更有层次、更像「梦里江湖」。
- **配色气质总结:** 艳而不甜,华而不浮,冷中带毒,贵气里有杀气。

## 四、场景 / 置景(写分镜时取材)

- **标志性空间:** 红灯笼长廊、深宅庭院、朱门大户、屏风密室、荒庙佛龛、阴森地牢、客栈大堂、竹林 / 假山 / 回廊 / 水榭、山洞石窟 / 机关暗道。
- **空间的情绪功能:** 客栈=风波将起;长廊=埋伏试探;荒庙=宿命对决;深宅=门派权谋;地牢密室=阴谋酷刑;夜林 / 山道=追杀逃亡。
- **空间是情绪容器:** 空旷大堂显孤绝,幽深长廊显危机四伏,帷幔飘动显暧昧杀机并存,灯火通红显权力血腥,雾气重重显虚实难辨。
- **装饰元素:** 雕花门窗、帷帐纱幕、烛台香炉、木格屏风、兵器架、匾额牌楼——贵气又危险,繁复又压抑。
- **构图偏好:** 端正、严整、对称;人物居中或对称站位;门框 / 窗棂 / 屏风 / 廊柱形成画中画;前中后景层次清晰、室内布置「满」。

## 五、角色造型(写角色设定时取材)

- **侠客:** 窄袖劲装、披风、束腰、长靴,英挺、清峻、肃杀。
- **女侠:** 修身劲装、披纱、束发、利落线条,冷艳妆感、眉眼锋利——美而不柔,艳而不媚,冷而有锋。
- **反派:** 暗色重纹样、夸张层次,贵气邪气并存,造型更诡更华丽。
- **掌门 / 权臣:** 宽袍大袖、厚重材质、装饰性强。
- **面料质感:** 缎、绸、纱、麻、皮革感,带反光的厚缎面、暗纹刺绣、金边滚边、护腕腰封。
- **身段:** 站姿、转身、抬手、拔剑、回眸都有戏曲「身段」感,人物像在「摆出命运」,而非日常行动。

## 六、动作设计(写打斗分镜时取材)

- **程式化武打:** 戏曲化身段 + 武术套路拆解 + 兵器对抗节奏,讲究进退、亮相、收势;美中带狠,不是花拳绣腿。
- **节奏先静后爆:** 对峙 → 眼神试探 → 手按刀柄 → 一句冷话 → 突然爆发 → 快速数招 → 拉开距离 → 再试探 → 绝杀 / 反杀。精彩处在「打之前空气已经紧了」。
- **兵器是人格外化:** 刀=狠 / 直 / 决绝;剑=冷 / 快 / 贵气;鞭=妖 / 险 / 诡;暗器=阴 / 毒 / 突然;双兵器=技巧灵动。
- **血色诗意:** 喷血、伤口、倒地是类型化美学暴力——血很红很醒目,与白衣、黑夜、冷光对比,产生近乎妖异的美感。
- **爱拍的细节镜头:** 眼睛、握兵器的手、刀刃出鞘、袖中暗器、滴血、足尖落地、衣摆翻动、烛火摇曳、纱帘 / 珠帘后窥视——制造「杀机早有伏笔」的预兆感。

## 七、叙事氛围 / 故事母题(写脚本时取材)

- **常见母题:** 江湖恩怨、门派纷争、忠义两难、师徒反目、血亲复仇、身份伪装、美人与杀局、权力争夺、正邪难分、情爱与牺牲。
- **底层氛围:** 人活在规矩、仇恨、名节、师门、欲望之间,谁都不真正自由——华丽外壳之下总有一层冷酷宿命。
- **脚本调性建议:** 台词克制冷峻,情绪压着而非外放;转折靠伏笔与眼神;高潮落在一次决绝的出手或反转的身份揭露。
