# 运镜与镜头语言

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 目录
1. 战斗急速运镜设计规范
2. 非战斗运镜规范

## 1. 战斗急速运镜设计规范

### 急推（Whip Zoom / Push）
用于力量聚集瞬爆、表情极度拉扯特写、或兵刃撞击核心爆点。从全景/中景瞬间硬拉（Hard Push）至角色双眼、紧绷肢体或刃口咬合特写，建立瞬间压迫张力。指示后期安排极速突进与高能聚拢音效卡点。

### 急拉（Whip Pull / Pull-back）
用于冲击波炸裂扩散、受击飞退、或蓄势后撤。从极近景/局部特写秒级瞬间急速拉远（Hard Pull）至大全景或远景，拉出场景爆破、碎石瓦解或风沙席卷的宏大威压。指示后期安排声压向四周排开的低频空间音效延展。

### 横扫/急扫（Whip Pan / Sweep）
用于身法闪避、极速对折、多方向突击或多人乱战。镜头沿动作施力方向或视线轨迹进行极其高速的横向或纵向扫掠（Whip Pan），背景笔墨高速失焦、景物化为写意流线，焦点牢牢锁死在动作的动能切线上。指示后期安排横向立体声扫频声场（Stereo Panning）。

## 2. 非战斗运镜规范

### 文戏长卷平移（Long-Scroll Panning）
镜头移动速率为"微速、极其平缓"，展现中国画长卷缓缓展开的徐疾美学。画面边缘的焦墨、重彩随平移徐徐隐入或显现，云雾、烟雨在画面中央进行舒缓的"呼吸式"扩散，留白空间随山水地貌渐进式起伏。

### 国画陈设特写推进
慢速推进的特写与极写镜头（Close-up to Extreme Close-up），焦点锁定在孤碑残损刻痕、劲松虬枝坚韧开裂或竹叶上滑落的一滴水墨。通过极细微的相机摇移或云雾游移，将陈设物象的宏观坚硬/挺拔与水墨介质的湿晕流动性进行视觉碰撞。

## 3. 场景强绑定与一致性规范

### 显式指向场景 ID
每一镜中都必须显式声明其所属的场景元素 ID（scene_id，例如指向 [Element_Scene_01]）。严禁规划无场景归属、或使用模糊泛指描述的镜头。

### 连续场景完全复用
若相邻镜头在同一地点、同一时值下发生，或镜头之间属于同一个打斗/对话回合，则指向的场景元素 ID 必须保持绝对一致（完全相同的 ID）。下游生成器依据该 ID 强制加载并复用同一个四宫格场景参考图资产，从分镜设计源头根除"场景跳画、背景前后不一致、突变穿帮"的问题。

## 落 prompt 前自检

- 急推/急拉/横扫是否标注了对应的后期音效指示？
- 文戏平移是否标注"微速、极其平缓"？
- 每镜是否显式声明 scene_id？
- 同一地点连续镜头是否指向相同 scene_id？
