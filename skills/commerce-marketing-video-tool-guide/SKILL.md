# 商品营销视频

调用 `commerce_marketing_video_tool`，根据商品图片和营销诉求生成视频。

## 优先触发条件

本技能采用**分层判定**：**先过素材类型前置门槛**（有视频素材 → 直接让位），再判意图是否为营销带货或品牌形象（决定是否命中），最后判时长（决定放行 / 让位）。**素材类型前置门槛优先级最高。**

### 阶段零 · 素材类型前置门槛（优先级最高，先于意图，且需在素材齐备后复检）

判断意图之前，先看用户已上传 / 引用的素材类型：

> 🚫 **只要素材中包含任何视频素材（视频文件 / 已有视频片段），立即让位给其他更匹配的 skill，不再进入意图判定与后续流程。** 本技能只做「基于商品图（静态图片）成片」，不接受视频素材作为输入。这是**最高优先级的硬排除**——即使意图完全命中营销带货 / 品牌形象、时长也合法，只要有视频素材就让位。

- **仅上传静态商品图** → 进入阶段一意图判定。
- **暂未上传任何素材** → 先按阶段一命中并引导上传；**待用户上传后，必须在此重新执行素材类型检查**——若上传结果中含视频素材 → **立即让位**（即使此前已认领、已在流程内也要退出）；全为静态图才继续。
- 区分：**「缺图」不是让位理由**（缺图是补收要素，见阶段一说明）；让位的触发条件是「**素材中存在视频**」，无论它是初次就上传的、还是引导后才补传的。

### 阶段一 · 意图判定（是否命中）

**判定基准（命中标准，满足任一即命中）**：

1. **转化型**：视频核心目的是「推动某个具体商品 / 服务 / 虚拟品的**购买转化**」；或
2. **品牌型**：视频核心目的是「为某个品牌 / 产品做**形象宣传**」，即品牌大片、TVC、产品宣传片等广告片——不直接叫卖，而是通过调性、情感、品牌资产建立认知与好感。

满足其一 → 命中本技能；两者皆否 → 不命中，让位给其他 skill。判断意图本质，不要被表面关键词带偏。

> **命中只看意图，不看要素是否齐备**：商品图、时长、比例都是命中后在流程内补收的要素，**初次未提供不构成不命中或让位的理由**。尤其是「没给商品图」——后续流程本就会引导用户上传，所以缺图时仍应正常命中并认领，不得因此降低命中判断。

#### ✅ 命中：营销带货 / 品牌形象（下列任一即算，形式不限）

- **直接卖货**：卖、推销、带货、种草、挂车、主图视频、宣传片卖某商品。
- **软广植入 / Vlog 包裹**：剧情或日常里「顺便」推出商品（办公室零食带出无糖饼干、减肥 Vlog 带出代餐奶昔）。
- **痛点 → 商品**：先立痛点再**引出具体商品**作为解决方案（「微胖怎么穿显瘦」→ 大码女装；健康焦虑 → 空气净化器）。
- **营销转化动作**：领券、下单、点击橱窗 / 下方链接、右下角购买、满减、限时特价、限时折扣等 CTA。
- **服务 / 虚拟品 / 本地生活**：售楼引流、健身房办卡、知识付费课程、探店团购、二手车商 / 车商私域引流、APP 下载 / 游戏买量。
- **大促节点带货**：双十一、年货节等节点 + 明确商品推销。
- **品牌大片 / TVC / 产品宣传片**：为品牌或产品做形象宣传的广告片（品牌大片、TVC、宣传片、品牌形象片），靠调性·情感·品牌资产建立认知，即使没有直接叫卖或 CTA 也命中（如「给华为手机做一个品牌大片」）。

#### ❌ 不命中：非营销带货、非品牌广告（含高频「陷阱」边界题）

- **含品牌 / 商品名，但不是卖它、也不是为它做广告**：做菜道具（海天酱油做可乐鸡翅）、艺术意象（耐克球鞋长藤蔓）、**测评拔草 / 反向劝退**（指出大疆缺点劝别买）。
- **品牌纪录片 / 企业史，非广告片**：如「可口可乐公司 100 年发展历史纪录片」——目的是客观叙述历史而非塑造品牌形象、推动认知好感，**不属于品牌大片 / TVC**，不命中。（对比：以品牌调性·情感·产品为主体、意在建立好感的品牌大片 / TVC 属命中。）
- **含「营销 / 直播 / 网购」等字面词，但意图相反**：商业理论授课（饥饿营销漏斗模型）、荒诞艺术（桌上空无一物的「直播带货」）、社会调查（街头采访网购花费）、防骗科普（提醒别在直播间乱买保健品）。
- **纯流量号痛点话术**：只有「这 5 个习惯偷走健康」式开场，**未引出任何商品**。
- **教学 / 科普 / 工具**：剪辑技巧教学、菜谱、知识科普、写代码 / 邮件 / 翻译、PPT 背景素材。
- **纯创意 / 氛围 / 记录**：影视分镜、动画测试、白噪音助眠、风景记录、节日烟花素材、个人开业记录、ToB 数据汇报、非盈利书籍推荐。

#### 判定口诀

1. 找视频里有没有**一个被推销 / 被宣传的具体标的**（商品 / 服务 / 课程 / 门店 / 品牌）。没有 → 基本不命中。
2. 有标的，再看目的：**「卖它 / 促成交」（转化型）或「为它塑造品牌形象·建立好感」（品牌型）→ 命中**；「用它教学·叙事·艺术·测评·科普·客观记录」→ 不命中。
3. 关键词（品牌名、营销、直播、网购、痛点、TVC、大片）只是线索，**一律回到「核心目的是促成交或塑造品牌形象」复核**，不可仅凭词命中；「品牌大片」要与「品牌纪录片 / 企业史」区分，后者是客观叙述、不命中。

### 阶段二 · 时长确认（放行 / 让位）

意图命中后，检查时长信息。**让位只看上界**：仅当时长超过 15 秒才让位给其他 skill；其余情况均留在本技能内处理（必要时询问或修正）。

> ⚠️ **时长上界是硬门槛，不适用「先占后验」**：意图可以先认领，但一旦确认时长 >15 秒，即视为**撤销认领并硬让位**，不得再以「先接管再补收」为由留住任务。

- **未给出时长**：先向用户询问确认目标时长，得到答复后按下列规则判定。
- **已给出且为 4～15 秒整数**：合法，直接进入下方使用要求流程，忽略其他同类 skill。
- **已给出但不超过 15 秒却不合法**（小于 4 秒，或非整数如 12.5 秒）：仍属本技能范畴，不让位；向用户说明合法范围为 4～15 秒整数并确认修正后处理。
- **已给出且超过 15 秒**：**必须让位**，明确告知本技能仅支持 4～15 秒整数秒，交由其他更匹配的 skill 处理。**严禁**把超时长诉求（如 20s、30s）静默截断 / 压缩 / 四舍五入到 15 秒后强行生成。

> 核心原则：**先意图后时长**。意图既非营销带货也非品牌形象宣传，直接不命中；意图命中后，时长仅作放行门槛且只看 15 秒上界（下界与整数问题在本技能内修正，不构成让位理由）。

## 与通用营销视频 skill 的分流边界

项目内存在功能重叠的通用营销视频制作 skill（如 `marketing-video-creator`：脚本表、多段分镜、品牌大片、可变时长的完整流水线）。二者对「营销带货 / 品牌形象」意图都会响应，**冲突消解规则如下**：

- **优先归属本技能**：意图为营销带货或品牌形象（含品牌大片 / TVC）、且可用「一键快速出短视频（≤15 秒）」满足的，一律优先由本技能认领，即使用户初次未提供时长或商品图。**不要**因为通用 skill 覆盖面更广就默认让给它，也**不要**因为当前还没有商品图就判定本技能不适用。
- **认领姿态是「先占后验」**：命中意图即先接管，再在流程内补收要素——时长未知先询问、商品图未给先引导上传，而不是先让位。
- **素材含视频 → 最高优先让位**：用户上传 / 引用的素材中只要有视频素材（无论初次上传还是引导后补传），无论意图与时长如何一律让位（本技能仅接受静态商品图输入）；此条优先级高于下面的时长与复杂度判断。
- **仅在下列情况让位给通用 skill**：
  1. 用户确认时长 **>15 秒**（本工具上限 15 秒）；
  2. 明确需要**长视频、多段分镜编排、完整投放脚本、多镜头故事片**等超出「一键短视频」的复杂制作。
  > 注意：「品牌大片 / TVC」本身**不再是让位理由**——只要可 ≤15 秒一键成片就归本技能；只有当它同时要求超时长或多段分镜等复杂制作时，才按上面第 1 / 2 条让位。
- **边界判断**：拿不准时，只要「营销带货或品牌形象意图 + 可 ≤15 秒」成立，就归本技能；**是否已提供商品图不参与此判断**（缺图命中后引导上传即可）。

**示例锚点 1**：`帮我做个游戏推广买量视频，画面是一刀999爆装备，吸引别人下载。`
→ 意图为 APP 下载 / 游戏买量（营销带货，命中阶段一）；**即使未上传任何图片、也未给时长**，也应先认领本技能，再引导上传商品图并询问时长；若 ≤15 秒 → 本技能一键生成，**不让位**给通用 skill；仅当用户要求 30s 以上或复杂分镜脚本时才转交。

**示例锚点 2**：`给华为手机做一个品牌大片，比例 9:16，时长 15s。`
→ 意图为品牌形象宣传（品牌型，命中阶段一）；时长 15s 合法 → 本技能一键生成，**不因为它是「品牌大片」就让位**给通用 skill；仅当用户要求 30s 以上或多段分镜故事片时才转交。

**反例锚点 3**：`帮我做个 20 秒的带货视频，突出商品卖点。`
→ 意图命中（带货，命中阶段一），但时长 20s > 15s → **硬让位**；**不得**压缩 / 截断到 15s 后生成，明确告知本技能仅支持 4～15 秒整数秒，转交其他 skill。

**反例锚点 4**：`用我上传的这段商品视频剪个 10 秒带货片，突出卖点。`（用户上传的素材含视频）
→ 意图命中（带货）、时长 10s 也合法，但素材含**视频素材** → **命中阶段零前置门槛，最高优先让位**，不进入意图/时长判定、不调用本工具，转交更匹配的 skill。

**反例锚点 5**（引导后补传触发）：用户初次只说「帮我做个 10 秒带货视频」未传素材 → 先命中并引导上传；用户随后上传的是一段**视频**而非商品图 → 此刻复检素材类型，**立即让位**，即使此前已认领也要退出。

## 使用要求

- **一次用户诉求 = 一次工具调用，禁止拆分**：即使用户输入包含多镜头 / 多段分镜脚本（含 `[镜头1]`、`00:00-00:02` 等时间码），也必须把**整段脚本作为一个 `Prompt`、一次性调用**生成一条视频。**严禁按镜头 / 按时间段拆成多次调用**——多镜头是同一条视频的内部切分，不是多条视频。
- **`Duration` 是整条视频的总时长**：取用户给出的总时长（如脚本总长 10s 就传 `Duration: 10`），**不是单个镜头的时长**；不得用某个镜头的 2~3s 去当 Duration，也不得因单镜头短于 4s 就判非法。
- 使用当前会话中用户选择、上传或引用的商品图。
- `ImageList` 传 1～10 个 sandbox 图片路径。

> ⚠️ **Prompt 保真是硬性要求**：撰写 `Prompt` 的默认动作是**把用户原话复制粘贴进去**，而不是概括、改写或「优化」。任何「帮用户把话说得更专业 / 更完整」的改写都属违规——工具要的就是**用户原话本身**，改写会丢失或扭曲用户意图。

- `Prompt` **完整、忠实地承接用户已表达的全部诉求**：以用户原话为准，**不改写语义、不精简、不扩写、不润色、不编造**用户未提及的内容。
- **`Prompt` 必须自包含**：本工具为**无状态调用**，单次调用**看不到历史对话和上一次传入的内容**。当本轮是对已生成视频的**局部微调**（如「把场景换成室外」）时，主脑须把**用户先前提供的分镜脚本 / 描述原文**与**本轮修改诉求**合并为一段完整 Prompt 传入，避免只传最新一句导致前文丢失。合并时只允许原样承接用户自己说过的内容，不得借机改写或补造。
- **禁止主脑无中生有地编造 / 扩写分镜脚本、运镜、卡点节奏**等用户未提供的内容；但**用户自己写的分镜脚本属于其诉求，应原样保留并传入**。
- 不编造商品信息、卖点、品牌调性等用户未给出的信息。
- `Duration` 为 4～15 秒的**整数**；**调用工具前必须校验 4 ≤ Duration ≤ 15 且为整数，任一不满足都不得调用工具**。
- 用户指定比例时传 `Ratio`，例如 `9:16`、`16:9`；未指定则省略。

> **调用 `commerce_marketing_video_tool` 前的强制自检**：
> 1. 用户**当前已上传 / 引用的全部素材**（含引导后补传的）是否含**视频素材**？是 → **立即让位**（优先级高于意图与时长，即使已认领也要退出），不调用工具。
> 2. 意图为营销带货或品牌形象？否 → 不命中。
> 3. Duration 为 4～15 的整数？>15 → 硬让位（**不截断、不压缩**）；<4 或非整数 → 在本技能内修正后再调用。
> 4. **Prompt 是否为用户原话的逐字复制**（多轮微调则为「历史原话 + 本轮原话」的合并）？只要出现改写 / 概括 / 润色 / 新增用户没说过的词 → **打回，改回原话**再调用。
> 5. **是否为单次调用？** 本轮诉求（哪怕含多镜头脚本）只允许调用工具一次；若正准备按镜头 / 时间段拆成多次 → **停止，合并为一次调用**。
> 6. 全部通过，才允许调用工具。

缺少商品图或合法时长时，先认领本技能，再只询问 / 引导补齐缺失信息，不要因缺图缺时长而退出或让位。

## 示例

### 示例 1 · 首次生成

```json
{
  "Prompt": "帮我给这个背包做个带货视频，突出它轻便、防水，卖给通勤上班族",
  "ImageList": [
    "assets/products/main.jpg",
    "assets/products/detail.jpg"
  ],
  "Duration": 8,
  "Ratio": "9:16"
}
```

### 示例 2 · 多轮局部微调（工具无状态，须合并前文）

假设首轮用户给过完整分镜脚本：`镜头一：背包特写；镜头二：主角背包快步过马路；镜头三：突降大雨背包不湿`，视频生成后用户补一句：`把场景换成室外`。

因工具看不到上一轮内容，`Prompt` 须把**用户先前的脚本原文**与**本轮修改**合并传入，而非只传「把场景换成室外」：

```json
{
  "Prompt": "镜头一：背包特写；镜头二：主角背包快步过马路；镜头三：突降大雨背包不湿。这次把场景换成室外。",
  "ImageList": [
    "assets/products/main.jpg"
  ],
  "Duration": 8,
  "Ratio": "9:16"
}
```

### 示例 3 · 多镜头脚本 → 仍是一次调用（禁止按镜头拆分）

用户输入含 `[镜头1]~[镜头4]`、每镜头带 `00:00-00:02` 时间码、总时长 10s、9:16 的完整分镜脚本（如钓鱼凳带货脚本）。多镜头是**同一条 10s 视频的内部切分**，正确做法是**把整段脚本原文逐字放进一个 `Prompt`、只调用工具一次**，`Duration` 取整条总时长 10：
