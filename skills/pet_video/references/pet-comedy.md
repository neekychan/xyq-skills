# 类型 D：萌宠搞笑段子创作指南

## 设计原则

**核心卖点**：短平快 + 反转出其不意 + 节奏感让人忍不住循环看。

**反转类型**（选一个方向，不要每次都用"认真学习→睡着"）：
- **预期颠覆**：建立正常预期 → 结果完全相反（认真健身→其实在挠痒痒）
- **身份反转**：看起来是A → 揭示其实是B（以为在打工→其实是老板）
- **规模反转**：小事变大/大事变小（认真准备→对象是只蚂蚱）
- **时间反转**：主人在 vs 不在、白天 vs 晚上、工作 vs 休息
- **因果反转**：努力做A → 意外获得B，**B 必须来自外部意外变量**（另一主体介入、镜面反射、突然的光/声源、真实物理意外），不要写成"被自己的动作/伪装吓到"这种自证式反转——观众能一眼看穿那就是它自己，缺乏真正的意外性，是这类段子里最容易被想到也最没意思的处理方式
- **打破第四面墙**：宠物突然看镜头/与观众互动

**节奏设计**：
- 三拍是基础（引子→铺垫→反转），但节拍数可以变化
- 两拍极速反转（前一秒还在A→后一秒完全B）适合表情包式内容
- 四拍递进（小反转→以为结束→更大反转）适合"一分钟能有多少反转"
- **反转点之前的铺垫要足够"正经"**——铺垫越认真，反转越好笑。硬要求：铺垫时长 ≥ 全片 40%（20s 段子至少 8s 铺垫）；铺垫阶段动物表演"认真到夸张"（端坐/凝视/点头/严肃），**禁止提前暴露反转意图**（如铺垫阶段就出现"邪魅笑容"）——观众在铺垫阶段应真的以为它在做正经事，反转才有效

**反转的意外性（选"时间反转/因果反转"时尤其注意）**：
- "时间反转"（主人在/不在）是最容易想到、最可预测的套路，用它时必须引入至少一个外部意外元素（主人回来时手里多了个东西、突然门铃响、镜子照出真相），避免纯"在/不在"被一眼看穿
- "因果反转"的 B 必须来自**外部意外变量**（另一主体介入/镜面反射/突然光声源/物理意外），禁止"被自己的动作/伪装吓到"这种自证式反转——观众一眼看穿是它自己，最没意思

**BGM 使用**：
- BGM 是段子的节拍器——动作切换对齐 BGM 重拍
- 反转点用音效强化（刹车声、玻璃碎裂声、"叮"、静音突停）
- 一首 BGM 贯穿，不要中途换歌

**画面节奏**：快切为主，每个画面 1-3 秒

**最后一拍要有"破绽出卖它"**（段子最容易丢分的地方）：最好笑的从来不是"装无辜"本身，而是装无辜时**藏不住的破绽**。别停在"推东西回原位→装睡"就收尾——再加一拍让证据出卖它：屏幕弹出 VICTORY / 尾巴骄傲地拍地 / 嘴角忍不住上扬 / 藏起来的东西露出一角。这一拍才是转发钩子（"这就是我家猫"）。收尾停在破绽前一拍 = 白铺垫。

## Prompt 示例

### L1/L2 反转段子

```
参考@图片1的橘猫形象（正常家猫体型，橘白相间短毛），写实摄影风格。
干净整洁的书房，桌上摊开一本书。

镜头1：橘猫四足端坐在书桌前，前爪搭在书页上，低头凝视书本，耳朵竖起，一脸认真。
（轻柔的钢琴曲）

镜头2：画面缓缓推近，橘猫眼皮逐渐下垂，头开始一点一点往下栽，前爪缓缓滑离书页。

镜头3：橘猫整个脑袋"啪"一下拍在书上，四脚朝天翻倒，露出肚皮。
<"啪叽"的拍击音效>

快切节奏，画面稳定，保持无字幕，画面中禁止出现人类手部。
```

## 分段策略

段子通常单段完成，一气呵成效果最好。
反转节奏在段内用画面阶段分隔，**不拆段**——跨段拼接会破坏节奏感。
