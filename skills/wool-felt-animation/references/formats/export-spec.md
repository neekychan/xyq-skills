# 最终合成导出规范
## 合成顺序
1. 视频轨道：将所有确认完成的分镜视频按故事板shot_list顺序拼接，转场使用硬切或羊毛毡风格柔和过渡（如毛毡纤维溶解过渡），避免花哨转场效果
2. 音频轨道：
   - 主音轨：保留分镜视频自带的SFX音效，音量调至-12dB ~ -18dB
   - BGM轨道（若有）：音量调至-20dB ~ -24dB，不盖过人声和SFX
   - 旁白轨道（若有）：音量调至-6dB ~ -10dB，清晰可辨
3. 音画同步校验：确保旁白与对应镜头画面完全对齐，BGM节奏与视频情绪匹配

## 输出规格
- 格式：MP4（H.264编码 + AAC音频）
- 比例：9:16竖屏
- 分辨率：与分镜视频一致（默认720p，若分镜为更高分辨率则匹配）
- 帧率：24fps
- 码率：默认5Mbps，保证清晰度的同时控制文件大小
- 附加要求：无内置字幕、无水印、无文字叠加、无片尾logo

## 导出前检查
1. 所有镜头顺序正确，无遗漏、无重复
2. 音画同步，无延迟、无错位
3. 音量平衡，无爆音、无音量忽大忽小
4. 全片风格统一，无跨镜头材质/色彩跳变
5. 无违规内容、无侵权元素
