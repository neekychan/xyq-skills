# Seedance 2.0 视频提示词规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

视频阶段负责把图片资产转成60秒动画短片。提示词必须是工程型指令，不是单纯堆形容词。

## 素材引用规则

使用格式：`@图片1` `@图片2` `@视频1` `@音频1`

不要裸写asset ID，不要写[asset-xxx]。

## 主体绑定规则

如果有角色图，必须先定义主体：

```
将 @图片1 中的圆润奶油小狐狸定义为 <主角>。
将 @图片2 中的雨后森林窗台小屋定义为 <场景>。
将 @图片3 中的发光种子和小陶盆定义为 <道具>。
```

之后全程只用 `<主角>` `<场景>` `<道具>`，不要写"@图片1跑过去"。

正确写法：`<主角> 慢慢走向 <道具>。`

## 角色一致性绑定规则

- 每个镜头必须绑定同一张主角资产图作为参考，不能换用不同角色图或省略角色引用
- 绑定对应关系要正确：主角引用必须是该角色的资产图
- 视频提示词中角色的颜色、服装、眼睛形状、耳朵/尾巴/配件必须与主角资产图完全一致，不能加新衣服、改颜色、换配饰
- 多角色场景：每个角色各自绑定对应资产图，用不同标签区分（如 `<主角>` `<小鸟>`）
- 失败重跑时保持绑定不变，只调整动作/运镜描述

## 60秒视频三段论结构

### 第一段：总体设定 + 主体定义

写清：
- 故事发生在哪里，整体氛围
- 哪张图绑定哪个主体标签
- 哪张图是场景、道具、首帧、尾帧
- 是否参考音频或运镜视频

### 第二段：镜头分镜

使用"镜头1/镜头2/镜头3"顺序，不写绝对秒数。分镜表里可以写建议时长方便剪辑，但提示词里用镜头顺序。

### 第三段：风格 + 约束包

必须包含：
- 原创软萌3D治愈动画风格
- 高清，细节丰富，电影质感
- 色彩自然，光影柔和
- 人物面部稳定不变形
- 动作连贯自然
- 无穿模，无卡顿
- 保持无字幕，避免生成任何文字或字幕
- 不要生成水印，不要生成logo
- 不要塑料玩具感
- 不要镜头乱飞
- 不要角色重复、分身、双胞胎效果

## 一镜一运镜规则

每个镜头只允许一种主要运镜：

可用：固定机位 / 缓慢推进 / 轻微横移 / 缓慢后拉 / 平稳跟拍 / 轻微上摇 / 轻微下摇

禁止：推进+横移+环绕+变焦 / 快速旋转 / 360度环绕 / 镜头乱飞 / 大幅度手持晃动

## 单镜头动作规则

每个镜头只安排一个主要动作。

适合：眨眼 / 抬头 / 低头 / 伸手 / 递出 / 抱紧 / 轻轻触碰 / 慢慢靠近 / 小心观察 / 耳朵微动 / 尾巴轻轻摆动 / 小物体发出微光

避免：跑跳翻滚 / 快速转身 / 大幅度挥手 / 多角色同时复杂动作 / 复杂舞蹈 / 追逐打斗 / 镜头内塞太多事件

## 人物与物体互动5步法

1. 角色先看向物体
2. 角色慢慢靠近
3. 手、爪子、鼻尖或视线与物体产生接触
4. 物体给出轻微反馈
5. 角色产生表情变化

反面：不要只写"小狐狸和发光种子互动"。
正面：`<主角> 先低头看向 <道具> 中的发光种子，鼻尖慢慢靠近，爪子轻轻扶住小陶盆边缘，发光种子微微亮起，<主角> 的眼睛变亮，嘴角露出温柔微笑。`

## 音频分层规则

视频提示词中只用音效和台词生成视频内同步音频：

- 音效：`<窗外传来细小雨滴声>`
- 台词：`{你终于发芽啦}`
- 字幕/标题：【小狐狸的雨后花园】（如非明确要字幕，不要生成）

BGM不在视频提示词中生成。BGM作为独立音轨用文字转器乐能力单独生成，后期叠加。视频提示词里不写BGM相关描述。

## 完整60秒提示词示例

```
整体设定为一条60秒原创软萌3D治愈动画短片，故事发生在雨后的森林小屋窗边，整体氛围温暖、干净、清新、童话生活感。将 @图片1 中的圆润奶油橘小狐狸、浅绿色小围裙、蓬松尾巴和柔软短绒质感定义为 <主角>。将 @图片2 中的雨后森林小屋窗边、圆角木质窗台、奶油色墙面、浅绿色软垫和柔和晨光定义为 <场景>。将 @图片3 中的发光种子、小陶盆和迷你木铲定义为 <道具>。@图片4 作为首帧氛围参考，@图片5 作为结尾情绪参考。全片围绕 <主角> 发现发光种子并把它种成小花的温柔小事件展开，<主角> 的情绪从好奇、小心，逐渐变成惊喜、温柔和安心。

镜头 1：固定机位，展示 <场景> 的雨后森林小屋窗边，窗外还有细小雨珠，<主角> 坐在窗边木桌旁，尾巴轻轻摆动，眼神安静温柔，画面节奏慢，伴随 <窗外细小雨滴声>。

...（镜头3-11省略，格式同上）...

镜头 12：缓慢后拉，<主角> 双手轻轻抱着开花的小陶盆，坐在 <场景> 的窗边看向雨后阳光，窗外雨停，远处传来轻微鸟鸣，画面停在温暖安静的治愈结尾，伴随 <雨停后的鸟鸣声>。

全程保持原创软萌3D治愈动画风格，角色圆润可爱，五官亲和，表情细腻，材质柔软，毛绒、布料、木质、陶瓷和奶油墙面质感清楚。画面高清，细节丰富，电影质感，色彩自然，低饱和奶油橘、浅绿色、米白和暖黄色搭配，光影柔和温暖。人物面部稳定不变形，五官清晰，动作连贯自然，不僵硬，无穿模无卡顿。保持无字幕，避免生成任何文字或字幕，不要生成水印，不要生成logo。不要廉价3D，不要塑料玩具感，不要过度反光，不要背景脏乱，不要颜色刺眼，不要强硬阴影，不要冷灰脏光，不要镜头乱飞，不要快速旋转，不要突然变焦，不要大幅度动作，不要角色分身，不要双胞胎效果，不要出现外形和服装完全一样的重复角色。
```

## 品牌风格禁止

严禁出现：Pixar/皮克斯/Disney/迪士尼/DreamWorks/梦工厂/Blender/Cycles及任何动画工作室名、电影名、IP角色名。

## BGM生成规则

- 生成时机：所有视频镜头生成完成后、进入最终组装前
- 生成方式：用文字转器乐能力生成独立BGM音轨
- 提示词要求：描述音乐风格、乐器（轻柔木琴、钢片琴、弦乐、温暖环境氛围）、节奏（慢、舒缓）、情绪走向（温暖、治愈、安静）
- 叠加方式：BGM作为独立音轨在组装时与视频画面和视频内音效/台词叠加
- 提示词中不要出现知名音乐人名字

## 落 prompt 前自检

- 三段论结构是否完整（总体设定+分镜+风格约束）？
- 每个镜头是否只绑定一种运镜和一个主要动作？
- 角色一致性：每个镜头是否都绑定了主角资产图？外观是否与资产图一致？
- 音频分层是否正确（视频内音效用<>，台词用{}，BGM不在视频提示词中）？
- 是否有品牌名混入？
- 互动是否遵循5步法？
