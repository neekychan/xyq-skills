# 创作 Agent 画布

创作 Agent 画布支持一边对话寻找创作灵感，一边调整素材与生成效果；资产库、画布与对话窗口的资源同步联动。适用于小云雀 Web 创作 Agent，不将这些入口套用到短剧画布或 App。

[创作 Agent 画布使用手册](https://bytedance.larkoffice.com/wiki/QYydwNHGdiQbkykeulOczZOpn7g)仅供用户自行查看，Agent 不得访问或抓取。

## 入口与首次使用

- 首页「创作Agent」模式：开启输入框中的画布开关，输入提示词并生成，即可进入画布。
- 首页「沉浸式短片」模式也可开启画布开关，提交后画布会带入刚才的生成任务。
- 首页输入框下方小工具区域点击「自由画布」，进入空白画布。

从创作 Agent 提交指令后，初始界面左侧为画布，右侧为 Agent 对话。创意设计、关键参考图、分镜视频等生成结果会自动添加到画布。等待生成时，可新建节点创作下一个视频，也可开启新会话讨论其他创意。

## 对话、节点、连线与资产

| 概念 | 作用 |
| --- | --- |
| 对话 | 通过指令检索创意、生成或润色提示词、生成图片与视频；同一画布可开启多个对话并行处理任务 |
| 节点 | 每个内容单元。文本节点可保存提示词、故事线、分镜描述；图片或视频节点可上传文件，或在空节点中使用模型生成 |
| 连线 | 表示引用上下文关系。当前节点左侧连接参考输入，右侧连接以当前节点为参考的输出 |
| 项目资产 | 对话内「项目资产」包含当前对话与画布历史生成、上传的资产；素材从画布移除后仍可在这里找回 |

例如，文本节点向右连接图片或视频节点，可将文本作为生成提示词；图片节点向右连接视频节点，可将图片作为生成参考。不同节点可引用或被引用的节点类型有区别，不推断任意类型都能连接。

## 多会话与创意助手

会话顶部左侧是多个会话标签，右侧依次为「新建对话」「对话历史」、会话窗口靠左或靠右、分享会话、收起。关闭标签后，可从「对话历史」重新打开。

在会话输入框开启「创意助手」，可检索抖音热点、筛选 7 天内爆款、拆解参考视频爆点，结合热点、记忆与参考案例推荐选题，或细化已有想法。助手可输出创意方案骨架与视频 Prompt，确认方案后进入视频生成流程。这里的 7 天指热点筛选范围，不是生成时长或效果保证。

## 使用 @ 引用素材

引用到会话输入框有四种方法：

1. 先在会话输入框上传素材，再输入 `@` 选择已上传素材，并补全指令。
2. 直接输入 `@`，选择历史资产库、角色库、商品库或当前画布素材。
3. 对对话前文已生成内容点击「引用到输入框」。
4. 点击画布节点左上角的 `@`；多选或打组后可以批量引用一组素材。

引用到生成节点：先把参考素材连接到空白图片或视频节点，再在提示词中输入 `@` 指定参考并完善指令，也可点击参考缩略图上的 `@`。

## 创建节点

可从左侧菜单栏新建、在画布空白处右键新建或上传、从已有节点左右侧新建，或直接让 Agent 对话生成内容并自动添加对应节点。新节点默认为空白，可从本地或资产库上传素材，也可用模型生成。

## 节点编辑

先选择对应节点，再使用其编辑工具栏。图片与视频节点的工具不同。

| 节点 | 工具入口 |
| --- | --- |
| 图片 | 工具栏有「全景图」「打光」「镜头」「超分」「裁剪」「旋转」；「…」菜单有「解析」「抠图」「扩图」 |
| 视频 | 工具栏有「抽帧」「高清」「截取」「音频分离」「裁剪」「解析」「智能抠像」「旋转」；「…」菜单有「去剪映编辑」「去字幕」「向后延长」「倒放」「倍速」 |

工具栏还提供下载图标，可用于获取节点素材。没有收录的参数范围、导出规格、会员要求或费用，不根据图标或示例数值推断。

### 全景图、打光与镜头

- 全景图：选择图片生成全景图，可得到 720° 全景预览；调整至所需角度后截图到画布。
- 智能打光：选择图片的「打光」，设置光源方位、亮度、质感与色温，可补充提示词后生成。方位包含左侧、顶部、右侧、前方、底部、后方；可重置参数。
- 镜头调节：选择图片的「镜头」，调节水平、垂直取景方向与景别，可补充提示词后生成新的取景角度；可重置参数。镜头调节生成新的取景画面，与视频运镜库分别使用。

### 提示词反解析与涂鸦画笔

图片、视频均支持「解析」，可反解析成提示词，用于理解创意或爆款复刻。更完整的逐镜拉片流程见[画布拉片与复刻](video-breakdown.md)。

涂鸦画笔支持自由绘制图案、圈选位置、画简笔画。生成新图后，再配合模型提出具体修改指令，表达需要修改的位置和内容。

### 智能运镜库

在画布视频输入框找到「📷 运镜」，向提示词插入所需运镜效果，再完善生成指令。预设 33 种运镜，示例包括镜头下摇、固定镜头、跟随拍摄、第一视角、柯克变焦、穿越、横滑揭示、甩摇。此处仅收录画布手册明确给出的入口与示例，不补全未收录的全部预设或模型限制。

### 拼图、视频合成与抽卡记录

- 拼图：选中一组图片，点击「拼图」。
- 视频合成：选中一组视频，点击「合成」。需要时间线精细编排时见[多轨编辑](multitrack.md)。
- 重新抽卡：对生成结果不满意时，在画布点击「生成」再次生成。同一提示词多次生成的结果会折叠为一组；从「抽卡记录」选择需要的版本，后续引用参考以指定版本为准。

## 分组与画布布局

多选素材后打组，可为不同组设置名称和底色。打组后支持批量 `@` 到对话、批量参考生成新内容，以及合成多分镜视频。

左下角菜单从左至右为：

1. 重置：恢复全局视角。
2. 隐藏边：隐藏或恢复节点连线。
3. 整理画布：按节点连线层级横向或纵向展开。
4. 画布小地图：查看全局位置。
5. 网格吸附：开启后节点排列吸附网格。
6. 调整画布缩放比例。

## 分享与深色模式

画布素材与对话过程仅支持分别分享。按需要复制画布分享链接或对话历史分享链接；分享会话可从会话顶部操作栏进入，不把任一链接描述为同时包含两者。

深色模式入口：右上角头像 →「设置」→「通用」→ 开启「深色模式」。

## 常见问题

**怎么直接进入空白画布？** 首页输入框下方小工具区域点击「自由画布」。

**生成时能继续做其他任务吗？** 可以新建节点创作下一项内容，也可新建多个会话并行处理任务。

**从画布移除的素材如何找回？** 在对话内打开「项目资产」，查找历史生成或上传的素材。

**怎样让模型使用指定素材？** 用 `@` 引用到会话输入框；在生成节点内使用时，先连接参考素材，再通过 `@` 指定并完善提示词。

**为什么后续引用用了某次抽卡结果？** 后续引用以「抽卡记录」中指定的版本为准，可在记录中重新选择。

**画布太乱或连线不见了怎么办？** 多选素材打组并设置名称、底色；用左下角「整理画布」调整层级布局，「隐藏边」可恢复连线，「重置」可回到全局视角。

**分享画布会一起分享对话吗？** 素材与对话过程分别分享，需要按用途复制对应链接。

**画布有多少节点上限、能上传多大文件？** 本地资料未收录这些限制；使用未命中提示，不将未收录解释为无限制或不支持。
