# 流派 04: 电子 / 赛博 / 粒子 (Cyber & Electronic)

* **适用曲风**：EDM、Future Bass、Trap、赛博朋克科幻、电音单曲
* **视听公式**：`[Drop 爆发] + [空间折叠/几何解构] + [声波共振粒子流] + [FPV 穿梭暴冲与故障风]`
* **表演配比**：纯视觉与动作爆发，不对嘴（或极少量机械冷感口型）。

---

## 一、正交积木库

* **起手式**：`空间中悬浮单一发光几何立方体随低频脉动` / `主角置身暗黑虚空，瞳孔倒映全息数据流` / `巨大机械结构缓缓展开`
* **动作与调度**：`声波冲击波将整个三维场景炸裂为万千发光粒子` / `主角身体周围环绕悬浮晶体碎片在光芒中重组` / `FPV 镜头极速穿梭过折叠空间`
* **光影与材质**：`电光蓝、荧光粉与激光束交织` / `全息半透明材质与色散效果 (Chromatic Aberration)` / `金属机械冷硬光泽`
* **爆发与收尾**：`在 Drop 最顶峰粒子流瞬间汇聚为巨大光芒图腾` / `全景瞬间坍缩为一个发光奇点并全黑定格`

---

## 二、语法示范（15 秒 4 阶段电子赛博）

```text
@图片1 锁主角面部五官与黑色机能服（超写实真人，严禁将主角金属化）。@视频1 提供全段唯一背景音乐与节拍时间轴，不提供画面。画面动作与节奏必须严格跟随 @视频1 的音频作为 BGM，不擅自编曲，严禁生成任何其他无关背景音乐。全段纯视觉与动作爆发，不对嘴。

赛博朋克超现实科幻，超写实真人电影质感(Photoreal)，24mm广角大透视镜头，全息霓虹电光蓝与高反差荧光紫粉，色散效果与光芒拖尾。主角在折叠赛博三维空间中引爆粒子流。

严格跟随 @视频1 的音频作为 BGM，不擅自编曲，全段纯视觉爆发。

第0-3秒 (数据倒映与低频脉冲)：极简纯黑高反差空间，主角正中站立，瞳孔倒映电光蓝数据流，随低频重音脉冲，黑色镜面地面泛起三道发光同心圆环。
第3-7秒 (Snap Zoom 与折叠空间)：随Drop蓄力，镜头在4帧内极速砸入瞳孔微距(Snap Zoom)，深邃眼眸化作视差通道，瞬间硬切为九十度折叠的赛博摩天大楼全景空间，高楼表面布满发光霓虹管。
第7-11秒 (FPV 穿梭与故障色散)：FPV 第一人称视角以极高速度在金色粒子流与倒立霓虹建筑间穿梭暴冲，建筑表面全息广告牌产生3帧RGB故障色散(RGB Glitch)。
第11-15秒 (粒子汇聚与全屏爆白)：在Drop最高潮点，万千发光粒子自画面四周向中心急速收缩汇聚为巨大光之立方体，重拍落下瞬间全屏爆白，主角站在纯黑虚空中右手虚握光芒定格。

保持无字幕，不要生成水印/logo，真人面部不变形，全片不要复制相同人物，严格以@视频1中的音频作为全片唯一背景音乐，严禁生成任何与@视频1无关的背景音乐或杂乱音轨。
```
