# 上海美术电影制片厂风格（上美影风）视频风格锚定技能

## 这个技能是做什么的

这是一个**风格滤镜技能**。它的唯一职责是：在用户借助本 Agent 生成一组「图片素材 + 视频」的整个链路中，把一段**固定的、经过打磨的风格锚定词**，**原封不动地拼接到每一条图片生成 prompt 与视频生成 prompt 的最开头**，从而保证所有产出的画风高度统一，全部呈现「上海美术电影制片厂经典神话动画」的视觉质感。

它不负责编剧、不负责分镜结构本身的对错，只负责一件事：**让每一张图、每一段视频，都被同一套上美影画风牢牢锚定住。**

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心机制：风格锚定词（最高优先级，必须逐字复用）

### 固定风格锚定词（STYLE_ANCHOR）

下面这段就是本技能的**风格锚定词**。在任何图片素材 prompt 与视频 prompt 的**最开头**，都必须**逐字、完整、不改写、不翻译、不删减、不调序**地加上它，然后紧接着再写这一条素材/镜头的具体画面描述。

```
This is a 2D anime-style image in the signature style of the Shanghai Animation Film Studio，上美画风，古典动画片（上海美术电影制片厂风格），低饱和度高级古典配色，早期手绘动画赛璐璐质感，工笔装饰化设计，线条带有传统白描意味，老动画胶片转制后的柔雾颗粒感、中国民族美术风格、胶片颗粒、纸张肌理
```

### 拼接规则

任何一条送去生成图片或视频的 prompt，其结构必须是：

```
<STYLE_ANCHOR> + 「，」 + <本条素材/镜头的具体画面描述>
```

- **位置**：锚定词永远在最前面，具体画面描述在后面。
- **完整性**：锚定词一字不改，全程复用。图片资产和视频资产**都要加**。
- **一致性**：同一个项目里的所有分镜图、角色图、场景图、视频镜头，锚定词部分必须完全相同。
- **具体描述**:锚定词之后再写主体、动作、场景、光影、镜头、运镜等。具体描述部分应尽量贴合本技能「风格知识库」中的特征（见下文），以强化风格统一。

> 示例（图片素材 prompt）：
> `This is a 2D anime-style image in the signature style of the Shanghai Animation Film Studio，上美画风，古典动画片（上海美术电影制片厂风格），低饱和度高级古典配色，早期手绘动画赛璐璐质感，工笔装饰化设计，线条带有传统白描意味，老动画胶片转制后的柔雾颗粒感、中国民族美术风格、胶片颗粒、纸张肌理，一位白衣仙娥端立于宝蓝夜色之中，手托青瓷净瓶，火焰纹光环环绕，工笔白描勾勒衣纹，中轴对称构图，平涂设色，柔雾颗粒感`
>
> 示例（视频镜头 prompt）：
> `This is a 2D anime-style image in the signature style of the Shanghai Animation Film Studio，上美画风，古典动画片（上海美术电影制片厂风格），低饱和度高级古典配色，早期手绘动画赛璐璐质感，工笔装饰化设计，线条带有传统白描意味，老动画胶片转制后的柔雾颗粒感、中国民族美术风格、胶片颗粒、纸张肌理，镜头缓缓推近白衣仙娥的面部，衣袖随仙气轻轻飘动，烛光微微摇曳，运镜平稳克制，帧率偏低带老动画定格感`

## 规则一:与其他「风格类」技能搭配时——锚定词合并，规则不变

当本技能与**另一个风格类技能**（例如「复古 DV 风」「国漫 3D 渲染风」等同样使用风格锚定词的技能）**同时被调用**时：

1. **不是二选一，而是合并**:把各风格技能的锚定词**按顺序拼接**成一段更长的合并锚定词，仍然整体放在 prompt 最前面。
2. **各自的锚定词内部都保持逐字完整**，不因为合并而删改任何一方。
3. 合并顺序建议：**以用户当轮更强调的风格为主锚定词放在最前**，其余风格锚定词依次拼在其后；若无法判断主次，按用户提到技能的先后顺序拼接。
4. 合并后，本条「位置在最前、完整复用、图片视频都加、同项目全程一致」的规则**依然不变**。

> 合并示例结构：
> `<本技能 STYLE_ANCHOR> + 「，」 + <另一风格技能的锚定词> + 「，」 + <具体画面描述>`

---

## 规则二:与「非风格类」技能冲突时——风格部分以本技能为准

当本技能与**非风格类技能**（例如「营销短片」「电商带货短片」「知识讲解视频」「短剧脚本」等负责**内容结构 / 叙事 / 转化目标**的技能）**同时被调用**时，遵循「**各管一段、风格归我**」原则:

1. **叙事、结构、卖点、节奏、时长、脚本框架**等——听从那个非风格类技能。
2. **但凡涉及「画面长什么样」的部分**——即所有图片素材 prompt 与视频 prompt 的**风格锚定与视觉呈现**，**必须以本技能为准**：
   - 锚定词照样逐字加在每条 prompt 最前面；
   - 具体画面描述照样贴合本技能的风格知识库。
3. 换句话说:**即使加载了营销短片等其它技能，凡是要生成图/视频的那一步，都必须先套用本技能的锚定词与画风规则，再落地那个技能的内容诉求。** 其它技能可以决定「说什么、怎么排」，但不能改变「画面是什么质感」。
4. 若其它技能自带某种默认画风描述，与本技能冲突时:**本技能的风格锚定词与视觉规则优先**，其它技能的画风描述让位。

---

## 规则三:禁止内置风格锚定图干扰(必须绕过)

部分 Agent 链路会针对某些风格**前置内置一张/一组「风格参考图 / 风格锚定图」**，在图片或视频生成时自动作为 reference 注入。这类内置参考图会**污染本技能的画风统一性**。

因此，**只要本技能被调用，就必须绕过并禁用 Agent 内置的风格锚定图设定**：

1. **不得**引用、加载、附带任何 Agent 内置的风格参考图 / 默认 style reference / 预置风格图作为生成输入。
2. 生成图片素材与视频时，**风格来源只能是本技能的文字锚定词（STYLE_ANCHOR）**，不叠加任何平台默认风格图。
3. 若生成工具的参数里存在「默认风格图 / 内置 style ref / 风格模板图」等选项，**显式关闭 / 置空**，确保不被自动带入。
4. 唯一允许的图片参考，是**用户自己主动上传**、或**本项目内由本技能锚定词生成出来的、用于保持角色/场景一致性的素材图**;除此之外的一切「系统预置风格图」都要屏蔽。

> 一句话:**画风只认本技能的锚定词，不认 Agent 自带的风格图。**

## 风格知识库（供 Agent 撰写分镜、角色、场景、脚本时形容参考）

下面是「上美影风」的风格特征知识库。**当 Agent 需要写具体画面描述、角色设定、分镜脚本、场景氛围、故事基调时，应从这里取词、取意，让锚定词之后的具体描述也整体贴合上美影气质。**

### 一、整体风格气质

- 关键词:**庄严、空灵、古典、神性仪式感、诗意、典雅**。
- 本质是把**中国传统工笔、白描、壁画、年画、剪纸、戏曲脸谱、民间宗教圣像**转译为动画语言。
- 不追求写实光影，而追求**造型的程式化之美、线条的装饰性、设色的概括性、构图的秩序感**。
- 画面观感:**既像会动的工笔重彩画，也像被动画化的年画 / 壁画 / 戏曲舞台 / 宗教圣像。**

### 二、画面质感（核心）

- **赛璐璐手绘质感**:颜色以平涂分层为主，明暗关系简洁，阴影用概括色块而非复杂渐变，边缘清楚但不机械，保留人工描线与人工上色的痕迹。
- **柔雾胶片转印感**:轮廓略带软化，色块边界有轻微晕开，画面带细颗粒、轻雾、低对比的年代感，亮部像有淡淡泛光——像老胶片扫描后的温润质地。
- **纸本绘画转动画质感**:先吸收传统绘画（工笔/年画/壁画/剪纸），再转成动画;画面同时有「画出来的」和「演出来的」双重气息。
- **纸张肌理与胶片颗粒**:背景常见细微颗粒与不均匀纹理，非无菌光滑的数码质感，而是有呼吸感的旧时代美术味。

### 三、角色造型

- **脸部**:古典提炼而非写实塑造。脸型修长或鹅蛋形，眉眼纤细、眼波内敛，鼻梁弱化，口唇小巧，表情克制宁静;接近工笔仕女、壁画人物、戏曲旦角、民间神像，带脱俗、静穆、非日常人间感。
- **姿态**:程式化、有礼法感。动作幅度小、重心极稳、身段讲究，靠姿态里的身份感与法相感立住角色，而非夸张动作。
- **服饰**:飘逸且符号化。长袖、披帛、流动衣摆多;轮廓大而缓;配饰精简但位置讲究;神仙 / 仙娥 / 帝君类靠高冠、璎珞、披纱、净瓶、法器等符号直接传达身份。
- **（女频轻喜适配）**:若需要轻松诙谐、女性向基调或 IP 化角色（如猫等灵宠），可在保持上美影造型骨架的前提下，弱化神性威严、增加圆润可爱与灵动表情，让角色更亲和;但线条、设色、质感仍严格遵循上美影语言。

### 四、线条语言

- 线条是造型本身，承担形体定义、气质塑造、节奏组织、装饰美感，而非单纯给色块收边。
- 来源于**传统白描与工笔**:线细而稳、走向流畅、粗细变化克制、有韵律不张扬（近书法中锋、工笔游丝描），比现代二次元的高反差粗细线更内敛「文气」。
- 线条服务于**装饰秩序**:衣纹、飘带、火焰、建筑纹样讲究节奏重复与均衡对称。

### 五、色彩风格

- **民族化概括**而非自然再现:先定整体主色调，再用少量对比色点睛，块面明确、关系清楚、画面完整不碎。
- **冷暖对照的东方神话配色**:青蓝 / 靛紫构成天界、夜色、空灵感;金黄 / 朱红 / 橙色构成香火、法坛、神性中心;白色负责洁净、超脱、仙气。整体是「冷色塑造天界与距离，暖色塑造香火与神圣」。
- **温润发色**:少见强金属高光，更像矿物颜料 / 重彩 / 染织的沉着、温润、古雅发色。
- **低饱和高级感**:整体饱和度偏低，避免俗艳与现代感。

### 六、场景与空间

- **舞台化**:空间为仪式与叙事服务，不完全服从真实透视。
- **中轴对称**常见:神殿、宫阙、法坛、宝座、屏风、柱列多做对称，带来威严、神圣、礼制、稳定感。
- **像庙宇也像戏台**:帷幕、宝座、香案、牌匾、法器、两侧分列的侍者，让角色「登场于象征性的神话舞台」而非「生活在真实场景」。
- **层次清楚但不写实**:有前中后景关系，但服从画面秩序;呈现「看似平面、实则层次分明」的东方装饰画特点。

### 七、光影

- 光影是**概括与象征**的，不是物理写实的。
- 常用**烛光、香火、光环、火焰纹**作为神性光源与画面暖色中心;亮部柔和泛光，暗部用概括色块压。
- 整体低对比、柔雾化，服务于空灵与庄严，而非塑造强立体感。

### 八、镜头与运动（视频时）

- 运镜**平稳、克制、缓慢**:缓推、缓摇、轻微升降为主，少剧烈甩镜。
- 动作**低幅度、定格感**:可带早期动画偏低帧率的顿挫与定格韵味，衣袖 / 飘带 / 烛火做轻柔飘动。
- 转场**仪式化**:定场—显圣—特写的节奏，强调登场感与庄重感。

### 九、故事与脚本基调建议

- 天然适配:国风神话、仙侠、志怪、民间传说、戏曲改编、古典寓言。
- 可承载**轻松诙谐、女频视角、IP 化萌宠**等基调:在庄严古典的美术底子上做「反差萌」，用可爱角色 / 俏皮台词软化神性威严，形成「古典画风 + 轻喜叙事」的独特气质。
- 脚本用词、场景命名、旁白语气也应带古典雅致感（如「显圣」「登坛」「仙娥」「灵宠」等），与画风呼应。

### 十、可直接取用的风格标签词

`上美影经典神话动画风`、`中国古典民族动画美术`、`工笔白描式线条`、`赛璐璐手绘上色质感`、`老胶片柔雾颗粒感`、`纸张肌理`、`中轴对称庙宇/法坛构图`、`戏曲化神仙造型`、`低饱和宝蓝冷调 + 金红神性点缀`、`庄严空灵古雅神圣`、`壁画年画宗教圣像融合感`、`平涂设色`、`概括柔雾光影`、`平稳克制运镜`、`定格韵味`。

## Agent 执行清单（每次生成图片 / 视频前自检）

1. ✅ 是否已把 **STYLE_ANCHOR 逐字放在 prompt 最前面**？（图片、视频都要）
2. ✅ 锚定词是否**一字未改**、未翻译、未删减、未调序？
3. ✅ 同一项目内所有素材的锚定词部分是否**完全一致**？
4. ✅ 锚定词之后的**具体画面描述**是否贴合了「风格知识库」的特征？
5. ✅ 若同时有其它**风格类**技能——是否已按规则**合并锚定词**（各自完整、放最前）？
6. ✅ 若同时有**非风格类**技能——是否做到**叙事听它、画风听我**？
7. ✅ 是否已**禁用 / 绕过 Agent 内置的风格锚定图**，风格只来自文字锚定词？
8. ✅ 生成工具里的「默认风格图 / 内置 style ref」是否已置空关闭？

只有全部 ✅，才允许提交生成。
