# 无参考图时3方向提案模板

> 可适配的模式与句式，按场景改写，不要逐字照搬。

如果用户没有参考图，只说"我要做软萌3D治愈动画"，不要停下来反复追问。直接提供3个方向。

## 方向1：动物治愈日常

- **适合角色**：小熊、小猫、小狐狸、小兔子、小企鹅等
- **故事核心**：分享、陪伴、等待、发现、安慰
- **典型场景**：雨后森林小屋 / 阳光花园 / 冬天壁炉旁
- **情绪线**：安静→好奇→试探→温柔→安心

## 方向2：幻想小生物童话

- **适合角色**：云朵精灵、星星精灵、蘑菇小人、小龙、小鹿、小水滴等
- **故事核心**：发光种子、星星掉落、月光小屋、森林秘密
- **典型场景**：月光下森林 / 星空小桥 / 云端小屋 / 发光蘑菇丛
- **情绪线**：安静→发现魔法→好奇靠近→温柔触碰→感动

## 方向3：小孩温馨生活

- **适合角色**：小女孩、小男孩、双胞胎、小朋友和小动物互动
- **故事核心**：撑伞、送花、烤棉花糖、窗边看雪、发现小生命
- **典型场景**：厨房窗边 / 花园小径 / 雪天门口 / 阳台花架旁
- **情绪线**：平淡→发现→想照顾→小心行动→满足

## 每个方向都要给

1. 角色设定（含具体外观描述、材质、配色）
2. 场景设定（含空间描述、材质、光线）
3. 小故事（含小事件、情绪弧线）
4. 情绪线走向
5. 视觉关键词（3-5个）

详细角色/场景/材质/配色句式见 `references/industries/<对应方向>.md`。

## 落 prompt 前自检

- 3个方向是否覆盖了3种不同角色类型？
- 每个方向是否有完整角色+场景+小故事+情绪线？
- 方向之间是否有足够差异（不是同一故事换了不同动物）？
