# 分镜图模板：营销转化 · 痛点-解决方案分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：围绕“用户痛点 → 产品解决方案 → 使用效果/结果”三段结构规划的营销分镜图，强调让观众先感受问题，再看到产品如何具体解决，并用前后对比完成转化闭环。
- **典型场景**：
  - 电商短视频、信息流广告中的“问题-解决”类脚本；
  - 功能型产品（清洁、收纳、效率工具等）的痛点故事片段；
  - 教育/服务类产品的案例故事，用用户困境带出课程/服务解决方案。

## 2. 判定关键词与适用边界
- 典型触发词：`痛点`、`解决方案`、`怎么改善`、`用了之后有什么变化`、`对比`、`前后变化`、`过去很痛苦`、`现在轻松很多`。
- 适用判定：
  - 用户描述中反复提到目标用户目前的困扰/问题，并希望“用某款产品/服务来解决”，强调“问题被解决后的效果”；
  - 需要清晰的前后对比画面或情境，从而推动观众产生行动（购买/咨询）。
- 不适用场景：
  - 只是简单展示产品外观与卖点，没有明确的痛点情景 → 更适合“产品讲解型分镜图”；
  - 以知识传播为主，只想解释原理而不强调买或用 → 可归为“教学科普分镜”或其他非营销类；
  - 纯情绪/剧情向故事，仅隐约出现产品、不强调转化 → 可归为剧情分镜或品牌故事分镜。

## 3. 分镜结构建议
- **推荐宫格数**：6–12 格，常见为 6/9 格，完整走完“痛点 → 方案 → 效果 → CTA”链路。
- **结构骨架**：
  1. 痛点引入（1–2 格）：交代角色、场景与困境状态，让观众产生共鸣；
  2. 痛点放大（1–2 格）：展示问题带来的具体后果或情绪压力，可用对比镜头；
  3. 解决方案亮相（2–4 格）：产品/服务登场，重点展示“如何解决”而非只说名称；
  4. 使用过程与关键卖点（2–4 格）：拆解使用步骤或核心功能，每格一个明确要点；
  5. 效果展示/前后对比（1–2 格）：使用后的结果画面，与前面的痛点形成强对比；
  6. 行动号召收尾（1 格）：Logo + Slogan + 核心利益点/优惠信息，引导购买或咨询。
- **规划方式**：
  - 先用一句话写出链路：“[受众] 以前因为 {核心痛点} 很困扰，现在用 {产品名称} 后 {效果结果}”，再把这句话拆进各宫格；
  - 痛点段多用生活化场景与表情特写，方案段多用产品特写与操作步骤，效果段强调空间变干净、状态变轻松等可见变化；
  - 保证至少一格专门承载最终结果与 CTA，不要把行动号召完全塞在画面角落。

## 4. 生图 Prompt（PE）模板

```text
你是一名品牌营销分镜师，请为下述 {产品名称} 设计一张 {宫格数} 宫格的“痛点-解决方案分镜图”（用途类型 = 痛点-解决方案分镜），整体画幅为 {画幅比例说明，如“9:16 竖屏信息流广告”或“16:9 横版品牌广告”}。

【产品与受众信息】
- 产品品类：{如清洁喷雾/收纳工具/效率软件/线上课程等}
- 产品名称或系列：{产品名称}
- 核心解决方案：{一句话说明这款产品如何解决问题}
- 目标用户：{如“租房上班族/精致妈妈/大学生/自由职业者”等}

【痛点洞察】
- 核心痛点：{1–3 条具体困扰，如“家里总是很乱”“做事拖延效率低”等}
- 痛点场景：{痛点最典型发生的生活场景，如“早晨出门前”“打扫房间时”等}
- 情绪基调：{如“焦虑/疲惫/心累/尴尬”等}

【使用场景与效果】
- 使用场景：{产品实际使用的关键场景}
- 使用步骤：{简要列出 2–4 个关键操作步骤}
- 使用后效果：{1–3 条可见变化，如“房间变整齐”“时间利用更高效”等}
- 行动号召信息：{优惠/限时活动/关键 CTA 文案，如“立即下单”“扫码领取课程”等}

【分镜排布】
- 宫格数量：{宫格数，如 6/9/12 格}，按阅读顺序编号 P1–P{N}。
- 推荐结构：痛点引入 → 痛点放大 → 解决方案亮相 → 使用过程与卖点 → 效果展示 → CTA 收尾。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 P1 到 P{N} 的分镜要点（每格对应的痛点/解决方案/效果与卖点），供用户确认；确认后再按以下格式，为每格写出详细中文分镜说明：
1. P1：
   - 场景与人物：{谁在什么场景中遇到什么困扰}
   - 痛点表现：{身体动作/表情/环境细节如何放大痛点}
   - 文案/旁白：{一行痛点文案，如“每天找东西都要翻半天”}
2. P2：
   - 场景与人物：{痛点继续或升级的画面}
   - 痛点表现：{更具体的困扰或后果}
   - 文案/旁白：{补充痛点或情绪话语}
……
直到 P{N}，确保完整走完“痛点 → 方案 → 使用过程 → 效果 → CTA”链路，每格清楚写明该格的核心信息（痛点/方案/效果/行动号召）。

【画幅与风格约束】
- 画面比例：{9:16 / 16:9}，默认 9:16 适配信息流与电商场景。
- 画风：{写实棚拍/生活化摄影/3D 渲染/插画等}，整体色调与品牌调性一致。
- 要求人物/场景与产品外观在所有格中保持一致，仅在“效果展示”段适度改变环境状态（变干净/变整齐/变轻松），禁止更换主角或产品型号。
```

## 5. 一致性与避坑
- 确保“痛点 → 方案 → 效果”链路在宫格顺序上清晰可读，不要出现方案先于痛点或效果不明确的情况。
- 痛点段的情绪要真实但不过度夸张，避免负面情绪过重影响品牌好感；保持生活化细节而非空洞抱怨。
- 产品外观、Logo、包装信息在方案与效果段所有格中保持一致，有参考商品图时严格对齐。
- 效果展示段一定要有明确的视觉对比（前后状态、环境变化、角色表情变化），避免只通过文字说明“好很多”。
- CTA 文案与画面要预留足够空间，避免被复杂背景或其他元素遮挡；价格/优惠信息不要与痛点段混杂，统一放在收尾格。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”营销执行模板：
  - 在 plan 与分镜阶段先按“痛点-解决方案”结构写出文字分镜列表，并通过本模板生成多宫格分镜图；
  - 在视频阶段沿用同一链路，将 P1–P{N} 作为时间轴参考，确保每个痛点、每个解决方案和每个效果格都有对应画面段。
- 视频生成时优先走“参考图生视频”路径：
  - 选取痛点段、解决方案亮相段、效果展示段和 CTA 段中的关键格作为参考帧，锁定人物、场景和产品外观；
  - 使用 `storyboard-sheet-prompt.md` 中的产品讲解视频 PE 模板，将“痛点引入/卖点展开/结果与行动号召”字段填入，对齐 {时长秒数} 秒视频的开头、中段和结尾。
- 镜头节奏建议：前 1/3 时长用于痛点与情境铺垫，中间 1/3 用于解决方案与卖点拆解，最后 1/3 给足效果展示与 CTA；避免痛点段过长或 CTA 一闪而过。
- 若用户提供完整商品精修图或环境素材图，需在视频 Prompt 中显式声明“严格保持参考图中的产品外观与场景结构”，并在 plan 中引用 assets/ref-image-design.md 与 assets/character-lock.md 的锁定规则，防止人物或产品在视频中漂移。
