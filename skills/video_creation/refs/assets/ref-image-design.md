# 参考图设计与生成指南(风格锚定 + 人物 + 场景)

本指南解决参考图质量问题的两个根因:①**把抽象的角色/场景描述翻译成可被生图模型精准落地的物理白描 Prompt**——模型只会画它"看得见"的物理实体,看不见抽象气质/氛围,看不懂技术黑话;②**同一风格描述下多张图风格漂移**——文字风格描述是一对多映射,每次采样落点不同,必须用风格概览图做图像层锚定。

**阅读规则**:下方【通用红线/通用强制规则】所有参考图共用,**必读**;§〇 风格锚定与生成流程在多段/多素材任务时必读(单段例外补图可跳过);§一 人物专章、§二 场景专章按需读。

## 通用红线(所有参考图共用)

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 抽象风格/氛围/情绪词(赛博朋克感/高级感/神秘感/科幻感/唯美) | 模型无法落地,画风随机漂移 | 拆解为可见物理实体:空间几何/材质/纹理/固有色/结构 |
| 技术黑话(8k/photorealistic/RAW/V-Ray/Unreal/85mm/电影感光影) | 在描述里制造语义噪声,挤占有效信息 | 用生活经验级物理白描还原干湿/新旧/松紧/软硬 |
| 非写实画种下沿用摄影语言(色温K值/体积光/三层纵深/材质物理质感),风格词只缀在末尾 | 文字权重压过风格锚,出图变成"写实场景+一点风格色" | 按 §〇.4 切换为画种程式语言,风格块置顶,摄影词进负向 |
| 在参考图里嵌文字/标签/数字/箭头/辅助线/几何标注 | 文字混入画面,污染参考 | Prompt 末尾必写"禁止生成任何文本、标注、字幕" |

## 通用强制规则

1. **物理白描而非技术修饰**:用具体动词和形容词精准还原物体表面的客观状态(如"领口泛黄""风化青砖""地面积水反光"),禁用"次表面散射、精致雕刻、完美比例"等浮于表面的技术词。
2. **抽象概念必须物理化拆解**:风格/氛围/气质词一律先降维成客观物理载体,公式 `[部件] + [具体材质] + [固有色/纹理]`(如"科技感"→"拉丝金属墙面、几何光导纤维暗纹";"古风沧桑"→"风化青砖、剥落的朱砂矿物颜料")。
3. **模式判定先行**:写任何参考图 Prompt 前,先按项目风格定位判定渲染模式,**二选一、严禁混写**——
   - **A 写实模式**(实拍电影感/写实 CG):按本文件全部规则执行;
   - **B 风格化模式**(国画/水墨/版画/皮影戏/赛璐璐/像素等非写实画种):§二 场景强制规则 5、6 及模板光影行**被 §〇.4 覆盖**,其余规则(空镜/机位/骨相/常态化/道具留白/禁文字)与画种无关,继续生效。
4. **白描对象随模式切换**:A、B 两模式都是物理白描,区别只在对象——A 模式白描**画面里世界的物理**(材质、光影、纹理);B 模式白描**画作本身的物理**(技法、颜料、载体:平涂、勾线、晕染、绢纹)。禁止的从来是抽象词与跨模式混写,不是白描本身。

# §〇 风格锚定与素材生成流程

机制:用一张**风格概览图**(style anchor)做全链路风格基准,所有人物/场景参考图并行引用它生成。风格锚不是滤镜——Prompt 写法不随模式切换,文字会压过参考图(§〇.4,本节最高频翻车点)。

## 〇.0 适用判定

| 条件 | 动作 |
|------|------|
| 多镜头/多素材任务 + creative_design.md 有统一视觉风格要求 | 启用风格锚定 |
| 单段任务 / 无风格统一要求 | 跳过本节,直接按 §一/§二 生成 |
| 系列/多集项目已有落盘锚点 | 跳过第 0 轮,直接读取复用 |

## 〇.1 风格概览图设计

定义:整条素材链**第一张**生成的图,唯一职责是定义"这部片子的世界长什么样"。确认后落盘为 `style_anchor.png`。

| 设计原则 | 要求 | 不做的后果 |
|---------|------|----------|
| 材质词汇表覆盖 | 从 creative_design.md 提取本片高频内容元素塞进概览图。**A 写实模式:只放场景侧元素**(建筑/器物/材质/环境光/配色基调),**禁止出现人物面部/身体**——写实风格下人脸会泄漏进下游角色图,且色板/材质/光影用纯场景即可充分示范。**B 风格化模式:场景侧 + 人物侧**(五官可辨的泛指人物),因为勾线/笔触/渲染程式只在具象题材上显形 | 概览图没示范的内容域,下游生成回落到模型默认先验,风格断裂 |
| 内容原型化 | 人物(B 模式下出现时)与场景无名无情节(泛指人物、泛指环境) | 具体身份与构图泄漏进下游 |
| 光线中性 | 柔和漫射、无投影、无特定时段光效(画种自带光线程式的,按程式写) | 锚点光线特化污染全链路(夜景锚把白天戏带脏) |
| 风格信息显性化 | 笔触/勾线/质感在画面中真实可见(皴法笔触、勾线、绢纹纸纹),不能只靠抽象风格词 | 只有色板被迁移,风格锁定退化成调色滤镜 |

**预置锚定图优先**:第 0 轮开始时,先查 `creative/style-master.md` 速查表中匹配风格行的「预置锚定图」列。有路径且文件存在 → `sandbox_bash` cp 到 `assets/{project}/style_anchor.png`,跳过下方生成流程,直接进入第 1 轮。值为 `—` 或风格不在速查表中 → 走下方生成流程。

**确认环节**(仅生成流程,预置锚定图跳过此步):出 2~4 张候选 → 默认 Agent 按自检清单选定;高成本项目(长片/多集)弹给用户挑选 → 落盘。锚点平庸,后面全部锁死在平庸上。

**禁止形式抽象化**:不要把概览图做成色板/纹理样片。B 模式下风格的多数要素只在具象题材上显形(勾线怎么处理一张脸、皴法怎么画山石),抽象样片给不了这些信息,且"抽象"本身可能被当作风格迁移。A 写实模式下虽然不放人物,但场景必须是具象的实景(带具体材质纹理的房间/街道/环境),不是抽象色块。

## 〇.2 素材生成流程

```
第 0 轮   查 creative/style-master.md 速查表「预置锚定图」列
          ├─ 有路径且文件存在 → cp 到 style_anchor.png,跳过生成
          └─ 无预置图 → 生成候选 → 确认 → 落盘 style_anchor.png      (每项目一次,跨集复用)
━━━━━━━ 阻塞点:style_anchor.png 落盘后才能进第 1 轮 ━━━━━━━
第 1 轮   全部人物参考图 ∥ 全部场景参考图,全并行
          每张引用 @style_anchor,引用语见 〇.3
分镜阶段   引用对应实体参考图(风格已烘焙进实体图),不再携带概览图
          唯一例外:无实体空镜 → 直接引概览图
```

**第 0 轮与第 1 轮之间是阻塞点,禁止同批并行**。"第 1 轮全并行"指第 1 轮**内部**各张之间并行,不含第 0 轮的锚点。把锚点和参考图放进同一批调用 = 风格锚定当场失效:参考图 ImageList 里的 `@style_anchor` 指向尚未落盘的文件,该批全部退化成无锚生成,而出图看起来正常、不报任何错,只在下游发现风格不统一时才暴露。

**发第 1 轮前的自检**(一步,必做):确认 `assets/{project}/style_anchor.png` 已存在(cp 或生成落盘均可)。不存在就不发第 1 轮。

| 变体情况 | 调整 |
|---------|------|
| 本片主场景天然含人物近景、元素覆盖足够 | 主场景参考图兼任概览图,省一张专职图 |
| 标定发现"概览图 → 人物"风格迁移差 | 升级三轮:第 1 轮先出主角图(引概览图),其余角色第 2 轮引主角图(串行深度 +1) |
| 某张参考图风格漂移 | 先查 Prompt 是否违反 〇.4(最常见根因)→ 再调参考强度 → 只重生成该张,不动锚点 |

## 〇.3 锚点引用语(固定话术,不得简写)

**CRITICAL**:ImageList 传入 `@style_anchor` 后,**Prompt 文本中必须包含 `@图片N` + 引用语句**,否则模型不知道如何使用该参考图。仅传 ImageList 而不在 Prompt 中写 `@图片N` 引用 = 参考图无效。

- **场景图引用**:Prompt 中写"仅参考@图片N的画面风格、色彩与笔触质感,不参考构图与具体人物"
- **人物图引用(A 写实模式)**:锚点本身不含人物,引用语与场景图相同——"仅参考@图片N的画面风格、色彩与材质质感,不参考构图"
- **人物图引用(B 风格化模式)**:"仅参考@图片N的画面风格、色彩与笔触质感,**严禁参考人物五官、体型与构图**"——锚点中含泛指人物,角色设定稿是最易被其污染的环节,引用语必须写满

## 〇.4 B 风格化模式编写规范

核心认知:**风格锚不是滤镜**。Prompt 主体用摄影语言时，文字权重压过参考图，模型画出"写实场景 + 一点风格色"。

强制规则:
1. **风格块置顶**:画种 + 载体质感 + 构成方式 + 技法 + 光影总程式写在 Prompt 第一行(§一/§二 模板中"{风格关键词}"在末尾的写法,B 模式下作废)
2. **摄影词汇全禁**:色温/K 值、光源方向与投影、体积光/丁达尔、镜头焦距/景深、3D 纵深、材质物理质感——一律不写,并加入负向清单
3. **光影程式化翻译**:不描述光,把光翻译成画种程式;物体用技法语言描述(`[部件]+[技法]+[画种色板固有色]`);时段/天气程式化(夜 = 深色平涂底 + 留白月);色彩限定收口(Prompt 末段列画种色板防漂移)
4. **负向固定项**:写实摄影、3D 渲染、电影光效、体积光、镜头景深(原有"无人物、无文字"约束不变)

**B 模式场景模板**(替代 §二 模板,所有场景默认俯拍):B 模式场景模板 = §二 A 模式对应模板的三处变换:(1) 风格块置顶;(2) 光影行替换为「无明暗体积塑造、无投影、无光束」;(3) 末尾追加「色彩限定:{画种色板}」与负向清单「写实摄影、3D 渲染、电影光效、体积光、镜头景深」。

**B 模式下的人物图**:§一 全部规则保留(无背景/四视图/骨相/常态化),仅渲染描述切换为技法语言(肤色以淡赭轻染、衣纹勾线填色),"纯白背景"可改为画种底色(如绢本米白),"{风格关键词}"按本节规则 1 置顶展开。

## 〇.5 标定与自检

**标定**(每接入新生图模型或新画种做一次):概览图出 4 选 1 → 3 个异质 Prompt 各生成一张检查四要素迁移(色板/勾线笔触/载体质感/光影程式) → 泄漏反查(有构图或人物泄漏则降参考强度)。

**出图自检追加一条**:对照锚点检查风格四要素,任一不符 → 按 〇.2 失败回滚处理,先查 Prompt 模式再调强度。

## 〇.6 风格类失败模式速查

| 失败 | 根因 | 修法 |
|------|------|------|
| 出图是"写实场景 + 一点风格色" | Prompt 混写:摄影词汇 + 末尾风格标签 | 切 B 模式:风格块置顶、摄影词进负向、光影程式化 |
| 某内容域(夜景/室内/器物)风格断裂 | 概览图材质词汇表未覆盖该域 | 高频域:补进概览图重生成锚点;低频域:该张 Prompt 按 〇.4 写满程式细节兜底 |
| 下游出图复读锚点构图/人物 | A 模式锚点含人物面部(应纯场景),或参考强度过高,或引用语缺失 | A 模式:锚点改为纯场景图重生成;B 模式:降强度+按 〇.3 强化引用语 |
| 整链风格统一但平庸 | 锚点确认环节缺失或敷衍 | 锚点必须 N 选 1,高成本项目交用户确认 |
| 多集之间风格漂移 | 每集重新生成锚点 | 锚点落盘,跨集复用同一文件 |

# §一 人物参考图

## 人物红线(高频翻车点)

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 提示词出现背景/场景/天气/地点("宫殿中""月光下""废墟背景") | AI 画出环境抢戏,干扰主体,参考图掺入杂物 | 角色提示词**只描述角色本体**,零背景 |
| 笼统脸型词(锥子脸/方脸/瓜子脸/心形脸) | 所有角色撞脸,千人一面 | 骨相矩阵差异化:面部折叠度+颅骨比例+下颌角折角+皮肉包裹度 |
| 用暴露/深V/短裙表现落魄悲惨 | 低俗,且不符合角色所处时代的着装礼仪 | 只能靠服装**物理损耗**:褪色/撕裂脱线/陈年污渍/材质降级 |
| 擅自给角色加伤疤/血迹/擦伤 | 偏离设定、不可控、面部脏污 | 除非明确写有伤,**面部必须干净无伤** |
| 瞬时动作/表情(奔跑/低头/弯腰/尖叫/流泪) | 设定图不稳定、姿态怪异、无法做通用参考 | 常态化基准:双足平踏地面、挺拔站立、中性放松表情 |
| 把剧情状态写进设定图("因熬夜眼下青黑""头发凌乱""指甲啃咬痕迹""嘴角上翘") | 生图模型夸大状态描述,出图满脸黑眼圈/蓬头垢面/诡异表情,无法做通用参考 | 设定图只写角色**出厂默认外观**:健康肤色、整洁发型、中性表情、干净指甲。剧情状态(疲态/邋遢/诡异)留给视频 Prompt 在对应镜头中描写 |
| 四视图中的全身视图只画上半身或裁切到腰 | 缺下半身,无法做全身镜头参考 | 正面/侧面/背面三个全身视图从**头顶完整到脚尖**,严禁裁切下半身 |

## 人物强制规则

1. **先判定个体/群像**:四视图只服务"同一个人"的身份锁定。名称或描述是群体/类型角色时(如孩童、老人、村童们、村民、路人、围观群众、士兵队列),按"群像/类型角色例外"生成群像类型参考图,禁止套四视图。
2. **角色无背景原则**:参考图提示词**只描述角色本体**,绝对禁止任何背景、场景、地点、天气、建筑、自然环境、时代世界观、故事情节。
3. **抽象词必须物理化**:风格/情绪/气质词一律先转成可见的物理实体——材质、服装结构、色彩、纹样、饰品、发型、妆容、五官细节。
4. **物理白描而非技术黑话**:见通用强制规则 1。
5. **由头到脚连贯白描**:外观描述是一段**由头到脚空间顺序流动**的中文,逗号无缝衔接,**严禁拆成"基本信息/服饰装备/配饰"等标签模块**。按下方 7 段顺序组织。
6. **解剖级骨相反同质化**:禁用笼统脸型词,必须用【面部折叠度】+【颅骨比例】+【下颌骨折角】+【皮肉包裹度】组合出独一无二的脸(见骨相矩阵)。
7. **着装底线**:落魄/战损/贫困**只能**用服装物理损耗(褪色斑驳/边缘撕裂脱线/陈年污渍/不规则缝线)、穿搭状态(外袍半褪但内衬严实包裹)、材质降级(粗布麻衣取代绫罗)表达,严禁衣不蔽体,须符合角色时代的着装礼仪。
8. **面部洁净度**:除非明确写出面部有伤,否则无论角色经历多坎坷,**绝对禁止**擅自添加伤疤/血迹/擦伤。沧桑感只能通过服装损耗、眼神聚焦、发丝干枯表达。
9. **常态化基准**:设定图是角色的**出厂默认态**,拒绝一切非默认状态——包括瞬时动作(低头/弯腰/下蹲/踉跄)、瞬时生理状态(汗湿头发/流泪/气喘)、夸张情绪(尖叫/大哭/瞪眼/挑眉),以及**剧情驱动的持续性状态**(黑眼圈/暗沉/蓬乱头发/啃咬指甲痕迹/嘴角上翘/面部肌肉紧绷)。判据:**这个特征是角色天生就有的,还是剧情赋予的？** 天生的写,剧情赋予的不写——留给视频 Prompt 在对应镜头描写。人物必须**双足平稳踏地、挺拔端正站立、平视镜头、中性放松表情、发型干燥整洁且结构清晰、肤色健康、指甲干净**。
10. **风格锚定(启用时)**:ImageList 传入 `@style_anchor`,引用语按 〇.3 对应模式版本选用;B 风格化模式下的模板调整见 〇.4 末段。

## 群像/类型角色例外

四视图只服务"同一个人"的身份锁定;群像参考图服务"同一类人"的风格和造型约束。

**命中判定**:满足任一条件时,按群像/类型角色处理,禁止生成四视图:
- 名称或描述带集合语义:孩童、老人、村童们、村民、路人、围观群众、士兵队列、一群人、众人、3-4名等;
- 没有姓名、没有独立台词,观众不需要跨镜头识别为同一个具体人物;
- 描述重点是年龄层、阶层、时代服饰、群体行为或氛围,而不是单个角色的脸、发型、服装精确锁定。

**反向例外**:群体词如果实际指向固定主角或重要配角(有姓名、反复出现、承担独立行动/台词),仍按个体角色生成四视图。

**生成格式**:
- 画面中包含 2-4 个不同个体,超过 4 人先拆成多张群像参考图;
- 中景或中近景展示全身/大半身,自然站立、坐姿或轻微互动,人物之间有自然间距;
- 同组人物年龄层、服饰时代、发型和气质一致,但五官、身形、表情有轻微差异,禁止复制粘贴式相同长相;
- 背景纯色或极简,不出现复杂场景;追逐、嬉戏、围坐共享天伦等剧情动作留给视频 Prompt,参考图只保留可持续姿态;
- 文件命名 `character_xxx_group.png`,比例跟随视频最终比例或 16:9。

**群像参考图 Prompt 模板**:
```
{群体类型}的群像类型参考图,画面中包含{2-4人数量}名不同个体,
中景/中近景展示全身或大半身,人物之间有自然间距,
每个人年龄层、服饰时代、发型和气质符合设定,但五官和身形有轻微差异,禁止复制粘贴式相同长相。
背景保持纯色或极简,不出现复杂场景。
{风格关键词}。
禁止生成任何文本、标注、字幕。
比例:{跟随视频比例或16:9}
```

## 固定参考图格式:四视图角色设定稿

同一角色的人物正面特写和三个完整全身视图,横向排列:

| 视图 | 朝向 |
|------|------|
| 人物特写 | 角色正面头肩特写,只显示头部至肩部,不显示腰部、腿部和脚 |
| 正面 | 角色面向镜头 |
| 侧面 | 角色面向画面左侧 |
| 背面 | 角色背对镜头 |

- 四视图角色特征及服装细节**完全一致**,自然站立、平视镜头
- **正面/侧面/背面三个全身视图必须从头顶完整展示到脚尖,严禁裁切下半身或只画半身**
- 纯白色背景,均匀平光照明,无明显阴影(B 模式可改画种底色,见 〇.4)
- 服装材质细节与轮廓线条清晰,色彩准确一致
- 比例 **16:9**
- 文件命名 `character_xxx_sheet.png`

> 四视图横排会压缩单个人物的纵向空间,是裁切高发场景——Prompt 里"正面/侧面/背面三个全身视图从头顶到脚尖、严禁裁切下半身"是必写的兜底约束,不能省。

## 同一角色多形象（仅多段流程）

本节只服务多段 `creative_design.md` 已声明的同角色多形象。单段流程不进入参考素材生成，不适用本节；素材阶段不得自行增加形象。

1. **唯一基础形象**：每个多形象角色必须有且只有一个基础形象，文件命名 `character_xxx_base_sheet.png`。用户素材未明确绑定具体形象时默认作为基础形象；用户已明确绑定变化形象时保持其绑定，不得改作基础形象。
2. **先基础、后变化**：先生成或确认基础形象，完成身份、构图完整性和风格自检并写回素材绑定关系后，才能生成变化形象。不同角色的基础形象可并行；基础形象通过后，同一角色的多个变化形象可并行。
3. **变化形象必须直引基础形象**：每个变化形象的 ImageList 必须传入该角色基础形象，启用风格锚时同时传入 `style_anchor`。禁止引用另一个变化形象继续派生，避免身份特征逐代漂移。
4. **只改声明变化项**：Prompt 逐字承接 creative_design.md 的身份锚点、保留项和变化项。骨相、五官比例、瞳色、不可替换标记等身份锚点必须保留；仅替换服装整体、年龄阶段、形态/物种状态、妆造等已经声明的显著变化项。
5. **四视图规范不变**：基础形象和每个变化形象都按本节前述四视图规范生成，变化形象文件命名 `character_xxx_{appearance}_sheet.png`。表情、姿势、光线、脏污、轻微伤痕、小配饰或局部颜色变化留给视频 Prompt，不单独生成形象图。

**变化形象 Prompt 前缀（固定话术）**：

```text
参考@图片1为{角色名}的基础形象，当前仍是同一角色。严格保留{身份锚点}，并保留{保留项}；只将{变化项}替换为当前形象定义，禁止改变未列明的五官、骨相、体型和身份标记。
```

启用风格锚且基础形象排在 ImageList 第一张时，`style_anchor` 顺延为 `@图片2`，再追加 §〇.3 对应的风格引用语；基础形象始终是身份来源，风格锚不得覆盖身份特征。

**生成后自检**：将基础形象与所有变化形象并排核对。身份锚点缺失或被改写 → 只重生成失败的变化形象；变化项未显著落地 → 强化变化项后重生成；差异仅为表情、姿势、光线、小配饰或局部颜色 → 删除该变化形象，把差异下沉到对应视频 Prompt。禁止为修复变化形象而重生成已经通过的基础形象。

# §二 场景参考图

场景图是一张**纯空镜环境概念图(Environment Concept Art)**,为视频提供环境底板或镜头关键帧。核心是空镜、客观物理化、电影级纵深(A 写实模式;B 风格化模式的纵深与光影按 〇.4 程式化)。

## 场景红线(高频翻车点)

| 错误写法 | 后果 | 正确写法 |
|---------|------|---------|
| 画面出现人物/人群/动物/背影/剪影 | 视频生成时误当角色参考 | **纯空镜,零人物**,Prompt 明写"无人物、无人影、无剪影" |
| 把文本指定机位擅自拉成远景全景 | 丢失文本要的近景/遮挡/狭窄透视 | 严格按文本机位/视角/焦距 |
| 抽象氛围词(神秘感/科幻感/唯美大气) | 模型无法落地 | 物理化为空间几何/材质/纹理/固有色 |
| 只写"月光"或"暖光" | 光源方向/色温不明 | A 模式:光源方向+色温+阴影+空气感;B 模式:按 〇.4 程式化 |
| 瞬时动态事件入图(酒液流淌/火星迸溅/器物坠落) | 底板无法复用,视频起点被锁死 | 物体处于稳定可持续状态(炭火明红/雾气弥漫),动势留给视频 Prompt |

## 场景强制规则

1. **绝对空镜**:Prompt 必含"无人物、无人影、无剪影、纯空镜场景"
2. **机位尊重**:严格按文本描述的机位和视角,**严禁擅自拉开远景**
3. **客观物理化**:抽象概念降维为客观物理载体,公式 `[场景部件] + [具体材质] + [固有色/纹理]`
4. **电影级纵深【仅 A 写实模式】**:前景/中景/远景三层(B 模式:以色彩渐淡/剪影/留白分层,见 〇.4)
5. **光影与材质【仅 A 写实模式】**:光源方向+阴影对比+空气感+材质物理质感(B 模式:按 〇.4 程式化)
6. **比例感知**:场景图比例与视频最终比例一致
7. **静态常态基准**:一切物体处于稳定可持续常态,禁止进行中的瞬时动态事件;可持续环境状态可保留(炭火明红/烛光/雾气/积水)
8. **道具留白**:只画固定环境要素,角色将交互的小道具(杯盏/兵器/信札)**不入图**,交视频模型即时生成
9. **禁文字标注**:Prompt 末尾必写"禁止生成任何文本、标注、字幕"
10. **风格锚定(启用时)**:ImageList 传入 `@style_anchor`,引用语用 〇.3 场景版

## 场景描述组织

**俯拍底板**按空间层级用短句组织(由整体到局部):整体空间形状与主要分区 → 核心主体(建筑/景观 + 材质 + 固有色) → 地面材质与家具/物件分布 → 光区与暗区分界 → 出入口/边界。杜绝长句。

## 抽象氛围词 → 物理载体 转换示例(场景)

| ❌ 抽象词 | ✅ 物理载体 |
|----------|-----------|
| 科技感 | 拉丝金属墙面、几何光导纤维暗纹、高精密碳纤维外壳 |
| 古风沧桑 | 风化的青砖岩石、剥落的朱砂矿物颜料、长满苔藓的榫卯结构 |
| 神秘感 | 低照度环境、局部漏下的光斑、弥漫的雾气体积光、暗部偏冷的固有色 |

## 机位选择

场景底板默认**高角度俯拍**(约 45°),无论室内室外。俯拍能暴露完整空间布局(室内:家具分布/门窗朝向;室外:地形走势/道路走向/植被分布),视频模型切换到任意景别/机位时都能从底板中提取空间线索,跨视角一致性显著优于平视底板。

| 场景类型 | 默认机位 | 原因 |
|---------|---------|------|
| 室内/庭院/有限封闭空间 | 高角度俯拍(约 45°) | 暴露平面布局:家具分布、柱子位置、门窗朝向 |
| 室外街道/村落 | 高角度俯拍(约 45°) | 暴露路网走向、建筑分布、空间纵深关系 |
| 山川/旷野/海洋 | 高角度俯拍(约 45°) | 暴露地形走势、道路走向、植被/岩石分布 |

镜头专用关键帧(特定机位/前景遮挡的精确控制,对应 `review/quality-control.md` 关键帧策略)不受此限,按需选择任意机位。

## 场景失败模式

| 失败 | 后果 | 修法 |
|------|------|------|
| 场景图混入人物/人影 | 视频误当角色参考 | 纯空镜,生成后检查,有人必重做 |
| 凝固的运动瞬间 | 视频被锁死 | 静态常态基准 |
| 交互小道具入图 | 道具分身 | 道具留白,小道具由视频 Prompt 生成 |
| 场景图比例与视频不符 | 二次裁剪变形 | 比例跟随视频最终比例 |
| 室内场景用平视底板,视频切仰拍/俯拍时空间身份丢失 | 模型重新想象空间,跨视角环境不一致 | 所有场景底板默认高角度俯拍,暴露空间布局 |
