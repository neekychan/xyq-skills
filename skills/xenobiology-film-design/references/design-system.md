# 异生视觉设计系统（方法层）

本文件只负责**把视觉语言转成原创设计图资产、提示词与交付物的方法**。所有美学决策以其它文件为准，避免重复与冲突：

- **纯真人电影质感、真实材质、物理光线与默认无魔法光效** → 每个项目先读 `live-action-cinematic-lock.md`，且它优先于本文件及旧的「仙气/风格化」表述。
- **角色/异生物造型、配色、镜头、原型、示例 prompt、融合呈现分级** → 一律遵循 `series-visual-grammar.md`（类人可读 + 人-生物精致融合：人像优先 + 一组有物种逻辑的明确漂亮主锚点 + 真实连接与可拍材料 + 现实可穿着的设计服装 + 真实空间；主锚点可由一项辅助材料/服装/环境线索支持，不要求堆满全部物种特征；避免血浆、溃烂、外露内脏、密集孔洞、卡通怪兽，也避免「被感染」的病灶感和油塑料 CG 材质）。
- **泛白雾面调色** → 遵循 `milky-fog-grade.md`，按需加挂，不在本文件复制其模块。

本文件只补充三样 `series-visual-grammar.md` 未展开的通用工具：全片视觉契约、三段呈现层次、交付格式。角色设计图由用户在角色内环选择横屏 16:9 正背双视图（左正面、右背面，均到腰线下方或大腿上段）或竖屏 3:4 单人肖像（单一连续构图，头顶至腰线下方或大腿上段）；场景气氛图统一横屏 16:9。默认交付以「实拍相机测试」而非概念设定板呈现；用户明确要求概念化时才放宽。

## 0. 全流程单一视觉真源

本文件中的视觉契约必须成为当前对话唯一的 `MASTER_VISUAL_LOCK`，而不是一份仅供结项阅读的说明。建立后，角色设计、场景气氛、关键帧、镜头建议和交给 video creation 的每条视频提示词，均以它为前置硬约束；任何创作输出不得只保留剧情/动作信息而遗失介质、色光、空气、材质、光源、摄影和禁忌。

最小字段为：`MEDIUM | WORLD | PORTRAIT | BEAUTY_PROFILE | HAIR_MAKEUP | PALETTE_HARMONY | MATERIAL | ANCHOR_TOPOLOGY | COSTUME | GRADE | AIR | LIGHT | ROLE_ASSET_FORMAT | CAMERA | EXCLUSIONS`。`PORTRAIT` 默认锁定漂亮、真实、个体化的亚洲面孔；用户明确指定欧洲或其他面孔时覆盖。`BEAUTY_PROFILE` 给所有性别表达同级选角、脸部、妆发、服装、取景面积与雾面调色；男性角色明确为俊美、精致、有辨识度的亚洲男性异生体。`HAIR_MAKEUP` 与 `PALETTE_HARMONY` 要求先定服装主色和锚点材质，再选择自然色、邻近色或已有色的发色；深衣深发通过材质、轮廓补光和背景明度分层，不默认银白浅发。`ANCHOR_TOPOLOGY` 锁定主锚点准确数量、根部、比例、朝向、折叠和遮挡；收拢翼不得另有竖立小翅、孤立翅片或第二套翼。`ROLE_ASSET_FORMAT` 由用户按角色选择横屏 16:9 正背双视图或竖屏 3:4 单人肖像，同一角色默认只选其一。`GRADE` 锁的是柔和冷环境底、低饱和中间调、抬起石墨阴影、珍珠乳白高光、清透肤色与均匀空气感，而不是把所有对象染蓝；角色背景默认雾蓝，也可使用相邻冷灰、灰绿或珍珠色。其余字段维持纯真人、实体材料、有动机光源与无魔法光效的底线。**角色设定图也必须继承，且其背景优先稳定使用低饱和雾蓝**；`MEDIUM`、`LIGHT`、`CAMERA` 与 `EXCLUSIONS` 必须维持纯真人电影写实底线。

用户修改视觉方向时，只更新这一份锁并将其替换到后续全部创作内容；剧情、镜头或地点的迭代不得擅自改动它。交接 video creation 时，先原样交付 `MASTER_VISUAL_LOCK` 并标为「逐镜生成前置硬约束」，再给参考图、镜头与动作。

## 1. 全片视觉契约

先写一句能约束所有画面的总述，再锁定下列变量；写成**全片锁定词**，原样挂到每条 prompt 末尾（与 `series-visual-grammar.md` 的 WORLD/PORTRAIT/BIOLOGY/COSTUME/LIGHT/CAMERA 锁定词保持一致，不要另起一套）。

示例总述：

> 一个与某种壳质海洋生物融为一体的美丽异生命，使用可被实拍捕捉的壳层、织物、雨后反射与假体连接，穿一件贴合壳色、端庄宽松、完整覆盖全身的现实可穿着长衣，在仍有人生活的旧公寓里出现；异生锚点调动了该物种的完整语汇，像本就长在这具漂亮人形上一样成体系。

| 变量 | 需要决定什么 | 推荐基调 |
| --- | --- | --- |
| 融合生物 | 用哪类生物、选择哪一组主锚点 | 壳/螺/蚌、蛾/鳞翅、两栖、直翅/节肢、蕨/苔等；每部短片只选 1 种主物种，先选**一组最有分量的主锚点**（如收拢蛾翼、肩背壳层、臂部鳍膜），再至多用一项材料/服装/环境线索支持它。头脸默认不叠加触角、复眼或额部器官。 |
| 空间母题 | 融合体在哪里出现 | 走廊、排水口、门缝、柜体、雨棚、旧浴室；选 2–3 个反复出现 |
| 材质三联 | 什么使它一眼属于此世界 | 从鳞粉、壳层、珍珠层、磨砂鳍膜、潮湿织物、苔藓或树皮里选，只选 3 种；写清厚度、干湿差异、磨损与反光来源，不用全局莹光替代材料 |
| 人像基底 | 角色默认以何种真实面孔出现 | 默认漂亮、真实、个体化的亚洲面孔；不以单一脸型、妆容或文化符号模板化。用户明确指定欧洲或其他面孔时覆盖默认，不因面孔归属推导服饰或人格。 |
| 美貌档案 | 如何避免同一套「漂亮」只对女性生效 | 每角色先写一条档案，所有性别表达获得同级选角、脸部、妆发、服装、取景面积和雾面调色。男性必须明确写为俊美、精致、有辨识度的亚洲男性异生体；避免明显腮红色块，但保留极淡冷玫瑰肤色底，不能灰白无血色。 |
| 发型、发色与妆容 | 如何避免发色和服装各自为政 | 按服装主色 → 锚点材质 → 肤色 → 发色 → 背景排色。发色可为自然黑、蓝黑、石墨、深茶或克制的低饱和彩色；浅色只在确有明度或材质呼应时采用。深衣深发靠质感和轮廓光分离。 |
| 主锚点拓扑 | 如何避免收拢翅膀旁又冒出一片小翅 | 锁定种类、准确数量、根部、比例、朝向、折叠和遮挡。每个可见异生部件都必须属于已声明结构；收拢翅面统一向下叠合，禁止未声明的竖立小翅、孤立翅片、第二套翼和翅状服装装饰。 |
| 服装风格 | 异生命穿什么 | 默认由物种结构转译出的华丽仪式礼服、层叠结构外套或宫廷式设计，并与主锚点共同构成完整剪影。精致剪裁西装、宫廷式礼服西装只在用户明确指定职业、身份或权力感时使用；此时也须有物种材质和廓形改造，避免普通职业装。允许适度、可拍的配饰与层级。合规靠正向的端庄、结构清晰、现实可拍表达——**写提示词时严禁出现裸露、皮肤外露、紧身/贴身、身体曲线、性感等词,正面与负面/排除词都不写**；「莹润通透」只用于生物锚点材质,不用于服装或身体 |
| 主色温 | 光线如何塑造人物 | 阴冷青灰、苔绿阴影、脏钠黄或病态肤色高光；高饱和色只做极少量点缀 |
| 形态设定 | 有无常态/异化双形态 | 标明角色属于「始终显形」或「常态/异化」；后者需给一处异化揭示特写（如脊背/体内） |
| 人类尺度 | 人如何保持可共情 | 漂亮人形、脚踝、指关节、后颈、被门框切割的半身；保留骨架与情绪 |
| 禁忌项 | 什么会打破世界或越界 | 干净实验室、霓虹赛博光、抛光 CGI 皮肤、居中摆拍怪物、无来源漂浮特效、干爽哑光皮肤；以及血浆内脏、脓疮溃烂、寄生虫、密集孔洞、昆虫复眼、外露肌肉、把人拆成一团器官、把生物做成贴上去的病灶；**以及「普通人 + 只贴一个偷懒部位」的太常规做法**。服装合规不靠一律排除西装或列禁忌词实现，而靠华丽、端庄、结构清晰、现实可拍的正向服装逻辑。 |

锁定词是所有设计图共享的视觉 DNA，不在同一项目中随意改写。

**贯穿全片的一条原则——不要「随便贴一只生物」**：「太常规」不是因为只有一个明显锚点；一组收拢蛾翼也可以非常高级。问题在于它像道具贴上去、没有重量和根部、没有被材料与服装统一。做对它要：(1) 选一组有足够面积、结构和物种辨识度的**主锚点**；(2) 用**根部连接、承重关系、真实材料与现实可穿着的服装**把它长进身体；(3) 至多加入一项材料/服装/环境线索支持，而非堆器官；(4) 保留清晰漂亮的人形与情绪，头脸默认不作异化。造型细则见 `series-visual-grammar.md`。
**异化的部分和人体占比要趋近原生物特性**，如蝴蝶异生物，翅膀的大小需要和人体一致或更大，需要描述大小与比例。

## 2. 三段融合呈现层次

无论造型走哪条路线，都用三段层次控制「异生主锚点显现到什么程度」，避免每张设计图都同一强度。注意：升级的是「主锚点的可见度、结构完整性与材料存在感」，不是增加身体器官数量，也对应「常态→异化」的谱系：

1. **潜隐（常态）**：锚点只含蓄可辨——一处莹润异质、透光或微光反光，或异化藏在脊背/体内暂不显；空镜或远景就能感到不寻常。
2. **显现**：一组成体系锚点已明确覆盖整块区域（整片肩背/整条臂/半张脸），与漂亮人形自然合一（对应视觉语法的 L2–L3）。
3. **主导（异化顶点）**：一组大面积、结构清晰的主锚点 + 真实连接与材料 + 现实可拍的设计服装统一成一个美丽异生命，异生逻辑主导整体，人的轮廓、姿态或一处特征仍锚定「这仍是人」；空间气质随之翻转。无需因等级升高而在头脸增加触角或其它器官。

每张设计图只升级一个变量：锚点语汇的丰富度、材质密度、人物距离或呈现层级（常态/异化）。

## 3. 建议交付格式（设计图资产 + 视觉锁定包）

本环节只交付**视觉设计包**，不写剧情、对白、事件时间线或逐镜分镜（这些交给 video creation）。除非用户要求更短版本，按以下顺序给出：

1. 一句视觉总述与主视觉命题（长什么样、什么气质，非故事）。
2. 全片视觉契约（八项）。
3. 异生物卡、角色卡、地点卡，各 3–7 条（造型规则见 `series-visual-grammar.md`）。
4. 调色/材质/镜头规则与禁忌项（见 `series-visual-grammar.md`；雾面见 `milky-fog-grade.md`）——作为视觉约束。
5. **设计图资产**：每位角色 1 张用户在角色内环选定的角色设定图：横屏 16:9 时为左正面、右背面，均到腰线下方或大腿上段；竖屏 3:4 时为单一连续构图，完整收入头顶至腰线下方或大腿上段。正背模式同一角色两侧必须同脸、同发色、同服装、同锚点与同曝光；肖像模式不出三视图、脸部插图或拼格。**出图数量硬约束**：每角色只出 1 张,场景图只出必要几张,**不出任何"看视觉是否合适"的风格基准图/锚点微距/校色卡/变体/关键帧测试图**,不对同一资产反复重复出图。**提示词合规**：服装只用正向端庄描述,**不出现裸露、皮肤外露、紧身/贴身、身体曲线、性感等任何词(正面与负面/排除词都不写)**。
6. **视觉锁定包**：WORLD/PORTRAIT/BEAUTY_PROFILE/PALETTE_HARMONY/BIOLOGY/ANCHOR_TOPOLOGY/COSTUME/LIGHT/ROLE_ASSET_FORMAT/CAMERA 锁定词 + 排除项；标明哪些词必须跨镜头锁死、哪些变量允许变化。
7. **造型传递方式（硬约束）**：交给 video creation 时，**角色造型/外形一律以本环节产出的设计图作为参考图直接引用,视频提示词不要用文字重新描述造型**（人形、锚点、服装、质感等）。视频提示词只写镜头、动作、地点、光线与情绪,角色长相与穿着一律「见参考图」。理由:文字复述造型既会造成跨镜头不一致,也容易在复述服装/身体时无意引入敏感词或走向低俗——交给已通过合规自检的设计图承载更稳更安全。

每份交付都写明交接说明：接下来由全能创作Agent（video creation）基于本视觉设计包规划剧情、分镜与成片，视觉约束不得被推翻；**角色造型以设计图为参考图引用,视频提示词不再用文字重述造型**。
