# 银雾泛白调色与雾面光感

在用户想要「泛白、雾面、湿冷但好看」的**场景气氛图、叙事关键帧或角色设定图**时读取。它不是普通低饱和、绿滤镜或大雾；它同时控制明度、色相、空气透视与人像质感。它只补充调色，不改变 `series-visual-grammar.md` 中的融合造型与画面视觉方法。角色设定图无论为横屏 16:9 正背双视图还是竖屏 3:4 单人肖像，均继承乳白雾面色光、主体全清晰；正背双视图的左右两侧曝光和色温必须一致。

生成时同时遵守 `live-action-cinematic-lock.md`：这里的「银雾」是天气、空间与曝光控制的简称。它可以形成**均匀、轻盈、乳白的雾面空气感**，但不能成为一团烟、一条横带、贴地蒸汽或漂浮附件；默认通过漫射冷光、背景明度、远处对比递减、湿面反射与曝光控制来成立，也不是无来源辉光或数字特效滤镜。

## 视觉判断

“泛白雾蓝”来自三件事同时成立：黑不是死黑，而是湿石墨；白不是过曝，而是有纹理的珍珠乳白；柔和冷环境底让对比自然退后。因此它是一套摄影曲线，不是固定蓝色滤镜。角色可以穿黑、灰绿、壳粉或其它项目主色，背景也可改为相邻冷灰、灰绿或珍珠色；只要低饱和中间调、抬黑、珍珠高光、清透肤色与轻盈空气感同时成立，仍属于同一视觉质感。

| 常见误区 | 为什么不像 | 替代方法 |
| --- | --- | --- |
| 全局降饱和 | 会灰、脏、没有皮肤活气 | 只压环境纯度，保留珍珠白、灰粉肤色和少量生物本色。 |
| 压暗黑位 | 会变成硬、脏的恐怖片 | 把黑抬成冷石墨灰；只在发缝、门缝与焦点边缘保留少量真黑。 |
| 在画面中加雾 | 容易变成贴地烟、漂浮附件或空间断层 | 前景睫毛、水珠、壳缘、手指保持清晰；只通过远处对比自然递减来建立空气感。 |

## Look Lock：六项同时锁定

1. **黑位**：大面积暗部是蓝灰、石墨、湿柏油或褪墨色；仍可看见衣物纤维、头发与潮墙的形状。
2. **白位**：阴天窗光、莹润肌肤、玻璃、水面、壳和浅色衣物都是微冷、柔软的乳白高光；留住蓝灰或粉灰纹理。
3. **中间调/肤色**：环境以银蓝、淡青或项目主色的低饱和邻近色为底；嘴唇、耳缘和面颊保留极淡灰粉/冷玫瑰底色。男性可以没有可见腮红，但不能因此变成灰白、干硬、没有血色。
4. **空间深度**：近景清晰；远处的对比、饱和度与边缘锐度在乳白空气感中自然递减。场景图与角色图都允许均匀、轻盈的白雾观感，但空间内没有可见烟、雾团、横向雾带、贴地蒸汽或颗粒特效。
5. **莹润高光**：只在眼睑、唇、发丝、水珠、玻璃裂纹、壳缘和潮地面上出现细小点/线状反光；不要把皮肤磨成油塑料。
6. **光源**：先用一层无明显方向的大软冷光/阴天光作银雾底，再用一处画内实景灯定位；光比柔，不做硬轮廓炫光。

## 色光分支

| 状态 | 画面控制 | Prompt 短语 |
| --- | --- | --- |
| 雨天/外景 | 银蓝环境光、湿石墨阴影、珍珠白天空反射 | `柔和的明亮阴天光，乳白银蓝调，抬起的石墨灰阴影，被雨打磨的表面` |
| 家庭/照护 | 冷灰底不变，人物附近只留一小团脏琥珀/灰粉暖光 | `冷调珍珠灰环境补光，一处微弱的钨丝暖光，无橙色泛滥` |
| 机构/夜间 | 冷白荧光和玻璃反射，局部钠灯只给深度 | `漫射的实用荧光灯，玻璃上的珍珠光反射，克制的钠灯溢光` |

## 固定 Prompt 模块

将这段原样加在每条 prompt 的光色块中：

```text
乳白银灰、柔和冷环境底与低饱和项目主色的调色，
抬起但保留纹理的炭黑阴影，
珍珠质的灰白高光过渡，
带一丝玫瑰底色的、有活气的柔和肤色，
整体低对比但湿润的细小高光锐利可见，
前景主体清晰，均匀的乳白空气感包住背景，远处对比与饱和度自然递减，画面中没有中间横带、局部雾团或贴地烟，
干净的数字电影质感，无可见胶片颗粒
```

并附加：

```text
--排除 青橙调色，沼泽绿偏色，纯黑阴影，过曝的白皮肤，浓重的前景雾，烟雾颗粒特效，硬边缘光，粗糙胶片颗粒，霓虹赛博朋克，油亮塑料皮肤
```

## 跑偏纠正

| 若结果… | 先这样改 |
| --- | --- |
| 灰绿/黑色方案丢失雾面质感 | 保留服装与锚点本色，补回 `柔和冷环境底`、`抬起的石墨阴影`、`珍珠乳白高光`、`低饱和中间调`、`一丝冷玫瑰肤色底色`；不要简单把所有物体改蓝。 |
| 太白、像过曝美颜 | 保留 `抬起但保留纹理的炭黑阴影` 与 `莹润的细小高光锐利可见`；加入深色头发、衣物或门框前景。 |
| 太雾、人物也糊 | 删除所有可见雾的描述；改成 `前景主体清晰，远处对比与饱和度在潮湿空气中自然递减，画面中没有可见雾层`。 |
| 太硬、太商业棚拍 | 使用 `大面积漫射阴天主光`、`柔和的阴影过渡`、`有动机的实用光`；移除 `硬边缘光`、`美颜灯`、`戏剧化对比`。 |
| 太像赛博/通用 AI 恐怖 | 移除 `霓虹`、`青蓝`、`紫色`、`电影恐怖感`；回到地点功能、湿面细节、画内光与一个融合特征锚点。 |

## 通过标准

缩略图里先读到的是珍珠灰白高光、清透人像和轻盈空气感，而不是某一种固定蓝色；黑、灰绿或其它项目本色仍能保留。放大后看得见睫毛、唇纹、壳缘与发丝细节。目标是「可换主色，但不能丢失雾蓝摄影质感；泛白雾面但不糊，画面内没有可见雾」。
