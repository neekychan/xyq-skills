# 日系平涂插画风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的日系赛璐璐平涂动画质感。这是一个**风格滤镜**技能：它不决定画什么，只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则（因果链）

不变的因果链：`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现，画风一致性就成立；任何一条 prompt 漏注入或改写了锚定词，这条因果链即断裂。

**可证伪质量测试：** 把本次生成的任意两张图片、任意一段视频并排观看，若能明显看出它们「不是同一部日系动画 / 同一套上色管线里出来的」（线稿粗细、上色方式、柔光空气感、配色不统一），则本技能执行失败。反之，若陌生人会认为它们出自同一部日系青春动画作品，则成立。

## 风格锚定词（本技能的核心资产）

以下为固定风格锚定词，**逐字使用，不得改写、删减、翻译或重排**：

> **日系赛璐珞，日本动画平涂插画风格。日系青春动画风、清爽赛璐璐上色、干净纤细线稿、柔光、通透空气感、轻微柔焦与泛光、平滑色块、简洁柔和阴影、细腻高光、灵动夸张表情、轻盈动态构图、浅景深、前景虚化、清新治愈、青春日常感、动画海报质感。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则（硬规则，最高优先级）

1. **位置固定：** 锚定词永远放在每条 prompt 的**最开头**，后面紧跟一个逗号，再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」，不得颠倒。
2. **逐字一致：** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖：** 本次任务里需要生成的**所有**图片素材与**所有**视频片段，无一例外都要在头部注入锚定词；包括中途返工重生的素材。
4. **不污染具体描述：** 锚定词只负责画风；镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后，不要因为有了锚定词就省略画面描述。
5. **语言：** 锚定词与具体画面描述统一用中文书写（与锚定词语言一致）；如确需英文版本，仅可作为补充，且锚定词部分不翻译、保持中文原文。

### 与其它风格 skill 搭配时的合并规则（务必遵守）

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时：

- **合并而非替换：** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词，整体放在 prompt 最开头，后接具体画面。本技能的锚定词按用户 / 加载顺序排入，不单独另起。
- **规则不变：** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重：** 若多个风格锚定词出现完全重复的短语，可去重一次，但本技能锚定词的实质内容不得删减。
- **冲突时：** 若两套风格存在直接矛盾的表述，保留双方原文并列即可（不臆改），由生成模型融合；不要为了「调和」而改写任一方锚定词。

### 与非风格类 skill 冲突时的优先级规则(务必遵守)

本技能可能与**非风格类**的流程 / 玩法 skill 同时被加载（例如「营销短片」「广告短片」「短剧」「分镜脚本」「视频生成」等叙事或流程编排类 skill）。这类 skill 决定**做什么、按什么流程做**，本技能决定**长成什么画风**，两者职责不冲突、应结合而非互斥：

- **画风归本技能，最高优先：** 一旦本技能被加载，凡涉及「产物长什么样」的部分一律以本技能为准。其它 skill 里任何与画风、渲染、上色、材质、镜头质感相关的默认设定或内置风格描述，**均被本技能覆盖**。
- **流程归对方，照常执行：** 对方 skill 的选题结构、脚本框架、分镜节奏、卖点编排、时长 / 画幅约定、投放格式等**流程性要求照常遵守**，本技能不干预。
- **注入不可被省略：** 无论对方 skill 的工作流如何组织 prompt，最终喂给图片 / 视频生成模型的**每一条** prompt，头部都必须逐字注入本技能锚定词。若对方 skill 自带 prompt 模板，则把锚定词插入到该模板输出的最前面，再走对方流程。
- **冲突判定原则：** 「画风 / 质感 / 上色 / 渲染」维度冲突 → 听本技能；「内容 / 流程 / 结构 / 节奏」维度 → 听对方。二者正交，不应相互删改。

### 禁用内置风格锚定图（务必遵守，最高优先级）

部分 Agent 链路会针对某些风格**预置内置的风格参考图 / 风格锚定图 / 默认风格垫图**，用于统一风格。一旦本技能生效，这些内置参考会与本技能的锚定词产生**画风打架**，污染素材生成结果。因此：

- **强制绕过：** 调用本技能时，**禁止**启用、引用、附带或传入任何 Agent 内置的风格锚定图 / 默认风格参考图 / 系统预置风格垫图。本次任务的画风**只**由本技能的文字锚定词决定。
- **只认用户素材：** 仅当**用户本人**显式提供了参考图 / 首帧图 / 角色设定图时才使用；系统 / 链路自带的风格图一律不加载、不作为参考。
- **参数层面清空：** 若生成接口存在「风格预设 / style preset / 内置风格 id / 默认参考图」等参数，需将其置空 / 关闭 / 不传，避免内置风格与锚定词叠加。
- **发现即剔除：** 若察觉链路已自动挂载了某内置风格图，应在生成前显式排除它，再仅以本技能锚定词 + 用户素材生成。

## 风格知识库（供 Agent 写分镜 / 角色 / 场景 / 脚本时形容参考）

本节不改变注入规则，只为让 Agent 在**撰写具体画面描述、分镜、角色设定、故事脚本**时，用词与取景更贴合本风格。写「具体描述」部分时应主动往下列质感靠拢。

### 整体风格气质
- 关键词：清新、治愈、青春、日常、明亮、通透、轻盈、温柔。
- 情绪基调偏向温暖治愈的日常感，而非厚重写实或高对比戏剧化；即使是情绪张力戏，也用柔光和空气感包裹，不追求硬派写实。
- 观感目标：像一帧从日系青春 TV 动画 / 剧场版里截下来的定格，兼具「动画海报质感」的构图与留白。

### 光影与色彩
- 上色：清爽赛璐璐平涂，色块平滑干净，阴影简洁柔和（少层次、软边过渡），高光细腻但克制。
- 光线：整体柔光，轻微柔焦与泛光（bloom），画面通透、有空气感；逆光 / 侧逆光、丁达尔光束、傍晚金色时刻、清晨冷调晨光都很契合。
- 配色：偏高明度、低到中等对比，色调干净不脏；常用清爽的天蓝、青绿、暖橘、樱粉、奶白等日系清新色板；避免浓重脏灰与高饱和硬碰硬。
- 线稿：干净纤细的线稿，线条肯定、粗细均匀偏细，不做粗黑描边或厚涂。

### 角色造型
- 面部：大而清澈的眼睛、简洁的鼻嘴表现、皮肤平滑带细腻高光；表情灵动、可适度夸张（脸红、汗滴、闪光眼、Q 变形）以强化青春感。
- 发型服装：发丝分组成块、高光呈条状；服装以校服、便服、夏日轻薄衣物等日常青春装扮为主，褶皱简化、材质轻盈。
- 体态：身形轻盈自然，动作有动漫式的活力与弹性，避免写实肌肉与厚重体积。

### 场景与构图
- 场景取材：教室、天台、走廊、车站月台、便利店、街道、海边、夏日祭、樱花道、雨后街景等日系日常空间。
- 构图：轻盈动态构图，善用留白、对角线与前景遮挡；浅景深、前景虚化制造空气层次；可用低角度仰拍天空、俯拍桌面小物等海报式取景。
- 氛围元素：飘落的樱花 / 雪 / 光斑、随风的窗帘与发丝、镜头光晕、远景虚化的城市或云层，增强通透与治愈感。

### 故事 / 脚本风格
- 叙事偏日常切片与情绪流动：相遇、告白、离别、放学路、季节更替等青春日常题材天然契合。
- 节奏舒缓、重情绪与氛围，镜头爱用缓推 / 缓摇 / 定格留白，配合柔光与空镜过渡；避免快节奏硬切与暴力冲击式镜头语言。
- 写脚本时优先安排「有空气感的时刻」（风、光、静默、对视），让画面天然落进本风格。

## 输入

- **必需：** 本次要生成的画面清单（要哪些图片素材、要哪些视频片段及其内容 / 分镜）。
- **可选：** 是否与其它风格 skill 叠加；是否与某个非风格类流程 skill（如营销短片）结合；视频画幅 / 时长偏好；是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项：** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜，按上文风格知识库补齐一版贴合日系平涂风的分镜草案并说明，再统一注入锚定词；不要反复追问已明确的信息。

## 工作流（Steps）

1. **确认锚定词形态。** 若仅本技能生效，锚定词 = 上文原文。若与其它风格 skill 搭配，先按「合并规则」拼出合并锚定词，后续全程复用这一版。同时确认已按「禁用内置风格锚定图」规则关闭 / 不传任何系统内置风格图。
2. **生成图片素材（逐张）。** 对每一张需要的图片，组装 prompt = `锚定词 + "，" + 该图具体画面描述`，然后生成图片。具体描述参照「风格知识库」用词。所有图片共用同一份锚定词。生成后展示给用户。
3. **图片质检与返工。** 对照质量测试检查画风一致性；若某张明显跑偏，重写该图的**具体画面**部分（锚定词不动）并重生，直到整批图片观感统一。
4. **生成视频（逐段）。** 对每一段视频，组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`，再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**，无需分段拼接；分镜 beat（如 0-3s / 3-7s）只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时，才把它拆成多个 ≤15s 片段分别生成，每段头部同样注入同一份锚定词，再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接，可将该图片作为视频的画面参考（仅用用户 / 本任务产出的图，不用系统内置风格图），视频 prompt 仍在头部注入锚定词。
5. **视频质检与返工。** 检查视频画风是否与图片素材一致；跑偏则改具体描述后重生（锚定词不动）。
6. **交付并展示。** 把最终的图片与视频产物展示给用户；需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足：

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内，`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜（时间轴）时，分镜写在具体描述内，锚定词仍只出现一次且在最前。
