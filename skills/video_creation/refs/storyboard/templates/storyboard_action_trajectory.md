# 分镜图模板：动作分解 · 运动轨迹示意分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：用轨迹线、箭头、残影等视觉元素，强调物体或角色在空间中的运动方向、路径和落点的**运动轨迹示意分镜图**，适合分析或教学“东西从哪儿出发、沿什么轨迹运动、最终到哪儿”的过程。
- **典型场景**：
  - 篮球运球与投篮、足球传球与射门、网球/羽毛球击球轨迹等体育技术讲解。
  - 跳跃、翻滚、跑酷、器械摆动（如钟摆、机械臂、工业机器人）等运动路径示意。
  - 动画/游戏中的技能飞行轨迹、角色位移路径规划与镜头运动设计辅助图。

## 2. 判定关键词与适用边界
- 典型触发词：`运动轨迹`、`路径示意`、`箭头标注`、`残影`、`弹道`、`运球路线`、`跳跃轨迹`、`器械运动路径`。
- 适用判定：
  - 用户希望看到“球/角色/器械在场地里是怎么走的”“轨迹线怎么规划”，而不仅仅是单个姿态定格；
  - 分镜是给技术分析或动作设计用，重点在空间路径可视化，而非情绪/剧情。
- 不适用场景：
  - 纯姿态教学，关注身体角度与重心是否标准 → 适合“姿态连续分镜”；
  - 只讲故事或广告情绪，不需要轨迹线与方向示意 → 适合剧情/产品类分镜模板。

## 3. 分镜结构建议
- **推荐宫格数**：4–9 格，一套分镜通常覆盖“起始位置 → 关键路径节点 → 结束落点”，复杂路线可扩展到 12 格。
- 规划方式：
  - 先确定参考平面与视角（如俯视战术板、侧视全身、三维透视），整个分镜尽量保持同一视角，以便对比各格轨迹；
  - 将完整运动路径拆成若干关键节点，每格展示一个节点附近的轨迹线变化（入射方向、最高点、落点、转折位置等），并用箭头标注运动方向；
  - 对于多条路径（如多次投篮或多玩家跑位），可在同一格中绘制多条轨迹线，但需用颜色/虚实线区分，不超过 3 条。
- **画面特征**：地面/场地线条明确（如三分线、边线、区域划分），主体物体（球、角色、器械）清晰，轨迹线颜色与样式统一，箭头方向易读。

## 4. 生图 Prompt（PE）模板

```text
你是一名战术分析师兼动作设计师，请为 {运动场景，如“篮球运球与投篮路线/足球进攻跑位/跑酷路线规划/机械臂运动轨迹”等} 设计一张 {宫格数} 宫格的运动轨迹示意分镜图，整体画幅为 {画幅比例说明，如“16:9 横版战术板”或“9:16 竖屏技术讲解”}。

【运动与场地信息】
- 运动对象：{如“篮球+球员”“足球+前锋和中场”“机械臂末端执行器”等}
- 场地类型：{如“标准篮球场/五人制足球场/工厂流水线/室内训练场”等}
- 视角设定：{俯视战术板/侧视全身/斜俯视三维等，建议在整套分镜中保持一致}
- 技术目标：{如“解释最佳运球路线”“展示传球组合”“说明机械臂安全运动范围”等}

【轨迹拆分要求】
1. 先用文字描述完整运动路径：
   - 起点：{物体/角色出发位置与状态}
   - 关键节点：{途中转折点、最高点或速度变化点列表}
   - 终点：{落点或停下位置}
2. 根据路径复杂度确定 {宫格数}，将路径拆成 {宫格数} 段或若干关键节点，每格负责说明一段轨迹。

【分镜与编号】
- 宫格数：{宫格数，如 4/6/9 格}，按路径顺序编号 T1–T{N}；
- T1 通常为整体起始位置与起始方向，T{N} 为终点与结果，其余格分别展示中途的转折/加速/减速/最高点等。

【分镜输出格式】
请依次为 T1–T{N} 输出以下信息：
- 路径阶段：{如“起始推进”“突破侧移”“高点抛射”“落点回防”等}
- 轨迹线描述：{线条颜色、粗细、虚实、箭头方向，如“浅蓝实线从底线右侧向左上弧形抛射”}
- 主体位置与状态：{球/角色/器械在场地上的具体位置、动作姿态与速度感}
- 场地参照物：{标注边线、区域、障碍物等，帮助观众理解距离与方位}
- 视角说明：{如“俯视战术板视角”“侧视全身中景”等}
- 技术要点：{该阶段需要注意的战术/技术信息，如“此处保持中速，避免过度贴边”}

【画幅与风格】
- 画面比例：{16:9 横版/9:16 竖版等，战术板类建议 16:9}
- 画风：{战术板平面示意/简洁插画/仿真 3D 场景等}
- 颜色规范：{主色调与轨迹线颜色搭配，如“场地为淡绿色，轨迹线为高对比的红/蓝/黄”等}
- 要求整套分镜中的场地线条、比例与坐标轴保持一致，轨迹线绘制风格统一，避免跨格视角和比例剧烈变化。
```

## 5. 一致性与避坑
- 全套分镜应使用同一种基础视角（俯视或侧视），避免上一格俯视战术板、下一格突然变成人物近景，导致轨迹线难以对齐。
- 场地线条、区域划分和参照物位置在所有格中保持一致，防止“线条漂移”让观众误判位置。
- 轨迹线颜色与样式统一，同类路径保持同一颜色，不要每格换色导致无法追踪同一对象的运动。
- 单格中轨迹线数量不宜过多，最多展示 3 条，并用颜色或虚实线区分，避免视觉噪声。
- 描述路径时同时给出起点、终点和方向，避免只写“球飞过去”“人跑过去”而不说明从哪里到哪里。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“动作分解表”及战术类讲解场景：
  - 分镜阶段用本模板将运动路径拆成 T1–T{N} 的轨迹段，作为动作分解表中“运动路径/跑位示意”的补充视图；
  - 视频阶段可按每个轨迹段配置镜头，将轨迹分镜中的场地与路径作为参考帧或叠加图层，确保实际画面中的运动大致沿同一条轨迹。
- 当运动轨迹涉及高速度、强冲击或多人对抗（如爆发冲刺、跳跃扣篮、急停转身等），对应时间段的视频 Prompt 编写可参考 `storyboard/vfx-action-prompt.md`：
  - 为关键 3–5 秒段落选择合适的动量锚点运镜模式（主角动量跟随或一镜到底），在 Prompt 中明确镜头随运动路径推进；
  - 在描述碰撞或急停瞬间时加入环境反馈与动态模糊提示（尘土、碎石、速度线等），增加速度感与重量感。
- 本模板适合与“姿态连续分镜”“动作导演镜头表”组合使用：轨迹示意分镜负责空间路径可视化，姿态分镜负责身体姿态细节，镜头表负责机位与运镜，共同约束动作视频在空间与时间上的连贯性。
