# 分镜图模板：动作分解 · 姿态连续分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：强调身体姿态、重心变化与运动方向的连续动作分镜，一格一关键姿态，形成类似连拍照片的**姿态序列**，适合动作教学与动画设计。
- **典型场景**：
  - 健身/瑜伽动作分解、舞蹈动作教学、体育技术讲解。
  - 角色动画关键帧设计、动作连招设计参考。

## 2. 判定关键词与适用边界
- 典型触发词：`姿态连续`、`动作分解图`、`关键帧`、`标准动作教学`、`分解每一步`、`看动作是否规范`。
- 适用判定：
  - 用户关心“动作标准/姿态是否正确”，希望看到清晰的每一步动作；
  - 目标是教学/复现动作，而不是讲故事或仅展示氛围。
- 不适用场景：
  - 主要是打斗故事、剧情片段 → 可用“动作分镜型”或“剧情叙事型”。

## 3. 分镜结构建议
- **推荐宫格数**：4–12 格，根据动作复杂度选择；
- 一般结构：起势 → 中段关键姿态 2–8 格 → 收势/结束姿态。
- 每格必须明确：
  - 身体重心位置（脚步、支撑点）；
  - 四肢方向与关节角度；
  - 朝向（面向镜头/侧面/背面）；
  - 动作节奏（慢/中/快）与是否停顿。

## 4. 生图 Prompt（PE）模板

```text
你是一名动作指导兼体态教练，请为 {动作类型，如“深蹲/硬拉/瑜伽下犬式/篮球上篮动作”等} 设计一张 {宫格数} 宫格的姿态连续分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏动作教程”}。

【动作信息】
- 动作名称与目标：{如“标准深蹲，用于训练下肢力量和稳定性”}
- 使用场景：{如“健身教学短视频/训练动作示范/动画参考”等}
- 节奏与拍点：{如“中速，每 2 秒一个关键姿态”}

【主体设定】
- 角色：{性别、年龄、体型、服装风格}，需在所有格中保持一致。
- 场景：{健身房/舞蹈室/空白背景等}，背景简洁，突出姿态。

【分镜与编号】
- 宫格数：{宫格数，如 6/8/10 格}，按时间顺序编号 A1–A{N}；
- 为每一格输出：
  - 姿态描述：{如“臀部向后坐，膝盖不超过脚尖，背部保持中立”}
  - 重心位置：{如“重心在脚跟，脚掌均匀受力”}
  - 动作方向：{如“向下缓慢控制”“向上爆发发力”等}
  - 视角与构图：{如“侧面全身中景”“45 度斜侧全身”}

【输出步骤】
1. 先列出从起势到收势的动作步骤（文字列表）：
   - 步骤1：起始姿势
   - 步骤2：下蹲中段
   - …
   - 步骤N：结束姿势
2. 再为每个步骤匹配 A1–A{N} 的画面描述，确保动作在视觉上完整连贯。

【画幅参数】
- 推荐比例：{9:16 竖屏} 适合手机观看，必要时可用 16:9 横版用于教学大屏；
- 完成度：{草稿/精修/成品级渲染}，教学类通常建议精修级。
```

## 5. 一致性与避坑
- 所有格的角色外观、服装、体型必须一致，防止姿态判断被风格变化干扰。
- 保证地面与背景线条一致，便于观察重心变化与肢体位置。
- 明确左右方向：保持视角一致，避免上一格面向左、下一格突然面向右导致误解。
- 不要在同一格中混合两个不同步骤的动作，避免“前后动作混在一张图”。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“动作分解表”相关模板：
  - 先用本模板生成姿态连续分镜图；
  - 视频阶段以这些关键姿态格为参考帧，强调动作连贯性与力量感；
  - 教学视频可在每个关键姿态停留稍长时间，并叠加文字要点说明。
- 适合与“动作导演镜头表”组合使用：本模板负责体态准确性，镜头表负责景别与运镜规划。
