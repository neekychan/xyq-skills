# 营销表达规则 / Marketing Expression Rules

Use this reference when choosing the selling point, writing benefit voiceover, and writing CTA. The goal is to make the video persuasive without becoming slogan-heavy, over-claimed, or disconnected from visible proof.

## One Main Selling Point

Each 15-second video should drive one main selling point.

Use this mapping:

```text
痛点/欲望 -> 商品动作 -> 可见证明 -> 人话利益 -> CTA
```

Secondary details may appear as short visual cues, packaging close-ups, or optional text, but should not compete with the main line.

## Human Benefit Rule

Turn features into human reasons:

- ingredient/material -> feeling, texture, safety, durability, or use situation
- capacity/quantity -> one-day use, family use, storage, value
- speed/performance -> saved time, easier process, less waiting
- design/appearance -> styling, gifting, home scene, confidence
- price/offer -> why now, what is included, value confirmation
- service/process -> where to go, how to redeem, what experience to expect

Final spoken lines should sound like a creator speaking to a real viewer, not a product spec sheet.

## Proof-Led Marketing

Every claim needs a visual proof type:

- `效果`: before/after, close-up result, user reaction
- `省事`: process shortening, one-hand use, phone tap result
- `舒服`: try-on, movement, texture touch, relaxed reaction
- `划算`: package layout, item count, price page, product card
- `安心`: label/detail, clean use process, parent/caregiver handling
- `质感`: material close-up, unboxing, hand texture, lifestyle placement
- `好吃好喝`: bite/sip reaction, texture close-up, portion display
- `到店`: store sign, package contents, service step, redemption page
- `游戏/IP`: reward page, character/skin, phone screen, player reaction

## Platform Marketing Tone

- 抖音: faster hook, clearer product card/offer, direct CTA.
- 小红书: softer recommendation, more experience detail, save/comment tone.
- 快手: practical, real, value-for-money, direct but grounded.
- 微信视频号: trust-led, service/value clarity, moderate pace.
- 本地生活: package, price, route, redemption confidence.
- 游戏/IP: reward motivation, participation, event page, join/download CTA.

## Offer Expression

If the user provides price, coupon, bundle, gift, group-buying, presale, or limited-time info:

- Show one offer cue in 0-3s or 12-15s.
- Return to product proof in 3-7s.
- In the final CTA, recall the offer lightly.
- Use exact user-provided numbers.

Do not let offer text replace product proof.

## CTA Fit

The CTA must match the user's actual conversion target:

- ecommerce: 商品卡 / 领券 / 下单
- Xiaohongshu seeding: 收藏 / 看同款 / 评论区
- group-buying: 团购券 / 到店核销 / 预约
- service: 咨询 / 预约 / 了解详情
- game/IP: 预约 / 下载 / 领福利 / 参与活动

Use one next action only.

## Marketing Safety

Use restrained claims:

- Prefer `用起来`, `看起来`, `这个状态`, `我实测`, `这一点`.
- Use strong claims only when the user provides evidence.
- For beauty, health, maternal/child, food, finance, education, medical-adjacent, and safety-related content, keep claims observational and experience-led.

## Final Marketing Check

Before final output, confirm:

- The first 3 seconds create a reason to watch.
- The product appears early.
- The main selling point is visible, not only spoken.
- The CTA follows from the proof.
- The script does not become a feature list.
- The platform tone is correct.
