# 图片素材风格化转绘规则

> 本文件定义如何把用户上传的图片素材，用锚定词做成统一画风的角色/场景资产。这是视频生成前的必经中间步骤。

## 一、前置硬条件

本技能的用法是：**用户必须先上传一批自己已确定的图片素材（角色或场景分镜）。** 没有上传素材，不能进入风格化，也不能进入视频生成——此时只追问缺失的素材，不臆造、不用文字凭空造图。

## 二、逐张判定：哪些图转绘，哪些不转绘

对上传的每一张图片单独判断：

- **需要转绘**：图中存在**明确的角色主体**——人物、宠物、拟人角色等有明确主体的画面。
- **不转绘（原样保留进入下一阶段）**：
  - 单独的物品图（没有角色主体）
  - 空镜场景图
  - 无明确主体的风景图

只对存在明确角色主体的图片做风格化转绘；其余图片保持原样。

## 三、转绘方式（核心规则）

对每一张需要转绘的图片，生成一张风格化图片，遵循：

- **编辑提示词 = 风格锚定词本身，直接、完整地使用，不额外添加任何其他内容。**
  即：把 `references/style-anchor.md` 中的锚定词（若叠加了其他风格技能，则用合并后的锚定词）作为该图的编辑提示词，**不再补写任何画面描述、题材、动作、镜头或其它文字**。
- **完全基于用户原图转绘**：以用户上传的原图为底，只做画风转换，不改变原图的构图、主体、动作与内容。
- 转绘结果应保留原图角色的核心视觉识别点（发型、服装轮廓、配饰、体型、年龄感等），只替换画风。

## 四、产物

风格化转绘完成后，得到一套画风统一的角色/场景资产（转绘图 + 原样保留的非角色图）。这套资产是：
- 用户只要图片时的**最终交付物**；
- 用户要动画视频时的**视频生成输入素材**。

## 五、落 prompt 前自检

- [ ] 是否已确认用户上传了图片素材？
- [ ] 是否逐张判定了角色主体、正确跳过了物品/空镜/无主体风景图？
- [ ] 每张转绘图的编辑提示词是否就是锚定词本身、没有夹带任何其他内容？
- [ ] 转绘是否完全基于原图、未改变构图与主体内容？
