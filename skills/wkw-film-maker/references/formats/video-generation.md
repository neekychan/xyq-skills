# 多模态连续视频生成规范

本规范定义了从图像资产预生成、角色音色绑定到15秒多镜头视频生成的完整技术流程与约束。

---

## 一、生成路径与模型锁定

### 1.1 核心视频生成能力
- 必须使用多模态参考生成能力（同时传入图片参考和音频参考生成视频），严禁使用仅依赖首尾帧或单张图片的简单生成路径（其依靠硬编码首尾帧进行插帧，动作会极其呆板）。
- 支持的模型：
  - **高画质模型**：最高画质输出，支持720p和1080p分辨率，适合最终出片
  - **快速模型**：速度更快，固定720p分辨率，适合角色设定视频生成和快速预览

### 1.2 核心图像生成能力
- 使用文生图/图生图能力，采用高素质图像模型生成2K分辨率图像
- 角色设定图和场景参考图均需2K分辨率以保证细节

### 1.3 音频生成能力
- 使用纯乐器BGM生成能力生成背景音乐（推荐高品质音乐生成模型）
- 角色音色不使用TTS合成，必须从角色设定视频中提取真实音色

---

## 二、图像资产预生成与绑定规范

在生成任何15秒主体视频前，必须确保以下资产已生成并绑定。

### 2.1 多角色参考图

**生成规范**：
- 为每个角色分别生成独立的"多视角角色设定图"
- 布局：四图水平排列的单张横向拼版图
  - 左侧：大幅半身特写（占40%宽度）
  - 右侧依次：正面全身、侧面全身、背面全身
- 背景：纯白背景
- 光影：柔和均匀的工作室环境光，无硬阴影
- 风格：真人实拍风格，强调皮肤毛孔、发丝质感、衣物纹理
- 分辨率：2K

**绑定规范**：
- 将每个角色的设定图分别注册为独立的角色参考资产
- 命名规范：角色设定图A、角色设定图B（对应角色A、角色B）
- 保证跨镜头面部、身材与服装纹理的高度一致性
- 后续所有视频生成必须引用对应角色的设定图作为视觉参考

### 2.2 场景参考图

**生成规范**：
- 生成具备真实物理透视的场景设定图
- 低照度光影，符合选定美学色盘
- 细节逼真：墙面纹理、地面反光、光源位置、道具布置
- 明确体现前景-主体-背景三层空间结构
- 分辨率：2K

**绑定规范**：
- 注册为场景参考资产
- 后续所有在该场景发生的视频段落必须引用此场景图作为参考

---

## 三、声音资产提取与角色视频预生成规范

### 3.1 多角色设定视频生成

**目的**：为每个角色生成一段展示其说话状态和声音特征的短视频，用于提取真实音色。

**参数锁定**：
- 模型：快速模型
- 分辨率：720p
- 时长：4秒至6秒
- 参考输入：仅传入对应单个角色的设定图
- 提示词内容：包含一段简短的角色台词（使用确认的方言/语言），描述角色说话时的面部状态和语气（如"角色微微侧头，眼神温和，用粤语缓慢说出一句问候台词，嘴唇自然开合，面部肌肉放松"）
- 每个角色单独生成，不混合多个角色

### 3.2 音频音色提取的路由边界

**重要分工**：
- 视频生成能力只负责生成角色设定短视频
- 音色提取必须使用专门的音频分析处理能力从生成的视频中提取
- 角色设定视频生成完成后，必须回到流程顶层执行音色提取
- 不得将音色提取任务委派给视频生成模块
- **严禁使用任何TTS/语音合成路径来替代"从视频提取音色"**，包括但不限于：
  - 禁止使用文本转语音生成替代音色
  - 禁止搜索或使用预置音色ID
  - 禁止使用语音生成工具直接生成音频
  - 音色必须且只能从角色自己的设定视频中提取，以保证音色与角色外貌的一致性

### 3.3 音频音色绑定

- 只有在音色提取成功并返回可用音频后，才将其注册并绑定为对应角色的声音参考资产
- 命名规范：角色音色A、角色音色B
- 这些音色资产将作为后续对应角色所有对白和内心独白的声音参考
- 彻底杜绝无声默片与声音串音（角色A的对白必须使用角色A的音色，角色B的对白必须使用角色B的音色）

### 3.4 失败处理

如果出现以下情况，必须暂停并告知用户：
- 无法从视频中提取音频
- 提取的音色质量不可用（噪音过大、声音失真）
- 音色的方言口音明显错误（如选了粤语但生成了普通话音色）
- 视频中角色没有说话导致无法提取有效语音

向用户提供两个选择：
1. 重新生成该角色的设定视频（调整提示词后再次尝试）
2. 用户自行提供该角色的音频参考文件（用户上传音频后直接绑定）

**严禁静默失败或用TTS冒充提取音色。**

## 四、多镜头切片视频生成逻辑

### 4.1 多参数注入

生成15秒主体视频时，必须同时传入：
- **视觉参考**：绑定的多角色参考图（角色A设定图、角色B设定图）+ 场景参考图
- **音频参考**：当前镜头说话角色对应的音色资产（作为口型驱动源）
- **提示词**：严格遵循四模块结构的纯中文提示词（见提示词规范）

**不使用任何多宫格故事板作为输入**——依靠提示词中的时间线切片描述和自动切镜能力完成多镜头叙事。

### 4.2 多角色声音同步与口型对齐

- 在音频参考配置中，必须根据当前镜头说话主体的不同，精准引用对应角色的音色资产
- 必须将对应的音频资产作为口型驱动源输入，确保生成的角色在说出对白/内心独白时：
  - 嘴部动作与语音高精度同步（口型对齐）
  - 呈现极其生动的说话状态（嘴唇开合、牙齿、舌头的自然运动）
  - 说话时伴随自然的面部肌肉联动（脸颊微动、下颌运动）
- 依据Final_Video_Spec的输出语言配置，在提示词中显式指定所需的方言语调口音
- 发挥视频模型优秀的原生方言口音直接生成能力

### 4.3 参数硬性约束

| 参数 | 高画质模型 | 快速模型 |
|---|---|---|
| 分辨率 | 720p / 1080p（1080p需会员权限） | 固定720p |
| 单段时长 | 物理整数，4秒至15秒，锁定15秒 | 物理整数，4秒至15秒，角色设定视频用4-6秒 |
| 画面比例 | 遵循Final_Video_Spec确认的比例 | 同左 |
| 音频 | 必须包含对白/独白或环境音效，禁止无声 | 同左 |

### 4.4 逐段生成与确认机制

- 严格按照分镜脚本顺序逐段生成15秒视频
- 每段生成后必须暂停，与用户确认质量
- 确认维度：
  1. 角色面部是否一致、是否有生动微表情
  2. 是否出现瞬移、穿帮、反关节等物理错误
  3. 与上一段的衔接是否流畅（对照视觉状态账本）
  4. 对白声音是否清晰、口型是否对齐、方言是否准确
  5. 景深是否有三层结构、光影是否合理
- 用户确认通过后才生成下一段
- 用户不满意则根据反馈调整提示词重新生成该段

## 五、王家卫电影海报风格封面设计规范

### 5.1 美学设计目标

生成符合王家卫电影海报美学的艺术封面：
- 高对比度低照度光影
- 强烈的色彩饱和度与冷暖对比（绿-红、蓝-黄）
- 手持微晃的动感或优雅静止
- 艺术排版与手写字/中英双语台词装饰感
- 平视视角或微仰视角
- 暧昧、孤独、怀旧、若有所思的氛围
- 胶片颗粒质感
- 主体人物通常不直视镜头，呈现侧脸、背影或半遮面

### 5.2 多尺寸出图控制（分步执行）

**第一步：16:9主封面**
- 先生成16:9比例的主封面图
- 包含完整的海报排版元素（电影标题、双语台词、装饰性文字）
- 提交给用户进行视觉审核与确认

**第二步：比例延展**
- 待用户确认16:9主封面通过后
- 以16:9图为风格参考基础
- 延展生成3:4和4:3两个比例的封面图
- 保持视觉风格、色盘、人物状态一致
- 调整排版以适应新比例
- 达成全端、全比例覆盖
