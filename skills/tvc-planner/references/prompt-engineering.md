# 提示词构建规范（阶段9执行标准）
## 总原则
1. 所有Prompt必须使用中文书写，必要的英文镜头术语、摄影术语、模型负向约束可以保留。
2. Prompt目标是把已确认的品牌调性、视觉反推文档、资产要求、表格分镜、Storyboard Shot翻译为可执行的生成指令。
3. 不得重新编写剧情，不得新增未确认画面，不得生成未确认内容，不得改变镜头顺序。
4. 每个15s Storyboard Shot对应一个独立的视频Prompt，必须将该Shot内5-12个镜头的逻辑完整融入同一个Prompt。

## 视频Prompt万能公式（必须严格按此结构编写）
```
[参考锁定] → [摄像机参数] → [代言人/产品/表演] → [空间/材质] → [光影/色彩] → [动作节奏（按镜头顺序）] → [片段首尾衔接] → [转场逻辑] → [声音设计] → [负向约束]
```

### 1. 参考锁定（每个Prompt开头必须写）
```
使用已确认代言人三视图、产品三视图、对应场景调性资产、必要跨分镜重复资产、用户上传原始参考图作为视觉参考，保持代言人身份、面部结构、体型比例、妆发、服装、产品结构、材质、品牌色彩、场景光影与整体TVC调性一致。
```

### 2. 摄像机参数
明确整体镜头风格、焦距范围、景深控制、画面比例、分辨率、帧率，如"720p分辨率，24fps电影帧率，9:16竖屏，35mm-85mm焦段，浅景深，胶片质感"。

### 3. 代言人/产品/表演
明确代言人整体状态、妆造、服装，产品核心识别点，整体表演基调，如"代言人冷冽克制表情，动作缓慢有力，身着高定黑色羊毛西装，产品为银色金属机身智能手机，边缘倒角呈现冷白高光"。

### 4. 空间/材质
明确场景空间结构、核心材质表现，如"极简混凝土展厅，地面为哑光灰色水泥，墙面为清水混凝土，金属展架呈现细腻拉丝纹理，皮革装饰面可见细密压纹"。

### 5. 光影/色彩
明确整体布光逻辑、色彩调性，如"冷调侧光为主，主光从左侧45度打入，辅光柔和补暗部，轮廓光勾勒人物与产品边缘，整体低饱和冷灰色调，无暖色光，暗部层次丰富，细腻胶片颗粒感"。

### 6. 动作节奏（按镜头顺序完整写入，不得遗漏）
按表格分镜的镜头顺序，逐个镜头写入：
```
[镜头N：时间段，景别，视角，运镜方式] 画面内容与表演细节、品牌/产品/代言人关系、光影与材质细节、SFX音效、音乐情绪、商业表达功能。
[转场方式：动势匹配/物理遮挡/几何重合/光影延续/声音桥/节拍延续] 转场物理依据说明。
```
- 必须严格保留镜头顺序，不得删减任何镜头。
- 必须明确节奏节点：
  - 0-3s：品牌视觉钩子与第一个视觉反馈点
  - 3-6s：代言人气质、产品材质或核心结构展示
  - 6-8s：第一个视觉或情绪高潮
  - 8-12s：空间、动作、产品价值或品牌理念升级
  - 12-15s：品牌Hero Moment/产品Hero Moment/全球Campaign记忆点或下一片段衔接点
- 质感表达必须落到具体物理细节，禁止使用"高级感""电影感"等空洞词汇，可使用：
  - 金属漆面形成长条形环境反射
  - 玻璃屏幕出现受控高光但不溢出
  - 皮革表面可见细密压纹与边缘油蜡光泽
  - 缎面布料随身体转向形成窄幅高光
  - 碳纤维纹理在侧光下产生方向性反射
  - 鞋底橡胶在地面接触处轻微压缩
  - 汽车轮毂旋转时高光形成连续弧线
  - 3C产品倒角边缘产生冷白轮廓光
  - 代言人眼部高光随转头发生微小位移

### 7. 片段首尾衔接（必须明确写入）
- 若为第一个片段：开头必须写明"0-2s建立品牌视觉钩子：[具体钩子内容]"
- 若非第一个片段：开头必须写明如何承接上一片段结尾，如"片段开头承接上一段结尾的手部抬起动作余势，从手指触碰产品的特写开始，保持上一段结尾的镜头运动方向与音乐节拍"
- 若为最后一个片段：结尾必须写明"12-15s形成品牌记忆点：[具体记忆点内容]，画面停留在[具体画面]，音乐收束，留下余韵"
- 若非最后一个片段：结尾必须写明如何为下一片段预留衔接接口，如"片段结尾保留代言人转头的动作余势，镜头保持向右缓慢移动的动势，<低频转场音效>渐起，为下一片段预留动作与声音衔接接口"

### 8. 转场逻辑
明确所有镜头之间的转场方式，必须是无缝转场，说明物理依据，禁止黑场/白场/渐隐/渐显/叠化。

### 9. 声音设计
- 使用`<...>`标注具体物理音效，如`<皮革摩擦声>`、`<金属扣轻触声>`、`<车辆低频电机声>`、`<轮胎掠过湿地面的细密摩擦声>`、`<屏幕解锁轻响>`、`<镜头呼吸式低频冲击>`、`<转场低频下潜>`
- 使用`(...)`标注音乐情绪曲线，如`(冷调弦乐铺底)`、`(低频脉冲渐强)`、`(鼓点短暂停顿后重新进入)`、`(品牌Hero瞬间音乐抬升)`
- 若分镜中没有旁白或对话，不得自行添加；若存在旁白或对话，必须逐字保留，不得改写。

### 10. 负向约束（每个Prompt末尾必须包含）
```
no subtitles, no random text, no watermark, no unauthorized logo, no unauthorized brand mark, no product label unless explicitly approved, no malformed typography, no fading to black, no fade in, no fade out, no black screen, no extra character, no identity drift, no distorted face, no mutated hands, no product deformation, no vehicle deformation, no screen gibberish, no destructive transition.
```

## 禁用描述
Prompt中严禁出现以下词汇及相关破坏性概念：破裂、分割、破碎、裂缝、切割、爆破、碎片。
如需表达变化，使用：滑开、展开、抬起、翻转、漂浮、聚拢、旋转、靠近、遮挡、显露、折射、漫反射、高光滑移、焦点迁移、空间重构、节拍延续、声音桥、光影延续。
