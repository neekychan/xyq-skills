# 分镜图模板：音乐 MV · 舞蹈·唱跳

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以**舞蹈编排与唱跳表演**为核心的 MV 分镜，强调“动作有连贯、节拍有卡点、队形有层次”。
- **典型场景**：
  - 偶像/团体唱跳 MV、舞蹈翻跳、编舞展示。
  - 副歌“记忆点舞段”（hook dance）的分镜规划。
  - 街舞、现代舞、宅舞等舞蹈表演视频。

## 2. 判定关键词与适用边界
- 典型触发词：`唱跳`、`舞蹈 MV`、`编舞`、`翻跳`、`hook 舞段`、`卡点舞蹈`、`队形`。
- 适用判定：
  - 重点是舞蹈动作、节拍卡点与队形变化；
  - 需要把动作拆成关键姿态/分解步骤。
- 不适用场景：
  - 仅正脸演唱、无舞蹈 → 用“表演·对口型”模板；
  - 纯意象无人物动作 → 用“情绪氛围/概念视觉”模板。

## 3. 分镜结构建议
- **推荐宫格数**：8–16 格，按“乐段 + 关键舞蹈动作”拆分；
- 规划方式：
  - 按音乐结构定舞段：前奏律动 → 主歌基础步 → 副歌记忆点舞段 → 舞蹈 break → 收势；
  - 副歌 hook 舞段拆出起势/过程/爆发/定格等关键姿态，单独占格；
  - 标注队形（单人/双人/群舞）与机位（正面全景/低角度/环绕）。

## 4. 生图 Prompt（PE）模板

```text
你是一名唱跳 MV 分镜导演，请根据下述信息，设计一张 {宫格数} 宫格的“舞蹈·唱跳”分镜图，整体画幅为 {画幅比例说明，如“9:16 竖屏 MV”}。

【人物与歌曲信息】
- 表演者设定：{单人/团体、人数、形象与造型，需全片一致}
- 歌曲名称与曲风：{歌名 / 流行·电子·嘻哈等}
- 节奏与卡点：{BPM 或“副歌每 2 拍一个动作切换”等}
- 记忆点舞段：{描述副歌 hook 舞蹈的核心动作}

【拆分要求】
1. 按乐段 + 舞蹈动作拆格：前奏 → 主歌基础步 → 副歌 hook 舞段（拆关键姿态）→ break → 收势；
2. 每格标注：舞蹈动作/姿态、节拍点、队形、机位；
3. 副歌 hook 舞段至少拆 3–4 个关键姿态，保证动作连贯可读。

【分镜输出格式】
- 宫格编号：M1–M{N}，按时间与动作顺序排列；
- 对于每一格输出：
  - 所属乐段：{前奏/主歌/副歌/break/收势}
  - 舞蹈动作/姿态：{起势/过程/爆发/定格的具体姿态描述}
  - 节拍卡点：{如“副歌第 1 拍起手，第 2 拍定格”}
  - 队形与机位：{单/双/群；正面全景/低角度/环绕等}

【画幅与风格】
- 画面比例：{9:16 / 16:9}，默认 9:16，利于全身舞蹈展示（注意留全身空间）；
- 画风：{写实舞台 / MV 灯光 / 2D/3D 卡通}；
- 表演者形象与服装全片一致，舞蹈动作连贯、关节合理，避免肢体错位。
```

## 5. 一致性与避坑
- **动作连贯与人体结构合理**：相邻格的姿态要能自然衔接，避免关节扭曲、多手多脚。
- 全身舞蹈镜头要预留全身构图空间，避免裁切到关键动作。
- 群舞需保持队形与人数一致，避免人数忽多忽少。
- 表演者造型、服装、人数在全片保持一致。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“音乐 MV 类”执行模板：
  - 分镜图阶段把 hook 舞段拆为关键帧序列；
  - 视频阶段以关键姿态为参考帧，Prompt 中强调动作连续性与节拍卡点；
  - 若平台支持，按 BPM/节拍时间轴对齐动作切换。
- 动作拆解与连贯性复用 `storyboard/vfx-action-prompt.md` 与“动作分解 / 姿态连续”模板（`storyboard_action_motion.md`、`storyboard_action_pose_sequence.md`）的关键帧方法。
