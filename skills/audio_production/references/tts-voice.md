# TTS 语音工程：声线塑造、韵律控制与多角色编排

基于高保真语音合成（TTS）的文本声学标记、音色工程与对白控制指南。

---

## 一、标点符号声学停顿工程 (Punctuation-to-Cadence)

TTS 深度神经网络对文本标点具有高度敏感的声学映射。通过精准设计标点与换行，可彻底消除机械生硬感，赋予语音自然的呼吸气口与起伏律动：

| 标点 / 格式 | 声学物理响应 (停顿/包络) | 典型应用场景与情绪目的 | 示例 |
|---|---|---|---|
| **破折号 (`——`)** | **400~600ms 阻断停顿**，声带微悬空 | 意想不到的转折、戏剧性顿挫、重音强调前的蓄力 | `"成功从来不是偶然——而是无数次绝望中的坚守。"` |
| **省略号 (`……`)** | **500~800ms 渐弱衰减**，尾音微带叹息 | 沉思、回忆、情绪余韵、依依不舍 | `"那年夏天的蝉鸣，好像……再也没有响起过。"` |
| **双换行 (`\n\n`)** | **800~1200ms 深呼吸重置**，重置基频 | 段落转折、章节转换、换幕留白 | `"这是第一条法则。\n\n接下来，我们谈谈生存。"` |
| **单逗号 (`，`)** | **200~300ms 微换气**，声调平稳过渡 | 控制长句气口，防止一口气念完导致机械赶拍 | `"科技的温度，不在于冰冷的数据，而在于人性的关怀。"` |
| **感叹号 (`！`)** | **字头瞬态增强**，音量突增 +1.5dB | 强号召力、情绪爆发、关键动作指令 | `"此刻，出发！"` |
| **问号 (`？`)** | **句末基频上扬 20~40Hz**，微悬念感 | 设问、反问、引发受众思考与注意力拉拢 | `"在这个快节奏的时代，你有多久没有停下来了？"` |

### 旁白时长精确预估公式
$$\text{预估时长 (秒)} = \frac{\text{纯汉字数}}{\text{目标语速 (字/秒)}} + \sum (\text{各标点停顿总和})$$
*在编写 TTS `Text` 之前，先按目标总时长反推允许的总字数，避免后期视频或配乐无法对齐。*

## 三、多角色对白与声音工程规则

处理广播剧、短剧或多角色访谈对白时，遵循以下工程标准：

1. **分轨文件物理隔离**：
   严禁将不同角色的台词拼接在一句 Text 中一次性生成。每个角色的每句台词必须单独生成独立文件：
   - 角色 A：`assets/audio/voice/scene01_host_take01.mp3`
   - 角色 B：`assets/audio/voice/scene01_guest_take01.mp3`
2. **角色声线锁定 (Timbre Anchoring)**：
   同一角色在跨场景的所有生成中，必须复用**完全一致的 `VoiceDesc` 字符串**，防止音色发生漂移。
3. **对话交接时间隙编排 (Handover Padding)**：
   在后续混音拼接时：
   - 正常对白交替之间，保留 300~500ms 的自然停顿空白；
   - 争吵或紧迫插话时，可设置 -100ms~-200ms 的轻度重叠（Overlap）。
4. **多语言标识**：
   中文传 `Lang: "zh"`，纯英文传 `Lang: "en"`。中英混排且以中文为主体时（如讲科技专业术语），传 `Lang: "zh"` 即可。
