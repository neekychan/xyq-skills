# 3D古风短剧制作

## 启动协议

用户触发本技能时，首先判断属于以下哪种场景，并据此选择对应路径：

1. **从零开始（0→1）：** 用户只有创意构思或粗略大纲，尚无完整剧本。先与用户深入沟通，帮助其梳理故事框架、人物关系、核心冲突；在用户确认框架后，协助将构思发展为可拍摄的短剧剧本。每一步修改须向用户展示并确认，不得擅自定稿。
2. **半成品（需补充资产）：** 用户已有剧本或部分素材（剧本/分镜/设定图/参考图等），但不完整。分析已有素材，识别缺失环节（如缺角色设定图、缺部分场景描述、剧本未写明角色外貌等），逐项向用户确认补充方式后再推进。
3. **材料齐全：** 用户提供了完整剧本及全部所需资产图。直接进入分析→Storyboard→生成流程。

无论哪种场景，启动时须确认以下基础参数：
- 已有素材清单（请用户上传或粘贴现有剧本/分镜/设定图/参考图等）
- 输出语言偏好（分镜脚本通常中文；提示词通常英文，但中文同样可行）
- 画幅比例：**默认16:9横版**，如用户要求其它比例则以用户为准

**影像风格固定为3D古风，无需用户确认。**

## 核心原则

**最高原则——不擅自决策：** 本技能涉及的所有创作决策（剧本改写、角色外貌定义、场景细节补充、钩子设计、镜头取舍等），无论大小，必须向用户呈现选项或建议并经确认后才执行。宁可多问一句，不可擅自拍板。

**持久引擎（因果链）：**
用户输入（剧本/大纲/素材）→ 剧本分析与成熟度评估 → 钩子强度诊断 → 短剧化改编（可选）→ 全局风格锁定（3D古风/暖白肤色/光影基准）→ key_element登记与设定图生成 → Storyboard分镜设计（空间锚点/情绪动势/眼神互动） → 逐镜视频生成（参考帧四层过滤/首镜强制暂停） → 音频制作（BGM/旁白/内心OS内嵌） → 组装剪辑与音画同步 → 成片交付

## 质量测试（可证伪）

**如果第一镜确立的场景空间、人物站位、光影基调在后续镜头中出现漂移或矛盾，则该镜必须重新生成——空间一致性是3D古风短剧的生命线。** 没有空间锚点卡和参考帧机制保障的一致性，跨镜生成会级联失败，角色外貌漂移、背景元素矛盾、站位断裂，整片不可用。

## 输入诊断

生产前必须明确或合理假设的维度：

- **剧本来源与成熟度：** 完整分镜脚本 / 粗略大纲 / 小说原文（需短剧化改编）/ 仅有创意构想
- **剧本类型：** 权谋 / 武侠 / 言情 / 悬疑 / 其他古风类型
- **角色清单：** 姓名、身份、关系、多套造型需求
- **场景清单：** 空间类型、固定陈设、群像场景标识
- **关键道具清单：** 小型可移动物品（大型固定陈设归入场景）
- **钩子强度评估：** 开篇3秒是否有冲突/悬念/反转/视觉冲击
- **已有资产：** 用户上传的角色/场景/道具参考图是否为3D风格（非3D需风格转化）
- **缺失项识别：** 角色外貌未描述 / 场景空间细节不足 / 台词缺失等
- **目标时长与shot数量预估**
- **输出语言偏好**
- **合规敏感点：** 暴力尺度、敏感题材等

**信息缺失处理：** 剧本中未写明的角色长相、场景细节、影像风格，一律主动询问用户，不得静默假设或擅自补充。

## 工作流

### 阶段1：剧本/创意大纲分析与资产分析

1. 读取用户上传的剧本文件或创意大纲，提取角色（姓名、身份、关系）、场景（空间类型、关键陈设）、关键道具，识别剧本类型，评估剧本成熟度与钩子强度。
2. 若用户上传的是小说而非分镜脚本，识别并标注需短剧化改编的部分，告知用户该文本需先完成改编。向用户提供两种选项：**①用户自行修改**（推荐优先）；**②由Agent协助优化**（生成改编建议，逐条展示并经用户确认后落地）。无论哪种方式，都不得擅自补全剧本中未描述的角色外貌或场景细节。
3. 分析用户上传的角色/场景/道具参考图，判断是否为3D古风风格——若非3D风格，标注"需风格转化"并记录原图身份特征供后续转化使用；若为3D风格，标注"可直接绑定"。
4. 分析上传参考图中的场景空间布局信息；若场景描述不足以确定空间方位关系，标注"需向用户确认空间布局"。
5. 输出结构化分析报告：角色清单、场景清单、道具清单、剧本类型、成熟度评估、钩子评估、缺失项清单。

**关键暂停点：** 剧本分析完毕后暂停，告知用户剧本类型、成熟度评估、缺失项，等待用户确认再继续。

### 阶段2（可选）：剧本细化与钩子增强

当用户的剧本尚不成熟时，主动向用户提供以下服务，但须逐项展示修改建议并经用户确认后才落地，绝不在用户不知情的情况下改写剧本：

- **钩子增强：** 分析前3秒（对应开篇第1个shot）是否具备足够吸引力——冲突、悬念、反转、视觉冲击至少占其一。若开篇平淡，向用户提出具体改写建议，等用户确认后再写入。
- **节奏与冲突密度优化：** 检查各幕是否存在拖沓段落（连续多shot无冲突推进、无情绪变化），向用户指出并建议收紧或增补冲突点。
- **角色动机与关系线补全：** 若角色行为缺乏动机或关系线断裂，向用户提出问题并建议补全方向，由用户决定是否采纳。
- **台词精炼：** 若台词冗长或口语现代化，向用户标注并建议改写，由用户确认。

**所有细化建议以卡片或对话形式逐条呈现，用户逐条确认后才能写入剧本；用户否决的不得强行保留。**

**关键暂停点：** 剧本细化建议逐条确认后暂停，进入全局制作参数与Storyboard前。

### 阶段3：全局制作参数

将全局制作参数记录如下：
- 画幅比例：16:9横版（默认，如用户要求其它比例则以用户为准）
- 目标时长
- 影像风格基调：3D古风
- 输出语言

### 阶段4：Storyboard设计

详细规则见 `references/storyboard-design.md`。核心步骤：

1. **全局风格锁定：** 统一3D建模风格，明亮清透色调，饱和度中低到中等，阴影柔和暗部保留细节，不出现射光/体积光。场景华丽细节强化，角色服装纹样强化，禁止任何现代元素。
2. **登记key_element：** 角色（含跨角色暖白肤色一致性锁定）、场景（含固定光影基准与四向空间信息）、关键道具（大型固定陈设归入场景）。登记角色key_element_audio（音色样本）。
3. **拆解shot列表：** 每个shot ≤ 15s，建议2—5个内切镜，出场人物 ≤ 3人。优先设计10—15s较长镜头，最低10s。连续动作不拆镜。每个shot须包含空间锚点卡、人物动作与对白（含情绪动态、眼神互动、台词落点停留）、分镜语法三件套（景别+机位+运镜）。
4. **设计audio_layer：** BGM、第三人称旁白VO、角色内心OS（内嵌于视频生成，不单独生成）。

**关键暂停点：** Storyboard草稿确认后暂停，进入生成前。

### 阶段5：key_element设定图生成

详细模板见 `references/prompt-templates.md`。核心规则：

1. **角色设定图：** 文生图，2K分辨率，16:9横版。左侧1/3面部特写 + 右侧2/3全身三视图。所有角色统一风格关键词与暖白肤色。
2. **场景四视图：** 文生图，2K分辨率，2×2网格四向空间覆盖。平光无阴影均匀照明，色彩调性与全局基调一致。
3. **关键道具设定图：** 文生图，2K分辨率，纯白背景。
4. **同一角色多套造型：** 图生图，首套造型图为参考，锁定脸型/五官/肤色/身高比例，仅替换服装/发型/妆容/配饰。
5. **角色key_element_audio：** 语音合成，10—15s音色样本，注册绑定到角色。
6. **用户上传非3D资产图：** 图生图风格转化，保持身份特征不变，仅转化渲染风格。

**关键暂停点：** 所有key_element设定图确认后暂停——此时通过卡片向用户询问视频生成模式（见下文）。

### 阶段6：逐shot视频生成

详细规则见 `references/prompt-templates.md`（视频提示词段）与 `references/spatial-consistency.md`。核心规则：

1. **生成前资产重检（强制）：** 每次生成镜头视频之前，必须重新检查当前镜头涉及的所有key_element下已有哪些已绑定资产，以及当前镜头是否已有参考资产。用户可能随时新增资产，不可依赖上次的记忆。
2. **防漏帧校验（强制）：** 若检查发现当前shot所需的某种参考帧在前序截取帧中不存在，须先回溯前序shot视频补截对应帧并补做视觉内容分析，补截完成后再进入生成。
3. **第一个shot的参考输入：** 该镜涉及的所有角色key_element图像（选取对应造型）+ 场景四宫格key_element图像。
4. **从第二个shot起追加空间一致性参考帧：** 从所有已生成的前序shot中挑选参考帧，须通过四层过滤（背景内容匹配→角色过滤→方向过滤→景别兼容性），任一层不通过则排除。若所有前序帧均未通过背景内容匹配过滤，改用角色key_element图像 + 场景四宫格 + 提示词文字描述固定站位关系。
5. **撰写视频提示词前须执行空间校验（强制）：** 对照空间锚点卡逐角色确认背景元素描述正确，确认画面外不可见元素已排除，确认参考帧背景内容匹配。
6. **视频提示词结构：** [影像风格] → [摄影机] → [主体] → [空间] → [音频] → [禁止] → [时长]，各段规则详见 `references/prompt-templates.md`。
7. **视频生成：** ≤15s的视频用一次生成即可拿到完整片段。若视频生成失败，可尝试重新生成；若多次失败，停止任务并向用户说明。

**第一个shot视频生成后强制暂停（强制·不受模式选择影响）：** 第一个shot生成后必须暂停，向用户展示视频，请用户确认场景布局是否正确、人物站位是否合理。若用户不满意，根据反馈调整空间锚点卡/shot描述后重新生成。确认通过后再继续后续shot。

**重新生成单个shot时的内容锁定（强制）：** 须复用该shot已确认的提示词原稿，仅改用户指定部分。重新生成前须向用户展示"保留内容vs修改内容"清单，经用户确认后执行。

**视频生成模式选择（进入视频生成前强制询问）：** 在所有key_element设定图确认通过、即将开始逐shot视频生成时，必须通过卡片向用户提供以下两种模式选择：
- **一键生成模式：** 第一个shot仍强制暂停确认。确认通过后，剩余所有shot连续生成，中途不再逐镜暂停；全部shot生成完毕后统一向用户展示结果。若用户在生成过程中主动要求暂停或修改，则立即响应。
- **逐镜确认模式：** 每个shot生成后都暂停，向用户展示视频并等待确认再生成下一个。

无论哪种模式，第一个shot的强制暂停均不可跳过。

### 阶段7：音频生成

1. **BGM：** 音乐生成，按audio_layer中的BGM设计生成。视频本身不内嵌BGM，后期混音。
2. **第三人称旁白VO：** 语音合成，按narration_speaker_profile生成。
3. **角色内心OS：** 内嵌在视频生成中（写入视频提示词[音频]段，与台词同级），通过角色key_element_audio绑定保持音色一致。OS期间角色嘴唇不动，须为OS时段设计具体的面部表情变化路径。

### 阶段8：组装与剪辑

1. 按Storyboard shot顺序组装时间线。同一物理空间内相邻shot优先无缝硬切；跨空间切换可使用淡入淡出（0.3s以内）。
2. 注意180°轴线规则：若两个相邻shot之间出现跳轴，在中间插入一个正面或过肩过渡shot。
3. 音频混音：BGM音量低于人声8—12 dB，情绪高潮段可适当提升3—5 dB。BGM与旁白/台词交叉淡化处理（crossfade 0.5s）。
4. 组装时如发现跨镜站位漂移或场景背景不一致，须回溯至阶段6重新截取参考帧或调整空间锚点描述。
5. 导出基准：分辨率对齐生成时最高规格（默认720p），帧率24fps。

**关键暂停点：** 所有分镜视频生成完毕后暂停，进入组装前。

## 关键暂停点汇总

每个阶段完成后必须暂停，等待用户确认再继续（视频生成阶段除外，由模式选择决定）：
1. 剧本分析完毕后（告知用户剧本类型、成熟度评估、缺失项）
2. 剧本细化建议逐条确认后（进入全局制作参数与Storyboard前）
3. Storyboard草稿确认后（进入生成前）
4. 所有key_element设定图确认后（进入视频生成前——此时通过卡片询问视频生成模式）
5. **第一个shot视频生成完毕后（强制，无论哪种模式——确认场景空间、人物站位是否合理）**
6. 所有分镜视频生成完毕后（进入组装前）

**半成品场景的资产缺口处理：** 分析已有素材后，将缺失环节整理为清单向用户展示，逐项与用户确认补充方式（用户提供/生成补充/用户口述后由Skill整理），不得在用户未确认时擅自补全。

## 输出契约

### key_element设定图
- 角色设定图：16:9，2K，左侧面部特写+右侧三视图，纯白背景
- 场景四视图：16:9，2K，2×2网格四向空间覆盖，平光无阴影
- 关键道具图：16:9，2K，纯白背景
- 角色音色样本：10—15s，注册并绑定到角色

### Storyboard
每个shot结构：
- 空间锚点卡（场景名/固定参照物/人物当前状态/离场角色位置状态/光影基调）
- 场景引用（element scene ID）
- 人物动作与对白（含情绪路径/眼神互动/台词落点停留/动作落点停留）
- 分镜语法三件套（景别+机位+运镜）
- 时长（≤15s，≥10s）

### 单shot视频提示词
固定结构：[影像风格] → [摄影机] → [主体] → [空间] → [音频] → [禁止] → [时长]

### 视频生成方式
≤15s的成片用一次视频生成即可拿到完整片段。多段beat（0-3s/3-7s/…）是同一次生成内部的时间轴描述，不等于要多次调用。只有成片时长超过15秒时，才需要拆成多个≤15s片段分别生成，再做后处理拼接。

## 静默自检

交付前逐项核查：

- [ ] **遗漏检查：** 原剧本中所有关键动作、台词、转折是否都有对应shot？
- [ ] **逻辑一致性：** 人物在前后shot的位置/镜头相对背景描述/手持物是否连贯？空间描述是否使用了镜头相对写法？
- [ ] **在场/离场一致性：** 已离场角色原位置/道具在后续shot中的视觉状态是否被显式登记且逐镜一致？
- [ ] **接镜顺畅度：** 前一shot出画方向与后一shot入画方向是否符合轴线规则？
- [ ] **景别偏好：** 有人物镜头是否以近景/特写/大特写为主？是否出现全景/大全景（禁止）？
- [ ] **时长合规：** 每个shot合计是否≤15s且≥10s？固定镜头是否均≤4s？
- [ ] **镜头动势合规：** 每句台词对应的内切镜是否都包含至少一个镜头动势词？是否存在零动势镜？
- [ ] **情绪动态合规：** 每个shot内是否有情绪起伏与递进？关键节拍处情绪强度是否显式放大？
- [ ] **眼神互动合规：** 每句台词是否至少附带一个眼神动作？对话场景中是否设计了角色间的眼神互动？
- [ ] **空间一致性：** 同一场景下所有shot的光影基调是否与场景element scene的固定光影基准完全一致？
- [ ] **角色一致性：** 角色代号是否全程统一？跨角色肤色是否统一为暖白？
- [ ] **风格关键词：** 所有提示词是否逐字写入了风格关键词组？是否禁用了真人摄影/解剖学词汇？
- [ ] **禁用比喻性情绪词：** 提示词中是否避免了"面目狰狞""面色惨白"等带物理外观副作用的比喻词？
- [ ] **现代元素禁止：** 所有角色造型、服装、道具、建筑、台词是否严格符合古代/古风世界观？
- [ ] **首镜暂停：** 第一个shot是否已执行强制暂停确认？
- [ ] **措辞是否正向：** 提示词是否以正向措辞为主，不堆否定式约束？
- [ ] **全文语言一致性：** SKILL.md与references是否与目标市场语言一致，无中英混杂？
