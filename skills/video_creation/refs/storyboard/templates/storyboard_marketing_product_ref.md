# 分镜图模板：营销转化 · 商品图参考分镜

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以现有商品实拍图、电商主图、详情页图片为主参考，围绕这些图像构造分镜图的“商品图参考分镜”，强调严格还原产品外观、包装细节与颜色，不允许随意改造。
- **典型场景**：
  - 有成熟电商素材，希望基于现有商品图做图生视频；
  - 品牌方提供官方产品图/包装设计稿，需要保持高度一致；
  - 多 SKU 商品集合，按已有主图与细节图排布分镜，制作选品/合集视频。

## 2. 判定关键词与适用边界
- 典型触发词：`商品图参考`、`电商主图`、`参考图生视频`、`按现有图片做分镜`、`不要改产品外观`、`按这个主图做视频`。
- 适用判定：
  - 用户已提供多张商品实拍图/主图/详情图，并明确要求“按照这些图做分镜/做视频，不要改样子”；
  - 对产品外观、包装、Logo 位置等一致性要求极高（如品牌旗舰店、政企/医疗/金融等严肃品类）。
- 不适用场景：
  - 主要需求是设计新包装或新视觉 → 更适合“视觉设计/主视觉生成”类流程而非分镜；
  - 没有现成商品图，只想概念性展示产品 → 可归为“产品讲解型分镜图”；
  - 对产品外观容许较大创意改动，只要传达卖点 → 优先使用其他营销分镜模板。

## 3. 分镜结构建议
- **推荐宫格数**：根据参考图数量确定，常见为 6 / 9 / 12 格；参考图较少时可通过同一商品图的不同构图与场景扩展画面，但外观不得改变。
- **结构骨架**：
  1. 商品主图还原（1–2 格）：严格还原核心主图的构图与光线，用于片头或关键卖点段；
  2. 细节特写与卖点（2–4 格）：围绕包装细节、功能细节、材质纹理等做特写，仍以参考图为基础；
  3. 使用场景延展（2–4 格）：在不改变产品外观的前提下，将商品放入生活场景或模式图中；
  4. SKU/组合展示（1–3 格，可选）：将多款同系列商品按参考图组合排布；
  5. Logo/Slogan 与 CTA 收尾（1 格）：沿用品牌视觉规范收束。
- **规划方式**：
  - 先整理用户提供的所有商品图，按“主图/细节图/场景图/组合图”分类，再为每类分配若干宫格；
  - 分镜说明要显式写出“参考哪一张图”，例如“参考图1：主图”“参考图3：背面包装”，以便后续图生视频严格对齐；
  - 画幅比例可根据原图比例设置 ratio=0（跟随原图），或在 plan 中标注统一目标比例后，由脚本做智能裁切，禁止在分镜 Prompt 中让模型随意拉伸或改变比例。

## 4. 生图 Prompt（PE）模板

```text
你是一名电商视觉分镜师，请基于下述商品参考图片，设计一张 {宫格数} 宫格的“商品图参考分镜图”（用途类型 = 商品图参考分镜），整体画幅为 {画幅比例说明，如“9:16 竖屏带货视频”或“16:9 横版合集视频”}，在所有格中严格保持产品外观与包装细节与参考图一致。

【商品与品牌信息】
- 品牌名称：{品牌名称}
- 产品品类：{如护肤品/家电/数码/服饰/食品等}
- 产品名称或系列：{产品名称}
- 核心卖点：{3–6 条简要卖点，用于分配到各格}

【参考图片列表】
- 参考图1：{文件路径或 ID + 简要说明，如“电商主图，正面视角”}
- 参考图2：{如“背面包装细节图”}
- 参考图3：{如“顶部/底部结构图”}
- 参考图4：{如“使用场景图”}
- ……按实际数量补充说明，确保每张图的用途清晰。

【一致性要求】
- 所有格中的产品造型、颜色、Logo 位置、文案排版必须与对应参考图完全一致，不得随机更改。
- 若某格为“场景延展”，仍需以参考图中的产品为基础，只调整背景与光线，不改变产品本身。
- 若用户指定某张图为“必须完整还原”的关键参考图，请标记为“锁定参考”，在分镜说明中重复强调。

【分镜排布】
- 宫格数量：{宫格数，如 6/9/12 格}，按阅读顺序编号 R1–R{N}。
- 推荐结构：主图还原 → 细节特写 → 使用场景 → SKU/组合展示 → Logo/Slogan + CTA。

【文字分镜列表 + 逐格分镜输出要求】
在正式构造图像 Prompt 前，先以纯文字列表形式列出 R1 到 R{N} 的分镜要点（每格对应的参考图编号与卖点），供用户确认；确认后再按以下格式，为每格写出详细中文分镜说明：
1. R1：
   - 参考图绑定：{如“参考图1：电商主图”}
   - 画面内容：{说明如何在分镜中还原这张主图的构图与光线}
   - 卖点信息：{该格强调的核心卖点或标签}
2. R2：
   - 参考图绑定：{如“参考图2：包装背面细节图”}
   - 画面内容：{特写某个功能描述、成分信息或注意事项}
   - 卖点信息：{与细节相关的卖点说明}
……
直到 R{N}，保证每格都绑定至少一张参考图，并明确该格的卖点或展示作用。

【画幅与风格约束】
- 画面比例：{9:16 / 16:9 / ratio=0 跟随原图}，在 Prompt 中说明是否需要依据参考图原始比例保持或统一裁切。
- 画风：{写实摄影/3D 渲染/电商插画等}，应与原始商品图画风接近，避免跨风格重绘。
- 禁止在分镜生成阶段让模型随意改动产品造型或添加不在参考图中的元素（如奇怪的贴纸、额外文字），必要文字与 UI 均由脚本后期叠加。
```

## 5. 一致性与避坑
- 所有产品形态必须与参考图严格对齐：颜色、材质、比例、Logo 位置、包装版式均不可随意更改，尤其是在严肃行业（医疗、金融、政企）中。
- 分镜说明中必须显式写出“参考图绑定关系”，避免后续生图或生视频时漏传参考图片，导致模型凭空改造产品。
- 不要在同一视频中混用画风差异极大的参考图（如棚拍与纯插画），若必须混用，应在 plan 中明确主风格并在分镜中用统一调色或版式平衡差异。
- 参考图数量有限时，宁可在多个格中重复使用同一参考图（配以不同文本与构图变化），也不要让模型凭空“想象新包装/新颜色”。
- 若用户提供的参考图包含大量中文文案，需在 plan 中说明“图像模型不直接生成长篇中文文字”，让脚本或后期叠加字幕与价格信息，以提升画质与文字清晰度。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中“产品讲解分镜图”营销执行模板：
  - 将商品图参考分镜视为产品讲解分镜的“参考图强约束”变体，在视频 Prompt 中复用同一输入结构（分镜图 + 参考图 + 目标画幅 + 模型），但增加对参考图一致性的硬性说明；
  - 在 plan 中明确每段视频使用的参考图列表，与 R1–R{N} 的绑定关系一一对应。
- 视频生成时严格走“参考图生视频”链路：
  - 对每个关键镜头，将对应的商品图作为 ImageList 的参考帧输入，禁止在无参考图情况下生成产品画面；
  - 使用 seedance2.0_fast_vision 或 seedance2.0_direct 等视觉模型提升还原度，探索阶段可先用 seedance_2.0_fast 验证节奏。
- 镜头节奏建议：开头 1–2 镜显示主图与品牌信息，中段按参考图顺序展示细节与场景扩展，结尾 1–2 镜回收主图或组合图并叠加 Logo/Slogan 与 CTA。
- 若用户希望直接从商品图生成无分镜的视频，可在 plan 中说明“先按商品图参考分镜模板输出最小分镜表（如 6 格），再按 `storyboard-sheet-prompt.md` 的视频模板生成短视频”，避免缺乏结构导致信息堆砌。
