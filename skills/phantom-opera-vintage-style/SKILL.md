# 歌剧魅影戏剧复古风

把一段固定的「风格锚定词」注入到本次任务里**每一条**图片 prompt 与视频 prompt 的最开头，让同一批图片素材与视频成片拥有完全一致的《歌剧魅影》电影级戏剧复古质感。这是一个**风格滤镜**技能:它不决定画什么,只决定「所有东西都长成同一种画风」。

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## 核心原则(因果链)

不变的因果链:`风格锚定词恒定 → 每条 prompt 头部统一注入 → 图片素材画风一致 → 视频画风与图片素材一致 → 整批产物观感统一`。

只要锚定词在**所有** prompt 的开头逐字出现,画风一致性就成立;任何一条 prompt 漏注入或改写了锚定词,这条因果链即断裂。

**可证伪质量测试:** 把本次生成的任意两张图片、任意一段视频并排观看,若能明显看出它们「不是同一套渲染管线 / 同一部电影里出来的」(辉光强弱、雾化浓淡、配色冷暖、镜头光斑肌理不统一),则本技能执行失败。反之,若陌生人会认为它们出自同一部《歌剧魅影》风格电影,则成立。

## 风格锚定词(本技能的核心资产)

以下为固定风格锚定词,**逐字使用,不得改写、删减、翻译或重排**:

> **《歌剧魅影》电影质感，华丽复古风格，复古戏剧化朦胧辉光滤镜，充满阴郁神秘感，末世神话与超现实梦境。整体画面低饱和度，高光影反差，十分梦幻和迷幻的感觉，变形镜头光斑。主光源以暖橙为主，辅以极其讲究的微光，画面干净空旷华丽，暖色高曝辉光与体积雾共同塑造空间深度，低饱和度 、低对比度的高光影反差营造拍摄真实感。镜头前始终附着环境的微粒肌理，每帧都有自然的暗调辉光弥散效果。**

这段词就是「锚定词」。下文所有「注入锚定词」均指把上面这段中文原文放在 prompt 最前面。

## 注入规则(硬规则,最高优先级)

1. **位置固定:** 锚定词永远放在每条 prompt 的**最开头**,后面紧跟一个逗号,再接本条画面的具体描述。顺序恒为「锚定词 → 具体画面」,不得颠倒。
2. **逐字一致:** 每条图片 prompt、每条视频 prompt 使用的锚定词必须**字节级一致**——同一批任务里不能这条多一个字、那条少一个字。
3. **全覆盖:** 本次任务里需要生成的**所有**图片素材与**所有**视频片段,无一例外都要在头部注入锚定词;包括中途返工重生的素材。
4. **不污染具体描述:** 锚定词只负责画风;镜头、动作、构图、人物、场景等具体内容照常写在锚定词之后,不要因为有了锚定词就省略画面描述。
5. **语言:** 锚定词与具体画面描述统一用中文书写(与锚定词语言一致);如确需英文版本,仅可作为补充,且锚定词部分不翻译、保持中文原文。

## 禁止内置风格锚定图干扰(硬规则,最高优先级)

部分 Agent 生图 / 生视频链路针对某些风格预置了「内置风格参考图 / 风格锚定图 / 默认风格垫图 / style reference image」。这些内置参考图会与本技能的锚定词争夺画风控制权,污染产物质感,**必须绕过**。

- **一旦本技能生效,即视为用户已显式指定专业风格,禁止启用、注入、附加任何链路内置的风格锚定图 / 默认风格参考图 / 预置 style image**;本技能锚定词是唯一的画风来源。
- 若生图 / 生视频工具支持「关闭默认风格参考 / 不使用内置垫图 / 清空 style reference」的参数或开关,**必须显式关闭**,再进行生成。
- 若某工具无法关闭内置风格图、只能在「用内置风格图」与「用本技能锚定词」之间二选一,**优先本技能锚定词**;宁可不使用该工具的风格图能力,也不能让内置风格图覆盖锚定词。
- 用户主动提供的参考图(角色定妆图、分镜草图、指定首帧等)不属于「内置风格锚定图」,可正常使用;要绕过的只是**链路自带、非用户指定**的风格垫图。
- 自检:若发现某张产物的画风更像链路默认风格而非本技能锚定词描述的《歌剧魅影》质感,判定为内置风格图未绕过干净,关闭 / 剔除后重生。

## 与其它风格 skill 搭配时的合并规则(务必遵守)

当本技能与其它「风格 / 画风」类 skill 同时启用、需要叠加多种风格时:

- **合并而非替换:** 把各风格 skill 的锚定词**依次拼接**成一段合并锚定词,整体放在 prompt 最开头,后接具体画面。本技能的锚定词按用户 / 加载顺序排入,不单独另起。
- **规则不变:** 合并后仍遵守上面全部注入规则——位置固定在最开头、逐字一致、全覆盖、不污染具体描述、禁止内置风格图干扰。合并锚定词在本次任务的所有 prompt 里同样逐字一致。
- **去重:** 若多个风格锚定词出现完全重复的短语,可去重一次,但本技能锚定词的实质内容不得删减。
- **冲突时:** 若两套风格存在直接矛盾的表述,保留双方原文并列即可(不臆改),由生成模型融合;不要为了「调和」而改写任一方锚定词。

## 与非风格类 skill 搭配时的约束(务必遵守,最高优先级)

当本技能与**非风格类** skill(如营销短片 / 短剧 / 广告脚本 / 分镜生成 / 视频创意等)同时被调用时,可能出现职责冲突:对方 skill 也会给出图片 / 视频 prompt 的组织方式。此时以本技能的画风控制为准:

- **画风归本技能,内容归对方:** 对方 skill 负责「拍什么」(叙事、卖点、节奏、分镜结构、口播、字幕等);本技能负责「长成什么画风」。无论对方 skill 如何组织 prompt,**每一条最终送入生图 / 生视频工具的 prompt,其最开头都必须逐字注入本技能锚定词**,再接对方 skill 产出的具体画面 / 分镜描述。
- **本技能规则不可被覆盖:** 即使对方 skill 有自己的 prompt 模板、风格倾向或默认画风建议,也**不得替换或省略**本技能锚定词;对方模板里的画面描述部分照用,画风前缀一律替换为本技能锚定词。
- **禁止内置风格图规则同样生效:** 加载了营销 / 短片类 skill 后,若其链路引入内置风格锚定图,同样按上文「禁止内置风格锚定图干扰」处理,一并绕过。
- **结合方式:** 先让对方 skill 产出内容 / 分镜 / 文案,再由本技能对每一条画面 prompt 统一加锚定词前缀并做画风质检。交付时对方的叙事结构与本技能的统一画风二者兼得。
- **判定优先级:** 凡涉及「最终产物长什么样、画风、光影、色调、辉光、镜头质感」的决策,本技能规则高于对方 skill;凡涉及「讲什么故事、卖什么点、怎么排结构」的决策,尊重对方 skill。

## 风格知识库(供写分镜 / 角色 / 场景 / 脚本时形容参考)

本节是**创作参考素材**,当用户没给分镜、需要 Agent 补齐分镜草案、角色设定、场景描述或风格脚本时,从下面取词造句,让「具体画面描述」部分也贴近《歌剧魅影》戏剧复古气质。锚定词本身仍逐字不变,本节只影响锚定词**之后**的具体描述。

### 整体风格气质

- 关键词:华丽而阴郁、神秘、末世神话感、超现实梦境、戏剧张力、宿命与哀愁、盛装下的孤独、被时间遗忘的辉煌。
- 情绪基调:压抑中的美、繁华落幕、朦胧不真实的梦境感、悲剧的浪漫、危险的诱惑。
- 时代质感:19 世纪末巴黎歌剧院、镀金巴洛克 / 洛可可装饰、丝绒与烛台、面具舞会、地下湖穴、老旧机械与吊灯。

### 场景光影典型质感

- 光源:主光源暖橙(烛光 / 煤气灯 / 舞台聚光)为主,辅以极讲究的微光;暖色高曝辉光配合体积雾塑造空间深度。
- 反差:低饱和、低对比度下的高光影反差——亮处发光晕开,暗处沉入暗调,而非硬边黑白。
- 空气感:画面前景始终附着环境微粒肌理(浮尘、雾、烟、飞絮),每帧自然的暗调辉光弥散。
- 镜头:变形宽银幕镜头质感、横向拉丝光斑(anamorphic flare)、浅景深、柔焦辉光边缘、轻微暗角。
- 典型场景:烛火通明的空旷歌剧大厅、垂落的巨型水晶吊灯、地下暗河与孤舟、镜廊与面具、后台幕布与道具堆、被红丝绒包裹的包厢、暴雨夜的哥特建筑外景。

### 角色造型典型质感

- 服装:华丽复古礼服、束胸长裙、燕尾服与斗篷、蕾丝手套、镀金刺绣、面具(尤其半脸白瓷面具)、羽饰头冠。
- 妆发:苍白肤色配深邃眼影、复古卷发或高盘发、烛光下的高光颊骨、神秘而疏离的神态。
- 姿态:戏剧化的肢体语言、舞台式的凝望与转身、盛装孤影、掩面 / 执烛 / 抚琴等富仪式感的动作。
- 气质:优雅中带危险、脆弱与执念并存、被面具遮蔽的身份、宿命纠缠的爱恋。

### 故事 / 脚本风格参考

- 叙事母题:被隐藏的天才与畸零者、面具下的深情与占有、舞台上的荣光与幕后的黑暗、宿命的三角情感、繁华崩塌前的最后一夜。
- 节奏:缓入的悬念、静默中的张力、情绪在高潮处骤然爆发、悲剧收束。
- 分镜倾向:大量空镜渲染氛围(空荡大厅、摇曳烛火、飘落的幕布)、以光影和雾切换情绪、特写面具与眼神、以吊灯 / 镜子 / 蜡烛作为反复出现的符号意象。
- 用法提示:写脚本时可用「末世神话」「超现实梦境」串联超现实转场;用「暖橙微光 + 体积雾」统一每个场景的氛围锚点。

> 以上知识仅用于丰富锚定词**之后**的具体画面 / 分镜 / 角色 / 脚本描述,帮助整体内容更贴近风格;不改变、不替代锚定词本身。

## 输入

- **必需:** 本次要生成的画面清单(要哪些图片素材、要哪些视频片段及其内容 / 分镜)。
- **可选:** 是否与其它风格 skill 叠加;视频画幅 / 时长偏好;是否需要图片先行作为视频的首帧参考。
- **素材缺失只追问缺失项:** 若用户只给了「用这个风格做一个 XX 短片」而没给分镜,按上文风格知识库补齐一版分镜草案并说明,再统一注入锚定词;不要反复追问已明确的信息。

## 工作流(Steps)

1. **确认锚定词形态。** 若仅本技能生效,锚定词 = 上文原文。若与其它风格 skill 搭配,先按「合并规则」拼出合并锚定词,后续全程复用这一版。若同时加载了非风格类 skill,按「与非风格类 skill 搭配时的约束」明确画风归本技能、内容归对方。
2. **绕过内置风格图。** 生成前先按「禁止内置风格锚定图干扰」检查并关闭链路内置风格参考图 / 默认垫图,确保画风只来自锚定词。
3. **生成图片素材(逐张)。** 对每一张需要的图片,组装 prompt = `锚定词 + "，" + 该图具体画面描述`(具体描述可引用风格知识库措辞),然后生成图片。所有图片共用同一份锚定词。生成后展示给用户。
4. **图片质检与返工。** 对照质量测试检查画风一致性;若某张明显跑偏(或更像内置默认风格),重写该图的**具体画面**部分(锚定词不动)并重生,直到整批图片观感统一。
5. **生成视频(逐段)。** 对每一段视频,组装 prompt = `锚定词 + "，" + 该段镜头 / 动作 / 画面描述`,再生成视频。
   - **≤15s 的片段一次生成即可拿到成片**,无需分段拼接;分镜 beat(如 0-3s / 3-7s)只是同一次生成内部的时间轴描述。
   - 仅当成片时长**超过 15 秒**时,才把它拆成多个 ≤15s 片段分别生成,每段头部同样注入同一份锚定词,再做后处理拼接。
   - 若用户要求视频与前面某张图片衔接,可将该图片作为视频的画面参考,视频 prompt 仍在头部注入锚定词。
6. **视频质检与返工。** 检查视频画风是否与图片素材一致;跑偏则改具体描述后重生(锚定词不动)。
7. **交付并展示。** 把最终的图片与视频产物展示给用户;需要保存时按用户要求处理文件。

## 输出契约

每条产物 prompt 必须满足:

```
<锚定词逐字原文>，<本条具体画面 / 镜头 / 动作描述>
```

- 图片 prompt 与视频 prompt 均遵循此结构。
- 同一批任务内,`<锚定词逐字原文>` 部分字节级一致。
- 视频片段附带其 beat 分镜(时间轴)时,分镜写在具体描述内,锚定词仍只出现一次且在最前。

## 静默自检(交付前内部跑一遍,不展示给用户)

- [ ] 本次每一条图片 / 视频 prompt 的**最开头**都逐字出现了锚定词(或合并锚定词)?
- [ ] 同一批任务内锚定词是否字节级一致、无任何一条被改写 / 漏注入?
- [ ] 锚定词之后是否都保留了具体画面描述,没有被风格词挤掉?
- [ ] 是否已绕过链路内置风格锚定图 / 默认垫图,画风只来自锚定词?
- [ ] 若叠加了其它风格 skill,是否按合并规则拼接、规则未变、未删减本技能锚定词?
- [ ] 若叠加了非风格类 skill(营销 / 短片等),是否做到画风归本技能、内容归对方,锚定词未被对方模板覆盖?
- [ ] 图片之间、图片与视频之间画风是否通过了「同一部《歌剧魅影》风格电影」的一致性测试?
- [ ] 超过 15s 的成片是否才做了分段;≤15s 的是否一次生成?

发现弱项就在交付前重写对应 prompt 并重生,不要把本清单暴露给用户。
