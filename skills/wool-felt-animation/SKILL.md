## 核心原则
羊毛毡动画的核心是「用羊毛毡材料1:1复刻真实世界」，而非制作微缩模型、玩偶舞台或Q版手办。所有场景、道具、建筑、食物均保持真实世界比例，仅材质替换为羊毛毡；角色造型根据叙事需要分级（写实可爱/适度Q版/高度Q版），不强制全片统一风格。画面与旁白强绑定，每个镜头的动作、构图、情绪必须直接对应旁白内容，禁止声画脱节。全流程逐节点暂停，用户确认后再推进下一阶段。

### 持久引擎（因果链）
文案输入 → 规格锚定（9:16竖屏、羊毛毡风格基准）→ 故事板分镜（声画对应、10-15s/镜头、内部分段）→ 元素资产（角色/场景三视图，风格统一）→ 逐镜头生成（单镜头确认后推进）→ 可选音频（BGM/旁白按需生成）→ 合成导出

### 质量测试
成片需满足：1）所有物体表面均有可见羊毛纤维纹理，无尖锐棱角、无CG光泽、无真实人类皮肤；2）场景为真实比例的羊毛毡世界，无微缩模型/玩偶舞台感；3）每个镜头画面内容与旁白100%对应，无声画错位；4）角色动作流畅柔和，无僵硬卡顿；5）全片风格统一，无跨镜头材质跳变。

## 输入诊断
启动制作前必须确认以下维度，缺失项主动向用户询问：
1. **文案内容**：用户提供的纯文字脚本/旁白内容，无需参考视频
2. **视频规格**：固定比例9:16竖屏，需确认预计总时长、主题情绪基调
3. **旁白配置**：是否需要旁白配音、旁白语言（中文/英文等）、配音风格偏好
4. **BGM需求**：是否需要背景配乐，偏好的音乐情绪/乐器
5. **角色参考**：若用户有指定的角色形象参考图可提供，无则完全按文字描述生成
6. **合规敏感点**：严格遵守内容合规规范，避免违规内容，商业内容需符合广告法规范

## 工作流（严格按顺序执行，逐节点暂停确认）
### 阶段1：文案接收与规格确认（planner）
1. 读取用户提供的纯文字文案/旁白内容，无需用户上传参考视频
2. 生成《Final_Video_Spec.md》，包含：视频标题、固定比例9:16、预计总时长、主题情绪、羊毛毡风格基准说明
3. **暂停点1**：向用户展示规格文档，确认时长、主题、旁白语言，用户确认后进入下一阶段

### 阶段2：故事板设计（storyboard_designer）
1. 基于规格和文案，设计故事板结构，包含三部分：
   - **key_elements**：定义所有角色、场景、道具，包含文字描述（外貌/材质/色彩），预留后续参考图绑定位置
   - **shot_list**：按叙事顺序排列镜头，每个镜头10-15秒，包含时长、画面动作、场景氛围、运镜方式，画面与旁白强关联；每个镜头内部分2-4段时间分段描述
   - **audio_layers**：预留BGM位置，SFX由视频生成时自动烘焙，无需单独定义
2. 角色造型根据内容语境选择风格分级（写实可爱/适度Q版/高度Q版），非人物元素统一保持真实世界比例
3. **暂停点2**：向用户展示分镜结构，核对旁白与画面的对应关系，用户确认后进入下一阶段

### 阶段3：元素图生成（media_generator）
1. 根据故事板中key_elements的定义，逐个生成角色/场景/道具参考图
2. 输出规格：16:9白底三视图（正面+侧面+3/4背面，左到右排列），2K分辨率，每个元素一张
3. 提示词严格遵循`references/craft/prompt-guide.md`中的元素图写法规范，开头固定注入羊毛毡风格锚定词
4. 若用户已上传元素参考图，直接绑定，不重复生成
5. **暂停点3**：向用户展示所有元素图，确认羊毛毡风格一致性、角色/场景造型符合预期，用户确认后进入下一阶段

### 阶段4：逐镜头视频生成（media_generator）
1. **严格按镜头顺序逐个生成，每次只生成一个镜头，生成后立即暂停确认**
2. 每个镜头生成参考输入：对应角色正面图 + 场景全景图组合
3. 输出规格：720p分辨率，时长与故事板设定对齐（4s-15s范围）
4. 提示词严格遵循`references/craft/prompt-guide.md`中的视频提示词写法规范，包含参考图绑定、风格锚定词、分段动作脚本、音效提示、反向约束
5. **暂停点4（每个镜头生成后都触发）**：向用户展示当前镜头视频，确认羊毛毡质感、角色一致性、SFX音效、节奏符合预期，用户确认后再生成下一个镜头
6. 所有镜头生成并确认完成后，进入下一阶段

### 阶段5：可选音频生成（media_generator）
1. **暂停点5a**：询问用户是否需要BGM，用户确认需要后再生成
   - BGM生成：时长与总视频时长对齐，提示词描述情绪+乐器+节奏，风格匹配羊毛毡温暖手工感
   - BGM生成后向用户确认，满意后绑定
2. **暂停点5b**：询问用户是否需要旁白配音，用户确认需要后再生成
   - 旁白生成：基于故事板中各镜头的旁白文案，逐段生成，指定语速和情感基调
   - 旁白生成后向用户确认，满意后绑定到对应镜头

### 阶段6：最终合成导出（video_assembler）
1. 将所有确认完成的视频片段按顺序拼接，叠加已确认的BGM和旁白音轨
2. 输出规格：9:16竖屏，分辨率匹配生成的视频片段，音画同步
3. **暂停点6**：向用户展示最终成片，确认无误后引导导出

## 输出契约
### 中间产物规范
1. 《Final_Video_Spec.md》：Markdown格式，包含标题、比例、时长、主题、风格基准
2. 故事板：JSON/Markdown格式，包含key_elements、shot_list、audio_layers三部分，shot_list每个镜头包含时长、画面分段描述、运镜、旁白对应
3. 元素图：PNG格式，16:9白底三视图，2K分辨率，命名格式`element_角色名/场景名.png`
4. 分镜视频：MP4格式，720p，命名格式`shot_镜头序号.mp4`
5. 音频文件：MP3格式，BGM命名`bgm.mp3`，旁白命名`narration_镜头序号.mp3`
### 最终产物
- 成片：MP4格式，9:16竖屏，包含所有视频片段、BGM、旁白，音画同步，无字幕、无文字叠加

## 静默自检
每个阶段交付前必须完成以下自检，不符合要求的立即修正：
1. 风格检查：所有图像/视频是否包含羊毛毡核心特征（可见纤维、柔软圆角、暖哑色调、真实比例），是否出现微缩/玩偶/手办感
2. 声画检查：每个镜头画面是否与对应旁白内容完全匹配，是否存在声画错位
3. 时长检查：每个镜头时长是否在10-15s范围（特殊短镜头不短于4s），内部分段是否在2-4段
4. 动作检查：角色动作是否流畅柔和，是否存在僵硬卡顿或过度剧烈动作
5. 一致性检查：跨镜头的角色造型、场景材质、色彩风格是否统一，无跳变
6. 禁忌检查：是否出现尖锐棱角、CG光泽、真实人类皮肤、文字叠加、字幕等禁用元素
7. 流程检查：是否严格按顺序逐节点暂停，未跳过用户确认环节
