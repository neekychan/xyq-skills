# 现实悬疑电影风：画幅、观感强化与合规

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 一、画幅选择

| 目标场景 | 建议画幅 | 说明 |
|---|---|---|
| 电影感最强、宏大横向构图 | 2.39:1 | 宽银幕，最贴合悬疑电影的横向大场面与压抑留白 |
| 常规影视剧 / 预告片 | 16:9 | 通用横屏，兼顾质感与分发 |
| 竖屏短视频（抖音/短视频平台） | 9:16 | 现代平台分发，保留冷调悬疑质感，人物居中留大量顶部/两侧暗部 |
| 线索道具 / 组图 | 1:1 | 图片素材组图、社媒展示 |

画幅只影响构图与分发，**不影响风格锚定词**——锚定词在任何画幅下都逐字前置。悬疑电影优先横向宽幅以承载“宏大横向构图”。

## 二、现实悬疑观感强化技巧（写进具体描述段，不改锚定词）

锚定词已经定了大方向，若想进一步强化，可在具体描述段补充这些**内容性**线索（而非再堆风格形容词）：
- **场景**：空旷旧工厂、废弃厂房、深夜走廊、老式楼道、审讯室、雨夜街道、荒郊公路、停尸间、地下车库、破败居民区。
- **光线时刻**：夜晚、阴天、清晨冷雾、荧光灯冷白、单一光源逆光、走廊尽头的窄光——冷硬光比暖光更出悬疑味。
- **构图手法**：宏大横向大远景把人物压小、大量深黑负空间、对称/中心构图、门框/窗框的框中框、人物背对或侧脸。
- **氛围道具**：闪烁的荧光灯、雨水、烟雾、旧档案/照片、警戒线、破碎玻璃、生锈金属、积水倒影。
- **运镜**：固定长镜头、极缓慢横移、缓慢推拉、轨道跟移——沉稳克制，避免手持晃动与快切。
- **人物状态**：克制的注视、停顿、缓步、微表情——重“真实压抑”而非戏剧化表演。

## 三、合规与安全

- **肖像**：涉及真实人物形象需确保有授权；避免生成可识别的真实公众人物。
- **暴力 / 犯罪呈现**：悬疑题材克制处理，避免血腥、露骨、可被模仿的犯罪手法细节；点到为止、以氛围叙事为主。
- **未成年人**：涉及儿童场景保持得体、非危险化、非性化，谨慎处理。
- **品牌 / 商标**：场景里的品牌 logo 若非必要不刻意精确复刻，避免侵权。
- **敏感符号**：避免涉及敏感历史/政治符号与真实案件的对号入座。
