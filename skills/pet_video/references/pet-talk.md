# 类型 C：萌宠说话/口播创作指南

## 设计原则

**核心卖点**：宠物开口说话的反差萌 + 口型同步的"真实感"。

**品种反差利用**：当动物品种自带认知标签时（鹦鹉/鹩哥=学舌怪调，八哥=直男嘴替，猫=傲娇拒绝配合），创意必须显式利用该标签制造反差或梗，不能只是"把台词换个口音/换个内容"——否则跟画面里换成任何动物都成立，等于没利用反差萌这个核心卖点。例如鹦鹉口播可以让台词中间穿插一句怪调重复（模仿学舌感），而不是从头到尾流畅说完一整段人类语言。

**必须满足以下至少一项，否则重写**：① 台词中穿插品种专属反差行为（学舌怪调重复/傲娇扭头/直男吐槽）；② 台词语气与品种刻板印象强绑定；③ 微动作与品种性格匹配。**判据**：台词换成任何动物说都成立=没利用反差，重写。

**品种反差示例库**（找感觉用，不要照抄）：
- 英短/蓝猫（高冷傲娇）：{哼，本喵亲自来祝福你，还不快感恩？} → 说到一半扭头、露不屑
- 橘猫（佛系吃货）：{新年快乐……话说有小鱼干吗？没有祝福不作数} → 舔嘴、眼睛瞟向旁边
- 鹦鹉（学舌怪调）：{恭喜发财～财～财～} → 歪头，学舌般重复末字
- 柴犬（憨厚热情）：{新年快乐！我超开心！你也要开心！} → 疯狂摇尾、耳朵飞起
- 二哈（蠢萌破音）：{新……新年快乐！我没拆家！真的！} → 破音、眼神闪躲

**点到为止**：品种反差手法（学舌重复末字/傲娇扭头/破音）**全片用 1-2 次即可，别每句都用**——每句台词都重复末字（财财/康康/意意）会从"反差萌亮点"变成"机械套路"，反而廉价。挑最适合的 1 句强化，其余台词正常说。

**体型准确性**：生成 Prompt 前确认清楚该品种的真实体型量级（如金刚鹦鹉是大中型鹦鹉、虎皮鹦鹉是小型），不要凭配色印象套用错误的体型词，体型描述自相矛盾会导致生成时比例混乱。

**场景选择**（根据内容匹配，不要总用客厅沙发）：
- **节日祝福**：匹配节日元素的场景（春联/圣诞树/月饼/蛋糕）
- **品牌口播**：匹配产品的场景（厨房/办公桌/户外）
- **情感表达**：匹配情绪的场景（雨天窗台/夕阳阳台/被窝里）
- **搞笑吐槽**：日常场景反差（一本正经地坐在书桌前/穿着西装在沙发上）

**萌感设计**（口播的核心竞争力）：
- 微动作是灵魂，但**每段只选 1-2 个**，多了反而分散注意力
- 微动作菜单：歪头、眨眼/慢慢眨眼、前爪微微抬起挥动、耳朵抖动/竖起/后压、嘴角上扬/露小虎牙、尾巴轻摇
- 微动作要和台词情绪匹配（撒娇→歪头、惊讶→耳朵竖起、害羞→耳朵后压）

**台词心法**：
- 简短有力，单段 ≤3 句（口播不是演讲）
- 语气匹配动物"人设"——奶猫撒娇、大狗憨厚、英短高冷
- 用户提供了台词 → 逐字保留；未提供 → 根据场景和动物性格创作

**音色匹配**：
- 幼猫/小猫 → 软萌奶气的童音
- 成年猫 → 慵懒中性的嗓音
- 幼犬/小狗 → 活泼可爱的童音
- 大型犬 → 浑厚低沉的中年男声

## Prompt 示例

### L2 口播（模板）

```
参考@图片1的{品种}形象（{体型词}，{毛色描述}），
{场景背景描述}，轻微虚化。

{品种}正面看向镜头，嘴角微张说话，口型与台词同步，
说话时{微动作1}、{微动作2}，全程保持真实{物种}形体。

{品种}说：{台词内容}

{音色描述}。近景固定机位，{光线描述}。
五官清晰不变形，画面稳定，保持无字幕，画面中禁止出现人类手部。
```

### L2 口播（完整示例）

```
参考@图片1的柴犬形象（中型犬体型，赤色短毛，白色脸颊和胸口），
温暖的客厅，身后是装饰着彩灯的圣诞树，暖色调。

柴犬正面看向镜头，嘴角微张说话，口型与台词同步，
说话时轻轻歪头、尾巴在身后摇摆，全程保持真实犬类形体。

柴犬说：{圣诞快乐！今年你有没有乖乖的呀？}

活泼可爱的童音。近景固定机位，圣诞灯光映照毛发，温暖氛围。
五官清晰不变形，画面稳定，保持无字幕，画面中禁止出现人类手部。
```

## 分段策略

口播通常单段完成。多句台词优先合并为一段，用画面阶段分隔。

**单段口播不做音色锚定**：音色锚定（`sandbox_generate_audio` 生成参考音频）只在多段流程、且同一台词角色跨 ≥2 段时才需要（见 `pet-assets.md`）。单段口播直接在 Prompt 里用文字描述音色（如"慵懒中性带傲娇感的嗓音"）即可，不要多此一举生成音频文件——生成了又不传 AudioList 只会浪费调用、还可能引入音色漂移。
