# 画布视频拉片与复刻

## 功能用途

小云雀 Web 支持在画布中对视频拉片：拆分片段，分析风格、镜头手法、核心 Hook 和爆点，把可继续创作的信息整理到画布，并可在后续对话中基于拉片结果复刻。

## 路径一：视频节点拉片

1. 进入小云雀的“自由画布”，点击左侧“+”添加视频节点。
2. 上传本地视频，或从资产库选择已有视频。
3. 选中视频节点，点击节点上方工具栏中的“拉片”。

## 路径二：链接与 Agent 对话

必须使用画布中的 Agent 对话；从创作 Agent 发起时需开启“画布”开关。

1. 在创作 Agent 输入框粘贴抖音分享链接。
2. 在同一条消息中写明“帮我拆解一下这个视频”，打开“画布”开关后发送。
3. Agent 解析链接，将拉片结果放到画布。

可用的示例指令：“帮我拆解这个视频，重点看关键元素、镜头语言和爆点。”

## 如何看拉片结果

先看全片，再查看各片段的镜头分析：

- 全片层：创意命题、风格参考、视觉元素、镜头与声音规律、人物和 BGM 等。
- 片段层：按时间码查看画面骨架、景别、机位、调度、构图与焦点，以及镜头表和生成 Prompt。
- 分镜拆解关注转场、连续镜头和关键剧情的拆分与聚合；分析重点包括核心 Hook 和镜头语言。

长视频也有拉片分析案例，但片段、人物、参考图及 BGM 的数量由实际内容和结果决定，不承诺固定数量。

## 拉片后继续复刻

1. 完成拉片后，在画布 Agent 的后续对话中明确要求使用刚才的拉片结果。
2. 说明复刻范围、需要保留的风格和需要替换的主体；需要更换主角时上传人物参考图片。
3. 可要求复刻全部片段并合成完整视频，在同一画布查看生成片段和最终成片。

示例指令：

> 基于刚才的拉片结果，复刻全部片段并合成完整视频。把主角替换为上传图片中的人物，其他伴舞可以自由调整，但整体风格与主角保持一致。

已有案例展示复刻直接复用前一轮的片段拆解与生成计划，没有重新分析原视频；生成片段和完整成片回到同一画布，原视频音轨重新合入成片。这是案例表现，不保证每次都不重新分析，也不保证完全复现画面、节奏或音轨。需要保留原音轨时可在需求中明确说明。

## 常见问题

**找不到“拉片”入口怎么办？**

先确认处于自由画布且已选中视频节点，“拉片”在节点上方工具栏。若用链接方式，确认开启了“画布”，并在同一条消息提供链接与明确拆解指令。仍无法调起时，不能据此猜测权限、套餐或故障原因；使用知识库未命中提示引导查看主手册。

**必须先下载视频吗？**

不一定。可上传本地视频、从资产库选视频，也可在开启画布的 Agent 对话中直接发送抖音分享链接。其他平台链接能否直接拉片未收录，不沿用其他复刻入口的平台支持范围。

**拉片后能换人复刻吗？**

可以继续提出基于已有拉片结果复刻的需求，并上传人物参考图片，说明替换主角及需要保留的风格。已有案例完成了片段生成与整片合成，具体效果不能保证与原片一致。

**能分析长视频吗？最长多久？**

有约 3 分钟视频的分析案例，能输出全片拆解及逐段镜头分析；这不代表最长时长。最长时长、文件大小和格式限制未收录。

**拉片多久完成、收费多少、复刻分辨率是多少？**

固定耗时、收费规则及复刻输出规格未收录。案例时长、片段数量、分辨率和界面积分数值不是产品限制或效果承诺，缺少依据时使用未命中提示。
