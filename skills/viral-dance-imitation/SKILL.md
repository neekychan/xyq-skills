# 爆款舞蹈模仿视频

把参考舞蹈的传播点、动作节奏、镜头与群舞关系迁移到新角色上。保留原始 BGM，分段生成连续画面，完成音轨替换、质量检查和画布交付。

## 必用技能

按需学习并使用以下技能；只需调用，不要在执行中解析或改写这些技能：

1. `视频复刻`：分析参考视频、生成复刻脚本并指导角色替换。
2. `FFmpeg`：分离和替换音轨、生成静音视频、裁剪片段、探测媒体信息。
3. `画布技能`：读取画布结构并把最终产物作为节点写入画布。

## 输入

至少需要：

- 一条参考舞蹈视频。

可选输入：目标比例、目标时长、需保留或改变的场景、服装、伴舞、字幕和平台风格。

素材缺失时只追问缺失项。素材齐全时直接执行。

## 工作流

### 1. 检查素材

- 使用文件读取和媒体探测工具确认路径、格式、分辨率、时长、音视频流与角色素材可用性。
- 建立任务规划，记录各阶段产物路径。

### 2. 先保存原始节奏资产

- 使用 FFmpeg 从参考视频提取完整原始音轨，保存为无损音频。
- 同时生成不含音频的参考视频。
- 后续画面分析、裁剪和视频生成均使用静音参考视频；原始音轨只用于最终回配。

不要直接拿带原音轨的参考视频进入生成阶段。

### 3. 分析爆点并生成复刻脚本

- 使用视频复刻技能和复刻解析工具分析静音参考视频。
- 总结首屏钩子、领舞与群舞反差、标志性动作、队形变化、镜头节奏、舞台视觉和情绪高潮。
- 从角色素材提取稳定的外观锚点，例如轮廓、服装、配色、材质、头部和配饰。
- 生成按时间段拆分的复刻脚本，明确每段的参考区间、目标时长、角色替换、动作、镜头、场景和连续性要求。
- 只保留对传播效果有贡献的爆点；不要机械复制无关细节。

### 4. 规划分段与连续性

- 单次生成片段控制在当前视频生成能力支持的最大时长内；默认按不超过 15 秒规划。
- 第一段直接参考对应的静音原视频区间。
- 后续段同时引用：上一生成片段的结尾 3–5 秒，以及静音原视频的下一时间段。
- 使用上一段结尾作为延续参考，固定角色外观、动作起点、舞台位置、光线和镜头方向。

例如，21 秒参考视频可拆为 `0–15s` 和 `15–21s`；第二段同时引用第一段的 `10–15s` 尾部。

### 5. 裁剪参考素材并逐段生成

- 使用 FFmpeg 裁剪脚本要求的静音参考片段和上一段尾部。
- 使用视频生成工具按脚本顺序生成每个分镜。
- 每生成一段即检查角色一致性、舞蹈动作、伴舞队形、镜头和时长。
- 不合格片段立即重生成，不要带病进入合成。

### 6. 合成画面

- 使用视频合成或渲染工具按时间顺序拼接所有合格片段。
- 检查拼接点是否跳帧、角色突变、动作断裂或镜头方向翻转。
- 此阶段的输出只是候选合成视频，不能因为“存在音频流”就认定音轨正确。

### 7. 强制替换为原始 BGM

严格执行以下顺序：

1. 去掉候选合成视频自带的全部音频，得到纯画面视频。
2. 将步骤 2 保存的原始音轨合入纯画面视频。
3. 以视频时长为边界处理音轨，避免尾部黑屏或多余音频。

禁止把“合成视频已有音频流”当作原始 BGM 已正确回配的证据。

### 8. 验收

使用媒体探测、文件读取和预览工具检查：

- 最终视频包含一个视频流和正确的原始音轨。
- 时长与目标一致，音画起止点对齐。
- 替换角色在所有片段中外观稳定。
- 标志性舞步、节奏、群舞反差和镜头爆点得到保留。
- 拼接处动作连续，没有明显画面或声音跳变。

任何一项失败时回到对应步骤修复。

| 爆点与脚本 | 复刻视频解析 |

| 拼接成片 | 视频合成或渲染 |
| 质量验收 | 媒体探测、文件读取、视频预览 |
|  |

工具名称因运行环境不同可以变化，按能力匹配当前可用工具，不要臆造不存在的调用。

## 输出契约

完成后简要报告：

- 爆点提炼：保留了哪些动作、反差、镜头和节奏。
- 角色替换：使用了哪份角色素材和关键外观锚点。
- 分段方案：每段时长及连续性引用关系。
- 音频处理：确认已执行“合成后去音轨，再回配原始 BGM”。
- 验收结果：时长、音画、角色一致性和拼接连续性。
- 交付位置：最终文件路径和画布节点状态。

不要输出内部思考过程，不要把 Skill 创建过程写进创作总结。
