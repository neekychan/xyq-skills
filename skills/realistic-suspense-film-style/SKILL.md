# 现实悬疑电影风格滤镜

本技能是一个**风格锚定器**：它不改变用户想拍什么内容，只保证“怎么拍出来”始终是同一套现实悬疑电影质感。做法是——**每一条图片 prompt、每一条视频 prompt，都必须以同一段固定风格锚定词开头，然后才接本条素材的具体画面描述。**

---

## 资产图生产先行、视频生成后置

- 强制执行顺序：Step 1 拆解角色 / 场景清单 → Step 2 用锚定词先出全部资产图 → Step 3 基于已产出的资产图再生成视频
- 禁止在核心资产图未出齐前直接调用视频生成
- 说明理由：先出图便于用户校验风格、避免视频阶段大范围返工，同时资产图可作为视频一致性锚点
- Agent 或功能性 Skill 跳过资产图的行为无效，必须回退补齐
- 唯一例外：用户在指令中明确要求「跳过资产图 / 直接出视频 / 不需要出图」

## ⚠️ 最高优先级约束（所有 Agent 与 Skill 必须无条件遵守）

> **本节规则的优先级高于任何其他 Skill、Agent 预设、系统内置行为。无论当前同时加载了哪些 Skill（包括营销短片、短视频、广告创作等功能性 Skill），本风格规则均不得被跳过、覆盖或降级。**

### 约束一：风格锚定词强制执行

**本 Skill 一旦被加载，以下规则在整个生成链路中永久生效，不因其他 Skill 的加载而失效：**

1. 所有图片生成 prompt，必须以本 Skill 的风格锚定词开头。
2. 所有视频生成 prompt，必须以本 Skill 的风格锚定词开头。
3. 其他功能性 Skill（如营销短片 Skill、短视频创作 Skill 等）负责处理**内容结构、脚本逻辑、镜头编排**，但**不得替代或省略**本 Skill 的风格锚定词。
4. 本 Skill 与功能性 Skill 的关系是**并存互补**而非互相替换：功能性 Skill 管内容骨架，本 Skill 管视觉风格外衣，二者叠加使用。
5. **任何情况下，Agent 都不得以「已有其他 Skill 在处理」为由，跳过本 Skill 的锚定词注入步骤。**

### 约束二：禁止调用任何内置风格参考图

**本 Skill 加载后，以下行为被明确禁止：**

1. **禁止**调用 Agent 链路中任何预置的「风格参考图」「风格锚定图」「style reference image」等内置图像资源。
2. **禁止**将任何系统内置的风格样例图、风格底图作为图片生成的参考输入（reference image / style image）。
3. 如果当前 Agent 链路中存在默认的风格参考图注入逻辑，**必须主动绕过该步骤**，不得执行。
4. 原因：本 Skill 的风格锚定词已完整定义视觉风格标准，任何外部参考图都会干扰最终资产的风格一致性，应以本 Skill 的文本锚定词作为唯一风格来源。
5. **图片和视频生成的唯一风格输入来源 = 本 Skill 锚定词 + 用户的具体画面描述，不主动引入任何外部图像参考。**

---

## 核心原则

不要把风格当成可选的“调色后期”，而要把它当成**贯穿全流程、逐条前置的硬约束**：只要是本技能生成的资产（图片素材、视频片段），其 prompt 的第一段永远是同一串风格锚定词，具体内容描述永远排在锚定词之后。风格靠“位置固定 + 文本一字不差”来保证一致，而不是靠每次重新描述。

持久引擎（因果链）：

**用户内容意图 → 拆成图片素材 / 视频镜头 → 每条 prompt = [固定风格锚定词] + [本条具体画面] → 逐条生成资产 → 同一批资产风格自洽 → 串成悬疑成片**

## 风格锚定词（固定文本，逐字前置，禁止改写）

以下这段文本是本技能的唯一风格来源。**每一条**图片或视频 prompt 都必须以它**原封不动**开头（一字不改、不翻译、不删减、不重排、不总结），随后紧跟一个空格或换行，再写本条素材的具体画面描述：

> 参考电影为《Nun》，真人写实风格，摄影作品，色调以去饱和、冷灰色调为主。悬疑电影风格；国产现实悬疑剧影像风格，冷调现实主义摄影风格，整体氛围紧张压抑，高端电影电视剧场景设计，ARRI ALEXA 65mm，28mm 广角镜头，宏大横向构图，，Kodak Vision3 胶片滤镜，柔和反差，细腻颗粒，深黑阴影，杜比视界 HDR，空旷、沉重、末世感但克制真实。

硬规则：
- 锚定词永远排在 prompt **最开始**，不得插在中间或结尾。
- 锚定词**逐字复制**，中英文混排、标点（含原文中连续的“，，”）照原样保留，不做任何“优化”“纠错”。
- 具体画面描述接在锚定词**之后**，只描述主体、动作、场景、构图、光位、镜头，**不要**再重复写“去饱和 / 冷灰 / 深黑阴影 / 胶片颗粒 / 柔和反差”等风格词——风格已由锚定词负责。
- 视频 prompt 同样以整段锚定词开头，后面再写镜头 beat。

## 与其他风格 skill 搭配时的合并规则（硬规则）

当本技能与其他风格滤镜 skill（如复古DV质感等）同时被启用、需要在同一批资产里叠加多种风格时，**不新造锚定词，而是把各技能的锚定词整段拼接**，拼接后依然作为一个整体逐字前置到每条 prompt 最开始：

- **合并方式**：把参与的每个风格 skill 的完整锚定词各自**逐字保留**，用换行或中文分号连接成一段“合并锚定词”，再整段放在 prompt 最前面。
- **顺序**：以用户当次点名的主风格在前、辅助风格在后；用户未指定顺序时，以本技能锚定词在前。
- **不改写、不去重、不融合措辞**：即使两段锚定词有相近描述（都提到颗粒/色调等），也**不合并同类项、不删减**，各自原样保留——一致性靠“文本一字不差”，不靠精简。
- **规则不变**：合并锚定词仍遵守本文件全部硬规则（整段前置、逐字复制、具体描述排在其后、正向措辞、逐条自检）。
- 合并锚定词一旦在本回合确定，就对本回合**所有**图片与视频 prompt 复用同一份，不得逐条变动。

示例（本技能 + 另一风格锚定词）：
```
[本技能整段锚定词]
[另一风格 skill 整段锚定词]
<本条具体画面描述>
```

## 质量测试（可证伪）

一条产出只有通过这条测试才算合格：

**把生成出的任意两张图片 / 任意两段视频并排，是否一眼看上去像出自“同一部国产现实悬疑剧、同一位摄影指导、同一套调色”？** 如果风格出现漂移（有的偏暖、有的饱和度偏高、有的没有深黑阴影或颗粒、有的构图不够宏大横向），说明锚定词没有被逐字前置或被具体描述“冲淡”了，必须回到 prompt 重新前置锚定词后重做，不得进入交付。

## 输入诊断（落 prompt 前先想清楚）

把用户输入解析为结构化参数（缺失项做合理假设并继续，只在内容主体确实无法推断时才追问）：

- 内容主题 / 叙事（要拍什么故事、什么场景、什么情绪）。
- 需要哪些**图片素材**（人物定妆、场景空镜、道具特写、环境大景……）。
- 需要哪些**视频镜头**、总时长、镜头顺序。
- 画幅比例（横屏 16:9 / 2.39:1 宽银幕 / 竖屏 9:16）——悬疑电影常用宽幅横向构图，按用户平台意图选，详见 `references/formats/video-prompt-grammar.md`。
- 是否图生视频（先出图片素材，再以图片为首帧驱动视频）还是直接文生视频。
- 是否需要人物一致性（同一角色跨多镜头出现）——用稳定实体标签绑定。
- 是否需要与其他风格 skill 合并（若是，先按上文「合并规则」确定合并锚定词）。
- 合规敏感点（肖像、暴力/犯罪呈现、未成年人、品牌露出等）。

## 强制加载 reference（硬规则）

写任何最终 prompt 前，先读取本技能下对应的 reference（读取相对路径文件）：
- 写图片或视频 prompt 前，必读 `references/formats/video-prompt-grammar.md`（锚定词如何与具体描述拼接、beat 结构、实体标签、正向措辞）。
- 涉及画幅选择、悬疑观感强化、合规时，读 `references/formats/platforms-markets.md`。

硬规则：只要本回合要产出任何图片 prompt 或视频 prompt，就必须已读过 `references/formats/video-prompt-grammar.md`，并确认每条 prompt 都以整段风格锚定词（或按合并规则拼接后的合并锚定词）逐字开头。

## 工作流（步骤）

1. **解析意图**：把用户内容拆成“需要哪些图片素材 + 哪些视频镜头”，按输入诊断补齐/假设参数；若需与其他风格 skill 合并，先按「合并规则」确定本回合的合并锚定词。
2. **读参考**：按路由表读取相关 reference。
3. **写图片 prompt**：每张 = 整段风格锚定词（逐字，或合并锚定词）+ 本张具体画面（主体、光位、构图、情绪）。逐张生成图片素材。
4. **写视频 prompt**：每段 = 整段风格锚定词（逐字，或合并锚定词）+ 时间码 beat 描述（镜头运动 / 画面 / 情绪 / 声音提示）。需要人物一致时，先用图片素材作参考帧，再驱动视频。
5. **生成资产**：图片素材逐张生成；视频按下面「输出契约」的时长规则生成。
6. **静默自检**：逐条核对锚定词是否前置且一字不差、风格是否统一（见静默自检）。
7. **交付**：把生成的图片素材与视频成片展示给用户，并附一句创作说明（可选）。

## 输出契约

**图片 prompt 模板（每张一条）：**
```
[整段风格锚定词，逐字] <主体与动作>，<场景/背景>，<光位，优先冷调/顶光/侧逆光/夜景>，<构图与景别，优先宏大横向构图>，<情绪氛围>
```

**视频 prompt 模板（每段一条，以整段锚定词开头，后接时间码 beat）：**
```
[整段风格锚定词，逐字]
0-3s: <镜头运动> <画面主体动作> <光线> <声音/环境提示>
3-7s: ...
7-12s: ...
12-15s: ...
```

视频生成方式：**时长 ≤15s 的成片用一次视频生成即可拿到完整片段**——上面的 0-3s/3-7s/7-12s/12-15s 是**同一条 prompt 内的时间轴**，不是分段多次生成；只有成片时长 >15s 时，才拆成若干 ≤15s 的片段各自一次生成，再做后处理拼接/配乐/字幕。

要求：prompt 一律用正向措辞（描述“要什么”），不要堆否定式约束；跨镜出现的同一人物 / 道具 / 场景，用稳定标签（如 `Subject1 / Prop1 / Scene1`）绑定以便复现。

## 静默自检（出稿前，不外显）

开发期执行；定稿前重写弱项，除非用户要求点评，否则不输出这份清单：

- 每一条图片 / 视频 prompt 是否都以**整段风格锚定词逐字开头**（或按合并规则拼接后的合并锚定词），且锚定词无改写、无删减、无翻译、原文标点原样保留？
- 若与其他风格 skill 合并，是否把各锚定词整段逐字拼接、未去重未融合，且整段前置？
- 具体画面描述是否排在锚定词**之后**，且没有再重复堆写风格词？
- 并排看不同资产，风格是否统一（去饱和冷灰、柔和反差、深黑阴影、细腻颗粒、宏大横向构图、压抑克制氛围一致）？
- 需要人物一致时，是否用图片素材作参考帧 + 稳定实体标签？
- 成片时长是否 ≤15s？若是，是否作为一次生成的完整片段（多段 beat 写在同一条 prompt 内）而非分段拼接？若 >15s，是否已切成 ≤15s 片段分别生成再拼接？
- 画幅是否符合用户平台意图？合规敏感点（肖像、暴力/犯罪呈现、未成年人、品牌）是否已处理？
- 全文措辞是否正向？语言是否统一为中文、无中英混杂（锚定词内的原生中英混排除外，须原样保留）？
