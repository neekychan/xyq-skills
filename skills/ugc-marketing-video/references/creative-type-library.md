Pick one primary selling point to drive the video.

每条短视频只选择一个主卖点作为主线。

Prefer:

- pain point or desire first / 先讲痛点或欲望
- selling point as relief, proof, convenience, transformation, taste, texture, comfort, durability, value, or social proof / 把卖点转成解决、证明、便利、变化、口感、质感、舒适、耐用、价值或社会证明
- product use as evidence / 用产品使用作为证据
- visible result as confirmation / 用可见结果确认卖点
- CTA as a natural closing line / CTA 自然收尾

Avoid:

- feature dumping / 堆功能
- opening only with product name / 开头只报产品名
- brand slogans / 品牌口号
- vague praise without visual evidence / 没有视觉证据的空泛夸奖
- claims that cannot be shown or spoken believably / 无法展示或无法可信口播的宣称

Translate features into human reasons:

- not "contains ingredient X"; say "when my skin feels dry, this is the one I reach for"
- not "large capacity"; say "I can pack a full day of stuff without switching bags"
- not "professional motor"; say "it blends this in seconds without leaving chunks"

把功能翻译成人话：

- 不说“含某某成分”，说“皮肤干的时候我会拿它”
- 不说“大容量”，说“出门一整天的东西都能塞进去”
- 不说“专业电机”，说“几秒就打匀，没有明显颗粒”

## Format Patterns / 内容结构

Use the smallest pattern that matches the user's request.

选择最贴合用户需求的结构，不要过度复杂化。

For each content type, output by this method:

不同类型视频分别按以下方法输出：

- `带货视频 / Sales video`: emphasize purchase reason, product card/offer, visible proof, and direct CTA / 强调购买理由、商品卡/优惠、可见证明和直接 CTA
- `口播种草 / Voiceover seeding`: emphasize creator credibility, personal reason, product-in-hand, soft recommendation, and natural lip-sync / 强调达人可信度、个人理由、手持产品、软推荐和自然口型同步
- `好物推荐 / Product recommendation`: emphasize daily scene, repeated-use reason, convenience/value, and friend-to-friend tone / 强调日常场景、复用理由、便利/价值和朋友式语气
- `产品测评 / Product review`: emphasize test setup, objective observation, tactile detail, result, and verdict / 强调测试设置、客观观察、触感细节、结果和结论
- `卖点展示 / Benefit demo`: emphasize one benefit, one action, one visual proof, and one CTA / 强调一个卖点、一个动作、一个视觉证明、一个 CTA
- `效果展示 / Effect demo`: emphasize before/after, process close-up, result readability, and claim restraint / 强调前后对比、过程特写、结果一眼可读和宣称克制
- `达人探店 / Influencer store visit`: emphasize route, environment, signature item/service, real reaction, and location/order CTA / 强调路线、环境、招牌项目、真实反应和到店/下单 CTA
- `团购视频 / Group-buying deal video`: emphasize package contents, price/value, redemption confidence, store proof, and buy/reserve CTA / 强调套餐内容、价格价值、核销信任、门店证明和购买/预约 CTA
- `游戏/IP活动视频 / Game and IP campaign video`: emphasize gameplay desire, character/skin/event proof, reward or ticket value, and download/reserve/join/check-in CTA / 强调玩法欲望、角色/皮肤/活动证明、福利或票券价值，以及下载/预约/参与/打卡 CTA
- `UGC-style video / UGC 风格短视频`: emphasize realistic filming, imperfect everyday motion, product consistency, natural speech, and action continuity / 强调真实拍摄、日常轻微不完美、商品一致、自然口播和动作承接
- `Viral remake / 爆款复刻`: emphasize structural adaptation, not verbatim copying; preserve hook mechanism, rhythm, proof mechanism, and platform-native music mood / 强调结构迁移而不是逐字复制；保留钩子机制、节奏、证明机制和平台音乐氛围
- `Sales-script-to-video / 带货脚本视频化`: convert every claim into visual action, lip-synced speech, product proof, and continuous shot logic / 把每个文案点转成画面动作、口型同步口播、产品证明和连续镜头逻辑

## Creative Type Library / 创意类型库

When the user asks for a creative format, or when analyzing reference ads, choose one creative type before writing the script. Each creative type must keep a stable rhythm, one main action per beat, one short spoken line per beat, and a visible reason to act.

当用户要求创意形式，或基于参考广告分析时，先选择一个创意类型再写脚本。每个创意类型都要保持稳定节奏：每段一个主动作、每段一句短口播、每段都有可见行动理由。

Creative pacing rule / 创意节奏规则:

- A creative hook can be sharp, surprising, funny, or price-led in the first 0-3 seconds, while the full video should feel persuasive rather than rushed / 0-3 秒钩子可以强、惊喜、好笑或价格前置，但全片节奏应有说服层次，而不是一路急促
- Any visual hook, meme, drama opening, or unrelated-looking attention grabber must connect back to the product and selling point during 3-6 seconds / 任何视觉钩子、玩梗、剧情开场或看似无关的吸引注意画面，必须在 3-7 秒回到商品和卖点
- Use a fast hook -> clear product -> proof/action -> value confirmation -> CTA rhythm when the goal is sales conversion / 转化目标使用“快速钩子 -> 商品清楚入镜 -> 证明/动作 -> 价值确认 -> CTA”的节奏
- Use a hook -> context -> proof -> feeling/reaction -> soft CTA rhythm when the goal is seeding or trust / 种草或信任目标使用“钩子 -> 场景 -> 证明 -> 感受/反应 -> 软 CTA”的节奏
- If screenshots, app pages, deal pages, order pages, or game reward pages appear, bridge from real scene to screen with a visible phone raise, screen tap, hand-held phone close-up, or creator pointing gesture / 如果出现截图、App 页面、团购页、订单页或游戏福利页，用举起手机、点击屏幕、手持手机特写或达人指向动作完成实景到屏幕的桥接

### 功能挑战型 / Feature Challenge

Best for cars, phones, appliances, sports/outdoor, games, cleaning, and performance products.

适合汽车、手机、家电、运动户外、游戏、清洁和性能类产品。

1. `0-3s` challenge hook: show the difficult condition or challenge result first / 挑战钩子：先展示难条件或挑战结果
2. `3-7s` setup: show product, environment, and challenge rule in one clear frame / 挑战设定：一镜交代产品、环境和挑战规则
3. `7-10s` action: product performs the key function under the challenge / 功能动作：产品在挑战中完成关键功能
4. `10-13s` proof: show result, comparison, reaction, or measurable cue / 结果证明：展示结果、对比、反应或可衡量线索
5. `13-15s` CTA: invite test drive, try, buy, download, reserve, or comment / CTA：引导试驾、试用、购买、下载、预约或评论

### 真实场景 Vlog 型 / Real-Scene Vlog

Best for travel, home, drinks, fashion, electronics, parenting, pets, and local services.

适合旅游、家居、饮品、服饰、数码、母婴、宠物和本地服务。

1. `0-3s` lived-in hook: creator enters a real scene mid-action / 生活钩子：达人从真实动作中进入画面
2. `3-7s` context: show why the product/service naturally appears here / 场景交代：说明产品或服务为什么自然出现
3. `7-10s` use moment: show one continuous use, visit, drink, wear, or service step / 使用瞬间：连续展示一次使用、到店、饮用、穿搭或服务步骤
4. `10-13s` feeling proof: show reaction, comfort, convenience, taste, view, or result / 感受证明：展示反应、舒适、方便、口味、景观或结果
5. `13-15s` soft CTA: save, ask, search, navigate, reserve, or check link / 软 CTA：收藏、提问、搜索、导航、预约或看链接

### 清单合集型 / Listicle And Collection

Best for accessories, fashion, shoes, drinks, snacks, gifts, travel outfits, phone cases, and small goods.

适合配饰、服饰、鞋子、饮品、零食、礼品、旅行穿搭、手机壳和小商品。

1. `0-3s` collection hook: show the full set or strongest item first / 合集钩子：先展示全套或最强单品
2. `3-7s` item one: pick one item and show its use scene / 单品一：拿起一个并展示使用场景
3. `7-10s` item two/three: place the current item down, hold a clear stable frame, then cut to the next item already supported in the lineup or on the tabletop / 单品二/三：放下当前单品，保持清晰稳定画面，再切到下一件已在排列区或桌面上获得支撑的单品
4. `10-13s` selection reason: say who each item fits or when to use it / 选择理由：说明每款适合谁或什么场景
5. `13-15s` CTA: ask viewer to save, choose a style/flavor/color, or check product card / CTA：引导收藏、选择款式/口味/颜色或看商品卡

### 多款对比型 / Side-By-Side Comparison

Best for cars, phones, cosmetics shades, shoes, bags, appliances, drinks, snacks, and service packages.

适合汽车、手机、彩妆色号、鞋包、家电、饮品、零食和服务套餐。

1. `0-3s` comparison hook: show two or three options in one stable frame / 对比钩子：稳定画面展示两到三个选项
2. `3-7s` option A: demonstrate the first option's strongest scene / A 款：展示第一款最适配的场景
3. `7-10s` option B: demonstrate the second option with matching camera angle / B 款：用相近机位展示第二款
4. `10-13s` decision rule: explain the selection logic by user need / 选择规则：按用户需求说明怎么选
5. `13-15s` CTA: guide comment, consult, choose model, buy package, or save comparison / CTA：引导评论、咨询、选型号、买套餐或收藏对比

### 前后对比型 / Before-And-After

Best for skincare, makeup, hair, cleaning, home decor, outfit styling, medical beauty services, and productivity tools.

适合护肤、美妆、美发、清洁、家居改造、穿搭、医美服务和效率工具。

1. `0-3s` after-result hook: show the final clean/pretty/efficient result first / 结果钩子：先展示最终变干净、变好看或更高效的结果
2. `3-7s` before state: show the original pain point or baseline / 前状态：展示原始痛点或基线
3. `7-10s` process: show product/service/tool acting on the problem / 过程：展示产品、服务或工具作用在问题上
4. `10-13s` after proof: show the result under similar angle or clear reset / 后证明：用相似角度或明确重置展示结果
5. `13-15s` CTA: connect the result to purchase, appointment, save, or consult / CTA：把结果连接到购买、预约、收藏或咨询

### 开箱上手型 / Unboxing And First Use

Best for digital products, beauty, luxury, toys, gifts, shoes, accessories, and appliances.

适合数码、美妆、奢侈品、玩具、礼品、鞋子、配饰和家电。

1. `0-3s` package hook: show the box, first reveal, or strongest detail / 包装钩子：展示盒子、首次揭示或最强细节
2. `3-7s` unbox: open package with hands and reveal product clearly / 开箱：手部打开包装，产品清楚出现
3. `7-10s` first use: turn on, wear, apply, assemble, taste, or test one function / 首次使用：开机、佩戴、上脸、组装、试吃或测试一个功能
4. `10-13s` reaction/detail: show tactile detail, sound, texture, fit, screen, or output / 反应细节：展示触感、声音、质地、适配、屏幕或产出
5. `13-15s` CTA: recommend who it fits and guide purchase/search/save / CTA：说明适合谁，引导购买、搜索或收藏

### IP/明星/达人共创型 / IP, Celebrity, Or Creator Co-Creation

Best for luxury, beauty, cars, beverages, games, tourism, and brand events.

适合奢侈品、美妆、汽车、饮品、游戏、旅游和品牌活动。

1. `0-3s` face/IP hook: show the celebrity, creator, IP character, or signature asset / 人物/IP 钩子：展示明星、达人、IP 角色或标志资产
2. `3-7s` product connection: show how the person/IP naturally connects to the product or event / 关联建立：展示人物/IP 与产品或活动的自然关系
3. `7-10s` signature action: person uses, wears, drives, drinks, plays, or checks in / 标志动作：人物使用、佩戴、驾驶、饮用、游玩或打卡
4. `10-13s` emotional payoff: show charm, fan moment, status, atmosphere, or reveal / 情绪回报：展示魅力、粉丝瞬间、身份感、氛围或揭示
5. `13-15s` CTA: guide search, buy, reserve, download, ticket, or follow campaign / CTA：引导搜索、购买、预约、下载、购票或关注活动

### 情绪大片型 / Mood Film

Best for luxury, watches, cars, perfume, fashion, travel, premium beverages, and brand image with conversion endpoint.

适合奢侈品、腕表、汽车、香水、时装、旅行、高端饮品和有转化出口的品牌形象广告。

1. `0-3s` atmosphere hook: show striking scene, light, motion, or texture / 氛围钩子：展示强场景、光影、运动或质感
2. `3-7s` object reveal: product appears as part of the world, not as a hard sell / 产品揭示：产品自然进入世界观
3. `7-10s` sensory detail: show material, sound, movement, color, landscape, or body motion / 感官细节：展示材质、声音、动作、颜色、景观或身体动态
4. `10-13s` meaning beat: connect product to identity, occasion, freedom, confidence, or memory / 意义节拍：连接身份、场合、自由、自信或记忆
5. `13-15s` elegant CTA: search, reserve, discover collection, visit store, or learn more / 优雅 CTA：搜索、预约、探索系列、到店或了解更多

### 评论区回复型 / Comment Reply

Best for fashion, beauty, digital, beverages, games, local stores, and high-question products.

适合服饰、美妆、数码、饮品、游戏、本地门店和高咨询商品。

1. `0-3s` comment hook: show a clear viewer question or comment card / 评论钩子：展示一个清楚的用户问题或评论卡
2. `3-7s` direct answer: creator answers while product enters frame / 直接回答：达人回答，产品入镜
3. `7-10s` proof: show the answer through try-on, test, taste, UI, visit, or comparison / 证明：通过试穿、测试、试喝、界面、到店或对比回答
4. `10-13s` extra tip: add one useful detail that builds trust / 补充技巧：补一个有用细节建立信任
5. `13-15s` CTA: ask next question, comment keyword, save, or check link / CTA：引导继续提问、评论关键词、收藏或看链接

### 避坑/别买错型 / Pitfall And Buying Guide

Best for electronics, skincare, travel packages, cars, appliances, shoes, bags, medical beauty, and services.

适合数码、护肤、旅游套餐、汽车、家电、鞋包、医美和服务类。

1. `0-3s` risk hook: name the common wrong choice or pain point / 风险钩子：点出常见买错点或痛点
2. `3-7s` wrong example: show the mismatched use case or confusing option / 错误示例：展示不匹配场景或容易混淆的选项
3. `7-10s` right check: show the product/service detail that solves it / 正确判断：展示解决问题的产品或服务细节
4. `10-13s` decision rule: give one simple buying rule / 选择规则：给一个简单购买判断
5. `13-15s` CTA: ask viewer to comment need, consult, save, or choose model/package / CTA：评论需求、咨询、收藏或选择型号/套餐

### 任务挑战型 / Task Challenge

Best for games, cars, sports, drinks, fitness, cleaning, pets, toys, and offline events.

适合游戏、汽车、运动、饮品、健身、清洁、宠物、玩具和线下活动。

1. `0-3s` task hook: show the mission or challenge title visually / 任务钩子：视觉化展示任务或挑战标题
2. `3-7s` participant setup: show creator/player/user starting the task / 参与设定：展示达人、玩家或用户开始任务
3. `7-10s` task action: show the main attempt with continuous motion / 任务动作：连续展示主要尝试
4. `10-13s` success/reward: show completion, reward, reaction, or unlock / 成功回报：展示完成、奖励、反应或解锁
5. `13-15s` CTA: invite viewer to join, download, check in, try, or comment result / CTA：邀请参与、下载、打卡、尝试或评论结果

### 线下打卡型 / Offline Check-In

Best for restaurants, scenic spots, exhibitions, game/IP theme areas, retail pop-ups, clinics, and local services.

适合餐饮、景区、展览、游戏/IP 主题区、快闪店、诊所和本地服务。

1. `0-3s` destination hook: show storefront, entrance, sign, landmark, or crowd / 目的地钩子：展示门头、入口、标识、地标或人气
2. `3-7s` arrival: show route, ticket, reservation, or check-in action / 到达：展示路线、票券、预约或打卡动作
3. `7-10s` experience: show signature item, interaction, service, installation, or atmosphere / 体验：展示招牌、互动、服务、装置或氛围
4. `10-13s` value/reaction: show price, limited item, taste/use reaction, or photo result / 价值反应：展示价格、限定物、入口/使用反应或成片
5. `13-15s` CTA: navigate, buy coupon, reserve, buy ticket, save location, or comment city / CTA：导航、买券、预约、购票、收藏地点或评论城市

### 福利倒计时型 / Reward Countdown

Best for games, group-buying, ecommerce promotion, new launches, ticketing, live rooms, and seasonal limited products.

适合游戏、团购、电商促销、新品上市、开票、直播间和季节限定产品。

1. `0-3s` urgency hook: show the reward, discount, limited item, or countdown visual / 紧迫钩子：展示福利、折扣、限定物或倒计时
2. `3-7s` qualification: show how to get it in one clear step / 获取条件：展示一个清楚领取步骤
3. `7-10s` proof: show reward page, coupon, package, product, ticket, or in-game item / 福利证明：展示福利页、券、套餐、商品、票券或游戏道具

#### 荒诞打断式 Hook / Absurd Interruption Hook

Use this as a hook engine inside meme, visual hook, UGC vlog, product review, seeding, fashion, beauty, beverage, snack, and aspirational lifestyle videos.

这是一个开头引擎，不是完整视频类型。它适合嵌入表情包、视觉钩子、UGC vlog、测评、种草、服饰、美妆、饮品、零食和生活方式单品视频。

Core mechanism / 核心机制：

1. `0-3s` absurd interruption: a surprising, staged, non-serious event interrupts the creator, but the camera keeps rolling / 荒诞打断：一个意外、好笑、可控的事件打断达人，但镜头继续拍
2. `3-7s` deadpan product pivot: the creator quickly regains composure and naturally turns the interruption into a product reveal or review setup / 冷静转商品：达人迅速恢复，把打断自然转成商品露出或测评理由
3. `7-12s` proof or review: show one real product proof, texture, fit, taste, feature, deal, or lifestyle value / 证明或测评：展示一个真实商品证明、质感、上身、口味、功能、优惠或生活方式价值
4. `12-15s` unbothered CTA: close with a calm, funny, or aspirational CTA while the product stays visible / 淡定 CTA：在商品仍可见的情况下，用冷静、好笑或生活方式感的 CTA 收尾

Use these hook patterns as inspiration, not as fixed scripts. Adapt them to the product and keep every action controlled, staged, non-injurious, and physically plausible.

这些钩子只能作为灵感，不要逐字照抄。必须按商品改写，并保持所有动作可控、表演化、无真实伤害、物理合理。

- **Failed stunt to deadpan review / 失败动作后冷静测评**: A creator attempts a visibly staged, low-risk trick or pose, lands awkwardly on a soft surface, immediately sits up, takes out the product, and reviews it calmly as if this was planned.
- **Beauty reveal pause / 美妆揭示停顿**: Start from an extreme close-up of collarbone, skin, fabric, hand, or detail; tilt up to reveal the finished look, then pull back into selfie framing before a silent beat turns into the product pitch.
- **Stranger-answer chain / 路人答案接力**: Interviewer asks a second stranger a question based on the first stranger's odd answer; the confusion builds until the second person notices the product and pivots into a casual review.
- **Random object microphone / 随机物当麦克风**: During a casual vlog, an absurd object lands safely into the creator's hand from above; the creator treats it like a microphone and continues a serious product review.
- **Camera bump recovery / 镜头误撞恢复**: The camera lightly bumps into the creator's shoulder, hand, hat, or safe prop; the creator reacts for one beat, recovers, and uses the moment to reveal the dress, accessory, product, or detail.
- **Product near-miss pivot / 商品飞入转测评**: A product or package enters frame as a soft, controlled near-miss; the creator ducks or catches it safely, then stands holding the product and begins reviewing it as if nothing happened.
- **Aspirational item notice / 生活方式单品被注意到**: In an Erewhon-style aspirational scene, the product first appears as a status/lifestyle detail that a stranger or friend notices, then the creator casually explains why it is worth trying.

Prompt writing rules / Prompt 写法：

- Keep the hook short; the product must become clear by `3-7s`.
- The absurd event should create attention, not replace the selling point.
- Write the action as performed/staged comedy, not real injury or danger.
- Prefer safe phrases such as `soft landing`, `staged comic stumble`, `light prop bump`, `controlled near-miss`, `safe catch`, `creator immediately recovers`, `unbothered deadpan review`.
- Keep one main physical action per shot, then transition to product proof.
- Use `苹果原相机拍摄风格`, handheld UGC framing, and natural reaction timing unless the user asks for a different style.

### 爆款视频复刻 / Viral Remake

Extract:

- opening hook type / 开头钩子类型
- shot rhythm / 镜头节奏
- creator energy / 达人状态
- conflict/desire / 冲突或欲望

- CTA shape / CTA 形态

Adapt:

- same structural engine / 复用结构引擎
- new product facts / 替换为新产品事实
- new wording / 重写表达
- new scene/action details / 重写场景和动作

Timed remake structure:

爆款复刻的时间结构：
