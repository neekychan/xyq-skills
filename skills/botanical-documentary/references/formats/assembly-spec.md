# 组装与导出规范 / Assembly & Export Specification

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 时间轴结构

```
00:00 ──────────── 15:00 ──────────── 30:00 ──────────── 45:00
│     Section A      │     Section B      │     Section C      │
│  植物信息展示        │  植物种植过程       │  功效与使用场景      │
│  白底信息图          │  写实自然绿棕       │  生活中性明亮        │
└────────────────────┴────────────────────┴────────────────────┘
```

三组视频按 A → B → C 顺序拼接至时间轴，总时长 45 秒。

---

## 转场规范

### L-Cut / J-Cut 逻辑

组内镜头及组际转场全面应用 L-Cut / J-Cut：

- **L-Cut**：画面已切换到下一镜头，但上一镜头的音频延续约 0.5 秒
- **J-Cut**：下一镜头的音频提前约 0.5 秒切入，画面尚未切换

### 跨剪辑点 Foley

| 转场位置 | 提前切入的 Foley | 效果 |
|---|---|---|
| A→B（信息图→种植） | 泥土碎裂声 | 预告土地与生命 |
| B→C（种植→功效） | 石磨/切刀碰撞音 | 预告加工转化 |
| B 组内 Beat 间 | 水滴声、风吹叶声 | 维持自然沉浸感 |
| C 组内 Beat 间 | 研磨声、生活环境音 | 维持人文沉浸感 |

## 音轨层级

三条独立音轨，音量层级严格如下：

```
Track 1: Narration VO    ████████████████████  最高
Track 2: Foley           ████████████          中
Track 3: BGM             ████████              最低
```

- Narration VO 始终最清晰，不被 Foley 或 BGM 遮蔽
- BGM 全片铺底，在 VO 停顿处自然补位
- Foley 紧贴画面动作，增强写实段落的沉浸感

## 色彩弧光审计

### 审计标准

对照 Botany_Spec.md 核验全片色调演变是否契合设定弧光：

| 段落 | 色彩弧光设定 | HSL 参考区间 |
|---|---|---|
| Section A | 清爽白底信息图 | 高亮度、低饱和、冷中性 |
| Section B | 写实自然绿棕 | 自然绿（H: 80–140, S: 30–60%）+ 泥土暖棕（H: 20–40, S: 40–70%） |
| Section C | 生活中性明亮 | 中性暖灰（H: 30–50, S: 15–35%）+ 柔和天光 |

### 视觉连续性

- 18 个分镜中植物叶形与花色的视觉连续性核验
- 相邻镜头视觉重心偏差控制在 20% 以内
- 跨组转场时色调平滑过渡，不出现突变

详细色彩弧光与视觉焦点轴线规范见 `references/craft/color-arc-eye-tracing.md`。

## 导出规格

- 总时长：45 秒
- 画幅：16:9 横版
- 组级视频分辨率：720p（最终导出可提升至更高清）
- 音频：三轨混音（VO + Foley + BGM）
- 审计通过后执行高清导出
