# 分镜图模板：知识讲解 · 讲解脚本表格

## 0. 结构化约束

> 本模板只提供该呈现形式的画面/版式细节。三道门禁、逐格状态卡、必须出现/禁止出现、人物关系证据、双阶段生成、单格质检、双版本输出、空间坐标/出场时机/角色锁、单格图作首帧、切分自检等结构化约束一律以 `storyboard/storyboard-sheet-prompt.md`「结构化分镜执行规则」为准，优先级高于本模板，模板未列出的字段以此补齐。

## 1. 类型定义与典型场景
- **类型定义**：以“镜号/画面/讲解文案/图示/时长”列为核心，将知识讲解拆解成一行一镜头的**讲解脚本表格**，同时规划口播内容与画面内容，直接可用作视频生成脚本或拍摄脚本。
- **典型场景**：
  - 课程录播/公开课，需要先写清“第几秒讲什么、画面展示什么”，方便后续统一录制或用模型生成视频。
  - 品牌/机构的科普宣导视频，需要严谨可追溯的脚本表格，便于内部审核（每一行都有对应台词与画面）。
  - 需要多轮迭代文案与画面，但不希望频繁改图，先用表格脚本锁定结构，再驱动分镜/视频生成。

## 2. 判定关键词与适用边界
- 典型触发词：`脚本表`、`分镜表格`、`讲解脚本`、`镜号`、`台本`、`口播文案`、`画面说明`、`逐镜头脚本`。
- 适用判定：
  - 用户明确要求“按镜号列出每一镜的口播文案和画面内容”“要有时长字段方便控制节奏”；
  - 强调“要给到可执行的脚本/台本”，而不仅是一张分镜图或一段口播稿；
  - 知识点顺序和时长控制很重要（例如考试辅导课、合规宣导、品牌官方科普）。
- 不适用场景：
  - 只是想为一段现成文案配一组画面 → 优先用“知识讲解·文案逐句可视化”；
  - 重点在舞台/剧情/运镜设计，而非知识讲解 → 可用剧情/影视导演镜头表模板；
  - 仅需一张图解信息图或 PPT 式静态图 → 适用“图解信息分镜”或“PPT/课程转分镜”。

## 3. 分镜结构建议
- **推荐镜头数/行数**：6–15 行（镜头），短视频知识点浓缩在 5–8 行内更易消化；长课可拆分为多张脚本表。
- 规划方式：
  - 先列出知识主线：引入 → 知识点 1/2/3… → 小结与行动建议，对每个知识点预估需要的镜头数量与时长。
  - 统一表头列：
    - 镜号（S1、S2…）
    - 画面描述（场景/人物/构图要点）
    - 讲解文案（对应口播/字幕的核心内容）
    - 图示/提示（是否需要信息图、板书、重点标记等）
    - 预估时长（秒）
  - 每行只承担一个核心信息点（一个知识点或步骤），并估算该点口播需要的时间，避免“台词塞不下”。
  - 若知识点较复杂，可用多行连续镜号拆开：第一行提出问题，后续 1–2 行用于解释与示例。

## 4. 生图 Prompt（PE）模板

```text
你是一名知识视频编导，请根据下述信息编写一份包含 {镜头数} 行的“讲解脚本表格”，用于后续知识类视频制作。脚本需按镜号划分，每行同时给出口播文案、画面内容、图示类型与预估时长。

【知识与受众信息】
- 主题：{如“信用卡最低还款的真实成本/儿童预防近视/职场邮件礼仪”等}
- 目标受众：{如“大学生/新手妈妈/职场新人/中老年人”等}
- 核心结论：{希望观众记住的 1–2 句总结性话语}
- 关键知识点列表：{拆为 3–7 条，每条将对应至少 1 行脚本}

【视频规格】
- 目标总时长：{总时长秒数，如 60 秒}
- 画幅：{如“9:16 竖屏短视频/16:9 横版课程片段”等}
- 形式：{如“讲师出镜+板书/旁白+信息图/界面操作演示”等}

【脚本表结构】
- 行数/镜头数：{镜头数，如 8 行}，镜号依次为 S1–S{N}。
- 表头列：镜号、画面描述、讲解文案、图示/提示、预估时长(秒)。
- 时长控制：单行建议 2–6 秒，重要知识点可适当加长，保证观众有时间看清画面与字幕。

【输出要求】
1. 先给出“文字版结构草案”，说明每一行大致想讲的知识点与时长区间，用于校验总时长是否合理。
2. 然后输出完整的 Markdown 脚本表格，表头为：
   - | 镜号 | 画面描述 | 讲解文案 | 图示/提示 | 预估时长(秒) |
3. 表格每一行需满足：
   - 画面描述：{简要说明场景、主体和构图，如“讲师中近景，对着镜头讲，右侧保留板书区”}；
   - 讲解文案：{口语化中文短句，建议 15–35 字，避免过长一口气说不完}；
   - 图示/提示：{是否需要叠加小标题/关键词/信息图，可写“无”“显示公式”“显示对比条形图”等}；
   - 预估时长：{整数秒或带 0.5 的数，确保总和接近目标总时长}。
4. 脚本风格需口语化、说明清楚但不过度堆砌专业术语；关键危险提示或免责声明需单独一行强调。
```

## 5. 一致性与避坑
- 保证**一行只承载一个核心信息点**，不要把多个知识点和长段口播塞在同一镜号中；复杂内容应拆成多行。
- 讲解文案需要和预估时长匹配：文本过长时应主动缩减或建议增加一行/延长时长，避免在视频阶段出现“话没说完画面就结束”的问题。
- 画面描述要与知识属性对应：理论解释段可用讲师/信息图，操作演示段需要明确界面/设备/操作对象，避免全程“讲头”单一画面。
- 全表用统一的称呼与名词（同一个概念不要反复更换叫法），镜号连续清晰，避免跳号或重复号。
- 对于涉及合规/健康/金融风险的内容，应在脚本中预留“免责声明/温馨提示”一行，不要在画面里用夸张表达误导观众。

## 6. 视频生成策略
- 对接 `storyboard-sheet-prompt.md` 中知识类执行模板：
  - 将本模板生成的脚本表格视为“文字分镜表”，在知识类视频 Prompt 中逐行映射到具体镜头或时间段；
  - 视频阶段按镜号顺序生成画面，禁止重排或跳过某行，确保每个知识点都有对应画面与口播。
- 在调用视频生成链路前，建议结合 `storyboard/dialogue-rules.md` 对每行“讲解文案”做一次时长校验：引用 `count_chars.py` 的耗时区间，必要时调整文案或时长字段，避免严重超时或空镜。
- 若后续仍需生成分镜图，可根据脚本表中“画面描述+图示/提示”列，使用教学/图解信息等模板生成对应分镜图，再在 `storyboard-sheet-prompt.md` 的知识类视频执行模板中，将“脚本表 + 分镜图”一并作为输入，实现更稳定的画面与知识对齐。
