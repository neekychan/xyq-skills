# Priority Creative Focus / 优先创意策略

When choosing the UGC marketing video direction, prioritize the following high-conversion creative engines. These are the core persuasion patterns for short-form commerce content. Use this file for direction selection, then use `creative-type-library.md` for second-level rhythm and timestamp details.

选择 UGC 营销视频方向时，优先从以下高转化创意引擎中选择。这里负责判断“该走哪种创意方向”；具体秒级节奏、镜头结构、口播方式和 CTA 细节，继续读取 `creative-type-library.md`。

| Priority creative focus / 优先创意策略 | Core hook / 核心钩子 | Best-fit scenario / 适配场景 |
|---|---|---|
| Offer-led sales / 优惠利益点前置 | Price, buy-one-get-one, coupon, limited-time deal, group-buying package, final price / 到手价、买赠、优惠券、限时、团购套餐 | Low-price goods, snacks, drinks, local services, group-buying, impulse purchase / 低价商品、零食饮品、本地生活、团购、冲动转化 |
| Voiceover seeding / 口播种草 | Creator's personal reason, daily pain point, friend-to-friend recommendation / 达人个人理由、日常痛点、朋友式推荐 | Apparel, beauty, skincare, daily goods, mother/baby, home, small electronics / 服饰、美妆护肤、日用品、母婴、家居、小家电 |
| Product review / 产品测评 | Test setup, tactile observation, comparison, verdict / 测试场景、触感观察、对比和结论 | Beauty, skincare, electronics, appliances, shoes, sports/outdoor, toys / 美妆护肤、数码家电、鞋、运动户外、玩具 |
| Benefit demo / 卖点展示 | One benefit becomes one visible action or proof / 一个卖点变成一个可见动作或证明 | Functional products, apparel details, appliances, cleaning, tools, software/platform demos / 功能型商品、服装细节、家电、清洁、工具、软件平台 |
| Effect demo / 效果展示 | Before/after, use process, result readability / 前后对比、使用过程、结果一眼可读 | Skincare, makeup, cleaning, food texture, fitness, service outcome / 护肤彩妆、清洁、食品口感、健身、服务效果 |
| Real-scene UGC vlog / 真实场景 UGC Vlog | Product naturally appears inside a believable day-in-life moment / 商品自然进入真实生活片段 | Fashion, travel, beverages, parenting, pets, home, local service / 服饰、旅游、饮品、亲子、宠物、家居、本地生活 |
| Store visit and group-buying / 探店与团购 | Route, environment, package value, redemption confidence / 到店路线、环境、套餐价值、核销信任 | Restaurants, cafes, hotels, scenic spots, medical beauty, dental, leisure services / 餐饮咖啡、酒店景区、医美口腔、休闲服务 |
| PDD-style pitch and live clip / 拼多多式口播与直播切片 | Fast benefit claim, price comparison, stock/urgency, simple CTA / 快速利益点、价格对比、库存紧迫、直接 CTA | Price-sensitive products, daily goods, apparel basics, snacks, household items / 价格敏感商品、日用品、基础服饰、零食、家居小物 |
| Drama plot / 剧情带货 | Conflict, misunderstanding, reversal, product resolves the tension / 冲突、误会、反转，商品解决矛盾 | Apparel, beauty, gifts, parenting, local service, emotional purchase scenes / 服饰、美妆、礼品、母婴、本地服务、情绪消费 |
| Listicle and carousel montage / 清单合集与轮播混剪 | Multiple SKUs, scenarios, colors, flavors, or outfits in a stable rhythm / 多 SKU、多场景、多颜色、多口味、多穿搭稳定轮播 | Accessories, outfits, shoes, snacks, drinks, gifts, small goods / 配饰、穿搭、鞋、零食饮品、礼品、小商品 |
| Side-by-side comparison / 多款对比 | Two or three options shown in one stable comparison logic / 两到三款用同一逻辑稳定对比 | Apparel variants, shoes, bags, phones, cars, packages, color shades / 服饰款式、鞋包、手机、汽车、套餐、色号 |

## Routing Rules / 路由规则

- If the user gives a clear price, coupon, package, buy-one-get-one, or final-price claim, prioritize `Offer-led sales` unless the user asks for another style.
- If the product depends on trust, texture, comfort, fit, daily usage, or personal recommendation, prioritize `Voiceover seeding` or `Real-scene UGC vlog`.
- If the product claim needs proof, choose `Product review`, `Benefit demo`, or `Effect demo`.
- If the product has many variants, colors, styles, flavors, SKUs, packages, or scenarios, choose `Listicle and carousel montage` or `Side-by-side comparison`.
- If the user provides a store, package, location, service, appointment, redemption, or group-buying deal, choose `Store visit and group-buying`.
- If the user asks for a viral style, strong hook, funny opening, meme, absurd interruption, deadpan review, or younger audience content, choose `Meme, absurd interruption, or visual hook`, then return to product and selling point in the first half.
- If the user asks for story, conflict, reversal, short drama, or emotional buying reason, choose `Drama plot`.
- If the user asks for game download, reservation, skin, character, event, welfare, IP activity, or offline check-in, choose `Game and IP campaign`.
