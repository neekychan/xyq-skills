# 灵笼电影制作器

## 核心原则

不要只做"末世风格画面拼接"，而要做**以世界观内在逻辑驱动每一个视觉决策**的电影级叙事——灵笼的视觉力量来自社会等级的空间编码、生物恐怖的日常化渗透、东方哲思的视觉化表达，以及战斗编排的真实物理约束。缺少这些，画面再精致也只是"废土皮"而非"灵笼骨"。

持久引擎（因果链）：

**世界观要素（灯塔/废土/玛娜生态/龙骨村） → 社会等级视觉化 → 场景类型判定 → 导演风格选择 → 分镜设计（shot拆分/合并决策） → 元素资产生成（角色三视图/场景四宫格/生物道具/对白音频） → 逐镜头视频生成（引用绑定+视觉锚点注入） → 音频层生成（BGM/旁白/对白错峰） → 最终组装（转场/音频同步/超分选择） → 成片交付**

### 质量测试（可证伪）

创意只有通过这条测试才算成立：

**如果抽掉灵笼世界观的四个核心场景（灯塔/废土/玛娜生态/龙骨村）中任何一个，或抽掉社会等级视觉化叙事，整片的情感弧线与哲学表达就无法成立——则分镜设计通过；否则只是套了废土皮的普通视频，须重做。**

## 输入诊断

生产前，识别或合理假设以下维度：

- **目标篇幅：** 默认 1-3 分钟（可覆盖）。1 分钟约 6-10 个 shot，2 分钟约 12-18 个，3 分钟约 18-25 个。
- **画幅与帧率：** 16:9 横屏，24fps（电影感），不可更改。
- **输出语言：** 默认中文（可覆盖）。提示词正文跟随用户语言；视频内对白/旁白台词遵循 Final_Video_Spec 锁定的输出语言。
- **视觉风格定位：** 半写实3D CG电影级末日废土科幻——介于高精度写实渲染与动漫风格化之间，核心是写实级渲染而非2D赛璐璐或日系二次元。基调黑暗、压抑、苍凉，废墟中穿插唯美光影与东方哲思诗意感。
- **导演风格：** 纪实沉浸风 / 史诗悲壮风 / 恐怖惊悚风。用户可指定单一风格贯穿全片，也可按段落混合。未指定时按场景类型默认匹配。
- **世界观场景覆盖：** 涉及哪些场景类型（地表废土/灯塔内部/玛娜生态核心区/龙骨村）？各场景的叙事比重。
- **角色清单：** 外貌、性格、装备、造型变化。猎荒者（机能风/战术军事风装备） vs 灯塔上层人员（白色/浅灰无菌感制服）。多造型须逐一描述。
- **生物清单：** 噬极兽/脊蛊/玛娜之花等，须明确种类、体型、行为特征。
- **叙事弧线：** 用户提供的剧情/灵感/大纲。若仅有灵感，须先走编剧引导流程（生成多方向 → 选定 → 分场剧本 → 分镜脚本）。
- **素材盘点：** 用户已上传哪些素材（角色参考图/场景参考图/角色参考音频/视频参考素材/文本文档）？已上传素材须先通过素材分析模块检测格式与风格一致性，绑定到正确 Storyboard 锚点，避免重复生成。
- **音频需求：** 是否需要旁白？旁白叙述者人设（如\[苍凉低沉男声\]）？BGM 基调？角色对白音色是否需要跨镜头一致（key_element_audio 绑定）？
- **超分需求：** 最终合成前须询问用户是否超分（建议 1080p，fps 24）。

若用户给的上下文很少，做合理假设并继续。仅当剧情方向、角色设定或目标篇幅确实无法推断时才发问。

## 工作流（步骤）

### 全片流程与依赖关系

```
步骤1: Final_Video_Spec.md（规格锁定）
  ↓
步骤2: Storyboard 设计（分镜脚本）
  ↓
步骤3: 元素资产生成（角色三视图 / 场景四宫格 / 生物道具 / 对白音频）
  ↓
步骤4: 逐镜头视频生成
  ↓
步骤5: 音频层生成（BGM / 旁白）
  ↓
步骤6: 最终组装（含超分选择）
```

依赖：2→1；3→2；4→3；5→2；6→3,4,5。

### 模型与失败处理

- **图像仅用 GPT Image 2**，视频仅用 **Seedance 2.0**，禁用其他模型。
- 失败时自动重试同一模型一次（应对瞬时故障）；仍失败则停止并告知用户，不静默切换模型。

### 步骤 1：建立 Final_Video_Spec.md

建立全片规格文件，锁定以下参数：
- 标题、类型、画幅（16:9）、时长（默认 1-3 分钟，可覆盖）、帧率（24fps）、视觉风格（半写实3D CG末日废土科幻）、输出语言（默认中文，可覆盖）。

Spec 锁定后进入里程碑暂停，与用户确认后方可继续。

### 步骤 2：生成 Storyboard

读取 `references/storyboard-design.md`，按其规范设计分镜脚本。Storyboard 须包含：
- **key_element 列表：** 角色（element character）、场景（element scene）、生物（key_element）、道具（key_element）。
- **shot 列表：** 每个 shot 包含场景引用、故事节拍（角色动作/对白，引用 character element ID）、摄影语言（景别、机位高低、运镜、**角色朝向**）。
- **audio_layer 列表：** BGM 轨、旁白轨（narration_speaker_profile + 脚本 + layout_instruction）。

完成后检查所有元素资产是否已生成并绑定，**严禁元素遗漏时进入下一步**。

里程碑暂停：Spec 锁定 → Storyboard 完成 → 用户确认后继续。

### 步骤 3：建立元素资产

读取 `references/image-prompt-grammar.md`，按其规范生成元素资产。如需分析用户上传素材，同时读取 `references/asset-analysis.md`。

**资产类型与规格（GPT Image 2，2K）：**

| 资产类型 | 生成方式 | 画幅 | 格式要求 |
|---|---|---|---|
| 角色三视图 | TextToImage / ImageToImage（多造型） | **16:9** | 全身三视图（正面、侧面、背面横向排列），严禁半身 |
| 场景参考图 | TextToImage | **4:3** | 多角度无人物四宫格（2×2） |
| 生物与道具参考图 | TextToImage / ImageToImage（多形态） | **4:3** | 生物须展现完整体型与生物力学细节；道具须中性背景多角度展示 |

**用户素材处理原则：**
- 角色三视图：优先用户上传，格式不符则参考素材重新制作。
- 场景参考图：优先用户上传，格式不符则参考素材重新制作。
- 已上传媒体须先通过素材分析模块绑定到正确 Storyboard 锚点，避免重复生成。
- 素材与目标风格不符时，以用户素材为基础重新制作符合风格的版本。

**对白音频绑定（key_element_audio）：**
- 进入步骤 4 前，须为所有有对白角色完成 key_element_audio 绑定。
- 有上传音频 → 直接绑定。
- 无上传音频 → 用 text to narration 生成 2-3 句对白样本作为参考源。

里程碑暂停：元素图像（角色/场景/生物道具/key_element_audio）一批一次性确认后继续。

### 步骤 4：逐镜头生成最终视频

读取 `references/video-prompt-grammar.md`，按其规范为每个 shot 编写视频提示词并生成。

**生成规格（Seedance 2.0，720p，4-15s）：**

**视频生成前核查（六项全过方可生成）：**
1. 场景参考图已引用
2. 人物参考图已引用
3. 台词对白完整
4. 旁白完整
5. 关键动作细节已体现
6. 图像引用总数 ≤ 9、音频引用总数 ≤ 3（超限已按优先级裁剪）

**图像引用优先级（总数不超过 9 张）：**
① 出场角色三视图（按戏份重要性排序，核心角色先绑，建议单镜头角色 ≤ 5 人）→ ② 场景参考图（1 张）→ ③ 关键道具/生物参考图。超限时优先保留核心交互角色与场景图，次要角色仅文字描述不绑图像。

**音频引用（audio_infos，总数不超过 3 条）：**
含对白镜头将 key_element_audio 填入 audio_infos。同镜有对白角色超过 3 人时，优先绑定台词最长/戏份最重的前 3 名，其余改为纯文字描述或拆分镜头。

**连续性处理：**
仅连续性极强时追加上一镜视频作为 reference_video，通常跳过。

里程碑暂停：镜头视频按场景段落批量确认。

### 步骤 5：生成音频层

按 Storyboard 中规划的 audio_layer 生成：
- **BGM：** text_to_instrumental，基调苍凉压抑、史诗悲壮。长片（3分钟+）可在转折点分段。
- **旁白：** text to narration，定义 narration_speaker_profile（如\[苍凉低沉男声\]）、语气与确切脚本。

里程碑暂停：音频完成后用户确认。

### 步骤 6：最终组装

读取 `references/video-assembly.md`，按其规范执行最终合成。

**合成前必须询问用户是否超分。** 确认后用 super_resolution（建议 1080p，fps 24）处理再合成；拒绝则按原始分辨率合成。

### 编剧与导演引导（当用户仅有灵感、尚无完整剧本时）

当用户仅有关键词或灵感时，按以下流程引导：
1. 根据关键词或灵感生成多个故事方向供选择。
2. 选定后扩展为分场剧本。
3. 再生成分镜脚本（含景别、运镜、转场）。
4. 每阶段输出后与用户确认，支持局部修改。

**导演风格选项：**
- **纪实沉浸风：** 长镜头跟随与手持摄影为主，减少切换，强调临场真实感；旁白克制。适合探索与生存题材。全段偏长镜头（10-15s），手持为主，切换极少（0-1次）。
- **史诗悲壮风：** 大远景与航拍展现巨物与渺小对比，慢动作高潮配合史诗 BGM；旁白承载存在主义叩问。适合大规模战斗与文明兴衰题材。大远景与航拍交替，镜头内含 2-3 次切换。
- **恐怖惊悚风：** 压抑幽闭构图、低光照、突发 jump scare；音效强化噬极兽嘶吼与黏液声，营造克苏鲁式生物恐怖。适合玛娜生态与遭遇战题材。单镜偏短（4-8s），切换频繁（3-4次）。

用户可指定单一风格贯穿全片，也可按段落混合。混合风格段落衔接处用渐黑或空镜缓冲风格落差；过渡镜时长取相邻段落区间中间值。

### 工作原则

- **用户主导创意：** 剧情构思由用户提供；元素资产优先用户提供，无法提供时系统生成。已提供媒体须先绑定到正确 Storyboard 锚点，避免重复生成。素材与目标风格不符时，以用户素材为基础重新制作符合风格的版本。
- **分阶段批量确认：** 在 Spec 锁定、Storyboard 完成、元素批次完成、各场景段落视频完成、音频完成、最终合成前（含超分选择）里程碑暂停审阅。同一批次内可连续生成后统一确认。

### 视频生成方式

- **单镜头时长 4-15s：** 每个 shot 对应一次视频生成调用（Seedance 2.0），一次生成即可拿到该 shot 的完整片段。shot 内的 beat（如 0-3s/3-7s/…）是同一次生成内部的时间轴描述，不等于要多次调用。
- **全片 >15s 时：** 拆成多个 ≤15s 的 shot 片段分别生成，再做后处理拼接。
- **镜头总量对齐：** 所有 shot 时长之和须与 Final_Video_Spec.md 锁定的目标篇幅对齐。完成后累计核对，超出或低于范围则调整 shot 数量或单镜时长。

### 图像提示词结构（TextToImage / ImageToImage, GPT Image 2）

核心风格锚定词（融入描述）：cinematic 3D CGI animation, semi-realistic anime style, post-apocalyptic sci-fi, high-fidelity rendering, subsurface scattering skin, pore-level detail, dirty realism aesthetic, cinematic lighting, volumetric light rays with dust particles, muted color palette with selective vivid accents。

详细写法见 `references/image-prompt-grammar.md`。

### 视频提示词结构（MultiModalToVideo, Seedance 2.0）

- 参考图绑定：用 <<<image_1>>>、<<<image_2>>> 等占位符逐角色/场景绑定。
- 运动栈：相机（运动/切换）→ 主体（动作与面部节拍）→ 空间（走位/环境变化）→ 音频（对白/音效备注）。
- 包装符：音乐 (...)、音效 <...>、对白 {...}、屏幕标题 【...】。

详细写法见 `references/video-prompt-grammar.md`。

## 静默自检

交付前内部跑清单并重写弱项，不外显。

- Final_Video_Spec 是否锁定（画幅 16:9、帧率 24fps、时长、输出语言）？
- Storyboard 中所有 key_element 是否已生成资产并绑定？有无遗漏？
- 角色 三视图是否为全身三视图（正面/侧面/背面）？画幅是否 16:9？
- 场景参考图是否为无人物四宫格（2×2）？画幅是否 4:3？
- 生物设计是否保持恐怖写实与生物力学合理性？有无卡通化或 Q 版？
- 每个 shot 的图像引用是否 ≤ 9 张？音频引用是否 ≤ 3 条？超限是否已按优先级裁剪？
- 有对白角色是否全部完成 key_element_audio 绑定？
- 视频 生成前六项核查是否全部通过？
- 角色朝向是否显式标注？背对镜头的镜头是否有多重朝向锚定？
