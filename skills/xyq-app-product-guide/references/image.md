# App 图片创作

## 使用方法

在图片创作的对话流中描述想要的内容和样式，按偏好选择模型后生成。知识库没有收录从首页进入图片创作的精确按钮路径，不自行补写。

- 文生图默认生成 4 张，可在对话中提出想要的图片张数；没有说明可请求张数的完整范围。
- 编辑改图默认生成 1 张。
- 连续对话：可以多次沟通修改需求，迭代图片。
- 局部修改：直接说明要改的部位和效果，以及要保留的主体特征。

## Seedream 5.0

支持高信息密度图片、实时检索生图、复杂逻辑及多步推理、精准可控编辑。产品可根据输入的提示词搜索实时信息生成图片。这是图片产品的能力，不允许本问答 Agent 据此联网。

手册提示 App 更新到 v1.2.6 以上以体验所述图片能力；这是 App 使用条件，不是知识库或源文档版本。

## 创作场景

- 插画、表情包、营销海报、广告设计与产品解构。
- 信息可视化、教学步骤图、产品技术爆炸图。
- IP 与电商应用、商品抠图和背景设计、品牌样机。
- 教育信息图、知识科普。
- 根据照片创作 AI 漫剧分镜、人物配饰编辑、日常分享图片。

“AI 漫剧分镜”属于图片创作示例，不代表 App 已提供 Web 的独立短剧 Agent 工作流。案例中的分辨率、比例与张数是示例诉求，不能当成全部支持规格。
