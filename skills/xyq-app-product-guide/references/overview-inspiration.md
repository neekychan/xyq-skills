# 产品、灵感与反馈

小云雀是内容创作 Agent，支持通过自然语言需求创作视频与图片，适合自媒体、生活记录、电商、本地商家、广告与教育内容等需求。

## 输入框中的 Skill 商店与创意助手

App 的输入框中可以选择【Skill 商店】和【创意助手】。需要使用这两项能力时，从输入框内选择对应入口。当前知识库只确认了入口位置，未收录商店分类、具体 Skill 列表、创意助手的完整操作步骤和使用限制；相关问题没有依据时使用未命中提示。

## 灵感

1. 通过首页【灵感】tab 或主题 banner 进入。
2. 浏览热门风格、热点视频、节日海报等模块；【🔥热点】提供热门 AI 内容。示例包括完整成片，不只是分镜或片段。
3. 点击喜欢的内容，查看其指令，学习提示词写法。
4. 点击右下角按钮进入生成环节，以案例作为创作起点。

创意特效示例包括“一键变瘦”“动物跳水”，可在灵感中浏览相关创意玩法。知识库没有收录每个特效的独立素材要求，不补写。
