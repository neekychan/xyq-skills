# 侏罗纪93电影工坊

本技能以1993年斯皮尔伯格《侏罗纪公园》第一部的视觉语言为唯一锚点，生产写实恐龙电影短片。全流程分六个阶段，阶段间有固定依赖顺序与里程碑确认点。所有产出——图像、视频、音频——必须与下方「视觉风格锚点」对齐，不得滑向现代CGI风格、卡通化或《侏罗纪世界》改版视觉。

## 视觉风格锚点（全局注入所有 shot 和 element）

- **时代感：** 1993年斯皮尔伯格《侏罗纪公园》第一部；35mm复古胶片摄影；16:9 画幅。
- **胶片质感：** 厚重胶片颗粒，8K修复胶片画质，柔和复古电影色阶，轻微晕影。
- **调色：** 90年代好莱坞商业大片写实调色；低饱和度复古绿调为主导色相；自然写实色彩，无现代高对比度HDR感。
- **光影：** 自然写实物理光影；光源动机明确（阳光、灯具等实体光源驱动）；避免数字渲染感或AI过度锐化。

## 核心原则

不要把恐龙拍成"特效展示"，而要拍成"被撞见的活物"——恐惧与敬畏来自生物的体量、纹理与不可预测的行为节拍，而非镜头炫耀。

持久引擎（因果链）：

**叙事意图 → 场景压力（围栏/丛林/暴雨）→ 恐龙作为不可控变量登场 → 人物反应镜头（斯皮尔伯格交叉剪辑）→ 体量感仰拍 + 皮肤纹理特写 → 1993胶片质感统一 → 全片装配**

### 质量测试（可证伪）

每条 shot 必须通过这条测试才算成立：

**如果把这头恐龙替换成一块石头或一辆车，这个镜头的恐惧/敬畏/转折是否还成立？若成立，该 shot 没有让恐龙作为"活物"发挥作用，重做。**

具体而言：恐龙的皮肤纹理、运动节拍或体量冲击必须在画面中承担叙事功能（制造威胁、揭示存在、改变人物行动决策），而非仅作背景装饰。

## 输入诊断

生产前，识别或合理假设以下维度：

- **叙事意图：** 用户想讲什么故事（发现/追逐/对峙/共生/逃亡）？是否有剧本草稿？
- **目标市场 / 输出语言：** 产物正文用中文；片中对白/旁白语言由 Final_Video_Spec 指定。用户使用中文交互时 prompt 正文以中文书写，对白/旁白台词遵循 Spec 指定语言。
- **画幅与时长：** 默认 16:9；时长意图（单 shot ≤15s，成片可拼多段）。
- **恐龙物种与数量：** 涉及哪些恐龙？参照 `references/elements-dinosaurs.md` 的预设模板（霸王龙/迅猛龙/腕龙），或按四维度规范自行定义新物种。
- **核心场景：** 丛林/访客中心/围栏区？参照 `references/elements-scenes.md`，或自行定义。
- **角色阵容：** 人类角色有哪些？外貌/服装/发型锚定（符合90年代写实风格）；多造型逐一列出。
- **关键道具：** 吉普车/夜视镜/骨架化石/警示标牌等。
- **参考素材：** 用户是否上传参考图？若有，提取调色/胶片/光影/构图信号，并与本技能视觉锚点对齐，不得矛盾（见下方「上传素材处理」）。
- **音频层需求：** 是否需要 BGM（约翰·威廉姆斯管弦乐风格）/ VO 旁白 / 环境音效？旁白需定义 narration_speaker_profile。
- **合规敏感点：** 恐龙攻击人类的暴力尺度控制在 PG-13 级别（暗示重于展示）；不出现血腥撕咬特写；儿童角色不出现在直接威胁画面中。

若用户给的上下文很少，做合理假设并继续。仅当叙事意图、恐龙物种或核心场景确实无法推断时才发问。

## 上传素材处理

若用户提供参考图像（剧照、概念图、场景图），提取以下信号并结构化输出供下游使用：

- **调色特征：** 色温、主导色相、饱和度范围、阴影/高光色阶倾向。
- **胶片质感：** 颗粒密度、胶片曝光感、对比度曲线特征。
- **光影结构：** 主光方向、光质（硬/软）、环境光比例。
- **构图与镜头语言：** 焦距感知、景深范围、画幅裁切线索。

提取结果须与本技能视觉风格锚点（1993《侏罗纪公园》35mm写实调色）对齐，不得矛盾。若参考图风格与锚点冲突（如现代高饱和HDR、霓虹冷调、卡通渲染），以锚点为准并告知用户已做修正。

## 全片制作流程（六阶段）

### 依赖关系与里程碑

```
阶段1 锁定规格 ← 阶段2 设计Storyboard
阶段3 生成Element ← 阶段2
阶段4 生成Shot视频 ← 阶段3
阶段5 生成音频 ← 阶段2
阶段6 全片装配 ← 阶段3, 4, 5
```

**里程碑确认：** 每个主要阶段（规格锁定、Storyboard完成、Element完成、Shot视频完成、音频完成）完成后**暂停**，等待用户确认后再推进下一阶段。不得跳过里程碑。

---

### 阶段1：锁定 Final_Video_Spec

建立全局规格文件，锁定以下参数：

- **画幅比例：** 16:9
- **时长意图：** 总片长 / shot 数量预估
- **视觉风格：** 1993年斯皮尔伯格《侏罗纪公园》第一部，35mm复古胶片（与上方「视觉风格锚点」一致）
- **输出语言：** 片中对白/旁白语言
- **恐龙物种清单：** 引用 `references/elements-dinosaurs.md` 模板或自定义
- **场景清单：** 引用 `references/elements-scenes.md` 模板或自定义
- **角色与道具清单**

**里程碑：规格锁定 → 暂停 → 用户确认。**

---

### 阶段2：设计 Storyboard

Storyboard 包含三个部分：key elements（角色/场景/道具）、shot 列表、audio layers。

#### 2a. 设计 key elements

覆盖主要角色、核心场景、关键道具。

**角色描述须包含：** 外貌、服装（符合90年代写实风格）、肤色/发型的具体锚定；如有多个造型，逐一列出。

**场景描述须包含：** 地貌/环境构成、光线条件（时段、天气）、场景内主要道具的位置关系；描述须与35mm写实胶片质感兼容。

**恐龙类 key element 专属规范（四维度）：** 详见 `references/elements-dinosaurs.md`。每个恐龙 element 必须锁定皮肤纹理、体型比例、运动方式、1993年电影视觉校准四个维度。

**预设模板可直接引用：** 霸王龙 / 迅猛龙 / 腕龙（见 `references/elements-dinosaurs.md`）；岛屿热带丛林 / 访客中心 / 高压围栏区（见 `references/elements-scenes.md`）。

#### 2b. 设计 shots

**镜头时长：** 优先设计 8–15s 的较长 take，内含内切（如推近+剪切到特写）；单 shot 不超过 15s。**≤15s 的 shot 用一次视频生成即可拿到完整片段**，shot 内的 beat（如 0-3s/3-7s/…）是同一条 prompt 内的时间轴描述，不等于要多次调用。成片总时长超过 15s 时，拆成多个 ≤15s 的 shot 片段分别生成，再做后处理拼接。

**每个 shot 描述须包含：**

- **场景：** 引用对应 element scene ID。
- **故事节拍：** 角色动作与情绪弧线；若有对白，写出精确台词，引用角色 element ID。
- **摄影语言：** 镜别（远景/中景/近景/特写/极近特写）、摄影机运动（从 `references/prompt-vocabulary.md` 的摄影机运动词库按需选取并标注具体运动参数）、构图（三分法/低角度仰拍强调生物威压感/前景遮挡制造悬疑）。
- **光影备注：** 时段、主光方向、环境光氛围（如傍晚侧逆光营造剪影张力）。
- **斯皮尔伯格构图偏好：** 大量低角度仰拍强调恐龙体量；前景遮挡制造悬疑；缓慢推镜积累张力；主角反应镜头与生物镜头交叉剪辑。

#### 2c. 设计跨 shot 音频层

- **BGM：** 参考约翰·威廉姆斯管弦乐风格，宏大写实交响乐感；根据叙事节奏可分段设计。
- **环境音/SFX：** 在 shot 描述中注明关键自然环境音（丛林虫鸣、雨声、脚步震动等），供生成时参考。
- **VO 旁白：** 若有旁白，定义 narration_speaker_profile（如：[沉稳男声，磁性，纪录片叙述风格]）及脚本内容。

**里程碑：Storyboard完成 → 暂停 → 用户确认。**

---

### 阶段3：生成 Element 资产

若用户已上传元素资产，直接绑定到对应 Storyboard 槽位；否则生成图像。

**图像生成规范：**

- 生成场景/道具元素图使用文生图能力；同一角色的不同造型优先使用图生图以保持跨造型一致性。
- 推荐分辨率 2K。
- 风格提示须包含35mm胶片颗粒感、写实自然光影、低饱和复古绿调等视觉锚点（固定短语见 `references/prompt-vocabulary.md`）。
- **角色图：** 生成横向拼合参考图——左侧头肩特写（面部特征锚定）、右侧全身（服装/体型）。
- **恐龙图：** 必须严格遵守 `references/elements-dinosaurs.md` 的四维度规范与 prompt 专属规范。
- key_element 图像锁定外观、服装、材质状态；避免画面内出现无关文字。

**图像 prompt 结构：** 主体 + 动作/姿态 → 环境/背景 → 光线条件 → 视觉风格固定短语 → 构图/镜别（详见 `references/prompt-vocabulary.md`）。

**里程碑：Element完成 → 暂停 → 用户确认。**

---

### 阶段4：逐 Shot 生成视频

逐 shot 生成最终视频片段。

**视频生成规范：**

- 分辨率 720p。
- 每个 shot 的参考输入：
  1. **Element 图像：** 该 shot 涉及的所有角色、场景、道具的 element 图像（默认必须绑定）。
  2. **前一 shot 视频（reference_video）：** 仅在与前镜头连续性极强时使用；常规情况下跳过，避免引入不必要的运动约束。
- 画幅在阶段6装配时确认为 16:9。

**视频 prompt 结构：** 参考图绑定占位符（<<<image_1>>>、<<<image_2>>> …，每个角色/场景独立标注）→ 运动描述栈：摄影机（运动类型/速度）→ 主体（动作节拍/面部反应）→ 空间（环境变化/遮挡关系）→ 音效提示（环境音/SFX；若无独立 VO 轨则在此注明）。固定负向词与斯皮尔伯格镜头语言词汇见 `references/prompt-vocabulary.md`。

**里程碑：Shot视频完成 → 暂停 → 用户确认。**

---

### 阶段5：生成音频层

生成所有音频层：

- **BGM：** 管弦乐风格描述，强调写实交响、90年代好莱坞冒险片质感。
- **VO 旁白：** 按 Storyboard 中定义的 narration_speaker_profile 设置音色，按脚本内容生成。
- **环境音/SFX：** 与 shot 描述中注明的关键自然环境音对齐。

**里程碑：音频完成 → 暂停 → 用户确认。**

---

### 阶段6：全片装配与导出

完成全片剪辑装配并引导用户导出。

#### 画幅与节奏

- 最终输出画幅 16:9；若生成素材比例不符，优先裁切而非压缩变形。
- 整体剪辑节奏参考90年代好莱坞叙事片：张力段落适度拉长 shot 时长制造悬疑，动作/追逐段落收紧节拍；避免现代快剪风格。

#### 转场

- 默认使用直切；情感过渡或时间跳跃段落可使用淡入淡出或溶叠；禁止使用花哨数字特效转场。

#### 音频混合

- BGM 层垫底，整体音量控制在不掩盖对白和关键 SFX 的水平。
- 环境音/SFX 层与画面动作同步（如恐龙脚步震动与画面对齐）。
- VO 旁白层优先级高于 BGM，保证清晰度。
- shot 内置音频与独立音频层混合时，注意避免对白/VO 重叠。

**里程碑：全片装配完成 → 展示成片 → 引导用户导出。**

## 静默自检

交付前内部跑清单并重写弱项。除非用户要求点评，否则不外显。

- 视觉风格锚点是否在每条 prompt 中注入（35mm胶片/低饱和复古绿调/自然光影/16:9）？
- 恐龙 prompt 是否通过四维度规范（皮肤纹理/体型比例/运动方式/1993校准）？是否出现禁止词（feathered、sleek smooth skin、vibrant saturated scales等）？
- 恐龙视觉是否对齐1993斯坦·温斯顿版本而非《侏罗纪世界》改版？
- 每个 shot 是否通过质量测试（恐龙在画面中承担叙事功能而非仅作背景）？
- shot 时长是否 ≤15s？若是，是否作为一次生成的完整片段（多段 beat 写在同一条 prompt 内）？成片 >15s 时是否已拆成多个 ≤15s 片段？
- 里程碑确认是否在每个阶段后执行（未跳过）？
- 视频负向词是否包含 no subtitles、no music（BGM走独立音频层）？若有独立 VO 轨，是否包含 no voiceover in video？
- 转场是否默认直切、无花哨特效？
