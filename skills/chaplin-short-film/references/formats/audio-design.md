# 音频设计规范

## 整体音频架构
采用三轨道结构：
1. 轨道1：视频画面（含字幕卡）
2. 轨道2：音效
3. 轨道3：配乐

## 配乐规范

### 配乐风格选项
1. **钢琴独奏（默认）**：温暖、抒情，适合情感类、治愈类故事，参考卓别林电影原声风格
2. **Ragtime（拉格泰姆）**：轻快、跳跃，适合喜剧占比高的追逐类、搞笑类故事
3. **弦乐四重奏**：深沉、优雅，适合社会寓言、悲剧内核较重的故事
4. **小型爵士乐队**：活泼、有年代感，适合城市背景、市井生活类故事
5. **现代配乐（仅B模式使用）**：在保留默片视觉的基础上，可使用现代极简钢琴、氛围音乐等风格，形成反差感

### 配乐节奏要求
- 喜剧段落：节奏明快，速度约120-140BPM，与画面动作节奏匹配
- 情感段落：节奏舒缓，速度约60-80BPM，旋律温暖抒情
- 追逐段落：节奏紧张，速度约140-160BPM，使用顿音、跳音增强喜剧感
- 结尾段落：节奏渐慢，旋律慢慢收束，与画面渐暗同步结束
- 音量标准：配乐整体音量-12dB，不得盖过音效

### 配乐创作规则
1. 全片配乐保持风格统一，不得随意切换风格
2. 旋律要简单易记，有歌唱性，符合默片时代的音乐特征
3. 音乐情绪要与画面情绪匹配，避免音画对立（特殊喜剧效果除外）
4. 结尾音乐必须缓慢淡出，与人物走向远方的画面同步结束
5. C模式（带对白）下，配乐音量适当降低到-15dB，避免盖过人声

## 音效规范

### 必加音效类型
1. **动作音效**：脚步声、手杖敲击地面声、摔倒声、碰撞声、开门声等，匹配画面动作
2. **环境音效**：街道嘈杂声、工厂机器声、风声、雨声等，营造场景氛围
3. **喜剧音效**：滑到的哨声、碰撞的夸张音效、追逐时的快节奏音效等，增强喜剧效果（默片风格的拟音，非现代搞笑音效）
4. **情感音效**：轻柔的钟声、风吹树叶声等，烘托情感氛围

### 音效设计规则
1. 音效采用默片时代的拟音风格，夸张但不突兀，符合早期电影音效特征
2. 音量标准：音效整体音量-8dB，比配乐高4dB，保证动作声音清晰
3. 音效与画面严格同步，口技、拟音风格优先，不用太写实的现代音效
4. 纯默片模式（A模式）下，音效可以适当夸张，增强喜剧效果
5. 禁止使用现代电子音效、合成音效，所有音效必须符合1920年代声学特征

## 对白规范（仅C模式使用）
1. 对白风格：简洁、克制，符合默片台词特点，不用长句
2. 配音风格：略带戏剧感的表演风格，不要太生活化的现代配音
3. 音量标准：人声音量-6dB，清晰可闻
4. 字幕卡与对白配合：关键台词仍然可以用字幕卡强调，一般对白直接用人声
5. 无需全程对白，保留默片的肢体表演优势，对白只作为补充

## 音频合成规则
1. 所有音频轨道电平统一，避免忽大忽小
2. 音乐与音效层次清晰，不互相掩盖
3. 转场处音频与画面同步淡入淡出
4. 结尾处所有声音随画面渐暗一起缓慢淡出，不要突然切黑断音
5. 整体音频动态范围不要过大，保持舒适的听感
